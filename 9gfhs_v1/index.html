Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Aims: To examine how framing of an animal's use in educational teaching influences people's perceptions of the animal's mind and the moral concern given to it.

Methods: Members of the New Zealand and Australian public (n=439 after exclusions) were recruited through an online platform and randomly assigned to read one of three vignettes describing a rabbit: a naturalistic vignette depicting the rabbit in its wild habitat (control; n=146), an observational teaching vignette (n=147), or an intervention teaching vignette describing a surgical procedure (n=146). All three vignettes were portrayed as occurring within an established ethical framework. Participants rated their perceptions of the rabbit's mental capabilities (two dimensions of mind perception: affective sociality and cognitive autonomy) and their moral concern for the rabbit, each on a scale from 0-7.

Results: There was no evidence that perceptions of the rabbit's affective sociality differed across vignettes: (ANOVA estimate of effect size (η²: a proportion ranging from 0 to 1) = 0.007, 90% CI = 0.000-0.022). Score for perceptions of its cognitive autonomy were slightly lower in the teaching vignettes than in the naturalistic vignette (naturalistic versus observational mean difference 0.45, 95% CI=0.06-0.84): a small effect (η²=0.019, 90% CI = 0.002-0.042). Contrary to a mind-denial prediction, moral concern score was higher in both teaching vignettes than in the naturalistic vignette (observational: 0.58 (95% CI = 0.29-0.88) points higher; intervention: 0.50 (95% CI = 0.20-0.79) points higher, statistically adjusting for mind perception). Moral concern was associated with perceptions of the rabbit's affective sociality (0.30 (95% CI = 0.21-0.38) points per scale point) but not its cognitive autonomy.

Conclusions: Framing a rabbit's use within a teaching context did not produce the mind denial seen when people consider animals used for meat or testing; moral concern was not diminished and was higher than for a naturalistic portrayal. Moral concern was driven by perceptions of the animal's capacity for emotional experience, which teaching-use did not reduce, leaving little basis for the withdrawal of mind and moral concern that characterises moral disengagement. Because all scenarios were ethically framed, these effects cannot be attributed to the ethical framing itself.

Clinical relevance: Among members of the New Zealand and Australian public, presenting an animal's use in education as ethically regulated was associated with greater, not lesser, moral concern for the animal. Whether this holds for veterinary students, and whether ethical framing is an operative factor, remains for future research.

Introduction

Animals are used in veterinary and biomedical education for dissection, teaching clinical skills, and, in some settings, live surgical training (Zemanova and Knight 2021). In New Zealand and Australia, this use is governed by legislation that requires ethical oversight, humane treatment, and consideration of alternatives (Anonymous 1999; NHMRC 2013). Even under such oversight, public and professional attitudes to using animals in teaching remain mixed. A recent Australian and New Zealand Council for the Care of Animals in Research and Teaching (ANZCCART) survey found that New Zealanders expressed moderate support for using animals in educational settings, but many felt uninformed about these practices (NielsenIQ 2023). Support may soften when people are made aware of the potential harm animals can experience during teaching (Williams et al. 2007), which suggests that acceptance depends partly on how the use of animals is framed and understood. Yet little research has examined how the framing of educational animal use shapes what the public perceives about the animals themselves: their mental capacities and the moral concern given to them. The present study begins to address this gap.

Mind perception

To understand how teaching contexts influence perceptions of animals, we draw on research on mind perception -the psychological process by which people attribute mental capacities to entities in their environment (Waytz et al. 2010). People tend to perceive and judge minds along two primary dimensions (Gray et al. 2007): affective capacities, relating to a being's emotional and social experience of the world, and agentic capacities, relating to its ability to think, plan, and control its circumstances. While mind perception is typically described in terms of experience and agency, Gray et al. (2007) derived their structure from judgements comparing a deliberately varied set of targets -human and non-human, living and non-living -and so describes how people discriminate minds between different kinds of entities rather than how judgements about animals are organised. Studies measuring mental capacities in animals specifically suggest a somewhat different structure (Rasmussen et al. 1993; Philipp and McMurtrie 2026). We therefore use terms established on animal targets: affective sociality (the perceived capacity to feel emotions, form social bonds, and experience pleasure or distress) and cognitive autonomy (the perceived capacity for planning, self-control, and goal-directed behaviour). The distinction matters morally. A being seen as capable of emotional experience is regarded as a moral patient: vulnerable to harm, deserving of empathy, and afforded greater moral concern. A being seen as capable of intentional, autonomous action is regarded as a moral agent, held responsible for its conduct (Gray et al. 2012).

The mind we perceive in an animal is not fixed; the context in which we encounter it can shift our perceptions and, in turn, our moral response. People ascribe reduced mental capacities to animals depicted as objects of human consumption compared with the same animals in naturalistic settings (Loughnan et al. 2010; Bastian et al. 2012; Vezirian et al. 2024), a phenomenon termed mind denial. The leading explanation is motivational (Bastian and Loughnan 2017): caring about animals while also using or eating them creates discomfort and denying an animal's capacity to think and feel eases that tension by removing the psychological basis for moral concern (Bastian et al. 2012; Loughnan et al. 2014). These attributions are strategic rather than fixed. People flexibly adjust the minds they grant to animals to fit their own use of them, for example attributing fewer capacities to the specific animals their diet relies on (Ioannidou et al. 2024). However, the evidence for this motivational account is mixed: if mind denial serves to resolve discomfort, then greater harm to the animal, or greater personal responsibility for it, should intensify the effect. Experimental attempts to demonstrate this have not consistently succeeded (Vezirian et al. 2024).

Research on animal mind denial has mainly treated perceptions of mind as a single quantity (Bastian et al. 2012; Vezirian et al. 2024), and where separate dimensions have been individually measured , each dimension's association with moral concern has been reported separately, without testing whether one predicts moral concern more strongly than the other (Ioannidou et al. 2024). It is not known whether a given use-context shifts the two differently: whether seeing an animal used by humans reshapes perceptions of its emotional and social life, its capacity for autonomous action, or both.

The present study

Mind denial has been studied almost entirely in animals categorised as food or as research subjects (Bastian et al. 2012; Vezirian et al. 2024). Notably, the phenomenon of mind denial appears to follow from the categorisation of the animal as a food or research animal, rather than from perceptions around the extent of the harm the animal will be subjected to or the extent of the responsibility of the human observer for the animal (Vezirian et al. 2024). Educational use potentially offers a different test of the effect of categorisation. It is unambiguously a use-context, and so should be subject to the same 'categorisation effect', but it is also conducted under ethical oversight intended to limit harm.

Building on the work of Vezirian et al. (2024), we used a rabbit as the target animal, framed within an educational use-context where it is recognised that the animal may still be harmed (Khoddami et al. 2026), but where the extent of this is governed and limited by ethical oversight and legislative requirements. The rabbit is itself an established live-animal model for training in laparoscopic surgery (Molinas et al. 2004; Esposito et al. 2016), which makes a student surgical scenario a realistic one. The rabbit also occupies an unusually unstable moral position in New Zealand and Australia, regarded at once as a companion animal, an agricultural and environmental pest, and a research and teaching animal. This makes it a useful case for examining how context, rather than species, shapes moral consideration. We do not claim that rabbits are typical of veterinary teaching in this region; rather, the scenarios serve as a controlled model of ethically regulated educational use.

We compared a naturalistic portrayal of a rabbit with two teaching-use portrayals: non-invasive observation, and a more invasive surgical procedure. Both teaching-use portrayals were described as taking place under ethical oversight, with humane housing and minimal avoidable harm.

Because this ethical framing may generate less of the moral discomfort thought to drive mind denial in overtly harmful contexts, we were uncertain how teaching-use would affect perceptions of the rabbit's mind and the moral concern shown towards it. We treated these as exploratory questions, examining how framing an animal's use as educational influences perceptions of its affective sociality and cognitive autonomy, and the moral concern it is afforded.

Materials and methods

An a priori power analysis for two-tailed independent samples t-tests with equal sample sizes and conventional error rates (α = 0.05, power = 0.80) indicated we would need a sample size of 130 people per group to detect an effect size of d = 0.35 or larger. We chose this target effect size because d = 0.36 was the lowest bound of the 95% CIs reported for effects of a manipulation on mind perception in Studies 1a and 1b of Vezirian et al. (2024). Given our between-subjects experiment included three vignette conditions, we recruited a sample of 450 participants (approximately 150 per group).

Participants

Participants were recruited through Prolific (www.prolific.com), an online research participation platform at which pre-screened members of the public complete studies for payment. Recruitment was restricted to people 18 years and older residing in New Zealand and Australia. Recruitment continued until the target sample size was reached. Sample size and participant characteristics are reported in the Results.

Materials

Each participant read one of three descriptive vignettes (full wording in Supplementary Material 1): (1) the naturalistic vignette (control), describing a rabbit in its wild habitat; (2) the observational vignette, describing a less invasive teaching setting featuring non-interventional observation, where students observed the rabbit's behaviour without physical interaction; and (3) the intervention vignette, describing a more invasive teaching setting involving a surgical procedure performed by students.

Above each vignette was an identical photograph of a rabbit (see supplementary materials for Vezirian et al. 2024). Both teaching-use vignettes included information about the rabbit's housing environment, with the observational vignette describing an enriched environment resembling the rabbit's natural habitat, and the intervention vignette describing a standard laboratory environment supporting recovery.

Perceptions of the rabbit's mental capabilities were assessed with 12 statements (e.g., "can be happy", "can exercise self-control") using a shortened form of the Perception of Animal Minds Surveyfoot_1 (PAMS; Philipp and McMurtrie 2026). Statements were rated from 0 (definitely not true) to 7 (definitely true). The short form comprises the two PAMS subscales most closely tied to judgements about animals: affective sociality (PAMS-AS) and cognitive autonomy (PAMS-CA), with six assessment statements retained from each: The fuller 24-statement PAMS factor structure has been confirmed across three validation studies with Australasian, UK, and USA samples (Philipp and McMurtrie 2026); the shortened form has not been previously validated as a standalone instrument. A higher PAMS-AS score indicates that the observer views the animal as more capable of emotional experience and social engagement (for example, feeling joy, fear, or affection and forming social bonds). A higher PAMS-CA score indicates that the observer views the animal as more capable of thinking, planning, and goal-directed, self-controlled behaviour. For each participant, the six items of each subscale were averaged to give a single PAMS-AS score and a single PAMS-CA score.

Moral concern was assessed with a measure adapted from Piazza et al. (2014) in which participants answered four questions (e.g., "To what extent do you think it deserves to be protected from harm?") on a scale from 0 (not at all) to 7 (very much). Items were averaged to give a single moral concern score.

Procedure

The study was approved by the Human Research Ethics Committee, University of Canterbury, NZ (HREC 2024/123/LR-PS). All participants gave informed consent before taking part. The study was administered via the Qualtrics online survey platform (Qualtrics, Provo, Utah, USA). After informed consent was given, participants were randomly assigned to one of the three vignettes described above. Each participant saw the same picture of a rabbit with the relevant vignette text.

As a comprehension check on the experimental manipulation, all participants were asked to give a written summary, in their own words, of the vignette they had read. These summaries were used to confirm that participants had read and attended to their assigned vignette. Summaries that were too vague or inaccurate to demonstrate comprehension led to exclusion of the data.

Next, they completed the PAMS-AS and PAMS CA assessments, and the moral concern assessment. Participants then answered questions about having a pet rabbit, beliefs about rabbits as pests, and the participant's general dietary habits (used to assess the balance of random assignment). No separate pilot was conducted; the measures were established instruments used in previous research by the authors, and comprehension of the vignettes was verified within the study. Participants' age, biological sex at birth, and country of residence were provided by Prolific -participants did not report this directly in the survey. The survey took a median of 4 minutes 30 seconds to complete. The full survey text is available at https://doi.org/10.6084/m9.figshare.32087010

Statistical analysis

Two a priori exclusion criteria were applied before analysis: (1) failure of the comprehension check described above, and (2) answering "yes" to the final question asking whether there was any reason the participant's data should not be used. To assess the robustness of our findings to these exclusions, all analyses were repeated with the excluded participants' data included; conclusions were unchanged. These analyses can be confirmed by accessing the data and analysis files linked in the Results heading below.

The analysed scale scores were mean composites of multiple ordinal items (0-7). These composite scores therefore had many possible gradations and were treated as approximately continuous, consistent with common practice for multi-item rating scales. This approach does not assume that the individual response categories are strictly interval scaled, but rather that the resulting composite provides a sufficiently fine-grained quantitative approximation for continuousdata methods; such methods are generally robust when applied to multi-item rating scales of this kind (Norman 2010). Internal consistency within the components of the PAMS-AS and PAMS-CA scores and within the moral concern score components was assessed by calculating Cronbach's α and McDonald's ω.

We analysed mean differences across the three vignettes for each PAMS subscale (PAMS-AS, PAMS-CA) using one-way ANOVA, with effect sizes reported as η², the proportion of total variance in the outcome explained by the vignette manipulation. We report 90% CI for η² because the Fdistribution is one-sided; a 90% CI therefore corresponds to the conventional α = 0.05 significance threshold. Statistically significant omnibus tests were followed by Games-Howell post-hoc comparisons, a conservative procedure that does not require equal variances across groups and controls for multiple comparisons.

A multiple linear ordinary least squares regression model, conducted at the level of the individual participant, examined how moral concern (the dependent variable) differed by vignette, and to what extent mind perception scores predicted moral concern. Two dummy-coded predictors represented the three vignettes (naturalistic vignette served as the reference), and each of the mind perception subscales (affective sociality and cognitive autonomy) was included as a continuous predictor. All predictors were specified a priori from the study design and hypotheses; no interaction terms were hypothesised or included. To confirm that the full model was warranted, we compared it against reduced models (vignette only; mind perception only) using hierarchical F-tests. Coefficients are reported as unstandardised estimates (β) with 95% CI, expressing effects in points on the 0-7 moral concern scale. Model assumptions were examined: multicollinearity via variance inflation factors, homoscedasticity via the Breusch-Pagan test, and residual normality via skewness and kurtosis of residuals. Because the Breusch-Pagan test indicated heteroscedasticity, all coefficients were re-estimated with heteroscedasticity-consistent (HC3) standard errors as a sensitivity analysis, and inferences were unchanged. As a check on random assignment, c 2 tests assessed whether measured background characteristics (pet ownership, pest beliefs, dietary habit) were distributed evenly across the three vignettes.

Analyses were conducted in jamovi (version 2.6), an open-source statistical programme (The jamovi project 2025). Figure 1, the effect-size CI, McDonald's ω, the model comparisons, the assumption checks, and the heteroscedasticity-consistent re-estimation were computed in R (R Core Team, R Foundation for Statistical Computing, Vienna, Austria, version 4.4) using the ggplot2, psych, effectsize, rstatix, car, and performance packages.

Perceptions of the rabbit's affective sociality were similar across the three vignettes: there was no evidence of a difference between vignettes (F(df 2, n = 436) = 1.495, p = 0.225), and the vignette manipulation explained less than 1% of the variance in affective sociality scores (η² = 0.007, 90% CI = 0.000-0.02). There was evidence that perceptions of the rabbit's cognitive autonomy differed between vignettes (F(2, 436) = 4.129, p = 0.017), although the effect was small: the manipulation explained approximately 2% of the variance in cognitive autonomy scores (η² = 0.019, 90% CI = 0.002-0.042). Games-Howell post-hoc comparisons indicated that participants who read the naturalistic vignette judged the rabbit to have greater cognitive autonomy than those who read the observational vignette (mean difference 0.452 (95% CI = 0.063-0.841, p = 0.018) points on the 0-7 scale); that is, they viewed the rabbit as more capable of making decisions and acting autonomously. This difference was modest in absolute terms (just under one-third of a standard deviation). The comparison between the naturalistic and intervention vignettes was in the same direction, but there was no clear evidence of a difference (mean difference 0.382, 95% CI = -0.026 to 0.790, p = 0.071), and there was no evidence of a difference between the observational and intervention vignettes (mean difference 0.069, 95% CI = -0.330 to 0.469, p = 0.912).

Discussion

This study examined whether framing an animal's use in a teaching context changes how people perceive its mind and the moral concern they extend to it compared to viewing the same animal within a naturalistic context. Three findings stand out. First, perceptions of the rabbit's affective sociality (its perceived capacity for emotions, social bonds, and subjective experience) showed no evidence of differing across the three vignettes. Second, perceptions of its cognitive autonomy (its perceived capacity for planning, self-control, and goal-directed behaviour) were lower in the teaching-use vignettes than in the naturalistic vignette, most clearly for the observational vignette, though the effect was small. Third, and contrary to what a mind-denial account would predict, moral concern for the rabbit was higher, not lower, in both teaching-use vignettes, and this held after accounting for mind perception. By "after accounting for mind perception" we mean that the higher moral concern in the teaching-use vignettes remained once we statistically adjusted for how participants rated the rabbit's affective sociality and cognitive autonomy: the vignette itself, not only the mind attributed to the rabbit, was associated with moral concern.

That moral concern was associated with affective sociality but not with cognitive autonomy fits the distinction between moral patients and moral agents (Gray et al. 2007 (Gray et al. , 2012)). What makes an entity an object of moral concern is its perceived capacity to feel, to suffer or to flourish, rather than its capacity to think and act autonomously. Participants who viewed the rabbit as more capable of emotional and social experience extended more moral concern to it, whereas perceptions of its cognitive autonomy were unrelated to moral concern. This replicates the parent PAMS validation work, in which affective sociality was the strongest positive predictor of moral concern and cognitive autonomy was not (Philipp and McMurtrie 2026), and it supports separating the two dimensions when studying moral judgements about animals.

The association between vignette and moral concern beyond mind perception invites further consideration; however, our design cannot settle it. Several features varied together across the teaching-use vignettes: the rabbit was described as used by humans, as dependent on human care, and, in the intervention vignette, as undergoing a procedure presented alongside welfare information and, in places, morally loaded wording (for example, that euthanasia would be considered only in extreme circumstances). Any of these features, rather than teaching-use as such, could have raised moral concern, for instance by signalling that the animal's welfare was ethically significant. We earlier described the teaching-use vignettes as conveying careful treatment, but this is our characterisation: we did not measure how participants themselves construed the scenarios, and we cannot show that they read the surgical vignette as careful treatment.

Our results do not follow the pattern of mind denial reported when people consider animals used for meat or in product testing, where presenting an animal as an object of human use lowers the mental capacities attributed to it (Loughnan et al. 2010; Bastian et al. 2012; Vezirian et al. 2024).

Here, teaching-use reduced perceptions of cognitive autonomy only slightly, did not lower perceptions of affective sociality, and moral concern was higher rather than lower.

The comparison with Vezirian et al. (2024) is particularly useful, since we used their rabbit image and a comparable naturalistic description. Across four studies they found that describing an animal as a laboratory subject reduced attributed mind by a consistent, medium amount (d = 0.52, 95% CI = 0.45-0.60), but that manipulating how much the animal was said to suffer, or how responsible participants were told they were for that suffering, made no difference to the size of that reduction.

They concluded that categorising an animal as a research subject is itself sufficient, and that the degree of harm is largely beside the point. This bears directly on our result: our vignettes also categorised the rabbit as an animal used by humans, so a categorisation account would predict a comparable reduction, but broadly we did not observe one. Two differences may be relevant, and our design cannot separate them. First, the capacities that shifted are not the same. Most of their items indexed what an animal feels rather than what it intends or plans, whereas here it was the agency dimension that shifted and the experiential dimension that did not. Second, their participants were first reminded that their own household purchases depend on animal testing, whereas ours had no personal stake in the use described -with less of one's own behaviour to justify, there is less reason to withdraw mind from the animal (Bastian and Loughnan 2017). We note that our moral concern finding does not contradict theirs: Vezirian et al. (2024) found no difference in moral concern (measured with a single item) between their laboratory and naturalistic descriptions, so what is novel here is the increase rather than the absence of a decrease. More generally, use-contexts do not shift perceptions in a single direction, since objectification lowers attributed mind whereas making an animal's suffering salient can raise it (Ioannidou et al. 2024). It should not be assumed that our teaching vignettes engaged the same process at all. Why, then, was cognitive autonomy lower in the teaching-use vignettes? A motivated-denial reading struggles here, because reducing an animal's perceived agency is not an obvious route to moral disengagement: agency is not what confers moral concern, and seeing an animal as less able to act for itself might if anything heighten concern for it. A simpler, perceptual reading fits better. In the teaching-use vignettes the rabbit is observed or operated upon, having things done to it, rather than acting freely in its habitat, and observers may reasonably have inferred reduced scope for autonomous action. On this reading the lower cognitive-autonomy ratings reflect the situation depicted rather than a strategy to license the animal's use, consistent with their being unrelated to moral concern.

Several limitations restrict these conclusions. Most importantly, all three vignettes were set within an ethical framework; we included no scenario in which teaching-use occurred without such oversight. We therefore cannot attribute the results to the ethical framing itself: the pattern could reflect the framing, the specific scenarios, or both. Isolating the contribution of ethical framing would require comparing otherwise-identical scenarios with and without it. Relatedly, because several features varied together across the vignettes, the design cannot identify which drove the effects; a controlled follow-up study varying one feature at a time and using richer stimuli than brief text vignettes (which lacked detail that may have increased variability in responses, and lacked the emotional potency of video or first-hand encounters) would be informative Our sample was recruited as a convenience sample and is not representative of a particular population. The point estimates should not be read as population values; replicating the study in another population would extend its generalisability. Finally, we studied a single species presented as an exemplar of ethically regulated educational use. Whether the same pattern holds for species and procedures more typical of veterinary teaching, or for scenarios involving terminal use, which remains common in some jurisdictions (Chadwin et al. 2025), is an open question, as is whether it holds among veterinary students, whose professional socialisation and first-hand experience with animals shape their perceptions differently from those of the public (Finnie et al. 2023). We expect individual differences would also moderate these effects (Ioannidou et al. 2024).

Conclusions

In a sample of the New Zealand and Australian public, we found that framing a rabbit's use within an ethically regulated teaching context did not produce the mind denial seen when people consider animals used for meat or in product testing. Moral concern was higher, not lower, than for a naturalistic portrayal, and it was driven by perceptions of the animal's capacity for emotional and social experience; perceptions of its cognitive autonomy were modestly lower but unrelated to moral concern. Because our design included no scenario lacking ethical oversight, we cannot conclude that the ethical framing itself maintained or enhanced moral concern; what we can say is that, within these ethically framed scenarios, moral concern was not diminished and mind denial did not occur.

For veterinary educators, the tentative implication is that making the ethical basis of animal use visible need not diminish, and may accompany heightened moral concern for the animals involved.

Establishing this, and whether it holds for veterinary students rather than the public, will require studies that manipulate ethical framing directly and sample the populations of interest.
