This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

Animal research committee names - Institutional Animal Care and Use Committee / IACUC (US standard) - Any sentence containing animal(s) and committee (or board/panel) within ~5 words of each other — catches Experimental Animal Care and Use Committee, Animal Ethics Committee, Animal Welfare Board, Animal Welfare Ethical Review Body, etc. - UK: Animal Welfare Ethical Review Body / AWERB - Dutch: Dierexperimentencommissie / DEC (see DEC constraint above); Instantie voor Dierenwelzijn / IvD - German: Tierversuchskommission / TvK (advisory committee under §15 Tierschutzgesetz) - French: Comité d'éthique en expérimentation animale / CEEA; Comité d'éthique animale - Spanish: Comité de ética en experimentación animal / CEEA

Waiver / exemption - Ethics/Ethical (waiver|exemption) - IRB (waiver|exemption|exempt) - Exempted from (ethics|irb|institutional review) - Waived by the (ethics|irb|institutional|review) (committee|board) - Deemed exempt

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. This package was validated by the Metacheck team on articles in Psychological Science.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

This module was developed by Lisa DeBruine and Daniel Lakens

Read more in the metacheck manual.

It missed 136 instances of imprecisely reported p-values (false negatives) and correctly identified 4557 cases of precisely reported p-values (true negative). Additionally, 78% of positive detections were correct (positive predictive value).

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Pragmatic abilities allow us to use and comprehend language in interaction. The assessment of individual differences in pragmatic abilities, both within and across cultural settings, is crucial to understanding how they develop. However, tools with good psychometric properties that suit this purpose are lacking. The current study describes the creation of a test battery assessing individual differences in 3-to 6-year-old children from different cultural and linguistic backgrounds. The battery is implemented as a tablet-based game, administrable both online and in person. Children are prompted by a character with one or multiple utterances and respond by selecting a picture among three options on a screen. An initial larger item pool was piloted in Germany and Kenya to ensure the items' cross-cultural adaptability. We then used item response modeling on a sample of 713 German children to select items that varied in difficulty and fit the Rasch model. The so-constructed 19-item battery shows excellent model fit, test-retest reliability and convergent validity. The way the battery was created allows for easy cross-cultural adaptation, easy administration and scoring, thereby addressing an important gap in the developmental study of the interplay between social cognition and language. All materials and code are freely accessible to interested researchers. The task can be used via the following website: https://devpsy.web.leuphana.de/prabat/.

Introduction

Pragmatics, which concerns the use of language in context (Bates, 1976), is a fundamental component of language use and learning. The first theories of pragmatics such as the Gricean Cooperative Principle (Grice, 1975) and Sperber and Wilson's Relevance Theory (1986), adopted a cognitive approach that conceptualized pragmatic processes as inferential processes that integrate literal meaning with information from the context, the speaker and the world.

Later accounts put more emphasis on the prominent social cognition component of pragmatics, thus seeing pragmatic inferences as social inferences, where Theory of Mind (ToM, or mentalizing), joint attention and perspective playing a crucial role (O'Neill, 2012; Sperber & Wilson, 2002). The extent to which pragmatics represents a submodule of, partially or totally overlaps with ToM, is subject of debate. On the one hand, numerous approaches propose different reconfigurations of pragmatic abilities in relation to social cognition (for some examples, see Andrés-Roqueta & Katsos, 2017 , 2020; Domaneschi & Bambini, 2020; Marocchini & Domaneschi, 2022; O'Neill, 2012; Rubio-Fernandez, 2024). On the other hand, more recent approaches, like the Rational Speech Act framework (Degen, 2023), propose a formalization of the traditional conversation principles, thereby operationalizing pragmatic processes as probabilistic, rational inferential processes. Despite the flourishing theoretical work, there is no agreed-upon definition of pragmatics and what it encompasses. This entails a "phenomenological diversity" that makes it difficult to establish whether all phenomena classified as "pragmatic" by different traditions -from implicature, metaphor, irony comprehension to communicative gesture, prosody, turn-taking and politeness understandingactually draw on the same cognitive resources and represent a single, unified construct (Floyd et al., 2025; Matthews, Biney, & Abbot-Smith, 2018; Russell & Grizzle, 2008).

Empirical research has found pragmatic abilities -differentially conceptualized -to be related to perspective taking, false-belief understanding, vocabulary, grammar, working memory, and inhibitory control (Bambini, Van Looy, Demiddele, & Schaeken, 2021; Matthews et al., 2018) but also mental health (Brenne & Rimehaug, 2019; Dall, Fellinger, & Holzinger, 2022; Law, Rush, Clegg, Peters, & Roulstone, 2015), peer popularity (Gottman, Gonso, & Rasmussen, 1975; Kemple, Speranza, & Hazen, 1992; Law et al., 2015; Law, Rush, & McBean, 2014; Mok, Pickles, Durkin, & Conti-Ramsden, 2014), child prosocial behaviour (Conti-Ramsden et al., 2019), social, emotional and behavioural difficulties (Helland, Lundervold, Heimann, & Posserud, 2014; Murphy, Faulkner, & Farley, 2014; St Clair, Pickles, Durkin, & Conti-Ramsden, 2011), relationship formation (Whitehouse, Watt, Line, & Bishop, 2009), and employability (Eaves & Ho, 2008; Lewis, Woodyatt, & Murdoch, 2008).

While the clear presence of a link between pragmatics and other domains -first and foremost language, social cognition, executive functions -underscores the importance of this ability for human development and wellbeing, there is a scarcity of psychometrically valid, reliable, individual differences assessment tools for pragmatic abilities (Matthews et al., 2018).

Being able to track individual differences is crucial in order to understand its development and identify what determines pragmatic development, its variation and how this variation can in turn affect the development of other cognitive and social abilities (Matthews et al., 2018).

In order to build universal theories about development, it is important to have a database that represents the diversity of human experience beyond traditionally overstudied populations from the Global North because pragmatic skills are tightly connected to culturally variable factors such as language and social norms (Levinson, 1983). Research at the level of individualdifferences can help achieve this goal (Levinson, 2012): it allows to verify whether the relationship between two variables (e.g., a cognitive trait and an aspect of experience, or the development of two different abilities) holds consistently both within and across cultural groups (Bohn, Fong, Pope-Caldwell, Stengelin, & Haun, 2024). The cross-cultural applicability is largely neglected in assessment tools for pragmatic abilities.

Even though a multitude of pragmatic assessment tools exist, there is a need for comprehensive measures of individual differences, in particular for young children (Matthews et al., 2018). A large portion of assessment tools were designed with a diagnostic/screening goal for a broad range of populations: from adults to children, from populations with developmental language disorders (CSBS-DP, Wetherby & Prizant, 2002; ESCS, Mundy et al., 2003), autism spectrum disorder (Pragma, Loukusa, Mäkinen, Gabbatore, Laukkanen-Nevala, & Leinonen, 2017; CCC-2, Bishop, 2006; YiPP, Simmons, Paul, & Volkmar, 2014; SEE, Wiig, 2008; ADOS, Lord et al., 2000), neurodevelopmental disorders (PleaseApp, Andrés-Roqueta, Flores Buils, & Igualada, 2024), attention (POM, Cordier, Munro, Wilkes-Gillan, Speyer, & Pearce, 2014) and social-pragmatics deficits (CCC-2, Bishop, 2006; LUI, O'Neill, 2007; PLSI, Gilliam & Miller, 2006) to brain injuries, neuropsychological and psychiatric disorders (ABaCo, Sacco et al., 2008; APACS, Arcara & Bambini, 2016). Most of the tests for children rely on a narrative structure and/or meta-cognitive approaches, by requiring children to either respond to or explain specific types of statements or stimuli. Alternatively, indirect measures such as checklists and questionnaires are used, where parents, clinicians, or experts answer questions based on previous observations of the child. Other instruments include either semi-structured interviews between the clinician and the child, or observations of unstructured interactions between the child and peers or adults during, e.g., play and school contexts, in some cases via time-sampling techniques (for an overview of the available instruments grouped according to this tentative classification, see Table 1). Most of these tests show good psychometric qualities (Hyter, 2017; Matthews et al., 2018). However, they present multiple disadvantages. As the observation of undisturbed interactions may provide the most naturalistic setting to assess a child's pragmatic abilities, this method requires, most of the time, highly trained personnel to conduct the assessment and is considerably time-consuming [not only for the time of the assessment, ranging from 20 (POM, Cordier et al., 2014) to 30 minutes (CSBS-DP, Wetherby & Prizant, 2002; PP, Prutting & Kittchner, 1987), but also for the scoring itself, which can last up to 60-75 minutes in the case of the CSBS-DP]. This problem is partially overcome by tasks that require children to respond to verbal prompts and reason about scenarios and conversations (Pragma, Loukusa et al., 2017; CASL, Carrow-Woolfolk, 2017; TOPL-2, Phelps-Terasaki & Phelps-Gunn, 2007). These instruments usually take less time and minimize the scoring length. However, they still require considerable control of attention, memory, and meta-cognitive skills that younger children may not have. Checklists and questionnaires completed by adult caregivers, in turn, eliminate this problem and allow to gain information about younger samples (Bishop, 2006; O'Neill, 2007), which would be hardly testable with tools requiring elaborate responses to verbal prompts. At the same time, by involving adults they sacrifice direct assessment of the child's pragmatic abilitiesand thus, ecological validity (O'Neill, 2014). Moreover, it is often difficult to determine who is the "most informed respondent": first, because, as children start going to school, neither parents nor teachers may be able to give the full picture of the child's communicative ability (O'Neill, 2014); second, because there is considerable cross-cultural variation in how many people are involved in the upbringing of a child (e.g., in Kenya, the rearing of the children involves extended family members as well, Oburu, 2024).

To our knowledge, there is only one example of a digital assessment tool that children can complete by themselves, namely the PleaseApp (Andrés-Roqueta et al., 2024). The PleaseApp instrument is a game application where 5-to 11-year-old children go through multiple scenarios, each involving the evaluation of different aspects of receptive pragmatic abilities, such as understanding of figurative language, narrative, referential expressions, indirect speech acts, humor, gesture-speech integration and politeness. The presence of text and the complexity of the tasks, however, makes the test not suitable for younger children. Nonetheless, as the authors underline, digital assessment tools offer a great opportunity to control for contextual factors, fundamental in pragmatic abilities' assessment, and can be administered both online and in person, increasing the probability to reach the desired sample size (the lack of which is often a problem when doing correlational research, Matthews et al., 2018). Moreover, the combination of visual and auditory stimulus presentation allows to simulate communicative contexts that would otherwise be difficult to recreate (Andrés-Roqueta et al., 2024).

In this paper, we present the development of a psychometrically reliable and valid, easilyadministrable tool that can assess individual differences in different pragmatic abilities in multiple cultural settings and languages in the preschool age (i.e., 3-to 6-year-old children). For its development we took the following steps. First, we created a large pool of items assessing a broad range of pragmatic abilities. In order to establish precise criteria about which items to include, we specified a working definition of pragmatic phenomena based on previous literature (Grice, 1975; O'Neill, 2012; Sperber & Wilson, 1986). For our purpose, an item requires pragmatic reasoning to be solved when: 1) the item contains either a literal linguistic or paralinguistic message that is not sufficient in order to comprehend the intended meaning of the utterance; 2) to be correctly interpreted, the literal linguistic or paralinguistic message needs to be integrated with information either about the interlocutor, about the world, or about the context (see Appendix A for a list of items and how each one reflects these criteria) 1 . In order for the instrument to be objective and brief, we developed it as a digital application that could be administered both in person and online. This not only ensures consistency of variables such as conversational context and intonation, but also allows for easy administration -not requiring specialized personnel such as clinicians and speech therapists -and therefore facilitates achieving larger sample sizes. Because modern technologies do not (yet) allow for immediate and accurate transcription of audio (production) data, we focused on the assessment of receptive pragmatic abilities, a still understudied domain of pragmatics (Andrés-Roqueta et al., 2024). Because we wanted our test battery to be cross-culturally adaptable, we only included items that could be easily adapted to multiple cultures in a comparable way. To ensure that, we consulted with native speakers from Kenya, Türkiye, and Germany (the three contexts the battery was initially developed for, see section on Cross-cultural adaptation), and only included items that were judged appropriate across these three -culturally and linguistically distinct -contexts. For example, irony and sarcasm comprehension were left out, as the adaptation of such an item would require substantial changes to the task depending on the culture with little certainty about its cross-cultural comparability. We then used Item Response (IRT) models to select the bestperforming items from the initial pool to ensure that items measure the same latent ability. More precisely, we aimed for the battery to conform to a 1-parameter logistic (1PL; Rasch) model, so that the sum score can be used as a score for performance (Rasch, 1960). Although factorial work is much needed to investigate the potential heterogeneous nature of pragmatics (Floyd et al., 1 It is important to note that our goal here is not to give a definition of pragmatic ability, but rather to define operationalizable and concrete criteria that help us in defining what should be included as pragmatic phenomena.

2025), IRT is well suited for test construction, as it allows to build item sets by looking at the probability to solve an item as a function of the underlying ability and item-level estimates.

Whereas other latent-variable approaches as, e.g., exploratory factor analysis (EFA) investigate how many latent dimensions account for shared variance between items, our goal was not to identify the different dimensions characterizing pragmatics; rather, we aimed at building a battery consisting of items that function well along a common pragmatic-ability continuum and that allowed us to distinguish with precision individuals with different pragmatic ability levels.

Additionally, we aimed for a final battery that contained items that not only best measure the latent pragmatic ability, but that can also capture individual differences. In order to achieve both these goals, we used a semi-automated selection procedure to find a subset of items that both conformed to a Rasch model and contained items spread across the latent ability scale. Finally, in order to ensure the psychometric quality of the instrument, we looked at differential item functioning, and assessed the test -retest reliability and convergent validity.

In the following sections, we report the construction, psychometric evaluation, and crosscultural adaptation of this measurement tool, which we call PraBat (Pragmatics test Battery).

Task design and implementation

The test battery was implemented as an interactive picture book in HTML, CSS and JavaScript. It was programmed as a Progressive Web App and can thus be run online as a website in any browser but can also be downloaded and run offline if needed.

In the battery, children interact with a cartoon character, Ella. The battery begins with a short sequence of images where Ella introduces herself, her family, and friends. This introduction is thought to engage children and familiarize them with the character. At the end of the introduction, Ella asks the participant to play with her, and after pressing on 'continue' the test battery starts. In all trials, children are asked to click on one of three options (Figure 1. A shows an example trial, Mutual Exclusivity in nouns). The first three trials are familiarization trials, where children are asked to click on an object among three familiar ones, in order to get acquainted with the procedure. In the discourse-based inference items, a sequence of short scenes are presented to provide the conversational context for the critical prompt (i.e. Ella's request), while the Discourse Continuity item consists of five exposure trials and one critical trial (see Appendix A for a more detailed description of the items). A response can be given only once the audio prompt has finished playing. As per instruction, children are guided through the task by an adult native speaker (caregiver or experimenter). The adult is instructed to click on the 'continue' button to proceed with the next trial after their child has given a response.

In case the child asks for it, the caregiver (or experimenter) can also replay a trial by clicking on the audio symbol, visible next to the continue button. When administered on a tablet with a touch screen, children respond by touching a picture on the screen. When no touchscreen is available (e.g., in case of online data collection -see below) children are instructed to point to the screen and the adult should then select the pointed-to-picture (via mouse click). Test sessions can be recorded using the webcam if needed. The correct response appears almost equally in each of the three positions (12 times on the left, 11 times in the center, 12 times on the right). Together with familiarization and exposure trials, the full test battery comprises 35 trials. Once the battery is completed, a . IRT models describe the probability to solve an item with a logistic function that takes into account the person's ability level and specific item parameters. This function is best represented by Item Characteristic Curves, which show the probability to solve an item given a specific ability level. ICCs can also be used to visually inspect the parameter estimates of different items not only in relation to one another, but also in relation to the latent ability in question. For example, an item's curve position along the x axis is determined by its difficulty, while an item's curve steepness is determined by how precisely that item discriminates between individuals with different ability levels, i.e. the item's discrimination: a highly discriminating item differentiates more strongly between individuals with slightly different ability levels around the item's difficulty, resulting in a steeper ICC. with low discrimination differentiates less strongly between individuals with different ability levels, resulting in a flatter slope. While 2PL models allow items to vary both in their discrimination and difficulty parameters (ICCs would therefore vary both in position in the x axis and slope), Rasch models only allow for the difficulty parameter to vary, but assume all items to have the same discrimination parameter (with items only varying in their position on the x axis, but exhibiting the same slope, as in Figure 2). The sum score can be used as a sufficient test score only if the items conform to the Rasch model: across the entire latent ability, the model assumes that the probability to solve an easier item will never be lower than the probability to solve a more difficult item. This assumption does not hold in the case of 2PL models. 2PL models would therefore need the test results to be fit into the model in order to estimate the person's ability level, thus requiring norming data and a scoring model. A Rasch compliant battery is therefore a better solution for easy and immediate scoring.

For each item, we quantified its fit to the Rasch model in the following way: first, we extracted item fit statistics, i.e. Infit and Outfit. These statistics indicate the fit of the individual items to the model. While Infit focuses on the model's performance when the person's ability level is at the item's target difficulty level, the Outfit describes the model's performance when the person's ability level is far from the item's target difficulty level, thus being more sensitive to outliers. These statistics are calculated for each item and should have a value between 0.7 and 1.3 (Wright & Linacre, 1994).

Second, we extracted the discrimination parameters for each item from the 2PL model. In order to build a battery containing items that well fit a Rasch model, it is necessary for the main assumptions to be satisfied. Items with very similar discrimination parameters are items that together will give a better Rasch model fit.

Lastly, in order to have a battery that allows us to look at individual differences, a sufficient number of items covering a wide range of the target latent ability are necessary. From the Rasch model, we extracted easiness (inverse of difficulty) parameters, as to know how items are distributed along the latent ability scale.

The next step was to use the statistics we extracted and use them to determine the best subset of items. To do that, we formulated an objective function that would calculate a score for each subset of items based on the infit, outfit, easiness, and discrimination parameters of the contained items. The objective function's purpose was to penalize subsets that did not reflect the following criteria: contained Rasch compliant items; contained items equally spread across the latent ability scale; contained items that had similar discrimination parameters.

These requirements were quantified in the following way. The score for easiness spacing was calculated as the standard deviation of the distance between difficulty estimates of adjacent estimates. Items were sorted by difficulty, and the distance was calculated as the difference between difficulty estimates of adjacent items. A lower score indicated a lower standard deviation of the difficulty spacing between items, namely closer-to-equal easiness spacing between the subset's items. This score was then divided by three to bring it to a scale comparable to the other components. To score Infit and Outfit, we calculated the average of the distance of each item's fit value from 1. This average was then multiplied by -4 in the case of Infit and -2 in the case of Outfit. More weight was therefore given to bad Infit values. Lastly, the discrimination score was determined as the variance of the subset items' discrimination parameters multiplied by -6. These four scores were summed together resulting in an always negative total score. More negative values therefore indicated a lower, i.e. worse score.

Step 2. Automated selection process.

The objective function's score would then be used inside a simulated annealing (SA) algorithm (Kirkpatrick, Gelatt, & Vecchi, 1983). The SA algorithm is a probabilistic optimization procedure that, in our case, returns the best item combination for each subset size. For each subset size considered, the algorithm does the following: it starts from a randomly determined subset of items; randomly substitutes items of that subset; if the objective function returns a better value than before, the newly proposed subset becomes the starting point for the successive proposals. A "temperature" parameter influences the probability of the algorithm to accept a specific proposal. In the initial "hot" phase, where the temperature parameter is high, the process accepts more often proposals that decrease the objective function's score, preventing the algorithm from getting stuck in local optima (best subset within a neighboring set of choices) and facilitating the discovery of global optima (best subsets overall). As the temperature decreases, the probability of accepting lower scored subsets decreases, favoring the acceptance of better proposals. This allows for the refinement of the best subset found during the hot phase. Because we did not want to have a battery containing less than 18 items (as to cover the latent ability range with enough precision) and because we already knew at least two to three items had very bad parameters and/or fit, we let the SA algorithm iterate over 18-to 23-item subset sizes.

Once the simulated annealing algorithm identified the best subset for each subset size, we assessed whether the Rasch model provides an acceptable fit both in absolute terms and relative to a 2PL model. Consequently, for each subset we calculated several model fit indices models fits using Bayesian approximate leave-one-out cross validation (Vehtari, Gelman, & Gabry, 2017) based on differences in the expected log posterior density estimates (ELPD) and their standard error. More specifically, based on suggestions in the literature, we considered: the absolute fit acceptable if the CFI was equal or higher than 0.90, the RMSEA was lower than 0.08, the SRMSR lower than 0.10 (Hu & Bentler, 1999); the Rasch and 2PL models to be equivalent up until the difference of the models' ELPD was not higher than two times its standard error (Sivula, Magnusson, Matamoros, & Vehtari, 2025). All subset sizes returned acceptable absolute fit indices (with CFI ranging from 0.92 to 0.95), with 18-to 20-item subsets showing the best fit. indicates chance level.

This procedure consists of estimating the same parameters (here: difficulty) for the considered subgroups and looking at whether the 95% CrIs overlap.

Test-retest reliability

In order to assess whether the final battery is suitable for measuring individual differences, a test -retest reliability study was conducted (link to pre-registration: [https://aspredicted.org/zr94wp.pdf] ). 68 children (mean age = 5.32, range: 2.90-6.90) were recruited through local kindergartens in Lüneburg, Germany, and tested two times with a one week distance between the two test points.

Because of an error, most of the children (N = 63) were tested on an 18 items version, instead of 19 (the Verb Metaphor item was erroneously excluded during the reprogramming of the final battery version). However, we think this does not substantially influence the interpretation of the results. The Pearson's correlation between the two test points' proportion of correct answers was high (r = .70, p < .001), indicating good reliability (see Figure 3. B).

Convergent Validity

Since vocabulary skills have been shown to strongly correlate with pragmatic abilities (Bohn & Frank, 2019; Matthews et al., 2018; Pronina, Prieto, Bischetti, & Bambini, 2023), we assessed convergent validity by administering a receptive vocabulary test, the oREV (Bohn, Prein, et al., 2024). The oREV consists of a picture selection task where children hear a word and have to select the picture depicting the target word among four options. As PraBat, oREV is a browser-based web application and can be completed online. Cross-cultural adaptation

The battery was developed in the context of a broader, cross-cultural project that involves samples from Germany, Türkiye and Kenya. Therefore, we wanted to ensure the battery would be suitable for multiple cultural and linguistic settings and jointly developed the battery for German, Turkish, Kikuyu, and Kiswahili (the latter two being the local and common languages in the testing area in Kenya).

Native speakers of each of the languages were involved in the item creation process and assessed whether each item was suitable for the respective cultural contexts. All verbal prompts were recorded by native speakers of the language. Image and translation adaptations were made when needed to make the items more culturally appropriate, making sure this adaptation would not compromise the nature of the item and the comparability with the original item in the other contexts. For example, if an item contained fruits, local types were chosen so that children would be familiar with them. As far as the linguistic aspects are concerned, changes in translations were made only when they improved the naturalness of the prompts without compromising the crosslinguistic comparability of the relevant pragmatic phenomenon. Discussion

In the current study, we presented the development of PraBat, a test battery to assess individual differences in pragmatic abilities in preschool children from different cultural and linguistic backgrounds. We initially compiled a larger item pool of pragmatic tasks based on the literature. We then used Item Response models in combination with a semi-automated selection algorithm, to identify a set of items that best balanced between an overall good fit to the Rasch model and a set size that allows differentiating between individuals. The result is a 19-item battery which displayed good test-retest reliability and convergent validity.

Out of the 27 items in the initial item pool, 8 were excluded. One might wonder what the exclusion of these items means for the questions of which items -and with that which procedures or inferences -should be considered part of the broader concept of pragmatics. The fact that specific items were not included in the final battery does not necessarily negate their pragmatic nature and should be seen in light of how items were selected. The selection was guided by an algorithm that maximized an objective function which balanced between variability in item difficulty, item discrimination, and fit to the Rasch model. Therefore, the reasons for the exclusion of specific tasks are manifold. Some items, for example, had good discrimination and fit, but were very similar in difficulty to other items which had an overall better profile. This was the case for the items Listener conversational perspective taking 1 and 2, and Communicative gesture comprehension 3. Other items were excluded because they showed a poor outfit (Metaphor Adjective) or low discrimination (Conversational Implicature 1, Informativeness 1, see Figure 1 in Supplementary Material). While poor outfit (the only item-level fit issue present in our items, see Figure 2 in Supplementary Material) may indicate too high predictability of the responses and may be due to the high easiness of the items (Boone, Staver, & Yale, 2014; Linacre, 2002; Wright & Linacre, 1994), low discrimination values indicate that a specific item does not differentiate well between different sections of the latent ability, but not that the supposedly measured ability is not pragmatic. For example, low discrimination value for Informativeness 1 may have been determined by the heavy load of the task on memory skills, while performance in Conversational Implicature 1 may have been influenced by the ambiguous nature of the prompt sentence. However, other items capturing the same phenomena (Informativeness 2 and Conversational Implicature 2) showed better discrimination estimates, indicating that different versions of the same items, relying less on memory and on less ambiguous sentences, succeeded in differentiating between sections of the latent ability. Scalar Implicature and Verb Mutual Exclusivity on the contrary, were very difficult items that were probably excluded due to their high difficulty compared to the rest of the items, and would not have guaranteed sensitivity to individual differences for higher ability levels: the objective function penalizes item subsets where the deviation of the average easiness distance between adjacent items is high; therefore, subsets including these two items, being very far in difficulty from the rest of the items, were penalized by the objective function.

PraBat has several advantages that make it an important addition to the toolkit for investigating pragmatic abilities. First, the battery shows very good psychometric qualities, in particular good test-retest reliability and convergent validity. On the practical side, it is implemented as a web app that can be used both remotely and in person. This allows for easy data collection, with no need of manual coding, transcriptions, and trained personnel. The good fit to the Rasch model allows for easy scoring because the sum score serves as a sufficient statistic (Rasch, 1960). Moreover, children can complete the final battery in approximately 5 to 10 minutes. These two features address the resource issues that most of the pragmatic assessment tools have, allowing to potentially reach bigger samples needed for individual differences research (Matthews et al., 2018).

PraBat's practicality additionally applies to its cultural and linguistic adaptability. The interface was designed to be appropriate for multiple cultural contexts. More importantly, the items have been thought to be suitable for three very different linguistic and cultural contexts (Germany, Türkiye and Kenya) from the start: the included items therefore comprised only phenomena that, for their resolution, require context, speaker, and world information potentially available to children from different cultures and speaking different languages. Therefore, all items can potentially be adapted and translated to a vast range of cultures and languages without major changes.

Despite the benefits of the final battery, there are also several limitations. First, there are important pragmatic phenomena which could not be included, such as, for example, politeness and humor, which highly rely on cultural aspects, other more language-specific phenomena that involve, e.g., reference assignment, interpretation of definite and indefinite articles, determiners and pronouns, intonation patterns marking information structure, pragmatic particles. As already mentioned, these phenomena were excluded to ensure the cross-cultural appropriateness of the battery.

Secondly, we are aware of the fact that, despite careful adaptation and translation, there might be fine-grained pragmatic aspects that can change from one context to another. Apart from the linguistic nuances that might be an inevitable and direct consequence of translation, culture might also have an influence on the priority with which specific kinds of information are being considered when solving an item. Additionally, whether the result of IRT measurement models are valid for other cultural contexts -i.e., if they are invariant -needs to be further investigated (Kachergis et al., 2025). However, we believe our battery can be appreciated as one of the first committed efforts to minimize the impact of cross-cultural differences on assessment of pragmatic abilities.

Despite these limitations, we still argue that the performance in this battery, be it receptive, applied in interaction with an animated character, and possibly subject to fine-grained cross-linguistic and cross-cultural differences, can be indicative of children's general pragmatic ability.

Nonetheless, future research aiming at untangling the nature of pragmatic abilities could create more items measuring the excluded abilities as, e.g., scalar implicatures and conversational perspective taking, and verify whether their fit indices and parameters change. For example, we believe the use of the quantifier "einige" (german translation of "some") might have contributed to the high difficulty of the scalar implicature item. Investigating the fit of a scalar implicature involving another quantifier might reveal whether scalar implicatures per se constitute other forms of meaning enrichment not represented in the pragmatic continuum assessed in this battery (e.g., explicatures, Noveck & Sperber, 2007). Whether this difficulty is caused by children's inability to find lexical alternatives for the -rather infrequent -quantifier "einige" (Barner, Brooks, & Bale, 2010); or whether scalar implicatures are not an integral part of pragmatic reasoning.

Further research can also aim to broaden the range of pragmatic abilities assessed using the same IRT-based approach. For example, when looking at Figure 2. B, it can be noticed the battery could use the addition of more difficult items, making up for the still uncovered portions of latent ability (e.g., between Gesture 2 and Emotional Prosody) and therefore improving the individual-differences sensitivity of the battery. Joint efforts by researchers from different linguistic and cultural backgrounds could be made in order to create items that measure other excluded abilities, such as, e.g., irony, in a cross-culturally comparable way. Furthermore, innovations in the field of audio transcriptions and large language models (LLMs) could be leveraged to create reliable digital tools that permit to integrate expressive abilities assessment, thus making the assessment context more dialogic. For example, a version of the battery could be created where children are able to converse with the character, Ella, and Ella can react based on the children's replies, which could be automatically transcribed and scored. Although research regarding LLMs' potential role in pragmatic tasks is still at a very early stage, such goals do not seem too unrealistic given the rapid development of these technologies (Lee & Cook, 2024). On the other hand, future cross-cultural research, can investigate the extent of cross-cultural differences in pragmatic phenomena in order to investigate their comparability.

Conclusion

In the current paper, we reported on the development of PraBat, a test battery to assess individual differences in pragmatic abilities in young preschool children from different cultural backgrounds. PraBat represents an important step forward in pragmatic research, as it addresses the need of easily administrable tools that can provide high-quality assessment of individual differences. We believe this instrument represents an important tool for any researcher investigating pragmatic abilities and how these relate to other social-cognitive abilities or life experiences.
