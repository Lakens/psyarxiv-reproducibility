Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. This package was validated by the Metacheck team on articles in Psychological Science.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Codebook Check works

This module checks whether the data columns in a repository are documented in a codebook or README. It locates codebook/readme files, extracts the variable definitions they contain, matches those definitions against the data columns extracted by data_check, and reports documentation coverage: how many data columns are documented, and which documented variables are never used.

The Codebook Check module consumes the columns and file classification produced by data_check (and, transitively, repo_check). Files classified as codebook or readme are parsed with parse_codebook(), which reads structured tables (CSV/TSV/Excel with a variable-name column and a label column), embedded labels in haven files (SPSS/Stata/SAS), and plain text from rich-text formats (docx/pdf/rtf/odt). Embedded haven labels from data files are also harvested directly.

Each data column is then matched against the parsed variable definitions with match_column_labels(), using normalised-name matching with experiment-group scoping, haven-label priority, and rule-based label-equivalence merging.

Beyond the variable label, the module harvests the DDI-style per-variable properties a source supplies: the value labels / code list (the 1=“Strongly disagree”…5=“Strongly agree” mapping — from SPSS/Stata value labels and from a codebook “values”/“coding” column), the missing-value scheme (which codes denote missingness, from haven declared missings and labels that read as “refused”/“n/a”), and question text and columns when present. These are carried onto the matched data columns and exported into the Psych-DS variableMeasured (as a schema.org code list plus namespaced metacheck: fields).

The module defaults to rules-only when llm_use(FALSE). When llm_use(TRUE), three optional LLM tiers run: parsing unstructured codebook text that the rules could not handle, fuzzy-matching still-unlabelled columns to still-unmatched codebook variables, and merging conflicting label definitions into a single canonical label.

How Repository Check works

This module retrieves information from repositories.

The Repository Check module lists files on the OSF, GitHub, ResearchBox, DSpace (PsychArchives and other legacy- and DSpace 7-based installations), Zenodo, Dataverse, Figshare, Dryad, ReShare, 4TU.ResearchData, Mendeley Data, DataONE (Arctic Data Center, KNB, and other member nodes), and LDbase based on links in the manuscript.

Listing a repository’s files never requires an API key, but some hosts answer faster or more completely with one: OSF allows 100 requests/hour unauthenticated versus 10,000/day with a token (see [osf_pat()]), and Dryad enforces a strict per-IP daily quota on repeated listing (see cache below). Dryad is a special case beyond rate limits: listing a Dryad dataset’s files works without a key, but actually downloading file CONTENTS from Dryad fails with HTTP 401 unless a key is set, even for a fully public dataset (see [dryad_pat()] or [dryad_auth()]). Since this module only lists files and never downloads their contents itself, that limitation applies to data_check and code_check (which do download content), not here – see their own documentation.

When a linked OSF page is a registration, its registered_from project (the one it was registered from, which the manuscript itself may never link directly) is also checked: if that project is public its files are listed under its own URL, and if it is closed or otherwise inaccessible the report flags it explicitly, since some registrations only describe their content rather than mirroring it.

If you want to extend the package to be able to download files from additional data repositories reach out to the Metacheck development team.

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Neurofeedback creates a closed loop between subjective experience and brain activity. Such a feedback loop might allow establishing direct neuro-experiential correspondences, thereby narrowing the gap between the seemingly irreconcilable domains of private conscioussness and external measurement. We introduce a repeated-probing paradigm that allows systematic testing of such neuro-experiential correspondences within individuals by randomizing and blinding the feedback signal direction across trials, combined with semi-structured phenomenological interviews following unblinded regulation sessions. We apply this paradigm to electroencephalography (EEG) neurofeedback in experienced meditators across two studies. Study 1 (n=9) aimed to replicate the previously reported correspondence between posterior cingulate cortex (PCC) gamma activity and effortless awareness, extending the paradigm from visual to auditory feedback. An exploratory Study 2 (n=4) evaluated three additional markers: occipital alpha, midfrontal theta, and PCC high-beta power. In Study 1, participants identified the expected correspondence significantly above chance for both visual and auditory feedback (mean accuracy=72.5%). Additionally, gamma power was significantly reduced during neurofeedback-assisted meditation. In Study 2, no marker yielded significant neuroexperiential correspondences, although alpha power increased and high-beta power decreased during neurofeedback-assisted meditation. Phenomenological interviews revealed distinct meditative strategies, with releasing effort and control predominating in gamma neurofeedback. However, wholebrain and control analyses raised concerns about the spatial specificity and potential muscular contamination of the gamma signal. Our findings introduce a novel neurophenomenological neurofeedback paradigm, replicate and extend previous findings on the correspondence between effortless awareness and gamma feedback, and highlight important limitations in interpreting these effects as reflecting neural rather than muscular activity.

1 Introduction

The relationship between subjective experience and physical processes in the brain remains one of the most difficult and persistent questions in science and philosophy (Cogitate Consortium, 2025; Nagel, 1974; Searle, 1992; Chalmers, 1995). One research approach that directly engages with this challenge is neurophenomenology (Varela, 1996). Rather than attempting to explain how consciousness "emerges" from brain processes, neurophenomenology attempts to find "meaningful bridges between two irreducible phenomenal domains" (Varela, 1996, p. 330). Thus, the problem is tackled from two sides, through neuroscientific experimentation as well as a disciplined investigation of subjective experience. However, this raises the question of how these distinct domains can be integrated (Berkovich-Ohana et al., 2020). In this context, neurofeedback has been suggested as a promising experimental approach (Bagdasaryan & Le Van Quyen, 2013; Bielas, 2017). Building on a previous line of studies (Garrison, Santoyo et al., 2013; van Lutterveld et al., 2017), we develop and evaluate the feasibility of applying this approach to states of meditation. Using neurofeedback based on source-localized oscillatory markers we investigate whether long-term meditators are able to create meaningful bridges between their subjective experience of the respective meditation state and corresponding large-scale neural oscillations. Specifically, we make three new contributions. First, we introduce a repeatedprobing paradigm in which the direction of the feedback signal is randomized and blinded across trials, so that each trial is an independent test of a neuro-experiential correspondence within each participant. Second, in a confirmatory Study 1, we use this paradigm to replicate and test the validity of the reported correspondence between posterior cingulate cortex (PCC) gamma feedback and effortless awareness (van Lutterveld et al., 2017), extend it from visual to auditory (eyes-closed) feedback, and test whether the effect is specific to the PCC and robust to muscle artifacts. Third, in an exploratory Study 2, we test whether the paradigm transfers to three further oscillatory markers (midfrontal theta, occipital alpha and PCC high beta) and their associated meditation states. Neurofeedback is a form of biofeedback which provides individuals with information about their brain activity, which allows them to monitor and modulate it and establishes a closedloop system between mental and neural processes (Sitaram et al., 2017). In the context of neurophenomenology, this can be understood as a unique situation where the conscious inner state and the measured neurophysiological processes mutually influence each other and can be correlated moment-to-moment from within the participant's perspective. The participant thus takes the role of a co-researcher who aims to observe correspondences between inner experience and the feedback signal (here referred to as neuro-experiential correspondences). In this vein, neurofeedback promises to allow establishing mutual constraints between first-person subjective experience and physical brain activity, which is the central tenet in Varela's pragmatic approach to the neuroscience of consciousness. In contrast to classical neurofeedback studies (cf. Sitaram et al., 2017), which usually do not pay attention to features of conscious experience and their relation with the feedback signal, the neurophenomenological approach requires the integration of so-called first-person methods (Varela and Shear, 1999). These methods are used to track and document observed neuro-experiential correspondences, as well as the characteristics of the mental gestures, i.e., deliberately enacted cognitive or attentional strategies used to influence the feedback signal. Specifically, neurophenomenology aims to uncover pre-reflective structures of experience beyond the contents of experience. Methods to access these structures include phenomenological interviews which support awareness of fine-grained dynamics and prereflective characteristics (Petitmengin, 2006). It has further been suggested that employing meditators as participants can support neurophenomenology (Berkovich-Ohana et al., 2020), and some positive examples are available (e.g., Jo et al., 2013; Jo et al., 2014; Dor-Ziderman et al., 2016; Trautwein et al., 2024). This idea is also backed by research showing that meditation training can foster self-regulatory, attentional, interoceptive and introspective abilities (Fox et al., 2012; Sedlmeier et al., 2012; Treves, Chen et al., 2025; Treves et al., 2019). Accordingly, experienced meditators might be able to report on subtle aspects of their conscious experience with greater reliability (Lutz et al., 2007; Berkovich-Ohana et al., 2020; Bauer et al., 2025). Several studies have attempted to implement this approach (Garrison, Santoyo et al., 2013; Garrison, Scheinost et al., 2013; van Lutterveld et al., 2017; Davelaar et al., 2018 , Davelaar, 2025). One study provided fMRI based real-time feedback about activity in the posterior cingulate cortex (PCC) while participants meditated (Garrison, Santoyo et al., 2013; Garrison, Scheinost et al., 2013). Another study used source-localized EEG gamma activity from PCC (van Lutterveld et al., 2017). These studies found that both novice and experienced meditators could influence PCC activity through meditation (Garrison, Santoyo et al., 2013; van Lutterveld et al., 2017). Such decreases in PCC activity corresponded with inner experiences of effortless awareness, a meditative state characterized by open, non-striving awareness without deliberate control or focused effort (Garrison, Santoyo et al., 2013). These findings suggest a neuro-experiential correspondence and a causal link between specific brain processes (activity in PCC) and phenomenology (experience of effortless awareness). However, so far these findings have not been replicated and rely on only one EEG and one fMRI study. In particular there are several caveats to the findings from the EEG study: van Lutterveld et al. (2017) did only report offline ROI analyses, and no whole-brain maps of the observed regulation effect. Given the high degree of spatial leakage in EEG based source imaging, this leaves open whether the observed effects were indeed driven by the PCC, or rather by other regions that spread into the PCC. Additionally, the gamma band is strongly contaminated by muscle activity (Whitham et al., 2007; Nekrasova et al., 2022), which might have confounded the results by van Lutterveld et al. (2017). The authors tested the influence of several specific highly salient artifacts (strong muscle contractions, eye blinks, eye movements) and found limited effects. However, previous research has shown that subtle muscle tension vs. relaxation effects predominate in the gamma band across the whole scalp, and particularly in lateral and posterior electrodes (Whitham et al., 2007; Whitham et al., 2008). Thoroughly assessing the effect of muscle artifacts therefore requires assessment of entire scalp topographies in frequency bands contaminated by muscle activity. Study 1 addresses these questions, and thereby replicate and extend van Lutterveld et al. (2017). Beyond the PCC gamma band effects reported by van Lutterveld et al. (2017), it is an open question whether the overall approach can be transferred to other EEG frequency bands which have previously been linked to meditation (Lee et al., 2018). Establishing the feasibility of the approach for other frequency bands which are not (or much less) confounded by muscle activity would both widen the scope of the paradigm and support the robustness and validity of the approach. In study 2 of the present report we therefore explore the feasibility of transferring the approach to other frequency bands. Specifically, we identified the following neuro-experiential correspondences as suitable to be probed with a neurofeedback paradigm: First, increased theta activity (4-7 Hz) in the anterior cingulate cortex has been associated with focused attention, a meditation practice in which attention is focused on a single object such as the breath (Tang et al., 2019; Brandmeyer and Delorme, 2020; Cahn et al., 2010). Second, increased alpha activity in the occipital cortex has been associated with relaxed alertness in meditation (Lomas et al., 2015; Lagopoulos et al., 2009). Third, reduced high beta activity (21-30 Hz) in the PCC has been associated with meditation-induced self-boundary dissolution, characterized as a reduction of the sense of being an embodied, bounded entity (Ataria, 2015; Nave et al., 2021; Dor-Ziderman et al., 2016; Trautwein et al., 2024).

Both studies also address two methodological features of the paradigm employed by van Lutterveld et al. (2017). First, feedback was provided using a visual graph, which limits the application to meditative states that are typically practiced with eyes closed. Therefore, we also applied an auditory feedback condition and compared it with visual feedback. This allows eyes-closed meditation, a common and often preferred way of practicing. Moreover, in the study by van Lutterveld et al. (2017) the direction of the feedback graph (upward vs. downward) corresponding to increased or decreased gamma power in the PCC was randomized across participants and remained consistent across multiple neurofeedback trials within each participant. Given that participants gradually built up their understanding regarding the relationship, the trial-wise correspondence ratings cannot be evaluated as independent data-points. Consistency could therefore only be tested across participants (i.e., the percentage of individuals identifying the correct direction). This reduces statistical power and limits possibilities to test for other relationships (e.g., whether the meditative techniques employed by certain participants influenced their ability to identify a relationship). We therefore randomized the signal direction (whether activity increase leads to signal increase or decrease) over trials, such that each trial yields an independent data point. This offers a substantial increase in statistical power and resolution compared to the original study. Beyond its utility as a research paradigm, neurofeedback has been suggested to enhance attentional control and deepen meditative states via brain regulation (Brandmeyer & Delorme, 2020). Yet, evidence for such regulation effects in consumer devices is lacking (Treves, Bajwa et al., 2025), and still scarce for lab-based interventions (Chen & Ziegler, 2025). We therefore also test whether the investigated brain markers of meditation states can be regulated during neurofeedback-supported meditation beyond effects induced by meditation alone.

Within both studies, we addressed the following research questions: Q1: Are participants able to detect a correspondence between their subjective meditation experience and the feedback signal based on the respective brain markers (cf. Table 1).

Q2: Are participants able to regulate the respective brain marker (cf. Table 1) during neurofeedback-supported meditation beyond effects induced by meditation alone? Q3: Are the reported mental gestures through which the feedback were manipulated consistent with the phenomenology of the corresponding meditation type (cf. Table 1)?

For study 1, the following additional questions were addressed to thoroughly investigate the validity of this finding and rule out confounding effects: Q4: Is the regulation effect primarily driven by the brain marker region on which the feedback was provided, rather than by other regions? Q5: Is the gamma feedback signal driven primarily by neural rather than muscular activity?

2 Methods

Two studies with similar methods were conducted and we describe them jointly below. Study 1 employed PCC gamma feedback (both visual and auditory) and study 2 tested auditory feedback in the theta, alpha and high beta band (see details below). Deviations for study 2 are mentioned within the respective sections. We used a within-subjects, repeated-measures design in which each participant was tested in several experimental sessions (2 sessions for study 1 with visual/auditory feedback modalities, 3 sessions for study 2 with theta/alpha/high beta feedback conditions). For both studies, we employed the same methodological approach and study design (Figure 1C): Participants first completed a meditation baseline to calibrate the neurofeedback system and to obtain a baseline for the following stages. Subsequently, they completed two long (5 mins) and 10 short (2 mins) neurofeedback runs with randomized and blinded signal direction (i.e. whether increase in the brain marker leads to increase in the feedback signal was randomized across trials). After each run we probed the perceived direction (addressing Q1). Then, participants completed two regulation runs, in which they were asked to modulate the signal in the direction of a deeper meditation state (i.e. they were unblinded with respect to the expected signal direction) (addressing Q2). Finally, phenomenological interviews characterized the strategies participants found effective in influencing the feedback (addressing Q3). Here we employed phenomenological interviews, which were guided by principles of the micro-phenomenological interviewing approach (Petitmengin, 2006). These interviews thus serve to describe the phenomenological character of the investigated neuro-experiential relationships.

2.1 Participants

Experienced meditators were recruited by contacting meditation centers and communities around Freiburg, Germany. Inclusion criteria were a minimum of 700 lifetime practice hours in either a secular or Buddhist style of mindful awareness meditation (e.g., secular mindfulness, Vipassana, Zen or Mahamudra). Exclusion criteria were ongoing psychiatric or psychotherapeutic treatment, acute psychological symptoms or experience of strong and uncontrollable adverse effects during meditation. Study 1 was conducted with 9 participants (7 male, 2 female; mean age 37.56 years, SD 5.25 years; 2 high school and 7 universityeducated; between 740 and 15816 meditation hours, mean 4075 h, SD 4743 h). Study 2 was conducted with 4 participants (all male; mean age 41 years, SD 4.73 years; all universityeducated; between 1709 and 35046 meditation hours, mean 11793 h, SD 15591 h). Meditation hours were calculated according to Bowles et al. (2022). Some data from Study 1 were not usable, which resulted in EEG data being available from 9 visual and 8 auditory sessions and phenomenological interviews from 8 sessions in each modality. All participants had normal or corrected-to-normal vision and hearing, had been informed about the objectives and protocol of the study prior to their consent and were compensated financially with 40€ per experimental session (approx. 4 hours). The study was approved by the ethics committee of the University Medical Center Freiburg.

The sample size was based on pragmatic and statistical considerations: Power analysis was conducted using the simr package (Green and MacLeod, 2016). Data were generated under a binomial mixed-effects model with a random intercept for subject. The null hypothesis corresponded to a baseline probability of 0.50. We assumed a true probability of 0.75, conservatively assuming the lowest accuracy (12/16 correct) reported by van Lutterveld et al. (2017) and a moderate between-subject standard deviation of 0.5. For study 1, a design with 8 subjects and 12 trials per subject, 1000 simulation runs yielded an estimated power of 96.5% (CI 95-97.5%) using a two-sided Wald Z-test (α = 0.05). Study 2 was designed as an exploratory feasibility study. Under the same assumptions, N=4participants would yield 81% power (CI 78-83%). However, these assumptions are derived from PCC gamma feedback, and no prior correspondence data exist for the Study 2 markers. We therefore do not treat this figure as evidence that Study 2 was adequately powered, and we interpret its results cautiously.

2.2 Meditation instructions

Participants received meditation instructions by email two days prior to each experimental session. These were either in the form of a guided audio meditation for self-boundary dissolution, or written instructions for the other meditation practices. Importantly, these instructions oriented participants towards the state the feedback would likely respond to, but participants were free to experiment with other techniques. Instructions were reviewed at the beginning of the session with the experimenter and questions could be clarified.

2.2.1 Effortless awareness

In line with van Lutterveld et al. (2017), participants were instructed to practice a meditation technique in which they noted everything that happened in their awareness (or in their conscious space) without attempting to change any aspect of it. They were asked not to exercise effort to constrain their attention, but also not to get carried away by thoughts. It was suggested to participants to achieve this state by assigning a mental label to everything they noticed in their experience. However, they were also invited to practice effortless awareness without such labeling, according to their preference.

2.2.2 Focused attention

Participants were asked to focus their attention to a specific narrow aspect of their experience. It was suggested to use the sensation of breathing below the nose, but they were free to choose another sensation to focus on. Whenever their attention was captured by a sensation or thought different than what they were set to focus on, they should note this and subsequently return their attention to their point of focus. Focused attention meditation differs from effortless awareness in that it relies on sustained, selective attention and active redirection toward a chosen object, rather than allowing awareness to remain open and nonselective. Therefore, both states were used as a control meditation state for each other in the baseline recordings (see section 2.4).

2.2.3 Self-boundary dissolution

Participants focused on dissolving the perceived distinction between oneself and the environment in which this self is immersed. They received a guided audio meditation obtained from boundary dissolution training in previous studies (Nave et al., 2021; Trautwein et al., 2024). These instructions encourage "not to be restricted to the physical body, and to drop into the spatial quality of awareness". This experience was approached by stretching and expanding awareness to all directions, letting go and releasing a sense of control, effort and tension.

2.2.4 Self-boundary maintenance

Participants focused on maintaining the perceived distinction between oneself and the environment, typically by focusing on the experience of the shape and boundaries of their body. This was used as a control meditation state to self-boundary dissolution in which the contrast between these two states was maximized.

2.2.5 Meditative relaxation

To achieve a state of meditative relaxation, participants were instructed to imagine themselves in a comfortable environment and to observe the flowing of the breath. They were asked to let go of all tension and discomfort, to deeply relax, find a sense of calmness and warmth and to allow tiredness to arise.

2.2.6 Arousal

Participants were instructed to bring themselves into a state of activation, typically through imagining themselves in an activating or energizing situation such as during an exciting or threatening activity. This was used as a contrasting control state to meditative relaxation.

2.3 Feedback signal

2.3.1 Technical setup

The electroencephalogram was recorded with 64 active electrodes and a QuickAmp amplifier (Brain Products, Munich, Germany), with a sampling rate of 1000 Hz. Recordings were conducted in a chamber shielded against sound and electromagnetic radiation to avoid noise interference. Participants had the choice of sitting on either a meditation cushion or a chair in front of a screen on which instructions were shown via Psychopy software (Version 2023.1; Peirce et al., 2019).

2.3.2 Online data processing and source power estimation

Online (real-time) data processing was conducted using Neuropype software (Version 2022.0; Intheon, 2023). The following processing steps were applied: 1) Bandpass filter: A Finite Impulse Response (FIR) filter was applied to the raw EEG signal to isolate physiologically meaningful EEG activity.

To minimize leakage beyond the pass band, a roll-off was applied to the frequency cutoff, i.e., the frequencies between the roll-off and the cutoff were included gradually in the signal. The lower bound was selected with a roll-off between 0.5 and 1 Hz, and the upper bound with a roll-off between 60 and 65 Hz for the gamma power condition and between 35 and 40 Hz for all other conditions. These cutoffs retained each feedback band (up to 60 Hz for gamma, 30 Hz otherwise; Table 1) while attenuating slow drifts and high-frequency muscle activity, with transition widths kept narrow enough for low-latency real-time filtering.

2) Downsampling to 500 Hz to reduce computational load.

3) Bad channel removal and interpolation: Prior to the start of the measurement, 20 seconds of data were buffered to detect bad channels. A channel was considered bad and removed if it was either correlated below 0.8 with surrounding channels, or had an amplitude which differed more than 4 standard deviations from all other channels. Bad channels were interpolated by using the spherical spline method. 4) Re-referencing to across-channel average. 5) Source estimation: The source time course was estimated with a linearly constrained minimum variance (LCMV) beamformer (Van Veen et al., 1997). This source localization method is widely used and has been suggested as the method of choice to reduce the spatial extent of the reconstructed sources (Halder et al., 2019), which we considered especially important for localizing small brain regions such as the PCC. Beamforming was performed with a regularization strength of 0.001 and based on a per-element covariance matrix which was smoothed with an exponential moving average of a half-life constant of 3 seconds. For the forward model, a boundary element model (BEM) of 4495 vertices was constructed based on the Colin 27 head model (Holmes et al., 1998) with unconstrained dipole orientations. 6) Region selection: Regions were parcellated based on the Desikan-Killiany cortical atlas (Desikan et al., 2006), from which the region of interest (ROI) was selected as shown in Table 1 and Figure 1A for each neurofeedback condition. The source time course of all vertices within the ROI was averaged to yield a single ROI time course. 7) Oscillatory band power computation: The ROI time course was bandpass-filtered via a Butterworth Infinite Impulse Response (IIR) filter. This filter type smooths the cut-off boundaries and thereby avoids distortions of the passband. To reduce leakage of undesired frequencies into the pass band, a roll-off curve was applied to the frequency bands, i.e., the attenuation was gradually increased between two frequencies. The bandpass range varied between conditions and is shown in Table 1. After filtering, the oscillatory power of the signal was computed as its root-mean-square. An exponential moving average with a half-life constant of 3 seconds was applied between squaring and taking the square root. Compared to a simple moving average, this increased the weight of more recent parts of the time course compared to less recent parts, which decreased the perceived delay of the feedback signal.

2.3.3 Calibration

Prior to giving feedback, the range of expected source power was determined. It should neither be too large to avoid low-resolution feedback confined to a small part of the range, nor too narrow to prevent feedback values from frequently falling outside the range. The value range was calibrated on the data from the baseline (where participants alternated between meditation and resting states without receiving neurofeedback), for which the average power in the region and frequency range of interest was sampled every two seconds. The center of the feedback range was defined by computing the mean over these baseline samples, and the upper and lower bounds of the feedback range was set to ± 3 standard deviations around the mean.

2.3.4 Visual feedback

In the visual feedback condition of study 1, the feedback was provided as a bar plot in which the incoming value was represented by the bar height. The middle line of the bar plot was set to the baseline mean, and the y-axis limits corresponded to the expected value range. For randomization, in half of the trials the signal direction was flipped with respect to the brain marker by multiplying values by -1 to invert the bar direction. The signal was updated every 2 seconds by a new bar appearing at the center of the screen, and all previous bars moved one step to the left. Participants were instructed to keep their eyes open and to focus on the red dot at the mid-point of the graph, where the new bars appeared. See Figure 1B for an example of the visual feedback screen.

2.3.5 Auditory feedback

In study 2 and in the auditory condition of study 1, the feedback was provided as a prerecorded clarinet tone with varying pitch, with a tone range of 20 steps on a chromatic halfstep scale between B2 and G 4. The expected value range was divided into 20 bins (one for ♭ each tone), and an incoming value was assigned to a bin and converted to the corresponding tone, which was then played as the auditory feedback signal. If the incoming value was above or below the value range, it was assigned to either the highest or lowest bin, respectively. If the direction of the feedback signal was flipped with respect to the brain marker, the highest bin corresponded to the lowest tone and vice versa. A tone was played for two seconds, after which the signal was updated. Participants were instructed to keep their eyes closed during the measurement.

2.4 Experimental procedure

The experimental procedure consisted of the following steps (see Figure 1C for an overview): 1) Preparation: Participants received study information and the consent form by email before their first session, at which they signed the consent form and completed a demographic and meditation-experience questionnaire.

At each session, EEG electrodes were applied and the procedure and meditation instructions were reviewed, allowing participants to ask questions to clarify the procedure.

2) Motor task: Prior to the meditation-related feedback, we conducted feedback on a motor task to familiarize participants with the feedback signal. This was done with a simple motor task previously shown to elicit reliable sensorimotor beta desynchronization (Guarnieri et al., 2020). Participants received feedback on the beta-activity (12.5-29.5 Hz) in the sensory-motor region (Paracentral and precentral areas in the Desikan-Killiany atlas). The feedback direction was randomized and double-blinded, i.e., a change in brain activity would move the signal either upwards or downwards. To manipulate the feedback, participants were instructed to either perform wrist flexions/extensions with both hands, or to keep their body still. In each round of 1 minute duration, they altered five times between stillness and motion, always beginning with stillness. At the end of each round, they were asked in which direction the feedback signal had changed when they performed the wrist movement (up or down), and how certain they were about their answer. This procedure was repeated for 6 rounds, and the feedback direction (upwards or downwards) was balanced over the rounds.

3) Baseline: To calibrate the neurofeedback signal and gather recordings of the different states for later offline-analyses, a baseline was recorded during which no feedback was given. Participants alternated between a resting state, the primary meditation state and the control meditation state (control meditation states for each condition are shown in Table 1). During resting state participants were instructed not to meditate. For the instructions of the meditation and control states see section 2.2. Guided by pre-recorded auditory instructions, the procedure was as follows: 90 seconds rest, followed by five alternations between the primary meditation state and the control state of 60 seconds in each state, and ultimately another 90 seconds rest. This block was repeated twice, and participants had the option to pause as long as they wished between the two blocks. In the first block the alternations started with the primary meditation state, and in the second block with the control state. Participants were instructed to keep their eyes open if the baseline was followed by visual neurofeedback and closed if it was followed by auditory neurofeedback. 4) Test probes: Here, neurofeedback was provided to participants (see section 2.3 for feedback signal description). The duration of the first two rounds ("Free Play") was 5 minutes to give participants enough time to explore and familiarize themselves with the feedback. This was followed by 10 shorter rounds of 2 minutes each ("Short Probes"). The direction in which the feedback moved was either correlated or anti-correlated with the brain marker. For example, Effortless Awareness was expected to be marked by a reduction in PCC gamma activity, and this reduction moved the feedback signal either downwards (correlated) or upwards (anti-correlated). The signal direction was randomized and double-blinded, with half of the trials in both the Free Play and Short Probes in upward and the other half in downward direction. Participants were instructed to find out which feedback direction corresponded to a deepening of the instructed meditation state and to explore different inner gestures of entering that state. Immediately after the end of each of the probes participants were asked two questions over the computer screen in front of them regarding perceived signal correspondence ("In which direction did the signal move with your meditation?" → Two possible answers: Up, down) and confidence in the judgement ("How certain are you?" → Answer on a continuous Likert-scale from 1 (not certain) to 10 (very certain)). 5) Regulation: In this step the signal direction was fixed and unblinded, so that participants were informed at the beginning of each round in which direction the feedback signal was expected to move with the primary meditation state. In Study 1, two rounds of 5 minutes were conducted, with one round in upwards and one in downwards direction. Due to technical issues, in three of the auditory sessions in Study 1, only one round was available. In Study 2, only one round of 5 minutes in downwards direction was completed. At the end of each round, participants were presented on the screen with the question 'How strongly was your meditation connected with the feedback signal?'. The answer was a selection on a continuous visual scale from 1 (no connection) to 10 (strong connection). 6) Phenomenological Interview: Immediately after the regulation part, a semi-structured phenomenological interview was conducted to assess participants' experience while meditating with neurofeedback (see next section for details).

2.5 Phenomenological interviews

At the end of the neurofeedback session, semi-structured phenomenological interviews were conducted to characterize the subjective experience of meditation during the neurofeedback runs (test probes and regulation). This allowed us to verify and describe the experiential processes participants used while engaging with the feedback. The interview procedure was based on the principles of micro-phenomenology (Petitmengin, 2006) and focused on concrete moments, where the neurofeedback seemed to work optimally for the participant. The interview started with an open question, asking which meditative strategies or mental gestures resulted in a good correspondence with the signal. Participants were then instructed to focus on one moment where they perceived the highest correspondence between their experience and the neurofeedback signal. They were asked to become aware and to "re-live" this experience by getting in touch with it and recalling it with the sensory and motoric aspects it entailed (Petitmengin, Remillieux & Valenzuela-Moguillansky, 2019), a process termed evocation (Petitmengin, 2006). The interviewer then focused on this concrete lived experience by asking non-directive questions (e.g.: "When you do X, what exactly do you do?" ; Petitmengin, 2006). Additionally, nonverbal cues like physical gestures were verbally described by the interviewer to deepen descriptions and provide information for the analysis (Petitmengin, 2006; Valenzuela-Moguillansky & Vásquez-Rosati, 2019). In this second part of the interview, the interviewer focused on facets of embodied self-experience that were previously found to be modulated in deep meditative states (Nave et al., 2021). These descriptions are not analzed and reported here since they go beyond the purpose of the current report. Finally, subjects were asked to elaborate if they experienced the neurofeedback as helpful for their meditation. All interviews were conducted either in German or English and lasted 20 to 35 minutes. One interview was conducted as a self-interview, with a participant trained in the micro-phenomenological method using the interview guidelines to evoke their own experience. The interview was included for further analysis as literature indicates that self-interviewing can be a valid method of investigating phenomenal experience, if conducted by trained individuals (Sparby, 2022; Sparby et al., 2021).

2.6 EEG offline processing

To process EEG recordings for offline analyses, the following steps were applied: 1) In preparation for independent component analysis (ICA), highly noisy channels and segments with strong artefacts were removed.

Noisy channels were detected based on their correlation with other channels (at least 10% of time windows showed inter-channel correlation below 0.2), as well as deviation from the average signal amplitude (average zscore > 7). Strong artefacts were detected based on high-frequency power (removed if envelope magnitude from 110-140 Hz exceeded a z-score of 7).

2) Average referencing was applied, the data were bandpass-filtered between 1 and 100 Hz and a 50 Hz notch-filter was applied to remove power line noise. Data were segmented into 1second epochs.

3) An ICA was applied to the data based on the infomax method, with the number of components matching the number of good channels. Components were automatically labeled by using mne-icalabel (Li et al., 2022). Components which received an artefact label (i.e., a label which was not 'brain' or 'other') with probability above 75% were excluded. If the first component was labeled 'eye blink', it was excluded regardless of the probability. 4) Automatic detection and repair of bad channels was conducted by using Autoreject (Jas et al., 2017). The n_interpolate parameter was set such that the algorithm tried to interpolate 1, 2 or 4 channels in an epoch before removing it.

5) The data were manually screened for overly sensitive removal of artefacts if more than 10% of epochs were detected as bad. This was because the autoreject parameter 'n_interpolate' was set to remove bad epochs more readily compared to the default setting. Where necessary, the output of autoreject was corrected. 6) Bad channels marked during step 1 and 4 were interpolated.

2.7 Estimation of source level oscillatory power

The preprocessed EEG data (see Section 2.6) were further processed analogous to the online-processing by using MNE-Python (Gramfort et al., 2013). Sources were localized by an LCMV beamformer with regularization strength of 0.01. The forward solution was modeled on a three-layer Boundary Element Method (BEM) model with an ico-3 source space of the Colin 27 head model with unconstrained dipole orientations. The data covariance matrix was computed over the combined baseline and regulation segments to ensure the comparability between conditions by using the same spatial filters in all of them. Based on the resulting source time course, the oscillatory power in the frequency of interest (shown for different conditions in Table 1) was computed based on Welch's method (Welch, 1967). The n_fft parameter was set to the maximum of either 256 or the ratio between sampling frequency and the lowest frequency of interest to ensure adequate frequency resolution.

2.8 Analysis

In this section we will present our analyses on whether participants were able to detect the correct feedback direction, whether they were able to regulate the feedback signal, and which strategies were experienced as most successful in influencing the feedback signal. In study 1 we additionally present an analysis of the influence of muscular contamination on the feedback signal.

2.8.1 Detection of the correct signal direction

Participants' self-reports on the direction in which the feedback signal moved with the effortless awareness meditation were coded with respect to the actually presented feedback direction (i.e. whether increases or decreases of the respective region were chosen). An accuracy score was calculated by comparing this direction to the expected direction defined in Table 1 (1 = expected direction was chosen;0 = opposite direction was chosen) and averaging over the 12 probes. Mean accuracy was calculated separately for each modality (9 visual and 8 auditory participants) and across modalities by averaging over all available sessions. Modality-specific 95% confidence intervals were calculated using the t-distribution across participant-level accuracies. The overall 95% confidence interval was calculated using a percentile bootstrap that resampled participants while retaining all their available sessions. Accuracy scores were tested against chance level (50%) using a logistic generalized linear mixed model containing only an intercept and a random effect for subject. To assess whether feedback modality influenced accuracy, a second model including modality as a fixed effect was compared to the intercept-only model using a likelihood ratio test. Because nonsignificant results do not constitute evidence for the absence of an effect, we additionally conducted a Bayesian model comparison. Bayes factors were computed to quantify the relative evidence for models with versus without a fixed effect of modality, allowing direct evaluation of evidence both for the presence and for the absence of a modality effect.

2.8.2 Regulation of the brain marker

To analyze the source time course in the condition specific ROI (see Table 1) as well as over all other brain regions, the time course was averaged over all emitters within each region in the Desikan-Killiany cortical atlas, and the resulting data of each region were z-transformed within each recording session. A linear mixed-effects model was fit to gamma power in each region to examine the effects of timepoint (indexed by original 1-second epoch positions, retaining gaps after epoch rejection and centered at the integer midpoint of each original task series), task (rest, primary meditation baseline, control meditation baseline, and regulation), and modality (visual or auditory feedback), as well as their two-and three-way interactions. The model included random intercepts and slopes for timepoint by subject to account for differences between individuals in both baseline activity and in the rate of change across timepoints. To account for temporal autocorrelation in repeated measures, residuals were modeled using a first-order autoregressive structure. The model was initially fit using restricted maximum likelihood (REML).

Following the recommendations by Meteyard and Davies (2020), a stepwise backward selection was conducted to test whether the complexity of the initial maximal model was necessary. Random effects and the autoregressive structure were retained based on likelihood ratio tests using REML. Fixed effects were selected using maximum likelihood (ML) estimation and model comparison based on Akaike's Information Criterion (AIC). The full model was preferred among the tested hierarchical simplifications. The same model was then fitted to all other brain regions. All models were fit in R (version 4.4.3; R Core team, 2025) based on the nlme package (Pinheiro and Bates, 2000).

From the final model we derived the estimated marginal means (EMMs), where all task-mean contrasts were evaluated at centered timepoint zero. We evaluated whether the neural activity differed significantly when participants meditated with or without feedback based on the EMM contrasts, and whether the neural marker showed a significant trend in one direction based on the EMM time-trend estimates.

2.8.3 Analysis of phenomenological interviews

Analysis of the phenomenological interviews focused on descriptions of meditation strategies that were employed during moments of good correspondence between meditative experience and the feedback signal. This analysis aimed to a) check how participants actually implemented the meditative instructions and b) characterize the mental processes that potentially affected the neural processes represented by the feedback signal. These processes were not described on a coarse conceptual level (e.g., using general terms such as focused attention meditation), but were characterized in terms of employed mental gestures. In micro-phenomenology, mental acts or "micro-gestures" are an important unit of analysis (Petitmengin, Remillieux & Valenzuela-Moguillansky, 2019), and phenomenology more broadly understands them as co-constituating factors in conscious experience. Moreover, this concept has proven useful for characterizing meditation practice in previous research (Petitmengin, van Beek et al., 2019; Nave et al., 2021).

The qualitative analysis adhered to principles of thematic analysis (Braun & Clarke, 2012), and combined inductive and deductive (or theory-driven) data coding in a hybrid approach, which has been recommended for mixed methods research (Proudfoot, 2023). Moreover, the identified categories and codes (see below) were grounded in concrete experiential descriptions of participants (and not in contextual information or interpretations and beliefs regarding the experience) as suggested by the micro-phenomenological analysis approach (Petitmengin, Remillieux & Valenzuela-Moguillansky, 2019). Overall, this analytical approach allowed us to characterize mental gestures enacted in order to influence the neurofeedback, focusing on those gestures perceived as most effective by the participants, while also enabling integration with quantitative data (see below).

The first step of the procedure involved verbatim transcription of audio recordings of the interviews, including description of non-verbal and paralinguistic elements such as pauses, grunts or laughter (Valenzuela-Moguillansky & Vásquez-Rosati, 2019). Subsequently, relevant passages were analyzed by allocating codes that summarize the essential meaning of individual utterances. The codes were then ordered and merged based on redundancy and similarity in their content, resulting in a list of codes for each interview. After the intraindividual analysis, structurally similar themes of different participants were grouped to derive a general inter-individual thematic structure. These themes were then contrasted with existing phenomenological categorization schemes (Nave et al., 2021 , Garrison, Santoyo et al., 2013) to enrich the current analysis and to allow for integration with the previous literature. The final categories were defined in a way that ensured grounding in and comprehensive description of the gestures emerging from the interviews. After generating this categorical structure, we scored, for each interview, whether each of these categories was present (1) or not (0), allowing for multiple categories per interview. Note that this process was performed jointly across all interviews from all conditions in both studies in order to yield a common set of categories which allowed for an overall comparison between conditions.

2.8.4 Correlation with Accuracy

For study 1 we tested whether participants with higher accuracy in recognizing the correspondence between feedback signal and their meditation experience would also be better in regulating the signal. We computed the Pearson correlation between the accuracy and the mean power difference during effortless awareness meditation with and without feedback, as well as between accuracy and the power slope during regulation.

2.8.5 Contamination by muscular activity

Considering that the gamma band is strongly contaminated by muscular activity (Whitham et al., 2007; Nekrasova et al., 2022), we estimated to what extent the feedback signal is driven by muscular activity. Two analyses were conducted:

First, we computed the Pearson correlation between the brain marker time course on which the feedback was provided and the oscillatory power time course of each sensor. This analysis aimed to test if sensors located close to muscular noise generators contributed strongly to the ROI timecourse estimation. The raw (uncleaned) sensor data were used because this was the original input for the neurofeedback application on which the brain marker time course was computed. Analogous to the online-feedback, a Butterworth Infinite Impulse Response filter was applied to the raw sensor data and the power was computed by applying a root-mean-square with an exponential moving average of a half-life constant of 3 seconds. This was done once by filtering for the same gamma frequency range as was used for the feedback (38-60 Hz) and additionally by filtering for the peak muscular frequency (110-140 Hz). If the feedback signal was driven by PCC rather than muscular activity, we expected the brain marker time course to show the highest correlation with central EEG sensors near the posterior midline because these are most proximate to the PCC. If, on the other hand, the signal was driven by muscular activity, we expected the correlation to be highest with sensors close to potential muscular sources, i.e., frontal, temporal and occipital sensors on the periphery of the montage.

Secondly, we examined the sensor weights of the LCMV beamformer used for PCC source reconstruction, to test which sensors were most influential on the projected PCC activity. Sensor weights from the cleaned offline covariance estimate were averaged across all vertices in the PCC to yield a single effective weight vector, and weights were normalized across sensors to allow for comparisons across sessions. We expected the weights to be highest at sensors close to potential muscular sources if the PCC signal was contaminated by muscular activity, and highest in the posterior central area otherwise.

2.8.6 Correction for multiple comparisons

Benjamini-Hochberg False Discovery Rate (FDR) correction was applied to control the false discovery rate at 5% for each hypothesis, i.e., separately for correspondence and regulation within each study. Correspondence families comprised three tests: visual, auditory and combined in Study 1, theta, alpha and beta in Study 2. Regulation families comprised six tests: three meditation-baseline-minus-regulation contrasts and three regulation slopes across the same modalities or markers. Whole-brain contrasts were corrected separately across 67 regions. Additional supplementary task comparisons are descriptive and report unadjusted pvalues.

3 Results

3.1 Study 1: Effortless awareness and gamma power in PCC

Study 1 aimed to replicate previous findings of a neuro-experiential correspondence between gamma power in the PCC and states of effortless awareness in meditation, extending the paradigm to also include auditory feedback. Nine participants completed visual and auditory neurofeedback sessions. One auditory EEG recording was lost due to technical issues, leaving 9 visual and 8 auditory EEG sessions for analysis. Participants were tested over 12 blinded neurofeedback runs ("probes") and 2 unblinded runs ("regulation"). For each of the probes, participants reported the direction of the perceived correspondence (i.e. whether the signal went up or down when entering states of effortless awareness). The accuracy in identifying the correct signal direction in line with previous findings (gamma power reduces with effortless awareness) is evaluated in section 3.1.1 (testing research question Q1 in the introduction). In section 3.1.2 we test whether participants were able to regulate the signal (i.e. reduce PCC gamma power) in the unblinded runs (testing research question Q2). In section 3.1.3 we characterize the meditative strategies that were employed by the participants to influence the signal, providing thicker phenomenological descriptions of this side of the neuroexperiential relationship (evaluating research question Q3). The subsequent sections qualify these results by evaluationg whole brain effects of regulation (section 3.1.4; research question Q4) and addressing potentially confounding muscle artifacts (section 3.1.5; research question Q5).

3.1.1 Participants identified the expected relationship

To test whether participants were able to detect a correspondence between their subjective meditation experience and the feedback signal (Q1), we computed accuracy across all 12 probes, defined as the ability of the participant to identify the feedback direction in accordance with predictions based on past research (i.e., reduced PCC gamma power corresponding with effortless awareness). Accuracy scores ranged between 33 and 100%, with a mean of 75% (95% CI: 57.5-92.5%; n = 9) for the visual and 69.8% (95% CI: 55.4-84.2%; n = 8) for the auditory feedback condition (see Figure 2). Across modalities, this yielded an overall mean accuracy of 72.5% (95% cluster-bootstrap CI: 62.7-83.8%).

An intercept-only binomial logistic generalized mixed-effects model was fitted to the data to test whether the accuracy differed significantly from chance level (50%). The accuracy across participants was significantly above chance level for both visual and auditory feedback modalities, as well as for both modalities combined (see Table 2). This was further supported by a likelihood ratio test that showed that adding modality as a fixed effect did not improve the model (χ²(1) = 0.291, p (FDR-corrected) = 0.59). Moreover, the Bayes factor in favor of the null model (BF₀₁ = 12.351) can be interpreted as strong evidence for the absence of a modality effect on accuracy. This indicates an established neuro-experiential correspondence in both feedback modalities equally.

3.1.2 Gamma power was reduced during regulation compared to meditation baseline

In this section we tested whether participants were able to regulate PCC gamma power beyond changes induced by meditation alone (research question Q2). To this end, PCC gamma power served as the dependent variable, and a linear mixed-effects model was fitted to the time course of PCC gamma power. Model summary statistics are shown in the Supplementary materials (Table 1 for fixed effects and Table 2 for random effects). We tested two hypotheses using pre-specified contrasts: a) PCC gamma power will be significantly reduced during neurofeedback assisted meditation (regulation) compared to the baseline meditation. This was evaluated based on the estimated marginal means contrasts, which are shown in Table 3 (only those relevant for the hypotheses; for all contrasts and trend estimates, see Table 3 in the Supplementary materials). PCC gamma power was significantly lower during regulation than during the effortless-awareness baseline in the auditory modality and across both modalities combined (both FDR-corrected p<0.001). The visual contrast was not significant (FDR-corrected p=0.091). These results support hypothesis a) for the auditory and combined analyses. The second hypothesis we tested was b) PCC gamma power will show a significantly negative slope (time trend) during the regulation task. This was evaluated based on time-trend estimates for each feedback modality (see Table 3 for estimates relevant for hypotheses; for all contrasts and trend estimates, see Table 3 in the Supplementary materials). None of the regulation slopes differed significantly from zero (FDR-adjusted pvalues: visual 0.427; auditory 0.427; combined 0.924), which provided no support for hypothesis b). The mean and slope for all conditions are shown graphically in Figure 3. Following these results, we also tested whether a higher correspondence between subjective experience and the brain marker (as shown in section 3.1.1) predicts participants' ability to regulate the respective brain marker. Accuracy in recognizing the signal direction was not significantly correlated with either the difference in mean gamma power between effortless awareness and regulation, nor the slope of gamma power during regulation. See Figure 1 in the Supplementary materials for details.

3.1.3 The phenomenology of employed meditation strategies confirms and refines descriptions of effortless awareness

Besides the quantitative analyses presented so far, we also addressed the following two questions (related to research question Q3): a) Are the reported gestures consistent with the hypothesis that meditative states of effortless awareness (and not other meditative gestures) are the driving mental processes that influence the feedback signal?

b) Are specific gestures, in particular those related to effortless awareness, associated with a higher accuracy in the identified relationship? This section reports the meditative strategies in terms of mental gestures that were enacted by the participants to influence the neurofeedback signal as derived from qualitative analysis of the phenomenological interviews completed after the neurofeedback sessions. The interviews focused on moments of subjectively perceived good correspondence between meditative experience and feedback signal. Based on a joint analysis of all interviews from both studies, 10 categories of identified gestures emerged (see Figure 4). Note that some of these categories were only or predominantly present in the neurofeedback conditions tested in study 2 and are reported here for the sake of comparability. Phenomenological interviews were available from 8 visual and 8 auditory sessions. Participant 4's available interview was from the auditory session, and participant 6's from the visual session. As shown in Figure 4a, the gesture "Letting go of effort and control" was reported consistently across all participants and both feedback modalities. Moreover, the gestures "Connecting with the field of perception", "Perceiving without judgement or involvement" and "Meta-awareness" were reported frequently. This overlaps with and adds nuance to previous findings of meditation based modulation of PCC activity through effortless awareness, described previously by qualitative categories of "effortless doing" and "undistracted awareness" (Garrison, Santoyo et al., 2013).

3.1.4 Gamma-power reductions during regulation were spatially widespread

We examined whether gamma-power reductions during regulation were specific to the PCC or also occurred in other regions (research question Q4). We fitted the model described in Section 2.8.2 to each of the 67 cortical regions with source coverage and evaluated the effortless-awareness-baseline-minusregulation contrast across both modalities (Figure 5). Under the selected model, 60 regions showed significant differences after FDR-correction. The largest standardized reduction occurred in the right pars triangularis (estimate = 0.524). Both PCC hemispheres also showed significant reductions (estimate left: 0.249; right: 0.232), although these reductions were substantially lower than in other regions. These findings indicate that the estimated regulation effect was spatially widespread rather than specific to the PCC, contrary to our expectation in research question Q4.

3.1.5 Was the feedback signal driven by changes in muscular activity?

As the range of the gamma band used for the feedback is heavily conflated with muscular activity (Whitham et al., 2007; Nekrasova et al., 2022), we aimed to evaluate whether there were indications that the feedback signal was influenced by muscular activity (research question Q5). First, we correlated the PCC gamma time course (on which the feedback was based) with sensor-level gamma power at 38-60 Hz and at 110-140 Hz. The latter range is the default frequency range for muscle activity annotation in the MNE-Python software (annotate_muscle_zscore; MNE 1.10.2 documentation) and has been used in past studies to control for muscle activity (e.g. de Vries et al., 2017; van Vugt et al., 2020). Average r-values are shown in Figure 6A and B, and the results for each individual session can be found in the Supplementary materials, Figures 2 and 3. Results show a strong correlation with lateral fronto-temporal electrodes, which are known to be heavily influenced by (temporalis and frontalis) muscle activity (Whitham et al., 2007; Whitham et al., 2008; Yilmaz et al., 2014). This suggests that the feedback signal is driven at least partly by muscular activity. Secondly, we examined the sensor weights of the offline LCMV reconstruction fitted to cleaned EEG data. The averaged weights across subjects are shown in Figure 6C, and results for individual sessions can be found in the Supplementary materials, Figure 4. This shows that the beamformer weights are on average highest around central and midline electrodes, which we would expect considering that these are spatially closest to the PCC. Taken together, this indicates that even though the beamformer weighed central electrodes highly, the activity in lateral fronto-temporal electrodes was strong enough to exert substantial influence on the signal time course. This pattern was also observed for the high gamma (110-140 Hz) range, aggravating concerns about muscular confounds. Moreover, although the average beamformer weights were focused on the central electrodes, many individual sessions showed additional strong weights in temporal and occipital electrodes (see Supplementary materials, Figure 4). Some sessions showed substantial weights at temporal and occipital sensors, indicating that the offline PCC reconstruction remained sensitive to signals recorded at these locations. Together, the sensor correlations and offline weight patterns raise concerns about a muscular contribution to the estimated PCC gamma activity. Further evidence for the interpretation that the feedback reflects muscle rather than PCC activity comes from one participant who was excluded from the analysis because this participant reported deliberate muscle usage (swallowing and frowning) to manipulate the feedback signal. Based on this strategy the participant was able to estimate the correct feedback direction with 100% accuracy. Although we excluded this participant from all analyses presented so far, this session serves as a reference for explicit muscle use. The correlations between sensor and feedback time course as well as the sensor weights for PCC localization are shown in Figure 7, as well as in the Supplementary materials, Figures 2 3 4, for a direct comparison with the other individual sessions. Both the correlations and the sensor weights look very similar in the session of explicit muscle usage and some of the other sessions in which muscle usage was not explicitly reported. This additionally supports the interpretation that muscle tension or relaxation might have been implicitly used by some of the participants to influence the feedback signal.

3.2 Study 2: Exploratory extension to other brain markers

In study 2 we aim to test the feasibility of extending the developed approach from study 1 to other frequencies and brain regions of interest, which were defined based on previous meditation research (see Table 1 and Figure 1A). Specifically, three brain markers were tested across 12 EEG sessions in four participants. Study 2 was designed as an exploratory feasibility study and therefore relied on a small sample (n=4). The repeated probes (n=12) paradigm nevertheless allows characterizing individual subject effects and detecting group effects with magnitudes comparable to those of study 1 (see methods section). In section 3.2.1 we report accuracy of the identified direction with respect to the expected direction for each brain marker (cf. Table 1; research question Q1). In section 3.2.2 we test whether participants were able to regulate the respective brain markers during neurofeedbacksupported meditation beyond the effect by meditation alone (research question Q2), and section 3.2.3 characterizes the phenomenology of the employed meditation strategies, testing in particular if there are differential profiles of strategies for the different brain markers (research question Q3).

3.2.1 Participants did not identify consistent relationships

We assessed whether participants could detect the correspondence between their subjective experience and the corresponding brain marker based on the feedback (research question Q1). Figure 7 shows accuracies achieved by each participant and mean across participants for each condition. The binomial generalized logistic mixed-effects model did not show significant effects in any of the conditions (cf. Table 5). Given that we ran two-sided tests, this indicates that no clear group-level evidence, either in the direction of our hypotheses or the opposing direction was identified. Of note, for the alpha and beta conditions, two individuals showed highly consistent judgements (12 out of 12) in the expected direction (beta) or in the opposite direction (alpha). This suggests that it might be possible to correlate meditative experience and feedback of the respective brain marker for some individuals. The theta estimate was opposite to the hypothesized direction but was not significant (FDR-corrected p=0.335).

3.2.3 Meditation strategies show differential but overlapping phenomenological patterns for the four conditions

We evaluated whether the mental gestures which participants employed to manipulate the feedback signal were consistent with the phenomenology of the corresponding meditation type (research question Q3). Participants reported differential but overlapping patterns of mental gestures in the three neurofeedback conditions (Figure 4b, see Table 4 for a definition of the gestures). In the alpha condition, all participants engaged in gestures that suspend effort and control (category A), and some reported to attend to bodily processes without judgment or involvement (categories C and H) and gestures that enhanced drowsiness (category J) during moments of correspondence. Here the most effective strategy was "Attenuating sensory experience" (category E), which was used by the single participant showing high consistency in the opposite direction. In the beta condition, gestures of letting go of effort and control (category A), merging with the surroundings (category B) and noninvolved or non-judgmental perception (category C) were predominant, consistent with previously reported phenomenology of boundary dissolution (Nave et al., 2021). The most effective strategies were "Meta-awareness", followed by "Imagination" and "Directing attention to bodily processes" (categories D, H and I). In the theta condition, the most frequent strategies were "Concentrated punctual focus" (category G) and "Direction attention to bodily processes" (category H), consistent with the instructed meditation type (Focused attention with the example of focusing on bodily sensations). None of the strategies showed a clear peak in accuracy.

These phenomenological results confirm that participants mostly used strategies that are consistent with the instructed type of meditation. Moreover, they provide tentative ideas about what kind of strategies might have been effective in the alpha and beta conditions. Thereby, the results demonstrate how variability in phenomenological fingerprints could be used in future studies with larger samples to establish neuroexperiential relationships for the investigated brain markers.

4 Discussion

4.1 Summary of findings

The present study set out to refine and extend previous neurophenomenological work investigating real-time correspondences between meditative experience and neural activity using source-localized EEG neurofeedback. Here we used a novel paradigm that repeatedly probes participants' perceived correspondence between their inner experience while meditating and monitoring the neurofeedback signal. Across two studies, this was tested for four neural markers that were associated with specific meditation states in previous research (gamma power in PCC and effortless awareness; high beta power in PCC and self-boundary dissolution; occipital alpha and relaxation; midfrontal theta and focused attention). In addition to probing these neuro-experiential relationships and characterizing the phenomenology of the actual meditative experience, we tested if meditators could regulate the feedback signal in the presumed direction of the respective meditation state. Our results in study 1 show that the expected correspondence between PCC gamma power feedback and states of effortless awareness could be established, replicating previous results (van Lutterveld et al., 2017). Furthermore, we extend this finding from the visual to an auditory feedback modality, but also raise concerns about the neural specificity and artifact confounding of this result. Our results establish that experienced meditators can detect a feedback feature that tracks their meditative experience and gamma power changed during neurofeedback-assisted meditation. However, they do not establish, and raise considerable doubt, that this feature reflects PCCspecific neural activity. Exploratory Study 2 examined neuro-experiential correspondence and regulation for three additional markers based on beta, theta and alpha power. Group-level correspondence analyses were inconclusive, while regulation analyses suggested differences in alpha and beta power between baseline and feedback-supported meditation.

4.2 Neuro-experiential correspondence

In Study 1, participants reliably identified the correspondence between their meditation experience and the direction of PCC gamma feedback signal with above-chance accuracy (mean accuracy = 72.5% across modalities) when feedback direction was randomized and double-blinded. This constitutes the first conceptual replication of van Lutterveld et al. (2017). Moreover, while van Lutterveld et al. used only visual feedback, we showed that this correspondence also generalizes to auditory feedback, demonstrating that neurofeedback of meditation states can be successfully implemented with eyes closed. This is relevant for future neurophenomenological studies investigating meditation based neurofeedback, since many meditation practices are typically performed with eyes closed.

Study 2 explored whether the approach could be extended to meditation-frequency mappings involving theta, alpha and high beta. Given that Study 2 included only four participants, its group-level analyses should be considered exploratory, with individual-session results potentially providing more informative insights into participant-specific responses. The grouplevel correspondence analyses were inconclusive, limiting conclusions about the suitability of these markers for real-time feedback. However, two individuals displayed highly consistent accuracy in the beta and alpha conditions (with alpha effects in the opposite direction to our hypothesis), suggesting that individual-level correspondences may exist even when the group-level effects are inconclusive. Together, these observations point to potential neuroexperiential correspondences at the individual level, which future studies with larger samples should examine systematically.

One possibility for future investigation is that the selected regions or frequency ranges were not sufficiently well matched to the targeted meditative states. Specifically, for beta power, they were obtained from MEG source imaging (Trautwein et al., 2024) and for theta and alpha from reviews that integrate and interpret EEG sensor level results (Lomas et al., 2015; Tang et al., 2019 and Brandmeyer and Delorme, 2020). Future studies could evaluate other neural regions and frequencies, or use aperiodic, nonlinear or connectivity based neural features (Atad et al., 2025; Yordanova et al., 2021; Shrimali et al., 2025). Moreover, the absence of an effect in frequency bands other than gamma might also be due to the lower frequency bands being not or much less contaminated by muscular activity than the gamma band (Whitham et al., 2008), although high beta is partly affected as well. Thus, the signal strength (or signal to noise ratio) of the actual neural band-power effects might be too low, such that they cannot be meaningfully captured in real-time, but only show up in traditional offline analyses (Lomas et al., 2015; Lee et al., 2018). Future work could use advanced preprocessing methods or other neuroimaging modalities to increase signal-to-noise ratio. Moreover, multivariate decoding techniques have shown promissing results in single-trial prediction of meditative states (Röhr et al., 2026; Reggente et al., 2025) and might be a promising direction for enhancing the sensitivity of neurofeedback approaches.

4.3 Regulation of the neural markers

Regulation results were more mixed than the correspondence results. In Study 1, sourceestimated gamma power in the PCC was lower during neurofeedback-assisted meditation than during the effortless-awareness baseline in the auditory condition and across modalities, but not significantly in the visual condition. No regulation slope differed from zero, so we found no evidence of progressive learning within the regulation runs, and the ability to identify the correspondence did not predict regulation success. Moreover, the gamma reduction was spatially widespread rather than specific to the PCC (Section 4.5). These effects should therefore be read as widespread changes in source-estimated gamma power during neurofeedback-assisted meditation, not as evidence that feedback supported participants to specifically modulate PCC activity. In Study 2, exploratory regulation analyses further showed increases in occipital alpha and decreases in PCC beta, indicating that neurofeedbacksupported modulation was possible for some of the targeted markers even when subjective moment-to-moment correspondence was unclear. Future studies could build on these results and investigate potential state effects or treatment benefits of these neural modulation effects.

4.4 Phenomenology of effective gestures

For PCC gamma feedback investigated in study 1, phenomenological interviews showed that the correspondence with the feedback signal was detected by the participants using meditation gestures of releasing effort and control, opening or expanding awareness, and adopting a stance of non-involved, non-judgemental perception. These descriptions closely align with the phenomenology of effortless awareness reported in earlier work (e.g., Garrison, Santoyo et al., 2013) and add nuances based on the fine-grained resolution and prereflective focus of the employed microphenomenological methodology (Petitmengin, 2006). Specifically, our results characterize the interrelated mental and embodied aspects of "effortlessness" and show how such cessation of perceived effort relates to changes in perception and cognition.

In study 2, the phenomenological data indicate that participants largely employed strategies consistent with the instructed meditation type.

4.5 Mechanistic specificity and muscular confounds

While replicating previous work (van Lutterveld et al., 2017), our analyses also raise substantial challenges to the interpretation that PCC gamma activity truly underlies these effects. Whole-brain source analysis showed widespread gamma-power reductions during regulation, with the largest standardized reduction in right inferior frontal cortex and significant reductions in both PCC hemispheres. Thus, the estimated effect was not specific to the PCC. Moreover, correlations between PCC gamma power and raw sensor gamma band activity peaked at lateral fronto-temporal scalp locations, regions that are highly susceptible to EMG contamination from the temporalis and frontalis muscles (Whitham et al., 2007; Whitham et al., 2008; Yilmaz et al., 2014). If the signal indeed originated from the PCC, we would have expected it to show the strongest correlations with the central sensors closest to the PCC (and accordingly, the highest beamformer sensor weights in this area). Furthermore, the correlation patterns and beamformer weights of several participants were very similar to those from a participant excluded from the analysis who intentionally manipulated facial muscles to influence the signal. These findings make it likely that the replicated gamma effect reflects, at least in part, reductions in facial or scalp muscle activity that co-occur with the experiential quality of "letting go," a core gesture in effortless awareness meditation. As such, the correspondence between the feedback and phenomenology is genuine, but the assumed neural mechanism may not be.

It is therefore important to separate what the present data establish from what they do not. They establish (i) that experienced meditators can reliably identify, under randomized and blinded conditions, the direction in which the feedback signal co-varies with their meditative experience, for both visual and auditory feedback; (ii) that source-estimated gamma power, including in the PCC, was lower during neurofeedback-assisted meditation than during the meditation baseline; and (iii) that the correspondence was accompanied by consistent reports of releasing effort and control. They do not establish (iv) that these effects reflect activity of the PCC, since the gamma reduction was spatially widespread and smaller in the PCC than in most other regions, or (v) that the feedback signal reflects neural rather than muscular activity, since its time course was most strongly coupled to lateral fronto-temporal sensors and its spatial signature resembled that of a participant who deliberately used facial muscles. The correspondence we replicate is thus a correspondence between experience and a processed EEG signal whose neural source remains open.

Although we replicated the findings by van Lutterveld et al. (2017) showing a correspondence between effortless awareness meditation and gamma activity attributed to the posterior cingulate cortex, the absence of analogous effects in other frequency bands and indications that muscle activity likely contributed to the gamma signal call the original interpretation into question. It should be noted that the experimental paradigm was identical across all frequency bands, and the successful operation of the gamma neurofeedback suggests that the absence of effects in the other conditions is unlikely to be attributable to methodological or technical shortcomings of the setup. Thus, it seems likely that the observed correspondence in the gamma condition was at least partially driven by systematic changes in facial or scalp muscle tension accompanying states of "letting go". This perspective reframes the apparent specificity of the gamma finding and highlights the need for neural markers that are both physiologically robust and resistant to muscular interference. These results might also call into question other findings which have found gamma activity as a neural marker of meditation states (e.g., Lutz et al., 2004; Lehmann et al., 2001). From another more theoretical perspective it is interesting to note, if the effects are indeed muscular, that they were still perceived as corresponding with participants' subjective conscious state. From the perspective of embodied and enactive cognition (cf. Varela et al., 1991; Thompson & Varela, 2001; Gallagher, 2023) this might highlight the embodied nature of meditative states, such that neural and bodily changes interact and thereby give rise to the conscious experience of meditation.

4.6 Limitations and future directions

Several limitations qualify the results. First, sample sizes were small, especially in Study 2, which included four participants.For Study 1, the repeated-probe design provided adequate power to detect a correspondence effect of the size reported by van Lutterveld et al. (2017); Study 2 should be considered exploratory, and its inconclusive group-level results cannot be taken as evidence of absence. Further limitations are related to the real-time data processing pipeline, especially the absence of elaborate data cleaning procedures. Also, the covariance estimate of the LCMV beamformer was continuously updated over short time windows, which might have reduced spatial accuracy. Another limitation is due to the inhomogeneous practice background of our participants, whose meditation experience varied between 740 and 35,046 lifetime hours and who practiced in different meditation traditions and styles. This might have contributed to the heterogeneous results in terms of accuracy and employed meditative gestures in study 2. Nonetheless, results from study 1 show that participants were clearly able to track and influence aspects of their experience in real-time in ways that align with the feedback signal.

Future research will benefit from using neural markers and imaging modalities which are not (or less) contaminated by muscular artefacts (e.g., lower frequency bands such as theta and alpha), more advanced real-time artefact rejection (as reviewed in Dhole et al., 2025), and neural markers with a higher signal to noise ratio (e.g., lower frequency bands which have a higher signal amplitude or connectivity/coherence measures in which shared noise between sources is canceled out), as well as concurrent EMG/EOG recordings. They could also evaluate other neural regions and frequencies, or use aperiodic, nonlinear or connectivity based neural features (Atad et al., 2025; Yordanova et al., 2021; Shrimali et al., 2025). Moreover, multivariate decoding techniques have shown promissing results in single-trial prediction of meditative states (Röhr et al., 2026; Reggente et al., 2025) and might be a promising direction for enhancing the sensitivity of neurofeedback approaches.

4.7 Conclusion

Taken together, our results replicate previous findings (van Lutterveld et al., 2017) about the relationship between PCC gamma power and effortless awareness while cautioning against the neural specificity and validity of this finding. Moreover, our studies provide refinements of the neurophenomenological neurofeedback approach, demonstrating the usefulness of an auditory feedback modality and the increase of power based on a randomized and blinded probing procedure. We hope that these developments pave the way for future successful, reliable and valid descriptions of neuro-experiential correspondences. While methodologically challenging, such research bears the potential of illuminating the reciprocal interplay between conscious states and local neuronal activity, thereby narrowing the gap between subjective experience and physical processes in the brain.
