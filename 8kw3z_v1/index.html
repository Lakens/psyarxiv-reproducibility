How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Full text

Abstract

When people are expecting a stressful upcoming day, they tend to sleep poorly; sleeping poorly in turn has been linked to expecting a more stressful upcoming day. These mutual associations have led researchers to assume a mediating effect of evening stress anticipation on morning stress anticipation via nightly sleep. One important gap in these considerations is that people are likely able to predict how stressful the next day will be, as indicated by substantial associations of evening stress anticipation and next-day well-being irrespective of sleep. In the present study, we thus aim to disentangle time-ordered associations among evening stress anticipation, sleep, and morning stress anticipation in a 2-week ambulatory assessment study. A sample of 126 young adults (Mage = 21.5 years, SD = 2.7, 84.1% women) rated their stress anticipation for the upcoming day every evening and the next morning. Additionally, they reported their sleep quality and duration each morning and wore a smartwatch to track their sleep. Results from two-level structural equation models showed that evening stress anticipation predicted lower self-reported sleep quality, which predicted morning stress anticipation. The findings did not support a mediating process but rather an additive effect of sleep quality on morning stress anticipation beyond stability of evening stress anticipation. There were no significant association with smartwatch measured sleep. In conclusion, stress anticipation was rather stable overnight, but an additional effect of sleep quality suggests morning stress anticipation appraisals may be affected by reduced available resources following poor sleep.

Introduction

When people are stressed or worried in the evening, they tend to sleep worse the following night (e.g., Åkerstedt et al., 2012; Yap et al., 2020). Most research has focussed on people feeling stressed or worried in the moment. However, more recently, stress anticipation, that is, expectations of how stressful the next day is going to be, has come into focus and has been linked with worse sleep as well (Lee, 2024). Similarly, research has linked worse nightly sleep not only with increased stress or lower well-being the next day (Lücke et al., 2022; Yap et al., 2020), but also with higher stress anticipation for the upcoming day reported in the morning (Wang et al., 2021; Wen et al., 2024). Because of these mutual associations, researchers have hypothesized about mediating effects of evening stress anticipation on next-day well-being via worse sleep, arguing that anticipating a stressful day leads to worse sleep, which in turn decreases well-being the next day (Lee, 2024; Werner et al., 2025). Although a mediating effect was found in two studies, it was small compared to the direct effect of evening anticipations on next-day affect (Lee, 2024; Werner et al., 2025). One important gap in these considerations is that people are likely able to predict how stressful the next day will be, as indicated by substantial associations of evening stress anticipation and next-day wellbeing irrespective of sleep (Hyun et al., 2019). Accordingly, given people's knowledge about the upcoming day, evening and morning stress anticipations should show substantial overlap.

Building on previous findings and considerations, in this study we test time-ordered associations between evening stress anticipation, sleep, and morning stress anticipation to disentangle the links among these three variables. To this end, we use data from 126 younger adults who participated in a two-week ambulatory assessment protocol during which they rated their stress anticipation for the upcoming day each evening and morning, reported on their sleep quality and duration each morning, and wore a smart watch to monitor their sleep.

Reciprocal Associations Between Stress Anticipation and Sleep

Stress can be understood as resulting from interactions between an individual and their current environment through situation-specific appraisals (Lazarus & Folkman, 1984): Stress occurs when a situation is seen as important and potentially threatening and one's current resources as insufficient to successfully deal with this situation. While typically applied to ongoing stressors and stressful situations, the same logic can be applied to anticipated future situations. Stress anticipation is thereby defined as expecting to feel stressed in the future (Neupert et al., 2019), which also likely results from appraisals of the anticipated situations and expected resources to deal with those situations (Powell & Schlotz, 2012). Similar to ongoing stress, stress anticipation goes hand in hand with decreased affective well-being and increased physiological stress responses such as salivary cortisol (e.g., Smyth et al., 1998).

In addition to these more immediate stress responses, both current stress and stress anticipation in the evening have been linked to worse subsequent sleep. Only one study specifically focused on stress anticipation and found that expecting the next day to be more stressful predicted lower self-reported sleep quality, sleep sufficiency, and shorter time-in-bed, as well as lower actigraphic sleep efficiency and shorter actigraphic sleep duration (Lee, 2024). Other studies considered similar constructs and found that stress and worries at bedtime, either reported in the moment or retrospectively the next morning, also predicted lower self-reported sleep quality (Åkerstedt et al., 2012; Werner et al., 2025), lower actigraphic sleep efficiency, and shorter actigraphic sleep duration (Werner et al., 2025). While mechanisms linking stress anticipation with sleep have not been explicitly identified, research linking bedtime stress to subsequent sleep found that these associations were mediated by pre-sleep arousal (Tousignant et al., 2019; Winzeler et al., 2014). This seems like a relevant mechanism that may explain how stress anticipation may impact subsequent sleep as well.

In addition to these links between evening stress anticipation and nightly sleep, nightly sleep predicted stress anticipation in the morning. Lower self-reported sleep quality (Wang et al., 2021; Wen et al., 2024) and shorter self-reported sleep duration as well as shorter actigraphic sleep duration (Wen et al., 2024) predicted higher stress anticipation for the upcoming day. With insufficient (i.e., short or low quality) sleep, people may have fewer resources to deal with the day's demands which could explain why their appraisals lead to them anticipating it to be more stressful.

The time-lagged association between stress anticipation and subsequent sleep, and between sleep and next morning stress anticipation, respectively, might indicate reciprocal, mutually reinforcing associations. However, before drawing firm conclusions in this regard, it needs to be considered that people can probably correctly anticipate at least some of the upcoming day's events and challenges. For instance, stressful events such an exam or a particularly stressful day at work are often foreseeable in the evening already, which would lead to a strong association between stress anticipation in the evening and the next morning. This is supported by previous research showing moderate within-person correlations of evening stress anticipation with next-morning stress anticipation using a single-item measure (r = .36; Hyun et al., 2019).

The Current Study

The present study targets associations among evening stress anticipation, sleep, and morning stress anticipation, and aims to disentangle how these variables are linked across time in a 2-week ambulatory assessment study with a sample of 126 young adults. We expect that higher evening stress anticipation is linked to worse sleep the following day (Hypothesis 1). Additionally, we expect that worse sleep is linked to higher stress anticipation the next morning (Hypothesis 2). Given that the anticipated demands of the upcoming day do not change overnight, we further expect that higher stress anticipation in the evening is also linked to higher stress anticipation the following morning (Hypothesis 3). Considering the multivariate interplay among all three constructs, there are two constellations that seem plausible: Based on the idea that sleep mediates the effect of evening stress anticipation on next day's affect (Lee, 2024; Werner et al., 2025), sleep might act as the mediator of the association between evening and morning anticipation. Alternatively, the association between sleep and morning anticipation might be spurious and induced by evening anticipation: higher stress anticipation in the evening reduces nightly sleep quality and predicts stress anticipation in the next morning, but after controlling for evening anticipation, there is no unique association between sleep and morning anticipation. This latter pattern is in line with the findings that the mediating effect of evening anticipation via sleep duration on affect the next-day was no longer significant when controlling for actual occurrence of next-day stressors (Lee, 2024).

Previous work has linked insufficient sleep with lower affective well-being, stronger perceived stress, and worse emotion regulation (Lücke et al., 2022; Mauss et al., 2013; Yap et al., 2020), often theoretically explained by reduced available resources to deal with daily demands, which suggests that at least part of the association between evening stress anticipation and morning stress anticipation may be mediated through sleep. We thus preregistered the hypothesis that sleep would partially mediate the lagged association of evening stress anticipation and morning stress anticipation (Hypothesis 4). For Hypotheses 1, 2, and 4 we expect these predictions to hold for (a) self-reported sleep quality, (b) self-reported sleep duration, (c) smartwatch sleep quality, and (d) smartwatch sleep duration.

Methods

Participants

Participants in this study were 126 younger adults with an average age of 21.5 years (SD = 2.7); one person did not report their age. Most of the participants were women (84.1%, n = 106), born in Germany (88.9%) and reported German as their first language (91.2%). All participants were university students recruited via the SONA platform at RWTH Aachen University.

Procedure

The study was approved by the Ethics Committee of the Department for Empirical Human Sciences at RWTH Aachen University (approval #2025_01_FB7_RWTH AACHEN) and conducted from April to December 2025. Participants started the study with an in-person onboarding session during which they gave informed consent, completed a baseline questionnaire on the online platform SoSci Survey (Leiner, 2024), and enrolled for the study in the Avicenna Research app (Avicenna Research, 2026). They received an example questionnaire to familiarize themselves with the app. Furthermore, they received a Garmin vívoactive® 5 smartwatch to wear on their non-dominant wrist throughout the study. Starting in the afternoon on the day of the onboarding session (Day 1), participants received push notifications prompting them to complete short questionnaires. Each of the following days, they were asked to fill out six short questionnaires. There were three different kinds of questionnaires in this study (morning, daytime, evening) which partly included different questions.

The morning questionnaire contained the relevant questions regarding the previous night's sleep and expectations for the upcoming day; the evening questionnaire containing the relevant questions regarding expectations for the next day. All questionnaires included further questions, for example participant's current affect and the occurrence of stressors. The morning questionnaire was prompted every hour starting at 6.00h until 9.00h; it was available until 10.00h and participants were instructed to answer it as soon as possible after waking up. The evening questionnaire was available in the app from 20:30h and first prompted at 21:00h and then again at 22:00h and 23:00h if it had not been filled out yet. It was available until 4:00h. Participants were instructed to complete it shortly before going to sleep. Each of the questionnaires could only be filled out once. The study ended with the morning questionnaire on Day 15.

Participants received reimbursement in the form of partial course credit or retail vouchers according to their adherence to the protocol. For participating in the baseline questionnaire and at least 30% / 60% / 85% of the momentary questionnaires they received either 1.5 / 4 / 5.5 hours partial course credit or a 20 € / 80€ / 100€ voucher, respectively. On average, participants completed 84.2% of the morning questionnaires and 93.7% of the evening questionnaires. Smartwatch data was available for 120 participants (95.2%) on 79.6% of all nights.

Materials

Stress Anticipation

Participants rated their stress anticipation on a four-item version of the Anticipatory Stress Questionnaire (Kramer et al., 2019; Powell & Schlotz, 2012) twice per day. They rated the extent to which they expected the day to be stressful, they would be in control of the day's events, their ability to cope with the day's challenges, and their worries about the day on a scale from0 = not at all to10 = very much with the items either referring to "tomorrow" (evening) or to "today" (morning). Items assessing expected control and ability to cope were reverse-coded before calculating evening and morning stress anticipation as the mean across the four items, respectively. Higher values indicate higher anticipated stress. Internal consistency (multilevel omega, Lai, 2021) for evening and morning stress anticipation was 0.72 and 0.74 respectively at the within-person level and 0.83 for both at the between-person level.

Sleep

Self-Reported Sleep. Each morning, participants rated their overall sleep quality on a scale from0 = very bad to10 = very good and reported how restorative their sleep was, how unsettled it was, and whether they experienced problems falling asleep and staying asleep on a scale from0 = not at all to10 = very much (PROMIS Health Organization, 2012). The items regarding unsettled sleep and problems falling and staying asleep were reverse-coded before calculating daily sleep quality as the mean of the five sleep quality items, with higher values indicating better quality sleep. Internal consistency was 0.81 at the within-person and 0.75 at the between-person level. Each morning participants additionally reported how long they slept during the past night in hours and minutes; this sleep duration was converted to decimal hours for the analyses (e.g., 7:15 became 7.25).

Smartwatch-Based Sleep.

Participants wore a Garmin fitness watch (vívoactive® 5) for the duration of the study. Sleep quality was derived from the Garmin sleep score. This score incorporates sleep duration, sleep architecture (i.e., the percentage of time spent in deep, light and REM sleep), and restlessness. In lieu of EEG measures to identify sleep stages, Garmin uses movement and heart rate data for sleep staging via a proprietary algorithm (Garmin, 2026). The sleep score ranges from 0 -100 with higher values indicating better sleep. We recoded it to range from 0 -10 by dividing it by 10 to match the scale of the other variables. Sleep duration is calculated by Garmin as the time between sleep onset and sleep offset that was not classified as wake (converted to decimal hours).

Covariates

Two important further factors that may impact both stress anticipation and sleep are selfrated health and the day of the week. When people are in poorer health, they may perceive having fewer resources and thus expect the next day to be more stressful than they otherwise would. At the same time, worse health may also imply increased sleep disturbance. Similarly, when the following day is a weekend-day, people may anticipate less stress but are also more likely to get longer and potentially better sleep. Thus, we will account for effects of evening self-rated health as well as whether the upcoming day is on a weekend vs. during the week. In this study, participants rated their overall health that day on a scale from0 = very bad to10 = very good. Based on the ESM date and time logs, we determined whether a given day was a weekday or on the weekend. For the analyses we created a binary variable with weekdays coded as 0 and weekend days coded as 1.

Data Analytic Strategy

To test the hypotheses, we used two-level Bayesian multilevel models in Mplus. We specified separate two-level models for each hypothesis and each of the sleep parameters (self-reported sleep quality, self-reported sleep duration, smart watch sleep quality, smart watch sleep duration). The models included random intercepts for all sleep and anticipation variables, which results in latent person-mean centered variables on Level 1, allowing us to cleanly analyze within-person associations. The main associations between anticipation and sleep were all implemented as random slopes on Level 1, allowing participants to differ in these associations.

In the H1 models, evening stress anticipation predicted sleep; in the H2 models, sleep predicted morning stress anticipation; in the H3 models, evening stress anticipation predicted morning stress anticipation. In the H4 models, we included all three of these associations in the same model and calculated an additional parameter representing the indirect effect of evening anticipation on morning anticipation via sleep (see Figure 1 for a visualization). In all models, selfrated health and weekday (vs. weekend) were included as additional predictors of evening anticipation, sleep, and morning anticipation on Level 1 and all random intercepts and slopes were allowed to covary on Level 2. We used Mplus standard uninformative priors and ran each model for at least 5,000 iterations with a thinning factor of 5. Convergence was determined using the potential scale reduction factor (PSR < 1.01) and parameter trace plots. All estimates where the 99% Bayesian Credible Interval (CI) did not include 0 were considered statistically significant.

To determine whether the interplay between evening stress anticipation, sleep, and morning stress anticipation is adequately described by a mediation process, we jointly consider results of the H1-H3 and H4 models. Each of the H4 sub-hypotheses is supported when we find a significant indirect effect of evening anticipation on morning anticipation via nightly sleep In contrast, the data would speak to a confounding effect of evening anticipation if we observe significant effects in line with H1-H3 but the effect of nightly sleep on morning anticipation is non-significant when controlling for evening anticipation in this model. When the indirect effect is significant and the effect of nightly sleep on morning anticipation gets smaller in this model, we cannot cleanly differentiate between partial mediation vs. partial confounding (MacKinnon et al., 2000).

Results

We report descriptive statistics for the study variables in Table 1. In line with H3, evening stress anticipation predicted morning stress anticipation, b = -0.610, 99% CI [0.537, 0.677]. However, in contrast to H4, there was no statistically significant indirect effect of evening stress anticipation on morning stress anticipation via any of the sleep parameters.

Whereas the direct effect of self-reported sleep quality on morning stress anticipation remained unchanged in the mediation model testing H4, the effect of shorter self-reported sleep duration on morning stress anticipation was not statistically significant (in contrast to the H2 model).

Exploratory Analyses

To further situate these results within the context of previous findings we conducted nonpreregistered exploratory analyses. Previous research has focussed on the mediating role of sleep in linking evening stress anticipation and next-day well-being but did not consider morning stress anticipation. Accordingly, we ran additional analyses predicting the day's average positive and negative affect (assessed at all six daily beeps) from morning stress anticipation, evening stress anticipation, and prior sleep. Morning stress anticipation significantly predicted daily positive and negative affect across all models. Evening anticipation additionally predicted negative affect (albeit to a much smaller degree) but not positive affect. Better self-reported sleep quality (but none of the other sleep parameters) predicted higher positive and lower negative affect. When comparing model fit via the deviance information criterion, including any predictors beyond morning stress anticipation did not improve the model. (See Supplement S2 and S3 for more details on the assessment and model results.)

To approximate the role of a day's actual stressfulness, we used the number of stressors that were reported across five daily beeps and controlled for its effects on evening and morning stress anticipation (H4 models) as well as on positive and negative affect (exploratory models). Results showed that the number of stressors was associated with both evening and morning stress anticipation (Table S2), however, it was not linked with morning stress anticipation above and beyond evening stress anticipation; the stability of stress anticipation across the night was unaffected (Table S4a). Regarding well-being, the associations of morning stress anticipation and selfreported sleep quality with well-being remained unchanged when controlling for stressors, whereas the effect of evening stress anticipation on negative affect was no longer significant (Table S4b).

Discussion

We tested time-ordered associations between evening stress anticipation, different sleep parameters, and morning stress anticipation. Results showed that evening stress anticipation predicted worse self-reported sleep quality but none of the other sleep parameters. Worse selfreported sleep quality and shorter self-reported sleep duration predicted stronger morning stress anticipation. There were no indirect effects of evening stress anticipation on morning stress anticipation via any of the sleep parameters. After controlling for evening anticipation, the effect of self-reported sleep duration on morning stress anticipation was no longer statistically significant.

Associations with sleep self-reports vs. smartwatch measures

We only observed associations between stress anticipation and self-reported sleep, not with the smartwatch-assessed sleep parameters. This contrasts with other research which observed associations with objectively measured sleep parameters as well (Lee, 2024; Wen et al., 2024; Werner et al., 2025). One important difference is that previous research relied on actigraphy whereas we used a consumer-grade smart watch without clear validation. Additionally, the smartwatch sleep quality score does not cleanly map onto typically used actigraphy parameters.

Thus, the lack of associations with smartwatch sleep measures in this study might result from limited validity of the measurement. However, in line with the current findings, previous research has found that self-reported sleep quality (vs. actigraphy) is most closely linked with different psychological outcomes (e.g., affect; Konjarski et al., 2018).

Morning and evening stress anticipation

Stress anticipation was relatively stable overnight, with evening anticipation consistently predicting morning anticipation across model configurations, aligning with previous research (Huyn et al, 2019). This finding supports the notion that both evening and morning stress anticipation rely (at least partly) on shared knowledge of the upcoming day. Both evening and morning stress anticipation showed corresponding links with the day's actual stressfulness (the number of stressors that occurred). The number of stressors did not predict morning stress anticipation above evening anticipation. Thus, evening and morning anticipation seem to tap into the same construct, and people similarly able to predict upcoming stressors in the evening and in the morning.

Associations between Stress Anticipation and Sleep

Stronger evening stress anticipation was linked with reporting lower sleep quality the next morning, similar to previous findings (Lee, 2024). Effects of experienced stress on subsequent sleep seem to be driven by pre-sleep arousal, with cognitive arousal (e.g., ruminating, pondering events of the day) identified as a more important predictor of sleep quality than somatic arousal (e.g., a jittery, nervous feeling in one's body, perspiration; Tousignant et al., 2019; Winzeler et al., 2014). Pre-sleep arousal also could be a plausible mechanism accounting for the effects of evening stress anticipation on sleep that remains to be tested in future research.

For the opposite direction, both lower self-reported sleep quality and shorter self-reported sleep duration higher morning stress anticipation, aligning with previous empirical research (Wen et al., 2024). Interestingly, the standardized effect of sleep quality on morning stress anticipation (b = -0.185, 95% CI [-0.237, -0.132]) was numerically stronger than the effect of evening stress anticipation on nightly sleep quality (b = -0.104, 95% CI [-0.158, -0.046]). In this regard, the associations mirror those found for self-rated momentary stress in previous research (Lücke et al., in preparation).

Accordingly, sleep may be more important for subsequent stress processes than vice versa.

One main aim of the current study was to determine whether the interplay between evening stress anticipation, sleep, and morning stress anticipation is adequately described by a mediation process -this was not the case: None of the included sleep measures mediated associations between evening and morning stress anticipation. However, the results did not support the competing explanation of evening anticipation confounding the effect of sleep (quality) on morning stress anticipation either. While somewhat numerically reduced, the effect of self-rated sleep quality on morning stress anticipation was consistently significant across model configurations. This pattern of findings thus suggests additive effects as a third possibility regarding the multivariate associations among evening stress anticipation, sleep, and morning stress anticipation. In addition to the stability in stress anticipation overnight, self-rated sleep quality seems to explain some further variance in morning stress anticipation in line with theoretical predictions that insufficient sleep reduces available resources and thereby increases stress anticipation. Alternatively, this result might also reflect sleep related negative bias (Wen et al., 2024). Because we do not know how people arrived at their stress anticipation ratings and which information they considered, both these options remain speculations to be substantiated by future research.

Affective Well-Being as Outcome

In addition to the pre-registered hypothesis tests, we conducted further analyses considering affective well-being as an outcome. Results revealed morning stress anticipation as the most important predictor of daytime affect which one may interpret as a correct anticipation of the day's demands. However, this effect was only minimally reduced when controlling for the day's stressfulness by including the daily number of stressors. Nonetheless, it seems unlikely that there is a causal effect of morning stress anticipation on affective well-being throughout the day. First, the reported number of stressors throughout the day is only a rough proxy for the day's stressfulness.

Perceived demands (Powell & Schlotz, 2012), which may exceed available resources and can therefore lead to anticipatory stress, cannot only result from concrete events people experience (e.g., an exam) but could also, for example, stem from high workload or preparation for a stressful event sometime in the future. A shared predictor, such as reduced available resources, could be another possible explanation which would also explain the small additional effect of sleep quality which, although statistically significant, did not improve model fit.

Strengths and Limitations

The main strength of the current study extending previous work is that we included both evening and morning stress anticipation, showing that these cognitive appraisals are relatively stable overnight. Although we consider it as a further strength that we used both self-report and more objective measures of sleep, the smartwatch sleep measures come with limitations, namely unknown reliability and validity, which may explain why we only observed associations of selfreported sleep (quality) with stress anticipation. Furthermore, this association may have been overestimated due to common method bias (both being assessed by self-report) and/or sleep and morning stress anticipation being assessed in close temporal proximity during the same momentary assessment. Further limitations relate to the current sample which consisted of young, well-educated adults who reported relatively low levels of stress anticipation overall. This limits generalizability to other age groups or more vulnerable populations, who may experience differing daily demands and changes to their sleep and whose sleep-stress dynamics might therefore also differ.

Conclusion

Evening and morning stress anticipation showed substantial overlap. While stronger stress anticipation in the evening impacted subsequent sleep quality, this association did not play a role in conferring effects of stress anticipation to the next day. Sleep quality, as consciously experienced and reported, was a predictor for both stress anticipation and well-being, supporting theoretical considerations that insufficient sleep reduces available resources to deal with daily demands.
