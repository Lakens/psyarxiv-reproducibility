To check Non-Significant P Value Check

What we found

We found 34 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

Power analyses need to contain the following information to be interpretable: the type of power analysis, the statistical test, the software used, sample size, critical alpha criterion, power level, effect size, and an effect size metric. An a priori power analysis for an independent samples t-test, conducted using the pwr.t.test function from pwr (Champely, 2020), indicated that for a Cohen’s d = 0.5, an alpha level of 0.05, and a desired power level of 80% required at least 64 participants in each group.

This module uses regular expressions to identify sentences that contain a statistical power analysis. The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Introduction

It is estimated that between 11% and 13% of children and adolescents live with a mental disorder (Kieling et al., 2024; Polanczyk et al., 2015) and these disorders contribute substantially to the global burden of disease among young people (Kessler et al., 2005). Early access to mental health services may reduce the risk of persistent or recurrent psychopathology across development (Copeland et al., 2021; Neufeld et al., 2017). However, youth mental health systems continue to face major challenges in meeting increasing service demands. Long waiting times, fragmented care pathways, and limited access to evidence-based interventions leave many children and adolescents without appropriate treatment (Brown et al., 2002; Chavira et al., 2004; Kowalewski et al., 2011; Meng & Wiznitzer, 2024; Roennfeldt et al., 2024; Singer et al., 2022). These pressures have intensified in the context of global crises, including the COVID-19 pandemic (Racine et al., 2021) and climate change (Lawrance et al., 2022), contributing to growing calls for evidence-based practices that are scalable, expand timely access to care, and eliminate disparities in healthcare worldwide (Benton et al., 2021; McGorry et al., 2025).

Stepped-Care Psychological Interventions

Stepped care aims to allocate treatment intensity according to clinical need while minimizing unnecessary use of high-intensity interventions (Bower & Gilbody, 2005). In psychological care, stepped-care approaches typically (1) include different established and evidence-based treatments, referred to as steps, varying in their intensity (e.g., treatment continuum starting with low-intensity, low-barrier, and cost-effective treatments transitioning to more intensive and often more costly treatments) and (2) define specific criteria for when individuals transition between the different steps (e.g., non-response within a specific time frame and/or individual preference) (Bower & Gilbody, 2005). When applied to individuals at elevated risk or with subthreshold symptoms, these approaches are often described as preventive stepped care, whereas models targeting diagnosed mental disorders are typically referred to as stepped-care treatments. Notably, school-based service models such as multi-tiered systems of support (MTSS, e.g., Arora et al., 2019; Lee & Gage, 2020; Sugai & Horner, 2009) follow principles closely aligned with stepped care by matching support intensity to student needs across tiers. However, these frameworks typically use different terminology and are often implemented at the school level rather than through predefined individual transition criteria.

Two broad stepped-care approaches are commonly distinguished. In progressive stepped care, all patients start with the lowest step and transition to more intense steps, if needed. In stratified stepped-care models, patients are assigned to an intervention to which they are individually more likely to respond, with the possibility of increasing treatment intensity when responding insufficiently with lower-level care (Arns et al., 2022; Asarnow et al., 2025). Proceeding from this rationale, general models of care can also be offered in a stepped format. For example, collaborative, or shared care can also be stepped (Härter et al., 2018) to aid in a smooth transition across the continuum of interventions. Across both approaches, stepped-care models are intended to improve efficiency, accessibility, and coordination of mental healthcare services by reserving more resource-intensive interventions for children and youths requiring additional support.

Although stepped-care models have been investigated across a wide range of mental health conditions, including personality disorders (Grenyer & Bailey, 2024), depression (Jagayat et al., 2024), anxiety (Wuthrich et al., 2021), PTSD (Roberts & Nixon, 2023), substance abuse (Morse et al., 2023), eating disorders (Le Grange et al., 2021), insomnia (Schlarb et al., 2025), and have also been combined with transdiagnostic treatments targeting shared psychological processes (Kennedy et al., 2021), their implementation in routine practice remains challenging (Hermens et al., 2014; Marchionatti et al., 2024; Richards et al., 2012). In particular, uncertainty persists regarding which interventions should be included as treatment steps, how transitions between steps should be determined, and to what extent current stepped-care implementations reflect the principle of beginning with low-intensity and scalable interventions (e.g., Berger et al., 2022; Hermens et al., 2014). These challenges may be especially relevant in child and adolescent mental health systems, where developmental considerations, caregiver involvement, school contexts, and concerns regarding risk management may complicate treatment allocation and monitoring. In sum, evidence from adult stepped-care systems may not generalize directly to children and adolescents due to differences in development and contexts of implementation.

Previous reviews have identified substantial variation in the structure and intensity of interventions included within stepped-care models, ranging from watchful waiting and self-help interventions to individual psychotherapy and intensive care services. The steps can be ordered based on various criteria. For example, steps can be ordered depending on the professionals involved (Gjerdingen et al., 2008; Ollendick et al., 2018), the treatment intensity, for example the number of sessions (Rivero-Santana et al., 2021; Wilson et al., 2000), or the treatment costs and resources needed for implementation (Ho et al., 2016). Most models include between two and four treatment steps (Gjerdingen et al., 2008; Ho et al., 2016; Mareya et al., 2024; Meuldijk & Wuthrich, 2019; Roberts & Nixon, 2023; van Straten et al., 2015). It has been argued that the number of steps is closely related to the available resources (Bower & Gilbody, 2005) and that the entire spectrum of available steps should be implemented (Berger et al., 2022).

Transition decisions are commonly based on disorder-specific symptom measures or responder criteria tailored to specific populations and conditions (Borsari et al., 2012; Pettit et al., 2017). For example, specific responder criteria have been proposed for the first step in treating trauma in children and adolescents (Salloum et al., 2015) or stepped-care services for anxious youth (Kendall et al., 2016; Silverman et al., 2016). More recently, shared decision-making approaches have emphasized incorporating patient preferences and individualized treatment goals into stepping decisions (e.g., Cornish, 2023).

Study Overview

In light of the growing interest in stepped care as a scalable model for child and adolescent mental health services, this meta-analysis provides timely evidence to guide researchers, practitioners, and policymakers. Existing reviews have primarily focused on clinical effectiveness within specific disorders or adult populations, with less attention to implementation characteristics, transition procedures, and scalability in child and adolescent mental health systems. Methods

The current meta-analysis follows the PRISMA guidelines for systematic reviews (Page et al., 2021) and was preregistered through PROSPERO (ID will be added here). The coding sheet and corresponding R scripts of all analyses are available via the Open Science Framework (URL will be added here).

Eligibility Criteria

Studies were included in the current meta-analysis when they fulfilled all the following three criteria: 1.

In the study, a stepped-care psychological intervention was implemented. The stepped-care intervention (1) explicitly included at least two predefined intervention components (i.e., steps), (2) varied in intensity and patient burden according to the patient needs, and (3) implemented predefined and explicit criteria to transition between steps (e.g., non-response after eight weeks).

2. The participants were children and adolescents ranging from 0-21 years of age.

3. The study reported (a) a percentage regarding dropout, response, remission, or number of participants transitioning to the next step and/or (b) a standardized effect size with the corresponding number of participants or descriptive data (e.g., means, standard deviations, and number of participants). The effect size can relate either to pre-post within-group effects or post-post comparisons across two different groups (e.g., stepped care CBT vs. CBT).

We included studies independent of the control condition (e.g., no control, passive control, active control), the reported outcome (e.g., response, remission, quality of life, costs), and the characteristics of the stepped-care intervention (e.g., number of steps, stepping up or down criteria, and progressive or stratified stepped care).

Literature Search

Relevant studies were identified through two distinct search procedures, a standardized search and an exploratory hand search. For the standardized search, we searched titles and abstracts (PsycInfo, Medline) or titles, abstracts, and keywords (CENTRAL) for papers published from the database inception to October 2026, limited to "Human," "English language" (all three databases). We used the same standardized search string that included commonly used keywords regarding the stepped-care intervention (first bracket) and the age group (second bracket) for each database: (stepped care or sequential treatment* or adjunctive treatment* or tier* treatment* or adaptive treatment* or staged treatment* or sequential intervention* or adjunctive intervention* or tier* intervention* or adaptive intervention* or staged intervention* or sequential psycho* or adjunctive psycho* or tier* psycho* or adaptive psycho* or staged psycho*) and (adolescent* or teen* or young people or youth* or child*)

For the exploratory search, we screened the references of the included studies of all published meta-analyses on steppedcare psychological interventions (Firth et al., 2015; Ho et al., 2016; Rivero-Santana et al., 2021; van Straten et al., 2015) and reviews on stepped-care interventions in children and adolescents (Berger et al., 2022; Kendall et al., 2016; Ollendick et al., 2018). In addition, we manually searched other databases, such as Google Scholar and ResearchGate.

The systematic search provided 2,358 references without duplicates. The exploratory search identified 25 additional references. The entire search procedure is portrayed as a flowchart in Figure 1.

Coding Procedure

Coding occurred in a two-step procedure. In the first step, all 2,358 abstracts were screened for inclusion. The inclusion criteria were liberally applied to minimize the chance of falsely excluding relevant articles based on the title and abstract. Two trained and independent raters screened half of the titles and abstracts for inclusion. Their inter-rater agreement for the inclusion of studies based on titles and abstracts was high with 98%; Cohen's κ = .825. Coder A then rated the remaining half of the identified hits. If either of the two coders included the reference based on the title and abstract screening, the full text was assessed for eligibility. A total of 113 full texts (88 from the standardized search, 25 from the exploratory search) were obtained for further investigation.

In the second step, the full texts of all relevant abstracts were screened for inclusion and exclusion and coded. The same two raters independently screened all full texts for inclusion in the meta-analysis. The inter-rater agreement for the inclusion of the full texts was 89%, Cohen's κ = .805. Again, disagreements were resolved through discussion. Excluded articles are listed in Table S1.

We identified 50 studies that met the inclusion criteria of the current meta-analysis. For all eligible full texts, the effect sizes and study characteristics were coded independently by the two coders. A full description of the coded variables and corresponding inter-rater agreement (% and Cohen's κ) is presented in Table S2 in the Supplemental Material. The coding was documented in a standardized predefined coding sheet incorporating previously proposed reporting standards for stepped-care interventions (van Straten et al., 2015). We classified the implemented intervention according to the Stepped Care 2.0 framework (Cornish, 2020), which provides a comprehensive continuum for intervention steps within stepped models. Cost outcomes were restricted to intervention costs, when studies reported total health care or societal costs, which include costs not directly attributable to the intervention, only the intervention cost component was coded.

Quality-adjusted life years reported in economic evaluations were not coded, as they combine utility scores with time. For sequential multiple assignment randomized trials (SMARTs), all embedded intervention sequences consisted of predefined steps with explicit transition criteria. Effects were coded as reported, typically pooled across second-stage options within first-stage conditions; as SMARTs compared different stepped-care sequences rather than stepped care versus a control condition, they contributed pre-post and proportional data but no controlled effects. Whether the design was a SMART was examined as a moderator. The mean inter-rater agreement across all variables was 89%; for categorical variables the mean Cohen's κ was .787. Whenever relevant data regarding the effect size were missing from the original article, we contacted the authors requesting the missing data. In total, we contacted seven authors, four of whom responded to our request.

Data Preparation

We performed two types of meta-analyses: (1) a meta-analysis for standardized mean differences of within effects (i.e., pre-post effects) or group differences (i.e., post-post or pre-post gain group differences), and (2) a meta-analysis for proportional data (i.e., proportion that transitioned, dropout, response, and remission). Transition was defined as the proportion of participants who moved from one step to the next according to the study-specific transition criteria (e.g., clinical non-response or patient/family request). The data preparation was twofold. For within and between effects, we computed the effect size as Cohen's d from the coded descriptive data using syntax. For 55 effect sizes, descriptive data were not available. Instead, we converted the reported chi 2 (k = 18) or odds ratio from the contingency table (k = 29) using syntax. In two cases, we had to apply continuity correction at the 2 × 2 contingency table, since two cells were 0 (Salloum et al., 2016; Wainer et al., 2021). For the remaining eight effect sizes, the standardized mean difference was directly reported as Cohen's d. For proportional data, we calculated the proportions from the frequencies reported in the single studies. We used a logit transformation for the reported proportional data (Barker et al., 2021). Furthermore, in some cases, the post-test only included data for the step one non-responders; data for the step one responders were missing (Herpertz-Dahlmann et al., 2021). In these cases, we only coded the available proportions because of the incomplete sample at posttest.

In meta-analyses, it is generally possible to correct the results for measurement error (Schmidt & Hunter, 2015).

However, because the reliability of measurements was reported for only 41 of 195 (21%) of the included effect sizes, we did not correct for measurement error in our meta-analysis and performed a bare-bones meta-analysis.

Statistical Analyses

Most of the included studies reported more than one relevant effect size. Effect sizes from the same study are statistically dependent and cannot be handled using conventional meta-analytic techniques (Hedges et al., 2010). To account for the dependency among the effect sizes, we employed robust variance estimation (RVE; Hedges et al., 2010; Tanner-Smith et al., 2016; Tanner-Smith & Tipton, 2014). Given the expected heterogeneity, we used random-effects models for all analyses (Cooper et al., 2019). Mean effect sizes and meta-regression models employing RVE were estimated using a weighted least squares approach (Hedges et al., 2010; Tanner-Smith & Tipton, 2014). Effects were considered significant when the 95% CI excluded zero. Estimates with fewer than four adjusted degrees of freedom were considered unreliable and are reported descriptively only (Tipton, 2015). Further, we performed omnibus tests for categorical moderators (Tipton & Pustejovsky, 2015). We used the robumeta package (Fisher & Tipton, 2015) in the R statistical environment (R Core Team, 2024) for the statistical analyses. To assess potential publication bias (Rothstein et al., 2005), we examined the symmetry of effect sizes around the mean using visual inspection of funnel plots. Publication bias was further statistically evaluated using PET-PEESE analyses (Stanley & Doucouliagos, 2014). PET-PEESE (a) is considered particularly appropriate in the presence of between-study heterogeneity, which is common in psychotherapy research, (b) has been recommended as a robust alternative to traditional publication bias methods, and (c) is suitable for analyses using RVE.

Results

Included Studies

A total of 50 studies met the inclusion criteria for this analysis (for an overview, see Table S3 in the Supplemental Material). The 50 studies included data from 39 independent samples comprising 4,007 participants. The samples' mean ages ranged from 3.15 years to 17.40 years and included participants between 1 and 21 years. The most reported effect sizes related to PTSS/PTSD (26%), followed by anxiety disorders (23%), and obsessive-compulsive disorder (11%). Furthermore, many effect sizes were from studies conducted in the United States (43%), followed by Australia (16%) and Sweden (11%).

Of all reported effect sizes, 108 related to proportions from 36 independent samples reported in 39 studies (i.e., proportions on transition, response, remission, dropout), 195 to uncontrolled effects from 25 independent samples reported in 31 studies (i.e., pre-post effects, various outcomes), and 167 to controlled effects from 15 independent samples reported in 18 studies (i.e., group differences from controlled trials or randomized controlled trials, various outcomes). For the controlled trials, most reported effects compared stepped-care interventions to active controls. In 12 of 15 independent samples (80%), the control condition consisted of the full-dose version of the most intensive step of the respective steppedcare intervention, delivered to all participants from the outset. Two samples compared stepped care with usual care, and one with a passive control. The reported proportions ranged from .063 to .990, the pre-post effect from d = -1.15 to d = 4.80, and the controlled effects from d = -1.50 to d = 2.58.

Overall Effects of Stepped-Care Psychological Interventions (RQ1)

The overall pre-post effect for uncontrolled studies, summarizing 195 effect sizes from 25 unique samples, demonstrates a significant positive effect of stepped-care interventions with 𝑑 ̅ = 1.25, 95% CI [0.982; 1.51]. We found no evidence of moderation for sample characteristics such as age or gender. Furthermore, stepped-care interventions significantly reduced symptoms (𝑑 ̅ = 1.41, 95% CI [1.11; 1.71]) and significantly enhanced functioning (𝑑 ̅ = 0.814, 95% CI [0.439; 1.19]). Effects on parent/family outcomes were available for only three samples and, as such, not summarized.

Effects were significant at both post-test (𝑑 ̅ = 1.22, 95% CI [0.952; 1.50]) and follow-up (𝑑 ̅ = 1.02, 95% CI [0.551; 1.48]), with no significant difference between assessment points (p = .272). Regarding assessment source, pre-post effects were significant for self-reports (𝑑 ̅ = 0.840, 95% CI [0.585; 1.10]), parent reports (𝑑 ̅ = 1.02, 95% CI [0.846; 1.20]), clinician ratings (𝑑 ̅ = 1.56, 95% CI [1.07; 2.04]), and mixed sources (𝑑 ̅ = 2.05, 95% CI [1.36; 2.74]), while the assessment source significantly moderated the effect (p = .025). Teacher reports were available for only one sample. Overall, the results demonstrate significant pre-post effects of stepped-care interventions; apart from assessment source, there was no evidence of moderation by sample, outcome, or methodological characteristics (see Table 1, left columns for detailed results).

The overall effect of stepped care when compared to a control group (i.e., post-post group differences or group differences in pre-post gains) summarizing 167 effect sizes from 15 unique samples indicates no significant difference across groups, with 𝑑 ̅ = 0.039, 95% CI [-0.162; 0.240]. The estimate was similar when restricted to randomized controlled trials (𝑑 ̅ = -0.019, 95% CI [-0.224; 0.186]) while only two samples came from non-randomized controlled trials. Effects did not differ by effect size type (post-post: 𝑑 ̅ = 0.089, 95% CI [-0.129; 0.307]; pre-post gain: 𝑑 ̅ = 0.021, 95% CI [-0.114; 0.157]; p = .856). As almost all samples used active controls, the type of control condition could not be tested. The same applied to blinding. Regarding outcomes, none of the clinical outcome categories showed a significant difference between stepped care and control conditions: symptoms (𝑑 ̅ = 0.038, 95% CI [-0.094; 0.171]), remission (𝑑 ̅ = -0.271, 95% CI [-0.628; 0.086]), functioning (𝑑 ̅ = -0.020, 95% CI [-0.143; 0.104]), dropout (𝑑 ̅ = -0.165, 95% CI [-0.669; 0.338]), and treatment satisfaction (𝑑 ̅ = -0.116, 95% CI [-0.447; 0.216]). Intervention costs were significantly lower for stepped care (𝑑 ̅ = 1.23, 95% CI [0.213; 2.24]); given the small number of samples, this estimate should be considered preliminary. Two studies additionally reported total health care and societal costs, which include costs beyond intervention delivery (e.g., other health services, productivity losses). Descriptively, total costs were lower in the stepped-care groups in both studies; the difference was significant in Aspvall, Sampaio, et al. (2021) but not in Chatterton et al. (2019). Estimates for response, parent/family, and other outcomes were based on too few samples (df < 4) and are reported descriptively in Table 1. Group differences were larger at post-test (𝑑 ̅ = 0.096, 95% CI [-0.087; 0.279]) than at follow-up (𝑑 ̅ = -0.272, 95% CI [-0.702; 0.158]; p = .048), although neither estimate differed significantly from zero. Effects did not vary by assessment source (p = .734). Because few controlled samples were available per diagnostic group, moderation by mental disorder could not be tested. Moderation by age and gender could only be estimated with fewer than four degrees of freedom and was therefore not interpreted. Overall, stepped care did not differ significantly from control conditions in clinical outcomes, whereas intervention costs were lower, summarizing the few studies reporting cost data (see Table 1, right columns for detailed results).

Variations in the Effectiveness of Stepped-Care Psychological Interventions (RQ2)

Next, we investigated whether variations in the stepped-care intervention significantly contributed to differences in its effectiveness (see Table 2 for an overview). For both the pre-post effects of stepped-care interventions and the between-group effects in controlled trials, we did not identify any significant moderator relating to the intervention characteristics. The effectiveness did not vary by intervention aim (pre-post: p = .706; controlled: p = .365), the number of steps (pre-post: p = .092), overall duration of treatment (pre-post: p = .826, controlled: p = .365), the target population addressed (pre-post: p = .493; controlled: p = .398), the professionals involved (pre-post: p = .582), whether psychopharmacotherapy was included or not (pre-post: p = .980), the timing of the first decision point (pre-post: p = .202), or shared decision-making (pre-post: p = .063). Because of the small number of studies, we could not statistically test differences based on the professionals involved and the number of steps for controlled effects.

Implemented Steps in Stepped-Care Interventions (RQ3)

The included studies reported a variety of different steps (see Table S4 in the Supplemental Material for an overview). When summarizing the first implemented steps in a category, most effect sizes related to treatment effects that began with guided self-help (48%), flexible individual programming (31%), or interactive self-directed (14%). Hence, most studies started in the middle of the Stepped Care 2.0 continuum of treatment intensity (Cornish, 2020), involving some kind of contact with a professional; only a few started with low-intensity interventions, such as self-directed self-help. The initial step was delivered in specialist mental health outpatient services in 31 of 39 independent samples (79%). Three samples initiated stepped care in medical settings, such as emergency departments or trauma centers (Cunningham et al., 2021; Kassam-Adams et al., 2011; Zatzick et al., 2014), two in schools (Ellis et al., 2013; Malik et al., 2022), two in community services (Malik et al., 2023; Shyam et al., 2024), and one in inpatient care (Herpertz-Dahlmann et al., 2021). Perhaps surprisingly, in almost all studies, the stepped-care intervention started at the lowest step (i.e., a progressive approach, 92%); only one study used a stratified stepped-care approach (Olsson et al., 2025; Saha et al., 2026). Notably, one study implemented a reversed progressive approach, starting with a higher step (e.g., inpatient treatment) and progressing to stepping down (e.g., home treatment) (Herpertz-Dahlmann et al., 2021).

Transition Criteria for Stepping Up (RQ4)

Regarding the transition criteria, most of the studies implemented the Clinical Global Impression Scale (Busner & Targum, 2007) or disorder-specific measures (e.g., symptom-specific rating scales) to assess responses within a specific timeframe to determine the need to transition to the next step (see Table S4 in the Supplemental Material for details). Of the effect sizes reported, only a fifth related to a shared decision approach (19%), where the patient or family, sometimes with the clinician, could decide whether to step up. The timing of the first decision point varied between 14 and 196 days, with a median of 42 days.

Exploratory Analyses

We conducted several exploratory analyses regarding the reported proportional data (see Table S5 in the Supplemental Material). The results may serve as preliminary benchmark data when planning and implementing future The overall rate of transition from the first to the next step was .499, 95% CI [.413; .585] (see Table S5); the transition after step two was .603, 95% CI [.343; .816]. The transition rate after step one did not differ significantly from that after step two (F(1, 6.65) = 0.738, p = .420). Moreover, transition rates after the initial step did not vary significantly due to the patients' age (p = .122), timing of transitioning (p = .937), or treatment implemented in the initial step (p = .878; for details, see Table S6 in the Supplemental Material). More than half of the patients did not transition after step one, independent of the treatment received. However, the data are limited since not the whole bandwidth of possible steps has been investigated in the included studies; for some steps, only a few studies reported proportions, limiting the interpretability of the results.

Publication Bias

The funnel plot for the uncontrolled and controlled effects is shown in Figure 2. Regarding uncontrolled effects, visual inspection showed slight asymmetry in the effect sizes around the mean. Furthermore, PET-PEESE analyses indicated only weak evidence of small-study effects; the PET slope was not statistically significant (p = .084). Because the PET intercept was significantly different from zero (p = .041), we report the PEESE estimate as the bias-adjusted effect, which remained significant (d = 1.05, 95% CI [0.66; 1.43], p < .001). For the controlled effects, visual inspection also demonstrated slight asymmetry in the effect sizes around the mean. Further, the PET slope indicated weak, non-significant evidence of small-study effects (p = .071). Because the PET intercept was not significantly different from zero (p = .095), PEESE was not applied.

Discussion

This meta-analysis integrated available evidence on stepped-care psychological interventions for children and adolescents, with the aims of assessing overall effectiveness, exploring potential moderators of treatment effects, informing clinical implementation, and identifying priorities for future research. The findings yielded three key insights. First, stepped care did not differ significantly from control conditions in clinical outcomes, although controls mostly received the fulldose version of the most intensive step. Preliminary evidence further suggests lower intervention costs. Second, approximately half of the patients did not transition beyond the initial step, which was of lower intensity relative to subsequent steps. Third, stepped-care models varied substantially in their aims, implemented steps, and transition criteria, whereas genuinely low-intensity initial steps, multi-informant transition criteria, and settings with broader reach were rarely implemented.

Overall Effectiveness of Stepped-Care Interventions

The present findings indicate that stepped-care interventions did not differ significantly in clinical outcomes from control conditions, which in most studies consisted of the full-dose version of the most intensive stepped-care step delivered to all participants from the outset, while being associated with lower intervention costs in the small number of studies reporting cost data. We found significant pre-post effects of stepped-care interventions for outcomes regarding symptoms and functioning. Furthermore, the pre-post effects persisted up to the follow-up assessments. Descriptively, positive effects were found across various mental disorders. The positive pre-post effects (𝑑 ̅ = 1.25) are comparable in direction and magnitude to previous meta-analytic findings on the effects of stepped care in adult patients (Wakefield et al., 2021). In controlled comparisons, stepped care did not differ significantly from control conditions in clinical outcomes (𝑑 ̅ = 0.04), in which participants received the full-dose version of the most intensive step in most studies. Separately, intervention costs were lower for stepped care (𝑑 ̅ = 1.23), although this estimate is based on only five samples. For clinical outcomes, similar results were found in previous meta-analyses with adult patients for outcomes of depression (Ho et al., 2016) or PTSD (Roberts & Nixon, 2023). However, some previous meta-analyses found superior effects of stepped-care interventions when compared to care as usual (Ho et al., 2016; Rivero-Santana et al., 2021; van Straten et al., 2015). The current meta-analysis included a younger age group and a broader range of mental disorders and outcomes, which might serve as a potential explanation. Furthermore, the control conditions in the current meta-analysis included full-dose treatments in relation to the stepped-care intervention in most cases. The effects of stepped-care interventions might be even higher in magnitude when compared to care involving waiting-list controls.

Response After Initial Step and Corresponding Transition

Approximately half of the patients who completed the first step did not transition to a subsequent step. As transition criteria were mostly based on clinical response, this suggests that the initial step was sufficient for a substantial proportion of patients. However, non-transition may also reflect natural recovery or treatment dropout, and should therefore not be equated with treatment success. Moreover, it is important to note that the initial steps were of lower intensity only relative to subsequent steps. Treatment intensity can be reduced along several dimensions, including the type and format of treatment (e.g., self-help or digital instead of face-to-face therapy), the dose (e.g., number and length of sessions), and the degree and qualification of professional involvement (e.g., guided self-help or lay counsellors instead of therapist-led treatment). In most included studies, the initial step was reduced on only one or two of these dimensions and frequently consisted of structured, professionally delivered treatment (e.g., individual CBT with fewer sessions or internet-delivered CBT with therapist guidance), which may itself be considered moderate-to high-intensity care. Accordingly, our findings indicate that a less intensive start than the full-dose treatment did not compromise outcomes, but they do not speak to the effectiveness of genuinely low-intensity first steps, such as self-directed interventions or single-session interventions, which were rarely implemented. The finding highlights the potential of stepped-care models to reduce unnecessary exposure to more intensive and costly treatments while preserving opportunities for escalation when clinically indicated.

However, evidence regarding optimal criteria for selecting initial treatment intensity and determining transitions between steps remains limited. Most studies based transition decisions primarily on disorder-specific, mostly clinician-rated symptom measures, whereas functioning and patient preferences were rarely considered, and only a minority of studies used shared decision-making. Our findings suggest that two distinct decisions should be distinguished. First, the decision whether a transition is clinically indicated should be based on standardized outcome monitoring (McAleavey et al., 2024).

Notably, pre-post effects were substantially larger for clinician ratings and mixed sources than for youth self-reports, consistent with well-documented informant discrepancies in youth psychopathology (Achenbach et al., 1987; De Los Reyes et al., 2015). Young people may thus be classified as responders despite persisting self-reported distress, and transition criteria should integrate multiple informants, including youth self-report. Second, the decision to which step a patient should transition may benefit from shared decision-making with young people and their families, as proposed in stratified stepped-care models. Accommodating patient preferences has been associated with lower dropout and better outcomes in psychotherapy (e.g., Swift & Callahan, 2009; von Wirth et al., 2025; Wasmann et al., 2019). As the moderation by assessment source was observed only in uncontrolled pre-post comparisons, these implications should be tested in future research.

Stepped Care to Enhance Scalable and Accessible Mental Health Interventions

A central finding of this review was the substantial heterogeneity in how stepped-care interventions were implemented across studies. Although stepped-care models are typically conceptualized as beginning with low-intensity, scalable interventions that are intensified only when needed, many included studies implemented relatively intensive initial treatment steps. This pattern suggests a potential implementation paradox in child and adolescent mental health care: stepped care aims for scalability and efficiency, yet its implementation frequently relies on resource-intensive intervention pathways. Notably, genuinely low-intensity interventions have been found to be effective in prior research. For example, single-session interventions (SSI), defined as interventions that intentionally involve only one visit or encounter with a clinic or healthcare provider (Schleider et al., 2020), have demonstrated good effectiveness for a variety of patients of various age groups and mental disorders (Schleider et al., 2025). However, none of the studies included in the current metaanalysis used an SSI as an initial step, despite recent work highlighting their potential as a useful addition to stepped-care models (Bivins et al., 2025; Rizvi & Kleiman, 2023) and single studies implementing them successfully as part of an adaptive intervention (Walton et al., 2025). Extending the steps by scalable, stigma-free, and low-barrier interventions, such as self-directed SSIs, can be a valuable extension of stepped-care approaches. Several factors may contribute to the limited use of low-intensity interventions. Clinicians and services may have concerns regarding risk management, symptom complexity, family involvement, and the developmental appropriateness of minimally guided interventions for younger populations and may be unfamiliar with the approach itself (e.g., Berger et al., 2022; Franx et al., 2012). In addition, strained patient relationships, reimbursement structures, limited availability of resources and validated low-intensity interventions, and implementation barriers in school or community settings may constrain adoption (e.g., Brantnell et al., 2026; Heath et al., 2026; Maehder et al., 2020). Consequently, some interventions labeled as stepped care may more closely resemble treatment sequencing or resource triage models than fully progressive stepped-care systems. Furthermore, developmental considerations may distinguish stepped-care implementation in children and youth and adult mental health systems. Treatment transitions in children and youth services often involve caregivers, schools, and multidisciplinary providers, while symptom presentation and treatment needs may vary considerably across developmental stages. These factors may complicate decisions regarding treatment intensity and modality, monitoring, and transition. Moreover, only one of the included studies has used a stratified stepped-care approach to decide on the initial step and subsequent transition (Olsson et al., 2025). Previous reviews discuss such clinical practice as an effective approach for adult patients (Cornish, 2023; van Straten et al., 2015). However, empirical evidence is scarce, especially for children and youth. Initial findings indicate that stratified stepped care may yield better outcomes than care as usual in youth and young adults (Asarnow et al., 2025), and a pilot trial suggested advantages over progressive stepped care (Olsson et al., 2025).

Nonetheless, further research is needed to directly compare different stepped-care models and establish their relative effectiveness.

Generalizability and Future Directions

As with other meta-analyses, this review is not without limitations. First, almost all control conditions included patients receiving the full-dose version of the most intensive step of the stepped-care group, usually treatments currently delivered in contemporary health systems, as a comparator to the stepped-care group. However, it is unclear whether stepped-care models have further benefits, such as reducing treatment barriers, waiting times and buffering the associated increase in symptoms. Comparing stepped-care interventions with care as usual when entering the health system involving long waiting times might provide further insights into the potential benefits of stepped-care treatments.

Second, the number of studies in some of the moderator categories was rather low (i.e., fewer than five). While the meta-analytic results are not fully reliable in these cases, they indicate relevant gaps in the research that can be investigated in future studies. For example, we were unable to determine possible moderating effects due to intervention characteristics, such as the number of steps or using a shared decision-making approach. Further, not much is known about the mechanisms specific to stepped care, such as the possible synergistic effects of the different steps, as proposed and identified in previous research (Cornish & Berry, 2025; Tobias et al., 2022). Future research can enhance the understanding of the effects of stepped-care interventions in pediatric psychotherapy by systematically examining variations in effectiveness associated with implementation strategies that have thus far received limited investigation.

Third, most effect sizes were derived from studies conducted with WEIRD (Western, Educated, Industrialized, Rich, Democratic) samples within mental health care systems. Only a few studies have included non-WEIRD samples, for example from Brazil (Fatori et al., 2018) or India (Malik et al., 2022).

Fourth, most stepped-care interventions were initiated in specialist mental health outpatient settings, whereas relatively few began in schools, community services, or general medical settings such as emergency departments, although these settings may be particularly suited for low-threshold initial steps. A recent review showed that low-intensity interventions delivered in school settings are effective (Cohen et al., 2024), suggesting that schools may be a promising setting for the initial step of stepped-care models. However, our search was based on clinical stepped-care terminology. School-based tiered support models, such as multi-tiered systems of support (MTSS), use different terminology and may therefore be underrepresented in the current review. Moreover, these models are rarely labeled as stepped care, research has largely examined school-wide implementation or individual tiers in isolation (e.g., Cho Blair et al., 2021; Lee & Gage, 2020), and transitions are often based on triage processes rather than a predefined sequence of steps increasing in intensity.
