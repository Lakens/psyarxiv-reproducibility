This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). Introduction

The emerging abilities of infants and children shape how they interact with others and the world around them. Two key developmental abilities are motor and language skills. While the development of these two abilities has often been assessed separately, there is reason to believe that they do not develop in isolation but might be related, such that motor abilities support the development of language abilities (Gonzalez et al., 2019; Iverson, 2021). Examining how these abilities interact could lead to novel insights into factors such as the source of developmental boosts and individual differences in development.

The interaction between motor and language skills could happen through two major routeswhich we will refer to as the physical and developmental cascades routes in the following. The physical route could promote language development because speech requires coordinated, controlled and timed movement of the articulatory organs. Oral-motor skills are related to fine-motor skills, which are the skills to control and coordinate small muscles in movement, such as those in the hands and fingers (Newmeyer, et al., 2007). Oral-motor skills such as those used in language production are related to speeded tasks that require precision grip (Brookman et al., 2013) -perhaps because the oral skills required for speech are also speeded, coordinated and precise. The physical route could also affect language development by shaping neural pathways associated with motor skills. For instancehttps://www.zotero.org/google-docs/?broken=szFLul infants with speech/language delays seem to also display more deficits in both fine and gross motor skills (https://www.zotero.org/google-docs/?broken=szFLul Gaines & Missiuna, 2007) , and these two deficits might have the same neural underpinning (Redle et al., 2015). Gross motor skills (using large muscles in the torso, legs, and arms for whole-body movements like sitting and walking) are also related to speech production. For example, upright position (sitting or standing) makes it easier for infants to produce sounds by enabling infants to breathe more deeply, maintain subglottal pressure, and affect the curve of the vocal cords (Yingling, 1981).

Motor skills might also contribute to language development via another route, the developmental cascades route. According to this theory, motor skills enable an infant a more proactive relationship with their environment (Iverson, 2010 (Iverson, , 2021)). Interactions with parents are then changed by the new way the infant interacts with their environment, creating a cascade of developmental processes. Indeed, parents have been found to talk more, and differently, to walking than to crawling infants aged 9 to 15 months (Karasik et al., 2011; Schneider & Iverson, 2022). Walle (2016) showed that walking experience is associated with more infant initiation of joint engagement, as well as gaze following -that is, walking is associated with more proactive relationships with the environment, which in turn can lead to more occasions for caregivers to (verbally) respond to infants of 10-to 13 months. He et al. (2015) found that walking American and Chinese 12-to 14-month-old infants had larger vocabularies than crawling infants of the same age. In this context, responsive parenting, parental behaviors that are contingent on the child's behavior and appropriate to their needs, has been shown to contribute to both language (Tamis-LeMonda et al., 2001) and motor development Wang et al., 2022).

Unlike for gross motor skills, the link between fine motor skills and caregiver interactions is less intuitive. One suggestion is that advanced fine motor skills might enable the child to manipulate toys for a longer time period giving parents more to talk about during play time, as parents' utterances were found to contain a significantly greater proportion of labels relative to moments when infants (aged 10 to 14 months) were not holding objects (West & Iverson, 2017). This suggestion, however, highlights the challenge of discriminating between the effect of fine and gross-motor skills on language development at this age: Infant sitting frees up their hands to manipulate objects and gesture, and so, it is a combination of both fine and gross motor skills that would be related to language development. Gestures themselves are an invaluable part of the development of language and communication (e.g., Longobardi et al., 2014), and have been shown to not only predate but also predict changes in language, suggesting that early gesture may be paving the way for future developments in language (Iverson & Goldin-Meadow, 2005).

Research on non-typically developing children has found significant relations between motor and language skills. For example, infants with cerebral palsy and preterm infants with motor development delays, tend to also show language delays (Ross et al., 2018). Research also shows both language and motor delays in autistic children (Iverson et al., 2019; West et al., 2019). While this could be informative for typical development as well, there are some differences between these populations.

For example, Parents of autistic 18-month-old infants respond differently to their infant's movement bids compared to parents of typically developing children (Calabretta et al., 2022).

In typically developing children, motor and language abilities are also correlated in early development. For example, Salavati et al. (2017) examined smooth, fluent movements in 22 three-and five-month-olds and found that these movements were positively associated with language skills at four and ten years. Likewise, Andalò et al. (2022) followed 36 infants longitudinally and found that both fine-and gross-motor skills at 18 months predicted language abilities in the late second and third year of life. However, research about the relation between motor and language skills in typically developing children is somewhat limited. One review found only 17 studies investigating typically developing children in infancy and the early years -up to six years of age (Leonard & Hill, 2014). A more recent review from 2019, focusing on children up to 5 years of age, found 23 such studies (Gonzalez et al., 2019). Both reviews conclude that motor and language skills are positively correlated. Howeverhttps://www.zotero.org/google-docs/?5x8taq excluding one large longitudinal cohort dataset (Wang et al.https://www.zotero.org/google-docs/?XAUpy7 2014) , all longitudinal studies were based on small observational or lab samples (https://www.zotero.org/google-docs/?XAUpy7 Clearfield, 2011; Oudgenoeg-Paz et al., 2012) , and crosssectional studies, while having a larger sample size, tend to rely exclusively on parental reports (Bar-Or & Havron, 2024) https://www.zotero.org/google-docs/?OBdAWg (Longobardi et al., 2014).

Additionally, because most studies are cross-sectional, a concurrent relationship between motor and language skills may reflect other factors that positively affect both. For examplehttps://www.zotero.org/google-docs/?W7nxuI infants' executive function skills might also be linked to both motor (Maurer & Roebers, 2019) and language development (Viterbori et al., 2012) , and it has been found that they tap into joint resources, such that there exists an interference effect between motor and cognitive activities at 12 months of age (Boudreau & Bushnell, 2000). If such a third factor is at play, then the observed relation found between motor and language skills might be an artifact of other confounding factors rather than evidence for a true contribution of motor development to language development.

The current study

The state of the literature leaves several unanswered questions. The major question is how robust and generalizable the relation between motor and language skills is, given the limitations of samples and methods previously used. The second question is whether fine or gross motor skills, or both, relate to language acquisition. The third is whether this relation exists only concurrently, or whether infants who develop motor skills early keep their language-skills advantage during childhood.

First, for the question of robustness, there are not enough large, longitudinal studies to be able to assess such robustness. Moreover, as far as we could tell, almost all studies were performed on WEIRD (Western, Educated, Industrialized, Rich, Democratic) samples. One study was performed in China (He et al.https://www.zotero.org/google-docs/?45xOoD 2015) and one in East Asia and the Pacific (Zhang et al., 2018) , focusing on older children. Interestingly, Zhang et al. (2018) found some differences in the contribution of motor skills to language and literacy between different countries in Asia and the Pacific, stressing the importance of understanding cultural diversity and the generalizability of these effects.

As for the second question, previous research has found that both gross and fine motor skills are related to language outcomes, but the majority of studies have only tested gross motor skills (Gonzalez et al., 2019). A stronger relation between language development and one of these sets of skills might help us distinguish between the physical and developmental cascades routes. Gross motor skills seem more relevant to the developmental cascades route, where one main factor helping the child become a more proactive partner in interaction is increased locomotion abilities (West & Iverson, 2021). In addition, the developmental cascades route would predict stronger effects of motor on language development after the onset of walking, around age one, while the physical route seems to be more relevant to earlier motor development and language production. We analyze data from the "Growing Up in Singapore Toward Healthy Outcomes" (GUSTO), a population-based birth cohort study from Singapore (Soh et al., 2014). The GUSTO cohort is particularly valuable due to its large size, longitudinal design, collection of demographic, perinatal, and parental factors, and ethnically diverse population. This cohort includes more than 1,000 children and has data on motor development at 9, 18, and 24 months, and on language development at 9, 18, and 24 months and at 4 to 4.5 years of age. We addressed three research questions. First, are motor and language skills concurrently associated in a large, non-WEIRD population cohort? We hypothesized that fine and gross motor skills would each be associated with language at 9, 18, and 24 months.

Second, do motor skills predict later language over and above earlier language skills? We hypothesized that motor skills would predict language from 9 to 18 months, 18 to 24 months, and 24 months to 4-4.5 years. Third, do fine and gross motor skills differ in their relation to language? We expected both to be related to language, but made no prediction about their relative strength. The children were born between November 30, 2009 and May 1, 2011, and data collection is still ongoing. Participants all had a homogeneous parental ethnic background, following the CMIO model (Chinese-Malay-Indian-Others) commonly used in Singapore. At study onset, 56.1% of participants were Chinese, 25.4% Malay, and 18.5% Indian.

Materials

Control Variables. We selected control variables based on prior literature emphasizing the role of multiple confounding factors when examining associations between developmental domains. For instance, Peyre et al. (2019) investigated language, gross motor, and fine motor skills at 2, 3, and 5-6 years, while accounting for a range of environmental and psychosocial factors. Similarly, Ibanez et al. (2015) considered several dimensions of the early environment and parental characteristics. Control variables thus included: the target child's sex, birth weight (kg), gestational age (weeks), age at testing, language of test administration, number of older siblings, maternal alcohol consumption during pregnancy (grams/day), maternal smoking status at the 26th week of pregnancy, breastfeeding duration (6 categories: < 1 month, 1 month to < 3 months, 3 months to < 6 months, 6 months to < 12 months, 12 months to < 18 months, > = 18 months), maternal anxiety (STAI, 3 months postpartum) and depression (EPDS, 3 months postpartum), maternal education (six categories: no education, primary, secondary, ITE/NITEC, GCE (polytechnic/diploma), university (bachelor/masters/PhD), paternal education, maternal age at delivery (years), and paternal age at delivery. We also controlled for the language of the test administration for the KBIT-2 language assessment. Data were collected from obstetrical records (gestational age and birth weight) and from questionnaires administered to the parents (see Table 1 for descriptive statistics).

Motor Skills. Predictors included: children's gross motor and fine motor skills. These were assessed by administering the Ages and Stages Questionnaire, 3rd Edition (ASQ-3®, Squires et al., 2009) to parents at child's age of 9-, 18-and 24-months. The ASQ-3 assesses the child's development from 2-to-60 months of age and has good validity and reliability (Squires et al., 2009, see Table 1 for descriptive statistics). These subscales contain six questions for each motor area as each of the time points. For each item the parent marks whether the infant performs this activity ("yes", "inconsistently" or "not yet"). The gross motor scale contains such items as standing and bending (9 months), walking and climbing (18 months) and kicking and climbing stairs (24 months). The fine motor scale contains such items as picking various objects up (9 months), drawing and stacking (18 months) and using a spoon and flipping book pages (24 months).

Language Skills (Outcomes Measures).

Ages and Stages Questionnaire 3. Language and communication skills at 9, 18 and 24 months of age were assessed using the Communication subscale from the ASQ-3 (ASQ-3®, Squires et al., 2009) filled in by the parents. This subscale contains six questions for each timepoint. For each item, the parent marks whether the infant performs this activity ("yes", "inconsistently," or "not yet"). At 9 months, parents were asked about producing syllables, canonical babbling, sound imitation, playing nursery games, following simple commands, and first words. At 18 months, parents were asked about pointing, following simple instructions, first words, and two-word utterances. At 24 months, parents were asked about following complex instructions, naming, pronoun use, and production of multi-word utterances.

Bayley Scales of Infant and Toddler Development.

Language skills at 2 years of age were assessed using the Bayley Scales of Infant and Toddler Development (version III, BSID-III, Bayley, 2006), which were administered in participants' homes by trained examiners. BSID-III examiners attended 3 days of training with the clinicians from the Kandang Kerbau Women's and Children's Hospital. Afterward, they conducted supervised visits (not on the GUSTO sample) until the clinician deemed them competent (see Table 1 for descriptive statistics). For this study, we used the Language scale, which consists of two subscales: receptive communication and expressive communication. Both the ASQ-3 and the BSID-III were administered in the participant's dominant language.

Peabody Picture Vocabulary Test. At 48 months, language skills were assessed by administering the Peabody Picture Vocabulary Test (PPVT-4, Dunn & Dunn, 2007) to the children.

The PPVT tests receptive vocabulary by asking the child to point to one of four pictures that is named by the examiner. It consists of 228 items grouped into 19 sets of 12 items arranged in order of increasing difficulty. The test demonstrates strong psychometric properties (Dunn & Dunn, 2007). The PPVT-4 was administered to all children in English (see Table 1 for descriptive statistics).

Kaufman Brief Intelligence Test.

At 54 months, language skills were assessed by administering the Kaufman Brief Intelligence Test, second edition (KBIT-2, Kaufman & Kaufman, 2004) to the children in their dominant language (see Table 1 for descriptive statistics). The KBIT-2 is an individually administered assessment of intellectual ability normed for ages 4 to 90. Although this battery results in three scores: a verbal score, a non-verbal score, and an IQ composite, here, only the verbal score was used. The verbal scale is itself made up of two subtests, Verbal Knowledge and Riddles. Verbal Knowledge is receptive: the examiner says a word or asks about a general-information concept and the child points to the picture that best fits. In the Riddles subscale, the examiner gives several verbal clues about a concept, and the child identifies a word that fits all conditions. The KBIT-2 shows good reliability and validity (Singer, et al., 2012).

Statistical Analyses

All statistical analyses were conducted in R (R Core Team, 2020). Language and motor variables (ASQ Communication, BSID-III, PPVT, KBIT) were entered into the model as their original z-scores from the dataset, each standardized within wave on the full available sample for that instrument. The PPVT (administered at 48 months) and the KBIT-2 verbal subtest (administered at 54 months) were treated as two language measures available at 4 to 4.5 years, and (as at all ages with two available measures) were combined into a latent language factor (described below). Continuous covariates (gestational age, birth weight, parental ages, breastfeeding duration, maternal and paternal education, maternal anxiety and depression) and age-at-testing variables were standardized before entering the SEM to ensure numerical stability. All standardization was conducted on the full analytic sample prior to model fitting. We used no imputation; FIML handled all missing data directly.

Cross-lagged Panel Analysis

To examine the developmental relationship between motor and language skills, we implemented a cross-lagged panel model using the lavaan package (Rosseel, 2012) and plotted with DiagrammeR (Iannone & Roy, 2026). This approach allowed us to simultaneously model autoregressive paths (stability within domains over time), cross-domain effects (influences from one domain to another over time), and within-time covariances (concurrent relations between domains). The model included both fine and gross motor measures at 9, 18, and 24 months, and language measures at 9, 18, 24 months, and 4-to-4.5 years. Specifically, our model estimated: autoregressive paths for motor and language skills, cross-domain effects from motor to language skills, and within-time covariances between domains.

Fine and gross motor skills were allowed to covary within each wave but not across waves.

At time points where multiple language instruments were available, we specified latent language factors. At 24 months, a latent factor was defined by the ASQ Communication subscale and the BSID-III Language scale, with the ASQ loading fixed to 1 for identification, and the BSID-III loading freely estimated. At four to four and a half years, a latent factor was defined by the PPVT and the KBIT-2 verbal subtest, with the PPVT loading fixed to 1. This approach allows the data to determine the relative contribution of each instrument and partitions measurement error into indicatorspecific residual variances. At 9 and 18 months, only the ASQ Communication subscale was available, so the observed score was used directly. Residual covariances between examiner-administered instruments across waves (BSID-III at 24 months with PPVT and KBIT at four to four and a half years) were included.

Demographic and perinatal covariates were included as predictors of each observed variable and latent factor at every wave. The covariates were: sex, alcohol consumption during pregnancy, smoking during pregnancy, birth weight, gestational age, number of siblings, breastfeeding duration, maternal anxiety (STAI, 3 months postpartum), maternal depression (EPDS, 3 months postpartum), maternal and paternal age at delivery, and maternal and paternal education. Age at testing was included as a predictor of each variable at its corresponding wave, with separate age variables for the ASQ covariation (standardized cov = 0.350, p < .001). Language at 18 months was significantly associated with both fine motor skills (standardized cov = 0.302, p < .001) and gross motor skills (standardized cov = 0.139, p = .020).

At 24 months, significant covariances were observed between fine and gross motor skills (standardized cov = 0.344, p < .001), between language and fine motor skills (standardized cov = 0.308, p < .001), and between language and gross motor skills (standardized cov = 0.177, p = .042).

These standardized covariances reflect small to moderate concurrent relations between domains at each timepoint.

Sensitivity to Control for Confounding Factors

To examine the impact of our covariate adjustment, we also estimated the model without covariates or age-at-testing controls. The unadjusted model showed acceptable fit (χ²(38) = 72.463, p = .001, CFI = 0.964, RMSEA = 0.056, SRMR = 0.074). The significant cross-lagged path from the adjusted model remained significant without covariates: gross motor at 18 months predicted language at 24 months (β = 0.157, p = .007). The fine motor at 9 months path, which was marginal in the adjusted model, reached significance without covariates (β = 0.114, p = .046), suggesting that its attenuation in the adjusted model partly reflects shared variance with demographic and perinatal factors. However, the unadjusted model also showed an additional path that did not survive covariate adjustment: fine motor at 24 months showed a marginal association with language at four to four and a half years (β = 0.130, p = .051). The attenuation of this path after controlling for demographic, perinatal, and maternal variables suggests it partly reflects shared variance with confounding factors rather than a direct developmental effect.

Discussion

The current state of the literature on the relation between motor and language development leaves several unanswered questions. The main question is how robust and generalizable the effect of motor development on language outcomes is, given the methodological limitations of previous studies. The second question is whether it is fine or gross motor skills, or both, that are related to language acquisition. The third is whether this relation exists only concurrently or whether infants who develop motor skills early preserve their language-skills advantage during childhood.

Regarding the first question, our findings provide evidence for robust concurrent relations between motor and language skills, replicating previous findings (e.g., Andalò et al., 2022; Gonzalez et al., 2019; Wang et al., 2014) in a new cultural context with a large population cohort, while controlling for multiple potential confounding factors. Within-time covariances showed significant associations between motor and language skills at all time points for which we had data on both areas.

Regarding the second question of whether fine or gross motor skills are more strongly related to language development, our results suggest that fine motor skills may show more consistent relations with language outcomes concurrently, but we found no evidence that fine motor skills were more strongly related to language than gross motor skills were longitudinally. Specifically, our analysis found that fine motor skills at 9 months significantly predicted language skills at 18 months, while gross motor skills at 18 months predicted language skills at 24 months, however, the size of the effect of fine and gross motor skills on language at both these time points was not significantly different.

Concurrently, fine motor skills were more closely related to language than were gross motor skills at 18 months of age, but not at 9 months of age, and the results were marginal, though not significant, at 24 months of age. This pattern aligns with theoretical frameworks emphasizing the physical route between motor and language development (Brookman et al., 2013; Gaines & Missiuna, 2007), particularly given that the 18-month language assessment includes substantial motor components (production and gestural communication comprising two-thirds of the items). Fine motor control at 18 months may support the oral-motor coordination and general motor control systems that underlie both speech articulation and gestural communication abilities measured at 18 months, potentially through shared neural pathways (Redle et al., 2015). However, the equal weight of fine-and gross-motor skills at 9 months is surprising, since most items on the language assessment at 9 months focused on language production. Regarding the third question of whether relations are concurrent versus predictive, our findings suggest that motor-language associations are primarily concurrent rather than reflecting long-term developmental cascades. When controlling for potential confounding variables, only one out of six cross-domain longitudinal paths was significant -the effect of gross motor skills at 18 months on language at 24 months. Fine motor skills at 9 months had only a marginal, non-significant effect on language at 18 months. No significant cross-domain effects were observed at the later developmental period.

The finding that both significant and marginal cross-lagged paths occurred between early time points warrants consideration. These findings mirror Oudgenoeg-Paz et al. (2016), who found that age of walking did not directly predict language at age 43 months. One interpretation is that motorlanguage cascades are genuinely limited to the first two years, when motor and communicative development are most rapidly co-developing. During this period, motor advances open new opportunities for social interaction and exploration that may scaffold language acquisition. Fine motor control at 9 months supports gesture and object manipulation that elicits caregiver labeling (West & Iverson, 2017), while gross motor advances at 18 months such as stable walking expand the child's capacity for initiating joint attention and accessing new communicative contexts (Walle, 2016; Karasik et al., 2011). By 24 months, when motor competence is more established and language development is increasingly driven by linguistic input and cognitive factors, the direct contribution of motor skills may diminish. However, an important consideration in interpreting these developmental trajectories is the nature of the language measures across time points. The language assessments at 18 and 24 months included both comprehension and production components (ASQ Communication at both time points and Bayley Language scales at 24 months), while the 4-to-4.5 years assessments focused on receptive vocabulary and verbal reasoning abilities rather than speech production (PPVT and KBIT verbal subtests). The absence of cross-domain effects in the later developmental period may reflect this shift from mixed comprehension-production measures to purely receptive language abilities, suggesting that any motor-language connections may be more pronounced for expressive rather than receptive language skills. If this is the case, then it is not necessarily that the relations between motor and language skills shift across developmental stages, but that, lacking a measure of language production at later ages, we fail to detect the relation between fine motor skills and language production at later stages of development.

While statistical tests found no significant differences between the size of the relationship of language skills and fine-and gross-motor skills, it is worth considering why it was fine motor skills at 9 months which marginally predicted language at 18 months, and gross-motor skills which predicted language at 24 months. One possibility has to do with the nature of the questions asked of parents in the fine-and gross-motor subscales. As we mention in the introduction, sitting is one gross-motor milestone which is considered important by the developmental cascades theory, as infant sitting frees up their hands to manipulate objects and gesture. Libertus & Violi (2016) found a relationship between the development of sitting skills around five months of age and language skills at 10 and 14 months of age. However, manipulating objects and gesturing (which sitting allows for) would be considered finemotor skills. In the ASQ the parents filled in for our current study, at 9 months, parents are asked about manipulating and picking up objects in the fine-motor subscale. Only one question in the gross-motor subscale related to sitting, with the others focusing on standing (except one about cruising) -which might be less relevant to language development. The fine-motor scale will therefore be more relevant according to the developmental cascades theory. At 18 months, half of the gross-motor questions were about walking, which is also considered a significant gross-motor milestone in the developmental cascades theory. The fine motor questions however, focus on more precise grip and hand-eye coordination, such as "Does your child get a spoon into her mouth right side up so that the food usually doesn't spill?". At 18 months, therefore, the gross-motor subscale was more relevant to the developmental cascades theory. While it is tempting to interpret these results in line with the developmental cascades model, the relationship between language and these two motor areas is statistically indistinguishable in both ages, and so these findings might represent sampling variability rather than a meaningful difference between motor domains.

Finally, when we reran our analysis without controlling for confounding factors, the pattern of cross-domain effects shifted subtly. The fine motor at 9 months path, which was marginal in the adjusted model, crossed the significance threshold without covariates, despite the effect sizes being nearly identical -illustrating the fragility of relying on conventional significance cutoffs alone. Fine motor skills at 24 months also showed a marginal association with language at four to four and a half years that did not approach significance in the adjusted model. These shifts highlight the importance of controlling for potential confounds, as shared risk and protective factors may create spurious associations between motor and language development. For instance, executive function skills are linked to both motor (Maurer & Roebers, 2019) and language development (Viterbori et al., 2012).

Similarly, when we replaced the latent language factor at 24 months with only the examineradministered BSID-III, a significant path from fine motor skills at 24 months to language at four to four and a half years emerged. This could be because we were now modeling a path from an examineradministered tool to an examiner-administered tool. This is another important methodological point to consider when interpreting our results. However, given the reduced model fit in that analysis, this result should be interpreted cautiously. These findings do not negate the importance of motor development for overall child development, but they do suggest that interpretations of direct causal relations should be made with care.

Limitations and Future Directions

The current study has several important limitations that constrain our ability to draw strong causal conclusions. First, the only measure used to asses infants' motor development was the ASQ, which is a parental report which only includes six questions per motor area. The ASQ may be more appropriate for screening purposes than for assessing individual differences, given that at 18 months 61.8% of children scored the maximum, and at 24 months 49.4% scored the maximum. This ceiling effect can reduce variance and may have attenuated the cross-lagged estimates for gross motor at these waves.

Second, at 18 and 24 months both language and motor skills were assessed with subsets of the same measure, the ASQ. At 24 months we also had access to the BSID-III as a language assessment, and our analysis showed that the relationship between gross-motor and language skills remains significant even if only the BSID-III is kept as a language measure and the ASQ is excluded. Nonetheless, having no other language assessment other than the ASQ at 18 months is a limitation.

Third, we lacked direct measures of parent-child interactions, which may serve as important mediating mechanisms in motor-language relations. Previous research has demonstrated that motor development changes the nature of parent-child interactions, with parents talking more, and differently, to walking compared to those who are crawling (Karasik et al., 2011; Schneider & Iverson, 2022) and walking experience being associated with more infant-initiated joint engagement (Walle, 2016).

Additionally, fine motor skills may influence interactions by enabling longer toy manipulation periods that provide more opportunities for parental labeling (West & Iverson, 2017). Observational studies examining these interaction patterns could illuminate whether motor skills influence language development through enhanced social engagement opportunities as proposed by Iverson (2010 Iverson ( , 2021)).

Finally, our language measures varied in their assessment focus across developmental time points, with early measures including both comprehension and production components while later measures focused on comprehension. This measurement heterogeneity complicates the interpretation of developmental trajectories and may contribute to the absence of later cross-domain effects.

Conclusions

Our analysis of a large population cohort provides evidence for concurrent relations between motor and language skills, with fine-motor skills being somewhat more strongly related to language skills than are gross-motor skills. However, our results also suggest that longitudinal motor-to-language effects are more limited, with one two out of six paths proving significant. The finding that gross-motor skills at 18 months predict language at 24 months even when controlling for multiple confounds, are consistent with both the physical route between motor and language skills and the developmental cascades theory.

However, given that statistical tests showed no difference between the relationship of fine-and grossmotor skills and language at that timepoint, they should be interpreted with caution.
