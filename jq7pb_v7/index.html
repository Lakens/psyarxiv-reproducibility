Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

The rise of online sports betting, facilitated by technological innovations such as the cash-out feature, has transformed the gambling landscape. While cash-outs (a facility provided by betting operators which allows gamblers to close a bet early before the final outcome of a sports event is known) have been suggested to intensify problematic gambling behaviors, empirical studies to date have been correlational, leaving a gap in determining causal evidence. The present Registered Report investigated the direct impact of the perceived availability of the cash-out feature on various facets of gambling behavior in an online experiment. Hungarian residents with an online gambling history (N=595) were informed that they would have the chance to gamble with real money on sports events. Following random allocation, half of the participants were told that they would have the option to cash out their bets before the outcome of the sports event is known, while the other half did not have this option. Overall, the findings provided evidence that cash-out availability did not influence bet placement, wager size, or bet risk among our sample. However, the low variance in the outcomes may have limited the ability to detect subtle differences. Consequently, the null results should not be taken as conclusive evidence of no behavioral effect.

Introduction

Online sports betting has significantly increased in recent decades, with the number of users worldwide projected to reach 314.5 million players by 2030 (Statista, 2026). This popularity can be partly attributed to the introduction of cash-outs, a facility provided by betting operators which allows gamblers to close a bet early before the final outcome of a sports event is known. While cash-outs provide bettors with an additional decision point during gambling, their impact on betting behavior remains unclear. Much of prior research has focused on inplay betting more broadly, highlighting its association with a greater risk of harm (Hing et al., 2016 (Hing et al., , 2017;; Killick & Griffiths, 2019). For example, a British gambling prevalence study (Gambling Commission, 2018) reported that the proportion of gamblers classified as problem gamblers was much higher among those who bet in-play compared to online gamblers who do not (27.4% vs. 5.4%).

However, in-play betting is a broader concept than cash-outs because it refers to bettors' ability to place, adjust, or close bets while a sporting event is ongoing. Prior studies have not isolated the specific role of cash-outs in gambling behavior and have used correlational designs.

The present study aimed to bridge this gap by conducting an online experiment. The study investigated several dimensions of betting behavior, including the proportion of participants placing bets, bet sizes, and bet risks, both in the presence and the absence of cash-out options.

Importantly, the study also examined the differential effects on specific high-risk subgroups.

Ever since the British gambling operator William Hill first introduced cash-outs in 2012 (Gaming Intelligence, 2014), they have become a common feature on online sports betting sites (Killick & Griffiths, 2019; Lopez-Gonzalez & Griffiths, 2016). The increased penetration of smartphones and the 'always-on' culture have significantly facilitated this trend, increasing the availability of gambling, which has important implications for bettors' decision-making (Lopez-Gonzalez et al., 2019; Lopez-Gonzalez & Griffiths, 2017). There are different forms of cash-out, including full cash-out, partial cash-out (only part of the bet is cashed out), and automatic cash-out (if at any point during an event, the cash-out value matches a preset amount, the bet is automatically cashed out).

Similar to other bets, the amount offered for the cash-out is calculated by the gambling provider based on several factors, including the odds and amount of the original bet, as well as how the given event is progressing. For example, if the home team scores a goal in a football match, their odds of winning increase, resulting in an increased cash-out offer to players compared to before the goal was scored. The mere availability of cash-outs for sports events can have important implications even if nobody cashes out their bet, because it can influence key decisions during gambling. For instance, it could impact how many individuals bet, how much money they wager, and the level of risk in their betting.

One key cognitive heuristic by which cash-outs influence gambling behaviors is the illusion of control (Langer, 1975) it creates. By offering the option to close bets early, cashouts can -falsely -increase the perceived control over the success of the bets even though the objective level of control over the final success of the bets remains unchanged. Therefore, cashouts can nudge players to take greater risks by giving them the impression that they can close their bets with minimal losses. Bennett et al. (2024) demonstrated this effect by utilizing a cardbetting task (Bennett, 2022). In this task, participants predicted the color of a randomly selected card (red or blue) from 10 cards, and participants could wager points on each prediction. During some trials, participants were offered a "cash-out" option for a partial payout based on the expected value of their wager. The authors found that participants' bet amounts increased by up to 35% when the cash-out option was available. They posited that the perception of the initial bet being reversible may have increased their perception of control over the outcome.

Consequently, this perceived control could appeal to inexperienced or low-risk gamblers, increasing their risk tolerance as an effect of the greater perception of control. Similarly, Lopez-Gonzalez and Griffiths (2017) suggested that the cash-out feature can potentially increase the vulnerability of the bettors, because they can view gambling on sports as an investment, such as trading on the stock market, where they can control when to open and close their positions.

Moreover, some sports betting advertisements appear to encourage gamblers to see themselves as professionals by promoting game analysis to beat the service providers (Lopez-Gonzalez et al., 2018). Parke and Parke (2019) conducted an observational study on 19 online sports bettors with problematic gaming patterns and noted that the cash-out feature was associated with prolonged online sports betting sessions and increased bet frequency by enabling bettors to rapidly re-stake the cashed-out money, reinforcing impulsive and continuous gambling behaviors while minimizing breaks. Enabling bettors to cash-out changes the structure of betting from a previously discontinuous form of gambling (placing a single bet on the sporting event's final outcome) into a continuous one (i.e., bettors can now make multiple bets during a sporting event on many different aspects as opposed to placing a single bet on the winner) (Griffiths & Auer, 2013; Harris & Griffiths, 2018). Hing et al. (2016) similarly reported that a higher frequency of bet placements and impulsive responses to betting opportunities, such as the use of the cash-out feature, was associated with a higher risk of harm from gambling.

Self-report survey-based studies (Lopez-Gonzalez & Griffiths, 2017; Lopez-Gonzalez et al., 2019) have suggested that the use of cash-out functions is more prevalent among problem gamblers. While these studies offer valuable insights into the gamblers' psychological and demographic attributes (e.g., perceptions, clinical characteristics, income) and their offline gambling activities, they only provide correlational evidence. Moreover, it is not clear whether (i) the availability of cash-out in sports betting increases problem gambling, (ii) problem gamblers are more prone to play more impulsively when cash-out options are readily available, or (iii) the relationship is bidirectional.

While cash-outs are often discussed within the broader context of in-play betting, they also function as a standalone feature, yet research isolating their effects remains scarce. Most prior studies have largely focused on in-play betting as a whole, emphasizing its continuous nature and association with problem gambling. For example, behavioral tracking data (LaBrie et al., 2007; LaPlante et al., 2008; Nelson et al., 2008) and self-report studies (Hing et al., 2016 (Hing et al., , 2017;; Lopez-Gonzalez & Griffiths, 2017) have associated in-play betting with higher gambling risk. However, these studies do not distinguish whether the observed risks stem from cash-outs themselves or from other features of in-play betting, such as the ability to place multiple rapid bets within a single event. Consequently, there is a lack of research specifically isolating the effects of cash-outs on gambling behavior, highlighting the need for experimental research that isolates the effects of cash-outs.

Additionally, the effects of cash-outs may not be uniform across all bettors. Individual differences, such as financial status (Gray et al., 2012), high trait impulsivity (Hing et al., 2018), and lower statistical numeracy skills (Cokely et al., 2012), have been associated with higher gambling risk. Moreover, studies have identified frequent and intensive betting combined with high variability in wagering amounts and an increasing bet size during the first month of actual online gambling to be associated with high-risk subgroups among gamblers (Braverman & Shaffer, 2012), while participating in two different gambling types along with in-play betting has been reported to be an important predictor of gambling problems (Braverman et al., 2013).

Another study found that while demographic differences in cash-out feature use can be reasonably expected, no significant differences were found in participants' demographicssuch as gender, sexual identity, ethnicity, education, employment status, household income, and relationship status -regarding their use of cash-out features (Sinclair et al., 2024). The authors recognized that their sample may have lacked diversity and might not be representative of the general population. Moreover, while researchers might not observe significant demographic differences in cash-out use, other factors such as bet risk, bet size, or betting behavior may still vary. Taking this into account, demographics could still play a role in cashout use under different conditions. Additionally, heterogeneity in the impact of cash-outs may exist due to factors beyond demographics.

While the extant literature provides insight regarding the potential risks and motivations underlying the cash-out feature, a comprehensive understanding of its direct impact on gambling behavior remains elusive. To date, most studies have been correlational, leaving a gap in determining causal mechanisms. The present study sought to address this by employing an experimental methodology, offering a more robust examination of the effects of cash-out options. Moreover, recognizing the potential heterogeneity in responses, the study more deeply examined the differential impacts on specific high-risk subgroups, including those with low income, low numeracy skills, high impulsiveness, or mental health issues. By doing so, the study aimed to provide a nuanced understanding of the cash-out feature's influence, enriching the literature and offering actionable insights for both policymakers and stakeholders in the gambling industry.

Methods

The

Design and procedure

The study was designed as an online experiment to delineate the effect of the perceived availability of the cash-out option on online gambling behavior. Participants in the cash-out condition were informed that they would have the option cash-out their bets before the event the participant bet on concluded, although in reality, the experiment ended before the actual cash-out could happen. Such deception was a necessary and crucial part of the study because it addressed the potential hypothetical bias (Harrison, 2024) and ensured that the decision of the gamblers accurately reflected their natural responses to the availability of the cash-out option. Participants completed the study online. All participants who completed the study were paid a total fee of 6,000 Hungarian Forints (HUF) at the end of the experiment. During recruitment, participants were informed of a payment structure consisting of 3,000 HUF + 2,300 HUF + 700 HUF for completing specific tasks, for a total compensation of 6,000 HUF. 1During the experiment, they were told that they could receive 2,300 HUF by decoding randomly generated sequences of letters and numbers from distorted images (i.e., CAPTCHAs). At the end of the study, participants were debriefed about the purpose of the study and that their bets were simulated. They received a 700 HUF consolation prize for not winning or losing what they thought they had made on the bet, contrary to what they were informed before the experiment began.

After providing informed consent, participants received instructions to avoid any nonexperiment-related activities, such as listening to music or chatting. Participants were then prompted with an attention check question, followed by an exclusion question asking if they are under the influence of drugs or alcohol (yes/no). Participants who provided any response to the attention check question or answered 'yes' to the exclusion question were not permitted to continue, and the questionnaire automatically ended for them.

Participants who passed all checks were then informed that if they completed seven or more CAPTCHA codes correctly, they would receive a bonus payment of 2,300 HUF. The completion of CAPTCHA codes served two purposes. First, it was used as an attention check.

Participants who failed to complete at least seven of the ten CAPTCHA codes were excluded from the main analyses. Second, by making participants work for the financial reward, it was expected to increase their sense of ownership of the financial bonus (for a similar approach, see Newall et al. [2022]). The financial reward offered was in line with the median online bet sizes on sports events in the Hungarian gambling populationfoot_1 . Following this task, half of the participants were randomly assigned to the cash-out condition, while the other half were randomly assigned to the no-cash-out condition.

Participants in both conditions were told that they could gamble some or all of their financial bonus on one sports game, choosing from a list of potential events, or they could opt not to gamble. The only difference between the two groups was that in the cash-out condition, participants were informed about the option to cash out the following way: "If you place a bet, after placing the bet, before and during the sporting event, you will have the possibility to use the cash-out function to collect your winnings (see Experiment Flow Diagram)." The study used a description of the cash-out feature closely adapted from the Betfair website. "Cash-out lets you take profit early if your bet is coming in or get some of your stake back if your bet is going against you-all before the event you're betting on is over. Cash-out offers are made in real time on your current bets, based on live market prices. Cash-out is available on a wide range of sports, including football, tennis, horse racing, and many more! You can cash-out of bets pre-play, in-play, and between legs". Participants were then redirected to the webpage where they could choose to place their bet.

All participants were given instructions on how they could make their bets. They were told that they could gamble on a sporting event that would take place a few days after they had completed the experiment. To make the experience of the participants as close as possible to real-life online gambling, the structure and the content of the gambling options followed the commonly used format of online gambling providers in Hungary. That is, the sporting event was described (e.g., a football [soccer] match: Barcelona vs. Real Madrid), along with the time and date of the match, the odds for the 'home win', 'away win', and -where relevant -the 'draw' option. Below these options, participants were able to manually enter the amount of money they wanted to wager. Participants could only make one bet. The amount of the bet could not exceed the financial bonus they were given. To maximize the probability that participants would find the gambling options appealing, they were shown approximately 50-100 sports events that they could bet on covering the following sports: football, handball, rugby, e-sports, ice hockey, American football, boxing, tennis, water polo, basketball, and futsal. The data regarding gambling events shown in the experiment was extracted from the largest Hungarian online gambling website (www.szerencsejatek.hu) one day before the data collection started and was updated on a 2-to-3-day interval. 1 The list of sports events depended on the available events at the gambling website during data collection, and only events that were scheduled to occur after participants completed the questionnaire and betting task were offered. This approach yielded two distinct advantages. First, participants were shown a large collection of sports events that would take place in the target two-week period, therefore participants' experiences closely resembled their real-life gambling experiences. Second, participants were given realistic odds for each of the outcomes as calculated by a gambling service provider.

After participants had placed their bet or chosen not to bet, they were asked to fill out a self-report survey comprising three sections: demographic measures, measures that might moderate the effect of the cash-out option on gambling behavior, and a question assessing understanding of the cash-out option (see section on 'Self-report measures'). After the experiment, debriefing took place, where the true aim of the study was explained to the participants. They were also informed that the bets they had made were not real, but they would receive a consolation prize, irrespective of how their bet would have played out. Finally, participants were offered the contact details of professionals who could help them in case they felt they needed help with any gambling-related problems.

Significant correlations supported the criterion validity of these self-report measures.

The target sample size and power analysis

The minimum target sample size was determined in consultation with the recruiting partner, Vegas.hu. Based on their prior experience with the availability of eligible participants, they estimated that at least 500 valid responses could be obtained with high certainty after applying exclusions. Therefore, this number was treated as the minimum guaranteed recruitment sample size. A power analysis using the pwr package in R determined that 500 participants would provide evidence for an effect size of 0.23 (Pearson r) in a regression model with 43 predictors (Team R, 2013) at a 0.05 significance level with 0.80 power for testing H1 (see next section for study hypotheses). Based on a prior randomized online experiment (see Study 3 by Newall et al. [2022], using a similar strategy), it was estimated that approximately 61% of these participants would place bets, resulting in a subset of 305 participants for testing H2 and H3 (see next section for study hypotheses). A power analysis suggested that this subset would provide statistical evidence for an effect size of 0.29 (Pearson r) under the same statistical conditions. Such an effect size estimate is consistent with the upper bound of effect sizes found in recent meta-analyses on related phenomena. For instance, a meta-analysis of pop-up interventions during gambling (Bjørseth et al., 2021) found an overall effect size of g = 0.507 (approximately r = .25). Similarly, a meta-analysis on gambling advertisements and their impact on gambling behavior (Bouguettaya et al., 2020) reported effect sizes ranging from r = -.08 to r = .68. However, because no prior research has used experimental methods to directly estimate the present effect, there are no studies that could be directly used to estimate the expected magnitude of the effect.

It was also likely that a substantially larger sample than 500 participants could be recruited by the gaming partner (Vegas.hu). Therefore, to avoid unnecessarily wasting participants' time, the smallest effect sizes of interest were identified. It was considered that an effect of r = 0.1 would still be of theoretical and practical interest. The sample size required to detect such an effect (at α = .05 with 80% power) was calculated. This resulted in a sample size of 2,840 participants. For that reason, if possible, the plan was to continue data collection up to 2,840 participants for H2 and H3. Data collection would cease if either (i) this upper recruitment limit was reached or (ii) Vegas.hu exhausted its pool of potential gamblers to contact.

Hypotheses and data analysis strategy

In the present study, the impact of the availability of the cash-out option on three dimensions of gambling behavior was investigated. Accordingly, in the primary confirmatory analyses, three confirmatory hypotheses (Hs) were tested. It was hypothesized that (i) participants would be more likely to place a bet in the cash-out condition compared to the no cash-out condition (H1); (ii) among participants who placed a bet, individuals would place higher cash amounts in the cash-out condition compared to the no cash-out condition (H2); and (iii) among participants who placed a bet, individuals would select bets with higher odds (riskier bets) in the cash-out condition compared to the no cash-out condition (H3).

To test the robustness of the primary analyses and to test their sensitivity to different analytical choices, a multiverse analysis was conducted. Moreover, exploratory analyses aimed to identify which factors moderated the effect of cash-out options on gambling behavior. To do this, random forest models concerning each of the aforementioned hypotheses defined were conducted.

Statistical framework for inferences

To make inferences, an alpha level of .05 was used. In case a p-value was significant, and the direction of the interaction aligned with the hypotheses, it was treated as evidence for the hypothesis. If a p-value was nonsignificant or significant but the direction of the effect was misaligned with the hypotheses, it was concluded that there was no evidence for the existence of the effect, and if the effect existed, the effect size (r) was likely smaller than 0.23 (or 0.1 depending on the final sample size), as determined by the power analysis.

Sampling

As aforementioned, participants were recruited via the mailing list of the Hungarian online gambling service provider, Vegas.hu. Individuals who met the criteria of being at least 18 years old, residing in Hungary, and having prior experience in sports betting were eligible to participate. Vegas.hu sent out recruitment emails in chunks to the participants, and data collection took place from 19 January 2026 to 28 January 2026. A total of 1,126 participants were recruited for the study. Individuals who did not provide informed consent or who exited the survey before providing any survey or behavioral data were excluded prior to the application of the exclusion criteria.

Exclusions

To ensure data quality and validity in the primary analyses, participants were excluded if they (i) were under the age of 18 years, (ii) did not solve at least 7 of the 10 CAPTCHAs correctly, (iii) were self-reportedly under the influence of any drugs or alcohol during the experiment, (iv) did not demonstrate understanding the cash-out feature, (v) failed the attention check, (vi) completed the survey in less than three minutes, or (vii) provided the same answer on ten consecutive survey items. For the 69 participants who failed the attention check, and the 14 who reported being under the influence of alcohol or drugs, the survey immediately ended. This resulted in an initial analyzable sample of 963 participants.

Results of reliability and validity testing

Internal consistency was acceptable to excellent across self-report measures in the study sample. The BIS-R-21 showed good reliability for the total scale (α = .85, ω = .88) and adequate reliability for its three subscales (α = .73 -.81). The PGSI-HU demonstrated excellent reliability (α = .90, ω = .90). Item Response Theory was used to analyze the computer-adapted Berlin Numeracy Test (see Supplementary Materials for full results). The results indicated the highest measurement precision around average numeracy levels (θ ≈ 0), with adequate item discrimination for three items and weaker performance for the first item. Estimated scores (θ), showed a clustered pattern with a slight ceiling effect, suggesting that the BNT functioned as a moderately coherent numeracy measure among participants in the study sample.

Correlations among the self-report measures (see Table 2) were generally consistent with theoretical expectations. Impulsiveness was moderately associated with problem gambling (r = .50, p < .001) and showed small positive associations with gambling pattern variables such as daily gambling frequency (r = .17, p = .002 and gambling amount consistency (r = .17, p = .003). Problem gambling severity showed positive association with gambling patterns overall frequency (r = .20, p < .001), daily frequency (r = .26, p < .001), and consistency (r = .34, p < .001). Correlation involving whether participants placed bet were not estimated with the amount wagered and odds selected due to missingness by design, these variables were only defined for participants who placed bets.

Treatment of missing values

To compensate for differential attrition, missing values in incomplete survey responses were imputed. The analysis used the k nearest neighbor imputation method, with k = 3, following the recommendations of Beretta and Santaniello (2016). This method identifies the k closest observations with similar characteristics to those containing missing data. Imputation was performed only for age, impulsiveness, PGSI, poverty index, and numeracy. Only survey variables were used as predictors in the imputation model, betting behavior and CAPTCHA performance were not used as predictors.

Results of the primary analyses

To test the primary hypotheses, three sets of analyses were conducted, one for each hypothesis. In each of these sets, the analysis fitted two separate models, one containing the experimental condition dummy (cash-out vs. no cash-out) and one not. Both models included the following variables that have been theorized to affect gambling-related behavior: impulsiveness, problem gambling, gaming patterns, numeracy, age, employment, gender, household income divided by the square root of the number of household members, highest educational attainment, and experience with the cash-out feature.

Likelihood of placing a bet (H1).

To test whether participants were more likely to place bets in the cash-out condition (H1), the registered intention-to-treat binomial logistic regression models were fitted to predict whether participants chose to make a bet or not. The results did not support the hypothesis that participants in the cash-out condition would be more likely to place bets compared to participants in the no cash-out condition (OR = 1.00, 95% CI [0.64, 1.58], p = .993). The addition of the cash-out predictor did not significantly improve the model fit compared to the baseline model (χ 2 (1) < 0.01, p = .993). However, it was observed that 80% of participants chose to place a bet, indicating a potential ceiling effect that likely reduced statistical power to detect a difference.

Wager amount (H2).

To test whether participants who placed bets wagered higher amounts in the cash-out condition (H2), the preregistered analysis plan specified the use of either a linear or ordered logistic regression model depending on the distributional properties of wager amounts. However, because the frequency plot of wagered amounts showed a high ceiling effect with a 92% of participants selecting the maximum bet (Figure 3), it was determined that the dependent variable did not have sufficient variance to fit either linear or ordered logistic regression models. Therefore, the analysis deviated from the preregistration and instead fitted a binomial logistic regression model to predict whether participants placed the maximum bet amount, among participants who placed a bet (n = 474). While controlling for preregistered covariates, the analysis did not support the hypothesis that participants in the cash-out condition would be more likely to bet the maximum amount compared to participants in the no cash-out condition (OR = 1.08, 95% CI [0.48, 2.47], p = .848). The addition of the cash-out predictor did not significantly improve the model compared to the baseline model (χ 2 (1) = 0.04, p = .848).

Bet risk (H3).

To test whether participants who placed bets selected bets with higher odds (riskier bets) in the cash-out condition (H3), first, the decimal odds were transformed into probabilities by taking the reciprocal of the odds before the analysis. This transformation places the decimal odds selected on a probability scale making it more suitable for linear repression analysis. Then, linear regression models were fitted to predict the probabilities associated with the chosen bets of the individuals. The effect of the availability of cash-out on bet risk remained non-significant, β = -0.031, 95% CI [-0.066, 0.003], p = .077. The baseline model, including only covariates, explained 11.5% of the variance of the odds selected by participants (R² = .115), while the model including cash-out and covariates explained 12.1% of the variance (R² = .121), an increase of ΔR² = .006. The addition of cash-out did not significantly improve the model fit compared to the baseline model, F(1, 435) = 3.14, p = .077. Therefore, H3 was not supported.

Robustness tests of the primary analyses: Multiverse analyses

To assess the robustness of the results and their sensitivity against the methodological choices, a multiverse analysis was conducted. Multiverse analysis involves "performing all analyses across the whole set of alternatively processed data sets corresponding to a large set of reasonable scenarios" (Steegen et al., 2016; p. 702). The addition of a multiverse analysis was useful given that there were several choices that could have influenced the results. The multiverse analysis was exploratory because there were no specific hypotheses for each analysis. Accordingly, multiple versions of the analyses specified in the primary analysis was conducted with 24 (2 x 12) alternatively processed datasets.

First, all analyses were repeated with the exclusion criteria listed above and also including all individuals without excluding any participant. Second, all analyses were repeated with 11 different imputation methods: with the imputation listed in the primary analyses, with only the inclusion of complete cases, and with the use of different k values (1-10). In addition to the analysis of bet risk (H3), a robustness analysis was conducted using untransformed decimal odds. This was conducted to help contextualize the participants' interpretation of the decimal odds, which could yield more realistic insights into perceived risks and betting behaviors. Across all confirmatory models that were applied identically across all 24 specifications, none of the models produced a statistically significant effect of cash-out (0/96 tests with p < .05). The magnitude of the effects remained extremely small across all specifications, and the direction of the effects was consistent with the primary analyses. The only exception was H1 (bet placement) where the clean sample showed a positive effect while the full sample showed a negative effect. In both cases, this appeared to reflect the small magnitude of the effect rather than a meaningful change in interpretation. Overall, no specification meaningfully altered the substantive interpretation of the results. Full specification-level results are reported in the Supplementary Materials (Table S1).

Finally, the study explored the variables moderating the impact of the availability of cash-outs on key dependent behaviors (betting vs. no betting, amount of money wagered, odds associated with the bets). To do this, three random forest models, which use multiple decision trees to predict an outcome, were conducted separately for each of these outcome variables, examining how various demographic and self-report variables influenced these betting behaviors.

Data were split into training and test sets in an 80-20 ratio, and the training set was used to find the number of variables sampled at each split of a decision tree for the random forest models. The number of variables was set between 1 and the number of included interaction variables, and tuned via repeated 10-fold cross-validation. To address class imbalance in the categorical outcomes, stratified bootstrap sampling was implemented within the random forest algorithm. For each tree, equal numbers of observations were sampled from each outcome category based on the size of the minority class, minimizing bias toward the majority class.

More specifically, the random forest algorithms drew stratified bootstrap samples matching the size of the minority class for each tree, preventing the majority class from biasing the split criteria. The analysis included all of the following variables: psychological traits and gambling behaviors assessed through self-report measures of impulsiveness, problem gambling severity, gambling patterns, and numeracy. Discussion

The present study's findings do not support the hypotheses (H1 to H3) that cash-out availability influenced the likelihood of betting, the amount wagered, or the riskiness of bets made in this experimental context. However, 80% (N= 471) of the participants included in the analyses chose to place bets. Moreover, 91.8% of them bet the maximum possible amount (2,300 HUF). This observed ceiling effect likely reduced the sensitivity of the analyses to detect differences between experimental conditions, and provides a possible explanation for the null findings.

Several factors may have contributed to the ceiling effect. Participants may not have treated the reward as equivalent to their own money, although the CAPTCHA reward was framed as money participants had personally earned to strengthen their sense of ownership over it. But the reward did not constitute their full compensation of 6,000 HUF, which may have reinforced this perception. Participants may instead have treated it as supplementary, reducing their sensitivity to potential losses. This pattern is consistent with the 'house money effect' (Post et al., 2008; Thaler & Johnson, 1990), in which individuals treat experiment-provided funds as money they are already ahead on, discounting potential losses. Prior familiarity with cash-out was widespread in the study sample. Only 20 participants had no prior experience with the feature (3%). Those with prior experience may have relied on existing beliefs or habitual strategies rather than responding to experimental manipulation.

To understand the ceiling effect, the study design was compared with Newall et al.

(2022), whose Experiment 3 used a similar protocol but did not produce a ceiling effect. Four differences stand out. First, the present study sample had higher PGSI scores (Ferris & Wynne, 2001) than either condition of Newall et al. (2022). In the present study, the full sample had a mean PGSI score of 4.74 (SD = 4.56), with means of 4.86 (SD = 4.70) for the control group Although the ceiling effect provides a plausible explanation for the null findings, alternative interpretations should also be considered. One possibility is that cash-out availability does not alter betting behavior in online sports betting contexts or that its effects depend on the characteristics of the betting environment. For instance, Bennett et al. (2024) found that cash-out availability affected behavior in a card betting task suggesting that the context or the characteristics of the cash-out offer may have moderated the effect of cash-out availability. Real-life sports betting may involve more established expectations, strategies, and prior experiences, particularly among experienced bettors. The sports betting task used in the present study may therefore have weaker or more conditional effects than those observed in other gambling contexts. The reality is further complicated by the fact that cash-out availability may have an effect in a situation on some outcomes but not on others. The recent findings of Hayes et al. (2026) found that cash-out availability affected willingness to gamble in a simulated horse-race betting task but did not affect bet amounts or bet risk among participants who chose to gamble. This pattern suggests that cash-out availability may influence the decision to participate in gambling without affecting the characteristics of the bet, such as bet risk and amount.

Another possibility behind the null findings involves the number of betting decisions participants were asked to make. Bennett et al. (2024) used repeated trials, and they found that the effect of cash-out on bet amount was initially small and increased over repeated bet decisions. If cash-out effects develop habits in betting through repeated exposure, a singledecision paradigm such as the present one may have been insufficient to capture them. This possibility also overlaps with the methodological differences of the current study from Newall et al. (2022), whose multi-bet design provided greater opportunity for habit formation.

Repeated exposure may therefore be an important condition under which the behavioral effects of cash-out become more apparent.

Additionally, drawing from Ngieng et al. (2026) where the authors suggested that cashout may appeal primarily to those with lower impulsivity and PGSI scores, raising the possibility that cash-out features could facilitate sport-betting involvement among relatively low-risk consumers. If so, the experienced sports-betting sample in the present study may have been relatively insensitive to manipulation. Participants with established betting habits may already have developed strategies for managing cash-out opportunities, reducing the likelihood that experimentally introducing or removing the feature would substantially alter their behavior. Although the present study was not designed to test this moderation directly, these considerations highlight the importance of examining individual differences in future research.

Several limitations of the study should be considered. The experimental paradigm offered strong internal validity but limited ecological validity. Participants made betting decisions within a simulated environment using experiment-provided money to gamble, which does not fully capture real-world gambling contexts where personal financial consequences are more salient. Although recruiting active online sports bettors was a strength for ecological relevance of the participant population, it might have simultaneously reduced the impact of the sensitivity of the experimental manipulation. Participants were likely to be familiar with the feature and have their own experiences and interpretations of the feature that the present study's explanation could not override. A notable proportion of participants failed the question assessing their understanding of the cash-out function, suggesting that participants' preexisting knowledge or interpretations of the feature may not have aligned with the experimental explanation. Lastly, the present study was conducted with a Hungarian sample, which may limit the generalizability of the findings to gambling populations in other cultural or regulatory contexts.

Future research, focusing on these new forms of gambling problems (Czakó et al., 2025), could also address some of these limitations. For instance, studies could increase the perceived personal ownership towards betting stakes by allowing the use of participants' own money or incentive structures that are more directly tied to effort and performance. Field experiments conducted in collaboration with gambling operators using behavioral data from real betting environments could provide an ecologically valid context across multiple dimensions by capturing repeated betting decisions, more realistic financial consequences, and naturally occurring interactions with cash-out. Additionally, recruiting more diverse samples, including less experienced or lower-risk gamblers, could also help clarify whether observed effects are moderated by gambling-related characteristics such as experience with cash-outs and/or with sports betting, impulsivity, and problem gambling severity. Finally, longitudinal designs where participants are introduced to the cash-out feature and their betting behaviors are tracked over time may provide insight into the long-term impact of the cash-out feature.

Overall, the present findings provide no empirical evidence that cash-out availability influences betting behavior in this experimental context. However, the observed ceiling effect in betting decisions suggests that the task may have lacked sufficient sensitivity to detect subtle differences between the cash-out and no-cash-out conditions. Consequently, these null findings should not be interpreted as definitive evidence that cash-out availability has no behavioral consistent with the possibility that the effects of cash-out depend on the betting context, prior experience, and individual differences in gambling-related characteristics. This contrasts with theoretical accounts suggesting that cash-out features may increase perceived control and encourage greater risk-taking. Further studies employing more ecologically valid designs such as conducting field experiments with providers and involving more diverse samples that include less experienced or lower-risk gamblers are needed to establish whether, for whom, and under what conditions do cash-out features influence gambling behavior.

Deviations From Stage 1 Protocol

In contrast to the original plan, the following sports were not offered for the participants to bet on: darts, cricket, motorsports, table tennis, snooker, mixed martial arts fighting, Aussie rules, golf, table tennis, baseball, and floorball. This happened because the odds were extracted from an online gambling website, and the final set of sports offered to participants depended on the sports available on the platform during the data collection period. Additionally, the initial plan was to present 50-100 sports events. However, this range was exceeded due to the number of available events on the Hungarian online gambling website during the data collection period. The number of events were updated as follows: 193 events on 21/01/2026, 429 events on 24/01/2026, 116 events on 26/01/2026, and 95 events on 01/02/2026.

After examining the data, the preregistered CAPTCHA exclusion criterion (failing >3 of 10 items) was slightly modified, as it was realized that some of the CAPTCHA stimuli contained ambiguities in distorted characters leading to systematic errors among study participants. Consequently, the research team identified those cases where at least 10% of the participants provided the same alternative response to one CAPTCHA letter, and these were accepted as correct. The adjusted CAPTCHA exclusion was applied prior to hypothesis testing.

To assess robustness, all analyses were repeated using the original preregistered criterion leading qualitatively to the same results. The results of this sensitivity analysis are reported in the Supplementary materials (Tables S6 -S8).

For H2, the preregistered plan was to model wagered amount using either linear regression or ordered logistic regression depending on the distribution. However, 92% of bettors wagered the maximum amount (2,300 HUF), producing a severe ceiling effect and eliminating meaningful variance in the continuous outcome. Therefore, the analysis used a binomial logistic regression instead predicting whether the participant placed the maximum bet (1 = max bet,0 = not max bet).

The preregistration specified 43 predictors. However, due to Helmert and dummy coding, the number of covariates differed slightly in the fitted models resulting in 41 instead of 43. No conceptual predictors were omitted.

Moreover, two minor changes were made that were approved by the PCI recommenders prior to data collection: (i) the recruitment email was updated to include full payment information (3,000 HUF base + 2,300 HUF and 700 HUF task-based bonuses), and (ii) the exclusion questions (attention check and drug/alcohol use) were moved to the start of the survey to prevent uncompensated participation.
