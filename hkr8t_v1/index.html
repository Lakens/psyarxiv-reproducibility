Power analyses need to contain the following information to be interpretable: the type of power analysis, the statistical test, the software used, sample size, critical alpha criterion, power level, effect size, and an effect size metric. In addition, it is recommended to make sure the power analysis is reproducible (by sharing the code, or a screenshot, of the power analysis), and to provide good arguments for why the study was designed to detect an effect of this size.

An a priori power analysis for an independent samples t-test, conducted using the pwr.t.test function from pwr (Champely, 2020), indicated that for a Cohen’s d = 0.5, an alpha level of 0.05, and a desired power level of 80% required at least 64 participants in each group.

A sensitivity power analysis for an independent samples t-test, conducted using the pwr.t.test function from pwr (Champely, 2020), indicated that with 64 participants in each group, and an alpha level of 0.05, a desired power level of 80% was reached for an effect size of d = 0.5.

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

Declaration of Helsinki - Declaration of Helsinki / Helsinki Declaration

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. This package was validated by the Metacheck team on articles in Psychological Science.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Codebook Check works

This module checks whether the data columns in a repository are documented in a codebook or README. It locates codebook/readme files, extracts the variable definitions they contain, matches those definitions against the data columns extracted by data_check, and reports documentation coverage: how many data columns are documented, and which documented variables are never used.

The Codebook Check module consumes the columns and file classification produced by data_check (and, transitively, repo_check). Files classified as codebook or readme are parsed with parse_codebook(), which reads structured tables (CSV/TSV/Excel with a variable-name column and a label column), embedded labels in haven files (SPSS/Stata/SAS), and plain text from rich-text formats (docx/pdf/rtf/odt). How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Checking code requires downloading its file contents. For a paper whose repository is on Dryad, this never succeeds unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (listing the repository’s files does not need one). Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. Revisiting the Radius of Trust Problem: Who Counts as "Most People"?

Social scientists have long observed that societies and economies thrive when individuals trust both other members of their community and people in general (Fukuyama, 1995). A widely accepted view is that the functioning of our day-to-day lives and social order rests on interpersonal trust-nearly all our decisions involve trusting someone else. The more complex the society, the greater the dependence on others (Rotter, 1971). Already Adam Smith (1776) believed that trust is crucial to a nation's wealth accumulation because it reduces transaction costs and increases economic efficiency. Similarly, Durkheim (1933) argued that while the primary purpose of the division of labor is to enhance economic productivity, it cannot occur without mutual trust among those participating in economic transactions.

The division of labor is not the sole factor contributing to the growth of solidarity and other prosocial relationships. However, cooperation and mutual trust are essential for the functioning of any society, especially those that are technologically and socially advanced. The set of forces that facilitate human interaction and enable social functioning is collectively referred to as social capital, commonly defined as "connections among individuals-social networks and the norms of reciprocity and trustworthiness that arise from them" (Putnam, 2000, p. 19).

Theories that emphasize the critical role of trust in society have been supported by ample empirical evidence over the past few decades. Research across the social sciences, economics, and psychology has shown that trust helps predict a society's prosperity and economic growth (Beugelsdijk et al., 2004; Bjørnskov, 2012; Dearmon & Grier, 2009; Dearmon & Grier, 2011; Delhey et al., 2011; Knack & Keefer, 1997; Paldam, 2011) and, more broadly, its level of human well-being and economic development, as measured by the Human Development Index (Bjørnskov, 2022; Graafland, 2019; Özcan & Bjørnskov, 2011; Welzel et al., 2003).

Furthermore, trust in others has been shown to predict welfare, economic freedom, the rule of law, and many other positive societal outcomes (Delhey & Newton, 2005; Graafland, 2019 Graafland, , 2023;; Welzel & Delhey, 2015).

Measuring Trust with a Single-Item General Trust Question

Given the central role of trust in personal and societal functioning, many different methods for measuring it have been developed over time (Robbins, 2023; Wheeler et al., 2025) with a main focus on general trust in other people (Frazier et al., 2013; Nannestad, 2008; Paldam, 2011; Rotter, 1971; Schilke et al., 2021; Uslaner, 2002 Uslaner, , 2018)). In large-scale social surveys, each construct must be measured as concisely as possible to avoid respondent burden. Consequently, general trust is often measured using a single-item general trust (SIGT) question (Nannestad, 2008; Sztompka, 1999; Uslaner, 2018; Yamagishi, 2011). The classic SIGT asks: "Generally speaking, would you say that most people can be trusted, or that you need to be very careful in dealing with people?" (Uslaner, 2015 (Uslaner, , 2018)). Confidence in the SIGT grew as research showed that the average scores across hundreds of countries, measured repeatedly over extended periods, are fairly good indicators of countries' economic wealth (Paldam, 2009 (Paldam, , 2011) ) and other aspects of human development (Beilmann et al., 2018; Dakhli & De Clercq, 2004; Graafland, 2019; Özcan & Bjørnskov, 2011). More recently, a study has shown that the SIGT is also related to psychological measures of trust at both the individual and country levels and exhibits broadly similar patterns across gender, age, and education (Realo & Allik, 2026).

Despite its wide use, the validity of the SIGT has been questioned (Delhey et al., 2011; Lundmark et al., 2015; Miller & Mitamura, 2003; Reeskens, 2013; Reeskens & Hooghe, 2008; Sturgis & Smith, 2010; van Hoorn, 2014). One of the main problems was clearly articulated by Reeskens (2013): "But who are those 'most people' who can be trusted?" (p. 703). For example, if a respondent interprets "most people" as referring only to those born in that country, this differs from a respondent who means all people, regardless of origin (André, 2014). If "most people" refers to different groups or categories of people across countries, the SIGT cannot be considered a valid universal measure of generalized trust (Delhey et al., 2011; Reeskens, 2013; van Hoorn, 2014).

For instance, the People's Republic of China is a common outlier in general trust research, with reported levels of general trust exceeding predictions derived from other socioeconomic and cultural indicators (Feng et al., 2016; Steinhardt, 2012; Steinhardt & Delhey, 2020; Wu et al., 2024; Zhou & Hu, 2013). One possible explanation is that "most people" in China seems to refer only to close family members (Fukuyama, 1995; Steinhardt, 2012), whereas in other countries, "most people" usually includes out-group members and strangers as well (Delhey et al., 2011).

The interpretation of "most people" as referring primarily to close relatives is also supported by findings indicating that trust in out-groups tends to be higher in more modern regions of China than in more traditional ones (Steinhardt & Delhey, 2020).

The Radius of Trust Problem

Unexpected findings on general trust in China partly inspired Fukuyama (1995) to distinguish between two components of trust: its overall strength and its radius. While the overall strength of trust is clearly important, the extent to which trust extends beyond ingroups (i.e., individuals who belong to the same social, ethnic, cultural, or religious group as oneself, such as family members, friends, neighbors, and people from the same ethnic group) to outgroups (i.e., individuals who do not belong to one's primary groups but are members of different social, cultural, ethnic, or religious groups) is even more relevant.

If respondents interpret "most people" as referring primarily to members of their ingroup, this may create the impression that they trust complete strangers and people from different ethnic and religious backgrounds equally. Thus, to properly measure general trust, it is not sufficient to ask whether one trusts most people; it is also necessary to assess the extent to which trust extends to socially distant groups-that is, the radius of trust (Fukuyama, 1995).

Subsequent research demonstrated that the radius of trust is more critical than the overall level of general trust alone. For instance, in societies where trust is confined to a narrow ingroup, such as one's family or kinship group, people tend to be less engaged in civic participation and exhibit lower levels of social capital (Realo et al., 2008). The importance of the radius of trust is also consistent with the view, noted above, that it is important to distinguish between ingroup and outgroup trust (Portes 1998; Sztompka 1999; Beugelsdijk & Smulders 2004).

Is the Radius of Trust the Same as Out-Group Trust?

The introduction of the concept of a radius of trust made it clear that the phrase "most people" needed disambiguation, leading to the addition of six specific trust questions to the World Values Survey (WVS) questionnaire (Delhey et al., 2011; Delhey & Welzel, 2012; Haerpfer et al., 2022; Inglehart et al., 2022). Since Wave 5, the specific trust items have asked respondents to rate their trust in their family, neighborhood, and people they know personally, as well as in people of another religion, people of another nationality, and people they meet for the first time, using a scale ranging from "Do not trust at all" to "Trust completely." (Haerpfer et al., 2022; Welzel & Delhey, 2015). In numerous studies analyzing these items, a two-factor solution often emerges, distinguishing between ingroup trust-trust in family, neighbors, and familiar individuals-and outgroup trust-trust in people of different religions and nationalities, as well as those met for the first time (Crepaz et al., 2014; Delhey et al., 2011 Delhey et al., , 2014;; Delhey & Welzel, 2012; Norris, 2022). When responses to the SIGT measure of trust in "most people" were analyzed alongside the six additional trust items, the SIGT showed moderate loadings on both factors but tended to load more strongly on the outgroup factor (Newton & Zmerli, 2011, Table 1).

However, the emergence of two orthogonal factors related to ingroup versus outgroup trust does not imply the absence of correlation between ingroup and outgroup trust items. Research has shown a fairly strong correlation between ingroup and outgroup trust items at both the individual (r = .48) and aggregated societal (r = .59) levels (Norris, 2022). These relatively high correlations warrant an explanation of the relationship between these two forms of trust. One explanation proposes that outgroup trust may develop via two distinct mechanisms: projection and creation (Delhey & Welzel, 2012). Under the projection mechanism, outgroup trust is derived from ingroup trust (Freitag & Traunmüller, 2009), whereas under the creation mechanism, it can emerge independently, depending on a society's level of modernity (Delhey & Welzel, 2012).

To address the considerable correlation between ingroup and outgroup trust-and, with it, the question of the radius of trust- Delhey et al. (2011) proposed calculating the radius as the difference between ingroup and outgroup trust indices, thereby capturing the relative strength of outgroup trust. Using WVS Wave 5 data from 51 countries (2005) (2006) (2007), they first demonstrated that ingroup and outgroup trust form a two-factor structure exhibiting configurational and partial metric invariance across cultures. They then estimated the radius of trust "by first quantifying the associations of unspecified trust (trust in most people) with in-group and out-group trust, and then by calculating the difference in strength between these two associations" (Delhey et al., 2014 (Delhey et al., , p. 1263)). In this framework, the more the balance tips toward outgroup trust, the wider the notion of "most people" and hence the broader the radius of trust (Delhey et al., 2011). While general trust tended to be higher in countries where "most people" included outgroups, a variety of combinations of trust level and radius existed, with the radius of trust best predicted by a country's Confucian legacy and economic prosperity. To account for this, Delhey et al. (2011) introduced a radius-adjusted measure of general trust, calculated by multiplying each country's general trust score ("most people can be trusted") by its radius of trust. When this adjustment was applied, the exceptionally high levels of general trust reported in China and several other Asian countries were substantially reduced.

Van Hoorn (2014), in his commentary on Delhey et al.'s (2011) study, acknowledged their significant progress in developing a method to quantify the radius of trust but argued that there is neither theoretical nor empirical justification for equating the radius of trust with the level of general trust or out-group trust. In a subsequent study, van Hoorn (2015) provided further evidence that the overall trust level-that is, the intensity with which people trust others-should be treated as distinct from the radius of trust, with the two representing relatively independent components of trust. In response to this critique, Delhey et al. (2014) later retracted one of their central claims, namely, that outgroup trust constitutes a valid proxy for the radius of trust, while leaving the other findings of their study unaffected.

The Aims of the Present Study

The present work builds on previous research on this topic and has three main, related aims.

The primary aim of this study is to analyze the meaning of "most people" by reconstructing the underlying semantic space of respondents' answers to the SIGT and six specific trust items in the Integrated Values Surveys (IVS) dataset , which consolidates data from the European Values Study (EVS) and the WVS (Inglehart et al., 2022). Previous studies have mainly been limited to examining linear correlations between items or their loadings on two factors obtained through factor analysis (Crepaz et al., 2014; Delhey et al., 2011 Delhey et al., , 2014;; Delhey & Welzel, 2012; Norris, 2022). However, such an approach does not provide a sufficiently clear understanding of the semantic space underlying trust assessments and the rules governing it.

Second, our study aims to identify the best measure of general trust, defined as the widest radius of trust that includes distant categories of people, such as those from different ethnic or religious groups.

Third, we aim to determine whether the radius of trust, or another form of trust, is the best indicator of overall human well-being and socioeconomic development, as measured by the Human Development Index (HDI).

Measures

General trust. General trust was measured with the following question: "Generally speaking, would you say that most people can be trusted or that you need be very careful in dealing with people" (A165; SIGT). Participants were asked to choose between two options: "Most people can be trusted" (1) or "Need to be very careful" (0). The mean country-level SIGT score (N = 104) reflects the percentage of participants who indicated that "most people can be trusted." As noted above, data on the SIGT were available for 104 countries and territories.

Country-level SIGT scores across survey waves ranged from 0.04 in Trinidad and Tobago to 0.70 in Norway, with an overall mean of 0.24 (SD = 0.14).

Group-specific trust. Participants in WVS5 (2005 WVS5 ( -2009)), WVS6 (2010-2014), and WVS7 (2017-2022) data waves were also asked to indicate their level of trust in specific groups: family (D001_B; Tfml), people in their neighborhood (G007_18_B; Tnbr), people they know personally (G007_33_B; Tprs), people of another religion (G007_35_B; Trel), people of another nationality (G007_36_B; Tnat), and people they meet for the first time (G007_34_B; T1st). Responses were given on a four-point scale:1 = Do not trust at all,2 = Do not trust very much,3 = Trust somewhat,4 = Trust completely. For comparison with the dichotomous single-item general trust scale, responses to these six questions were transformed into a unit scale where the lowest score (i.e., "Do not trust at all") was recoded as zero and the highest score (i.e., "Trust completely") as one. Data on group-specific trust items were available for 88 countries and territories. Across all countries and territories and the three survey waves, trust scores were highest for family members (Tfml = 0.70) and lowest for people the respondents met for the first time (T1st = 0.24).

Based on previous research (Delhey et al., 2011), two indices were computed to measure ingroup and outgroup trust, respectively. The Ingroup Trust Index was calculated as the average of items assessing trust in family, neighbors, and personally known individuals. TIN = (Tfml + Tnbr + Tprs)/3. The Outgroup Trust Index is the mean of trust in someone met for the first time, people of another religion, and people of another nationality. TOUT = (T1st + Trel + Tnat)/3. Higher scores indicate higher levels of ingroup and outgroup trust, respectively.

HDI.

The HDI developed by the United Nations Development Programme, is a composite measure of life expectancy, education (including mean years of schooling completed and expected years of schooling upon entering the education system), and economic wealth.

Countries with higher HDI scores exhibit greater life expectancy, higher levels of education, and higher gross national income (GNI) per capita, adjusted for purchasing power parity (PPP). This study used the available Human Development Index data for 2021 (HDI2021) (United Nations Development Programme, 2022). HDI2021 data were also available for all 104 countries and territories for which SIGT scores had been obtained.

The Relationships between General and Group-Specific Trust

To determine whether general and group-specific assessments of trust show any common pattern, we conducted a correlational analysis between SIGT and the six group-specific trust items. The correlations were r = .23, .42, .59, .39, .52, and .68 for Tfml, Tnbr, Tprs, Trel, Tnat, and T1st, respectively. All correlations were statistically significant at p < .001, except for Tfml, which was significant at p = .032. As shown by the coefficients, the concept of trusting "most people" appears to align most closely with trusting a person one meets for the first time and people personally known.

To further analyze the covariance pattern among the seven trust items (i.e., SIGT and six group-specific trust items), a principal component analysis (PCA) was conducted on the countrylevel means for 88 countries and territories, followed by a normalized varimax rotation. To ensure sufficient indicator variation for the factor analysis (cf. Marsh et al., 1998), we computed gender-specific country-level scores for the SIGT and each of the six group-specific trust items (resulting in 14 indicators) and conducted exploratory factor analysis on the resulting countrylevel dataset. We also checked that there were no significant differences between the separate and combined analyses of women's and men's data that could affect the interpretation of the results. Two factors were required to describe the pattern of covariation among the 14 variables (seven items by gender), explaining 82% of the total variance. Factor loadings for women and men were closely aligned, indicating substantial similarity between genders (see Figure 1). The first principal component (PC1) primarily reflected outgroup trust, with the highest loadings for items concerning trust in individuals of different religions (Trel) or nationalities (Tnat), whereas PC2 represented ingroup trust, with the highest loadings for trust in family (Tfml) and neighbors (Tnbr).

As shown in Table 2, the two-factor solution was relatively simple, with all items except two loading above .40 on a single factor. The exceptions were SIGT and trust in people personally known (Tprs). SIGT loaded slightly higher on the first factor (Outgroup Trust; .60) and lower on the second factor (Ingroup Trust; .38-.39), placing it between the two dimensions. This pattern supports previous observations that the concept of "most people" primarily, though not exclusively, refers to outgroup members. Trust in personally known people also loaded strongly on both factors (above .60), suggesting that these individuals may be considered part of one's ingroup, such as close acquaintances, but can also encompass outgroup members based on social, cultural, ethnic, or other distinctions.

To better visualize the structure of the loadings, the fourteen items (i.e., seven trust items for men and seven for women) are depicted in Figure 1 in a two-dimensional space defined by the principal components PC1 and PC2, which represent the Outgroup and Ingroup Trust factors, respectively. As shown in Figure 1, the loadings of the group-specific trust items (i.e., Tfml, Tnbr, Tprs, Trel, Tnat, and T1st) are nearly equally spaced from the origin. Indeed, a circle with radius R = 0.93 passes very close to all these loadings, and the correlation between the empirically observed factor loadings and those predicted by the circle is effectively one (r = .99). In contrast, SIGT loadings on both axes are closer to the origin than those of the group-specific trust items.

Whether the shorter radius of SIGT carries substantive meaning remains unclear, as it may simply reflect differences in variance and correlations arising from items with two versus four response options. It is also possible to treat the country mean ingroup trust TIN and outgroup trust TOUT scores shown in Table 1 as coordinates of a vector, and to calculate the angle of this vector as φ = arctan(TIN/TOUT). The values of φ for each country are shown in the 14th (penultimate) column of Table 1. If the angle of the vector is greater than 45 degrees (φ > 45º), it indicates that the ingroup is trusted more than the outgroup in this country. There was no country where out-group trust was higher than in-group trust. The smallest gap between ingroup and outgroup trust was in Haiti (φ = 51º), but this was mainly due to a low overall level of trust. The largest surpluses of ingroup trust over outgroup trust were in Tajikistan (φ = 74º), Libya, Uzbekistan, and Yemen (φ = 73º). Expectedly, the angle between ingroup and outgroup trust φ, was negatively correlated with SIGT (r = -.39, n = 88, p < .000l) and also with HDI2021 (r = -.35, n = 88, p = .00l). This demonstrates that the direction of the vectors toward greater ingroup or outgroup trust can be used as an indicator of the percentage of people who say they trust most people, and as an indicator of the level of human development in that country. In countries and territories with a higher level of human development, the gap between ingroup and outgroup trust narrows.

Undoubtedly, the fact that all assessments of trust can be described by a single angle of rotation of a vector of constant magnitude is a significant improvement in the economy of the description. But more important is the description of an important invariance or regularity that previous researchers had not noticed. This regularity shows that there is no simple, onedimensional concept of trust in people's minds worldwide. Everywhere, trust is a complex concept with two components related by an invariant such that the sum of their squares is always constant. It can also be said that trust is assessed using a universal pointer that indicates the direction between the ingroup and the outgroup.

Discussion

Who Do People Trust When They Say They Trust "Most People"?

Over the past seventy or so years, hundreds of thousands of people worldwide have been surveyed about their trust in others-both generally and in specific groups-because trust, as a component of social capital, is considered a key force that binds societies and supports their smooth functioning (Bourdieu, 1986; Coleman, 1988; Portes, 1998; Putnam, 2000; Rothstein, 2003). One of the most important theoretical contributions was the development of the concept of the radius of trust, which shifted the focus from measuring overall levels of general trust to assessing how far trust extends from familiar individuals to socially distant groups (Delhey et al., 2011 (Delhey et al., , 2014;; Delhey & Welzel, 2012; Freitag & Traunmüller, 2009; Fukuyama, 1995; Realo et al., 2008; Reeskens, 2013; van Hoorn, 2014). However, the main instrument for measuring general trust, SIGT, asks about trusting "most people," not about the extent of the trust radius. To overcome this problem, Welzel and other VWS researchers (Delhey et al., 2011 (Delhey et al., , 2014;; Delhey & Welzel, 2012) supplemented SIGT with items assessing trust in specific categories of people and, based on their analyses, proposed a solution to the radius-of-trust problem. Their proposal can be summarized in a series of theoretical statements: (a) trust is best measured by the maximal range of its radius; (b) there are two independent forms of trust, one of which-outgroup trust-is a genuine form of generalized trust; (c) "most people" primarily refers to absolute strangers, people never met before; (d) human development growth is always accompanied by an increase in trust; and (e) the radius of trust varies across cultures, but its magnitude serves as a necessary basis for human development.

The analyses reported in this study do not support the view that the "most people" question primarily captures the radius of trust, defined as how far trust extends across social distance.

Although SIGT indicators showed slightly higher loadings on the Outgroup Trust factor than on the Ingroup Trust factor, they loaded significantly on both. Therefore, it would be inaccurate to conclude that "most people" in SIGT refers exclusively to outgroup members. The distinction between ingroup and outgroup trust is also blurred, as trust in people personally known to the respondent showed substantial loadings on both factors. Thus, "most people" in SIGT appears to occupy a position at the boundary between ingroup and outgroup, leaning somewhat toward the outgroup side.

So, who do people trust when they say they trust "most people"? On average, respondents across countries and territories do not seem to interpret "most people" as referring to just anyone, including strangers from distant ethnic and religious groups. Instead, they tend to interpret it as referring to a typical stranger-someone they do not know personally but are likely to encounter in everyday life. In this sense, "most people" does not extend to individuals beyond one's usual radius of trust. Since encounters with very distant others-people with markedly different ethnic backgrounds or religious beliefs-may be relatively rare in everyday life, at least in many contexts, it is plausible that when thinking of "most people", respondents primarily have in mind the unfamiliar people they encounter in traffic, in service settings, or in shops.

In many ways, this interpretation corresponds to what Milgram (1970 Milgram ( , 1972) ) called "familiar strangers": people whom one sees or observes regularly but with whom one does not interact, except when strictly necessary. Repeated encounters of this kind may foster a sense of shared event-or place-based identity, and through routinized encounters, support moral obligations, unspoken norms, mutual understanding, and reciprocated trust (Zahnow & Corcoran, 2025). In this sense, people may be inclined to extend trust to those who occupy an intermediate position in their social world: neither personally known individuals nor entirely distant others, but familiar strangers whom they recognize through repeated encounters. This kind of general trust may help society and the economy function effectively, rather than relying on how much respondents say they trust complete strangers from other countries, cultures, or religions.

Trust as a Constant-Size Vector

A key contribution of this study is the identification of a clear and systematic pattern in trust judgments. Every assessment involves two forms of trust-ingroup and outgroup-that operate under a principle of reciprocal balance. As one increases, the other decreases in such a way that the sum of their squared values remains constant. Geometrically, this relationship can be represented as a vector of constant length, whose direction reflects the balance between ingroup and outgroup trust.

The proposed model substantially improves on previous explanations based on a linear relationship, which yielded a correlation of approximately r = .50 and accounted for about 25% of the variance. In contrast, the constant-length vector model accounts for 98% of the variance across hundreds of thousands of responses from 88 countries and territories.

We do not yet have a clear explanation for why trust behaves as a vector of constant length, nor do we fully understand the mechanism underlying this constancy. An analogy can be drawn from physics: the power of a time-varying signal is defined as the square of its amplitude, which represents the energy transmitted. Similarly, the squares of the ingroup and outgroup trust components may reflect a constant "trust energy." Across nearly a hundred countries and territories, the overall level of trust remains essentially unchanged, whether directed toward a close family member or a very distant stranger. Only the proportion between the two components varies, while the constant sum of squares is preserved. Trust does not disappear when directed at strangers; rather, one component replaces the other in a precise balance. Thus, it seems universal to measure trust on a scale from family members at one end to a total stranger at the other, so that the total energy of trust remains unchanged.

A Nonlinear Relationship Between General Trust and Human Development

As noted above, a country's economic prosperity and level of human development are closely associated with its overall level of general trust (Bergh & Bjørnskov, 2011; Bjørnskov, 2012; Bjørnskov & Méon, 2015; Makrychoriti et al., 2022; Özcan & Bjørnskov, 2011; Paldam, 2009 Paldam, , 2011)). The concept of the radius of trust suggests general trust may extend beyond familiar individuals to encompass increasingly distant social groups, including outgroups. When examining the three trust indicators (SIGT, TOUT, and TIN), our analysis showed that SIGT was a substantially stronger predictor of HDI than the other two measures, even though its reference to "most people" may primarily capture trust in "familiar strangers." This finding should be considered alongside research suggesting that high levels of ethnic, cultural, and religious diversity may weaken social solidarity and social capital, potentially reducing cooperation, limiting friendship networks, and undermining trust (Dinesen & Sønderskov, 2015; Laurence, 2009; Le, 2013; Nannestad, 2008; Portes, 1998). One possible interpretation, consistent with Putnam's (2007) discussion of diversity and social capital, is that respondents may be less inclined to extend the general trust measured by SIGT to more distant outgroups when they perceive these groups as threatening existing social ties and solidarity.

The relationship between SIGT and HDI is generally assumed to be linear (Chan et al., 2017; Nannestad, 2008; Paldam, 2007 Paldam, , 2011)). Our analysis, however, revealed a J-shaped relationship between SIGT and HDI2021. In countries and territories below the very high human development category (HDI < 0.80), the relationship was virtually flat, indicating little association between the two variables. Above this threshold (HDI ≥ 0.80)-which may correspond to the point of the Great Transition as proposed by Paldam (2011)-SIGT increased sharply with HDI. This pattern suggests that the relationship between trust in familiar strangers and human development varies with a country's level of development. In our data, higher levels of general trust were associated with higher levels of human development, primarily among countries and territories that had achieved very high levels of human development in terms of health, education, and standard of living. The direction of this relationship, however, remains unclear.

As Fukuyama (1995) argues, trust may be central for economic and social development, not the other way around.

More broadly, countries with very high levels of human development often perform well on indicators of governance and control of corruption (Holmberg et al., 2009) and on measures of liberal democracy (Spaiser et al., 2014) which is often considered a cornerstone for human development. These factors have also been linked to general trust (e.g., Uslaner, 2013).

However, as Norris (2022) suggests, these relationships may depend on the political context, being stronger in open societies than in closed societies where freedom of expression and access to alternative sources of information are restricted. General trust, often regarded as desirable or even as a social good in high-trust, high-HDI Western societies (Holmberg & Rothstein, 2020), may be less beneficial or even counterproductive in low-trust, low-HDI societies (Yamagishi et al., 1999). Future research should investigate the factors associated with general trust in countries and territories that have not yet reached the very high HDI category.

Interestingly, our results also revealed a curvilinear relationship between TOUT and HDI2021: outgroup trust was relatively high in countries and territories with both low and very high levels of human development, whereas it was lowest in those with medium to high levels of human development. In contrast, the relationship between TIN and HDI2021 was comparatively weak.

Strengths, Limitations, and Recommendations

The biggest strength-and at the same time the main limitation-of our study lies in the data used for the analyses. The IVS , which combines the WVS and EVS, is likely the world's most comprehensive database of values and trust attitudes. One of its greatest advantages is that it relies on representative samples and should therefore reflect entire national populations rather than specific segments. However, despite its extensive coverage of countries and territories worldwide, potential sampling bias should still be considered, as the survey may overrepresent more developed countries.

Another limitation concerns the group-specific trust items included in the WVS since Wave 5 (Delhey et al., 2011; Delhey & Welzel, 2012; Haerpfer et al., 2022; Inglehart et al., 2022). Our analysis shows that SIGT measures general trust, specifically when this trust does not extend to very distant outgroups with whom respondents are unlikely to interact in their daily lives. In this regard, creating new trust items referring to specific groups of people was undoubtedly the right approach. However, one important factor that has often been overlooked is the ethnic, religious, and cultural diversity within each country. When evaluating trust in individuals from different ethnicities and cultures, it is important to consider the levels of ethnic, cultural, and linguistic diversity within a country (Bjørnskov, 2008). The likelihood of encountering people from various ethnic groups can vary significantly from one nation to another. In countries with higher cultural and linguistic diversity, you are more likely to meet individuals who are distinctly different from you. Trusting individuals from different religious and ethnic backgrounds often depends on personal experiences with them in everyday life, leading to a different radius of trust when asked about trust in "most people."

Our findings offer guidance for further research and recommendations for social survey designers. Asking respondents about trust in specific groups, introduced in Wave 5 of the WVS, was a logical attempt to measure the radius of trust. The unexpected finding, however, was that the key factor was not trust in very distant and completely unknown people, but rather trust in familiar strangers. Given the apparent importance of the distinction between strangers whom respondents may encounter in everyday life and those they have never met or are unlikely to ever meet, future surveys could ask respondents about their trust in strangers with varying degrees of familiarity.

Conclusions

To examine whether "most people" in the SIGT encompasses the widest possible radius of trust, extending to complete strangers and people of other nationalities and religions, previous studies have included questions assessing trust in more distant outgroups (Delhey et al., 2011 (Delhey et al., , 2014)). Our analyses suggest that trust is a more complex construct, whose invariant property across cultures is a fixed-length vector comprising the squares of its two components: ingroup and outgroup trust. Moreover, higher levels of general trust are not accompanied by a substantial expansion of the radius of trust to encompass very remote outgroups. Instead, individuals appear to interpret "most people" as referring to "familial strangers." (Milgram, 1970 (Milgram, , 1972)-people they do not know personally but are likely to encounter in everyday life. It is trust in these familiar strangers, rather than in more distant outgroups, that is most strongly associated with the HDI. This association, however, becomes pronounced only at very high levels of human development.
