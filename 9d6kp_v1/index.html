Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

2. Definitions and timing

Video watch duration estimation: For each video, we have the participant’s start time of viewing but not a stop time, so watch duration must be inferred. We first construct gaps for each video, which is the time elapsed between when a participant starts watching one video and when they start the next. Because a gap can span time spent off the app, we adjust it based on session context (a session being a continuous block of active in-app usage): if the next video falls within the same session, the gap is the raw time between events; if the session ends before the next video starts, the gap is capped at the session’s own end time, excluding the off-app interval; if no session covering the event exists to verify either case, the raw gap is retained but flagged as unverified; and if there is no next event at all recorded for that participant, the gap is left unbounded.

Then, we cross-check the gap with the video length. Where the video’s own length is known (from the downloaded file), watch duration is defined as the shorter of the video’s length and the session-aware gap. If the gap is shorter, it means the participant navigated away before the video finished, so the gap itself is the true watch time; if the gap is longer than the video’s length (including an unbounded gap), there was enough time for the video to have played out fully, so we assume it did and count the full video length.

Where the video’s own length is unknown, there is no independent value to check the gap against, so the gap itself must serve as the watch-time estimate. We accept it only after a trust check, applied in decreasing order of confidence: (1) if the following event is confirmed within the same session, the participant was continuously active in the app throughout, so the raw gap is used directly; (2) failing that, if a session log is available and shows the session ended before the next video started, only the time up to that session’s recorded end is used, since that is the portion known to reflect active viewing; (3) failing that, the raw gap is accepted only if it does not exceed the participant’s own median duration across their trusted videos, defined as videos with a known length whose next event was also confirmed within the same session, as a plausibility check in the absence of any session data; (4) if none of these conditions hold, including the case of no following event at all, we substitute a random draw from that same trusted distribution (the participant’s own length-known, session-confirmed videos), rather than assuming the video was watched in full or leaving the duration unbounded.

Exposure calculation: Total exposure per day is defined as the sum of watch durations (in seconds) across all videos classified as containing at least one beauty filter or a beauty-related content diversification label for that day. This sum is restricted to videos watched between 4:00am and the moment of the end-of-day assessment on that day.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. Abstract

Experimental studies show that viewing idealised bodies on social media can lower body satisfaction, but whether this extends to the content adolescents actually encounter is unknown, because studies of everyday exposure have relied on self-report rather than on what was actually viewed. In an observational study, we combined TikTok data donation with a 14-day ecological momentary assessment in 66 female adolescents aged 14-18. A locally run computer vision pipeline classified the visual content of 242,422 watched videos for thin and sexualised female bodies -coding the imagery itself rather than hashtags or captions -and metadata-based classifiers identified beauty-filter use and TikTok's own beauty-related content labels. Content meeting the body criterion made up under one minute of roughly 91 watched minutes per day. Across all three measures, daily exposure was not associated with end-of-day body satisfaction, within or between persons, nor was morning body satisfaction associated with subsequent exposure. Everyday exposure to appearance ideals may be too sparse and too stable from day to day for day-level designs to detect any effect of it.

Social influence matters more in adolescence than at almost any other stage of life. 1 Today, much of that influence is mediated through screens. Sensitivity to social influence is greatest in early to mid-adolescence, [2] [3] [4] [5] when young people feel a strong need to belong while still forming their identity and self-concept. 6, 7 What they absorb shapes how they see their own bodies: a healthy body image is associated with better psychological, emotional and social well-being, whereas negative body image is linked to low self-esteem, disordered eating and broader mental health difficulties. 8, 9 Adolescents encounter appearance-based norms constantly on social media -in the UK, nearly all adolescents report regular engagement with social media platforms, with usage now a routine component of daily life. 10, 11 TikTok is among the most heavily used platforms among adolescents. 10 Its short-video format delivers many separate items per session, and its main feed is chosen by a recommendation algorithm rather than by whom the user follows. 12, 13 Appearance-focused content now reaches millions of adolescents through algorithmically curated feeds: most 8-17-year-olds mainly scroll and watch rather than post, and much of what they see is selected for them rather than by them. 14 What adolescents encounter in these feeds has become a current policy question. In 2025, the European Commission's guidelines under the Digital Services Act recommended that platforms prevent minors' repeated exposure to "content promoting unrealistic beauty standards" and switch off by default filters associated with negative effects on body image; 15 in September 2026, the Commission went further and proposed the EU Kids Act, which would turn these recommendations into binding obligations and bar under-13s from social media altogether. 16 Australia's minimum age of 16 for social media use took effect in December 2025, 17 and the United Kingdom has announced equivalent legislation for 2027. 18 Yet these measures rest on a thin evidence base, as shown by a narrative review commissioned by the UK Department for Science, Innovation and Technology. 19 Much of this traces back to measurement: Until recently, researchers had no way to observe what adolescents actually see in their feeds and no means of coding appearance content in video at scale; consequently, most evidence comes from laboratory exposure to static images or from self-reported exposure to appearance-based content. Two developments make a different approach possible. Data donation, grounded in the right to data portability under the UK GDPR, 20 lets young people export and share their own platform data, including full watch histories, for research; 21 and computer vision -artificial-intelligence models capable of recognising and labelling what is shown in an image or video frame -models can now classify appearance content in video at scale. 22 The present study combines both: We link the TikTok videos adolescent girls actually watched, captured through data donation and coded for appearance content with computer vision, to their body satisfaction reported three times daily over two weeks.

Adolescence is the formative period for body image. 23, 24 Culturally transmitted beauty standards in the West have proven to be remarkably hegemonic: despite greater variety in model body types, the predominant 'thin ideal' for women has remained largely unchanged over the past 50 years. 25 Two established frameworks explain how exposure to such ideal bodies becomes body dissatisfaction, and both suggest the current media environment may intensify the process. The Tripartite Influence Model identifies peers, parents, and media as the primary sources of appearance norms, which act on body image through internalisation of the ideal and upward appearance comparison. [26] [27] [28] [29] Objectification Theory further holds that repeated exposure to sexually objectifying environments, including media, leads individuals to adopt an observer's perspective on their own bodies; this self-objectification manifests as habitual body surveillance and, in turn, body shame. 30 Internalisation of body ideals predicts body dissatisfaction across genders, but girls report more of it across countries and socioeconomic contexts. 31, 32 Social media use has been linked to higher body dissatisfaction, disordered eating symptoms, and self-objectification among adolescents and young adults. [33] [34] [35] [36] And exposure to idealised peer or celebrity content on Instagram and Facebook has been linked to increased appearancebased social comparison and negative mood. 37, 38 Yet at the population level, associations between aggregate social media use and adolescent well-being are typically small, heterogeneous across specifications, and inconsistent across individuals. [39] [40] [41] This apparent tension is informative rather than contradictory. Time-based measures treat all screen time as equivalent, collapsing ideal appearance content together with content of no appearance relevance whatsoever; if the active ingredient is the depiction or promotion of idealised appearance, an undifferentiated exposure measure will necessarily attenuate the effect it is intended to detect.

Ideal appearance content is no longer only depicted but manufactured at scale: platforms offer beauty filters that users can apply to their own videos, and AI has made these filters ever more naturalistic. Retouched images have been linked to lower state body satisfaction in adolescent girls. 42 Filtered, retouched and platform-labelled beauty content in short-form video is thus a further, increasingly prevalent channel for the same tripartite and objectification mechanisms. Therefore, progress depends on measuring what adolescents are shown, objectively examining what they view, and linking this to their body satisfaction. In the present study, sixty-six female adolescents donated their TikTok viewing histories and completed ecological momentary assessments (EMAs) three times a day for two weeks, including a daily body-satisfaction rating. Linking the two sources allowed us to characterise the appearance content adolescents consumed over the course of a day and examine whether days with more of it are days with lower body satisfaction.

We measure appearance-focused exposure in three ways, each computed as the daily time (in seconds) a participant spent watching TikTok videos that (a) depict at least one thin and sexualised female body, coded by our computer vision pipeline from slim body stature, minimal clothing, and posing of body or face; (b) are tagged by the platform as using a beauty filter; or (c) carry one of TikTok's beauty-related content labels. Measure (a) is derived from the visual video content; measures (b) and (c) are derived from video metadata . These three measures capture distinct aspects of ideal appearance content: what actually is depicted in a given video, how a creator has modified their own appearance, and how the platform itself categorises content. State body satisfaction assessed at the start of each day precedes the day's content exposure and end-of-day satisfaction follows it.

Results

Descriptive statistics of the sample

The 66 included female adolescents had a mean age of 16.71 years (SD = 1.03, range 14-18).

State body satisfaction, i.e. if they felt satisfied with the way their body looks, clustered in the lower-to-middle range of the 1-5 scale: at the mean of person means was 2.46 (SD = 0.89), with few participants reporting high satisfaction. Within-person variation was small by comparison: the mean day-to-day SD within a participant was 0.56 scale points, so about twothirds of the variance in evening body satisfaction lay between rather than within participants (descriptive ICC = .66), and 56% of participants never moved more than one scale point across the 14 days (Supplementary Fig. S2).

Participants were substantially engaged with TikTok during the study period: they used the platform on a median of 14 of the 14 study days (mean 12.8, range 1-14), viewing on average 517 videos (median 484) and 107 minutes of video (median 91) per active day. Donated watch histories covered all but 16 of the 924 participant-days. Engagement nonetheless varied between participants: 56 of the 66 (85%) used TikTok on 13 or 14 of the 14 study days, whereas 7 (11%) used it on fewer than 60% of the days.

Overall content exposure in the sample

Exposure to content meeting all criteria predefined for the study (visual: portrayal of thin and sexualised female bodies; metadata: video with a beauty filter and/or beauty-labelled video) constituted a small fraction of overall viewing. Across covered participant-days, daily exposure to thin and sexualised female bodies averaged 0.81 minutes (median 0.48, maximum 7.9) of an average 91.4 watched minutes per day, i.e. about 0.9% of watched time, and 15.5% of days (141 of 908) contained no such exposure at all; person-level means ranged from 0 to 3.0 minutes per day. Discussion

Sixty-six adolescent girls rated how satisfied they felt with their body three times per day for two weeks, and then donated those two weeks' TikTok viewing data, comprising roughly 242,000 videos. On an average day, the average adolescent girl watched 91 minutes of TikTok across roughly 500 videos, of which 0.8 minutes showed a thin and highly sexualised female body per our definition; beauty filters appeared in 1.7 minutes, and 12.5 minutes of video content carried one of TikTok's own beauty labels. Body satisfaction, meanwhile, was more a stable characteristic than a daily state. Girls differed considerably from one another in how satisfied they felt, but each girl varied little from day to day, and more than half never moved more than one point on the five-point scale in two weeks. Under these conditions, the smallest within-person effect that this design could have detected was approximately 0.06 scale points per minute of exposure. For this to be registered, a day with ten more minutes of such content than usual (before the evening or after the morning assessment, respectively) would have had to lower that evening's body satisfaction by roughly 0.6 points -close to one full step on the 5-point Likert scale -which almost never occurred. Furthermore, if highly sexualised ideal appearance content would function by shaping what a female adolescent comes to regard as normal or desirable, as proposed by tripartite-influence and internalisation theory, then its effect will not be evident as a difference between, for example, Tuesday and Wednesday. Rather, it would be evident in long-term differences in what girls have internalised from their feeds.

Moreover, the content we focus on here was narrowly defined: the visual criterion required a thin body in minimal or tight clothing, posing for the camera, whereas the experimental literature has often defined idealised content more broadly, for example as thinness alone. 37, 43, 44 The feeds our participants were actually served were far more heterogeneous in appearance content than our visual criterion could capture: content meeting it made up only 0.8 of roughly 91 watched minutes per day. Furthermore, experiments present images in isolation, whereas in daily life the same imagery is embedded in rapid, continuous scrolling amid much other content.

Several limitations merit consideration when interpreting this null result. Firstly, the design is observational, so it cannot establish or rule out a causal effect. Secondly, an association could have been masked by unmeasured influences, such as the events of the day or the company in which videos were watched. Bearing this in mind, the absence of a day-level association at this everyday dose does not contradict experimental evidence; rather, it suggests that laboratory exposure and contexts are not representative of daily-life exposure on social media and likely there is also co-use of other platforms (e.g., Instagram, Snapchat). Finally, the present study investigated 66 UK female adolescents over 14 days; this design did not allow us to detect small effect nor to investigate long-term, low-dose exposure. Thus, future research would benefit from investigating longer timescales in larger samples.

Our study implemented a novel design: social media data donation and a fully locally run computer vision pipeline -on-premises processing being an ethical requirement for material concerning minors -reconstructed 242,422 watched videos and approximately 5.6 million depicted person instances into per-event, time-stamped exposure, validated against blinded human review (Supplementary Section 3) and analysed under a preregistered plan with documented deviations, and complemented by two independently constructed, metadata-based classifiers of beauty-filter use and platform beauty labelling. This yields an unprecedented, directly measured account of what adolescent girls are 'speed consuming' in daily life, at a granularity self-report cannot approach, and reveals the composition of algorithmically curated feeds from three complementary angles: highly sexualised ideal appearance content under one percent of viewing time, sexually suggestive posing characterising only about 1.1% of classified person instances, and beauty-related platform labels attached to roughly 14% of all watched time.

In conclusion, this study is the first to measure what adolescent female adolescents actually see on TikTok and to relate it to how they feel about their bodies on a daily basis. Our findings show the difference between laboratory exposure and speed-consuming content in daily life.

The idealised content the field has studied in the laboratory makes up a sliver of everyday viewing, body satisfaction is close to a trait over two weeks, and on neither side is there enough day-to-day variation for a same-day effect to show, under any of three independent measures. While the causal effects of highly sexualised ideal appearance content on viewers' body image are unclear, our study indicates a potential method for studying them.

Methods

Study procedure

An overview of the study procedure is shown in Figure 2. After participant and parental consent was obtained, participants completed a baseline survey collecting demographics, mental health, body image, and social media use. The baseline assessment included socio-demographic factors (age, gender, sexual orientation, nationality, socio-economic status), the Strengths and Difficulties Questionnaire (SDQ) 45 , the Online and Offline Social Sensitivity Scale (O2S3) 46 , and the Intolerance of Uncertainty Scale for Children (IUS-C) 47 . Participants also received a detailed introduction to the study procedure.

Participants then completed a 14-day ecological momentary assessment (EMA) protocol capturing daily fluctuations in body satisfaction, emotions, and related psychosocial variables.

Assessments were administered three times per day (morning, afternoon, evening) via m-Path.

EMA invitations were scheduled around each participant's reported availability at intake: the morning EMA within the two-hour window before their school start time, the afternoon EMA within the two-hour window after school ended, and the evening EMA within the two-hour window before their reported bedtime. After an invitation was sent, participants had three hours to complete the survey. The morning and evening assessments are classified as "start-of-day" and "end-of-day" respectively.

At the end of the EMA period, participants requested and downloaded their own TikTok data packages via their respective accounts. Once their data donation packages were available, participants received a unique, personalised link to a secure data donation interface powered by Port, an open-source tool designed to facilitate privacy-preserving data donation. Through this interface, participants could select and process their downloaded data locally on their devices without transferring the complete raw files to the researchers. Port 48 then extracted predefined, research-relevant information from the participants' watch histories, including time-stamped records of the videos they had viewed, complete with unique identifiers.

Participants could review their processed data before deciding whether to donate it, ensuring they retained control over the information shared. Only the extracted data was securely transferred to the research team for subsequent analysis.

Participants

The present study uses data collected from N = 358 adolescents aged 13-18 years recruited from six schools in Cambridge, Birmingham, London, Liverpool, and Manchester. 21 A subsample of 119 participants also provided TikTok data donation files and participated in the EMA component of the study, which involved completing three assessments per day over a two-week period in 2024.

Per the preregistered unit-of-analysis criteria, participants were included if they (a) identified as female, (b) completed at least three valid EMA prompts assessing body satisfaction and (c) provided TikTok donation data with sufficient metadata to derive exposure variables. Because every EMA prompt (morning, afternoon, and evening) contained the state body satisfaction item, criterion (b) was implemented literally as at least three answered EMA prompts of any type (this and other resolutions of ambiguities in the preregistrations are listed in Supplementary Section 2, Table S5). Sixty-eight female participants met all three criteria.

Two participants were subsequently excluded because the TikTok data they donated covered a period entirely preceding their participation in the EMA study and therefore did not overlap with the EMA assessment window, precluding the derivation of time-varying exposure measures for any study day. The final analytic sample comprised N = 66 female adolescents, applied identically across all three exposure operationalisations reported below.

Power analysis

An a priori power analysis was conducted for the primary confirmatory hypothesis (H1), the within-person (Level 1) association between daily exposure to thin and sexualised female bodies on TikTok (in seconds) and subsequent state body satisfaction. Given the hierarchical structure of the data, with repeated end-of-day EMA observations (Level 1) nested within participants (Level 2), a multilevel modelling approach that explicitly accounts for this dependency was required. Based on the information available at the preregistration stage, an analytic sample of approximately 68 female participants was anticipated, each contributing on average 10 valid end-of-day EMA assessments across the two-week study period.

To inform the expected effect size, we drew on the experimental literature on exposure to appearance-ideal content. In a meta-analysis of experimental studies, de Valle et al. 44 found that on the between-person level viewing appearance-ideal images on social media had an immediate, moderate negative effect on body image on the between person level relative to both non-appearance control content (Hedges' g = -0.61) and other appearance-related images (Hedges' g = -0.68). Following Arend and Schäfer, 49 moderate Level 1 direct effect was treated as corresponding to approximately 9% explained outcome variance at Level 1. Consistent with current best practice for power analysis in intensive longitudinal designs, power considerations were informed by the Monte Carlo simulation study of Arend and Schäfer 49 for two-level models. Based on the anticipated sample size and number of repeated assessments, the planned study was expected to be adequately powered to detect a moderate within-person association between daily appearance content exposure and state body satisfaction at the subsequent EMA assessment. No corresponding a priori power analysis was preregistered for the beauty-filter or beauty-label extensions.

Measures

State body satisfaction.

State body satisfaction was assessed with a single item administered three times per day over the 14-day EMA period and treated as continuous. Participants were instructed: "Carefully read the following statements and select the option that best reflects the way you have felt since the last notification." The item, adapted from the State Self-Esteem Scale, 50 read "I felt satisfied with the way my body looks" and was answered on a 5-point scale (1 = not at all,2 = a little bit,3 = somewhat,4 = very much,5 = extremely).

Daily exposure time.

Daily exposure was defined, per the preregistration, as the time (in seconds) spent watching TikTok videos containing at least one thin and sexualised female body, derived from participants' donated watch histories (Supplementary Section 5; the source of each viewing event's watch-duration estimate is tabulated in Table S11) and the content classification pipeline (Supplementary Section 3). A participant's exposure on a given day is the summed presentation duration of viewed 1-second stills classified as containing at least one qualifying body. Two further, non-preregistered daily exposure measures were derived using the identical watch-duration procedure (Supplementary Section 5) but different content classifiers (Methods, Beauty filter content classification and Beauty label content classification): daily time spent watching videos using at least one beauty filter, and daily time spent watching videos carrying at least one TikTok beauty-related content label. To account for late bedtimes, a study "day" was defined as 04:00 on a calendar day until 03:59 the following day, as preregistered; this definition was applied identically across all three exposure measures.

Treatment of missing data

Per the preregistration, three types of missing data were expected for TikTok content exposure (all hypotheses): (1) if participants did not use TikTok on a given day, they were coded as having had no content exposure; (2) if participants did use TikTok on a given day but some viewed videos were unavailable (e.g., deleted), each missed 1-second video still was assigned the average probability of containing a thin and sexualised body among the participant's other available video stills on that day; and (3) if participants did use TikTok on a given day but no videos were available, each missed video was assigned the average probability among the participant's available videos across the whole 14-day study period. This content-probability substitution procedure is deliberately distinguished terminologically from the multiple imputation of body-satisfaction scores described below, since the two address different variables via different mechanisms; full implementation details are given in Supplementary Section 5.

An additional, unanticipated type of missing data occurred which is only considered in the beauty filter and beauty content preregistration: partially missing TikTok data for participants whose donation period did not fully overlap with the EMA assessment period. In total, 16 of the 924 participant-days (1.7%) fell outside a participant's donation coverage. No participants were excluded on this basis; their available, overlapping days were retained and contribute to the analysis as usual, while non-overlapping days necessarily contain no derivable exposure data. Of 66 participants across the 14-day study period (924 possible participant-days), 754 participant-days (81.6%) had an evening EMA response recorded; on the remaining 170 participant-days (18.4%) the evening EMA was not answered, and end-of-day body satisfaction was multiply imputed as described below.

For state body satisfaction, two further types of missing data were expected: (1) participants did not fill in the EMA at the start/end of a given day; (2) participants filled in the EMA but skipped the state body satisfaction item. The preregistration specified pan as the imputation engine, a burn-in of 6,000 iterations, and m = 30 imputed datasets drawn 200 iterations apart. Two documented deviations from these settings were required. Analytical approach

The data have a hierarchical structure, with EMA observations and exposure time (Level 1) nested within individuals (Level 2). All models were computed with the nlme R package (linear mixed-effects models). To separate within-from between-person variation, person-mean centering was used. Each model included a random intercept and a random slope for the withinperson predictor -accounting for non-independence of repeated observations and for individual differences in the within-person association -together with a first-order autoregressive (AR(1)) residual correlation structure over study days within participants.

Beauty filter content classification

A video is classified as "beauty-filtered" if its metadata indicates the use of at least one effect from the reference list below. On TikTok, a sticker effect is an augmented reality effect that users can apply to videos to modify or augment their appearance or surroundings. Beauty filters are defined as sticker effects that alter a user's facial or body appearance to conform more closely to idealised beauty standards, including changes such as skin smoothing, facial reshaping, makeup application, eye enlargement, lip enhancement, hair modification, or other cosmetic enhancements. This definition is consistent with prior experimental work examining beautifying and slimming filters. 53 The beauty-filter reference list was built in two steps: candidate effects were identified from appearance-related keywords in their names (e.g., "makeup", "smooth", "lashes") and from a manual scan of effect names for appearance-altering effects the keywords missed (e.g., "prettiest"), giving the preregistered candidate list; every candidate was then reviewed by name, with unclear names looked up on the TikTok website, and effects that do something other than beautify (e.g., "Ugly Face") were excluded. The final list of 243 effects, the keywords and the exclusions are given in Supplementary Section 7 (Table S12).

Beauty label content classification.

As per our preregistration, a video was classified as beauty-related if it had one or more of TikTok's official content diversification labels associated with beauty content. Platformgenerated labels are assigned by TikTok and are presumed to be derived from multiple features of the video, such as its transcript, caption, and visual content. Each video could receive multiple labels. To identify the set of beauty-related labels, we used snowball sampling beginning with three seed labels: "Beauty," "Beauty and Style," and "Beauty and Care." We then identified all labels that co-occurred with these seeds, yielding three additional unique labels: "Outfit," "Nail Art," and "Hair." Accordingly, we defined beauty-related content as videos containing any of these six labels, which collectively accounted for 29,989 of 242,422 videos watched by eligible participants, or approximately 12.4%.
