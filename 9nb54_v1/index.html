Reporting p values imprecisely (e.g., p < .05) reduces transparency, reproducibility, and re-use (e.g., in p value meta-analyses). Best practice is to report exact p-values with three decimal places (e.g., p = .032) unless p values are smaller than 0.001, in which case you can use p < .001.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (e.g., “decreased at the p < .05 significance threshold”).

To check Non-Significant P Value Check

What we found

We found 9 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

For each block, participants provided arousal-valence (A-V) ratings at three time points: before the arithmetic task, after the arithmetic task, and after the silence-or music-listening period.

Participants were instructed to provide their answers using the arrow keys “Top”, “Bottom”, “Left”, “Right” instead of typing their answers.

To increase stress and mitigate potential habituation effects across blocks, several strategies were used: (1) Adaptive difficulty: the task increased in difficulty when participants were performing well, to guarantee all participants achieved a similar failure rate, (2) Social comparative stress: feedback was shown to participants on screen, telling them that they are performing poorly compared to their peers regardless of actual performance, (3) Incorrect response stress: participants received real-time feedback when an incorrect answer is given, in the form of a red ‘X’ and a buzzer sound, and (4) Financial incentive: participants are informed that their performance in the task will affect the financial compensation, such that incorrect answer lowers their financial reward.

Participants completed the Depression, Anxiety and Stress Scale 21 (DASS-21) [61] as a measure of their trait-level depression, anxiety, and stress.

Lastly, participants completed questions related to musical taste and experience at the end of the experimental block (see Supplementary Table S1 online for further details of the questionnaires).

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). Abstract

Recent advances in generative music systems offer new opportunities for supporting stress regulation in individuals experiencing psychological distress. However, the degree to which music should reflect the desired relaxation state, and the neural dynamics underlying music-based regulation, are not well understood. The present study investigated the electrophysiological correlates of stress reduction using generated music that expresses different degrees of relaxation. Twenty-seven adults (10M, age: 31.33 ± 9.65 years) with elevated anxiety (measured by the Depression, Anxiety, Stress Scale-21) completed three blocks of a stress-inducing arithmetic task, each followed by three minutes of silence, Low-relaxation music (Low-RM), or High-relaxation music (High-RM). Low-RM anchored musical characteristics near participants' post-stress affect ratings; High-RM shifted these parameters 30% toward positive-valence and low-arousal. Following stress induction, subjective valence increased in both music conditions but arousal decreased only in High-RM and silence. Relative to silence, frontal delta suppression was observed in both music conditions, with additional parietal delta suppression in Low-RM. Exploratory analyses identified parieto-occipital alpha suppression during High-RM. Across conditions, greater frontal delta reduction was associated with lower Anxiety scores. These findings provide new insights for the efficacy of affective generated music in modulating neurophysiological processes implicated in stress regulation for individuals with elevated anxiety.

1. Introduction

Mental health conditions constitute a substantial and growing global health burden. According to the World Health Organization (WHO), approximately one in seven people globally live with a mental disorder, with anxiety and depressive disorders representing the most prevalent conditions [1]. Anxiety and depression frequently co-occur, with comorbidity reported in up to 75% of cases [2], although anxiety often precedes depression or constitutes the primary condition [3].

Anxiety is characterized by heightened vigilance, increased attentional bias toward threat [4] [5] [6], and persistent difficulties in down-regulating negative affect [7]. These regulatory difficulties in individuals with elevated anxiety are not merely behavioral, but are accompanied by measurable disruptions in physiological markers such as heart rate variability [8, 9] and neural oscillatory dynamics [10] [11] [12]. In particular, studies have commonly reported increased frontal delta [13], disrupted frontal alpha asymmetry during resting-state electroencephalography (EEG) -with left frontal hypoactivation observed in depressed patients [14] [15] [16] [17] [18] [19] [20], and altered lateralization of parietotemporal alpha activity to be associated with elevated anxiety levels [19] and depression [15].

Consequently, these behavioral attributes and physiological dysfunction in individuals with elevated anxiety may increase their susceptibility to the effects of stressors. Chronic stress further compounds these difficulties, driving adverse immune and physiological outcomes including dysregulation of the hypothalamic-pituitary-adrenal (HPA) axis, increased inflammatory markers, and reduced resistance to illness [21] [22] [23] [24]. Despite the substantial societal burden and debilitating consequences imposed by these mental health conditions, access to effective and scalable interventions remains limited, and the gap between the prevalence of psychological distress and treatment uptake continues to widen [25]. It is therefore a pressing public health priority to develop accessible strategies to support stress recovery in individuals with psychological distress.

In this regard, music-based intervention presents as a promising non-pharmacological solution which has been shown to reduce stress [26] [27] [28] and anxiety [29] in the general population, as well as those with elevated anxiety [30, 31]. The efficacy of using music for reducing stress or anxiety is often attributed to the ability of relaxing music to reduce cortisol levels [32], modulate the HPA axis activity [33] and patterns of brain activity that are dysregulated in individuals with clinical depression [34] and non-clinical anxiety [35].

Furthermore, music listening engages neural networks that substantially overlap with those dysregulated in these affective disorders. Music listening recruits distributed brain networks encompassing auditory processing, emotional regulation, memory systems, and reward pathways [36, 37], with the prefrontal cortex-hippocampus-amygdala circuit playing a central role in modulating stress-related emotions, including anxiety and fear [38]. Studies have found that music listening produces changes in oscillatory power across frontal regions across delta (1-4 Hz), theta (4-8 Hz), alpha (8-13 Hz), and beta (13-30 Hz) frequency bands [39] [40] [41]. Beyond frontal regions, studies have increasingly reported additional involvements of central, temporal, and parietal regions [41] [42] [43], which could be a result of music listening involving cognitive processes such as attention, working memory, and predictive processing [44, 45].

Recovery from a stressor is generally more effective when participants listened to music which is low in arousal and positive in valence [46]. However, the majority of music-based stress research has treated music as a homogeneous intervention, with relatively little attention paid to the critical question of how relaxing the music should be relative to the listener's current emotional state. This question is addressed by the iso principle, a foundational concept in music therapy. Originating in 1940s, the iso principle involves initially matching the music to the listener's current affective state and then gradually shifting toward a desired emotional state can be more effective for mood regulation as compared to listening to music that outright targets the desired state [47]. Recent evidence suggests that meeting listeners "where they are" emotionally before attempting to shift their mood is an important component of successful mood modulation [48], and that affectsequencing can be effectively applied through systematically designed musical playlists [49, 50]. This is further supported by the mood congruence hypothesis [51], which holds that listeners engage more readily and deeply with music that matches their current affective state [52]. Beyond mood congruence, listening to music of a preferred genre has also shown to be more effective in inducing targeted emotions [53].

However, findings from the relatively fewer studies testing the iso principle in non-clinical contexts have been less consistent. For instance, a recent study [54] found that among healthy young adults, there was no difference in anxiety reduction between music playlists adopting the iso principle and those using the compensatory principle (i.e., the proposition that music with the desired affective qualities, contrasting with one's current feelings, will be effective in modulating emotion; [55]). Further, individual factors including personality [56], and the type of mood regulatory strategies an individual uses [57], have been shown to influence the efficacy of musicbased emotion regulation. One plausible explanation for these inconsistencies is that naturalistic playlist-based paradigms cannot precisely control the acoustic and affective properties of stimuli. As such, the degree to which music actually diverges from a listener's current emotional state may likely be confounded with other non-musical variables, making it difficult to isolate the contribution of affective matching per se. This constraint can now be addressed through recent advances in generative music systems, which enable the production of music anchored to prespecified levels of valence and arousal in real-time [58]. In particular, AffectMachine-Classical [59] and AffectMachine-Pop [60] are generative music systems capable of creating pleasant, unfamiliar instrumental music where one can explicitly manipulate the level of arousal and valence to test a hypothesis of interest.

The present study thus aimed to investigate the electrophysiological correlates of stress recovery using generated affective music which differed in the degree of relaxation content in a sample of adults with elevated anxiety. Rather than strictly implementing the iso principle (i.e., designing the music to move gradually towards a state of relaxation), we compared the impact of music with lower degree of relaxation (Low-Relaxation Music; Low-RM) versus a higher degree of relaxation (High-Relaxation Music; High-RM) in the valence-arousal space. This design was chosen based on two reasons: (1) to enable clear behavioral and neural comparisons between these affective states, and (2) to overcome the difficulty of distinguishing continuous neural changes underlying the affective trajectory change inherent in iso-principle designs. In the Low-RM condition, musical parameters were anchored to the participant's self-reported post-stress valence and arousal levels, whereas these parameters were shifted toward a calmer, more positive affective target in the High-RM. EEG was recorded continuously as participants completed three blocks of a stress-inducing mental arithmetic task, each followed by a three-minute recovery period of silence, Low-RM, or High-RM. Participants also completed behavioral questionnaires measuring personality, music-based regulation strategies, music preferences and experience. By combining behavioral and electrophysiological measures, this study aims to provide a more holistic understanding of how the degree of relaxation embedded in generative music shapes the neural and affective processes involved in recovering from stress in a sample of individuals with elevated anxiety, after accounting for the listener's choice of preferred music genre.

2.1. Participants

Participants were recruited via advertisements placed around Nanyang Technological University (NTU), Singapore, and through social media. The study was advertised as an investigation of the neural correlates of mathematics and music to avoid priming participants to the stress-regulation aim. Ethical approval was granted by NTU Institutional Review Board (No. IRB-2024-434), and all methods were performed in accordance with the relevant institutional guidelines and regulations.

Individuals were excluded if they self-reported having any diagnosed neurological conditions, currently using psychotropic medication, or have uncorrected hearing or vision impairment. Recruitment targeted individuals scoring in the elevated range on the Stress subscale of the Depression, Anxiety, Stress Scale-21 [61], and was subsequently broadened to include individuals with elevated scores on any of the DASS-21 subscales due to initial recruitment constraints.

A total of 39 adults (14M, age range: 21-54 years, M = 32.03, SD = 10.97) were recruited, and informed consent was obtained from all participants prior to the start of experiment. Following exclusion for technical issues (n = 6), missing data (n = 1) and poor EEG data quality (n = 4), 28 participants remained. As all but one participant scored Severe-to-Extremely-Severe on the Anxiety subscale, the one participant scoring in the Moderate range was excluded in the final analyses to establish sample homogeneity with respect to anxiety severity. This exclusion was made on the basis of inspection of distribution of DASS-21 scores alone, prior to any EEG or behavioral analyses. The final sample for analyses thus comprised 27 participants (10M, age range: 21-53 years, M = 31.33, SD = 9.65).

2.2. Procedure

The experiment was programmed and presented with PsychoPy3 (v2024.2.3) [62]. Participants first completed questionnaires related to music-based mood regulation; personality; depression, anxiety, and stress; music preferences and experience (see Section 2.3.3 for more details). Next, they were fitted with the EEG cap. Participants sat in a dimly lit room and were presented with verbal as well as written instructions on the computer screen for the experiment. In particular, they were first introduced to the definitions of valence and arousal, and the experimenter ensured that participants understood these terms correctly. The audio stimuli were played through loudspeakers (AudioEngine HD3), and participants were asked to adjust the volume to a comfortable level and maintain that volume for the duration of the experiment. Participants completed three blocks of a stress-inducing mental arithmetic task, which is each followed by a 3-minute recovery period of silence, Low-relaxation music (Low-RM), or Highrelaxation music (High-RM). In the Low-RM condition, musical parameters were anchored to the participant's self-reported post-stress valence and arousal levels, whereas these parameters were shifted 30% toward positive-valence and low-arousal relative to the Low-RM in the High-RM condition. The music was generated by either AffectMachine-Classical [59] or AffectMachine-Pop [60], depending on their indication for pop or classical music.

For each block, participants provided arousal-valence (A-V) ratings at three time points: before the arithmetic task, after the arithmetic task, and after the silence-or music-listening period. Both arousal and valence were rated on a scale of 0 (arousal: Less Energy; valence: Less Positive) to 10 (arousal: More Energy; valence: More Positive), with 5 being neutral. In addition, discrete emotions were measured after the music listening conditions using the Geneva Music-Induced Affect Checklist (GEMIAC) [63]. It consists of 14 terms: wonder, moved, enchanted, inspired, energetic, joyful, powerful, tender, relaxed, melancholy, sentimental, indifferent, tense, and agitated. Each item was rated on a scale of 1 (not at all) to 5 (very much). After the last block, participants answered questions related to the arithmetic task and their mathematical abilities with a continuous slider from 0 (not at all) to 100 (agree completely): "I found the questions easy", "I found the task stressful", "I wish I had more time to answer the questions", "In general I am good at maths", "I am happy with my performance in the task" (Fig. 1). music listening conditions are counterbalanced. 2.3.1. Stress induction task

In this study, we developed an Adaptive Mental Arithmetic Task (AMAT), modified from the repeated Montreal Imaging Stress Test (rMIST) [64] to induce stress. While the rMIST represents an advance over single-session stress paradigms in its ability to elicit consistent selfreported and physiological reactivity across repeated exposures, this approach is often limited by constraints in intra-session stimulus novelty. This constraint may attenuate the experienced stress over time, thereby producing a habituation effect. Furthermore, the original MIST incorporated a failure algorithm that adjusted time limits based on individual performance during a pre-task training phase. This pre-specification of difficulty may limit the extent to which the task remains individually challenging and stressful throughout, particularly for participants whose arithmetic performance deviates substantially from the group mean. The AMAT was therefore designed to address these limitations by introducing trial-level adaptive difficulty and greater stimulus variability across blocks.

The AMAT was developed as a computer-based arithmetic task that dynamically adjusted task difficulty based on the individual's performance throughout the duration of the task. This was implemented by (1) increasing the value of numbers, (2) using division and multiplication rather than addition and subtraction, or (3) combining multiple operations in an equation. Participants were instructed to provide their answers using the arrow keys "Top", "Bottom", "Left", "Right" instead of typing their answers. This was designed to minimize motion artefact in the EEG recording.

To increase stress and mitigate potential habituation effects across blocks, several strategies were used: (1) Adaptive difficulty: the task increased in difficulty when participants were performing well, to guarantee all participants achieved a similar failure rate, (2) Social comparative stress: feedback was shown to participants on screen, telling them that they are performing poorly compared to their peers regardless of actual performance, (3) Incorrect response stress: participants received real-time feedback when an incorrect answer is given, in the form of a red 'X' and a buzzer sound, and (4) Financial incentive: participants are informed that their performance in the task will affect the financial compensation, such that incorrect answer lowers their financial reward. This was deception as all participants received the full SGD $100 in vouchers at the end of the study.

2.3.2. Music generation systems: AffectMachine

In this study, 13 participants listened to AffectMachine-Classical while 14 participants listened to AffectMachine-Pop, as informed by their musical preference. Both AffectMachine systems were developed in Python and generate music through rule-based compositional frameworks that manipulate musical features shown to influence emotional expression in music, such as harmonic, rhythmic, timbral, and loudness parameters. Each system was designed to follow the stylistic conventions of their respective genre (for more details, see [59, 60]). The systems accept a sequence of arousal-valence (A-V) coordinate pairs as input, each within the normalized range [0, 1].

The systems take A-V values of the self-reported ratings after the mental arithmetic task as the first value to generate music. Corresponding harmonic, rhythmic, and timbral parameters are then encoded in the form of a MIDI event stream as output. These musical parameters are updated in real time at each bar in accordance with the current A-V values. The resulting MIDI event stream is transmitted to Ableton digital audio workstation (DAW) over virtual MIDI buses, where it is rendered into audio (Fig. 2a). Both systems have been validated through listening studies, which demonstrated that listeners reliably perceived the generated music as expressing the intended target emotions [59, 60].

For both conditions, a machine learning approach was used to map the continuous EEG signal to A-V values in real-time, with the A-V values serving as input parameters for AffectMachine. Specifically, EEGNet [65] was deployed to generate output for arousal and valence separately every four seconds. EEGNet is a compact convolutional neural network developed for EEG-based brain-computer interfaces, using depthwise and separable convolutions to extract temporal and spatial features from EEG signals. It is robust across different task paradigms and can be trained with limited data [65].

The output of the A-V models were within a narrow range for both conditions: A-V values for the Low-relaxation music (Low-RM) condition were closer to the self-reported emotion ratings post-math task as compared to the High-relaxation music (High-RM) condition (Low-RM: Arousal = 2.27 ± 1.81, Valence = 2.60 ± 1.77; High-RM: Arousal = 3.79 ± 1.91 and Valence = 4.50 ± 2.47). Consequently, the music in the Low-RM condition comprised significantly different A-V values compared to the High-RM condition at p < .05 (Fig. 2b, c).

2.3.3. Questionnaires for individual differences

Participants completed the Depression, Anxiety and Stress Scale 21 (DASS-21) [61] as a measure of their trait-level depression, anxiety, and stress. Motivated by literature that suggests associations between mood regulation strategies and personality with music-based mood regulation [56, 57], participants also completed relevant validated questionnaires: Music-based mood regulation was measured by the Brief Music in Mood Regulation Scale (B-MMR) [66]; personality was measured by the Short form of the Big Five Inventory-2 (BFI-2-S) [67], which assesses the Big Five personality domains and 15 more specific facet traits. We limit the current analyses to the five domains, as it is recommended that facet-level traits can only be useful for examination in reasonably large samples (approximately ≥ 400 observations) [67]. Lastly, participants completed questions related to musical taste and experience at the end of the experimental block (see Supplementary Table S1 online for further details of the questionnaires).

2.4. EEG acquisition

EEG data were recorded using a 64-channel gel-based actiCAP (Brain Products, Gilching, Germany) arranged according to the extended 10-20 system. The sampling rate was set at 1000 Hz. The ground electrode was placed at the centre of the forehead, and the reference was placed at FCz. Two scalp electrodes (PO7, PO8) were repurposed to measure electrooculography (EOG): one positioned at the lateral canthus of the right eye, and one positioned infraorbitally to the right eye. Consequently, 61 scalp electrodes were available for subsequent analyses.

2.5. EEG preprocessing

EEG data were preprocessed using a custom automated pipeline implemented in Matlab R2019b with EEGLAB [68]. Continuous EEG data were first bandpass filtered between 1 and 40 Hz using EEGlab's finite impulse response filtering function, then downsampled to 250 Hz. Next, EOG channels were identified and extracted for subsequent eye-blink artifact correction. Automatic bad channel detection was performed on non-EOG channels using a kurtosis-based criterion with a z-score threshold of ± 5. Channels identified as noisy were interpolated using spherical spline interpolation to preserve scalp topography. On average, 3 channels were interpolated per participant.

Eye-movement artifacts were corrected using a regression-based EOG correction approach [69]. EOG auto-covariance and EEG-EOG cross-covariance matrices were computed across the continuous recording to derive global ordinary least-square regression weights, estimating the contribution of ocular activity to each EEG channel. The weighted EOG signal was subsequently subtracted from the EEG to obtain corrected data, after which EOG channels were removed, retaining 61 scalp channels. The continuous corrected EEG data without EOG channels were then segmented into three epochs of interest corresponding to condition onsets: Silence, High-RM, and Low-RM. Each epoch spanned -10 s to +180 s relative to condition onset, yielding a total epoch length of 190s. The 10-sec pre-onset buffer was retained to provide a baseline window for subsequent time-frequency analysis and to guard against wavelet edge effects at low frequencies.

To remove residual non-ocular artifacts, Independent Component Analysis (ICA) was performed using the Extended Infomax algorithm implemented in EEGLab (runica, extended mode). Prior to ICA decomposition, data rank was computed accounting for the number of interpolated channels, and was passed as the argument for Principal Component Analysis (PCA) dimension reduction to ensure a full-rank decomposition. Importantly, common average referencing was deferred until after ICA to avoid an additional rank reduction during decomposition. Artifactual ICs were then identified and removed automatically using the ADJUST toolbox [70], which classifies components into eye blinks, horizontal eye movements, generic discontinuities, and/or abnormal spectral profiles. On average, 13 ICs were removed per participant. Finally, the ICA-cleaned data were re-referenced to the common average reference (CAR) [71] computed across all 61 scalp channels, excluding any previously interpolated channels from the reference computation.

2.6. EEG analysis: Time-frequency decomposition and statistical analyses

A time-frequency representation (TFR) was derived for each condition by computing complex Morlet wavelet transform (CWT) for each channel and condition. The Morlet wavelet was chosen as it is the most established type of wavelet for EEG signals and thus recommended [72]. The wavelet kernel length was set to 6 seconds. The frequency range was linearly spaced and set to 2 -30 Hz with a resolution of 1 Hz to cover the most relevant frequencies. The number of wavelet cycles was set to gradually increase from 10 cycles for the lowest frequency to 30 cycles for the highest frequency. For each cleaned epoch, baseline correction was performed by subtracting the average amplitude of the period -5 to 0 sec from the entire signal epoch. Lastly, we excluded the first and last 10-sec of each epoch for analyses as these were time segments subjected to more movement as a result of participants moving around to respond to questions.

2.6.1. A priori ROI analyses and associations with questionnaires for individual differences

Region-of-interest (ROI) analyses were conducted across frontal (F1, F2, F3, F4, F5, F6), central (C1, C2, C3, C4, C5, C6), and parietal (P1, P2, P3, P4, P5, P6) regions, motivated by existing literature implicating these regions in delta (2-4 Hz), theta (4-8 Hz), alpha (8-13 Hz), and beta (13-30 Hz) frequency bands. For each ROI, time-frequency power was averaged across the constituent channels at the single-subject level prior to any statistical analyses.

Prior to statistical testing, temporal pre-processing was applied to each epoch. As the conditions of interest involved sustained auditory stimulation spanning 170 seconds rather than discrete time-locked events, fine temporal resolution was not expected to be informative and was likely to introduce noise into group-level comparisons. To address this, a Gaussian smoothing kernel of 10-sec was first applied along the time dimension of each participant's time-frequency map, followed by aggregation into non-overlapping 5-second time bins by averaging within each bin. Normality of the difference between conditions was next assessed at each time-frequency bin using the Shapiro-Wilk test. The proportion of cells consistent with normality was reported as a guide to test selection: if one or more group-level comparison showed that more than 50% of timefrequency cells violated normality assumptions, the Wilcoxon signed-rank test was used instead of paired t-test for all comparisons.

Group-level comparisons between condition pairs (i.e., High-RM vs. Silence, Low-RM vs. Silence, High-RM vs. Low-RM) were conducted using a cluster-based permutation procedure [73] applied separately per frequency band and ROI. At each time-frequency cell, a Wilcoxon signedrank z-statistic was computed on the pairwise differences across participants. Contiguous clusters of cells exceeding a z-threshold of a cluster-defining α = 0.10 (two-tailed) were identified whereby cells were considered adjacent only if they shared an edge in the frequency-time plane (horizontally or vertically), not diagonally. The cluster statistic was defined as the sum of z-values within each cluster. A null distribution of maximum cluster statistics was generated over 5,000 permutations. Clusters were considered significant if their statistic exceeded the 95th percentile of this null distribution (α = 0.05), and a minimum cluster size of 2 time-frequency bins was required.

Finally, EEG power was averaged within each frequency band per ROI, yielding withincondition power indices for each of the three conditions (High-RM, Low-RM, Silence). Pairwise difference scores were also computed by subtraction (High-RM vs. Silence, Low-RM vs. Silence, High-RM vs. Low-RM) to index condition-related changes in band power. Spearman correlations were conducted between these EEG indices and scores on individual difference measures (i.e., DASS-21, BMMR, BFI-2-S). To control the false discovery rate (FDR), p-values were corrected using the Benjamini-Hochberg procedure separately within each questionnaire family with a corrected significant threshold of p < .05.

2.6.2. Exploratory three-dimensional cluster-based permutation analyses

To complement the a priori ROI analyses, exploratory cluster-based permutation tests were conducted across all channels simultaneously within each frequency band (delta, theta, alpha, beta) using the same epoch segment of 10 -170 seconds. Analyses were implemented using the FieldTrip toolbox, revision 20250106 [74], with permutation testing carried out using FieldTrip's Monte Carlo method. Data were aggregated into non-overlapping 10-second time bins prior to analyses. The channel neighbour structure was constructed using the 'distance' method within FieldTrip's "ft_prepare_neighbours" function. At each channel-frequency-time point, a pairedsamples t-statistic was computed, with condition labels permuted within each participant independently. Contiguous clusters of points exceeding a cluster-defining threshold of α = 0.05 (two-tailed) were identified, with the requirement that each channel in a cluster must have at least two spatial neighbours also exceeding the threshold. The cluster statistic was defined as the sum of t-values within each cluster. A null distribution of maximum cluster statistics was generated over 5,000 permutations. Clusters were considered significant if their statistic exceeded the 95th percentile of this null distribution (test α = 0.05).

2.7. Behavioral data analysis 2.7.1. Emotion ratings after music listening conditions

To characterize the affective responses elicited during the music conditions, descriptive statistics of discrete emotion ratings from the Geneva Music-Induced Affect Checklist (GEMIAC) [63] were first tabulated. For inferential analyses, arousal-valence ratings were selected as the primary outcome emotion measures given their direct correspondence with AffectMachine's affective parameter space.

Self-reported arousal and valence ratings were analyzed using linear mixed effects models (LME) fitted with the lme4 package [75] in R version 4.5.2, with Satterthwaite-corrected degrees of freedom and p-values obtained via lmerTest [76]. For each emotion dimension, a single model was specified with time-point (pre-math, post-math, post-condition), condition (Silence, High-relaxation music, Low-relaxation music), and their interaction as fixed effects. Two nuisance covariates were additionally included: music presentation order ("music_order"; whether High-or Low-relaxation music was presented first) to control for potential carryover or order effects arising from the counterbalanced design, and block number ("block"; 1, 2, 3) to account for the nested temporal structure of the experiment whereby the post-condition rating of each block serves as the pre-math baseline of the subsequent block. The resulting model was: rating ~ time-point * condition + music_order + block + (1 | participant) Random intercepts were included for participant to account for individual differences in baseline ratings. We initially specified a maximal random effects structure including by-participant random slopes for time-point; however, this model was singular. Removing the intercept-slope correlation did not resolve convergence, and we therefore adopted a random intercept-only structure, which converged without singularity. This simplification is consistent with recommendations for parsimonious random effects structures when more complex specifications are not supported by the data [77].

Planned pairwise contrasts were extracted using the emmeans package v2.0.3 [78] to address three planned research questions: (1) whether arousal and valence changed significantly from pre-to post-math (stress induction manipulation check), (2) whether arousal-valence ratings recovered from post-math to post-condition (recovery effect), and (3) whether post-condition ratings returned to pre-math baseline levels. All contrasts were Bonferroni-corrected for three comparisons per condition, with statistical significance set at α = .05.

2.7.2. Associations between Arousal-Valence ratings and questionnaires for individual differences

To quantify the degree of change in self-reported levels of arousal or valence elicited by the silence/music conditions, a change score was calculated as: Δ valence = valence post-condition -valence pre-condition Δ arousal = arousal post-condition -arousal pre-condition whereby successful recovery from stress is represented by a positive Δ valence (i.e., increased valence) and negative Δ arousal (i.e., reduced arousal levels). Thereafter, simple linear regressions were conducted to examine whether individual difference measures (DASS-21 subscales, B-MMR subscales, BFI-2-S domains) predicted Δ arousal and with Δ valence scores in the Low-and Highrelaxation music conditions. To correct for multiple comparisons, false discovery rate correction (FDR; Benjamini-Hochberg) was applied separately within each questionnaire family.

4. Discussion

The current study investigated the electrophysiological correlates of stress recovery using generated affective music which differed in the degree of relaxation content in a sample of adults with elevated anxiety. Results showed that after taking into account the listener's preferred music genre (classical or pop), only High-relaxation music (High-RM) produced recovery in both arousal and valence dimensions simultaneously, while Low-relaxation music (Low-RM) restored valence comparably but failed to reduce arousal significantly. Compared to both music conditions, the silence condition reduced arousal but did not restore valence to baseline.

The efficacy of High-RM in regulating both arousal and valence towards the desired relaxation state can be understood through the combined logic of the iso principle [47] and the mood congruence hypothesis (MCH) [79]. In the current study, High-RM was designed to express music of a higher degree of relaxation than Low-RM, with affective qualities first calibrated near participants' post-stress state and shifted 30% toward positive-valence and low-arousal, rather than generating music reflecting a fully relaxed state. This partial-match design draws on the logic underlying the iso principle, in that the music does not immediately impose a fully relaxed target state but instead offers a state more proximal to the listener's own emotion state. This proximity, in turn, may explain why the music was successfully engaged with: according to the MCH, information or stimuli that are affectively congruent with one's current state are processed more readily and preferentially [79], and music that is mood-congruent has been shown to be more strongly engaged with and preferred over incongruent music [52]. Taken together, High-RM may have been effective precisely because it was congruent enough with participants' post-stress affective state to be readily engaged with (mood congruence), while still being sufficiently shifted toward a calmer, more positive target to elicit genuine recovery in both arousal and valence (embodiment of the iso principle).

Interestingly, our findings point toward the efficacy of Low-RM as well in regulating valence, although not arousal. This is somewhat surprising, as music is generally more effective at reducing arousal than shifting valence [46, [80] [81]. This positive effect on shifting valence in both music conditions is reminiscent of studies that compared the effects of iso-versus compensatory playlists on emotion regulation in healthy adults and found no differences between the effectiveness of both types of playlists in regulating emotions compared to a control condition [49, 54]. Another notable observation is the decrease in arousal observed in the silence condition, which may be attributed to either active self-regulation (e.g., controlled breathing, reappraisal; [82]) or passive physiological recovery, which does not require deliberate intervention [83].

4.1. Fronto-parietal suppression in music conditions relative to silence

The a priori ROI-level time-frequency analyses revealed that both music conditions suppressed frontal delta activity relative to silence. Increased delta power, particularly over frontal regions, has been reported across depression and anxiety [13]. This account is further supported by the positive correlations between the Anxiety subscale of DASS-21 and frontal delta power of each condition observed in the current study. To the extent that frontal delta indexes trait-level anxious distress, this convergence between existing literature and the present within-sample correlations lends support to interpreting the observed suppression of frontal delta during music listening, relative to silence, as reflecting a shift away from the distress-related neural state induced by the preceding arithmetic stressor. This interpretation is broadly consistent with the behavioral finding that both music conditions produced comparable stress recovery on self-reported valence.

Interestingly, Low-RM produced an additional delta suppression in the parietal region. Delta oscillations have been proposed to index attention to internally directed processing, with delta increases reflecting inhibition of external sensory interference during effortful internal concentration [84]. Accordingly, it is plausible that this parietal delta suppression during Low-RM may reflect a shift away from internally-directed processing toward external, stimulus-driven attention, given that Low-RM was generated at levels close to the post-stressor affective state.

Exploratory 3D cluster-based permutation analyses yielded a broadly similar pattern of results compared with the a priori ROI-level time-frequency analyses. Delta suppression was also observed in Low-RM relative to silence, with contributing electrodes from frontal and posterior regions. This is congruent with the finding of fronto-parietal delta suppression from the ROI analyses, with the exploratory analyses showing that the cluster included more neighboring electrodes compared to those defined in the ROI analyses.

4.2. Parieto-occipital alpha suppression in High-relaxation music relative to silence

Interestingly, parieto-occipital alpha suppression emerged in the comparison of High-RM relative to silence in the exploratory cluster-based permutation analyses, but not in the a priori ROI-level analyses. Of note, the exploratory analyses considered all 61 channels simultaneously within each frequency band and identified clusters based on spatial adjacency across the full scalp [73]. This approach can thus detect contiguous electrodes irrespective of pre-defined ROI boundaries. Consistent with this account, the parieto-occipital cluster identified to be different in the High-RM versus silence comparison included electrodes extending beyond the boundaries of the parietal ROI defined in the a priori analysis. Given the exploratory nature of this analysis, this effect should be interpreted with appropriate caution.

The observed alpha suppression may be understood through the lens of attentional engagement. Alpha-band suppression has long been considered a neural marker of attentional engagement with the external environment, with greater suppression reflecting increased attentional engagement towards the external environment [85, 86]. Under this account, the parietooccipital alpha suppression observed during High-RM may reflect heightened attentional engagement with the music itself. This is consistent with the proposal that High-RM, being calibrated to be proximal to but not fully divergent from participants' post-stress affective state, facilitated greater engagement with the music (i.e., mood congruence hypothesis; [52, 79]), an observation not found in Low-RM.

4.3. Individual differences: Stress is associated with valence recovery while trait anxiety is associated with delta power across conditions

Findings from the current study showed that the effect of increase in valence for both music conditions was larger for individuals with a lower score on the Stress subscale of DASS-21. However, the Stress subscale of DASS-21 was not extensively associated with electrophysiological markers within condition and condition-related changes. Instead, the strength and topographical extent of the association between DASS-21 scores and delta power varied systematically by condition: In silence, higher scores on the Anxiety subscale were associated with higher delta power across frontal, central, and parietal regions; in Low-RM, a positive correlation between the Anxiety subscale and delta power was observed only in the frontal region; in High-RM, however, associations between behavioral measures and EEG were both broader across regions and extended to all three DASS-21 subscales, including an additional link between Anxiety and parietal theta, which were all in a positive direction.

One plausible explanation draws on the iso principle and compensatory listening frameworks. Given that High-RM was calibrated to be more affectively discrepant from participants' post-stress state than Low-RM [47, 48], engaging with it may have required more active regulatory work for individuals with elevated anxiety, who have been shown to rely more heavily on compensatory, mismatch-driven regulation strategies than mood-matched ones [50]. This would be consistent with attentional control theory, which proposes that individuals with elevated anxiety recruit additional processing resources to sustain goal-directed engagement, particularly under conditions of greater affective or attentional demand [5]. Accordingly, a broader and more effortful neural engagement with High-RM among more anxious participants would therefore be expected. Alternatively, this broader pattern may simply reflect a more general association between trait negative affect and neural markers of engagement or effort during exposure to strongly positively valenced stimuli, a possibility that cannot be disambiguated with the current data.

While interesting patterns of correlations emerged between DASS-21 subscales and within-condition EEG power, no condition-related change in band power was significantly associated with any individual difference measure after FDR correction. This suggests that the degree of neural change elicited by music relative to silence was not reliably moderated by trait anxiety, depression, stress, habitual music-based mood regulation strategies (as measured by B-MMR), or personality (as measured by BFI-2-S), in this sample of individuals with elevated anxiety. This null pattern is notable given that trait-level constructs such as Negative Emotionality/Neuroticism and maladaptive music-regulation strategies (e.g., Discharge) have previously been linked to affect-related neural responses to music [87].

Taken together, these findings suggest a divergence between the subjective and neural correlates of individual differences in stress recovery: whereas the DASS-21 Stress subscale moderated the magnitude of behavioral valence recovery, no individual difference measure moderated condition-related neural change. This divergence should be interpreted with appropriate caution, but raises the possibility that self-reported affective recovery and the neural markers examined here may not be capturing fully overlapping aspects of the stress-recovery process.

4.4. Limitations & future directions

While this is one of the first studies that examined stress recovery with generated affective music of differing levels of relaxation, it is not without limitations. In this study, we did not explicitly measure stress-level after each block of arithmetic task, but instead measured negative affect (i.e., self-reported valence-arousal ratings). It is plausible that the lack of effect in reducing arousal level could be attributed to the intensity of the arithmetic task. Studies have reported that music may only be effective in reducing stress in the context of a mild stressor as opposed to a strong stressor [32, 80]. Further, we employed a passive control condition whereby the participants simply remained silent after the arithmetic task. Thus, for the comparisons between music conditions against silence, we cannot effectively rule out alternative explanations such as general auditory engagement or attentional capture by the music stimuli. In addition, there may be a potential confounding effect of music listening for the next stress block. While this has been accounted for in our analyses, it could nonetheless affect the interpretations of stress-recovery in subsequent blocks. Lastly, the current sample scored highly across all DASS-21 by design, which could possibly limit the analyses of individual differences. Future research could examine a broader or more stratified range of anxiety severity to test whether this affected the individual difference analyses.

Results from this study nevertheless demonstrate an overall efficacy of using generated affective music for stress reduction and emotion regulation. We also demonstrate that listening to music of different degrees of relaxation could have an effect on self-reported felt emotions and involve different brain regions. There is thus potential in integrating generated affective music into neurofeedback systems to assist with emotion regulation in individuals with psychological distress. It would also be interesting to examine the system's efficacy with those diagnosed with mental illnesses. Lastly, future work should test the iso principle as compared to the compensatory approach in designing musical neurofeedback, in both those with clinical and non-clinically diagnosed anxiety. Overall, results from this study could inform future developments of musical neurofeedback and treatment interventions for those with undiagnosed anxiety/depression.
