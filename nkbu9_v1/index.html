measured_variables Expectations of Peer Reactions

Participants completed a measure of their perceptions about how their friends would feel about their possible behaviors in a given scenario. Participants answered questions about six scenarios. Each scenario involved the participant imagining a social context (e.g., “You see two kids your age about ready to start a fight in school.”). Participants then answered two questions about how they thought their friends would react if they enacted a specific behavior for each scenario. One question involved a negative behavior (e.g., “What would your friends think if you cheered on the fight?”). The other question involved a positive behavior (e.g., “What would your friends think if you went to get a teacher?”). Participants selected whether they thought their friend would support the behavior, not support the behavior, or would be neutral about the behavior. Participants also had the option to skip each question.

Answers will be recoded such that the neutral option will be coded as 0, the support option will be coded as +1, and the unsupportive option will be coded as -1. For each time point, the mean of responses for each subscale will be specified as the independent variables.

Physical and relational aggression were measured with the Problem Behavior Frequency Scale (PBFS). Participants indicated how often the did a given action (e.g., “Picked on someone”, “Shoved or pushed someone”) in the last 30 days using a numerical scale (1 = Never, 2 = 1-2 times, 3 = 3-5 times, 4 = 6-9 times, 5 = 10-19 times, 6 = 20 or more times). Participants had the option to skip each question (coded as 7). We will recode skipped items to 0. For each time point, the mean of responses for each subscale will be specified as the dependent variable. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. Longitudinal Associations Between Meta-Perceptions of Friends' Reactions and Physical and Relational Aggression Perpetration During Early Adolescence

Peer norms are linked to aggressive behaviors -attempts to harm someone who does not wish to be harmed (Allen & Anderson, 2017) -during adolescence as both a promotive and constraining factor. Adolescents may prefer friends over non-friends as sources of social information (Slagter et al., 2023) and may engage in aggressive or nonviolent behaviors as a means of peer acceptance (Laursen et al., 2011). Recent evidence suggests adolescent behavior is shaped by friendship influence in addition to normative pressure (Zingora & Flache, 2025). Less is known, though, about the role of intrapersonal expectations of peer reactions to aggressive and nonviolent conflict resolution strategies. We examine longitudinal associations between youths' expectations of friends' reactions to these strategies and youths' aggressive behavior perpetration among middle schoolers.

Norms and Aggression During Early Adolescence

Social norms regulate behavior by communicating what is typical and acceptable within a social context. Norms can be classified as either descriptive (i.e., perceptions of others' common behaviors) or injunctive (i.e., perceptions of the social approval or disapproval of behaviors; Cialdini et al., 1990). While both types guide behavior, injunctive norms may be particularly informative for aggressive behaviors that carry social evaluative weight (Cialdini & Trost, 1998). When individuals perceive that others would disapprove of aggression, they may be less likely to enact it; if aggression is perceived as socially sanctioned, they may be more likely to perpetrate it (Henry et al., 2000). Understanding how early adolescents perceive norms around aggression -and whose approval informs these behaviors -is critical as peer influence intensifies.

Early adolescence (i.e., roughly ages 10 -14) is a period with heightened susceptibility to peer influence (Steinberg & Monahan, 2007), as youth reorient from caregivers to peers as primary sources of social influence and behavioral guidance (Brown & Larson, 2009). Before this shift, friends are not yet salient evaluative referents whose anticipated reactions inform decision-making (e.g., Larson & Richards, 1991), so meta-perceptions of friends' reactions may be less construct-relevant. Peer relationships also become central to identity formation, and social acceptance is prioritized (Brechwald & Prinstein, 2011), shaping middle schoolers' attunement to peer norms.

Perceived peer norms supporting aggression predict aggressive behavior among youth: adolescents who perceive aggression as normative responses within their peer contexts, through both descriptive and injunctive norms, are more likely to perpetrate it (Henry et al., 2000; Salmivalli & Voeten, 2004). The normative context may vary by type of aggression. Physical aggression (i.e., direct physical harm to others) is typically counter-normative, particularly in middle school when youth internalize prohibitions against physical violence (Coie & Dodge, 1998), and early adolescents typically perceive it as disapproved by peers (Xie et al., 2002). In contrast, relational aggression (i.e., behaviors which harm others through damage to relationships or social status) occupies more ambiguous territory and may be perceived as more normative (Crick et al., 1999). Meta-analytic evidence suggests that early adolescents who perpetrate relational aggression may maintain, or even enhance, their social status in middle school (Casper et al., 2020), implying that peer groups may tolerate or approve of it (Rose et al., 2004; Vaillancourt & Hymel, 2006).

Most of this literature, though, reflects generalized peer norms, which may be too broad to capture relevant influences on aggression. During early adolescence, when close friendships are forming and intensifying, youth may be less concerned with what peers in general think and focus more on what their friends think (Rubin et al., 2006).

Examining expectations about how specific close others (i.e., friends) would respond to their behaviors therefore requires moving beyond general peer norms. Such expectations are meta-perceptions (Kenny, 1994).

Cognitive Meta-Perceptions Inform Behavior

Meta-perceptions refer to individuals' beliefs about how others perceive them (Kenny & DePaulo, 1993). Unlike general normative beliefs about what behaviors are approved or disapproved, meta-perceptions involve expectations about how particular relationship partners view or would evaluate the self. Their study has foundations in symbolic interactionist theory, which posits that individuals come to evaluate the self as they believe others see them (Cooley, 1902; Mead, 1934).

Meta-perceptions also fit within social-cognitive theories of behavior. In the social information processing model (Crick & Dodge, 1994), meta-perceptions become relevant as youth clarify their goals and assess the likely consequences of different behavioral options (Fontaine et al., 2002; Lansford et al., 2010; Van Dijk et al., 2017), functioning as internalized cognitive guides even when they develop through social learning (Huesmann & Guerra, 1997).

Meta-perceptions inform behavioral decisions across domains ranging from selfpresentation to relationship maintenance (Carlson, 2016). Meta-analytic evidence suggests that their accuracy is modest at best (Carlson, 2016), though individuals can make valid distinctions between self-perceptions and meta-perceptions (Carlson et al., 2011). Inaccuracy may reflect genuine difficulty assessing the private thoughts and evaluations of others (Vazire & Carlson, 2011). Meta-accuracy may be especially limited during early adolescence as perspective-taking capacity continues to develop (Choudhury et al., 2006). Early adolescents may struggle more than older adolescents or adults to infer others' evaluations (Harter, 2012). Fischer's dynamic skills theory, though, suggests that cognitive performance in adolescence is context-dependent and can be scaffolded through task structure (Fischer, 1980; Fischer & Bidell, 2006), such that youth reason more maturely when tasks are concrete and well-supported than when they are abstract and decontextualized (Dawson, 2002; Fischer et al., 1993).

Asking early adolescents concrete, specific questions about how friends would react to specific behaviors may therefore scaffold more accurate meta-perceptual judgments despite general constraints on abstract perspective-taking.

Despite their limited accuracy, meta-perceptions may still powerfully influence behavior, as inaccurate beliefs may guide decisions if they feel real to the individual (Carlson & Kenny, 2012). For middle schoolers, meta-perceptions of friends' evaluations may be particularly influential. First, friends interact frequently across domains, providing opportunities to communicate approval and disapproval (Laursen & Hartup, 2002). Second, friendships during early adolescence involve heightened investment and emotional intensity, which may make perceived approval or disapproval especially salient (Furman & Buhrmester, 1992). Third, friends often serve as behavioral models and sources of social comparison, making their evaluative standards salient and known (Prinstein & Dodge, 2008).

The distinction between peer norms and friend-specific meta-perceptions may be particularly important for aggression perpetration among middle schoolers. Metaperceptions may exert stronger influence on the decision to aggress than general normative beliefs, especially when friends are present, likely to find out about the behavior, or seen as relevant evaluators. Whether such influence operates between youth or as a process that unfolded within youth over time has not been established.

The Present Study

Understanding how expectations about friends' reactions related to aggression requires distinguishing two questions. The social-cognitive account described above is a within-person process, but youth also differ from one another in relatively stable ways (e.g., the friendships they form). Most evidence linking norms and normative beliefs to aggression comes from cross-sectional data, two-way designs (e.g., Huesmann & Guerra, 1997), or cross-lagged models that do not partition more stable between-person variance from within-person change (e.g., Krahé & Busching, 2014). Cross-lagged estimates from such models can reflect stable individual differences and misrepresent prospective processes (Hamaker et al., 2015). Recent work on perceived peer norms and aggression has explicitly called for random intercept cross-lagged panel models (RI-CLPMs; Bullo & Schulz, 2025). To our knowledge, the between-person and withinperson associations between expected friend reactions and aggression perpetration have not been examined separately; clarifying which level carries these associations is a central contribution of the present study.

To that end, we examined the longitudinal associations between meta-perceptions of aggressive and nonaggressive behaviors and reported physical and relational aggression perpetration among early adolescents. Overall, we expected the social cognitive meta-perceptions of aggressive and non-aggressive behaviors to inform their reported aggression perpetration. We pre-registered several hypotheses (https://osf.io/q27a9/overview?view_only=5c1dd775967744f8bcbadaf51efc7a6a ).

At the between-person level, we hypothesized that youth who generally expect their friends to be supportive of aggressive behavior will report greater physical aggression perpetration (Hypothesis 3) and relational aggression perpetration (Hypothesis 6). Additionally, we hypothesized that youth who generally expect their friends to be more supportive of nonviolent behaviors would report lower physical aggression perpetration (Hypothesis 9) and relational aggression perpetration (Hypothesis 12).

At the within-person level, we expected meta-perceptions and aggression to be dynamically linked across waves, consistent with the social-cognitive account of response evaluation. Regarding meta-perceptions of aggressive behaviors, we hypothesized that, within-participants, relatively greater expectation for friends' support for aggressive behaviors at one timepoint will predict relatively greater physical aggression perpetration (Hypothesis 1) and relational aggression perpetration (Hypothesis 4) at the subsequent timepoint, and that relatively greater physical aggression perpetration (Hypothesis 2) and relational aggression perpetration (Hypothesis 5) will predict relatively greater expectations for friends' support for aggressive behaviors at the subsequent timepoint. Regarding meta-perceptions of nonviolent behaviors, we hypothesized that, within-participants, relatively greater expectation for friends' support for nonviolent behavior at one timepoint will predict relatively lower physical aggression perpetration (Hypothesis 7) and relational aggression perpetration (Hypothesis 10) at the subsequent timepoint, and that relatively lower physical aggression perpetration (Hypothesis 8) and relational aggression perpetuation (Hypothesis 11) will predict relatively greater expectations for friends' support for nonviolent behaviors at the subsequent timepoint.

Measures

Meta-perceptions of friends' reactions were measured using the Friends'

Reaction to Responses to Conflict Situations Scale (Farrell et al., 2017). Participants were instructed that these questions referred to the participant and their friends, as compared to the broader peer network in classrooms. The measure included six hypothetical, but likely, scenarios that describe a challenging situation that might arise (e.g., "You and another kid get into an argument at school. Other students are there boosting it up saying, 'Fight, fight, fight.'") and asked to "think of how your friends might react if you tried the different ways of dealing with these difficult situations". All scenarios were followed by two questions that asked about meta-perceptions of their friends' reactions if they enacted an aggressive behavior (e.g., "What would your friends think if you threw the first punch?") or non-violent behavior (e.g., What would your friends think if you tried to talk to the person calmly to settle the argument?). The full measure may be found in the Supplemental Materials. For each behavior, participants selected whether they thought their friends would support (scored as 1), not support (scored as -1), or be neutral (scored as 0) about each behavior. As such, six questions (i.e., one question per scenario) measured meta-perceptions about friends' support for aggressive behaviors and six questions measured meta-perceptions about friends' support for non-violent behaviors. Most importantly, these questions probed contextualized and concrete behaviors which may support the scaffolding necessary for early adolescents to engage in accurate meta-perceptual judgements (Fischer, 1980; Fischer & Bidell, 2006).

Physical and relational aggression perpetration were measured using the Problem Behaviors Frequency Scale -Revised (PBFS-R; Farrell et al., 2000).

Participants reported how frequently they enacted specific behaviors in the past 30 days using a 6-point anchored scale (1 = Never,2 = 1-2 times,3 = 3-5 times,4 = 6-9 times,5 = 10-19 times,6 = 20 or more times). Each item included a decline to answer option.

For the present study, we used only the items which were available in the dataset and identified in prior psychometric work of the PBFS (Farrell et al., 2020). Physical aggression perpetration was assessed with five items (e.g., "Hit or slapped someone", "Thrown something at someone to hurt them"). Relational aggression was assessed with six items (e.g., "Spread a false rumor about someone", "Made fun of someone to make others laugh").

Analysis Strategy

Prior to our hypothesis tests, we calculated the mean for all variables at each time point. Then, we conducted two separate RI-CLPMs. Variance inflation factors indicated no evidence of problematic multicollinearity among peer reactions to nonviolence and aggression (all VIFs < 2.0). As such, we report combined models with expectations of friend reactions to both positive and negative behaviors as independent predictors. We specified separate models for each outcome variable (i.e., physical and relational aggression perpetration). Our two-model approach was guided by two considerations. First, a single model incorporating cross-lagged and random-intercept parameters, along with their covariance, would have substantially increased model complexity relative to our sample size, raising concerns about power to detect the within-person effects central to our hypotheses. Second, we reasoned that statistically controlling for the overlap between physical and relational aggression risked producing residualized effects that would be difficult to interpret across the broader literature, which typically treats these as related but distinct forms of aggression. Within each model, we constrained autoregressive and cross-lagged paths to be equal across time.

All models were estimated using full information maximum likelihood to account for missing data at each timepoint. For each model, we dummy coded intervention condition and school site and regressed these variables onto random intercepts to control for context-specific influences on reported aggressive behaviors. We fixed observed residual variances to 0, so all variance was partitioned into stable betweenand-within person variances. We fit each model using the lavaan package (Rosseel, 2012) for R (v.4.4.2; R Core Team, 2024).

Given that each model tests distinct theoretical predictions with unique predictoroutcome combinations and all hypotheses were pre-registered, we did not apply familywise error correction across models. Deviations From Pre-Registration

Although neither pre-registered nor associated with a formal hypothesis, we assessed the between-person association between students' meta-perceptions and their aggressive behaviors by computing the standardized correlation of the randomintercepts in the models. These analyses are exploratory and should be viewed with appropriate caution. We did not preregister whether we would allow residual variances to vary freely or be constrained to zero. We view this as a deviation from a non-specified preregistered plan, but do not view this as shifting the hypothesis tests from confirmatory to exploratory.

Power Considerations

In line with our pre-registered analysis plan, we attempted to conduct a sensitivity power analysis using the powRICLPM package for R (Mulder, 2023) to identify the minimum detectable effect size (MDES) with 80% power for the cross-lagged effects and the random intercept correlations (see Giner-Sorolla et al., 2024). Unfortunately, due to the mathematical constraints which arose from the models' high intraclass correlations and moderate random intercept correlations, formal MDES calculations using this package were not feasible. These constraints reflect the mathematical incompatibility between high between-person variance and the additional complexity of cross-lagged parameters, resulting in non-positive definite covariance matrices in the power simulation framework. This is a limitation of the package's utility for sensitivity power analysis.

It is unclear if null results for within-person effects are due to a lack of power or the absence of a true effect. With that in mind, all conclusions regarding within-person cross-lagged effects should be viewed cautiously until an agreed-upon process for conducting sensitivity analyses for RI-CLPMs emerges. The effect sizes reported here can be used to guide future a priori power analyses, an area where the powRICLPM package demonstrates excellent utility. Regarding the between-person associations between random intercepts, a sensitivity analysis using the pwr package for R (Champely, 2020) indicated we can detect correlations as small as |r| = 0.18 with 90% power at = .05 with 𝛼 N = 304 (i.e., the smallest number of cases for any variable across all waves).

Discussion

The present study examined whether early adolescents' meta-perceptions about friends' reactions to aggressive and non-violent conflict resolution strategies prospectively predict physical and relational aggression perpetration. Using RI-CLPMs across four timepoints, we found statistically significant between-person associations.

Youth who generally believed their friends supported aggressive responses to conflict situations tended to engage in more physical and relational aggression, whereas those who believed their friends supported non-violent responses tended to engage in less.

Perceived friend support for aggressive and non-violent responses thus functioned as promotive and constraining factors, respectively. The only statistically significant withinperson effect indicated that relational aggression perpetration predicted higher perceived support for aggressive conflict resolution strategies at the subsequent timepoint.

Between-Person Associations Without Within-Person Dynamics

The statistically significant associations between random intercepts indicate substantial between-person covariation, consistent with previous research linking perceived peer norms to involvement in aggressive behavior (e.g., Henry et al., 2000; Salmivalli & Voeten, 2004). The absence of statistically significant cross-lagged paths indicates that this covariation does not reflect within-person change processes operating across the study period.

The lack of widespread convergence between between-person and within-person effects carries important theoretical implications (Hamaker et al., 2015). Traditional cross-lagged panel models, which do not partition variance into these components, can yield misleading cross-lagged coefficients when constructs show stable between-person associations, because apparent prospective effects may reflect stable third variables.

The RI-CLPM's separation of stable and time-varying components provides a more rigorous test of whether one variable predicts changes in the other.

An additional, non-mutually exclusive possibility concerns developmental timing.

Because early adolescence is when friends emerge as salient social referents, friendspecific meta-perceptual schemas may still have been consolidating among participants. Between-person differences may already reflect meaningfully different schemas rooted in youth's friendship histories, while the schemas may not yet fluctuate enough to produce detectable within-person cross-lagged effects. Assessing the construct across a wider developmental period, spanning the increasingly strong role of peer social orientation in early adolescence, would clarify whether within-person dynamics strengthen as schemas mature or are more detectable earlier, before schemas stabilize around established friendship configurations.

Plausible Alternative Explanations and Mechanisms

Statistically significant between-person associations without widespread crosslagged effects may suggest that selection processes play an important role in the observed covariation, an alternative explanation deserving of focused inquiry. Youth with higher levels of aggressive behavior may select friends who hold pro-aggressive attitudes or may selectively attend to and remember instances when friends condoned aggressive responses. This idea may be supported by the statistically significant crosslagged effect of relational aggression perpetration on expected reactions to aggressive conflict situation responses.

Friend similarity reflects selection as much as or more than mutual influence (e.g., Kandel, 1978; Prinstein & Dodge, 2008). Social network analyses show that homophily (i.e., the tendency to form friendships with similar others) accounts for substantial friendship similarity in aggressive behaviors (Sijtsema et al., 2010; Veenstra et al., 2013), as youth preferentially select friends who are behaviorally and attitudinally similar to themselves (McPherson et al., 2001). Longitudinal network analyses further suggest that selection processes may be particularly prominent during early adolescence (Logis et al., 2013; Molano et al., 2013).

Cognitive consistency processes could also maintain stable perceptions of friends' responses, leading youth to hold meta-perceptions that align with their behavioral tendencies even without accurate information about friends' actual attitudes.

Youth who behave aggressively may engage in biased information processing that leads them to perceive friends as more supportive of aggression than they actually are, whereas youth who aggress less may consistently interpret friends as more supportive of non-violent behaviors. Such biases would create more stable between-person covariation without meta-perceptions causally influencing behavior. Shared third variables (e.g., neighborhood contexts, family socialization practices, individual personality traits) could also influence both aggressive behavior (e.g., as protection from environmental harm) and meta-perceptions.

The absence of widespread meta-perception effects on aggression should not be interpreted as evidence against peer influence more broadly. Peer contexts are vastly important throughout adolescence (Slagter et al., 2023; Prinstein & Dodge, 2008; Zingora & Flache, 2025), and the mechanisms linking them to aggressive behavior may differ from those examined in the present study.

Direct and immediate social reinforcement may matter more than cognitive expectancies about generalized approval. Friends may laugh at an aggressive act, show fear, or increase their evaluations of a perpetrator's social status in the moment, and such consequences may shape behavior more powerfully than abstract beliefs about whether friends generally approve of aggressive or nonviolent responses to conflict situations. Behavioral modeling represents another mechanism that does not require meta-perceptions. Youth may imitate friends' aggressive behaviors through social learning processes (i.e., Bandura, 1973), particularly when aggression appears to be a successful means of achieving a desired end-state, making friends' actual aggressive behavior a more proximal influence on youth aggression than youth's metaperceptions. Peer influence could also operate through identity processes and selfcategorization, which do not depend on outcome expectancies. Early adolescents may adopt behavioral characteristics of their social network to affirm their membership and express their social identity (e.g., Tarrant et al., 2006), a process involving perceived behavioral norms that define group membership.

Limitations and Future Directions

Several limitations warrant discussion. First, data were collected between 2008 and 2010, and evidence is mixed regarding technology's impact on adolescents' abstract thinking and capacity for meta-perceptions (e.g., Adelantado-Renau et al., 2019), so the findings may not generalize to contemporary early adolescents. Second, while the sociodemographic diversity and inclusion of students in both urban and rural areas is a strength of the study, we did not delve into subgroup analyses. We are unable to make claims about any one subgroup of participants. Future research could investigate the role of ethnoracial identity, socialization practices, and context between rural and urban areas. Third, aggression was self-reported and may have been misremembered or misreported; future research might utilize objective measures of aggressive behavior (e.g., Taylor Aggression Paradigm; Taylor, 1967).

Ultimately, the findings underscore the value of distinguishing selection from influence processes. Future research might examine meta-perceptions at multiple temporal resolutions. Moderately intensive timescales (e.g., daily, weekly) could test whether situation-specific meta-perceptions predict proximal aggressive or non-violent responses, whereas longer intervals might detect cumulative effects not apparent across a semester-based period. Network analyses might identify which network members influence meta-perceptions, aggressive behavior perpetration, or both. Future research should also examine alternative mechanisms, including direct reinforcement, behavioral modeling, identity processes, and structural features of peer networks, that might operate independently or interactively with meta-perceptual processes.

Conclusion

Youth who generally perceived their friends as supportive of aggressive responses to conflict situations reported higher frequencies of relational and physical aggression, and those who perceived their friends as supportive of non-violent responses reported lower frequencies; the only within-person prospective effect ran from relational aggression perpetration to expected reactions to aggressive responses.

Distinguishing individual differences from dynamic change processes is therefore essential for assessing associations between meta-perceptions and aggressive behavior during early adolescence.
