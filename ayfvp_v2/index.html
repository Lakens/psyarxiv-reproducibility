How Ethics Approval Check works

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

IRB and IEC are kept unconstrained as they are not observed to collide in practice. - Dutch: Medisch-ethische toetsingscommissie (METC) - French: Comité d'éthique / Comité d'Ethique

Animal research committee names - Institutional Animal Care and Use Committee / IACUC (US standard) - Any sentence containing animal(s) and committee (or board/panel) within ~5 words of each other — catches Experimental Animal Care and Use Committee, Animal Ethics Committee, Animal Welfare Board, Animal Welfare Ethical Review Body, etc. - UK: Animal Welfare Ethical Review Body / AWERB - Dutch: Dierexperimentencommissie / DEC (see DEC constraint above); Instantie voor Dierenwelzijn / IvD - German: Tierversuchskommission / TvK (advisory committee under §15 Tierschutzgesetz) - French: Comité d'éthique en expérimentation animale / CEEA; Comité d'éthique animale - Spanish: Comité de ética en experimentación animal / CEEA

Approval phrasing - Ethics/Ethical (approval|clearance) [was] (granted|obtained|received|given|secured) - Ethically approved - Approved by the (ethics|irb|institutional|independent|local|review|research) ... - This/The study/protocol/experiment/procedures/methods/research [was] (approved|reviewed) by - Study was ethically approved - (Followed|met|follow) the ethical (guidelines|standards|requirements) - In accordance with ... ethical (guidelines|standards) - Ethics protocol - Approved under (protocol|reference|number)

Waiver / exemption - Ethics/Ethical (waiver|exemption) - IRB (waiver|exemption|exempt) - Exempted from (ethics|irb|institutional review) - Waived by the (ethics|irb|institutional|review) (committee|board) - Deemed exempt

Declaration of Helsinki - Declaration of Helsinki / Helsinki Declaration

Patterns are NOT designed to capture: - General ethical considerations or ethical dilemmas in study content - Mentions of “ethics” in theoretical or philosophical contexts - Author approval of a manuscript (e.g. “all authors approved the final version”) - Ethical behaviour as a measured variable (e.g. “ethical decision-making”) - URLs containing “ethics” in path components

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. Abstract

This randomised controlled trial examines if a one-week social media abstinence intervention can reduce social media use by lowering automaticity of and craving for social media use.

Participants motivated to reduce their social media use were assigned to an immediate one-week detox (N = 50) or a waitlist control condition (N = 67). Using a combination of smartphone usage logging and weekly surveys, we found that the detox produced significant reductions in social media use (d = 0.79), automaticity (d = 1.05), and craving (d = 0.52) one week post-detox relative to the waitlist group. Pooling data from both groups after each had completed the detox (N = 112), we found that larger reductions in automaticity predicted larger reductions in use, and that baseline automaticity predicted self-reported attempts to open removed apps (i.e. habitual slips of action) during the detox. The reductions persisted across the three-week followup, and social media use remained below baseline at a six-month follow-up in a subsample (N = 49). The detox also shifted participants' subjective relationship with social media, increasing perceived control and reducing self-reported mindlessness, without changing how much they liked it or considered it purposeful. Together, these findings suggest that, for those who want to cut back, taking a short break is an effective way to disrupt social media habits and restore a sense of control.

1. Introduction

Social media has become a central part of daily life. Worldwide, almost 6 billion people (around 2 in 3) spend on average more than 18 hours weekly on those platforms (Global Social Media Statistics, 2026). This popularity makes sense: social media serves many genuine needs, from staying connected and informed to entertainment and self-expression (Whiting & Williams, 2013). At the same time, most people spend more time on social media than they want to, and struggle to cut back (Dekker et al., 2026). The tension between the value social media offers and the difficulty of using it in a balanced way sits at the heart of growing concerns about digital wellbeing (Vanden Abeele, 2020). Why is it so hard to strike this balance, and can a temporary break from social media help restore it? In this study, we investigate whether a one-week social media detox produces lasting reductions in social media use, and whether it does so by disrupting the habits that normally drive use.

People often fail to change their behaviour despite good intentions, a phenomenon known as the intention-behaviour gap (Sheeran & Webb, 2016). A key reason is that much of our behaviour is not deliberately controlled but habitual. Habits are automatic, cue-triggered behaviours that operate largely independently of current goals (Wood & Rünger, 2016). These features make habits hard to change: because they are triggered by context rather than intention, they can persist even when they conflict with what we want. Habits form when a behaviour is repeated frequently in a stable context -and few behaviours are repeated as frequently, in as many contexts, as social media use. This makes social media use a strong candidate for being highly habitual (Anderson & Wood, 2025; Bayer et al., 2022). Indeed, early research found that smartphone checking habits -brief, automatic inspections of the phone -characterize smartphone use (Oulasvirta et al., 2012). In line with the idea that habits undermine intentions, people who report stronger social media checking habits also report more difficulty controlling their use (Du et al., 2019).

One increasingly popular way to regain control is a period of abstinence, or 'digital detox' (Nguyen, 2021; Radtke et al., 2021). The central assumption is that a digital detox can help people break their unwanted social media habits. This effect may be achieved by removing behavioural accessibility -one of several strategies for disrupting habitual behaviour (Gardner et al., 2024; Wood & Neal, 2016). By removing social media apps from one's phone, a detox makes the habitual response temporarily unavailable, creating a 'window of opportunity' to shift toward alternative behaviours (Gardner et al., 2024; Verplanken et al., 2018). Because the habitual response repeatedly goes unperformed, the underlying cue-response association may weaken (or be overridden by alternative cue-response associations). We therefore expect more sustained reductions in use for those in whom the detox more strongly reduces the subjective automaticity of their social media use -a proxy for habit strength (Gardner et al., 2012).

Restricting behavioural accessibility, however, may have a downside. Blocking the response while the triggers for use remain may increase the urge to use. Such an 'incubation of craving' is well-documented across substance use disorders (e.g. Bedi et al., 2011; Li et al., 2014), and behavioural addictions (Fernandez et al., 2020). Similarly, previous studies have observed increased social media craving during (Wadsley & Ihssen, 2023; Wilcockson et al., 2019) and following (Stieger & Lewetz, 2018) a detox, raising the possibility that craving leads to a rebound effect once the apps are again available. In the current study, we therefore assess both habit as a potential mechanism of the detox's effect, and craving as a process that may work against it.

Taken together, these observations highlight two research gaps. First, it remains largely unknown whether a detox produces reductions in use that persist after normal access resumes, because most studies measure effects only during the abstinence period itself (Radtke et al., 2021). Second, to the extent that a detox does reduce subsequent use, the question remains through which mechanisms it does so.

In the present study, to address both gaps, we invited participants motivated to reduce their social media use to complete a one-week social media detox, and followed them for three weeks after the detox, and a subset for even longer (six months). Using a randomised controlled trial combined with a longitudinal within-subject design, participants were randomly assigned to detox either immediately or after a three-week waiting period (waitlist control), with weekly surveys throughout. The randomised comparison allowed us to causally test the detox's effects up to one week post-detox, after which the waitlist group underwent the detox as well. Pooling both groups after each had detoxed additionally allowed us to test the persistence of the effect within-subject in the full sample. Objectively logged social media use, self-reported automaticity, and craving were measured at baseline and across the three-week follow-up, alongside participants' subjective experience of their social media use and mental wellbeing.

Our preregistered research questions were: (1) does a one-week detox reduce social media use; (2) does it reduce automaticity of social media use; (3) does it affect craving. We hypothesised that social media use and automaticity would be reduced after the detox, while craving would increase during it. We further preregistered to test if (4) changes in automaticity, craving, and baseline motivation predict the reduction in social media use, and (5) baseline social media use, automaticity, or craving predict the number of times during the detox participants reported wanting to open the app before realising it was removed (i.e. slip of action). Exploratory analyses were run on the effect of the detox on social media and general smartphone use, the subjective experience of social media use, and mental and affective wellbeing. These exploratory analyses used within-subject comparisons (baseline to postdetox), allowing us to examine effects up to three weeks following the detox.

2. Methods and Materials

The present study was pre-registered on the Open Science Framework (https://osf.io/9k8rw/), approved by the Psychology ethics committee of the University of Amsterdam (2020-CP-12644) and performed in accordance with those guidelines. Data collection took place between April and July 2021.

2.1 Participants

Participants were recruited through the university network and paid advertisements on Facebook and Instagram. Before admission, participants signed an informed consent form and completed an inclusion screener. Criteria were: age 16-40, EU residence, Android or iOS phone ownership, daily social media use of at least one hour, and motivation and willingness to remove their social media apps for one week. We selected highly motivated participants to match the target group for whom a detox is a plausible intervention, and to avoid known problems with unmotivated participants such as non-adherence, dropout and negative wellbeing effects (Vanden Abeele et al., 2025).

The study was conducted in both English (n = 49) and Dutch (n = 68), with participants completing all materials in their chosen language. Participants received €25 for completing the study. We deliberately kept the compensation relatively modest, to select for participants who were intrinsically motivated to detox. Additionally, participants could win €5 per day through a lottery draw tied to EMA compliance, where each completed survey (three per day) served as a lottery ticket. Any bonus earnings were paid out at the end of the study.

The original preregistration specified a target of 100 usable datasets, evenly distributed across conditions. Shortly after data collection began, we updated the stopping rule via a registered amendment (https://osf.io/gepnk/),, as recruiting in discrete batches and waiting up to seven weeks per batch to assess attrition made the original plan logistically unfeasible within the available timeframe. This amended stopping rule described that enrolment would cease after 120 participants had completed the first three weekly questionnaires, based on an expected 15% attrition rate thereafter.

Of the 233 eligible applicants, 76 (32%) dropped out before the study began, leaving 157 who started. Of these, 30 (19%) did not complete the full three weeks and were excluded, leaving 127 completers. This number is slightly higher than the target of 120 because some participants were already partway through the study when the enrolment threshold was reached, consistent with the anticipated attrition buffer. Of the 127 completers, 10 were excluded for the following reasons: missing SMU data (n = 2), implausible smartphone data (weekly mean screen time below 15 min/day or above 16 h/day; n = 3), failing both attention checks (n = 1), and continued social media use during the detox exceeding the preregistered threshold of 20% of baseline usage (n = 4). The final sample consisted of 117 participants. A further exclusion based on the same detox-adherence threshold was applied to the waitlist group for the withinsubject analyses, resulting in N = 112 for those analyses.

2.2 Design and procedure

This study employed a randomised controlled trial (RCT) design. Participants were randomly assigned to either an immediate detox group or a waitlist group. As illustrated in Figure 1, the waitlist group completed three weeks of baseline measurements before starting the detox, allowing us to compare detox and follow-up effects in the experimental group against the waitlist group's baseline weeks. All participants ultimately completed the detox, enabling both a between-subjects comparison (n = 50 vs n = 67) and a within-subject analysis in a larger sample (n = 112).

Data were collected at four timepoints: baseline (T0), intervention (T1), post-detox (T2), and a final follow-up three weeks after the detox (T3). The waitlist group had two additional baseline weeks before following the same procedure (BL0 and BL1), while BL2 did double duty as baseline (T0) for the within-subject comparisons. During baseline week(s), participants were instructed to use social media as usual. At the start of the detox week, they were asked to remove all social media apps from their smartphones and to stop using these platforms on any other devices or browsers (e.g., laptops, tablets). The detox covered the following social media platforms: Facebook, Instagram, Pinterest, Reddit, Snapchat, TikTok, Buzzfeed, Tumblr, Twitter, and YouTube (selected based on Brown & Kuss, 2020). WhatsApp and similar direct-messaging apps were excluded, both because they fall outside the scope of social media as operationalised in the literature (Bayer et al., 2020) and for practical reasons.

Participants were free to remove additional apps if they wished. During the three follow-up weeks, participants could reinstall and use social media as they pleased.

Each Monday, participants received a weekly instructions-email and a link to a

Qualtrics survey (version April 2021), sent via an automated in-house mailing system. A reminder was sent at 8pm if the survey had not yet been completed. If participants had still not responded by the following morning, they were contacted by phone. Those who had not completed the survey within 24 hours of the initial email (Tuesday noon) were dropped from the study. Two attention checks were included at T1 and T2 (e.g., "If you are still paying attention, select 'Completely agree'"). One participant who failed both checks was excluded from the analyses.

To enhance detox compliance, we implemented several behaviour change techniques at the start of the intervention. These included signing a self-commitment contract and watching a motivational video. Participants also reflected on their reasons and goals for the detox, anticipated challenges, and strategies to overcome them.

2.3 Measures

The measures described below were administered at all timepoints, with the exception of BL1 for the waitlist group, where the craving and mental wellbeing surveys were unintentionally omitted. This precluded a between-groups test of changes during the detox week for these measures, but the pre-post comparisons (comparing T0 and T2 to BL0 and BL2, respectively) and within-detox-group changes (T0 vs. T1) were unaffected. In all surveys, participants were asked to reflect on their experience over the past week.

2.3.1 Smartphone and social media usage

Social media and smartphone usage were assessed using the built-in smartphone apps Screen Time (iOS) and Digital Wellbeing (Android). At each timepoint, participants retrieved and reported three metrics from the preceding week: (1) total daily screen time, (2) daily number of unlocks (referred to throughout as "pickups"), and (3) (time spent on) top three most-used social media apps, which we subsequently summed to obtain daily social media use. Weekly scores were computed as the average of the available daily values. At T0 and T3, participants retrospectively reported the preceding two weeks. At the end of the detox week, participants additionally uploaded screenshots of their Screen Time or Digital Wellbeing data. These were requested to encourage accurate self-report, and only in case of doubt did we cross-reference them with the reported values. The processing of the reported values is described in the Supplementary Methods.

Because iOS and Android operationalise these metrics slightly differently, we compared baseline values between operating systems. Only pickups differed (Supplementary Methods). Because pickups were only analysed as within-person change over time, we pooled across both operating systems in all analyses.

2.3.2 Automaticity

Subjective automaticity was measured using the Self-Report Behavioural Automaticity Index (SRBAI; Gardner et al., 2012), a four-item scale (e.g., "I do automatically," "I do without thinking") with responses ranging from 'Strongly disagree' (1) to 'Strongly agree' (7).

Participants completed the SRBAI only if they reported using social media in the past week.

Following our preregistration, we distinguished between automaticity of opening (reflecting on the moment of selecting a social media app) and automaticity of usage (reflecting on scrolling behaviour once the app is open), using the stem "Going on social media is something…" and "Using social media (i.e., once opened and scrolling) is something…," respectively. Scores were computed as the mean across four items (range 1-7). Reliability was excellent across timepoints (Cronbach's α = .87-.94).

The two scales were highly correlated across timepoints (r = .67-.78; Supplementary Table S8), indicating substantial shared variance. Since the intervention primarily targets the initiation of social media use, all analyses focus on automaticity of opening. The detox effect was also present for automaticity of usage (Group × Time, F(1, 115) = 17.67, p < .001).

2.3.3 Craving

Craving was measured using the five-item Social Media Craving Scale (SMCS; Savci & Griffiths, 2019). Items assess the frequency, intensity, and duration of craving, ability to resist craving, and overall craving severity, rated on a 7-point scale (0-6). An example item is: "In the past week, how often have you thought about using social media, or about how good using social media would make you feel?" The scale score is the mean of all five items (range 0-6), with higher scores indicating greater craving. Reliability was good across timepoints (Cronbach's α = .79-.86).

2.3.4 Self-reported slips

To examine whether participants continued to reach for social media apps after removing them -i.e. habitual 'slips' -we asked, each evening during the detox: "Did you have a moment today that you wanted to open one of your social media apps, before realizing that the app had been removed from your phone?" Those who responded positively were asked to estimate how often using ordinal categories (1 = 1-3 times,2 = 4-6 times,3 = 7-10 times,4 = 10+ times). These data were collected using the Avicenna mobile application (Avicenna Research, https://avicennaresearch.com/ formerly Ethica Data). Throughout the whole study, participants also completed brief Ecological Momentary Assessment (EMA) surveys on craving and automaticity three times daily (at pseudo-randomised times within fixed morning, afternoon, and evening windows). This repeated self-monitoring likely encouraged active reflection, which we expected to improve the accuracy of weekly retrospective assessments.

2.3.5 Mental wellbeing, sleep, and mental health symptoms

Participants completed three self-report measures related to their psychological functioning at each survey timepoint. Mental wellbeing was assessed with the Warwick-Edinburgh Mental Wellbeing Scale (WEMWBS; (Tennant et al., 2007), a 14-item measure of positive aspects of mental wellbeing covering psychological functioning, satisfying interpersonal relationships, and positive affect. Items are rated on a 5-point Likert scale (1 = none of the time to5 = all the time) and summed to a total score ranging from 14 to 70. Higher scores indicate greater mental wellbeing. Sleep quality was measured with the single-item Sleep Quality Scale (Snyder et al., 2018), in which participants rated their sleep over the past week from0 = terrible to10 = excellent. Symptoms of depression, anxiety, and stress were assessed with the 21-item Depression Anxiety Stress Scales (DASS-21; Henry & Crawford, 2005), which contains three subscales of 7 items each. Items are rated on a 4-point scale (0 = not at all to3 = very much) and summed within each subscale. Subscale scores are multiplied by two following standard scoring conventions, yielding a range of 0-42 per subscale with higher scores indicating greater symptom severity. Internal consistency across the four timepoints was good to excellent for all scales: WEMWBS α = .90 -.94, DASS-21 anxiety α = .76 -.85, depression α = .86 -.90, and stress α = .81 -.85.

2.3.6 Follow-up surveys

As preregistered, participants were invited to complete follow-up surveys post-detox, including the same questionnaires as the weekly surveys (with weekly rather than daily screentime metrics). The 12-week follow-up offered €5 compensation and yielded a low response rate (n = 34). To improve response for the final follow-up, we increased compensation to €10 and sent reminder emails, resulting in a higher response rate at 24 weeks (n = 51, of whom 49 provided usable objective social media use data). Because the 24-week wave yielded a substantially larger sample than the 12-week wave, we report self-report measures from the 24-week followup in the main text (12-week results in Supplementary Table S4), whereas for social media use, our primary outcome, we report both follow-ups.

2.3.7 Additional measures

At baseline (T0), participants completed a survey that included questions on demographics (gender, age, education, employment), and open-ended questions about how they used social media. Both before and after the detox, participants reported on their subjective experiences with using social media, including perceived control over use, purposefulness of use, proportion of mindless use, perceived appropriateness of one's SMU, and liking of social media (details are in Supplementary Table S2). At the end of the detox (T1i and T3w), we additionally inquired about their experiences with the detox. This included questions about whether they found the detox useful (1 = not useful,7 = extremely useful), if they would recommend the detox, and if they became aware of any triggers of social media use.

2.4 Data analyses

Below, we describe our preregistered confirmatory analyses followed by exploratory analyses.

Across these analyses, two complementary analytical approaches were used. The first approach is a between-groups comparison of the immediate detox (N = 50) and waitlist group (N = 67), used for the three preregistered hypotheses on the effect of the detox (RQ1-RQ3), and the exploratory mediation and moderation analyses. The second approach combines data from both groups after each had completed the detox, providing within-subject pre-post comparisons for the full sample (N = 112) across up to three weeks of follow-up. This was used for the two remaining preregistered analyses regarding predictors of the reduction in SMU (RQ4) and habitual slips during the detox (RQ5), and for the exploratory analyses on longitudinal effects and mental wellbeing. Analyses were conducted in R, version 4.5.3 (R Core Team, 2026).

2.4.1 Confirmatory analyses

We first describe the confirmatory analyses corresponding to our five preregistered research questions. Deviations from the preregistration are reported under 2.5.

2.4.1.1 Effects of the detox on social media use, automaticity, and craving (RQ1-RQ3; between-group)

Three confirmatory hypotheses concerning the effects of the detox on social media use (RQ1), automaticity (RQ2), and craving (RQ3) were tested using mixed ANOVAs with Time (pre, post) as a within-subject factor and Group (detox, waitlist) as a between-subjects factor. For SMU, baseline was computed as the average of the two weeks preceding the detox to obtain a stable estimate, given that daily SMU can fluctuate considerably. For automaticity and craving, the single pre-detox baseline week was used (a two-week automaticity baseline, as in the within-subject analyses, gave the same result; Supplementary Section S3.5). A significant Group × Time interaction would reflect a differential pre-to post-detox change between groups. Significant interactions were followed by planned simple effects (pre vs. post within each group), reported without correction for multiple comparisons given the small number of a priori, directional contrasts.

As robustness checks on the preregistered between-groups results, we additionally report (a) the SMU analysis excluding extreme outliers (defined as values > 3 SD from the within-group mean on the post-detox measure) and (b) comparisons of pre-post change scores between groups with an independent t-test, which also provided Cohen's d with 95% confidence intervals. As preregistered, we also repeated the analyses including the participants who did not adhere to the detox, restricted to participants who did not use social media at all during the detox, with log-transformed SMU, and with non-parametric tests (Supplementary Section S3.5).

2.4.1.2 Predictors of detox success: mechanism and slips (RQ4-RQ5; within-subject)

RQ4 tested whether the reduction in SMU following the detox could be predicted by (i) prepost change in automaticity, (ii) during-detox craving, and (iii) baseline motivation to reduce SMU. We tested this with a multiple regression of pre-post SMU change on the three predictors (preregistered as a linear mixed model; Supplementary Materials S2, Deviation 3). We additionally report an ANCOVA predicting post-detox SMU from baseline SMU and the same predictors, which adjusts for individual differences in starting level. The preregistered research question was whether automaticity, craving and motivation mediate the effect of the detox on SMU. We therefore additionally report formal mediation analyses (Section 3.3.1) as a more direct (but exploratory) test of the mediation hypothesis.

For RQ5, we tested the preregistered prediction that the number of habitual slips during the detox week could be predicted from baseline SMU, automaticity, and craving. Two participants did not complete the daily slips reports, so this analysis included 110 participants.

As for SMU, baseline automaticity in the within-subject analyses was the mean of the two predetox weeks, to obtain a more reliable baseline for the change scores. Craving was only measured in the last pre-detox week. The ordinal frequency categories were recoded to approximate counts (Supplementary Materials, Section S1.3), and the seven daily values were averaged into a weekly mean slips score. We tested the preregistered hypothesis by entering baseline SMU, automaticity, and craving simultaneously as predictors in a regression model on the weekly mean. As a robustness check, given the right-skewed count nature of the slips outcome, we repeated the regression as a negative binomial model of the weekly total of the recoded daily values, with the number of completed daily reports as offset. We additionally examined how slips developed over the course of the detox week with an exploratory repeatedmeasures ANOVA on the seven daily values, restricted to the 81 participants who completed all seven daily reports.

2.4.2 Exploratory analyses

We conducted several exploratory analyses to complement the preregistered tests. Using the between-group sample, we tested whether the detox's effect on SMU was mediated by changes in automaticity or craving, and whether baseline characteristics moderated the effect (3.3.1-3.3.2). Using the within-subject sample, we examined how a range of outcomes changed over time with mixed ANOVAs, including Time as a within-subject factor. The specific timepoints varied by measure and are stated with each result. Group (initial detox vs. initial waitlist) was added as a between-subject factor to check whether within-subject trajectories differed between the groups; all Group and Group × Time effects are reported in the Supplementary Material (Section S3.6 and Tables S5 and S6). Post-hoc comparisons were Bonferroni-corrected.

2.5 Deviations from preregistration

We deviated from the preregistration on nine points (Supplementary Section S2). One affects the interpretation of a confirmatory result: H3 predicted that craving would increase during the detox, but the analysis plan specified only a pre/post-detox comparison. We therefore tested H3 within participants (Section 3.3.5), which is a less severe test than a between-group comparison. The other deviations concern a reversed expected direction in the RQ4 analysis plan, analytic details the preregistration did not specify, and the missing 6-week follow-up.

3. Results

>Results

3.1 Sample characteristics & randomization check

The 117 included participants were randomly assigned to the detox group (n = 50) or a waitlist group (n = 67). The sample was predominantly female (106 female, 10 male, 1 other) and highly educated, with an average age of 23.5 years (SD = 4.0; range 17-37; one participant did not report their age). Of the 117 participants, 72 (62%) used iPhones and 45 (38%) used Android devices. The groups did not differ significantly on age, gender, education, or smartphone related metrics (all ps ≥ .16; see Table 2) indicating that randomization was successful.

Instagram was indicated most as primary social media app (n = 64, 54.7% of participants), while Facebook (n = 15, 12.8%), TikTok (n = 15, 12.8%) and YouTube (n = 15, 12.8%) were also often listed. As main reasons for the detox, participants selected most frequently: "Reduce my social media use, in order to free up time for other activities" (n = 87, 74.4%) and "Experience how it is to be offline, to get insight" (n = 76, 65.0%). On average, participants rated the detox as useful (M = 4.89, SD = 1.14 on a 1-7 scale) and 93% would recommend the detox to a friend.

When asked whether they had become aware of triggers that would normally initiate their social media use, the large majority of participants (90%) answered yes and elaborated on specific cues. By far the most frequently mentioned trigger was boredom (63% of elaborated responses). Another set of triggers clustered around downtime and transitional moments: breaks from work or study (26%), waiting or commuting (21%), idle time (11%), and moments around waking or going to sleep (15%).

Smaller proportions described notifications and messages (20%), procrastination (12%), negative emotions or stress (12%) as trigger, and habit or automaticity was even explicitly named a significant number of times (12%).

3.2 Confirmatory analyses

We first report three preregistered confirmatory hypotheses that concern between-groups comparisons of the detox and waitlist groups (RQ1-RQ3). We then report the two remaining within-subject preregistered analyses, on the mechanisms underlying the detox effect (RQ4) and (self-reported) habitual slips during the detox (RQ5).

3.2.1 RQ1: what is the effect of the detox on social media use?

The detox significantly reduced social media use one week later (Figure 2a). As hypothesised, significant main effects of Time, F(1, 115) = 20.82, p < .001, η²p = .15, and Group, F(1, 115) = 5.15, p = .025, η²p = .04, were further explained by a Group × Time interaction, F(1, 115) = 18.01, p < .001, η²p = .14. The detox was effective at reducing usage: participants in the detox group reduced their daily social media use by ~41 minutes (38.1%), from M = 107.2 minutes (SD = 61.0) at baseline to M = 66.4 minutes (SD = 58.0) one week post-detox (t(115) = 5.82, p < .001), whereas the waitlist group showed no meaningful change (M = 113.7, SD = 67.1 to M = 112.2 minutes, SD = 75.1; t(115) = 0.24, p = .81). One waitlist participant reported extreme post-detox social media use (>400 min/day). The Group × Time interaction remained significant when this participant was excluded, F(1, 114) = 17.39, p < .001, η²p = .13, confirming that the effect was not driven by this outlier.

To confirm the result did not depend on the analytic approach, we compared the prepost change scores between groups. This showed a significantly greater reduction in the detox group than the waitlist group, t(99.23) = 4.18, p < .001, Cohen's d = 0.79, 95% CI [0.41, 1.17].

Together, these analyses indicate that the detox successfully reduced social media use relative to the waitlist group.

3.2.2 RQ2: what is the effect of the detox on subjective automaticity?

The reported automaticity of opening social media was also significantly reduced due to the detox (Figure 2b). Again, significant main effects of Time, F(1, 115) = 29.06, p < .001, η²p = .20, and Group, F(1, 115) = 13.85, p < .001, η²p = .11, were complemented by a significant Group × Time interaction, F(1, 115) = 31.72, p < .001, η²p = .22. Subjective automaticity (range 1-7) was high at baseline in both the detox group (M = 5.52, SD = .94) and the waitlist group (M = 5.59, SD = .95), and significantly reduced one week post-detox in the detox group (M = 4.32, SD = 1.59; t(115) = 7.28, p < .001) but not the waitlist group (M = 5.62, SD = 1.06; t(115) = -0.18, p = .85).

Again, we also compared pre-post change scores between groups to confirm the result did not depend on the analytic approach. This showed a significantly greater reduction in the detox group, t(70.33) = 5.20, p < .001, Cohen's d = 1.05, 95% CI [0.66, 1.44]. Thus, the oneweek detox also reduced the experience of automaticity of opening social media.

3.2.3 RQ3: what is the effect of the detox on craving?

Our preregistered hypothesis (H3) was that craving would increase during the detox week. Due to the unintentional omission of the BL1 craving survey in the waitlist group, the preregistered between-group test of during-detox change could not be conducted. Notably, the within-subject test of H3 (Section 3.3.5), which is less severe than the preregistered between-group test, indicates that craving did not significantly increase during the detox, contrary to our prediction.

Here, we report on the between-group pre-post comparison.

The detox also significantly reduced craving one week later (Figure 2c). A significant main effect of Time, F(1, 115) = 17.73, p < .001, η²p = .13, but not Group, F(1, 115) = 0.82, p = .37, η²p = .01, was further explained by a Group × Time interaction, F(1, 115) = 7.73, p = .006, η²p = .06. This effect was driven by a significant decrease in craving in the detox group (from M = 2.82, SD = 1.02 at baseline to M = 2.23, SD = .96 post-detox; t(115) = 4.62, p < .001), which was absent in the waitlist group (from M = 2.73, SD = 0.98 to M = 2.61, SD = 0.98; t(115) = 1.09, p = .28).

We compared the pre-post change scores between groups, which showed a significantly greater reduction in the detox group, t(85.77) = 2.66, p = .009, Cohen's d = 0.52, 95% CI [0.15, 0.89]. Thus, the detox was associated with a significant reduction in craving from baseline to one week after the detox. In a sensitivity analysis restricted to complete abstainers (detox group n = 36), this effect was smaller and not significant (Group × Time F(1, 101) = 2.12, p = .15, d = 0.30; Supplementary Table S7).

3.2.4 RQ4: is the effect of the detox on SMU mediated by automaticity, craving or motivation to reduce usage?

As described in Section 2.4.1.2, we used the preregistered regression and an additional ANCOVA to test whether the reduction in SMU could be predicted by (i) change in automaticity, (ii) during-detox craving, and (iii) baseline motivation. The preregistered regression of pre-post SMU change on the three predictors was significant, F(3, 107) = 2.97, p = .035, R² = .08. Within this model, only automaticity change predicted the reduction in SMU (b = 9.25, SE = 4.54, p = .044; Figure 3a), whereas during-detox craving (b = -3.11, SE = 6.34, p = .63) and baseline motivation (b = 13.91, SE = 8.74, p = .11) did not. The association with automaticity change was stronger when one participant with an extreme increase in use was excluded, in a rank-based analysis, and with log-transformed SMU (Supplementary Section S3.5 and Table S7). This suggests that the preregistered linear estimate is conservative, as it is sensitive to a single extreme value.

In the additional ANCOVA analysis, we predicted post-detox SMU while adjusting for baseline SMU, which provides a more sensitive test by removing between-person differences in baseline use. The overall model was significant, F(4, 106) = 15.79, p < .001, R² = .37, largely driven by baseline SMU (b = 0.59, SE = 0.08, p < .001). Within this model, automaticity change again predicted post-detox SMU (b = -8.47, SE = 4.10, p = .042), whereas during-detox craving (b = 7.95, SE = 5.81, p = .17), and baseline motivation (b = -11.98, SE = 7.91, p = .13) did not.

Overall, participants whose automaticity decreased more also reduced their social media use more, whereas during-detox craving and baseline motivation did not predict such a reduction. This also answers our preregistered exploratory question on 'incubation' of craving: craving during the detox did not predict post-detox SMU.

In fact, craving did not increase during the detox (Section 3.3.5) and was reduced one week post-detox (Section 3.2.3). In exploratory mediation analyses (Section 3.3.1), we therefore used post-detox craving (rather than during detox) and post-detox automaticity as mediators.

3.2.5 RQ5: Do baseline SMU, automaticity, or craving predict habitual 'slips'?

If social media use is habitual, removing the apps should provoke 'slips of action': cuetriggered actions that persist even when the goal (opening the app) is no longer reached.

To test this, we asked participants at the end of every day during the detox how often they reached for their phone to use social media, before realising the apps had been removed. Nearly all participants (93.6%) reported at least one slip during the detox, with an average daily number of 2.30 slips (SD = 2.02) across the week. As an exploratory first step, we examined how self-reported slips developed over the detox week (Figure 3b). Among the 81 participants who completed all seven daily reports, the number of slips decreased steadily across the week, from a mean of 3.49 (SD = 2.80) on the first day to 0.86 (SD = 1.69) on the seventh day. A repeated-measures ANOVA confirmed a significant decline over time, F(4.63, 370.24) = 18.09, p < .001, η²p = .18.

To test our preregistered research question about predicting the number of self-reported slips during the detox from baseline measures, we entered baseline SMU, automaticity, and craving, simultaneously as predictors into a regression model. The overall model was significant, F(3, 106) = 4.05, p = .009, R² = .10. Of the three predictors, only automaticity was significantly associated with slips (b = 0.58, SE = 0.21, p = .007, 95% CI [0.16, 0.99]): participants with stronger habitual automaticity at baseline reported more slips during the detox (Figure 3c). Baseline SMU (b = 0.002, SE = 0.003, p = .38) and baseline craving (b = 0.12, SE = 0.20, p = .52) did not significantly predict slips. Because slip scores were right-skewed counts, we repeated the analysis as a negative binomial regression. This confirmed the preregistered result: baseline automaticity remained the only significant predictor of slips (b = 0.27, SE = 0.10, p = .006), while baseline SMU (p = .20) and craving (p = .52) did not. We additionally tested whether the effect of the detox on SMU was moderated by participants' baseline usage, automaticity, or craving. We ran three separate regression models predicting post-detox SMU from group, a (mean-centered) baseline moderator, and their interaction.

The within-subject analysis further confirmed the effectiveness of the detox in reducing SMU up to three weeks later (Figure 4a-b). Excluding three participants with extreme (> 3 SD) SMU one week post-detox, including the participants who did not adhere to the detox, or restricting the sample to complete abstainers did not change these results (Supplementary Table S7).

The impact of the detox on automaticity was also sustained three weeks later (Figure 4c). A mixed ANOVA across three timepoints (pre, one week post, three weeks post; n = 111, see Section 2.4.1.2) revealed a significant main effect of Time, F (1.81, 197.66) = 58.67, p < .001, η²p = .35. Post-hoc comparisons indicated that, relative to baseline (M = 5.58, SD = 0.93), automaticity was significantly reduced at one week post-detox (M = 4.35, SD = 1.59; p < .001, d = 0.89). Similar to SMU, automaticity increased from one week to three weeks post-detox (p = .015), indicating a partial rebound, but importantly remained significantly reduced at three weeks post-detox (M = 4.63, SD = 1.49; p < .001, d = 0.73).

3.3.5 Enduring (up to three weeks) effects of the detox on craving

Craving was also assessed during the detox week itself (Figure 4d), allowing a within-subject test of H3 in place of the preregistered between-group test. This analysis therefore included all four timepoints (baseline, detox week, one and three weeks post-detox).

There was a significant main effect of Time, F(2.70, 296.83) = 38.82, p < .001, η²p = .26. Posthoc comparisons indicated that, contrary to our preregistered prediction, craving during the detox week (M = 2.79, SD = 0.98) did not significantly differ from baseline (M = 2.69, SD = 0.98; p = 1.00, d = 0.11). Craving was significantly reduced relative to baseline at one week post-detox (M = 2.08, SD = 1.00; p < .001, d = 0.68) and remained significantly reduced at three weeks post-detox (M = 2.06, SD = 1.08; p < .001, d = 0.72). In contrast to automaticity and SMU, craving did not increase from one week to three weeks post-detox (p = 1.00), indicating no rebound effect.

3.3.6 Effect of detox on subjective relationship with social media

We additionally examined whether the detox shifted participants' perceived control over use, purposefulness of use, proportion of mindless use, perceived appropriateness of one's SMU, and liking of social media from baseline to three weeks post-detox. Three of these single-item measures showed substantial changes: perceived control over use increased (p < .001, d = 0.60), self-reported proportion of mindless use decreased (p < .001, d = 0.49), and perceived appropriateness of one's SMU shifted from "way too much" toward "just right" (p < .001, d = 1.00). In contrast, neither liking of social media nor perceived purposefulness changed significantly. The full results are reported in Supplementary Table S3.

We were additionally interested in the relationship between perceived control and automaticity of social media use. At baseline, participants with higher automaticity reported lower perceived control over their social media use (r = -.38, p < .001). Interestingly, individuals who reduced their automaticity more from baseline to three weeks post-detox reported larger increases in perceived control (r = .34, p < .001).

Together, the detox left participants feeling more in control of their social media use, less mindless about it, and closer to an amount they were comfortable with, without changing how much they liked social media or how purposeful they considered it.

3.3.7 Long-term (up to six months) effects of the detox

A subset of participants completed long-term follow-up surveys at 12 weeks and 24 weeks post-detox, providing usable SMU data for, respectively, 34 (30%) and 49 (44%) of the 112 included participants. At 12 weeks, SMU (M = 77.2, SD = 51.8) was still significantly lower than at baseline (M = 103.2, SD = 58.5), t(33) = 3.35, p = .002, Cohen's d = 0.57, 95% CI [0.21, 0.93]. At 24 weeks, SMU (M = 86.3, SD = 69.5) remained significantly lower than at baseline (M = 111.3, SD = 69.2), t(48) = 3.05, p = .004, Cohen's d = 0.44, 95% CI [0.14, 0.73].

Responders and non-responders did not differ in pre-post SMU change (both ps > .51), nor in baseline or post-detox SMU (all ps > .32) at either follow-up, indicating that the long-term reductions were not driven by differential retention of stronger responders.

Turning to the self-report measures at 24 weeks (n = 51, 46%; 12-week results in Supplementary Table S4), automaticity remained reduced 24 weeks after the detox (M = 5.77 vs. 4.99; d = 0.60, p < .001), and craving was also lower than at baseline (M = 2.63 vs. 1.91; d = 0.69, p < .001). Other self-report measures did not differ from baseline (Supplementary Table S4). Given the modest, self-selected subsample, these long-term self-report findings should be interpreted with caution.

3.3.8 General smartphone use during and after the detox (total screentime and pickups)

To assess the effect of the detox on overall phone use, we analysed total screentime (which includes social media use), non-social-media screentime (total screentime minus SMU), and the number of phone pickups across the four study timepoints (Supplementary Figure 1). Both screentime measures showed a significant main effect of Time (total: F(2.64, 290.03) = 22.72, p < .001, η²p = .17; non-social-media: F(2.77, 305.15) = 27.55, p < .001, η²p = .20), but in opposite directions. During the detox week, total screentime decreased relative to baseline (p < .001), whereas non-social-media screentime increased (p < .001). After the detox, total screentime was still lower than baseline one week post-detox (p = .002), in line with the sustained reduction in SMU, and returned to baseline by three weeks (p = .24), whereas nonsocial-media screentime returned to baseline at both timepoints (both ps > .41). The number of daily pickups did not change across the four timepoints (F(2.57, 282.69) = 0.30, p = .80, η²p < .01), suggesting that the detox affected how long people stayed on their phones rather than how often they reached for them. Full results are reported in Supplementary Table S5.

Thus, the detox reduced total phone use because social media were not used, but other phone activities partly replaced social media, and participants picked up their phones as often as before.

3.3.9 Effect of detox on affective and mental wellbeing

Finally, we examined whether the detox affected sleep, mental wellbeing and affective wellbeing (anxiety, depression, and stress). All five measures showed a significant main effect of Time (all ps ≤ .041; Figure 5 and Supplementary Table S6), driven by two different patterns of results. Mental wellbeing significantly improved during the detox week (d = 0.42), and sleep quality showed a small, non-significant improvement (d = 0.23, 95% CI [0.04, 0.42]; p = .057 after Bonferroni correction). Both returned to baseline at one and three weeks post-detox. In contrast, the DASS-21 symptoms showed more lasting reductions: anxiety, depression, and stress were all reduced during the detox (d = 0.49, 0.32, and 0.39) and remained significantly below baseline three weeks later (d = 0.25, 0.27, and 0.31). Thus, the detox produced a temporary improvement in subjective sleep and wellbeing only during the detox, but a more lasting reduction in negative emotions. Because these measures were only compared withinsubject, the changes cannot be attributed to the detox with certainty. Moreover, the time course of mental wellbeing, anxiety and stress differed between groups (Group × Time, all ps ≤ .037; Supplementary Table S6): both groups improved during their detox, but only the immediatedetox group maintained these improvements afterwards, whereas the waitlist group returned to baseline.

4. Discussion

Can a brief social media detox provide a window of opportunity for breaking social media habits in individuals motivated to reduce their usage? The present randomised controlled trial suggests the answer to this question is yes: a one-week detox significantly reduced subsequent social media use and subjective automaticity, and to a lesser extent craving, relative to a waitlist control group. The reductions in use and automaticity persisted at three-week follow-up and remained evident at six months in a smaller subsample. Importantly, as expected, participants whose automaticity decreased more also reduced their use more, consistent with the idea that the detox works (at least partly) by disrupting automaticity.

Several strands of evidence support the interpretation that the detox worked by disrupting habits. First, the detox reduced not only social media use but also the automaticity of opening social media, and the size of this reduction predicted the reduction in use ( RQ4).

An exploratory mediation analysis pointed in the same direction, although the indirect effect was not significant. Second, although self-reported automaticity warrants some caution in interpretation (Hagger et al., 2015), our findings lend further credibility to the measure: baseline automaticity predicted self-reported slips of action during the detox week, mirroring experimental laboratory work (Watson et al., 2022). Third, larger decreases in subjective automaticity were associated with larger increases in perceived control, consistent with automaticity and control representing opposing processes. Finally, reductions in social media use were sustained at follow-up, in line with the detox successfully disrupting social media habits. Together, these findings support the idea that -by removing behavioural accessibility -a social media detox can destabilise social media habits, creating an opportunity for lasting behaviour change in individuals motivated to change. These findings add to existing evidence that the frequency of social media use is strongly associated with its automaticity (Anderson & Wood, 2025) and the self-reported habit strength of social media use is high (Sharpe et al., 2025).

Contrary to our expectations, craving did not increase during or following the detox. In hindsight, this is perhaps not surprising given our temporary, one-week abstinence period.

Incubation of craving effects have been primarily demonstrated in addiction contexts where abstinence is maintained over weeks to months (e.g. Parvaz et al., 2016). Previous social media detox studies have reported mixed effects on craving, though most assessed it during or immediately after abstinence (Stieger & Lewetz, 2018; Wadsley & Ihssen, 2023; Wilcockson et al., 2019). We extend these findings by showing that craving remained reduced in the weeks following the detox, although this reduction was unrelated to changes in social media use.

Our findings contribute to the literature on what kind of interventions are likely to help, and for whom (Vanden Abeele et al., 2024). The detox was most effective for heavier users, although this partly reflects that they had more room to reduce. The finding that a one-week detox produces lasting behavioural change, rather than merely suppressing use while access was restricted, is promising for detox interventions and addresses a gap in the literature, which is dominated by short-term or during-intervention outcomes. Notably, our results speak to a broader question about how (digital) behaviour change interventions work. Our detox can be contrasted with a recent intervention that disabled smartphone notifications for one week (Dekker et al., 2025). Unlike our detox, this did not reduce smartphone checking or screen time, nor improve perceived control, although it did reduce perceived checking-habit strength.

The authors offered two explanations: one week may be too brief to disrupt ingrained habits, or smartphone use is largely self-initiated rather than notification-driven, in line with naturalistic evidence (Heitmayer & Lahlou, 2021). Our findings argue against the first, as a one-week detox did produce lasting reductions, and are consistent with the second. If the cues that drive social media use are largely internal, such as boredom, removing external cues such as notifications should have little effect, whereas removing access prevents the habitual response regardless of what triggers it. Although this comparison is across studies, it suggests that removing access to the behaviour, rather than some of its cues, may be more effective in disrupting well-established social media habits.

Furthermore, the current detox -through temporary app removal -appears to be more effective than interventions that rely on planning (e.g. Brockmeier et al., 2025; Keller et al., 2021). One explanation could be that such planning interventions mainly target self-regulatory processes, and that this does not work well for social media. In contrast, approaches targeting automatic processes directly, such as adding friction through a brief pause before an app opens (Grüning et al., 2023), combining nudge-based interventions such as greyscale and disabling notifications (Olson et al., 2023), or personalised, automatic interventions specifically targeting habitual use (Roffarello & De Russis, 2021), seem to be more effective. A detox fits into this second category, as it works on the automatic response (by removing behavioural access) rather than on the intention.

Our finding that reductions in social media use persisted for three weeks and (in a smaller subsample) up to six months, converges with Allcott et al. (2022), who found that a three-week financial incentive to reduce social media use produced reductions lasting six weeks after withdrawal. While this is encouraging, in both cases usage did gradually drift back toward baseline, suggesting that a single disruption may not permanently reset a habit. These findings suggest that periodically abstaining may be needed to maintain a desired level of use.

Another important consideration concerns the scope of the effects of the detox. At all timepoints, total screen time decreased less than social media use, because it got replaced by other phone use -particularly during the detox. This pattern is consistent with the broader media displacement literature (Vanden Abeele et al., 2024). Moreover, phone pickups did not change at any point, which suggests that the internally triggered self-interruption that drives most smartphone interactions (Heitmayer & Lahlou, 2021) remained intact, with other applications displacing social media. Importantly however, despite the limited reduction in overall smartphone use, anxiety, stress, and (to a lesser extent) depressive symptoms did reduce up to three weeks after the detox, extending Calvert et al. (2025) who similarly found affective wellbeing improvements during a social media detox even as total screentime increased. These within-subject changes should be interpreted with caution, however, as only the immediatedetox group maintained them. Mental wellbeing showed a subtle improvement during the detox, consistent with recent meta-analyses (Ansari et al., 2024; Lemahieu et al., 2025), but this effect was not sustained afterwards. This is consistent with evidence that mental health relates not to total smartphone use but to the automaticity and centrality of specific apps within users' smartphone routines (Turner, Gastelum, et al., 2026), which is precisely what our detox disrupted by specifically reducing social media. The detox also improved participants' subjective relationship with social media, increasing perceived control and appropriateness of use, and reducing mindless use, without altering how much they liked the platforms.

Limitations and future directions

We deliberately recruited participants highly motivated to reduce their usage. This has several benefits: alongside practical advantages such as reduced dropout, it reflects the population most likely to seek out and benefit from such an intervention. On the other hand, self-selection means our sample consists of precisely those most likely to adhere and to benefit, so our estimates likely represent an upper bound, rather than an average, on the effect in the general population (Vanden Abeele et al., 2025). Moreover, because automaticity and use were measured at the same timepoint, we cannot establish the direction of this effect. Truly establishing a causal role of automaticity requires designs that manipulate it directly.

Furthermore, both automaticity and slips of action relied on self-report, and their association should be read with common-method variance in mind. Future studies should assess the habit construct more directly, for example by measuring slips behaviourally rather than through selfreport. Finally, the randomised comparison extended only to one week post-detox. The effects at three weeks and six months rest on within-subject change, so we cannot rule out that part of the longer-term reduction reflects factors other than the detox.

Building on the present study, there are several promising directions for future research.

First, longer follow-up is needed to establish how durable these effects are. Second, future work could examine the optimal form of a detox: how long, how often, and what to detox from (e.g. social media or smartphone use in general). Full abstinence may not be necessary (Brailovskaia et al., 2023), and longer abstinence may not be better (Hall et al., 2019). Identifying the minimum effective dose is therefore an important next step, particularly given that spontaneously adopted disconnection strategies are not associated with reduced use (Dekker et al., 2026; Vanden Abeele & Nguyen, 2024). Third, testing the detox in samples that vary in baseline motivation and habit strength would improve generalisability and help disentangle how much each factor contributes to lasting change. Together, this could lead to concrete recommendations on how people can use a detox to change their social media habits.

Our findings also raise the question of which level of habit a detox actually targets.

Social media habits have been described as operating at multiple levels (Bayer et al., 2022), from broad contextual cues -which app or situation triggers use -to specific response tendencies, such as reacting to a notification versus scrolling a feed, to social media posting behaviour (Turner, Gunschera, et al., 2026). The effect of a detox is blunt: completely removing apps disrupts the whole system at once, which precludes any claim about which specific component is responsible for the effects we observed. A complementary route for future research would be to manipulate specific components of habitual use to identify the most effective levers for change.

In addition, we see value in developing more direct behavioural measures of habitual social media use. Slips of action -mindless, habitual initiations of app use -are clinically relevant because these could help to reveal the distinct contribution of habitual processes to social media use, alongside motivational and goal-directed processes (e.g., seeking information or relief from boredom). More broadly, social media and smartphone use offer a promising real-world model of high-frequency, low-effort habitual behaviour, in which behaviour can be directly measured in ecologically valid settings. This could make a valuable contribution to the habit research field more generally, which currently lacks reliable models of habitual behaviour in naturalistic settings. One concrete step in this direction is to measure automaticity of specific social media habits, rather than general opening automaticity, for example by identifying prominent personal triggers of social media use and assessing automaticity with respect to those specific triggers (e.g., "Going on Instagram when I'm feeling bored is something I do automatically"). Our findings point to several promising candidate triggers, including internal cues, most commonly boredom, and external cues, such as breaks, commuting, waking, going to sleep, or notifications.

Conclusion

Together, these findings offer support for the idea that social media use is highly habitual, and that a one-week detox was sufficient to destabilise it. Critically, these effects were not confined to the detox period, but persisted for weeks and, in a subsample, were still evident six months later. This suggests that the detox did not merely suppress behaviour temporarily but supported sustained behavior change through the disruption of social media habits. In other words, it facilitated a recalibration in which usage becomes less automatic and mindless, more in line with users' intentions, and more within their control. We hope the present work encourages further research into how digital disconnection can be optimised to support sustained digital wellbeing.

Deviations from preregistration Deviations are classified following Lakens (2024). Deviation 1: Test of H3 (missing information)

We hypothesised that craving would increase during the detox (H3), but the analysis plan specified only a pre/post-detox mixed ANOVA, which tests change after the detox. No analysis was specified for change during the detox.

We tested H3 by comparing detox-craving with baseline-craving (i.e. within-subject), pooling both groups (Section 3.3.5). We had envisioned to also run a between-group version of this test, but this was not possible because the craving questionnaire was left out of the waitlist group's BL1 survey through an administrative error. Without a concurrent control group, the within-subject test cannot separate an effect of the detox from changes over time. The preregistered pre/post comparison (Section 3.2.3) and the analysis predicting change in SMU from craving during the detox (Section 3.2.4) were not affected. Deviation 2: 6-week follow-up (mistake in study execution)

We preregistered follow-ups at 6, 12 and 24 weeks. Due to an oversight, the 6-week follow-up was not sent.

Long-term effects are reported for 12 and 24 weeks. These analyses were secondary, so the confirmatory tests are unaffected. Deviation 3: Analysis model for RQ4 (mistake in the preregistration)

We preregistered a linear mixed model to predict pre-post change in SMU. Change scores yield one value per participant, so there is no nesting to model.

We used multiple regression, the single-level equivalent. This did not affect the severity of the test. As a non-preregistered check, we also report an ANCOVA predicting post- detox SMU from baseline SMU and the same predictors.
