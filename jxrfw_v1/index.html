Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Introduction

The ability to represent temporal duration is a fundamental aspect of human cognition.

Humans encode passing time perceptually (see Grondin, 2010; Pöppel, 1997; Wittmann, 2013), but also in natural language via conventional units such as "second", "minute", and "hour" to denote precise durations, and expressions such as "more" or "longer" to compare relative durations (e.g., "John danced for more than two hours"). Although temporal language is highly frequent in early linguistic input, and time imbues every aspect of human experience, time words are mastered relatively late in acquisition (e.g., Shatz et al., 2010; Tillman & Barner, 2015; Tillman et al., 2017). In the current study, we explored the nature of this protracted development by investigating how children learn to encode passing time with the comparative "more."

Temporal comparison provides an important test case for understanding how children encode time linguistically, because whereas lexical representations of duration like "second" and "minute" are learned relatively late in development and are not adult-like until age 6 or 7 (see Tillman & Barner, 2015), children begin to use the comparative "more" by age 3 to quantify domains like number and space (Barner & Snedeker, 2006; Gathercole, 1985; Odic et al., 2013).

Combined with the observation that humans can discriminate temporal durations non-verbally beginning in infancy (e.g., Brannon et al., 2007), this raises the possibility that children can linguistically encode and compare temporal durations relatively early in development, and before they encode absolute duration information in words like "minute" and "hour". Given this, the current study investigated preschool-aged children's comprehension of the comparative "more" when used to evaluate relative temporal durations.

The ability to non-verbally discriminate temporal durations emerges early in development. By 6 months of age, infants are able to discriminate durations in 2:1 ratio (e.g., 1 vs. 0.5 seconds, 3 vs. 1.5 seconds, and 4 vs. 2 seconds), dishabituating when the duration of a familiarized event changes (Brannon et al., 2007; vanMarle & Wynn, 2006). By three years of age, children can make explicit judgments comparing the duration of two events. For example, in a study by Droit-Volet and colleagues (2001), children as young as 3 successfully judged that a stimulus duration (e.g., a circle appearing on a screen) differed from a previously trained standard of comparison (i.e., by identifying it as not being "their" circle) when the difference between the test duration and the standard was several seconds long (e.g., 4 vs. 8 seconds). In another study, Droit-Volet and Wearden (2001) trained children to associate one button with a short duration and another with a long duration (either 1 vs. 4 seconds or 2 vs. 8 seconds). After training, children were presented with intermediate durations (1.5-3.5 or 3-7 seconds, depending on the condition) and asked to choose which button corresponded to each. Three-year-olds reliably classified the shorter intervals with the "short" button and longer intervals with the "long" button, demonstrating sensitivity to relative differences in duration.

While these findings demonstrate that children can discriminate perceptual durations by at least age 3, it remains unclear whether they are able to encode and compare such comparisons in a symbolic, linguistic format, and whether this differs from their ability to reason about other domains, like number or space. Time may be especially difficult to encode linguistically because of its abstract nature: while not being a property of any individual object that we can perceive, it permeates every perceptual experience, posing a potentially difficult problem of identifying when a speaker intends to refer to time itself, rather than the objects and events that are situated within it (for discussion, see Gleitman et al., 2005; Shatz et al., 2010; Tillman & Barner, 2015; Tillman et al., 2024). Consistent with this, previous studies find that children's learning of duration words is highly protracted. While children produce words referring to absolute durations such as "second", "minute", and "hour" by as early as 3 years of age, they do not acquire adult-like meanings for these words until around age 7 (Grant & Suddendorf, 2011; Shatz et al., 2010; Tillman & Barner, 2015). Further, although 5-year-olds can judge the relative magnitudes of duration words like "minute" and "hour", they show little evidence of representing their absolute durations (Tillman & Barner, 2015).

It is currently unknown whether children undergo a similarly protracted learning trajectory when linguistically comparing relative durations. As in the case of learning duration words, to encode relative durations in comparative statements involving "more", children must represent the relative magnitudes of different events. Also, they must recognize that the linguistic unit "more" can apply to durations, and that events should be measured temporally -i.e., that someone who "did more dancing", did more of the event by virtue of having spent more time doing so. This latter process may be non-trivial, since events can be quantified by a wide range of dimensions other than time. For example, deciding who did "more helping" or "more eating" might be judged on the basis of time, but also on, e.g., how helpful one is, or how much food they ate (see Barner et al., 2008, for evidence that adults consider multiple possible dimensions for quantifying events). This leaves open the possibility that children do not readily select time as relevant when interpreting linguistic quantifiers like "more". On the other hand, encoding time with "more" may be easier than learning words like "minute" or "hour", given that the latter words require learning arbitrary culturally-mediated durations that may depend on learning number words and multiplicative relations (e.g., that an hour is 60 minutes). Whereas the comparison of relative magnitudes is commonplace in language and "more" can be applied to just about any dimension, children may not expect words to encode precise, arbitrary amounts of time. Thus, it is possible that encoding time in comparative language emerges earlier than other forms of temporal language, and perhaps on the same timeline as comparison of other domains like number or space.

Previous studies report that children begin to produce "more" at 2 years of age, though these initial productions are limited to the additive meaning of "more", as children often use "more" to request additional amounts (e.g., of food; Beilin, 1968; Carter, 1975; Gathercole, 2008; Weiner, 1974). By 3½, children begin to show evidence of understanding the comparative meaning of "more" as well, for both discrete number and continuous amount (Barner & Snedeker, 2006; Donaldson & Balfour, 1968; Gathercole, 1985; Odic et al., 2013; Palermo, 1973; Townsend, 1974; Wannemacher & Ryan, 1978; Weiner, 1974). Given these findings, if children are able to encode and compare relative durations as easily as other dimensions, then we might expect them to make comparative judgments with "more" for time by around age 3½.

Some previous studies suggest that once children learn the comparative meaning of "more", they may apply it equally well across different domains. First, in a study by Odic et al. (2013), children made accurate comparative judgments for both number and surface area between 3 and 3½ years of age. Based on this, Odic et al. argued that children learn to apply "more" to all domains of magnitude simultaneously. Relevant to this, some researchers argue that a common mechanism may underlie our perception of numerical, spatial, and temporal magnitudes (see Lourenco, 2015; Walsh, 2003 for reviews). As evidence for this, these studies note parallels in the development of the discrimination of magnitudes across domains -e.g., that 6-month-old infants can discriminate 2:1 ratios but not smaller ratios for numerical sets, spatial amounts, and temporal durations, while discrimination of 3:2 ratios emerges later, at 9-10 months (Brannon et al., 2004 (Brannon et al., , 2006 (Brannon et al., , 2007;; Lipton & Spelke, 2004; vanMarle & Wynn, 2006 , 2009; Xu, 2003; Xu & Spelke, 2000; Xu et al., 2005). Also, some studies find cross-domain transfer between infants' representations of space and time (e.g., in which infants associated longer durations with larger numbers or sizes; de Hevia & Spelke, 2010; de Hevia et al., 2014; Lourenco & Longo, 2010; Srinivasan & Carey, 2010). However, others question these claims, and argue either that magnitude is represented by distinct, modality-specific systems for domains such as number, time, and space (Clarke & Beck, 2021; Odic, 2018; Yates et al., 2012), or that an initially general magnitude system present in infancy differentiates into domain-specific systems over development (Cantrell & Smith, 2013; Hamamouche & Cordes, 2019; Lourenco & Longo, 2011; Newcombe, 2014).

In the current study we investigated children's ability to linguistically compare relative durations in "more" constructions, and how this relates to their ability to make numerical comparisons. In Study 1, we tested 2½ to 4-year-old children with a Temporal Quantification Task in which they judged which of two people did "more" of an action like "waving", and compared this to a Numerical Quantification Task that asked them to make quantity judgments with the comparative "more" between arrays of objects. Because children could have succeeded on the Temporal Quantification Task in Study 1 via a bias to select the person who completed the action last, in Studies 2 and 3 we tested 3-to 4-year-old children in a Temporal Quantification Task in which the person who performed the action longer did not perform it last, removing the possibility of using such a bias.

Discussion

Study 1 found two main results. First, 3-and 4-year-olds were better than chance when making "more" judgments for temporal durations. Second, however, 3-and 4-year-olds performed better on the Numerical Quantification Task than the Temporal Quantification Task.

Together, these results suggest that children are able to quantify temporal durations relatively early in development and may apply quantifiers such as "more" not only to more concrete domains such as number but to more abstract domains such as time as well.

There are multiple reasons why children might have performed better on numerical than temporal quantification. One possibility is that children are able to compare relative magnitudes with "more" for number (and perhaps continuous amount; see Odic et al., 2013) first, and can only do so for time slightly later in development. Another possibility, however, is that children apply "more" to all dimensions simultaneously when they first use the word, and that differences in performance are due to differences in task demands. In particular, while sets of objects were presented statically and were available when the test question was posed in the Numerical Quantification Task, the actions in the Temporal Quantification Task unfolded dynamically and sequentially, requiring children to track and retain information in mind before making the quantity judgment. Supporting the possibility that task demands may have masked comprehension of "more", a follow-up study (reported in Supplementary Study 1) found that participants performed worse on numerical quantification than temporal quantification when the objects in each set were presented sequentially over a fixed period of time, possibly due to the even greater difficulty of tracking the number of objects presented in each set over time than tracking who performs an action longer.

Although children performed above chance on the Temporal Quantification Task at 3 years of age, consistent with a linguistic comparison of temporal duration, it is also possible that children simply selected the person who finished the action last (since the actor who performed the action longer always performed it last). Providing evidence against this possibility, a second follow-up study (reported in Supplementary Study 2) found that children selected the person who performed the action last (and longer) less often when "more" was replaced by a nonce word ("tiv") in the test question (e.g., "Who did tiv waving?"), suggesting that children's success on the Temporal Quantification Task cannot be fully explained by such a bias. Nonetheless, in Study 2 we designed a revised version of the Temporal Quantification Task that tested children's temporal quantification when a strategy to select the person who completed the action last was not possible.

Study 2

In Study 2, children completed a Temporal Quantification Task in which one person began performing an action before the other person joined in, and both ended their actions at the same time. Here, and in Study 3, we focused on assessing the nature of children's temporal quantification. Although one of our goals was to compare temporal quantification to other domains like number, Study 1 and Supplementary Study 1 convinced us that a perfectly controlled comparison of time vs. number might not be possible. When sets of objects are presented statically in a numerical quantification task, children are not required to track information over time in order to make a magnitude judgment, as they are in a temporal quantification task, introducing a potential difference in task demands as a confound in the manipulation of dimension of magnitude. This confound was present in Study 1, in which children performed better on a static numerical task than a dynamic temporal task. But while sets of objects can be presented sequentially over time instead, a numerical quantification task employing this mode of presentation still differs in a critical way from a temporal task. In such a version of the numerical task, objects are presented one by one, requiring children to individuate each object and update a count of objects in working memory for each actor. In contrast, while information unfolds over time as well in the temporal task, duration is experienced continuously rather than accumulated item by item, which may be more challenging. Children's worse performance in such a modified numerical quantification task in Supplementary Study 1 demonstrates this problem.

Given this limitation, in the remainder of this paper we aimed to create a strong test of children's ability to linguistically compare temporal magnitudes, and tested whether this ability emerged on roughly the same timeline as comparison in other domains, as reported in past work (Barner & Snedeker, 2006; Gathercole, 1985; Odic et al., 2013). This approach also allowed us to assess whether children's ability to linguistically compare temporal magnitudes emerges at the same time as duration words like "minute" and "hour", or if it instead emerges earlier in development.

Temporal Quantification Task. Children completed six trials. On each trial, children watched a video of two people sitting behind a table performing an action (Figure 1). The durations were reduced compared to Study 1 to minimize the amount of time the child was required to remember who had started acting first. For each action, one actor first performed the action alone for approximately two seconds, at which point the other actor began performing the action as well. For two more seconds, both actors performed the action, and then both stopped simultaneously. The actions performed were identical to those in Study 1. In half the trials, the person on the left performed the action longer and in half the trials the person on the right performed the event longer. The experimenter told the child, "Look, Kat is waving, and Hannah is waving too," and pointed to each person when naming them. At the end of each trial, the experimenter asked the child, "Who did more waving?" Children could respond either by pointing to the character or saying the character's name.

One-sample t-tests revealed that children performed significantly better than chance (0.5) on the Temporal Quantification Task (M = 0.60, SD = 0.24; t(89) = 4, p < .001). Discussion

We found that 4-year-olds, but not 3-year-olds, succeeded at a Temporal Quantification Task in which the person who performed the action more did not perform it last. This contrasts with our finding that both groups succeeded in Study 1. While the results of these studies provide strong evidence that 4-year-olds succeed, they leave open whether 3-year-olds lack knowledge or instead failed in Study 2 due to an inability to hold in working memory which actor began performing the action first. We explored this possibility in Study 3 by presenting children with scenes in which the actors alternated in performing actions that summed to an overall shorter or longer duration.

Study 3

In Study 3, participants completed a revised Temporal Quantification Task in which the actors alternated performing the actions, but the sum of the durations of one actor's actions was three times greater than that of the other. In this task, the person who acted last acted for a shorter total duration, meaning that the use of a strategy of selecting the person who acted last would actually result in answering incorrectly, in contrast to Study 1. This allowed us to test not only whether children could quantify time in this novel task, but also whether children, particularly younger children, exhibited a bias to select the person who acted last.

These results are compatible with the hypothesis that children acquire the ability to compare temporal durations with "more" at 4 years old. Three-year-olds' success in the Temporal Quantification Task in Study 1 is thus unlikely to be the result of such a bias.

General Discussion

Across three studies, we investigated children's ability to make "more" judgments for temporal durations, and found that this ability emerges sometime between 3 and 4 years of age.

In Study 1, children as young as 3 correctly identified an actor who performed an action "more" than a second actor. However, in Studies 2 and 3, only 4-year-olds made accurate "more" judgments when the actor who performed the action longer did not perform it last. These findings suggest that children are able to linguistically compare temporal durations earlier than they encode words like "second" and "hour", but around the same age (or slightly older) that they successfully compare durations in non-verbal tasks (Droit-Volet et al., 2001; Droit-Volet & Wearden, 2001) and make comparative judgments with "more" for number and continuous amount (Barner & Snedeker, 2006; Gathercole, 1985; Odic et al., 2013). These data suggest that, by at least age 4, children are able to identify temporal durations as the relevant dimension of comparison. This is not necessarily trivial, since most events are multi-dimensional and can be measured in multiple ways. For example, as people walk, they produce a number of steps covering a particular distance, and do so for a particular amount of time. Previous studies find that adults are sensitive to this ambiguity, and are able to identify multiple dimensions like number, distance, intensity, and time when asked how they would measure events like walking, dancing, and running (see Barner et al., 2008). Given these facts, when children are exposed to descriptions of events in their language input, they must not only identify the events that are referred to, but also which dimensions of experience are relevant to quantifying these events in different contexts -a task that is arguably more challenging than in domains such as number or space. Despite these challenges, our study suggests that by at least age 4 children are able to linguistically quantify the temporal durations of events. 1 not long after 1 Recall that we only selected actions which could not be clearly individuated (i.e., continuous actions such as "stretching", "cleaning", as opposed to repeated actions such as "clapping", "jumping", etc.), in order to prevent confounding duration with number of actions. they begin to quantify other dimensions like number and spatial extent (see Barner & Snedeker, 2006; Gathercole, 1985; Odic et al., 2013).

One question raised by this work is which abilities are involved when children compare temporal durations in natural language. On standard semantic analyses of comparative expressions containing "more", this process involves multiple steps. For example, to evaluate an expression like, "Kat did more waving than Hannah," listeners must represent the duration of each waving event, and then project these magnitudes onto a common scale of degrees. These degree values are then compared, supporting the interpretation of "more" (Cresswell, 1976; Kennedy, 2007; Kennedy & McNally, 2005). On some accounts, this scale of degrees is abstract, such that the same scale is deployed across different dimensions of measurement, permitting cross-dimensional comparison (e.g., "He is richer than he is smart"; see Bale, 2008). Thus, in order to interpret comparative statements for events quantified by time, children must encode each duration, represent each in an analog format on the same scale, and compare these degrees.

As noted in the Introduction, the present study is relevant to understanding children's acquisition of other duration expressions, like "second", "minute", and "hour", which are acquired gradually between the ages of 4 and 7 years of age (Shatz et al., 2010; Tillman & Barner, 2015). The present study suggests that the challenge of learning these expressions cannot be explained by factors like the salience of time, or by an inability to encode specific temporal durations. Instead, some accounts propose that duration words like "minute" may be hard because they represent culturally mediated arbitrary divisions of time that children do not spontaneously consider as possible meanings for words (Tillman et al., 2024). Also, previous studies suggest that such words may depend on prior mastery of exact numerical language.

Consistent with this, Tillman and Barner (2015) found that children do not represent the absolute durations of words like "minute", "hour", "day", etc., until they can explicitly state their definitions, e.g., how many minutes are in an hour.

While the main focus of this study was on children's comparison of temporal durations, it remains unclear whether the linguistic comparison of durations emerges in synchrony with comparison of other dimensions, like number and space, which emerge around 3½ years of age (Barner & Snedeker, 2006; Gathercole, 1985; Odic et al., 2013). In Study 1, we found that 3year-olds could identify the person who kept performing an action longer as having done "more" of it. However, when the person who did the action longer did not perform it last in Studies 2 and 3, 3-year-old children performed at chance, unlike 4-year-olds. A conservative interpretation of these mixed findings is that 3-year-olds cannot linguistically compare temporal durations (consistent with data from Studies 2-3). Thus, their success in Study 1 (replicated in Supplementary Study 1) may not reflect competence, but may instead reflect a bias to select the person who performed the action last. On this view, children initially use "more" to quantify concrete domains, and only later extend its application to more abstract dimensions like time, by virtue of both the non-linguistic similarities between representations of number, space, and time, as well as grammatical similarities in how words for these different domains are used (de Hevia et al., 2014; Gentner, 2001; Lakoff & Johnson, 1980; Murphy, 1996; Smith & Sera, 1992; Spence, 2011).

It is also possible that children learn to linguistically compare magnitudes with "more" for all dimensions simultaneously, as hypothesized by Odic et al. (2013), but that children's performance across domains is modulated by differences in task demands. On this account, the success of 3-year-olds in Study 1 might reflect genuine competence, whereas their failures in Studies 2-3 reflect task demands. Several findings support this analysis. First, in Supplementary Study 2, children chose the person who acted both longer and last less often when "more" was replaced with a nonce word, suggesting that children's judgments with time in Study 1 could not be explained by a baseline bias to select the person who completed the action last. Second, in Study 3, no age group performed below chance when the last actor acted for less total time, as would be expected if children had a last actor bias. Third, we found evidence that task demands may actually mask quantification competence in 3-year-olds. In Supplementary Study 1, children performed worse on numerical quantification than temporal quantification when actors placed objects into boxes sequentially in the numerical task. Given that they performed well in quantifying numerical quantities in Study 1 when arrays of objects were presented statically and were visually available at test, children's poor performance in Supplementary Study 1 cannot be attributed to a lack of ability to compare numerical quantities with "more", and is instead likely the product of task demands involved in tracking dynamically presented information over time.

The current study has several limitations which should be addressed in future work. First, while we focused our investigation on the comparative "more", children's use of other words which quantify relative duration such as "longer" should be investigated as well. Does use of both terms arise simultaneously, and does their application across domains follow a similar trajectory? Also, our investigation was limited to English, which uses one word "more", to compare quantities across all domains, whereas other languages use different quantifiers for different domains. For example, in Swedish, "fler" denotes more in number while "mer" denotes more in amount. Whether children learn to use these words simultaneously could shed light on the process of learning to use comparatives across domains. If these quantifiers are acquired simultaneously despite different evidence for mapping word to meaning (because they operate over different types of quantities), then there may be one common bottleneck for linguistically encoding comparisons of magnitude. But if they are acquired at different ages, then learning to encode comparisons of magnitude may be a challenge which is solved individually in each domain, with differences in the informativity of the evidence for mapping word to meaning possibly resulting in different ages of acquisition (see Gillette et al., 1999; Gleitman et al., 2005).

Finally, we controlled other domains of magnitude in the current study, such that temporal trials differed only in duration and numerical trials differed only in number. It would be interesting to contrast who did more in different domains (e.g., one person doing an action longer vs. the other at a greater rate) and ask children and adults to make quantity judgments to understand the relative dominance of different domains in judging magnitude, and to explore the influence of extra-perceptual factors such as verb semantics (see Barner et al., 2008).

In summary, we find that children are able to quantify temporal duration with the comparative "more" by 4 years of age, several years before they master other temporal language and about the same time or slightly later than their use of "more" in the domains of number and space. This sheds light on the mechanisms of time word learning and the reasons for which children may be delayed in learning other classes of time words, especially exact duration words.

We also suggest several avenues for future research, including further investigation on the simultaneity of children's learning of "more" across domains and exploration of cross-linguistic differences in quantification.
