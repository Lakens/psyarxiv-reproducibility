To improve Non-Significant P Value Check

What we found

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. This package was validated by the Metacheck team on articles in Psychological Science.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Codebook Check works

This module checks whether the data columns in a repository are documented in a codebook or README. It locates codebook/readme files, extracts the variable definitions they contain, matches those definitions against the data columns extracted by data_check, and reports documentation coverage: how many data columns are documented, and which documented variables are never used.

The Codebook Check module consumes the columns and file classification produced by data_check (and, transitively, repo_check). Files classified as codebook or readme are parsed with parse_codebook(), which reads structured tables (CSV/TSV/Excel with a variable-name column and a label column), embedded labels in haven files (SPSS/Stata/SAS), and plain text from rich-text formats (docx/pdf/rtf/odt). Embedded haven labels from data files are also harvested directly.

Each data column is then matched against the parsed variable definitions with match_column_labels(), using normalised-name matching with experiment-group scoping, haven-label priority, and rule-based label-equivalence merging.

Beyond the variable label, the module harvests the DDI-style per-variable properties a source supplies: the value labels / code list (the 1=“Strongly disagree”…5=“Strongly agree” mapping — from SPSS/Stata value labels and from a codebook “values”/“coding” column), the missing-value scheme (which codes denote missingness, from haven declared missings and labels that read as “refused”/“n/a”), and question text and columns when present. These are carried onto the matched data columns and exported into the Psych-DS variableMeasured (as a schema.org code list plus namespaced metacheck: fields).

The module defaults to rules-only when llm_use(FALSE). When llm_use(TRUE), three optional LLM tiers run: parsing unstructured codebook text that the rules could not handle, fuzzy-matching still-unlabelled columns to still-unmatched codebook variables, and merging conflicting label definitions into a single canonical label.

This module retrieves information from repositories.

The Repository Check module lists files on the OSF, GitHub, ResearchBox, DSpace (PsychArchives and other legacy- and DSpace 7-based installations), Zenodo, Dataverse, Figshare, Dryad, ReShare, 4TU.ResearchData, Mendeley Data, DataONE (Arctic Data Center, KNB, and other member nodes), and LDbase based on links in the manuscript.

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Checking code requires downloading its file contents. For a paper whose repository is on Dryad, this never succeeds unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (listing the repository’s files does not need one). Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Fluid intelligence (Gf) and working memory (WM) are strongly correlated, with the binding hypothesis suggesting that this relationship is driven by the capacity to bind content to context. However, it remains unclear how various binding functions overlap and relate to Gf. This study investigates the extent of overlap between five binding functions (item-tolocation binding, item-to-item binding, relational integration, relation processing, and perceptual feature binding) and their relationship with Gf. A sample of 174 young adults completed three visuospatial variants of tasks measuring these five binding functions alongside three Gf tasks. Data were analyzed using structural equation modeling and latent network analysis to evaluate shared and unique variances. Results indicated significant overlap among the binding functions, with item-to-location and item-to-item binding best modeled as a single latent variable termed binding memory. The shared variance among binding memory and the remaining binding functions was represented by a higher-order, process-general latent factor labeled Binding which was found to be statistically isomorphic with Gf. Latent network analysis further revealed that binding memory, relational integration, and relation processing each exhibited unique, direct relationships with Gf, whereas perceptual feature binding related to Gf only indirectly. These findings indicate that an overarching, domain-general ability to form and utilize bindings in a goal-directed manner is deeply intertwined with Gf, supporting theories emphasizing binding and relational mechanisms in Gf.

Binding Memory and Relational Mechanisms: The Central Role of Binding in Fluid Intelligence

A central goal in cognitive psychology is to understand the mechanisms that underlie fluid intelligence (Gf) and working memory (WM), because both Gf and WM support understanding and interacting with the environment, enabling crucial daily activities, such as cooking, reading, and navigating. Gf is the ability to reason and solve new problems, and WM is the ability to maintain and manipulate information for ongoing processing. Gf is strongly related to WM capacity (WMC; Kyllonen & Christal, 1990), but it is not clear why.

Understanding the relationship between Gf and WMC is crucial for building comprehensive models and theories of cognition.

One explanation for the WMC-Gf relationship is the binding hypothesis, which proposes that WMC and Gf are predominantly limited by the capacity for bindings between content and context representations rather than individual representations in WM (Oberauer, 2009; Oberauer et al., 2007). Whereas individual representations convey information about single elements (e.g., a cat), binding representations can convey relational information (e.g., a cat chasing a dog). The binding hypothesis specifies that such relational information is necessary for Gf. Specifically, the comparison and application of relational information are proposed to be necessary for inductive (Klauer, 1996) and deductive (Goodwin & Johnson-Laird, 2005) reasoning such that greater capacity for relational information allows for more complex reasoning. Thus, the binding hypothesis suggests that greater WMC equates to greater binding capacity, which allows for the comparison and application of more relational information and, thus, higher Gf (Oberauer et al., 2007 (Oberauer et al., , 2008)).

The binding hypothesis is mostly supported by evidence showing that binding errors, in which content in WM is bound to the incorrect context, occur more often than item errors, in which representations are recalled that are not bound to any task-relevant context (Bartsch & Oberauer, 2023; Henson et al., 1996; Oberauer, 2019; Pertzov et al., 2012). For example, Henson and colleagues (Henson et al., 1996) investigated recall for letters bound to their serial position and found that item errors only accounted for 3% of the total errors while binding errors accounted for 92% of all errors. Bartsch and Oberauer (2023) found a similar difference in the frequency of binding and item errors when using pictures bound to words and additionally found that item memory was unaffected by set size.

However, critical questions about the relation between binding, WMC, and Gf remain. First, it is possible that other abilities pertaining to binding, not binding capacity, are associated with Gf. For example, Chuderski (2019) examined the association between Gf and relation processing (the ability to represent, transform, and apply relations in the mind), operationalized with a relation matching task. In this task participants need to match identical bindings that stay on screen (for details and an illustration of our adaptation, see Method). Therefore, this task requires binding but is assumed to have minimal requirements on WMC. Nevertheless, strong associations with Gf were observed, suggesting that individual differences in Gf may be driven by binding but not binding capacity. Second, (Oberauer et al., 2007) proposed that the capacity for binding is limited by binding interference which occurs as a result of retrieval competition and representational interference between overlapping bindings. However, recent research found a lack of individual differences specific to the ability to manage binding interference (Garvey et al., 2026), questioning the viability of binding interference as the driver of individual differences in binding capacity and, therefore, WMC and Gf.

Along with relation processing, several binding functions have been proposed that have conceptual and, possibly, mechanistic overlap, and it is unclear how these abilities are related to each other and to Gf: item-to-location binding, item-to-item binding, relational integration, relation processing, and perceptual feature binding. The purpose of this study is to determine the extent of the overlap between these binding functions and their relationship with Gf.

Binding Functions

While binding capacity is thought to reflect a general ability, distinct types of binding may utilize different cognitive mechanisms. For example, an item can be bound to the space it had occupied (item-to-location) or to another item representation (item-to-item). Item-tolocation binding is operationalized with the local recognition task in which participants are sequentially shown items in different locations and then indicate whether probes represent the same items in the same locations (Oberauer, 2003). Item-to-item binding is operationalized with the associated-pairs task in which participants are sequentially shown pairs of items and then indicate whether probes represent the same pairs that were previously shown (e.g., Wilhelm et al., 2013). Shared variance in performance on the local recognition task (item-to-location binding) and the associated-pairs task (item-to-item binding) has been used in past research to indicate binding ability (De Simoni & von Bastian, 2018; Garvey et al., 2026). However, because it involves representations of two items, itemto-item binding may provide greater semantic richness than item-to-location binding. Semantic richness may facilitate retrieval from long-term memory (Brady et al., 2013; Konkle et al., 2010). This difference in the utilization of long-term memory may affect the variance that is shared between item-to-item and item-to-location binding. For example, representations in long-term memory may be less susceptible to binding interference. Indeed, it may be that Garvey et al. (2026) was unable to find significant individual differences in the ability to manage binding interference because this ability was indicated by shared variance in local recognition and associated-pairs tasks. If the associated-pairs task utilizes long-term memory, and long-term memory is not susceptible to binding interference, then the shared variance between the associated-pairs and local recognition tasks would not be indicative of binding interference.

Another proposed binding function is relational integration, which is the ability to integrate bindings into structural representations. In context of the binding hypothesis, structural representations permit the comparison and application of relational information and, therefore, reasoning ability (Oberauer, 2009; Oberauer et al., 2008). Relational integration has been found to positively relate to Gf even when statistically accounting for differences in mental speed and storage factors (Krumm et al., 2009). Furthermore, relational integration predicted Gf better than other cognitive abilities, namely attention control and short-term memory (Chuderski, 2014), and performance on complex span tasks (Chuderski, 2014; Oberauer et al., 2008).

Recently, relation processing has been shown to be strongly related to Gf; it only requires the ability to match relations between bindings rather than building structural representations via relational integration (Chuderski, 2019). While relation processing would appear to be necessary for relational integration -assuming that relations need to be processed before they are integrated -the relationship between relational integration and relation processing has not been investigated. It may be that the relationship between relational integration and Gf found in previous studies is at least partially attributable to relation processing.

Moreover, the relation between Gf and binding may be due to a lower-level cognitive process than relation processing -one that does not require WM. For example, perceptual feature binding is the ability to bind simultaneously presented features into a single coherent object before or during WM encoding. Perceptual feature binding has been studied for decades (Kovacs & Harris, 2019; Treisman & Gelade, 1980; Wolfe & Cave, 1999), using a wide variety of tasks. Traditionally, these tasks would present objects outside the spatial attentional spotlight, and examine whether a target's low-level features (e.g., color, orientation) are correctly bound together or incorrectly fused with a nearby distractor. Here, we used a variant of the rapid serial visual presentation (RSVP) task, where participants are shown images sequentially in the same location at a rate of 100 ms per item. Participants are asked to report a target item that is cued, for example, by a frame. In this task, binding errors occur frequently. Specifically, the item appearing immediately after the cued item is often erroneously reported as the target (Botella et al., 2001; Chun, 1997; Zivony & Eimer, 2023), indicating perceptual feature binding across time. Individual differences in this kind of feature binding have not been the topic of much investigation, but a recent study showed that these perceptual binding errors are highly reliable and stable over time (Zivony et al., 2026). The inclusion of the RSVP task allowed us to examine whether Gf is predicted uniquely by WM binding, or by binding at a lower cognitive level.

The Current Study

The goal of this study was to determine the extent to which five binding functionsitem-to-location binding, item-to-item binding, relational integration, relation processing, and perceptual feature binding -overlap and relate to Gf. We compared latent variable models beginning with a model which has six correlated latent variables representing each function and Gf. We systematically modified each model by reducing the number of latent variables until further reductions did not improve model fit. We also used latent network analysis to model the partial correlations between latent variables to reveal any binding functions that have unique relationships with Gf. We expected to find that each function significantly relates to each other and to Gf, but we had no prediction for the magnitude of their overlap.

Method

This study was pre-registered on the Open Science Framework (https://osf.io/dgckf).

A total of 201 young adults were recruited from Sheffield, England through Sona Systems, posters, social media advertisements, and word of mouth. Participants were included if they indicated that they were young adults (18-30 years old, inclusive), fluent in English, had normal or corrected-to-normal vision (color vision was tested using the Ishihara test), did not have ongoing psychiatric or neurological disorders, and were not currently using psychotropic drugs. Participants were compensated with a £25 gift card, course credits, or a mix of both. Ethical approval for this study was received from the University of Sheffield's Ethics Review Committee administered by the School of Psychology.

Materials and Procedure

After providing informed consent and completing the Ishihara test, participants completed three visuospatial variants of local recognition, associated pairs, monitoring, relation matching, RSVP, and Gf tasks. Each paradigm (apart from Gf) used the same three sets of stimulus materials (i.e., arrows, symbols, and fractals), one for each task variant. The symbols were a selection of those used in the figural-icon tasks of Himi et al. (2023). The fractals were a selection of those used in the binding tasks of previous work (von Bastian & Oberauer, 2013). The arrows were created to point in one of eight directions evenly divisible by 45 degrees and to be either long and thin or short and wide (see Figure A1 in the Appendix for selections from each stimulus set). We deviated from the pre-registration (which specified two 10-min breaks) to increase participant comfort. Data were collected in groups of up to seven participants.

In each block, participants are given 3 min to complete up to 10 problems with progressive difficulty.

In the locations task, participants are presented with five rows with a variable number of dashes separated into a variable number of groups in each row. In the top four rows, one of the dashes is replaced with an "X" following a certain pattern, and the participants' task is to recognize this pattern to decide where the "X" should be placed in the bottom row out of a possible five options by selecting the corresponding number on a keyboard. Participants are given two practice trials in which feedback is given. The locations task is split into two blocks. In each block, participants are given 6 min to complete up to 14 problems with progressive difficulty. The dependent variable for each of the Gf tasks was the proportion of correct responses out of the total number of possible problems.

Analysis

Statistical analyses were performed with R (R Core Team, 2024) and RStudio (Posit team, 2024). Except for the Mahalanobis Distance cutoff, p < .05 was considered significant.

Data cleaning deviated from the preregistration which stated that we would calculate guess rate to exclude participants and winsorize data. Instead, participants were excluded for disingenuous effort, which was identified by examining raw data. Specifically, participants' response patterns for a task were examined if they scored below the lower quartile in that task. These participants were excluded if they had RTs < 300 ms in more than 25% of the trials of the local recognition, associated pairs, and relation matching tasks; streaks of 20 or more repetitive responses in any task; false alarm rate > 50% in any monitoring task; or RTs < 2000 ms in any of the Gf tasks. Mahalanobis Distances were then calculated for each participant to identify multivariate outliers. Participants whose Mahalanobis Distance exceeded the critical value (p < .001) were excluded. The dependent variables for each task were then examined for normality in distribution based on skew and kurtosis indices, and then z-transformed. If the absolute value of a skew index was above 3.0 or the absolute value of a kurtosis was greater than 10.0 (Kline, 2015), we used appropriate transformations to approach normal distributions.

Latent Variable Modeling

Confirmatory factor analysis was performed using the "lavaan" package (Rosseel, 2012). Model fits were estimated with a maximum likelihood approach and evaluated based on the confirmatory fit index (CFI), root mean squared error of approximation (RMSEA), and standardized root mean squared residual (SRMR). CFI > .95, RMSEA < .06, and SRMR > .08 were considered good fit (Hu & Bentler, 1999). CFI > .90 (Hu & Bentler, 1999), RMSEA < .10, and SRMR < .10 (Kline, 2015) were considered acceptable fit. Nested models were compared using the chi-square statistic (χ 2 ).

To determine the extent of the overlap between binding functions, we used a stepwise model comparison approach beginning with the baseline structural equation model (excluding Gf) where indicators loaded onto their respective paradigm-specific latent factors.

In each subsequent step, we identified the two latent factors with the strongest correlation and tested a nested model in which these factors merged into a single factor. If merging the factors did not significantly worsen model fit compared to the baseline model, we retained the nested model as the reference model and compared subsequent models to this model. If the fit significantly worsened, we tested a nested model that merged the pair of factors with the next-highest correlation, comparing it with the baseline model or the reference model if one was established. This process continued until no further factors could be combined without significant loss of fit. We also explored a model (excluding Gf) in which each paradigm-specific latent factor loaded onto a higher-order latent factor.

Latent-Network Modeling

Latent network analysis was performed on the best-fitting model to explore the unique relationships between binding functions and Gf. In a latent-network model, network nodes represent latent variables, and edges represent the conditional dependent associations (also known as partial correlations) between pairs of connected nodes. All network models are estimated by modeling the variance-covariance matrix of the data in Gaussian graphical models (Epskamp et al., 2018). Models were estimated using the Maximum Likelihood approach using the "qgraph" (Epskamp et al., 2012) and "lvnet" (Epskamp, 2019) packages.

Discussion

This study investigated relations among binding functions (item-to-location binding, item-to-item binding, relational integration, relation processing, and perceptual feature binding) and between binding and Gf. All binding functions correlated strongly with Gf, though perceptual feature binding showed the weakest correlations with other binding functions as well as with Gf. Complementing these findings, network analysis revealed that binding memory, relation processing, and relational integration but not perceptual feature binding were uniquely related to Gf, setting perceptual feature binding somewhat apart from the other binding functions. Furthermore, only item-to-location binding and item-to-item binding could be represented by a single combined latent variable -binding memory.

Binding memory and the other binding functions shared a high amount of variance which could be represented without significant loss of fit by a higher-order ability -Binding.

Statistically, Binding was isomorphic with Gf indicating that individual differences in one ability are highly similar to individual differences in the other.

Binding Memory

Binding memory represents all that the local recognition and associated-pairs tasks have in common, which includes, but is not limited to, the ability to store, maintain, and retrieve content-context bindings in WM as well as familiarity-based retrieval (see Limitations). Moreover, given previous evidence suggesting that WMC is limited by binding capacity (for reviews, see Oberauer, 2009; Oberauer et al., 2007), we cannot conclude that binding memory is WMC. Indeed, this possibility may be reflected in the network analysis results, which showed that binding memory had the strongest unique association with Gf among all binding functions; this pattern may reflect the well-established strong relationship between WMC and Gf (Engle et al., 1999; Kyllonen & Christal, 1990).

Although item-to-item and item-to-location binding appear to differ in the semantic richness of their binding contexts -a factor evidenced to facilitate retrieval from long-term memory (Brady et al., 2013; Konkle et al., 2010) -they were best represented by a single variable: binding memory. If there were a substantial mechanistic difference in item-to-item and item-to-location binding regarding semantic processing, this would be reflected as distinct variables of item-to-location and item-to-item in our models. Instead, our models favor a single latent variable of item-to-item and item-to-location binding, suggesting little inherent difference in semantic processing between item-to-location and item-to-item binding. This result is consistent with Konkle et al. (2010), whose findings suggest that scene and object categories are represented at a similar level of abstraction in long-term memory.

To the extent that item-to-item bindings could be considered simple scenes in general, then in comparison to objects (item-to-location bindings), they have similar levels of abstraction in long-term memory. Therefore, item-to-item and item-to-location binding may not differ in retrieval from long-term memory, which was the potential mechanism through which semantic richness differentiated item-to-item and item-to-location binding.

Relation Processing and Integration

Relation processing exhibited remarkably strong relationships with Gf, other binding functions, and the process-general Binding factor. Supporting the findings from Chuderski (2019), relation processing was identifiable as a latent factor across tasks using diverse visual and spatial stimuli and was highly correlated with Gf. Thus, Chuderski's (2019) conclusion that single simple bindings are critical for Gf is supported by the current study. Moreover, relation processing directly related to Gf in the network analysis, indicating that their relationship is not entirely accounted for by relational integration or other binding functions (although their direct relationship was smaller, ranging from r = .78 to rxy.z = .32).

Similar to relation processing, relational integration was highly related to Gf, the other binding functions, and the overarching latent Binding factor. Network analysis revealed unique relationships between relational integration, relation processing, and Gf, indicating that although relation processing and integration are highly related, the shared variance between relational integration and Gf is not entirely accounted for by relation processing or the other binding functions. This finding is consistent with previous studies that found strong relationships between relational integration and Gf (Chuderski, 2014; Krumm et al., 2009; Oberauer et al., 2008). However, because of their strong interrelationship, relational integration and relation processing are difficult to disentangle and might have been confounded in previous studies. The present results make this interrelation explicit and show that relational integration and Gf are associated above and beyond of what they share with relation processing, and vice versa.

Perceptual Feature Binding

Perceptual feature binding shared significant variance with the other binding functions, suggesting that it draws partly on common mechanisms. At the same time, it loaded less strongly on Binding and was not directly connected to Gf in the network; rather, its association with Gf was accounted for by its shared variance with relation processing and integration. Together, these findings suggest that perceptual and WM binding are neither fully separable nor equivalent: perceptual binding relies substantially on processes specific to perception, yet it is embedded in the broader binding system that supports reasoning.

Notably, the RSVP task used to assess perceptual feature binding involved no retention interval, making it unlikely that the shared variance reflects WM maintenance demands.

Instead, the overlap may arise at the stage at which perceptually bound features are selected and consolidated into WM (see also (Ricker et al., 2018), suggesting that perception and WM interact closely during the formation of bindings. This pattern is consistent with accounts in which WM operates on perceptual representations (for an overview, see (Kiyonaga & Serences, 2025).

The Diversity of Binding

The latent network analysis revealed differences in the pathways connecting the binding functions to each other and to Gf. Although the binding functions were all highly correlated, Gf accounted for most of the relationship between binding memory and both relational integration and relation processing. To some extent, this pattern of results may be reflective of the domain-generality of Gf and, by extension, Binding; binding functions may have been related only indirectly because they are representative of different process domains. If the binding functions tap into distinct process domains, only an overarching, process-general mechanism, like Gf, could capture variance shared between these functions.

The groupings of the binding functions in the network analysis may suggest three process domains: binding memory, relational mechanisms (relational integration and relation processing), and perceptual feature binding. Mechanistic differences between these process domains are apparent in the representational demands. Relational mechanisms require processing multidimensional relations between representations (i.e., the direction of the slash as well as the items in the relational representation task, and the direction of the match across the grid in the monitoring task), and these relations must be processed for goalattainment. In contrast, for binding memory, the relationship between items or between an item and a location is binary: the content is either bound to the probed context or it is not.

Finally, perceptual feature binding differs from binding memory and relational mechanisms in that it is binding at the perceptual rather than WM level. However, perceptual feature binding is directly related to relational mechanisms -possibly indicative of the theoretical expectation that perceptual feature binding serves as a foundational prerequisite for complex relational mechanisms. These differences in representational demands among binding memory, relational mechanisms, and perceptual feature binding may underpin their different relations to Gf.

Another possibility is that the distinction between binding memory and relational mechanisms reflect differing demands on attention control and that Gf is representative of individual differences in attention control. Attention control is defined as the ability to direct attention and ignore internal and external distractors in pursuit of a goal (Engle, 2002). The disengagement hypothesis proposes that attention control supports the maintenance of representations in WM and the disengagement from irrelevant information and false hypotheses to the benefit of Gf (Burgoyne et al., 2022; Shipstead & Engle, 2013). Indeed, the current findings map onto the mechanisms of the disengagement hypothesis. Specifically, binding memory aligns with the maintenance of representations in WM, while relational integration, relation processing, and perceptual feature binding could all require inhibiting irrelevant information and, thus, disengagement. As such, Gf may have accounted for much of the relationship between binding memory and the other binding functions because it represents shared variance in attention control. However, the measurement of attention control remains debated; many studies find weak correlations between measures of attention control (Keye et al., 2009; Rey-Mermet et al., 2019; Shilling et al., 2002; von Bastian et al., 2020). Moreover, when influences of processing speed are accounted for, measures of attention control do not significantly correlate with WMC or Gf (Rey-Mermet et al., 2019).

The attention control account of the current results should, therefore, be interpreted with caution.

Binding and Fluid Intelligence

The common thread across the tasks used in this study to assess the five binding functions is the ability to form and make use of bindings in a goal-directed manner, so this is likely what the second-order factor Binding represents. The overlap between Binding and Gf supports theories of Gf or complex reasoning in which Gf depends on bindings, such as the binding hypothesis (Oberauer, 2009) or the relation processing account (Chuderski, 2022).

Importantly, binding memory, relation processing, and relational integration each correlated with Gf independently of each other -indicating that none of these specific binding functions could completely account for individual differences in Gf. Rather, the more process-general Binding factor was isomorphic with Gf, which is consistent with previous findings that highlight the association of binding maintenance with Gf (Garvey et al. 2026).

Previous studies have typically isolated specific binding functions, demonstrating that individual mechanisms capture a significant, yet partial, portion of individual differences in Gf (e.g., Chuderski, 2022; Garvey et al., 2026). By demonstrating that a process-general Binding can explain nearly all reliable variance in Gf, the current results suggest that binding constitutes an even more central constraint on Gf than these previous, domain-specific studies could reveal.

Strengths, Limitations, and Future Directions

A strength of this study was the use of the same sets of visual/spatial stimuli for each binding paradigm. Using the same stimuli sets allowed us to focus the shared variance on paradigm-specific mechanisms (the binding functions) and pre-emptively remove error variance due to stimulus-specific variance that might have otherwise varied between paradigms. Furthermore, each stimulus set was chosen to differ meaningfully from each other to mitigate the influence of specific task strategies (e.g., verbal labelling). The fractals were meaningless, colorful, and visually complex. The arrows were more meaningful, blackand-white, and less complex than the fractals but were identical to each other apart from orientation and thickness. The symbols were the most meaningful, black-and-white, and less visually similar than the arrows. These considerations likely contributed to the strong correlations, high factor loadings, and good model fits observed in the structural equation models. However, using the same sets of stimuli for each paradigm and using only visual/spatial Gf tasks could also be considered a limitation. It is possible that shared method variance artificially inflated factor loadings and the correlations between the latent factors. Additionally, because we only used visual/spatial tasks, we cannot definitively conclude that the present results extend to verbal/numerical domains. While some research suggests that WMC is largely domain-general (e.g., Vergauwe et al., 2022), future research should use a broader array of stimulus domains to investigate the domain-general nature of the Binding-Gf isomorphism.

One limitation of the current study is the influence of individual differences in response criterion. As in past research (De Simoni & von Bastian, 2018a; Prieto et al., 2023; Talmi & Goshen-Gottstein, 2006; Thompson et al., 2013; von Bastian et al., 2013; von Bastian & Eschen, 2016), we used the discrimination parameter d' to isolate recollection from familiarity-based performance in the local recognition and associated-pairs tasks.

However, recent research has shown that the discrimination parameter does not adequately distinguish individual differences in response criterion to judge a probe as a match (Brady et al., 2023). As such, the strong relationship between item-to-item and item-to-location binding is likely inflated by individual differences in weighting given to evidence identifying a probe as either "old" or "new" ("same" or "different" in the current study). Future research should implement methods for gauging individual difference in participants' response criterion, such as receiver operating characteristic (ROC) curves of participants' confidence ratings (see Brady et al., 2023).

Individual differences in evidence weighting may have contributed to another caveat of the current results: that the split-half reliability estimates were low for the associated pairs and local recognition tasks, especially for the fractals associated-pairs task. The fractals associated-pairs task may have had particularly low reliability due to differences in the distinctiveness between the fractal stimuli. Participants may have benefited from labeling the shapes and colors for certain fractal pairs but not others. For example, only one fractal was black and white, while multiple fractals were red. Labeling the black and white fractal may have facilitated recognition, but labeling the red fractals may have resulted in more false alarms. Regardless, the latent variables of local recognition, associated pairs, and binding memory were identifiable with high loading coefficients, indicating that the individual local recognition and associated-pairs tasks measured the same variable to some extent.

Given the importance of understanding the mechanisms that underlie Gf, and the current findings that show substantial overlap between Gf and process-general Binding, future research should investigate additional binding functions that could be encompassed by Binding. The present study only targeted extrinsic bindings (the relations between items and independent spatiotemporal contexts or other items), but intrinsic bindings (the integration of features of a single, unified item; i.e., working memory feature binding) may exhibit different patterns of relationships. Indeed, past research has shown intrinsic and extrinsic binding abilities to be distinct in their neurophysiological signatures (Ecker et al., 2007; Zimmer & Ecker, 2010), relationships with age (Old & Naveh-Benjamin, 2008), and performance under cognitive load (Allen et al., 2006). Intrinsic binding would be expected to not share substantial variance with extrinsic binding, but further research is needed to evidence the binding functions that are encompassed by process-general Binding.

Conclusion

This study investigated the shared and unique variance between item-to-location binding, item-to-item binding, relational integration, relation processing, and perceptual feature binding and how they relate to Gf. We found significant overlap between binding functions, but only item-to-item and item-to-location binding were best modelled as one ability, binding memory. Moreover, the shared variance between binding memory and the other binding functions was well-represented by a process-general ability, Binding, which seems to represent the ability to form and use bindings in a goal-directed manner. Binding was statistically indistinguishable from Gf while each individual binding function (apart from perceptual feature binding) uniquely related to Gf in a latent network analysis. Taken together, these results indicate that, more so than any specific binding function, the general ability to form and use bindings in a goal-directed manner explains nearly all of the variance in Gf.
