Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Full text

Abstract

Previous research has shown that personality descriptions influence the perceived cuteness of young children and female adults' caregiving motivation toward them. The purpose of this study was to extend these findings by examining whether such effects also manifest in subjective and body postural responses of approach-avoidance tendencies. Thirty-seven female university students participated in a preregistered experiment. First, they stood on a force plate while viewing images of young children's faces, during which postural responses were recorded. They also provided subjective ratings of cuteness and their approach-avoidance motivation. Each face was then paired with a personality description (positive, negative, or no description). After this manipulation, the participants viewed the same faces again, and their postural responses and subjective ratings were remeasured. The results showed that positive personality descriptions increased perceived cuteness and approach motivation, while negative descriptions decreased both. However, no significant changes were observed in postural responses across conditions. These findings suggest that while personality descriptions shape subjective experiences of cuteness and approach motivation, their effect is not strong enough to elicit changes in postural approach responses.

Factors influencing perceived cuteness

Cuteness is often thought to be determined primarily by physical features such as baby schema, which includes a large head, rounded body, and chubby cheeks (Kawaguchi & Waller, 2024; Lorenz, 1943). These features are known to attract attention (Brosch et al., 2007; Proverbio et al., 2011), activate reward processing in the brain (Kringelbach et al., 2008), and increase caretaking motivation (Glocker et al., 2009). In addition to baby schema, smiling expressions enhance cuteness ratings (Aradhye et al., 2015), and larger eyes are perceived as cuter across different ages and facial expressions (Yao et al., 2022).

While physical attributes play an important role, perceived cuteness and the feeling associated with it (called "kawaii" in Japanese) are shaped by a cognitive appraisal process that assesses the relationship between the perceiver and the stimulus (Nittono, 2016). Previous research showed that cognitive factors such as personality information and familiarization influence perceived cuteness of children (Hunt et al., 2023; Hunt & De Pascalis, 2024; Parsons et al., 2014; Takamatsu et al., 2023).

Infants described as having an easy temperament are rated as cuter and elicit stronger motivation to view their faces compared to before the temperament information was given, while difficult-tempered infants are rated as less cute and elicit decreased motivation to view their faces (Parsons et al., 2014). Similarly, children's faces paired with positive personality descriptions were rated as cuter, while negative descriptions reduced perceived cuteness, with effects persisting over time (Takamatsu et al., 2023).

Infants with cleft lips were initially rated as less cute, but a week-long familiarization with them increased their perceived cuteness (Hunt et al., 2023) and eliminated the negative relationship between gaze duration to cleft-affected features and cuteness ratings, which was observed for unfamiliarized participants (Hunt & De Pascalis, 2024). These findings indicate that cuteness perception is flexible and can be shaped by cognitive evaluation rather than being solely determined by physical attributes.

Personality traits and individual motivations influence how people perceive cuteness, leading to variations in its intensity and expression. Prosocially oriented women demonstrate higher physical carefulness, reflected in increased precision in their physical movements, in response to cuteness cues than women who are less prosocially oriented (Sherman et al., 2013). People with greater emotional empathy display stronger baby schema effects toward human and animal infants, meaning they have heightened sensitivity to infantile features that evoke caregiving behaviors and positive emotions in adults (Lehmann et al., 2013). Additionally, parental caregiving motivation plays a significant role in shaping responses to cuteness. Parental caregiving motivation consists of two components: protection, which involves guarding children from harm; and nurturance, which involves providing care and affection.

These tendencies vary among individuals. Hofer et al. (2018) found that only nurturance motivation uniquely predicted prolonged viewing time for infant faces. Furthermore, individuals with higher parental nurturance motivation tend to find human babies and children cuter (Takamatsu & Nittono, 2024). These findings suggest that gender, personality traits, and caregiving motivation contribute to how people experience and respond to cuteness. This study defines "perceived cuteness" as a concept that encompasses both stimulus attributes and emotional responses. While the English term "cuteness" primarily refers to an object's physical attributes, the Japanese word "kawaii" encompasses both stimulus attributes and emotional responses (Nittono, 2016). In this study, the term "perceived cuteness" is used to reflect the subjective experience of finding something cute, rather than describing its physical characteristics. This approach is in line with previous research that has highlighted the emotional aspects of cuteness perception (Buckley, 2016; Steinnes et al., 2019 Steinnes et al., , 2024)).

Measuring approach tendencies toward cute/kawaii stimuli

Perceived cuteness is defined as a positive emotion accompanied by approach motivation (Nittono, 2016). When people see cute things and beings, they not only evaluate them as cute but also show a tendency to be drawn to and approach them. Approach tendencies toward cute entities have been measured through both subjective ratings of approach motivation and behavioral approach-avoidance tendencies.

Research using subjective ratings has demonstrated that perceived cuteness is accompanied by approach motivation (Nittono & Ihara, 2017). In an experiment in which participants rated images on various dimensions, including "I want to approach," images rated as cute were associated with a stronger approach motivation than neutral images. This effect was observed regardless of whether the cute images exhibited strong baby schema features. Furthermore, subjective ratings of cuteness were positively correlated with pleasantness and the desire to approach, and negatively correlated with unpleasantness (Nittono & Ihara, 2017).

Behavioral measures often involve tasks requiring finger movements, such as mouse clicks and key presses. Studies using tasks in which participants can adjust stimulus presentation time through mouse clicks have shown that stimuli rated as cute tend to be viewed for longer durations (Nittono & Ihara, 2017). Similarly, studies using tasks in which participants can extend or shorten the viewing time of infant faces by pressing keys have demonstrated that faces rated as cuter are viewed longer (Parsons et al., 2011; Sprengelmeyer et al., 2013). In a task measuring the timing of participants spontaneous stopping video clips by clicking, videos of smiling children rated as cute were viewed longer than those showing neutral expressions or crying children (Aradhye et al., 2015). Recent research using a manikin task, in which participants moved an on-screen manikin toward or away from stimuli using key operations, has demonstrated facilitated approach responses to infant face images (Yagi et al., 2024).

Thus, various tasks have demonstrated that perceived cuteness is accompanied by strong approach motivation.

In addition to finger-based tasks, approach responses have been examined using posturography, a method that measures whole-body postural responses while standing. Posturography measures the center of pressure (COP), the point of application of the ground reaction force between the feet and the contact surface, to assess whole-body approach-avoidance responses to stimuli. During quiet standing, the COP reflects variations in the body's center of mass (Winter, 1995) and one of the most common measurement indicators for quantifying postural changes (Masani et al., 2014; Ruhe et al., 2011). Previous studies have indicated that a forward COP shift represents approach, while a backward shift indicates avoidance (Akounach et al., 2022; Brunyé et al., 2013; Eerland et al., 2012; Lebert et al., 2024), with the mean COP position being considered a suitable index for objectively studying approach-avoidance behaviors (Lelard et al., 2019; Monéger et al., 2025). Kuraguchi et al. (2024) demonstrated that female participants consistently showed a forward COP shift when presented with infant face images, regardless of their cuteness ratings. Similarly, Nakamura et al. (2025) confirmed a tendency for forward COP shifts in response to pleasant animal pictures perceived as cute, while neutral and unpleasant pictures tended to induce a backward COP shift, reflecting an avoidance response. Additionally, while larger image sizes generally enhanced the backward shift for neutral and unpleasant images, this effect was not observed for pleasant images, suggesting that the approach response to cute images remains stable regardless of image presentation size (Nakamura et al., 2025). These studies suggest that when cuteness is perceived, the body tends to lean toward the object, indicating a physical embodiment of approach motivation.

Purpose of this study

The purpose of this study was to investigate how personality descriptions affect the approachavoidance postural response, perceived cuteness, and the subjective motivational direction toward the images of young children's faces. While previous research has shown that perceived cuteness can be modified by personality (Parsons et al., 2014; Takamatsu et al., 2023), the impact of such changes on approach-avoidance postural responses has not yet been investigated. Therefore, this study utilized face images and personality descriptions from previous research (Takamatsu et al., 2023) to examine their effects on postural responses and subjective ratings, as well as the differences between evaluations before and after the images were matched with personality descriptions. Additionally, based on previous findings on nurturance and protection factors (Hofer et al., 2018; Takamatsu & Nittono, 2024), this study exploratorily examined the relationship between individual differences in parental caregiving motivation and changes in perceived cuteness and postural responses induced by personality descriptions.

Hypotheses

The following hypotheses were preregistered. H1 was a new research question that was addressed in this study for the first time, while H2 and H3 aimed to replicate the results of a previous study (Takamatsu et al., 2023).

H1

Personality descriptions of children will affect approach-avoidance postural responses to images of their faces. Faces with positive personality descriptions will elicit a greater postural approach response than those with negative descriptions (H1a). Faces with positive personality descriptions will elicit a greater postural approach response than those with no descriptions (H1b). Method

The preregistration (https://osf.io/zbqf7) and the data (https://osf.io/7wpjh) supporting the results reported in this paper are available on OSF.

Power analysis

Since G*Power (version 3.1.9.3) (Faul et al., 2009) does not calculate statistical power for twoway repeated-measures ANOVAs, the following alternative was used. In the present study, the effects of personality manipulation appear in the change score (post minus pre) of the three conditions. These change scores can be compared using a one-way repeated-measures ANOVA with a factor of personality description (positive, negative, and no description). A total sample size of 32 is calculated using a power analysis (a medium effect size, f = 0.25, α = .05, 1-β = .80, number of groups = 1, number of measurements = 3, correlation between repeated measures = .5, non-sphericity correction ε = .8).

Participants

We recruited 41 participants to compensate for potential data loss. After data exclusion, the final sample was 37 participants (age range: 19-39 years, M = 22.97, SD = 3.44; see the Results section). The participants were undergraduate and graduate students with normal or corrected-to-normal vision and the ability to maintain a standing posture. Following previous research (Takamatsu et al., 2023), we recruited only nulliparous women. Based on the Japanese version of the FLANDERS handedness questionnaire (Okubo et al., 2014), 36 participants were right-handed and one was left-handed. This study was approved by the Behavioral Research Ethics Committee of the Osaka University School of Human Sciences, Japan (HB024-094) in accordance with the Declaration of Helsinki. Participants were informed that they could discontinue the experiment at any time, and written informed consent was obtained. All participants received an Amazon gift card worth 1,000 Japanese yen as compensation. The recruitment period was between November 3 and 22, 2024. The study was conducted between November 5 and 28, 2024.

Study design and procedure

A within-subjects design was used for two factors: time (pre-and post-manipulation) and personality description (positive, negative, or control [no description]). 18 face images of young children with moderate levels of kawaii (nine boys, nine girls) were selected according to the ratings of a pilot study by Takamatsu et al. (2023). They were divided into three sets (six pictures each) with equivalent perceived cuteness ratings, and each set was assigned to each personality condition. Twelve personality descriptions (six positive and six negative) were also selected from the same pilot study.

The experiment was conducted using Inquisit 6 (Millisecond Software, USA). Fig 1 illustrates the experimental setup. Participants were asked to stand on the force plate while viewing the stimuli projected on a screen at a visual angle of 18° × 18° (45 cm × 45 cm). This size of images was chosen based on previous COP studies (Nakamura et al., 2025). The screen was positioned 140 cm away from the participants, with its center 170 cm above the floor. A handrail was installed in front of them to prevent falls. The participants were instructed as follows: "You will see face images of young children. Please view the images while imagining how you would interact with the children." The experiment consisted of three phases and lasted approximately 50 minutes in total.

Pre-manipulation postural measurement and subjective ratings

First, the participants stood on a force plate, and the COP was measured while each face image was presented on the screen for 6 s with an interstimulus interval of 6-9 s in random order (Fig1b, c).

After completing the COP measurement for all 18 face images, participants then rated each face image presented on the screen at their own pace (see Fig1d and Measured variables below). To prevent fatigue, they sat on the edge of a desk directly behind them while remaining on the force plate.

Personality manipulation

After completing the pre-manipulation rating task, participants were asked to remain seated and run through the personality manipulation session (Fig1e). Each face image was presented on the screen with positive or negative personality descriptions or no description for 5 s. The combinations of faces and descriptions were counterbalanced across participants. A fixation cross was then presented for 2 s, followed by the face image alone for 3 s. After the face image disappeared, the participants rated the desirability of the child's personality on a 7-point scale (1 = very undesirable to7 = very desirable) to verify the effectiveness of the personality manipulation. The set of 18 face images was presented twice.

Post-manipulation postural measurement and subjective ratings

The participants stood on the force plate again, and COP was measured, similar to the premanipulation session. After completing the COP measurement for all images, participants sat and rated each face image at their own pace, similar to the pre-manipulation session. Note. Therefore, the JPCM was used as an alternative to the PCAT-pn.

Measured variables

The following variables were measured to assess the effects of personality information on the participants' responses. The anterior-posterior center of pressure (AP COP) was recorded during the COP measurement phases. The COP was measured using a force plate (T.K.K.5810, Takei Scientific Instruments, Japan). The sampling rate was 100 Hz for each AP shift and medio-lateral (ML) shift. The mean AP COP between 3 s and 6 s after the onset of a face image was measured, using the 3-s period before the onset as baseline, following Nakamura et al. (2025). During the rating phases, participants evaluated perceived cuteness using three items (cute, adorable, and endearing) on a 9-point scale (0 = not at all to8 = extremely). Perceived cuteness was calculated as the mean score of these three items.

Participants also rated their subjective motivational direction on a 9-point scale (-4 = want to avoid,0 = neutral, and +4 = want to approach).

Exclusion criteria

Participants whose mean desirability ratings of the children's personalities did not follow the expected order (i.e., positive > no > negative descriptions) in the second run of the personality manipulation phase were excluded from the analysis, because this indicates that those participants did not understand the personality descriptions in the intended way. In addition, trials with COP measurements that exceeded the mean ± 3 SD of each participant, based on calculations from the pre-and postmanipulation phases, were excluded (four trials, 0.3% of all trials).

Data analysis

All analyses were performed using JASP version 0.19.0 (JASP Team, 2024) and R Statistical Software version 4.4.1 (R Core Team, 2024) with the Psych package version 2.4.6 (Revelle, 2024). The significance level was set at .05. For ANOVA, the Greenhouse-Geisser ε correction for sphericity assumption was applied when the degree of freedom in the numerator exceeded 1. For post-hoc multiple comparisons of means, the Holm method was used to adjust the comparison-wise significance level.

Effect size is reported as partial η² (ηp² ) for ANOVAs and as d (mean difference divided by pooled standard deviation) for paired comparisons.

To test H1, H2, and H3, a 2 (time: pre-and post-manipulation) × 3 (personality description: positive, no description, negative) repeated-measures ANOVA was conducted on each measure. The dependent variables were AP COP, perceived cuteness, and subjective motivational direction. When significant interactions were found, post-hoc comparisons between conditions using change scores (post minus pre) were conducted to test the subhypotheses (a, b, and c). Following Takamatsu et al. (2023), Cronbach's alphas for the three kawaii rating items (cute, adorable, and endearing) were computed for all images separately for pre-and post-manipulation phases. Furthermore, some exploratory analyses were conducted. First, to investigate the relationship between AP COP changes and subjective ratings at the within-participant level, correlations were calculated after controlling for between-participant variability by subtracting each participant's mean values from their data for each trial. Degrees of freedom were calculated as N(k-1)-1, where N is the total number of participants and k is the number of measurements per participant (Bakdash & Marusich, 2017).

Second, to examine the relationship between individual differences in nurturing motivation and physical approach-avoidance responses, between-participant correlation analyses were performed between the mean AP COP changes in each condition and the parental care motivation scale scores for each participant. The method of Benjamini & Yekutieli (2001) was used to control for the false discovery rate in correlation coefficient tests.

Correlations between measured variables

Table 1 shows the results of the within-participant correlation analysis. No significant correlations were found between AP COP and subjective ratings either pre-or post-manipulation. The kawaii ratings were positively correlated with approach motivation ratings both pre-and postmanipulation, pre: r(628) = .69, p < .001; post: r(628) = .78, p < .001.

Correlations with personality traits

The influence of personality traits on responses to infant faces was examined through correlations between parental care motivation and behavioral measures. Moderate correlations were observed between AP COP values and the nurturance factor, before the manipulation (rs = .19-.31, uncorrected ps = .066-.260, for the three conditions) and after the manipulation in the negative condition (r = -.33, uncorrected p = .048). However, these correlation coefficients were not statistically significant after false discovery rate correction (see Supplementary Information).

Discussion

The present study examined the effect of personality descriptions on perceived cuteness, approach-avoidance postural responses, and subjective motivation. Personality descriptions significantly affected perceived cuteness, with positive descriptions leading to higher ratings and negative descriptions leading to lower ratings. These results are consistent with Takamatsu et al. (2023). Additionally, this study made a novel finding that personality descriptions also influenced self-reported approachavoidance motivation, showing a similar pattern to perceived cuteness. However, no significant effects of personality descriptions were observed in postural responses, indicating that these descriptions did not directly impact physical approach-avoidance behavior. An exploratory analysis further examined the relationships between the parental caregiving motivation scale, AP COP, and subjective ratings, but no significant effects were found.

Discrepancy between subjective ratings and bodily responses

The present study found that while personality descriptions significantly influenced subjective ratings, no significant changes were observed in bodily responses. Several factors may account for this discrepancy.

First, the intensity of emotional change required to elicit bodily responses may not have been sufficient. Nakamura et al. (2025) demonstrated clear approach responses to highly positive animal images that strongly elicited perceived cuteness, with a very large effect size (ηp² = 0.87). In contrast, the effect size of personality manipulation on perceived cuteness ratings in the present study was ηp² = 0.49, suggesting that the emotional shift induced by personality descriptions was relatively weak. One possible reason for this effect size difference is the types of stimuli used. While Nakamura et al. (2025) used animal images of various affective categories, the present study used similar neutral images of human children. Previous research has shown that people tend to rate animals as cuter than humans (Borgi et al., 2014). The smaller variety of stimuli in this study may explain the absence of corresponding bodily responses.

Second, procedural differences may have contributed to the observed results. In Takamatsu et al.

(2023), face images and personality descriptions were presented simultaneously, and evaluations were conducted immediately after the association. In the present study, participants were first presented with personality descriptions, followed by a delay before they rated the images and their postural responses were measured. This procedural difference may have weakened the association between the face images and personality descriptions. Indeed, the changes in perceived cuteness were small in this study (positive: +0.23, negative: -0.95) compared to Takamatsu et al. (2023) (positive: +1.13, negative: -2.20), suggesting a weaker impact of personality manipulation.

Third, subjective evaluations and behavioral tendencies may not coincide and thus reflect different parts of the approach-avoidance system. Matsuda and Nittono (2023) demonstrated that repeated execution or inhibition of an action toward an object in a Go/NoGo task altered explicit preferences, with Go-primed items rated as more preferable and NoGo-primed items rated as less preferable relative to unprimed items. However, these subjective changes were not accompanied by differences in approach-avoidance behavior, as measured by reaction times in a subsequent manikin task (Matsuda & Nittono, 2023). Similarly, in the present study, personality descriptions altered perceived cuteness ratings and self-reported approach-avoidance motivation but did not induce corresponding changes in bodily responses. These findings across different experimental paradigms suggest that subjective and behavioral responses may represent distinct aspect of the approach-avoidance system.

Fourth, this study's discrepancy between subjective and behavioral responses may reflect a general phenomenon of parenting. For example, a meta-analysis of self-reported and observed parenting behaviors revealed weak correlations between them (Hendriks et al., 2018). Another meta-analysis found only modest agreement between parents' and children's reports of the same parenting behaviors, as parents tended to report their behavior more favorably than children did (Korelitz & Garber, 2016). These findings suggest that subjective evaluations of parenting behavior often diverge from either observed behavior or other informants' perceptions. Although this study was conducted outside of parenting contexts, the dissociation between subjective and behavioral responses to child faces may reflect a common mechanism underlying the broader parental care motivation system (Schaller, 2018).

Maintaining consistent behavior despite changes in conscious attitudes toward children may have adaptive significance.

Personality traits

The present study found no statistically significant correlations between caregiving motivation and COP shifts. However, although not significant, individuals with higher nurturance scores tended to show a greater forward COP shift in response to children's face images prior to the personality manipulation (r = .19-.31). This tendency is consistent with research showing that higher self-reported maternal nurturance is associated with increased neural responses to infant faces in reward-related brain regions (Endendijk et al., 2020), suggesting a stronger motivational drive to approach infant stimuli. Kuraguchi et al. (2024) also reported that women, but not men, showed approach responses to infant images. In contrast to their initial tendency to approach, participants with higher nurturance scores in this study showed more avoidance responses to negatively informed children's faces after personality manipulation. Although these results are intriguing, future research is needed to test these trends with larger sample sizes.

Investigating the influences of other individual differences would also be worthwhile. Although all participants in the present study were nulliparous women, they may have had different levels of exposure to and familiarity with children (e.g., through babysitting or having younger siblings).

Experience with children during development influences how adults respond to children's faces. Adults with siblings showed greater likeability for children's faces than those without siblings (Luo et al., 2015).

Additionally, individual differences in imagery ability may affect COP measurements because the present study involved participants imagining interactions with children while viewing their faces. People with higher imagery ability have been shown to exhibit larger physiological responses to affective materials than those with lower imagery ability (Miller et al., 1987). Controlling for these factors would help obtain a clearer picture of the effects.

Limitations and future directions

This study has several limitations. First, the association between face images and personality descriptions may not have been strong enough due to methodological and temporal limitations. In Takamatsu et al. (2023), participants rated faces immediately after the personality descriptions were provided, which might have increased the salience of the association but also introduced demand characteristics. In the present study, the participants underwent multiple phases before the final evaluation, which may have weakened the effect of personality manipulation. Additionally, research on long-term associations (Hunt et al., 2023; Hunt & De Pascalis, 2024) suggests that stronger approach responses may emerge with prolonged exposure and reinforcement. For instance, individuals develop lasting emotional and behavioral tendencies toward familiar faces over time, such as in parent-child relationships. Future studies should explore whether extended exposure to children's faces paired with personality descriptions can strengthen approach-avoidance responses.

Second, the postural changes in the second measurement may have been masked by other factors such as habituation, perceptual adaptation, fatigue, and cognitive demand. Habituation effects may have occurred due to repeated exposure to the same or similar stimuli. In the present study, each face image was presented eight times, resulting in participants viewing a total of 144 face presentations throughout the experiment, which likely induced substantial habituation effects. This habituation effect is consistent with previous research showing that facial muscle responses tend to be weaker when similar infant faces are presented in succession (Nittono & Ohashi, 2024), compared to when infant faces appear intermittently among various types of stimuli (Nittono & Ihara, 2017). Perceptual adaptation may have also contributed to the reduced responsiveness. Previous research showed that perceptual adaptation influences cuteness judgments, with prior exposure to less attractive faces increasing subsequent ratings of infant cuteness, and exposure to highly cute faces producing the opposite effect (Golle et al., 2013).

This demonstrates that perceptual adaptation can alter facial evaluations, and similar adaptation processes may have occurred in the present study through repeated exposure. Furthermore, fatigue and cognitive load may have diminished the postural responses. Unlike previous studies, the present study measured COP shifts twice using the same images, which may have led to diminished responsiveness due to repetition and accumulated fatigue from multiple measurements. Alternatively, participants may have engaged in the process of retrieving personality descriptions in the post-manipulation session. Since cognitive demands interfere with postural control (Balasubramaniam & Wing, 2002), these recollection demands may have reduced or masked postural responses in the present study. The validity and reliability of postural changes to emotional stimuli across various situations should be determined in future studies.

Recording psychophysiological measures along with COP may be useful for examining the influence of personality descriptions on both emotional and physiological responses to infant faces. For example, previous studies have shown that infant faces with pronounced baby schema features elicit increased activity in the zygomaticus major muscle associated with smiling (Spencer et al., 2024), whereas unattractive infant faces evoke greater activation in the corrugator supercilii and levator labii superioris muscles associated with negative affect (Schein & Langlois, 2015). Given that the present study found changes in perceived cuteness due to personality descriptions, it would be valuable to examine whether facial muscle responses mirror these shifts. Combining facial expressions with COP measurements may then offer a more comprehensive view of how personality descriptions influence both emotional and behavioral aspects of approach-avoidance tendencies. Specifically, future studies could investigate whether negative personality descriptions enhance muscle activity related to negative affect, providing further insight into the relationship between cognitive appraisal and emotional expression.

Conclusion

The present study demonstrated that adding personality descriptions to images of young children's faces altered perceived cuteness and self-reported approach-avoidance motivation but did not affect postural responses. This discrepancy between subjective ratings and bodily responses suggests that stimulus characteristics, experimental design, and the short duration of cognitive manipulation may have limited the emotional changes necessary to elicit bodily responses. Alternatively, this dissociation may reflect a broader pattern observed in parenting, where subjective evaluations and behavioral responses often diverge. Although COP measurements are a novel method with face validity for accessing one's approach-avoidance tendencies, they may not consistently correspond with subjective ratings. Future research should examine when subjective and behavioral measures diverge and whether this dissociation helps caregivers maintain consistent behaviors toward children despite changes in their subjective evaluations.
