research_questions Literature on parenting stress, or stress that arises from the demands of parenting, has previously shown a salient influence on children’s internalizing and externalizing behaviors (Rodriguez, 2011; Tsotsi et al., 2019). However, there remains a gap in research that would look exclusively and specifically at its influence on anxiety in childhood. We’re also interested in identifying potential moderating effects of one parent and one child factor that may emerge as risk or protective factors in the strength of this relationship.

The parent factor we plan to explore is psychological distress, or more simply, the parent’s mental health status. Multiple studies (Babore et al., 2023; Tsoti et al., 2019) found parenting stress to act as a moderator between the mental health of parent and child, therefore we’re interested to see if parent mental health and parenting stress can be swapped in this triadic relationship. As such, we expect higher parent psychological distress to strengthen the relationship between parent stress and child anxiety.

The child factor we chose to examine is child resilience. Higher levels of resilience have historically been found to act as a protective factor against developing psychopathology, and so we predict higher resilience to weaken the relationship between parenting stress and child anxiety.

Our hypotheses are as follows:
H1: Increased parenting stress will be positively associated with higher child anxiety.
H2: The positive relationship between parenting stress and child anxiety will be stronger when parents report higher levels of psychological distress.
H3: The positive relationship between parenting stress and child anxiety will be weaker when children report higher levels of resilience.
study_type Observational Study - Data is collected from study subjects that are not randomly assigned to a treatment. This includes surveys, “natural experiments,” and regression discontinuity designs.

How Ethics Approval Check works

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. Abstract

Parenting stress, or stress that arises from the demands of parenting, has been linked with children's internalizing and externalizing behaviors (Rodriguez, 2011; Tsotsi et al., 2019). Of these behaviors, less is known about its unique relation to anxiety, a prevalent and significant disorder for many children. The present study aims to address this gap by examining the relation between parenting stress and childhood anxiety while also testing whether parental psychological distress or child resilience would emerge as significant moderators. Parenting stress was found to positively predict children's anxiety, such that as parenting stress increases, so does child anxiety. However, neither parental psychological distress nor child resilience emerged as significant moderators of this relation. Future studies should explore other potential variables that could act as risk or resilience factors to further our understanding of factors that may exacerbate or protect against increased child anxiety due to parenting stress.

[div-01]

Anxiety has been shown to affect many aspects of a child's life. Current literature demonstrates that children with clinical anxiety disorders exhibit greater impairment in domains of the home, school, and peers as well as impairment in overall quality of life compared to their non-anxious peers (Dickson et al., 2024). Childhood anxiety is a widely recognized and frequently studied problem and can last into adolescence or adulthood if not properly treated (Essau et al., 2014). Prior studies have credited the development of anxiety disorders in children to a number of factors, including genetic vulnerability and environmental factors (Murray et al. 2009). One such environmental factor is the parent-child relationship, which has been deemed as a salient predictor of children's developing psychopathology. Within this work on the parentchild relationship, parenting stress, or psychological distress that arises from the demands of parenting, has been indicated as a risk factor (Deater-Deckard, 1998). One meta-analytical review concluded that parenting stress was positively associated with children's internalizing and externalizing behaviors, poorer parent-child relationship quality, reduced parental engagement with the child, and poorer parental mental health during the COVID-19 pandemic (Chung et al., 2024). The literature consistently identifies this domain-specific stress as an influence on the development of both internalizing and externalizing disorders in children (Rodriguez, 2011; Tsotsi et al., 2019). As parenting stress is relatively common, the extent to which it can impact children's outcomes is likely to be of particular interest to parents who experience it. Moreover, because parent-child interactions and their subsequent impacts on children's development are complex and likely the culmination of a variety of factors, we seek to explore other commonly studied relevant factors that may impact parenting stress' influence.

Parenting Stress & Child Anxiety

Much of the existing literature on parenting stress and its influence on children links increased parenting stress with child externalizing behaviors (Tsoti et al., 2019b; Solem et al., 2011). A certain level of parenting stress is expected and considered normal. Increased parenting stress, however, has been found to be associated with children's behavioral issues (Williford et al., 2007; Mak et al., 2020). Further, findings from Neece et al. (2012) support a bidirectional relation between parenting stress and child behaviors, such that both variables act as an antecedent and a consequence of the other. This finding aligns with a transactional model, such that children's development is influenced by continuous, reciprocal interactions between the child and aspects of their environment (Sameroff & Mackenzie, 2003), in this case, the parenting they receive. Similar literature on internalizing symptoms appears to also suggest a reciprocal relation between parenting stress and children's internalizing symptomology (Rodriquez, 2011).

One study found parenting stress to predict children's internalizing symptoms across multiple time points and vice versa (Woodman et al., 2015), again suggesting a continuous and bidirectional relation. van Oort et al. (2010) found a modest, positive association between parenting stress and children's anxiety, though it overlapped with children's depression symptoms and the effect was attenuated after accounting for parental mental health. While this is an important addition to the literature, further research is needed to clarify whether parenting stress is uniquely associated with children's anxiety.

Childhood anxiety is a common and significant disorder, having a prevalence rate of 16% in the United States (Sappenfield et al., 2024) and high rates of comorbidity with other psychological disorders (Kendall et al., 2001). While substantial evidence suggests that anxiety has a significant genetic component (Hettema et al., 2001; Schreier et al., 2008), there is also a large body of literature examining parenting factors that influence its etiology in children.

Factors such as lower maternal warmth, higher anxious modeling (Drake & Ginsburg, 2011), and parental overinvolvement (Yap & Jorm, 2015) have been found to be positively associated with childhood anxiety. Additionally, harsh or authoritarian parenting are associated with children's anxiety (Yaffe, 2018), with characteristics of this parenting style (i.e., inconsistent, punitive parenting) predicted by increased parenting stress (Shea & Coyne, 2011).

Moreover, certain parent and child variables can act as risk or protective factors on the relation between parenting stress and child anxiety. Literature on risk and resilience experiences in childhood recognizes how both shape children's development through multiple pathways (McDorman et al., 2024). Cumulative risk models operate under the assumption of a gradient of risk, such that the higher the number of risk events, the more likely of negative later outcomes (Appleyard et al., 2005). Risk, in the form of increased parental psychological distress, could further exacerbate parenting stress's influence on child anxiety. Studies have shown parenting stress to be distinct from parent's mental health (van Oort et al., 2010), supporting this idea of cumulative risk. In contrast, child resilience is a positive adaptation to adversity, and much research has established its protective effects against risk (Zolkoski & Bullock, 2012). Therefore, child resilience could result in a weakened association between parenting stress and child anxiety. Applying this risk and resilience framework to consider variables that can change the strength and or direction of the relation between parenting stress and child anxiety would further our understanding of the mechanisms at play as well as inform future research and intervention work.

Parent Psychological Distress

Psychological distress, or the discomforting emotional state experienced by an individual in response to a specific stressor (Ridner, 2004), may commonly act as a deterrent to normal daily functioning. Certain psychological distress symptoms, such as anxious or depressive symptoms, interfere with an individual's ability to go about their daily lives, including the ability to interact effectively with others. Parents, therefore, who experience psychological distress may find that symptoms affecting their functioning and interaction patterns can have effects on their children. Amrock & Weitzman (2014) found that both maternal and paternal psychological distress were associated with an increased likelihood for mental health problems in the child.

Similarly, some have posited that a bidirectional relation exists between parent and child psychological distress (Ge et al., 1995), suggesting that parent's mental health influences their children's mental health in various ways. As parenting stress and psychological distress can both affect some parents, previous studies have examined the intersection of these two variables on children's mental health. Babore et al. (2023) found that parenting stress during the COVID-19 pandemic mediated the relation between maternal distress and child depression. Similarly, Tsoti et al. (2019) revealed increased maternal trait anxiety to be associated with increased parenting stress, leading to higher internalizing and externalizing problems in children. These studies demonstrate how these three variables can interact, with parenting stress commonly being found as a mechanism through which parental distress influences children's mental health. Because parental distress has been shown to have the power to influence children's mental health on its own, in addition to the culminating risk from both parental stress and distress, we were interested in examining whether it had such power to change the strength of the relation between parenting stress and child anxiety.

Child Resilience

Resilience is a commonly studied protective factor in children, with much of the prior research examining it as a moderator of the association between other variables. For example, one study found that resilience moderated the relation between COVID-19's psychological impact and anxiety symptoms in adolescents, such that those with higher resilience showed fewer anxiety symptoms in relation to COVID-19 than those with lower resilience (Traunmüller et al., 2023). Another study found that resilience moderated the relation between number of adverse childhood experiences (ACEs) and odds of having mental health disorders, with children having higher resilience exhibiting lower odds of having mental health disorders in relation to their number of ACEs as compared to children with lower resilience (Okwori, 2022). Some studies have found resilience to have a moderating effect on the relation between stress and the mental health of either the child (Anyan & Hjemdal, 2016) or the parent (Wu et al., 2025), however, it remains to be seen if resilience will appear to alter the impact of parenting stress in particular. As these findings point to resilience being a robust protective factor against mental health risks in increased risk individuals, it is unknown how it may mitigate the impact of parenting stress on anxiety symptoms.

The Present Study

Our research questions are as follows: 1) is parenting stress associated with children's anxiety? 2) Does parental psychological distress moderate this relation? 3) Does children's resilience moderate this relation? We predict that we'll find a statistically significant positive relation between parenting stress and child anxiety. Moreover, as we examine both parental psychological distress and child resilience as moderators of the association between parenting stress and child anxiety, we hypothesize that parental psychological distress will strengthen the influence of parenting stress on child anxiety and increased resilience in the child will weaken the relation between parenting stress and child anxiety.

Methods

Participants

The participants in this study were part of a larger national twin project, the National Project on Achievement in Twins (NatPAT; Hart et al., 2026). The NatPAT project sought to examine twin's academic achievement and researchers partnered with the University of Oregon to use their Dynamic Indicators of Basic Early Literacy Skills (DIBELS) database of participating schools. Beginning in 2021, NatPAT participants were invited to be part of a new project focused on caregivers' and twins' experiences following the COVID-19 pandemic and the impacts on their personal and educational lives. This COVID-19 focused project uses a cohort sequential design with annual surveys sent to families for one caregiver and both twins (if enrolled in, or having completed, grade 3) to complete. The present study will use the 2023 wave of survey data collection that asked parents and twins about their COVID-related and general experiences during the 2022-2023 school year, as well as mental health related measures relevant to our research questions. For this study, participants included 576 caregivers and 1,152 children.

Children were nearly equally distributed in sex (male: 48.2%, N = 555; female: 51.8%, N = 597) and parents were mostly biological mothers (85.8%, N = 494). In regard to race, twins identified as White (87.1%, N = 1006), Mixed race (6%, N = 68), Black or African American (4.8%, N = 54), Asian (0.7%, N = 8), American Indian/Alaska Native (0.5%, N = 6), and Native Hawaiian/Pacific Islander (0.2%, N = 2). Moreover, 91% (N = 1048) identified as non-Hispanic/Latino. Families lived across the geographical United States, with survey responses from families across 40 states. Children's ages ranged from 8 to 17 years old (M = 13.2, SD = 2.21).

Procedure

The 2023 wave survey was sent to all families who were currently enrolled in the project with children under the age of 18. Parents were asked questions about themselves and each of their twins or multiples, receiving a $50 gift card for the completion and return of this questionnaire. Children were asked questions about themselves and were given a $20 gift card for the completion and return of their questionnaires.

Measures

Parenting Stress

Parents completed a one item parenting stress measure that asks, "During the 2021-2022 school year, how stressful were your parenting experiences with your child?", with responses on a 5-point Likert scale ranging from 1 (Not at all) to 5 (Very much). The item is adapted from the parenting stress question from Prime et al.'s (2021) COVID-19 Family Stressor Scale.

Child Anxiety

Children completed the Spence Children's Anxiety Scale (SCAS-8; Reardon et al., 2018) to assess the severity of anxiety symptoms. Eight items were ranked on a 4-point Likert scale ranging from 1 (Never) to 4 (Always). For scoring, sum scores were computed, with higher scores indicating greater levels of anxiety in the child. Reliability in this sample was α = 0.82, suggesting good internal consistency.

Parent Psychological Distress

Parents completed the Kessler Psychological Distress Scale (Kessler et al., 2002), a 10item measure asking about various domains of psychological distress on a 5-point Likert scale ranging from 1 (None of the time) to 5 (All the time). All items are summed to create a total score, where higher scores indicated greater parental psychological distress. Reliability was high in the sample, α = 0.92.

Child Resilience

Children completed the Brief Resilience Scale (BRS; Smith et al., 2008) to measure their ability to bounce back. It is a 6-item measure ranked on a 5-point Likert scale ranging from 1 (Strongly disagree) to 5 (Strongly agree). Items 2, 4, and 6 were reverse coded and all items were summed to create a total score. Higher total scores represent higher levels of child resilience.

The BRS demonstrates good internal consistency in this sample, with an alpha of 0.78.

Analyses

Multilevel Modeling

Due to the nested structure of our data (i.e., children nested within families), we used hierarchical linear modeling with families at level 2 and children at level 1 (HLM) in R (Version 4.5.1) using the packages tidyr (Wickham et al., 2025) and dplyr (Wickham et al., 2026) to clean the data. HLM partitions the variance in child anxiety into between family variance and residual variance which includes the variance due to differences across individuals within families (e.g., genes, etc.) plus measurement error. We took a sequential model-building approach, starting with an unconditional model and then adding predictors to examine each research question. All models were estimated using restricted maximum likelihood (REML).

Openness and Transparency

This study was preregistered on Open Science Framework (https://doi.org/10.17605/OSF.IO/XAZJ7). The data for this project is available on LDbase (Du et al., 2025), and the code for this project is openly available on GitHub (https://github.com/steph-estrera/parent-stress-child-anx).

Unconditional Model

Prior to all subsequent modeling, we centered the predictor variables for clearer interpretation of the model results. Level 1 predictors (parenting stress reported for each child, and child resilience) were group-mean centered, and the Level 2 predictor (parent distress) was grand-mean centered.

First, we tested the unconditional model with no predictors to parse the variance of child anxiety both within-and between-families. We found an average anxiety score of 5.33 (SE=0.14, p<.001) across all children. The between-family variance was 5.86 (SD=2.42), and the residual variance was 8.47 (SD=2.91) plus measurement error. The intraclass correlation indicates that 40.90% of the variance in child anxiety is attributed to the difference between families. This substantial between-family variance justified the use of multilevel modeling.

Parenting Stress (RQ 1)

To address our first research question, we conducted a random intercepts model with parenting stress as a Level 1 predictor of child anxiety. The fixed effect of parenting stress was significant, that for every one-unit increase in parenting stress, child anxiety increased by 0.65 points on average (SE=0.21, t(754.18) = 3.13, p =.002). This suggests parenting stress to be a statistically significant and positive predictor of child anxiety (see Figure 1). The between-family variance was 5.94 (SD=2.44), and the residual variance was 8.31 (SD=2.88), which indicates significant variability in child anxiety across families even when adding parenting stress as a 1 predictor. Discussion

The current study sought to investigate the relation between parenting stress and children's anxiety, while also exploring whether parental psychological distress and child resilience would emerge as moderators. Our results revealed a significant main effect between parenting stress and child anxiety, both confirming our hypothesis and mirroring prior literature.

Similar to how past research has found parenting stress to be associated with internalizing symptomology in children (e.g., Rodriquez, 2011) and with children's anxiety in particular (e.g., van Oort et al., 2010), we found that as parenting stress increased, so did child anxiety. This finding lends itself to further the conversation of the unique role of parenting stress in the etiology of children's anxiety. While past research has considered factors such as parenting styles and behaviors, future studies should investigate potential parental mechanisms through which parenting stress may be influencing child anxiety. Nevertheless, our result adds to the validity of the relation of these two variables and leads us to consider what factors may hinder or exacerbate their influence.

Beyond the direct association between parent stress and child anxiety, we were interested in examining whether parental psychological distress or child resilience would play a moderating role in the relation between parenting stress and child anxiety. Past research supports that parenting stress mediates the relation between parental distress and child anxiety (Tsoti et al., 2019; Babore et al., 2023), and we wondered if it would extend as a moderator as laid out by the cumulative risk framework (Appleyard et al., 2005). Parent psychological distress was a statistically significant main effect on child anxiety. However, our results did not support parent distress as a moderator, which suggests that it may be limited to the mediating pathway as described in prior work. The cumulative risk framework did not appear to apply to this sample in the way we hypothesized.

Further confirming the well-known protective effects of increased resilience in children (Traunmüller et al., 2023), we found that child resilience demonstrated statistically significant main effects and predicted decreased anxiety in our sample. Additionally, we hypothesized that resilience would buffer the impact of parenting stress on child anxiety, similar to previous reports (e.g., Anyan & Hjemdal, 2016; Wu et al., 2025). Although it demonstrated an association with decreased child anxiety, there was not a statistically significant interaction between parenting stress and child resilience.

In total, neither parent psychological distress nor child resilience emerged as statistically significant moderators, suggesting that although they are each correlated with child anxiety, they are not interactive on the relation between parent stress and child anxiety. While this was contrary to our initial hypotheses, these results still inform our understanding of the relation between these oft-associated variables. Agreeing with the current literature, parents experiencing increased distress may contribute to their child's own anxiety symptoms and children with increased resilience may experience protective effects against potential parental influences leading to anxiety. However, while these variables independently contribute to children's anxiety, from our findings it does not appear that they interact in a way that supports a risk and resilience framework being applied to this specific combination of variables.

Limitations and Future Directions

While our results add to established literature on additive pathways to children's anxiety, there are several limitations to consider. One limitation may be the brevity of the parenting stress measure. Because it is a one-item scale, it's possible it lacks the intricacies that could provide a more thorough look at the concept of parenting stress. Similarly, as this measure is self-report and given the subject, has the potential for social desirability bias. Future studies may wish to use a more comprehensive measure or collect biological data to get a fuller and unbiased picture of parenting stress. Another limitation may lie in the substantial unexplained variance in each of the models, indicating there are other factors not measured in the present study that further explain between-family differences in child anxiety. Including a wider range of familial factors in future models may help account for more of this variance as well as identify additional risk or resilience factors that may prove statistically significant in protecting against or exacerbating children's anxiety from parenting stress.

Because parenting stress is widely prevalent and shown to interact with children's anxiety, future research should explore how best to identify afflicted families and examine best practices and interventions to mitigate parental effects on children's mental health. Our sample had generally low levels of symptomology overall and future researchers may want to apply this methodology to more clinical samples to determine if the effects still hold. In sum, our findings provide a foundation for researchers to clarify family-level factors underlying the etiology of anxiety in children, consider child-specific interventions, and provide parents with actionable insights into supporting their children's mental well-being.

Descriptive statistics for the transformed variables can be found in Table 1 and descriptive statistics for the raw data can be found in Supplemental Material 2.

Missingness was assessed at the variable level for each of the four main variables (Table 1). Missingness was also assessed at the case level and found that participants are missing on average 4.9% of their responses across all variables. The majority of our respondents have all four variables (N=1010). We used the MissMech package (Jamshidian et al., 2014) and the misty package (Yanagida, 2026) in R to test whether the data is missing at random. We used Little's MCAR test (Little, 1988), which indicated no significant evidence against MCAR (p=.52).

However, we also conducted a Hawkins' parametric test which examines covariance homogeneity in the missing data patterns, and this test indicated a significant departure from MCAR (p<.05). The results of both tests suggest that while the mean patterns were consistent, the covariance structures were different. To be more conservative, we treated the data as missing at random (MAR) and proceeded using multiple imputation by chained equations with the MICE package in R (van Buuren & Groothuis-Oudshoorn, 2011). We generated 20 imputed datasets after 20 iterations which uses the Fully Conditional Specification approach and predictive mean matching for all continuous variables (i.e., parenting stress, child anxiety, parent distress, and child resilience) that have missing data. All subsequent analyses were fitted to the imputed datasets, and results were pooled using Rubin's rules (Rubin, 1987). Pearson correlations were computed using the miceadds package in R (Robitzsch & Grund, 2026) and reported in Table 2.
