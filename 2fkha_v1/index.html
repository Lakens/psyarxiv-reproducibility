Reporting p values imprecisely (e.g., p < .05) reduces transparency, reproducibility, and re-use (e.g., in p value meta-analyses). Best practice is to report exact p-values with three decimal places (e.g., p = .032) unless p values are smaller than 0.001, in which case you can use p < .001.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (e.g., “decreased at the p < .05 significance threshold”).

The APA manual states: Report exact p values (e.g., p = .031) to two or three decimal places. However, report p values less than .001 as p < .001. However, 2 decimals is too imprecise for many use-cases (e.g., a p value meta-analysis), so report p values with three digits.

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Data Check works

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

1 Introduction

Abnormalities in language, such as formal thought disorder (FTD) and disorganized speech, are central to the clinical presentation and diagnostic criteria of schizophrenia (Andreasen & Flaum, 1991). Psychotic symptoms such as auditory hallucinations, which are present in 60-80% of patients (Lim et al., 2016), frequently involve speech in the absence of sensory input. Indeed, it has been proposed that the emergence of schizophrenia is closely tied to the evolutionary development of the language system (Chang et al., 2022). Therefore, the identification of behavioural, cognitive, and neurobiological correlates of language dysfunctions is important for understanding the pathophysiology of schizophrenia as well as for the identification of biomarkers (Chang et al., 2022; Corcoran et al., 2020; Hinzen & Palaniyappan, 2024; Meyer et al., 2021; Morgan et al., 2021; Tang et al., 2023). However, the underlying loci of language-related dysfunctions in schizophrenia remain unclear.

Language processing in schizophrenia has been shown to differ across multiple psycholinguistic levels of representation, ranging from acoustic-phonetic and categorical perception (Bruder et al., 2001; Cienfuegos et al., 1999; Fisher et al., 2008), to higher-order semantic and syntactic processing (Ditman & Kuperberg, 2007; He et al., 2024; Kuperberg et al., 2006; Swaab et al., 2013).

Language deficits have also been observed in clinical high-risk for psychosis (CHR-P) individuals, often involving changes to semantic networks (Morgan et al., 2021; Nettekoven et al., 2023). The pattern of language deficits involves both bottom-up as well as disrupted higher-order linguistic functioning (M. Brown & Kuperberg, 2015; Kuperberg et al., 2006) but contributions of domain-general mechanisms, such as attention, have not been investigated.

Neural oscillations provide a means of investigating bottom-up and top-down processing during speech comprehension. Oscillations are a fundamental aspect of brain functioning (Engel et al., 2001; Singer, 2009) and constitute an important aspect of the pathophysiology of schizophrenia (Hirano & Uhlhaas, 2021; Uhlhaas & Singer, 2015). Further evidence suggests that endogenous oscillations are entrained by speech, especially in lower (delta <4 Hz, theta <8 Hz) frequency bands (Arnal & Giraud, 2012; Giraud & Poeppel, 2012). Low-frequency speech entrainment is correlated with speech intelligibility (Gross et al., 2013; Peelle et al., 2013) and associated with the tracking of linguistic information at different timescales, such as phonemes, syllables, and prosody (Di Liberto et al., 2015; Hyafil et al., 2015; Lamekina & Meyer, 2023).

However, the contribution of attention to language processing in CHR-Ps is unclear. Attention has been shown to enhance representation of task-relevant speech in the auditory cortex (Mesgarani & Chang, 2012). This is consistent with the "cocktail-party phenomenon", an ability to focus in on a target speech stream. Attending to specific speech streams increases event-related desynchronization in the alpha frequency band (~8-10 Hz) in auditory cortices (Dimitrijevic et al., 2017). Indeed, alphaband oscillations during speech perception may support the engagement of task-relevant brain regions (Tóth et al., 2019), with some authors proposing alpha activity as a proxy for attentional processes (Wöstmann et al., 2017). The presence of background speech can also disrupt entrainment to target speech (Dai et al., 2022), suggesting that in normal brain functioning, background speech is still monitored and encoded even if that speech is outside the main focus of attention (A. Brown et al., 2023; Dai et al., 2022). In schizophrenia and in CHR-P, attentional deficits are an important aspect of cognitive impairments, observed through both behavioural and neuroimaging data (Braff, 1993; Braff & Light, 2004; Kim et al., 2012; Üçok et al., 2013; Verleger et al., 2013).

In the present study, we used electroencephalography (EEG) to investigate speech processing impairments in CHR-P. In a previous MEG study, we showed that speech entrainment in the auditory cortices was reduced in CHR-Ps and schizophrenia patients compared to controls (Grent-'t-Jong et al., 2024), with the most pronounced effect in the theta band (4.50-6.50 Hz). However, the contribution of attention towards speech entrainment was not investigated. To examine this question, we implemented a dual-task speech entrainment paradigm to separate the effects of bottom-up processing and top-down attention in CHR-P individuals and healthy controls (HCs). We hypothesized that oscillations in the auditory cortices of CHR-Ps may be differently modulated when speech listening is task-relevant. Specifically, we expected reduced speech entrainment in the delta and theta bands for CHR-Ps compared to HCs, consistent with proposed deficits in bottom-up speech processing in this population. We also expected a difference in alpha entrainment, with CHR-Ps showing reduced alpha entrainment compared to HCs when the speech is not task relevant, indicating a group difference in attention-driven modulations of entrainment.

2 Methods

2.1 Participants

A total of n=46 participants were recruited (age range 12-31 years), with n=21 CHR-P individuals (mean age 16.8 ± 3.3 years, 17 females) and n=25 HCs (mean age 19.3 ± 5.6 years, 15 females). CHR-P status was confirmed via the Structured Interview for Psychosis-Risk Syndromes (SIPS, V3.0, German, (Miller et al., 2003) and the Scale of Psychosis-Risk Symptoms (SOPS), with the following inclusion criteria: a) at least one symptom from P1-P5 rated between 3 and 5, b) one symptom rated 6 on P1-P5 that occurs infrequently or resolve spontaneously within 7 days without medical intervention, or c) familial high-risk with significant loss of functioning. Present functioning was assessed using Global Assessment of Functioning (GAF), Global Functioning role (GF-role) and Global Functioning social (GF-social) scales. The Structured Clinical Interview for DSM-5 Disorders-Clinical Version (SCID-5-CV) (First et al., 2016) or the Schedule for Affective Disorders and Schizophrenia-Present-and-Lifetime Version (K-SADS-PL, (Kaufman et al., 1997) were used to determine comorbid DSM-V diagnoses. Participants also completed subtasks of CANTAB testing battery, including Emotion Recognition (ERT), Motor Screening (MOT), Paired Associates Learning (PAL), Reaction Time (RTI), Rapid Visual Information Processing (RVP), Spatial Span (SSP), Spatial Working Memory (SWM), and Verbal Recognition Memory (VRM) (Robbins et al., 1994).

All participants were recruited at the Department of Child and Adolescent Psychiatry, Charité -Universitätsmedizin Berlin, Germany. Healthy control participants were recruited from the local community. Ethical approval of the study was provided by the Institutional Research Board of the Charité -Universitätsmedizin Berlin. All participants had normal or corrected-to-normal vision and were not hearing impaired. Only native German speaking, right-handed participants were included in the present analyses. All participants provided written informed consent (when younger than 18 years, consent was also provided by a parent/guardian) and were paid 10 Euro per hour of participation.

2.2 Experimental Paradigm

Participants listened to 5.8-minute children's Sherlock Holmes story (available online from OHRKA e.V.). The story was presented in three listening conditions: (1) Active, (2) Passive, and (3) Passive-reversed (i.e., unintelligible time-reversed and noise-vocoded speech). In all three conditions, visual stimuli corresponding to the Flanker task were presented at fixation while the story was played.

There was one block per condition. During the Active listening block, participants were instructed to attentively listen to the story, while ignoring visual stimuli. This was followed by a 20-item comprehension questionnaire, whereby participants were presented with statements about the story content and were asked to rate the validity of a statement on a scale from 0% to 100%, providing a measure of both comprehension accuracy and confidence.

2.3 EEG and MRI-Data Acquisition

Participants were seated in a sound-attenuated booth at 80 cm from the screen while EEG-data was collected using an actively shielded EEG-amplifier (ANT-neuro) and 64-channel Waveguard caps.

Reference and ground were placed on the earlobes and data were sampled at 500 Hz without online filtering (DC-250 Hz range). The audio was presented through an EEG-compatible Etymotic Research (ER-3C) inner-earphone system at 50 dB above individually determined hearing threshold. T1weighted structural magnetic resonance images (MRI) were obtained on a later date, with a 3T Siemens Prisma scanner using a 3D Magnetization Prepared Rapid Gradient Echo sequence (1x1x1 mm resolution, 176 volumes, TR=2500 ms, TE=2.64 ms, FA=8).

2.4 Data Processing and Analysis

EEG data were pre-processed in MATLAB using the FieldTrip Toolbox (Oostenveld et al., 2011).

One EEG trial was created, time-locked to the onset of the audiobook. Data were downsampled to 250 Hz, demeaned, and high pass filtered (>0.1 Hz). Artefacts (eyeblinks, eye movements, heartbeat) were corrected using independent component analyses (ICA). Data were then re-referenced to the common average reference. Gaussian-Copula Mutual Information (MI) analysis was used to estimate individual speech-tracking ability (Ince et al., 2017). This method computes statistical dependence between the EEG and the speech amplitude envelope (Gross et al., 2013). The MATLAB Chimera toolbox (Gross et al., 2013) was used to reconstruct the amplitude envelope by splitting the speech signal into nine frequency bands from 100-10,000 Hz using equidistant spacing on the cochlear map (Smith et al., 2002) and bandpass filtering using a 4th order Butterworth filter (two directions). Amplitude envelopes were then computed for each band as absolute values of the Hilbert transform, then subsequently averaged across bands to obtain a wide-band amplitude envelope, which was downsampled to 250 Hz for further analyses. The MI analyses were conducted at sensor-level and at source-level, with the latter including virtual-channel data reconstructed from manually selected left and right auditory cortex locations (LAUD and RAUD; see Figure 2A), approximately 0.5 cm below Heschl's gyrus, inside the superior temporal gyrus, and approximately 2 cm inwards from the outer cortex seen on the coronal slice through Heschl's gyrus. These regions of interest (ROIs) were selected as they showed reliable speech entrainment across groups in the previous MEG study (Grent-'t-Jong et al., 2024).

For virtual-channel reconstruction, individual T1-weighted scans were co-registered with the EEG data using anatomical landmarks (nasion and bilateral pre-auricular points), followed by tightfitting of standardized electrode positions. A Boundary Element Method (BEM) volume-conduction model of the head was computed using OpenMEEG routines (Gramfort et al., 2010), creating meshes for three surfaces (brain, scalp, skull: number of vertices 3000, 2000, and 1000, respectively). Then, a 10 mm source-grid was created with 3294 dipoles inside and 3510 dipoles outside the head warped to the subject-specific grid, based on the MNI template (Montreal Neurological Institute). Virtualchannel timeseries were computed for LAUD and RAUD ROIs using eLORETA in FieldTrip (Oostenveld et al., 2011) with a regularisation parameter of 10%. Finally, sensor-level and virtual-channel data were shifted by +100 ms as in previous studies (Grent-'t-Jong et al., 2024; Gross et al., 2013) to compensate for delays between the brain response and auditory input. MI analyses were applied comparing the audio envelope and the sensor-level or virtual-channel EEG data for frequencies between 0.25 and 50 Hz, using 0.25 Hz resolution and Slepian multitapers with a smoothing factor of 4 Hz. Mean MI values were extracted for both the sensor-level and virtual-channel data and submitted to statistical testing.

2.5 Statistics

2.5.1 Behavioural data analyses

Data were first tested for violations of normal distribution and homogeneity of variance.

Where assumptions were violated, equivalent non-parametric tests were used. Story comprehension was assessed with percent accuracy and confidence of true/false ratings using a one-way ANOVA.

Flanker task performance was assessed with percent accuracy and mean reaction times using ANOVA with the between-subject factor of Group and the within-subject factors of Congruency (levels: Congruent, Incongruent) and Speech Intelligibility (levels: Passive, Passive-reversed).

2.5.2 EEG data analyses

Sensor-level data were tested for main effects of Attention (Active vs Passive) and Speech Intelligibility (Passive vs Passive-reversed) across all participants in the frequency domain (0.25-15 Hz) using non-parametric cluster-based permutations tests (t-statistic, alpha=0.05, 2-tailed) for timeseries data (Maris & Oostenveld, 2007). Subsequent statistical analyses were performed using JASP (JASP Team, 2024). We examined the effect of attention on entrainment in bilateral auditory cortex using mean MI extracted from virtual channels. Statistical testing included repeated-measures Linear Mixed Models with the between-subject factor of Group (levels: CHR-P, HC), within-subject factors of Attention (levels: Active, Passive) and ROI (levels: LAUD, RAUD), all interaction terms between these three factors. Models included the additive factor Age to control for developmental differences, and random intercepts to control for by-Subject variance (example R-syntax: average MI ~ Group * Condition * ROI + Age + 1 | Subject).

Tests were conducted separately for three frequency ranges: delta (0.25-3.00 Hz), defined based on the cluster from the present sensor-level analysis; theta (4.5-6.5 Hz), defined based on the significant cluster of the previous MEG study (Grent-'t-Jong et al., 2024); and alpha (7.0-10.0 Hz), defined following visual inspection, and supported by its overlap with auditory alpha frequency ranges used in previous investigations of attention-related oscillations in speech listening tasks (Wöstmann et al., 2017). For CHR-Ps, performance on speech comprehension and the Flanker task as well as scores on clinical symptom measures were compared to entrainment (MI) using Bayesian Pearson Correlation.

4 Discussion

Alterations in language processing are a core symptom of schizophrenia, yet the relative contribution of bottom-up and top-down deficits remains unclear. Here, we manipulated speechdirected attention to investigate how top-down processing impacts entrainment in the auditory cortex during language comprehension. Our findings reveal that theta entrainment was reduced in CHR-Ps while delta and alpha entrainment were modulated by attention, suggesting a combination of both bottom-up and top-down mediated speech processing impairments in CHR-Ps.

In the current study, we observed increased delta entrainment for intelligible compared to unintelligible speech (Passive>Passive-reversed), demonstrating preferential entrainment for speech signals. Moreover, we observe an effect of attention, whereby delta entrainment is further enhanced when attention is directed to speech (Active>Passive). Thus, we demonstrate that speech entrainment in the delta band is sensitive to both bottom-up and top-down processes.

In CHR-Ps, theta entrainment was reduced across conditions, which is consistent with our previous MEG findings (Grent-'t-Jong et al., 2024). Alpha entrainment showed a more complex picture.

When attention was directed away from speech, alpha entrainment was reduced in CHR-Ps but maintained in HCs. Moreover, HCs showed longer RTs in the Flanker task when background speech was intelligible, potentially indicating distraction and interference by speech for HCs but not CHR-Ps.

Delta and theta oscillations are central to the bottom-up language processing and the encoding of speech information (Di Liberto et al., 2015; Giraud et al., 2007; Giroud et al., 2024; Meyer, 2018; Meyer et al., 2020; Peelle et al., 2013; Peelle & Davis, 2012). Modulation of delta entrainment by attention is consistent with previous reports (Dai et al., 2022; Ding et al., 2018), and suggests that domain-general modulations of neural gain may enhance entrainment (Bouwer, 2022; Lage-Castellanos et al., 2023; Pesnot Lerousseau et al., 2021). Furthermore, if entrainment emerges via stimulus-driven and linguistically-guided processes (Gwilliams, 2020; Meyer et al., 2020), then the observed theta entrainment deficit in CHR-Ps may contribute to disrupted bottom-up spectrotemporal and phonemic processing critical for speech encoding and subsequent linguistic processing (Giroud et al., 2024).

Alpha oscillations, which are proposed to reflect attentional control during speech processing (Wöstmann et al., 2017), are known to be disrupted in schizophrenia (Abeles & Gomez-Ramirez, 2014; Basar-Eroglu et al., 2008; Uhlhaas & Singer, 2015). Reduced alpha entrainment was observed in the current study in CHR-Ps when attention was directed away from speech, while HCs showed elevated alpha entrainment irrespective of whether speech task-relevant or in the background. There are two possible explanations for this reduced alpha entrainment. First, modulations in alpha entrainment may reflect domain-general resource allocation. If the CHR-P group have limited domain-general resources, this could lead to reductions in alpha entrainment to background speech when top-down attention is redirected away. At the same time, even when speech listening is not the attended task, HCs may still have resources available to monitor background speech, resulting in elevated alpha entrainment.

Alternatively, it is possible that alpha entrainment reflects stimulus-driven exogenous attentional capture. If CHR-Ps have deficits in bottom-up processing (perhaps due to dysfunctional theta oscillations) this could disrupt the stimulus-driven and linguistically-guided parsing mechanisms of speech entrainment, thereby disrupting the mapping between speech input and linguistic knowledge and preventing sufficient encoding required for exogenous (stimulus-driven) attentional capture. In contrast, intact speech encoding and an intact mapping from speech to linguistic knowledge in HCs could give rise to exogenous attentional capture by speech and thereby enhanced alpha entrainment. This explanation can account for both the attention-independent alpha entrainment and the distraction effect in the Flanker task in HCs. It is also possible that both endogenous top-down control and exogenous stimulus-driven capture are both at work. It is further supported by brainbehaviour correlations in CHR-Ps, in which greater alpha entrainment during Passive listening is associated with higher comprehension, while greater attention-driven delta modulations between the Active and Passive conditions are associated with fewer perceptual symptoms in CHR-Ps.

5 Conclusion

Our findings show that speech entrainment in CHR-Ps involves both bottom-up deficits in theta-band activity while delta-and alpha-band entrainment are impacted by attention. Furthermore, CHR-Ps show less distraction and reduced alpha entrainment in the presence of off-task intelligible speech.

We postulate that reduced alpha entrainment is consistent with dysfunction in either exogenous attentional capture, top-down domain-general attentional control, or both, in this population. Overall, our findings support disrupted entrainment as a potential locus of speech processing deficits in schizophrenia. Future studies are needed to further characterize the contributions of stimulus-driven processing and linguistically-guided parsing to speech entrainment in general, particularly in the theta and alpha ranges, and to disentangle these factors in language processing in schizophrenia. During the Passive and Passive-reversed blocks, participants were asked to perform the visual Flanker task. The Flanker task included an array of 5 horizontally presented arrowheads, centred at fixation (extending approximately 10 degrees of visual angle). The middle arrowhead was relevant for the task (press left or right button to indicate the direction of the arrowhead, 160 trials per run, 50% left button 50% right button response), and two flanking arrowheads were presented on either side of the stimulus. The flankers were either pointing in the same direction (i.e., congruent, 50% of trials) or pointing in the opposite direction (i.e., incongruent, 50% of trials) with respect to the central arrowhead.
