Reporting p values imprecisely (e.g., p < .05) reduces transparency, reproducibility, and re-use (e.g., in p value meta-analyses). Best practice is to report exact p-values with three decimal places (e.g., p = .032) unless p values are smaller than 0.001, in which case you can use p < .001.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (e.g., “decreased at the p < .05 significance threshold”).

To check Non-Significant P Value Check

What we found

We found 25 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

Animal research committee names - Institutional Animal Care and Use Committee / IACUC (US standard) - Any sentence containing animal(s) and committee (or board/panel) within ~5 words of each other — catches Experimental Animal Care and Use Committee, Animal Ethics Committee, Animal Welfare Board, Animal Welfare Ethical Review Body, etc. - UK: Animal Welfare Ethical Review Body / AWERB - Dutch: Dierexperimentencommissie / DEC (see DEC constraint above); Instantie voor Dierenwelzijn / IvD - German: Tierversuchskommission / TvK (advisory committee under §15 Tierschutzgesetz) - French: Comité d'éthique en expérimentation animale / CEEA; Comité d'éthique animale - Spanish: Comité de ética en experimentación animal / CEEA

Waiver / exemption - Ethics/Ethical (waiver|exemption) - IRB (waiver|exemption|exempt) - Exempted from (ethics|irb|institutional review) - Waived by the (ethics|irb|institutional|review) (committee|board) - Deemed exempt

Declaration of Helsinki - Declaration of Helsinki / Helsinki Declaration

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. Abstract

Reading words aloud improves later recognition relative to reading them silently, a phenomenon known as the production effect. This advantage may reflect not only the distinctive sensorimotor information generated by production, but also cognitive control processes that prioritise this information during encoding. Given the central role of the dorsolateral prefrontal cortex (DLPFC) in supporting cognitive control, we tested whether this region causally contributes to the production effect using transcranial magnetic stimulation (TMS). In a preregistered within-participant study, 40 adults completed three sessions in which TMS was delivered bilaterally to the DLPFC. They received continuous theta-burst stimulation (cTBS), expected to reduce DLPFC excitability; intermittent thetaburst stimulation (iTBS), expected to increase it; or sham stimulation. Participants then read words aloud or silently before completing an old/new recognition test with confidence and recollection judgements. There was a clear production effect: words read aloud were recognised more accurately and quickly, with greater confidence and more frequent recollection ratings, than words read silently. Crucially, cTBS reduced the accuracy advantage for aloud words relative to sham and iTBS. Exploratory receiver-operatingcharacteristic (ROC) and unequal-variance signal-detection (UVSD) modeling approaches provided converging evidence that cTBS reduced the memory advantage for words read aloud. Stimulation did not reliably affect responses to new words. These findings provide the first causal evidence that the DLPFC helps make words read aloud more memorable, DLPFC AND THE PRODUCTION EFFECT 3 consistent with a role for cognitive control in prioritising the distinctive information generated by speaking.

Introduction

Reading a word aloud at study reliably improves subsequent memory for that word relative to reading it silently, a phenomenon known as the production effect (Hopkins & Edwards, 1972; MacLeod et al., 2010). This memory advantage extends across materials, memory tests, and forms of production (Fawcett, 2013; Forrin et al., 2012; MacLeod & Bodner, 2017; Zormpa et al., 2019). A prominent explanation is that production makes an item distinctive in memory: speaking adds auditory, articulatory, and somatosensory features that can provide evidence of prior study (Bailey et al., 2021; MacLeod et al., 2010). These features are particularly useful in mixed-list designs, where aloud and silent words are studied together (Ozubko & MacLeod, 2010).

Evidence from neuroimaging and psychophysiology links the production benefit to both sensorimotor processing and preparation to speak. Activity in auditory, motor, and somatosensory regions during encoding is associated with subsequent recollection of aloud words (Bailey et al., 2021). Preparing to read aloud also elicits greater pupil dilation and larger cue-evoked P300 responses than preparing to read silently (Fawcett et al., 2026a; Hassall et al., 2016). Preparing to read a word aloud can even improve memory relative to silent reading when the anticipated signal to speak never appears (Fawcett et al., 2026b).

Thus, processes preceding vocalisation may contribute to the memory benefit alongside the sensorimotor information generated by speaking.

These findings are consistent with a contribution from cognitive control, defined here as the use of goals and task rules to guide processing and behaviour (Friedman & Robbins, 2022; Miller & Cohen, 2001). In a mixed-list task, participants must select the instructed reading mode, with aloud trials additionally requiring preparation and coordination of a vocal response. Control processes may help prioritise production-related information and incorporate it into the memory representation of the word. This proposal complements the distinctiveness explanation by identifying control processes that could support the encoding and use of distinctive features. However, existing behavioural and physiological evidence does not establish whether a neural system supporting cognitive control causally contributes to the production effect.

The dorsolateral prefrontal cortex (DLPFC) provides a plausible neural substrate for a control contribution to the production effect because of its role in maintaining task goals and biasing processing towards relevant representations and actions (Badre & Nee, 2018; Miller & Cohen, 2001). It also supports the organisation of information during encoding and the evaluation of retrieved information (Blumenfeld & Ranganath, 2007; Dobbins et al., 2002; Murray & Ranganath, 2007). In production-based tasks, these functions could support the encoding of production-related features and their subsequent use as evidence that a word was studied. If DLPFC-supported control helps confer the memory advantage of speaking, perturbing this region should alter the aloud-silent memory difference.

We tested this proposal in a preregistered within-participant study crossing encoding condition (aloud, silent) with bilateral DLPFC stimulation (continuous theta-burst stimulation [cTBS], intermittent theta-burst stimulation [iTBS], sham). Theta-burst stimulation can transiently alter cortical and network function (Huang et al., 2005; Suppa et al., 2016). We predicted that aloud items would be recognised more accurately and rapidly, with greater confidence and recollection (H1), and that iTBS would increase whereas cTBS would reduce this advantage relative to sham (H2).

Materials and Methods

Participants

Forty adult participants (22 female, 17 male, and 1 non-binary), aged 18-41 years (M = 22.8, SD = 3.88) completed three experimental sessions and were included in the analyses.

No participants were excluded. Participants were recruited from the University of Aberdeen School of Psychology participant pool and through local advertisements and received either course credit or financial compensation.

Eligibility required self-reported proficiency in English and fulfilment of TMS safety criteria, assessed with a TMS screening questionnaire. Individuals were not eligible to participate if they reported contraindications for TMS, including a personal or family history of seizures or epilepsy, or other neurological conditions. The study was approved by the Psychology Ethics Committee at the University of Aberdeen (Worktribe ID 815096). All participants provided informed consent before taking part and were fully debriefed following their final session.

Sample Size Determination

The target sample size was determined using a simulation-based power analysis for a three-level repeated-measures comparison, implemented in R using the 'MASS' package (Venables & Ripley, 2013). The simulation assumed a target power level of 0.90, two-sided alpha level of 0.05, rho of 0.50, and a standardised mean difference of d = 0.52, based on reported effects of TMS on verbal memory accuracy (Osaka et al., 2007). The analysis indicated that 40 complete datasets were required.

Preregistration

The hypotheses, design, sample size rationale, eligibility and exclusion criteria, dependent variables, production effect indices, and confirmatory analysis plan were preregistered: https://osf.io/yreag/overview?view_only=265c50fac9434301b96c8f9525329f5f. Analyses not specified in the preregistration are identified as exploratory. There were no deviations from the preregistration.

Stimuli

The stimulus pool was adapted from the materials used by MacDonald and MacLeod (1998) and comprised 480 English nouns. The words were grouped into three 160-word lists.

In each session, participants studied 80 words, of which 40 were assigned to the aloud condition and 40 to the silent condition. The subsequent recognition test comprised the 80 studied words and 80 previously unseen words, yielding 160 test trials per session. Each word appeared in only one session for each participant. The assignment of word lists to stimulation sessions and of words to the aloud and silent conditions was counterbalanced across participants. The studied versus new word assignment was also counterbalanced across participants.

Word lists were matched as closely as possible on word frequency, syllable count, initial phoneme, and concreteness. Each list contained equal numbers of abstract and concrete nouns, and this balance was preserved across the aloud and silent conditions and between studied and new words. Analyses of variance confirmed that SUBTLEX-UK word frequency (van Heuven et al., 2014) did not differ across the three lists, F(2, 237) = 0.01, p = 0.99, between aloud and silent conditions, F(1, 234) = 0.001, p = 0.98, or by the list × encodingcondition interaction, F(2, 234) = 0.01, p = 0.99; nor did it differ between old and new items, F(1, 474) = 0.27, p = 0.60, or by the list × word-type interaction, F(2, 474) = 0.001, p = 0.99. Syllable counts likewise did not differ across lists, F(2, 237) = 0.09, p = 0.91, between aloud and silent conditions, F(1, 234) = 0.06, p = 0.80, or by the list × encoding-condition interaction, F(2, 234) = 0.28, p = 0.76, and did not differ between old and new items, F(1, 474) = 0.01, p = 0.91, or by the list × word-type interaction, F(2, 474) = 0.08, p = 0.92. Initial phonemes were balanced across lists so that no stimulation or encoding condition carried a systematic word-onset bias.

Transcranial Magnetic Stimulation

Each participant completed one cTBS, one iTBS, and one sham stimulation session.

The order of stimulation conditions across sessions was counterbalanced across participants.

TMS procedures followed current safety recommendations for use with healthy adults (Rossi et al., 2009 (Rossi et al., , 2021)). Stimulation was delivered with a MagPro X100 stimulator and a MagVenture CB-70 coil (outer diameter = 7.5 cm; MagVenture A/S, Farum, Denmark). The description of the TMS procedures was guided by TMS-RAT v1.0, which provides a comprehensive framework for documenting TMS study characteristics (Székely et al., 2026).

Active motor threshold (AMT) measurement. Each participant's AMT was measured using surface electromyography at the start of their first session. After skin preparation, surface electrodes were placed over the right first dorsal interosseous (FDI) muscle, with the active electrode over the muscle belly, the reference electrode on the index finger, and the ground electrode on the dorsum of the hand. Single-pulse TMS was delivered over the left primary motor cortex while participants maintained a slight contraction of the right FDI. The coil was adjusted to identify the motor hotspot, and stimulation intensity was varied adaptively. AMT was defined as the lowest stimulator output that elicited motorevoked potentials (MEPs) of at least 150 μV peak-to-peak amplitude in at least three of five consecutive trials.

Neuronavigation and stimulation sites. After AMT measurement, DLPFC targets were identified using Montreal Neurological Institute (MNI) template-based stereotactic neuronavigation. Neuronavigation was performed using Localite software (Localite GmbH, Sankt Augustin, Germany). Each participant's scalp anatomy was coregistered to the MNI ICBM152 T1 template by identifying landmarks, including preauricular points, outer eye canthi, nasion, inion, and posterior and superior scalp surfaces using a tracked pointer. The left DLPFC target was defined as x = -50, y = 30, z = 36, a coordinate at the junction of Brodmann areas 9 and 46 derived from Rusjan et al. (2010). The homologous right DLPFC DLPFC AND THE PRODUCTION EFFECT 10 target was defined by reversing the sign of the x-coordinate (x = 50, y = 30, z = 36). The TMS coil position and orientation, together with participants' head position, were monitored in real time during stimulation.

Stimulation parameters. Active stimulation was delivered bilaterally over the DLPFC at 90% of each participant's AMT, with the same intensity in all three TMS sessions for each participant. The left and right DLPFC were stimulated sequentially, with the stimulation order counterbalanced across sessions and participants. For cTBS, 600 pulses arranged in continuous triplet bursts at 50 Hz were delivered as a 40 s train. For iTBS, 600 pulses arranged in continuous triplet bursts at 50 Hz were delivered in 2 s trains repeated every 10 s for a total duration of 190 s (Huang et al., 2005). During the sham session, the cTBS protocol was administered using a CB-70 coil placed on the participant's head while the active coil was oriented 90° away from the scalp, resulting in no effective cortical stimulation. Participants were blind to stimulation condition and were monitored for discomfort and adverse events during and after stimulation.

Production Effect Task Encoding phase. Immediately after stimulation, participants completed the production-effect task. Inquisit Lab 6 software (Millisecond, Seattle, USA) was used for stimulus presentation. The encoding phase contained 80 trials: 40 words presented in blue, which participants read aloud, and 40 words presented in white, which participants read silently. Stimuli were presented on a black background. Each word was displayed for 2000 ms, followed by a 500 ms inter-trial interval, in a random order for each participant in each session. Participants were instructed to try to remember all words for a memory test that would follow.

Recognition phase.

The recognition phase contained 160 trials -the 80 studied words and 80 new words-all presented in yellow, in a unique random test order. For each word, participants first made an old/new recognition judgement by pressing 'Y' for old or 'N' for new. They then rated their confidence from 1 (not sure at all) to 4 (very sure). For words judged as old, participants indicated whether they recollected any specific detail from encoding episode, such as the word's colour or whether it had been spoken, by responding 'Y' for yes or 'N' for no. All recognition phase responses were self-paced.

Language background measures. After the recognition phase in the third session, participants completed the Lexical Test for Advanced Learners of English (LexTALE; Lemhöfer and Broersma, 2012), a brief test of English proficiency. They also completed an abbreviated Language Experience and Proficiency Questionnaire (LEAP-Q; Marian et al., 2007) to collect information on their language background. These measures were not included in the preregistered hypothesis tests.

Experimental Design

The experiment used a 3 × 2 within-participant design with stimulation condition (sham, cTBS, iTBS) and encoding condition (aloud, silent) as factors. Stimulation condition varied between sessions, with one condition administered per session and session order counterbalanced across participants; encoding condition varied within each session.

Dependent measures included recognition accuracy, response time, confidence, and recollection.

Data Analysis

All analyses were conducted in R with a significance criterion of α = .05.

Confirmatory analyses followed the preregistered analysis plan and were implemented with the 'rstatix' package. For all repeated-measures analyses of variance (ANOVAs), sphericity was assessed with Mauchly's test, and uncorrected degrees of freedom are reported where sphericity held.

Preregistered tests of the production effect and its modulation. To test for H1, i.e., the presence of a production effect, we examined the effect of encoding condition (aloud vs silent) on each of four memory measures-recognition accuracy (hit rate) for old words, response time for correctly recognised old items, confidence, and recollection-using pairedsamples t-tests that collapsed across stimulation condition. Effect sizes are reported as dz. For response-time analyses, we retained only correctly recognised old-item trials and excluded individual trials with latencies more than 3 SD above or below the grand mean of those trials before computing participant-level means, limiting the influence of atypically fast or slow responses that were unlikely to reflect engaged task performance.

To test for H2, i.e., the role of the DLPFC in the production effect, we first computed within-participant difference scores in each stimulation condition. Difference scores were calculated as aloud minus silent for recognition accuracy (hit rates), confidence, and recollection, and as silent minus aloud for response time, such that positive scores consistently indicated an advantage for aloud items. For each measure, these scores were submitted to a one-way repeated-measures ANOVA with stimulation condition (sham, cTBS, and iTBS) as the within-participant factor. Recognition accuracy (hit rate) was designated the primary outcome for H2 because it provides the most direct behavioural index of recognition success and was the measure on which the a priori sample size calculation was based (Osaka et al., 2007). Each ANOVA was followed by three planned contrasts (cTBS vs sham, iTBS vs sham, and cTBS vs iTBS) with Holm corrections for p values. Effect sizes are reported as generalized η² for the ANOVAs and dz for the contrasts.

Exploratory robustness and decomposition analyses. Exploratory follow-up analyses were then used to assess the robustness of the primary accuracy finding.

To characterise how the stimulation-related change in the production effect was distributed across encoding conditions, participant-level old-word hit rates were analysed using a 3 (stimulation: sham, cTBS, iTBS) × 2 (encoding: aloud, silent) repeated-measures ANOVA. The stimulation × encoding interaction is algebraically equivalent to the one-way stimulation effect on the corresponding aloud-minus-silent difference scores. Pairwise comparisons were Holm-corrected pairwise across the six simple effect pairwise contrasts.

We also assessed whether the effects of TMS on recognition accuracy could reflect a speed-accuracy trade-off in an exploratory analysis. Within each stimulation × encoding condition, we correlated old-word recognition accuracy (hit rate) with mean response time. In addition, within each stimulation condition, we correlated the magnitude of the accuracy production effect (aloud minus silent) with the magnitude of the response-time production effect. Correlations were computed as Pearson's r, with Spearman's rho reported as a sensitivity analysis, and Bonferroni-corrected p values within each family of comparisons.

Control new-word analyses.

To test whether stimulation produced a general change in recognition responding, performance on new words-rejection rate, confidence, response time, and false-alarm recollection-was analysed using a one-way repeated-measures ANOVA with stimulation condition as the within-participant factor. New-word response times were computed on correct rejections only, following the hits-only definition used for old words.

Receiver operating characteristic (ROC) analyses. Exploratory receiver-operatingcharacteristic (ROC) analyses were used to distinguish mnemonic discriminability from response criterion. ROC curves were constructed for each condition by combining the old/new decision and four-point confidence rating were combined into an eight-category ordered response scale ranging from a high-confidence "new" response to a high-confidence "old" response. For each stimulation and encoding condition, cumulative hit and false-alarm rates were calculated across successive criteria to construct the empirical ROC. The area under each curve (AUC) was computed using the trapezoidal rule as an index of discriminability (Hautus et al., 2021; Macmillan & Creelman, 2005). To estimate the variability of the AUC values and compare conditions, a bootstrap procedure with replacement was used: on each of 10,000 iterations, participants were resampled with replacement while preserving the within-participant dependency between the aloud and silent conditions, and AUC values were recomputed. For each pairwise comparison, the difference between the empirical AUC values was divided by the standard deviation (s) of the bootstrapped differences to yield the statistic D = (AUC₁ -AUC₂)/s where AUC₁ and AUC₂ are the original empirical estimates. The same bootstrap procedure was applied to the aloud-minus-silent AUC difference to compare the magnitude of the production effect across the three stimulation conditions.

Formal signal-detection models.

To complement the nonparametric ROC analysis, the confidence data were fitted using an unequal-variance signal-detection (UVSD) model (Egan, 1975; Green & Swets, 1966; Wixted, 2007). The UVSD model assumes that recognition decisions arise from continuous memory-strength distributions for studied and lure items, with the two distributions permitted to differ in variance. The model was fitted simultaneously to the observed response frequencies from all six stimulation × encoding conditions by minimising Pearson's chi-square goodness-of-fit statistic.

Absolute model fit was evaluated using Pearson's chi-square goodness-of-fit statistic.

The primary model-based analysis tested whether stimulation altered the production-related increase in discriminability, indexed in the UVSD model by da. The unconstrained model allowed the aloud-silent difference in da to vary across stimulation conditions. Two nested models were then fitted: one constrained the aloud-silent difference to be equal under cTBS and sham stimulation, and the other constrained it to be equal under iTBS and sham stimulation. Each constrained model was compared with the unconstrained model using a one-degree-of-freedom chi-square difference test.

Enhanced Memory for Aloud Relative to Silent Encoding Across Memory Measures

Our first hypothesis (H1) was that items produced aloud at encoding would be remembered better than items encoded silently, yielding higher recognition accuracy, faster responses to correctly recognized old items, higher confidence, and more frequent recollection of encoding-specific details for aloud items than silent items. To test this, performance was averaged across the three stimulation conditions and compared between encoding conditions. The old-word hit rate was higher for words read aloud (M = .75 proportion correct, SD =.13) than for words read silently (M = .58, SD =.14), t(39) = 9.68, p < .001, dz = 1.53. Speed-Accuracy Relationships

We next examined whether the observed accuracy effects could be explained by a speed-accuracy trade-off. None of the six correlations between hit rate and response time within individual stimulation × encoding conditions reached significance after Bonferroni correction (all adjusted ps ≥ .504; Table S1). We then correlated the magnitude of the accuracy production effect in accuracy (aloud -silent hit rate) with the magnitude of the response-time production effect (silent -aloud response time) within each stimulation condition. These two effects were positively associated following sham stimulation (r = .41, Bonferroni-adjusted p = .025) and iTBS (r = .46, Bonferroni-adjusted p = .009), but not following cTBS (r = .07, Bonferroni-adjusted p = 1.00). Spearman correlations produced the same pattern (Table S2). Larger accuracy benefits were associated with larger speed benefits, rather than costs, in two conditions (Figure 5), providing no evidence that effects of TMS on the production effect arose from a speed-accuracy tradeoff.

To determine whether TMS altered the magnitude of the production effect, we next compared the difference in AUC values (aloud minus silent) across stimulation conditions.

The production effect was smaller following cTBS (ΔAUC = .067) than following either sham stimulation (ΔAUC = .098) or iTBS (ΔAUC = .098). These results provide converging evidence that cTBS attenuated the magnitude of the production effect.

Signal Detection Model Fits

To complement the nonparametric ROC analyses, an unequal-variance signaldetection (UVSD) model was fitted to the confidence-based response data (Green & Swets, 1966; Egan, 1975; Wixted, 2007). Pearson's χ² goodness-of-fit test compared the observed and model-predicted response frequencies across confidence categories and the six stimulation × encoding conditions. This test indicated no significant lack of fit, χ²(6) = 2.22, p = .898, and the model-predicted curves closely followed the empirical ROC points (Figure 7).

To examine whether TMS altered the magnitude of the production effect, we fit a series of nested UVSD models in which the increase in discriminability associated with producing items aloud rather than silently (i.e., the production effect) was constrained to be identical across stimulation conditions. Because discriminability in the UVSD model is indexed by da, these constraints were imposed directly on the production-related change in da.

We first constrained the production effect to be equal between the cTBS and sham conditions. This constraint significantly worsened model fit, χ²(7) = 7.52, Δχ²(1) = 5.30, p = .021, indicating that the production effect differed reliably between these stimulation conditions. We next constrained the production effect to be equal between the iTBS and sham conditions. In contrast, this constraint did not significantly worsen model fit, χ²(7) = 2.28, Δχ²(1) = 0.06, p = .812, indicating that the production effect was statistically comparable under iTBS and sham stimulation. These model-based analyses thus closely mirrored the nonparametric ROC analyses: cTBS selectively attenuated the production effect relative to sham stimulation, while iTBS produced no detectable change in the magnitude of the production advantage relative to sham.

Discussion

The present study tested using transcranial magnetic stimulation (TMS) whether the dorsolateral prefrontal cortex (DLPFC) causally contributes to the production effect in recognition memory. Reading words aloud produced the expected advantage over silent reading: aloud items had higher hit rates, were recognised more rapidly and confidently, and were more often accompanied by reported recollection. Crucially, continuous theta-burst stimulation (cTBS) reduced the magnitude of the production effect relative to both sham and intermittent theta-burst stimulation (iTBS). Receiver-operating characteristic (ROC) and unequal-variance signal-detection (UVSD) analyses provided converging evidence for a smaller production advantage in aloud vs silent word discriminability following cTBS relative to sham stimulation. Finally, stimulation did not reliably alter responses to new words, and the accuracy effects were not accompanied by evidence of a speed-accuracy trade-off, arguing against a general shift in recognition responding or response strategy.

Taken together, these findings provide the first causal evidence that DLPFC-targeted stimulation can alter the relative memory advantage conferred by speaking. DLPFCsupported cognitive control may contribute to the production effect by shaping how production-related information is selected during encoding and used during recognition.

The overall advantage for aloud items across accuracy, response time, confidence, and reported recollection replicates previous findings (Kelly et al., 2022; MacLeod et al., 2010; Ozubko et al., 2012). The ROC analyses further showed that the area under the curve was greater for aloud than silent items in every stimulation condition, demonstrating a production advantage in recognition discriminability across response criteria. Distinctiveness provides a useful framework for interpreting this advantage: speaking generates auditory, articulatory, and somatosensory information that can help distinguish studied items from new items (Bailey et al., 2021; MacLeod et al., 2010; Saint-Aubin et al., 2021). The selective compression of this advantage by cTBS suggests a possible neural contribution to this process. DLPFC-supported control may help determine how production-related information becomes available and useful for remembering.

We therefore propose complementary roles of production and cognitive control in working toward an integrative account of the production effect: production supplies potentially distinctive information, while control helps prioritise and use that information.

During mixed-list encoding, participants must interpret each trial cue (e.g., word colour) and select the instructed reading mode (e.g., reading aloud vs silently). Aloud trials additionally require participants to prepare and execute a vocal response, check its accuracy, and process its auditory consequences. The DLPFC may maintain the current task rule and coordinate these operations, increasing the likelihood that production-related features are incorporated into the representation of the word (Badre & Nee, 2018; Friedman & Robbins, 2022; Miller & Cohen, 2001). Perturbing this contribution could make the resulting memories for aloud and silent items less differentiated. At recognition, DLPFC-supported control might instead, or additionally, help evaluate production-related features as evidence that an item was studied.

This interpretation also connects the present results to evidence that productionrelated processing begins before vocalisation. Preparing to read aloud elicits greater pupil dilation and larger cue-evoked P300 responses than preparing to read silently (Fawcett et al., 2026a (Fawcett et al., , 2026b;; Hassall et al., 2016). Moreover, preparing to produce a word can improve subsequent memory even when the anticipated signal to speak never occurs (Fawcett et al., 2026b). Preparation can therefore contribute to the memory benefit alongside the sensory and motor consequences of speaking. The present stimulation findings extend this evidence by implicating a neural system that could support the selection and coordination of productionrelated processing. While production supplies additional sensorimotor features, cognitive control may influence how strongly those features are selected, bound to the studied word, or used at recognition. The persistence of a production effect following cTBS is consistent with this integrated account. Sensorimotor information remained available, but its mnemonic influence may have been weakened when the DLPFC contribution was perturbed.

The ROC and UVSD findings help clarify the behavioural effect because hit rates alone can vary with response criterion (Brady et al., 2023; Hautus et al., 2021; Wixted, 2023. The reduced cTBS-sham difference in discriminability suggests that the primary accuracy result reflected a change in mnemonic sensitivity rather than simply a greater or lesser tendency to respond "old", although these model-based analyses were exploratory. The absence of reliable stimulation effects on new-word responses and the lack of a speedaccuracy trade-off further argue against a global change in response strategy or general slowing.

The predicted reduction in the production effect following cTBS was accompanied by no detectable enhancement following iTBS. Although cTBS and iTBS are commonly associated with decreased and increased motor-cortical excitability, respectively, these protocols do not guarantee opposing effects in the prefrontal cortex, as TBS responses vary substantially across individuals (Chung et al., 2019; Lowe & Hall, 2018; Suppa et al., 2016).

The iTBS result could reflect the lack of reliable physiological effect on DLPFC function, a physiological change without a corresponding behavioural benefit, or heterogeneous effects that were obscured at the group level. The current task's substantial memory and responseselection demands may also have resulted in relevant control processes being strongly recruited under sham stimulation, leaving limited scope for further enhancement under iTBS.

Several future research questions remain. While the present study provides causal evidence that the DLPFC contributes to the production effect, it remains to be established whether this contribution generalises to other populations, forms of production, or memory tests such as free recall. Additionally, behavioural measures alone cannot identify the exact operation affected by DLPFC stimulation. Candidate mechanisms include maintaining task rules, suppressing competing responses, selecting production-related features, binding those features to the word, and/or monitoring evidence at retrieval. The present pattern of results provides reason to predict potentially stronger DLPFC contributions at encoding: cTBS attenuated memory for studied items without affecting responses to new words, arguing against a nonspecific effect on recognition decisions or response criterion and suggesting that disruption may instead have altered processes involved in forming production-related memory traces. Future studies using temporally specific stimulation during encoding and retrieval could directly distinguish these possibilities. Combining TMS with pupillometry or EEG could also be used to determine whether DLPFC perturbation attenuates the preparatory signals previously associated with intended production, thereby providing converging evidence for an encoding stage contribution.

In sum, DLPFC-targeted cTBS reduced the recognition advantage for words read aloud, linking the production effect to neural processes implicated in cognitive control. The findings support the proposal that production supplies distinctive information whose mnemonic value depends partly on how that information is prioritised and used. While production may supply features that can distinguish an item in memory, cognitive control may help determine how strongly those features are selected, bound, or used during the memory episode. The present study identifies the DLPFC as one potential contributor to that interaction. Thus, the advantage of saying a word aloud is not simply a stronger trace left behind by speaking-it is a trace whose mnemonic consequences are partly shaped by prefrontal control.
