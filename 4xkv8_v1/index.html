How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Although interpersonal factors are implicated in theoretical models of non-suicidal self-injury (NSSI), little is known about how objective social context and subjective interpersonal experiences contribute to momentary NSSI urges and behaviors in clinical populations. The present study examined between-and within-person associations among several interpersonal processes (perceived rejection, perceived social support, social context, social context appraisals, loneliness) and NSSI urges and behavior in daily life. One-hundred-twenty-five treatment-seeking adolescents and adults with recent NSSI completed a 28-day Ecological Momentary Assessment (EMA) protocol with six daily surveys (15,098 assessments). Dynamic structural equation modeling examined between-and within-person contemporaneous and temporal associations. Higher perceived rejection at baseline predicted greater average NSSI urge intensity and NSSI behavior during the 28-day EMA period, whereas baseline perceived social support was unrelated to either outcome. Momentary objective social context (i.e., being alone versus with others) was not a robust predictor of NSSI urges or behavior in daily life. In contrast, more positive momentary appraisals of social contexts predicted prospective decreases in NSSI urge intensity across 2-hour intervals, while higher-than-usual momentary loneliness predicted within-person increases in both NSSI urge intensity and the likelihood of NSSI behavior. Fully prospective mediation analyses indicated that the temporal effects of loneliness and social context appraisals on NSSI behavior operated primarily through their effect on NSSI urges. Subjective interpersonal experiences, rather than objective social context, were consistently linked to short-term NSSI risk. Interventions targeting maladaptive social appraisals and loneliness, including just-in-time adaptive interventions, may help prevent NSSI urges and behavior in daily life.

Introduction

Non-suicidal self-injury (NSSI) involves intentionally inflicting physical tissue damage upon oneself in the absence of suicidal intent (International Society for the Study of Self-Injury, 2026; Nock & Favazza, 2009). NSSI is a pervasive behavior in clinical populations of adolescents and emerging adults, with past-month prevalence estimates ranging from 8.1% to 71.7%, depending on the level of care of the treatment setting (Christensen et al., 2021; Millon et al., 2024; Ose et al., 2021). NSSI is a predictor of future onset of mental disorders and suicide attempts, even above and beyond the presence of comorbid disorders (Franklin et al., 2017; Kiekens et al., 2018; Kiekens, Hasking, et al., 2023). Theoretical models posit that NSSI is triggered by both intrapersonal and interpersonal factors (Klonsky, 2009; Nock & Prinstein, 2004; Taylor et al., 2018). Interpersonal processes warrant particular attention because social functions of NSSI are endorsed by a substantial proportion of individuals who self-injury (Taylor et al., 2018) and because interpersonal experiences are modifiable targets in psychological treatment. While intrapersonal factors (e.g., negative emotions, stress, self-criticism) have been consistently identified as predictors of NSSI in daily life (Kuehn et al., 2022; Robillard et al., 2025), less is known about interpersonal processes and social context as real-time factors (Janssens et al., 2024).

Much of the literature on interpersonal processes and social context to date is hampered by: (1) cross-sectional designs to identify interpersonal correlates of NSSI engagement (e.g., Wang et al., 2022), (2) focus on NSSI behaviors but not on NSSI urges (e.g., Cipriano et al., 2017), even though urges are highly prevalent in clinical samples and are near-term risk factors for NSSI behavior (Kiekens et al., 2024; Turner et al., 2019; Washburn et al., 2010), and (3) the use of community samples (e.g., Gillies et al., 2018), whose findings may not generealize to treatmentseeking individuals with more frequent or severe NSSI.

In addition, most longitudinal studies investigate developmental patterns and distal factors that increase an individual's risk for the onset and persistence of NSSI (see Plener et al., 2015). This leaves substantial gaps in our understanding of real-time factors impacting NSSI in clinical samples.

Traditional research using cross-sectional and longitudinal methodology has added to our understanding of who is at risk for NSSI based on interpersonal processes across adolescence and adulthood, but not of when risk increases across hours and days within a person. For example, these studies have repeatedly found a positive association between perceived rejection, namely perceived familial rejection, and a history of NSSI (Cipriano et al., 2020; Cruz et al., 2014; Quirk et al., 2014), and a negative association between perceived social support and subsequent development of NSSI behavior (Hankin & Abela, 2011; Tatnell et al., 2014; Yang et al., 2023). Researchers have recommended that future studies investigating NSSI should also investigate sources of support (e.g., family, friends, significant others) in addition to composite scores (Turner et al., 2016).

However, whether perceived rejection and low social support also predict NSSI urges and behavior in the short term among individuals seeking treatment remains unclear, as daily life research has largely relied on community samples (Janssens et al., 2024). Interpersonal processes may also shape momentary social context: individuals who feel rejected may withdraw from others to avoid further rejection (Watson & Nesdale, 2012), and spending a significant proportion of time alone may perpetuate social challenges over time (Buchholz & Catton, 1999). Despite these theoretical connections, the relationship between time spent physically by oneself (i.e., aloneness) and NSSI urges and behaviors remains unexplored.

Ecological Momentary Assessment of Interpersonal Processes

Ecological momentary assessment (EMA), also known as experience sampling methodology (ESM), offers a powerful method for addressing these gaps (Myin-Germeys & Kuppens, 2026). By repeatedly capturing experiences in daily life, EMA reduces recall bias and allows researcher to separate between-person differences (i.e., who tends to experience more NSSI urges and behavior) from within-person fluctuations (i.e., when an individual's risk is elevated relative to their own typical level; Kiekens et al., 2021; Myin-Germeys & Kuppens, 2026). A recent review by Janssens and colleagues (2024) found a limited number of EMA studies examining the role of interpersonal mechanisms implicated in the manifestation of NSSI in real time, with no research done in clinical samples.

One psychosocial factor potentially relevant to NSSI is how individuals appraise their momentary social contextthat is, whether they like being alone or enjoy the company they are in (Moors et al., 2013). These appraisals are conceptually distinct from loneliness. Whereas aloneness refers to an objective social state, loneliness is the unpleasant subjective experience that one's social relationships or interactions are not meeting one's needs, and can therefore occur both when individuals are alone and when they are with others. Loneliness is thought to involve negative evaluations of the self, others, and the social environment (Buchholz & Catton, 1999; Cacioppo & Hawkley, 2005; Rodriguez et al., 2020). Despite their potential relevance, it remains unclear how appraisals of the momentary social context and feelings of loneliness are associated with NSSI urges and behavior in daily life among treatment-seeking individuals.

EMA studies have found that NSSI urges occur at about the same rate when physically alone compared to with others (Hepp et al., 2021; Nock et al., 2009; Victor et al., 2019), suggesting that objective social context alone may not differentiate moments of elevated urge intensity, although being with others may reduce the opportunity to act on urges (O'Loughlin et al., 2021).

Though there is no EMA research looking at aloneness or the appraisal of social contexts and NSSI to date, one EMA study found loneliness to be a short-term risk factor for self-harm thoughts irrespective of suicidal intent when controlling for aloneness (Janssens et al., 2026). As such, more EMA work looking at interpersonal factors that contemporaneously and temporally predict NSSI urges and behavior is necessary. Drawing from ideation-to-action theories of suicide which posit that factors preceding suicide urges may differ from those that precede suicidal behaviors (Klonsky & May, 2015; O'Connor & Kirtley, 2018; Van Orden et al., 2010), there may be utility in investigating if interpersonal factors precede NSSI urges versus NSSI behavior (Janssens et al., 2024). However, to date, little research exists investigating NSSI urge-to-behavior pathways (Victor et al., 2026), with few studies having focused on interpersonal factors especially in clinical samples (see Janssens et al., 2024 for an overview). As such, there is a need for comprehensive clinical EMA studies that consider contextual (e.g., objective social context), cognitive (e.g., appraisals of that context), and affective interpersonal processes (e.g., loneliness) when examining momentary risk for NSSI.

The Present Study

Using EMA in a treatment-seeking sample, the present study investigates the interconnected role of interpersonal processes (i.e., rejection, social support, appraisals of social context, feelings of loneliness) and examines how they may unfold in the manifestation of NSSI in daily life. By combining baseline measures of perceived rejection and social support with momentary assessments, this work bridges prior longitudinal and EMA research. Specifically, we examined whether: (1) higher perceived rejection and lower social support at baseline predict more intense NSSI urges and a higher likelihood of NSSI behavior across the EMA period, (2) the proportion of time spent alone or with others and the typical appraisal of these contexts are associated with average NSSI urge intensity and the likelihood of behavior, (3) momentary social context, its appraisal, loneliness and NSSI are correlated within the same assessment, (4) these momentary variables predict changes in NSSI urge intensity and likelihood of NSSI behavior two hours later, and (5) the effects of social context appraisal and loneliness on of NSSI behavior occur via changes in subsequent NSSI urge intensity.

We hypothesized that: (1) higher perceived rejection and lower social support at baseline would predict more intense NSSI urges and a higher likelihood of NSSI behavior across the EMA period, (2) patients who spend more time alone (and less time with others) and who appraise these contexts more negatively will report higher average NSSI urge intensity and likelihood of NSSI behavior, (3) being alone, more negative appraisals, and higher loneliness would be positively correlated with NSSI urges within the same assessment, (4) these momentary factors will prospectively predict increases in NSSI urge intensity and likelihood of NSSI behavior two hours later, and, (5) the effects of social context appraisals and loneliness on NSSI would be mediated via increased NSSI urge intensity.

Materials and Methods

Participants and Procedures

The objectives and research plan were postregistered on the Open Science Framework prior to analyses (https://osf.io/nxq6c/) using the ESM registration framework (Kirtley et al., 2021). Indepth procedures for this EMA project can be found in Kiekens and colleagues (2023). Individuals between the ages of 15 and 39 who were receiving mental health treatment in inpatient, outpatient or hybrid care settings were recruited for study participation. Prospective participants who were fluent in Dutch and reported NSSI urges or behavior in the past month were eligible for the study.

Participants underwent a baseline assessment which included self-report surveys and the Dutch version of the Structured Clinical Interview for DSM-5 (SCID-5; Arntz et al., 2018; First et al., 2016). They were then trained to complete EMA surveys via the smartphone app m-path (Mestdagh et al., 2023) and completed a 28-day EMA protocol that comprised six regular semi-random surveys sent between 10:00 a.m. and 9:00 p.m. each day at roughly two-hour intervals. Additional burst surveys, triggered by intense urges (Kiekens, Claes, et al., 2023), were not included in this study and were solely used to screen for NSSI behavior between regular surveys. Participants were required to begin completing EMA surveys within 15 minutes of being prompted and were given an additional reminder if they did not begin the survey within 10 minutes of the initial prompt.

Only responses completed within 45 minutes after initiation were deemed valid to avoid backfilling of responses. Participants were also able to record NSSI behavior without being prompted (i.e., event-contingent responses). Participants received €20 for a compliance rate of ≤ 33%, €35 for compliance 33% to 64.9%, €70 for compliance 65% to 82.9%, and €100 for compliance 83% or higher. Participants' clinicians were given personalized feedback reports from the EMA protocol to discuss relevant information with participants.

Between June 2021 and August 2023, 132 individuals participated in the study, 124 of whom completed the 28-day EMA period. One completer was excluded for insufficient EMA data, while two participants who discontinued the protocol were retained because they met the minimum EMA assessment threshold of 25 surveys or more, which was used as the inclusion threshold for the specification of random effects (Asparouhov & Muthén, 2024). This gave a final sample size of 125 participants (94.7%; Mage = 22.98, SD = 5.32) submitting an average of 121 surveys (SD = 34.5) per patient, resulting in a median compliance of 78.6% (IQR = 59.5% -88.7%). There were 25 surveys submitted after 45 minutes which were excluded, resulting in a total of 15,098 assessments for analysis across the 28-day EMA period.

Baseline Measures

Sociodemographic and Clinical Characteristics

Sociodemographic information including age, gender identity, education level, and sexual orientation was assessed at enrolment. Additionally, history of NSSI engagement (e.g., lifetime frequency, past year frequency, past month frequency, lifetime methods, age of onset, presence of NSSI disorder) was measured at baseline using a Dutch version of the Self-Injurious Thoughts and Behaviors Interview (SITBI; Kiekens et al., 2018; Nock et al., 2007). Mental health diagnoses were assessed at baseline using a Dutch version of the SCID-5 (Arntz et al., 2018; First et al., 2016).

High interrater-reliability coefficients for diagnoses were achieved among clinical psychologists using the SCID-5 (rates of agreement = 92 -100%; mean kappa = 0.96, range = 0.84 -1.00) in a 20% subsample (n = 25; see Kiekens et al., 2024).

Perceived Rejection

Perceived rejection in the past month was assessed at baseline using the Dutch version of the Perceived Rejection Scale of the Adult Toolbox Social Relationship Scales (PR; Cyranowski et al., 2013). The PR-scale contains eight items about how often one perceived those around them as being neglectful or insensitive within the past month (e.g., people in my life…act like they don't have time for me"), rated from 1 (never) to 5 (always; range: 8 -40; Cronbach's  = .89 in this sample).

Perceived Social Support

Perceived social support was assessed at baseline using the Dutch version of the 12-item Multidimensional Scale of Perceived Social Support (MSPSS; Pedersen et al., 2009; Zimet et al., 1988), comprising friends, parents, and significant-other subscales. Items were rated from 1 (very strongly disagree) to 7 (very strongly agree; total range: 12 -84; Cronbach's  = .90 total, .90 -.94 for subscales in this sample).

EMA Measures

Objective Social Context

Momentary social context was assessed by asking the question: "Are you alone or with others?". Responses included: (a) "alone"; (b) "others physically"; and (c) "others online".

Appraisal of Social Context

Participants then rated an appraisal item matched to their reported context: "I like being alone", "I enjoy the company of these people", or "I feel connected to those I am in contact with online". Response options for all prompts were measured on a seven-point scale ranging from 0 (not at all) to 6 (very much).

Loneliness

Momentary loneliness was assessed with the item: "Right now, I feel lonely" with responses measured on the same seven-point scale.

NSSI Urge Intensity and NSSI Behavior

Urge intensity was assessed with the item: "Right now, how strong is the present urge to hurt yourself without wanting to die?" rated from 0 (not at all) to 6 (very strong). NSSI behavior was assessed with a yes/no item ("Since the last beep, have you deliberately hurt yourself without wanting to die [for example, cut, scratched, or hit yourself]?"). Participants could also log NSSI behavior with using an event marker on their smartphone (available for 91.2% of participants).

Behavior was coded as present between consecutive surveys if it was recorded either way.

Statistical Analysis

Analyses were performed in Mplus 8.11. Regarding preliminary analyses, we reported descriptive statistics (e.g., proportions/means and standard deviations) for the baseline and EMA variables. For the continuous EMA variables, we examined total variance (variance estimated across time and across individuals), between-person variance, within-person variance, and intraclass correlations (ICCs). The main research objectives were addressed using Multilevel Vector Autoregressive (MVAR) models within a Dynamic Structural Equation Model (DSEM) framework (Asparouhov et al., 2017; McNeish & Hamaker, 2020).

The DSEM framework uses Bayesian estimation with non-informative priors based on Markov Chain Monte Carlo using Gibbs sampling. Unstandardized point estimates were obtained for the associations by taking each parameter's median of the posterior distribution. The presence of social context (e.g., being alone) and subsequent appraisal of that context was treated as a twostage process (Muthen et al., 2025; Olsen & Schafer, 2001). Appraisals, feelings of loneliness, and intensity of NSSI urges were predicted using Bayesian linear regression, whereas Bayesian probit regression was used for presence of social contexts and NSSI behavior. A two-hour transformed time interval was specified to account for unequally spaced intervals due to missing data and random sampling within blocks. Baseline variables (i.e., perceived rejection and social support) were grand-mean centered, whereas time-varying EMA variables were latent person-meancentered, indicating a participant's deviation from their own mean score while accounting for measurement error. All estimated models included autoregressive effects for independent and dependent variables and included random intercepts, treating the slopes of continuous variables as random when possible with an unrestricted covariance matrix. Residual variances of NSSI urges were allowed to be person-specific. Given a previously observed linear decline in reported NSSI behavior across the 28-days (Kiekens et al., 2024), NSSI behavior models included a linear trend.

A series of MVAR models were run to address the research questions. To examine research question 1, we investigated separated models to assess whether perceived rejection and low baseline perceived social support at baseline each predicted a higher mean intensity of NSSI urges and a higher likelihood of NSSI behavior. To explore differences between sources of social support (i.e., friends, parents, significant others), these DSEM models were repeated using the subscales for each support source instead of the composite social support scale. In these models, we allowed for a between-person association between NSSI urges and NSSI behavior.

To examine research questions 2 and 3, we used Residual DSEM to investigate both between-person associations across the 28-day EMA period and within-person contemporaneous associations. These models, as regular DSEM models, include autoregressive associations but model this through a lagged association between the residuals, allowing the estimation of unbiased contemporaneous associations (Asparouhov & Muthén, 2020). Because models including online contact did not converge due to the low frequency of this social context, we estimated models for being alone and for being with others physically (hereafter refered to as social contact). Estimates were standardized to obtain within-and between-person correlations between latent factors.

To examine research question 4 regarding temporal within-person associations, we ran two sets of three DSEM models -one for each social context (alone, social contact, online contact) -to evaluate whether specific contexts and appraisals predict changes in urge intensity and the likelihood of NSSI behavior within the subsequent two hours. For online contact, convergence required simplified models that were restricted to patients who reported online contact, with all latent variables treated as fixed. Finally, to address research question 5, we estimated three fully prospective within-subject mediation models (1-1-1) to examine whether momentary appraisal of a contextt-4h, and momentary lonelinesst-4h predict NSSI behaviort indirectly via NSSI urge intensityt-2h as an action tendency. Each model estimated both the indirect paths through urge intensity as well as the direct effects of social appraisalt-4h, and lonelinesst-4h on subsequent NSSI behaviort. To avoid downwardly biased estimates, prospective models included only participants showing within-person variation in the relevant outcome. Statistical significance was determined by estimating 95% credibility intervals (CrI), with effects considered to be non-null when the CrI did not include zero.

Discussion

The present study used EMA in a treatment-seeking sample to examine how interpersonal processes relate to NSSI in daily life. Four main findings stand out and warrant further discussion.

First, baseline perceived rejection predicted higher average NSSI urge intensity and NSSI behavior across 28 days of EMA monitoring. Second, across both between-and within-person levels, appraisals of social contexts, but not the objective social context itself, were consistently associated with NSSI, supporting subjective experiential conceptualizations of interpersonal risk (Achterhof et al., 2022). Third, positive appraisals of social contexts prospectively predicted decreases in NSSI urges. However, loneliness emerged as the most robust prospective predictor, uniquely predicting both increases in NSSI urge intensity and the likelihood of NSSI behavior. Finally, findings supported an ideation-to-action pathway in real time, in which interpersonal processes temporally predicted NSSI behavior indirectly through their effect on NSSI urge intensity. Together, these results suggest that NSSI risk is best understood by considering dynamic subjective interpersonal processes, where negative appraisals of social contexts and feelings of loneliness, rather than simply being alone are more closely linked to short-term NSSI risk and whereby NSSI urges act as a bridge between these interpersonal processes and NSSI behavior.

Consistent with our first hypothesis, higher baseline perceived rejection predicted greater average NSSI urge intensity and likelihood of NSSI behavior across the 28-day EMA period. This extends cross-sectional and longitudinal work linking perceived rejection to NSSI history and persistence (Cipriano et al., 2020; Cruz et al., 2014; Quirk et al., 2014) by showing that recent rejection also identifies treatment-seeking individuals at elevated risk of NSSI daily life, possibly by heightening sensitivity to social threat and promoting withdrawal (Cacioppo & Hawkley, 2005; Watson & Nesdale, 2012). In contrast, perceived social support was not associated with NSSI urges or behavior, either as a composite score or when separated by social support type, unlike in prior longitudinal work (Hankin & Abela, 2011; Tatnell et al., 2014; Yang et al., 2023). Rejection and support likely reflect distinct processes rather than opposite ends of the same interpersonal dimension: the counterpart of rejection may be closer to acceptance or belonging, whereas support concerns having people to turn to when things are hard. Support may therefore protect against NSSI onset and persistence over months or years without shapping short-term fluctuations in risk among patients already in treatment.

Our second and third hypotheses pertained to the role of the objective social context, appraisals of this context, loneliness, and NSSI risk. Overall, findings suggest that the objective social context (i.e., being alone, physically with others, or connected with others online) was not a robust predictor of NSSI outcomes. At the between-person level, the proportion of time patients spent alone or in social contact with others was not significantly associated with average loneliness, NSSI urge intensity, or likelihood of NSSI behavior. At the within-person level, being alone was contemporaneously associated with higher NSSI urge intensity while being with others was associated with lower urge intensity. These findings add to prior EMA work suggesting that NSSI urges can occur both when individuals are alone and when they are with others (Hepp et al., 2021; Nock et al., 2009). Importantly, however, appraisals of social context were more consistently linked to NSSI outcomes. Patients who generally appraised being alone more positively reported lower average loneliness and NSSI urge intensity. Similarly, those who generally appraised physical social contact more positively reported lower average loneliness, lower NSSI urge intensity, and reduced likelihood of NSSI behavior. Within individuals, moments with more positive appraisals of being alone or being with others were also associated with lower concurrent loneliness, lower NSSI urge intensity, and lower likelihood of NSSI behavior. These findings align with appraisal-based accounts of emotion, which emphasize that emotional responses arise not only from external situations themselves, but from individuals' interpretations of those situations (see Moors et al., 2013). In the context of NSSI, the subjective meaning of a social context may be more clinically relevant than the context itself. For example, being alone may feel restorative or isolative, and being with others may feel supportive or alienating.

Consistent with our fourth hypothesis, momentary appraisals of social contexts predicted changes in NSSI urge intensity over the following two hours, whereas the objective social context itself did not. Across all contexts, more positive appraisals were associated with subsequent reductions in urge intensity, suggesting that patients' interpretations of their social environment may be more important than the environment itself in shaping short-term NSSI risk. However, loneliness emerged as the most robust prospective predictor. Unlike appraisals, momentary loneliness predicted both increases in NSSI urge intensity and a greater likelihood of NSSI behavior over the subsequent two hours. This pattern suggests that although cognitive evaluations of social situations may influence the onset of urges, loneliness as an affective state may represent a more proximal affective interpersonal state that directly contributes to behavioral risk for NSSI. This represents an important future research direction.

Finally, with respect to the fifth hypothesis, the temporal findings were broadly consistent with an ideation-to-action pathway in which interpersonal experiences were associated with subsequent NSSI urges, which in turn predicted later NSSI behavior. However, the mediation patterns differed somewhat across different objective social contexts. During periods of being alone, both loneliness and appraisals of being alone influenced NSSI behavior indirectly through subsequent urge intensity, with no remaining direct effects. Similarly, during in-person social contact, loneliness, but not appraisals of the contact, predicted later NSSI four hours later indirectly through urges two hours later. Although caution is needed for the online contact, given the low endorsement of this context in our sample, feeling connected to others online remained directly associated with a lower likelihood of NSSI behavior even after accounting for urge intensity.

Notably, higher connectedness to others online was positively predictive of NSSI urge intensity two hours later, but negatively predictive of NSSI behavior four hours later. This finding may suggest that online social connectedness may confer additional protection against acting on NSSI urges beyond its influence on urge intensity alone. Although our item did not specify the type of online contact, research on social media similarly suggests that online engagement neither uniformly protective nor harmful with respect to NSSI (Nesi et al., 2021). As such future work should investigate both perceived connectedness in online contact as well as the content with which an individual is engaging.

The results of the present study hold several clinical implications worth mentioning. First, interventions focused solely on increasing social contact may be insufficient for reducing NSSI risk. Although social connection is often perceived as beneficial, present findings suggest that objective social context did not prospectively predict NSSI urges or behavior. Therefore, encouraging patients to spend less time alone or more time with others may not reduce risk unless the quality, meaning, and appraisal of those contexts are also addressed. Second, clinical work may benefit from targeting negative social appraisals in the therapeutic context. Cognitive and behavioral interventions could help patients identify patterns of negative interpretations, such as equating being alone with being rejected or outcast, and generate more flexible appraisals of ambiguous social situations via cognitive restructuring techniques (Hofmann et al., 2012).

Moreover, increasing social contact may provide opportunities to challenge negative social appraisals through real-world experiences that serve to foster more adaptive interpretations of being alone or interacting with others (Cacioppo & Hawkley, 2005; Masi et al., 2011).

Third, loneliness might be an important momentary treatment target, thus interventions may help patients recognize loneliness as an emotional state rather than evidence of being unwanted or fundamentally disconnected. Mindfulness and meaningful solitary activities may be useful for reducing the urgency associated with loneliness, even when immediate social contact is unavailable or unhelpful (Heath et al., 2016). Finally, because loneliness predicted NSSI behavior through urge intensity in real time, momentary loneliness may represent an important target for ecological momentary interventions. Rather than intervening only after NSSI urges have intensified, interventions could be designed to detect increases in loneliness and deliver support before urges escalate into self-injurious behavior. One promising approach is the use of just-in-time adaptive interventions (JITAIs), which involve the use of technology such as smartphones to monitor an individual's current state and deliver personalized, context-specific, real-time interventions in moments of need (Nahum-Shani et al., 2015). In addition to monitoring loneliness, future JITAIs may benefit from incorporating momentary appraisals of social contexts, as present findings suggest that changes in how individuals interpret being alone or interacting with others precede changes in NSSI urge intensity. Future work could investigate whether real-time changes in social context appraisals and loneliness can be used to identify optimal windows for delivering adaptive interventions aimed at preventing escalation of NSSI risk (Luijsmans et al., 2026).

Several limitations should be considered when interpreting these findings. First, the sample was recruited entirely from the Flanders region in Belgium, thereby limiting generalization of findings to more diverse populations. Second, appraisal items were worded differently for each social contact (e.g., liking being alone vs. enjoying others' company), so appraisal effects may not be directly comparable across contexts. Third, the broad age range of participants may have obscured developmental differences in social experiences, as adolescents and adults differ in the amount of time spent with parents, cohabitants, peers, romantic partners, and children. Fourth, EMA compliance may itself depend on social contact (e.g., patients may be less likely to respond when with others (e.g., patients may be less likely to respond or respond differently when with others; see Eisele et al., 2026), and online contact was rare, which limited power for the online contact models. Future research should work to replicate these findings in larger and more diverse clinical samples and examine whether trauma history influences momentary interpersonal processes and NSSI risk. Experimental studies that manipulate social appraisals could help establish causal mechanisms underlying the observed real-time associations. The present findings also provide a rationale for developing future JITAIs that use real-time changes in loneliness and social appraisals to deliver personalized interventions to prevent NSSI urges and behavior.

Conclusion

The present study is among the first EMA studies to examine interpersonal processes as real-time predictors of both NSSI urges and behaviors in a treatment-seeking sample. By assessing objective social context, subjective social appraisals, and loneliness at both the between-and within-person levels, the study provides a nuanced understanding of when and how interpersonal processes contribute to NSSI risk in daily life. Overall, interpersonal risk for NSSI is seemingly less dependent on whether individuals are objectively alone, but more so on how they experience and interpret their social contexts. Momentary loneliness was the only interpersonal lprocess that prospectively predicted both NSSI urges and behavior, and NSSI urges appeared to serve as a pathway through which interpersonal processes translated into behavioral risk.
