To check Non-Significant P Value Check

What we found

We found 8 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Ethics Approval Check works

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

Human research committee names - Institutional Review Board / IRB (US standard) - Independent Ethics Committee / IEC (ICH-GCP international clinical trial term) - Ethical/Ethics Review Board (generic) - Ethics (Advisory/Review) Committee/Board/Panel/Sub-committee - Research Ethics Committee/Board/Panel (UK/Canada/Australia) - Medical Ethics Committee - Human Subjects/Research Committee / Human Research Ethics (Advisory) Panel - Committee for/on the Protection of Human Subjects - Committee on (Health) Research Ethics - Office of Research Ethics - Abbreviations: IEC, REC, REB, ERB, METC, DEC. IRB and IEC are kept unconstrained as they are not observed to collide in practice. - Dutch: Medisch-ethische toetsingscommissie (METC) - French: Comité d'éthique / Comité d'Ethique

Animal research committee names - Institutional Animal Care and Use Committee / IACUC (US standard) - Any sentence containing animal(s) and committee (or board/panel) within ~5 words of each other — catches Experimental Animal Care and Use Committee, Animal Ethics Committee, Animal Welfare Board, Animal Welfare Ethical Review Body, etc. - UK: Animal Welfare Ethical Review Body / AWERB - Dutch: Dierexperimentencommissie / DEC (see DEC constraint above); Instantie voor Dierenwelzijn / IvD - German: Tierversuchskommission / TvK (advisory committee under §15 Tierschutzgesetz) - French: Comité d'éthique en expérimentation animale / CEEA; Comité d'éthique animale - Spanish: Comité de ética en experimentación animal / CEEA

Approval phrasing - Ethics/Ethical (approval|clearance) [was] (granted|obtained|received|given|secured) - Ethically approved - Approved by the (ethics|irb|institutional|independent|local|review|research) ... - This/The study/protocol/experiment/procedures/methods/research [was] (approved|reviewed) by - Study was ethically approved - (Followed|met|follow) the ethical (guidelines|standards|requirements) - In accordance with ... ethical (guidelines|standards) - Ethics protocol - Approved under (protocol|reference|number)

Waiver / exemption - Ethics/Ethical (waiver|exemption) - IRB (waiver|exemption|exempt) - Exempted from (ethics|irb|institutional review) - Waived by the (ethics|irb|institutional|review) (committee|board) - Deemed exempt

Declaration of Helsinki - Declaration of Helsinki / Helsinki Declaration

The helper uses conservative patterns to avoid flagging secondary data analyses, computational experiments, or economics papers that analyse existing survey data. See .detect_live_data() for the full list of patterns and intentional exclusions.

A paper that states that no human or animal subjects took part (“no human subjects were involved”, “did not involve human participants”, or people taking part “not as subjects”) is not expected to have an ethics statement, whatever participant phrase it also has (see .detect_no_participants()). A negation near a participant phrase alone (“No participants were excluded”) does not count: it reports a study with participants.

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Full text

Abstract

Misinformation on online platforms is of great concern for democracy, public health, and civic discourse. In fast-paced feeds, users often rely on heuristics when deciding what to attend to, believe, and share. One such heuristic is confidence, which, prior research shows, is treated as a cue of knowledge and credibility. Yet, we show that in over 4 million posts across seven social media platforms and one messaging app, confidence is negatively associated with information quality: posts written with greater confidence are more likely to link to lower-quality news domains and to contain false claims -even controlling for user baselines, toxicity, political lean, emotionality, and valence. Furthermore, we find that confident posts receive more engagement. Together, these results reveal a problematic asymmetry in online information environments: a widespread linguistic cue that is likely to be read as a signal of knowledge, and to attract engagement, is in fact associated with lower-quality information.

Introduction

The spread of misinformation on social media (1) has become one of the more salient concerns in the context of the functioning of democratic societies, the integrity of public health communication, and the epistemic foundations of civic discourse. It is not just what is reported but how it is written-and framed-that determines public uptake and belief (2). In fast-paced online environments, users are frequently exposed to news headlines, social commentary, and linked articles in rapid succession. Under such conditions, prior work suggests that users often rely on surface-level cues rather than deliberative processing to assess content credibility (3) (4) (5). These heuristics-including linguistic shortcuts that affect judgment-can be consequential. Indeed, growing evidence suggests that the stylistic features of how information is conveyed may be quite influential (6).

One important cue that has not been studied in misinformation contexts is confidence. When communicators convey a strong sense of conviction through their language, audiences infer greater credibility, expertise, and status, and become more receptive to their claims. Experiments indicate that people apply a confidence heuristic: more confident communicators are judged as more knowledgeable and their arguments more persuasive, even when objective knowledge is held constant (7). Laboratory and field evidence shows that confident wording increases perceived credibility and engagement (8, 9), while expressed confidence elevates perceived expertise/status, which in turn boosts influence and persuasive power (10). Confidence is therefore a cue that proxies for knowledge and competence. This makes it particularly relevant in information environments where the central question is whether a source is credible.

However, expressed confidence may not necessarily reflect genuine knowledge or conviction. For example, people use confident language to get attention, regardless of whether their claims are accurate (11). Further, when people feel doubtful, they often respond by advocating for their beliefs more forcefully by using strong, unequivocal language (12). In other words, confident expression may actually mark uncertainty rather than knowledge. This raises an ironic possibility for social media and misinformation: the very language that people use as a sign of knowledge may systematically signal lower knowledge and lower-quality, misinformative content (vs. higher-quality content). Moreover, confidently worded news posts might also attract greater engagement (8). If so, a cue people rely on to signal knowledge would instead amplify the information that deserves the least attention.

Despite this, to our knowledge, prior work has yet to examine whether expressed confidence is systematically associated with information quality. Therefore, in the present work we shed light on this question empirically. Specifically, we ask whether confident wording -the degree of conviction or certainty expressed through language -is associated with information quality. Using a dataset of over 4 million social-media posts linking to independently-rated news domains, we measure confidence using a validated linguistic measure (13) and news quality using a wisdom-of-experts rating aggregated across professional fact-checkers, journalists, and academics (14) as well as direct fact-checking using AI. Our models adjust for baseline writing style across users via user fixed effects. This allows us to compare higher-versus lower-confidence posts from the same user, accounting for individual differences in writing style and source-selection tendencies. We also account for political lean because both news quality and the use of confident language may vary systematically with the ideological orientation of the sources being shared. Beyond that, we control for a range of linguistic factors that could otherwise contribute to the association between confidence, quality, and engagement. Specifically, prior research finds toxicity to be associated with lower-quality information and higher engagement (15, 16), emotionality and valence to predict content virality and diffusion (17) (18) (19), including differences in the spread of true versus false information (20) as well as to help distinguish fake from real news (21), and post length to be associated with both information quality (22) and greater engagement on social media (23). This allows us to test whether confidence has an association with information quality and engagement over and above these related linguistic and content features. We additionally examine whether confident news posts also attract more engagement (diffusion). Prior work has established that confident language increases engagement in commercial and social contexts (8), and we test whether this pattern extends to news, and whether it replicates at scale across a diverse set of platforms.

Our core finding is that linguistic confidence is robustly and negatively associated with information quality. This association emerges across eight platforms, in both news headlines and user-generated language, across topical domains and over time, and after accounting for a range of linguistic and content factors. Moreover, when information quality is assessed directly at the level of individual posts, more confident language is associated with a greater likelihood of false or misleading claims. Confidence-a cue people often use as a signal of knowledge-is therefore, on average, associated with lower-quality and misleading information.

Results

Our data consist of 4,309,213 primary posts (excluding reshares and replies) containing links to one of 8,798 news domains, collected from X, LinkedIn, Gab, GETTR, Truth Social, Mastodon, Bluesky, and Telegram, primarily during January 2024 (see Methods for collection details and platform-specific exceptions). Each post is characterized by three main variables. News quality is the rating of the linked domain from a "wisdom of experts" aggregation of fact-checker, journalist, and academic assessments (14), normalized to a 0-1 scale on which higher values indicate higher-quality sources. Linguistic confidence is the score assigned to the post text by the Certainty Lexicon (13), ranging from 0 ("very uncertain") to 9 ("very certain"); we validated this measure against human judgments on a sample of our posts (SI). Political lean is the lean of the linked domain, rated from -5 (strongly left) to 5 (strongly right). In additional models we also control for language toxicity (percentile-transformed), emotionality and valence , and word count. We imputed missing values for control variables with mean value.

Linguistic Confidence and Information Quality

We began by analyzing the association between news quality and linguistic confidence across different platforms. To do so, we predict the quality of the news domain linked in each post (higher values indicate higher-quality sources) using the linguistic confidence of the post as the main predictor. We also include the political lean of the news source (higher values indicate more conservative) as a control variable. The primary analysis is an ordinary least squares regression predicting domain level quality using linguistic confidence. Differences across platforms are handled by estimating separate models for each platform. Standard errors are clustered on user to account for repeated observations from the same (in robustness analyses, we also user fixed effects). All variables are z-scored within the platform before estimation, so each coefficient represents the change in news quality, in standard deviations, associated with a one-standard-deviation increase in linguistic confidence within that platform. Following Mosleh et al., (2025), The platform-level coefficients and their standard errors are then combined in a random-effects meta-analysis (REML estimation, inverse-variance weighting) to obtain the overall estimate, its 95% confidence interval, and a test of heterogeneity across platforms. This approach allows every model parameter to be estimated separately for each platform, rather than constrained to be equal as in a single pooled model (which is important as platforms differ markedly in user populations, posting norms, affordances, moderation, and the distribution of news quality and political lean), while still yielding an overall estimate and an assessment of heterogeneity across platforms in the key estimand.

As hypothesized, across all platforms, we find that posts written with greater confidence link to lower quality news domains (b=-0.037, SE=0.009, z=-4.31, p<0.001 without controlling for political lean; b=-0.024, SE=0.005, z=-5.29, p<0.001 with controlling for political lean; Figure 1A). Because within-platform standardization could in principle compress differences between platforms, we re-estimated the same models on the unstandardized variables, so that the coefficient represents the change in news quality (on its 0-1 scale) per one-point increase in linguistic confidence (on its 0-9 scale). The results are qualitatively the same (b=-0.008, SE=0.002, z=-3.83, p<0.001 without controlling for political lean; b=-0.005, SE=0.001, z=-4.38, p<0.001 with controlling for political lean; Figure SI3c). The association is negative on every platform, though its magnitude varies. A random-effects meta-analysis indicates significant between-platform heterogeneity (Q(7) = 43.72, I² = 90.14%, τ² = 0.0005 without controlling for political lean and with standardizing within each platform). Much of this variation reflects differences in the political composition of the news shared on each platform: adjusting for political lean reduces the estimated between-platform variance by roughly 80% (τ² = 0.0005 without control versus 0.0001 with control). Consistent with this, political lean is positively associated with linguistic confidence (b = 0.027, SE = 0.002, t = 15.82, p < .001) and negatively associated with news quality (b = -0.419, SE = 0.009, t = -48.77, p < .001), even after accounting for other controls (Table SI3). Importantly, however, the negative association between linguistic confidence and news quality persists after adjusting for political lean, suggesting that the relationship is not simply an outcome of differences in the political orientation of the news being shared.

Next, as a complement to the meta-analytic approach, we pooled posts from all platforms into a single regression. Variables are z-scored on the pooled sample and standard errors are clustered by user. We found a similar significant negative relationship between news domain quality and the linguistic confidence of post (b = -0.054, SE = 0.003, t = -19.66, p < 0.001 without controls; b = -0.028, SE = 0.002, t = -14.41, p < 0.001 controlling for political lean; b = -0.030, SE = 0.002, t = -16.23, p < 0.001 controlling for political lean, emotionality, valence, language toxicity, and number of words). Adding platform fixed effects, so that the relationship is identified from within-platform variation only, leaves the pattern intact (b = -0.028, SE = 0.002, t = -15.45, p < 0.001 without controls; b = -0.018, SE = 0.002, t = -11.69, p < 0.001 controlling for political lean; b = -0.019, SE = 0.001, t = -13.24, p < 0.001 controlling for political lean, emotionality, valence, language toxicity, and number of words).

Additionally, in the analysis pooling posts from all platforms into a single regression, we account for variation in user-level baseline in addition to platform-level baseline in the usage of confident language by including user fixed effects. This model also shows a similar pattern (b = -0.007, SE = 0.001, t = -7.53, p < 0.001 without controls; b = -0.005, SE = 0.001, t = -6.22, p < 0.001 when controlling for political lean; b = -0.005, SE = 0.001, t = -6.12 with all controls; See Figure SI3a-c for individual platforms). Across all analytic approaches -cross-platform meta-analysis, pooled regression, and controls for political lean and other linguistic featuresthe relationship between linguistic confidence and lower news quality is consistent and robust. Crucially, this relationship holds even within users: the same individual, when posting with greater confidence, links to lower-quality news -ruling out the possibility that the pattern reflects robust between-user differences in baseline writing style or systematic preferences for particular news sources.

The Certainty Lexicon scores only the 4 million posts containing at least one confidence dictionary term that make up our primary sample; posts with news links that do not contain any confidence dictionary terms (typically short posts) are excluded from the main analyses by listwise deletion. To check that this exclusion does not drive our results, we re-estimated the pooled platform-fixed-effects models on all posts, assigning unscored posts the scale midpoint and adding a missing-score indicator (which absorbs the mean difference between scored and unscored posts, so the confidence slope does not depend on the fill-in value). The association between confidence and news quality was essentially unchanged: (without controls) b = -0.028, SE = 0.002, t=-15.45, p<0.001 with listwise deletion versus b = -0.023, SE = 0.001, t=-16.36 , p<0.001 with all posts retained; (with controls) b = -0.019, SE = 0.001, t=-13.25, p<0.001 versus b = -0.016, SE = 0.001, t=-13.3, p<0.001. Posts without confidence scores link to domains have similar average quality to posts with confidence scores (0.691 vs 0.684), indicating that omitted posts do not differ systematically in the quality of news they share.

Post-Level Validation of the Confidence-Quality Relationship

While widely used in prior work (26) (27) (28) (29), domain-level quality scores assign the same rating to all content originating from the same website. To assess the robustness of our results using a more granular, post-level measure, we annotated all posts using Gemini 3.1 Flash-Lite (see SI for prompt). We also validated the scoring by Gemini 3.1 Flash-Lite, replicating prior results (30), whereby Gemini 3.1 Flash-Lite agrees with professional fact-checkers as much or more than professional fact-checkers agree with each other (see SI for details). We conducted a logistic regression predicting whether the post includes misleading or false claims (coded 1 if the LLM rated the central claim False or Misleading, 0 if otherwise), with linguistic confidence z-scored and standard errors clustered by user, so odds ratios represent the change in the odds of a false or misleading claim per one-standard-deviation increase in confidence. Consistent with our analysis of domain-level quality rating, we find a significant relationship between linguistic confidence and post-level accuracy ratings: posts written with more confident language were more likely to contain false or misleading information (OR = 1.10, SE = 0.005, z=21.4, p<0.001 without controls and without user fixed-effect; OR=1.05, SE=0.003, z=18.4, p<0.001 without controls and with user fixed-effect; OR = 1.10, SE = 0.004, z = 24.9, p<0.001 with controls for political lean, emotionality, valence, language toxicity, and number of word and without user fixed-effect; and OR = 1.06, SE = 0.003, z = 21.0, p<0.001 with user fixed-effect and with controls). This confirms that the confidence-quality relationship reflects the actual informational content of individual posts, not merely the aggregate reputational score of the outlets they link to.

Confidence-Quality Relationship at the Platform Level

We further assess the relationship between the average linguistic confidence and the average quality of news shared across each of the eight platforms. When averaging these characteristics at the platform level (Figure 2), we observe a strong negative correlation: platforms with posts containing higher average linguistic confidence tend to also have posts containing links to lower-quality news sources (Pearson r across the eight platform means, n = 8; r=-0.877, p =.004). Additionally, we find a strong association between use of confident language and conservative political lean at the platform level (r=.913, p=0.002), justifying our use of political lean as a control.

Confidence-Quality Relationship Across Text Sources

Although all observations are from social-media posts, the textual source varies: some posts contain user-generated commentary attached to a news link, whereas others display only the headline text supplied by the news domain. These texts are produced under different norms-idiosyncratic social expression versus professionally edited headline copy-so the confidence-quality association documented in aggregate could differ across them (cf. 2). To assess generalizability, we next examine whether the confidence-quality relationship holds across different textual sources, and whether it extends beyond outlet-level strategy to users' own expressive behavior, by focusing on a subset of N=41,040 unique headlines for which we extracted just the news headline (see Methods). We use linear regression to predict news domain information quality from linguistic confidence of news headlines with cluster standard errors on news domain. Consistent with our findings above, we find headlines written with greater linguistic confidence come from lower-quality domains (b = -0.103, SE = 0.026, t = -3.92, p < 0.001 without controls; b = -0.060, SE = 0.012, t = -5.17, p < 0.001 when controlling for political lean, emotionality, toxicity, valence, and number of words) (Fig 1C). Furthermore, we examine whether the relationship between confidence and content quality is confined to headline text-where it could be interpreted as a deliberate attention-grabbing tactic by low-quality news outlets-or whether it also extends to user-generated content. To do so, for posts where we also obtained the headline text, we calculated the cosine similarity between the post text and the headline text (we did so to account for the platform affordances i.e., the post text and headline text may not exactly match due to variance from extra characters). We find a significant relationship between confidence and content quality for cases where the post content and headline are not similar, suggesting that this relationship extends to user generated content as well (b = -0.040, SE = 0.002, t = -19.6, p < 0.001 where post and headline text cosine similarity <.9; b = -0.007, SE = 0.001, t = -7.27, p < 0.001 where post and headline text cosine similarity <.9 with user fixed-effect; b = -0.028 SE = 0.002, t = -11.4, p < 0.001 where post and headline text cosine similarity <.5; b = -0.005 SE = 0.001, t = -4.15, p < 0.001 where post and headline text cosine similarity <.5 with user fixed-effects; pooled OLS with platform fixed effects, user-clustered standard errors, on the subset of posts meeting each threshold). So, we find that the confidence-quality relation is predicted by linguistic confidence and is not simply an outcome of low-quality news outlets using confidence as a strategy to gain attention. When we look at user generated content in the posts, the same negative association holds. These results confirm that the confidence-quality relationship reflects two routes: not only the choices of low-quality news outlets, but also the spontaneous linguistic behavior of users amplifying that content.

Confidence-Quality Relationship across Political Leanings

We next examined whether the relationship between linguistic confidence and information quality holds across the political spectrum. Whereas our primary analyses control for political lean, here we stratified posts into left-leaning (lean = -5 to -2), center (lean = -1 to 1), and right-leaning (lean = 2 to 5) groups based on the political lean of the shared news domain. We estimated a single linear regression predicting information quality from linguistic confidence interacted with group indicators, controlling for platform (i.e., using platform fixed effects), with standard errors clustered by user. Confidence was negatively associated with information quality within all three groups, both when controlling only for platform (left: b = -0.010, SE = 0.002, t = -5.92, p < .001; center: b = -0.010, SE = 0.002, t = -6.14, p < .001; right: b = -0.040, SE = 0.004, t = -9.14, p < .001) and when additionally controlling for toxicity, valence, emotionality, and post length (left: b = -0.010, SE = 0.002 , t = -6.1, p < .001; center: b = -0.009, SE = 0.002, t = -6.1, p < .001; right: b = -0.04, SE = 0.004, t = -9.25, p < .001; Fig. SI6; Fig SI7). Pairwise comparisons of the group-specific slopes showed no difference between the left-leaning and center groups (platform control only: Δb = 0.000, SE = 0.002, t = -0.20, p = .844; full controls: Δb = -0.001, SE = 0.002, t = -0.30, p = 0.766). The negative association was, however, significantly stronger for right-leaning posts than for left-leaning posts (platform control only: Δb = -0.030, SE = 0.005, t = -6.38, p < .001; full controls: Δb = -0.030, SE = 0.005, t = -6.43, p < .001) or center posts (platform only: Δb = -0.031, SE = 0.005, t = -6.61, p < .001; full controls: Δb = -0.031, SE = 0.005, t = -6.71, p < .001). In sum, the negative confidence-quality association holds across the political spectrum, but is strongest among right-leaning content, indicating the strength of the association varies across the political spectrum, but political lean does not explain the main result.

We further examined whether the negative association between linguistic confidence and information quality was consistent across time and topics. The association was robustly negative across the study period and remained significantly negative after accounting for day and platform fixed effects, both with and without additional linguistic controls (Fig. SI8). Similarly, the association was significantly negative across all four topical domains examined (politics, economy, health, and science), as well as posts outside these categories, both with and without controls (Fig. SI9). Full methodological details and results are reported in the SI. Together, these findings provide further evidence of the robustness of the negative confidence-quality relationship across time and topical domains.

Linguistic Confidence and Engagement

Having established a robust negative association between confidence and information quality, we next examine whether confident posts also attract greater engagement -the number of likes and reshares (diffusion). To do this, we meta-analyze the results of separate linear regressions estimated for each platform, predicting engagement with posts (engagement counts are log-transformed to correct for skewness-log₁₀(likes + reshares + 1), likes only on Telegram -and variables are z-scored within platform). Following (24), each model includes user fixed effects because of obvious user-level confounds when predicting engagement, such as number of followers, user position in the network, level of engagement of their followers, posting frequency, etc. In other words, we test whether the same user tends to receive more engagement when posting with higher versus lower linguistic confidence. Consequently, any observed relationships cannot be attributed to differences in users or in their audiences. The pattern of results suggests that overall a given user's posts with higher linguistic confidence receive significantly more engagement than their posts with lower linguistic confidence (b=0.011, SE=0.002, z=4.28, p<0.001 without controlling for political lean; b=0.011, SE=0.003, z=4.17, p<0.001; Figure 3A).

Next, as a complement to the meta-analytic approach, we pooled posts from all platforms into a single regression. In these models all variables are z-scored on the pooled sample, user and platform fixed effects are included, and standard errors are clustered by user. We again find a significant positive relationship between linguistic confidence and engagement (log₁₀-transformed likes plus reshares; b = 0.010, SE = 0.0005, t = 18.80, p < 0.001 without controlling for political lean; b = 0.010, SE = 0.001, t = 18.74, p < 0.001 controlling for political lean). The results are qualitatively unchanged when we model raw engagement counts with a fixed-effects negative binomial regression rather than a linear model of logged engagement (b = 0.042, SE = 0.003, z = 15.52, p < 0.001 without controlling for political lean; b = 0.042, SE = 0.003, z = 15.51, p < 0.001 controlling for political lean; coefficients on the log-count scale, approximately the proportional change in expected engagement per SD increase in confidence)), and when we use a logistic regression with platforms fixed-effects predicting whether a post receives any engagement at all (OR = 1.03, SE = 0.002, z = 13.25, p < 0.001 without controlling for political lean; OR = 1.03, SE = 0.002, z = 13.3, p < 0.001 controlling for political lean). The same pattern holds when likes and reshares are analyzed separately as log-transformed outcomes (likes: b = 0.009, SE = 0.0005, t = 16.87, p < 0.001; reshares: b = 0.011, SE = 0.0006, t = 18.56, p < 0.001). Finally, because some news domains are simply more popular than others, differences in baseline domain popularity could in principle account for the engagement effect. The relationship is robust to this concern: adding news-domain fixed effects alongside the user and platform fixed effects yields a near-identical estimate (b = 0.010, SE = 0.0005, t = 19.84, p < 0.001).

Finally, our results are robust to also including other features that could be associated with both engagement and linguistic confidence, including toxicity (15, 16), emotionality and valence (17) (18) (19) (20) (21), and word count (22) (23). In a single model including all predictors (user and platform fixed effects, standard errors clustered by user), linguistic confidence remained significantly associated with engagement (b = 0.010, SE = 0.001, t = 19.72, p < 0.001), as did (low) news quality (b = 0.015, SE = 0.001, t = 13.6, p < 0.001), toxicity (b = 0.011, SE = 0.001, t = 11.9, p < 0.001), emotionality (b = 0.002, SE = 0.0004, t = 4.87, p < 0.001), and log-transformed word count (b = 0.055, SE = 0.002, t = 35.2, p < 0.001). Negative valence was positively associated with engagement when entered on its own (b = 0.002, SE = 0.0004, t = 6.06, p < 0.001) but not once the other predictors were included (b = 0.0002, SE = 0.0004, t = 0.50, p = 0.62). Figure 3B shows the coefficients from the separate models (one predictor each) alongside the combined model; the confidence estimate is essentially identical in the two (b = 0.010 in both, t = 18.8 when entered alone).

Discussion

This paper examines how confidence operates within online information sharing environments and documents a systematic and consequential pattern in real-world platform discourse. Across seven social media platforms and one messaging app -differing in content types, recommendation algorithms, content moderation policies, and user populations -and over 4 million posts, we find that linguistic confidence is robustly and negatively associated with news quality. This relationship holds even after accounting for user baselines, political lean, toxicity, emotionality, and other linguistic features. Importantly, this pattern also emerges when information quality is assessed at the level of individual posts: posts expressed with greater linguistic confidence are more likely to contain false or misleading claims as well. The pattern is also evident at the platform level, such that platforms characterized by greater average linguistic confidence are those in which users share lower-quality news on average. The core implication is that confidence -a cue people are most naturally inclined to treat as a marker of knowledge and credibility -is, on average, associated with lower-quality rather than higher-quality content online. Compounding this, we also find that confident posts receive more engagement, extending prior work to the domain of news. This suggests that platform dynamics reward a cue that, on average, points in the wrong direction about informational value.

Two additional findings hone the contribution. First, the confidence-quality relationship holds after controlling for other linguistic dimensions that prior work has linked to engagement and information sharing, like emotionality, valence, word count, and toxicity. This establishes that confidence is not simply a proxy for these other features. Second, the relationship is not merely a result of low-quality news outlets writing confident headlines as an attention-grabbing strategy. When we isolate user-generated content, the same negative association holds as when we examine headlines, suggesting that users' own expressive confidence plays an independent role in coupling confident language with low-quality information. Together, these results indicate that the confidence-quality mismatch operates through at least two routes: the editorial choices of low-quality outlets, and the spontaneous linguistic behavior of the users who amplify their content.

The relationship also exhibits substantial generality. The negative association between linguistic confidence and news quality was consistently observed across political leanings (although, it was stronger for right-leaning news sources), throughout the study period (rather than being concentrated around particular days), and emerged across science, politics, health, and economic news topics. Thus, the confidence-quality relationship appears to characterize a general feature of news on social media rather than one tied to a political lean, a particular topical domain or moment in time.

Substantively, the results help reconcile how confident language is more likely to "win the feed" despite the lower quality of information conveyed. Those pathways are desirable from the standpoint of persuasion and attention, but they also decouple confidence from actual quality of information. In modern social media feeds, confidence is not simply a marker of persuasive skill; it is more likely to accompany lower-quality information that is nonetheless rewarded by engagement-sensitive ranking systems. This reframing shifts the conversation from whether confidence persuades (it does) to what confidence is associated with in terms of content quality (in these data, lower quality on average).

We show that confident language-which has been shown to be more persuasivepersuades-is systematically associated with lower-quality news sources and with higher engagement. By examining the association with quality separately from the association with engagement, our results clarify why confident, low-quality content is more likely to spreads: the same confidence cue that signals authority to readers is, on average, associated with lower informational value, and engagement-sensitive systems reward it. Theoretical accounts of misinformation therefore need to incorporate confidence not merely as a driver of persuasion, but as a cue whose perceived meaning and empirical correlates diverge in information ecosystems.

Practically, the findings point beyond generic tone moderation. If confidence is negatively associated with quality at scale, then interventions should focus on quality-aware ranking, transparency of source credibility, and context at the point of sharing. In sum, our findings position confidence as a distinct construct in the psychology of misinformation-one that is persuasively potent yet negatively associated with information quality at scale. By examining quality and engagement separately, we show that the same cue is associated both with greater engagement and with lower informational value, offering a principled constraint for theories of persuasion and social transmission. We hope this decoupling framework invites work that builds theory forward-linking confidence to belief revision, memory, and networked influence-so models of communication account not only for whether messages persuade, but how their style relates to truth.

Methods

We leveraged a dataset of social media posts containing links to news domains shared on seven social media platforms and one messaging app (24): X (Twitter), LinkedIn, Gab, GETTR, Truth Social, Mastodon, Bluesky, and Telegram. For X, by far the largest platform, we analyzed posts from 1 January to 31 January 2024. For the seven smaller platforms we included all posts available at the time of data collection regardless of posting date, to maximize statistical power. Our results are qualitatively unchanged when every platform is restricted to January 2024 (Figure SI3b) . To ensure comparability across platforms, the selection of posts focused on those that (i) permit collection of individual-level posting data and (ii) allow users to share external links, which serve as our indicators of high-and low-quality content. These criteria enabled consistent operationalization across platforms but excluded major image-and video-based sites such as YouTube, TikTok, and Instagram and also Facebook, where individual-level posting data are unavailable. For X, LinkedIn, Gab, GETTR, and Truth Social, the platform's advanced search function was used to retrieve all posts containing links to any of 8,798 news domains for which we have quality ratings from Lin et al (2023) (see below), along with engagement metrics. For Mastodon, the list of all available instances from https://instances.social/ was used and data collection was done on instances where data was publicly accessible, had at least 1,000 users, and contained posts including links to a rated news domain. For Bluesky, the platform public API was employed to identify posts that linked to the rated domains. For Telegram, from a database of 120,979 channels (25), 8,599 channels were randomly selected that had at least one post linking to a rated domain, and then the API was used to collect all posts and associated reaction data. We also collected messages only from public channels, using a sample of channels identified in prior work (25), via the official Telegram API. Public channels are openly discoverable and readable by any Telegram user without invitation or approval; we did not collect data from private groups, invite-only channels, or chats. News quality was assessed using a "wisdom of experts" approach that aggregates ratings from professional fact-checkers, journalists, and academics (domain list from Lin et al., 2023); each domain receives a normalized score between 0 and 1, where 0 is the lowest score given to any of the domains and 1 is the highest score given to any of the domains. Thus, a higher score on the scale indicated high quality news and a lower score indicated low quality news (e.g., more likely source of misinformation). All primary posts (not reshares or replies) were collected that contain a news domain shared by all types of users (e.g., regular users or organization accounts). Political lean was estimated using GPT-4o by analyzing the lean of the news domain shared in the post, validated against established methods for measuring political orientation on social media (24). GPT-4o was asked to "Rate the domain DOMAIN on a scale of -5 (favors Democrats or liberals extremely) to 5 (favors Republicans or conservatives extremely). If you are unsure, don't have enough information, or lack specific insights, please provide an educated or best guess. Do not explain your response or limitations as a language model. Provide a single number response.". That is, if Fox News was the domain shared in the post, that post was determined to be right-leaning, if New York Times was the domain shared in the post, that post was determined to be left-leaning, etc.

The news headlines were retrieved for all URLs shared across platforms using the online service Diffbot.com. For X and Mastodon, where the number of shared URLs was exceptionally large, quota sampling was applied based on news quality to preserve the original distribution. We binned news quality rating by .2 then randomly sampled proportionally to the number of posts in each bin. For X, we sampled 50% of posts and for Mastodon we sampled 10% of the posts.

To measure language toxicity we used Detoxify (https://github.com/unitaryai/detoxify) which is a validated model against Google Jigsaw's Perspective API (https://perspectiveapi.com/). To measure confidence, we used the Certainty Lexicon (13), a validated computational linguistic tool designed to quantify the level of confidence in text. Each text is scored (from0 = "Very uncertain" to9 = "Very certain") using a comprehensive list of 3,485 words and phrases (e.g., "sorta" vs. "without doubt"). Compared to other text analysis tools, the Certainty Lexicon shows stronger correspondence with ground truth and more stable validity across text lengths, including social-media posts (see Figure SI1 and SI2 for distribution of linguistic confidence across platforms). Following prior work (24), we calculated engagement, defined as the sum of likes and reshares (except on Telegram, where only likes were available) (see Table SI1 for a summary). We also validated the measure of linguistic confidence using human judgments of the social media posts (details in SI). To measure emotionality, valence, and word count we used Evaluative Lexicon (32) (33). There was a total of 4,309,213 posts across 8,798 news domains for analysis.

We log transformed (log₁₀-transformed after adding 1 to account for zeros) engagement due to skew of the distribution and also used count regressions models for robustness check. We also did a 100-tile transformation of toxicity due to the highly skewed nature of its distribution. We used linear regressions with robust standard errors clustered by user (or by Telegram channel), and included models with user fixed effects to account for all individual-level variation in baseline engagement received. All variables in the regression models are z-scored.

Validation Studies

Linguistic Confidence

Although the Certainty Lexicon has been validated across contexts previously (Rocklage et al., 2023), we conducted a validation study to test whether Certainty Lexicon scores correspond to human judgments of certainty in the current context specifically. This study's methods, analyses, and criteria for success were preregistered (https://researchbox.org/10953%20(CODE:%20KFRAJN)

Method

To provide a range of scores, the validation set consisted of a stratified random sample of 90 posts: 30 posts from each of low, medium, and high Certainty Lexicon score percentiles (bottom 10%, 45-55%, and top 10%, respectively). To ensure representation across platforms, each certainty level included at least one post from each platform, with the remaining posts allocated in proportion to each platform's prevalence in the full dataset.

We aimed to recruit 200 participants, and a total of 198 participants provided complete data. Each participant rated five randomly selected posts. For each post, participants rated how much certainty or uncertainty it expressed (0 = very uncertain,9 = very certain). The primary measure was the average human certainty rating for each post.

Consistent with our preregistered exclusion rule, participants who provided the same rating to all five posts they evaluated were excluded from the primary analysis. Five participants met this criterion, leaving 193 participants.

The preregistered primary analysis calculated the correlation between Certainty Lexicon scores and average human certainty ratings across the 90 posts. We also preregistered that the validation would be considered successful if this correlation was positive and statistically significant (two-sided p < .05). With 90 posts, the study had 80% power to detect a correlation of approximately r = .29 or larger.

Results

As predicted, Certainty Lexicon scores were positively associated with average human certainty ratings (r = .50, 95% CI [.33, .64], p < .001) 1 . Thus, posts that received higher Certainty Lexicon scores were also perceived as expressing significantly greater certainty by human judges, meeting the preregistered criterion for successful validation.

Robustness to Alternative Measures of Linguistic Confidence

The primary analyses measure linguistic confidence using the Certainty Lexicon. To assess whether the confidence-quality relationship depends on this particular linguistic measure, we repeated the focal analyses using three conceptually related categories from LIWC: certitude, tentative, and all-or-none (Boyd, Ashokkumar, & Pennebaker, 2022). Certitude and all-or-none measure forms of more certain language, whereas tentative captures uncertainty and should therefore show relationships in the opposite direction. We otherwise followed the same analytic approach as in the primary analyses: all variables in the regression models were z-scored, standard errors were clustered by user, and, where applicable, platform-specific estimates were meta-analyzed across the eight platforms.

Confidence and News Quality

We first examined the relationship between these alternative measures and news quality. Consistent with the primary results, across platforms posts containing greater certitude were associated with lower-quality news (b = -0.0172, SE = 0.0046, z = -3.75, p < .001), as were posts containing greater all-or-none language (b = -0.0217, SE = 0.0059, z = -3.70, p < .001). As expected, the relationship was the opposite for tentative language: posts containing more tentative language were associated with higher-quality news (b = 0.0258, SE = 0.0087, z = 2.96, p = .003). When controlling for political lean, the relationships remained significant for certitude (b = -0.0141, SE = 0.0039, z = -3.59, p < .001) and all-or-none language (b = -0.0217, SE = 0.0069, z = -3.16, p = .002). The relationship for tentative language was also significant in the cross-platform meta-analysis when controlling for political lean (b = 0.0179, SE = 0.0089, z = 2.01, p = .044).

Next, we aggregated data from all platforms and found the same pattern. Greater certitude was associated with lower news quality (b = -0.0207, SE = 0.0012, t = -17.52, p < .001), as was greater all-or-none language (b = -0.0399, SE = 0.0022, t = -17.86, p < .001), whereas greater tentative language was associated with higher news quality (b = 0.0255, SE = 0.0015, t = 16.50, p < .001). These relationships remained significant when controlling for political lean (certitude: b = -0.0205, SE = 0.0009, t = -21.74, p < .001; all-or-none: b = -0.0330, SE = 0.0015, t = -21.99, p < .001; tentative: b = 0.0094, SE = 0.0013, t = 7.49, p < .001).

We further tested whether these relationships could be accounted for by other linguistic and content features. Consistent with the primary analyses, we simultaneously controlled for political lean, emotionality, valence, language toxicity, and number of words. The same pattern emerged: greater certitude (b = -0.0135, SE = 0.0013, t = -10.64, p < .001) and all-or-none language (b = -0.0213, SE = 0.0021, t = -9.97, p < .001) continued to predict lower news quality, whereas greater tentative language predicted higher news quality (b = 0.0196, SE = 0.0017, t = 11.45, p < .001).

Accounting for variation in user-level baseline news quality using user fixed effects showed a similar pattern. The same individual, when using greater certitude, was more likely to link to lower-quality news (b = -0.0066, SE = 0.0004, t = -14.86, p < .001), as was the case when using greater all-or-none language (b = -0.0076, SE = 0.0006, t = -13.32, p < .001). Conversely, the same individual was more likely to link to higher-quality news when using more tentative language (b = 0.0025, SE = 0.0005, t = 5.35, p < .001). Results were similar when controlling for political lean (certitude: b = -0.0064, SE = 0.0004, t = -15.28, p < .001; all-or-none: b = -0.0074, SE = 0.0005, t = -13.61, p < .001; tentative: b = 0.0018, SE = 0.0004, t = 4.08, p < .001).

Finally, we included user fixed effects while simultaneously controlling for political lean, emotionality, valence, language toxicity, and number of words. Greater certitude continued to significantly predict lower news quality (b = -0.0069, SE = 0.0007, t = -9.73, p < .001), as did greater all-or-none language (b = -0.0103, SE = 0.0009, t = -11.14, p < .001). Tentative language remained in the expected opposite direction, although the relationship was no longer significant in this most stringent specification (b = 0.0013, SE = 0.0008, t = 1.56, p = .119).

Confidence and Engagement

We additionally examined whether the relationship between linguistic confidence and engagement generalized to these LIWC measures. As in the primary analyses, these models included user fixed effects so that we test whether the same user tends to receive more engagement when using more versus less confident language. In the pooled analysis, greater all-or-none language predicted greater engagement (b = 0.0058, SE = 0.0007, t = 8.82, p < .001), while greater tentative language predicted less engagement (b = -0.0080, SE = 0.0005, t = -17.31, p < .001). Certitude was positively but not significantly associated with engagement in this specification (b = 0.0005, SE = 0.0008, t = 0.68, p = .495). Controlling for political lean produced virtually identical results (certitude: b = 0.0005, SE = 0.0008, t = 0.68, p = .495; tentative: b = -0.0080, SE = 0.0005, t = -17.33, p < .001; all-or-none: b = 0.0058, SE = 0.0007, t = 8.86, p < .001).

The cross-platform meta-analysis showed a similar pattern. Greater all-or-none language was significantly associated with greater engagement (b = 0.0061, SE = 0.0016, z = 3.72, p < .001). Greater tentative language was significantly associated with less engagement (b = -0.0084, SE = 0.0029, z = -2.91, p = .004), whereas certitude was not associated with engagement (b = -0.0004, SE = 0.0009, z = -0.40, p = .689). These results were similar when controlling for political lean (certitude: b = -0.0005, SE = 0.0009, z = -0.54, p = .586; tentative: b = -0.0084, SE = 0.0029, z = -2.89, p = .004; all-or-none: b = 0.0060, SE = 0.0016, z = 3.66, p < .001).

Finally, we examined the fuller engagement specification controlling for news quality, language toxicity, emotionality, valence, and number of words. In these models, greater certitude significantly predicted greater engagement (b = 0.0016, SE = 0.0006, t = 2.65, p = .008), while greater tentative language significantly predicted less engagement (b = -0.0104, SE = 0.0007, t = -15.40, p < .001). Greater all-or-none language remained positively and significantly associated with engagement (b = 0.0056, SE = 0.0007, t = 7.73, p < .001). Including political lean in addition to these controls produced essentially identical results (certitude: b = 0.0016, SE = 0.0006, t = 2.65, p = .008; tentative: b = -0.0104, SE = 0.0007, t = -15.55, p < .001; all-or-none: b = 0.0055, SE = 0.0007, t = 7.76, p < .001).

Discussion

Taken together, the LIWC measures provide converging evidence for the relationship between linguistic confidence and information quality. The confidence-quality relationship is particularly consistent: across all three LIWC measures, more certain and less tentative language is associated with lower-quality news, including after accounting for political lean and other linguistic features and, for certitude and all-or-none, in the most stringent within-user specification. The engagement relationship also generalizes across multiple alternative measures, although the pattern is less uniform across specifications than the relationship with news quality.

Information Quality

In this pre-registered study, we validate the information quality scoring generated by two LLMs, GPT-4o and LLM Gemini 3.1 Flash-Lite (without websearch), using two independent professional fact-checkers from Upwork. Following prior work (30), we compare agreement between the human fact-checkers with average agreement between the LLM and each of the human fact-checkers. Each fact-checker completed the task independently and was compensated through the platform. The stimulus set consisted of 60 social media posts drawn from the corpus used in the main analyses. Posts were selected on the basis of GPT-4o's classification, yielding three sets of 20 posts each: posts GPT-4o classified as false (mean LLM composite score = 1.00 on a 1-7 scale, where higher values indicate higher information quality), true (M = 6.88), and unsure (M = 4.12). The posts originated from eight platforms (Telegram, n = 30; X, n = 11; Mastodon, n = 5; Bluesky, n = 4; Gab, n = 3; Truth Social, n = 3; LinkedIn, n = 2; Gettr, n = 2) and ranged from 58 to 1,945 characters in length. The fact-checkers were not informed of the GPT-4o's ratings or of how the stimulus set was composed. For each post, the fact-checkers and the LLMs answered the same questions, using the same response options and rating scales. After providing informed consent, fact-checkers were told that they would see a series of short social media posts, one at a time, and were asked to read each post carefully, to answer a few questions about how true, accurate, and trustworthy they thought it was, and to judge each post on its own. The 60 posts were then presented one at a time in an order randomized separately for each fact-checker. Each post first appeared on its own page. The three questions that followed were each presented on a separate page, with the text of the post repeated above each question so that it remained visible while the fact-checker responded.

The first question -on which we focus -measured the overall impression of the post's veracity ("What is your overall impression of the main claim in this post?"), with four response options: True, Misleading, False, and Not sure. As this question is categorical, it allows for a straightforward assessment of agreement between raters. Following prior work (30), we also asked various 7-point Likert measures about perceived bias ("Do you think this post is written in an unbiased way?") and perceived accuracy and credibility ("This post is objective," "This post describes something that actually happened," "This post is accurate," "This post is reliable," "This post is trustworthy," and "This post is true"), but we do not analyze those responses here. Responses to all questions were required, so each fact-checker provided a complete set of ratings for all 60 posts.

The two fact-checkers gave the same overall assessment for 45 of the 60 posts (75.0%). Gemini 3.1 Flash-Lite agreed with Fact-checker 1 on 76.7% of posts and with Fact-checker 2 on 85% of posts, yielding an average agreement with fact-checkers of 80.8%. GPT-4o mini agreed with Fact-checker 1 on 63.3% of posts and with Fact-checker 2 on 66.7% of posts, yielding an average agreement with fact-checkers of 65%. Thus, consistent with prior work (30), Gemini 3.1 Flash-Lite showed quite good agreement with the fact-checkers. This validates our use of Gemini 3.1 Flash-Lite to fact-check the posts in our dataset.
