Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Checking code requires downloading its file contents. For a paper whose repository is on Dryad, this never succeeds unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (listing the repository’s files does not need one). Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Neural dedifferentiation, characterized by reduced distinctiveness of neural representations, is a robust feature of cognitive aging. Multivoxel pattern analyses often operationalize neural distinctiveness as the difference between within-category similarity (reliability) and between-category similarity (confusability). However, it remains unclear whether age-related reductions in distinctiveness are driven by decreases in reliability, increases in confusability, or both, and whether these components demonstrate similar longitudinal trajectories. Using cross-sectional and longitudinal data from the Michigan Neural Distinctiveness (MiND) study, we decomposed distinctiveness into its two components across visual, auditory, and motor cortex in more than 200 young (18-29 years) and older adults (65-94 years) and estimated cross-sectional between-person age differences and longitudinal withinperson change simultaneously in mixed-effects models. We found that reliability was lower in older vs. younger adults cross-sectionally, and this reduction was significantly larger than the corresponding effect on confusability. Moreover, reliability also declined longitudinally within individuals across a mean interval of four years. These findings indicate that age-related dedifferentiation is driven primarily by declining reliability rather than increasing confusability, and that reporting distinctiveness alone can conceal substantial age-related change in its components.

Age-Related Neural Dedifferentiation Is Driven by Declining Reliability

1. Introduction

Neural dedifferentiation has emerged as an important framework for understanding agerelated changes in the brain. Broadly defined, dedifferentiation refers to reductions in the specificity or distinctiveness of neural representations (for review, see Koen et al., 2020). At the level of category representations, it has been commonly operationalized as an age-related reduction in neural selectivity in category-preferring cortical regions; that is, the difference in response to preferred versus non-preferred stimulus categories is attenuated in older vs. younger adults (Carp et al., 2011b; Park et al., 2004; Park et al., 2012; Simmonite and Polk, 2022; Voss et al., 2008). This reduction in neural selectivity has been linked to age-related declines in cognitive abilities, such as fluid intelligence (Park et al., 2010), episodic memory (Abdulrahman et al., 2017; Koen et al., 2019), and working memory (Payer et al., 2006).

Empirically, evidence for dedifferentiation has been most extensively documented in ventral visual cortex, first reported by Park et al. (2004), who demonstrated age-related reductions in the selectivity of brain activation in response to various categories, including faces, houses, pseudowords, and chairs. These findings have since been widely replicated (e.g., Chamberlain et al., 2021; Voss et al., 2008; for review, see Koen et al., 2020 and Koen and Rugg, 2019) and extended to auditory (Du et al., 2016; Lalwani et al., 2019) and motor regions (Carp et al., 2011a; Cassady et al., 2019), suggesting that neural dedifferentiation is a general feature of brain aging. Although early studies focused on mean activation differences between preferred and non-preferred categories, more recent work using multivoxel pattern analysis (MVPA) has enabled researchers to capture the spatial pattern of activation across voxels, and it provided a more sensitive measure of how different categories are represented in cortex (Carp et al., 2011b; Norman et al., 2006; Sommer and Sander, 2022). In this framework, dedifferentiation is indexed by reduced neural distinctiveness, and it reflects less differentiated multivoxel patterns across stimulus categories. For example, Carp et al. (2011b) demonstrated that multivoxel representations in older adults were less distinctive across visual categories relative to young adults.

Neural distinctiveness is often operationalized as the difference between two measures: (1) within-category similarity, or how similar brain activation patterns are in response to the same category of stimuli (e.g., how similar is the activation pattern in response to different blocks of faces), and (2) between-category similarity, or how similar brain activation patterns are in response to different categories of stimuli (e.g., how similar is the activation pattern in response to faces compared to the activation pattern in response to places) (Chamberlain et al., 2021; Haxby et al., 2001; Simmonite and Polk, 2022; Williams et al., 2007).

Within-category similarity is an estimate of the reliability of neural activation in response to a particular stimulus category. If repeated presentations of the same stimulus category elicit very similar activation patterns, then those patterns are reliable and within-category similarity will be high. Conversely, between-category similarity reflects the confusability of neural activation patterns in response to different categories. If the activation patterns in response to two different stimulus categories (e.g., faces and places) are very similar, then those patterns are confusable and between-category similarity will be high.

Neural distinctiveness is often operationalized as the difference between these two measures: neural reliability (within-category similarity) minus neural confusability (betweencategory similarity) (Carp et al., 2011b; Simmonite and Polk, 2022; Williams et al., 2007). Agerelated reductions in neural distinctiveness may therefore arise from decreased reliability, increased confusability, or a combination of both. Indeed, some studies have reported that older adults exhibited both reduced reliability and increased confusability (e.g., Carp et al., 2011b; Simmonite and Polk, 2022).

Across studies, age-related reductions in neural distinctiveness have been most consistently associated with decreases in reliability. Reduced reliability has been reported in the ventral visual cortex (Carp et al., 2011b; Chamberlain et al., 2021; Guerreiro et al., 2024; Koen, 2022), auditory cortex (Guerreiro et al., 2024), and motor regions (Carp et al., 2011a). Critically, although neural dedifferentiation has been most extensively documented within these sensory and motor cortices, reduced reliability is not confined to them: it has also been reported in semantic association regions, such as the inferior parietal cortex (Margolles and Soto, 2024), as well as temporal cortex during memory tasks (Trelle et al., 2019). Moreover, greater reliability during memory encoding predicted stronger reinstatement at retrieval and superior memory performance in older adults, including those with preserved cognitive abilities (Katsumi et al., 2021), and this finding suggests that reliability may have functional relevance. Together, these results demonstrate that reduced reliability is a robust and general feature of neural aging.

In contrast, prior findings regarding confusability have been mixed. Some studies reported increased confusability in older adults (Carp et al., 2011a; Carp et al., 2011b; Margolles and Soto, 2024; Simmonite and Polk, 2022), although such effects were not consistently observed across modalities. Other studies found no reliable age differences in confusability (e.g., Chamberlain et al., 2021; Guerreiro et al., 2024). In many cases, confusability was computed as part of the distinctiveness measure but not explicitly examined or reported. This inconsistency raises the possibility that age-related reductions in distinctiveness may primarily reflect declines in reliability rather than increases in confusability. However, direct tests comparing the magnitude and trajectory of these two components remain limited.

Importantly, most prior studies have relied on cross-sectional comparisons between young and older adults (e.g., Carp et al., 2011a; Carp et al., 2011b; Chamberlain et al., 2021; Simmonite and Polk, 2022). Such designs prevent researchers from determining whether age differences in reliability and confusability reflect longitudinal within-person change with age or simply between-group differences that could be due to cohort effects rather than age per se (Raz and Lindenberger, 2011; Schaie, 1965). Therefore, longitudinal approaches are critical for clarifying how reliability and confusability progress with aging and whether they demonstrate similar or distinct trajectories across modalities.

In the current study, we tested whether age-related reductions in neural distinctiveness reflect decreased reliability, increased confusability, or both, and whether these components demonstrate similar or dissociable cross-sectional and longitudinal trajectories. To do so, we used both cross-sectional and longitudinal data from the Michigan Neural Distinctiveness (MiND) Study (Gagnon et al., 2019). First, we sought to replicate and extend prior crosssectional findings (Simmonite and Polk, 2022) by directly decomposing distinctiveness into its reliability and confusability components across visual, auditory, and motor cortices. The present cross-sectional sample substantially overlaps with the sample from that prior study, so these analyses represent a reanalysis and extension of a largely shared dataset rather than an independent replication. Second, we examined longitudinal trajectories to assess whether reliability and confusability change with age within individuals. By integrating cross-sectional and longitudinal approaches, the present study aims to clarify the mechanisms underlying age-related reductions in neural distinctiveness and determine whether these effects are domaingeneral across modalities.

2.1.3. Screening and Inclusion Criteria

Prior to enrollment, participants completed a telephone screening to ensure absence of MRI contraindications and that they did not use medications with psychotropic effects. All participants scored ≥ 85 on the NIH Toolbox Cognition Battery.

For the functional MRI data, we quantified head motion as framewise displacement (FD) computed from the rigid-body realignment parameters.

Volumes exceeding an FD threshold were treated as motion outliers and scrubbed (i.e., excised from the data, and the remaining good TRs were then stitched) prior to modeling, and a task run was discarded entirely when the proportion of scrubbed volumes met or exceeded a run-level cutoff. In the main text, we reported the analyses that use a conservative rule: volumes with FD ≥ 0.4 mm were scrubbed, and runs with ≥ 10% scrubbed volumes were excluded. This rule excluded 131 of 855 assessed task runs (15.3%). Because head motion was greater in older than in young adults, and run exclusion was therefore not age-invariant (Table S3), we repeated all analyses under a more liberal rule (volumes scrubbed at FD ≥ 0.5 mm; runs excluded at ≥ 20% scrubbed volumes), which excluded 14 runs (1.6%). All participants provided written informed consent in accordance with the University of Michigan Institutional Review Board.

2.2. Study Design

Participants completed three testing sessions on separate days: (1) a behavioral session, (2) a functional MRI (fMRI) session, and (3) a magnetic resonance spectroscopy (MRS) session.

Sessions were completed within approximately three weeks of each other (M ≈ 22 days). The present paper focuses on the fMRI session; additional details of the full MiND protocol are described in Gagnon et al. (2019). Task design, MRI acquisition, preprocessing, ROI definition, and distinctiveness calculation procedures were based on those described in Simmonite and Polk (2022). We restate these procedures below to provide a self-contained description of the current analyses.

2.3. Functional MRI Tasks

During fMRI acquisition, participants completed three block-design tasks designed to elicit activity in visual, auditory, and motor cortex, respectively (Figure 1). Each task lasted six minutes and included two experimental conditions and a fixation control condition. Each experimental condition was presented in six 20-second blocks, and twelve 10-second fixation blocks were interleaved throughout the run. Experimental blocks were pseudorandomized and alternated with fixation blocks, and block order was identical across participants.

In the visual task (Figure 1A), participants viewed blocks of grayscale photographs of faces and houses, adapted from prior studies of age-related dedifferentiation (Park et al., 2004; Park et al., 2012). Each experimental block contained 20 stimuli presented for 500 ms each, separated by a 500 ms interstimulus interval during which a fixation cross was displayed. Each image was presented once. To ensure attention, participants performed a target-detection task.

During face blocks, targets were female faces, and during house blocks, targets were apartment buildings. Six targets appeared over the course of the task, ranging from one every 30 to 90 seconds, and participants responded using their right index finger.

In the auditory task (Figure 1B), participants listened to blocks of foreign speech or Responses were recorded using a Celeritas 5-button fiber-optic response unit, and auditory stimuli were delivered through an Avotec Conformal Headset.

2.4. MRI Acquisition

Structural and functional images were acquired at the University of Michigan Functional MRI Laboratory using a GE Discovery MR750 3T scanner equipped with an 8-channel head coil. Participant motion was minimized using foam cushions and Velcro straps.

High-resolution anatomical images were collected using a 3D fast spoiled gradient-echo (SPGR) BRAVO sequence with the following parameters: TR = 12.2 ms, TE = 5.2 ms, TI = 500 ms, flip angle = 15°, field of view = 256 × 256 mm, and 1 mm isotropic voxels (156 axial slices).

Functional images were acquired using a single-shot gradient-echo reverse spiral sequence with the following parameters: TR = 2000 ms, TE = 30 ms, flip angle = 90°, field of view = 220 × 220 mm, and 3 mm isotropic voxels (43 axial slices, 180 volumes per run). Each task run lasted six minutes.

2.5. MRI Preprocessing

>MRI Preprocessing

2.5.1. Structural Preprocessing

We preprocessed each participant's high-resolution T1-weighted anatomical image using FreeSurfer's automated cortical reconstruction pipeline. This procedure included skull stripping, intensity normalization, Talairach transformation, white and pial surface reconstruction, and automated cortical parcellation according to the Desikan-Killiany atlas. The resulting surfaces and parcellations served as the anatomical framework for defining modality-specific search spaces and extracting vertex-wise activation estimates.

We visually inspected all cortical reconstructions and manually corrected segmentation errors when necessary to ensure accurate surface placement and parcel boundaries.

2.5.2. Functional Preprocessing

We preprocessed all functional MRI data using a combination of SPM, FSL, and FreeSurfer's surface-based analysis stream. Prior to statistical modeling, raw functional volumes were corrected for physiological noise arising from cardiac and respiratory cycles, using a RETROICOR-based approach. We then performed slice-timing correction to account for temporal offsets in slice acquisition and applied rigid-body motion correction to align all volumes within each run to a reference image.

Next, we imported motion-corrected volumes into a surface-based processing stream.

Using each participant's reconstructed cortical surfaces, we projected functional data onto the individual's native cortical surface and resampled them to a common template surface (fsaverage) to enable group-level comparisons. We spatially smoothed (5 mm full-width at halfmaximum, surface-based smoothing) the data. All preprocessing steps were applied separately to each run.

We visually inspected anatomical reconstructions and functional alignment for quality control. Runs with excessive motion, as defined in Section 2.1.3, or preprocessing failures were excluded prior to analysis.

2.6. ROI Definition

Functional regions of interest (ROIs) were defined separately for each modality (visual, auditory, motor), using a two-step procedure that combined anatomical constraints with participant-specific functional activation.

2.6.1. Anatomical Constraints

First, we defined modality-specific anatomical search spaces using each participant's cortical parcellation. Following Simmonite and Polk (2022), the visual mask combined the bilateral fusiform gyrus and parahippocampal gyrus; the auditory mask combined the bilateral superior temporal gyrus, banks of the superior temporal sulcus, transverse temporal gyrus, and supramarginal gyrus; and the motor mask combined the bilateral precentral gyrus, postcentral gyrus, and supramarginal gyrus. We constructed these anatomical masks separately for each hemisphere and used them as constrained search spaces for functional ROI selection.

2.6.2. Functional Ranking within Anatomical Masks

Second, we estimated task-evoked responses using FreeSurfer's FSFAST pipeline. For each task, we fit a general linear model (GLM) that included regressors for both experimental conditions and fixation, each convolved with a canonical hemodynamic response function. We then computed contrasts comparing each experimental condition to fixation.

This vertex-selection procedure was carried out separately for each task, within the task's corresponding anatomical mask. For a given task, vertices in the participant's anatomical mask were ranked according to their beta values separately for each of that task's two experimental conditions. To ensure balanced representation of both stimulus categories, we alternated selecting vertices from the highest remaining beta values of each condition. If a vertex selected for one condition had already been included because of high activation in the other condition, the next highest vertex was selected instead. This procedure yielded, for each task, functional ROIs that contained the most responsive vertices while preserving equal contribution from both of that task's experimental conditions. Using this procedure, we constructed a functional ROI containing the 2,000 most responsive vertices within the anatomical mask for each participant.

2.6.3. Neural Reliability, Confusability, and Distinctiveness

Neural reliability, confusability, and distinctiveness were quantified using a correlationbased multivoxel pattern similarity approach consistent with prior work (Cassady et al., 2020; Haxby et al., 2001; Simmonite and Polk, 2022). For these estimates, a separate GLM was fit for each task in which each of the 12 experimental blocks was modeled with a unique regressor, yielding 12 beta estimates per vertex.

Within each functional ROI, we computed reliability (within-category similarity) by correlating activation patterns from blocks of the same experimental condition (e.g., a face block with another face block) and averaging these correlations. We computed confusability (betweencategory similarity) by correlating activation patterns from blocks belonging to different experimental conditions (e.g., a face block with a house block) and averaging those values.

Distinctiveness was defined as their difference (reliability -confusability), such that higher values indicate activation patterns that are more distinct across the two stimulus categories.

Because all three measures are averaged pattern correlations computed on the same blocks, they share a common scale, and the distinctiveness measure decomposes exactly into its two components.

2.7. Statistical Analyses

All statistical analyses were conducted in R (Version 4.5.2). Linear mixed-effects models were fit using the lme4 package and estimated by maximum likelihood (REML = FALSE), with degrees of freedom and p-values obtained using Satterthwaite's approximation as implemented in lmerTest. Unstandardized fixed-effect estimates (b) and standard errors are reported throughout.

2.7.1. Model Specifications

Rather than fitting separate cross-sectional and longitudinal models, we fit a single mixed-effects model per outcome that simultaneously estimates between-person age differences and within-person age change (Hoffman and Stawski, 2009). We decomposed the chronological age at each session into two components: between-person age was defined as the participant's mean age across their retained waves, centered at 65 years, and indexes cross-sectional age differences across individuals; within-person age change was defined as each session's deviation from the participant's own mean age and therefore isolates longitudinal change. For participants who contributed a single wave, their within-person age change is zero by construction, so singlewave participants inform the between-person effect and the covariates but not the within-person slope.

For each of the three outcomes -reliability, confusability, and distinctiveness -we fit the model:

outcome ~ within-person age + between-person age + sex + education + modality contrasts + (1 | participant)

Modality was entered using two effect-coded contrasts, the first comparing motor to auditory cortex (auditory = -1, motor = 1, visual = 0) and the second comparing visual to auditory cortex (auditory = -1, visual = 1, motor = 0). Modality was included to account for systematic differences among the three ROIs, and the primary analyses and interpretation focused on age effects pooled across modalities. Sex and years of education were included as covariates. A random intercept for participant accounted for the non-independence of the three modality-level observations within each session and of repeated sessions from the same individual.

These models were fit to the 724 modality-level observations from 276 sessions, contributed by 218 participants described above. Among all sessions, 58 of them are return visits.

2.7.2. Age Effects Magnitude Comparison

A central question of the present study is whether age effects are stronger for reliability than for confusability. To directly compare the magnitude of age-related differences in reliability and confusability, we compared the absolute values of their age coefficients from the pooled mixed-effects models described above. Because reliability and confusability were on the same scale (i.e., from -1 to 1), we defined the magnitude contrast as Δ 𝑚𝑎𝑔 = |𝛽 𝑅𝑒𝑙𝑖𝑎𝑏𝑖𝑙𝑖𝑡𝑦 | -|𝛽 𝐶𝑜𝑛𝑓𝑢𝑠𝑎𝑏𝑖𝑙𝑖𝑡𝑦 |, such that positive values indicated a larger absolute age coefficient for reliability, and negative values indicated a larger absolute age coefficient for confusability. We separately estimated the magnitude contrasts for the between-person age and within-person age effects. Uncertainty in each contrast was estimated using a participant-level cluster bootstrap with 5,000 resamples, with the reliability and confusability models re-estimated within each bootstrap sample and 95% percentile confidence intervals calculated from the resulting bootstrap distribution.

4. Discussion

The current study aimed to examine whether age-related reductions in neural distinctiveness (i.e., neural dedifferentiation) primarily reflect decreased neural reliability, increased neural confusability, or both, and whether these components show similar crosssectional and longitudinal changes. After successfully replicating age-related declines in neural distinctiveness, we found that reliability declined significantly within individuals across a ~4year interval, whereas confusability showed no overall association with age. Direct comparison of the absolute age coefficients further indicated that the between-person age association was larger in magnitude for reliability than for confusability, although the corresponding withinperson difference was not supported. Thus, the cross-sectional pattern provides direct evidence that reliability contributes more strongly than confusability to age-related differences in neural distinctiveness, while the longitudinal data support a decline in reliability but do not establish that its rate of change differs from that of confusability.

4.1. Reliability as the Locus of Dedifferentiation

Reliability, as measured here, is the similarity between activation patterns evoked by different presentations of the same stimulus category. It asks how consistently a region reproduces the same pattern when given the same kind of input, and says nothing about how that pattern compares to the one evoked by a different category (Haxby et al., 2001; Simmonite and Polk, 2022). Therefore, an age-related decline in reliability points to representations that are less stable across repetitions, even where the separation between categories is preserved. This interpretation aligns with computational models of cognitive aging that emphasize age-related reductions in neural gain and increases in neural noise (Li et al., 2001; Li and Lindenberger, 1999; reviewed in Koen and Rugg, 2019). These models proposed that weaker neuromodulation lowers the ratio of signal to noise in cortical circuits: neurons respond less selectively to their preferred input and more variably from one presentation to the next. Greater trial-to-trial variability should reduce reliability directly, because reliability depends on reproducing the same pattern twice. It does not necessarily increase confusability, though, because random variability lacks systematic direction, and confusability would increase only if noise pulled neural patterns systematically toward one another. Consistent with these models, we found robust age-related reductions in reliability without a corresponding overall increase in confusability.

The findings also speak to whether dedifferentiation reflects broadening or attenuation (Koen and Rugg, 2019; Park et al., 2012). Broadening -that is, larger responses to non-preferred stimuli -should raise between-category similarity, and so appear as increased confusability.

Attenuation -that is, smaller responses to preferred stimuli -should weaken the evoked pattern relative to noise, and so appear as reduced reliability. Reliability declined with age both crosssectionally and longitudinally, whereas confusability did not show age-related changes. This pattern suggests that attenuation-like changes may be a more general feature of age-related dedifferentiation, whereas broadening may be more context-dependent.

Neurochemical evidence offers a possible substrate. Age-related reductions in GABA, the cortex's principal inhibitory transmitter, have been linked to lower neural distinctiveness in sensory cortex (Chamberlain et al., 2021; Lalwani et al., 2019). Inhibition sharpens how narrowly neurons respond to their preferred input (Isaacson and Scanziani, 2011), and in human somatosensory cortex, higher GABA concentrations accompany sharper responses and better perceptual acuity, with response sharpness mediating the link between the two (Kolasinski et al., 2017). Importantly, GABAergic signaling maintains the precision of cortical representations (Leventhal et al., 2003), and recent computational work suggests that GABAergic inhibition supports representational precision by implementing gain control mechanisms such as divisive normalization, which stabilize neural responses and preserve differences between activity patterns (Zhou and Polk, 2026). In other words, losing inhibitory tone should therefore make stimulus-evoked responses more variable -the same endpoint the gain-and-noise models predict, reached through a specific mechanism. Declines in inhibitory function with age have been reported in both animals and humans (Cassady et al., 2019; Leventhal et al., 2003). Notably, this kind of change could make category representations less consistent across repetitions without necessarily making different categories more similar to one another, which closely matches the pattern we observed.

4.2. Why Confusability Has Been Mixed in the Literature

In contrast to reliability, neural confusability, operationalized as between-category similarity, did not show robust longitudinal change or exhibit consistent cross-sectional age differences. This finding suggests that age-related reductions in neural distinctiveness do not necessarily reflect increased similarity between representations of different stimulus categories. This result adds to a mixed literature on age-related changes in confusability. Some studies have reported age-related increases in confusability (Carp et al., 2011a; Carp et al., 2011b; Simmonite and Polk, 2022), while others reported little or no evidence for an age difference (Chamberlain et al., 2021; Guerreiro et al., 2024). Notably, some of these studies used overlapping datasets (e.g., Chamberlain et al., 2021; Simmonite and Polk, 2022), suggesting that differences in findings cannot be attributed solely to sample differences and may instead reflect variation in the regions examined, the stimulus categories used, or the geometry of the underlying representational space. In particular, the effect of added neural noise on betweencategory similarity should depend in part on how separated the category representations are to begin with (Margolles and Soto, 2024). When category representations are already well separated, greater variability could reduce the reliability of each category representation without necessarily making the categories more similar to one another. In this case, an age-related decline in reliability does not entail an increase in confusability.

A related pattern appears in the behavioral literature on aging and categorization, where older adults often rely more on category-level or gist-based representations and less on itemspecific detail (Bowman et al., 2022; Hess, 1982; Hess et al., 1996; Hess and Wallsten, 1987).

They showed particular difficulty with boundary items that require fine-grained discrimination while showing relatively preserved performance for items that reflect the central tendency of a category (Bowman et al., 2019 (Bowman et al., , 2022)). At a broad level, this is compatible with reduced representational fidelity without a wholesale loss of categorical organization. However, the correspondence should not be pushed too far. Our tasks did not involve category learning or explicit categorization judgments, and our reliability measure reflects the consistency of activation patterns across different exemplars of the same category rather than the fidelity of individual exemplar representations.

4.3. Cross-Sectional and Longitudinal Age Effects

The longitudinal design complements the cross-sectional analysis by testing whether neural measures change within the same individuals over time (Rohrer and Murayama, 2023).

Reliability declined within participants across the approximately 4-year follow-up interval, consistent in direction with the negative between-person age association. We did not formally test whether the between-and within-person age coefficients differed, and their magnitudes should not be directly compared because the between-person effect was estimated across roughly six decades of age, whereas the within-person effect is based on 58 returners followed over approximately 4 years. The longitudinal estimate is therefore less precise, but it provides converging evidence that neural reliability decreased with age. Consistent with this lower precision, the bootstrap confidence interval for the within-person magnitude contrast was wide and included zero (Figure 3). Thus, although the point estimate favored a larger age effect on reliability, the data did not establish that the magnitude of within-person change differs between reliability and confusability.

4.4. Implications, Limitations, and Future Directions

The current study provides evidence that reductions in neural distinctiveness are driven primarily by declines in neural reliability rather than by increased neural confusability. This finding has important theoretical implications. Many prior studies have operationalized distinctiveness as the difference between within-and between-category similarity (e.g., Carp et al., 2011b), and they implicitly assumed that age-related change reflects both reduced reliability and increased confusability. However, by decomposing these components, we showed that the two did not change together or make equal contributions to reductions in neural distinctiveness.

Methodologically, these findings highlight the importance of decomposing difference scores that are based on multiple variables. Treating neural distinctiveness as a single construct may obscure mechanistic differences between neural reliability and confusability. Reliability declined both between-and within-individuals and may offer a more direct index of age-related representational change than composite distinctiveness.

There are several limitations that are worth keeping in mind. The cross-sectional sample overlaps substantially with that of Simmonite and Polk (2022), so these analyses constitute a reanalysis and extension of a largely shared dataset rather than an independent replication. In addition, the age distribution is bimodal, with young adults aged 18-29 and older adults 65 and above and no participants in between, so the between-person slope is better understood as a contrast between two age groups than as a continuous function of age across adulthood. Future research should consider recruiting participants across the lifespan and examine whether the patterns we found generalize across the adult lifespan.

Moreover, our measures were derived from block-based similarity across 12 blocks per run, which captures stability across repeated blocks rather than trial-to-trial variability, and event-related designs would support a finer-grained characterization. Each modality contributed only two conditions, so confusability rests on a single pairwise comparison per region. However, it remains possible that age-related increases in confusability would emerge in tasks involving more perceptually or semantically overlapping categories, where category boundaries are less sharply defined (Margolles and Soto, 2024). Future studies should therefore include a broader set of stimulus categories to test whether this yields a more sensitive measure of age-related changes in between-category similarity.

Another limitation is that reduced reliability may reflect not only changes in neural representations but also age-related differences in data quality. For example, greater residual head motion, physiological noise, or changes in neurovascular coupling in older adults could make activation patterns appear less consistent across repetitions (Power et al., 2012; Satterthwaite et al., 2013). We addressed head motion using two exclusion criteria and obtained similar results, but we could not directly account for other potential sources of measurement noise. In addition, although our interpretation draws on theories involving neural gain and inhibitory signaling, we did not directly measure these mechanisms.

Future research can therefore integrate reliability measures with neurochemical indices such as GABA concentration to examine whether reductions in inhibitory tone contribute specifically to diminished neural reliability (e.g., Kolasinski et al., 2017). Computational modeling may further help formalize how reductions in inhibitory tone degrade neural reliability without necessarily affecting neural confusability. Extending the decomposition across ROI scales and to regions beyond sensory and motor cortex would test how general the reliability effect is. Future research should also link reliability to behavior across perception, episodic memory, and higher-order cognition and examine how general the feature is.

Taken together, these findings suggest that age-related neural dedifferentiation may be better understood as a decline in neural reliability rather than a general collapse of categorical organization.
