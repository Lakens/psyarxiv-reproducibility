Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. This package was validated by the Metacheck team on articles in Psychological Science.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Codebook Check works

This module checks whether the data columns in a repository are documented in a codebook or README. It locates codebook/readme files, extracts the variable definitions they contain, matches those definitions against the data columns extracted by data_check, and reports documentation coverage: how many data columns are documented, and which documented variables are never used.

The Codebook Check module consumes the columns and file classification produced by data_check (and, transitively, repo_check). Files classified as codebook or readme are parsed with parse_codebook(), which reads structured tables (CSV/TSV/Excel with a variable-name column and a label column), embedded labels in haven files (SPSS/Stata/SAS), and plain text from rich-text formats (docx/pdf/rtf/odt). Embedded haven labels from data files are also harvested directly.

Each data column is then matched against the parsed variable definitions with match_column_labels(), using normalised-name matching with experiment-group scoping, haven-label priority, and rule-based label-equivalence merging.

Beyond the variable label, the module harvests the DDI-style per-variable properties a source supplies: the value labels / code list (the 1=“Strongly disagree”…5=“Strongly agree” mapping — from SPSS/Stata value labels and from a codebook “values”/“coding” column), the missing-value scheme (which codes denote missingness, from haven declared missings and labels that read as “refused”/“n/a”), and question text and columns when present. These are carried onto the matched data columns and exported into the Psych-DS variableMeasured (as a schema.org code list plus namespaced metacheck: fields).

The module defaults to rules-only when llm_use(FALSE). When llm_use(TRUE), three optional LLM tiers run: parsing unstructured codebook text that the rules could not handle, fuzzy-matching still-unlabelled columns to still-unmatched codebook variables, and merging conflicting label definitions into a single canonical label.

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Public Significance Statement

Although conditionals play a key role in hypothetical thinkingfrom making predictions to evaluating explanationsexisting empirical findings have not yet provided a conclusive answer as to when people consider them acceptable. Using a new experimental procedure that allows a clear distinction between competing theoretical models, this study shows that reasoning about conditionals is context-sensitive: when the antecedent and consequent of a conditional are arbitrarily linked, people tend to rely on how likely the consequent is given the antecedent, whereas when they are causally linked, people focus on whether the antecedent provides a good reason to expect the consequent. These findings indicate that no single existing model can fully account for how people evaluate different types of conditionals, and they have practical implications for generating more effective hypotheses across various fields.

A conditional is a sentence that expresses a hypothetical statement and consists of an antecedent (the if-clause) and a consequent (the then-clause, in which the word then is sometimes implicit). For example, "If it is snowing, (then) it is cold" is a conditional, where "It is snowing" is the antecedent (a) and "It is cold" is the consequent (c). Conditionals are often formally represented as a→c, and the statements expressed are hypothetical, in that neither a nor c are implied by the conditional. This means that when one asserts "If it is snowing, it is cold," they are not asserting that "It is snowing" or that "It is cold". What one asserts is that a certain relation holds between "It is snowing" and "It is cold."

Conditional statements play a central role in human reasoning, as they occur in a wide variety of inferences directly involved in the construction and transmission of knowledge. These range from exploring hypotheses to evaluate outcomes that would obtain under alternative assumptions, to anticipating consequences of future actions. Scientific predictions are also largely structured around hypothetical statements, as in causal laws or in theory testing (e.g., "If copper is heated, it will expand.") A paradigmatic example is the inference rule modus ponens: from the premises a→c and a, one can infer the conclusion c. Thus, for example, if we have reasons to believe that "If it is snowing, it is cold", and we observe that "It is snowing", we can safely conclude that "It is cold". This rule, which logicians regard as fundamental, essentially relies on the properties of conditionals.

The question of what a conditional is, however, has no easy answer. The meaning of if, unlike that of not or and, for instancerepresented respectively as  and is particularly hard to capture in formal terms. According to the material interpretation of conditionals adopted in classical propositional logic, a→c is true if and only if it is not the case that a is true and c is false. This interpretation, however, is widely regarded as inadequate for capturing the ordinary use of conditionals because of its patently counterintuitive consequences. For example, suppose that Beth is in Spain. Then, "If Beth is in Paris, she is in Italy" turns out to be true, and so does "If Beth is in Paris, she is in Spain". More generally, under the material interpretation, the false antecedent principle (according to which a conditional with a false antecedent is always true) and the true consequent principle (according to which a conditional with a true consequent is always true) hold, so that a→c is entailed by a and by c, respectively. In order to avoid such unpalatable consequences, a variety of alternative interpretations have been explored, giving rise to extensive and intricate discussions (Edgington, 2025).

The contemporary debate on conditionals encompasses a wide range of proposals that depart from the material interpretation in different ways. Although most of them have been examined primarily from a logical perspective, some have also attracted the interest of experimental psychologists. Indeed, each specific model that has been advanced, independently of normative considerations, can be assessed as an empirical hypothesis about the ordinary use of conditionals.

In what follows, we consider the two accounts that have received the most attention within both communities, outlining their formal aspects and the empirical evidence offered in their favor.

The Suppositional Account

The suppositional account is currently one of the most influential approaches to conditionals in philosophy and psychology. It builds on the Ramsey Test, according to which asserting a→c amounts to claiming that c holds on the supposition that a holds (Ramsey, 1929 (Ramsey, /1990)). This idea has been developed in different ways, which correspond to distinct specifications of the Ramsey Test.

A first version goes back to Adams (1965; 1975). On this approach, a conditional a→c is assigned a quantitative semantic value corresponding to the conditional probability of the consequent given the antecedent, i.e., P(c|a).

A second version, developed by Stalnaker (1968 Stalnaker ( /1991)), defines a qualitative criterion of truth in modal terms: a conditional a→c is true if and only if c is true in the closest world in which a is true. A related version has been developed within the belief revision framework established by Gärdenfors (1978, but see also Spohn, 2015). On this proposal, a conditional holds if and only if a rational agent's belief state includes the consequent c once revised on the basis of the antecedent a.

There are also variants of suppositionalism that make use of non-classical logics. Among these, a particularly influential approach, inspired by de Finetti (1936), retains a truth-functional treatment of conditionals but replaces the classical binary assignment of truth values with a trivalent one. This yields the so-called defective truth table (see Égré et al., 2021), according to which a conditional is true when both its antecedent and consequent are true, false when its antecedent is true and its consequent false, and void otherwise. Provided that P(a) > 0, this approach allows the probability assigned to a conditional to equal P(c|a), sidestepping the so-called triviality results arising from Lewis's (1976) work (see Over & Evans, 2024).

For the purpose of our study, it is sufficient to note that all the models discussed above have similar consequences, including the rejection of controversial principles of the material interpretation. In particular, suppositional approaches elude the false-antecedent and the trueconsequent principles, as well as monotonicity (according to which a conditional remains true when its antecedent is strengthened with additional information).

The suppositional view has been widely regarded as normatively compelling and, intuitively, as a descriptively accurate characterization of conditionals. In particular, Adams (1965; 1975) suggested that, as far as we restrict consideration to conditionals where a and c do not themselves contain conditionals, a measure of their acceptability 1 is the conditional probability of c given a is (as long as P(a) > 0): (1) AccSU(a→c) = P(c|a).

Several logicians have entertained the thought that (1) might be descriptively correct: Stalnaker (1970), Lewis (1976), Jackson (1987), Edgington (1986), McGee (1989), Bennett (2003), among others.

As far as the descriptive adequacy of the suppositional account is concerned, a nonnormative variant deserves special consideration. Various authors (e.g., Oberauer, Geiger, et al., 2007; Over & Evans, 2003), while endorsing the normative status of the suppositional account, have also considered a different prediction about intuitive assessments of conditionals. According to this, individuals who rely more on intuition than on deliberation (see López-Astorga et al., 2022) evaluate the acceptability of a conditional a→c by considering only the probability of the conjunction of a and c, an interpretation of conditional statements that has been labelled as conjunctive (Evans et al., 2003): (1bis) AccCJ(a→c) = P(a∧c).

Further discussion of this point can be found in the next section, where we examine participants' judgments in psychological studies of the acceptability of conditionals.

Most of these studies (e.g., Evans et al., 2003; Hadjichristidis et al., 2001; Oberauer & Wilhelm, 2003; Over & Evans, 2003) focused on arbitraryfoot_0 conditionals, that is, conditionals in which the antecedent-consequent relation is meaningful within the set of elements under consideration but is not grounded in prior knowledge and may therefore fail to generalize to other sets (see also Gauffroy & Barrouillet, 2009; Weidenfeld et al., 2005). A typical example (e.g., Evans et al., 2003) is a conditional expressing a given association between features of an item, such as: "If the card is yellow, it has a circle printed on it".

A variety of experimental procedures have been employed. Among these, a common task consists of asking participants to estimate, on the basis of frequency information corresponding to the four possible conjunctions of the antecedent and the consequent, the probability that a conditional is true or holds, either in a single judgment or across an extended sequence of trials (e.g., Evans et al., 2003; Fugard et al., 2011). Other tasks include estimating the chances of winning bets expressed as conditionals (Politzer et al., 2010) or classifying a conditional as true, false, or neither (e.g., Baratgin et al., 2013).

These studies consistently led to two main results. First, the material interpretation of conditionals has been found to be largely counterintuitive. This emerged both in tasks eliciting probability judgments (e.g., Fugard et al., 2011; Hadjichristidis et al., 2001; Politzer et al., 2010) and in tasks requiring more qualitative evaluations. In the latter case, some support has been found for a defective truth table (see, for instance, Baratgin et al., 2013). Second, most of participants' probability judgments for conditionals closely aligned with P(c|a), whereas a minority of judgments appeared to reflect a conjunctive interpretation, especially in one-shot evaluations (e.g., Cruz & Oberauer, 2014; Evans et al., 2003; Oberauer & Wilhelm, 2003).

The empirical support for the suppositional account extended beyond arbitrary conditionals (Evans, Handley, Hadjchristidis, et al., 2007; Evans et al., 2008; Ohm & Thompson, 2006; Over et al., 2007), as subjective estimates of P(c|a) were also found to correlate with judgments about the probability that conditionals expressing inducements (i.e., promises and threats) or advice (i.e., tips and warnings), as well as causal conditionals (i.e., conditionals with a causal link between the antecedent and the consequent), were true.

As mentioned above, studies that yielded evidence in favor of the suppositional view frequently also reported a minor, yet reliable, degree of alignment with the conjunctive interpretation (e.g., Baratgin et al., 2013; Evans et al., 2003; Oberauer & Wilhelm, 2003; see also Girotto & Johnson-Laird, 2004), a result that appeared to reflect a consistent response style exhibited by a subset of individuals rather than mere noise (Oberauer, Geiger, et al., 2007).

Notably, developmental studies have also suggested that such an interpretation predominates among sixth graders but declines over time in favor of the suppositional one (Gauffroy & Barrouillet, 2009). Moreover, research on individual differences has revealed a positive relationship between measures of general intelligence and the tendency to adopt a suppositional rather than a conjunctive interpretation (Evans, Handley, Neilens, and Over, 2007). Taken together, these findings lend support to the idea that the conjunctive interpretation may reflect an incomplete implementation of the evaluative processes underlying the suppositional interpretation of conditionals.

The Inferential Account

The main alternative to the suppositional account of conditionals is the inferential one. The term inferentialism was introduced by Douven et al. (2023) to express the idea that asserting a→c amounts to asserting that c can be inferred from a. However, this can be instantiated in different ways, and three recent proposals stand out. Douven (2016) defined a qualitative criterion of acceptability, according to which a conditional a→c is acceptable if (i) P(c|a) is high enough relative to a threshold of 0.5 and (ii) a provides some degree of evidential support for c. Following a standard construal of Bayesian evidential support, this means that P(c|a)>P(c). Such a requirement is intended to capture the intuition that the antecedent of an acceptable conditional must be relevant to its consequent, and more specifically must provide some degree of support for it.

A second model, which has appeared in the literature in various forms and has received an extensive formalization in the work of Rott (2022 Rott ( , 2024 Rott ( , 2025)), hinges on the notion of Differencemaking (labelled DM hereafter): a→c holds if and only if (i) c holds in all closest worlds in which a holds, and (ii) it is not the case that c holds in all closest worlds in which a holds. While (i) expresses the Ramsey Test, (ii) is an additional clause devised to capture the intuition that a makes a difference to the credibility of c. Rott labels as Relevant Ramsey Test the combination of (i) and (ii). The DM is spelled out deliberately within a qualitative framework to represent doxastic states of acceptance and non-acceptance. However, a probabilistic version can also be provided. In Adams' semantics, the modal interpretation of the Ramsey Test corresponds to the requirement that P(c|a) be high for a conditional to be accepted. Rott's model implies a strengthening of the Ramsey Test through an additional clause that can be interpreted as requiring that P(c|a) be low (for more in-depth discussions of the implications of this model, see Calderisi, 2023, and Rott, 2024). More precisely, under the measure defended by Christensen (1999) and Joyce (1999), the difference in the first branch of (2) represents the degree to which the antecedent evidentially supports the consequent, whereas under Nozick's (1981) measure, it represents the degree to which the consequent evidentially supports the antecedent (see Climenhaga, 2013, and Crupi et al., 2007, for criticisms of these measures).

If we now restrict our attention to causal conditionals, and to predictive conditionals in particular (i.e., conditionals in which the antecedent refers to a cause and the consequent to one of its effects), (2) is equivalent to the positive part of the well-known contingency measure ΔP (with c denoting the effect and a one of its causes), which is widely used to quantify causal strength (Allan, 1980; Jenkins & Ward, 1965). Building on Cheng's (1997) power PC theory, van Rooij and Schulz (2019) model conditional acceptability in terms of a normalized version of ΔP, dividing it by 1-P(c|a). Under the model's standard assumptions, this normalization makes it possible to estimate the power of the cause expressed by the antecedent (a) to produce the effect expressed by the consequent (c), separately from the influence of background causes, thereby addressing an important limitation of ΔP. Their analysis also extends to diagnostic conditionals (i.e., conditionals in which the antecedent refers to an effect and the consequent to one of its possible causes). In this case, the same normalized expression is applied in the diagnostic direction of the conditional (i.e., effect→cause), but, crucially, it is now interpreted as the probability that the cause (mentioned in the consequent) produced the effect (mentioned in the antecedent), given the occurrence of that effect.

Empirical Support for the Inferential Account

An early contribution to the inferential account was made by Douven (2008), who focused on missing-link conditionals, that is conditionals whose antecedent and consequent bear no meaningful connection, such as "If Chelsea wins the Champions League, there will be at least one head in the first 1,000,000 tosses of this fair coin." These conditionals sound clearly odd, which, according to Douven, shows that a high value of P(c|a), even one close to 1, is not sufficient to capture the acceptability of a conditional.

Building on the considerations above, empirical work has called into question some findings previously regarded as supporting the suppositional account. Douven et al. (2018) provided evidence that the defective truth table does not reflect a stable, context-independent pattern of conditional evaluation: when false antecedents were inferentially relevant to their consequents, participants did not systematically select the "neither true nor false" response but instead evaluated the conditionals as true or false depending on whether the antecedent confirmed or disconfirmed the consequent and on the strength of this relation. Furthermore, Douven and Verbrugge (2012) found that acceptance of non-arbitrary indicative conditionals, such as "If there is another largescale terrorist attack, security measures at airports will be upgraded," depended not only on a high rating of P(c|a) but also on whether the antecedent supported the consequent, operationalized as a higher rating of P(c|a) than of P(c) on a 7-point Likert scale. Along the same lines, Skovgaard-Olsen et al. (2016) showed that P(c|a) closely tracked both probability and acceptability ratings of conditionals when the antecedent was positively relevant to the consequent, whereas this relationship became substantially weaker for missing-link conditionals and for conditionals in which the antecedent has a negative impact on the credibility of the consequent.

Yet points of contention remain. Earlier studies had already examined whether judgments of conditionals are sensitive to covariation between antecedent and consequent, as measured by ΔP.

For example, Oberauer, Weidenfeld, and Fischer (2007) found little evidence that covariation influenced belief in a conditional, and Over et al. (2007) found that P(c|a) was by far the strongest predictor of the probability assigned to causal conditionals, with P(c|a) exerting only a smaller negative effect. Skovgaard-Olsen et al. (2016) questioned the use of artificial stimuli in Oberauer, Weidenfeld, and Fischer (2007) and noted that the ΔP values in Over et al.'s (2007) stimuli covered only a narrow range of positive relevance, yet their own study did not systematically vary the degree of positive relevance either. Finally, Douven and Verbrugge (2012) did not directly compare the predictions of the suppositional and inferential accounts. They showed that the antecedent must also provide positive evidential support for the consequent, while maintaining that a high value of P(c|a) is a necessary, although not sufficient, condition for accepting an indicative conditional.

Disagreement also concerns the implications of the two accounts, including the so-called centering principle (or conjunctive sufficiency), according to which one may infer a→c from a∧c.

Because centering is valid under the suppositional but not the inferential account, several studies have investigated whether people endorse this inference. Empirical findings are, once again, mixed: some results provide evidence that they do (Cruz et al., 2016), whereas others suggest that endorsement depends on the inferential connection between the antecedent and the consequent, with particularly low endorsement rates for missing-link conditionals (Douven et al., 2026; Krzyżanowska & Douven, 2018).

As the discussion above makes clear, the use of missing-link conditionals in this debate is both crucial and delicate. On the one hand, these conditionals have offered to the inferential account one of its most enduring and widely invoked theoretical arguments, as well as some of the clearest empirical evidence in its favor. On the other hand, they appear anomalous in many ordinary contexts, which complicates the interpretation of participants' experimental responses.

Notably, neither these conditionals nor their apparent anomaly represents a recent discovery.

Conditionals of this kind -also known as Walrus conditionals, after the Walrus in Lewis Carroll's nonsense poem "The Walrus and the Carpenter" (Over & Evans, 2024) -had already been extensively discussed by linguists and philosophers, including proponents of the suppositional account. For example, Edgington (1995, p. 268; notation adapted) argued that these conditionals pose no difficulty for the suppositional account, since the focus should rather be on conditionals "where we're not sure whether a, not sure whether c, but the supposition that a has some bearing on whether c." Along similar lines, other researchers (e.g., Bourlier et al., 2023; Cruz et al., 2016; Over & Cruz, 2023) have argued that the weak correlations found in empirical studies between P(c|a) and the perceived probability or acceptability of missing-link conditionals merely reflect the 'infelicity' of such conditionals (i.e., their violations of conversational norms), rather than participants systematically treating positive relevance as part of the meaning of conditionals. For example, Cruz et al. (2016) suggested that the oddness of missing-link conditionals may stem not from the absence of an inferential connection but from the lack of a shared discourse topic linking the antecedent and the consequent (see also Lassiter, 2023, for an explanation of the oddness of missing-link conditionals based on failures of discourse coherence, and Lassiter & Li, 2024, for empirical evidence supporting this explanation). Meanwhile, Krzyżanowska et al. (2017) reported evidence showing that propositions sharing a common topic but lacking positive relevance (e.g., "Sophie likes the Alps" and "Mountaineering can be dangerous") are generally judged as sensible in conversational contexts, but not when combined into a conditional. Without pursuing this side debate further, we simply note that, in our view, the empirical comparison between the suppositional and inferential accounts needs to be broadened beyond missing-link conditionals to include ones in which the antecedent-consequent connection is precisely quantified and experimentally manipulated.

Overview of Experiments Aim

As illustrated when reviewing the empirical support for the two accounts, the results of experimental studies have consistently undermined the descriptive adequacy of the material interpretation. However, the debate over whether the suppositional or the inferential account better captures how individuals interpret conditionals remains far from settled. This may be due, at least in part, to the fact that empirical research within the two traditions has typically relied on distinct stimuli and methodologies, neither of which is immune to confounds, as discussed in the following section.

The present study provides an empirical test of the descriptive adequacy of the accounts outlined above by refining and extending existing methodologies, thereby strengthening the evidence available to date. In particular, we propose a novel experimental paradigm designed to minimize the risk that the stimuli or questions may be misunderstood or may bias responses in favor of either account. Before introducing this paradigm, we briefly discuss what we deem to be the principal limitations of the extant empirical literature.

Limitations of the Existing Empirical Evidence

Although historically important, previous empirical studies vary in several methodological respects, making their findings difficult to interpret and compare.

A first major issue concerns the stimuli, which have typically differed across studies supporting the two accounts. With a few exceptions, studies in the suppositional tradition have used arbitrary conditionals referring to randomly selected items from specified frequency distributions. By contrast, studies taken to support the inferential account have more commonly used conditionals with ordinary content, while measuring (either directly or indirectly) participants' perceived strength of the inferential connection between the antecedent and the consequent, rather than experimentally manipulating that strength. (See also Zhan & Wang, 2025, for a closely related discussion of a potential confound arising from the comparison between what they call artificial conditionals accompanied by explicit extensional probabilities and realistic conditionals evaluated by reference to intensional probabilities.) Moreover, inferentialists have made extensive use of missing-link conditionals, such as "If Mark is wearing socks, then his TV will be working" (Skovgaard-Olsen et al., 2016) or "If the Pope goes blind, the Great China Wall will be invaded by moss" (Douven et al., 2022), which suppositionalists have widely rejected as "odd for pragmatic reasons" (Cruz et al., 2016).

A second issue concerns the questions used to elicit judgments. Studies cited in support of either account have typically asked participants to directly assess either the probability that a given conditional is true or its acceptability (e.g., Douven & Verbrugge, 2012 , 2013; Oberauer, Weidenfeld, and Fischer, 2007; Over et al., 2007; Skovgaard-Olsen et al., 2019; Skovgaard-Olsen et al., 2017). Yet both notions are controversial, even within the philosophical literature (e.g., Douven, 2016; Edgington, 2025), and naïve participants may not interpret them uniformly, potentially adding further noise into their responses. To complicate matters further, the stimuli presented could also have influenced how participants interpreted these questions. Specifically, in studies within the suppositional tradition, participants were sometimes asked to make these judgments in gambling-like tasks. For example, in Politzer et al. (2010), participants were shown small arrays of chips that varied in shape and color and asked to estimate the probability that a conditional referring to a randomly selected chip (e.g., "If the chip is square, then it is black") was true. In such situations, it cannot be ruled out that participants interpreted the question as asking them to estimate the conditional probability of the consequent given the antecedent, rather than the probability that the conditional itself was true. By contrast, as Over and Cruz (2023) argue, in studies framed within the inferential account, participants presented with missing-link conditionals may have understood the question as asking not so much about the conditional itself as about whether a meaningful relation exists between its antecedent and consequent and, possibly, how strong that relation is.

A third major limitation of previous research is its overreliance on correlational approaches.

Participants' ratings of the truth or acceptability of conditionals have typically been correlated with the values relevant to the models under investigation (i.e., the probability of the consequent given the antecedent or the strength of the association between the two). These values have been derived either from the frequency distributions provided to participants (e.g., Oberauer, Weidenfeld, and Fischer, 2007), elicited from the same participants who evaluated the conditionals (e.g., Douven et al., 2022; Singmann et al., 2014), or obtained from a different group of participants (e.g., Hadjichristidis et al., 2001, Study 1; Skovgaard-Olsen et al., 2016). However, because the probability of the consequent given the antecedent tends to be higher when the inference from antecedent to consequent is stronger, correlational methods are ill-suited to empirically distinguishing between the predictions of the two accounts.

General Method

In the present work, we propose a novel experimental paradigm, designed to provide a robust discriminative test of the descriptive adequacy of the main accounts of conditionals advanced in the literature, and we implement it in three online experiments conducted via SoSci Survey (https://www.soscisurvey.de/). In all experiments, participants were presented with scenarios consisting of a brief background story, followed by a conditional expressing a character's thought (regardless of whether this character would be willing to assert it to anyone else). The stories ranged from everyday situations involving hobbies, as in Experiments 1 and 2, to more technical contexts, such as industrial or safety supervision, as in Experiment 3 (see Figure 1 for example scenarios and Supplementary Materials for the full set of stimuli). Importantly, each story was framed such that the character was intended to be uncertain about the truth of the antecedent and the consequent of the conditional. The point of this was to prevent participants from disregarding cases in which the antecedent was false or from focusing exclusively on cases in which the consequent was true. After reading each story, participants were provided with two tables reporting the frequency distributions of the four possible combinations of the antecedent and consequent, alongside their respective negations, that is: ac, ac, ac, and ac. Compared with previous experimental paradigms, ours offers two main advantages. First, it does not require participants to evaluate conditionals in terms of abstract -and potentially elusive -notions such as truth or acceptability, which may increase variability in task interpretation and introduce noise into the data. Second, by employing pairs of distributions explicitly designed to disentangle competing interpretations, it elicits judgments that unambiguously favor one account over the other, thereby reducing the amount of non-discriminative data.

Data Analysis

As a first step, we excluded participants who failed the attention check in Experiments 1 and 3 or any of the three attention checks in Experiment 2.

Our main analysis consisted of an account-discriminating test, implemented via a logistic mixed-effects model, with the chosen distribution as the dependent variable, such that the intercept captured the overall tendency to select the distribution aligned with one interpretation of the conditional rather than the alternative. The model included the other manipulated factors and all possible interactions as fixed effects, as well as random intercepts for participants, distribution pairs and, where necessary, scenarios to account for individual differences and stimulus-level variability (see below and the Supplementary Materials for details).

Additionally, we examined whether judgments were consistent within each participant or whether they alternated between the two accounts under comparison. Specifically, participants were classified as consistent when all their judgments aligned with the same account. Participants were classified as inconsistent when their responses did not show a clear preference between the two accounts (i.e., when 2 of the 4 responses supported each account in Experiments 1 and 3, or when at least 5 out of 12 responses supported each account in Experiment 2). Participants who did not meet these criteria were excluded from the analysis, as it was not possible to distinguish a consistent pattern affected by occasional errors from genuine inconsistency. A binomial test was then used to assess whether the proportion of consistent participants exceeded that of inconsistent participants, while a chi-square test of independence was used to examine whether this proportion differed across experimental conditions.

Experiment 1

In Experiment 1, we examined whether individuals' interpretations of conditionals were consistent with the two normatively grounded theoretical accounts (i.e., the suppositional and inferential accounts) by contrasting their shared prediction with that of the conjunctive interpretation. To this end, we employed arbitrary conditionals, which figured prominently in much of the early empirical literature -including studies that provided some support for the conjunctive interpretation -thereby allowing us to compare our results directly with previous findings.

To increase the generalizability of our results, we manipulated the number of cases in the distributions presented to participants. Although this factor has not been systematically investigated in previous work (but see Evans et al., 2003, for a preliminary exploration), it may nonetheless influence participants' judgments. In particular, with proportions held constant, greater numerosity may increase the salience of individual cells in the contingency tables, thereby favoring responses consistent with the conjunctive interpretation.

Method

Participants

The research protocol was submitted to the Research Ethics Committee of the University of Trento, which determined that it did not pose risks to participants' well-being or rights and therefore did not require full ethical review (Prot. No. 2025-027ESA, University of Trento, Italy).

All participants were recruited on Prolific. Inclusion criteria required participants to be native speakers of English residing in the UK and to have a Prolific approval rate higher than 98%. For each experiment, the required sample size was determined by means of an a priori power analysis conducted through a simulation-based approach implemented in R (Green & MacLeod, 2016; Kumle et al., 2021).

For Experiment 1, the power analysis indicated that a total sample of 360 participants would provide 80% power to detect a small effect of the numerosity manipulation. We collected data from 380 participants, 12 of whom were excluded for failing the attention check. The final sample therefore comprised 368 participants: 187 in the Low-numerosity condition (97 reported their sex as female and 90 as male in their Prolific profiles; Mage = 46.81, SDage = 14.50) and 181 in the High-numerosity condition (88 reported their sex as female and 92 as male, while this information was marked as expired by Prolific for one participant; Mage = 47.87, SDage = 13.05). Discussion

The majority of participants' judgments were in line with the suppositional and inferential accounts, whereas only a smaller proportion supported the conjunctive interpretation of conditionals. Importantly, analyses of response patterns revealed a high degree of intra-individual consistency, with most participants exhibiting a clear preference for one interpretation rather than switching across trials.

The effect of total numerosity only approached statistical significance, despite the substantial difference between the two conditions (i.e., an order-of-magnitude difference). This suggests that, even if total numerosity might affect participants' responses, its impact is relatively limited within the type of experimental paradigm employed here.

Experiment 2

In Experiment 2, we contrasted the suppositional and inferential accounts, again using arbitrary conditionals. In doing so, we manipulated two factors.

The first was the relevance of the antecedent to the consequent, operationalized as the qualitative Bayesian evidential support (Crupi & Tentori, 2016) that the antecedent provides to the consequent: positive/neutral/negative relevance iff P(c|a)>/=/<P(c), respectively. We included this factor because, as discussed above, previous work has shown that it may influence participants' alignment with the accounts. It is important to clarify, however, that the conditionals in the neutralrelevance condition of our experiment are not missing-link conditionals. Although their antecedents and consequents are probabilistically independent (i.e., P(c|a) = P(c)), the scenarios nevertheless allow for a potential connection between them.

The second factor concerns the labeling of the expressions designating the complements of the antecedent and the consequent in the frequency-distribution tables. Specifically, for a conditional such as "If the toy is a triangle, it will be yellow," the distributions presented to participants, as in Experiment 1, referred to alternative predicates (i.e., 'circle' and 'blue') or to negations of the original predicates (i.e., 'not triangle' and 'not yellow'). Whereas the former framing is standard in the literature, the latter explicitly highlights the complements, potentially encouraging their consideration and, thereby, weakening a suppositional interpretation of the conditional. Although the conditionals used in our scenarios contained no negations and participants were presented with conditionals rather than arguments, our labeling manipulation bears some relation to research on the implicit negation effect (e.g., Evans & Handley, 1999; Vance & Oaksford, 2021). This effect refers to differences in endorsement rates for logically equivalent conditional inferences depending on whether a negated category is instantiated by an affirmative member of a contrast set or by an explicit negation. These findings prompted us to examine whether participants' interpretations of the conditionals would change when the predicates in the second row or second column of the contingency tables were labeled with either complements of the predicates used in the conditionals or their explicit negations. Finally, to enhance generalizability, we included both low-and high-numerosity scenarios from Experiment 1.

Method

Participants

The a priori power analysis indicated that a sample of 280 participants would provide 84% power to detect a small interaction effect between the two experimental variables (i.e., relevance and complement labels conditions). We collected a total of 340 participants, of whom 45 were excluded for having failed at least one attention check, leaving a final sample of 295 participants (157 reported their sex as female and 137 as male in their Prolific profiles, while one participant chose not to disclose this information to Prolific; Mage = 45.15, SDage = 13.03). Participants were compensated with £1.00.

Stimuli and Experimental Design

Experiment 2 employed a 2 × 3 design crossing complement labels (between subjects: alternative predicate vs. predicate negation) with relevance (within subjects: negative relevance vs. irrelevance vs. positive relevance). As noted above, numerosity (low vs. high) was also manipulated between subjects to enhance generalizability; however, given its non-significant effect in Experiment 1, it was not included as a primary factor in the analyses of Experiment 2.

To contrast the suppositional and inferential accounts, we generated four pairs of distributions for each level of relevance. Specifically, four distributions more closely aligned with the suppositional account instantiated negative relevance, four irrelevance, and four positive relevance between antecedent and consequent. By definition, all distributions consistent with the inferential account necessarily instantiated positive relevance. The two accounts were dissociated by pairing a distribution that violated at least one modal requirement of both inferential models with a distribution that, although satisfying all modal requirements of the inferential models, had a lower P(c|a). The former should be chosen according to the suppositional account, whereas the latter should be selected according to the inferential account. Notably, among the possible pairings, we prioritized those exhibiting the largest quantitative differences. To rule out a possible effect of the conjunctive interpretation, the value of P(ac) was held constant across the two distributions within each pair (see Table S4 for the exact distributions and the corresponding values relevant to the dissociation).

Participants were randomly assigned to one of the four conditions defined by the combination of the two between-subjects factors. Each participant viewed a total of 15 scenarios: 12 target pairs of distributions contrasting the suppositional and inferential accounts, and three attention checks (i.e., as specified in the General Method, scenarios including one distribution endorsed by all accounts considered). Scenarios were presented in randomized order, with one attention check appearing after every four target pairs.

Results

The logistic mixed model showed that participants' responses were more in line with the suppositional account than with the inferential one (68% vs. 32%, respectively), as indicated by the significant intercept of the model, OR = 0.13, p < .001 (95% CI [0.08, 0.22]; see the central portion of Figure 2). The relevance condition showed a mildly significant effect on participants' choice, p = .045, likely driven by the reduced tendency to choose the table aligned with the suppositional account when the antecedent and the consequent were negatively related (67%), compared with conditions of irrelevance (69%) or positive relevance (70%). However, after Bonferroni correction for post hoc comparisons, none of these contrasts reached significance (all ps ≥ .061), and responses in line with the suppositional account remained significantly more frequent than inferential responses at all levels of relevance (Bonferroni-corrected ps for the intercept < .001). The complement labels condition and its interaction with relevance condition were not significant (p = .216 and p = .088, respectively). The variance of the random intercept associated with total numerosity was estimated as zero, indicating no detectable variability attributable to this factor. 6As in Experiment 1, the number of participants providing consistent answers (N = 149, of which 115 in line with the suppositional account and 34 with the inferential one) was significantly greater than the number of participants providing inconsistent answers (N = 29), p < .001 (see the central portion of Figure 3). Such tendency toward consistent responding was similar in the two complement conditions (90 consistent vs. 16 inconsistent participants and 59 consistent vs. 13 inconsistent participants, respectively), χ²(1) = 0.28, p = .600.

Discussion

The primary finding of Experiment 2 is that participants' judgments were significantly and consistently more aligned with the suppositional account.

As in Experiment 1, the total numerosity of the distributions did not influence participants' interpretations of the conditionals. Nor did the label used in the frequency-distribution tables. The latter result is consistent with the probabilistic contrast-set explanation of the implicit negation effect advanced by Vance and Oaksford (2021), which predicts that the use of implicit rather than explicit negation should affect conditional judgments only when the corresponding probabilities differ. Under the binary interpretation instantiated in our experiment (where 'circle' was coextensive with 'not triangle' and 'blue' with 'not yellow'), the two framings pick out the same events and thus convey the same probabilistic information; they would therefore be expected to yield the same pattern of responses.

Finally, the relevance manipulation had only a weak effect. Overall, endorsing a suppositional view of arbitrary conditionals was dominant. Nonetheless, participants selected the suppositional distribution slightly less often when the antecedent provided negative support to the consequent, suggesting that at least some participants perceived this pattern as problematic for the acceptability of the conditional.

Experiment 3

In Experiment 3, we examined whether the results of Experiment 2 extend to causal conditionals -that is, conditionals conveying a diagnostic or predictive dependency between antecedent and consequent. Although the suppositional and inferential accounts are, in principle, formulated to apply to conditionals independently of their content, this may not fully hold from a psychological point of view, as people may align with one account or the other depending on the type of conditional being evaluated. In particular, when reasoning about arbitrary conditionals a suppositional interpretation may suffice, but when the conditional expresses a causal relation, individuals may resort to a more restrictive interpretation, which requires an inferential dependency between antecedent and consequent.

Specifically, we further generalized our investigation of causal conditionals by presenting participants with either predictive conditionals, featuring an enabling cause in the antecedent and one of its possible effects in the consequent (e.g., "If the machinery is jammed, then the package will leak"), or diagnostic conditionals, which presented an effect in the antecedent and a potential enabling cause in the consequent (e.g., "If the package is leaking, then the machinery was jammed"). 7 Evans, Handley, Hadjchristidis, et al. (2007) provide empirical evidence that both forms of conditionals are evaluated in line with the suppositional account. However, the methodology employed in that study exhibits several of the limitations outlined in our introduction (in particular, the ambiguity related to the question on the probability of the conditional to be true).

Method

Participants

The a priori power analysis indicated that a sample of 360 participants would provide 80% power to detect a small main effect of the experimental condition (predictive vs. diagnostic form of the conditional). We collected a total sample of 401 participants, from whom 44 were excluded for having failed the attention check. The final sample therefore comprised 357 participants: 181 in the Predictive condition (87 reported their sex as female and 93 as male in their Prolific profiles, while one participant chose not to disclose this information to Prolific; Mage = 45.66, SDage = 12.99) and 176 in the Diagnostic condition (71 reported their sex as female and 103 as male in their Prolific profiles; one participant chose not to disclose this information to Prolific, while Prolific marked it as expired for another participant; Mage = 46.33, SDage = 13.85). Participants were compensated with £0.63.

Stimuli

For Experiment 3, we generated five scenarios, each presented in both a predictive and a diagnostic version. The scenarios depicted different types of accidents in which the antecedent and consequent elements of the conditionals could be clearly identified as causes and effects. Particular care was taken to ensure that the five scenarios were structurally equivalent and, above all, isomorphic between the diagnostic and predictive versions, in order to reduce potential confounds.

In particular, the elements constituting the antecedent and the consequent of the conditional in the two versions were the same, only switched in their role. An example of the scenarios is reported below, while all scenarios are reported in Table S12.

His task is to identify any integrity issues early.

While on duty, he is informed of an alert, but he doesn't know the details.

Given this, Sam thinks: "If the machinery is jammed, then the package will leak."

While on duty, he is informed of an alert, but he doesn't know the details.

Given this, Sam thinks: "If the package is leaking, then the machinery was jammed."

The total numerosity of each distribution was always set to 200, as they were intended to reflect the experience of a professional in the field described in the scenario. Moreover, since the complements of the antecedent and the consequent of the conditionals employed in Experiment 3 could refer to multiple contents, and given that we did not find any effect of the complement label in Experiment 2, when presenting the distributions we always referred to simple negations of the antecedent and the consequent. Additionally, as in Experiment 2, the value of P(ac) was identical across the two distributions within each pair, ensuring that participants' choices were not driven by a conjunctive interpretation of the conditionals.

Although under a suppositional interpretation the pattern of confirmation or disconfirmation between antecedent and consequent should not affect the acceptability of a conditional, in Experiment 3 (unlike in Experiment 2) all distributions aligned with the suppositional account exhibited positive relevance between them. The rationale for this choice is that it might seem implausible for professionals, such as the character of our scenarios, to assert a causal conditional within their domain of expertise when antecedent and consequent stand in a relation of negative relevance or even irrelevance. We further matched each selected pair of distributions to the content for which it appeared most plausible. For instance, the pair featuring the lowest probabilities for the antecedent and the consequent was assigned to scenarios involving highly specialized industries, where the corresponding accidents would reasonably be expected to occur infrequently.

Finally, the distributions presented in the predictive and diagnostic versions were identical, differing only in the arrangement of rows and columns (i.e., in the predictive version, the presence / absence of the cause was represented in the rows and the presence / absence of the effect in the columns; whereas, in the diagnostic version, this arrangement was reversed). This ensured that the values of the relevant probabilistic measures were identical across the two versions of the conditional. Each pair of distributions was used only once. (As shown in the Supplementary Materials, for both the predictive and diagnostic conditionals used in Experiment 3, the predictions derived from power PC never diverge from the common predictions of the two inferentialist models considered.)

The experimental design included a single between-subjects factor (conditional form, 2 levels: predictive vs. diagnostic), with participants being randomly assigned to the predictive or diagnostic version of the task and each viewing a total of five scenarios (four target scenarios in which the suppositional and inferential accounts were contrasted and one attention check, always presented at the end).

Results

The logistic mixed model revealed that participants were more likely to respond in line with the inferential account than with the suppositional account (69% vs. 31%, respectively), as indicated by the significant intercept of the model, OR = 3.83, p < .001 (95% CI [2.73, 5.37]; see the right portion of Figure 2). The model also revealed a significant increase in choices in line with the inferential account when the conditional was presented in a predictive (74%) rather than a diagnostic form (64%), OR = 2.27, p = .002 (95% CI [1.34, 3.84]). Nevertheless, the choices in line with the inferential account remained predominant in both conditions (Bonferroni-corrected ps of the intercept < .001).

As in Experiments 1 and 2, the number of consistent participants (N = 191, of which 36 aligned with the suppositional account and 155 with the inferential one) significantly exceeded the number of inconsistent ones (N = 68), p < .001. While consistent responding was observed in both experimental conditions, it was slightly more pronounced in the Predictive (110 consistent vs. 29 inconsistent participants) than in the Diagnostic condition (81 consistent vs. 39 inconsistent participants), resulting in a significant chi-square test of independence, χ²(1) = 4.50, p = .034 (see the right portion of Figure 3).

Discussion

The results of Experiment 3 indicate that participants predominantly and consistently favored the inferential interpretation of causal conditionals, regardless of whether they were predictive or diagnostic. The finding that this trend was slightly more pronounced for predictive conditionals may indicate that these conditionals are cognitively easier to process than diagnostic ones, as their structure mirrors the temporal direction of the underlying causal relation, thereby reducing noise. Supporting this interpretation, prior research shows that individuals sometimes mentally reverse the antecedent and consequent of diagnostic conditionals (Weidenfeld et al., 2005).

General Discussion

Experiment 1 provides evidence that most individuals go beyond a purely conjunctive interpretation of conditionals and systematically favor normatively motivated interpretations.

Experiments 2 and 3, in turn, pose a symmetrical and unprecedented challenge to the two normative accounts under consideration by showing that participants' interpretations are not constant but, instead, sensitive to the semantic and structural features of the conditional at issue. Specifically, when the association between antecedent and consequent is arbitrary, judgments reliably align with the predictions of the suppositional account. By contrast, when the antecedent and consequent plausibly instantiate a causal link, regardless of its predictive or diagnostic direction, participants' judgments are better aligned with the inferential account. This pattern of results suggests that, for arbitrary conditionals, participants focused only on the first row of the contingency tables, whereas for causal conditionals they attended to the information contained in both rows: namely, to what happened both in the presence and in the absence of the effect in diagnostic conditionals and to what happened both in the presence and in the absence of the cause in predictive conditionals. 8 The obtained findings offer a comprehensive picture to reconcile a literature that has long appeared theoretically and empirically divided. Prior studies have alternately supported either the suppositional or the inferential account. We contend that this oscillation reflects not only the methodological limitations discussed above, but also a systematic sensitivity to the type of conditional under investigation. What appeared to be empirical disagreement can, in our view, be traced to previously unrecognized heterogeneity in the methods and stimuli employed. Critically, we have identified a dissociation between the suppositional and inferential interpretations within 8 Our task elicited a forced choice between two distributions rather than a quantitative assessment of how much they differed, as we considered the former type of judgment to be more reliable and robust. However, it is worth clarifying that the absolute differences between the values assigned by the competing accounts to the distributions being compared cannot explain the reported response patterns. Indeed, in the negative-relevance and irrelevance conditions of Experiment 2, the differences in P(c|a) were smaller than those yielded by the inferentialist models (particularly DM), yet most responses aligned with the suppositional account. By extending our analysis beyond arbitrary or missing-link conditionals and showing that, for causal conditionals, the same interpretation robustly generalizes across both predictive and diagnostic cases, we have not only advanced the existing debate, but also placed it on firmer and more comprehensive empirical grounds, thereby clarifying the explanatory reach of the competing accounts.

Refinements of current models aimed at achieving a more comprehensive characterization of conditionals could proceed in several directions. In particular, although both suppositional and inferential accounts have been proved to capture aspects of how conditional assessment operates in human cognition under specific circumstances, they require substantive revision and further theoretical development to accommodate the systematic variability observed across different types of conditionals. A key strategy for the uncompromising suppositionalist seeking to preserve their analysis as the uniquely correct account of the cognitive representation of conditionals could be to accommodate the data favoring inferentialism (i.e., those from Experiment 3) as driven by pragmatic factors. 9 However, this stance is unlikely to succeed: given our experimental procedure, there is no compelling reason to suppose that participants' responses reflect assessments of conversational appropriateness in Experiment 3 but not in Experiment 2. Similarly, the uncompromising inferentialist might attempt to defend their position and question the data favoring suppositionalism (i.e., those from Experiment 2), by arguing that the experimental procedures were not sufficiently effective at disentangling the tasks of assessing conditional acceptability from that of estimating the posterior probability of the consequent given the antecedent. Here again, the complaint would be hard to maintain: there is no compelling reason to think that participants responded as if prompted to translate a conditional sentence into a conditional probability in Experiment 2 but not in Experiment 3. A straightforward interpretation of our results is a third possibility, which is viable and no less plausible, although perhaps bound to disappoint purists: the suppositional and inferentialist approaches can be combined, much as they coexist in logic (e.g., Crupi & Iacona, 2022b , 2023; Raidl & Rott, 2024). On this view, nontruth-functional conditionals do belong as elements of human cognition in more than one form: individuals would have access to both suppositional and inferential representations, recruiting one or the other depending on contextual and semantic cues, such as the presence or absence of credible and robust causal relations. Participants' preference for inferential distributions as representations of the acceptability of causal but not arbitrary conditionals would reflect sensitivity to the existence and possibly the strength of the causal dependencies involved. This interpretation is consistent with evidence from Ali et al. (2011) that people do not rely only on the logical and linguistic form of a conditional, but construct a representation that is sensitive to the direction of the underlying causal relation and structurally analogous to a Causal Bayes net (Pearl, 1988 (Pearl, , 2000;; see Oaksford & Chater, 2020a, for the proposal that Causal Bayes nets can provide a cognitive implementation of inferentialism). Apparent inconsistencies in the literature, with some experimental studies supporting the suppositional account and others the inferential account, would then reflect shifts in the interpretive strategy predominantly adopted by participants rather than misunderstandings or instability in their hypothetical reasoning competence.

Whatever the future trajectory of the theoretical debate on the interpretation of conditionals, our findings carry significant practical implications. For example, they can inform research in more applied domains, such as explainable artificial intelligence (XAI). Systems designed to enhance the interpretability of a model's output -whether in decision-support tools, diagnostic systems, or automated reasoning platforms -often generate or evaluate explanations expressed in conditional form (commonly referred to as "rule-based explanations"; Bodria et al., 2023). Effective functioning of these systems requires a solid understanding of how humans interpret "if-then" constructions, as well as which factors shape such interpretations. Our results suggest that these are not uniform, but rather systematically depend on perceived semantic features and causal relations. Incorporating this sensitivity into AI systems could enhance their alignment with human reasoning patterns, thereby improving both interpretability and user trust. More broadly, understanding when individuals adopt a suppositional versus an inferential reading may contribute to the design of explanation strategies that are cognitively natural and context-sensitive.

Constraints on Generality

As described in the Method section of Experiment 1, to minimize potential linguistic misunderstandings of the stimuli, which could have been particularly problematic in a study of this kind, we recruited native speakers of English residing in the UK through Prolific. We chose this platform because, although online samples cannot generally be regarded as fully representative of the broader population, Prolific's UK participant pool is particularly large and heterogeneous.

Importantly, we have no theoretical reason to believe that the phenomenon investigated here, namely the interpretation of conditionals, depends substantially on demographic or cultural factors.

We therefore expect the findings from our three experiments to generalize to a broader population of adults, although this remains to be confirmed empirically.

A potential theoretical limitation of the present work is that we treated the inferential account as a unitary framework, even though, as noted in the Introduction, it encompasses a range of theoretically distinct models. An important next step would therefore be to compare the extent to which lay intuitions align with the specific predictions of various inferential models, rather than with the inferential approach as a whole. Moreover, the present work was limited to the investigation of indicative conditionals, with positive atomic formulas as antecedent and consequent, but the methodology we have introduced could be applied to other types of conditionals, including concessives and counterfactuals, in order to assess whether similar patterns of dissociation persist across a broader range of constructions.

Future research could also more systematically examine whether endorsement of the two interpretations scales proportionally with expectations of the strength of association -causal or otherwise -between antecedent and consequent. In addition, it would be interesting to use the experimental paradigm described in the present study to compare conditionals beyond those considered in our experiments (i.e., arbitrary conditionals and conditionals whose antecedents and consequents are likely to be perceived as directly causally related). Among these, relevant cases might include causal conditionals in which the antecedent and consequent are only indirectly linked, as well as conditionals expressing habits, personal dispositions, or social norms. As argued by Oaksford and Chater (2020a), the extent to which the acceptability patterns of these conditionals align with the predictions of various models may depend on the causal structure underlying the relation between the antecedent and the consequent, as well as on the perceived strength of the relevant dependencies. We also expect that another relevant factor, related to but not necessarily overlapping with those mentioned above, is the perceived robustness of the dependencies at issue, specifically, the extent to which conditionals are perceived to express general regularities rather than relations that hold only in particular contexts. These conditionals are often labelled basic in the literature. However, we prefer to avoid this term, not only because it is used with slightly different meanings by different authors but, more importantly, because it may suggest that these conditionals have a more fundamental status or primacy than they in fact do.

Our paradigm was partly inspired by Experiment 2 inEvans et al. (1996), in which participants were presented with a series of conditionals involving colored symbols and asked to complete empty grids with frequency distributions that would render each conditional either true or false, depending on the experimental condition. However, the distributions elicited in that experiment are compatible with all the accounts considered in the present work, thereby limiting the extent to which the task can discriminate among them.

We take these judgments to reflect an empirical notion of acceptability that is intelligible in its own right and relevant to the debate about the interpretation of conditionals, without first having to be characterized in epistemic, semantic, and pragmatic terms.

Since the inferential models considered are more restrictive than the suppositional ones, no distribution exists in which the probability orderings required by the latter are violated while those required by the former are respected.

We also tested whether including total numerosity as a factor, in interaction with relevance and complement label, affected the model results, but it did not.

We refer to enabling causes and possible effects because these conditionals did not express deterministic relations, but rather defeasible connections between events.

According to the possible argument involved here, an asserted conditional would have evidential relevance between a and c as a pragmatic implicature, which is not, however, encoded in the semantics. Missing-link conditionals, for instance, are rejected by suppositionalists as pragmatically defective in this sense.
