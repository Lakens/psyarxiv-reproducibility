How Ethics Approval Check works

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Previous research on emotion regulation (ER) has primarily focused on individual strategies and their association with well-being and psychopathology. Recent frameworks emphasize a context-sensitive, goaldependent approach, defining ER flexibility as the ability to adaptively adjust ER strategies based on contextual demands and personal goals. Despite growing evidence for its relevance, a concise self-report measure designed to capture trait-level, strategy-independent ER flexibility has been lacking. To address this gap, we developed the Flexible Emotion Regulation Scale (FlexER-Scale) and validated it using data from four independent samples (N = 1,019). Exploratory factor analysis (EFA) and confirmatory factor analysis (CFA) in an independent sample examined the scale's structure; criterion validity was assessed via correlations with the WHO-5 Well-Being Index and the Emotion Regulation Questionnaire (ERQ). The final 10-item FlexER-Scale demonstrated good psychometric properties, including satisfactory item discrimination and high internal consistency (α = .85). EFA suggested a two-factor structure differentiating hedonic and contra-hedonic ER flexibility, which was supported by CFA. The FlexER-Scale showed a significant positive correlation with psychological well-being, driven by the hedonic factor. Small but significant correlations with habitual reappraisal and suppression use provided initial evidence for discriminant validity. The FlexER-Scale is a promising tool for assessing ER flexibility, offering a concise alternative to existing measures by capturing adaptive regulatory variability without relying on predefined strategies. Future research should examine its construct validity, longitudinal stability, and predictive validity. Given that the validation was based on predominantly student samples from a German-speaking context, broader generalizability remains to be established.

1. Introduction

Emotions guide individuals toward goal attainment by providing feedback on progress and potential threats, but can also hinder success, necessitating regulation (Gross, 2014). Emotion regulation (ER) refers to processes by which individuals modify emotional experience, expression, or physiology (Gross, 1998). Early ER research emphasized single regulation strategies, whereas the more recent Canonical Process Model of Emotion Regulation conceptualizes ER as a multilevel, dynamic process involving the identification of regulatory goals, selection of strategies, implementation of regulation tactics, and continuous monitoring of regulatory success (Ford et al., 2019). Accordingly, ER can occur via the strategies situation selection (e.g., avoidance), situation modification (e.g., problem-solving), attentional deployment (e.g., distraction), cognitive change (e.g., reinterpretation, distancing, acceptance, rumination), and response modulation (e.g., expression or suppression of the emotional reaction, experiential avoidance; Gross, 1998; Powers & LaBar, 2019). Initially, these strategies were differentiated as adaptive and maladaptive in (short-term) effectiveness and relation to psychopathology (Aldao et al., 2010; Dörfel et al., 2014; Webb et al., 2012; Zaehringer et al., 2020). However, accumulating evidence suggests that flexibility, that is, the ability to use diverse strategies as situational demands change, is more beneficial than rigid reliance on a single strategy (see for instance Aldao, 2013; Kashdan et al., 2015; Troy et al., 2013). Indeed, studies show that individuals who use a broader repertoire of strategies, including both putatively adaptive and maladaptive ones, tend to show lower risk for psychopathology, whereas those using only maladaptive strategies or few strategies overall are at higher risk (Dixon-Gordon et al., 2015; Lougheed & Hollenstein, 2012; Southward et al., 2018). This recognition has shifted attention toward emotion regulation flexibilitythe adaptive adjustment of regulatory strategies to contextual demands (Aldao et al., 2015; Bonanno & Burton, 2013). Emotion regulation flexibility describes the ability to select and modify strategies from a diverse repertoire of ER approaches according to changing contexts and personally meaningful goals (Aldao & Tull, 2015). Effective ER therefore involves achieving an optimal balance of emotional dynamics that support both short-and long-term adaptation (Bonanno & Burton, 2013; Sheppes et al., 2014; Troy & Mauss, 2014).

A key framework for understanding regulatory goals is provided by Tamir (2016), who distinguishes between subordinate goals, typically hedonic (e.g., increasing or reducing specific emotions, such as more happiness or less anxiety), and superordinate goals, which may be hedonic or instrumental, such as performing well or maintaining relationships (see also Aldao et al., 2015). Depending on the context, individuals may even pursue contra-hedonic goals (e.g., intensifying negative emotions) if doing so supports a higher-order goal (Tamir et al., 2008 (Tamir et al., , 2015)). This highlights an important distinction from coping, which primarily aims to reduce stress responses, whereas ER may involve temporarily amplifying negative emotions to achieve meaningful goals (Ford et al., 2019). Hollenstein's Flex 3 model (Hollenstein et al., 2013; 2015) further conceptualizes flexibility across three time scales: micro-level moment-to-moment variability, meso-level behavioral adjustments across contexts (aligning with Aldao's definition of ER flexibility), and macro-level trait-like differences in habitual flexibility. Similarly, Bonanno and Burton (2013) emphasize sensitivity to context, a diverse repertoire of strategies, and adaptive monitoring of regulatory success as central components of emotion regulation flexibility.

To assess ER flexibility across time scales, researchers recommend a multimethod approach, including experimental, momentary, and self-report measures (Aldao et al., 2015; Barnow et al., 2020; Bonanno & Burton, 2013; English & Eldesouky, 2020; Pruessner et al., 2020). Ecological Momentary Assessment (EMA) captures situational, moment-to-moment variability and context-dependent fluctuations in ER success, whereas self-report scales assess more stable, trait-like flexibility. Several self-report instruments related to regulatory flexibility have been proposed. For example, the Coping Flexibility Scale (Kato, 2012) assesses the ability to modify coping strategies when they are ineffective, whereas the Flexible Regulation of Emotional Expression (FREE) Scale (Burton & Bonanno, 2016; Gonzalez-Escamilla et al., 2022) measures the ability to enhance or suppress emotional expression depending on situational demands. More recently, Monsoon et al. (2022) introduced the Emotion Regulation Flexibility Questionnaire (ERFQ), a brief self-report measure assessing individuals' perceived ability to flexibly select, modify, and maintain regulation strategies across contexts.

Other instruments assess individuals' repertoire of ER strategies or specific regulatory tactics (De France & Hollenstein, 2017; Nelis et al., 2011). Although these measures capture important aspects of ER flexibility, they typically focus on coping processes, expressive regulation, or general perceptions of strategy use, rather than flexible, context-dependent adaptation to personal goals. Moreover, available flexibility measures are often lengthy, strategy-specific, or restricted to experimental contexts, limiting their applicability in larger or clinical samples. Thus, at the time of our study, no brief self-report scale existed that assessed trait-level ER flexibility across contexts without relying on predefined strategies.

To address this gap, we developed the Flexible Emotion Regulation Scale (FlexER-Scale) as a concise, context-sensitive measure of adaptive, goal-directed, trait-level emotion regulation flexibility. Its development was guided by established theoretical frameworks on ER flexibility and goal-directed emotion regulation (Aldao et al., 2015; Aldao & Tull, 2015; Bonanno & Burton, 2013; Tamir, 2016). Our objective was to create items that assess emotion regulation across different situational contexts, covering both negative and positive emotions and reflecting hedonic and contra-hedonic regulation goals (context sensitivity). The scale also captures variability in strategy use (repertoire) and the ability to adaptively switch strategies when current ones prove ineffective (responsiveness to feedback). The FlexER-Scale is designed to be strategy-independent in that it does not assess the frequency or effectiveness of any specific, predefined strategy. Rather, it captures the perceived ability to vary and adjust regulatory approaches in response to situational demands and personal goalsincluding items that reflect strategy breadth and switching tendencies, which are inherent features of flexibility as a construct.

Finally, we examined associations between flexible emotion regulation and psychological well-being (WHO-5

Well-Being Index) as well as habitual emotion regulation strategy use (Emotion Regulation Questionnaire; ERQ) to evaluate the scale's criterion validity, assuming that greater flexibility is associated with greater wellbeing and reappraisal use and inversely related to suppression use. The following sections describe the scale's development, psychometric properties, and validation results.

2. Method

>Method

2.1 Participants and Procedure

2.1.1 Preliminary Item Development and Reduction

First, one of the authors (DD) generated an initial pool of 81 items based on expert interviews with a clinical psychologist and two differential psychologists (including AG) and by reviewing items from existing ER and coping flexibility questionnaires (Berking & Znoj, 2008; Dennis & Vander Wal, 2009; Ehring et al., 2008; Gross & John, 2003; Kato, 2012; Martin & Rubin, 1995; Vriezekolk et al., 2012). Second, the items were rephrased to align with the concept of emotion regulation flexibility and the taxonomy of regulation goals (Aldao et al., 2015; Tamir, 2016). Third, five experts independently rated the 81 items regarding their relevance for assessing emotion regulation flexibility using a binary yes/no scale. Items were retained if at least four out of five experts endorsed them with a "yes". Due to incomplete ratings for 12 items, inter-rater agreement analyses were conducted on the subset of 69 items with complete ratings from all five experts. Unanimous agreement among all five raters was observed for 31 of these 69 items (44.9%). Averaged across all 10 possible rater pairs, mean pairwise percentage agreement was 71.3%, indicating moderate-to-high inter-rater agreement. However, chance-corrected agreement indicated only slight agreement (Fleiss' κ = 0.083; Fleiss, 1971; Landis & Koch, 1977). This discrepancy is likely attributable to a high base rate of "yes" responses (80.6%), which inflates expected agreement by chance (see, e.g., Feinstein & Cicchetti, 1990). Fourth, 53 items were retained for further refinement. These items were screened for duplicates, translated into German, and slightly revised for clarity. This process yielded a preliminary 41-item version rated on a 5-point Likert scale (1 = completely true,3 = neutral,5 = not true at all).

In Sample 1, an online survey was conducted with 273 university students from various disciplines to evaluate item properties of the preliminary 41 items. Based on indices of careless response behavior (person SD, maximum long string), 118 participants were excluded, leaving N = 145 complete datasets that included both the FlexER items and the Coping Flexibility Scale (Kato, 2012; see Table 1). The relatively high exclusion rate in the initial sample may be related to the use of online and participant pool recruitment, which can increase inattentive responding. These data included responses with complete answers on both FlexER items and the Coping Flexibility Scale (Kato, 2012) and were used to examine item characteristics (item difficulty and discrimination), and to ensure item-level conceptual divergence from general coping flexibility (Kato, 2012) in order to filter out unspecific items prior to finale scale construction. Additionally, items were inspected for content validity, ensuring that they covered both positive and negative valence as well as up-and downregulation of emotions. As a result, the number of items was reduced to a longer version with 26 items and a short version with 12 items (see Supplement 1, Tables S1, S2, and Supplement 2, Table S3).

The short version was validated in a pooled Sample 2 of N = 1,280 (final N = 1,100 with complete data) drawn from multiple studies conducted in our lab and collaborating laboratories (see Table 1). Analyses of item characteristics and factor structure (see Supplement 2, Tables S4-S6) led to the retention of eight items and rewording of two others to improve item difficulty and ensure a balanced representation of emotional valence and regulatory goals. The response format was changed from a 5-point to a 4-point Likert scale to improve clarity and consistency. This resulted in the final 10-item FlexER-Scale, which was then subjected to a validation analysis.

2.1.2 Validation of the final 10-item version

The FlexER-Scale was validated using data from four independent samples (Sample 3, 4, 5, and 6; total N = 1,019). Sample 3 (N = 356) was obtained from an online questionnaire study at two German universities specifically designed to validate the final version of the scale. It included students from various disciplines and university employees (M = 30.2 years, SD = 12.0; 224 female). Sample 4 (N = 375) comprised rescue service employees who participated in a study on psychological factors relevant to their profession (M = 32.5 years, SD = 9.9, 141 female). Sample 5 (N = 126) comprised mainly psychology students and was collected within a study on cognitive and affective discounting (Scheffel et al., 2023; Zerna et al., 2023; M = 22.5 years, SD = 3.0, 104 female). Across all studies, participants could skip individual items. Those with missing responses or indicators of careless response behavior were excluded. 2.3 Statistical Analyses

All analyses were conducted in R (R Core Team, 2024) and RStudio (RStudio Team, 2020). The following packages were used: dplyr (Wickham et al., 2023), foreign (R. Core Team, 2023), ggplot (Wickham, 2016), GPArotation (Bernaards & Jennrich, 2005), here (Müller, 2020), MVN (Korkmaz et al., 2014), nFactors (Raiche & Magis, 2022), psych (Revelle, 2024), psychometric (Fletcher, 2023), renv (Ushey & Wickham, 2024), reshape2 (Wickham, 2007), tibble (Müller & Wickham, 2023), tidyr (Wickham et al., 2024), and tidyverse (Wickham et al., 2019). Data from all studies were pooled, and cases with missing FlexER responses were excluded. Response patterns were examined by checking whether participants responded with "1" or "4" across all items, and by computing the maximum long string (Niessen et al., 2016), and the person standard deviation, which reflects response variability across items (with zero indicating identical responses on all items).

Descriptive statistics were computed for each item, including item difficulty (Pi Dahl), item discrimination (itemtotal-correlation rit), and internal consistency (Cronbach's α and McDonald's ω).

To examine the factor structure, we conducted an exploratory factor analysis (EFA) using maximumlikelihood extraction with oblimin rotation. Sampling adequacy was assessed via the Kaiser-Meyer-Olkin (KMO) criterion (Kaiser & Rice, 1974) and Barlett's test (Bartlett, 1937). The number of factors was determined through parallel analysis, a method agreement procedure, and additional criteria including the Very Simple Structure (VSS) criterion, Velicer's Minimum Average Partial (MAP) criterion, Root Mean Square Error of Approximation (RMSEA), and Bayesian Information Criterion (BIC). The factor structure was subsequently tested in an independent sample using a confirmatory factor analysis (CFA). A τ-congeneric measurement model was estimated using the R-package lavaan (Rosseel, 2012) with the Weighted Least Squares Mean and Variance Adjusted (WLSMV) estimator, appropriate for ordinal Likert-scale data.

Criterion validity was assessed via Spearman correlations between the FlexER, WHO-5 well-being, and the Emotion Regulation Questionnaire (ERQ; Gross & John, 2003). The analyses reported in this study were not preregistered. Based on previous literature, we expected positive associations between ER flexibility, psychological well-being, and reappraisal use, and a negative association with suppression use; however, no specific a priori effect size was specified.

3.2 Exploratory Factor Analysis

The exploratory factor analysis was conducted in a pooled sample (Samples 3, 4 and 5; total N = 680; 416 female, Mage = 28.1 years, SD = 7.9). First, the suitability of the data for factor analysis was assessed using the Kaiser-Meyer-Olkin (KMO) test and Barlett's test. The KMO value of.868 indicated meritorious sampling adequacy (KMO ≥ .80), and Barlett's test (χ²(45) = 2850.16, p < .001) confirmed that a factor analysis was appropriate. A parallel analysis, which is widely considered the best available approach for determining the number of factors (e.g., Ruscio & Roche, 2012), suggested a two-factor solution. The first three eigenvalues were 3.90, 0.97, and 0.12, indicating a clear drop after the second eigenvalue (see Supplement 3, Figure S1).

Additional criteria (VSS, MAP, BIC, RMSEA) showed a mixed picture (see Supplement 3, Table S8). This approach combines several factor-retention methods, which differ in quality and assumptions, and identifies the factor solution most often supported across methods. It was revealed that 9 out of 21 tests supported the two factor structure, which was the highest (see Supplement 3, Figure S2).

3.3 Confirmatory Factor Analysis

The two-factor structure was evaluated in an independent sample (Sample 6, N = 162; 123 female, Mage = 23.3 years, SD = 4.9; see Table 1). To test the two-factor structure, a τ-congeneric measurement model was estimated using the R-package lavaan (Rosseel, 2012; see Seupplement 3, Figure S3). The first factor was defined by six items (1, 4, 5, 6, 7, and 10), while the second factor was defined by four items (2, 3, 8, and 9).

Given the ordinal nature of the data, the Weighted Least Squares Mean and Variance Adjusted (WLSMV) estimator was employed, which is robust to non-normality and appropriate for ordinal Likert-scale data (Beauducel & Herzberg, 2006; DiStefano & Morgan, 2014; Flora & Curran, 2004). The items were treated as ordered categorical variables to ensure accurate estimation of thresholds and factor loadings. Model fit was evaluated using common fit indices, including the Comparative Fit Index (CFI), Tucker-Lewis Index (TLI), Root Mean Square Error of Approximation (RMSEA) with its 90% confidence interval, and Standardized Root Mean Square Residual (SRMR).

The two-factor model demonstrated acceptable fit, though some indices approached rather than fully met conventional thresholds: χ²(34) = 74.403, p < .001, CFI = 0.945, TLI = 0.927, RMSEA = 0.086 (90% CI: 0.059-0.113), SRMR = 0.081 (see Supplement Table S9). CFI and TLI approached but did not fully meet the conventional threshold of 0.95, and RMSEA and SRMR were within acceptable ranges (Browne & Cudeck, 1992; Hu & Bentler, 1999; Kline, 2016). Although the χ²-test was significant, a post-hoc power analysis revealed a high statistical power of 1-β = 0.969 (based on α = .05, RMSEA = 0.086, df = 34, and N = 162).

However, the χ²-test is documented to be highly sensitive to sample size, potentially overestimating misfit when other indices indicate acceptable fit (Bergh, 2015; McHugh, 2013). Moreover, with N = 162, alternative fit indices may be subject to potential small-sample biases; for example, RMSEA tends to be upwardly biased while CFI and TLI tend to be downwardly biased relative to population values (Shi et al., 2019). The overall pattern across indices should therefore be considered rather than any single index in isolation. All items loaded significantly onto their respective factors (p < .001), with standardized loadings ranging from 0.482 to 0.880 for Factor 1 and 0.571 to 0.735 for Factor 2, indicating strong relationships between the items and their underlying constructs, while the correlation between the two factors was weak and non-significant (r = .171, p = .066).

Residual variances for the items ranged from 0.226 to 0.767, indicating varying levels of unexplained variance across items (see Supplement 3 Table S10 and Figure S3).

To further examine the dimensionality of the scale, we estimated a nested one-factor model in which all ten items were specified to load onto a single latent factor using the WLSMV estimator with ordered categorical indicators. The one-factor solution demonstrated poor fit: CFI = 0.616, TLI = 0.506, RMSEA = 0.224 (90% CI: 0.202 -0.247), and SRMR = 0.165, with CFI and TLI falling well below and RMSEA and SRMR substantially exceeding recommended thresholds for acceptable model fit (see Supplement Table S7). A χ²-difference test revealed that the two-factor model provided a significantly better fit than the one-factor model (Δχ²(1) = 59.722, p < .001).

3. 4 Criterion Validity

To assess criterion validity, we computed correlations between the two FlexER factors and the WHO-5 well-being score across all subsamples with available data for both measures (Sample 3, N = 255; Sample 4, N = 300; Sample 5, N = 125). We computed Spearman correlations as both variables were not normally distributed.

Thirteen participants with missing WHO-5 data were excluded, leaving N = 667 complete cases. The results showed a significant medium correlation of the FlexER factor 1 (hedonic ER flexibility) with WHO-5 (ρ = .34, p < .001), whereas FlexER factor 2 (contra-hedonic ER flexibility) was not significantly correlated (ρ = .04, p = .363; see Table 5).

To further assess criterion validity, we computed Spearman correlations between both FlexER factors and the two ERQ subscales across all subsamples with available data for both measures (Sample 3, N = 255; Sample 5, N = 125; Sample 6, N = 162), yielding a final sample of N = 528 after excluding incomplete cases.

Both FlexER factors showed small but significant positive correlations with ERQ Reappraisal (ρ = .12, p < .01, and ρ = .11, p < .01, respectively; see Table 5). Interestingly, FlexER factor 2 (contra-hedonic ER flexibility) showed a small but significant negative correlation with ERQ Suppression (ρ = -.15, p < .001; see Table 5).

4. Discussion

This study introduces the Flexible Emotion Regulation Scale (FlexER-Scale), a brief self-report measure of goal-dependent emotion regulation flexibility. Unlike previous measures that focus on specific regulation strategies, the FlexER-Scale assesses the adaptive, context-sensitive use of emotion regulation strategies to up-or down-regulate both positive and negative emotions. Its development was guided by theoretical frameworks that emphasize regulatory flexibility as a key determinant of psychological adjustment (Aldao et al., 2015; Bonanno & Burton, 2013; Tamir, 2016).

Our findings demonstrate satisfactory to good item characteristics. Item difficulty levels were acceptable, and most items closely aligned with the ideal difficulty range (however, there is some discussion on how to interpret item difficulty in (personality) trait measures; see Reise & Revicki, 2015). Item discrimination values indicate that the FlexER-Scale effectively differentiates between individuals with varying levels of selfreported ER flexibility. Our findings further provide evidence for the factor structure and reliability of the scale:

The parallel analysis indicated the distinctiveness of two latent constructs: a hedonic and a contra-hedonic ER flexibility factor. Although this pattern may initially appear counterintuitive, it aligns with research on goal-directed emotion regulation, which suggests that individuals may sometimes regulate emotions in seemingly paradoxical ways to achieve higher-order goals (Tamir, 2016). The confirmatory factor analysis (CFA) supported the two-factor structure identified in the exploratory factor analysis (EFA), with all items loading significantly onto their respective factors and adequate overall model fit.

The two-factor model also showed a significantly better fit compared to a one-factor model.

Notably, the exploratory factor analysis did not separate the theoretically proposed facets of ER flexibility such as strategy repertoire or switching tendencies. Instead, items referring to the availability and switching of strategies loaded on a common factor, suggesting a more general flexibility trait reflecting the perceived availability and adaptability of regulation strategies. In contrast, the second factor was primarily defined by items reflecting contra-hedonic regulation, such as reducing positive emotions or intensifying negative emotions when this serves a goal. This pattern is consistent with theoretical accounts of goal-directed emotion regulation and may indicate that the factor structure reflects differences in regulatory goals across emotional valence rather than differences in regulatory processes.

Criterion validity analyses indicated a positive association between FlexER scores and psychological well-being (WHO-5), consistent with prior findings linking emotion regulation flexibility to mental health and adaptive functioning (Bonanno & Burton, 2013; Southward et al., 2018). Importantly, only the hedonic ER flexibility factor showed a significant moderate positive association with well-being, while the contra-hedonic factor showed no significant association. This differential pattern is consistent with theoretical accounts suggesting that hedonic ER flexibility (which reflects the ability to regulate emotions in line with one's hedonic preferences) may more directly translate into subjective well-being. In contrast, contra-hedonic ER flexibility captures the ability to regulate emotions in seemingly paradoxical ways to serve higher-order goals, a capacity that may be less consistently tied to hedonic well-being and may even involve short-term affective costs. One could speculate that contra-hedonic ER is more closely related to social and professional success than to personal well-being. The moderate effect size of the hedonic factor, alongside the near zero association for the contra-hedonic factor, further supports the utility of retaining both factors rather than collapsing them into a single score, and suggests that the two dimensions may have distinct implications for psychological health.

However, the correlational nature of our study limits causal interpretations. Longitudinal and experimental designs are needed to clarify whether ER flexibility promotes well-being or vice versa.

The present study further sought to establish a first estimate of the criterion validity of the FlexER-Scale by examining its associations with the ERQ, a widely used measure of habitual strategy use. Both FlexER factors exhibited small but significant positive correlations with the ERQ Reappraisal subscale, while only

Factor 2 (contra-hedonic ER flexibility) showed a small negative correlation with the ERQ Suppression subscale. These findings are theoretically coherent and consistent with the conceptual distinction between the constructs assessed by the two instruments. The FlexER-Scale was explicitly designed as a strategyindependent, context-sensitive measure of emotion regulation flexibilitya higher-order meta-skill reflecting the adaptive selection and adjustment of regulatory strategies in response to situational demands and personal goals. Specifically, "strategy independence" refers to the absence of strategy-specificitythe scale does not privilege any particular regulatory approachrather than the absence of any reference to regulatory variability.

While some items implicitly reference strategy breadth or switching tendencies, this reflects an inherent feature of the construct itself rather than a conceptual inconsistency: flexibility, by definition, involves access to and the ability to shift between multiple regulatory approaches. The FlexER-Scale is nonetheless conceptually distinct from instruments such as the Coping Flexibility Scale (Kato, 2012) or the FREE Scale (Burton & Bonanno, 2016), which assess either the ability to modify ineffective coping strategies or the enhancement and suppression of emotional expression, respectively; the FlexER-Scale, by contrast, focuses explicitly on goaldirected, context-sensitive regulation across both hedonic and contra-hedonic goals. In contrast, the ERQ assesses the habitual frequency of two specific strategies-cognitive reappraisal and expressive suppressionwithout regard to contextual appropriateness. Given this difference in conceptual level, small correlations between the FlexER-Scale and ERQ subscales are not only expected but also desirable, as they indicate that the FlexER-Scale captures a broader, strategy-neutral dimension of regulatory variability rather than simply reflecting the frequency of any single strategy. The observed small correlation coefficients fall within the range typically reported in the literature for associations between strategy-specific and flexibility-based measures, as seen in prior work with self-report flexibility instruments such as the FREE Scale (Burton & Bonanno, 2016).

The positive direction of the correlations with ERQ Reappraisal suggests that individuals higher in ER flexibility may be more likely to draw on reappraisal as one tool within a broader adaptive repertoire, though the modest effect sizes reinforce that flexibility is not reducible to reappraisal tendency alone. Notably, only the contra-hedonic factor (Factor 2) showed a small negative correlation with ERQ Suppression. This pattern is theoretically meaningful: contra-hedonic ER flexibility involves the willingness to engage with or tolerate aversive emotional states in service of higher-order goals, which may be inversely related to the habitual tendency to suppress emotional expression. However, given the small magnitude of this association, it should be interpreted with caution and warrants further investigation.

Importantly, the generally low correlations between the FlexER-Scale and ERQ subscales provide evidence for the discriminant validity of the FlexER-Scale. This supports the view that emotion regulation flexibility, as operationalized by the FlexER-Scale, constitutes a conceptually distinct construct that is only partially overlapping with habitual strategy. Such findings are in line with theoretical models positing flexibility as a higher-order regulatory capacity, rather than a function of any single strategy use (Aldao et al., 2015; Bonanno & Burton, 2013; Sanchez-Lopez, 2021).

4.1 Limitations and Future Directions

Future research should further validate and refine the FlexER-Scale in several key areas. First, the stability of the factor structure should be examined in different populations. Further, its predictive validity should be examined across different psychological domains such as resilience, psychopathology, and adaptive coping, to clarify its relevance in clinical and non-clinical contexts. Second, assessing test-retest reliability will help determine the temporal stability of flexible emotion regulation and whether the scale reflects a trait-like or state-dependent construct. Third, cultural and contextual influences on the flexible use of emotion regulation strategies merit further investigation, as ER flexibility may manifest differently across cultures and may thus influence its generalizability and relation to well-being. The present validation was based on German-speaking samples, with a large proportion of students and relatively young participants. Accordingly, the generalizability of the findings to other age groups, cultural contexts, and clinical populations remains to be established. Fourth, future studies could complement traditional factor-analytic approaches with network-analytic methods to further explore the latent structure and interrelations of FlexER items. Integrating factor and network models may provide additional insights into the organization of emotion regulation flexibility (e.g., Song et al., 2023). Fifth, a further limitation concerns the reliance on self-report methodology. The FlexER-Scale captures individuals' perceived tendency to regulate emotions flexibly rather than directly observed regulatory behavior. Self-reports may be influenced by self-perception biases and therefore may not fully reflect moment-to-moment regulatory processes in real-world contexts. Future research should therefore combine the FlexER-Scale with multimethod approaches, such as behavioral paradigms, or experience-sampling methods, to more comprehensively assess emotion regulation flexibility. Sixth, future research may also examine how ER flexibility relates to broader individual difference variables and self-regulatory adaptability constructs. For example, attachment orientations have been linked to systematic differences in emotion regulation and may influence how flexibly individuals regulate emotions across interpersonal contexts (e.g., Domic-Siede et al., 2026). Investigating such associations may help to further situate the FlexER-Scale within a broader framework of personality and interpersonal functioning. Finally, studies should examine the neural and physiological correlates of ER flexibility.

Identifying brain activity and physiological markers could deepen our understanding of the mechanisms underlying adaptive emotion regulation (cf. Diers et al., 2023; Gärtner et al., 2019 Gärtner et al., , 2023)).

Overall, the FlexER-Scale represents a novel and promising tool for capturing goal-directed flexibility in emotion regulation. Further validation across cultures and languages is needed before its broader application can be established. Addressing these future directions will enhance its ecological and cross-cultural applicability and strengthen its value for both research and clinical contexts in mental health and well-being.
