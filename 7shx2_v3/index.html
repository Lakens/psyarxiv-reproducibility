What we found

We found 11 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. This package was validated by the Metacheck team on articles in Psychological Science.

This module was developed by Lisa DeBruine, Daniel Lakens and Cristian Mesquida

Read more in the metacheck manual.

Validation: In a sample of 128 papers with 246 instances of power statements, 203 were correctly detected (true positives), 22 were missed (false negatives) and 21 were incorrectly detected (false positives). Overall, among all instances flagged as power statements, 90.6% were correct (positive predictive value).

How Preregistration Check works

Retrieve information from preregistrations in a standardised way, and make them easier to check.

The Preregistration Check module identifies preregistrations on the OSF and AsPredicted based on links in the manuscript, retrieves the preregistration text, and organizes the information into a template. The module retrieves text from the OSF with its API, and from AsPredicted with ResearchBox’s API when a ResearchBox key is set (see rbox_token()), or else from the preregistration’s web page. The information in the preregistration is returned. An AsPredicted link that could not be read is named in the report, with the reason.

The module can’t extract information from non-structured preregistration templates (i.e., where the preregistration is uploaded in a single text field) and it can’t retrieve information in preregistrations that are stored as text documents on the OSF.

If you want to extend the package to be able to download information from other preregistration sites, reach out to the Metacheck development team.

How Marginal Significance works

List all sentences that describe an effect as ‘marginally significant’.

The marginal module searches for regular expressions that match a predefined pattern. The list of terms is a subset of those listed in a blog post by Matthew Hankins. The module returns all sentences that match terms describing ‘marginally significant’ results.

Some of the terms identified might not be problematic in some contexts, and there are ways to describe ‘marginal significance’ that are not detected by the module.

How StatCheck works

Check consistency of p-values and test statistics

The Statcheck module runs Statcheck. Statcheck searches for regular expressions that match a predefined pattern, and identifies APA reported statistical tests. More information on the package can be found at https://github.com/cran/statcheck. The module only returns Statcheck results for t-tests and F-tests, as these are the only tests which have been validated, see https://osf.io/preprints/psyarxiv/tcxaj_v1/.

Statcheck was developed by Michèle Nuijten and Sascha Epskamp.

Statcheck considers p = 0.000 an error, as you should report p < 0.001. Furthermore, p < 0.03 is an error if the p-value was 0.031, and one should simply report exact p-values (p = 0.031). Statcheck might miss one-sided tests, and falsely assume the p-value is incorrect. For more information, see StatCheck.

This module only checks statistical results reported in the running text of the manuscript. It cannot (yet) process statistics reported only in tables.

This module was developed by Daniel Lakens and Lisa DeBruine

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

What Makes Co-Speech Gestures Memorable? I. Introduction

Speakers naturally move their hands when they talk--they gesture. These co-speech gestures serve communication by giving listeners access to information, some of which is found exclusively in gesture (Goldin-Meadow, 2003 , 2023). For example, a speaker says, "I ran upstairs," while producing an upward spiral gesture; only the gesture tells the listener that the stairway is spiral. Co-speech gesture is a unique visual stimulus because it is fully integrated with speech (Congdon et al., 2017; McNeill, 1992) and thus multimodal. It is produced without speakers' intentional planning (Rauscher et al., 1996), reduces speakers' cognitive load (Goldin-Meadow et al., 2001; Ping & Goldin-Meadow, 2010), and benefits learning in speakers (Goldin-Meadow et al., 2009) and listeners (Wang et al., 2026; Zhang et al., 2025). These properties make gesture a powerful tool for teaching and learning. However, the mechanisms underlying gesture's benefits are poorly understood, limiting its application to educational settings.

Gesture might affect learning by enhancing memory. Although we know that gesture promotes memory for new vocabulary (So et al., 2012) and that information in speech is better remembered when it occurs with gesture than without it (Church et al., 2007), very little is known about how gesture affects memory. Studies of visual stimuli other than gesture find that certain visual stimuli are more likely to be remembered than others, regardless of who is doing the remembering. Despite individual differences in memory capability and personal experience, as a group, people tend to consistently remember, and forget, particular visual stimuli (Bainbridge et al., 2013; Guo & Bainbridge, 2025; Isola et al., 2011). Such memory consistency across people for a given stimulus is called memorability. Here, we examine whether people display memory consistency for co-speech gestures, presented with speech (gesture+speech audiovisual stimuli) and without it (gesture visual stimuli). Importantly, only one prior study has studied memorability for multimodal stimuli, specifically examining audio and visual features of movie clips at a coarse level (Cohendet et al., 2018). Only one other study has examined memorability for dynamic visual information, focusing on dance movements presented without sound (Ongchoco et al., 2022). The close coupling between gesture and speech allows us to explore multimodal factors that shape memorability of audiovisual stimuli, as in everyday communication.

Studying memorability of gesture-speech stimuli, whose modalities are tightly integrated before encoding (Murray et al., 2024), can provide insight into the cognitive model of multisensory memory processing. In Baddeley's (2020) influential model of working memory, auditory and visual information are processed separately and then integrated in an episodic buffer before being transferred to long-term memory. This account allows for integration of information from separate modalities in the buffer, which could result in new information.

Importantly, Baddeley's model argues that the central executive, including attention, is not necessary for multisensory integration in the episodic buffer; that is, unisensory information can directly contribute to the episodic buffer without the central executive actively selecting and binding unisensory inputs. In contrast, the predictive coding framework (Quak et al., 2015) suggests that attention plays a key role in determining what and how multimodal sensory inputs are combined with existing representations in long-term memory. Memorability is well suited to disentangle the role of attention in memory for multimodal information because it explains variance in memory independent of attention (Wakeland-Hart et al., 2022). If gesture-speech integration is controlled by attention (as per Quak et al.), we would expect no effect of integration on memorability, which captures variance in memory not attention. But if gesture-speech integration takes place in the episodic memory buffer, where attentional control is not necessary, we might expect effects on memorability. Finding that combined gesture-speech memorability exceeds what can be accounted for by gesture and speech memorability alone would provide additional evidence for Baddeley's (2020) buffer.

Memorability is driven by properties intrinsic to the stimulus, as found in thousands of participants remembering and forgetting the same stimuli across retrieval delays (Goetschalckx et al., 2018; Isola et al., 2014; Lin et al., 2021). Moreover, both meaning and form features of visual stimuli affect their memorability. Memorability for object images is driven primarily by semantic features (category, function, etc.; Kramer et al., 2023); memorability for dance movements is driven by form features (scale of movements; Ongchoco et al., 2022). Researchers typically code gesture form and meaning (e.g., McNeill, 1992). But when relating gesture to the speech it accompanies, meaning is the more important construct (Goldin-Meadow, 2003). The speech+gesture stimuli we use offer an opportunity to examine how gesture's meaning and form, taken in relation to speech, affect memorability.

Here, we examined (1) whether certain gestures, presented alone or with speech, are more memorable than others, and, if so, (2) which properties of co-speech gesture (form/meaning) contribute to its memorability. We ran a series of experiments to measure memorability of hundreds of stimuli presented to different participants in three conditions-gesture alone (visualonly), speech alone (audio-only), or gesture+speech together (visual+audio)-and we examined how they relate to each other. To enhance the ecological validity of our stimuli, we used recordings of spontaneously produced gestures during speakers' explanations of a difficult concept.

II. Method

A. Stimuli

We created a set of stimuli by video recording 20 naïve participants (whom we call "speakers"; see Supplemental Table .1.1 for information on the speakers and Supplemental Method.1 for methods used to generate and process the video recordings). These 20 adult speakers were recruited on the streets of downtown Chicago near Mindworks, a public-facing laboratory. They first watched videos of children who failed to explain Piagetian conservation problems (Piaget & Szeminska, 1941 /1952), such as believing that liquid volume changes when the shape of a container changes or that the number of items changes when they are arranged differently. Conservation is a particularly informative task for studying speech+gesture integration for three reasons: (1) The cognitive effects of gesture produced on conservation tasks has been extensively studied (Alibali et al., 2014; Church, 1999; Church & Goldin-Meadow, 1986; Goldin-Meadow et al., 1992; Kelly et al., 2002; Kelly & Church, 1997 , 1998; Perry et al., 1992; Ping & Goldin-Meadow, 2010). ( 2) There is an established, reliable coding manual for children's explanations of conservation (Church & Goldin-Meadow, 1986); we adapted this manual to code the speakers' speech and gesture explanations (see Table .2). (3) Explanations of conservation often include meaningful iconic gestures illustrating the spatial relationship between differently shaped containers, which are interpretable even in the absence of speech (ing & Goldin-Meadow, 2008). We can therefore examine the impact of gesture meaning on memorability.

The speakers then watched a series of demonstrations in which continuous quantities were poured into containers of different shapes. The speakers produced unscripted speech and gestures as they explained each demonstration (see Fig. 1). B. Participants

We collected online participants' memories of the stimuli (see Fig. 1) using a betweensubjects design in three separate experiments. We recruited 1338, 1165, and 1545 online participants using Prolific for the audiovisual, visual-only, and audio-only experiments, respectively. To ensure data quality, we only recruited participants who reported being fluent English speakers in the United States and having at least 90% approval rates on at least 50 previous tasks. All participants consented to participate following the Institutional Review Board (IRB) guidelines at University of Chicago (IRB98-056, IRB19-1395, applied to all experiments in this study).

C. Procedure

Before proceeding with the online task, participants answered prescreening questions to ensure that the video and sound would play smoothly. In the audiovisual experiment, participants answered a video prescreening question that required them to count and report the number of letters within a digit sequence, and an audio prescreening question that required them to type out a sentence they had heard. Participants could replay the video and audio. Participants in the visual-only experiment answered only the video prescreening question, and participants in the audio-only experiment answered only the audio prescreening question.

The online task used a study-test paradigm (Fig. 2). Each participant was randomly assigned to observe two speakers in two different study-test blocks of the experiment. During the study phase, 9 stimuli (a random half of stimuli associated with a speaker) were presented in a sequence with a 1-s interstimulus interval during which a fixation cross appeared. Participants were not provided with any context for the speakers' explanations and were instructed to memorize the 9 stimuli for an upcoming memory test. As an attention check, the border of each stimulus turned red at a random time point during the last three seconds of each trial as the stimulus was playing. Participants were told to press the r key when the border turned red.

Regardless of whether participants indicated the red border, it disappeared at the end of each trial.

After the study phase, participants were shown instructions for the test phase, and their memory was tested using 18 old/new memory judgment test trials that included the 9 studied stimuli and 9 foil stimuli from the same speaker. In each test trial, the stimulus was presented in a looped manner, and the participant had to rate the stimulus as "definitely old," "probably old," "not sure," "probably new," or "definitely new." An optional break followed the first study-test block. The second study-test block was the same as the first, except that stimuli from another randomly chosen speaker were presented. At the end of the second study-test block, participants filled out a demographic survey, rated whether the experiment ran smoothly, and gave additional comments, if any.

We chose the study-test paradigm for two reasons: (1) We wanted to test memory within the same speaker's gestures to avoid extraneous differences between speakers (e.g., backgrounds, clothes) that might affect participants' memory. (2) There were not enough stimuli (18/speaker) to serve as targets and fillers in a continuous recognition paradigm (a more commonly used paradigm to test memorability), where participants indicate target repeats within a stimulus sequence containing targets and fillers. Memorability has been shown to be a robust measure across different task parameters (Bainbridge, 2020; Bylinskii et al., 2015; Goetschalckx et al., 2019; Xie et al., 2020), and extends to the study-test paradigm (e.g., Gillies et al., 2023; Goetschalckx et al., 2019; Xie et al., 2020).

D. Measures of Gesture and Speech Features in Stimuli

To determine which aspects of the speech and gestures in the stimuli contributed to gesture memorability, we extracted semantic meaning features and visual form features using expert coding and computational measures (Fig. 1). We also used online crowdsourcing to obtain ratings of the movements, based on a rating task used in a previous study of memorability for dance (Ongchoco et al., 2022).

Expert-coded semantic meaning of gesture and speech. We adapted a system developed to code children's speech and gesture explanations of their beliefs about conservation (Church & Goldin-Meadow, 1986). Table .2 lists the strategies the speakers gave, divided into five types (dimensions, identity, count-equate, add-subtract, actions), with examples of each strategy in gesture and in speech. Two trained experimenters coded independently, focusing on a single modality each time, and discussed disagreements to make final coding decisions. Intercoder reliabilities (IR) for gesture strategies and speech strategies were 80.17% and 80.34%, respectively, established using different stimuli subsets (each subset contained 15% of the 360 stimuli, coming from at least 6 different speakers). When an overarching strategy contained component strategies (e.g., Compensation contains Height-Comparison and Width-Comparison), the overarching strategy was coded rather than the components. The speakers often produced different strategies in speech and gesture within a single explanation (see Church & Goldin-Meadow, 1986); as a result, the speech and gesture strategies within a stimulus may differ. Our experts also coded visual form features in gesture, which predicted memory patterns in gesture (see Supplemental Results.5); however, because we can test gesture form with greater subtlety using motion tracking (see next subsection), we focus on the meaning coding our experts did and not their form coding.

We operationalized semantic meaning as the number of unique strategies represented in a snippet to capture a measure of informativeness in each modality (see Supplemental Results.4 for analyses suggesting that no single gesture or speech strategy predicted gesture memorability).

The number of gesture strategies within a stimulus ranged from 0 to 5, and the number of speech strategies within a stimulus ranged from 0 to 4. We counted the number of strategies that appeared uniquely in gesture (i.e., in gesture and not in speech) in each of the 360 stimuli, as well as the number of strategies that appeared uniquely in speech (i.e., in speech and not gesture). We also examined the effects of speech informativeness on gesture memorability because the informativeness of gesture and speech modalities has been shown to be related (Cánovas et al., 2020).

Gesture responses with more explanatory strategies are likely to contain more individual gestures. To be able to control for gesture quantity in our analyses of gesture informativeness, we had two trained experimenters independently code the total number of gestures (range=[0,16]; IR>80%, established on a subset comprising 7.5% of the 360 stimuli) in each video snippet.

Gestures separated by a substantial pause, as determined by visual inspection, were coded as distinct gestures. The number of strategies expressed in gesture reflects the number of different types of explanatory strategies (see Table .2). Column 5 illustrates each gesture strategy.

Computationally extracted visual form features of gesture. For each 10-second video stimulus (≈ 30 fps), we extracted Cartesian coordinate landmarks of the left and right wrists in 29 (evenly-spaced) frames using Google MediaPipe, an open-source computer vision tool that tracks hand movements in the vertical, horizontal, and depth dimensions (Lugaresi et al., 2019).

The extracted wrist landmarks were meter (unit) estimations of real-world coordinates from the origin (the midpoint of the speakers' hips).

Based on the wrist coordinate data, we computed parameters that quantified the visual form features of gestures. For each video stimulus, we measured parameters related to 8 broad categories of features used to characterize the distance, speed, and other aspects of gestures (Table .3). For each form category, we extracted its mean and standard deviation on three dimensions (vertical, horizontal, and depth) for the left, right, and both wrists combined (See Supplemental Method.7). We generated 154 parameters, including 87 distance-related parameters, 45 speed-related parameters, and 22 other parameters.

The average feature ratings range from 1 to 9. II. Results

A. Memorability is found in co-speech gesture

Our first question is whether memorability extends to gesture, with speech or without it.

To determine whether there are consistent memory patterns across people for our gesture and speech stimuli, we tested split-half reliability of hit rate, HR (Supplemental Method.2), for 360 stimuli presented in visual-only (M=.60, SD=.12), audio-only (M=.72, SD=.12), and audiovisual (M=.69, SD=.12) conditions. Not surprisingly (Revsine et al., 2025), participants were consistent in the stimuli they remembered when presented auditorily (Spearman-Brown corrected, SBc, ρ=.67, p<.001; Fig. 3B). But participants were also consistent in the stimuli they remembered when presented visually (SBc ρ=.49, p<.001, Fig. 3A) and audiovisually (SBc ρ=.59, p<.001, Fig. 3C). Certain gestures, presented with or without speech, are better remembered than others across people. This is the first robust evidence that multimodal stimuli show consistent memory patterns across populations.

B. Audiovisual memorability goes beyond its audio and visual components

To examine whether gesture+speech memorability is predicted by memorability of its unimodal components, we ran Spearman correlations across conditions for all 360 stimuli.

To explore this interaction, we grouped stimuli into low-, medium-, and high-audio HR tertiles (120 stimuli each) and correlated visual-only and audiovisual HRs within each tertile.

Visual-only HR correlated with audiovisual HR when audio-only HR was high (Spearman ρ=.23, p=.01), but not when it was low or medium (ps>.05) (Fig. 5). Therefore, memorability of audiovisual (speech+gesture) stimuli is affected by memorability of its visual component (gesture) only if its audio component (speech) is highly memorable.

Speech memorability influences whether the accompanying gesture is memorable. Feature analysis results in the following sections (III.C-E) are similar when the same analyses are conducted using the 120 stimuli with high-audio HR (see Supplemental Results.6); we therefore focused on the full set of 360 stimuli for the feature analyses.

We conducted the reverse analysis, grouping stimuli into low-, medium-, and high-visual HR tertiles (120 each). Audio-only HR correlated with audiovisual HR for low (ρ=.46, p<.001), medium (ρ=.71, p<.001) and high (ρ=.60, p<.001) visual-only tertiles. However, the correlation was significantly stronger in medium than low visual-only HR tertiles (Fisher's z=-2.98, p=.001, one-tailed); medium and high tertiles did not differ significantly. Therefore, memorability of audiovisual stimuli is more affected by memorability of its audio component (speech) if its visual component (gesture) is more memorable. Thus, gesture memorability also influences whether the accompanying speech is memorable.

Finally, we wanted to test whether there was a remaining memorability effect of the integrated audiovisual stimuli when taking out its separate audio and visual memorability components. To examine this question, we tested the residuals from the linear regression, which represent the portion of the stimulus' audiovisual HR that cannot be explained by a linear combination of its visual-only and audio-only HR. A split-half consistency analysis on the residuals (Supplemental Method.2) showed significant cross-participant consistency (360 stimuli: SBc ρ=.31, p=.001, Fig. 3D). As expected, the residuals from the 360 stimuli did not correlate with visual-only or audio-only HR (ps>.05), suggesting that the multimodal residuals capture information beyond the information in either modality. Audiovisual memorability thus reflects a whole that is more than the sum of its unimodal components--integrating auditory and visual information produces new information that participants consistently latch onto.

C. Expert-coded semantic meaning features predict gesture memorability

What features account for gesture memorability? We focus first on meaning categories coded in gesture (Table .2). Number of gesture strategies positively predicted visual-only HR (Spearman ρ=.17, p<.001), suggesting that more informative gestures (those containing more strategies) were better remembered. The total number of gestures did not predict visual-only HR (p>.05), suggesting that more memorable gestures are not simply those containing more individual gestures, but rather those containing more information.

Interestingly, when gesture was embedded in speech in the audiovisual condition, number of gesture strategies did not predict audiovisual HR (p>.05). We controlled for the number of gestures and found that the total number of gestures did predict audiovisual HR (Spearman's ρ=.12, p=.02), suggesting that participants attend to individual gestures more when gesture is embedded in speech but without extracting more meaning from them.

Because speech and gesture were produced simultaneously, speech information might have affected information conveyed in gestures. We therefore conducted the same analyses on speech meaning categories. As expected, number of speech strategies positively predicted audiovisual HR (Spearman ρ=.18, p<.001). Number of speech strategies also predicted visualonly HR (Spearman ρ=.19, p<.001), a surprising result given that participants in this condition did not hear speakers' speech nor see their faces. Informative speech may be related to informative gesture because information is shared across modalities. In fact, number of strategy types conveyed in speech and gesture were positively correlated (Spearman ρ=.23, p<.001).

We then modeled how much variability in visual-only HR could be accounted for by strategies unique to each modality and shared across modalities. The model fit was significant (adjusted R² =.04, p<.001, AIC=571). Gesture-unique (β=.10, p=.03), speech-unique (β=.09, p=.01), and shared (β=.18, p<.001) strategies each significantly predicted visual-only memorability, even though participants did not hear speech-again suggesting modality links through shared meaning.

We modeled the same linear regression to predict audiovisual HR, and found a significant model fit (adjusted R² =.02, p=.01, AIC=698). Speech-unique (β=.13, p=.005) and shared (β=.14, p=.02) strategies significantly predicted audiovisual memorability, but gesture-unique strategies did not (p>.05). To the extent that gesture meaning influences audiovisual memorability, it is when gesture and speech convey the same information.

D. Computationally extracted visual form features weakly predict gesture memorability

We first examined gesture form independent of meaning. We correlated each of the 154 visual form parameters (standardized), extracted using computer vision, with visual-only HR and audiovisual HR. We found no significant correlations with False Discovery Rate correction (q<.05, ps>.05).

We then asked whether form features that reflect meaningful distinctions on the task predict gesture memorability. Because the dimensions of the containers in the task are crucial for understanding conservation, we examined distance-related form features, contrasting them with speed-related features. We fitted separate linear regressions to predict visual-only and audiovisual HR using 87 distance-related parameters, and we fitted separate linear regressions using 45 speed-related parameters. We used stepwise linear regression to avoid making assumptions about parameter collinearity for two reasons: (1) there are no psychological theories specifying how these parameters are conceptually related within the visual system; (2) we included the same parameters for left, right, and both wrists combined, which are inherently correlated.

Using distance-related parameters to predict visual-only HR led to significant model fit (adjusted R² =.02, p=.01, AIC=574). Using speed-related parameters did not (p>.05). We found the same results for audiovisual HR (distance-related: adjusted R² =.05, p<.001, AIC=687; speedrelated: p>.05). Gesture lengths and distances, which are related to reasoning about conservation, better predict gesture memorability (with or without speech) than gesture speed and manner, which are not directly related to reasoning about conservation. The finding adds to the gesture literature by reinforcing the practice of focusing on gesture meaning, rather than form, to predict learning (Goldin-Meadow, 2003). See Supplemental Fig. 7.1 for fine-grained results on form in gesture and Supplemental Results.7, Figs.7.2-.3 for comparable analyses of form in speech.

To explore whether gesture meaning and form together contribute to its memorability, we ran a stepwise linear regression model to predict visual-only HR (logit-transformed) using both number of gesture strategies (a meaning feature; standardized) and 154 visual parameters (all form features, including distance-and speed-related features; standardized) as predictors. We found significant model fit (adjusted R² =.04, p<.001, AIC=568), with number of gesture strategies (β=.09, p<.001) and a distance-related form feature (SDvertical hand distance; β=-.07, p=.02) as significant predictors of visual-only HR. We ran the same regression to predict audiovisual HR. We found several distance-related features (scale, magnitude, distance between hands on vertical/sagittal dimensions) and a direction feature to be significant predictors (adjusted R² =.06, p<.001, AIC=687; Supplemental Table .7.1), but not number of gesture strategies. Only gesture's distance-related form features (which are related to meaning) predict both visual-only and audiovisual memorability.

E. Naïve online crowdsourced rating on typicality predicts gesture memorability

We examined the impact of ratings by non-experts on gesture memorability. Using naïve ratings of visual-only stimuli, we conducted separate linear regressions to predict visual-only and audiovisual HR (see Supplemental Table .8.3 for descriptive statistics). The model predicting visual-only HR was marginally significant (p=.06, Table .4), indicating that the gesture features examined-including scale of movement, which reliably predicts memorability in dance (Ongchoco et al., 2022)-do not predict memorability when gesture is presented without speech.

The model predicting audiovisual HR was significant (adjusted R² =.03, p=.01, AIC=699). In both models, gesture typicality was the only significant predictor (visual-only: β=.08, p=.02; audiovisual: β=.11, p=.008). We found the same pattern when using naïve ratings of audiovisual stimuli from a separate group, suggesting that the limited predictive power of these naïve ratings was not due to the absence of speech (Supplemental Results.9, Tables.8.1-.2,8.4,9.1).

III. Discussion

Our study has three central findings. First, we provide the first robust evidence that multimodal stimuli elicit consistent memory patterns across individuals. In other words, the memorability effect extends to multimodal stimuli--in particular, to gestures spontaneously produced with speech. Our findings thus extend memorability to a multimodal behavior naturally produced in everyday settings.

Second, we show that memorability for multimodal stimuli is explained by distinct contributions of its unimodal information streams. Memorability of gesture+speech is predicted by gesture memorability (on its own) only when the accompanying speech is highly memorable (on its own). Memorability of gesture+speech is also better predicted by speech memorability (on its own) when the accompanying gesture is more memorable (on its own). But memorability for multimodal stimuli is also explained by integrated information across the unimodal streams.

Participants consistently remembered aspects of the audiovisual stimuli not explained by memory for the visual-only or audio-only versions. Audiovisual memorability thus reflects a whole that is more than the simple combination of its unimodal parts--integrating auditory and visual information produces additional information, reliably remembered across people.

The fact that gesture-speech memorability goes beyond the independent contributions of gesture memorability and speech memorability provides support for the episodic buffer in Baddeley's (2020) model. According to the model, auditory and visual (in this case, speech and gesture) information are processed separately and integrated within the buffer before being transferred to long-term memory. The buffer allows for additional information to be created by providing a stage when information from the individual sensory modalities can be integrated.

Because memorability explains variance in memory independent of attentional factors (Wakeland-Hart et al., 2022), the fact that memorability for gesture+speech goes beyond its component parts suggests that memory, rather than attention, is central to gesture-speech integration. Under Baddeley's (2020) model, working-memory resources are limited and shared across processing modules. When encoding speech on its own, auditory processing receives all available resources, and when encoding gesture on its own, visual processing receives all available resources. During gesture-speech encoding, if the visual module requires fewer resources to process gesture, more resources become available to the auditory module (and vice versa). Because more memorable stimuli require less time and fewer resources to encode (Bainbridge et al., 2026), memorable speech or gesture may reduce a listener's cognitive load, leaving more resources available to process the other modality or integrate the two modalities.

Our findings align with this prediction: gesture memorability predicted gesture-speech memorability only when speech was highly memorable, and speech memorability was more strongly correlated with audiovisual memorability when gesture was more memorable. Hostetter (2011) also found that gesture has the greatest impact on learning and memory when it conveys clear, unambiguous information not present in speech, suggesting that informative gestures, which are likely to be memorable, enhance memory for gesture-speech communication. These findings shed light on how gesture could benefit learning.

Third, we find that gesture memorability is predicted by its meaning. The number of strategies found uniquely in gesture, as well as the number shared across gesture and speech-but not the number of individual gestures--predict gesture memorability. Moreover, to the extent that visual form features predict memorability, it is the features capturing dimensions relevant to the task that have an impact on memorability, again suggesting that memorability for gesture is based on meaning.

These findings highlight differences across different types of dynamic visual information.

Because co-speech gestures are inherently meaningful and convey messages to listeners (e.g., Goldin-Meadow & Sandhofer, 1999), it is not surprising that listeners remember gestures based on semantic meaning, rather than visual form. Nor is it surprising that visual features had an impact on gesture memorability only when highlighting a meaningful strategy. In contrast, dance movements are not necessarily intended to be interpreted semantically, and their memorability is predicted by visual form (movement scale, Ongchoco et al., 2022). However, in narrative-based dance forms-such as Indian classical dances or musical theater choreography-meaning might also contribute to memorability. Future research is needed on dynamic visual stimuli that vary in meaning, and on cases in which the same stimulus affords different levels of meaningful parsing across individuals (e.g., sign language comprehension in fluent signers versus naïve viewers).

It is, of course, possible that the distance-related form features isolated here are memorable in other contexts. The finding that "typicality" predicts memorability in the naïve ratings study could mean that distance forms are recognizable as typical and therefore memorable regardless of task. To be certain that gesture form impacts memorability only through meaning, we need to conduct our study with tasks that give rise to gestures with different forms.

Nevertheless, our study provides support for the hypothesis that coding gesture meaning is more important than coding gesture form when assessing gesture's impact on cognition (Goldin-Meadow, 2003). And, as our study shows, gesture needs to be coded and analyzed in relation to the speech it accompanies to fully determine its impact.

IV. Conclusion

Our study investigates the memorability of naturally elicited, multimodal stimuli and demonstrates how the constituent modalities interact to contribute to overall memorability. We also discovered that semantic meaning features are the driving force behind gesture memorability in our task. Visual form features predict gesture memorability only when they reflect the semantics of the task. Interestingly, these visual features become even more important to memorability when the same gestures are presented with speech.

Overall, this study opens a new direction for examining memory for dynamic, multimodal stimuli and offers a methodological framework for isolating unimodal contributions within complex stimuli. Although decades of work show that gesture supports learning, the gap between gesture and cognitive research limits our understanding of mechanisms linking gesture to its behavioral benefits (see Guo et al., 2025, for review). As a result, despite evidence that gestures aid learning in several domains (e.g., mathematics, conservation, chemistry), we still know little about which gesture properties affect memory and how they do so, making it difficult to harness gesture in classrooms. This study provides the first attempt to probe memory mechanisms underlying gesture's benefits. Our results reveal nuanced effects of different gesture properties-particularly in coordination with speech-highlighting the need for further research on cognitive processes that make gesture effective across contexts. Notably, multimodal integration between gesture and speech generates new information not present in either modality alone, which people consistently latch onto and use to enrich representations held in memory. A clearer understanding of these mechanisms will help educators and caregivers use gesture more effectively in real-world environments.
