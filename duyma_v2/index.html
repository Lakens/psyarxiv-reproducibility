To fix Exact P-Values

What we found

Show details

Reporting p values imprecisely (e.g., p < .05) reduces transparency, reproducibility, and re-use (e.g., in p value meta-analyses). Best practice is to report exact p-values with three decimal places (e.g., p = .032) unless p values are smaller than 0.001, in which case you can use p < .001.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (e.g., “decreased at the p < .05 significance threshold”).

The APA manual states: Report exact p values (e.g., p = .031) to two or three decimal places. However, report p values less than .001 as p < .001. However, 2 decimals is too imprecise for many use-cases (e.g., a p value meta-analysis), so report p values with three digits.

What we found

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. This package was validated by the Metacheck team on articles in Psychological Science.

This module was developed by Lisa DeBruine, Daniel Lakens and Cristian Mesquida

Read more in the metacheck manual.

How Preregistration Check works

Retrieve information from preregistrations in a standardised way, and make them easier to check.

The Preregistration Check module identifies preregistrations on the OSF and AsPredicted based on links in the manuscript, retrieves the preregistration text, and organizes the information into a template. The module retrieves text from the OSF with its API, and from AsPredicted with ResearchBox’s API when a ResearchBox key is set (see rbox_token()), or else from the preregistration’s web page. The information in the preregistration is returned. An AsPredicted link that could not be read is named in the report, with the reason.

The module can’t extract information from non-structured preregistration templates (i.e., where the preregistration is uploaded in a single text field) and it can’t retrieve information in preregistrations that are stored as text documents on the OSF.

If you want to extend the package to be able to download information from other preregistration sites, reach out to the Metacheck development team.

How StatCheck works

Check consistency of p-values and test statistics

The Statcheck module runs Statcheck. Statcheck searches for regular expressions that match a predefined pattern, and identifies APA reported statistical tests. More information on the package can be found at https://github.com/cran/statcheck. The module only returns Statcheck results for t-tests and F-tests, as these are the only tests which have been validated, see https://osf.io/preprints/psyarxiv/tcxaj_v1/.

Statcheck was developed by Michèle Nuijten and Sascha Epskamp.

Statcheck considers p = 0.000 an error, as you should report p < 0.001. Furthermore, p < 0.03 is an error if the p-value was 0.031, and one should simply report exact p-values (p = 0.031). How Exact P-Values works

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

1. Introduction

The field of psychiatry has experienced substantial growth in recent years, as evidenced by an increase in scientific publications worldwide. This upward trend not only reflects the growing prominence of psychiatry in the scientific community but also serves as a measure of its research productivity. Scientific output, often measured by publication volume, offers valuable insights into the development and impact of a research field [1]. Identifying the factors that drive this output is essential for promoting advancements in research [2].

Scientific publications are the primary means of disseminating new discoveries and play a central role in academic recognition and career advancement [3]. The production of scientific publications is influenced by a combination of economic, demographic, and social factors. For instance, previous studies have examined geographic trends in psychiatric research output. [4] analyzed publications published between 2004 and 2009 finding large differences between and within countries in psychiatry research productivity. [1] explored the influence of economic and demographic variables on national research output in various countries worldwide. Based on data from 2011 to 2015, their study revealed a positive correlation between publication frequency and factors such as Gross Domestic Product (GDP) and population size. Hence, more publications were observed in high-and upper-middle-income countries. Similarly, within the field of psychiatry, [5] observed a positive correlation between GDP and research productivity regarding schizophrenia. The study by [5] further demonstrated that Accordingly, we used countries' GDP, population density, and HDI and investigated their associations with the number of publications at both global and continent levels. By incorporating social variables and extending the analysis to cover the period from 2000 to 2022, this work aims to offer a broader, fine-grained, and up-to-date perspective on publication frequency and the main drivers of research productivity.

2. Methods

>Methods

2.1. Data collection

The dataset used for the analysis in the current work comprised all documents categorized under "Psychiatry" in Web of Science, published between 2000 and 2022. The Web of Science database was selected for its comprehensive citation tracking, recognition as a leading academic database, and frequent use in similar research studies [4, 15, 1]. Data extraction, conducted on 17 February 2025, included 1,071,338 publications. The number of papers published for each country was used as the indicator of scientific productivity. Country attribution was based on all author affiliations indexed in the Web of Science "Countries/Regions" field.

For subsequent geographic analysis, countries were grouped by continent and region following the United Nations Statistics Division classification [16].

2.2. Key predictors of psychiatry research output

To analyze factors associated with the number of scientific publications per country, we focused on four key indicators in the global model: GDP, population density, population size, and HDI. GDP quantifies a country's economic output, and population density reflects its demographic distribution. Widely used in previous studies of [5, 9, 1], both indicators have been positively associated with scientific productivity. Population density was selected because total population size does not capture how residents are spatially distributed within a country. Countries with comparable populations may differ substantially in land area and, consequently, in the geographic concentration of their populations. Population density may therefore capture aspects of spatial concentration and potential proximity among universities, hospitals, and research institutions that are not represented by population size alone. A similar distinction between population size and density has been examined in previous bibliometric research [17]. Therefore, to adopt a comprehensive approach, we decided to include population density alongside the population size variable. In addition, to incorporate social and well-being dimensions alongside economic and demographic factors, we included the HDI [14]. The HDI is a composite measure that assesses a country's average achievements in health, education, and standard of living [14]. This index is calculated as the geometric mean of these three normalized domains, providing a comprehensive indicator of overall human development. The HDI is composed of four indices that reflect the three key dimensions of health, education, and standard of living. The health dimension is assessed through life expectancy at birth. The education dimension is measured by the average years of schooling, along with the expected years of schooling for children entering the education system. The standard of living dimension is evaluated using gross national income per capita [14]. The HDI was chosen for this analysis over other global social indicators for several reasons. Primarily, the HDI is based on a development approach that focuses on human growth and how the environment helps people reach their potential [18, 19]. Furthermore, the HDI is widely recognized as a standard metric for assessing human development and represents a conceptual shift, redirecting the focus from mere economic progress to overall human well-being [18, 20, 21]. Other social indicators reflect various aspects of human development. However, the HDI offers a more comprehensive measure by combining health, education, and standard of living into a single composite index. It emphasizes the well-being of the population living in the country rather than focusing solely on national-level indicators [19].

Data on GDP and national population density were retrieved from the World Bank database [22]. These variables were imported for each country and year from 2000 to the most recent update in 2022. Data on the HDI were retrieved from the Human Development Report by the United Nations Development Programme covering years from 2000 to 2022 [14].

2.3. Data processing and analysis

The data employed for the analysis were processed and analyzed using R version 4.3.3. [23].

For each country, we recorded the number of documents published each year in psychiatry, representing the absolute frequency of publications. Based on these absolute frequencies, we also calculated the relative frequencies. Relative frequency was calculated as the ratio of the number of psychiatry publications from a given country in a specific year to the total number of psychiatry scientific publications recorded for that year. This value represents the relative share of psychiatry publications produced by each country compared to the global annual production of scientific publications in psychiatry.

Prior to the analyses, the distributions of the continuous predictors were inspected for skewness. GDP, total population, gross national income per capita, life expectancy, and mean years of schooling were logarithmically transformed using log(x + 1). HDI, population density, and expected years of schooling were retained on their original scales. All continuous predictors were subsequently standardized as z scores, whereas publication year was retained on its original scale. The outcome variables were neither logarithmically transformed nor standardized.

Absolute publication frequency was entered in the models as the original document count. It was analyzed using generalized linear mixed-effects models with a log link: Poisson models were retained when dispersion diagnostics did not indicate overdispersion, whereas negative-binomial models were used when overdispersion was detected. Accordingly, the global absolute-frequency model and the component-level post hoc models without overdispersion were fitted using Poisson distributions, whereas the continent-specific absolute-frequency models were fitted using negativebinomial models. Relative publication frequency analyses used binomial generalized linear mixed-effects models with a logit link. For Asia, instead, residual overdispersion in the initial relative-frequency model was addressed by fitting a binomial generalized linear mixed-effects model with an observation-level random intercept. Overdispersion assessments and other model diagnostics are reported in the Supplementary Materials.

To assess whether correlations among fixed-effect predictors could affect the stability and interpretation of coefficient estimates, multicollinearity was evaluated separately for each model using variance inflation factors (VIFs). VIF values exceeding 5 were considered indicative of potentially problematic multicollinearity. For the global models, collinearity diagnostics did not indicate problematic multicollinearity among the predictors. In the absolute-frequency model, VIFs were 3.31 for GDP, 1.05 for population density, 2.69 for population size, 4.15 for HDI, and 4.87 for publication year. In the relative-frequency model, VIFs were 2.89 for GDP, 2.88 for HDI and 1.05 for population density. VIFs were also low in the HDI-component mod-els, ranging from 1.77 to 2.55 for absolute frequency and from 1.89 to 2.65 for relative frequency. For the continent-specific models, population-related variables and GDP were removed because of multicollinearity.

The statistical analyses were conducted using generalized linear mixedeffects models to account for the non-Gaussian distributions of the outcome variables and the hierarchical structure of the country-year observations. To do so, we used the lme4 package for R [24]. Overall, we conducted the analyses at two levels of specificity, focusing first at the global level and, afterward, at the continent level. Moreover, additional within-between sensitivity analyses were conducted to distinguish temporal variation within countries from differences between countries. Complete methodological details and results are reported in the Supplementary Materials (Tables S10-S13). Data from the different sources were matched by country and calendar year. Publication trends were described using all available publication records from 2000 to 2022. For the statistical analyses, countryyear observations were included only when publication frequency and all country-level predictors were available. Because HDI data were available through 2022, the statistical models were consequently limited to the common period from 2000 to 2022.

Overall, the analytical approach was divided as follows: 1.

To test the association between sociodemographic factors and research productivity at the global level, we tested two statistical models. In the first model, we used the absolute number of publications in psychiatry as the dependent variable, and GDP, population density, population size, HDI, and years were included as fixed effects. Individual continents and countries were included as random effects. To control for the effect of publication year, we conducted the same model using relative psychiatric publication frequency as the dependent variable. GDP, population density, population size, and HDI were included as fixed-effect predictors, whereas countries, regions, and continents were included as random intercepts. Publication year was not included in the relative-frequency model because its denominator was the year-specific total number of publications. Moreover, as a sensitivity analysis at global level, we disaggregated the HDI into its four underlying indicators-expected years of schooling, mean years of schooling, life expectancy, and gross national income per capita-and included them as fixed effects in the model. This allows us to assess the individual contributions of each component to the dependent variables.

2. At the continent level, separate generalized linear mixed-effects models were fitted for each continent. HDI was retained as the sole fixedeffect predictor because the inclusion of the additional sociodemographic variables produced VIF > 5. This specification also reflected the primary focus of the study on HDI as a multidimensional indicator of human development. Countries and regions were included as random intercepts, except in Oceania, where only countries were included because no lower-level regional grouping was available. Absolute publication counts were analyzed using negative-binomial mixed-effects models with a log link. Relative publication frequencies were analyzed using binomial mixed-effects models with a logit link. For the Asian relative-frequency model, residual overdispersion was addressed by including an observation-level random intercept. Exploratory post hoc analyses were subsequently conducted by replacing the composite HDI score with its four components. For absolute publication frequency, Poisson mixed-effects models were used for Africa, North America, Oceania, and South America, whereas negative-binomial models were used for Asia and Europe because overdispersion was detected in the corresponding initial Poisson models. For relative publication frequency, binomial mixed-effects models were used; observation-level random intercepts were added to the African and Asian models to address overdispersion. Bonferroni correction was used as the sole multiple-comparison procedure for the continent-specific analyses and was applied separately to the absoluteand relative-frequency outcomes. For each outcome, the primary HDI analyses comprised a family of six tests, corresponding to one HDI coefficient for each continent. The component-level post hoc analyses comprised a separate family of 24 tests per outcome, corresponding to four HDI components across six continents. Model intercepts were excluded from all correction families. Bonferroni-adjusted p-values below .050 were considered statistically significant.

3.1. Worldwide publication trends

Using data from the Web of Science database, we identified a total of 1,071,338 psychiatry-related papers published between 2000 and 2025. However, as data for the other socioeconomic variables were only available up to 2022, we standardized the timeframe across all analyses to cover the period 2000-2022, thereby ensuring consistency while capturing the evolutionary trends over this period. The descriptive analysis revealed an increase in the production of psychiatric research with significant differences in the number of publications on different continents around the world.

The temporal trend analysis (as shown in Figure 1) reveals an increase in the number of psychiatric publications over the years, reflecting the growing global interest in psychiatric research. This growth is particularly salient from the early 2000s onward, with an increase in publications from 2010 to 2021. The number of Web of Science-indexed psychiatry publications increased substantially between 2000 and 2022, with the highest observed annual count occurring in 2021. To statistically assess the temporal trajectory of psychiatric publications, we applied a cubic spline regression [25]. The model explained a substantial proportion of variance in the data (adjusted R² = 97%, F(4, 18) = 195.7, p < .001). All four estimated spline basis coefficients were statistically significant: β1 = 8,985, SE = 3,663, p = .025; β2 = 14,949, SE = 2,706, p < .001; β3 = 34,597, SE = 2,193, p < .001; and β4 = 30,780, SE = 2,110, p < .001.

Notably, Europe and North America have consistently contributed the highest number of publications, whereas publications from Asia, Oceania, South America, and Africa, although increasing, remain comparatively lower.

The geographical distribution of publications (Figure 2) underscores a marked heterogeneity, with a higher concentration of psychiatric publications observed in high-income countries. Particularly, the United States of America exhibits the largest number of publications, followed by several European countries, such as the United Kingdom, Germany, and France. Other high-income nations, including China, Canada, and Australia, also show significant research output. In contrast, low-and middle-income countries show lower numbers of psychiatric research publications.

To estimate the association between sociodemographic variables and research productivity indices at the global level, we conducted two models. 4. Discussion

Publications in psychiatry have increased worldwide, particularly in high-income regions such as North America and Europe [1, 5]. However, the sociodemographic factors behind this trend remain mostly investigated in high-income countries and only from an economic point of view. Closing this gap in the research literature, this study provides a comprehensive analysis of global and continent-specific research productivity in psychiatry over the first quarter of the 21 st century, examining the role of economic, demographic, and social factors, providing a more comprehensive and nuanced perspective on the factors shaping scientific output.

The temporal trend analysis conducted in the current work revealed an increase in the number of psychiatric publications over the years, consistent with prior studies [6, 9]. This growth likely reflects advancements in psychiatric research methodologies, increased recognition of mental health issues, and improved access to research funding, particularly in high-income countries. These findings show that the majority of psychiatric research originates from high-income nations [1, 4].

The consistency of this pattern with previous studies suggests that it likely reflects cross-national differences in research funding, institutional capacity, and access to trained researchers. Nevertheless, the selective coverage of Web of Science may accentuate this geographic gradient because English-language and internationally visible journals are more comprehensively represented than regional and non-English-language publication outlets [26, 27].

The first part of the statistical analyses, focused on investigating associations between sociodemographic factors and productivity indices at the global level. GDP and HDI were positively associated with both the absolute number of psychiatric publications and countries' relative share of annual global psychiatric publications. Population size and population density were both positively associated with absolute publication frequency. By contrast, population density was not associated with relative publication frequency, while population size showed a negative association with this outcome. The positive association between population size and absolute publication output is consistent with previous research showing that more populous countries produced a larger number of publications [1]. It is also consistent with [17], who reported an association between publication counts and population size but not population density. Importantly, the negative population-size coefficient in the relative-frequency model should not be interpreted as indicating that larger populations reduce scientific productivity. Absolute frequency represents publication volume, whereas relative frequency represents a country's share of the global annual output. Thus, after adjustment for GDP, HDI, and population density, countries with larger populations tended to account for a smaller relative share of global psychiatric publications despite producing more publications in absolute terms. The difference between the two models was also reflected in the marginal R² , which was substantially higher for absolute frequency (76%) than for relative frequency (24%). Broad economic, demographic, and human-development indicators therefore characterized differences in national publication volume more closely than differences in countries' relative position within global psychiatric research. The conditional R² approached 100% in both models, indicating that the random effects captured substantial additional variation, particularly in the relative frequency model. The within-between sensitivity analyses complemented this interpretation by showing that some pooled associations were primarily related to changes occurring within countries over time, whereas the corresponding between-country associations varied according to the predictor and outcome. These global models findings indicate that the fixed predictors did not capture all persistent cross-national heterogeneity. Such heterogeneity may be related to unmeasured country specific characteristics, including research funding, institutional capacity or scientific workforce, and access to international research networks. GDP was positively associated with both publication outcomes, consistently with previous findings in psychiatry and other medical fields [15, 1]. Greater economic capacity may coincide with greater availability of financial and institutional research resources. However, research and development expenditure and institutional research capacity were not measured directly, and the present analyses cannot establish whether they account for the observed GDP associations. Previous evidence indicates that scientific output is also associated with more proximal research inputs, including university capacity, and the size of the scientific workforce [10]. HDI remained positively associated with both outcomes. This suggests that the association with publication output was not limited to aggregate economic production but also encompassed the broader educational, health, and living-standard context represented by HDI. Consistent with this interpretation, the exploratory global HDI component analyses showed positive associations for expected years of schooling, mean years of schooling, life expectancy, and gross national income per capita in both outcome models. This pattern is consistent with previous literature relating education, health, and intellectual capital to scientific and knowledge production [28, 29, 30].

The continent-specific analyses yielded two complementary findings. First, HDI was positively associated with both absolute and relative psychiatric publication frequency in all six continents, indicating that the relationship between human development and scientific output was geographically widespread. Second, the within-between analyses and the HDI component analyses showed that this relationship did not have the same structure across regions. Within-country HDI was positively associated with both outcomes in every continent, whereas between-country associations were limited to Europe, North America, and Oceania for absolute frequency and to North America and Oceania for relative frequency. The most consistent pattern was therefore the parallel variation of HDI and publication output within countries over time, rather than a universal cross-sectional gradient separating countries with higher and lower average HDI. This distinction was especially evident in Africa, Asia, and South America, where the primary HDI associations were not accompanied by significant between-country differences. The explanatory contribution of HDI also varied according to the outcome and regional context. HDI accounted for a meaningful proportion of variation in absolute publication frequency across all continents, although its contribution ranged from 27.7% in South America to 78.9% in Oceania. Greater heterogeneity emerged for relative frequency: HDI accounted for a comparatively large proportion of variation in Asia and Oceania, but only a limited proportion in Europe, North America, and South America. Thus, in Europe and North America, human development was associated with the overall volume of psychiatric research but contributed relatively little to explaining countries' share of global annual output. Their relative scientific position may be more closely associated with features of established national research systems, such as funding structures, university and institutional capacity, scientific workforce and participation in international research networks [2, 10, 11]. This finding is also consistent with the large difference between marginal and conditional R² , which indicates that country-and region-level heterogeneity accounted for substantial variation beyond HDI. The exploratory component analyses provided further insight into the dimensions of human development associated with these regional patterns. Education was the most consistent component across continents. Mean years of schooling was positively associated with absolute publication frequency in every continent and with relative frequency in all continents except South America, while expected years of schooling showed a similarly widespread pattern. The clearest example was Asia, where both education indicators were associated with absolute and relative publication frequency, whereas gross national income per capita and life expectancy were not significant. Accordingly, the association between HDI and psychiatric research output in Asia was more closely aligned with educational development than with the income component of the index. A similar distinction emerged in Africa, where income was associated with absolute publication volume but not with relative frequency, whereas both education indicators were associated with countries' relative contribution to global psychiatric output. These findings are consistent with evidence that scientific production depends not only on general economic resources but also on the availability of educated and specialized human capital [29, 30, 31]. The relative importance of economic resources appeared to differ across regional contexts. In South America, gross national income per capita was positively associated with both absolute and relative publication frequency, a pattern compatible with economic resources remaining an important marker of national research capacity where scientific infrastructure is more unevenly distributed. In Africa, the income association was confined to absolute publication volume, suggesting a closer relationship with the scale of research production than with countries' relative international contribution. In North America, by contrast, income was associated with absolute frequency but not with relative frequency, for which education and life expectancy remained significant. One possible interpretation is that, in a predominantly high-income context with established research infrastructure, additional variation in income has limited discriminatory value for countries' relative scientific position, whereas differences in education, health, and related institutional conditions remain informative. Europe presented a comparable non-linear pattern: income was positively associated with absolute output but negatively associated with relative frequency after adjustment for the other HDI components, while education and life expectancy were positively associated with relative output. This result indicates that variation in European psychiatric publication share cannot be represented by a simple positive income gradient. The health dimension was less consistent geographically. Life expectancy was positively associated with both outcomes in Europe and North America, unrelated to either outcome in Africa, Asia, and Oceania, and negatively associated with both outcomes in South America. Together with the heterogeneous income coefficients, this pattern indicates that the individual HDI components might not operate as interchangeable proxies for a single development gradient. Rather, the composite association with HDI appears to summarize different configurations of economic resources, educational attainment, and population health across continents. In some settings, particularly South America, economic capacity was more closely associated with publication output; in others, most clearly Asia, the educational dimensions were more prominent; and in established high-income research systems, non-income dimensions were more informative for relative scientific contribution. These regional configurations offer grounded hypotheses about how national development and research capacity are associated.

4.1. Limitations

Several limitations should be acknowledged for the current work. First, the study relies on data from the Web of Science, which, while comprehensive, does not represent the so-called "gray literature" and may not represent or under-represent research published in non-indexed or regional journals. This limitation is particularly relevant because the likelihood of publishing in English-language, internationally indexed journals may itself be associated with national economic resources and human development. Consequently, the observed associations of GDP and HDI with publication frequency may partly reflect differences in database coverage and international research visibility, in addition to differences in underlying scientific production. Future studies should replicate these analyses using complementary international databases. Moreover, the analysis focuses only on GDP, population size and density, and HDI as primary drivers, but other factors such as government research policies or funding mechanisms are not explicitly considered. In this context, future research could build on these findings by also considering the percentage of GDP invested in research, which can provide a more comprehensive understanding of the relationship under investigation [32]. Additionally, other potentially relevant variables, such as the prevalence of psychiatric disorders, the number of psychiatrists or the level of financial support for psychiatric research across countries, were not included and may offer further insights into the factors shaping publication patterns. More fundamentally, the observational and correlational design does not allow causal direction or temporal ordering to be established. Although GDP and HDI were associated with psychiatric research output, these findings do not demonstrate that economic or human-development investments directly increase research productivity. Furthermore, the associations may be partly explained by omitted countrylevel factors, including research and development funding, the number and capacity of universities and research institutions, the size of the scientific workforce, English-language proficiency, access to international publication networks, and research infrastructure. The results should therefore be interpreted as country-level associations rather than causal effects. Finally, in the continent-specific analyses, we restricted the main models to HDI and the exploratory models to its constituent components, both to address model-diagnostic and multicollinearity concerns and because HDI was the primary variable of interest in this study. Nevertheless, other variables not included in these models may also be important for understanding cross-national publication patterns.

5. Conclusion

This study provides a global and continent-specific examination of the socioeconomic and human-development correlates of psychiatric research productivity from 2000 to 2022. It documents the substantial growth of Web of Science-indexed psychiatric research during this period, alongside persistent geographical differences in publication output. Particular attention was given to HDI because it extends beyond economic production by integrating education, health, and living standards, thereby providing a multidimensional perspective on the national contexts associated with scientific activity.

At the global level, GDP and HDI were positively associated with both absolute and relative publication frequency, whereas population size and density showed outcome-specific patterns. HDI was also positively associated with both outcomes in all six continents. The within-between analyses indicated that these continental associations predominantly reflected parallel changes in HDI and publication output within countries over time, while between-country associations were more geographically restricted. The component analyses further identified education as the most consistent correlate, whereas income and life expectancy showed greater regional variability. These findings suggest that HDI captures different configurations of economic resources, educational attainment, and population health across regional research contexts.

These findings provide a framework for examining geographical disparities in psychiatric research beyond national wealth alone. The prominence of education-related indicators in Asia, the more consistent association with income in South America, and the relevance of non-income dimensions of HDI for relative publication frequency in Europe and North America illustrate how the composition of this relationship differs across regional contexts. The within-between results further highlight the importance of distinguishing changes occurring within countries over time from stable differences between countries. Future research combining these patterns with direct measures of research funding, institutional capacity, scientific workforce, and international collaboration may help explain why countries with comparable levels of development display different research profiles and identify the conditions associated with broader participation in psychiatric knowledge production.
