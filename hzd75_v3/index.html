Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

Human research committee names - Institutional Review Board / IRB (US standard) - Independent Ethics Committee / IEC (ICH-GCP international clinical trial term) - Ethical/Ethics Review Board (generic) - Ethics (Advisory/Review) Committee/Board/Panel/Sub-committee - Research Ethics Committee/Board/Panel (UK/Canada/Australia) - Medical Ethics Committee - Human Subjects/Research Committee / Human Research Ethics (Advisory) Panel - Committee for/on the Protection of Human Subjects - Committee on (Health) Research Ethics - Office of Research Ethics - Abbreviations: IEC, REC, REB, ERB, METC, DEC. How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. The regular expressions can miss power analyses, or fail to classify them correctly. How Code Check works

How reproducibility_check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Introduction

In their first nine years of school, students spend 7,533 hours being taught [1], and teachers are among the most influential factors for outcomes [2]. Most research on teacher effects has focused on achievement. Here we examine how teacher behaviour influences student engagement, a prerequisite for successful learning [3].

Student engagement is a prerequisite for academic thriving

Engagement refers to how students think (cognitive engagement), feel (emotional engagement), and what they do to make progress (behavioural engagement) [4]. Less engaged students are more likely to be disruptive, struggle academically and drop out [5].

School engagement predicts academic performance [6] and even occupational attainment around 20 years later [7]. Teacher behaviours can nourish or stifle engagement [8], so helping teachers adopt nourishing behaviours is a logical strategy. It may also be cost-effective and scalable, because each teacher works with dozens of students, often for years.

Like achievement, engagement is domain-specific [9, 10]. A student can be highly engaged in physical education (PE) yet disengaged in mathematics. We studied mathematics and PE because engagement in both declines during the transition to secondary school and because they are contrasting instructional environments. Mathematics emphasises abstract reasoning and individual problem-solving; PE involves embodied learning, teamwork and public performance. The teacher behaviours that matter may therefore differ between subjects, so we designed a separate intervention for each.

A targeted approach to increasing engagement Performance in both mathematics and PE is declining in Australia. PISA mathematics scores have fallen faster than reading or science scores, and further than the OECD average [11]. Australia received a D-for physical fitness on its most recent Physical Activity Report Card [12]. In both subjects students learn by doing: in mathematics by attempting problems, asking questions and discussing ideas [13], and in PE by running, jumping and throwing rather than sitting and listening [14]. Engaging students is therefore central to learning in both.

Children from disadvantaged backgrounds are more likely to become disengaged [4].

With fewer supports at home and school, they may benefit more from interventions [15]. A meta-analysis of 101 interventions for students of low socioeconomic status (SES) found that they improved learning, particularly in mathematics, but not by enough to close the gap explained by socioeconomic advantage [16]. We therefore focused on improving engagement in low-SES schools. We also focused on the transition to secondary school (Year 6 to Year 7 in Australia), "one of the most stressful events in a young person's life" [17]. Students lose familiar teachers, routines and friendship groups, and engagement usually drops sharply [18].

Teacher behaviours for student engagement

Whether engagement drops seems to depend on what teachers do [19]. According to self-determination theory [20], teacher behaviours shape students' satisfaction of three basic psychological needs: autonomy (feeling volitional), competence (feeling effective) and relatedness (feeling connected to others). Variety has been proposed as an additional need that may matter most when other needs are poorly satisfied [21]. Teachers satisfy these needs when they offer choice and rationales, set optimal challenges with scaffolding, and show warmth [8, 22].

Many trials show that training teachers in need-supportive behaviours can improve student outcomes. Cheon, Reeve and colleagues have reported consistent effects on motivation, engagement and well-being, mostly in PE [23] [24] [25]; a meta-analysis of selfdetermination theory interventions in education found reliable effects on need satisfaction and autonomous motivation [22]; and web-based autonomy-supportive training can change teacher practice and student experience [26, 27].

These interventions share a design feature: researchers or experts select the targets, usually from within self-determination theory [28]. However, other theoretical models explain teachers' effects on engagement. Good teachers act as positive role models (transformational leadership theory [29]), foster growth-oriented beliefs about ability [30] and mastery-focused achievement goals [31]. Instead of only choosing intervention components based on theory or expert judgement, we chose intervention components empirically [32]. We used data-driven selection to complement expert judgement.

The present study

In an earlier two-wave study of 1,799 Year 7 students in 17 low-SES schools, students rated their teachers on 71 behaviours drawn from four motivational theories, and we used elastic net regression to identify the behaviours that best predicted change in engagement (the PE analyses are published [19]; the mathematics analyses are unpublished). The predictors differed by subject. In PE, transformational leadership behaviours (e.g., being a good role model) and variety mattered most, consistent with research showing that PE engagement depends on teacher enthusiasm and varied activities [33]. In mathematics, relational behaviours (e.g., showing warmth and unconditional positive regard) were more predictive, consistent with self-determination theory's emphasis on relatedness [20].

We built professional learning for teachers on the six strongest predictors for each subject (Supplementary Table S1) and tested it in a cluster randomised trial. Our primary hypothesis was that the program would increase student engagement relative to a waitlist control. We also hypothesised that it would increase psychological need satisfaction, the mechanism proposed by self-determination theory [8, 22]; foster mastery-oriented rather than ego-oriented achievement goals [31, 34]; improve PE students' attitudes toward physical activity through role modelling and variety [35, 36]; increase mathematics students' instrumental motivation, the perceived usefulness of mathematics [37]; and improve physical activity and mathematics achievement as distal outcomes [6, 14].

Intervention

Identifying intervention components

The behaviours were identified through a two-wave prospective study of 1,799 Year 7 students (1,324 reporting on PE and 475 on mathematics) taught by 110 teachers across 17 low-SES schools; the PE analyses are published elsewhere [19]. In that study, we created a taxonomy of 71 teacher behaviours drawn from four major motivational theories: selfdetermination theory, achievement goal theory, growth mindset theory, and transformational leadership theory. This taxonomy was created by drawing behaviours from questionnaire items in previous research. From 111 papers, we sourced 49 unique scales, containing 1,151 candidate items. Each of the 1,151 items was reviewed by two authors and grouped into 'bins' of items measuring similar constructs (e.g., all items measuring 'provides meaningful choices'). If items did not fit any category, a new category was created. We then had two authors choose the exemplar item that best represented the category; exemplars were member-checked by eight experts in motivation and five teachers from local secondary schools. This resulted in a list of 71 motivational behaviours. Students rated their teacher on all 71 behaviours in the middle of a school year, and we tested which behaviours predicted change in engagement across the year.

To manage risks of multicollinearity, we used elastic net regression on the longitudinal data to identify which behaviours best predicted changes in student engagement across the school year. The six behaviours selected for each subject were those with the strongest predictive validity (R² = 5.09% for total engagement; R² = 4.36% on new data not used in original model fitting). These proportions of explained variance are consistent with the generally small effects of individual teaching behaviours on student outcomes [42].

Intervention format

The intervention involved approximately 12 hours of blended teacher professional learning: a 1-hour introductory workshop, usually delivered face to face at the school, followed by approximately 11 hours of online learning and mentoring (the dose registered with the NSW Education Standards Authority). After the workshop, teachers completed six online, asynchronous modules (1-2 hours per module). Each module covered one of the six key behaviours identified in the longitudinal data for their subject (Supplementary Table S1).

Professional learning modules included videos covering each core concept, multiplechoice questions to check teacher understanding, case studies with feedback to apply the concepts, worksheets to apply the concepts to their own teaching, and action plans with examples to put the key behaviours into practice. Teachers were asked to complete worksheets and modules in small groups with their colleagues, ideally at fortnightly intervals to promote spaced learning and implementation. Following the six online modules, teachers completed a 1-hour, synchronous online mentoring session to consolidate learning, construct ongoing action plans, and provide accountability for completing the other content. A detailed curriculum is available on the Open Science Framework (https://osf.io/m7rb9/).

Primary outcome

We prospectively registered a range of outcomes for student motivation, engagement, and behaviour (https://osf.io/m7rb9/). The primary outcome variable was student engagement. We used the Student Engagement in School measure [43] because it has shown scores with good internal consistency, test-retest reliability, factor fit, and construct validity [43]. We selected four items assessing each of affective, behavioural, and cognitive engagement. We calculated students' scores by averaging the three engagement subscales (affective, behavioural, and cognitive), consistent with the theoretical model of engagement as a higher-order construct encompassing these dimensions [43]. At baseline, we worded questions to ask students about their experiences during the Year 6 academic year (i.e., "... describe your experience in Year 6 PE practical lessons"). At follow-up, we worded questions to ask about their experience of the most recent school term (i.e., "... describe your experience in PE practical lessons over the past two months"). At both baseline and followup, the total engagement score's alpha and omega were strong among both our mathematics and PE students (all ≥ 0.84; Supplementary Table S3); the behavioural subscale was less reliable (alpha 0.42 to 0.56) because students did not answer its reverse-keyed item consistently with the other three. Confirmatory factor analyses supporting this and our other scoring decisions are reported in Supplementary Note S1, and correlations among all constructs in Supplementary Fig. S1.

The distinction between primary and secondary outcomes was established in our preregistration (https://osf.io/m7rb9/). Student engagement was designated as the primary outcome because it was the direct target of the intervention. The protocol listed need satisfaction, which reflects the hypothesised mechanism, as a secondary outcome, together with physical activity, attitudes toward physical activity, achievement goals, mathematics achievement and instrumental motivation. Agentic engagement was not listed in either version of the protocol, and mindset beliefs and the relative autonomy index were listed in the original version but removed in the 12 November 2019 update, before student data collection; we collected all three and report them as exploratory outcomes.

Secondary and exploratory outcomes

We assessed a range of theory-driven antecedents and outcomes of engagement. We received ethics approval for these measures before finalising the specific intervention components. Thus, the secondary outcomes are not matched to intervention components; they test the intervention's possible mechanisms.

Agentic engagement

Because agentic engagement captures students' proactive contribution to their learning, a dimension not covered by the affective, behavioural and cognitive subscales [44], we also analysed it separately as an exploratory outcome. Students rated four items adapted from Reeve and Tseng [44] (e.g., "During class, I asked questions to help me learn") on a five-point scale from 'strongly disagree' to 'strongly agree'. At both baseline and follow-up, alpha and omega were acceptable among both our mathematics and PE students (all ≥ 0.78; Supplementary Table S3).

Basic psychological need satisfaction

We assessed students' basic need satisfaction using the same measures as Standage and colleagues [45]. We also assessed variety, which predicted greater motivation among people with low psychological need satisfaction in an exercise setting [21]. Given variety is not universally accepted as a basic psychological need, we presented effects of the intervention on psychological need satisfaction with and without variety included. We included three items to assess each of the four constructs: autonomy, competence, relatedness and variety. We averaged responses from the four subscales (autonomy, competence, relatedness, and variety) following standard practice in self-determination theory research where overall need satisfaction predicts motivational outcomes [20]. At both baseline and follow-up, the full measure's alpha and omega were strong among both our mathematics and PE students (all ≥ 0.90; Supplementary Table S3).

Physical activity

For PE students, we assessed physical activity (days per week, 0 to 7) using the single-item physical activity measure [46]. This item asks "In the past week, on how many days have you done a total of 60 min or more of physical activity, which was enough to raise your breathing rate? This may include sport, exercise and brisk walking or cycling for recreation or to get to and from places." This item has been shown to compare favourably with longer measures of physical activity, and correlates moderately with objective assessments (r = 0.44) [46].

Attitudes toward physical activity

For PE students, we assessed attitudes toward physical activity using items created by Barkoukis and Hagger [47], who developed them following standard guidelines for Theory of Planned Behaviour questionnaires. Questions assessed student beliefs about vigorous physical activity along four dimensions: bad to good; useless to useful; harmful to beneficial; and unenjoyable to enjoyable. At both baseline and follow-up, alpha and omega were strong for total scores among our PE students (all ≥ 0.88; Supplementary Table S3).

Achievement goal orientation

We assessed achievement goal orientations using the 3 × 2 framework [31, 48], focusing on the self and other components: self-approach, self-avoidance, other-approach, and other-avoidance goal orientations. PE students completed a questionnaire tailored to the physical activity domain [48] at baseline and follow-up; mathematics students completed the original, exam-focused questionnaire [31] at follow-up only, so intervention effects on goals were estimated in PE students. We scored the four subscales separately, as supported by confirmatory factor analysis (Supplementary Note S1). Task-based goals were not assessed at baseline, so we did not analyse them. At follow-up, alpha and omega for each subscale were strong among both our mathematics and PE students (all ≥ 0.82; Supplementary Table S3).

Mathematics achievement

Among mathematics students, we assessed achievement using a set of questions designed as practice for the Australian National Assessment Program -Literacy and Numeracy [49]. Students were given six minutes to complete six items without a calculator (e.g., "At a quarter to nine in the evening, what would the display on a digital clock show?"). These items were evenly split across the core topics of a full NAPLAN test (algebra, measurement, etc.). With only six items, internal consistency was modest (KR-20 = 0.54; Supplementary Table S3).

Instrumental motivation for mathematics

To explore attitudes toward the perceived utility of mathematics, we used the four items from PISA that assess instrumental motivation (e.g., "I will learn many things in Maths that will help me get a job") [50]. Alpha and omega were 0.85 to 0.88 (Supplementary Table S3).

Implicit theories of ability

At follow-up only, students rated their beliefs about whether ability in their subject is fixed (entity beliefs) or can be developed (incremental beliefs) using four entity and four incremental items. Mathematics students rated beliefs about intelligence using items from Blackwell and colleagues [30] (e.g., "You can always substantially change how intelligent you are") on a six-point scale from 'strongly agree' to 'strongly disagree', which we reversescored; PE students rated parallel items about sport ability (e.g., "How good you are at sport will always improve if you work at it") on a five-point scale from 'strongly disagree' to 'strongly agree'. Higher scores indicate stronger beliefs in both subjects. Alpha and omega were acceptable for both subscales in both subjects (all ≥ 0.80; Supplementary Table S3).

Relative autonomy for attending school

At follow-up only, PE students rated 12 reasons for attending school, two each reflecting intrinsic, identified, introjected-approach, introjected-avoidance, external and amotivated reasons (e.g., "Because I enjoy school"), adapted from Ryan and Connell [51], on a 7-point scale from 'not at all true' to 'very true'. We computed a relative autonomy index by weighting these reasons +3, +2, +1, -1, -2 and -3, respectively, and averaging.

Implementation, manipulation and fidelity measures

We measured teacher completion of the online learning using the analytics from our learning management system. These analytics reported each individual teacher's completion of each step of each module (e.g., whether they completed the multiple-choice questions or submitted an open-ended question). We operationalised 'completion' as having done at least 95% of the course.

As pre-registered, we also assessed teachers' beliefs about the target behaviours. At baseline and follow-up, teachers rated how effective each of the six target behaviours for their subject is for developing student motivation, on a 10-point scale. We reverse-scored the two behaviours the program taught teachers to avoid (unfair rewards in PE and harsh critical language in mathematics), averaged the six ratings, and compared intervention and waitlist teachers' standardised follow-up scores using linear regression adjusted for baseline scores. A random intercept for schools was estimated at zero, so we report the single-level model.

As a student-reported fidelity check, students rated at follow-up how much their teacher displayed each of the six target behaviours for their subject, on a 7-point scale. We reverse-scored the behaviour the program taught teachers to avoid, averaged the six ratings, and analysed this score in the same multiverse as the outcomes.

Following registration, we had a hypothesis that teachers would be less engaged in the intervention if they perceived the core behaviours were 'common sense'. As an exploratory analysis, we asked teachers how confident they were in each of the six behaviours before starting the intervention. They responded on a 10-point scale from 'not at all confident' to 'extremely confident'.

Randomisation

We used a Euclidean distance minimisation strategy to create pairs of similar low-SES schools for randomisation. The schools were matched on: (i) ICSEA, (ii) school size (number of students enrolled), (iii) public results from the national standardised tests of numeracy and literacy, which are completed by all New South Wales children. Following baseline data collection of the teacher outcomes, low-SES schools were paired on those variables then randomly assigned to the experimental or control arm. An experienced statistician who was not part of the research team used a computer-generated algorithm to conduct the randomisation procedure.

Blinding

Students were blind to the experimental manipulation. We were unable to keep teachers blinded to conditions because they were aware of the training during recruitment for the trial. We could not prevent teachers from discussing the training with students, but believed the likelihood of this influencing results would be low.

Statistical methods

As pre-registered, we analysed each outcome measured at baseline and follow-up with a linear mixed model (restricted maximum likelihood) of the follow-up score, with condition (intervention, waitlist, high-SES comparison) and the baseline score as fixed effects, and subject (mathematics vs. PE) as a covariate when both subjects were analysed together.

Random intercepts for schools and for teachers nested within schools accounted for clustering; the protocol specified students nested within teachers, and we added the school level because schools were the unit of randomisation. Mindset beliefs, the relative autonomy index and student-rated teacher behaviours were measured only at follow-up, so those models omitted the baseline score; because mindset beliefs were rated on different scales in the two subjects, we standardised them within subject before pooling. We analysed students according to their school's randomised allocation regardless of how much of the program their teacher completed, including students of teachers who never started it (intention to treat; the per-protocol analysis is the exception). For model parsimony we did not test random slopes. Because students were linked to teachers only at follow-up, the analysed sample comprises students who completed follow-up and could be matched to a participating teacher; students who left before follow-up cannot be identified, so we could not assess attrition between baseline and follow-up, or use the full-information maximum likelihood planned in the protocol. The eight intervention and waitlist students (0.6%) without a baseline score were excluded from models that adjusted for baseline. Intraclass correlations for student ratings of teacher behaviour, nested within teachers, are reported in Supplementary Table S4.

We report each intervention effect as the standardised mean difference between intervention and waitlist students in the follow-up score, adjusted for baseline where measured (Cohen's d in total-standard-deviation units of the outcome). We tested each effect with a two-tailed t test using Satterthwaite degrees of freedom [52], which allows for the small number of schools and teachers per arm, and report 95% confidence intervals from the same t distribution. We corrected for multiple comparisons using the Benjamini-Hochberg false discovery rate (FDR) procedure across all 88 effects estimated in the multiverse (listed in Supplementary Table S6). We report unadjusted (P) and FDR-adjusted (P FDR ) values, and describe an effect as statistically significant only when P FDR < 0.05 (α = 0.05).

We pre-registered a range of sensitivity analyses, but to account for some analytical decisions that were not pre-registered (restricting the sample by baseline timing, estimating effects separately by subject, and excluding variety from need satisfaction; see below), we used a multiverse analysis [53]. Multiverse analyses increase transparency of the effects of analytical decisions by presenting results of each decision [53]. They mitigate some of the risks to internal validity that can occur due to post-hoc analytical decisions (such as "Phacking") [54]. In our case, for each outcome, we presented the results using three subsets of the data, then additional specifications described below. As mentioned earlier, we had hoped to collect all data before students entered Year 7, so we presented results using only these data (40.3% of students, but only 12.3% of intervention students). We also present results for the full sample, including students who completed baseline data collection up to six weeks into Year 7. This may not be a valid baseline because students had experience with their Year 7 teacher, who was already implementing the strategies of the intervention. As a compromise between having an adequate sample size and a valid baseline, we also present results for students who completed baseline before the end of Week 1 of Year 7 (65.9% of students; 30.6% of intervention students). The first three school days of Year 7 (29-31 January 2020) would be unlikely to contaminate student responses, but including these students increases our sample size, especially for the intervention group.

As per our pre-registered analysis plan, we also conducted analyses that controlled for student demographic characteristics (gender, self-reported wealth on a social status ladder, the number of books reported in the home, language at home, and country of birth). For these models involving covariates, we used the data for students who completed baseline before the end of Week 1 of Year 7. We also pre-registered a per-protocol analysis restricted to intervention teachers who completed more than 90% of the program (24 of 40 intervention teachers); in the Week 1 subsample, where we ran it, the same teachers would be selected at a 95% threshold. Finally, we estimated effects separately for PE and mathematics students and, for need satisfaction, with and without variety. By using a multiverse analysis, we can see whether the intervention effects are sensitive to these analytical decisions.

Effects on psychological need satisfaction Need satisfaction did not differ reliably between intervention and waitlist students. Of the three samples, the estimate was largest among students who completed baseline by the end of Week 1 (d = 0.19, 95% CI [-0.01, 0.38]; P = 0.063, P FDR = 0.551); in this subsample, need satisfaction fell less among intervention students than the other groups (Fig 4B). The estimate was larger for PE students (d = 0.25, 95% CI [0.02, 0.47]; P = 0.034, P FDR = 0.521) than for mathematics students (d = 0.10, 95% CI [-0.39, 0.60]; P = 0.626, P FDR = 0.899), but no estimate survived FDR correction, and this subsample's intervention arm comprised 214 students of 16 teachers in 4 schools (81% in two of them). Estimates were close to zero in the full sample (d = 0.02, 95% CI [-0.20, 0.25]; P = 0.841, P FDR = 0.904) and the Year 6 subsample (d = 0.04, 95% CI [-0.24, 0.32]; P = 0.783, P FDR = 0.899). Within the Week 1 subsample, the estimate was similar without variety (d = 0.17, 95% CI [-0.04, 0.38]; P = 0.102, P FDR = 0.665) and in the per-protocol analysis (d = 0.20, 95% CI [-0.06, 0.46]; P = 0.128, P FDR = 0.665), which included 104 intervention students of 7 teachers. respectively).

Effects on other outcomes

None of the remaining secondary or exploratory outcomes showed effects that survived FDR correction (Supplementary Fig. S2). In the full sample, there were no effects on achievement goal orientations, including self-approach goals (d = -0.04, 95% CI [-0.31, 0.23]; P = 0.746, P FDR = 0.899), self-avoidance goals (d = 0.06, 95% CI [-0.14, 0.26]; P = 0.533, P FDR = 0.899), other-approach goals (d = -0.05, 95% CI [-0.29, 0.19]; P = 0.667, P FDR = 0.899), or other-avoidance goals (d = -0.07, 95% CI [-0.31, 0.18]; P = 0.574, P FDR = 0.899). Similarly, there were no effects on students' attitude toward physical activity (d = 0.05, 95% CI [-0.12, 0.21]; P = 0.556, P FDR = 0.899), their instrumental motivation for mathematics (d = -0.03, 95% CI [-0.28, 0.22]; P = 0.807, P FDR = 0.899), their mathematics achievement (d = 0.06, 95% CI [-0.33, 0.44]; P = 0.744, P FDR = 0.899), or PE students' relative autonomy for attending school (d = 0.16, 95% CI [-0.18, 0.50]; P = 0.336, P FDR = 0.879).

Nor were there effects on mindset beliefs in the full sample, either incremental (d = 0.03, 95% CI [-0.30, 0.37]; P = 0.846, P FDR = 0.904) or entity beliefs (d = -0.02, 95% CI [-0.19, 0.14]; P = 0.753, P FDR = 0.899). In the subsamples, intervention students reported weaker entity beliefs in the Week 1 subsample (d = -0.19, 95% CI [-0.38, -0.01]; P = 0.044, P FDR = 0.521) and weaker incremental beliefs in the Year 6 subsample (d = -0.50, 95% CI [-0.96, -0.05]; P = 0.032, P FDR = 0.521), whose intervention students attended 3 schools; neither survived FDR correction (Supplementary Fig. S2).

Implementation, manipulation and fidelity checks

Implementation was bimodal. Of the 40 intervention teachers whose students were analysed, 23 (58%) completed at least 95% of the program, while 10 (25%) completed less than 10%. The learning management system recorded the introductory workshop as complete for 34 of these teachers (85%): 30 in September-November 2019, before the COVID-19 pandemic, 2 early in 2020 and 2 later in 2020; 1 completed part of it and 5 did not start it.

The system did not record whether each teacher attended face to face or online. Of the 504 course activities (workshops, modules, worksheets and reflections) recorded as complete for these teachers, 73% occurred before April 2020, 25% between April 2020 and the start of student follow-up, and 2% after follow-up had begun. Teachers reported high confidence in the target behaviours before the program (M = 8.32/10, SD = 1.04; n = 25 teachers with ratings), but prior confidence was not reliably associated with completion (r = -0.19, P = 0.356, n = 25).

At follow-up, intervention teachers rated the target behaviours as slightly more effective than waitlist teachers did, adjusting for baseline ratings, but the difference was not significant (d = 0.21, 95% CI [-0.10, 0.52]; P = 0.177). This analysis included all teachers with ratings at both time points (36 intervention and 53 waitlist teachers), of whom 25 and 30, respectively, taught students in the analysed sample. Students' ratings of their teacher on the six target behaviours at follow-up did not differ between intervention and waitlist teachers in any specification, including the full sample (d = -0.04, 95% CI [-0.35, 0.28]; P = 0.806, P FDR = 0.899) and the Week 1 subsample (d = 0.15, 95% CI [-0.22, 0.53]; P = 0.419, P FDR = 0.899; Supplementary Fig. S2). We therefore have no evidence that teachers changed the targeted behaviours; we return to this limitation in the Discussion.

Discussion

This study tested whether a data-informed approach to selecting intervention targets could improve student engagement during the transition to secondary school. The intervention did not improve engagement, the primary outcome, in any specification, and no secondary or exploratory outcome differed after correction for multiple comparisons. Among students who completed baseline by the end of Week 1, estimates for physical activity and need satisfaction favoured the intervention, but neither was significant after correction (need satisfaction was not significant even before it), and both rest on an intervention arm from only 4 schools, so they are hypotheses to test rather than effects. Students did not report that intervention teachers used the targeted behaviours more, and teachers' beliefs about those behaviours did not change reliably, so we have no evidence that the program changed teaching.

Our teacher data suggest one reason for the weak effects. Before the program, teachers were already very confident in the target behaviours (M = 8.32/10), and some suggestions may have seemed obvious (e.g., 'use variety' in PE; 'use fair discipline' in mathematics). Yet in our longitudinal data, students reported that some teachers displayed these behaviours far more than others, and the difference mattered to them [19]; teachers' views of their own behaviour often differ from students' views [55]. Confident teachers may not see a personal need for training, and perceived usefulness predicts engagement in professional learning [56], although prior confidence was not reliably associated with completion here. Personalised feedback, such as lesson observations or feedback on video [57], may be needed to change behaviours that teachers regard as common sense. The COVID-19 pandemic also added to teachers' workload at a stressful time and may have reduced their engagement with the program.

Our estimates were smaller than those of the Cheon and Reeve program, which has produced consistently positive effects on motivation in PE through more intensive face-toface training and coaching [25]. Paap and colleagues [27] tested a web-based need-supportive program for PE teachers and found small effects on physical activity, which suggests that delivery format, rather than how targets are selected, may limit effect sizes. Effects of educational interventions shrink when they are delivered at scale [42].

The physical activity estimates would be important if replicated, but we treat them with caution. They did not survive correction for multiple comparisons, they were smaller in the full sample, and intervention students reported less physical activity than students in the other groups at baseline. Physical activity was also self-reported with a single item, which is less valid than device-based measures. Future studies of interventions like ours should measure physical activity with accelerometers or similar devices.

Other secondary outcomes were weak tests of the program. We registered outcomes before using data to choose the intervention components, so several were not matched to those components. For example, no mathematics component addressed career relevance, so the null effect on instrumental motivation is unsurprising. Behaviours that predict engagement need not influence every motivational outcome; targeting career value would require behaviours such as connecting mathematics to future study and work, which were not top predictors in our data.

Several other limitations constrain interpretation. First, we did not observe classroom practice, and neither the pre-registered manipulation check (teachers' beliefs about the effectiveness of the target behaviours) nor students' ratings of the targeted behaviours showed reliable change, so we cannot confirm that teachers changed their behaviour.

Engagement was self-reported across a whole term, whereas some trials with large effects used blind observer ratings [58]. Future trials should observe teaching, in person or by video.

Second, only 12.3% of intervention students completed baseline before Year 7, and restricting by baseline timing left few intervention clusters (4 schools in the Week 1 subsample and 3 in the Year 6 subsample), so those estimates are fragile. Third, two intervention schools withdrew and a third stopped the training, so 8 intervention schools were analysed, fewer than the 9 per arm assumed in our power calculation, and fewer still received the program as intended. Collecting baseline data before students met their Year 7 teachers proved difficult, and we surveyed many students who were not taught by participating teachers; asking Year 7 teachers to run the baseline survey in their first lesson would avoid both problems, at the cost of extra teacher workload. Fourth, the earlier study explained about 5% of the variance in engagement, a modest basis for selecting targets. Fifth, the light-touch online format likely reduced completion. Engagement in professional learning depends on time, support and interaction [56]; we recommend first testing a prototype with more support and then adapting it for scale, because a program designed for scale from the start offers few chances to iterate in response to user feedback. Finally, we compared the program with a waitlist rather than with an intervention whose components were chosen by expert judgement, which is the comparison needed to test data-informed selection itself.

The research team comprised university-based academics who were not members of the low-SES communities where the research took place. We designed the intervention with teachers but did not involve students or families. Student-reported data drove target selection, which partly offsets researcher assumptions, but future work should centre the perspectives of students and families in these communities.

This study tested a model for building targeted interventions to support students, especially those from lower socioeconomic backgrounds, during one of their most difficult transitions. Using data to identify the teacher behaviours that best predicted engagement, we built a brief, mostly online professional learning program and delivered it during a disrupted year. It did not improve engagement. The physical activity and need satisfaction estimates that favoured the intervention could be tested in larger trials with more schools per arm, direct observation of teaching, and device-based measures of activity. For practitioners supporting schools in low-SES contexts, our results suggest that brief online training in behaviours teachers already feel confident about is unlikely, on its own, to change student engagement. Effects on student engagement (primary outcome)

The intervention did not affect engagement in any specification (Fig. 3). Supplementary Note S1. Confirmatory factor analyses for scales in the study

All models were fitted in the analysed sample, separately for each subject, at baseline for measures collected at both time points and at follow-up for measures collected only then (lavaan; robust maximum likelihood with full-information estimation for missing items; robust fit indices). Reverse-keyed engagement items were reverse-scored first. Supplementary Table S5 lists every model.

Engagement.

The three first-order factors (affective, behavioural, cognitive) fitted acceptably and better than a single factor (Table S5). With three first-order factors, a higherorder model is statistically equivalent to the correlated-factor model, so these results are consistent with treating engagement as a multidimensional construct with a common core [S1,S2], which is how we scored it (the mean of the three subscales). The behavioural subscale's reverse-keyed item ('I did just enough to get by') loaded weakly and negatively even after reverse-scoring (standardised loading -0.09 in mathematics and -0.18 in PE), so many students seem to have read it as a positive statement; this explains that subscale's low alpha (Supplementary Table S3).

Need satisfaction. The four-factor and higher-order models fitted similarly (mathematics CFI 0.95 and 0.94; PE CFI 0.96 and 0.96), and both fitted far better than a single factor, with or without variety. All four needs loaded strongly on the higher-order factor (mathematics: autonomy 0.85, competence 0.62, relatedness 0.88, variety 0.94; PE: autonomy 0.97, competence 0.78, relatedness 0.90, variety 0.91), supporting a composite computed as the mean of the four subscale scores, alongside the distinction between needs.

Agentic engagement, attitude to physical activity and instrumental motivation.

Each fitted a single factor (CFI ≥ 0.98; Table S5).

Achievement goals.

The four-factor model (self-approach, self-avoidance, other-approach, other-avoidance) fitted better than a two-factor approach/avoidance model in both subjects (Table S5), so we scored the four subscales separately.

Mindset.

Two factors (entity, incremental) fitted much better than a single factor in both subjects (Table S5). The factors correlated -0.30 in mathematics and -0.10 in PE, so we analysed entity and incremental beliefs separately rather than as one mindset score.

Mathematics achievement.

For the six correct/incorrect items we report classical item statistics at baseline (n = 689): the proportion correct ranged from 0.30 to 0.62, corrected item-total correlations from 0.17 to 0.36, and KR-20 was 0.55.
