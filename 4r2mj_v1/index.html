What we found

We found 26 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Ethics Approval Check works

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

Animal research committee names - Institutional Animal Care and Use Committee / IACUC (US standard) - Any sentence containing animal(s) and committee (or board/panel) within ~5 words of each other — catches Experimental Animal Care and Use Committee, Animal Ethics Committee, Animal Welfare Board, Animal Welfare Ethical Review Body, etc. - UK: Animal Welfare Ethical Review Body / AWERB - Dutch: Dierexperimentencommissie / DEC (see DEC constraint above); Instantie voor Dierenwelzijn / IvD - German: Tierversuchskommission / TvK (advisory committee under §15 Tierschutzgesetz) - French: Comité d'éthique en expérimentation animale / CEEA; Comité d'éthique animale - Spanish: Comité de ética en experimentación animal / CEEA

Waiver / exemption - Ethics/Ethical (waiver|exemption) - IRB (waiver|exemption|exempt) - Exempted from (ethics|irb|institutional review) - Waived by the (ethics|irb|institutional|review) (committee|board) - Deemed exempt

Declaration of Helsinki - Declaration of Helsinki / Helsinki Declaration

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Full text

Abstract

As sounds unfold over time, listeners often need to relate successive events while keeping them distinct. Auditory working memory is susceptible to interference from subsequent sounds, yet whether resulting errors reflect distortion of the remembered target or intrusion of the intervening sound itself remains unclear. Although both mechanisms can produce similar average biases toward an intervening sound, they predict distinct distributions of reproduction errors. Recent advances in continuous pitch reproduction now allow us to test these predictions in audition. In two experiments, participants remembered a target tone over a brief delay and reproduced its pitch on a circular continuous-response scale. During the delay, an intervening tone was presented; participants either ignored it or judged its similarity to the target. We analyzed reproduction-error distributions with mixture modeling to distinguish systematic shifts in target-centred responses (i.e., distortion) from responses clustered around the intervening pitch (i.e., intrusion). The results showed that the error distributions were better accounted for by models incorporating responses centred near the intervening pitch (i.e., intrusion) than the models assuming continuous displacement of target-centred responses alone (i.e., distortion).

Exploratory analyses suggested that the influence of task relevance of the intervening sound was associated with baseline memory precision: listeners with less precise baseline reproduction tended to show greater interference when told to explicitly compare the sounds. Together, these findings suggest that intervening sounds may do more than bias reports of remembered pitch. On some trials, the intervening sound may guide the final response in place of the target, even when task-irrelevant.

Introduction

"Wait, what did they just say?" You're watching the final moments of a gripping television episode. A character delivers a cryptic line, but before you can make sense of it, another character speaks. Was that remark a warning, or an innocent response? You try to replay it in your mind but can't quite remember how it sounded. You reach for the remote to rewind.

Everyday life, however, offers no rewind button. As sounds unfold over time, we must retain what we have heard while processing what comes next. Making sense of these auditory sequences requires us to relate successive sounds without losing track of each one. The arrival of new auditory information may also change how an earlier sound is remembered. Can a subsequent sound affect not only how accurately we remember an earlier one, but what we ultimately report hearing?

Auditory interference research provides evidence of this vulnerability. Even when listeners are instructed to ignore intervening tones, their recognition of an earlier pitch can deteriorate (Deutsch, 1970; Pechmann & Mohr, 1992). However, interference is not merely a general loss of accuracy. Its magnitude depends on the pitch relationship between successive sounds (Deutsch, 1972), and interactions between sounds can produce systematic directional shifts in remembered pitch (Olson & Hanson, 1977). What remains unclear, however, is whether this interference reflects a distortion of the remembered sound or the replacement of the target sound by the intervening sound. In the former case, memory for the target may be systematically shifted toward the intervening sound; in the latter, listeners may instead report the intervening sound as though it were the original target. We refer to this report-level replacement as an intrusion of the intervening sound, without assuming that the original target representation has necessarily been lost. Distinguishing these possibilities is critical for understanding how subsequent auditory information influences memory for an earlier sound.

Characterizing the mechanisms underlying auditory interference requires moving beyond traditional discrimination tasks that offer only a small number of discrete response alternatives.

For example, Bancroft et al. (2016) demonstrated that an irrelevant intervening tone could influence auditory pitch-discrimination judgments, but their findings could not distinguish whether responses reflected a systematic shift in the remembered target or its replacement by the intervening tone. Continuous pitch-reproduction tasks have provided a more detailed characterization of auditory memory errors, including the contributions of memory precision and guessing (Kumar et al., 2013) and the effects of intervening sounds on reproduction accuracy and precision (Tollefsrud et al., 2024). However, these advances leave a fundamental question unresolved: When a subsequent sound influences memory for an earlier one, does it systematically shift responses toward itself, or do listeners sometimes report the subsequent sound in place of the original target? Distinguishing these possibilities requires examining how reproduction responses are distributed in relation to both the target and the intervening sound. To illustrate, consider a scenario in which an intervening sound induces a modest average bias toward itself when participants are instructed to report the target. This bias could arise because responses to the remembered target are consistently displaced toward the intervening sound. Alternatively, many responses might remain concentrated near the original target while others cluster around the intervening sound itself. Although both patterns could produce similar average attraction, they imply different underlying sources of interference. Thus, characterizing auditory interference requires examining the distribution of reproduction errors rather than average bias alone. The recently developed Auditory Reproduction Task (Karabay et al., 2024), which uses a circular Shepard-tone continuum (Shepard, 1964), provides a means of characterizing these distributions across a continuous auditory stimulus space. Research on visual working memory has long employed mixture modeling to distinguish different sources of error within continuous reproduction distributions, including imprecision, nontarget responses, and guessing (e.g., Bays et al., 2009; Van Den Berg et al., 2014; Zhang & Luck, 2008). Extending this approach to auditory reproduction opens a new avenue for disentangling the mechanisms of auditory interference, allowing us to determine whether intervening sounds systematically shift remembered pitch, are occasionally reported in place of the original target, or contribute to both forms of error.

Beyond identifying the sources of auditory interference, an important question is whether the task relevance of intervening sounds shapes their influence on memory. Although interference can occur when intervening sounds are to be ignored, explicitly comparing a subsequent sound with the remembered target may alter the nature and magnitude of this interference. Evidence from visual working memory supports this possibility. Explicit comparison between a memory representation and a new visual input can produce systematic attraction toward the new visual input (Fukuda et al., 2022; Saito et al., 2024), sometimes exceeding the attraction observed when the same information is to be ignored (Saito et al., 2023).

These findings suggest that actively comparing successive sounds may strengthen their interaction in memory, motivating an examination of whether task relevance similarly enhances attraction in auditory working memory and alters the underlying sources of interference.

To investigate the nature of auditory interference and its interaction with task relevance, we adopted the ART to examine how an intervening tone influences memory for an earlier target tone. Participants remembered a target tone over a brief delay and reproduced the tone on a circular continuous scale. Critically, an intervening tone was presented during the delay, and participants were instructed either to ignore it or to compare its similarity with the target tone, depending on the block. We applied mixture modeling to the resulting reproduction error distributions to distinguish the contributions of systematic attraction toward the intervening tone and probabilistic replacement of the target by the intervening tone. To preview the results, reproduction responses were systematically attracted toward the intervening sound even when listeners were instructed to ignore it, with no reliable overall difference in attraction between the task-relevance conditions. However, individual-differences analyses revealed that the difference in attraction between conditions was associated with baseline memory precision, such that listeners with less precise reproduction showed greater attraction when the intervening tone was task relevant. Moreover, reproduction error distributions were better described by models incorporating probabilistic replacement by the intervening sound than by models incorporating systematic attraction alone. Together, these findings suggest that the influence of subsequent auditory information on memory cannot be understood solely as a reduction in accuracy or a systematic shift in remembered pitch. Rather, auditory interference may also involve the replacement of the target by a subsequent sound, even when that sound is irrelevant to the task at hand.

Experiment 1

Experiment 1 investigated whether the influence of an intervening tone on auditory working memory reflects a systematic shift in responses toward the intervening pitch or the intrusion of the intervening tone itself. Using continuous pitch reproduction, we examined how an intervening tone presented during the retention interval affected working memory for a target tone and whether this influence depended on task relevance.

Method

Sample Size Justification and Participants

An a priori power analysis conducted using G*Power (Faul et al., 2009) indicated that a minimum of 34 analyzable participants would provide 80% power to detect a moderate withinparticipant difference in auditory memory attraction between the Compare and Ignore tasks (dz = 0.50), using a two-tailed paired-samples t-test at α = .05. We therefore aimed to obtain at least 34 participants with complete, usable data.

Forty undergraduate students from the University of Toronto Mississauga participated in the study. Four participants did not complete both task conditions, yielding a final analytic sample of 36 participants (24 women, 12 men; age range = 17-22 years, M = 18.61). Six participants identified as musicians, and three reported having perfect pitch. All participants reported no hearing issues. Participants received course credit for participating, and all provided informed consent under a protocol approved by the University of Toronto Research Ethics Board.

Apparatus

The tasks were programmed in MATLAB R2023b (The MathWorks, Inc., Natick, MA) using Psychtoolbox extensions and administered on a laboratory computer. Visual instructions and the response interface were presented on a 24-inch LCD monitor, with participants seated approximately 60 cm from the display. Auditory stimuli were delivered through over-ear headphones at a consistent listening level. Testing was conducted in a quiet laboratory setting, with an experimenter present to monitor task compliance and address technical issues.

Stimuli

Auditory stimuli were adapted from the Auditory Reproduction Task (ART; Karabay et al., 2024). Following the ART implementation, we used Shepard tone complexes to construct a continuous circular auditory feature space (Shepard, 1964). Shepard tones consist of octavespaced frequency components weighted by a fixed, bell-shaped spectral envelope, allowing pitch chroma to vary while rendering absolute pitch height ambiguous. Consequently, tones separated by a full octave share the same pitch chroma, allowing the stimulus continuum to wrap perceptually onto itself. The Shepard-tone space used in ART has previously been validated for use as a perceptually circular continuous-report space (Karabay et al., 2024).

Shepard tone complexes were generated in MATLAB using the ShepardTC function (Böckmann-Barthel, 2017). The circular space comprised 360 unique tone values logarithmically spaced across a single octave. Specifically, 361 values were generated between 278.4375 and 556.875 Hz on a log2 scale, and the octave-equivalent upper endpoint was removed to avoid duplicating the beginning of the circular space. Each Shepard tone comprised octave-spaced frequency components within a 30-16,000-Hz range, weighted by the fixed spectral envelope.

Tones were 1,000 ms in duration and included 25-ms onset and offset ramps. Following generation, the stereo waveforms were root-mean-square normalized to equate amplitude across stimuli.

On each trial, the target tone was randomly selected from the 360° circular stimulus space. On two-sound trials, the second tone was positioned 30°, 60°, or 90° from the target along the circular continuum, with offsets pseudorandomized and balanced within blocks. In Experiment 1, these offsets were always applied in the positive direction along the stimulus space.

Procedure

After providing informed consent, participants completed two experimental tasks, each consisting of 160 trials: a compare task and an ignore task. The order of the two tasks was counterbalanced across participants, such that half completed the Compare task first and half completed the Ignore task first. The full experiment lasted approximately 2 hours, including instructions and practice trials.

The Compare and Ignore tasks were administered in five experimental blocks of 32 trials each. Within each block, eight trials (25%) were one-tone baseline trials and 24 trials (75%) were two-sound trials. On two-sound trials, the second tone occurred at an angular separation of 30°, 60°, or 90° from the target, with each offset represented equally within every block.

Baseline and two-sound trials were presented in pseudorandom order.

Before each task, participants completed four single-tone practice trials with trial-by-trial feedback to familiarize themselves with the reproduction procedure. A response was considered accurate when it fell within 45° of the target. If fewer than 75% of responses met this criterion, additional practice was provided. Participants then completed four two-tone familiarization trials using the instructions appropriate to the upcoming task. Practice accuracy was not used as a participant-exclusion criterion. No accuracy feedback was provided during the experimental blocks.

During experimental blocks, each trial began with a 500-ms fixation interval, followed by a 1,000-ms target tone that participants were instructed to remember for later reproduction. On one-tone baseline trials, the target was followed by a 2,000-ms retention interval before reproduction. On two-sound trials, a second 1,000-ms tone was presented after a 500-ms interstimulus interval, followed by a 2,000-ms retention interval before reproduction. The first tone was always the to-be-reproduced target.

The critical manipulation concerned how participants processed the second tone. In the Ignore condition, participants were instructed to disregard the second tone while maintaining the target for subsequent reproduction. In the Compare condition, participants were instructed to actively compare the second tone with the remembered target and decide whether the two tones sounded similar or dissimilar. Thus, the tasks differed in how participants were instructed to process the second tone, while the auditory sequence and timing remained the same.

Following the retention interval, participants reproduced the target using the circular auditory response wheel. The cursor initially appeared at the center of the display. Moving the cursor outward engaged the circular response space, after which movement around the circumference continuously updated the corresponding Shepard tone. Participants could therefore search through the auditory feature space until the currently presented tone best matched their memory of the target, at which point they registered their response with a mouse click. The mapping between spatial position on the wheel and auditory frequency was randomly rotated on every trial to prevent the development of stable spatial-frequency associations.

After reproducing the target, participants rated their memory confidence as high confidence, low confidence, or guessing. On two-sound trials in the Compare condition, participants then reported the similarity judgment they had made by selecting either Similar or Dissimilar. Analyses

Our analyses addressed two related questions. First, does an intervening sound systematically bias reproduction of the remembered target, even when participants are instructed to ignore it, and does explicitly comparing the two sounds increase this influence? Second, what form does this interference take? A mean bias toward the intervening sound could reflect a continuous displacement of target-centred responses, occasional responses centred on the intervening sound itself, or both. We therefore examined the distributions of reproduction errors to determine which of these accounts best described the observed interference using a series of mixture modeling analyses (see Analyses section 3 for details).

Trial-level exclusions. We excluded trials with reproduction response times shorter than 1000 ms. Long response times were retained because reproduction was self-paced and longer response times could reflect genuine difficulty reconstructing the remembered tone. However, trials on which participants failed to provide a reproduction response within the 20-s response window were excluded from analysis. These criteria excluded 148 of 11,520 experimental trials (1.28%): 86 trials (0.75%) because reproduction responses were made in less than 1 s and 62 trials (0.54%) because of response timeouts.

Quantifying auditory memory bias. For each trial, reproduction error was calculated as the signed angular difference between the reported and target tones, wrapped to the range of -180° to +180° to account for the circular stimulus space. The first sound was always the reproduction target. For two-sound trials, errors were aligned relative to the direction of the second sound such that positive values indicated responses displaced toward the second sound and negative values indicated responses displaced away from it. In Experiment 1, all secondsound offsets were positive. For each participant, mean aligned reproduction error was calculated separately for each task (Compare, Ignore) and angular separation (30°, 60°, 90°).

1. Baseline reproduction performance.

Before examining the influence of an intervening sound, we assessed how accurately and consistently participants reproduced the target when no second sound was presented. These one-sound trials provided a measure of baseline reproduction performance, independent of interference from subsequent auditory input.

Importantly, we also examined whether baseline precision differed between the Compare and Ignore conditions, as differences in the fidelity of the remembered target could influence its susceptibility to interference. For baseline trials, signed reproduction error was calculated as the shortest angular difference between the reported and target sounds, with positive values indicating clockwise (CW) deviations and negative values indicating counterclockwise (CCW) deviations along the circular auditory continuum (-180° to +180°).

For each participant, we pooled one-sound trials across tasks and calculated mean signed error, mean absolute error (MAE), and the within-participant standard deviation (SD) of signed errors. To test for differences in baseline performance between tasks, we calculated MAE and SD separately for Compare and Ignore and compared these measures using two-tailed paired-samples t-tests.

2. Does an intervening sound bias auditory working memory, and does task relevance alter this bias?

We first tested whether the intervening sound systematically attracted reproduction responses in both task conditions. Attraction in the Ignore condition would establish that interference can occur even when the second tone was irrelevant to the concurrent task. Comparing the tasks then allowed us to determine whether the task relevance of the second tone modulated the strength of its interference.

For each participant, mean aligned reproduction error was calculated separately at offsets of 30°, 60°, and 90° within each task (Compare and Ignore). At each offset, mean errors were tested against zero using two-tailed one-sample t-tests, with Holm correction across the three offsets within each task (Holm, 1979). Positive mean errors indicated attraction toward the intervening sound.

To determine whether explicit comparison increased interference, and whether any difference between tasks depended on the separation between sounds, we conducted a 2 (Task: Compare, Ignore) × 3 (Offset: 30°, 60°, 90°) repeated-measures ANOVA. Sphericity was evaluated using Mauchly's test, with Greenhouse-Geisser (1959) corrections applied when appropriate. We also compared Compare and Ignore at each offset using two-tailed pairedsamples t-tests, with Holm correction across the three comparisons.

3. Distortion or replacement in auditory working memory?

Establishing that reproduction responses are attracted toward the intervening sound does not reveal how this interference arises. One possibility is that the remembered target is continuously displaced toward the second sound, producing a shift in the distribution of target-centred responses.

Alternatively, the intervening sound may compete with and replace the target for reproduction, producing an additional concentration of responses near Sound 2. These possibilities are not mutually exclusive, but they make different predictions about the distribution of reproduction errors. Results

1. Baseline reproduction performance

We first examined whether participants could reliably reproduce the target in the absence of an intervening sound and whether baseline performance differed between task conditions.

Across the 36 participants, 2,845 valid one-tone trials were retained. Averaged across participants, mean signed reproduction error was 2.34°, mean absolute error (MAE) was 46.27°, and mean within-participant standard deviation (SD) of signed errors was 61.98°. As illustrated in Figure 2, reproduction errors were concentrated around the target (0°), indicating that participants could reproduce the remembered sound in the absence of interference. We next examined whether the different task contexts affected baseline reproduction accuracy or precision. Mean absolute error did not differ reliably between Compare (45.78°) and Ignore (46.91°), t(35) = -0.50, p = .618, 95% CI [-5.70, 3.44], BF₀₁ = 4.96. Baseline precision, indexed by the within-participant SD of signed reproduction errors, likewise showed no reliable difference between Compare (60.74°) and Ignore (62.56°), t(35) = -0.71, p = .485, BF₀₁ = 4.43.

3. Mixture models favour a Sound 2-centred response component at larger separations

The behavioural analyses demonstrated that reproduction responses were systematically attracted toward the intervening sound, particularly at angular separations of 60° and 90°.

However, positive mean reproduction errors could reflect either a continuous displacement of target-centred responses toward the second sound or occasional reproduction of the second sound instead of the remembered target. To distinguish these possibilities, five candidate mixture models were compared using the distributions of trial-level reproduction errors pooled across participants, separately for each task and angular separation.

At 30°, BIC favoured the target-plus-guessing model (M2) in both the Ignore and Compare conditions, indicating that neither continuous bias nor swaps provided sufficient improvement in fit to justify an additional parameter. At 60° and 90°, however, BIC consistently favoured the model incorporating swaps and guessing without continuous bias (M4) in both tasks. Relative to the continuous-bias model (M3), the swap model showed lower BIC values at 60° (ΔBICIgnore = 10.45 and ΔBICCompare = 13.79) and 90° (ΔBICIgnore = 31.56 and ΔBICCompare = 34.70). Thus, across the larger separations, the distributions of reproduction errors were better captured by a model allowing occasional reports centred on the intervening sound than by one assuming a continuous displacement of target-centred responses alone. Importantly, adding a continuous-bias parameter to the swap model (M5) did not improve BIC in any of these conditions. Relative to M4, the combined model produced higher BIC values at 60° (ΔBICIgnore = +7.20 and ΔBICCompare = +5.06) and 90° (ΔBICIgnore = +7.23 and ΔBICCompare = +6.18). Estimated swap-component proportions in M4 were .109 and .079 for the Ignore condition at 60° and 90°, respectively, and .125 and .152 for the corresponding Compare conditions. Together, these findings suggest that the observed attraction toward the intervening sound was more consistently characterized by swap-like responses than by a uniform displacement of the remembered target.

To evaluate the stability of the principal model comparisons, the analyses at 60° and 90° were repeated using 200 participant-level bootstrap resamples per condition.

The swap model (M4) was preferred over the continuous-bias model (M3) in 95-100% of bootstrap samples across the four task-by-separation conditions. M4 was also preferred over the combined biasplus-swap model (M5) in 87-100% of samples. Moreover, the bootstrap 95% percentile intervals for the additional continuous-bias parameter in M5 included zero in every condition. These results indicate that the preference for a swap-like component was relatively stable across participant resamples.

Model-recovery simulations were conducted to assess whether the fitting procedure could distinguish data generated by swaps, continuous bias, or both. Across the four conditions, the correct swap-only model was selected in 89-99% of simulations generated without continuous bias. However, recovery was less consistent when both mechanisms contributed to the simulated responses. When a 5° continuous bias accompanied swaps, the combined model was correctly selected in only 2-76% of simulations, depending on task and separation. Recovery was particularly limited at 60°, where the procedure frequently selected either the bias-only or swap-only model despite both mechanisms being present. Thus, although the empirical preference for swaps was robust, the simulations indicate that the modelling procedure was not uniformly sensitive to additional continuous distortion.

Overall, the mixture-model analyses suggest that the systematic attraction of auditory reproduction responses toward an intervening sound was better explained by a swap-like component than by continuous response bias alone. The addition of continuous bias to the swap model was not consistently justified by the empirical model comparisons, but imperfect recovery of combined mechanisms prevents concluding that continuous distortion was entirely absent.

Interim Discussion

Experiment 1 demonstrated that an intervening sound systematically attracted auditory working-memory reproductions toward itself, even when participants were explicitly instructed to ignore it. The distributional analyses further suggested that this attraction may not be adequately characterized by a continuous displacement of target-centred responses alone. At larger separations, models incorporating a Sound 2-centred response component provided better descriptions of the observed errors, raising the possibility that some reproductions are a result of replacement rather than a shift in representation.

Interpreting these findings raises two important questions. First, because Sound 2 always appeared at a positive angular offset from the target, the predictable directional relationship between the sounds may itself have contributed to the observed attraction. For example, participants might have learned to use Sound 2 as a reference when reconstructing the target, with incomplete adjustment away from that reference producing responses displaced toward Sound 2. Alternatively, repeated exposure to the same directional relationship might have encouraged a more general tendency to shift responses in the positive direction. Would reproduction responses still be attracted toward Sound 2 if the intervening sound could appear on either side of the target? Second, although the distributional findings suggested that some responses were centred near Sound 2, final reproduction errors could not reveal how participants arrived at those responses. Did participants fail to sample a sound close to the target, or could attraction toward Sound 2 persist even after they had encountered a target-like sound?

Experiment 2 addressed these questions by introducing bidirectional offsets and examining the sequence of sounds sampled during reconstruction.

Experiment 2

Experiment 1 left open whether attraction toward Sound 2 depended on the predictable directional relationship between the sounds. Because Sound 2 always appeared at a positive angular offset from the target, listeners may have learned this regularity and used Sound 2 as a reference when reconstructing the target. Alternatively, repeated exposure to the same directional relationship might have encouraged a more general tendency to shift responses in the positive direction. By introducing both positive and negative angular offsets, Experiment 2 removed this consistent directional relationship and allowed us to determine whether reproduction biases continued to follow the position of Sound 2 when it could appear on either side of the target. We also examined whether the distributional evidence for Sound 2-centred responses and the relationship between interference and task context generalized under these conditions.

The response trajectories offered a complementary way to constrain our understanding of interference. Two reproductions ending near Sound 2 could reflect different paths through the auditory response space. In one case, participants might never have sampled a sound close to the target. In another, they might have passed through the target region before ultimately selecting a response closer to Sound 2. We continuously recorded the sequence of sound positions sampled during reconstruction in order to distinguish trials in which participants passed through the target region from those in which they did not. We therefore examined whether attraction persisted even on trials in which a target-consistent sound had been sampled. Evidence of interference under these circumstances would indicate that attraction cannot be explained solely by a failure to sample a sound close to the target.

A complementary question concerned whether susceptibility to interference varied with the precision of the remembered target. Previous research on visual working memory has found that individuals with lower baseline memory precision exhibit greater attraction bias toward the task-relevant visual input (Fukuda et al., 2022). More recent work manipulating stimulus certainty has similarly reported greater interference when target information was less reliable (Ünver et al., 2026). These findings raise the possibility that the influence of intervening auditory information depends on how precisely the target is represented. Moreover, although explicit comparison did not reliably increase interference on average in Experiment 1, its contribution might vary with baseline precision. We therefore examined whether individual differences in baseline auditory precision were associated with attraction toward Sound 2, and whether this relationship differed between Compare and Ignore, combining data across both experiments.

Method

Sample Size Justification and Participants

We adopted the same sample-size target as in Experiment 1, aiming to obtain at least 34 participants with complete, usable data.

Thirty-five undergraduate students from the University of Toronto Mississauga participated in the study. One participant did not complete the study and was excluded, yielding a final analytic sample of 34 participants (27 women, 7 men; age range = 17-20 years, M = 18.32, SD = 0.77). Ten participants identified as musicians, and none reported having perfect pitch. All participants reported no hearing issues. Participants received course credit for participating, and all provided informed consent under a protocol approved by the University of Toronto Research Ethics Board.

Apparatus

The apparatus and testing environment were the same as those used in Experiment 1.

Stimuli

The auditory stimuli were the same Shepard-tone complexes used in Experiment 1, drawn from a circular space containing 360 unique tone values. On two-sound trials, the second sound differed from the to-be-remembered target by 30°, 60°, or 90° along the auditory continuum. Unlike Experiment 1, in which the second sound was always displaced in the positive direction, Experiment 2 included both positive and negative offsets (±30°, ±60°, and ±90°, see Figure 1B). This manipulation allowed us to examine attraction toward the intervening sound independently of its direction along the auditory continuum.

Procedure

The overall task structure and instructions were the same as in Experiment 1. Participants completed separate Ignore and Compare tasks, each consisting of five experimental blocks of 32 trials (160 trials per condition; 320 trials total). Each block contained eight one-sound baseline trials and 24 two-sound trials, with four trials at each of the six signed offsets.

On baseline trials, the 1,000-ms target was followed by a 2,000-ms retention interval. On two-sound trials, the target was followed by a 500-ms interstimulus interval, the 1,000-ms intervening sound, and a 500-ms retention interval. Thus, the interval between target offset and reproduction was 2,000 ms for both trial types.

As in Experiment 1, participants reproduced the first sound using the auditory response wheel and subsequently reported their memory confidence. On two-sound trials in the Compare condition, participants additionally judged whether the sounds were Similar or Dissimilar, whereas in the Ignore condition, they were instructed to disregard the second sound. Practice procedures were unchanged.

Analyses

Trial-level exclusions. Trials were screened using the same criteria as in Experiment 1.

We excluded 115 of 10,880 experimental trials (1.06%): Thirty trials because reproduction response times were shorter than 1 s and 85 trials because participants failed to respond within the 20-s response window. No additional trials were excluded because of invalid response information, leaving 10,765 trials for analysis.

Quantifying auditory memory bias. As in Experiment 1, reproduction error was calculated as the signed angular difference between the reported and target tones, wrapped to the range of -180° to +180° to account for the circular stimulus space. Because Sound 2 could occur on either side of the target, signed errors were multiplied by the sign of the target-to-Sound 2 offset. Positive aligned errors therefore indicated displacement toward Sound 2, regardless of its direction along the auditory continuum. Participant-level mean aligned errors were calculated separately for each task (Compare, Ignore) and absolute angular separation (30°, 60°, 90°).

1. Baseline reproduction performance.

As in Experiment 1, we examined reproduction performance on one-tone trials to establish baseline accuracy and precision and determine whether these differed between task contexts. For each participant, baseline trials were combined across Compare and Ignore to calculate mean signed error, mean absolute error, and the withinparticipant standard deviation of signed errors. Mean absolute error and within-participant standard deviation were also calculated separately for each task and compared using two-tailed paired-samples t-tests.

2. Does an intervening sound bias auditory working memory, and does task

relevance alter this bias? Experiment 2 tested whether the attraction observed in Experiment 1 replicated when Sound 2 could occur at either positive or negative offsets, and whether explicit comparison increased its magnitude. Within each task, participant-level mean aligned errors were tested against zero at absolute angular separations of 30°, 60°, and 90° using two-tailed one-sample t-tests, with Holm correction across the three separations.

To determine whether explicit comparison altered interference, and whether this depended on angular separation, we conducted a 2 (Task: Compare, Ignore) × 3 (Absolute Offset: 30°, 60°, 90°) repeated-measures ANOVA, combining sign-aligned positive-and negative-offset trials. The inclusion of bidirectional offsets also allowed us to examine whether the magnitude of attraction differed according to the direction of Sound 2. We therefore compared mean aligned errors between directions within each task and absolute separation using paired-samples t-tests, with Holm correction across the three separations within each task.

4. Does interference persist when reconstruction samples the target region?

To determine whether attraction toward Sound 2 persisted even when participants sampled a sound close to the remembered target during reconstruction, we examined the continuous trajectories recorded by the auditory response wheel. This allowed us to distinguish trials in which a targetlike auditory value was encountered during reconstruction from those in which it was not.

Trajectories from valid two-sound trials were matched to the corresponding trial information and final responses. Analyses were restricted to periods when participants actively engaged the auditory wheel. A trial was classified as Pass if the trajectory sampled a sound within ±12° of Sound 1 at any point during reconstruction; otherwise, it was classified as No-Pass. Because the full trajectory includes the final response, this classification is partly dependent on where participants ultimately respond. We therefore repeated the analysis using trajectory samples from 100 ms after initial wheel engagement until 70% of the total engaged response-wheel duration to determine whether interference persisted when the target region was encountered earlier in reconstruction, before the final portion of the response.

For each participant, mean reproduction bias toward Sound 2 was calculated separately for Pass and No-Pass trials within Ignore and Compare. Estimates were first calculated at each angular separation, requiring at least three trials per category, and then averaged equally across separations with sufficient observations. Participants contributed to these analyses when both trajectory categories could be estimated from at least two separations. All 34 participants qualified for these comparisons. Across participants, Pass trials accounted for an average of 51.8% of trials in Ignore and 53.4% in Compare. The corresponding percentages at 30°, 60°, and 90° were 51.8%, 53.9%, and 49.8% in Ignore, and 54.1%, 51.9%, and 54.1% in Compare, respectively. The remaining trials were classified as No-Pass. General Discussion

Previous research has demonstrated that an intervening tone can impair memory for an earlier sound, even when listeners are instructed to ignore it (Deutsch, 1970; Pechmann & Mohr, 1992). But what does this loss of accuracy actually reflect? Does the intervening sound make the original memory less precise, shift its remembered pitch, or do listeners sometimes report the subsequent sound in place of the original target? Recognition accuracy alone cannot readily distinguish these possibilities. We therefore used the continuous Auditory Reproduction Task (ART; Karabay et al., 2024) to investigate how intervening sounds influence auditory working memory and, critically, the nature of this interference.

Across two experiments, we replicated the finding that reproduction responses were systematically attracted toward the intervening sound. Crucially, mixture-model analyses revealed that this attraction was better explained by a model incorporating responses centred near the intervening sound (M4) than by a model assuming continuous displacement of target-centred responses (M3). M4 was also preferred over a graded-attraction model that allowed the magnitude of continuous shifts toward Sound 2 to vary across trials. Furthermore, adding a continuous-bias component to the swap model (M5) did not improve model fit. Together, these findings suggest that the observed attraction was better explained by a combination of target-centred responses and intrusions from the intervening sound than by continuous distortion of target representations alone. This pattern is consistent with competition between the target and intervening sound over which auditory event guides the final report. Importantly, however, such intrusions could arise through at least two mechanisms. First, competition during memory maintenance could result in the subsequent tone overwriting the target representation, such that the intervening sound guides the response instead. Alternatively, competition could occur during response selection, with both representations remaining available but the intervening sound being mistakenly selected for report. Thus, although both mechanisms could produce intrusions at the level of the final response, they differ in whether the original target representation remains available. Evidence from macaque visual working memory provides some support for the latter possibility, suggesting that swap errors can arise during the selection of remembered information for report, even when the relevant memory representations remain available (Alleman et al., 2024).

Does the task relevance of the intervening sound change the magnitude or nature of auditory interference? Neither experiment revealed a reliable overall difference in attraction as a function of task relevance (Compare vs. Ignore), and M4 remained the preferred model at larger separations in both conditions. These findings suggest that interference from subsequent auditory events does not require deliberate comparison, although they do not rule out more subtle effects of task demands. This pattern is particularly interesting when considered alongside visual working-memory findings, in which subsequent information has been shown to produce continuous attraction, sometimes amplified by explicit comparison (Fukuda et al., 2022; Saito et al., 2023). What might explain why the influence of subsequent information, and its sensitivity to deliberate comparison, appears to differ across auditory and visual working-memory tasks? One possibility is that auditory and visual working memory differ in how subsequent information is processed. Second, similar principles of interference may operate across modalities, but differences in baseline memory precision across tasks may shape how interference is expressed.

A third possibility is that the influence of task relevance varies with individual differences in memory precision, such that opposing effects of comparison may be obscured at the group level.

We consider these possibilities in turn.

First, auditory and visual working memory may differ in how subsequent information influences remembered representations. Because auditory information unfolds over time, interpreting sequences of sounds often requires sensitivity to relationships between successive events. Indeed, research has identified mechanisms supporting implicit comparisons between sound frequencies, even when individual pitches are difficult to identify explicitly (Demany et al., 2011). Such relational processing may occur even when listeners are not instructed to compare the sounds. If the intervening sound is already processed in relation to the remembered target even when it is task irrelevant, explicitly comparing the two sounds may produce relatively little additional attraction. This could help explain why making the intervening sound task relevant did not reliably increase interference, although whether such processing accounts for the apparent contrast with visual findings remains to be established.

Second, auditory and visual working memory may operate according to similar principles of interference, with differences in baseline memory precision shaping how interference is expressed. Previous studies suggest that baseline reproduction responses in ART are relatively variable, with larger errors and greater dispersion than those reported in several visual continuous-reproduction tasks (Karabay et al., 2024; e.g., Gorgoraptis et al., 2011; Karabay et al., 2022; Zhang & Luck, 2008). Greater uncertainty about the remembered target could increase its susceptibility to subsequent information, potentially allowing an intervening sound to exert a substantial influence even when it is task irrelevant. Under these circumstances, making the intervening sound task relevant may produce relatively little additional attraction. However, these cross-study differences cannot establish that auditory working memory is intrinsically less precise, as reproduction performance may also depend on perceptual discriminability and other task characteristics. When auditory and visual stimuli are more closely matched in perceptual discriminability and task demands, auditory working-memory performance equalled or exceeded visual performance (Uluç et al., 2025). Thus, apparent differences in interference across auditory and visual tasks need not reflect distinct underlying mechanisms, but may instead depend partly on the precision of the remembered representations within each task.

Third, the absence of an overall task-relevance effect may also conceal individual differences in how deliberate comparison influences auditory interference. Indeed, Fukuda et al. (2022) found that lower baseline visual working-memory precision was associated with greater attraction toward subsequent visual input following explicit comparison. Our exploratory analysis of the pooled data across experiments revealed that listeners' baseline auditory memory precision was associated with the relative influence of task relevance on attraction. Listeners with less precise baseline reproduction tended to show greater attraction when the intervening sound was task relevant than when it was task irrelevant, whereas those with more precise reproduction tended to show the opposite pattern. One possible explanation is that when the remembered target is relatively imprecise, making the intervening sound task relevant encourages greater reliance on the new auditory information, increasing its influence on the final response. Conversely, when the target is represented more precisely, explicit comparison may facilitate distinguishing the two sounds, potentially limiting interference relative to passive exposure. Complementing these findings, experimental manipulations of target certainty through motion coherence have shown that less certain visual working-memory targets are more susceptible to interference from subsequent information (Ünver et al., 2026). Although exploratory, our findings raise the possibility that deliberate comparison may increase attraction when target representations are less precise but reduce it when they are more precise, potentially explaining why no reliable overall difference emerged between task conditions.

More broadly, these findings suggest that understanding interference requires considering both the nature of its influence on memory-guided responses and the conditions under which this influence emerges. The exploratory relationship between baseline precision and task relevance raises the possibility that the effect of deliberate comparison depends on the reliability of the remembered target, a possibility that warrants direct experimental investigation. An important question is whether representational precision and task demands shape not only the magnitude of interference, but also its form, including the relative contributions of continuous attraction and Sound-2-centred responses. Crucially, our modelling results suggest that the observed interference cannot be fully explained by continuous distortion of the remembered target alone.

Instead, subsequent auditory events may compete with earlier ones as the basis for the final response, even when the intervening information is task irrelevant. Although explicit comparison did not reliably increase interference overall, our exploratory findings suggest that its influence may depend on individual differences in baseline memory precision. Thus, interference from subsequent information may concern not only how faithfully an earlier event is remembered, but also which auditory event ultimately guides the final response and the conditions under which this influence emerges.

1. Baseline reproduction performance

We first examined whether participants could reliably reproduce the target in the absence of an intervening sound and whether baseline performance differed between task conditions.

Across the 34 participants, 2,690 valid one-tone trials were retained. Combining baseline trials across Compare and Ignore within each participant, the mean signed reproduction error was 2.03°, mean absolute error was 40.57°, and mean within-participant standard deviation of signed errors was 56.54°. As illustrated in Figure 5, reproduction errors were concentrated around the target (0°), replicating the baseline performance pattern observed in Experiment 1.

Baseline reproduction accuracy and precision did not differ reliably between tasks. Mean absolute error was similar in Compare (39.93°) and Ignore (41.24°), t(33) = -0.87, p = .389, 95% CI [-4.36, 1.74], BF01 = 3.83. Likewise, baseline precision, indexed by the within-participant standard deviation of signed errors, showed no reliable difference between Compare (55.27°) and Ignore (56.86°), t(33) = -0.79, p = .435, BF01 = 4.08. Thus, we found no evidence that the additional comparison requirement altered baseline reproduction performance when no intervening sound was presented. These findings suggest that the magnitude of auditory attraction may depend on offset direction, with the clearest evidence for directional asymmetry occurring in Ignore at 60°.

3. Mixture models favour a Sound 2-centred response component at larger separations

As in Experiment 1, positive mean reproduction errors could reflect a continuous shift in target-centred responses, occasional reports centred on Sound 2, or both. Five candidate mixture models were compared using pooled trial-level aligned errors for each task and absolute separation. At 30°, model preferences were weak: BIC favoured the continuous-bias model (M3) +12.35° on No-Pass trials, t(33) = 4.67, p < .001. A similar pattern emerged in Compare, where mean bias was +3.59° on Pass trials, t(33) = 2.48, p = .018, compared with +11.35° on No-Pass trials, t(33) = 4.11, p < .001. The persistence of interference on Pass trials was also observed when the analysis was restricted to the first 70% of engaged reconstruction time (Ignore: M = +3.95°, p < .001; Compare: M = +4.02°, p = .015). Thus, attraction toward the intervening sound remained detectable even when participants encountered a target-like auditory value during reconstruction.
