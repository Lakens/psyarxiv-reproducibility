Files that do not belong in the repository

We left out 17 files that software creates by itself, not the authors: operating system (16), R history (1). They hold nothing a reader can use, but they clutter the repository, and software can mistake them for real files (for example a ._ copy of a .csv for data).

Remove these: Operating system files: macOS adds a __MACOSX folder and a ._ copy of every file it puts in a zip, and .DS_Store files to folders; Windows adds Thumbs.db and desktop.ini. On a Mac, create zips from the command line with zip -r -X, or remove them afterwards with zip -d archive.zip "__MACOSX/*" "*.DS_Store". RStudio session files (.Rproj.user/) hold open tabs and unsaved edits; R history (.Rhistory) lists the commands typed in a session and can hold file paths and passwords; Jupyter checkpoints (.ipynb_checkpoints/) are automatic copies of notebooks; compiled Python files (__pycache__/, .pyc) are recreated when the code runs; open-document lock files (~$...docx, .~lock...#) are left while a document is open; editor backups (file~, .bak, .swp) and temporary files (.tmp, .temp) are copies a program made by itself.

Keep only on purpose: version control folders (.git, .svn, .hg) hold the project’s history, which can include earlier versions of files and data that was later removed; editor settings (.idea, .vscode) can hold paths on your own computer. A .gitignore based on GitHub’s templates (https://github.com/github/gitignore) keeps them out of a repository.

To improve Non-Significant P Value Check

What we found

We found 21 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

To learn the overlapping pairs, participants completed eight cycles of alternating study and test (Fig. 1b).

During study, each pair was presented for 3.5 seconds (0.5s inter-trial interval [ITI]) and participants were instructed to think of a story linking the items.

After study, participants were tested on their memory with feedback.

Participants were informed of and practiced both neutral and specific question types prior to learning.

To assess how overlap influenced memory for shared and unique features, participants completed a self-paced, post-training memory test (0.5s ITI) with questions following three structures: neutral, specific, or general (Fig. 1c).

At the end of the experimental session, participants completed a task in which they visually discriminated between exemplars from high and low overlap categories.

A main effect of trial type in this model is akin to corrected hit rate in that it reflects to what degree participants are more likely to respond “different” for items that are actually different compared to those that are the same.

This module uses regular expressions to identify sentences that contain a statistical power analysis. The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Over time we accumulate many interrelated memories which we draw upon to remember both generalities and specifics of our experience. While both aspects of memory improve through childhood, their maturation into adolescence remains poorly understood. Here, we compared how 39 adolescents (12-13 years old) and 36 adults managed differing levels of relatedness ("overlap") among learned associations to remember shared (general) and unique (specific) features. Our results reveal continued maturation of both general and specific memory into adolescence while demonstrating how the overlaps among our experiences shape what we remember.

Introduction

Through our lifetimes we encounter and build memories for many similar, overlapping experiences. From this interconnected network of memories, it is useful to recall both the details of particular experiences as well as commonalties across related events. The adult memory system is organized to serve these dual demands, supporting memory for both specifics and generalities through complementary learning systems (Kumaran & McClelland, 2012; McClelland et al., 1995; Schapiro et al., 2017). However, and despite considerable theoretical interest (Brainerd & Reyna, 2013; Keresztes et al., 2018; Ramsaran et al., 2019; Sloutsky et al., 2024), it remains unclear how these aspects of memory develop relative to one another, especially into the relatively understudied period of adolescence. Here, we designed a task to directly test both specific and general aspects of memory for the same related experiences in young adolescents (12-13 years old) and adults.

While a large body of work has documented dramatic improvements in specific memory from early to mid-childhood (Benear et al., 2021; Brainerd & Reyna, 2005; Ghetti et al., 2010), less is known about adolescence. There is some evidence for continued refinement beyond mid-childhood, with adolescents showing less detailed autobiographical memory (Willoughby et al., 2012) and poorer lab-based performance when there is high demand for specificity (Ngo et al., 2018; Rollins & Cloude, 2018). Continued improvements in specific memory may be linked to maturation of the hippocampus (Bouyeure et al., 2021; Callaghan et al., 2021; Daugherty et al., 2017; Keresztes et al., 2017; Lee et al., 2020; Schlichting et al., 2017) which is thought to accentuate the unique features of similar memories, i.e., "differentiate", and thus reduce memory interference in adults (Chanales et al., 2021; Favila et al., 2016; Wing et al., 2020).

Top-down retrieval mechanisms may also improve through adolescence to better support selective retrieval of target information from among competing memories (Sprondel et al., 2012 (Sprondel et al., , 2013)). However, more work is needed to directly test which circumstances lead adolescents to exhibit immature memory specificity.

It is unclear whether adolescents may also demonstrate reduced capacity to extract generalities across memories compared to adults. The ability to rapidly connect related experiences in memory on the basis of their shared elements has a prolonged development (Bauer et al., 2020; Horn et al., 2021; Schlichting et al., 2022; Schlichting et al., 2017; Shing et al., 2019; Yim et al., 2013), which tracks with the maturation of brain regions and circuits (Gogtay et al., 2004; Gogtay et al., 2006; Ofen et al., 2012; Sowell et al., 2003) that are critical for integrating related memories in adults (e.g., the medial prefrontal cortex (PFC) (Spalding et al., 2018) and its connections with the hippocampus (Zeithamova, Dominick, et al., 2012)).

Thus, adolescents may be less likely than adults to form integrated memory representations that emphasize generalities, even when learning circumstances encourage such integration. Alternatively, some developmental theories (Keresztes et al., 2018) suggest that immature pattern separation mechanisms in the hippocampus may instead lead younger learners to preferentially remember generalities over specifics. Here, we addressed these potentially conflicting viewpoints by directly comparing memory for generalities in young adolescents and adults when they were not explicitly instructed to make connections among related learning materials.

The current study investigated the relative maturity of memory for generalities and specifics in young adolescents (12-13 years old) compared to adults. Participants learned overlapping object pairs and were then tested on their memory for shared (general) and unique (specific) features. To best uncover potentially subtle developmental differences, we manipulated the degree of similarity, or overlap, among learned associations. We expected that for adults greater overlap would encourage integration of related memories (Bennion et al., 2024; Molitor et al., 2021a; van Kesteren et al., 2020) and thus lead to strong general memory, but at the cost of detail (Konkle et al., 2010; Tompary & Davachi, 2017; Wing et al., 2020) compared to lower overlap. In contrast, we expected that adolescents would not connect related pairs and thus show no benefit of greater overlap for shared feature memory. Further, we hypothesized that adolescents would show a similar but exaggerated cost of overlap for specific memory, indicative of still-maturing fine-grained memory. In this way, we expected developmental differences in both general and specific memory would be revealed by how adolescents and adults managed overlaps among learned information.

Method

Participants

Data from 39 adolescents (17 girls, 20 boys, 2 nonbinary, 12.0-13.9 years old, M=12.8, SD=0.63) and 36 young adults (19 women, 17 men, 25.5-35.6 years old, M=29.9, SD=3.06) are presented here. Participants were invited to partake in the study if they met recruitment criteria (Supplementary Methods) created for the purposes of magnetic resonance imaging (MRI) analyses (results not reported here). Data from an additional two adolescents were excluded after participation due to diagnosis disclosed during participation (N=1) and previous participation in a pilot study (N=1). No participants were excluded for poor learning performance (defined as accuracy <70% on the final cycle of pair learning). Additionally, only for analyses on the visual discrimination task, data from two participants were excluded due to technical issues (N=1 adolescent) or misunderstanding of task instructions (N=1 adult). All participants provided informed consent/assent prior to participating and were compensated with $20/hour (CAD) and a performance-dependent bonus up to $3. Permission was obtained from the parent or guardian of all adolescents. All procedures were approved by our institution's ethics committee.

Stimuli

Stimuli were 24 object-object pairs each comprised of one natural object and one unrelated artifact (Fig. 1a). Natural objects were drawn from two categories with high (apple, shell) and two with low (leaf, rock) intra-category conceptual and perceptual similarity, according to prior work (Konkle et al., 2010). Artifacts were distinct everyday objects chosen to depict concepts likely known by age 12 (Kuperman et al., 2012). Natural object-artifact pairings were semi-random for each participant with the constraint that each artifact was paired with each category equally often across participants.

Procedure

Training. To learn the overlapping pairs, participants completed eight cycles of alternating study and test (Fig. 1b). During study, each pair was presented for 3.5 seconds (0.5s inter-trial interval [ITI]) and participants were instructed to think of a story linking the items. After study, participants were tested on their memory with feedback. For each self-paced test trial (0.5s ITI), they were cued with an artifact and asked to select the paired item from two studied objects via keypress. Feedback (1s) included a sound indicating whether they responded correctly or not and a green checkmark and red ex appearing below the correct and incorrect options, respectively. To facilitate initial learning, questions followed a "neutral" structure (cycles 1-4) in which the options belonged to different natural categories (e.g., was the book was paired with apple 1 or shell 1?), allowing participants to answer correctly by remembering either the general category or specific item. The second half of learning then encouraged memory for unique features by using "specific" test questions in which participants chose between objects from the same category (e.g., apple 1 or apple 2?). Participants were informed of and practiced both neutral and specific question types prior to learning.

The order of trials within both study and test was semi-random, with the constraint that no more than two pairs from the same category appeared consecutively. Left/right position of objects on the screen was randomized. A given pair was tested against eight different lure items (four different-category, four within-category) across test cycles.

Post-training Memory Task.

To assess how overlap influenced memory for shared and unique features, participants completed a self-paced, post-training memory test (0.5s ITI) with questions following three structures: neutral, specific, or general (Fig. 1c). Neutral and specific questions were constructed in the same manner as training. "General" questions assessed memory for the feature shared amongst overlapping associations: Participants selected the category paired with a given artifact (e.g., was the book paired with "APPLE" or "SHELL"?).

General questions more cleanly assessed memory for the category than neutral questions because the options were presented in text and could not also be answered by recognizing item-unique features. The memory test did not include feedback.

All 24 pairs were tested once with each question type over three blocks. The order that a pair was tested with neutral, specific, and general questions was balanced across pairs. Within a block, question type was semi-randomly ordered to roughly balance the transitions between questions (e.g., neutral-specific, neutral-general). During (b) training, participants learned pairs through alternating cycles of study and test, first with neutral (cycles 1-4) and then specific (cycles 5-8) test questions. After training, the (c) memory task included specific, general, and neutral test questions (intermixed across three blocks). For illustration purposes, an example of each question type for the same pair is depicted in (c). In the actual task, the three questions on the same pair were never presented consecutively but instead each shown in a different 24-trial block.

Visual Discrimination Task. At the end of the experimental session, participants completed a task in which they visually discriminated between exemplars from high and low overlap categories. We used performance on this task to assess whether effects of overlap on memory could be explained by greater visual confusability of high compared to low overlap exemplars. We reasoned that if participants were similarly accurate in discriminating high and low overlap items, this would indicate that any effects of pair overlap on memory did not appear merely because participants were less accurate in identifying items from high compared to low overlap categories as different from one another. Similar to previous work using analogous tasks (Laurent et al., 2006; Tanaka et al., 2005), we use the term "visual discrimination" to describe this task because it was designed to reflect relatively immediate visual processing to a greater extent than long-term memory.

Participants indicated with a keypress whether sequentially presented images were identical or different (Fig. 3a). For each trial, a target object was presented (1s) followed by a visual mask (0.5s) and then a probe (1s). If a response was not made within 1 second, the probe was replaced with a question mark until a response was made (1s ITI). Visual masks were created by randomly sampling images from the target category (e.g., apples) to generate 24 scrambled images per category, which were then randomly assigned to trials testing that category.

Each object was tested once each against itself (same-item trials), every other object in the same category (within-category different trials), and one object from a different category (across-category different trials). Trials were semi-randomly intermixed with the following constraints: Targets from the same category did not appear consecutively; and within each of three task blocks, there were two same-item trials per category, five within-category trials per category, and four across-category trials.

Analysis

Our statistical analysis approach is described in detail in the Supplementary Methods. In summary, we ran mixed effects models in R (Bates et al., 2015) to test how trial-by-trial performance was predicted by factors of interest, while including random intercepts for participant and random slopes for within-participant main effects. For significant interactions, follow-up pairwise comparisons were conducted to characterize the nature of the interaction using model estimated marginal means (emmeans::emmeans v1.6.0; Lenth, 2021). For training performance, model predictors included overlap (high/low), age group (adolescent/adult), training cycle, and their interactions. For memory test performance, predictors included overlap, age group, and question type. For visual discrimination performance, predictors included trial type (same-item/within-category different), overlap, age group, and their interactions. A main effect of trial type in this model is akin to corrected hit rate in that it reflects to what degree participants are more likely to respond "different" for items that are actually different compared to those that are the same. Interactions with trial type indicate whether this discrimination accuracy differs by factors of interest. We excluded across-category comparisons which were irrelevant to this analysis.

Results

Greater Overlap Yields Interference Throughout Learning

We first established whether learning across training cycles differed according to degree of overlap among pairs. We expected different learning profiles across neutral and specific question training, with high and low overlap pairs learned with similar ease under initial neutral training, but high overlap yielding greater interference relative to low through later specific training. We instead found similar patterns across both neutral and specific question training.

Participants were more likely to remember the correct object-artifact pairings as training progressed (Fig. S1a; quadratic effect of training cycle for neutral: b=-18.27, 95% CI [-31.10, -5.43], z=-2.79, p=.005 [quadratic predictor improved model fit: c 2 (15)=27.91, p=.02]; linear effect for specific: b=0.50, 95% CI [0.34, 0.65], z=6.32, p<.001 [quadratic predictor did not improve fit: c 2 (15)=8.34, p=.9]) and adults were more accurate compared to adolescents (neutral: b=0.38, 95% CI [0.12, 0.64], z=2.82, p=.005; specific: b=0.28, 95% CI [.04, 0.52], z=2.28, p=.02).

Participants were also less accurate on high compared to low overlap pairs through both initial neutral (b=0.46, 95% CI [0.31, 0.61], z=6.00, p<.001) and later specific (b=0.92, 95% CI [0.74, 1.10], z=9.97, p<.001; no significant two-or three-way interactions among overlap, cycle, and age group for neutral [all z<1.9, p>.06] or specific [all z<1.0, p>.3]) cycles. Notably, at the transition from neutral to specific training we found a brief decline in accuracy (Supplementary Results) consistent with increased demand on more fine-grained memory and thus greater sensitivity to interference. Considering response times on correct trials revealed similar effects (Fig. S1b; Supplementary Results), and additionally indicated that (1) adults sped up over specific training at a steeper rate than adolescents and (2) participants were particularly slowed by the transition to specific questions for high compared to low overlap pairs. In sum, our manipulation elicited the intended interference among high compared to low overlap pairs, which manifested early in learning and persisted throughout.

Opposing Effects of Overlap on Memory for Shared and Unique Features

To address our main question, we tested whether post-training memory for shared features (general questions) and unique features (specific questions) differed according whether learned associations shared a high or low degree of overlap. Accuracy was very high overall (Fig. 2a; adolescents: M(SE)= 96.3(0.5)%; adults: 97.5(0.4)%), with all but one adolescent and one adult performing perfectly on one or more conditions. Given potential ceiling issues, we primarily focused on how quickly participants made correct responses as a more sensitive measure of differences across age groups and conditions. However, we report accuracy results briefly here for completeness.

In contrast to training, adolescents were no longer significantly less accurate than adults on the memory test (b=0.17, 95% CI [-0.13, 0.47], z=1.10, p=.3) nor were there reliable age group differences in effects of overlap or question type on accuracy (all z<1.5, p>.1). Collapsed across age groups, we found that the effect of overlap differed by question type (question x overlap interaction: b=0.51, 95% CI [0.28, 0.75], z=4.33, p<.001; question: b=0.15, 95% CI [-.09, 0.38], z=1.21, p=.2; overlap: b=0.18, 95% CI [-.06, 0.41], z=1.49, p=.1) in an intuitive pattern: Participants were less likely to remember the specific exemplar (z=-3.79, p<.001) but more likely to remember the correct category (z=2.21, p=.03) for high compared to low overlap pairs.

Response times also showed diverging effects of overlap across question types (Fig. 2b; question x overlap: b=-.08, 95% CI [-0.09, -.07], t(3220.22)=-12.60, p<.001; question: b=-0.12, 95% CI [-0.14, -0.10], t(71.50)=-14.52, p<.001; overlap: b=-.06, 95% CI [-.07, -.04], t(72.95)=-6.84, p<.001) where higher overlap slowed specific (z=-13.16, p<.001) but sped general (z=2.40, p=.02) responses. This pattern converges with accuracy results to suggest that greater overlap boosted general memory while impeding specific. However, the effect of overlap on response time also differed significantly across age groups (age group x overlap: b=.02, 95% CI [.002, .03], t(72.95)=2.18, p=.03; age group: b=-.07, 95% CI [-0.12, -.01], t(72.92)=-2.43, p=.02; no interaction between age group and question or age group, question, and overlap: all t<0.3, p>.8): Adults were significantly faster to respond than adolescents for high (z=2.85; p=.004) but only marginally faster for low (z=1.78; p=.07) overlap pairs. To better understand the meaning of this age group difference, we considered specific and general questions separately.

This revealed an interesting pattern whereby adults (z=-2.96, p=.003) but not adolescents (z=-0.39, p=.7) were sped by high relative to low overlap on general questions, such that adults responded faster than adolescents on high (z=-2.65, p=.008) but not low (z=-1.53, p=.1) overlap trials. Further, both adolescents (z=10.58, p<.001) and adults (z=8.07, p<.001) were slowed by higher overlap on specific questions, but this was numerically greater for adolescents such that they responded significantly slower than adults on high (z=-2.64, p=.008) while only marginally slower for low (z=-1.80, p=.07) overlap. Together, these results indicate that when remembering associations with greater overlap, adolescents both benefited little when recognizing shared features and showed a sizable cost for recognizing unique elements. In addition to specific and general questions, we explored whether performance on neutral questions differed as a function of overlap and age group. We reasoned that whether performance on neutral questions resembled general or specific questions may indicate whether adults and adolescents tend to rely on general or specific feature memory when the task can be resolved by either. We found that performance largely mirrored specific questions for both age groups (Fig. 2c): Higher overlap slowed correct responses (b=-.06, 95% CI [-.08, -.05], t(72.77)=-7.11, p<.001; see Supplementary Results, Fig. S2 for accuracy). While adults responded faster than adolescents overall (b=-.07, 95% CI [-0.13, -.02], t(72.92)=-2.84, p=.006) the magnitude of the overlap effect did not differ reliably across age groups (b=.009, 95% CI [-.008, .03], t(72.77)=1.05, p=.3). Interestingly, unlike general and specific questions, adults were significantly faster than adolescents on low overlap trials (t(73)=2.47, p=.02) in addition to high (t(73)=2.90, p=.005), hinting that adults may approach these questions in a distinct manner from adolescents.

Adults More Sensitive to Overlap than Adolescents at Visual Discrimination

Finally, we sought to establish whether effects of overlap on memory could be attributed to greater visual confusability among high compared to low overlap exemplars. It is possible that participants showed poorer memory performance on specific questions and better memory performance on general questions for higher overlap pairs in part because the exemplars were more difficult to tell apart visually. To test this question, we compared visual discrimination performance for exemplars from high and low overlap categories (Fig. 3b; see Fig. S3 for performance separated by trial type). Specifically, we modeled trial-by-trial responses ("same"/"different") as a function of trial type (same-item or within-category different), overlap, age group, and their interactions. Within this model, we first confirmed that participants completed the task correctly: Exemplars from the same category were indeed reliably discriminated from one another (correctly identified as "different" more often than identical items: b=3.02, 95% CI [3.21, 2.84], z=32.18, p<.001) by both adults (z=23.46, p<.001) and adolescents (z=22.26, p<.001).

Moreover, adults performed better overall than adolescents (more likely to correctly judge within-category as "different" [z=3.74, p<.001] and same-item as "same" [z=-4.28, p<.001]; age group x item type: b=0.46, 95% CI [0.28, 0.65], z=4.92, p<.001; age group: b=.02, 95% CI [-0.12, 0.15], z=0.23, p=.8).

Interestingly, we found an effect of overlap on visual discrimination that differed across age groups (overlap x age group x trial type: b=0.15, 95% CI [.02, 0.28], z=2.20, p=.03; overlap x trial type: b=-0.19, 95% CI [-0.32, -.05], z=-2.78, p=.005; overlap x age group: b=-.06, 95% CI [-0.19, .07], z=-0.84, p=.4; overlap: b=0.12, 95% CI [-0.01, 0.25], z=1.81, p=.07). Adults were less accurate in discriminating category exemplars from high compared to low overlap categories (z=-3.09, p=.002) while adolescents showed no such effect (z=-1.03, p=.3; no effect of overlap on same-item trials [adolescents: z=0.26, p=.8; adults: z=0.99, p=.3]). Our overlap manipulation also had the expected effect on response times for both adolescents and adults (Fig. 3c): Participants were slower to correctly discriminate high compared to low overlap exemplars (b=.01, 95% CI [.02, .007], t(318.94)=-3.79, p<.001) with no reliable difference across age groups (age group x overlap interaction: b=.003, 95% CI [-.005, .01], t(318.94)=0.67, p=.5; adolescents slower than adults overall: b=.08, 95% CI [.02, 0.14], t(71.00)=2.63, p=.01). This suggests that while higher overlap items were perceived as more similar by both age groups, thus slowing their discrimination decisions, only adults were also less accurate in telling higher overlap items apart. Notably, these results suggest that while visual discrimination may contribute the effects of overlap on memory-highlighted by similar slowing for high compared to low overlap pairs in both the discrimination and specific memory tasks-it does not fully account for developmental differences in memory. Discussion

We investigated developmental differences in how adolescents and adults manage memory overlap to both extract generalities and discriminate specifics. Consistent with our hypotheses, we found that high overlap hindered memory for unique features across age groups and especially slowed recognition for adolescents. In the opposite direction, we found that greater overlap enhanced memory for shared features. Intriguingly, this benefit was weaker in 12-13 year-olds, who did not show reliable speeding for shared feature recognition, suggesting they may generalize across related memories differently than adults.

As expected, adults showed interference in specific memory due to greater overlap among learned materials. In fact, interference was evident early in learning and persisted through multiple opportunities for restudy and retrieval. These results align with previous work finding that similar materials compete in memory (Chanales et al., 2021; Konkle et al., 2010; Wing et al., 2020) and can degrade memory precision (Sun et al., 2017). Complicating this interpretation, adults were also less able to visually discriminate more highly overlapping items, suggesting that effects of overlap on memory may have been driven in part by greater difficulty telling apart high compared to low overlap items. However, adults also demonstrated memory interference due to higher overlap on neutral questions, which did not require them to visually distinguish similar items. Nevertheless, our findings echo work in older adults (Gellersen et al., 2021; Hill et al., 2021) suggesting that the specificity with which information is processed at perception has downstream consequences for the fidelity of memory. Importantly, while greater visual similarity among high compared to low overlap items may drive interference in both visual discrimination and specific memory, conceptual similarity may also play a role (Gauthier et al., 2003). Here, we were not poised to tease apart similarity along conceptual and perceptual lines because we manipulated both in tandem. However, future work may pit these forms of relatedness against one another, akin to previous work on item memory (Delhaye et al., 2024; Konkle et al., 2010; Naspi et al., 2021), to test which drives interference in detail memory to a greater degree.

Adolescents were also hindered by overlap when remembering unique features. Further, adolescents were even slower than adults when recognizing unique features of highly overlapping memories. Our results are consistent with a sparse but growing body of evidence that memory specificity continues to be refined through adolescence (Rollins & Cloude, 2018).

Developmental improvements may be driven in part by maturation of the hippocampus and its capacity to represent highly similar events as distinct (Callaghan et al., 2021; Keresztes et al., 2017; Lee et al., 2014). Interestingly, adults showed signs of steeper learning for specifics than adolescents (Fig S1b), which could indicate they are more effective at using repeated learning opportunities to differentiate related memories (Chanales et al., 2017; Favila et al., 2016). If adolescents do not represent related memories as sufficiently different, they may need to rely more than adults on still-maturing (Sprondel et al., 2012 (Sprondel et al., , 2013) ) retrieval processes to select a target memory from among competing traces (Badre et al., 2005; Buckner & Wheeler, 2001).

Future research should tease apart the dual developmental trajectories of representational specificity and retrieval selection to characterize how these factors interact to produce continued improvements in detailed memory even beyond late childhood.

In striking contrast to memory for specifics, we found that greater overlap with other learned associations boosted rather than impeded memory for a shared feature. We predicted this pattern would emerge for adults because they would be more likely to connect highly related experiences (Bennion et al., 2024; Molitor et al., 2021a; Ritvo et al., 2019; van Kesteren et al., 2020) through learning and the resulting integrated traces would enhances memory for shared elements. Interestingly, participants were never explicitly prompted to integrate and if anything, task instructions and cycles of specific-level training encouraged participants to distinguish between related pairs (Hulbert & Norman, 2015). While previous work has found that learning goals shape resultant memory representations (e.g., Abolghasem et al., 2023; Richter et al., 2016), we find that high similarity among learned information may encourage integration even when this is not necessarily relevant for behaviour. While we do not have direct insight into the strategies employed by participants during learning, our findings are consistent with ideas that incidental memory integration can facilitate knowledge building beyond what we have directly experienced (Munnelly & Dymond, 2014; Shohamy & Wagner, 2008).

Somewhat in line with our predictions, adolescents did not show the same speeded shared feature recognition as adults due to overlap, suggesting they may generalize across their related memories in a different manner. One possibility is that adults integrated highly overlapping associations during learning itself and these memory representations then facilitated fast recognition of shared features later. By contrast, if adolescents only generalized at retrieval, this could have given rise to still highly successful but slower shared feature recognition. Consistent with this account, previous work has found that younger learners are less likely to connect related experiences during learning (Horn et al., 2021; Schlichting et al., 2022; Schlichting et al., 2017; Shing et al., 2019; Yim et al., 2013) but do so when prompted (Bauer et al., 2020; Wilson & Bauer, 2021). We extend this work to suggest that such delayed generalization may give rise to developmental differences in how the shared and unique elements of related experiences are remembered later.

We find evidence at the condition level for a trade-off between memory for shared and unique features-memory overlap appears to boost one at the cost of the other. Our results align with integrative encoding theories (Shohamy & Wagner, 2008; Zeithamova, Schlichting, et al., 2012) which predict that overlap between a current and past experience during learning triggers the formation of integrated representations (Eichenbaum, 2000) that enhance memory for shared features at the cost of idiosyncrasies (Carpenter & Schacter, 2017; Varga et al., 2019). Moreover, the likelihood of forming integrated representations increases with greater overlap among experiences (Leutgeb et al., 2004; Ritvo et al., 2019; Vazdarjanova & Guzowski, 2004). Interestingly, the developmental differences we observed under higher memory overlap suggest that adults may organize tightly related experiences is such a way that bolsters memory for both shared and unique features (Ferreira et al., 2019) compared to adolescents, perhaps by simultaneously integrating and differentiating memory representations in the brain (Molitor et al., 2021b; Schlichting et al., 2015). To this point, being able to leverage multiple representations for the same memory may have also allowed adults to respond faster on neutral questions than adolescents-facilitating recognition on the basis of both shared and unique features together.

While the current study does not provide direct insight into the latent representations driving behaviour, future work may test the predictions generated by our findings by comparing the neural memory representations formed and accessed by adolescents and adults.

Flexible recall of both the commonalities across related memories as well as their unique features is critical for making use of our past to inform behaviour (Buckner, 2010; Eichenbaum, 1999; McClelland et al., 1995). Here, we demonstrate that greater overlap among related experiences enhances memory for their shared features but comes at the cost of specifics. However, differences in this pattern for 12-13 year olds suggest both memory for specifics and generalities continue to be refined even beyond early adolescence signaling extended disparities in how related memories are organized through development. Moreover, we find developmental differences in memory could not be explained by parallel differences in visual discrimination ability. Overall, this work highlights how overlaps among our many interconnected experiences fundamentally shape how and what we remember in distinct ways across development. socioeconomic status influences cognitive and neural development (Rakesh et al., 2023), future research is also needed to examine how memory may differ for adolescents from varied socioeconomic backgrounds.

Constraints on Generality

The current findings are based on the visual recognition memory performance of healthy 12-13 year old adolescents and 25-35 year old adults from the Toronto city area who met our inclusion criteria (Supplementary Methods). Given these criteria, we expect our findings to generalize primarily to young adolescents and young adults with no diagnosed psychiatric, psychological or neurological disorders and who have normal or corrected to normal vision. We also required participants to self-report fluency in English to ensure they understood task instructions and could respond to memory questions on verbal category labels, which may limit the generalizability of our findings. Future work will be needed to examine the generalizability our findings to other periods of the lifespan, including but not limited to childhood, older adolescence, and older adulthood.

While adolescents in our study fell within a narrow age range (12.0-13.9 years old), they self-reported variable stages in pubertal development (Supplementary Information). Because puberty may further influence age-related differences in memory (Selmeczy et al., 2019), we conducted an exploratory analysis to test whether our findings differed by or generalized across adolescent pubertal stage. We found limited relationships between memory and self-reported pubertal status overall but did find that females but not males further in pubertal development showed better memory for generalities (Supplementary Information). As we did not design our study with the explicit aim of testing such relationships, future targeted work is needed to examine how puberty may uniquely contribute to development of memory organization and specificity through adolescence, potentially using more sensitive metrics of pubertal status such as hormone levels.
