How Ethics Approval Check works

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

Human research committee names - Institutional Review Board / IRB (US standard) - Independent Ethics Committee / IEC (ICH-GCP international clinical trial term) - Ethical/Ethics Review Board (generic) - Ethics (Advisory/Review) Committee/Board/Panel/Sub-committee - Research Ethics Committee/Board/Panel (UK/Canada/Australia) - Medical Ethics Committee - Human Subjects/Research Committee / Human Research Ethics (Advisory) Panel - Committee for/on the Protection of Human Subjects - Committee on (Health) Research Ethics - Office of Research Ethics - Abbreviations: IEC, REC, REB, ERB, METC, DEC. REC/REB/ERB/DEC are short enough to collide with unrelated jargon (e.g. REC as a recognition-heuristic model abbreviation, DEC as a decision-task label, Reb as an author surname), so these four require an ethics/approval/committee/board/panel/institutional/ protocol word within ~30 characters in the same sentence. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Checking code requires downloading its file contents. For a paper whose repository is on Dryad, this never succeeds unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (listing the repository’s files does not need one). Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Identity shift theory holds that selective online self-presentation can shift self-perception toward the portrayed identity, but its mechanisms assume that the presenter wrote the presentation.

Generative AI now lets people publish self-presentations they did not fully compose. In a preregistered 2 (extraversion vs. introversion) × 3 (manual writing, AI outline, AI draft) experiment (N = 388), participants assigned to present extraversion rated themselves as more extraverted than those assigned to present introversion (d = 0.32), and the size of this identity shift did not differ across authorship conditions. AI involvement changed the writing process.

Participants in both AI conditions searched their memories more deliberately for fitting examples, and participants who edited an AI draft felt less ownership of their text than those who wrote from an AI outline. Neither process accounted for the shift. The presenter need not be the sole author of a self-presentation for it to shape self-perception.

Who Writes the Self? Identity Shift Persists Under AI-Assisted Writing

Generative AI (GenAI) is reshaping how people present themselves online. Selfpresentation, the strategic curation of behavior and messages to shape how others see us, is a social process with psychological consequences. How people portray themselves feeds back into how they see themselves, especially when the portrayal is public (Bem, 1972; Goffman, 1959; Schlenker, 1985; Tice, 1992). Identity shift theory (IST) extends this logic to computer-mediated communication, proposing that selectively presenting oneself online shifts self-perception toward the presented traits (Gonzales & Hancock, 2008). IST was developed, however, in an era of human-authored communication, and its mechanisms presuppose that the person presenting the identity is also the person who wrote the presentation. GenAI text-based writing tools (hereafter "AI," for brevity) remove that assumption, because a self-presentation may now be generated or revised by a system other than the self.

Unlike simpler text-editing or autocomplete features, AI can generate, refine, and rephrase text iteratively and in context-sensitive ways, which creates competing possibilities for IST. On one hand, identity shift is thought to arise partly through processes engaged while composing the presentation. When constructing a self-presentation, especially one they know is public, writers selectively retrieve memories consistent with the trait they are portraying (i.e., engage in biased scanning), attend to how they are describing themselves, and revise the text (Carr et al., 2021; Gonzales & Hancock, 2008). If generating the text is delegated to AI, these processes may be short-circuited, and identity shift may weaken because the writer has invested less in the portrayal.

On the other hand, AI may amplify these same processes. The hyperpersonal model suggests the affordances of mediated communication (e.g., editability and asynchronous composition) encourage reflection and enable selective self-presentation (Walther, 1996), and AI potentially extends these affordances by letting users review and revise descriptions of themselves at scale and often with relatively minimal effort. From this perspective, AI involvement could intensify the reflective engagement thought to facilitate identity shift, even when individuals do not maintain full authorship as previously theorized. If so, identity shift may depend less on who wrote the text than on whether the person engages with it, identifies with its substance, and publicly commits to it (i.e., through posting it online).

The present study therefore tests whether the amount of authorship a person retains while composing a selective self-presentation affects subsequent identity shift. Adapting prior designs (Gonzales & Hancock, 2008; Tice, 1992; Walther et al., 2011), we randomly assigned participants to present themselves as extraverted or introverted in one of three authorship conditions: Participants wrote the presentation themselves (Manual), wrote from an AI-generated outline (AI-Outline), or edited an AI-generated draft (AI-Draft). This design isolates human-AI authorship effects, and in doing so, extends identity shift theory into the age of generative AI by examining whether the "self" must be the author of a self-presentation in order for it to reshape the self.

Literature Review Identity Shift in CMC

Early theories of online communication recognized that computer-mediated communication (CMC) allows people to strategically manage how they present themselves. Walther's (1996) hyperpersonal model describes how the affordances of mediated communication enable highly selective self-presentation in that senders can emphasize desirable traits and downplay undesirable ones, often producing intensified impressions in receivers. These performances can also feed back into the sender's own self-concept, in line with the lookingglass self, the idea that people develop self-views partly from how they believe others see them (Cooley, 1922; Mead, 1934). Gonzales and Hancock (2008) termed this shift in self-perception following online selective self-presentation identity shift.

IST's fundamental proposition is that selective mediated self-presentation leads people to see themselves more in line with the identity they portray (Carr et al., 2021). Four further propositions, publicness, identifiability, feedback, and identification with the claim, specify when the effect is stronger (Carr et al., 2021). Subsequent research has elaborated the boundary conditions and moderators of identity shift (see Carr et al., 2021, for a comprehensive review).

Similar to offline work on self-perception change following self-presentation (Tice, 1992), the publicness of an online self-presentation has proven crucial: Posting a selfpresentation publicly (e.g., on a blog visible to others) leads to greater observable self-concept shifts than writing privately for oneself, consistent with the idea that public commitment intensifies internalization (Gonzales & Hancock, 2008). Identifiability, the extent to which a selfpresentation is tied to the presenter's real identity, heightens self-awareness (Carr et al., 2021).

Confirming feedback amplifies identity shift, especially from close ties, whereas disconfirming feedback can dampen or even reverse it (Carr & Foreman, 2016; Walther et al., 2011). Finally, identification with the claim holds that the presented self must be a plausible or desirable possible self, one the person could envision becoming (Carr et al., 2021), because as Carr et al. (2021, p. 209) point out "no number of self-statements can likely convince the sender they are actually a 2-ton Rhinocerotidae."

Across this body of work, participants wrote the self-presentation themselves, so IST has never had to ask whether the person presenting the identity must also be its author for the effects to hold. However, as communication technologies increasingly incorporate AI systems capable of producing self-presentational text, this assumption warrants and invites direct examination.

We suggest that the processes thought to drive internalization, such as investing effort in the wording and drawing on one's own experiences, are engaged in the act of composing. The more of that composition a writer delegates to AI, the less these processes should be engaged, so we predict that identity shift will weaken as authorship moves from the self to the system: H1 (Authorship gradient): Post-task alignment with the assigned trait (i.e., identity shift) will be strongest in the Manual condition, intermediate in the AI-Outline condition, and weakest in the AI-Draft condition.

AI-Mediated Self-Presentation and Identity Shift

Online self-presentations may now range from fully self-written to fully AI-generated.

We focus on the composition stage, where authorship most directly intervenes, and hold constant the conditions outside it (e.g., feedback). All presentations are public, identifiability is fixed, and no third-party feedback is given. Within the composition stage we examine three constructs, drawing on prior identity shift work (Carr et al., 2021; Ross & DeAndrea, 2026).

The first, psychological ownership, was not considered in IST's original theorizing. In the early experiments, when participants wrote their own words, ownership and authorship were inseparable, but today's AI tools allow them to be disentangled for the first time. The second, biased scanning, the selective retrieval of trait-congruent memories during composition (Jones et al., 1981; Tice, 1992), was foundational to early identity shift theorizing but was not retained as a formal proposition (Carr et al., 2021; Walther & Lew, 2022). Following more recent calls to return to it (Ross & DeAndrea, 2026), we measure its deliberate component directly. The third, identification with the claim, concerns the fit between a portrayal's content and the self (Carr et al., 2021), and it was the moderator Ross and DeAndrea (2026) found most consistent across their studies.

Psychological Ownership

Psychological ownership is the feeling that something "belongs to me" (Pierce et al., 2003). It develops through control, investment of effort, and intimate knowledge (Pierce et al., 2003; Van Dyne & Pierce, 2004), and a conventional self-presentation task engages all three.

When individuals compose a self-presentational message, they exercise control over what aspects of themselves they highlight, invest effort in selecting memories and crafting language, and develop intimate knowledge of the resulting text through revision and reflection. From this perspective, the resulting self-presentational message can come to feel like an artifact that reflects and reinforces one's identity (Pierce et al., 2003).

A writer can now publish polished self-presentational texts they contributed very little to composing, and early evidence suggests that perceived ownership declines as AI's share of the writing grows (Draxler et al., 2024; Joshi & Vogel, 2025), even as writers sign the text under their own names (Draxler et al., 2024). If psychological ownership can be diminished in this way, the question for IST is whether internalization of the self-presentation (i.e., identity shift) still occurs. For example, if a professional asks an AI tool to draft a LinkedIn bio that casts them as ambitious and driven, the bio that appears under their name may read as accurate, even flattering, while still feeling less like something they made and more like something they received. We therefore treat authorship and psychological ownership as separate constructs in order to better understand how each contributes to identity shift.

A text experienced as "mine" can objectify and stabilize aspects of identity, inviting defense, justification, and incorporation into the self (Peck & Shu, 2009; Pierce et al., 2003), much as taking responsibility for a statement prompts people to adjust their private selfperceptions in order to maintain coherence (Festinger & Carlsmith, 1959; Schlenker et al., 1994; Tice, 1992). By contrast, when a self-presentation is experienced as produced and owned by an external agent, discrepancies or shortcomings may be more readily attributed to the AI, reducing the need to reconcile or integrate the portrayal into the self-concept. We predict that reduced authorship should therefore weaken identity shift partly by weakening the felt connection between text and self: H2 (Ownership mediation): Psychological ownership will mediate the effect of authorship condition on post-task trait alignment (i.e., identity shift), such that lower authorship → lower psychological ownership → weaker identity shift.

Deliberate Memory Search

A second mechanism is biased scanning, the selective retrieval of trait-congruent autobiographical memories during composition (Jones et al., 1981; Tice, 1992). Classical accounts of biased scanning propose that when people are asked to portray a trait, they search memory for confirming experiences, which then serve as internal evidence that they possess the trait.

Although central to early identity shift theorizing (Gonzales & Hancock, 2008) and the subject of recent calls to return to it (Ross & DeAndrea, 2026; Walther & Lew, 2022), biased scanning has never been measured directly in this body of work; prior studies inferred it from the shift outcome itself. This is likely in part because classical accounts of the process describe it as largely automatic and thus not suitable for self-reported measures. Therefore, we operationalize the component self-report can reach, which we call deliberate memory search, the effortful, motivated selection of trait-congruent memories and suppression of counter-trait ones during composition (e.g., "I deliberately searched for memories that showed me being [trait]"). AI authorship offers a natural test of this mechanism because it changes what the writer must do to produce the text. When people compose a selective self-presentation themselves, the page is empty until they supply content, and retrieval of trait-consistent content from their own past is forced by the task. In contrast, when AI supplies trait-congruent content, whether as an outline or as a full draft, writers may draw less on their own memories. Tice (1992) found that participants who drew on their own experiences to construct a self-presentation internalized the trait more strongly than those who delivered a presentation scripted by someone else. That study differs from ours in three ways. The presentation was delivered face to face rather than online, the script was written by another person rather than by AI, and participants delivered the script as written, without revising it. Our AI-Outline and AI-Draft conditions fall between Tice's two poles, because participants received machine-generated content but still wrote or revised the text before publishing it. If deliberate memory search drives internalization, the more content AI supplies, the less participants should search their memories, and the weaker the shift should be: H3 (Deliberate memory search mediation): Deliberate memory search will mediate the effect of authorship condition on post-task trait alignment (i.e., identity shift), such that lower authorship → reduced deliberate memory search → weaker identity shift.

Identification With a Claim

Within IST, identification with the claim is the extent to which the portrayed identity is perceived as a plausible or desirable possible self (Carr et al., 2021). People are more likely to adopt and defend identities that fit existing self-schemas or desired futures (Markus & Nurius, 1986), to seek verification of identities that feel consistent (Swann, 1983), and to distance themselves from claims that violate salient self-standards (Higgins, 1987).

Identification with a claim is distinct from the two mechanisms above. Where ownership concerns whether the text feels like one's own, and deliberate memory search concerns how its evidence was gathered, identification concerns whether the portrayed identity fits the self. Individuals may feel little ownership or engage in minimal deliberate memory search yet still judge a portrayal as a plausible or desirable self. AI-mediated writing makes this fit especially consequential because AI readily generates coherent, trait-congruent portrayals. For instance, suppose someone asks an AI tool to write their dating profile, and it returns one describing them as outgoing and spontaneous. If they already see themselves as someone who could be that way, internalization may occur independent of composition. If the presenter identifies with the content of the self-presentation, then endorsing and publishing it under their own name may be enough to produce shift regardless of who wrote the words. If the profile describes someone they cannot imagine being, internalization may rely more heavily on drawing on past experiences and ownership that full authorship provides. People low in identification should therefore be most exposed to the loss of authorship: H4 (Identification with a claim): Identification with the claim will moderate the authorship → identity shift relationship, such that the authorship gradient (H1) will be weaker when identification is high and stronger when identification is low. Note. H2 and H3 are mediation hypotheses; H4 is a moderation hypothesis. Method This study employed a 2 (trait portrayal: extraversion vs. introversion) × 3 (authorship condition: Manual vs. AI-Outline vs. AI-Draft) between-subjects experimental design. The design, hypotheses, and analysis plan were preregistered on the Open Science Framework (see Data Availability Statement).

Participants

Participants were recruited using Prolific's U.S. representative sampling option, which balances quotas for age, sex, and ethnicity to approximate U.S. census distributions (49.2% female, 48.7% male, 1.8% non-binary, 0.3% other or not reported; M age = 45.9, SD = 15.9, range = 19-85; 61.9% White, 12.6% Black, 6.4% Hispanic/Latino, 5.7% Asian, 11.3% multiracial, 2.1% other or not reported; 59.5% held a bachelor's degree or higher).

A preregistered power analysis (G*Power; Faul et al., 2009) for a one-way ANOVA across the three authorship conditions (f = 0.25, α = .05, power = .95) required 252 participants.

We planned 360 (60 per cell) and data collection continued until we collected at least 60 completed observations per cell, as preregistered. Of the 464 participants who reached their assigned condition, 394 completed the study; six completers were excluded (five failed the attention check; one recorded no survey responses), yielding N = 388 (Manual n = 132; AI-Outline n = 130; AI-Draft n = 126). Attrition analyses appear in the Supplemental Materials.

Participants were paid $12/hr for the 30-minute study, which ran on oTree, an open-source platform for online behavioral experiments (Chen et al., 2016). All participants gave informed consent, and procedures were approved by the institutional review board at the University of Michigan.

Procedure

Following prior identity shift experiments (Gonzales & Hancock, 2008; Tice, 1992; Walther et al., 2011), the study description told participants that the project examined psychology graduate students' ability to identify personality traits from online writing, and that their writing would be published on a public blog under their first name. This cover story, standard in identity shift research, was implemented to lend credibility to the public-posting manipulation and mask the study's focus on self-perception so that post-task self-ratings would not reflect demand characteristics.

After consenting, participants completed demographics and the pre-task possible selfpresentation measure following Ross and DeAndrea (2026) and were then randomly assigned to one of six conditions by block randomization (blocks of six, one instance of each condition).

Participants then completed the writing task and the post-task survey. Finally, they encountered a debriefing explaining that the public posting had been simulated and that their responses had not been shared outside the research team.

Selective Self-Presentation Task

Participants were instructed to portray either extraversion or introversion in a blog-style writing task. Assigning a trait allows identity shift to be detected as a between-group difference in post-task self-perception. If presenting a trait shifts the self-concept, extraversion-assigned participants should later rate themselves as more extraverted than introversion-assigned participants. Participants read a description of the assigned trait, completed an understanding check, and answered four open-ended questions about friends, family, hobbies, and school, and were instructed to draw from real past experiences consistent with the trait rather than fabricating responses. Upon submission, participants saw a simulated blog page showing their post as a published entry under their first name, with the date and a visitor count. Task instructions, outlines, drafts, and the publication screen are reproduced in the Supplemental Materials; Figure Note. Participants were randomly assigned to one of six conditions. Cell ns are analytic-sample sizes; 464 participants reached their assigned condition and 394 completed the study (see Supplemental Materials for attrition analyses).

Manipulations

Assigned Trait

When writing their posts, extraversion-assigned participants were told to emphasize times they were outgoing, energetic, talkative, or socially engaged; introversion-assigned participants, times they were reflective, thoughtful, reserved, or preferred quiet activities. In both conditions, participants were told that even if they did not usually see themselves this way, they should focus on moments when they did.

Authorship Condition

The authorship manipulation formed a gradient of decreasing authorship, from full composition (Manual) to composition guided by AI-generated ideas (AI-Outline) to revision of AI-generated prose (AI-Draft). In the Manual condition, participants wrote their responses entirely in their own words using a standard text-entry interface. In the AI-Outline condition, each prompt was accompanied by three ChatGPT-generated bullet points framed as an outline to guide participants' thinking toward the assigned trait while they composed responses in their own words. In the AI-Draft condition, each prompt was accompanied by a fully AI-generated text portraying the assigned trait and written in the first person; participants were instructed to revise the draft to reflect their own life and experiences while preserving the overall tone, with explicit guidance to adjust specific details rather than rewrite the paragraph entirely. If participants attempted to submit without revisions or to delete the entirety of the text in the AI-Draft condition, they were given a reminder of the instructions to revise and the AI text was restored.

Each response required at least 50 words, with no time limit. Because copy-and-paste was disabled in all conditions and attempted pastes were logged, participants could not import text from outside tools, including AI assistants, into their responses (see Behavioral Engagement). All outlines and drafts were generated in advance with ChatGPT (GPT-4o, July 2025) using standardized prompts and were identical for all participants within a condition; they are reproduced in the Supplemental Materials.

Measures

Full item wording for all measures appears in the Supplemental Materials.

Post-Task Extraversion and the Identity Shift Index

Post-task self-perceived extraversion was assessed with the bipolar adjective scales used in identity shift research (Fazio et al., 1981; Gonzales & Hancock, 2008; Walther et al., 2011).

Following Gonzales and Hancock (2008), participants were told after the writing task that a "true" rating of their personality was needed for later analysis and rated themselves on 10 extraversion-related bipolar adjective pairs using 11-point scales. After reverse-coding, ratings were summed to an extraversion score from 10 to 110 (M = 69.97, SD = 19.13, α = .88), with higher values reflecting a more extraverted self-perception.

The preregistered identity shift index rescales post-task extraversion so that higher values reflect self-perceptions more consistent with the assigned trait: the post-task score minus 60 for extraversion-assigned participants and 60 minus the post-task score for introversion-assigned participants (i.e., the signed deviation from the scale midpoint, oriented toward the assigned trait). Orienting the index by assignment is essential because, as in prior work with this scale (Gonzales & Hancock, 2008; Ross & DeAndrea, 2026; Walther et al., 2011), introversionassigned participants scored above the midpoint in every condition (all Ms > 65); an unsigned distance from the midpoint would conflate trait-consistent and trait-inconsistent ratings in that group.

Psychological Ownership

Psychological ownership was measured with five items adapted from Joshi and Vogel (2025) on 7-point scales (1 = strongly disagree,7 = strongly agree; the quality item,1 = very low,7 = very high; M = 5.84, SD = 1.07, α = .85). One item asks about the quality of the post rather than ownership per se and correlated only .39 with the remaining four; we therefore report a four-item composite (α = .88; r = .98 with the five-item version) as a robustness check alongside the preregistered scale. Higher scores reflect greater psychological ownership of the self-presentational content.

Deliberate Memory Search

Four items developed for this study and preregistered measured deliberate memory search, the motivated selection of trait-congruent memories during composition (e.g., "I deliberately searched for memories that showed me being [trait]";1 = strongly disagree,5 = strongly agree; M = 3.26, SD = 0.85, α = .70). The items index the deliberate component of biased scanning (directed search, selective focus, suppression of counter-trait memories, strategic selection).

Memory Accessibility

Five items, not preregistered, adapted from the accessibility subscale of the Memory Experiences Questionnaire (Sutin & Robins, 2007) asked how easily trait-relevant memories came to mind (e.g., "These memories were easy for me to recall"; 1-5; M = 4.09, SD = 0.73, α = .84), with negative items reverse-coded so that higher scores indicate easier retrieval.

Identification With a Claim

Following Ross and DeAndrea (2026), identification with the claim was assessed with two indicators. Possible self-presentation was measured before random assignment, and fluency of self-presentation after the task. For possible self-presentation, participants rated the stem "It is possible for me to present myself as..." for six adjectives from three of Fazio et al.'s (1981) bipolar pairs (extraverted/introverted, sociable/unsociable, talkative/quiet;1 = strongly disagree,7 = strongly agree); the three adjectives matching the participant's subsequently assigned trait were averaged into a matched composite (extraversion-assigned: M = 4.83, SD = 1.46, α = .86; introversion-assigned: M = 4.35, SD = 1.66, α = .88), with higher scores indicating that presenting the assigned trait felt more possible.

For fluency of self-presentation, participants completed eight items adapted from Shulman and Sweitzer (2018), following Ross and DeAndrea (2026) (e.g., "Overall, I found the task to be difficult," reverse-coded; M = 5.17, SD = 1.12, α = .88), with higher scores indicating a more fluent self-presentation. The two indicators capture identification with a claim at two stages, whether the assigned identity felt like a possible self before writing and whether it felt natural to enact afterward.

Editing Intensity (AI-Draft Condition Only)

To assess behavioral engagement with the AI-generated text, editing intensity was operationalized as the normalized character-level Levenshtein distance between each participant's submitted text and the original AI-generated draft, expressing the proportion of the text that was modified (M = 48.0%, SD = 17.8%).

Covariates

Because orientations toward AI could shape engagement with AI-assisted selfpresentations, we measured AI attitudes (M = 4.76, SD = 1.46, α = .92) and AI knowledge confidence (M = 5.12, SD = 1.06, α = .91) with items from Hong et al. (2021) on 7-point scales.

Because the conditions differed in how much composition they required, we measured perceived task demand with the NASA-TLX mental demand item (Hart & Staveland, 1988; 1-7; M = 3.90, SD = 1.62). None of the three differed by authorship condition (Fs ≤ 1.21, ps ≥ .299), and all conclusions were unchanged with them included as covariates (Supplemental Materials).

Deviations From Preregistration

One departure from the preregistration should be noted. The preregistered measures specified both possible and fluent self-presentation as indicators of identification with the claim, but the analysis plan left out possible self-presentation and named only fluency for H4; we test both. All other analyses not specified in the preregistration are identified as such where they are reported.

Manipulation Checks

Linguistic Manipulation Check

To verify that participants enacted the assigned trait in their writing, posts were analyzed with LIWC-22 (Boyd et al., 2022) on the linguistic markers of extraversion used by Walther et al. (2011), derived from Pennebaker and King (1999). These were word count, social processes, positive and negative tone, tentative language, causation, articles, and negations. Trait assignment had a significant multivariate effect, Wilks's Λ = .856, F(8, 379) = 7.96, p < .001, and the central markers differed as predicted. Extraversion-assigned participants used more social language (d = 0.48, p < .001) and positive tone (d = 0.29, p = .004), and introversionassigned participants more tentative language (d = 0.52, p < .001), with negations trending as expected (d = 0.20, p = .051). Word count and negative tone did not differ by trait condition, and causation and articles differed in the direction opposite to prediction; Walther et al. (2011) likewise found no differences on these two categories. Taken together, the primary social and affective markers confirm that participants produced linguistically trait-consistent selfpresentations.

From the four discriminating categories we derived a trait-consistent enactment score, z(social) + z(positive tone) -z(tentative) -z(negations), signed by trait assignment so that higher values indicate writing more consistent with the assigned trait (construction in Supplemental Materials). Enactment differed by authorship condition, F(2, 385) = 3.43, p = .033, with AI-Outline texts more strongly trait-typed than Manual texts (M = 1.11 vs. 0.31, Tukey p = .026); AI-Draft texts (M = 0.78) did not differ from Manual (p = .278). Because more strongly trait-typed texts could mask an authorship effect, we control for enactment under H1.

Perceived Publicness

Participants agreed that others would see their post (M = 5.76, SD = 1.65) and that researchers would read it (M = 6.46, SD = 1.10), both above the scale midpoint of 4 (ps < .001); perceived identifiability was below the midpoint (M = 3.58, SD = 2.14, p < .001), a pattern consistent with Walther et al. (2011). None of the three items differed by authorship condition (all Fs ≤ 2.16, ps ≥ .117). Participants also reported drawing on real experiences in all conditions (M = 4.71, SD = 0.63 on a 5-point scale; all condition Ms ≥ 4.47), with AI-Draft participants marginally lower than Manual (Tukey p = .066) and lower than AI-Outline (p < .001).

Behavioral Engagement

Telemetry indicated comparable engagement across conditions (373 intact logs; 15 logs were excluded: 14 reset by a page reload; one not recorded). Time from task start to publication of the text did not differ significantly by condition (Manual M = 11.78 min; AI-Outline M = 13.68; AI-Draft M = 12.53), F(2, 370) = 2.05, p = .130, nor did the number of writing pauses, F(2, 370) = 2.11, p = .123; total pause duration was marginally longer in the AI conditions, F(2, 370) = 2.93, p = .054. Blocked copy-and-paste attempts were rare (Mdn = 0) and did not differ by condition.

Two text-based indices confirmed that participants engaged with the AI content as intended. AI-Outline participants incorporated far more outline content than Manual participants, whose responses could resemble the unseen outlines only through chance topical overlap, t(260) = 8.03, p < .001, d = 0.99, and lexical similarity to the AI draft was high only in the AI-Draft condition (Ms = .30-.36 vs. ≤ .03 elsewhere), converging with the editing-intensity results (construction in Supplemental Materials).

Results

Analytic Strategy

All preregistered tests (H1-H4) use the identity shift index described under Measures.

Authorship is coded 0 (Manual), 1 (AI-Outline), and 2 (AI-Draft), so H2 and H3 predict a negative path a, a positive path b, and a negative indirect effect. Mediation models were estimated with the mediation package in R (Tingley et al., 2014) with 5,000 bootstrap resamples, as preregistered, with trait assignment as a covariate in the outcome model. Analyses not specified in the preregistration are marked as such; robustness checks appear in Table S1.

Identity Shift

Trait assignment produced the canonical identity shift effect. Extraversion-assigned participants (M = 73.06, SD = 19.41) rated themselves as more extraverted after the task than introversion-assigned participants (M = 66.97, SD = 18.41), a difference of 6.09 scale points, t(386) = 3.17, p = .002, d = 0.32 (Figure 3; Table 1). We refer to this quantity, the difference in mean post-task extraversion between the two trait-assignment groups, as the trait difference.

Computed within a single authorship condition (from the cell means in Table 1), it expresses the size of the identity shift effect in that condition. Note. Bars show condition means; error bars represent ±1 SE. The dashed line marks the scale midpoint (60). N = 388.

H1: Authorship Gradient

H1 predicted that identity shift would decline from Manual to AI-Outline to AI-Draft.

The preregistered one-way ANOVA on the identity shift index was nonsignificant, F(2, 385) = 0.05, p = .952, ηp² < .001 (Manual M = 2.48, AI-Outline M = 3.32, AI-Draft M = 2.87), as was the corresponding Trait × Authorship interaction on post-task extraversion, F(2, 382) = 0.06, p = .938.

The trait difference was 5.25 scale points in Manual, 6.35 in AI-Outline, and 6.89 in AI-Draft (Table S1), so the point estimates ran opposite to the predicted gradient. Within conditions, the trait difference was significant in AI-Outline, 95% CI [0.32, 12.39], p = .039, d = 0.37, and AI-Draft, 95% CI [0.10, 13.68], p = .047, d = 0.36, but not in Manual, 95% CI [-1.69, 12.18], p = .137, d = 0.26 (Table S1). Because each within-condition comparison had limited power (.43-.45 at d = 0.32), this pattern does not indicate that the effect differed by condition, consistent with the null Trait × Authorship interaction.

Controlling for how strongly each text expressed the assigned trait (enactment; see Manipulation Checks) did not change this result, F(2, 384) = 0.05, p = .949 (Table S1). The data provide no evidence that AI involvement weakens identity shift, but they cannot establish equivalence (see Limitations). H1 was not supported.

H2: Psychological Ownership

H2 predicted a mediation chain: greater AI involvement would reduce psychological ownership (path a), and lower ownership would, in turn, weaken identity shift (path b). The preregistered indirect effect was null, ACME = 0.04, 95% CI [-0.29, 0.34] (Table 2), and the chain broke at its second link: ownership was unrelated to identity shift, b = -0.31, SE = 0.91, p = .732.

The first link, the effect of authorship on ownership, emerged, but as a step rather than the predicted gradient. Ownership differed across authorship conditions, F(2, 385) = 3.36, p = .036: Manual (M = 5.89) and AI-Outline (M = 5.97) did not differ, and only AI-Draft was lower (M = 5.64; Tukey vs. AI-Outline p = .034, vs. Manual p = .154). Because the preregistered model coded authorship as a linear 0-1-2 gradient, this step pattern diluted path a, which fell short of significance, b = -0.12, SE = 0.07, p = .069. Recoding authorship to match the observed step, with AI-Draft against the other two conditions combined (not preregistered), produced a significant path a, b = -0.29, p = .013, but the indirect effect remained null, ACME = 0.09, 95% CI [-0.62, 0.77] (Table S1): however authorship was coded, ownership did not predict shift.

Two further tests converged on the same conclusion. Ownership did not moderate the trait effect on post-task extraversion (Ownership × Trait p = .908; Table S1); it was associated with more extraverted self-ratings equally in both trait groups, and therefore not with the difference between them that defines the shift. And within the AI-Draft condition, participants who edited the AI-generated text more extensively reported greater ownership (r = .25, p = .005; not preregistered), yet editing was unrelated to shift (r = .12, p = .178). AI drafting reduced felt ownership, but ownership did not carry the shift; H2 was not supported. -0.27], with a null total effect (b = 0.36, p = .78; Table 2). The pattern held when both AI conditions were contrasted against Manual (ACME = -1.45, 95% CI [-2.72, -0.47]) and when the outcome was modeled as a Deliberate Memory Search × Trait interaction on post-task extraversion, where search pulled self-ratings away from the assigned trait in both groups (Table S1).

H3: Deliberate Memory Search

Because deliberate memory search correlated with pre-task possible self-presentation (r = -.15), the negative association could reflect pre-existing trait standing rather than the search process. When we controlled for pre-task possible self-presentation of both traits (not preregistered), the Deliberate Memory Search × Trait interaction shrank by 71% and fell to marginal significance, b = -2.75, SE = 1.59, p = .086 (path b on the index, b = -1.37, SE = 0.80, p = .085), whereas the effect of authorship on search was unchanged (b = 0.18, p < .001). We also tested an alternative account (not preregistered), that difficulty retrieving trait-consistent memories, rather than deliberate selection, drives the association. It was not supported. Memory accessibility did not differ by condition or moderate shift, and controlling for it left the interaction unchanged (Table S1). H3 was not supported.

H4: Identification With the Claim

H4 predicted that identification with the claim would buffer the effect of low authorship.

Neither Authorship × Fluency, F(2, 382) = 0.53, p = .588, nor Authorship × Possible Self-Presentation, F(2, 381) = 0.58, p = .560, was significant, which is somewhat unsurprising given that there was no authorship effect to buffer. H4 was not supported.

Following Ross and DeAndrea (2026), we then tested whether the two indicators moderated the identity shift effect itself (Trait × Indicator on post-task extraversion, controlling for authorship; not preregistered). Possible self-presentation did so strongly, b = 14.33, SE = 0.98, p < .001, ΔR² = .313, predicting more extraverted self-ratings among extraversion-assigned participants (b = 7.45) and less extraverted self-ratings among introversion-assigned participants (b = -6.88). Fluency did so weakly, b = 3.18, SE = 1.36, p = .020, ΔR² = .008, with positive slopes in both groups (b = 4.53 and 1.36) rather than the opposing slopes of a shift moderator, which only partially replicates Ross and DeAndrea (2026). We return to the interpretation of the possible self-presentation result in the Discussion.

Discussion

The central question of this study was whether identity shift requires full human authorship, or whether the effect persists when composition is partially delegated to AI. Our findings show identity shift effects persist under AI-assisted writing. Across all three authorship conditions, participants who portrayed extraversion subsequently rated themselves as more extraverted than those who portrayed introversion (d = 0.32), and the trait difference was of similar size in each condition and did not detectably differ across authorship conditions (ds = 0.26, 0.37, and 0.36; Table S1) (H1). This held even though AI involvement changed how the presentation was produced. Participants felt the text was less their own under AI drafting and searched their memories more deliberately for fitting examples under AI assistance. We take each finding in turn.

Psychological Ownership

In previous identity shift studies, authorship and psychological ownership were fused in that participants wrote their own text, so the person presenting the identity was always the person who experienced the text as theirs. The present experimental design decouples these constructs, because participants could present an identity in text they did not write, and indeed, our empirical results echo this dissociation. Ownership was lowest when AI drafted the text. AI-Draft participants reported less ownership than AI-Outline participants, and the difference from Manual participants was in the same direction but not significant. This supports recent findings that AI involvement reduces felt ownership of self-relevant text (Draxler et al., 2024; Joshi & Vogel, 2025). Yet identity shift did not differ across conditions, and ownership was unrelated to the shift on every test (path b p = .732; Ownership × Trait p = .908; Table S1). Feeling that a self-presentation is one's own, in other words, is not a necessary condition for internalizing it.

At the same time, ownership responded to behavior. Within the AI-Draft condition, participants who edited the AI-generated text more extensively reported greater ownership of it (r = .25, p = .005), consistent with the idea that people come to feel ownership of things they have invested effort in (Pierce et al., 2003). Ownership rose with the amount of human contribution, then, but it was not what produced the shift. One interpretation is that what internalizes a self-presentation is enacting and committing to it, rather than feeling ownership of its words. A portrayal one revises, endorses, and publishes under one's own name may reshape self-perception even when the words were first written by someone, or in this case, something, else. Two caveats apply. First, ownership remained high in every condition (all Ms ≥ 5.6 on a 7point scale), plausibly because every condition required revision, which restores ownership of AI-assisted writing (Joshi & Vogel, 2025), so the data show that shift persists when ownership is reduced, not when it is low. Second, the reduction was specific to drafting, since an AI outline left ownership intact. One explanation is that psychological ownership tracks the words rather than the ideas. A writer working from an outline still writes every sentence and so keeps the control, effort, and familiarity that build ownership (Pierce et al., 2003); a writer editing a draft does not. This is consistent with evidence that ownership declines specifically as AI's share of the written text grows (Draxler et al., 2024; Joshi & Vogel, 2025), and it suggests ideational assistance and compositional assistance are not interchangeable inputs to felt ownership.

Deliberate Memory Search

Ross and DeAndrea (2026) called for a return to biased scanning as the explanatory center of identity shift. The present study provides a first self-report index of the deliberate component of that process, and the results do not support the classical account. Neither link of the preregistered mediation ran in the predicted direction. AI involvement increased deliberate memory search rather than reducing it, and more deliberate search predicted less identity shift, a significant negative indirect effect alongside a null total effect, or inconsistent mediation (MacKinnon et al., 2007). This negative association, however, mostly reflected participants' preexisting beliefs about the possibility of presenting as extraverted and introverted. Once we controlled for how well each trait fit participants before the task, it shrank by 71% and fell to marginal significance, while the effect of authorship on search was unchanged. Difficulty of retrieval (Schwarz et al., 1991) did not account for the pattern; memory accessibility did not differ by condition or moderate shift (r with deliberate search = -.10). The safer conclusion is that deliberate search did not strengthen identity shift, not that it weakened it.

Items in the deliberate memory search measure probe whether participants searched for, focused on, and selected trait-consistent memories while setting aside inconsistent ones. High scores therefore capture participants' awareness that they were curating their memories, which is likely strongest when the assigned trait fits a participant poorly, consistent with the measure's negative correlation with pre-task possible self-presentation (r = -.15). This fits a discounting account. Self-perception theory holds that people treat retrieved memories as evidence about themselves only when those memories feel like a fair sample (Bem, 1972; Fazio et al., 1981), and a writer who knows they went looking for confirming examples may experience them as examples they chose and assembled rather than as evidence of who they are. On this reading, biased scanning is effective precisely when it is not deliberate. The AI conditions turned writing into an explicit matching task ("here is a portrayal: find the parts of your life that fit it") and may have made participants aware of their selectivity without making the selected memories persuasive. We offer this as a hypothesis for designs that manipulate awareness of selectivity directly.

Identification With the Claim

Replicating Ross and DeAndrea (2026), pre-task possible self-presentation strongly moderated identity shift. Participants who rated the assigned trait as more possible to present showed a larger gap in post-task self-ratings between trait conditions, the largest effect in the design (ΔR² = .313). This is consistent with IST's identification-with-the-claim proposition (Carr et al., 2021) and with Ross and DeAndrea's conclusion that it is the theory's most robust moderator.

Two caveats qualify this moderation, however. The first concerns what the moderator actually measures. The possible self-presentation items were designed to capture a belief: whether participants felt they could present themselves as extraverted or introverted.

Because we did not measure baseline personality, however, high scores may instead reflect personality itself -people who are extraverted will naturally report that presenting extraversion is possible for them. Two patterns in the data are consistent with this reading. Each pole correlated with posttask extraversion at .66 (possible extraversion) and -.63 (possible introversion), correlations as large as those typically found between two measures of the same trait, and nearly identical to the values Ross and DeAndrea (2026) report. And when each pole was tested separately, neither moderated the trait effect (ps ≥ .54; Table S1), the pattern expected if the matched composite works by sorting participants on how extraverted they already are rather than by capturing identification with a claim. This concern applies only to the moderation. Because trait portrayal was randomly assigned, the identity shift effect itself does not depend on how the moderator is interpreted.

Both readings, however, imply the same underlying condition: the assigned identity matched the participant's sense of self, whether as a belief about what they could enact, as their actual standing on the trait, or both. That match is what the identification-with-the-claim proposition concerns, so we interpret matched possible self-presentation as an index of identity fit while remaining agnostic about its source. Ross and DeAndrea (2026) ground this proposition in personal standards from objective self-awareness theory, and our findings fit that framing as committing to an identity within one's personal standards promotes internalization, whereas committing to one outside them can reverse it, as in the boomerang effects observed at low identification (Ross & DeAndrea, 2026). Separating the two accounts would require a baseline personality measure collected well before the task.

Implications for Identity Shift Theory's Propositions

Read against IST's propositions (Carr et al., 2021), the findings reinforce some claims and raise new questions about others. For the fundamental proposition, that selective selfpresentation produces identity shift, the results add a boundary specification. The presenter need not be the sole author. Enacting, personalizing, and publicly committing to a trait-consistent portrayal produced shift that did not detectably differ whether participants wrote from scratch, elaborated an AI outline, or edited an AI draft. What remains untested is the case in which a person contributes nothing to the text, since every condition here involved compositional engagement. A design in which participants publish AI-generated self-presentations unedited would establish whether it requires any compositional engagement and whether the self can be merely the endorser rather than the editor.

Practical Implications for AI-Mediated Self-Presentation

AI-assisted self-presentation is becoming routine in precisely the contexts identity shift theory describes: public, identity-relevant, and asynchronous portrayals such as dating profiles and professional materials. Research on these contexts has long documented strategic enhancement, such as online daters embellishing identity characteristics (Ellison et al., 2006; Toma et al., 2008) and jobseekers inflating credentials (Guillory & Hancock, 2012), and has treated such embellishment primarily as a message aimed at an audience. To the extent that AI tools generate enactable self-presentations at scale, users may come to see themselves in line with portrayals they did not fully compose. Unlike online dating, where an eventual modality switch to face-to-face interaction supplies a corrective moment for idealized presentations (Ramirez & Zhang, 2007), many AI-assisted self-presentations have no equivalent point of disconfirmation. Moreover, our findings suggest the embellishment may not remain outwardfacing: AI-mediated self-presentations can shape how users see themselves, even when users recognize that the text is not entirely their own.

From a well-being perspective, this means that AI tools designed to help users craft positive, aspirational self-descriptions could facilitate beneficial identity exploration, such as trying on possible selves (Markus & Nurius, 1986) one could not have articulated independently.

On the other hand, the robustness of identity shift across authorship conditions raises the possibility that individuals could internalize self-presentations generated by AI systems optimizing for engagement or social desirability rather than authenticity, with implications for self-concept coherence over time. Both possibilities warrant study in more naturalistic settings.

Limitations

Several limitations qualify these findings. The study used a single-session, simulated blog-posting task, whereas real-world self-presentation is repeated and more socially consequential. The AI-generated content was produced by a single model and held constant within conditions; in practice it varies in quality, tone, and personalization; additionally, interactive generation, iterative prompting, or undesirable portrayals may moderate the effects observed here. Finally, as noted previously, every condition required either writing or revision, so the design cannot determine whether any compositional involvement is necessary for identity shift; the unedited-publication design described above would provide that test.

A second set of limitations concerns measurement. The deliberate memory search measure captures effortful, reportable search rather than the automatic retrieval classically theorized (Jones et al., 1981), and it was administered after the post-task self-rating, so it may partly reflect participants' inferences about their own process. The design also omitted a baseline personality measure, following standard identity shift methodology (Gonzales & Hancock, 2008; Ross & DeAndrea, 2026; Walther et al., 2011), which avoids priming and self-consistency effects but prevents separating identification with the claim from trait standing. Finally, completion was marginally lower under extraversion assignment and extraversion-assigned dropouts reported lower pre-task possible extraversion, so selective attrition could modestly inflate the overall trait difference; attrition did not differ by authorship condition, leaving the H1-H4 comparisons unaffected (Supplemental Materials).

The third limitation concerns what the null authorship effect can show. The preregistered power analysis assumed a medium-sized authorship effect on the identity shift index, but any realistic attenuation of the d = 0.32 shift constitutes a small difference of differences, which requires a substantially larger sample to detect (Sommet et al., 2023); sensitivity and equivalence analyses in the Supplemental Materials converge on this point. The null result therefore shows that we did not detect an authorship effect, not that none exists.

Conclusion

This study extends identity shift theory into the era of AI-mediated communication by asking whether the self must author a self-presentation for that presentation to reshape the self.

Within the bounds of this design, the answer is no: Identity shift replicated at an effect size comparable to prior work whether participants wrote from scratch, elaborated an AI-generated outline, or edited an AI-generated draft. AI involvement changed how the presentation was produced, lowering felt ownership and increasing deliberate memory search, but neither process accounted for the shift, consistent with the possibility that the effects followed instead from enacting, personalizing, and publicly committing to the portrayal. Whether AI weakens or amplifies the effect is a question for studies powered to detect a difference of differences. As AI becomes a routine co-author of how people describe themselves, the self-presentations people publish may shape who they believe they are, regardless of who wrote the words.
