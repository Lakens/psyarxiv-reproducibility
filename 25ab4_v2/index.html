Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

How Ethics Approval Check works

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

Human research committee names - Institutional Review Board / IRB (US standard) - Independent Ethics Committee / IEC (ICH-GCP international clinical trial term) - Ethical/Ethics Review Board (generic) - Ethics (Advisory/Review) Committee/Board/Panel/Sub-committee - Research Ethics Committee/Board/Panel (UK/Canada/Australia) - Medical Ethics Committee - Human Subjects/Research Committee / Human Research Ethics (Advisory) Panel - Committee for/on the Protection of Human Subjects - Committee on (Health) Research Ethics - Office of Research Ethics - Abbreviations: IEC, REC, REB, ERB, METC, DEC. How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Full text

Abstract

How new experiences can update a memory has important consequences for its long-term storage, but little is known about how different kinds of re-exposure may differentially influence its content. Inspired by theories of memory reconstruction that posit that memory retrieval depends on the integration of idiosyncratic details and relevant general knowledge, we investigated how exposure to a memory through category-or item-level processing may strengthen its episodic and semantic components. Across three behavioral experiments, participants encoded image-location associations in a protocol designed to generate a conflict between memory for specific images and knowledge of the general location of other images from the same category. Following learning of the locations, participants completed manipulations aimed to prioritize category-level or item-level processing of the images. We hypothesized that requiring semantic processing after learning would reinforce prior category knowledge associated with each image and increase category-driven distortions in memory at test. Our findings revealed that memory for images that underwent semantic processing were less precise and more distorted relative to memories that underwent item-level processing and relative to those that were not re-exposed after encoding. Furthermore, post-encoding manipulations more strongly updated memories of atypical category members, suggesting that the organization of prior knowledge can govern the extent that new memories can be updated.

Together, these results highlight the active role of post-encoding manipulations in differentially reshaping memory content and provide compelling evidence that episodic memory retrieval is a constructive process that integrates across prior knowledge, discrete experiences, and subsequent re-exposure.

Introduction

Rather than being perfect records of an experience, episodic memories are dynamic and malleable, subject to changes each time they are retrieved. Imagine you try a rambutan, a spiky red fruit, for the first time at a late-summer street market during a trip to Costa Rica. How might your memory for this fruit change if your next encounter with the rambutan at a grocery store is either grouped with peaches, cherries, and plums, or displayed alone? How new experiences can update a memory has important consequences for how we access and use memories to inform new experiences, yet, prior work has largely focused on how re-exposure to studied material dictates whether it is remembered or forgotten (e.g., the testing effect: Roediger III et al., 2011; Roediger III & Karpicke, 2006; Rowland, 2014). Although it is well known that memory is influenced by environmental factors present during retrieval (Hupbach et al., 2007; Loftus & Palmer, 1974), less is known about how different kinds of re-exposure may differentially influence the content of a memory. For instance, seeing the rambutan grouped with other stone fruits may emphasize its category membership, at the potential cost to memory for its unique taste. Here, we investigate how processing semantic information about a recently encoded episodic memory can shape how it is updated and stored for the long term.

To answer this question, we leverage the idea that memories are retrieved as a reconstructed form of the original experience integrated with relevant prior knowledge about the world (Bartlett, 1932; Schacter & Addis, 2007). Prior studies have shown that memory retrieval is well explained by the combination of both idiosyncratic details of specific events and prior semantic knowledge (Bartlett, 1932; Hemmer & Persaud, 2014; Huttenlocher et al., 1991). Specifically, new experiences that align with prior knowledge are often remembered more accurately (Alba & Hasher, 1983; Bransford & Johnson, 1972; Huttenlocher et al., 1991 Huttenlocher et al., , 2000) ) but may be at risk of systematic distortions in memory as a function of category membership (Hemmer & Persaud, 2014; Hemmer & Steyvers, 2009b). These systematic biases are theorized to rely on cognitive mechanisms captured by Bayesian approaches (Huttenlocher et al., 1991). These models predict systematic biases that result in episodic memories that are more closely aligned with prior knowledge (Hemmer & Steyvers, 2009a). Additionally, these models predict a tradeoff between the strength of the prior category knowledge and episodic memory strength such that, when an episodic memory is weak, it is more biased by prior category knowledge (Brady et al., 2018; Hemmer & Steyvers, 2009b; Tompary & Thompson-Schill, 2021). This distinction between these components of memory has also been observed when considering their relative strengths over time. As episodic memories weaken and fade with time, the relative influence of prior knowledge increases, resulting in more distorted memories (Tompary et al., 2020; Zeng et al., 2021). Together, this suggests that memory can be broken down into distinct components: an 'episodic' component representing the idiosyncratic details of an event, and a 'semantic' component that includes information like category membership or other relevant knowledge.

Here, we ask whether these distinct components can be intervened on to update a memory.

To examine how memory distortions emerge in distinct ways at test, we must take into account the structure of category knowledge. There has been extensive research highlighting the organization and structure of categories, with most focusing on the behavioral consequences of typicality, or category-belongingness, of different members of a category (Rosch et al., 1976).

Typical category members, which share the most featural overlap with other category members, are recalled better than atypical ones (Schmidt, 1996), but nonpresented typical category members are more susceptible to false alarms on a recognition test (Roediger & McDermott, 1995; Smith et al., 2000). Typicality has also been shown to modulate the extent that new memories are distorted by the prior knowledge of categories. Specifically, relative to that of atypical category members, location memory for typical category members was more distorted by the learned location of a cluster of other category members (Lu et al., 2026; Tompary et al., 2023; Tompary & Thompson-Schill, 2021). Jointly, these studies set an empirical precedent demonstrating that the structure of a category plays an integral role in the way we retrieve information from memory, and thus considering this category structure, may shed light on how different components of memories are updated after their initial formation.

In the current paper, we aimed to understand how the manner in which a memory is revisited (item-or category-level) can influence its episodic and semantic components. Across three experiments, participants learned image-location associations on a grid where most image locations were clustered near other images from the same category while some were not (Tompary & Thompson-Schill, 2021). This protocol allows participants to learn about the general locations of different categories (semantic/category knowledge) as they memorize the specific image locations (episodic details), and this general knowledge leads to systematic distortions in location memory for the images encoded far from their category location. In the current experiments, participants completed a series of post-encoding manipulations aimed to prioritize item-level or category-level processing of the images immediately after learning the locations.

We predicted that category-level semantic processing after learning would result in more distortions in location memory and item-level processing would result in more precise location memories. We also conducted a third experiment with a period of awake rest instead of post-encoding manipulations as a comparison for the findings observed in Experiments 1 and 2. By leveraging the findings from these experiments, we can better understand the nature of the distinct components of an episodic memory and their transformation over time.

Experiment 1 Methods

Data Collection.

Participants were recruited from Drexel University and the broader Philadelphia community. All participants were over 18 years old and were fluent in English. Participants were compensated for their participation at the rate of $15 an hour or class participation credit through Drexel University. All consent processes and experimental procedures were approved by the Drexel University Institutional Review Board.

Participants. The sample size was determined based on previous behavioral studies using the same paradigm (Tompary et al., 2023; Tompary & Thompson-Schill, 2021). Forty-one participants were recruited. Five participants were excluded due to a computer error occurring during the experiment, and one participant did not return for the second session. Two participants were identified as outliers based on the procedure described in the Outlier Detection section and were excluded from all analyses, and one participant was excluded due to letting 30 encoding trials time out, leaving a final sample of 32 participants (n = 32; 20 female, 2 other identity; M age = 19.3, SD age = 1.06, range age = 18-22).

Materials.

Stimuli consisted of 320 100x100-pixel images on white backgrounds used in prior studies (Tompary et al., 2023; Tompary & Thompson-Schill, 2021). Images were divided into two stimulus sets. Each set consisted of 160 images and were comprised of two superordinate categories, each with four categories (Set1 = Animals: mammals, sea creatures, insects, and birds; Household Objects: kitchen utensils, office supplies, furniture, and clothes; Set2 = Food: fruit, vegetables, grains, and seasonings; Expertise Objects: sports equipment, construction tools, musical instruments, and vehicles). Information regarding norming of the images can be found in Tompary & Thompson-Schill (2021). Participants viewed images belonging to one of two sets, counterbalanced across participants. This distinction was collapsed across all analyses.

Procedure Overview. Participants underwent a two-day in-person experiment (Figure 1). On Day 1, participants completed an encoding task in which they associated images with spatial locations on a grid (Figure 1C), followed by manipulation tasks and an immediate memory test of the encoded locations. After a 24-hour delay, participants returned to the lab for the same memory test and post-experiment questionnaires.

Encoding.

All images were presented with an associated location on a white 600 × 1200-pixel 123 rectangle with light gray gridlines spaced to form 50 × 50-pixel grids. The grid was divided into 124 halves with one superordinate category on each (e.g., animals on the left and household objects 125 on the right), with the mapping of category to each side counterbalanced across participants. All 126 images were spaced apart in a uniform distribution across the grid, with each half of the grid 127 broken into four quadrants with one category per quadrant (Figure 1C). Critically, for each 128 category, 14 images were located in their category's quadrant, and 6 images were placed in random locations across the other 3 category quadrants, following previous work (Tompary et al., 2023; Tompary & Thompson-Schill, 2021). In total, 112 images were in a quadrant that was consistent with their category membership ("spatially consistent"), and 48 were in a different category's quadrant ("spatially inconsistent"). This procedure was conducted separately for each of the two stimulus sets.

For each trial, each image would appear under the grid with a red dot that corresponded to its location. Participants were instructed to drag and drop each image onto the dot and press the "Enter" key or click the "Continue" button on the bottom of the screen when the image was over the dot. They were instructed to try to remember each image's location for a later memory test.

After confirming their response, participants advanced to the next trial. Participants had 6 seconds to complete this process before the trial would advance automatically to the next. All images were presented three times in separate learning blocks in a sequence that was randomized for each participant. Learning was divided into six blocks (each consisting of 80 images), with a short break after each to minimize participants' fatigue. Participants completed three practice trials before beginning the first encoding block.

Manipulations.

Following the encoding task, participants underwent two behavioral manipulations that aimed to promote either item-specific or category-level processing of the previously encoded images (order counterbalanced; Figure 1B). Each superordinate category was assigned to one of the two manipulations, with the mapping between manipulation and superordinate category counterbalanced. Trials were self-paced and the order of images was pseudo-randomized such that images of the same category did not repeat back-to-back.

In the item-specific manipulation, participants performed a pattern separation task, which has been demonstrated to recruit hippocampal computations (Brunec et al., 2020; Yassa & Stark, 2011). For each category, stimuli comprised of the six spatially inconsistent images from the encoding task, six perceptually similar foils, and six images from the same category that were not seen at encoding (unstudied). This resulted in 24 spatially inconsistent images, 24 perceptually similar foils, and 24 unstudied images for a total of 72 images total. On each trial, participants were asked to endorse whether the image was "old" (if they remembered seeing the image), "similar" (if the image was perceptually similar to an image they saw previously), "new" (if the image was not presented), or "unsure". Instructions for this task included examples of images that were either old, similar, or new from an unpresented category.

In the categorization manipulation, participants were asked to categorize each image into one of four categories listed below the image. The categories listed were the four categories from the corresponding superordinate category. For each category, stimuli comprised of the six spatially inconsistent images from the encoding task, six perceptually similar foils, and six images from the same category that were not seen at encoding (unstudied). This resulted in 24 spatially inconsistent images, 24 perceptually similar foils, and 24 unstudied images for a total of 72 images total. The inclusion of perceptually similar foils and unstudied images served to match the number and composition of stimuli in the item-specific manipulation. Instructions for this task included examples of images from unpresented categories.

Immediate and Delayed Memory Tests. The immediate memory test began after the two behavioral manipulations. The task was identical to the encoding phase but without a red dot marking the location of each image. Participants were instructed to drag each image to its corresponding location. After each trial, participants rated their confidence in their memory of the image's location as "Very confident," "Somewhat confident," "Guessed," or "Forgot item." After indicating their confidence, participants automatically advanced to the next trial. The order of these trials was randomized for each participant, with all 160 images seen during encoding being tested. The delayed memory test occurred approximately 24 hours after the first retrieval test and followed the same procedure as the immediate memory test. Note that all 160 images were tested at both timepoints.

Post-experiment questionnaire: Upon completion of the first session, participants answered questions regarding sleep and caffeine/nicotine use before the experiment. After completion of the second session, participants answered the same questions as before, provided demographic information, and completed a questionnaire accessing retrieval strategies and understanding of task structure. Data are not analyzed here but were qualitatively inspected to ensure compliance and understanding of the tasks.

Measured Variables.

Two dependent variables measured to assess memory for the images were developed and used previously (Lu et al., 2026; Tompary et al., 2023; Tompary & Thompson-Schill, 2021). Error was defined as the Euclidean distance from the encoded location and the retrieved location of an image (Figure 1D). Larger values indicate less precision (i.e., more error), whereas values closer to 0 indicate more precise memory (i.e., less error). Bias was defined as the proportion of error in the direction of the image's category cluster (Figure 1D). This is calculated by first subtracting the Euclidean difference between the encoded location and its cluster center from the Euclidean difference between the retrieved location and its cluster center, then dividing this unadjusted bias by the error for the image, resulting in a bias score ranging from -1 to 1. A bias score of 0 indicates no bias, a score greater than 0 indicates that retrieval is biased toward the image's category cluster center, and a score less than 0 indicates that retrieval was biased away from the cluster center.

Outlier Detection. The exclusion criterion was determined using participants' median error across all trials. Given the highly right skewed distribution of error within each participant, we excluded participants that exceeded three median deviations above the group median absolute deviation. Participants were also excluded from analyses if they let at least 30 encoding trials time out.

Data Transformation.

Following assumption testing for normality, participants' distribution of error was highly right skewed. Due to this violation in normality, we transformed error measures using a logarithmic transformation for all reported statistics. Bias was not skewed and thus not transformed.

Statistical Analyses.

Both measures (error and bias) were analyzed at the trial level using linear mixed-effects models. Models included different combinations of the following fixed effects and interactions: session (immediate memory test vs. delayed memory test), manipulation (category vs. item-specific), and typicality (atypical vs. typical). Random intercepts for participants and categories were included in all models. Statistical significance was assessed using Satterthwaite's method for approximating degrees of freedom. Post hoc comparisons of main effects and interactions of interest were conducted using estimated marginal means. P-values were not adjusted for multiple comparisons, and all significance annotations on figures reflect uncorrected p-values. Error bars on figures represent standard error. Following past work using the same experimental procedure (Tompary et al., 2023; Tompary & Thompson-Schill, 2021), Cohen's d was reported for effect sizes of within-subject comparisons and calculated as a within-subject measure by considering the correlation across the two compared conditions (Lakens, 2013).

Software. Stimuli was presented using custom scripts written in HTML and JavaScript and edited from Tompary et al., 2023. All statistical analyses were conducted using R (R Core Team, 2025). lmerTest was used to obtain statistics for main effects and interactions of mixedeffects models (Kuznetsova et al., 2017). emmeans was used to compute estimated marginal means of contrasts of simple effects (Lenth, 2017). All plots were generated using ggplot2 (Wickham, 2016).

Results

Performance on Manipulations.

We ran a paired sample t-test to assess both accuracy and response times on the manipulation tasks. For the categorization task, accuracy was calculated as the proportion of times the correct category was selected for a given image. For the itemrecognition task, accuracy was calculated by selecting the correct image status (i.e., if the image was 'old' and the participant selected 'old' then that trial was correct or if the image was 'similar' and the participant selected 'old' that trial was incorrect) for all 72 trials. We found a difference in performance for both accuracy and median response times. Participants were more accurate, (t(31) = 14.5, p < .001, d = 2.57, Supplemental Figure S1A; Expt. 1) and responded faster (t(31) = -3.75, p < .001, d = -0.66, Supplemental Figure S1B; Expt. 2), in the categorization manipulation compared to the item-recognition manipulation.

Bias by Manipulation.

As a reminder, we predicted that location memory would be more biased for images in the categorization task than images in the item-recognition task. To do this we computed a linear mixed effects model with fixed effects of session (immediate memory test vs. delayed memory test), manipulation (category vs. item-specific) and the interaction between the two. Consistent with our prediction, there was a main effect of manipulation (F(1, 3026) = 11.48, p < .001, Figure 2A; Expt. 1) with more bias for images in the categorization manipulation compared to the item-recognition manipulation (t(3026) = 3.39, p < .001, d = 0.52). There was a significant main effect of session (F(1, 3011) = 6.69, p < .01), in which there was more bias after the second session compared to the first session (t(3011) = -2.59, p < .01, d = -0.41). However, we did not see a significant interaction between manipulation and session (F(1, 3011) = 0.71, p = .40). Taken together, biases in memory were more prevalent for images after a delay and for images that underwent categorization.

Error by Manipulation.

We used the same model as above but with error as our dependent variable. There was a main effect of manipulation (F(1, 2956) = 4.8, p = .029, Figure 2B; Expt. 1) with greater error for images in the categorization manipulation, compared to the itemrecognition manipulation (t(2956) = 2.18, p = .029, d = 0.35). There was no main effect of session (F(1, 3011) = 2.64, p = .11) and no interaction between manipulation and session (F(1, 3011) = 0.19, p = .66) As was observed for bias, error in memory were greater for images that underwent categorization after encoding.

Bias by Category Typicality and Manipulation.

Given that category organization can determine how new memories are distorted (Tompary et al., 2023; Tompary & Thompson-Schill, 2021), we next explored how our behavioral manipulations differentially impacted memory distortions due to category typicality. Here, we used a linear mixed effects model with fixed effects of session (immediate memory test vs. delayed memory test), manipulation (category vs. item-specific), typicality (atypical vs. typical) and the interaction between manipulation and typicality.

Both session (F(1, 3010) = 6.70, p < .01) and manipulation (F(1, 3025) = 11.56, p < .001) remained significant in this model. Strikingly, there was no main effect of typicality (F(1, 3010) = 0.005, p = .95) but instead an interaction between typicality and manipulation (F(1, 3010) = 5.39, p = .020, Figure 3A). Post hoc contrasts reveal increased bias in the categorization task relative to the item-recognition task for atypical category members (t(3021) = 4.04, p < .001, d = 0.64) but not for typical category members (t(3021) = 0.79, p = .43, d = 0.16). When comparing across manipulations, we observed nonsignificant but diverging effects, such that for the categorization task, there was numerically greater bias for atypical category members compared to typical ones (t(3010) = 1.69, p = .091, d = 0.27) and for the item-recognition task, there was numerically greater bias for typical category members compared to atypical ones (t(3010) = -1.59, p = .11, d = -0.22). In brief, category-level processing after learning resulted in more bias only for atypical category members and not for the typical category members.

Error by Category Typicality and Manipulation.

To test how typicality interacted with the impact of our behavioral manipulations on error, we used a linear mixed effects model with the same fixed effects and interactions as in the prior section, but with error as our dependent variable.

We found a main effect of manipulation (F(1, 2958) = 4.84, p = .028) and typicality (F(1, 3011) = 21.2, p < .001), but no significant main effect of session (F(1, 3010) = 2.66, p = .10) and no interaction between typicality and manipulation (F(1, 3010) = 3.41, p = .065, Supplemental Figure S3A).

Discussion

In this experiment, we developed two behavioral manipulations aimed to induce either itemspecific or category-level processing of previously learned images. Unlike prior work that strengthens memory holistically through re-exposure of learned images (Ebbinghaus, 1885; Nelson, 1977) our manipulations were designed to isolate distinct "episodic" or "semantic" components of a memory and test how targeting different types of processing impacts the extent of its distortion due to prior category knowledge. Experiment 1 revealed that the images in the categorization manipulation exhibited greater bias and error at test compared to images in the item-recognition manipulation. In other words, memory for images that underwent semantic processing after learning were more distorted in the direction of their category cluster. This suggests that memory transformations can be driven by different types of processing during subsequent re-exposure.

We also explored whether the effectiveness of our manipulations was determined by the category typicality of the studied images, as our past work has shown that this semantic organization plays a role in how new memories are distorted (Lu et al., 2026; Tompary et al., 2023). We found that the categorization manipulation increased bias specifically for atypical category members-a striking parallel to our past findings that disruption to the anterior temporal lobe (ATL), a cortical region that has long been implicated in processing of category membership and conceptual information (Pobric et al., 2007; Ralph et al., 2017), reduced bias specifically for atypical category members. Together, this suggests that both enhancing (via a behavioral manipulation) or disrupting (via ATL inhibition) semantic processing is more impactful for items near the edge of a category boundary.

An alternative interpretation is that the observed differences in bias and error are due to differences in difficulty across behavioral manipulations. Namely, accuracy was lower and response times were longer for the item-recognition manipulation relative to the categorization manipulation. Thus, it is possible that because the item-recognition manipulation was more difficult, the greater efforted expended on those images helped to strengthen each image's location memory, resulting in less bias and less error. This interpretation would parallel findings on the testing effect, such that more effortful re-exposure like retest relative to restudy leads to memory enhancements (Roediger III et al., 2011; Roediger III & Karpicke, 2006; Rowland, 2014). Experiment 2 aims to rule out this alternative interpretation by including an easier task than the item-recognition manipulation for comparison to the categorization manipulation.

Experiment 2 Introduction

The results from Experiment 1 uncover an imbalance between the two post-encoding behavioral manipulations, specifically, the difference in difficulty across the two tasks. To address this issue, we designed a new manipulation to be a better match in difficulty to the categorization task while not requiring semantic processing. Instead of item-recognition, participants viewed each image and denoted whether a small hashtag was present in the image. Note that this is no longer an episodic retrieval task, but rather a low-level perceptual task to better equate effortful control with the categorization manipulation. Our prediction remains the same: categorization will result in more bias at test relative to a task that does not require semantic processing.

Methods

Participants.

Recruitment, exclusion, and outlier criteria remained the same as Experiment 1.

Experiment 1 revealed that images in the categorization task were retrieved closer to their category cluster relative to images in the item-recognition task; a power analysis using this effect size (Cohen's d = 0.50, α = .05, power = 0.8, two-sided, paired t-test) recommended a sample of 34 participants. To account for attrition, we recruited forty-eight participants. Four participants were excluded due to a computer error occurring, six participants did not return for the second session, and two participants were excluded due to letting 30 encoding trials time out, leaving a final sample of thirty-six participants for subsequent analyses (n = 36; 20 female, 4 other identity; M age = 20.4 years, SD age = 2.71, range age = 18-29 years). There were no statistical outliers for error identified when using the same outlier procedure as described in Experiment 1.

Materials.

Experiment 2 used a stimulus set that included only the Animal (mammals, sea creatures, insects, and birds) and Food superordinate category (fruit, vegetables, grains, and seasonings). Note that this experiment did not use Household Objects and Expertise Objects due to plans for an exploratory research question that ultimately was not pursued. Due to an error in stimulus generation, one image that was intended to be spatially inconsistent with its category membership was instead presented as spatially consistent, resulting in 113 spatially consistent images, and 47 spatially inconsistent images.

Overview of procedure: All elements of the procedure were identical to those described in Experiment 1, with the exception of one of the two manipulations.

Manipulations. The categorization manipulation and all stimuli remained the same as Experiment 1, including all spatially inconsistent, perceptually similar, and novel images used in both tasks. In place of the item-specific manipulation from Experiment 1, we developed a new manipulation to serve as a more equitable comparison to the categorization task. Participants indicated if each image on screen had a "hashtag" present or not. In this hashtag identification manipulation, a hashtag (#) randomly appeared on five out of the 72 images seen on screen.

Participants used the keyboard "yes" if there was a hashtag on the screen, and "no" if there was not a hashtag on screen. This task was self-paced and after each choice, the trial progressed to the next. This manipulation was designed to allow participants to engage with previously encoded images without promoting category-level processing (e.g., categorization).

Results

Performance on Manipulations.

As in Experiment 1, we assessed both accuracy and response times for the two manipulations. For the categorization task, accuracy was calculated identically as in Experiment 1. For the hashtag identification manipulation, accuracy was calculated as the proportion of correct 'yes's for the five target trials (i.e., if the image had a hashtag and the participant selected 'yes', then that trial was correct or if the image had a hashtag and the participant selected 'no', that trial was incorrect). Participants performed more accurately (t(35) = -2.58, p = .014, d = -0.43, Supplemental Figure S1A; Expt. 2) and responded faster (t(35) = 16.6, p < .001, d = 2.76, Supplemental Figure S1B; Expt. 2), on the hashtag identification task compared to the categorization task. In contrast to Experiment 1, the categorization manipulation was the more difficult task of the two.

Bias by Manipulation.

We employed the same linear mixed effects model as in Experiment 1, with manipulation, session, and their interaction as predictors of bias. As a reminder, we predicted greater bias at test for the images that underwent the categorization manipulation compared those that underwent the hashtag identification manipulation. As hypothesized, there was a main effect of manipulation on bias (F(1, 3343) = 4.42, p = .036, Figure 2A; Expt. 2).

Consistent with Experiment 1, the condition that required semantic processing (categorization) led to greater biases compared to the hashtag identification manipulation (t(3343) = 2.10, p = .036, d = 0.31). There was no effect observed for session (F(1, 3338) = 1.73, p = .18) and no interaction between manipulation and session (F(1, 3338) = 0.27, p = .60).

Error by Manipulation.

We used the same model as the section above but with error as our dependent variable. There was a main effect of manipulation on error (F(1, 3345) = 11.54, p < .001, Figure 2B; Expt. 2), with more error for images in the categorization condition compared to the hashtag identification condition (t(3345) = 3.40, p < .001, d = 0.39), replicating the findings observed in Experiment 1. We also observed a main effect of session (F(1, 3338) = 11.02, p < .001) with more error on Day 2 compared to Day 1 (t(3338) = -3.32, p < .001, d = -0.60). There was no interaction between manipulation and session (F(1, 3338) = 0.00, p = .96).

Bias by Category Typicality and Manipulation.

We next investigated whether the behavioral manipulations selectively impacted bias for atypical category members, as observed in Experiment 1. We again used a linear mixed effects model with fixed effects of session (immediate memory test vs. delayed memory test), manipulation (category vs. item-specific), typicality (atypical vs. typical) and the interaction between manipulation and typicality. There was no main effect of typicality (F(1, 3340) = 0.004, p = .95) or session (F(1, 3337) = 1.71, p = .19). However, the observed main effect of manipulation (F(1, 3342) = 4.42, p = .036) was qualified by a significant interaction with typicality (F(1, 3340) = 4.27, p = .039, Figure 3B).

Contrasts to characterize the interaction revealed an effect similar to what was found in Experiment 1, such that there was greater bias for images that underwent the categorization task relative to the hashtag task, but only for in atypical category members (t(3340) = 2.95, p < .01, d = 0.44) and not for typical category members (t(3342) = 0.026, p = .98, d = .03). We also observed a striking divergence in the way each manipulation updated memories according to their category typicality. After the categorization task, atypical category members were numerically more biased than typical ones (t(3337) = 1.43, p = .15, d = 0.22), and after the hashtag identification task, typical category members were numerically more biased than atypical ones, (t(3342) = -1.49, p = .14, d = -0.24). While these comparisons are not significant, they are notable for their consistency with Experiment 1.

Error by Category Typicality and Manipulation.

Like in Experiment 1, we used a linear mixed effects model with the same fixed effects and interactions as our bias by category typicality and manipulation analysis above, but with error as our dependent variable. We found a main effect of session (F(1, 3337) = 11.05, p < .001) and manipulation (F(1, 3344) = 11.57, p < .001) in the model, but there was no significant main effect of typicality (F(1, 3342) = 2.44, p = .12) or interaction between typicality and manipulation (F(1, 3342) = 3.79, p = .052, Supplemental Figure S3B).

Discussion

Experiment 2 replicated all major findings reported in Experiment 1. We found that semantic processing increased distortions and reduced precision in memory for encoded locations, but only for atypical category members. These results were observed despite substantial changes in performance on the behavioral manipulations. Specifically, in Experiment 2, accuracy was lower and response times were slower in the categorization manipulation compared to the hashtag identification manipulation, which is the opposite of what was observed in Experiment 1. Experiment 2 thus rules out the possibility that a more difficult post-encoding task may preserve memory for the locations. Rather, the two experiments provide converging evidence that semantic processing that occurs during the categorization task leads to more distorted and less precise memory. These effects emphasize that the post-encoding period may offer opportunities not only to stabilize but also to reshape memory traces, selectively amplifying semantic scaffolds depending on the demands placed on the memory system when re-visiting a recent experience.

However, an alternative interpretation of these findings is that fine-grained, item-level processing preserves location memories relative to semantic processing. Does semantic processing increase bias or does item-recogniton/perceptual processing perserve memory? To disentagle these two possiblities, we must have a comparable manipulation (i.e., no postencoding manipulation) to make appropriate comparisons to our findings. This comparison will also help us to understand whether post-encoding manipulations serve as distractors to learning (i.e., leading to increased bias and error) regardless of their processing demands.

Experiment 3 Introduction

Experiments 1 and 2 demonstrated that the categorization of images previously associated with spatial locations led to greater biases and error at test. However, it remains unclear if this semantic processing increases biases in memory, or if the opposing tasks (item-recognition in Experiment 1 and hashtag identification in Experiment 2) reduce biases compared to no task at all. Including a baseline rest condition allows us to test whether our behavioral manipulations promote or reduce distortions relative to rest, and whether semantic processing amplify or reduce these effects.

Prior research suggests that directly after learning memories are most prone to interference (Craig et al., 2014; Mercer, 2015; Robertson, 2012) with more difficult tasks disrupting consolidation and subsequently impairing memory performance relative to easier tasks (Dewar et al., 2012 (Dewar et al., , 2014;; Varma et al., 2018), while awake rest can further benefit memory retention (Wamsley, 2019 (Wamsley, , 2022;; meta-analysis: Weng et al., 2025). Still, these studies on interference employ unrelated stimuli within these intervening tasks. It is possible that engaging in any task which permits the re-exposure of previously encoded images may incidentally strengthen their associated location, resulting in lower error at test relative to rest. At the same time, the type of processing a task elicits after learning may differentially impact memory, such that semantic processing may lead to more bias relative to rest, but a task that does not elicit this type of processing may not. Experiment 3 was thus designed specifically to provide a baseline comparison with Experiments 1 and 2.

Methods

Data Collection.

Recruitment, exclusion, and outlier criteria remained the same as the previous experiments. Since this experiment was not designed to compare within-participant differences in the impacts of the behavioral manipulations, we conducted a power analysis based on the finding from Tompary & Thompson-Schill (2021) that typical category members were retrieved closer to their category cluster relative to atypical category members. Using this effect size, (Cohen's d = 0.48, α = .05, power = 0.8, two-sided, paired t test) a post hoc power analysis recommended a sample of 36 participants. Thirty-nine participants were recruited for the current experiment. Two participants did not return for the second session, one participant did not follow researcher instructions, and one participant had a severe visual impairment that was not disclosed upon screening, leaving a sample of 35 participants. After the conclusion of recruitment, three participants were identified as outliers based on the procedure described in the Outlier Detection section were excluded from all analyses. Our final sample was 32 participants, expected power at this sample size is 0.75 (n = 32; 25 female, 1 other identity; M age = 20.8 years, SD age = 2.21, range age = 18-26 years).

Materials.

Experiment 3 used identical stimulus sets as Experiment 1.

Overview of Procedure.

The procedure was identical to Experiment 1 and Experiment 2 except for the post-encoding manipulation.

Post-encoding Manipulation. After the encoding task, participants completed one five-minute awake rest period instead of an active task to equate to the amount of time the manipulation task took in Experiments 1 and 2. Participants were instructed to sit still and focus on a cross in the center of the otherwise blank computer screen.

Permutation Analyses.

We developed a permutation analysis to test whether bias was meaningfully different across experiments while accounting for observed differences in error across experiments. We made the decision to account for error when investigating bias across experiments after discovering that two measures are correlated across trials within participants (Figure 4B, left) and that the extent of their correlation is explained by participants' average error

(Fig 4B, right).

To compare bias across experiments, we computed two permutation tests that equated error of Experiment 3 to Experiments 1 and 2, respectively. We randomly selected ten participants from each experiment 20,000 times (e.g., 10 participants from Experiment 1 and 10 participants from Experiment 3) and compared whether error was different across experiments for each permutation. To do this, we fit a linear mixed effects model using error as our dependent variable and experiment as our independent variable. This resulted in 20,000 effect sizes reflecting the difference in error across the experiments. Of these permutated effect sizes, we selected a subset of 100 normally distributed around zero (signifying no difference), separately sampling 50 above zero (signifying less error in Experiment 3) and 50 below zero (signifying more error in Experiment 3). Note that ten participants were randomly selected from each experiment in each permutation to ensure a significant number of permuted effect sizes below zero; selecting larger subsets participants did not result in sufficient effect sizes below zero to generate a distribution of around zero. We then used the selected subjects from each subset to compare bias across the two experiments 100 times.

As this analysis was developed to assess how the awake rest manipulation of Experiment 3 compares to our categorization manipulation, we collapsed across experiments into a semantic processing manipulations (i.e., Experiment 1 and 2 categorization) vs. a non-semantic processing manipulations (i.e., Experiment 1 item-recognition and Experiment 2 hashtag identification). We employed a linear mixed effects model with fixed effects of manipulation type (semantic processing manipulations vs non-semantic processing manipulations), typicality (atypical vs. typical), and the interaction between manipulation type and typicality, with random intercepts for the two permutation tests (Experiment 1 to Experiment 3 vs. Experiment 2 to Experiment 3) and the 200 permutations (100 per test). Contrasts specific to each experiment are outlined in the Supplement (Supplemental Figure S4).

Results

Across Experiment Analyses

Bias by Typicality and Manipulation. First, we compared the within-subjects typicality effects observed in memories following awake rest relative to memories that have undergone semantic or non-semantic processing. We combined the categorization manipulations from Experiments 1 and 2 (semantic processing) and combined the item-recognition and hashtag identification manipulations (non-semantic processing). This serves to increase our power for comparison to Experiment 3. We computed a linear mixed effects model of bias as a function of typicality, manipulation type (awake rest vs. semantic processing vs. non-semantic processing), session, and the interaction between typicality and manipulation type.

In addition to a main effect of session, (F(1, 9396) = 10.53, p < .01) we find a main effect of typicality (F(1, 9397) = 4.78, p = .029) and manipulation type (F(2, 195) = 12.38, p < .001), qualified by their interaction (F(2, 9397) = 9.74, p < .001, Figure 3C). Contrasts on the interaction term revealed that awake rest (t(9396) = -3.78, p < .001, d = -0.68) showed greater bias for typical category members compared to atypical ones. This is a direct replication of the impact of typicality on bias as reported in studies by Tompary & Thompson-Schill (2021) and Tompary and colleagues (2023). In the same pattern as awake rest, non-semantic processing manipulations (t(9400) = -2.15, p = .031, d = -0.23) also showed greater bias for typical category members compared to atypical ones. In contrast, manipulations that required semantic processing had greater bias for atypical category members over typical ones (t(9396) = 2.23, p = .026, d = 0.25). Taken together, semantic processing of the studied images led to more bias location memory for atypical category members over typical ones, in contrast to non-semantic processing and awake rest.

Error by Typicality and Manipulation.

We used a linear mixed effects model with the same main effects and interactions as in the above section with error as our dependent variable. We find a main effect of typicality (F(1, 9398) = 63.23, p < .001), manipulation type (F(2, 193) = 14.71, p < .001), session (F(1, 9397) = 60.74, p < .001) and an interaction between typicality and manipulation type (F(2, 9398) = 12.15, p < .001, Supplemental Figure S3C). Post hoc contrasts on the interaction term revealed greater error for typical category members compared to atypical ones after both awake rest (t(9397) = -7.87, p < .001, d = -0.83) and non-semantic processing (t(9401) = -4.77, p < .001, d = -0.41). Conversely, manipulations that required semantic processing did not exhibit a significance difference in error for atypical category members over typical ones (t(9397) = -1.04, p = .30, d = -0.11). Overall, memory for the location of typical category members was less accurate than that of atypical category members, in line with studies by Tompary & Thompson-Schill (2021) and Tompary and colleagues (2023). Moreover, the impact of typicality on error resembled that of bias such that memory for typical category members was both less accurate and more biased relative to atypical category members after intervening tasks that do not require semantic processing.

Error by Experiment.

Since prior work shows that doing any task after learning results in worse memory (Dewar et al., 2012; Wamsley, 2019) compared to a period of awake rest (i.e., no task), we next compared overall error across the three experiments while collapsing across postencoding manipulations. We used a linear mixed effects model with fixed effects of experiment (Experiment 1, Experiment 2, and Experiment 3), session (immediate memory test vs. delayed memory test) and their interaction. There was a main effect of experiment (F(2, 99) = 7.05, p < .01 , Figure 4A), session (F(1, 9399) = 61.1, p < .001), and an interaction between experiment and session (F(2, 9399) = 13.6, p < .001). Compared to Experiment 3, both Experiment 1 and 2 had more error (Experiment 1: t(97) = -3.57, p < .001, d = -0.95; Experiment 2: t(99) = -2.82, p < .01, d = -0.65) and there was no significant difference in error between Experiment 1 and Experiment 2 (t(99) = 0.82, p = .41, d = 0.20). When considered separately, no single postencoding manipulation exhibited less error than awake rest (all t < -2.18, all less than p = .03; see Supplemental Figure S4). Results indicate that completing a task after learning increases the magnitude of error in location memory at test, in line with prior work on interference.

Permutation Analysis of Bias by Manipulation.

Next, we were primarily interested in comparing 554 how our post-encoding manipulations differentially impacted bias relative to awake rest. As can 555 be seen in Figure 3C, participants in Experiment 3 exhibited more bias relative to those in 556 Experiments 1 and 2, which is difficult to reconcile with their observed less error as it is directly 557 counter to predictions generated by a Bayesian model of reconstruction (i.e. more error should result in more bias). However, we first discovered patterns of correlations between error and bias that obscured our ability to make this comparison across experiments. Specifically, when participants frequently place images on the opposite side of the grid from the current superordinate category, negative bias is observed for those images, often resulting in highly negative average bias in poor performers. In contrast, good performers who place images near the appropriate category clusters exhibit higher bias, and a performer with perfect memory would exhibit minimal bias (Figure 4B; center). Indeed, we observe that in all experiments, an individuals' correlation between error and bias negatively scales with their overall error rate (Figure 4B, right). Because participants in Experiment 3 exhibited lower error relative to the Experiments 1 and 2, we observe a higher error-bias correlations for those participants (Figure 4B, left) and thus higher bias. To be able to compare bias across the experiments we wanted to account for these inherent between-subjects differences in error. To do this, we developed a permutation test that randomly sub-selected 200 cohorts of participants with equated error (see Methods and Figure 4C).

Over these 200 subsets, we compared how bias may be differentially impacted by the type of manipulation after learning: awake rest, manipulations that rely on semantic processing (categorization from Experiments 1 & 2), or ones that do not (item-recognition from Experiment 1 and hashtag identification from Experiment 2). Using a linear mixed effects model, to we found main effects of typicality (F(1,995) = 193, p < .001), type of manipulation (F(2, 995) = 771, p < .001), and the interaction between the two (F(2, 995) = 235, p < .001, Figure 4D). Contrasts revealed more bias for atypical category members following semantic processing than following awake rest (t(995) = -6.18, p < .001), but less bias for manipulations that did not require semantic processing compared to awake rest (t(995) = 25.8, p < .001). For typical category members, there was more bias following awake rest relative to both manipulations requiring semantic processing (t(995) = 21.5, p < .001) and ones that do not (t(995) = 28.1, p < .001). In other words, atypical category members have more bias after engaging in a task that requires processing semantic information than following period of awake rest.

Discussion

Experiment 3 provides a critical baseline to Experiments 1 and 2 by testing memory for the same image-location associations without intervening processing of the images. We found that relative to no task, completing of all post-encoding manipulations resulted in poorer memory (more error), supporting prior research on interference (Dewar et al., 2012; Wamsley, 2019).

Within experiments, we found evidence of greater error and bias for typical category members than atypical category members following awake rest, a replication of prior work (Lu et al., 2026; Tompary et al., 2023; Tompary & Thompson-Schill, 2021), as well as after manipulations that do not require semantic processing (item-recognition and hashtag identification).

Our primary goal for Experiment 3 was to better characterize the direction of findings in Experiment 1 and 2 such that atypical category members were more distorted after semantic processing, whereas memory for typical category members was not impacted by the intervening tasks. Given an observed relationship between error and bias, we equated error from Experiment 3 to Experiments 1 and 2 to control for differences in bias that may be explained by differences in error across experiments. We found a surprising interaction between typicality and manipulation type. Specifically, memory for typical category members was most distorted when following awake rest relative to memory following any other manipulation. At the same time, memory for atypical category members was most distorted following semantic processing, then awake rest, then least distorted following non-semantic processing. In sum, the type of processing required after learning interacts with an image's category membership to differentially modulate the extent its distortion in memory. We discuss this further in the General Discussion.

General Discussion

Across three experiments, we investigated how memories are updated by subsequent categorylevel semantic or item-level processing. Experiment 1 revealed that semantic processing after learning reduces accuracy and magnifies distortions in newly formed memories (Figure 2).

Experiment 2 replicated these findings and demonstrated that these changes in memories are specific to semantic processing and not the difficulty of the post-encoding task. Our results further revealed that semantic processing after learning is most impactful for atypical category members over typical category members. In brief, we demonstrate that the manner in which a memory is revisited can transform its distinct components, specifically by generalizing to components of a memory that are not directly revisited. Below we interpret our findings taking into account past research on reconsolidation, memory reconstruction, and interference.

The manipulations utilized in Experiments 1 and 2 were developed to actively update previously learned images by probing either prior semantic knowledge or item-specific information after learning. We leveraged theories of reconsolidation to develop our manipulations.

Reconsolidation theories claim that this memory updating is facilitated through retrieval processes (Nader et al., 2000), subsequently altering a memory's core components by incorporating new external details with each revisit (Forcato et al., 2010; Hupbach et al., 2007).

Such updating can result in either improved memory precision or the introduction of memory distortions. For example, memories can be retroactively enhanced through the incorporation of goal-relevant information such as monetary rewards (Adcock et al., 2006; Igloi et al., 2015; Murty et al., 2017; Tarder-Stoll et al., 2023), motivation to avoid threatening situations (Murty et al., 2012), or instructional goals (Wilhelm et al., 2011). On the other hand, reconsolidation can result in distortions through the incorporation of conflicting information (Loftus, 2005; Shao et al., 2023). Our results extend beyond this work by demonstrating that newly formed memories can either be strengthened or distorted depending on the type of processing required during reexposure, providing new evidence that the reconsolidation of a memory is shaped by the details of the environment in which it was retrieved.

Research on the testing effect has similarly focused on how different types of re-exposure can help or hurt memory. In this body of work, participants either restudy or are tested on the same information that was originally encoded, and being tested on previously learned material can effectively aid memory relative to restudy (Roediger & Butler, 2011; Roediger III et al., 2011; Roediger III & Karpicke, 2006a; Rowland, 2014). A critical distinction of our re-exposure tasks is that they were designed to be detached from the location information of the encoded images, which explains why revisiting these images do not reduce error relative to awake rest. A more appropriate comparison to our findings are from studies that generalize the effects of testing to unstudied items, either improving related memories (Carpenter, 2009; Chan, 2009; Chan et al., 2006) or increasing the likelihood of false alarms (Ferreira et al., 2019; Lee et al., 2019; Shao et al., 2022; Zhuang et al., 2022). Similarly, in our study, participants do not revisit the location of encoded images, but the effects of our manipulations generalize to their location memory. In other words, simply engaging with an image's category retroactively manipulates memory for its location. This raises a fascinating point that the nature of re-exposure of a memory, including its relatedness to the originally encoded event and the processing it elicits, is critical in determining whether the memory is preserved or distorted.

Our third experiment offered an appropriate benchmark to compare against the first two experiments by instructing participants to rest for five minutes after learning instead of completing post-encoding manipulations. We found that relative to awake rest, completing a task after learning resulted in worse memory (more error), supporting prior research that shows that interference after learning impairs memory (Craig et al., 2014; Dewar et al., 2012; Wamsley, 2019). However, not all interference is created equal; in our experiments, the type of task after learning significantly influenced how a memory was updated, such that semantic processing led to greater distortions in memories. Unlike in our experiments, most studies demonstrating interference from intervening manipulations utilize unrelated stimuli in their tasks and focus primarily on differences in difficulty as a factor in blocking memory consolidation. For instance, in a study by Varma et al., (2017) researchers used an intervening task that was designed to induce semantic processing similar to our categorization manipulation, but with untested stimuli. They found that memory after a manipulation with minimal semantic processing was no different than undergoing wakeful rest. They concluded that successful task interference likely requires a retrieval component-a component we highlight in our current study by instructing participants to categorize the same stimuli from encoding. If our categorization manipulation comprised untested stimuli, following Varma and colleagues (2017), then we would not expect the same observed updates in memories. Thus, interference from a post-encoding task is a likely explanation of the greater error seen at test following all manipulations compared to awake rest, but interference alone does not explain the extent to which memories were distorted.

The structure of semantic knowledge can provide insight into how memories can become distorted by further semantic processing. We found that location memories for typical category members were more distorted than that of atypical category members following awake rest (Figure 3), replicating prior work (Lu et al., 2026; Tompary et al., 2023; Tompary & Thompson-Schill, 2021). Interestingly we also found this effect following manipulations that did not require semantic processing (item-recognition from Experiment 1 and hashtag identification from Experiment 2), but this effect was reversed for manipulations that required semantic processing (categorization from Experiments 1 and 2). We suggest that categorizing these images emphasizes and subsequently updates the semantic component of a given memory, leading to more distortion in location memory due to relevant category knowledge. Indeed, we find that the semantic processing only induces distortions for atypical category members and does not impact typical ones. This is consistent with findings from Tompary and colleagues (2023) that showed inhibitory disruption of the ATL reduced distortions in memory (bias) specifically for atypical category members and not typical ones. Together these results reveal that the organization of semantic knowledge can govern how new memories can be updated, such that both neural and behavioral interventions primarily affect atypical category members. These findings are well explained by a recent update to theories of Bayesian reconstruction. This revision accounts for the likelihood that individuals infer a stimulus belongs to a particular category (Xu et al., 2025). Conceivably, an intervening manipulation such as categorization facilitates this inference more strongly for atypical category members, resulting in a reconstructed memory with a stronger semantic prior, and thus more distortion in memory. We also compared the impact of the manipulations on atypical and typical category members compared to rest. To do so, we first had to account for inherent differences in error across experiments, as individual idiosyncrasies in the correlation between error and bias were observed (Figure 4B). Relative to awake rest, atypical category members were more distorted after semantic processing and less distorted after non-semantic processing. In contrast, typical category members were most distorted after awake rest, suggesting that any manipulation that includes them reduces their distortion. Taken together, our findings suggest that semantic processing after learning primarily impacts memory for atypical category members by strengthening their connection to their category membership.

Modern theories of consolidation can provide insight into understanding how memory traces transform through re-exposure. These theories suggest that memory traces undergo a neural transformation starting in the hippocampus and spreading across the cortex (Antony et al., 2017; Preston & Eichenbaum, 2013; Sekeres et al., 2017; Tompary & Davachi, 2017 , 2024), such that the hippocampus protects unique memory traces from interference, while the cortex supports shared features across memories, leading to generalized memory representations (McClelland et al., 1995). Critically, the amount of item-specific or generalized information retrieved is determined by the magnitude of engagement from either of these regions (McClelland, 2013; Sekeres et al., 2018; Winocur et al., 2010). Our manipulations were developed to encourage localized neural engagement of either the hippocampus or cortex by reactivating memory traces by probing either item-specific or category-level information. We show compelling evidence that when using intervening behavioral manipulations, we can effectively manipulate and distort new memories by targeting semantic processing after learning. Analogous to our behavioral manipulations, in a recent study by Qi and Coutanche (2026), researchers instructed participants to access semantic knowledge at distinct hierarchical levels during retrieval as they underwent functional magnetic resonance imaging (fMRI). By promoting participants to focus on item-level information about an encoded stimulus ("Does this have seeds"), similar to use of our item-specific manipulations, researchers observed that memory traces were more distinct from one another compared to memories that were accessed at the category level ("Is this food?") or theme level ("Is this related to cooking?"), similar to our categorization manipulations. By using a manipulation that influenced the manner of processing, the researchers were able to successfully update the neural representations of the memories, directly parallel to the modulation of semantic processing we observed. Following their results, we might expect that our item-specific processing would result in more distinctive representations and more precise location memory, while semantic processing would result in more overlapping representations and thus more distortions. Such integration of behavioral and neural measures of accuracy and distortion is a promising avenue for future work.

Notably, although we designed the current experiments to investigate time-dependent impacts of semantic and item-level processing on new memories, we focused on analyses that collapse across immediate and delayed tests as we did not observe differences across tests that replicated across experiments. We chose to collapse all findings across sessions in our main figures for that reason (but see Supplemental Figure S2 for findings separated by session). One potential reason why we do not observe time-dependent effects is that all images were tested both on Day 1 and on Day 2, meaning that images tested on Day 2 may have been further strengthened due testing from Day 1. We suspect that canonical forgetting effects would have been more prominent if individuals were not being retested on the same images at both sessions (Supplemental Figure S2). We note that the one instance where we find a forgetting effect (more error the delayed test relative to the immediate test) is for images that underwent the hashtag identification task, whereas there was no forgetting for images that underwent itemrecognition. It may be that differences in the difficulty between the two item-level tasks could explain differences in forgetting rates across the two experiments, such that the more difficult item-recognition task induced more effortful engagement with the images and thus strengthened memory for their locations. Future experiments that are more suitably designed to test changes in memory over time may reveal further insights about the role of semantic and item-level processing in memory transformations.
