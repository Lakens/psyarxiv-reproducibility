Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. This package was validated by the Metacheck team on articles in Psychological Science.

This module was developed by Lisa DeBruine, Daniel Lakens and Cristian Mesquida

How Preregistration Check works

Retrieve information from preregistrations in a standardised way, and make them easier to check.

The Preregistration Check module identifies preregistrations on the OSF and AsPredicted based on links in the manuscript, retrieves the preregistration text, and organizes the information into a template. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Advertising restrictions largely remove gambling marketing from mass media, but digital channels, from social media to e-mail, leave room for paid, owned, and earned messages that are difficult to monitor. In a seven-day ecological momentary assessment, 178 Dutch online gamblers aged 18-30 documented encounters with gambling marketing with a screenshot or photo; all 1,377 images were content-analysed. At least one encounter was reported in 42% of assessment intervals and high-risk gamblers recalled more marketing encounters than other participants. Half of the documented marketing came from Instagram or Facebook, half offered a financial inducement, and one in fourteen messages came from unlicensed operators or impersonated licensed brands; high-risk gamblers mostly documented operators' own posts, the other groups mostly paid ads. At encounters, participants reported a stronger urge to gamble, anticipated more positive outcomes and more escalation of their gambling, and expected to feel less guilty about gambling than in their own unexposed moments. Additionally, gambling was more likely in the same interval as an encounter. Gambling marketing thus remains a routine part 2 of young gamblers' digital media use and encounters coincide with momentary shifts towards gambling.

Introduction

A young adult who wants to place a bet today needs nothing more than a phone. The same phone lets gambling operators reach that person at any moment: with an ad in their Instagram feed, a bonus offer by e-mail, or a text message about a free bet (De Jans et al., 2026).

In the Netherlands, where online gambling was legalized in 2021, young adults aged 18 to 23 held 22% of the online gambling accounts in use in the second half of 2025, although they make up only 9.3% of the adult population (Kansspelautoriteit, 2026b). This overrepresentation is particularly concerning because young adults are especially vulnerable to gambling-related harms, with potentially lasting consequences for their future life prospects (Wardle et al., 2024).

Such harms include financial problems, emotional distress, reduced performance at work or study, and relationship conflict, and can occur even among people who do not meet diagnostic criteria for a gambling disorder (Langham et al., 2016; Wardle et al., 2024).

Current frameworks locate gambling harm not only in individuals but also in the commercial, technological, and social environments that make gambling available and attractive (Hilbrecht et al., 2020; Wardle et al., 2024). Gambling marketing is part of this environment: it keeps gambling top of mind (Di Censo et al., 2024), links it to fun, sociability, and winning (Deans et al., 2016; Guillou-Landreat et al., 2021), and often places a route to participation, such as a "Bet here" link, next to the persuasive cue (Killick & Griffiths, 2020; Rossi & Nairn, 2022).

The Lancet Public Health Commission on gambling consequently recommends that governments prohibit or substantially restrict gambling advertising, sponsorship, and marketing (Wardle et al., 2024).

Many countries have responded accordingly. In the Netherlands, licensed online operators may no longer advertise on television or radio, in print, or in public spaces since July 2023, and sponsorship has been banned since July 2025. Advertising online, by direct mail, on social media, and within the gambling environment remains permitted under conditions: recipients must be able to opt out, at least 95% of the audience reached must be aged 24 or older, and operators must keep minors, young adults, and people who show signs of risky gambling from being confronted with their advertising (Kansspelautoriteit, n.d.-a, n.d.-b).

The channels that remain open differ from mass media in two respects. First, the marketing forms available on social media platforms are not limited to paid ads: operators post on their own accounts, creators promote gambling to their followers (De Jans et al., 2026), and memes and videos carrying an operator's logo circulate in ways that may not be recognisable as marketing (Dighton et al., 2025; Rossi & Nairn, 2025), so the environment combines paid, owned, and earned media (Lovett & Staelin, 2016). However, the public advertising repositories required by the EU Digital Services Act (Regulation (EU) 2022/2065, Art. 39) cover only paid ads and thus solely show what was bought rather than what a given person encounters (Xiao & Deery, 2026). Second, online marketing can be personalised on the basis of users' behaviour (Strycharz & Duivenvoorde, 2021). Engagement with gambling-related content may therefore lead to further marketing exposure, potentially concentrating repeated encounters among people already involved in gambling. This could be particularly concerning for those experiencing gambling-related harm, as marketing may encourage unplanned spending in this group (Wardle et al., 2024).

We therefore examined gambling marketing from the consumer's side. In a seven-day ecological momentary assessment (EMA), Dutch online gamblers aged 18-30 documented encounters with a screenshot or photo, reported further encounters at twice-daily questionnaires, and rated their gambling expectancies and urge to gamble in every report and questionnaire.

The study makes three contributions. First, it maps young gamblers' exposure to gambling marketing, documenting who encounters which forms of content and how often. By capturing content that advertising repositories do not record, it provides policy-relevant evidence on the marketing that continues to reach young gamblers after restrictions on mass advertising.

Second, it examines momentary associations between marketing encounters and gambling expectancies, urges, and behaviour, connecting everyday exposure to the psychological and behavioural responses that accompany it. Third, it provides a more differentiated account of susceptibility by examining gambling risk both as a predictor of exposure and as a moderator of momentary exposure-response associations. Greater exposure does not necessarily imply stronger responses to individual encounters. Separating these roles clarifies whether higher-risk gamblers' vulnerability is reflected in disproportionate marketing reach, heightened responsiveness, or both, with implications for where additional protection may be needed.

Theoretical Background

Reviews of gambling marketing link greater advertising exposure to increased gambling involvement, with evidence of a dose-response relationship (Bouguettaya et al., 2020; McGrane et al., 2023). However, an overall dose-response pattern can coexist with substantial variation in how individuals respond to a given encounter. Explaining this variation requires attention to the characteristics and experiences that users bring to media use.

Differential Exposure and Differential Responsiveness

The Differential Susceptibility to Media Effects Model (DSMM; Valkenburg & Peter, 2013) holds that media effects are conditional: dispositional, developmental, and social characteristics shape which media people use and how strongly they respond. Applied to gambling marketing, the DSMM points to two ways in which vulnerable people could be disadvantaged. Under differential exposure, they encounter more marketing; under differential responsiveness, a comparable encounter affects them more. These two paths correspond to the two roles the DSMM assigns to differential-susceptibility variables: they predict media use, and they moderate how strongly media use affects people's responses (Valkenburg & Peter, 2013).

We treat gambling risk as such a variable and examine both roles: its relation to exposure and its moderation of momentary responses.

Research on Exposure and Impact of Gambling Marketing

Most evidence on gambling marketing rests on retrospective surveys in which people summarise weeks or months of exposure in a single judgement (Bouguettaya et al., 2020). This work has shown a consistent link between exposure and gambling, but in cross-sectional data it is hard to tell whether marketing encourages gambling or simply reaches people who already gamble (Bouguettaya et al., 2020; Di Censo et al., 2024). Ecological momentary assessment studies address both problems by sampling experiences repeatedly, in daily life, and close to when they occur (Shiffman et al., 2008), which reduces recall bias and allows each person's exposed moments to be compared with their own unexposed moments (Bolger & Laurenceau, 2013).

Ecological momentary assessment can capture exposure in two ways. Event reports can be filed whenever an encounter occurs and can include screenshots or images of the message itself, but they require effort; scheduled reports ask about encounters not yet reported and demand less effort, but rely on memory. Earlier ecological momentary assessment studies of gambling marketing largely relied on scheduled reports (Browne et al., 2019; Hing et al., 2025; Rockloff et al., 2026). De Jans et al. (2023) combined both reports: young adults in Flanders uploaded each gambling ad they encountered during one week, right away or in a daily survey that also recorded days without ads, and the uploads were content-analysed; participants encountered about six ads per week, mostly digital ones. However, the study took place under Belgian rules that still allowed gambling advertising in most media. After Belgium banned most gambling advertising in 2023, young people who gamble reported seeing less of it in qualitative interviews, but described what remained, such as e-mails, sponsored posts, and operators' own social media channels, as more targeted (De Jans et al., 2026).

For strongly regulated markets such as the gambling markets in Belgium and The Netherlands, three questions remain open. How often do young adults still encounter gambling marketing? Which media carry it: paid ads, or operators' own and earned channels that escape the repositories? And where, from whom, and with what offers does it arrive? These questions are pressing because the remaining channels are both hard to oversee and consequential due to personalization (De Jans et al., 2026; Strycharz & Duivenvoorde, 2021).

RQ1: How often do young adults who gamble online encounter gambling marketing and what characterises the content?

Gambling Risk as Susceptibility Factor

Because gambling marketing remains permitted in digital and highly personalised environments, people who gamble regularly may encounter more of it. People who gamble more often hold more online gambling accounts (Gainsbury et al., 2015), and some young people who gamble follow operators' social media channels to obtain bonuses and odds boosts (De Jans et al., 2026), which opens channels for direct communication and supplies signals for personalised delivery (Strycharz & Duivenvoorde, 2021). Gambling cues may also be more salient to them, as gambling beliefs and gambling problems are linked to attentional biases for gambling cues (Grant & Bowling, 2015; McCusker & Gettings, 1997). Accordingly, young people who gambled more often documented more gambling ads in Flanders (De Jans et al., 2023) and reported encountering more advertising after the Belgian ban (De Jans et al., 2026), and moderate-risk and problem gamblers more often recall gambling promotions on social media, engage with operators there (Gainsbury et al., 2016), and report more exposure to direct marketing (Syvertsen et al., 2022).

We therefore treat gambling risk, measured with the Problem Gambling Severity Index (PGSI; Ferris & Wynne, 2001), as a dispositional susceptibility factor. Its nine items on problematic gambling behaviours and their consequences in the past 12 months form a single dimension (Miller et al., 2013) and are summed into a score conventionally divided into no-risk, low-risk, moderate-risk, and high-risk categories. Because Dutch licensed operators must not direct their advertising at vulnerable groups such as people who show signs of risky gambling (Kansspelautoriteit, n.d.-b), whether higher-risk gamblers encounter more marketing is an open question.

RQ2: Does exposure to gambling marketing and its characteristics differ by gambling risk?

Momentary Responses to Gambling Marketing

Gambling marketing foregrounds winning, entertainment, and sociability (Deans et al., 2016; Guillou-Landreat et al., 2021), uses bonuses to make betting appear less costly or risky (Browne et al., 2019; McGrane et al., 2025; Rossi & Nairn, 2022), and provides direct routes to gambling (Killick & Griffiths, 2020). Such framing may shape outcome expectancies, beliefs about consequences that guide behaviour (Bandura, 1986). Gambling expectancies comprise three positive dimensions (enjoyment, self-enhancement, and money) and two negative ones (over-involvement, or anticipated loss of control, and emotional impact, such as guilt; Gillespie et al., 2007). Among adolescents, more positive expectancies are associated with more frequent gambling and gambling problems (Donati et al., 2022).

Another proximal outcome that positively framed gambling marketing is likely to influence is the urge to gamble, the subjectively experienced desire to gamble, which links expectancies to behaviour. According to cue-reactivity research, cues repeatedly paired with gambling, such as brands, odds, and bonus offers, can come to elicit craving (Limbrick-Oldfield et al., 2017). In daily life, momentary cravings predicted gambling episodes (Hawker et al., 2021), and craving is linked to gambling severity and loss chasing (Mallorquí-Bagué et al., 2023).

If marketing encounters shift expectancies and urge, the question is whether they are also followed by gambling, as momentary cravings preceded gambling episodes in daily life (Hawker et al., 2021). In Australian ecological momentary assessment studies, operator e-mails and text messages were followed by betting intentions and betting (Russell et al., 2018), advertisements and inducements by higher intended and actual expenditure (Browne et al., 2019), and direct messages from operators, tipsters, and affiliates by more betting, expenditure, and harm (Hing et al., 2025).

These studies concerned wagering and relied on recalled encounters, and consequently, they were not able to capture how people felt at the moment of an encounter. In contrast to whether and how much someone bet, momentary states are harder to recall afterwards (Shiffman et al., 2008). Research on the marketing of other health-relevant products, alcohol and food, shows how such states can be captured. Participants filed a short report whenever they saw an ad and answered the same questions at random prompts, so that each person's states at exposure could be compared with their own states at other moments (Boyland et al., 2024; Martino et al., 2016). We applied this design to gambling marketing: event reports document the message and capture states at the encounter, scheduled questionnaires add encounters that could not be documented, and each participant's exposed moments are compared with their own unexposed ones.

H1: At encounters with gambling marketing, participants report more positive gambling expectancies (H1a), less negative gambling expectancies (H1b), and stronger urge (H1c) than in their own unexposed moments, and they are more likely to gamble in the same interval as an encounter (H1d).

In the DSMM, susceptibility factors can stimulate or reduce media effects (Valkenburg & Peter, 2013); for gambling risk, cue-reactivity research points to stronger responses. Through repeated gambling, brands, bonuses, and odds can acquire learned associations with reward.

People with behavioural addictions, including gambling disorder, report stronger subjective reactions to addiction-related cues than controls (Starcke et al., 2018), and people with gambling disorder show stronger reward-related brain responses to gambling cues (Limbrick-Oldfield et al., 2017). Operators' direct messages predicted betting, spending, and harm particularly strongly among higher-risk bettors (Hing et al., 2025). People with more severe problems also report stronger perceived advertising effects (Binde & Romild, 2019; Hanss et al., 2015; Syvertsen et al., 2022), but these are self-assessments of influence rather than observed responses. A withinperson test comes closer to responsiveness: a larger difference between a person's exposed and unexposed moments at higher risk indicates a stronger response rather than more exposure.

H2: The differences proposed in H1 are stronger in higher PGSI risk categories for positive expectancies (H2a), negative expectancies (H2b), urge (H2c), and gambling (H2d).

Method

Design and Procedure

To capture the exposure and proximal responses to gambling marketing, we conducted a seven-day ecological momentary assessment using the Avicenna software and application. Each day, participants received a morning questionnaire (at a random time between 8:00 a.m. and noon) and an evening questionnaire (at a random time between 4:00 and 8:00 p.m.), 14 in total; the first marked the start of the first assessment interval. These scheduled questionnaires counted as valid when completed within 120 minutes of the prompt. Because each interval ran from one questionnaire to the next, daytime intervals (morning to evening) were shorter than overnight intervals; all interval-level models therefore adjusted for interval length. Data were collected between January and September 2026. Our reporting follows the Checklist for Reporting Ecological Momentary Assessment Studies (CREMAS; Liao et al., 2016). Further details on the method and all results are available in the Online Supplement; https://osf.io/xnmt9/overview?view_only=e55938b594bb4468b8355941a1987874). Before the field period, participants completed a screening questionnaire (consent, eligibility, demographics, social-media use, past-year gambling, and the PGSI) and received illustrated instructions that defined messages about gambling broadly, from operator advertising to memes, betting tips, and anti-gambling messages. Whenever participants saw or heard such a message, they were asked to file an event report immediately or at the latest within 60 minutes, rate their current expectancies and urge, and upload a screenshot or photo. We chose this limit because event-contingent reports should be close to the event (Shiffman et al., 2008) as urges rise quickly after cues and peaks together with them (Gauld et al., 2025). At each scheduled questionnaire, participants rated their expectancies and urge and reported whether they had gambled since the last notification and any encounter not yet reported, including when the most recent one had occurred and what kind of message it was. Compensation (maximum €50) covered completed questionnaires and up to three event reports per day, a cap intended to discourage searching for gambling messages. Contact details of the support service Open over Gokken appeared in every questionnaire. The study was approved by the Ethics Review Board of [blinded for review] (FMG-17175), and it was preregistered on AsPredicted before data analysis (https://aspredicted.org/wc4vk4.pdf).

Participants

Participants were recruited through the commercial online panel IPSOS, the university participant pool, and flyers. Eligible were residents of the Netherlands aged 18-30 who bet on sports online or gambled online in another form at least once every six months. Of 205 participants who passed the screening and completed the first scheduled questionnaire, we later identified 26 enrolments that probably repeated an earlier enrolment by the same person, because they had been made on a device already used for another enrolment; we kept only the earliest enrolment per device. One further participant completed no scheduled questionnaire after the first one and was excluded.

The final analytic sample thus comprised 178 participants aged 18-30 (M = 24.20, SD = 3.68); 109 identified as men, 68 as women, and one as nonbinary. In the past year, 87.1% had bet on sports online and 78.7% had played online casino games. Participants completed 1,976 of 2,314 possible questionnaires after the first (compliance rate of 85.4%; M = 11.10 per person, Mdn = 12, range 1-13). We had preregistered a target of at least 180 analysable participants, based on simulations of the planned mixed models that assumed about 2.5 reported encounters per participant per day, an intraclass correlation of .40, a within-person coefficient of about 0.15 for positive expectancies and urge, and an odds ratio of about 1.40 for gambling; under these assumptions, 180 participants were expected to provide a power of at least .80. Interactions with risk were not powered. The final sample fell slightly short of this target, and exposure was lower than assumed (about one documented encounter per participant per day rather than 2.5), which reduces the power of the within-person comparisons.

Measures

Exposure to gambling marketing

Event reports were retained when the encounter had occurred no more than 60 minutes before submission and were assigned to the interval in which they occurred. A report counted as an encounter with gambling marketing when the image coding showed paid, owned, or earned marketing (Lovett & Staelin, 2016): advertising placed by or for a gambling operator (paid), operators' own posts, websites, and direct messages (owned), or undisclosed creator or meme content showing an operator brand (earned; Dighton et al., 2025; Rossi & Nairn, 2025). Services around gambling, such as tipster apps, generic gambling content, prevention messages, and unrelated images did not count. Encounters reported at scheduled questionnaires counted as marketing when participants described the message as promoting gambling or offering promotions or extras, the closest match available for encounters without an image.

At the interval level, exposure was coded as documented (at least one counted event report), recalled (a promotional encounter reported at the scheduled questionnaire), or any (either or both). For the analyses of momentary states, an encounter was either an event report or a scheduled questionnaire at which participants reported a recalled promotional encounter within the preceding 60 minutes.

Image coding

All 1,377 images attached to retained event reports were content-analysed with a codebook developed for this study (Krippendorff, 2018; Neuendorf, 2017). Each image first received one of five codes: paid or owned gambling marketing, commercial service around gambling, other gambling content (flagged when it showed an operator brand), prevention, or not gambling-related. Paid and owned marketing was further coded for product, source (e.g., labelled paid ad, operator's own post, direct message, affiliate, sponsorship), inducement (financial, competition, gift, or none), platform, and brand, following the visible content only. From the source we derived the media type: paid (labelled ads, affiliates, disclosed creator content, sponsorship, offline advertising), owned (operators' own posts, websites, direct messages), or earned (other gambling content with an operator brand). Licence status was derived from the brand using the register of the Dutch Gambling Authority.

The first coding of all images was carried out with a locally-run large language model (Claude Sonnet 5.5, Anthropic) provided by our university to ensure compliance with local privacy regulations. Such LLMs can match human annotators in many annotation tasks (Gilardi et al., 2023; Rathje et al., 2024) but must be validated for each task (Törnberg, 2024). The first author therefore independently coded a stratified random sample of 144 images, drawn from all coded images before the final exclusions. Agreement was high for the image code (κ = .93) and the dimensions of paid and owned marketing (κ = .82 to .98); disagreements were resolved by discussion and the clarifications applied to all images.

Gambling risk

The nine PGSI items (0 = never to3 = almost always) were summed (range 0-27; M = 5.71, SD = 6.17, Mdn = 3). Following the original scoring (Ferris & Wynne, 2001), 33 participants (18.5%) fell into the no-risk band (0), 45 (25.3%) into the low-risk band (1-2), 46 (25.8%) into the moderate-risk band (3-7), and 54 (30.3%) into the high-risk band (≥8).

Momentary states

In every event report and scheduled questionnaire, participants rated five statements adapted from the Gambling Expectancy Questionnaire (Donati et al., 2022), one per dimension to keep the repeated questionnaires short, from 1 (completely disagree) to 7 (completely agree): "If I were to gamble now, I would have fun / would come across as cool among my friends and peers / would win money / would probably want to gamble more and more / would feel guilty."

The first three are positive expectancies (enjoyment, self-enhancement, and money), the last two negative expectancies (escalation and guilt). The three positive items were averaged into a composite of positive expectancies (α = .88 between persons, .61 within persons). The two negative items were barely related within persons (r = -.08) and were analysed separately. Urge was measured with "How would you rate your desire to gamble at this moment?" (0 = no desire,100 = very strong desire; Young et al., 2008).

Gambling

Each scheduled questionnaire asked whether participants had gambled since the last notification and, if so, for how many minutes in total and with what total stake in euros. Eightyeight participants reported gambling in 388 intervals (19.6%); episodes lasted on average 37.7 minutes (SD = 39.8, Mdn = 30, range 0-350) with an average stake of €30.74 (SD = 34.9, Mdn = 20, range 0-300).

Analysis Plan

RQ1 was addressed descriptively. For RQ2, we fitted logistic mixed models with participant random intercepts for documented, recalled, and any exposure, testing the four risk categories jointly (likelihood-ratio test, 3 df) and against the no-risk group. To compare what the four groups documented, we fitted the same models at the image level for media type (paid, owned, earned), platform type (social media; e-mail or text message), financial inducement, and unlicensed or impersonating ads.

For H1a to H1c, we compared states at encounters with the same participant's states at scheduled questionnaires from intervals without any reported encounter, using linear mixed models with a person-mean-centred encounter indicator, the participant's mean, and random intercepts and encounter slopes (Curran & Bauer, 2011). Because event reports were spread across the day, models adjusted for part of the day and weekend. For H1d, we fitted logistic mixed models with person-mean-centred exposure for gambling in the same interval and, among intervals with gambling, linear mixed models of log-transformed time and stake. Interval-level models (RQ2, H1d) adjusted for questionnaire time (morning or evening), study day, weekend, interval length, and the final questionnaire. For H2, we added encounter × risk-category interactions (likelihood-ratio tests, 3 df).

We applied Holm's procedure (Holm, 1979) where several tests addressed one hypothesis or question that a single significant result would support (Rubin, 2021): across the two negative expectancy items (H1b, H2b), the three comparisons with the no-risk group, and the seven marketing characteristics. Missing data were not imputed. Analyses were conducted in R (version 4.3.3; R Core Team, 2024). Linear mixed models were fitted with lme4 (version 1.1-35.1; Bates et al., 2015), with p values based on Satterthwaite-approximated degrees of freedom (lmerTest, version 3.1-3; Kuznetsova et al., 2017), and logistic mixed models with glmmTMB (version 1.1.8; Brooks et al., 2017). relate to each other. Results and Discussion

Gambling Marketing in Everyday Media (RQ1)

Participants submitted 1,765 event reports. We removed 116 event reports filed more than 60 minutes after the encounter and 180 filed more than 12 hours before the first or after the final scheduled questionnaire. Of the remaining 1,469 reports, 1,377 (93.7%) included an image, and 1,201 of these (87.2%) showed gambling marketing. Documented encounters occurred in 32.3% of assessment intervals; counting recalled promotional encounters as well, 42.3% of intervals contained an encounter. Documented marketing was predominantly paid or owned media (Table 1), and financial inducements were common: three quarters of participants who documented marketing encountered at least one. Meta's platforms carried about half of the messages. Operators' own posts were common on Instagram, while paid advertising predominated on Facebook and Snapchat. Most television or offline encounters concerned lotteries (64 of 101). Exposure rates were similar below age 24 and at ages 24-30 (40.4% vs. 43.7% of intervals), although lotteries accounted for more of the younger group's documented marketing (28.8% vs. 12.2%).

Of the paid and owned messages, 83 (7.0%), seen by 32 participants (nearly a quarter of those who documented marketing), promoted operators without a Dutch licence (n = 71) or imitated a licensed brand in an ad the brand had not placed (n = 12), such as ads for a "Staatsloterij Casino", although the state lottery offers no casino games. Most promoted casinos (n = 65), usually with a financial inducement (n = 61), mainly through Instagram (n = 25) and email (n = 22). Such ads are a known problem: Holland Casino alone reported more than 64,000 fake gambling ads in a single month (Holland Casino, 2026; see also CasinoNieuws, 2026; De Jans et al., 2026; van Meijeren, 2026).

Gambling Risk and Exposure (RQ2)

Documented exposure did not differ by risk level, χ²(3) = 2.84, p = .418 (Table 2 and Figure 2; high vs. no risk OR = 1.46, 95% CI [0.69, 3.11]). Recalled promotional encounters did, χ²(3) = 40.15, p < .001: high-risk participants reported them in 34.2% of their intervals, compared with 6-10% in the other groups (OR = 14.34, 95% CI [4.32, 47.62], Holm p < .001).

For any exposure, the high-risk group therefore differed from the no-risk group (OR = 4.85, 95% CI [2.22, 10.60], Holm p < .001), whereas the low-and moderate-risk groups did not. Surveys consistently find that people with more severe gambling problems report more exposure to gambling marketing (Gainsbury et al., 2016; Syvertsen et al., 2022); we found this only for recalled encounters, not for documented encounters. High-risk participants recalled an encounter in 64.1% of their gambling intervals but documented one in only 26.0%.

Momentary Responses (H1)

The analysis of states (Table 4) compared 1,439 encounters (1,190 documented, 249 recalled within 60 minutes) with 1,021 scheduled questionnaires from intervals without an encounter; because each participant served as their own comparison, the encounter effects rest on the 154 of 178 participants who reported at least one encounter. At encounters, participants anticipated slightly more positive outcomes of gambling than in their unexposed moments (b = 0.09, 95% CI [0.00, 0.17], p = .047), supporting H1a. As predicted, they expected to feel less guilty if they gambled (b = -0.17, Holm p = .025), but, contrary to H1b, they also anticipated more escalation of their gambling (b = 0.17, Holm p = .011). Urge was about three and a half points higher on the 100-point scale (b = 3.40, p < .001), supporting H1c.

Encounters made gambling seem slightly more rewarding, in line with marketing that foregrounds winning, entertainment, and sociability (Deans et al., 2016; Guillou-Landreat et al., 2021). The difference was small (d = 0.14), and the lower bound of its confidence interval was close to zero, although positive expectancies had room to rise (M = 3.13 on the 7-point scale at scheduled questionnaires). The negative expectancies shifted as well, but these shifts allow several readings. Lower anticipated guilt could reflect normalisation, as sponsored gambling posts made young adults think that a typical student gambles more often (Hartmann et al., 2026).

Higher anticipated escalation may mean that encounters made further gambling more tempting.

The difference in urge fits cue-reactivity research (Limbrick-Oldfield et al., 2017; Starcke et al., 2018). The effect is small however (d = 0.25), and whether such momentary differences add up across frequent encounters, or translate into gambling as momentary cravings did in earlier ecological momentary assessment research (Hawker et al., 2021), remains to be tested.

Gambling was more likely in intervals with an encounter than in the same participant's unexposed intervals (OR = 1.97, 95% CI [1.27, 3.06], p = .003), supporting H1d and in line with Australian ecological momentary assessment studies (Browne et al., 2019; Hing et al., 2025; Russell et al., 2018), although participants did not gamble longer (-0.4%, 95% CI [-17.8, 20.7]) or stake more (-9.5%, 95% CI [-31.3, 19.2]) when they gambled. Slightly more positive expectancies, a stronger urge, and more anticipated escalation could make gambling more likely when an opportunity arises (Bandura, 1986; Hawker et al., 2021; Hofmann et al., 2012). Our design, however, shows co-occurrence, not causation. The order of encounters and gambling within an interval is unknown. Experiments could test causality: when Rockloff et al. (2026) randomised participants to opt out of operators' direct marketing, they placed fewer bets, spent less, and reported fewer harms.

Gambling Risk and Responsiveness (H2)

Gambling risk did not moderate the differences in positive expectancies (H2a), χ²(3) = 0.19, p = .979, anticipated escalation (H2b), χ²(3) = 3.10, Holm p = .376, urge (H2c), χ²(3) = 1.47, p = .690, the likelihood of gambling (H2d), χ²(3) = 7.26, p = .064, or gambling time, χ²(3) = 2.11, p = .549. It did moderate anticipated guilt, χ²(3) = 10.38, Holm p = .031, and stake, χ²(3) = 8.86, p = .031, in both cases only in the low-risk group, with lower anticipated guilt at encounters (b = -0.58, 95% CI [-1.02, -0.14]; other groups b = -0.05 to 0.01) and higher stakes in exposed intervals (+422%, 95% CI [35, 1, 914]; 34 gambling intervals from 16 participants). None of these patterns followed a risk gradient, so H2 was not supported.

Surveys in which people with gambling problems report stronger advertising effects (Binde & Romild, 2019; Hanss et al., 2015; Syvertsen et al., 2022) capture perceived impact, whereas we tested whether the same person's response to an encounter was larger at higher risk.

The low-risk pattern for guilt was not predicted and needs replication; it may partly reflect that no-risk participants anticipated little guilt in the first place (M = 2.91 vs. 4.10 to 4.40 in the other groups). The null results are not evidence of equal susceptibility: with 33 to 54 participants per risk category and about one documented encounter per person per day, only large differences in responsiveness could have been detected.

Theoretical and Practical Implications for Gambling Marketing Research

We set out to separate two ways in which gambling marketing could disadvantage people at higher gambling risk: encountering more of it and responding more strongly to it (Valkenburg & Peter, 2013). Our findings point to the first. High-risk gamblers did not document more marketing than other participants, but they recalled far more encounters, most of their gambling intervals contained one, and what they documented came mostly from operators' own accounts.

Their momentary responses, in contrast, were not larger: encounters coincided with a stronger urge, slightly more positive expectancies, and more anticipated escalation, and these differences did not grow with gambling risk, although only large differences in responsiveness could have been detected. In a market that has restricted mass advertising, gambling risk thus seems to matter mainly for how often and through which channels marketing arrives, and these are the channels that are hardest to monitor.

For regulators, these findings highlight the need to monitor the marketing young adults actually encounter. Advertising repositories capture paid advertisements but leave out unpaid posts from operators' accounts and private promotional messages. Participant screenshots, combined where possible with platform data donated with consent, could help capture these encounters (Araujo et al., 2022). Compliance checks should therefore include operators' own accounts and marketing within betting apps and websites. Existing research using Meta's advertising repository provides a starting point for examining age-targeting and audience reach (Xiao & Deery, 2026). Such audits should assess whether at least 95% of the audience reached by online gambling advertising is aged 24 or older.

Targeted protections for people showing signs of risky gambling remain important (Kansspelautoriteit, n.d.-b). Our findings also caution against assuming that only high-risk gamblers respond to marketing. Marketing encounters were associated with momentary shifts in the sample as a whole, although differences in responsiveness between risk groups could not be estimated precisely. Targeted safeguards should therefore complement broader restrictions on marketing exposure, as recommended by the Lancet Public Health Commission (Wardle et al., 2024).

Limitations and Future Research

Several limitations should be considered. First, exposure measurement depended on participants noticing, recognising, and reporting gambling marketing. Screenshots allowed verification of content, but only for encounters participants documented. Individual differences in attention to gambling cues (Grant & Bowling, 2015) may also influence which encounters are remembered and reported. Consequently, differences in reported exposure may reflect both differences in marketing encounters and differences in attention, recall, or documentation. Future studies could combine documented and recalled encounters with passive capture or data donation, where suitable exposure records are available, to reduce documentation demands (Araujo et al., 2022).

Second, the order of marketing encounters, gambling, and momentary states within each reporting interval was unknown. Participants may have noticed or reported more marketing because they were already gambling or considering gambling. The observed associations therefore cannot establish whether exposure preceded changes in expectancies, urges, or behaviour. Combining time-stamped gambling records with passively captured exposure could clarify temporal order, while experiments could provide evidence about causal effects.

Third, fewer participants and documented encounters were available than planned. We excluded 26 probable repeat enrolments, and participants documented approximately one encounter per day rather than the expected 2.5. This limited the information available for withinperson comparisons, particularly analyses of differences by gambling risk. Future studies should anticipate lower documentation rates when planning sample sizes and assessment periods.

Future research should also distinguish paid, owned, and earned media (Lovett & Staelin, 2016). Operators' own accounts were the source of most marketing documented by high-risk participants in this study. Measures limited to paid-advertising repositories would miss unpaid content from these accounts, underlining the importance of capturing exposure across different marketing channels.

Conclusion

Advertising restrictions aim to protect people from gambling marketing, and those most at risk above all. Among young Dutch adults who gamble online, gambling marketing remained part of everyday media, half of it on Instagram and Facebook, often with financial inducements, and sometimes from unlicensed operators or impersonators. Encounters coincided with a stronger urge, slightly more positive expectancies, and more anticipated escalation, and these shifts did not grow with gambling risk; high-risk gamblers instead reported more exposure, much of it from operators' own accounts.
