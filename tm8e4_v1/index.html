To fix Exact P-Values

What we found

We found 3 imprecise p values and 2 p values reported as exactly zero out of 103 detected p values.

Show details

Reporting p values imprecisely (e.g., p < .05) reduces transparency, reproducibility, and re-use (e.g., in p value meta-analyses). Best practice is to report exact p-values with three decimal places (e.g., p = .032) unless p values are smaller than 0.001, in which case you can use p < .001.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (e.g., “decreased at the p < .05 significance threshold”).

To check Non-Significant P Value Check

What we found

We found 27 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. This package was validated by the Metacheck team on articles in Psychological Science.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Codebook Check works

This module checks whether the data columns in a repository are documented in a codebook or README. It locates codebook/readme files, extracts the variable definitions they contain, matches those definitions against the data columns extracted by data_check, and reports documentation coverage: how many data columns are documented, and which documented variables are never used.

The Codebook Check module consumes the columns and file classification produced by data_check (and, transitively, repo_check). Files classified as codebook or readme are parsed with parse_codebook(), which reads structured tables (CSV/TSV/Excel with a variable-name column and a label column), embedded labels in haven files (SPSS/Stata/SAS), and plain text from rich-text formats (docx/pdf/rtf/odt). The module defaults to rules-only when llm_use(FALSE). When llm_use(TRUE), three optional LLM tiers run: parsing unstructured codebook text that the rules could not handle, fuzzy-matching still-unlabelled columns to still-unmatched codebook variables, and merging conflicting label definitions into a single canonical label.

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Checking code requires downloading its file contents. For a paper whose repository is on Dryad, this never succeeds unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (listing the repository’s files does not need one). Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Introduction

The vigilance decrement is defined as a progressive loss in the ability to monitor the environment and detect rare but critical stimuli, as evidenced by an increase in erroneous and slower responses over time (Davies & Parasuraman, 1982). The vigilance decrement can lead to mild consequences, such as missing a reading, or severe ones, such as a traffic accident (Baysari et al., 2008; Edkins & Pollock, 1997). The study of vigilance has gained considerable interest in understanding the causes and mechanisms associated with the vigilance decrement and to optimize performance in prolonged tasks (Thomson et al., 2015).

Several theoretical models have been proposed, which currently might be grouped into two relatively opposing frameworks: overload and underload theories (Thomson et al., 2015).

For decades, the most widely accepted explanation for the vigilance decrement has been the overload theory based on the resource depletion hypothesis (Warm et al., 2008).

According to this view, attention relies on limited resources that are consumed during sustained activity and are not quickly replenished (Dillard et al., 2019; Grier et al., 2003). In general, the resource depletion hypothesis posits that vigilance tasks-because they require substantial mental effort-consume more resources and produce a greater vigilance decrement. However, recent research has suggested that these resources may be renewable (Helton & Wen, 2023).

In contrast, underload theories include proposals such as the mindlessness hypothesis (Robertson et al., 1997), the resource control hypothesis (Thomson et al., 2015), and the mind-wandering hypothesis (Smallwood & Schooler, 2006). In particular, the mindwandering hypothesis, unlike the resource depletion account, argues that the vigilance decrement does not result from a depletion of resources, but rather from the redistribution of attentional resources toward irrelevant internal thoughts (i.e., mind-wandering). From mindwandering hypothesis, vigilance tasks are considered undemanding, monotonous, and cognitively unstimulating, which facilitates attentional disengagement (Neigel et al., 2020).

Consequently, the mind-wandering hypothesis predicts that more demanding or more engaging tasks should reduce the likelihood of mind-wandering and, in turn, mitigate the vigilance decrement (Smallwood, 2010), whereas boring or low-demand tasks should promote a faster withdrawal of attention and a more pronounced decline in performance over time (Thomson et al., 2015).

Numerous empirical studies have tested the assumptions of the resource depletion and mind-wandering hypotheses by manipulating task characteristics, such as load and/or physical features of stimuli, with the latter often operationalized through perceptual salience (Esterman & Rothlein, 2019; Gonçalves et al., 2017; Helton & Warm, 2008; Seli et al., 2018).

However, it appears that both theories are currently unable to explain the reported findings (Esterman & Rothlein, 2019; Neigel et al., 2020; Thomson et al., 2015).

In particular, task load is manipulated by varying the number of tasks performed simultaneously and the number of instructions that need to be maintained. Several studies show that performing a dual task affects vigilance more than performing a single task. For example, Head and Helton (2014) found that hits in the Sustained Attention to Response Task (SART) were worse when combined with a verbal memory task, compared to performing the SART alone. Epling et al. (2016) also observed a greater vigilance decrement when a semantic vigilance task was combined with a word recall task. Other studies have demonstrated that working memory load negatively affects vigilance (Helton and Rusell, 2011). Smit et al. (2004) found that performance in a vigilance task was worse when participants had to detect two stimuli instead of one. Overall, these results support the resource depletion theory, which proposes that higher cognitive demands deplete limited resources more quickly.

However, other studies indicate that increasing task load do not necessarily impair target's detection in the vigilance task and, in some cases, may mitigate the vigilance decrement. In this regard, for example, a correlational pattern was observed by Seli et al. (2016), who found that unintentional mind-wandering was more frequent during more demanding tasks, whereas intentional mind-wandering was more common during easier ones.

Building on this, Seli et al. (2018) tested the mind-wandering hypothesis by experimentally manipulating task difficulty: including a working memory component in the difficult condition and using a simple vigilance task in the easy one. Participants' responses were more accurate and faster in the easy condition, confirming the effectiveness of the manipulation. These results suggest that tasks with lower cognitive demands support more stable vigilance performance. Although the vigilance decrement was not directly measured, the authors examined in intentional and unintentional mind-wandering as a function of task difficulty. Overall, mind-wandering rates were lower in the easy task, though more often intentional-likely because the task required less cognitive control. In contrast, unintentional mind-wandering was associated with reduced performance in the difficult task. Also, Epling et al. (2019) found that vigilance remained stable when a semantic vigilance task was combined with a narrative memory task. Similarly, in air traffic control tasks, performing two tasks simultaneously did not reduce vigilance compared to performing only one (Pop et al., 2012; Stearman and Durso, 2016; see also Luna, Barttfeld, et al., 2022). These results seem to contradict the resource depletion hypothesis and could be better explained by the mindwandering hypothesis.

The lack of consensus in the results on the effects of task load on vigilance complicates agreement on theoretical explanations for vigilance decrement. While some findings align with the resource depletion hypothesis, others are better accounted for by the mind-wandering hypothesis.

Alternatively, task demands may be modulated by perceptual salience of the target stimuli. Evidence shows that more difficult tasks tend to yield worse overall performance and a greater vigilance decrement. Gómez Iñiguez et al. (2000) observed that in a difficult task (with more distractors), there were fewer hits and more false alarms. Similarly, Helton and Warm (2008) found that tasks with higher perceptual salience, i.e., easier tasks, led to reduced vigilance decrement. These findings support the resource depletion theory, which suggests that perceptually more demanding tasks require more resources, depleting them more quickly.

In general, these show that lower perceptual salience increases processing demands and tends to exacerbate the vigilance decrement.

However, it has also been found that tasks with more salient targets can generate a greater vigilance decrement. Ralph et al. (2017) compared two vigilance tasks with different levels of demands: an easy task, the Mackworth Clock Test (MCT, Mackworth, 1948), where participants had to detect repetitive stimuli in a monotonous sequence, and a difficult task (Car Task), which simulated driving a car, requiring participants to stay in lane while avoiding obstacles and compensating for wind gusts. Although the Car Task was perceived as more demanding, a vigilance decrement only occurred in the easy task. This supports the mind-wandering theory, as more engaging and demanding tasks seem to reduce taskunrelated thoughts and help maintain performance.

It is also important to note that vigilance theories have been developed using simple experimental tasks, such as the Sustained Attention to Response Task (SART) or the MCT.

Although these paradigms allow for precise experimental control, their extremely simple and monotonous nature limits their ability to capture how vigilance unfolds in more dynamic or realistic contexts (Thomson et al., 2016). In an attempt to overcome these limitations, Szalma et al. (2014) developed a video game-based vigilance task that incorporated continuous movement through a complex and perceptually rich virtual environment. This approach represented an improvement over tasks such as the SART and the MCT by offering greater ecological validity and a less artificial context. However, this same characteristic also introduced an important limitation: although the task reproduced subjective indicators typically associated with vigilance (e.g., increased distress and reduced engagement), the vigilance decrement was not consistently observed, likely because the richer and more engaging environment reduced the monotony that usually triggers such deterioration.

Moreover, simple vigilance tasks do not include additional measures of other attentional or vigilance components at the same time (Tkachenko & Dinges, 2018). Furthermore, when task load is manipulated, researchers often rely on different tasks (Epling et al., 2019; Head & Helton, 2014; Ralph et al., 2017) that vary in the variables assessed, the duration of the trials, and the characteristics of the stimuli. Consequently, the observed variations are difficult to compare among them, as task load is manipulated via different task parameters across studies.

A new tool for measuring multiple attentional and vigilance components in a single session has been developed by our lab: the ANTI-Vea task (Attentional Networks Test for Interactions and Vigilance -executive and arousal components; Luna et al., 2018; https://anti-vea.ugr.es/). The task captures the decrement on two vigilance components: (a) executive vigilance (EV), as the ability to monitor the environment to detect infrequent but critical signals, requiring higher-order cognitive processing such as updating working memory, making decisions, executing accurate responses to targets, and inhibiting responses to non-targets according to task goals (Hemmerich et al., 2025); and (b) arousal vigilance (AV), as the ability to maintain a fast response to an intermittent stimulus that always requires a response, which requires less cognitive control and facilitates a more automatic performance.

Importantly for our goals in the current study, the ANTI-Vea can be understood as a triple task that evaluates vigilance decrement under certain task load. In particular, this task integrates three type of trials, requiring different response sets: (a) the ANTI task, in which participants need to respond to the direction of a central arrow, surrounded by two more arrows on each side, and allows measuring the main effects and interactions between phasic alertness, orienting, and cognitive control (Petersen & Posner, 2012); (b) a signal detection task, similar to the SART, to assess the EV -by detecting an infrequent vertical shift of the central target arrow (present in 20% of the trials); and (c) a simple reaction time task, similar to the PVT, to measure AV in which a millisecond counter appears on the screen and participants must stop it as quickly as possible by pressing any key.

Several studies have replicated the validity and reliability of the ANTI-Vea across different experimental contexts (e.g., Coll-Martín et al., 2021; Luna, Roca et al., 2021), including online versions of the task (https://anti-vea.ugr.es/). Critically, these investigations have shown that measures obtained in online sessions outside the laboratory are comparable to those obtained under standard laboratory conditions. In both formats, the EV decrement is reflected by a reduction in hits over time.

Considering the advantages of the ANTI-Vea task, Luna, Barttfeld et al. (2022) manipulated task load in the ANTI-Vea task by varying the number of tasks to be performed simultaneously. They found that the dual-task condition, in which participants only had to respond to the EV and AV trials, mitigated the EV decrement, maintaining hit rates stable over time, compared to the single-task (i.e., when they only had to respond to EV trials) and triple-task conditions, where the typical EV decrement was observed. However, task load did not affect AV.

The present study aimed to examine the effects of perceptual salience and task load on the vigilance decrement by using a task paradigm that enables both factors to be manipulated within a single, integrated task. By employing the ANTI-Vea, which comprises several subtasks performed under identical task parameters, perceptual salience and task load were varied by manipulating only a single task parameter for each factor.

To this end, we conducted two studies and a reanalysis of a pooled dataset. Studies 1 and 2 were pre-registered on OSF, including objectives, hypotheses, procedure and design, sample size estimation, and data analysis plan. Note that, however, these pre-registrations included hypotheses and analyses regarding additional dependent variables collected through the ANTI-Vea task that are not part of the main goal of the present study. Here, we will only report measures collected through the EV sub-task of the ANTI-Vea, as it is the only sub-task in which perceptual salience and task load were manipulated across studies.

In Study 1, the perceptual salience of the target (i.e., magnitude of the vertical displacement to be detected) was manipulated between participants at three levels, to examine whether performance (hits, FA, sensitivity and response bias) over time benefits or rather is hindered by different levels of target salience (Gómez Iñiguez et al., 2000; Helton & Warm, 2008; Seli et al., 2018). In Study 2, participants completed nine sessions of the online ANTI-Vea (Luna, Roca et al., 2021) in which task load and target salience were manipulated orthogonally. In each session, task load was manipulated through instructions to complete one, two, or three of the ANTI-Vea subtasks, as in Luna, Barttfeld et al. (2022), and target salience was also varied across sessions, at three levels as in Study 1.

Study 3 reports a re-analysis of pooled data collected in Studies 1 and 2 of the present work together with data from a previous study on task load effects on vigilance (Luna, Barttfeld, et al., 2022). This re-analysis will enable us to further examine the effects of perceptual salience and task load on vigilance through data from a large sample size (N = 238).

Study 1

The present study aimed to examine the EV decrement via the online ANTI-Vea task as a function of different levels of perceptual salience of the target, to test some of the predictions of vigilance decrement models. Participants were assigned to one of three groups according to the perceptual salience of the target (i.e., low, standard, or high). Predictions were opposite for each theoretical account. According to the resource depletion hypothesis, it was expected that the lowest level of perceptual salience (i.e., highest difficulty to detect the target) would increase task demands and therefore hinder overall and time-on-task EV performance (hits, FA, sensitivity and response bias). In contrast, following mind-wandering hypothesis it might be expected that a high level of perceptual salience would reduce task demands, therefore facilitating task disengagement. Consequently, a perceptually less demanding task would lead to a larger EV decrement over time.

This study was pre-registered on OSF (https://osf.io/v3j5s/wiki/home/). Although preregistered, data of cognitive control and AV measures exceed the aim of this study and therefore are presented in the Supplementary Material.

Method Participants

In a previous study conducted with the ANTI-Vea (Luna, Barttfeld, et al., 2022), a summary analysis between experiments showed a between-within interaction with an effect size of 𝜂 𝑝2 = .06 for the change in hits (dependent variable) between task load (betweenparticipant factor with three levels: single/dual/triple) and block (within-participant factor with six levels). Using G*Power 3.1.9.7 (Faul et al., 2007), the minimum sample size required to observe a similar effect size to the one reported in Luna et al. (2022) was a-priori estimated for the present study, in which a similar design was used (between-participants factor: perceptual salience with three levels, low/standard/high; within-participant factor: block with six levels). Considering a power of 1-β = .95 and an α error = .05, the minimum sample size required to observe an interaction between perceptual salience and block with an effect size of 𝜂 𝑝2 = .06 was N = 84. Anticipating the potential need to exclude some participants from data analysis (following data filtering for standard analyses conducted with the ANTI-Vea, see Luna et al., 2021), we decided to gather data from 90 participants (n = 30 by group).

Ninety healthy young adults (61 women; age: M = 27.74, SD = 5.16), who were undergraduate students from the City of Córdoba, Argentina, volunteered to participate in the present study. All of them had normal or corrected-to-normal vision. Participants completed a written informed consent on the LimeSurvey platform before data collection. The study was conducted according to the ethical standards of the 1964 Declaration of Helsinki (last update: Brazil, 2013) and was part of a larger research project approved by a local Ethical Committee (CEIIPsi; project code: PE 41 v.2). Participants were randomly assigned to one of three experimental groups according to perceptual salience (low/standard/high) of the EV sub-task in the ANTI-Vea. Due to technical issues, data from 6 participants could not be included in the data analysis. Thus, the final sample was of 84 participants (i.e., as a-priori estimated), who were part of the experimental groups as follows: n = 28 in the low, n = 30 in the standard, and n = 26 in the high perceptual salience task group. Procedure and Design Participants received three web links via email to complete the procedure of the study in the following order: (a) the informed consent and a series of self-reported questionnaires in LimeSurvey (i.e., the Spanish version of the Mind Wandering-Deliberated/Mind Wandering-Spontaneous scales, the Discrete Emotional Scale [DES], and the Self-Assessment Manikin (c) another series of self-reported questionnaires on LimeSurvey to be completed post-task (i.e., NASA-TLX, thought identification question, DES, and SAM). With exception of the NASA-TLX, the inclusion of the remaining aforementioned self-reported questionnaires is, however, part of larger research project, and will be reported elsewhere.

Behavioral Task: ANTI-Vea

The ANTI-Vea comprises three embedded sub-tasks, which are randomly completed across three type of trials: (a) ANTI, a flanker task with an auditory warning signal and an exogenous visual cue, suitable to assess phasic alertness, orienting, and executive control as in the ANTI task of Callejas et al. (2004); (b) EV, a signal-detection task like the Mackworth Clock Test (Mackworth, 1948) suitable to assess the EV decrement; and (c) AV, a RT task that mimics the PVT (Lim & Dinges, 2008), suitable to measure the AV decrement. The procedure for each type of trial is depicted in Figure 1 and explained in further detail in previous studies and the online page of the task (https://anti-vea.ugr.es/, Luna et al., 2018; Luna, Roca, et al., 2021). Procedure of the ANTI-Vea trials. Note. Procedure and timing for (A) ANTI and executive vigilance trials, and (B) arousal vigilance trials. Note that, in all trials, responses were allowed until 2000 ms from target onset. (C) A representative illustration of the perceptual salience between-participant manipulation in the EV trials. (D) Correct responses for each type of trial.

In short, participants are instructed to fix their gaze on the fixation point at all times.

In the ANTI trials (60%, see Figure 1A), participants must select the direction pointed by the target (i.e., the central arrow), while ignoring the direction pointed by the surrounding arrows (see Figure 1D). Executive control is measured in the ANTI trials as the interference of distractors in target selection between congruent (50% of ANTI trials) and incongruent (50% of ANTI trials) see Figure 1D). Importantly, the ANTI trials also serve as the noise trials of the embedded signal-detection sub-task to assess EV. That is, if participants press the space bar key (i.e., the correct response to detect the infrequent signal in EV trials, see Figure 1D) as a response in an ANTI trial, the response is then categorized as a false alarm (FA). The EV trials (20%) follow the same procedure as the ANTI ones, except that the target is vertically displaced from its central position (see Figure 1A). Participants are instructed to detect the infrequent displacement by pressing the space bar, in these cases, ignoring the direction indicated by the target (see Figure 1D). Lastly, in AV trials (20%), no warning signal nor visual cue is presented (see Figure 1B). Participants are instructed to stop the millisecond counter as fast as possible by pressing any key from the keyboard (see Figure 1D).

The perceptual salience of the EV sub-task was manipulated between-participants (see Figure 1C). In the standard salience task, the vertical displacement of the target from its central position in the EV trials was fixed at 8 pixels (px), as in previous studies with the ANTI-Vea (Luna et al., 2018; Luna, Roca, et al., 2021). Instead, in the low salience task, the vertical displacement was fixed at 5 px, while in the high salience task was fixed at 14 px.

Importantly, to increase the difficulty of detecting the target displacement in EV trials, small random displacements (±2 px, applied to both the horizontal and vertical axes) were added to the position of stimuli. These displacements affected both the target and distractors in ANTI trials, but only the distractors in EV trials, wherein the target was always vertically displaced at its predefined level.

The experimental procedure comprised six consecutive blocks without breaks of 80 randomly presented trials (48 ANTI, 16 EV, and 16 AV), thus measuring vigilance in a period of 32 min 48 sec. Before experimental blocks, participants completed several practice blocks with and without visual feedback, as in previous studies with the ANTI-Vea (Luna et al., 2018; Luna, Roca, et al., 2021).

Mental Workload: NASA-TLX

After performing the ANTI-Vea, participants completed the Spanish translation (Arquer & Nogareda, 1999) of the short version of the NASA-TLX scale (Nygren, 1991).

The short NASA-TLX assesses the mental workload perceived about the task performed across six items (i.e., mental, physical, and temporal demands, effort required, perceived performance, and level of frustration) that are rated on a scale between 0 and 20. A summary score of mental workload is obtained by summing the ratings of the six items. The NASA-TLX has shown acceptable reliability scores (split-half and Cronbach's α coefficients > .80; et al., 2005), and has been extensively used to assess mental workload (Grier, 2015; Hart, 2006), and specifically also widely used to assess the perceived mental workload associated with the vigilance decrement (Grier et al., 2003; Helton & Warm, 2008; Warm et al., 2008).

Data Analysis

Analyses were conducted using R 4.2.0 (R Core Team, 2024) in RStudio 2022.02.3 (Posit team, 2024). Data was pre-processed with the reshape (Wickham, 2007) and plyr (Wickham, 2011) packages. Analysis of Variance (ANOVA) were conducted with the afex (Singmann et al., 2023) and emmeans (Lenth, 2023) packages. Effect sizes were computed with the effectsize package (Ben-Shachar et al., 2020) and CI following the Cousineau-Morey method (Morey, 2008) were calculated with the hausekeep (Lin, 2019) package.

Figures were created using Matplotlib (Hunter, 2007).

The EV decrement was analyzed via standard analyses usually conducted with the ANTI-Vea (Luna, Barttfeld, et al., 2021). In all analyses, data were averaged by block and the perceptual salience of the task was treated as a between-participants factor with three levels (low/standard/high). Hits were computed as the correct responses in EV trials and FA as the space bar responses in ANTI (i.e., noise) trials, as in Luna, Barttfeld, et al. (2021). Signal detection theory metrics were computed as A′ for sensitivity and B″ for response bias (Grier, 1971; Stanislaw & Todorov, 1999; Thomson et al., 2016). Polynomial contrasts of blocks were conducted to analyze trends of changes across time-on-task.

To identify potential outliers, we checked whether any participant exhibited a false alarm rate exceeding 50%; none met this criterion.

The mental workload score, obtained via the NASA-TLX scale, was analyzed through a one-way ANOVA, with perceptual salience of the task as between-participant factor. One participant was excluded from this analysis due to technical issues resulting in incomplete data.

Discussion

The results from Study 1 showed that increasing the salience of the signal was associated with a significant improvement in Ev. Specifically, the high-salience condition showed a higher proportion of hits and a lower FA rate compared to the low-and standard-salience conditions. These findings support the idea that greater perceptual salience of relevant stimuli, achieved by reducing perceptual task demands, helps maintain a more stable level of vigilance (Helton & Warm, 2008). In contrast, the low-and standard salience conditions replicated the classic deterioration pattern observed in the ANTI-Vea task, characterized by a progressive decline in hit rates. Note, however, that a similar effect over time was observed for the three levels of perceptual salience with sensitivity (A′) or response bias (B″) measures.

As expected, perceptual salience manipulations did not significantly affect AV measures, as shown in the supplementary material, replicating prior findings (Luna, Barttfeld, et al., 2022). This suggests that, although increased salience of relevant stimuli is effective in supporting goal-directed attention, it does not influence the ability to maintain a general state of alertness to unpredictable temporal signals.

Despite the above-mentioned differences in EV indices, perceived mental workload, as indexed by the global NASA-TLX score, did not vary as a function of perceptual salience.

Participants reported comparable workload after completing the vigilance task across all salience conditions, indicating that the benefits of increased perceptual salience were not accompanied by subjective reductions in workload. This dissociation between objective performance and subjective workload runs counter to predictions derived from the resource depletion hypothesis and suggests that perceptual facilitation may improve vigilance efficiency without substantially altering perceived task demands.

Study 2

Building on the results obtained in Study 1 on signal salience, as well as on evidence from a different study showing effects of task load on EV performance (Luna, Barttfeld, et al., 2022), Study 2 aims to replicate and extend these findings by combining the two dimensions orthogonally in a full within-participant design. Specifically, we examined how different levels of task load (elicited by a single, dual, or triple task, as in Luna, Barttfeld, et al., 2022) and the target's perceptual salience (low, standard, or high, as in Study 1) would modulate the EV decrement over time, as measured via adapted versions of the online ANTI-Vea task. This approach allows for the examination of not only the main effects of task load and the target's salience but also their potential interactions.

We anticipated different predictions according to the resource depletion hypothesis and mind-wandering hypothesis regarding the effects of task load and perceptual salience on the EV decrement. Following the resource depletion hypothesis, the highest overall hit rate and no decrease over time of hits in low demand task conditions was predicted-namely, the single task and high perceptual salience condition-compared to the high demand task conditions-that is, the triple task and the low perceptual salience condition. In contrast, according to the mind-wandering theory, it is expected that a less demanding task could increase task monotony and therefore exacerbate the vigilance decrement. Thus, probably a larger decrement would be observed in the single task load condition and in the high perceptual salience condition, than in more demanding conditions, such as the triple task and the low perceptual salience.

We also expected to replicate outcomes observed in previous studies conducted in our lab. Following Luna, Barttfeld, et al. (2022), we expected that task load would modulate the EV decrement, at least in the standard salience condition. In particular, we expected to observe a similar decrement in the single-and triple-task conditions, but no significant change across time-on-task in hit rate in the dual-task condition, replicating the pattern reported by Luna, Barttfeld, et al. (2022). Additionally, following the outcomes observed in Study 1, we hypothesized that perceptual salience would modulate the vigilance decrement specifically in the triple task condition, showing no significant change in hit rate in the high salience condition but pronounced decrements in the standard and low salience conditions.

We also expected a higher FA rate in the low compared to the standard and high perceptual salience conditions in the triple task load condition, as reported in Study 1.

This study was pre-registered on OSF (https://osf.io/csab3/wiki/home/). Note that, however, hypotheses related to self-reported mind-wandering and cognitive control measured via the ANTI-Vea in the triple task condition, were not analyzed here as they exceed the main objectives of the present manuscript and will be reported elsewhere.

Method Participants

Previous research with between-participants designs conducted with the ANTI-Vea observed that the decrement in hits was modulated by (a) task load, with n = 24 participants per group (Luna, Barttfeld et al., 2022), and (b) perceptual salience, with n = 28 participants per group (Study 1). In addition, the decrement in hits has been usually observed via the standard ANTI-Vea in studies with n = 40 participants per group (Luna et al., 2018; Luna, Barttfeld et al., 2021).

Considering all factors, and noting that in the present study task load and perceptual salience were manipulated within-participant across nine experimental sessions, we decided to gather data from 50 participants. We estimated that this sample size would be sufficient to replicate previous modulations of the vigilance decrement by task load (Luna, Barttfeld et al., become acquainted with the general characteristics of the task. Importantly, data from this session were not included in the analyses.

Participants were asked to complete the remaining nine experimental sessions in a controlled environment of their choice (quiet, well-lit, and with a stable internet connection), with the speaker volume set to 75% and trying to complete the task at the same time of the day every session (one session per day). Participants were instructed via email on how to select the task parameters for each session, being unaware of the specific task load and perceptual salience manipulations that were implemented in each session.

The following sessions were conducted on different days, encouraging participants to complete the next session in an interval between 24 to 72 hours from the last session, if possible. In each experimental session, participants completed one of the nine orthogonal combinations of task load (simple, dual, or triple) and perceptual salience (low, standard, or high), in a randomized order by participant. The experimental blocks lasted 32 minutes and 48 seconds, consisting of six consecutive blocks of 80 trials (48 ANTI, 16 EV, and 16 AV), presented randomly and without breaks.

Before each session, participants were given specific instructions and practice blocks according to the task type, to complete only the sub-task or sub-tasks of the ANTI-Vea of that session, as in Luna, Barttfeld et al. (2022). In addition, before and after the experimental task, participants completed a series of self-report questionnaires, that is, similar to the Study 1, the Dundee Stress State Questionnaire (pre-and post-task versions), SAM, DES, the NASA-TLX (Nygren, 1991), and visual analog scales for intentional and spontaneous mind-wandering at different time points of the task. The Intentional and Spontaneous Mind-Wandering Questionnaire (Cásedas et al., 2022) was also administered in the first session. Full details of these measures and their use are reported elsewhere in relation to the objectives of a larger research project.

Due to unknown reasons, 16 participants involuntarily repeated at least one of the nine sessions. To complete the nine sessions of the experimental design, 9 participants from UGR and 7 from UNC completed an additional session and one from UGR completed four additional sessions. Only the data from the second session were retained for analyses.

Behavioral Task: ANTI-Vea

The design of the ANTI-Vea task was the same as in Study 1. However, here, an additional manipulation of task load was introduced through task instructions, while keeping the stimuli and their duration constant across all conditions (as depicted in Figure 1A and 1B). Task load was varied at three levels, replicating the manipulation in Luna, Barttfeld et al.

(2022). In the single task condition, participants were required to respond only to EV trials by pressing the space bar when the target was vertically displaced (highlighted in green in Figure 4), while not responding when the target was not displaced (i.e., ANTI trials) or to the countdown (i.e., AV trials). In the dual task condition, in addition to responding to EV trials, participants had to stop the countdown by pressing any key in AV trials (highlighted in blue in Figure 4), while not responding when the target was not displaced (i.e., ANTI trials).

Finally, in the triple task condition, which is the standard ANTI-Vea task (Coll-Martín et al., 2024; Luna et al., 2018; Luna, Barttfeld et al., 2021), participants had to respond to all three types of trials (highlighted in orange in Figure 4): to the direction pointed by the target in ANTI trials, to detect the vertical displacement of the target in EV trials, and to stop the countdown as fast as possible in AV trials. The orthogonal combination of the three levels of task load (single, dual, and triple) and perceptual salience (low, standard, and high) resulted in a total of nine distinct experimental conditions. Data Analysis

As in Study 1, to detect any outliers, we checked whether any participant exhibited a false alarm rate exceeding 50%; none met this criterion.

To analyze the effects of perceptual salience and task load on the EV decrement, linear mixed-effects models (LME) were used. Analyses were conducted in R 4.2.0 (R Core Team, 2024) with RStudio 2022.02.3 (Posit, 2024), employing the lme4 package (Bates et al., 2015) and lmerTest (Kuznetsova et al., 2017).

The models included block (6 levels), perceptual salience (low, standard, high), task load (single, dual, triple), and sample (UGR or UNC) as fixed effects. Random effects for participants and number of sessions were included to account for their variability. Although LME models were not specifically anticipated in our pre-registered protocol, we decided to add random effects given the different number of sessions completed by participants. Note that dependent and independent variables (i.e., fixed effects) were included as anticipated in our pre-registered protocol. LME models were fitted using restricted maximum likelihood and degrees of freedom were estimated using the Satterthwaite method. Effect sizes for post hoc comparisons were calculated using the effectsize package (Ben-Shachar et al., 2020).

To assess performance decline over time, hits, FA, sensitivity, and response bias were calculated as in Study 1 and included as dependent variable in separated LME models. Main effects and interactions were examined using ANOVAs on each fitted model.

Mental workload, indexed by the NASA -TLX score, was analyzed using a repeatedmeasures ANOVA, with perceptual salience and task load as within-participant factors. Four participants were excluded from this analysis due to technical issues resulting in incomplete data.

Discussion

The results of Study 2 revealed clear main effects of both experimental manipulations, perceptual salience and task load. Consistent with the findings from Study 1, perceptual salience modulated overall hits and false alarms: participants detected more targets and made fewer false alarms when the target stimuli in the high salience condition. Regarding the preregistered hypothesis that FA rates would be higher in the low salience condition than in standard and high salience ones, the current outcomes replicated those of Study 1. These results could support the predictions of the resource depletion hypothesis, which posits that less salient stimuli increase task demands. This, in turn, leads to greater consumption of attentional resources and consequently poorer performance (Warm et al., 2008; Helton & Warm, 2008). This interpretation, however, is not supported by the results observed for sensitivity (A′), as no corresponding effect was observed. Importantly, no modulation of perceptual salience over the EV decrement was observed with any dependent variable.

Subjective workload measures converged with these performance effects. Specifically, NASA-TLX scores were higher in the low salience condition compared to the high salience condition, indicating that reduced perceptual salience was experienced as more mentally demanding. This pattern supports the interpretation that low salience increases perceived effort, even in the absence of changes in sensitivity.

On the other hand, the manipulation of task load showed a non-linear pattern on hits: the dual-task condition led to better hit rates than both the single and triple-task conditions, suggesting a benefit of maintaining a moderate level of mental workload.

This interpretation is strongly supported by the NASA-TLX results, which showed substantially higher workload in the triple-task condition compared to the single-task condition, indicating that the task load manipulation effectively altered perceived mental demand. The lower hit rates observed in the single-task condition are consistent with the mind-wandering hypothesis, which proposes that low task demands facilitate attentional disengagement and mind-wandering (Seli et al., 2018). In contrast, the decline in hit rates in the triple-task condition is more consistent with the resources depletion account, according to which excessive task demands may exceed available cognitive resources. Taken together, these findings suggest that the relationship between task load and vigilance decrement is better characterized by an inverted-U-shape pattern, whereby both insufficient and excessive workload impair hit rates, rather than by a single underload-based explanation (Luna, Barttfeld et al., 2022).

Importantly, this inverted-U-shape pattern was observed at the level of hits, while no corresponding differences were found in A′. This suggests that the task load manipulation could influence response bias rather than sensitivity. Recent work on vigilance tasks has highlighted that, particularly in modern paradigms characterized by very low FA, performance decrements may predominantly reflect shifts in response bias rather than changes in sensitivity (Thomson et al., 2016). From this perspective, moderate levels of task demand may promote a more optimal response criterion-supporting sustained engagement-whereas both low and high workload may bias participants toward a more conservative response criterion, leading to reduced hit rates.

This view is supported by previous research indicating that both active fatigue (associated with high load) and passive fatigue (associated with low stimulation) can impair performance in different ways, depending on how individuals regulate mental effort (Saxby et al., 2013). Similarly, a study in semi-automated driving contexts has shown that vigilance decrements emerge when mental workload is too low, highlighting the risks of sustained attention failures under underload conditions (McWilliams & Ward, 2021). Therefore, maintaining an optimal level of cognitive demand may be critical for sustaining attention, as suggested by both theoretical models and empirical findings. Nevertheless, and critically, despite these main effects of task load, no modulation over the EV decrement was observed.

Additionally, a significant interaction between perceptual salience and task load was observed: under low-salience conditions, lower-load tasks (single and dual) supported better performance in hits and FA compared to the triple-task condition. However, this effect diminished as salience increased, suggesting that more efficient perceptual processing may partially compensate for the detrimental effects of high task load. This interaction highlights the importance of considering multiple sources of task demands when studying vigilance decrement.

Importantly, despite these effects on overall performance, no significant interactions were found between time-on-task and the task load and perceptual salience manipulations.

This suggests that while these variables affect the overall level of performance, they do not substantially change the temporal trajectory of vigilance decrement.

Taken together, these findings underscore the need for more integrative models capable of explaining how task load and perceptual salience interact to influence both performance levels and attentional stability during prolonged tasks. They also highlight the utility of the ANTI-Vea paradigm as a sensitive tool for disentangling these effects and assessing the distinct contributions of different components of vigilance.

General Discussion 973

The present work analyzed how perceptual salience and task load independently and 974 jointly influence the EV decrement, using the ANTI-Vea task across three complementary 975 56 data sets. Study 1 manipulated perceptual salience; Study 2 implemented a full factorial design with both salience and task load; and Study 3, a final re-analysis, replicated this design in a larger more diverse sample (n = 238) by combining both studies with data from previous work (Luna, Barttfeld et al., 2022). Importantly, and in contrast to previous research, both target salience and task load were manipulated while maintaining all other aspects of the task, stimuli, and temporal parameters constant across conditions.

Across all three studies, the overall result showed that increasing perceptual salience consistently enhanced performance: higher salience levels were associated with higher hit rates, fewer FA, and greater sensitivity. In Study 1, the high-salience condition was associated with a higher proportion of hits and a lower FA rate than the low-and standard-salience conditions. Study 2 replicated and extended this pattern in a within-participant design, showing that salience affected EV even when combined with different levels of task load.

Finally, Study 3 confirmed the robustness of this effect in the pooled sample.

Critically, analyses on signal detection theory measures clarified the nature of the salience effect. Higher perceptual salience was associated with largest sensitivity, indicating that participants were better able to discriminate signal from non-signal trials when the target displacement was more salient. This graded pattern was especially clear in Study 3, where sensitivity was largest in the high-salience condition, followed by the standard-and lowsalience conditions. Therefore, the salience manipulation was effective not only in changing direct performance measures, such as hits and FA, but also in modifying the discriminability of the EV signal. This pattern is generally consistent with the idea that increasing the perceptual salience of critical signals reduces perceptual task demands and facilitates target detection (Helton & Warm, 2008; Warm et al., 2008). However, the findings also suggest that this interpretation should be qualified. In Study 1, although high salience improved overall performance, sensitivity did not show the same time-on-task modulation observed in hits.

Moreover, the NASA-TLX results in Study 1 indicated that subjective workload did not significantly differ as a function of perceptual salience. This suggests that increasing signal salience may improve perceptual discrimination without necessarily producing a corresponding reduction in perceived workload.

Task load, in contrast, showed a non-linear effect. In line with the findings of Luna et al. (2022), participants performed better under dual-task conditions compared to both single and triple-task conditions. This inverted-U pattern aligns with mind-wandering hypothesis and resource control theory (Seli et al., 2018; Thomson et al., 2015), which suggest that moderate task complexity promotes sustained attentional engagement. Performance declined when tasks were either too simple (low stimulation) or too demanding (overload), likely due to disengagement or fatigue. Moreover, a significant interaction between salience and task load was observed in Study 2 and the final summary reanalysis (Study 3): under low-salience conditions, performance was particularly impaired by high task load, while high salience mitigated this negative effect. This underscores the importance of jointly considering perceptual and task load when designing vigilance tasks.

However, the signal detection analyses indicate that this interpretation should be substantially softened. Task load did not produce a robust general effect on sensitivity. In contrast, it clearly affected response bias. Participants adopted the most conservative criterion in the triple-task condition, an intermediate criterion in the single-task condition, and the most liberal criterion in the dual-task condition. Therefore, the differences observed in hit and FA rates across task-load conditions should not be interpreted as direct evidence of differences in signal discrimination. Rather, they seem to reflect, at least in part, changes in response strategy. The lower hit rates observed in the single-task condition should not be directly attributed to mind-wandering, just as the lower hit rates observed in the triple-task condition should not be directly attributed to resource depletion. Although both mechanisms remain theoretically plausible, the present data do not allow us to distinguish them directly. In particular, the absence of a clear task-load effect on sensitivity suggests that the task-load manipulation primarily influenced the criterion used to respond to the EV signal, rather than producing a strong change in the ability to discriminate the signal itself.

Subjective workload showed a partial dissociation from performance. In Study 1, perceptual salience did not modulate NASA-TLX scores, despite clear improvements in hits and false alarms, suggesting that perceptual facilitation can enhance vigilance performance without reducing perceived task demand. In contrast in Study 2, both perceptual salience and task load affected NASA-TLX scores: low salience and higher task load were experienced as more demanding, indicating that subjective workload is sensitive to global task demands.

However, and as mentioned, despite these performance effects, none of the manipulations influenced the vigilance decrement over time. Performance declined steadily across all conditions, suggesting the involvement of additional factors beyond perceptual salience or task load. Thus, the solid pattern of data observed across the three data sets is difficult to reconcile with current resource depletion hypothesis or mind-wandering hypothesis of vigilance.

A central finding across the present work is that neither perceptual salience nor task load robustly modulated the vigilance decrement over time-on-task. In Study 1, the high-salience condition reduced the decrement in hits, but this pattern was not mirrored by a comparable modulation of sensitivity. In Study 2 and Study 3, the analyses of A′ and B″ showed significant changes across blocks, but no significant interactions between block and perceptual salience, block and task load, or block, perceptual salience, and task load. Thus, the manipulations affected the overall level of discrimination and response criterion, but they did not substantially alter the temporal trajectory of the EV decrement.

This pattern has important implications for theories of vigilance decrement. First, it shows that a decrease in hit rates should not automatically be interpreted as a loss of sensitivity. Changes in response criterion can produce similar patterns in hit and FA rates without necessarily implying that participants became less able to discriminate signals from non-signals. Second, the findings suggest that models based solely on overload or underload may be insufficient to explain the full pattern of EV performance. Task demands may influence both signal discriminability and response strategy, and these processes do not necessarily change in the same way over time-on-task (Thomson et al., 2015 (Thomson et al., , 2016).

An alternative interpretation of this pattern is offered by expectancy-based accounts of vigilance, which emphasize adjustments in response criterion rather than changes in perceptual sensitivity over time. In modern vigilance tasks characterized by low signal probability, such as the executive vigilance trials of the ANTI-Vea, performance decrements may be strongly reflected in shifts toward a more conservative response bias, sometimes without a corresponding decrease in sensitivity (Gyles et al., 2023; Roman-Caballero et al., 2023; Thomson et al., 2016). From this perspective, participants may progressively adapt their response strategy to the rarity of critical signals, resulting in fewer responses to both signal and non-signal trials. This account provides a parsimonious explanation for why the vigilance decrement persisted across conditions even when perceptual salience and task load changed overall performance.

At the same time, the persistence of the vigilance decrement across conditions leaves open the question of which mechanisms drive performance decline over time. One relevant candidate is mind-wandering. Numerous studies have shown that mind-wandering increases as time-on-task progresses, while task performance tends to decrease (Smallwood, 2010; Smallwood & Schooler, 2006 , Thomson, et al., 2015). According to resource-control theory, attentional resources do not necessarily disappear over time; rather, the allocation of resources between task-related and task-unrelated activity is regulated by cognitive control (Thomson et al., 2015). Over time, the ability to maintain task focus and suppress internal distractions may weaken, allowing attention to drift away from task goals. However, the present studies did not directly measure mind-wandering during task performance. Therefore, mind-wandering should be considered a plausible mechanism for future research rather than a demonstrated explanation of the present task-load effects. The same caution applies to resource depletion: although the overload framework provides a useful account of how high task demands may impair vigilance, the current results do not show that the triple-task condition reduced sensitivity through a depletion of attentional resources. Thus, the present findings are best interpreted as showing that perceptual salience and task load affect different components of EV performance, while the mechanisms underlying the time-on-task decrement remain to be directly tested.

Implications, limitations and Future Directions

The present findings have practical implications for the design of monitoring systems and tasks requiring sustained attention. Vigilance decrement can lead to a wide range of consequences, from relatively mild effects such as missing a critical signal to severe outcomes including fatal car crashes (Baysari et al., 2008; Edkins & Pollock, 1997; Wundersitz, 2019). Increasing the perceptual salience of critical signals reliably improved detection performance and sensitivity without necessarily increasing overall task demands. In addition, introducing moderate levels of task load may help sustain attentional engagement in monotonous or low-stimulation environments. However, the present findings also indicate that improving raw detection performance does not necessarily mean that the vigilance decrement has been eliminated. Even when perceptual salience improved sensitivity and task load modified response bias, neither manipulation robustly prevented the time-on-task decrement. Therefore, applied interventions should consider not only whether signals are detected more often, but also whether users are changing their response criterion over time.

The findings regarding task load also have applied relevance. The dual-task condition was associated with the least conservative response criterion, whereas the triple-task condition promoted the most conservative criterion. Thus, moderate task demands may increase participants' willingness to respond to vigilance signals, but this should not be interpreted as evidence of improved sensitivity or as direct evidence for an optimal level of attentional resources. In applied settings, reducing misses by encouraging a less conservative criterion may also increase the risk of FA, so the balance between sensitivity and response bias should be carefully considered.

The ANTI-Vea is available as an online, open-access platform (https://anti-vea.ugr.es/), which facilitates its implementation across a wide range of experimental and applied contexts. A key strength of the task is its modular structure, which allows different subtasks to be combined or isolated depending on the research question, enabling flexible referring to this specific class of task configurations. Consequently, future studies should examine whether similar performance patterns and vigilance dynamics emerge under alternative single-, dual-, and triple-task conditions that involve different combinations of cognitive processes.

An additional limitation, the perceptual-salience manipulation was based on three discrete levels of vertical displacement. This design was useful for comparing conditions of different perceptual difficulty and was consistent with the preregistered analyses of Studies 1 and 2, which focused on hits, FA, sensitivity, and response bias. However, the present studies were not designed to estimate individual psychometric functions. Although such analyses would provide a more fine-grained characterization of perceptual sensitivity and response bias, they were beyond the scope of the present design and analytic plan. Future research should use psychometric-curve analyses to distinguish more precisely changes in perceptual sensitivity, internal processing noise, lapse rate, guess rate, and response criterion (Gyles et al., 2023; Roman-Caballero et al., 2023).

A further limitation of this work is the absence of direct measures of mind-wandering and cognitive effort, which constrains a full understanding of the mechanisms underlying vigilance decrement. Future research should incorporate self-report, behavioral, or physiological indicators to better characterize these processes and refine explanatory models.

Finally, although the final reanalysis enhanced generalizability by including a larger and more diverse sample, data were collected under controlled laboratory settings or instructed homebased protocols, predominantly involving young adult participants. Replicating these findings in applied contexts and across broader populations would be essential to strengthen ecological validity.

Conclusions

Overall, results obtained using the ANTI-Vea task offer a sensitive assessment of EV and demonstrate that perceptual salience and task load influence vigilance performance in complex, interacting ways. Integrating measures of mind-wandering and cognitive control in future studies could further advance understanding of how concurrent demands and temporal dynamics interact to shape attentional control during prolonged tasks.
