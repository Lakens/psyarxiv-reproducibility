Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Checking code requires downloading its file contents. For a paper whose repository is on Dryad, this never succeeds unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (listing the repository’s files does not need one). Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Introduction

The population in many countries, particularly in Western societies, is ageing. With decreasing fertility, fewer young workers are starting to take part in the labour market. Current cohorts of middle-aged and older workers are expected to and likely to be working longer than previous birth cohorts were (Hess et al., 2021). Furthermore, due to shortages of qualified applicants, employer are increasingly interested to keep their older, experienced workers in the company, and effects of typical HR practices on employee behaviour and well-being seem to change with age (Kooij et al., 2013). All these developments make it even more important to understand what contributes to work satisfaction of aging workers (Hertel & Zacher, 2018).

Studies commonly found that older workers are more satisfied with their work than younger workers (Ng & Feldman, 2010). However, most of these studies were of cross-sectional nature and in convenience samples and the results may thus be overly optimistic. It is therefore important to investigate typical age-related trajectories of job satisfaction over time, before testing what characterizes more or less optimal developments (Zacher, 2015). Consequently, the first aim in the present study is to examine how work satisfaction changed over nine years in a population-based sample of German workers aged 40-59 at baseline. Second, we considered the role of the tendency to engage in flexible goal adjustment (Brandtstädter & Renner, 1990; Tolentino et al., 2013). Although higher scores in goal adjustment are known to be associated with better well-being and mental health, both cross-sectionally and longitudinally (Wettstein et al., 2019), its relation to work outcomes has rarely been investigated (Tolentino et al., 2013). We tested for its association with level and change in work satisfaction because of its role for informing ways to keep older workers motivated and satisfied in an ageing workforce.

Successful aging at work

With the increased aging of the workforce, it becomes more important than ever to study the aging worker's experiences at the work place. In the previous decade, research on "successful aging at work" has grown immensely. The most influential conceptualizations have been developed by Kooij (2015) and Zacher (2015). Kooij (2015) argued that successful aging at work means the maintenance of health, work motivation, and work ability over the work life span. Workers need to proactively adapt to their environment to ensure personenvironment fit to achieve these outcomes, for example via job crafting or coping behaviors. In contrast, Zacher (2015) defined successful aging as experiencing above-average trajectories of important outcomes such as work satisfaction or performance. Research based on Kooij's (2015) model has mainly focused on the adaptive actions of workers to ensure personenvironment fit, whereas research based on Zacher's (2015) model has mainly focused on predictors of above-average trajectories of work-related outcomes (Zacher et al., 2018). In the present study, we will contribute to both models: Based on Zacher's (2015) approach, we were interested in the typical age-related trajectory of work satisfaction, and what predicts deviations from the typical trajectory. However, in line with Kooij's (2015) approach, we consider a potential way to achieve person-environment fit -flexible goal adjustment (Brandtstädter & Renner, 1990).

Changes in work satisfaction with age

Age-related changes, for example with regard to cognitive performance (Fisher et al., 2019) or emotion regulation (Scheibe et al., 2016) present particular challenges and opportunities for reaching satisfaction with the job. Nevertheless, a meta-analysis, including both cross-sectional and (to a smaller degree) longitudinal studies, showed that like other work attitudes, job satisfaction shows a positive association with age (Ng & Feldman, 2010). The authors explain these findings with age-related changes in priorities, in line with socioemotional selectivity theory (Carstensen et al., 2003): With increasing age, people perceive their time as more limited, which leads to motivational changes. Older adults should therefore prefer immediate gratification from intrinsic parts of the job (e.g., social interactions, or pleasurable work tasks) over long-term benefits such as promotion or knowledge acquisition (Kooij et al., 2011). This would secure them maintained work satisfaction at work. Furthermore, older adults are more focused on experiencing positive emotions and avoiding negative ones than younger adults, and also seem to be better at emotion regulation (Scheibe et al., 2016), which should all help them to stay or become satisfied.

Likewise, and of particular importance for our study, authors have assumed that with older age, workers are more likely to engage in secondary control strategies (Kooij et al., 2011), which is a term from the motivational life span theory (Heckhausen et al., 2010). The theory implies that people strive to bring their situation in line with their goals and interests (primary control). In the face of increasing constraints, older workers should be more likely than younger workers to engage in strategies such as "managing the attractiveness of chosen goals, providing rationale for disengaging from nonchosen courses of actions, or bolstering perceptions of competence" (Rudolph, 2016, p. 142), which also in turns increases the chance to perceive primary control. Finally, over the work life span, workers are likely to search for more satisfying jobs and to leave those jobs that are not fulfilling their needs. All of these factors should contribute to increases in job satisfaction over the work life span.

However, it has been noted that most studies in the field are cross-sectional (Ng & Feldman, 2010). This means that observed age-differences could be caused, for example, by constant birth cohort differences (i.e., later-born individuals being less satisfied due to other factors, such as raising children) or selection into retirement (i.e., dissatisfied younger workers need to continue working, whereas dissatisfied older workers retire, cf. Henning et al., 2023).

Longitudinal studies are needed to show if cross-sectional differences correspond to withinperson changes over time (Dobrow Riza et al., 2018; McAdams et al., 2012). Furthermore, studies have often included a very large age-span, so it is unclear which phases of the work life span are associated with particular changes. In the current study, we study change in job satisfaction over nine years among workers who were aged 40-59 at baseline. These individuals were in midlife ("roughly 40-59", Lachman, 2015, p. 327) at baseline. Although the stereotypical "midlife crisis" seems to be not very common (Lachman, 2015), midlife is an important period in life with particular challenges and opportunities (Infurna et al., 2020). Individuals in midlife need to balance multiple roles, for example because of apart from managing their own career, workers are often needed to mentor younger co-workers, take care of children, grandchildren or ill family members (Infurna et al., 2020). Furthermore, midlife has been conceptualized as a pivotal period, as development in midlife is shaped by earlier developments but also sets the stage for late life developments in terms of health and wellbeing (Infurna et al., 2020; Lachman et al., 2014). It is therefore important to understand how individual job satisfaction develops in this period, and what contributes to interindividual differences in this development. In line with previous research, we assume H1. There is a positive association of age and higher job satisfaction at baseline.

Flexible goal adjustment

As noted above, Kooij (2015) emphasizes that workers need to engage in behaviours improving individual person-environment fit at work. Ageing workers are likely to experience that some of their goals (e.g., promotion) are not attainable, or become less attainable over time, which may decrease this fit and endanger successful aging at work and work satisfaction.

Therefore, workers are required to engage in proactive or adaptive goal (dis-)engagement strategies (Kooij et al., 2020). Such strategies can be found in the dual-process model of assimilative and accommodative coping (Brandtstädter & Rothermund, 2002), which is a lifespan theory, describing self-regulation over the lifespan and which bears some similarities with the motivational lifespan theory (Heckhausen et al., 2010). Assimilative coping means to bring the environment in line with one's goals (also called tenacious goal pursuit).

Accommodative coping, on the other hand, means to flexibly adjust ones goals and preferences in line with situational opportunities (Brandtstädter & Renner, 1990). Successful coping over the lifespan is reached in the situation-specific interplay of both strategies. In the current study, we focus on accommodative coping, which may be particularly important in the context of balancing family and work roles in midlife. Adjusting one's career goals and following those goals that are attainable while maintaining a satisfying family life may be necessary to remain satisfied with work over time.

The use of accommodative coping seems to become more frequent with age (Brandtstädter & Renner, 1990). Previous studies outside the work domain have shown that a higher use of flexible goal adjustment strategies is associated with higher well-being and better mental health (Bailly et al., 2012; Kubicek et al., 2011; Wettstein et al., 2019). Little research has studied accommodative coping in the work context (Rudolph, 2016), although it is likely to be as important as in other life areas. Previous cross-sectional studies, however, showed that flexible goal adjustment was associated with better job satisfaction (Abraham & Hansson, 1996) and career satisfaction (Tolentino et al., 2013). Furthermore, in a study among young adults in the transition from University to work, goal disengagement was related to increases in work satisfaction over time (but to declines in other aspects of well-being, (Haase et al., 2012). We assume that flexible goal adjustment is important to remain satisfied with one's work place in midlife, when many workers try to balance family life, care work and occupation, and for some, first physical health problems set in.

Given previous results, we expect H3: Flexible goal adjustment is associated with higher job satisfaction at baseline.

H4: Flexible goal adjustment is associated with increases in job satisfaction

The present study

In the present paper, we study the changes in work satisfaction across nine years among older adults in midlife, using four waves from the longitudinal German Ageing Survey (DEAS, Klaus et al., 2016). We considered the role of age and flexible goal adjustment for interindividual differences in the level and change in satisfaction. Our paper contributes to the literature, by adopting a lifespan perspective on job satisfaction (Rudolph, 2016), by using longitudinal methods, which are often still missing in research on job satisfaction and age (Bohlmann et al., 2018; Ng & Feldman, 2010), and by using a formerly seldom used concept in the work context (Rudolph, 2016), flexible goal adjustment.

Methods

Transparency and Openness

We report how we determined our sample size, and describe all data exclusions. The study was not pre-registered. The dataset (the German Ageing Survey) is available for the scientific community free of charge. However, for reasons of data protection, signing a data distribution contract is required before data can be obtainedfoot_0 . The syntax for data preparation in SPSS, as well as for all models on Mplus can be found on the OSF server: https://osf.io/rsm7z/?view_only=76c6d46d846749c4b86eaf40ef1edbef.

Participants

Our analyses were based on data from the DEAS, a longitudinal study on the German population aged 40 and above (Klaus et al., 2016). The study consists of four populationbased samples who were interviewed in 1996, 2002, 2008 and 2014, and are followed over time. Additional panel interviews have been conducted in 2011, 2017 and 2020, as well as 2021. The DEAS survey did not receive ethical approval, because ethical approval is not mandatory for general surveys in Germany. In the present study, we included the waves in 2008, 2011 and 2014 and 2017, because flexible goal adjustment was not assessed before 2008 and later waves were conducted during the Covid-19 pandemic, which may have affected work satisfaction in various ways that would be beyond the scope of the present paper. Individuals aged 40-59 at baseline were included to capture developments in midlife.

We further only included the baseline sample in 2008 to increase the representativeness of the study sample, as the inclusion of those participating already in 1996 or 2002 would have made the older part of the sample more selective than the younger (as the survey only starts at age 40). We only included individuals who were working at baseline in 2008 (N = 2,106).

One individual never reported work satisfaction and was thus excluded from the study samples. We included data from all remaining n = 2,105 in our analyses to achieve as unbiased estimates as possible, at least for information on the level of job satisfaction. Of those, n = 1,034 took part in the survey in 2011, n = 1,016 in 2014 and n = 893 in 2017.

Attrition

Attrition analyses showed that, compared to the longitudinal sample (n = 1,273), individuals who only participated once (n = 832) were significantly younger, (t(1,2103) = 2.81, p = .005, d = 0.12), reported less diseases (t(1,049.11) = 6.26, p < .001, d = 0.35), and less depressive symptoms (t(2,076) = 2.89, p = .004, d = 0.13) as well as less flexible goal adjustment (t(847.83) = 2.20, p = .028, d = 0.13), but groups did not differ significantly in work satisfaction (t(2,103) = 0.41, p = .679, d = 0.02). Men (χ²(1) = 8.68, p = .003, OR = 1.30) and lower educated individuals (χ²(1) = 26.36, p < .001, OR = 1.85) were more likely to participate only at baseline. All effect sizes were small in line with usual recommendations, which shows a rather small risk of bias in relation to the observed variables (Chen et al., 2010; Cohen, 1992).

In addition to study attrition, n = 124 individuals in 2011, n = 199 in 2014, and n = 279 in 2017 were retired or did not work and did therefore not contribute data on work satisfaction at these time points. Information on flexible goal adjustment and health was only available from those who completed the drop-off (with n = 1,425 without missing data on flexible goal adjustment and n = 1,423 without missing data on health). Descriptive statistics of this sample, as well as cross-correlations, can be found in Table 1.

[Please insert Table 1 here] Measures Work Satisfaction. Work satisfaction, our dependent variable, was assessed by one item from a list of attitudes toward work: "How satisfied are you with your work as a whole".

Response alternatives were very satisfied (1), satisfied (2), yes and no (3), dissatisfied (4), very dissatisfied (5). We recoded the item so higher scores meant higher satisfaction. No validated work satisfaction scale is included in the DEAS, but single-item measures of work satisfaction and other work-related constructs usually show very good reliability and validity (Matthews et al., 2022; Nagy, 2002).

Age. Age was included as a linear variable, and was centered around age 40. In addition, we tested for quadratic age effects in all models.

Flexible goal adjustment. Flexible goal adjustment was assessed with a 10-item short form of the flexible goal adjustment scale (Brandtstädter & Renner, 1990), which has been used in previous studies with the DEAS (Wettstein et al., 2020). Ten items (e.g., "Faced with a disappointment, I remind myself that other things in life are just as important") were rated from strongly agree (1) to strongly disagree (5). We recoded the items, so higher scores meant higher agreement, and we used mean scores. Cronbach's alpha reliability was α = .81.

Covariates. We controlled for gender, education, as well as physical and mental health. Gender was used as a dichotomous variable (0 = man,1 = woman). Education was assessed based on ISCED categories, but we dichotomized the item with 1 corresponding to high (tertiary) education. Physical health problems was assessed with a disease load index, based on a list of 11 chronic conditions (Spuling et al., 2017). Mental health was assessed with the short-form of the Allgemeine Depressionsskala (Hautzinger & Bailer, 1993), a German short version of the CES-D (Radloff, 1977). This scale includes 15 items, of which two (I was happy / I enjoyed life) were recoded. Participants rated their symptoms within the last week on a scale from1 = rarely or none of the time (less than 1 day) to4 = most of the time (5 to 7 days). The responses were recoded to 0 -4, and we used a sum score, so higher scores mean more symptoms.

Analysis

The dataset was prepared in SPSS. Analyses were run in MPlus v8.4 (Muthén & Muthén, 2020). Syntax for data preparation and analyses, supporting transparency and replicability, can be found on the server of the open science foundation:

We computed a latent growth curve (Ram & Grimm, 2007) to model linear change in work satisfaction from 2008 to 2017. The latent growth curve consisted of an intercept, representing the baseline level of work satisfaction, and a slope factor, representing the change per wave. As a first step, to test hypothesis 1 and hypothesis 2, we included only age as a predictor of intercept and slope, to test for age effects. Second, we included flexible goal adjustment as a further predictor, to test hypotheses 3 and 4. Finally, we added covariates to test if the effects of flexible goal adjustment stayed the same. Age was centred around age 40.

All continuous predictors (age, disease load, depressive symptoms, flexible goal adjustment) were grand mean centred. Missing data were handled by the robust Full Information Maximum Likelihood Estimator (MLR, (Enders, 2010)). Model fit was inspected based on the Comparative Fit Index (CFI), the root mean square error of approximation (RMSEA), standardized root mean square residual (SRMR). Acceptable fit is present at CFI values of 0.90 or higher, and RMSEA and SRMR values of 0.08 or less (Marsh, 2007).

Results

Main Models

A linear growth curve without any predictors included had a very good fit (CFI = 1.000, RMSEA = 0.000, 95%CI[0.000; 0.029], SRMR = .020). Adding a quadratic slope, which showed a non-significant mean and a non-significant variance, did not improve model fit significantly (TRd(4) = 1.78, p = .776). The model showed that workers were on average satisfied with their work at baseline, as they scored on average around 4 on a scale from 1 to 5 (M intercept = 4.15, SE = 0.02, p < .001). On average, the sample did not change over time (M Slope = 0.00, SE = 0.01, p = .690). Nevertheless, significant variances showed interindividual variability in both level (σ² Intercept = 0.25, SE = 0.03, p < .001) and change (σ² Intercept = 0.02, SE = 0.01, p = .028). [please insert table 2 here] Discussion

In the present study, we studied predictors of level and nine-year changes in work satisfaction in a sample of German workers who were in midlife at baseline. Midlife is an understudied period in life, although it is an important time when individuals need to balance their work life and private life while being engaged in different roles (Infurna et al., 2020).

Building on research on successful aging at work (Kooij et al., 2020), our focus was on the role of age and flexible goal adjustment. Our results show that work satisfaction, on average, is stable across midlife and that flexible goal adjustment is associated with levels, but not changes over time.

Work Satisfaction in Midlife

Previous studies have repeatedly shown positive effects of age on work satisfaction (Ng & Feldman, 2010). In our analyses, however, older age was not related to levels or changes in work satisfaction across midlife. This is in line with a recent study with a different German dataset than the one we used in the present study, which showed that there may be distinct declines at the end of one's working life, after an initial period of stability in Germany (Henning et al., 2024). It is unclear how generalizable the age differences are to other countries: Previous studies showed that job satisfaction levels differ between countries (Drabe et al., 2015). Different levels of job satisfaction can be partly explained by socioeconomic and differences, but also by varying cultural values and standards for what constitutes particular levels of job satisfaction (Drabe et al., 2015). Furthermore, while a positive relationship between age and job satisfaction has been established in the literature, it was shown to be moderated by national context (Tay et al., 2014).

Germany is individualistic and has a pronounced social security system, which may explain that such factors as job security are less important for job satisfaction than in other countries, while having an interesting job or good relationship with colleagues are quite important for job satisfaction (Drabe et al., 2015; Olsen et al., 2010). Of further relevance for older workers may be its retirement policies, with a statutory retirement age, as well as the socalled "early exit" culture with workers often trying to retire as early as their financial situation allows it (Ebener et al., 2019). Cross-cultural research is needed to understand the universality of within-person change or stability in job satisfaction in midlife.

The (Lack of) Effects of Flexible Goal Adjustment

Accommodation, or more specifically, flexible goal adjustment, which is the ability to easily adjust or drop one's goals if they are not reachable anymore, or if continuing to follow them would be maladaptive for the individual, is commonly associated with better well-being outcomes (Bailly et al., 2012) and also likely to be helpful for the work experience (Tolentino et al., 2013). However, we found only a significant cross-sectional association, but flexible goal adjustment did not predict changes in work satisfaction. One reason may be that the variance in change was rather small and none of our predictors, apart from age, did significantly predict change in work satisfaction. Flexible goal adjustment may also predict changes over shorter time spans, which could be assessed in daily diary studies (Scheibe et al., 2016). Comparable studies have been conducted with related concepts (i.e., selection, optimization and compensation, (Knecht & Freund, 2017)) among older adults before, but not in the work context. Furthermore, it may be stable or even improved goal adjustment, not baseline level, which matters for work satisfaction. Unfortunately, goal adjustment was not available at all waves, so we could not compute a parallel growth curve model to study slopeslope associations. Future studies with longitudinal assessments of both work satisfaction and flexible goal adjustment may test at a possible bidirectional, longitudinal relationship.

Successful Aging at Work -Remaining Satisfied Through Assimilation and Accommodation?

Fostering job satisfaction over the working life span is an important goal for researchers in the field of aging and work. As a consequence of the demographic developments, the work force is ageing, which makes it even more important to understand how job satisfaction typically develops, and what contributes to a fulfilling working life for middle-aged and older workers. Our results show that in a representative sample of middleaged German workers, work satisfaction was rather high and remained so over the course of the study. Nevertheless, more research is needed to understand when and for whom work satisfaction changes in midlife, and how life events and non-work roles contribute to work satisfaction. For example, there is only very scarce research of family care for job satisfaction (Stewart, 2013).

Although we did not find that flexible goal adjustment was associated with increases in satisfaction over time, we still believe that the distinction of assimilative and accommodative coping can be helpful for future research. Assimilation (i.e., tenacious goal pursuit) was not measured in our study, but future studies could test how both strategies contribute to long-term change in job satisfaction. Furthermore, diary or measurement burst studies may help to understand the interplay of accommodation and assimilation in everyday work life, and its short-and long-term consequences for performance and job satisfaction.

Strengths and Limitations

The present study is one of very few studies on longitudinal change in work satisfaction across several years in midlife, using a large sample from representative survey data. Furthermore, to our knowledge, this is the first attempt to study the association of flexible goal adjustment and work satisfaction with longitudinal data (Rudolph, 2016).

Limitations of our study include the large attrition rate over time, as well as the small number of measurements. Furthermore, our data did not allow us to run a parallel growth curve model, as flexible goal adjustment was not available at all waves. We also have a large agespan in the sample, which may obscure particular changes in specific phases, for example close to retirement (Henning et al., 2024). Finally, only flexible goal adjustment, not tenacious goal pursuit, the other adjustment mode in the dual-process model, was included in our data set. In general, the psychometric qualities of the original scales have been questioned (Henselmans et al., 2011), which is why we use a modified scale in the present study (Wettstein et al., 2020).

Conclusion

Taken together, our results show that the longitudinal relation of age and work satisfaction is complicated and likely non-linear (Hochwarter et al., 2001). Future studies may benefit from taken a more detailed look at different phases such as the time directly after job entry or close to retirement, (Henning et al., 2023; 2024), as well as the effects of engagement in non-work roles (Stewart, 2013). To cast more light on the role of flexible goal adjustment for a satisfying work experience, studies with work-specific scales and longitudinal measures of adjustment are needed.
