Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

Step 2: Indistinguishability
Before fitting models in Step 3, the assumption that dyad members are indistinguishable will be tested empirically. A model constraining member-level means and variances equal across the two arbitrarily labeled partners will be compared, via a likelihood-ratio test, against an unconstrained model allowing member-specific means and variances to differ freely. Justification for suppressed intercepts in Models A and B:
Because the emotions are standardized within-person (M = 0, SD = 1) prior to modeling, each individual’s own mean is 0 by construction, and each dyad’s mean (across the two members) is 0 by construction. Therefore, there is no fixed-effect intercept or random-effect intercept to estimate as both are known to be 0 rather than unknown quantities requiring a parameter. Including them would not bias the synchrony estimate, but would waste degrees of freedom estimating parameters whose value is already fixed by the standardization step, and departs from the definition of the quantity of interest. “-1” suppresses the fixed intercept in the outcome equation. “) +” suppresses the corresponding random intercept in the random-effects term, leaving only the random slope(s) to be estimated. This also carries a second, more specific consequence noted earlier: standardization makes the slope symmetric with respect to which member is coded as P1/P2 (i.e., for standardized variables, B_yx = B_xy = r), which is what allows this specification to respect indistinguishability without requiring a double-entry/pairwise-stacked dataset structure.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. Abstract

The moment-to-moment coupling of partners' facial expressions (i.e., synchrony) is a core channel of nonverbal coordination, yet it has rarely been measured during overt conflict. Using recorded facial expressions during a laboratory-based intimate partner aggression task, I estimated trial-level, same-emotion expressive synchrony, decomposed from between-dyad similarity, for 51 dyads (N = 102 participants).

Confirmatory analyses focused on emotional synchrony for anger, disgust, and happiness and tested whether a forced-break manipulation moderated synchrony.

Happiness synchrony was robust. Anger synchrony was not detected. Disgust synchrony was not reliably distinguished from zero, though statistical power was limited.

Contrary to the preregistered hypotheses, condition moderated only happiness synchrony, and in the opposite direction to what was anticipated. Positive coupling was stronger in the forced-break condition than the immediate-response condition, rather than remaining stable. Structured pauses during conflict may afford partners an opportunity to coordinate positive affect rather than serving only to interrupt negative affect. Altogether, partners' positive emotional expressions during a laboratory-based intimate partner aggression task couple, and this coupling is sensitive to the structure of the interaction.

Same-Emotion Synchrony During Laboratory-Based Intimate Partner Aggression

Intimate partner aggression (IPA)-an attempt to harm a current or former romantic partner who is motivated to avoid that harm-is often motivated by affect.

During conflict, each partner's affect is continuously shaped by the other's, and models of IPA increasingly locate IPA's drivers in the dyad rather than the individual (Bartholomew & Cobb, 2011; Capaldi et al., 2012). How tightly two partners track one another's emotions (i.e., their emotional synchrony) may bear on whether conflicts escalate or subside. Synchrony has seldom been measured directly in this setting, and whether interventions that reduce aggression do so partly by altering synchrony remains unknown. In what follows, I detail my examination of same-emotion synchrony during a laboratory-based IPA task and test whether a forced-break manipulation during the IPA task moderates same-emotion synchrony. McCurry et al. (2024) provided direct support for a dyadic account of IPA by using a face-to-face modification of a competitive reaction-time task (Taylor, 1967; Warburton & Bushman, 2019), in which romantic partners delivered aversive noise blasts to one another across repeated rounds. Both partners' negative affect, coded from facial expression, predicted the intensity of aggressive behavior. Furthermore, a forced-break manipulation that inserted a mandatory pause between provocation and response reduced aggression with the reduction mediated by lowered negative affect.

The manipulation was motivated by a Violence Escalation Cycle (Anderson et al., 2008; Dewall & Anderson, 2011) account, which posits that unchecked reciprocal negativity builds across an interaction until it culminates in aggressive behavior. A forced pause is presumed to interrupt the cycle before it peaks.

Mean-level negative affect, though, is only one way partners' emotions can be interdependent (e.g., Sels et al., 2020). A conceptually distinct quantity is synchrony: the trial-to-trial coupling of one partner's emotional expression with the other's, estimated net of each dyad's stable average level of that emotion. Synchrony indexes the moment-to-moment coordination, or covariation, of affect rather than its overall quantity. Importantly, the two can diverge. A couple may express little negativity on average yet track each other closely when it does arise. Whether such coupling matters, and how, is not neutral a question. Research on close relationships often treats partners' emotions as a coupled dynamic system whose coordination can regulate or dysregulate the couple's interactions by dampening arousal toward a shared equilibrium or amplifying it (Butler & Randall, 2013). A well-documented case of amplification is negative affect reciprocity, the tendency for one partner's negativity to elicit the other's negativity. Chains of reciprocated negativity escalate conflict and reliably forecast dissatisfaction and dissolution (Gottman & Levenson, 1992; Levenson & Gottman, 1983). Coordination of positive affect carries the opposite implication, reflecting the mutual attunement through which partners can co-regulate (Butler & Randall, 2013).

Emotional synchrony is therefore valenced in its likely consequences. While coupled negative states may mark a pathway to escalation, coupled positive states may mark a pathway to repair.

Of the emotions coded by McCurry et al. (2024), three emotions representing both negatively-and positively-valenced states pose the clearest rationale for examination. Anger and disgust are negatively-valenced emotions which are central to popular theoretical approaches to examining aggressive behavior (Anderson & Bushman, 2002; Bondü & Richter, 2016; Haidt, 2003), and approaching them separately respects a well-documented distinction in their elicitors and response tendencies (Rozin et al., 1999). Anger synchrony would index shared approach-oriented hostility (Carver & Harmon-Jones, 2009), whereas disgust synchrony would index a shared response of rejection or withdrawal (Rozin & Fallon, 1987). Happiness represents a positively-valenced emotion whose role in aggressive behavior is less clear. While positive affect is often assumed to dampen aggressive responding, it is not uniformly protective. Aggression can itself be rewarding, and positive feeling is increasingly implicated as a correlate and cause of aggressive behaviors (Chester, 2017; Chester, in press). Happiness synchrony is an ambiguous case; shared positive expressions during conflict may reflect co-regulatory attunement, or a mutual and rewarding investment in the exchange itself.

The Present Study

To my knowledge, no prior work has estimated trial-level same-emotion synchrony, separated from between-dyad similarity and modeled per emotion, during laboratory-based IPA, nor tested whether a forced-break manipulation moderates synchrony. The present study addresses both questions through a secondary analysis of the main study reported by McCurry et al. (2024), testing whether anger, disgust, and happiness show within-dyad coupling above stable average levels, and whether that coupling differs between the immediate-response and forced-break conditions.

I advanced two sets of preregistered hypotheses regarding these research questions. For the existence of same-emotion synchrony, I predicted detectable sameemotion synchrony larger than zero in anger (H1a), disgust (H1b), and happiness (H1c).

For moderation, I reasoned from the original mediation reported by McCurry et al.

(2024) that forced breaks operate by interrupting negatively-valenced emotion coupling while leaving positively-valenced emotion coupling intact. I predicted that forced breaks would weaken anger synchrony (H2a) and disgust synchrony (H2b) relative to immediate responses, while happiness synchrony would remain unaffected by condition (H2c). Because H2c represents an equivalence claim, it was evaluated against a preregistered equivalence-testing procedure rather than by failure to reject a null hypothesis.

Materials

As reported by McCurry et al. (2024), facial affective displays during the laboratory-based aggression task were captured using an Insta360 camera placed between participants. The camera was placed below face height so that participants were able to see each other with an unobstructed view. Action units of the Facial Action Coding System (FACS; Ekman & Friesen, 1978; Ekman et al., 1983) were extracted using OpenFace (Baltrušaitis et al., 2016), an open-source program which employs machine learning to automate FACS scoring 1 . Specific emotions were scored according to the FACS and Emotion FACS researcher manuals, which are not publicly available, by a member of the original research team who is certified to use the FACS and Emotion FACS by the Paul Ekman Group. Intensity scores of action unit activation were used as the index of experienced emotional arousal where higher intensity scores indicate a stronger prototypic emotional expression. These emotional displays were coded in accordance with the core combinations of facial action units (Ekman & Friesen, 1978; Ekman et al., 1983). The intensity of emotions was scored during the blast initiation response time window (+/-1 s; see Procedure and McCurry et al. (2024) for additional information).

Procedure

The procedure reported here details only what is pertinent for the present work; a richer description of the study's full procedure may be found elsewhere (i.e., McCurry et al., 2024). Study recruitment occurred through the University of St. Andrews' (St.

Andrews, Scotland) participant recruitment and memo systems. Interested individuals completed an online pre-screening survey to assess inclusion criteria (i.e., over the age of majority in Scotland, currently in a romantic relationship). If deemed eligible, potential participants were scheduled with their romantic partner to attend a laboratory-based experimental session. At the beginning of the laboratory-based session, participants provided their consent, though were left blind to the fact that the study measured intimate partner aggression. After providing their consent, dyad members were randomly assigned, as a unit, to either an immediate-response or forced-break condition, which applies to the aggression measure detailed next.

Participants were shown a brief demonstration of a face-to-face (FTF) version of the Competitive Reaction Time Task (CRTT; Warburton & Bushman, 2019). After the demonstration, participants completed 30 rounds of the FTF-CRTT. During the game, both romantic partners were in the same room, standing at separate monitors, but facing each other with an unobstructed view of their partner's face. During the task, participants competed to press a button faster than their opponent. In rounds where the discrepancy between the button press was 100 ms or lower, the winner was chosen at random. In the immediate-response condition, the winner immediately selected the volume of the noise blast to be delivered to their partner, ranging from 75 db to 110 db.

In the forced-break condition, the winner waited either 5 s, 10 s, or 15 s before making their decision (break lengths were collapsed for analysis; see Data Analysis Plan).

Video recording was continuous throughout the FTF-CRTT. A fuller account of the procedure and equipment setup may be found elsewhere (i.e., McCurry et al., 2024).

Data Analysis

All analyses were conducted in R (v4.5.2; R Core Team, 2025) using the dplyr (v1.2.0; Wickham et al., 2026), tidyr (v1.3.2; Wickham et al., 2025), and ggplot2 (v4.0.2; Wickham, 2016) packages for data preparation, the lme4 (v1.1-38; Bates et al., 2015) and lmerTest (v3.2-1; Kuznetsova et al., 2017) packages for linear mixed model estimation and Satterthwaite-approximated inference, the nlme (v3.1-168; Pinheiro & Bates, 2000; Pinheiro et al., 2025) package for indistinguishability and random-effect structure testing, and the simr (v1.0.9; Green & MacLeod, 2016) package for simulationbased sensitivity power analyses.

Data Preparation

Trial-level emotion intensity scores were standardized within-participants (i.e., M = 0, SD = 1) prior to modeling. This standardization enables the resulting synchrony estimate to be symmetric with respect to arbitrary partner labeling, which was central to the modeling approach adopted for indistinguishable dyads. Four of the dyads in the final sample had fewer than 30 rounds of the FTF-CRTT, for reasons unspecified in the original article. In each case, the shorter partner's round set was a subset of their partner's, and these dyads were retained by trimming to each dyad's own shared round set rather than excluded. This was considered to be a deviation from the preregistration.

Dyad members were treated as indistinguishable. Partner labeling was assigned at random within each dyad, independent of any substantive variable, since no systematic, theoretically meaningful distinction between partners was available in the sample.

Same-emotion synchrony was operationalized as the within-dyad, trial-to-trial (i.e., concurrent) covariation between partners' standardized emotion intensity scores estimated via linear mixed models with dyad as a random effect. This approach decomposes concurrent covariation into a within-dyad component and a between-dyad component, addressing a limitation of simple pooled correlations, which conflate the two.

Hypothesis Testing

Prior to modeling, base rates (i.e., percentage of trials with intensity > 0) and between-dyad intraclass correlations (ICCs, from a random-intercept model on raw, unstandardized intensity) were examined for all coded emotions. An emotion was considered viable for modeling if it cleared a non-floor base rate (i.e., intensity > 0 on at least 5% of trials) and showed non-trivial between-dyad variance relative to the other emotions. I did not specify a fixed, numeric ICC threshold as there is not a widelyestablished convention for this application.

For each emotion retained after assessing base rates and ICCs, a model constraining partner-level means and variance equal across the two arbitrarily labeled dyad members was compared to an unconstrained model allowing member-specific means and variances to differ freely. This check was conducted on raw intensity scores, since within-person standardization would trivially equate means and variances by construction.

For the condition-moderation model (Model B, below), whether the random slope variance should be estimated as shared across conditions or allowed to differ by condition was tested empirically via likelihood-ratio test, comparing a shared-variance specification against a heterogenous-variance specification, for each retained emotion.

Three linear mixed models were fit per emotion. Model A estimated a single pooled synchrony slope across conditions, testing whether same-emotion synchrony differed from zero. Model B tested condition as a moderator of synchrony via a dummycoded condition variable (control = 0, experimental =1), with the coefficient for the interaction serving as the omnibus test of whether synchrony differed between the immediate-response and forced-break conditions. As in McCurry et al. (2024), all forced-break conditions were collapsed into a single forced-break condition. Model C decomposed Model B's interaction into condition-specific simple slopes, reported alongside Model B to characterize the direction and magnitude of any condition effect. This model included two dummy-coded condition variables, one was the same variable used in Model B while the other reversed the scoring. This approach provides separate estimates of covariation in each condition. Fixed intercepts were omitted from all models, as within-participant standardization fixes each individual's and each dyad's mean at exactly zero, leaving no intercept to estimate.

As preregistered, the data were not detrended for the effect of time. Round number in the task is not included as a covariate in any model and the concurrent covariance structure is treated as the estimate of interest without adjusting for any linear or non-linear trend across the 30 rounds. This decision was made due to the fact that the round number does not map onto elapsed time in a comparable way across conditions. Detrending on round numbers would not cleanly separate a time effect from condition itself, and could introduce a confound rather than remove one.

Fixed-effect statistical significance tests used Satterthwaite-approximated degrees of freedom. Given evidence of non-normality in facial-affect intensity scores reported by McCurry et al. (2024), bootstrapped confidence intervals were computed as a robustness check on all primary fixed-effect estimates. Where bootstrapped and model-based inferences disagreed, the bootstrapped result was treated as authoritative, per the preregistered decision rule. For the directional hypothesis predicting equivalence in condition effects for happiness synchrony (i.e., H2c), a two one-sided tests (TOST) equivalence procedure was used (Lakens, 2017), with an equivalence bound of Δ = 0.10 on the standardized slope scale.

Deviations From the Preregistration

Three deviations from the preregistered analysis plan were deemed necessary during data preparation and analysis. Full details may be found in the Supplementary Materials. First, a subset of participants showed zero within-participant variance on a given emotion, most substantially for fear and anger. This was not anticipated in the preregistered exclusion criteria. Dyads containing such a participant were excluded from that emotion's models specifically, yielding a reduced analytic sample for anger (n = 39 dyads) relative to disgust and happiness (n = 51 dyads). Second, the preregistered indistinguishability check returned a statistically significant likelihood-ratio test for three emotions, which by the preregistered decision rule would have required revisiting the modeling approach. Diagnostic follow-up traced this to raw-scale variance heterogeneity unrelated to the standardized-scale synchrony estimates the models actually report. This conclusion was confirmed by 25 independent re-randomizations of partner labeling rather than relied upon as reasoning alone, after which the originally preregistered modelling approach was retained. Third, for disgust specifically, the bootstrapped confidence interval technically excluded zero (i.e., lower limit = 0.002) while the corresponding Wald test did not reach statistical significance. Given the boundaryadjacent lower bound of the interval, this was interpreted as a non-supported effect, departing from the preregistered rule prioritizing bootstrapped inference when the two methods disagree.

Power Considerations

As the present work reports a secondary data analysis, simulation-based sensitivity power analyses were conducted to identify the minimum detectable effect size (MDES) with approximately 80% power (Table 1). Because the zero-variance exclusions described above yielded emotion-specific analytic samples, power analyses were conducted separately for each emotion that survived the descriptive and floor check, using that emotion's own fitted model structure. This preserved that emotion's specific sample size, residual variance, and random-slope variance. I estimated statistical power across a range of hypothetical true effect sizes (i.e., b = 0.01, 0.05, 0.10, 0.15, 0.20, 0.25, 0.30) for both the pooled synchrony estimate (Model A) and the condition interaction term (Model B) using 1,000 simulations per emotion, per model, and per tested effect size. A second, fine-tuned power analysis was conducted for Model A for the range in which the power estimate crossed .80. This second round of power analyses used the same model structure, but estimated across a narrower range of hypothetical true effect sizes (i.e., b = 0.06 -0.11, Δ = 0.005). A similar approach was conducted for Model B using a different range of hypothetical true effect sizes (i.e., b = 0.15 -0.25, Δ = 0.01). Significance was assessed via a Wald z-test rather than simr's default Kenward-Roger approximation, as the latter's model-comparison procedure is incompatible with the intercept-suppressed model specification. A model with no fixed effects beyond the term of interest has no valid nested reduced-model comparison for Kenward-Roger to construct. The Wald approach is consistent with the inferential framework used elsewhere in the primary analyses.

Condition Moderation Effect on Happiness Synchrony Rather than remaining stable while negative-emotion coupling was disrupted, happiness synchrony was stronger in the forced-break condition compared to the immediateresponse condition. Anger and disgust showed no evidence of condition moderation in either direction. Together, these findings suggest a different account of how forced breaks during conflict may operate than the account motivating the preregistered hypotheses.

I originally predicted that forced breaks would function by selectively interrupting negatively-valenced emotion (i.e., anger, disgust) coupling while leaving positivelyvalenced emotion (i.e., happiness) coupling intact. This account was grounded in the Violence Escalation Cycle (Anderson et al., 2008; Dewall & Anderson, 2011) and the broader theoretical framing of McCurry et al. (2024), whose mediation analyses indicated forced breaks reduce aggressive behavior via reduced negative affect. That behavioral mediation is not engaged here as it concerns mean-level affect and its consequences for IPA behavior, whereas the present study estimated trial-to-trial coupling only. The results do not support the specific coupling-disruption mechanism I originally proposed. Anger and disgust showed no detectable coupling to disrupt in the first place, and happiness coupling was amplified.

One plausible alternative account is that forced breaks function less as an interruption of negative escalation and more as a shared coordination opportunity. A brief pause may allow partners to re-align on positive affect together, whether through eye contact, a shared laugh or smile, or simply time removed from the competitive framing of the task (e.g., Arias-Sarah et al., 2024; Delgado et al., 2023; Kurtz & Algoe, 2015). On this account, the break's value lies less in what it removes than in offering an opening for a positive coregulatory move that draws the dyad back to a shared equilibrium (Butler & Randall, 2013). The reframing shifts the proposed function of the break from disrupting an existing negative coupling to creating an occasion for positive coupling. Future research should test this proposed mechanism by varying what partners do during the pause, not only whether a pause occurs.

The absence of anger and disgust synchrony might be attributable to a lack of statistical power and may not serve as positive evidence against the coupling. Both emotions occurred at low base rates during the task, limiting the opportunity to detect coupling even where it existed. Anger was additionally floored for a substantial share of the sample; 12 dyads contained at least one participant with no variance in anger across trials and could not be modeled. With so little non-floor signal, the anger models were poorly positioned to recover coupling of any plausible magnitude, and the resulting null result is uninformative about the underlying effect. Disgust was constrained by a similarly narrow, low-intensity distribution.

Limitations and Future Directions

Several limitations warrant discussion. Most fundamentally, the present study does not examine the aggressive behaviors during the task. Whether same-emotion coupling relates to the intensity, likelihood, or form of aggression is a question the present design cannot address. The evidence reported here should not be interpreted as evidence that synchrony promotes or mitigates IPA perpetration. Estimating whether synchrony relates to aggressive behavior within this dataset is not straightforward.

Synchrony is a dyad-level quantity whereas each trial yields a single directed aggression outcome. A dyad-level association would rest on a maximum of 51 dyads using per-dyad coupling estimates that are imprecise. This remains an open question deserving of rigorous investigation.

Additionally, the condition cells were small and highly asymmetric. As the present work is a secondary analysis, the original design of the study was calibrated for meanlevel aggression and its affective drivers, not synchrony. The present work inherits a design optimized for those aims rather than for detecting differences in synchrony.

Future work should use the effect sizes reported here to conduct a priori power analyses for primary data collection calibrated to questions related to synchrony.

Because anger and disgust were floored by relatively low base rates, future studies should consider designs that elicit these emotions at rates permitting reliable estimation. Furthermore, the synchrony estimated here is facial-expressive and should not be conflated with physiological or autonomic synchrony. Future multi-method approaches may combine the facial-expressive synchrony estimates with cardiac or electrodermal synchrony.

Conclusion

This study offers a preliminary estimate of same-emotion expressive synchrony during a laboratory-based IPA task, decomposed from between-dyad similarity and modeled separately by emotion. Happiness synchrony was robust. Anger and disgust synchrony were not detected. Importantly, the design was better positioned to establish the happiness estimate than to rule out the anger and disgust estimates. The forcedbreak manipulation did not dampen negative-emotion coupling as predicted. Instead, the manipulation amplified happiness coupling, inviting a reconsideration of what such pauses afford partners rather than what they interrupt. Per-Emotion Exclusion of Zero-Variance Participants

The preregistered exclusion criteria did not anticipate participants who showed zero within-participant variance on a given emotion across trials. Such cases occurred, most substantially for fear and anger. Because trial-level emotion intensity scores were standardized within-person prior to modeling, a series with no within-person variance cannot be standardized as the operation requires division by the within-person standard deviation. Additionally, this carries no information about trial-to-trial coupling. I excluded any dyad containing such a participant from that specific emotion's models only, rather than removing the dyad from all analyses. The rationale is that the problem is emotionspecific. A participant who is flat on anger may vary normally on happiness. A listwise exclusion across all emotions would discard usable data for no methodological gain.

The consequence is that analytic samples differ by emotion. The anger models rest on 39 dyads, whereas the disgust and happiness models rest on the full final same. This exclusion, and the resulting emotion-specific sample sizes, propagate into the emotionspecific power analyses reported in the main text.

Non-Numeric Threshold for Between-Dyad Variance

For screening which emotions were viable for modeling, I preregistered attention to base rates and between-dyad variance but did not preregister a fixed numeric threshold on the intraclass correlation (ICC). I applied a base-rate floor (intensity greater than zero on at least 5% of trials) as a hard criterion, but evaluated between-dyad variance relative to the other coded emotions rather than against a preregistered ICC cutoff. I made this choice because no widely established ICC convention exists for this application, to my knowledge, and any fixed cutoff would have been largely arbitrary. This is best characterized as a clarification of an underspecified element of the preregistered analysis plan rather than a contradiction.

Resolution of the Indistinguishability Likelihood-Ratio Tests

I preregistered a check comparing a constrained model (equating partner-level means and variances across the two arbitrarily labeled dyad members against an unconstrained model, with the decision rule that a statistically significant likelihood-ratio test would require revisiting the modeling approach. The test was statistically significant for three emotions (anger, disgust, and the exploratory surprise). Following the preregistered rule literally would have prompted a change in approach. Diagnostic follow-up instead traced the statistically significant result to heterogeneity in the rawscale variances between the arbitrarily labeled dyad members, a feature that does not affect the standardized-scale synchrony estimate the models actually report. The indistinguishability check is necessarily conducted on raw intensity scores because within-person standardization would trivially equate means and variances by construction. The reported coupling estimates are computed on the standardized scale.

To confirm that the reported estimates were not sensitive to this raw-scale heterogeneity, I re-estimated the models across 25 independent re-randomization of partner labeling. The synchrony estimates were stable across all 25 relabelings. On this basis, I retained the originally registered modelling approach for all affected emotions. This is a departure from the preregistered decision rule. I believe it to be justified because the triggering condition was diagnosed as irrelevant to the quantities being estimated.

Interpretation of the Disgust Synchrony Estimate

For the pooled disgust synchrony estimate, the two inference methods disagreed. The bootstrapped 95% confidence interval technically excluded zero (lower limit of 0.002) while the corresponding Wald test did not reach statistical significance (p = .054). Under the preregistered decision rule prioritizing bootstrapped inference, this pattern would have supported H1b. I instead interpreted the effect as not supported, deviating from that rule. The reasoning combined three considerations: the lower bound of the bootstrapped interval sat immediately adjacent to zero, the Wald test was not statistically significant, and the sensitivity power analysis indicated the observed effect fell below the minimum detectable effect size this design could detect with approximately 80% power. Read together, these point to an underpowered, inconclusive result. The decision affects the verdict on H1b, which is reported as not supported, and it is framed throughout as an inconclusive result.

Future

For example, same-emotion lagged coupling deserves attention. The present work estimates concurrent, within-trial coupling, which cannot separate mutual co-expression from one partner leading and the other following. Concurrent and lagged coupling are different claims, and distinguishing them is a natural next step for characterizing expressive coupling during laboratory-based IPA. Other work may seek replication in a purpose-built and adequately powered sample. Because the coordination account and the disruption account it competes with make different predictions about what partners do during the pause, the most informative design would manipulate the content of the break itself.
