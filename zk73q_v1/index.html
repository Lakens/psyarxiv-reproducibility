How Power Analysis Check works

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Psychological experiments target the causal effects of latent variables, which they cannot manipulate directly. Researchers use manipulation checks to confirm that the latent variable changed, but then estimate the causal effect of the manipulation itself, not that of changes in the target latent variable. We treat the manipulation as an instrumental variable (IV) for the latent treatment, measured by several items, and derive conditions under which the treatment's average causal effect is identified. The resulting assumptions allow for some treatment-effect and loading heterogeneity, and are weaker than those most psychometric applications already make.

Because a latent treatment has no unit, the estimand is defined only once a scale is fixed. We define two and work out their identification: an anchored estimand, per unit of one item, and a standardized estimand, per standard deviation of the latent treatment.

The latter is more familiar but requires more assumptions and, notably, does not transfer between experiments. We show how to estimate both estimands with off-the-shelf SEM and IV software, and a simulation shows how the estimators behave in realistic samples when individual assumptions fail. Because researchers design the manipulation and choose the items, we close with practical implications.

Identifying Causal Effects in Experiments with Latent Treatments: An Instrumental Variable Approach

Psychologists and social scientists are interested in causal effects of changes in latent variables, such as psychological states, traits, or emotions. These latent variables pose two problems for causal inference: latent variables cannot be observed, and, more consequentially, they cannot be manipulated directly in an experiment. For example, to study how sadness X affects a financial decision Y , sadness must be manipulated by proxy, with an emotionally evocative film clip (Lerner et al., 2013). The film clip Z is the experimental manipulation, but it is of no substantive interest in itself: it serves only to shift the target variable X, the emotional state observed via self-reported affect ratings.

The same structure recurs whenever a procedure is used to move a latent state: a stereotype-threat framing raises experienced threat (Steele & Aronson, 1995), an induced-compliance procedure provokes dissonance (Festinger & Carlsmith, 1959), the Trier Social Stress Test elevates stress (Kirschbaum et al., 1993), and an effortful task induces ego depletion (Baumeister et al., 1998). In each case, the researcher randomizes Z but not X, so the study is not a classical experiment: observed changes between groups are due to Z, and this randomization does not rule out confounding of the X → Y relationship by unmeasured variables U . Retrieving the target causal effect (the causal estimand) therefore requires further assumptions about how X, its measurement, and the instrument Z used to shift it are connected.

Knowing these necessary assumptions is vital, because experimenters have some control over design and measurement and can tailor both to make the assumptions plausible. Psychological interventions Z can be characterized as indirect interventions (Junker & Grosz, 2026; Mathur, 2025), which places them in the general framework of instrumental variable (IV) identification, well established in the causal inference literature (Hernán & Robins, 2006; G. Imbens, 2014). IV approaches exploit the randomization of Z even though Z shifts X only partially. Outside of psychology, such a source of exogenous variation (a lottery, a policy change, or assignment to a treatment arm in a randomized trial) is used to estimate treatment effects even though the treatment itself was not randomized. In this sense, psychological experiments resemble randomized encouragement designs, common in medical trials with non-compliance, where participants can only be encouraged to take a treatment, but compliance is not enforced.

IV identification has received growing attention in the psychological literature, so far for manifest treatments (Grosz et al., 2024; Maydeu-Olivares et al., 2019; Student, 2026). However, this literature does not account for the treatment itself being measured only indirectly. Latent variables in experiments have so far been studied mainly as outcomes (Fu & Green, 2026a , 2026b; Stoetzer et al., 2025). We build on two features that distinguish the psychological setting from the typical econometric or epidemiological application. First, psychological variables cannot be measured directly: the latent treatment X is observed only through indicators I 1 , . . . , I J , each of which reflects X with error. Second, the instrument Z is chosen by the researcher rather than arising naturally, so it is a nuisance variable introduced only to induce variation in X. Psychologists are not interested in the effect of the film clip, the framing, or the stressor as such; they care about the causal effect of the latent X on the outcome Y.

In this article, we develop a unified set of causal and measurement assumptions under which the average causal effect of a latent, indirectly measured treatment can be identified and estimated from a randomized encouragement design. A latent treatment has no inherent scale, so its effect can be expressed on more than one scale. We define two estimands and provide practical estimation procedures for both. We close with the implications of our results for applied studies.

The Fourth Point-Identifying Condition: Homogeneity

By itself, a valid instrument Z does not suffice to point-identify the causal estimand.

What the instrument recovers is at best a weighted average of individual causal effects rather than the ACE in the whole population. Point identification of the ACE requires an additional assumption about effect homogeneity. The more commonly discussed alternative in econometrics is to forgo the ACE and instead target the local average treatment effect (LATE), the causal effect among the subgroup of compliers, identified under a monotonicity assumption (Angrist et al., 1996). The LATE is typically not the estimand psychologists are interested in (see Box 1), so we take the homogeneity route instead. Psychologists know this route far less well than the LATE framework, which is why we develop it in detail here. It also shows an instructive contrast: the econometric IV literature and psychometric modelers are willing to make quite different modeling assumptions.

For intuition, recall that IV identification works by inducing variation in X through an intervention on Z. Because Z is randomized, this induced variation is independent of any X → Y confounding. The exclusion restriction then licenses the claim that all observed differences in Y between levels of Z operate through differences in X.

Conceptually, however, we only learn directly about those individuals whose X actually changes in response to Z-if X were binary, these are the compliers with respect to the instrument. Participants not moved by the film clip contribute no variation in sadness, so the IV signal reflects only those whose sadness actually changes.

Box 1: Why Not the LATE?

In the econometrics literature, the well-known alternative to Assumption 4 is monotonicity (G. W. Imbens & Angrist, 1994). Assumptions 1-3 together with monotonicity identify the local average treatment effect (LATE), the causal effect in the subgroup of compliers. Monotonicity asserts that the instrument shifts treatment in one direction only: for every individual, being in the experimental group can raise X or leave it unchanged, but never lower it.

We do not pursue the LATE, because it is not a useful estimand in the settings we consider. There are at least three reasons.

First, the LATE depends on the instrument: different instruments induce different rates of compliance and thus different estimands. A sadness film and a sad autobiographical writing task move different people, so each identifies the effect of sadness on decision making in a different subpopulation. Psychologists rarely care about effects tied to one particular manipulation; they use instruments to shift a target construct and want the effect of that construct on the outcome. For the same reason, mediation effects of Z through X are not of substantive interest (Mathur, 2025).

Second, the complier population is itself not identified: without further assumptions, no individual can be classified as a complier. For continuous treatments such as psychological constructs, "compliers" are not even a well-defined group. With continuous X, the LATE becomes a weighted average of heterogeneous effects whose weights depend on the instrument in ways that are hard to interpret substantively (Angrist et al., 1996).

Third, monotonicity is not plausible in psychological settings. In medical trials it is defensible, because patients can typically access the treatment only if assigned to the treatment group. In psychological experiments, participants in both groups can move their latent state up or down, and it is unreasonable to assume that everyone responds to the instrument in the same direction or not at all. A film clip meant to induce sadness may leave some participants unmoved and strike others as absurd, cheering them up.

Strict Homogeneity

There are two possible conditions, each of which allows us to generalize immediately from the compliers to the population. Under the first, everyone responds to Z in exactly the same way, that is, the effect of Z on X is constant and additive across individuals: the film clip makes every participant sadder by the same amount. The instrument-induced variation in X is then homogeneous and there is no relevant non-complier subgroup to speak of. Under the second, participants differ in how sad the clip makes them, but a given increase in sadness changes the financial decision Y by the same amount for everyone. The complier-specific effect then coincides with the population ACE, and the IV estimate can be interpreted as the ACE.

Either condition suffices, and both are arguably strong and unrealistic, which is why the IV literature opted for different ways (see Box 1). Yet both conditions hold simultaneously in an LSEM without interactions. An LSEM takes Y to be linear in X and additionally restricts β Xi and β Y i to be constant across individuals. This is a peculiar assumption in light of Figure 1, which posits that unmeasured confounders U exist and jointly influence both X and Y : financial strain may make participants sadder and more impatient on average, but it is not allowed to make them more responsive to the film or more swayed by their own sadness. Many psychologists readily make these assumptions due to modeling convenience, because the standard LSEM encodes them by default.

We typically expect the effect of an intervention Z on X to vary substantially across individuals, and likewise expect the causal effect of X on Y to be modified by person-level characteristics. In that sense, the LSEM encodes a very special case of homogeneity: all effect modification by unmeasured variables is ruled out by construction.

The Anchor-Metric Estimand: Fewer Assumptions, Transportable Across Z

The standardized latent estimand is natural from a psychometric perspective, but it is not always the most useful causal estimand. Its unit is fixed by the variance of X, so the estimand depends on the distribution of the latent treatment. This becomes a problem when effects are transported to settings in which X has a different variance: to populations that vary more in their sadness, or to designs in which another film clip or a different Z shifts sadness more strongly. A sadder film makes one SD of sadness a larger dose, and so yields a larger reported effect. Comparability across studies is a central aim of experimental design, and study-specific scales are a recognized obstacle to it (Fu & Green, 2026a).

Simulation

A simulation study supplements the theoretical results and serves three purposes.

First, it confirms that both estimands are estimated without bias at a large sample size when theory predicts identification (see Table 1) and an appropriate estimator is chosen.

Second, it compares the estimators at a more realistic sample size, in scenarios where both estimands are identified and in scenarios where they are not. Third, it shows how the estimators perform for both estimands when a single item, or the anchor item itself, is affected by assumption violations.

Discussion

Psychological experiments do not directly manipulate a treatment variable X, which means that estimating the causal effect of X on Y is not guaranteed by design but requires additional assumptions: three classical IV assumptions that make Z a valid instrument and one assumption for the structural relationship between X and Y (NOSH). If X is latent, its scale is not intrinsic and multiple estimands may be identified. This paper developed strategies to identify two of those estimands. Via exclusion restrictions, the effect of Z on any downstream variable, be it an indicator or the outcome, should run only via X (Assumptions 2 and 5). Via uncorrelated-heterogeneity conditions, the person-level treatment effects and item loadings must be uncorrelated with first-stage β Xi (Assumptions 4(b) and 6(b)). Our simulation study violated these assumptions one at a time and demonstrated the resulting bias.

Which Estimand, and at What Cost

Because latent variables have no inherent scale, causal effects of a latent X can be expressed in two main ways: via an intervention that shifts X by one SD, or per unit on the scale of an anchor item, I 0 . Both estimands require the traditional IV identification Assumptions 1-4, yet they differ in the assumptions they require of the indicators. The SD strategy recovers the loadings, and hence the latent variance, from the inter-item covariance structure, so Assumptions 5-8 must hold at every indicator in the model. The choice between the two estimands is not only a question of which assumptions one is willing to defend: whenever θ SD is identified, a valid anchor necessarily exists. The decision is more about which estimand is useful. θ SD is familiar but has a major problem: its unit is fixed by Var(X), which depends on instrument strength. 5 A stronger Z inflates Var(X) and yields a larger θ SD even when the causal effect is unchanged. That standardized effects need care when compared across studies is well known (Pek & Flora, 2018). θ SD adds a further problem: it is standardized to an artificial experimental condition, for example the spread of X that one particular sad film produces, whereas causal questions in psychology usually concern X itself. The SD estimand is the more appealing choice for a latent X that is measured with no clear anchor but with a variety of valid indicators, which differ from task to task or from study to study. Cognitive tasks with a latent X such as memory or general ability are of this kind. The anchor strategy fits the opposite case: it is appealing if few items are available and the same established items already recur across studies. Personality research is one example, where a Big Five item can serve as the anchor. The anchor strategy fits with trends that emphasize shorter scales (Allen et al., 2022; Eisele & Houben, 2026; Matthews et al., 2022), but some estimators can also use information of other items to gain efficiency, provided Assumptions 7 and 8 hold at those items.

Connection to Measurement Invariance

Identification for both estimands requires that X is measured in the same way in both conditions of Z, which is why the assumptions made here resemble familiar assumptions about measurement invariance. Measurement invariance is typically defined as a probability statement: among participants with the same value of the latent variable, the indicators must have the same joint distribution in both conditions, (I 1 , . . . , I J ) ⊥ ⊥ Z | X (Meredith, 1993). This is usually discussed as a prerequisite for comparing latent variables across populations; here, only the experimental conditions Z ∈ {0, 1} are compared.

Recent work has recognized that traditional measurement invariance assumptions demand far more than most analyses require, and more than most analysts are willing to defend (Rohrer & Paulewicz, 2025; Sterner et al., 2026). They hold each indicator to be exogenous to every variable except the latent variable it measures, with loadings constant across persons. A factor model this restrictive trivially satisfies the conditions derived here, but assumes much more than IV analyses typically do. Suitable tests of measurement invariance, like multi-group SEMs, fail if any of Assumptions 5, 6 or 8 is violated, provided the other items are invariant. Yet they can also fail when the effect is identified: θ I 0 does not require Assumption 8 at the anchor, and heterogeneous loadings make the test of strict invariance fail even when they are unrelated to X and Z and thus satisfy Assumption 6(b).

This general understanding of measurement invariance is therefore not necessary for identification, and, more consequentially, a failing test does not show which assumption could be violated. Stating measurement invariance causally gives an opportunity to explain why invariance fails and to account for it in the analysis (Sterner et al., 2024).

Rather than asking whether measurement is invariant across treatment conditions, our approach follows the causal inference tradition (Hernán & Robins, 2006; G. W. Imbens & Angrist, 1994): state the causal estimand of interest, then find the minimal requirements under which it can be estimated from data. Accurate measurement of X that is comparable across other subgroups, such as fully transportable loadings, is at best collateral. The indicators are part of the same causal system as Z, X and Y , and the assumptions they must satisfy follow from the estimand and its identification strategy. The causal inference literature states assumptions about the causal substance, independent of estimation or modeling technique, and this makes those assumptions easier to evaluate. In the running example, Assumption 6(b) can be stated with reference to features of the experimental design: it fails if participants who are moved more by the film also use the sadness rating more extremely, for instance because both depend on emotional expressivity.

Stated this way, the assumption names a pre-treatment moderator that can be measured, checked and adjusted for. In contrast, assumptions that are stated about the model, such as "constant loadings" or (I 1 , . . . , I J ) ⊥ ⊥ Z | X, offer no such handle.

Limitations and Future Work

The identification results presented here rest on assumptions that psychometric applications routinely make, often in a stronger form. Still, they are restrictive and should be stated carefully in practice. Two of them are linearity requirements that could be relaxed. Linearity of X → Y (Assumption 4(a)) is probably a minor concern, because the measurement error common in psychological studies tends to make nonlinear effects look linear anyway (Jacobucci & Grimm, 2020). Linearity of X → I 0 (Assumption 6(a)) matters more in practice, because it restricts the anchor strategy to items that can be treated as continuous. That excludes the binary and ordinal item response models that dominate psychological measurement (Van Der Linden & Hambleton, 1997), which are nonlinear by construction. Existing alternatives trade linearity against other assumptions: they assume unconfoundedness (Schennach, 2007) or strict homogeneity (Stoetzer et al., 2025), or they require proxies that vary as richly as the latent variable they stand in for (Tchetgen et al., 2020). Extending the results presented here to IRT models, while retaining sufficient generalizability or heterogeneity, remains an open problem. One approach might be to define the item's potential outcomes as expected ratings given U i and ϵ ji , as Hartwig et al. (2023) do to accommodate binary variables.

Our simulation study had a limited scope and did not cover a range of realistic scenarios. The scenarios check the theoretical results and are no substitute for a design or power analysis. Each scenario violates a single assumption at moderate strength, with a strong instrument, a large causal effect, and high loadings. Applied studies likely face several violations at once. Weaker instruments, smaller effects, and lower loadings make every estimator less precise. The Anchor-Wald estimator is most affected, since it rests on a single item. The sample size a study needs, and the estimator that performs best in it, depend on all of these parameters jointly. A realistic power analysis therefore would need plausible values for each parameter, including the strength of every source of confounding and the combinations in which these sources are likely to co-occur. Future work should evaluate the estimators in more realistic scenarios and address the bias-variance trade-off of adding more items: each additional item may gain efficiency but may also add confounding.

Throughout, Y was treated as unidimensional or manifest for simplicity. The framework extends directly to a latent or multidimensional Y , for example by adding an indicator of Y to the Wald ratio. However, the approach does not generalize to multidimensional treatment variables X. Because each facet can be changed separately, the treatment can be changed in several ways, which makes the estimand harder to define. If the facets of X differ in their effect on Y , it is unclear which change the causal estimand refers to, and (causal) consistency between data and estimand fails (Junker & Grosz, 2026). In our example, sadness that comes with a sense of loss may trigger a search for immediate reward, which shifts financial decisions (Lerner et al., 2013); sadness that comes with a sense of personal failure might not. A causal estimand that takes broadly defined "sadness" as X is then ill-defined. Treatment variables should therefore be sufficiently unidimensional. This makes (causal) consistency more plausible and the exclusion restrictions (Assumptions 2 and 5) easier to state.

Practical Implications for Psychological Research

The assumptions laid out above are strong and will not hold perfectly in applied settings. That is precisely why they are worth stating. A psychological experiment is constructed by the experimenter, who usually chooses both the manipulation Z and the indicators I j from several candidates. The assumptions are therefore design targets and can be made more plausible beforehand.

IV applications in economics and epidemiology are often limited to natural experiments outside the researcher's control. In psychology, researchers can choose their Z according to desirable properties: First, the instrument Z should have a strong effect on X.

Weak instruments lead at best to wide, uninformative confidence intervals, and at worst they amplify bias whenever any of the other assumptions is even slightly violated (Hernán & Robins, 2020). Second, the exclusion restrictions on Z must hold: any causal effect of Z on Y , or on any indicator I j , that is not fully mediated by X is problematic. Notably this is an assumption about unmeasured paths, such as indirect Z → U → I j , outside the model. Third, Z should work through mechanisms unrelated to moderators of the X → Y relationship. A sad film depicting financial hardship moves financially strained participants most, and they are plausibly also the ones whose monetary choices react most to sadness. A sad film without financial content decouples the two and makes NOSH far more defensible.

Unfortunately, psychological methods offer no clear, empirically validated recipes for ensuring that these assumptions hold. Instead, there are many compelling examples of likely violations. Violations of IV assumptions behave differently from violations in traditional confounder-adjustment methods: they can amplify bias, so that a simple OLS estimate may be biased and still land closer to the ACE than an IV estimate in which a single assumption fails (Hernán & Robins, 2020). The exclusion restrictions, that Z affects both Y and I j only via X, are probably the most critical assumptions; but they plague any causal inference in psychological experiments, due to their indirect nature (Eronen, 2020; Mathur, 2025). In contrast, heterogeneous effects and loadings likely matter less in practice, but allowing them comes for free.

The NOSH assumptions stated here generalize constant-effect assumptions and permit arbitrary individual-level heterogeneity in both the Z → X and the X → Y relation. This gives applied researchers a more transparent target: instead of assuming away all heterogeneity, they are asked to reason about whether the variables that make individuals more (or less) responsive to the instrument are also likely to make them more (or less) susceptible to the treatment effect. If such moderators are plausible and measured, they can be included in the treatment and outcome models, relaxing the burden placed on the unmeasured remainder of U and making the homogeneity assumption more plausible.

From a practical standpoint, this does not make the models more complicated. If the ACE is the target, the heterogeneity does not need its own parameter and can remain in the error term. A study can still be planned under optimistic parametric conditions, for example by taking our clean baseline scenario and additionally assuming a standard LSEM, which takes effects and loadings to be constant. This makes plausible parameter values for a power analysis easier to manage. The analysis can then use the same model: in our simulation, SEM-IV, which fixes the loadings, remains unbiased when effects and loadings vary, provided the remaining assumptions hold, because the loading variance is simply absorbed into the item error.

The proposed identification strategies therefore do not require new estimation techniques: off-the-shelf software such as lavaan suffices, and the model settings differ from routine practice by a single scaling constraint. What may change is the target quantity, and studies that report SD scaled estimands could also report anchored estimands. The effect of sadness on financial decisions, for example, would be reported both per scale point of a single sadness rating and in units of the latent construct itself.

The anchor estimand is identified under less stringent assumptions. It is not "the effect" of sadness in the abstract way that researchers may have hoped to report, but it is the effect they are better equipped to identify, defend and compare. Thus, to quote Angrist and Pischke (2009, p. 83): "Sometimes You Get What You Need."

Two-Step Estimation (Factor Scores)

In the first approach, the latent variable is operationalized by estimating a Confirmatory Factor Analysis (CFA) model and extracting factor scores. These scores are then treated as a manifest variable in a standard two-stage least squares regression. While computationally simple, this method treats the factor scores as observed in the second stage. The standard errors are the HC3 standard errors of the manifest case with the scores in place of X. The uncertainty of the estimated loadings, which fix the scale of the scores, is not. Appendix B Estimation Estimation With a Manifest Treatment

The Wald ratio β IV (X) in Equation ( 9) is typically estimated by two-stage least squares, but it can equivalently be estimated within a SEM framework.

Two-Stage Least Squares

In the first stage, the treatment X is regressed on the instrument Z to isolate the variation in X that is induced by the instrument, yielding predicted values X. In the second stage, the outcome Y is regressed on these predicted values. The coefficient of X in the second stage is the estimator of the causal effect. Two-stage least squares can be fit with ivreg(Y ~X | Z) from the ivreg package (Fox et al., 2026). Its default standard error is the conventional two-stage least squares standard error, which assumes homoskedastic residuals (Angrist & Pischke, 2009). The residual variance σ2 = i ê2 i /(n -2) uses the structural residuals êi = Y i -αb • X i , with b = β IV (X) and α the estimated intercept. These residuals use the observed treatment X i , not its first-stage prediction Xi ; this is the adjustment that running the two regressions by hand misses. With a single instrument, the standard error reduces to where n is the sample size, σX the sample standard deviation of the treatment, and ρZ,X the sample correlation between instrument and treatment, that is, the strength of the first stage.

A stronger first stage therefore gives a smaller standard error.

Heterogeneous effects make the residual variance differ between persons. The simulation therefore reports heteroskedasticity-robust HC3 standard errors from the sandwich package (Zeileis et al., 2026),confint(fit, vcov. = vcovHC(fit, type = "HC3")), and t quantiles with n -2 degrees of freedom. They replace the common residual restricted specification and show its consequences in the simulation.

The structural coefficient inherits the scale of the latent variable X. With the loading of I 0 fixed to one, it estimates θ I 0 . The SD-scaled effect θ SD is retrieved from the std.lv column of lavaan's standardized output (standardizedSolution(fit, type = "std.lv")), which multiplies the coefficient by the model-implied SD of X. Its delta-method confidence interval accounts for the fact that this SD is estimated. The std.all column would additionally scale it by the SD of Y.

The assumptions stated here are slightly stronger than necessary, tailored to psychological experiments for clarity. For example, Z need not be randomized or causally efficacious itself(Hernán & Robins, 2020;Pearl, 2009).

Nor does a manifest X require Z to be independent of the item errors ϵ ji ; we include it here because randomization guarantees it anyway and the latent case introduced later relies on it.

If the anchor were nonlinear, the per-unit effect would vary across the range of X. The Wald ratio would then return an average weighted by where on the range of X the instrument happens to move respondents. Like the LATE (Box 1), this average depends on the instrument, which defeats the purpose of the anchor metric.

In practice, additional measurement assumptions can still be imposed so that the other indicators enter a latent IV model and improve efficiency, as is done in the simulation study.
