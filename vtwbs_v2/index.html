Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

About the personal-information flags. These are pattern matches, not confirmed disclosures, and they are tuned to over-report rather than miss something. Expect false positives:

  • Column names are matched against identifying words in English and other European languages (email, telefoonnummer, geboortedatum, …). A column called phone_number flags whether or not it holds one, and an empty or already-anonymised column flags on its name alone.
  • Values are matched against the shape of an identifier. An IP address pattern also matches a version string or a dotted numeric code; a card-number pattern requires both a real issuer prefix and a checksum, but a long numeric ID can still coincide.
  • Free text is flagged when a column holds long, mostly-distinct prose — the shape open-ended answers take. Most such columns contain no names at all.

A flag means look at this column. Where the data is already de-identified (an ip column reading Anonymized, a name column the authors emptied), no action is needed.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Philanthropic behaviors such as volunteering and charitable giving promote both societal welfare and individual well-being. Prior research has established cross-sectional links between broad personality domains and these behaviors, but it remains open whether and how personality differences prospectively predict philanthropic engagement (selection effects) and whether such engagement may, in turn, predict personality development over time (socialization effects). Furthermore, it is still unclear whether and how narrower personality aspects are linked to philanthropic behaviors. Drawing on five-wave nationally representative data from Switzerland (Nwave = 2,085 to 4,475), we extend prior research by testing prospective selection effects of personality traits on later philanthropic engagement and examining socialization effects of engagement on personality trajectories across broad personality domains and their narrower aspects. Results indicated that higher extraversion and lower neuroticism consistently predicted volunteering, whereas higher agreeableness and honesty-humility robustly predicted charitable giving. At the lower-order level of personality aspects, meaningful differences emerged within the domains of agreeableness and conscientiousness in predicting philanthropic behaviors, with compassion and industriousness showing more consistent and positive links than politeness and orderliness. Evidence for socialization effects was more limited. More time spent on volunteering was associated with smaller decreases in extraversion, although this effect differed depending on the included covariates. We discuss these findings in the context of theories on personality and prosociality and outline limitations and avenues for future research.

Personality Traits and Philanthropy Across Time

Understanding who engages in philanthropy and how such engagement relates to personality development could inform efforts to promote both individual well-being and societal welfare (Healy, 2002; Hui et al., 2020). Personality traits are meaningful predictors of a wide range of life outcomes (E. D. Beck & Jackson, 2022; Ozer & Benet-Martínez, 2006; Roberts et al., 2007; Soto, 2019 Soto, , 2021)), including people's engagement in philanthropic behaviors (e.g., Bleidorn, Stahlmann, Orth, et al., 2025; Stahlmann et al., 2025). Volunteering and charitable giving are core examples of such philanthropic engagement (Bekkers, 2006 (Bekkers, , 2010)).

Meta-analytic evidence indicates that high levels of extraversion and openness are linked to volunteering, whereas high levels of agreeableness are related to charitable giving (Bleidorn, Stahlmann, Orth, et al., 2025). However, effect sizes vary considerably across studies. This heterogeneity may stem from over-reliance on small samples and brief personality inventories, which limits precision and the ability to examine broad and narrow personality traits. Notably, theory and preliminary evidence suggest that narrow personality traits (e.g., compassion vs. politeness aspects of agreeableness) may differ in their relation to philanthropic behaviors (Bleidorn, Stahlmann, Orth, et al., 2025; Smillie et al., 2019; Zhao et al., 2017b), implying that associations observed at the broad domain level may be obscured or imprecise (Stahlmann et al., 2024).

Moreover, most existing research has relied on cross-sectional data and predominantly focused on concurrent links between personality traits and current or lifetime prevalence of philanthropic engagement. Longitudinal research examining both prospective selection effects of personality traits on subsequent philanthropic behavior and potential socialization effects of philanthropic participation on personality development remains scarce (cf. Luengo Kanacri et al., 2014). Finally, personalityphilanthropy transactions may unfold differently across the lifespan, raising the possibility of unique age-dependent links between personality traits and philanthropic behaviors.

The present study extends previous research by examining the longitudinal transactions between philanthropic behaviors and both broad and narrow personality traits across the lifespan. We used data from a nationally representative sample of Swiss adults who participated in a 5-wave longitudinal study spanning 2 years. By integrating repeated assessments of volunteering, charitable giving, and personality traits, we distinguished cross-sectional associations from prospective selection and socialization effects and tested how lower-order traits may have unique, developmentally sensitive links with philanthropic engagement beyond broader personality domains.

Traditional Philanthropy and Personality Traits

Volunteering and charitable giving are common forms of civic engagement often referred to as traditional philanthropy 1 (distinguished from health-related philanthropy such as blood donation; Bekkers, 2006 Bekkers, , 2010)). They involve donating time, effort, money, or other goods to individuals or organizations outside one's family and friends (Penner, 2002) 2 . Although these two forms of engagement are empirically linked to each other (S. M. Farmer & Fedor, 2001; Kawawaki, 2023; Wiepking & Maas, 2009; Yao, 2015), existing research suggests that they are best conceptualized as complementary yet distinct forms of philanthropy (E. Brown & Lankford, 1992; S. Brown & Taylor, 2018; Cappellari et al., 2011; Hill, 2012; Jones, 2006; L. Wang & Graddy, 2008). Both behaviors have been associated with beneficial effects for recipients (e.g., reduced loneliness, strengthened selfesteem, or subjective well-being more broadly; Grönlund & Falk, 2019; McGuire et al., 2022), donors (e.g., higher well-being, Hui et al., 2020), and broader societal functioning (e.g., increased social capital, Healy, 2002; OECD, 2021).

Prior research suggested that individuals differ systematically in their willingness to engage in philanthropy (Bekkers & Wiepking, 2011; S. Brown & Taylor, 2018), and that these differences can partly be explained by broad personality traits (Bleidorn, Stahlmann, Orth, et al., 2025; Smillie et al., 2019; Thielmann et al., 2020). Personality traits can be hierarchically organized, with the Big Fiveextraversion, agreeableness, conscientiousness, openness, and neuroticism-at the core of the hierarchy (John & Srivastava, 1999). The Big Five trait domains received robust support for their generalizability across samples and measures and represent a viable balance between conceptual 1 For readability in the present study, we refer to both behaviors as "philanthropy"/ "philanthropic". 2 In prior research, philanthropy was often operationalized as intentions to volunteer/donate (e.g., "I am willing to volunteer for an organization I care about without financial compensation for me"; MacDougall & McCann, 2020) or self-reported behavior (e.g., how much time people spent doing volunteer work; Allen et al., 2024), either using dichotomous (i.e., whether people volunteered/donated at all) or continuous scales (i.e., how much time/money invested in volunteering/charitable giving). Other indicators of philanthropic behavior, such as register-based donation records, are scarce (cf. Elinder & Erixson, 2025) and, though more objective, are difficult to link to individual survey data.

breadth and descriptive fidelity (John et al., 2008; McCrae et al., 2000). There are, however, different models of the lower-order structure of personality (Schwaba et al., 2020). Importantly, narrower personality traits at lower-order tiers can help improve the prediction of important life outcomes relative to broad domains (Jang et al., 2002; Mõttus et al., 2017 Mõttus et al., , 2024;; Stewart et al., 2022; Sun et al., 2018). As for philanthropic behaviors, preliminary evidence suggests that lower-order personality aspects show distinctive patterns of associations with prosocial and moral behavior (Smillie et al., 2019; Zhao et al., 2017a Zhao et al., , 2017b)). Therefore, collapsing across aspects may have obscured associations in prior research (e.g., Stahlmann et al., 2024). In the present study, we thus assessed the Big Five domains and 10 lower-order aspects (DeYoung et al., 2007).

Greater personality resolution may not be the only way to capture traits relevant to philanthropic behavior. Relevant individual differences may also lie outside the traditional Big Five structure. In particular, the HEXACO model distinguishes six rather than five broad personality domains (Lee & Ashton, 2004). It adds a sixth dimension, honesty-humility, which draws on agreeableness-and neuroticism-related content as well as content not captured by the Big Five (e.g., Ashton & Lee, 2007; Zettler et al., 2020). Honesty-humility has been found to be particularly relevant for prosocial behaviors (Smillie et al., 2019; Thielmann et al., 2020) and may therefore provide additional predictive value beyond Big Five traits. We next review prior evidence on cross-sectional associations of all Big Five domains and aspects as well as honesty-humility with philanthropy. We follow benchmarks representative of typical effects in personality psychology to describe effect sizes: r = .05 (very small), r = .10 (small), r = .20 (medium), r = .30 (large) (Funder & Ozer, 2019).

Extraversion reflects tendencies to seek out social activities and engage with others (John et al., 2008) and may thus relate to socially rewarding forms of philanthropy such as volunteering in group contexts (Bekkers, 2006; Omoto et al., 2010). Meta-analytic results confirm a very small to small positive association between extraversion and volunteering (r = .09) but not charitable giving (Bleidorn, Stahlmann, Orth, et al., 2025). At the aspect level, enthusiasm captures sociability and positive emotionality, whereas assertiveness reflects leadership and proactiveness (DeYoung et al., 2007), both of which may drive the volunteering link (King et al., 2015; Penner, 2002).

Agreeableness involves caring for others and favoring communal goals (John et al., 2008) and has long been theorized as a key predictor of prosocial and moral behaviors (Bekkers, 2006; Shane et al., 2021; Zhao & Smillie, 2015). This personality domain is conceptually and empirically related to narrower traits like altruism, empathy, and generosity, which have been studied specifically in relation to prosocial giving, helping, and volunteerism (e.g., Andreoni, 2006; Graziano et al., 2007; Haski-Leventhal, 2009). Despite this theoretical appeal, meta-analytic evidence supports a small positive association of agreeableness only with charitable giving (r = .14) but not with volunteering (Bleidorn, Stahlmann, Orth, et al., 2025). Specifically, the link between agreeableness and volunteering did not hold once corrected for small-study effects, potentially indicating that prior work on this trait may have been affected by publication bias. Distinguishing the aspects compassion and politeness may further clarify this pattern (Smillie et al., 2019): Compassion reflects empathic concern and may promote both direct helping such as volunteering and indirect prosociality such as charitable giving, whereas politeness captures norm adherence and fairness motives, aligning more closely with charitable giving only (Ferguson et al., 2019; Zhao et al., 2017a Zhao et al., , 2017b)).

Openness/intellect captures individual differences in imagination and curiosity (John et al., 2008) and predicts different prosocial behaviors (e.g., Arpino et al., 2025; Krämer & Bleidorn, 2025; Zhao & Smillie, 2015). It shows a very small positive meta-analytic association with volunteering (r = .05) but not with charitable giving (Bleidorn, Stahlmann, Orth, et al., 2025). Intellect, the cognitive aspect of this domain, tends to foster prosocial actions that require little material cost (Bleidorn, Stahlmann, & Hopwood, 2025; Ferguson et al., 2019; Zhao & Smillie, 2015), whereas the openness aspect may motivate engagement in unfamiliar environments. Together, these aspects may drive the observed link with volunteering.

Conscientiousness describes tendencies to be organized, reliable, and dutiful (John et al., 2008) and may thus support structured, socially responsible behavior. Meta-analytic associations with both charitable giving (r = .04) and volunteering (r = .03) were positive but minimal (Bleidorn, Stahlmann, Orth, et al., 2025). At the aspect level, orderliness may foster philanthropy through a sense of moral obligation, whereas industriousness may facilitate philanthropic behaviors through reliability and persistence. However, conscientiousness traits alone may not translate into philanthropy if ambition and dutifulness are oriented toward personal career advancement rather than prosocial goals (Stahlmann et al., 2024).

Neuroticism, the opposite pole of emotional stability, involves tendencies to worry, be selfoccupied, and experience negative affect (John et al., 2008), which might hinder philanthropic engagement. Neuroticism's negative association with volunteering (r = -.04) was again minimal, while no meta-analytic link emerged with charitable giving (Bleidorn, Stahlmann, Orth, et al., 2025).

At lower-order levels, withdrawal encompasses anxiousness and depressiveness and may be more relevant to volunteering than volatility, which refers to anger and emotional instability. Individuals high in withdrawal may avoid volunteering possibly due to fear of social evaluation or low selfefficacy (K. M. Brown et al., 2012; Eden & Kinnar, 1991).

Honesty-humility captures tendencies of being modest, greed-avoidant, and selfless (Ashton & Lee, 2009; Lee & Ashton, 2004) and consistently predicts cooperative and fair behavior, specifically in situations that afford the opportunity to exploit others (e.g., Columbus et al., 2019; Hilbig et al., 2018; Thielmann & Hilbig, 2018). Honesty-humility has thus been argued to capture unique variance in ethical restraint and active cooperativeness distinct from Big Five agreeableness (Ashton et al., 2014; Hilbig et al., 2013). Prior meta-analytic evidence indicates a medium to large association between honesty-humility and active cooperation-capturing cooperative, fair-minded, and loyal behaviorswith r = .27 (Zettler et al., 2020). Honesty-humility was also positively associated with prosocial behavior in economic games in a recent meta-analysis, with a small to medium effect size of r = .17 (Thielmann et al., 2020). For real-life charitable giving, one study found honesty-humility to correlate with the amount of money donated with a medium to large effect of r = .26 (Yelbuz & Thielmann, 2024). Regarding volunteering, honesty-humility was the strongest personality predictor of volunteer status even after adjusting for the other HEXACO dimensions (Marsh et al., 2022).

Taken together, meta-analytic findings suggest that being engaged in volunteering and, to a lesser degree, charitable giving is associated with adaptive levels of higher-order personality traits (Bleidorn, Hopwood, Ackerman, et al., 2020; Bleidorn, Stahlmann, Orth, et al., 2025; Marsh et al., 2022; Yelbuz & Thielmann, 2024). Volunteering has been related to higher extraversion, openness/intellect, conscientiousness, honesty-humility, and lower neuroticism, whereas charitable giving correlates with higher levels of agreeableness, conscientiousness, and honesty-humility.

Although these effect sizes tend to be small, their practical implications can be substantial at the population level (Funder & Ozer, 2019; Götz et al., 2022; Ozer & Benet-Martínez, 2006). For instance, even an association as small as r ≈ .05 could scale up to sizable differences in philanthropic behaviors over time when leveraged through personality-tailored recruitment of volunteers (Hirsh et al., 2012).

However, such reasoning presupposes that effect sizes are estimated reliably. Prior research may have fallen short in this regard: theoretical expectations and empirical findings sometimes diverge, as illustrated by the attenuation of the agreeableness-volunteering link after correcting for small-study effects (Bleidorn, Stahlmann, Orth, et al., 2025). More extensive personality measures that distinguish both broad domains and lower-order aspects, administered in sufficiently large and representative samples, are therefore essential for producing precise and stable estimates. Moreover, existing research focused on concurrent links, providing limited insights into how personality and philanthropy relate to one another over time. Personality traits and philanthropic behaviors could be linked because people with certain trait levels are more likely to later engage in volunteering or charitable giving (selection effects) or because personality traits change in response to engagement in philanthropic behaviors (socialization effects).

Selection Effects

Social selection refers to the tendency for people with certain traits to end up in social environments and roles that align with those traits (Caspi et al., 2005; Roberts & Jackson, 2008).

Consistent with previous research (e.g., Bühler et al., 2022 Bühler et al., , 2024;; Wrzus & Neyer, 2016), we use the term selection broadly to capture processes that guide people with certain individual characteristics towards specific events, contexts, or behaviors. In this sense, relatively stable personality traits have been theorized and found to predict later life outcomes, such as childbirth, occupational choices, and divorce (E. D. Beck & Jackson, 2022; Ozer & Benet-Martínez, 2006; Roberts et al., 2007). One important mechanism of selection is niche-picking, whereby individuals actively choose, shape, and maintain environments that fit their personal needs and preferences (Roberts & Damian, 2019). For example, extraverted people may decide to volunteer because they expect opportunities to socialize with other people. However, selection can also occur less actively, when differences in personality traits shape how individuals perceive, interpret, or are exposed to opportunities for philanthropy. For instance, agreeable individuals may notice and thus seize more opportunities to donate to charitable causes, because they are particularly attuned to others' needs.

The cross-sectional associations reviewed above provide an initial empirical basis for theorizing about selection effects from specific personality traits on different forms of philanthropic engagement. Because personality traits have long been theorized to be relatively stable across adulthood, they have often been examined as predictors distinguishing individuals who are more or less likely to engage in philanthropic behaviors, even if these variables were assessed simultaneously (e.g., Ackermann, 2019; King et al., 2015). However, two main problems prevent causal conclusions.

First, cross-sectional data cannot establish whether personality differences precede philanthropic engagement or simply co-occur with it. Consequently, prospective selection effects can differ from cross-sectional patterns. For example, agreeableness may correlate with charitable giving at baseline because prior donors have become more agreeable, yet baseline agreeableness may not predict new donations among previously uninvolved individuals (cf. Caprara et al., 2012). Prospective analyses are therefore essential to account for temporal precedence and test which personality traits forecast later philanthropic engagement.

Second, third variables may confound the relationship between personality traits and philanthropy. Economic resources, for example, have been linked to both personality traits such as openness/intellect, conscientiousness, and extraversion (e.g., Vella, 2024) and charitable donations (e.g., Schulreich et al., 2023). Confounding of between-person differences in these variables can be addressed by statistically controlling for them and may be reduced by adopting longitudinal designs that isolate differences in trait levels and trait change trajectories. However, time-varying withinperson confounders remain a threat to causal inference and demand clear articulation of underlying assumptions in psychological fields where experimental designs are not feasible (Grosz et al., 2020; Rohrer, 2018). This limitation applies to both directional interpretations: that personality traits shape philanthropic engagement and that philanthropic engagement contributes to personality change.

Socialization Effects

Longitudinal data also enable tests of this latter pathway of socialization, whereby engaging in philanthropic behaviors may be linked to personality development over time. Across adulthood, individuals tend to show adaptive personality change by becoming more agreeable, conscientious, and emotionally stable on average (e.g., Bleidorn et al., 2019; Bleidorn, Hopwood, Ackerman, et al., 2020; Roberts, Walton, et al., 2006). Social investment theory proposes that such normative development results from investing in social roles that demand caring, reliable, and emotionally regulated behavior (Roberts et al., 2005; Roberts & Nickel, 2017). As individuals commit to role-related responsibilities, they adapt their patterns of thoughts, feelings, and behaviors, and these adaptations may gradually consolidate into enduring traits. Consistent with this idea, socialization effects tend to be stronger when psychological role investment is high (Lodi-Smith & Roberts, 2007), although empirical support is overall mixed and effect sizes tend to be smaller than for selection effects (Bleidorn et al., 2013; Bühler et al., 2022 Bühler et al., , 2024;; Den Boer et al., 2019; Haehner, Krämer, Wright, et al., 2026).

Philanthropic engagement may elicit socialization effects in line with social investment theory.

Such behaviors can function as social roles when they involve sustained, normatively valued commitments that integrate individuals into broader social systems and foster a sense of affective, cognitive, and behavioral investment in the role (Bekkers, 2006; Lodi-Smith & Roberts, 2007).

Especially volunteering has been theorized to constitute a social role (Penner, 2002). In line with social investment theory, the decisive question may, however, not be whether someone engages in volunteering or not but how much a person invests in this social role. Investing more time in volunteering may thus be associated with specific personality trait changes that align with that role, such as becoming more extraverted through frequent social engagement and more open through repeated exposure to unfamiliar, intellectually stimulating contexts.

In contrast, charitable giving generally involves less psychological role commitment (Bekkers & Wiepking, 2011). Again, simple lifetime prevalence of having ever donated may not be consequential for personality development. Moreover, even individuals who regularly donate money may not necessarily identify with their role as a donor; they may simply view donating as a straightforward use of surplus income or as a way to feel good about themselves and fulfill a perceived moral responsibility. If charitable giving affects personality at all, such effects may operate mainly cognitively: as people reflect on their prosocial actions, they may view themselves as more caring or dutiful, potentially elevating self-reports of agreeableness or conscientiousness with higher amounts donated (for socialization effects of general prosociality on these traits, see Caprara et al., 2012; Luengo Kanacri et al., 2014). However, these dynamics are unlikely to produce profound personality changes in habitual patterns of feelings and behaviors, and we therefore treated socialization effects of charitable giving on personality change exploratorily.

Because role demands of philanthropic activities map more directly onto concrete behavioral tendencies, narrower personality aspects-such as assertiveness, compassion, or openness-may be specifically sensitive to socialization. These aspects can also show distinct developmental trajectories within the same domain (Haehner, Krämer, Schaefer, et al., 2026), implying that different mechanisms may shape different aspects over time. Together, both the specificity of role demands and the heterogeneity of aspect-level development underscore the value of examining socialization effects also at the level of lower-order traits.

Selection and Socialization Processes Across the Lifespan

The effects of both selection and socialization processes for philanthropic behaviors may wax and wane across the lifespan. Lifespan theories highlight age-graded changes in goals, resources, and social roles (Erikson, 1994; Freund & Baltes, 2002). Prosocial motives and values such as generativity, altruism, and self-transcendence tend to become more salient with higher age (Freund & Blanchard-Fields, 2014; McAdams, 2001), and philanthropic behaviors such as volunteering and charitable giving are more prevalent in middle and later adulthood (Best & Freund, 2021; Mayr & Freund, 2020; Shane et al., 2021). Personal resources-such as leisure time, income, or social networks-also change systematically across the lifespan, potentially amplifying or constraining opportunities for philanthropic engagement. Together, such age-graded shifts make it plausible that both selection and socialization processes differ across age.

For personality-based selection effects, there are theoretical arguments supporting either direction of age moderation. When life paths are still relatively open in young adulthood and philanthropic activities are less normative, the effect of personality traits on niche-picking may be amplified, because only individuals strongly predisposed to philanthropy might engage in philanthropic behavior. At the same time, with increasing age-when life structures stabilize and competing role demands decline (e.g., after retirement; Hämäläinen et al., 2024)-individuals also tend to gain more freedom to choose prosocial roles aligned with their personality traits, potentially strengthening selection processes. It is thus unclear whether higher age promotes or reduces the predictive power of personality traits on philanthropic engagement.

Similarly, socialization effects may either weaken or strengthen with age. Philanthropy-related role experiences may exert larger effects on personality earlier in adulthood when traits are more malleable (Bleidorn et al., 2022; Roberts, Walton, et al., 2006). In contrast, as prosocial roles become more normative, identity-defining, and institutionally embedded with age, this could deepen psychological investment and, in turn, increase the potential for role-related personality change (Lodi-Smith & Roberts, 2007; Neyer et al., 2014). Moreover, insofar as selection and socialization processes are conceptually linked (Roberts & Nickel, 2017), age-related conditions that shape one process may plausibly shape the other as well. However, whether age amplifies or attenuates socialization effects remains unclear.

In this study, we addressed limitations of previous research on Big Five and honesty-humility personality traits and philanthropic engagement by examining links between lower-order aspects and real-life philanthropy across 2 years in a representative sample. Procedure and Sample

We used data from the PERCIVAL project, a 2-year longitudinal study conducted in Switzerland and funded by the Swiss National Science Foundation (Grant number 205026). Five assessment waves (W1 to W5) were evenly spread between September 2022 and September 2024.

Data collection was approved by the ethics committee of the Faculty of Arts and Sciences of the University of Zurich and conducted by the professional survey institute FORS (https://forscenter.ch/).

The sample was drawn from the sampling frame for surveys of persons and households of the Swiss Federal Statistical Office. A probability sample (N = 16,052) of adult Swiss residents was invited to take part in the study. The sample was stratified based on gender (female, male), three age groups (18-34 years, 35-64 years, 65+ years), and the seven major Swiss regions (Lake Geneva Region, Espace Mittelland, Northwestern Switzerland, Zurich, Eastern Switzerland, Central Switzerland, Ticino;

Federal Office for Spatial Development, 1999). Participants were invited via email to the subsequent waves.

In the present study, we used data from participants who completed the W1 survey (N = 4,529). To ensure high data quality, we excluded data from n = 54 participants who provided the same response to more than 15 consecutive personality trait items (Yentes & Wilhelm, 2023). The final sample sizes were NW1 = 4,475, NW2 = 2,462, NW3 = 2,555, NW4 = 2,085, and NW5 = 2,360. At W1, participants were on average 50.32 years old (SD = 19.84), 50.55% were female, 40.83% had a university degree, and 83.62% held Swiss nationality. Attrition analyses indicated that participants who dropped out after W1 were more likely male, younger, more neurotic, less agreeable, less open/intellectual, and less often volunteers and donors (p < .01). The effect sizes of these group differences were small, with the biggest effect size being d = 0.22 for agreeableness. Details on attrition analyses can be found in Section 1.1 of the Supplementary Materials.

Measures and Transformations

Personality Traits

Big Five personality domains and aspects were assessed with the Big Five Aspect Scales (BFAS; DeYoung et al., 2007). The BFAS consist of 100 items capturing the Big Five domains with two lower-order aspects each: neuroticism (volatility and withdrawal), agreeableness (compassion and politeness), conscientiousness (industriousness and orderliness), extraversion (enthusiasm and assertiveness), and openness/intellect (intellect and openness). Items were assessed on a 5-point scale from1 = strongly disagree to5 = strongly agree (e.g., "take charge" = assertiveness, or "waste my time" = industriousness reverse coded). The full 100-item BFAS was used at W1 and W2. To reduce participant burden in the following waves, a 40-item short version of the BFAS was used (BFAS-40; Gallagher et al., 2023). German, French, and Italian translations of the BFAS and BFAS-40 have been validated in the PERCIVAL sample (Haehner et al., 2025). Both scale versions showed satisfactory convergence and acceptable psychometric properties in terms of their factorial validity and reliability.

Internal consistencies ranged from w = .83 to .91 for domains and w = .69 to .87 for aspects (long form) and w = .69 to .81 for domains and w = .51 to .75 for aspects (short form) at W1 in this sample.

We calculated mean scores for the Big Five domains and 10 aspects and z-standardized them prior to analysis.

HEXACO honesty-humility was assessed at W2 and W5 with the 10-item honesty-humility subscale of the 60-item version of the HEXACO Personality Inventory (HEXACO-60; Ashton & Lee, 2009; Lee & Ashton, 2004). Items (e.g., "I would never accept a bribe, even if it were very large") were assessed on a 5-point scale from1 = strongly disagree to5 = strongly agree.

In contrast to the analyses with Big Five traits, we did not conduct separate analyses for lower-order facets of honestyhumility (sincerity, fairness, greed-avoidance, modesty). These facets were assessed with only 2 to 3 items and are not recommended for use as mean scores in this short instrument (Ashton & Lee, 2009).

Internal consistency was w = .76 in this sample at W2. We calculated mean scores and z-standardized them prior to analysis.

Volunteering

At W1, participants reported whether they had ever volunteered ("Have you ever volunteered for a good cause, such as by fundraising, social work, or bookkeeping for a nonprofit organization?",0 = no,1 = yes). If participants had ever volunteered, they were asked if they had volunteered in the past 6 months ("Have you volunteered for a good cause, such as by fundraising, social work, or bookkeeping for a nonprofit organization in the past 6 months?",0 = no,1 = yes). In the following waves, participants were asked whether they had volunteered in the past 6 months (i.e., since the last assessment). Participants who volunteered in the past 6 months were asked to indicate the cause(s) they volunteered for (multiple choice; sport/recreation/hobby, welfare/community, health, emergency services, education/training/youth development, religion, environment, business/professional/union, law/justice/politics, arts/culture, foreign/international, other).

At W1 and W2, participants who reported volunteering in the past 6 months indicated how many hours per month they typically volunteered (open numeric entry). We checked these entries, excluded negative values, and harmonized any range or non-numeric entries (e.g., "around 6 to 7 hours" was coded as 6.5 hours). As preregistered, we winsorized these numeric entries to 45 hours to reduce the influence of extreme values. At W3-W5, volunteering hours were assessed using an ordinal scale with 10 categories ("less than 1 hour per month" to "more than 40 hours per month"). For analyses, we assigned midpoints to all categories; for the top category we used 45 hours to be consistent across waves. Numeric and categorical values were then combined to a quasi-continuous measure of monthly volunteering hours in the past 6 months. Because this variable was strongly skewed (skewness = 1.74), we applied log-transformation prior to z-standardization.

Charitable giving

At W1, participants reported whether they had ever donated something of value ("Have you ever donated something of value to you for charities or nonprofit organizations, such as money, food, or clothes?",0 = no,1 = yes). If participants had ever donated, they were asked if they had donated something in the past 6 months ("Have you donated something of value to you for charities or nonprofit organizations in the past 6 months?",0 = no,1 = yes). In the following waves, participants were asked whether they had donated something in the past 6 months (i.e., since the last assessment).

Participants who reported donations in the past six months were asked to indicate the type(s) of donations they made (multiple choice; money, food, clothes, furniture, electrical items, other).

At W1 and W2, participants who reported donating money indicated how much they had donated in the past 6 months (open numeric entry, in CHF). We checked these entries, excluded negative values, and harmonized any range or non-numeric entries (e.g., "maybe 100 or 150 francs" was coded as CHF 125). We winsorized these numeric entries exceeding mean + 3 SD. At W3-W5, the amount of monetary donations was assessed using an ordinal response scale with 11 categories ("CHF 1-100" to "more than CHF 1,000"). We assigned midpoints to all categories; for the top category, we used CHF 1,500 as estimate, reflecting plausible variation above CHF 1,000. Numeric and categorical values were combined to a quasi-continuous measure of monetary donations in the past 6 months. Because the resulting distribution was strongly skewed (skewness = 9.70), we applied log-transformation prior to z-standardization.

Socio-Demographic Variables

Age (in years) was computed based on participants' birth year at W1 in 2022. We grand-mean centered this variable across participants to ease interpretation. Average monthly net income was assessed at W1 in 16 exhaustive income brackets ("Less than CHF 1,000" to "More than CHF 15,000"). At W3 and W5, individuals indicated whether their income had changed in the past 12 months. If their income had changed, they were asked to specify their current income. Each bracket was represented by its midpoint (the top bracket by CHF 15,500) to obtain a quasi-continuous income variable. We averaged across available waves within participants to get a time-invariant income control variable. Because the distribution was strongly skewed (skewness = 1.60), we applied logtransformation prior to z-standardization.

Statistical Analyses

Analyses were conducted in R (version 4.5.2) using the package lme4 (Bates et al., 2015) and its extension lmerTest (Kuznetsova et al., 2017) for main analyses. To reduce the risk of Type I error, we adopted a stringent significance threshold of α = .01. Across analyses, main models included the core predictors and provided results on the confirmatory hypotheses regarding personality domains (H1 to H3, see Table 2).

Extended models additionally included a) age as a moderator and b) income as a control variable for between-person differences in economic resources and provided exploratory tests of age moderation effects (RQ1b, RQ2b, RQ3b). Individuals with no valid income entry only contributed to main but not to extended models. Group comparisons indicated that individuals who reported their income (n = 3,101) were more likely male, showed higher levels of extraversion, conscientiousness, openness/intellect, lower levels of neuroticism, and were more likely to have ever donated money compared to individuals who did not report their income (n = 1,374), with effect sizes of |d| = 0.13-0.26. The sample size and composition thus differed substantially between main and extended models (see Section 1.2 of the Supplementary Materials). We therefore expanded the preregistered analyses by additionally fitting extended models without income as a control variable. Age Moderation Effects

We examined whether age moderated cross-sectional associations, prospective selection, and socialization effects. Full results on age moderation are reported in Sections 2.4.2 (RQ1), 3.4.2 (RQ2), and 4.4.2 (RQ3) of the Supplementary Materials. Overall, only a few age moderation effects were significant; these effects were very small (0.99 ≤ OR ≤ 1.01 and |b| ≤ 0.01) and scattered across main and supplemental analyses. Significant age moderation effects (without controlling for income) mostly emerged for agreeableness and its aspect compassion, specifically for concurrent associations with charitable giving as well as prospective selection into volunteering and amount of money donated. These positive links tended to be slightly stronger with increasing age. Additionally, assertiveness was more strongly related to lifetime volunteering among older compared to younger adults, and the non-significant socialization links between average volunteering hours and change in enthusiasm as well as honestyhumility became increasingly negative with age. Beyond these findings, no consistent age moderation patterns were observed.

Income-Controlled Effects

Finally, we conducted all analyses while additionally controlling for income (see Sections 2, 3, and 4 of the Supplementary Materials). Even though the sample size and sample composition deviated substantially from our main analyses (DNW1 = 1,374; see Section 1.2 of the Supplementary Materials), most of the confirmatory effects remained significant in the models controlling for income. Exceptions were the concurrent link of honesty-humility with volunteering, the prospective selection effects of openness/intellect on volunteering, and the socialization effect on extraversion, which were not significant in this income-controlled model specification.

In contrast, most age moderation effects reported above did not hold once income was controlled. Only the age moderation of the prospective effects of compassion (on volunteering participation and the amount of money donated) and of the socialization effect of volunteering hours on honesty-humility remained significant. Conversely, additional moderation effects emerged specifically in the income-controlled models: the prospective effects of agreeableness and compassion on hours volunteered were stronger at older ages, whereas the prospective effect of politeness on charitable giving was somewhat weaker. Thus, most age moderation effects were not robust.

Discussion

Volunteering and charitable giving constitute core forms of philanthropic engagement with beneficial effects for recipients, donors, and broader societal functioning. This study extends prior research by moving beyond established concurrent links to examine prospective selection and socialization associations between broad and narrow personality traits and philanthropy in five-wave longitudinal data from a nationally representative sample of Switzerland.

There were three major findings in this study. First, extraversion and neuroticism consistently predicted volunteering, whereas agreeableness and honesty-humility emerged as robust predictors of charitable giving. Second, at the lower-order aspect level, meaningful differences emerged within the domains of agreeableness and conscientiousness: compassion and industriousness showed more consistent and positive links with philanthropic behavior than politeness and orderliness. Third, evidence for socialization was more limited, with only one effect: people who spent more time volunteering tended to show more stable extraversion trajectories. Age rarely moderated these associations, suggesting largely similar patterns across the adult lifespan. In the following, we discuss cross-sectional associations before turning to longitudinal evidence of selection and socialization processes and the broader context and implications of this study.

Replication of Cross-Sectional Associations

Overall, we found broad evidence for links between lifetime prevalence of philanthropic behaviors and personality traits at both the domain and aspect level. Both aspects of extraversion were positively associated with lifetime volunteering and charitable giving, suggesting that sociable and agentic people were more likely to have ever volunteered or donated to charity. Agreeableness and compassion were linked to both having volunteered and donated, whereas politeness was only related to lifetime charitable giving. Conscientiousness was also positively associated with lifetime charitable giving, whereas orderliness, unlike industriousness, was negatively associated with lifetime volunteering. Openness/intellect and both its aspects were positively associated with lifetime volunteering and charitable giving. In contrast, neuroticism and both withdrawal and volatility were negatively associated with both philanthropic behaviors. Finally, honesty-humility was positively associated with lifetime volunteering and charitable giving.

Consistent with prior meta-analytic effect sizes for the Big Five (Bleidorn, Stahlmann, Orth, et al., 2025), hypothesized associations of extraversion and openness/intellect with volunteering were very small to small (OR = 1.39-1.45, r ≈ .09-.10 9 ) and the concurrent link between agreeableness and charitable giving was small to medium (OR = 1.73, r ≈ .15). Similarly, we found a very small association between honesty-humility and volunteering (OR = 1.18, r ≈ .05) and a small association between this trait and charitable giving (OR = 1.53, r ≈ .12). These associations were considerably weaker than prior single-study estimates (Marsh et al., 2022; Yelbuz & Thielmann, 2024) as well as meta-analytic evidence from prosocial behavior in the lab (Thielmann et al., 2020; Zettler et al., 2020).

Despite their limited effect size, these associations should not be dismissed as irrelevant: in complex real-life behaviors like volunteering and charitable giving, which are shaped by many factors, effects of this magnitude are theoretically expected and can yield meaningful practical implications when aggregated across many people and opportunities for prosocial action (Funder & Ozer, 2019; Götz et al., 2022; Ozer & Benet-Martínez, 2006). We elaborate on these implications further below.

Whereas earlier research has often emphasized agreeableness and honesty-humility as key correlates of philanthropic activities (Bekkers, 2006; Carlo et al., 2005; Smillie et al., 2019), our findings suggest a broader and more nuanced range of relevant traits that distinguish engaged from non-engaged people. Across both philanthropic behaviors, engaged people were characterized by more adaptive personality trait levels (Bleidorn, Hopwood, Ackerman, et al., 2020; Pletzer et al., 2024). One possible interpretation is that personality traits linked to individual functioning and thriving are associated with greater philanthropic engagement perhaps because they confer personal and social resources that facilitate such behaviors. For example, traits such as extraversion and agreeableness are associated with larger and more active social networks and greater prosocial motivation, which may increase opportunities and willingness to engage (Bekkers, 2006; Okun et al., 2007). Similarly, honesty-humility and openness/intellect may encompass values, such as broadmindedness, universalism, liberalism/non-authoritarianism, or benevolence (Desimoni & Leone, 2014; Dollinger et al., 1996; Fischer & Boer, 2015; Kajonius & Dåderman, 2014). Because these values reflect concern for community welfare beyond people's immediate close social circle, they may foster prosocial and civic engagement (Hilbig & Zettler, 2009; Mondak et al., 2010; Mondak & Halperin, 2008). Prospective Personality Selection Effects on Traditional Philanthropy

The prospective pattern broadly mirrored concurrent findings: higher extraversion, higher openness/intellect, higher honesty-humility, and lower neuroticism emerged as predictors of both later volunteering and charitable giving. These effects suggest that personality differences are not merely correlates of engagement but characterize who enters or maintains philanthropic behaviors over time.

Extraversion robustly predicted later volunteering, also when controlling for income, which likely reflects both motivation and opportunity (Funder, 2016; Rauthmann et al., 2015). Extraverted individuals may perceive and encounter more opportunities to volunteer because they are socially integrated, have greater exposure to community initiatives, and may be more likely influenced by prosocially active peers (Okun et al., 2007). At the same time, extraverted individuals may be more inclined to seek out philanthropic opportunities to fulfill their need for social reward and express agency (DeYoung et al., 2007; Kwon et al., 2023; Omoto et al., 2010). Through repeated socially rewarding experiences, extraverted individuals may then also be more likely to sustain their engagement over time. The less robust effect on charitable giving may reflect that donating is less rewarding for extraverts, as it is often done at a greater spatial and social distance (Kawawaki, 2023).

High openness/intellect may motivate people to engage with unfamiliar and diverse contexts in volunteer work (DeYoung et al., 2007). Notably, this link did not hold once income was controlled, suggesting that openness/intellect's established link to higher income (Alderotti et al., 2023; Vella, 2024) may partly explain this prospective effect. In other words, people higher in openness/intellect may be more likely to take up or continue volunteering because they hold greater socioeconomic resources and thus have more flexibility in investing time in unpaid work. We also found a selection effect of openness/intellect on later charitable giving, potentially reflecting people's higher awareness of societal needs (Bekkers & Wiepking, 2011) or attentiveness to political and social issues (Mondak et al., 2010; Mondak & Halperin, 2008).

Honesty-humility was related to later charitable giving and to a lesser degree volunteering. This is consistent with general expectations that this trait is related to prosocial behavior (Hilbig & Zettler, 2009; Smillie et al., 2019). Individuals low in this trait may be less likely to enter or sustain philanthropic engagement particularly in situations where it conflicts with selfish interests (Columbus et al., 2019; Zettler et al., 2013). It should also be noted that the honesty-humility scale includes items that refer to relative disinterest in personal wealth and material gain. An alternative explanation is thus that there is overlap between the item content of the scale and prosocial outcomes that involve material sacrifice (e.g., Górnik-Durose & Pilch, 2016).

An unexpected finding was the consistent association between neuroticism and philanthropic behavior, although associations with charitable giving were no longer significant when controlling for income. This complements the broader notion that adaptive trait levels facilitate philanthropic engagement, and maladaptive trait levels may, in turn, hinder engagement. Specifically, neurotic people may refrain or withdraw from philanthropic engagement due to lower perceived self-efficacy (Barańczuk, 2021; Bekkers & Wiepking, 2011) or reduced interpersonal trust (Chapman et al., 2021; Evans & Revelle, 2008; Thielmann et al., 2020). Additionally, they may perceive volunteer work as more demanding or stressful, which could discourage them from engaging.

Although these prospective findings largely reinforced the importance of personality traits, they also diverged from the concurrent pattern in theoretically informative ways. Most notably, agreeableness predicted subsequent charitable giving but not volunteering. Although this finding contrasts with earlier theoretical accounts (e.g., Bekkers, 2006; Carlo et al., 2005), it aligns with recent meta-analytic evidence (Bleidorn, Stahlmann, Orth, et al., 2025) and is consistent with the modest associations between volunteering and charitable giving observed in our sample. The divergence between theory and empirical data at the domain-level has also raised the possibility that broad agreeableness may be too heterogeneous to capture the specific motivational processes underlying philanthropic engagement and narrower aspects may diverge in meaningful ways (Bleidorn, Stahlmann, Orth, et al., 2025; White et al., 2017; Yarkoni et al., 2015). Our analyses support this idea as compassion showed stronger and more consistent links to philanthropic engagement than politeness.

Compassion reflects affiliative emotions and empathy, whereas politeness captures more cognitive facets of agreeableness, such as respectfulness and fairness (DeYoung et al., 2007). Affective tendencies may thus play a more important role in motivating philanthropic engagement than more abstract moral or normative considerations. The link between compassion and charitable giving may, for example, reflect that agreeable people seek a "joy of giving" or act out of altruistic feelings when donating money rather than adhering to fairness norms (Bekkers & Wiepking, 2011; Zhao et al., 2017a). This reasoning aligns with research highlighting the role of concepts such as altruism, generosity, or empathy (Andreoni, 2006; Graziano et al., 2007), which resonate more closely with compassion rather than politeness.

A similar pattern emerged for prospective selection effects of conscientiousness aspects.

Orderliness, which partly reflects obligation to rules and norms, was unrelated to later philanthropic behavior, suggesting that moral standards alone may be less relevant to prosocial action. Conversely, positive links between industriousness and volunteering and charitable giving may reflect industrious people's commitment and willingness to follow through on prosocial intentions (Ajzen et al., 2009; Wilmot & Ones, 2019). This contrasts with earlier accounts suggesting that ambition and dutifulness may hinder philanthropic engagement by prioritizing career advancement (Stahlmann et al., 2024).

Our findings on differences between the two conscientiousness aspects suggest a more nuanced pattern, with industriousness promoting sustainment of philanthropy rather than hindering it. These considerations illustrate how integrating personality effects at different levels can help reconcile previously inconclusive findings. More broadly, these findings align with prior research highlighting the predictive validity of narrower personality traits (Jang et al., 2002; Mõttus et al., 2017; Stewart et al., 2022; Sun et al., 2018). Overall, the present findings suggest that understanding selection effects benefits from differentiated personality measures and longitudinal designs. The latter also allow us to disentangle these selection effects from the socialization effect considered next.

Socialization Effects of Volunteering on Personality Trait Trajectories

Consistent with the social investment principle (Roberts et al., 2005; Roberts & Nickel, 2017), we expected that sustained involvement in volunteer work would be linked to personality development through psychologically meaningful experiences. Supporting this idea, socialization analyses indicated that, among engaged volunteers, people who spent more time volunteering on average showed a slightly less negative extraversion trajectory. However, this effect did not hold when controlling for income. This may reflect reduced power in the smaller subsample as the income-adjusted analyses included fewer participants. Alternatively, income may partly account for the association between volunteering and extraversion change, or the inconsistent results may reflect sampling variability. The socialization effect on extraversion should therefore be interpreted cautiously and requires replication.

Nevertheless, there are plausible mechanisms through which more intensive volunteering could contribute to greater stability in extraversion. Highly engaged volunteers may be more likely to take on tasks involving responsibility, coordination, or leadership than people who spend less time volunteering. For these people, volunteerism is more likely to constitute a meaningful, intrinsically motivated social role they identify with rather than a casual activity they pursue to pass their time (Lodi-Smith & Roberts, 2007; Luhmann et al., 2021). Such agentic and committed roles may foster positive affect and a sense of influence, which could, over time, consolidate into extraverted tendencies (Anderson et al., 2012; Ensari et al., 2011). In addition, volunteering may provide sustained opportunities for social interaction, particularly for people who are regularly engaged. Given that social networks tend to shrink across adulthood (Wrzus et al., 2013), frequent volunteering may counteract this reduction in social contact and thereby contribute to more stable extraversion trajectories. At the same time, the reverse direction cannot be ruled out: individuals with more stable trajectories of extraversion may also be more likely to sustain higher levels of volunteering, as continued social motivation and opportunity could support ongoing involvement. Regardless of the direction, the observed pattern may be relevant for psychological well-being, given that both extraversion and sustained social participation have emerged as important correlates of mental health in prior meta-analytic research (Das et al., 2025; Hui et al., 2020; Pletzer et al., 2024).

In contrast, no socialization effect emerged for honesty-humility and the other Big Five traits including openness/intellect, for which we had expected a positive volunteering effect. This null finding may indicate that greater investment in volunteering among those already engaged does not provide sufficient novelty or cognitive stimulation to meaningfully shape this trait. More generally, it adds to prior research suggesting that socialization effects on personality traits tend to be smaller and less consistent than selection effects (e.g., Andrae et al., 2026; Krämer et al., 2026; Nissen et al., 2022).

The specificity of the one observed socialization effect may also be informative when comparing volunteering with charitable giving, for which we neither expected nor observed socialization effects. Although both behaviors are grouped under the umbrella of traditional philanthropy (Bekkers, 2006), volunteering may be more likely to shape personality trajectories because it typically involves more intensive time investment, role obligations, and coordination with others. Charitable giving, in contrast, can often be enacted at greater social and physical distance from recipients and the concrete context of need (Kawawaki, 2023). Thus, even if donating time and money can serve related psychological functions (Andreoni, 2006; Choi & Kim, 2011; Johnson & Park, 2021) and tend to be empirically linked (Hill, 2012; Wiepking & Maas, 2009), they may differ in their potential to provide the sustained social-role experiences through which personality development is expected to occur. However, we did not test this difference directly.

In sum, volunteering and charitable giving may be partially overlapping but psychologically distinct forms of philanthropy. Beyond this distinction between forms of engagement, age-graded changes in resources, opportunities, and role demands may also shape personality-philanthropy transactions. This lifespan perspective guided our final set of analyses.

Selection and Socialization Across the Lifespan

Across analyses, age moderation effects were inconsistent and very small in magnitude. The most consistent pattern emerged for agreeableness and its aspect compassion: Associations with philanthropic engagement tended to increase slightly with age. In particular, prospective selection effects of compassion on subsequent engagement were stronger at older ages, even when controlling for income. A possible interpretation is that dispositional differences in compassion become more consequential for behavioral choices later in life, when competing role demands tend to decline and people have greater flexibility to engage in activities aligned with their traits (Blum et al., 2018).

Alternatively, age-related increases in generativity and prosocial values may amplify the behavioral expression of compassionate dispositions in older adulthood (Fung et al., 2026).

Apart from this pattern, the largely absent and inconsistent age moderation effects suggest that associations between personality traits and philanthropic engagement are relatively stable across the adult lifespan. This pattern might indicate that the mechanisms linking personality traits and philanthropic engagement-such as social motivation, compassion, or value-driven behavior-may operate similarly across different life stages despite changing external constraints. However, the absence of robust moderation should be interpreted cautiously. Given the generally small effect sizes, statistical power to detect even smaller interaction effects may have been limited. Moreover, chronological age may be too coarse to capture meaningful life-stage differences, as more proximal factors such as retirement, health, or time availability may better reflect changes in opportunity structures for engagement (Komp et al., 2012). It is possible that selection into philanthropic activities occurs earlier in life, leaving less room for age-differentiated effects in later adulthood. Given these constraints and the exploratory nature of our analyses, future research should examine more specific life transitions and employ fine-grained longitudinal designs to better understand potential agedependent processes in personality-philanthropy transactions.

Theoretical and Practical Implications

The present findings have several theoretical and practical implications. From a theoretical perspective, this study contributes to a more nuanced understanding of the associations between personality traits and philanthropy. Personality traits primarily emerged as characteristics that concurrently and prospectively predict individual differences in philanthropic engagement and to a lesser degree as personal tendencies that might be shaped through sustained interactions with one's social environment. Similarly, philanthropic activities are not only behavioral endpoints predicted by personality, but also potentially psychologically consequential experiences that can relate to personality development over time. This adds to a broader body of literature emphasizing the transactional relations between personality and social contexts (Neyer et al., 2014; Wrzus et al., 2016), which at the same time suggests that selection processes tend to be more pronounced than socialization processes (e.g., E. Beck, 2019).

Our use of both broad personality domains and narrower aspects speaks to a long-standing tension between breadth and precision in personality science (Paunonen & Ashton, 2001; Wittmann & Süß, 1999). Trait hierarchies address this tension by capturing the major dimensions of individual differences at multiple levels of abstraction, from broad domains to narrower aspects and facets (e.g., DeYoung et al., 2007; Soto & John, 2017). Broad domains provide an abstract lens to describe and explain individual differences (Bainbridge et al., 2022; Reist et al., 2023), whereas narrower aspects and facets within these domains may show aligning or distinctive patterns. In line with prior research (e.g., Stewart et al., 2022; Sun et al., 2018), our aspect-level findings showed that narrower traits can contribute to a more nuanced understanding of philanthropic behavior beyond broad domains alone.

Constructs developed outside the Big Five and HEXACO traditions, such as values, political ideologies, or moral foundations, have also been linked to prosocial behavior (e.g., Hitlin, 2007; Nilsson et al., 2016 Nilsson et al., , 2020;; T.-M. Wang et al., 2024). Meta-analytic associations between constructs like moral identity and moral behaviors (r = .20; Hertz & Krettenauer, 2016), volunteer-related values and frequency of volunteering (r = .17; Zhou & Kodama Muscente, 2023), and social identification and charitable giving (r = .29; Chapman et al., 2025) are often stronger than those observed for personality traits. This raises questions about how to understand these kinds of variables from a personality perspective. Although it has been argued that constructs such as moral foundations represent unique content that is not captured by personality (Feher & Vernon, 2021; Haidt et al., 2009), it is also possible that these associations reflect predictor specificity within a general model of individual differences. Attitudes toward volunteering, for example, are more closely aligned with volunteering behavior than broad patterns of thoughts, feelings, and behaviors, but this does not necessarily mean that such variables cannot be considered a part of personality traits writ large. From a lexical perspective, Big Five and HEXACO dimensions are theorized to comprehensively cover individual differences in non-cognitive, normal range psychological functioning (Ashton & Lee, 2007; Goldberg, 1993; John & Srivastava, 1999). There is indeed reliable evidence that values, moral identity, or political ideology are systematically related to Big Five and HEXACO variables (Fischer & Boer, 2015; Hirsh et al., 2010; Xu et al., 2021), as are constructs designed to extend beyond these frameworks (Lee et al., 2005). While it is not surprising that predictive power improves the more similar the item content of a scale is to the predicted outcome, we would maintain that broad personality frameworks provide a useful framework for understanding the broader network of correlates of philanthropic engagement (Anglim & O'Connor, 2019).

From an applied perspective, our findings could inform efforts to promote philanthropic engagement. Solicitations could be tailored to personality-relevant motivations, for example by emphasizing socially rewarding aspects, highlighting opportunities for learning and novel experiences, or framing appeals in terms of compassion (Bekkers & Wiepking, 2011; Hirsh et al., 2012). At the same time, personality-informed outreach strategies could also be used to broaden participation by designing appeals and opportunities that resonate with individuals less inclined toward volunteering or donating. For example, people lower in extraversion may be more responsive to low-social-intensity forms of volunteering, whereas donation appeals for people higher in neuroticism may benefit from reducing uncertainty, emphasizing clear impact, and providing reassurance about trustworthiness of the organization. Importantly, implementing such targeted approaches both ethically and effectively will require transparency and collaboration with engaged communities to foster agency, trust, and sustainable involvement (Matz et al., 2024).

More broadly, our findings speak to the policy relevance of personality traits (Bleidorn et al., 2019) and align with prior research showing mutual links between prosociality, personality, and individual well-being (Hui et al., 2020; Smillie et al., 2019; Thielmann et al., 2020). This policy relevance should be interpreted cautiously, however, given the small size of the observed effects.

Rather than suggesting that personality traits strongly predict any single person's philanthropic behavior, the findings point to the potential value of broad, sustained, and low-cost approaches that may shift engagement patterns at the population level. Accordingly, interventions that foster wellbeing, prosocial activities, or adaptive personality functioning may be most consequential when evaluated in terms of cumulative population-level impact rather than large individual-level change.

Limitations and Future Directions

This study has several important limitations. First, although the longitudinal design improves on cross-sectional approaches by establishing temporal ordering and allowing us to distinguish withinfrom between-person variation, the observational nature of the data precludes causal conclusions. The findings are consistent with selection and socialization processes, but time-varying within-person confounders cannot be ruled out. For example, changes in health or family responsibilities may simultaneously shape personality development and opportunities for philanthropic engagement. Future research could move closer to causal inference by specifying the broader causal network of these associations more explicitly and, where feasible, combining repeated assessments of theoretically relevant contextual changes with longitudinal causal inference approaches (Chatton & Rohrer, 2024; Loh & Ren, 2023). Complementary quasi-experimental or intervention-based designs, such as programs that facilitate volunteering or encourage charitable giving, would provide further evidence.

Second, the 2-year observation period may have limited our ability to capture long-term personality development. Personality change often unfolds gradually and may be difficult to detect reliably across relatively short intervals (Jackson & Wright, 2024). Relatedly, a previous examination in this sample found comparatively high rank-order stability of personality domains and aspects (Haehner, Krämer, Schaefer, et al., 2026), suggesting that the present window may be too short to detect longer-term personality-philanthropy transactions. At the same time, personality traits can change within several months (Bleidorn, 2012; Wright et al., 2026), and the present 6-month schedule is more sensitive to such short-term change than panel studies with multi-year intervals (Bleidorn, Hopwood, Back, et al., 2020; Luhmann et al., 2014). Future research should therefore examine these processes with longer study durations while maintaining relatively frequent assessments to capture both long-term developmental trajectories and short-term change in personality and philanthropy simultaneously across time (Roemer et al., 2025; Wrzus & Roberts, 2017).

Third, both personality traits and philanthropic behaviors were assessed via self-report. Selfreports of personality traits can be constrained by imperfect self-insight and socially desirable responding (Grimm, 2010; Ziegler et al., 2010), which may have led people to report more adaptive personality levels such as high agreeableness or low neuroticism (Bleidorn, Hopwood, Ackerman, et al., 2020). A multi-method approach additionally integrating, for example, informant ratings or observational data could provide more comprehensive and predictive information on personality in future studies (e.g., Connolly et al., 2007; Mõttus & Henry, 2025; Roberts, Harms, et al., 2006). In contrast, distortion of philanthropic measures through socially desirable responding is probably lower, because items assessing concrete, recent behaviors rely more on direct recall than on abstract selfevaluation and inflating one's responses would require misreporting actual behavior rather than interpreting one's traits favorably. However, self-reported philanthropic behavior is vulnerable to recall error, particularly estimates of volunteering time and donation amounts. In addition, the philanthropy measures were rather coarse. They provide useful indicators of overall charitable giving and volunteering but do not distinguish between various activities, goals, or motives of philanthropy (Ackermann, 2019; A. Farmer et al., 2020; Nilsson et al., 2020).

Fourth and relatedly, associations may partly reflect shared method variance rather than solely substantive links between personality and philanthropic engagement (Podsakoff et al., 2024). General response tendencies, current mood, or the situational context may have jointly distorted responses of both personality and philanthropy variables, thereby inflating associations. However, if such biases were driving results, associations should be inflated fairly uniformly across traits and engagement indicators, yet we observed substantial variability across associations. Moreover, repeated, temporally separated assessments in longitudinal analyses are unlikely to be systematically affected by transient situational influences (Podsakoff et al., 2012). Finally, predictors and outcome variables had little semantic overlap, and recall of concrete behavior should be less susceptible to shared method variance than, for example, self-reported intentions (Baumsteiger & Siegel, 2019) or behavioral motives (Zhou & Kodama Muscente, 2023). Future studies should nonetheless complement self-reports with objective behavioral records, such as register-based donation data (Elinder & Erixson, 2025), which eliminate shared method variance by design and may also help differentiate different philanthropic causes (such as donations to local versus international institutions). Finally, the present data support generalizability to the Swiss context but only to a limited extent beyond it. Levels of philanthropic engagement are relatively high in Switzerland compared to rates in other European countries (Eurostat, 2024) and worldwide (Nakamura, Gibson, et al., 2025; Nakamura, Węziak-Białowolska, et al., 2025). Official Swiss statistics find that 39.2% of the population report having engaged in volunteering in the past 4 weeks (21.3% institutionalized, 26.3% informal; Bundesamt für Statistik, 2021) and that 82% of Swiss households donated money to charitable causes in 2024 (Swissfundraising & Stiftung Zewo, 2025). These figures are broadly comparable to our 6-month prevalences in volunteering (35.7-39.0% vs. a 4-week benchmark) and charitable giving (64.4-74.2% vs. an annual household benchmark) and do not indicate systematic over-reporting. At the same time, high lifetime prevalences, particularly for charitable giving (92%), leave little variance to be explained and may have limited the size of associations. These high levels of engagement potentially reflect context-specific features of Switzerland such as a dense network of civic organizations, high wealth, or a strong humanitarian tradition (Bauer et al., 2013). Such contextspecificities as well as cross-cultural variation in developmental trajectories of personality traits may alter personality-philanthropy links across countries and cultures (Thalmayer et al., 2022; Uskul et al., 2024). Future research should therefore examine associations between personality traits and philanthropy across different cultural contexts.

Conclusion

This study provides a longitudinal perspective on the associations between personality traits and philanthropic engagement. Across concurrent and prospective analyses, higher extraversion and lower neuroticism showed consistent links with volunteering, whereas agreeableness and honestyhumility were robustly associated with charitable giving. At the more fine-grained aspect level, compassion and industriousness emerged as important aspects in prospectively predicting philanthropic behaviors whereas politeness and orderliness were largely unrelated to later philanthropic engagement. Beyond these selection effects, people who spent more time volunteering on average showed less negative extraversion development over time. Although this effect was very small and not robust across analyses, it provides initial evidence that philanthropic engagement may not only reflect personality differences but could also relate to personality change. Overall, these findings suggest that targeted solicitation and outreach strategies could leverage personality-relevant motives to promote volunteering and charitable giving in real-world contexts. At the same time, future research should use more rigorous causal designs and longer-term multi-method assessments to better understand when and how personality and philanthropy shape one another across the lifespan.
