To check Non-Significant P Value Check

What we found

We found 4 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Exact P-Values works

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Checking code requires downloading its file contents. For a paper whose repository is on Dryad, this never succeeds unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (listing the repository’s files does not need one). Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Abstract

Face recognition in autism is well-researched and up to 1/3 of autistic individuals are reported to have severe face recognition difficulties. In comparison, there are few reports on object recognition performance in autism, and the findings are rather inconsistent. Here we report results from a series of object recognition tasks performed by autistic (N = 41) and matched non-autistic participants. Across tasks we varied the demand placed on perceptual differentiation, the structural similarity of the objects, and the salience and value of global shape information (the object's bounding contour) relative to local shape information (details) in the recognition process. Our main hypothesis was that when local shape information was less salient than global shape information, and when both types of information needed to be integrated to support performance, autistic participants would perform less efficiently than non-autistic participants. This hypothesis was not fulfilled as the autistic group performed just as efficiently as the non-autistic group across all tasks. We discuss our findings in the context of previous reports of object recognition performance in autism and argue that former reports of impairments might reflect lexico-semantic rather than perceptual processes.

1 Introduction Autism spectrum disorder (ASD) is a neurodevelopmental condition which is estimated to affect approximately 1% of the population (Zeidan et al., 2022). It is diagnostically defined by two core features: The presence of restricted, repetitive patterns of behavior or interest and persistent challenges in social communication/interaction (Lord et al., 2018). Autism is also a highly heterogenous condition in terms of presentation, support needs and associated characteristics. Difficulties with face recognition, for example, have been reported to exist for 1/3 of autistic individuals and have even been suggested as a potential endophenotype (Minio-Paluello et al., 2020). Similarly, it has been suggested that many autistic individuals have a special perceptual style where they -unlike most non-autistic individuals -weigh local information (details) more than global information (the overall layout of an object or a scene) (Frith, 1989; Mottron et al., 2006). It has even been suggested that difficulties with face recognition in autism may be directly related to such a local processing style because face processing is particularly reliant on global/holistic shape information (Behrmann, Avidan et al., 2006; Behrmann, Thomas et al., 2006). If difficulties with face recognition reflect an altered local/global processing style in autism, it poses the question of whether visual recognition performance with nonface objects may also differ between autistic and non-autistic populations? This is the main question we seek to address with the present work.

Compared with the extensive literature on face recognition (Griffin et al., 2021; Oruc & Iarocci, 2026), the literature on object recognition is sparse. Nevertheless, we were able to identify 24 studies where direct comparisons were made between autistic and non-autistic participants on object recognition tasks (Ameli et al., 1988; Behrmann, Avidan et al., 2006; Blair et al., 2002; Booth & Happé, 2018; Boucher & Lewis, 1992; Braverman et al., 1989; Burnett et al., 2015; Caplette et al., 2016; de Gelder et al., 1991; Dehaqani et al., 2016; Evers et al., 2014; Hauck et al., 1998; Loth et al., 2010; O'Hearn et al., 2014; Peristeri et al., 2023; Purpura et al., 2024; Sapey-Triomphe et al., 2020; Snow et Object recognition in autism 3 al., 2011; Suzanne Scherf et al., 2008; Teunisse & de Gelder, 2003; Trepagnier et al., 2002; Wallace et al., 2008; Weigelt et al., 2013; Wolf et al., 2008) (see table 1 for an overview).

Of these studies, 10 reported reduced visual object recognition performance in the autistic groups, 18 reported no group difference and 4 found evidence of better performance in the autistic than the non-autistic groups. Note that when these figures do not add up to 24 it is because some studies compared performance across several object categories with different findings. As an example, Blair et al. (2002) compared performance across five categories and found superior performance in the autistic group for buildings and leaves but similar performance to the non-autistic group for cats, horses, and motorbikes. Indeed, from inspection of Table 1, it is hard to establish a particular pattern across the autistic samples, age groups, task types etc. that could potentially explain the diversity of findings. We do note, though, that four out of six studies which used degraded pictures of common Object recognition in autism 4 objects found reduced performance for autistic compared to non-autistic participants (Booth & Happé, 2018; Burnett et al., 2015; Dehaqani et al., 2016; Evers et al., 2014). In the study by Loth et al. (2010), reduced performance with degraded objects was only found in a priming condition. The one other study that did not find a difference with degraded stimuli required detection of objects (Sapey-Triomphe et al., 2020) which might be an easier task compared with object naming in terms of the degree of perceptual differentiation required (see also the discussion below).

When stimuli are degraded -for example by presenting them as fragmented forms, with noise added or as silhouettes -information regarding details (local information) typically suffers more than information regarding global shape, i.e. the overall layout of the stimulus (Gerlach & Toft, 2011; Panis & Wagemans, 2009; Torfs et al., 2010). Hence, if global shape information is sufficient for object classification -as it typically is when objects are to be classified at the basic or superordinate level (Laws, 2000; Turnbull & Laws, 2000) -object identity can be determined based on derivation of global shape information despite stimulus degradation. Consequently, if a person is impaired in global shape processing or tends to weigh local shape information more than global shape information when these types of information need to be integrated, that person will be challenged in contexts where stimuli are degraded and need to be identified. This could be the reason why autistic participants are generally found to show reduced performance with degraded objects but not necessarily with non-degraded stimuli.

Even if many autistic individuals may exhibit a local processing strategy, there has been some disagreement concerning how this local processing style should be understood. According to the original version of the Weak Central Coherence account (WCC), autism is associated with a deficit in central coherence/global processing, reflected in a relative inability to integrate pieces of information into coherent wholes, causing a local processing preference (Frith 1989). In contrast, the Enhanced Perceptual Functioning (EPF) account proposed by Mottron et al. (2006) suggests that processing of global shape information is basically intact in autism and that the local processing bias is caused by an actual perceptual superiority for local shape processing. Thus, where global shape processing is assumed to be obligatory for non-autistic individuals, it is assumed to be optional for individuals with autism according to the EPF account. It should be noted, though, that the WCC and the EPF accounts have become more alike given the revision of the WCC which is now also based on the assumption that the local bias can be "overruled" (Happé & Frith, 2006). Consequently, both accounts now conceive of the local processing style associated with autism as a bias/inclination rather than being caused by a breakdown of global shape processing per se. Hence, to the degree that individuals with autism exhibit altered processing of global shape, both the WCC and the EPF accounts deem this to be secondary to the local processing enhancement/bias. That said, there is some evidence suggesting that global shape information may be derived more slowly in autistic than in non-autistic participants (Van der Hallen et al., 2015). The focus of the present work is therefore to examine visual object recognition in tasks where processing of global shape information is particularly important.

Global shape processing is often referred to as something singular even though different tasks assumed to tap "global" processing do not seem to measure the same construct (Milne & Szczerbinski, 2009). Even the "global advantage" often found with Navon's paradigm seems to reflect two independent mechanisms (Gerlach & Poirel, 2020; Schweigkofler et al., 2025). In line with this, global shape information may play different roles at different levels of processing. In the following we will describe one model which is based on such an assumption: The pre-semantic account of categoryeffects (PACE). We will use this account to derive hypotheses regarding how we expect autistic individuals to perform in specific tasks if they utilize global shape information differently than nonautistic individuals at different levels of processing.

The PACE framework was originally developed to explain different kinds of category-specific visual agnosias as well as category-effects in neurologically intact individuals (Gerlach, 2009 (Gerlach, , 2017b)).

Subsequently, it has also been used to explain aspects of developmental prosopagnosia (Gerlach & Object recognition in autism 6

Starrfelt, 2018a) and global-local effects in face and object recognition (Gerlach & Poirel, 2018; Gerlach & Starrfelt, 2018b).

PACE assumes the existence of two stages in visual object recognition: shape configuration and selection, which are held to be differentially affected by the structural similarity among objects and their visual complexity (Gerlach & Marques, 2014). Shape configuration is the binding of visual elements into elaborate shape descriptions corresponding to whole objects or large object parts in which relationships between the parts are specified. Shape configuration should thus be distinguished from low-level grouping processes such as grouping by proximity, collinearity (alignment), color, etc.

While these grouping operations do integrate elements in the visual scene, they require little shape configuration besides the ability to determine for example the orientation of the elements (Gerlach, 2009).

The configured shape representation is a description that -at the stage of selection -is matched with structural representations of whole objects or large object parts stored in visual long-term memory (VLTM). The process of finding a match between the configured representation and VLTM representations is considered as a race among VLTM representations that compete for selection. The VLTM representation that best matches the configured representation will be selected. The match criterion is flexible and also task dependent. If the task requires fine-grained discrimination, as in subordinate classification (e.g., "Is this a bulldog or a bull terrier?"), an elaborate match criterion will be in place. If the task only requires gross perceptual processing, as in superordinate classification (e.g., "Is this a natural object or an artefact?"), a more liberal match criterion will suffice. When the configured representation is matched with VLTM representations according to a given criterion, the object is recognized at a structural (but not yet a semantic) level.

An important assumption in PACE is that shape configuration follows a first pass access to VLTM representations based on global object contour -the object's outer bounding line -which yields initial hypotheses concerning the likely identity of the stimulus (Gerlach & Toft, 2011). These hypotheses are then used in a top-down manner to augment the build-up of a more detailed description of the stimulus (i.e., shape configuration) which again serves as input for a more specific match with VLTM representations (the selection stage). Hence, object recognition may take place without shape configuration, based mainly then on the object's bounding contour or perceptually unconnected details, but the identification process is then likely to be (abnormally) slow and error prone. This type of behavior is seen in integrative agnosia where patients seem to piece together a useful description of the stimulus bit by bit (Behrmann & Kimchi, 2003; Behrmann & Williams, 2007; Gerlach et al., 2005).

Shape configuration is thus an important part of normal visual object processing which operates recurrently until a successful match between the stimulus and VLTM representations has been obtained (following a coarse-to-fine temporal dynamic) (Gerlach, 2017b; Sanocki, 1993; Schyns & Oliva, 1994).

In PACE, fast derivation of global shape information is deemed significant in the recognition process because it: (i) facilitates the matching process proper by narrowing down the scope of likely VLTM candidates (via the "quick and dirty" first pass activation of VLTM representations), and (ii) provides the initial frame in which local details can later be embedded (the process of shape configuration).

Importantly there is evidence suggesting that these aspects of global shape processing are likely to reflect independent mechanisms (Gerlach & Poirel, 2018).

A final aspect to be considered is how shape configuration and selection are differentially affected by the structural similarity of the objects to be recognized. According to PACE, objects belonging to categories with high structural similarity (SS objects) will activate a greater range of structurally related VLTM representations compared with objects belonging to categories which are more structurally distinct (SD objects). The consequence of the greater competition for SS objects is that the matching process (selection stage) for these objects will be slower and more error prone than the matching process for SD objects. In comparison, at the stage of shape configuration SS objects enjoy an advantage. This assumption is based on the following premises: (i) global shape characteristics may be processed earlier on in time than local shape characteristics, providing the initial frame in which local details can later be embedded; (ii) global shape characteristics are more diagnostic of basic level object identity for SS than for SD objects; and (iii) information regarding object identity may augment shape configuration in a top-down manner (for discussion of evidence supporting these premises see Gerlach (2017b)).

As discussed above, autistic individuals: (i) (can) use global shape information when it is most salient, but (ii) seem to have difficulties when global and local information needs to be integrated (Happé & Frith, 2006; Mottron et al., 2006; Van Eylen et al., 2018). In PACE this can be interpreted as a normal first pass access to activation of VLTM representations (a process that is dominated by global shape information as this is the first type of information available), but difficulties with shape configuration because local details are weighted more than global shape when both types of information are available and need to be integrated.

Based on the PACE framework -and the assumption that autistic individuals have a local shape processing bias -we expected the following outcomes across a range of tasks where we manipulated the degree of structural similarity, stimulus characteristics (salience of global/local information), and task demands (degree of perceptual differentiation required): Autistic individuals will show reduced performance with recognition of fragmented objects relative to non-autistic individuals on a difficult object decision task (deciding whether stimuli depict real objects or nonobjects) (Hypothesis 1: H1). This prediction follows from the assumptions that: (i) a difficult task with fragmented objects places particularly high demands on perceptual differentiation, and thus also shape configuration, and (ii) the use of global shape information will support the configuration process. Hence, a local processing bias should thus be disadvantageous in this task. In comparison, autistic individuals will show performance within the non-autistic range on recognition of silhouettes in a difficult object decision task (H2). This prediction follows from the assumptions that: (i) global shape processing per se is not affected in autism, (ii) global shape is more salient than details Object recognition in autism 9 in silhouettes (Wagemans et al., 2008), and (iii) silhouette recognition does not rely on shape configuration (Gerlach et al., 2005; Riddoch & Humphreys, 1987).

Accordingly, a local shape bias should not impact much on task performance with silhouettes. Regarding effects of structural similarity, autistic individuals will show reduced performance for SS objects compared with SD objects relative to non-autistic individuals and this difference will be more pronounced with fragmented stimuli than with regular drawings (H3). In addition to the assumptions above, this supposition is based on the additional assumption that similarity in global shape is typically helpful in the shape configuration process (Gerlach & Toft, 2011). Finally, autistic participants will show reduced performance relative to nonautistic participants for SS objects but not for SD objects in a superordinate classification task (H4).

This prediction is based on the assumption that global shape characteristics are typically processed faster than local shape characteristics, but that performance in the superordinate classification task can be based on both local and global information. A local processing bias should thus be disadvantageous in this task. Hence, these tasks place high demands on perceptual differentiation -including recurrent shape configuration -and is associated with abnormal performance for patients with integrative agnosia (Gerlach et al., 2005). In comparison, the superordinate classification task described below only requires the participants to recognize the overall shape of the object or a detail (e.g., a tail) to categorize the stimulus as natural object. In this way we could manipulate the degree of perceptual differentiation required to solve the task (high demand in the object decision tasks, low demand in the superordinate classification task). 160 pictures were presented in each task: 80 real objects and 80 nonobjects. The regular drawings of real objects were taken from the set by Snodgrass & Vanderwart (1980) and consisted of 40 natural objects and 40 artefacts. These two sets of object drawings were matched with respect to familiarity, visual complexity, and image agreement (Kruskal-Wallis, p >.2).

In the present experiments we used category (natural objects vs artefacts) as a proxy for structural similarity. Natural objects typically belong to categories characterized by high structural similarity and artefacts to categories with low(er) structural similarity. Structural similarity has been operationalized differently by different authors. Hence two different measures of structural similarity were used to assess this aspect of the present stimuli: (i) The degree of contour overlap (CO) among objects (Humphreys et al., 1988), and (ii) the degree of within-item structural diversity (WSD) among objects (Turnbull & Laws, 2000). The measure of CO was generated by: (i) Normalizing all the pictures of objects in the Snodgrass and Vanderwart (1980) corpus for orientation and size, (ii) overlaying each picture on a grid with pictures of every other object from the same category (the categories being animals, birds, body parts, buildings, clothes, crustacea, fruit, furniture, implements, insects, vegetables, and vehicles), and (iii) calculating the average overlap between the pictures on their bounding contour -that is, on their outline shape without consideration of internal details -as a function of the amount of contour in each target picture. The measure of WSD, which is also based on the Snodgrass and Vanderwart corpus, was derived by presenting individuals with the name of an object and asking them to rate the extent to which instances with that name had similar structural representations (on a scale from 1-5;1 = very dissimilar;5 = very similar). The WSD measure can be considered a high-level measure of structural similarity because it is based on memories of objects rather than on the physical properties of objects (drawings) such as the CO measure (Gerlach, 2017a).

According to the CO measure, natural objects were more structurally similar than artefacts (Mann Whitney, p < .001) and they also scored significantly higher on the WSD measure than artefacts (Mann Whitney, p < .001). The CO measure was available for 35 of the natural objects and for 32 of the artefacts. The WSD measure was available for all stimuli.

The 80 nonobjects were selected mainly from the set made by Lloyd-Jones & Humphreys (1997). These nonobjects are drawings of closed figures constructed by exchanging single parts belonging to objects from the same category (see Figure 1).

All stimuli were presented centrally on a white background on a PC monitor and subtended 3-5° of visual angle. The stimuli were displayed until subjects made a response. The interval between response and presentation of the next object was 1 s. RTs were recorded using a serial response box.

Participants were encouraged to respond as fast and as accurately as possible. Prior to each of the tasks the participants performed a practice version of the upcoming task. The stimuli used in these practice tasks were not used in the actual experimental conditions.

2.2.2 The superordinate classification task

In the superordinate classification task, the participants were presented with the same real objects as were presented in the object decision with regular drawings tasks and had to classify them according to whether they were natural or artefactual. The viewing conditions and mode of presentation, including 16 practice trials, were the same as for the object decision tasks. In all tasks the order of the stimuli was randomized.

2.3 Data analysis

2.3.1 Dependent variable

As previous studies have reported that speed-accuracy tradeoffs are often exhibited by autistic participants (they typically prioritize accuracy over RT) (Van der Hallen et al., 2015), we combined RT (median correct) and accuracy for each participant into a single dependent measure by means of the Balanced Integration Score (BIS) (Liesefeld et al., 2015; Liesefeld & Janczyk, 2019). BIS are calculated by standardizing the RT and proportion correct (PC) for each participant and subtracting the standardized RT value (ZRT) from the standardized PC value (ZPC) yielding a BIS for each participant.

Positive BIS indicate performance above the mean of the whole sample (autistic and non-autistic participants) and negative BIS performance below the mean of the whole sample.

2.3.2 Statistical analyses

As per the preregistration the following analyses were performed. Simple group differences were examined by means of unpaired t-tests based on bias corrected accelerated bootstrap analyses [1000 samples] (H1) and an unpaired samples t-test based on Bayesian inference (H2). As H1 was directional, the effect was considered significant if the lower bound of the (two-tailed) bootstrapped 90%CI of the statistical test was positive (BIS are assumed to be higher for non-autistic than for autistic individuals).

Interactions and main effects for H3 were examined by means of a mixed factorial ANOVA with Group (autistic vs non-autistic individuals) as the between-subject factor, and Stimulus Type (regular drawings vs fragmented drawings) and Structural similarity (SS vs SD objects) as within-subject factors.

Because the predictions are directional, effects in the ANOVA will be considered significant if the onetailed p-value is < .05. Effect sizes for the ANOVA were indexed by partial eta squared.

Finally, for H4, interactions and main effects were examined by means of a mixed factorial ANOVA with Group (autistic vs non-autistic) as the between-subject factor, and Structural similarity (SS vs SD objects) as the within-subject factor. Again, because the prediction was directional, the interaction effect in the ANOVA was considered significant if the one-tailed p-value for it was < .05.

As will become apparent below one non-autistic participant (ID = 219) was an extreme outlier on all object recognition tasks (including the superordinate classification tasks). This was due to abnormally long RTs with accuracy within the normal range. It was not the case, however, that the person was impaired on all tasks requiring visual processing. The person performed quite well (within Object recognition in autism 16 normal range RT) in an embedded figure tasks and in Navon's paradigm. Hence, the person cannot be excluded on grounds of being inattentive or showing poor compliance. It is more likely that this person may suffer from a visual object recognition disorder; a possibility we cannot examine further.

A three-way mixed factorial ANOVA was performed with the between-subject factor Group (autistic vs. non-autistic participants), and Stimulus Type (regular drawings vs. fragmented forms) and Structural similarity (SS vs SD objects) as within-subject factors. The two-way interaction, which was the main target of this analysis, was not significant (F(1,80) = .1, p = .37 one-tailed). 4 Discussion It has been proposed that autistic individuals exhibit an altered visual perceptual processing style in that they weigh local shape information more than global shape information (the overall layout of a scene or an object) when they process visual stimuli (Happé & Frith, 2006; Mottron et al., 2006).

This altered processing style has also been linked to impaired face recognition (Behrmann, Avidan et al., 2006; Behrmann, Thomas et al., 2006) which is often observed in autistic individuals (Griffin et al., 2021; Kamensek et al., 2023; Minio-Paluello et al., 2020). Comparatively fewer studies have examined whether object recognition is also affected in autistic individuals -which has been considered likely (Behrmann, Thomas et al., 2006) -and the findings from these studies seem rather inconsistent as discussed in the Introduction.

In the present study we thus examined visual object recognition in autism in detail by examining performance across three quite demanding visual object recognition tasks, that differed in whether the stimuli presented were regular drawings, silhouettes or fragmented forms. In addition, we also examined effects of perceptual differentiation and the structural similarity of the objects to be recognized. Based on the PACE model of visual object processing (Gerlach, 2009 (Gerlach, , 2017b) ) we derived four predictions regarding how autistic individuals -provided that they have a local shape processing bias -should perform relative to non-autistic individuals across a range of tasks where we manipulated degree of structural similarity, stimulus characteristics (salience of global/local information), and task demands (degree of perceptual differentiation required).

Our main predictions regarding visual object recognition were that autistic individuals would perform like nonautistic individuals when local shape information is less salient than global shape information and these types of information need not be integrated to any great degree (recognition of silhouettes) [H2], but less efficiently when both types of information are available but global shape information is more important and the demand on shape configuration (the binding of visual elements into elaborate shape descriptions) increases (processing of fragmented forms) [H1/H3]. Finally, we predicted that structurally similar objects would be less efficiently processed by autistic individuals [H3/H4].

The results are easily summarized. Our second hypothesis, regarding processing of silhouettes, found support. This suggests that participants in our autism sample can and do process the global shape of objects when this is salient and use of details is limited. This finding is also what should be expected based on the WCC and EPF accounts. More surprisingly, the autistic individuals also performed in the range of the non-autistic participants on all other tasks, that is, regardless of whether: (i) the stimuli were fragmented or not, (ii) the demand placed on shape configuration was high or low, or (iii) whether the stimuli were structurally similar or not.

Accordingly, H1, H3, and H4 were not supported. These findings, however, can also be accounted for by both the WCC and the EPF. On these accounts, problems with global shape processing should only arise for autistic individuals with a local processing style and maybe such individuals were underrepresented in the present sample. While we cannot dismiss this possibility, our findings suggest that impaired processing of global shape and/or impaired integration of local and global shape information in the context of visual object recognition is not a general characteristic of individuals with autism.

The present findings add to the variability reported in previous studies of visual object recognition in autism (see table 1). Of the 10 studies that reported impaired processing of objects in autism, six examined adult populations of autistic individuals with normal to high intellectual functioning (Ameli et al., 1988; Behrmann, Avidan et al., 2006; Burnett et al., 2015; Loth et al., 2010; O'Hearn et al., 2014; Peristeri et al., 2023) like we did. Hence, differences in age and IQ are not likely explanations for the difference in findings. The same goes for stimulus degradation. Four of the studies reporting reduced performance in autism used degraded stimulus material (Booth & Happé, 2018; Burnett et al., 2015; Dehaqani et al., 2016; Evers et al., 2014). But again, so did we in two of the conditions without seeing any evidence of impairment in the autistic group. This leaves us with two explanatory possibilities: (i) differences in gender, and (ii) differences in the type of task used.

Regarding option 1, our sample is special in that it comprises a majority of female participants (73%).

In comparison, most other studies are based on male participants only or a majority of males (see table 1). However, as we are unaware of any systematic gender differences in visual object recognition -as revealed by for example meta-analytical studies -option 1 seems an unlikely explanation. This leaves us with differences in task type. Six out of the 10 studies that found impaired object processing in autism used object naming tasks (Booth & Happé, 2018; Burnett et al., 2015; Dehaqani et al., 2016; Evers et al., 2014; Loth et al., 2010; Peristeri et al., 2023). In comparison we used object decision tasks, which do not require lexico-semantic processing (Gerlach, 2009 (Gerlach, , 2017b)), and a superordinate classification task that does require access to lexico-semantic knowledge but does not require much lexicon-semantic differentiation as object individuation is not required (Gerlach et al., 2000). This raises the possibility that the reduced performance for autistic individuals on object naming tasks might not necessarily reflect a perceptual but rather a lexico-semantic processing difference between the groups. This would be interesting to examine more directly in future studies. It should be noted, however, that not all studies using object naming tasks have found behavioral differences (Caplette et al., 2016; Purpura et al., 2024) so it is unlikely to be the sole explanation for the inconsistency.

In summary, the present study found no evidence for a behavioral difference in visual object recognition between autistic and non-autistic participants despite using quite demanding tasks.

Examination of previous studies suggests that lower performance for visual object processing in autism is most pronounced on object naming tasks (using degraded stimuli). This could imply that the difference observed is more lexico-semantic than perceptual in nature, but the picture is far from clear.

A potential limitation of the present study -which also applies to other studies examining visual object recognition in autism -is that the sample was not selected to only include individuals with a local processing style. It just may be that it is only such individuals who would exhibit impaired performance in tasks that critically depend on processing of global shape information.
