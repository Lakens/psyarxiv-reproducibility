This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. This package was validated by the Metacheck team on articles in Psychological Science.

How Preregistration Check works

Retrieve information from preregistrations in a standardised way, and make them easier to check.

The Preregistration Check module identifies preregistrations on the OSF and AsPredicted based on links in the manuscript, retrieves the preregistration text, and organizes the information into a template. The module retrieves text from the OSF with its API, and from AsPredicted with ResearchBox’s API when a ResearchBox key is set (see rbox_token()), or else from the preregistration’s web page. How StatCheck works

Check consistency of p-values and test statistics

The Statcheck module runs Statcheck. Statcheck searches for regular expressions that match a predefined pattern, and identifies APA reported statistical tests. More information on the package can be found at https://github.com/cran/statcheck. The module only returns Statcheck results for t-tests and F-tests, as these are the only tests which have been validated, see https://osf.io/preprints/psyarxiv/tcxaj_v1/.

Statcheck was developed by Michèle Nuijten and Sascha Epskamp.

Statcheck might miss one-sided tests, and falsely assume the p-value is incorrect. For more information, see StatCheck.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

This module was developed by Lisa DeBruine and Daniel Lakens

Read more in the metacheck manual.

Validation: In a sample of 225 papers containing 405 instances of non-exact p-values, the module correctly detected 269 cases (true positives) and incorrectly identified 78 (false positives). It missed 136 instances of imprecisely reported p-values (false negatives) and correctly identified 4557 cases of precisely reported p-values (true negative). How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Increasing linguistic diversity in society means that many children acquire the majority language as an additional language. An important aspect of early language development is phonological processing, yet the factors underlying individual differences in monolingual and multilingual children in these abilities remain poorly understood.

To investigate these individual differences, the present study examined nonword repetition (NWR) performance in 793 children, including monolingual (n = 637) and multilingual (n = 156, 18 L1s) preschoolers (3-6 years) in Germany. We used mixed-effects models to investigate the role of lexical linguistic distance to German, German exposure, receptive vocabulary, and morphological skills on NWR while controlling for child age, sex, cognitive ability, and parental education, with preschool as random intercepts Results showed an association of receptive vocabulary with NWR performance only. These findings suggest that NWR performance in preschool children may be relatively independent of individual differences in linguistic background and exposure, while being moderately associated with lexical development.

1. Introduction

In the context of a rise in global migration and the increase of linguistic diversity in societies, children as well as adults are faced with the need and challenge of learning a new or additional language. For instance, in Germany, the proportion of population with an immigration background in 2025 was 31.1% (Statistisches Bundesamt (Destatis), 2026), and 42,7% were children under five in (Statistisches Bundesamt (Destatis), 2026). And in North Rhine-Westphalia, in the 2025/26 school year, 47.7% of primary school children had a migration background (Landesbetrieb IT.NRW, 2026).

Language skills are crucial for social integration, shaping immigrant children's peer acceptance, vulnerability to victimization in preschool (Von Grünigen et al., 2010), and educational upward mobility (Seuring & Will, 2022). Especially, the preschool period has been highlighted as critically important for language development, early literacy (Gillon, 2018; Turesky et al., 2025; Wagner et al., 2007), and school readiness (Snow, 2008). Upon entering school, children are expected to have already developed solid lexical and morpho-syntactic skills, enabling them to comprehend the majority language and articulate thoughts effectively.

The acquisition of a language starts with the formation of phonological skills at three different levels: phonological awareness, phonological recording in lexical access, and the phonetic recoding in working memory, allowing one to perceive and articulate sound sequences in words (e.g., Gillon, 2018; Wagner & Torgesen, 1987). In connection with early literacy, especially the ability to recode phonetic information in the working memory was largely investigated, which described the retrieving of phonological information from long-term memory and recoding written symbols into a sound-based representation system to maintain them efficiently in working memory (Wagner & Torgesen, 1987).

To assess phonological skills in the context of bi-and multilingualism, nonword repetition (NWR) tasks are commonly used. During the task, individuals are asked to listen and repeat socalled nonwords -speech sequences that follow the phonological rules of real words of the tested language (e.g., Coady & Evans, 2008) involving processes such as phonological assembly, motor skills, articulation, verbal short-term memory, and the activation of long-term memory representations (Archibald & Gathercole, 2006; Coady & Evans, 2008; Farabolini et al., 2021; Meir, 2017; Pigdon et al., 2020). NWRs are described as highly efficient because they are not stored in long-term memory (Meir, 2017), and are therefore less influenced by language knowledge (e.g., Chiat, 2015). NWR tasks were used to assess learners' phonetic memory in the second or foreign language (Chiat, 2015; Dos Santos & Ferré, 2018; Thordardottir & Brandeker, 2013) and in cross-linguistic research on typically developing children (Engel de Abreu, 2011; Gorman & Lee, 2013; Lee et al., 2013; Messer et al., 2010; Thordardottir & Brandeker, 2013).

These studies show mixed results regarding individual differences and the factors influencing NWR performance. Except for a few studies (Core et al., 2017; Farabolini et al., 2021 Farabolini et al., , 2022;; Thordardottir & Brandeker, 2013), language exposure was found to influence NWR performance (Farabolini et al., 2022 (Farabolini et al., , 2023)). Mixed results have been reported regarding the effects of socioeconomic status (Farabolini et al., 2022). Likewise, the effect of L1 or bilingualism on NWR in L2 is still debated, and while some studies reported no significant differences in NWR performance between monolingual and bilingual children (Core et al., 2017; Dos Santos & Ferré, 2018; Lee et al., 2013; Thordardottir & Brandeker, 2013), others have identified a bilingual disadvantage (Engel de Abreu, 2011; Messer et al., 2010) and still others suggested a bilingual advantage (Gibson et al., 2015; Krivickaitė-Leišienė & Dabašinskienė, 2022). Additionally, phonological transfer effects show that children can repeat more accurately nonwords containing sounds frequently occurring in their language, compared to those with infrequent sounds (Core et al., 2017; Sharp & Gathercole, 2013), and that L1 transfer can influence syllable structure processing in L2 (Duncan & Paradis, 2016).

Even if the ability to repeat non-words is not directly influenced by general language knowledge, they show a reciprocal association (Farabolini et al., 2022). For instance, lexical acquisition processes and lexical knowledge can influence NWR performance (e.g. Armon-Lotem et al., 2015). In turn, the ability to perceive and reproduce nonwords has been found to play a crucial role in the development of letter knowledge (De Jong & Olson, 2004), vocabulary growth (Lonigan et al., 2009), and early literacy (s. review Melby-Lervåg et al., 2012; Verhoeven & Perfetti, 2022). However, the extent to which vocabulary and general language knowledge interact with NWR skills and explain individual differences remains largely unquantified in the reviewed studies.

In sum, findings remain inconsistent, and most studies, particularly those including both monoand multilingual children, rely on relatively small samples (up to 105 children; see review Farabolini et al., 2022). The present study contributes by examining the effects of language exposure, L1, receptive vocabulary, and expressive morphological skills in explaining individual differences in a larger sample by addressing the question to what extent these variables can explain individual differences in NWR performance among monolingual and multilingual preschool children.

Based on this research question, four hypotheses were formulated: H1: Children whose home language is more closely related to the majority language, German, will demonstrate higher NWR performance.

H2: Greater exposure to German will be associated with higher NWR performance.

H3: Higher receptive vocabulary skills will be associated with higher NWR performance.

H4: Higher expressive morphological skills will be associated with higher NWR performance.

The associations were further examined while controlling for children's age at assessment, sex, cognitive abilities, and parental education.

2. Methods

>Methods

2.1 Participants and database

The present study analyzed cross-sectional data from 793 preschool children, comprising 637 monolingual German speakers and 156 multilingual children representing 18 different first languages (Appendix 1). Multilingual children were defined as those who spoke one or more languages other than German at home.

Participants ranged in age from 3 to 6 years, with balanced sex representation, and were recruited from 92 daycare centers. Informed parental consent was obtained for all participants.

The data were drawn from the SEIKA database, a longitudinal study conducted within the SEIKA-NRW project, which aimed to examine language development among primary school children in North Rhine-Westphalia (Bihler et al., 2021). The broader data collection specifically focused on identifying factors that positively influence language development. For the current investigation, only participants with complete data on all dependent and independent variables were included.

2.2 Instruments

Cognitive abilities were tested with the Hannover-Wechsler Intelligence Test for Preschool Age-III (Fritz-Stratmann et al., 2007). This nonverbal figure analogy assessment serves as an indicator of cognitive development and is particularly suitable for children with limited knowledge of German.

Phonological skills were assessed using the Phonologisches Arbeitsgedächtnis für Nichtwörter

(PGN; Phonological Working Memory for Nonwords), a subtest of the Sprachentwicklungstest für drei-bis fünfjährige Kinder (SETK 3-5; Grimm, 2001). The nonwords were specifically constructed for the test with varying degrees of wordlikeness and difficulty (Grimm, 2001). The test comprises 13 items with two-to four-syllable nonwords for children under 3 years of age.

For children aged 4 to 5 years, five additional items consisting of five-syllable nonwords are included, bringing the total to 18. The NWR performance was evaluated using item-level scoring.

Expressive morphological abilities were assessed using the Morphologische Regelbildung (Morphological Rule Formation) subtest of the Sprachentwicklungstest für drei-bis fünfjährige Kinder (SETK 3-5; Grimm, 2001).

Receptive vocabulary was assessed using the Peabody Picture Vocabulary Test -Fourth Edition (Dunn & Dunn, 2007) in its standardized German adaptation (Lenhard et al., 2015). The PPVT-4 is a norm-referenced test in which the examiner says a word and the child selects the matching picture from four options.

Child sociodemographic factors, including age in months, sex, and parental education, were included as control variables. Parental education was coded according to the International Standard Classification of Education (UNESCO Institute for Statistics, 2011), using the highest completed educational level of either parent, irrespective of the country in which the qualification was obtained.

Language exposure was included as an additional predictor variable. It was operationalized as the number of months children had been enrolled in preschool and thus exposed to German in an educational setting. This variable was calculated by subtracting the age at preschool entry from the child's age at the time of data collection.

Linguistic distance (LD) was measured to facilitate a more accurate comparison of the effects of L1 on L2 across languages and to better understand their relationships. LD measures provide continuous, nuanced data, allowing the comparison of multiple languages. Research applying various LD measures shows a robust effect of language similarity and differences on learning outcomes in adults (e.g., Chai & Bao, 2023) and adolescents (e.g., Jaekel et al., 2023). The effect of LD on language comprehension and production was found in children aged 3-80 months (Sussman et al., 2023), and on expressive and receptive vocabulary in 24-month-old toddlers (Floccia et al., 2018).

One widely used approach to measure the phono-lexical distance between languages is the Automated Similarity Judgement Program (ASJP; Wichmann et al., 2025). The ASJP method computes distances between languages based on standardized lexical comparisons across a core vocabulary list. The software first computes the normalized Levenshtein distance (Levenshtein, 1966) i.e., the number of changes, including deletions, insertions, or substitutions, necessary to change the phonetic representation of a specific target word from one language to another. The ASJP LD score is based on a 40-word Swadesh list, containing everyday words that have been shown to be universally important across languages and culturally independent (Swadesh, 1952).

Even though the LD is based on a limited number of lexical items, previous research shows that this measure successfully predicts language learning outcomes and is often used in linguistic and educational research (Chai & Ma, 2022; Jaekel et al., 2024; Vogel & Stang-Rabrig, 2025).

In the current study, the ASJP (Wichmann et al., 2025) LD measure was used to assess the influence of children's L1 on German as the target language. For each child in the sample, an LD score was derived representing the distance between German and the child's home language.

Higher values indicate greater dissimilarity from German. Appendix 1 provides an overview of the LD values for all languages represented in the dataset, as well as the number of children speaking the respective home languages.

2.3 Analysis

All analyses were conducted in R (version 4.3.3; R Core Team, 2024; Posit Team, 2024), and the code is provided in the supplementary materials (https://osf.io/havmn/overview?view_only=6a913896e87a46649f5b662f4c2d2c84). For all three linguistic tests (NWR, receptive vocabulary, and expressive morphology), agestandardized T-scores were extracted from the SEIKA-NRW database. These scores were derived from the age-specific normative tables provided in the respective test manuals (Grimm, 2001; Lenhard et al., 2015). T-scores have a mean of 50 and a standard deviation of 10, allowing children's performance to be interpreted relative to age-specific reference groups.

The cognitive ability age-normed standard scores from the figure analogy test were converted into IQ-scaled standardized scores based on the sample mean of 5.97 and standard deviation of 4.29.

First, descriptive statistics (means, standard deviations, and ranges) were computed for continuous study variables, and frequencies and percentages for categorical variables.

Differences between monolingual and multilingual children were examined using Welch's t-tests for continuous variables, the Wilcoxon rank-sum test for parental education (ISCED), and the chi-square test for sex.

The main analysis was conducted using linear mixed-effects models to account for the hierarchical structure of the data, as children were clustered within preschools (random intercept). Model building followed a theoretically motivated approach. Models 1-4 examined the individual associations of lexical LD, German exposure, receptive vocabulary, and expressive morphology with NWR performance, respectively. Additional models were estimated for each predictor, controlling for age, sex, parental education, and cognitive abilities. Model 5 included all four predictors and the control variables. Model 5 included all four predictors and the control variables (age, sex, cognitive abilities, and parental education). A sensitivity analysis was conducted in Model 6 by excluding LD from the full model. Marginal and conditional R² values were calculated to quantify the variance explained by fixed effects alone and by fixed and random effects combined, respectively. Fixed-effect estimates, standard errors, and p-values were extracted and summarized for interpretation.

3. Results

Descriptive statistics for the monolingual German and multilingual groups are presented in Table 1. Multilingual children were slightly older on average (M = 46.22 months, SD = 6.78) than monolingual children (M = 43.51 months, SD = 4.87), with a statistically significant difference (t = -4.70, p < .001). Parental education levels (ISCED) were significantly higher in the monolingual group (M = 4.50, SD = 1.87) than in the multilingual group (M = 3.62, SD = 2.08; W = 38,292, p < .001). Cognitive ability scores were comparable across groups (monolinguals: M = 109.47, SD = 10.91; multilinguals: M = 106.54, SD = 10.99), although the difference was statistically significant (t = 2.99, p = .003). LD showed substantial variation in the multilingual group (M = 96.21, SD = 7.44).

For the outcome measures, monolingual children showed slightly and significantly higher mean scores in NWR (M = 43.62, SD = 17.92) than multilingual children (M = 40.99, SD = 14.01; t = 1.98, p = .049). More pronounced group differences were observed for receptive vocabulary (monolinguals: M = 47.28, SD = 9.46; multilinguals: M = 34.17, SD = 7.76; t = 18.07, p < .001) and expressive morphology (monolinguals: M = 47.95, SD = 12.33; multilinguals: M = 27.54, SD = 15.30; t = 15.48, p < .001). The mixed-effects regression results for testing the four hypotheses are presented in Table 2.

Including the control variables in the individual Models 1-4 did not substantially change the estimated associations.

Hypothesis 1 predicted that children whose home language was more closely related to German would demonstrate higher NWR performance. This hypothesis was not supported. The phonolexical LD (B = -0.03) was not associated with NWR performance in Model 1.

Hypothesis 2 predicted that greater exposure to German would be associated with higher NWR performance. This hypothesis was also not supported, as German exposure (B = 0.09) was not associated with NWR performance in Model 2.

Hypothesis 3 predicted that higher receptive vocabulary scores would be associated with higher NWR performance. This hypothesis was supported. Receptive vocabulary was positively associated with NWR performance in Model 3 (B = 0.47, SE = 0.06, p < .001). The model explained 8.3% of the variance with fixed effects (R²m = .083) and 10.5% when random effects were included (R²c = .105).

Hypothesis 4 predicted that higher expressive morphological skills would be associated with higher NWR performance. Expressive morphology showed a positive association with NWR performance in Model 4 (B = 0.22, SE = 0.04, p < .001). The model explained 3.6% of the variance with fixed effects (R²m = .036) and 6.0% when random effects were included (R²c = .060), supporting hypothesis 4.

Finally, the full Model 5 included all four predictors and the control variables (age, sex, cognitive abilities, and parental education). Here, LD has a small but positive association with NWR performance (B = 0.05, SE = 0.02, p < .01). German exposure remained unrelated to NWR performance. Receptive vocabulary remained positively associated with NWR performance, whereas expressive morphology was no longer associated with NWR performance. The full model explained 10.1% of the variance with fixed effects (R²m = .101) and 12.6% when random effects were included (R²c = .126). The positive association between LD and NWR performance in Model 5 was unexpected, as higher LD was hypothesized to be associated with lower NWR performance. This finding may indicate a suppression effect, potentially due to multicollinearity, whereby a negative correlation between LD and receptive vocabulary (Appendix 2) may have affected the estimated coefficients (MacKinnon et al., 2000). Accordingly, a sensitivity analysis was conducted by excluding LD from the full model (Model 6). This analysis examined whether including LD affected the estimated associations between the remaining predictors and NWR performance. The results remained largely unchanged, with receptive vocabulary retaining its positive association with NWR performance (B = 0.47 in Model 5; B = 0.42 in Model 6), while expressive morphology remained unassociated (B = 0.05 in Model 5; B = 0.00 in Model 6).

To further investigate the unexpected positive association between LD and NWR performance in Model 5, a post hoc analysis was conducted to examine whether associations with LD differed across NWR, receptive vocabulary and expressive morphology. Figure 1 illustrates model-based predicted scores for the three outcomes across levels of LD. At LD = 0, corresponding to monolingual German children, predicted scores were relatively similar across outcomes. As LD increased, however, the slopes diverged: receptive vocabulary and expressive morphology showed negative gradients, whereas NWR remained relatively stable.

4. Discussion

The present study investigated individual differences in NWR performance in monolingual German-speaking and multilingual preschool children in Germany. Overall, the findings suggest that LD and German language exposure did not show the hypothesized associations with NWR performance, while receptive vocabulary and expressive morphology were positively associated with NWR performance. However, only receptive vocabulary retained its positive association in the full model, suggesting that lexical knowledge plays a particularly important and independent role in individual differences in NWR performance during the preschool period when other factors are controlled for.

Overall, the descriptive findings indicated small group differences in NWR performance between monolingual German-speaking and multilingual preschool children, which is in line with some previous findings (Core et al., 2017; Dos Santos & Ferré, 2018; Engel de Abreu, 2011; Lee et al., 2013; Meir & Armon-Lotem, 2017; Thordardottir & Brandeker, 2013). Likewise, although on average cognitive ability scores were higher in the monolingual than the multilingual group, this individual difference variable was not associated with NWR performance. In contrast, substantial group differences in receptive vocabulary and expressive morphology were found, which were associated with NWR.

Effects of Linguistic Distance

The mixed-effects analyses did not support Hypothesis 1, as LD did not show the hypothesized negative association with NWR performance. By operationalizing language background through LD using the ASJP measure (Wichmann et al., 2025). It is important to interpret the absence of the LD effect precisely. In the current study, LD captures overall phono-lexical similarity between languages but does not account for phonological complexity or structural differences between individual L1s and German phonological inventories. Additionally, the results indicate that while LD does not affect NWR, it is associated with receptive vocabulary and expressive morphology, suggesting that the linguistic background has differential effects on specific language skills, providing further context for the unexpected positive LD association in the full model.

Effect of Exposure

Likewise, exposure was not a significant predictor of NWR, which is in line with some previous findings (e.g., Engel et al., 2008; Meir & Armon-Lotem, 2017). In contrast, a comprehensive review showed that in most studies, language exposure was positively associated with better NWR performance, while also highlighting substantial variation in the operationalization of exposure measures and in scoring procedures across studies, limiting direct comparability of findings (Farabolini et al., 2022 (Farabolini et al., , 2023)).

In the current study, exposure was measured by the time the children had spent in preschool, which does not capture qualitative aspects of input, such as the intensity or quality of German use during the day, nor does it include information about additional exposure to German outside preschool. Consequently, the exposure variable does not fully reflect children's actual linguistic experience and may therefore have had limited validity and sensitivity in capturing the effect of language exposure on NWR performance.

Effect of receptive vocabulary and expressive morphology

In line with the third and fourth hypotheses, both receptive vocabulary and expressive morphology were positively associated with NWR performance in the univariate models. This relationship is theoretically plausible, as a richer lexical inventory may support the formation and retention of phonological representations, thereby facilitating the repetition of novel sequences (Chiat, 2015; Gathercole, 2006; Lonigan et al., 2009).

In the full model (Model 5), receptive vocabulary remained positively associated with NWR, whereas expressive morphology was no longer associated, potentially reflecting shared variance between these language skills. The unexpected positive LD association may similarly reflect changes in the estimated relationships after controlling for other predictors, rather than an advantage of greater linguistic distance. Receptive vocabulary retained its positive association in the sensitivity analysis excluding LD, supporting the consistency of this finding. Nevertheless, the full model explained only a modest proportion of variance in NWR performance (R²m = .101; R²c = .126), leaving most individual differences unexplained by the variables examined.

Beyond the associations examined in the present study, the findings also raise the question of the extent to which NWR depends on existing language knowledge, particularly as the present task included nonwords with varying degrees of wordlikeness (Grimm, 2001). Although NWR is considered less dependent on language knowledge because nonwords are not stored in long-term memory (Chiat, 2015; Meir, 2017)repetition draws on existing phonological and lexical representations (Archibald & Gathercole, 2006; Coady & Evans, 2008). Previous research has shown that lexical knowledge can influence NWR performance (Armon-Lotem et al., 2015) and that children repeat nonwords more accurately when they contain sounds frequently occurring in their language (Core et al., 2017; Sharp & Gathercole, 2013). The positive association between receptive vocabulary and NWR in the present study is consistent with these findings, suggesting that NWR performance, despite relatively small differences between monolingual and multilingual children, is not entirely independent of language-specific knowledge.

5. Conclusion

The present study shows that multilingual preschool children performed comparatively similarly to monolingual German-speaking children on NWR tasks despite substantially lower receptive vocabulary and expressive morphological skills. In addition, lexical LD, German exposure, age, sex, and parental education showed no consistent association with NWR performance, whereas receptive vocabulary emerged as the strongest predictor of NWR. Together, these findings suggest that phonological working memory, as assessed through NWR, may reflect cognitivephonological processing abilities that are comparatively less sensitive to multilingual language background and environmental factors during the preschool period than lexical and morphological language skills. At the same time, the modest explanatory power of the full model indicates that substantial variability in NWR performance remained unexplained. Future research should therefore further investigate the contribution of specific phonological characteristics of individual languages, qualitative aspects of language exposure, and additional cognitive mechanisms underlying phonological processing in multilingual children.
