How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Checking code requires downloading its file contents. Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

We conduct experimental economic games designed to study how reputational concern influences people's economic decisions. Donors make a series of "Dictator Game" decisions, splitting an endowment between themselves and a recipient. Crucially, recipients are not anonymous strangers, but are other individuals from the same community as the donor, presented to donors via photographs. By varying the identity of the recipient and whether or not the recipient will come to know the identity of the donor, we can effectively vary the reputational stake of the donor's decision. We expect that when Dictator Game allocation decisions have greater reputational stakes, donors will be more generous. Greater reputational stakes could arise from: the revelation of the donor's identity, the social proximity of donor and recipient, and the general network position of donor and recipient, all of which we consider. We conduct these games in eight rural communities in five countries, where we already have full sociodemographic and social network data on players and their connections. While there is substantial cross-site variation in the amounts given, we find strikingly similar effects of revelation and social proximity on allocation decisions: in all sites, donors give only slightly more in contexts where their identity is revealed, as opposed to being kept anonymous. Whether anonymous or revealed, donors give appreciably less to recipients who are more socially distant, with the largest drop occurring between immediate connections and connections-of-connections. We find mixed evidence that the effect of revealing a donor's identity diminishes with social distance. Finally, we do not find clear effects for the network position of donor and recipient. These results improve our understanding of how economic behaviour is intertwined with reputational dynamics in a wide variety of contexts. While altruistic behaviour does increase with reputational concern cross-culturally, it also appears that in tight-knit, small communities, absence of reputational concern may, contra expectations, lead only to a small increase in selfishness.

How do people act in light of their expectation of others' reactions? In this paper, we present the results of "lab in the field" experimental economic games wherein participants play not with anonymous partners but with known others from their communities. Our data are unique in that they they include not only individual-level information, as could be gleaned from standard protocols administered to university students, but also feature complete sociocentric network information describing people's relationships with one another in real-world settings. By varying whether a donor's decisions are revealed, and the social proximity of donor and recipient, we can vary the reputational stake of decisions, in order to investigate how the scope for reputational concern influences the actions of donors. or student populations so often studied, we work with adult residents of eight communities in India, Nepal, Colombia, Mexico, and Morocco. Despite differing markedly in their cultural norms and economic organisation, these communities share one key underlying feature-they are small, enduring, rural communities where residents know one another well, often relying on one another for various types of support. In such communities, a person's reputation can be of acute importance not only for their relationships, but also for the livelihood and wellbeing.

We invite community members to take part in a series of dictator games, wherein donors are given the opportunity to divide an endowment between themselves and a passive recipient. While past work has identified that the modal response is generally donors keeping the entire endowment for themselves (as we may expect them to rationally do), many donors typically do give something to the recipient and often split it evenly (see reviews by Engel, 2011; Doñate-Buendía et al., 2022). Consequently, the Dictator Game is taken as a measure of generosity or altruism, as well as adherence to norms of fairness or equity (Forsythe et al., 1994; Hoffman et al., 1994; Camerer and Thaler, 1995; Levitt and List, 2007). The inclusion of additional information in the Dictator Game design can be used to study the effects of manipulated variables on giving propensity (Levitt and List, 2007; Krupka and Weber, 2013). For example, if the donor knows that they share some social identity with the recipient, they often give more (Ben-Ner et al., 2009; Chen and Li, 2009; Baldassarri and Grossman, 2013; Ockenfels and Werner, 2014; Tanaka and Camerer, 2016; Ross and Pisor, 2025) as do they if they are paired with recipients to whom they are socially closer (Leider et al., 2009; Brañas-Garza et al., 2010; Goeree et al., 2010; Ligon and Schechter, 2012; Binzel and Fehr, 2013; Candelo et al., 2018; Robson, 2021). We take advantage of all of these affordances in our experimental design, making the recipients known to the donor and (variably) making the donor known to the recipient.

If recipients learn the identities of donors, and the amount they gave, it opens up their ability to subsequently respond, either through direct reciprocity or by relaying the donor's actions to others (i.e., gossiping), which creates scope for indirect reciprocity as well (Wu et al., 2016). These possibilities should in turn trigger concern among donors for how they will be perceived-i.e., image motivation and reputational concern (Bénabou and Tirole, 2006; Andreoni and Bernheim, 2009; Bursztyn and Jensen, 2017)-and strengthen incentives to abide by social norms (Cappelen et al., 2007; López-Pérez, 2008; Krupka and Weber, 2009, 2013; Kimbrough and Vostroknutov, 2016). In other words, more generous Dictator Game play may be driven both by a desire to develop a "good" reputation-as someone who behaves "appropriately"-as well as a desire to avoid a "bad" reputation-as someone who behaves "inappropriately". In line with this, donors have been shown to give more when their identity (conveyed via their name) is revealed to the recipient than when it is kept anonymous, whether they are American undergraduates (Leider et al., 2009), villagers in Paraguay (Ligon and Schechter, 2012, 2020), or residents in a Cairo neighbourhood (Binzel and Fehr, 2013).

Importantly, the effect of the recipient's knowledge of the donor's identity may vary based on features of the donor and recipient: donors may vary in sensitivity to reputational exposure, and exposure to specific recipients may be more reputationally consequential. First, there is the social proximity of donor and recipient: greater social proximity could make the prospect of future interactions more likely, immediate, and acute, and it could additionally raise the prospect of gossip with common acquaintances, raising the reputational premium of the decision. In line with this idea, Leider et al. (2009) find that the increase in generosity with "non-anonymity" is greater for socially proximate recipients and for those with more common partners. Alternatively, most people have an acute awareness of the reputational standing of their close connections-e.g., with respect to generosity, reciprocity propensity, and general character-which is unlikely to be updated much by a single allocation decision, whereas that same allocation decision might have a much larger marginal effect on standing updating for a more socially distant community member about which the focal has little prior information. As such, cooperative behaviour directed toward socially distant recipients may carry the greatest reputational premiums. Second, the overall social position of a known recipient may impact how a donor chooses to behave: a well-connected recipient could share information with many others, who may themselves be wellconnected. To our knowledge, this has not been directly investigated with the Dictator Game, but related experimental work with third-party observers has shown that people play more cooperatively when they are being monitored by more central observers (e.g., Chandrasekhar et al., 2018; Iacobelli and Singh, 2021). Third, the social positions of donors themselves may influence their play. There are mixed findings for the role of the donor's position on giving rates when play is anonymous (Brañas-Garza et al., 2010; Goeree et al., 2010; Baldassarri and Grossman, 2013). The only published work, to our knowledge, exploring how the effect of reveling a donor's identity depends on the social position of the donor is by Ligon and Schechter (2012), who find that (in Paraguayan villages) donors from households with more sharing partners and that spend more on gifts respond to being revealed to give to a chosen person by giving relatively more generously than others.

There is good reason to expect that the extent to which people are concerned about the reputational risks of their actions is contingent on their social position and identities (Bursztyn and Jensen, 2017). First, a person's social position and identities will shape the experiences they have, which may further influence their outlook and dispositions (Alesina and La Ferrara, 2002; Galinsky et al., 2006; Ray, 2006; Hoff and Stiglitz, 2016; Pepper and Nettle, 2017; La Ferrara, 2019). Participants of lower socioeconomic status, for example, appear to play more generously (Piff et al., 2010). Second, normative expectations vary from person to person, whether on the basis of gender (Ridgeway, 2011), class (Bourdieu, 1984), race (Loury, 2002), caste (Gorringe et al., 2017), or their intersection (Velaskar, 2016). People should anticipate responses to their actions that are contingent on how they expect to be perceived and judged by others (Bursztyn and Jensen, 2017). Further, the extent to which people are concerned about abiding by such norms may vary from person to person (Kimbrough and Vostroknutov, 2016; Henry and Sonntag, 2019) and by the social positions they occupy (Kovářík et al., 2012). Considering the social position of the donor, we can envision two alternatives. We may first expect that central donors will be particularly concerned with maintaining their good standing within the community, and so be relatively more responsive to revelation. Alternatively, we may expect that peripheral donors will be relatively more responsive to revelation, given the novel opportunity it provides for them to shape their reputation.

Beyond the dynamics outlined above, the larger sociocultural context could shape donor's allocation decisions. Different societies (Henrich et al., 2005; Cochard et al., 2021) and even different communities within the same society (Lamba and Mace, 2012) may differ in their norms and institutions, with players' ideas about such norms influencing their own actions (d 'Adda et al., 2020). Communities may differ in how they judge apparent transgressions (Barrett et al., 2016), how strictly people are expected to abide by norms (Gelfand et al., 2011; Chua et al., 2019), and the consequences for violating normative expectations (Eriksson et al., 2021). Communities may also differ in the extent to which people are interdependent and reliant on one another (Thomson et al., 2018). They may differ more generally in their network structure, such as how densely people are connected to one another or how segregated different groups may be from one another. All of these points of variation may mean that the meaning and implications of generosity will differ, and so too how people behave in such tasks as the Dictator Game (Doñate-Buendía et al., 2022).

Overall, this body of work demonstrates that the impetus to give in the Dictator Game can vary substantially across scenarios. Attributes of the donor, the recipient, their relationship to one another, the particular scenario, and the broader context can all induce different motives or incentives that can promote generous play. Our attention here is particularly on those features which modify what could be termed the social exposure or reputational stake of a person's behaviour.

Assuming that there is no social exposure when an allocation is made anonymously, we focus on the effect of revealing a donor's identity, and variation in the strength of this effect. Specifically, we ask: Q1 How does revealing a donor's identity to the recipient affect the amount given in a Dictator Game?

Q2 How does the this effect vary with the social proximity of donor and recipient?

Q3 How does this effect vary with the network centrality of donor and recipient?

Our general expectation is that the introduction of a reputational stake will heighten people's motivation to abide by normative expectations-whether personal or social-about how much they should give. Importantly, different normative expectations could be invoked in the Dictator Game. One is a general enjoinder to be generous. A corollary of this would be to not be selfish. Another is to be fair (Andreoni and Bernheim, 2009; Bicchieri and Chavez, 2010) or to avoid inequity (Fehr and Schmidt, 1999; Bolton and Ockenfels, 2000). These three normative expectations would be reflected by donors: (1) giving more (i.e., being generous), (2) being less likely to give zero (i.e., not being fully selfish), and (3) being more likely to give at least half (i.e., being fair). While ideas of what is fair are, of course, culturally variable (Henrich et al., 2005), existing meta-analyses and theoretical work suggest that giving fifty percent of the total stake is nevertheless salient and worthy of special attention (Engel, 2011; Andreoni and Bernheim, 2009).

Considering social proximity, we first expect to see a general proximity effect: regardless of condition/revelation, donors should (H1.1) be more generous, (H1.2) be more likely to split the endowment fairly, and (H1.3) be less likely to be selfish towards those whom they are closer to. Alternatively, (H3b) the effect of revelation should be weaker among dyads with greater social proximity, as closer recipients can more readily dismiss and distant recipients more readily learn from the allocation decision.

We next expect an interaction between revelation and the position of the recipient, such that: (H4) the effect of revelation is greater when the recipient is more central as their potential praise, scorn, or sanctioning can have more far-reaching effects. Finally, we expect an interaction between revelation and the position of the donor, again with two alternatives: (H5a) the effect of revelation should be stronger for more central donors as they have more to lose, or alternatively (H5b) the effect of revelation should be stronger for more peripheral donors as they both have more to gain and will be more sensitive to loosing standing in the eyes of the connections they do have.

Distribution of allocations

Reputational exposure

In all communities, the distribution of allocations has a strikingly similar shape in the anonymous and revealed conditions (see the left facet in Figure 2). This finding was surprising, as we expected a greater concentration of low allocations under anonymity and a wider upper tail when socially exposed, but this pattern is only visible in some communities, faintly. This is not to say revelation has no effect: indeed it does have a slight positive effect (see Table 1). Across all communities, when their identity is revealed to the recipient, donors give more (H2.1), are more likely to give half or more of the initial endowment (H2.2), and are less likely to give exactly zero (H2.3). SI C discusses whether the cross-community homogeneity reported here depends on partial pooling.

Model predictions suggest that, overall, revelation causes donors in our sample to give an additional 1.5% [1.2%, 1.7%] of the total endowment, on average. This varies from 0.9% [0%, 1.8%] in WH (Colombia) to 2.0% [1.5%, 2.4%] in NP (Nepal) (see Figure S2). The relative increase from amount given in the anonymous condition to the amount given in the revealed condition is 5.4% [4.6%, 6.3%] on average, ranging from 3.5% [0%, 7.3%] in WH (Colombia) to 12.8% [7.4%, 18.6%] in WL (Colombia). Overall, the effect of social exposure is well-identified, but small.

Social distance

Descriptive statistics suggest that allocations decrease with greater social distance, whether the allocation is revealed or kept anonymous (see Figures S4 and S5). Models confirm this association. As the distance between donor and recipient increases, the amount given decreases (H1.1), as does the probability of giving half or more of the endowment (H1.2). Model M3 is less clear but nevertheless suggests that the data are more compatible with distance increasing, rather than decreasing, the probability of allocating exactly zero to the recipient (H1.3, pd = 82%).

We find some limited evidence that reputational concern decreases with social distance. Estimated coefficients for M2 suggest that increasing distance could reduce the positive effect of revealing a donor's identity on the probability of giving at least half the endowment. This supports H3b over H3a, but note that the 95% posterior credibility interval for the corresponding parameter does, barely, include 0 (pd = 92% for the model without demographic controls, pd = 97% for the model with demographic controls; the same interval for models based on complete case analysis rather than multiple imputation does exclude 0). The other models also display greater compatibility with H3b over H3a, though the posterior contrasts less clearly exclude 0, the value of no-difference (pd = 85% for M1 and pd = 85% for M3). While the decrease in effect of revelation with social distance is small in absolute terms, it is non-negligible when considered against the already small effect of revelation itself: for M1, the average predicted effect of revelation at a distance of 4 or more is 55% [28%, 116%] its size at distance 1 (see Figure S3).

Donor and recipient centrality

We reach no clear conclusions for how allocations are associated with donor centrality, nor for how the effect of social exposure varies with it. The models present greater compatibility with central donors giving more, but identification is imperfect (pd = 93%). This is reflected in the positive slope and wide credibility intervals in the middle row of Figure 1. The models also show greater compatibility with central donors being less likely to give exactly 0 (pd = 91%), but they are fully equivocal on the relationship between donor centrality and giving half or more (pd = 54%). In addition, they are compatible with either positive and negative changes in the effect of revelation with donor centrality, which leaves us unable to endorse H5a or H5b.

Our within-subject design ensures that each individual donor gives to a wide range of recipients. This allows for precise identification of any potential relationship between recipient centrality and amount allocated (hence the narrow credibility intervals in the bottom row of Figure 1). However, we find no such relation. As such, we can exclude any large, cross-cultural direct association between recipient centrality and allocation. Among participants, shifting recipient centrality from the bottom to the top decile is associated with an overall change in allocation of 0.3% [-0.2% to +0.8%] of the total endowment. Site-wise associations are somewhat more heterogenous, with the notable suggestion of a small but positive association in UP (additional 1.2% [0.4%, 2.1%] of total endowment) and AZ (additional 1.0% [0.03%, 2.1%]).

The change in the effect of revelation when shifting recipient centrality from the bottom to the top decile is -0.35% [-0.97%, 0.24%] of the total endowment. Expressed relatively, the effect of revelation shrinks to 78% [48%, 120%] its size when changing recipient centrality from bottom to top decile. Note that H4 is monodirectional: it posits only an increase in the effect of revelation with recipient centrality. The model is compatible, at most, with a fairly small effect in this direction. Thus, we conclude that H4 is either wrong-there could be a sizeable negative interaction between revelation and recipient centrality-or, at best, correct but arguably negligible in size.

To ensure that montonicity constraints imposed by our models do not dissimulate a U-shaped relation between donor or alter centrality on the one hand, and allocations or the effect of revelation on the other, we additionally fit models without these constraints. We find no sign of such a relation. See SI D.

It is worth noting that these results describe how allocations and the effect of revelation vary with centrality while keeping other donor and recipient characteristics constant. In reality, individuals cannot easily change their centrality, and centrality is correlated with other measures that enter the model. Computing average fitted values by observed centrality reveals that donors in the top and third (but not second) decile are predicted to give substantially more than others, on average. This must be because of their distinct covariate profile and individual characteristics captured by random intercepts. No analogous finding holds for recipient centrality, nor for the interaction of revelation and donor or recipient centrality. SI E offers more detail.

Donor and donor-household heterogeneity

Examining the random effects in the models, we find substantial unexplained heterogeneity at the donor and donor-household level, both in terms of the average amount given and responsiveness to condition. This suggests that some participants-and, to a degree, participants from the same household-are consistently more or less generous than others. Similarly, there is systematic variation in how they respond to social exposure. In contrast, unexplained heterogeneity at the recipient level is low: specific individuals do not appear to systematically attract smaller or larger allocations from different donors. See SI F for further details. These strong donor effects may be down to individual personality, but it is also possible that parts of this variation could be explained by unmeasured characteristics.

Demographic factors (exploratory)

We fit a second set of models adding terms for donor and recipient age, gender, and household wealth. Estimated model coefficients for centrality and distance are remarkably similar in these models, suggesting that the associations reported above are not confounded by these demographic measures (see SI B and Figures S7, S8, S9).

For exploratory purposes, we consider the coefficient estimates for these demographic predictors in M1 (see Figure S10). These suggest that in most communities, men give more than women. Other demographic effects display more cultural variation. For example, older donors give less in all South Asian sites (TE, AZ, NP, UP), and older recipients are given more in TM (Mexcico), WL (Colombia), NP (Nepal), and UP (India). Notably, we find no evidence that the wealth of donor and recipient influence allocations, despite participants regularly reporting that they allocated according to need. We also find no cross-cultural interaction between these demographic predictors and the effect of revelation. There is however a suggestion that older donors may be less sensitive to revelation in TE (India) and WL (Colombia).

Discussion

The communities in which we conducted these Dictator Games differ markedly from the anonymous online or student populations in which economic games are so often administered-most notably by being rural, dense in kin, highly dependent on mutual aid and support provisioning, and featuring enduring social relationships spanning decades, if not generations. It is precisely in such contexts that we believe reputational cognition is best studied. In these communities, residents are often intimately involved in one another's lives, and are used to either making or declining to make support provisioning ties that carry real-world consequences for how they are perceived by others (e.g., as generous, selfish, or prestigious). We presume (and indeed show in Redhead et al., 2024 Redhead et al., , 2026) ) that reputational considerations then guide future economic decisions.

Although we do not have a comprehensive sample of human cultural diversity, these eight rural communities in India, Nepal, Mexico, Morocco, and Colombia differ markedly in terms of social organisation, local norms and beliefs, modes of subsistence, levels of market integration, religion, and a host of other variables. The recently settled Amazigh nomadic herders of the TZ community in the High Atlas mountains of Morocco live very different lives than the Tzotzil Mayan smallholder farmers of the TM community in Chiapas, Mexico, or the farmers and wage labourers of the UP community in Uttar Pradesh, India. In light of this diversity, it is no surprise that the allocation distributions vary so strongly across communities. Our results therefore confirm the cultural variation noted in prior work (Henrich et al., 2005; Doñate-Buendía et al., 2022): local norms, presumably stabilised over extended periods, appear to govern how much individuals typically share in the Dictator Game, despite the Dictator Game itself being novel to most participants.

This does not mean, however, that there are no cross-cultural regularities. We find a small but consistent effect of revealing the donor's identity to the recipient. Across the varied settings, donors are responsive to the reputational stake of their decisions. Revealing their identity to the recipient causes them to give more, and makes them more likely to give half or more of their endowment, and less likely to give exactly zero. The effects we find in the different communities are consistent in sign and magnitude, which suggests that the reputational motivations at play might transcend culturally varying normative expectations.

Our results suggest that the well-established association between social proximity and generosity holds cross-culturally: in all communities, donors are more generous with others with whom they are more closely connected. Our design allows us to comment on the mechanism that underlies greater generosity towards socially proximate others. Were this association driven only by the increased reputational concern one feels in one's immediate social circle, we would only find an association between social distance and amount allocated when the donor's identity is revealed to the recipient. In fact, the association holds even when the donor's identity is kept anonymous. We find mixed evidence suggesting that it is weaker in this case, but we establish firmly that it is still present. This is in line with prior findings on social distance with anonymous donors (Leider et al., 2009; Brañas-Garza et al., 2010; Goeree et al., 2010; Ligon and Schechter, 2012; Binzel and Fehr, 2013; Candelo et al., 2018; Robson, 2021), but here we are better able to disentangle the possible mechanisms at play. Even when they remain anonymous, donors may be driven by in-group favouritism (Balliet et al., 2014) or "social discounting" (Jones and Rachlin, 2006), and they may have greater "stake" in proximate partners due to greater interdependence (Roberts, 2005; Aktipis et al., 2018) and even biological relatedness (cf. Macfarlan and Quinlan, 2008; Gervais, 2017; Pisor et al., 2020; Ross and Pisor, 2025). Thus, while increased reputational concern may partly explain generosity towards proximate others, other mechanisms must also be at play.

In our initial hypotheses on the interplay of reputation and social distance, we formulated some opposite-direction predictions: participants could be reputationally "conservative"-i.e., primarily concerned with maintaining reputation in their immediate entourage-or they could be reputationally "eager"-primarily seeking to gain reputation in the eyes of distant others. Our results lend greater credence to the former than the latter, albeit equivocally: for one of the three outcomes, the effect of revealing a donor's identity is stronger when the recipient is socially proximate. For the other two, results are less clear but nevertheless show greater compatibility with this possibility than with the opposite.

To our surprise, we find no systematic pattern when considering the donor and recipient's positions in their community. While the middle row in Figure 1 suggests a positive association between donor centrality and amount allocated, credibility intervals are wide. We are left uncertain as to whether the social prominence of donors is associated with greater or lesser generosity, and we are completely uncertain about whether they show greater or lesser sensitivity to reputational exposure. With regards to recipients, we can exclude the possibility that there is any non-negligible, cross-site, systematic association between a recipient's centrality and the amount they are given (contra work on the centrality of third party monitors: e.g., Chandrasekhar et al., 2018; Breza and Chandrasekhar, 2019; Iacobelli and Singh, 2021). If donors are in fact more or less generous towards socially prominent recipients, our findings suggest that it is to a degree so small that it arguably does not matter in practice. Moreover, the effect of social exposure either diminishes substantially when giving to more prominent recipients, or increases so little that we can consider it effectively unchanged (contra Ligon and Schechter, 2012). Taken at face value, this result suggests that one of the fundamental assumptions we made when designing the study was mistaken: we had speculated that because central individuals exercise more control over the flow of information in their communities, people would behave more generously towards them in the revealed condition. This does not appear to be the case.

Overall, the average effect of revelation we observe is relatively small . A number of reasons could explain this modest effect size. One is the relative lack of salience and immediacy of revelation in our design, as this happens several days after the allocation and without the donor being physically present. Studies where revelation is immediate and visible to all (e.g., Frey and Bohnet, 1995; Bohnet and Frey, 1999) typically find stronger effects than those where revelation is indirect (e.g., Rotella et al., 2021). Alternatively, it may be that the "anonymous" condition did not feel truly anonymous to participants, for example, because of the presence of the interviewer recording allocations on a tablet. The extent to which decisions are transparent to experimenters is known to influence play (Hoffman et al., 1994 (Hoffman et al., , 1996;; Lamba and Mace, 2010). Moreover, in small, face-to-face societies where gossip is common, people may not believe secrecy is a viable option; they may be disposed towards believing that their actions will, eventually, be revealed publicly regardless or our assurances to the contrary. We even speculate that the small effect size may reflect an important sensitivity to reputational bookkeeping. In our framing, we follow past work (e.g., Ligon and Schechter, 2012) in implicitly assuming that motives for giving in the anonymous condition (for a self-interested agent) are small, and they would only become large in the revealed condition if agents were behaving so as to minimize the social sanctioning that might follow from giving less than what is viewed as appropriate by a recipient. However, it is possible that this framing is wrong-rational, reputationally risk-sensitive agents might prefer to behave similarly in both anonymous and revealed conditions either because they are following internal norms to behave in public like they would in private (doing the right thing either way), or strategically bet-hedging against reputational loss that would come from 'anonymous' behaviour that comes to light. We also know that some participants did not fully comprehend the difference between conditions. Dropping those who failed comprehension checks, however, does not affect results (see Figures S32 and S33), which offers some reassurance against this threat. Finally, and most interestingly, it may simply be that, in these relatively small, close-knit communities, donors are relatively unconcerned with how public their decisions are, letting other considerations be front of mind when making allocations. Reputational concern is obviously not the only factor that encourages generosity, and it may be secondary to other considerations in these settings.

This study establishes many avenues for future work. At the measurement level, there is a need to validate results obtained with the photograph-driven, asynchronous protocol we used. It is likely that this design attenuates effects when compared to a synchronous design in which donor and recipient are physically present at the time of allocation, but we do not know how strongly. On a substantive level, further studies are needed to consolidate our emergent understanding of how reputational concern and social distance interact, and we need more work to check whether the absence of an effect for recipient centrality is robust. Finally, additional modelling work on the data we have collected may yield new insights: in particular, models allowing for latent classes among donors may help us better understand the behavioural heterogeneity that our data suggests exists even within each community.

Much theoretical and empirical work has sought to establish how reputation and reputational concern shapes people's behaviour and relationships (Giardini and Wittek, 2019). Yet, there are still many outstanding questions on how this transpires in practice (Giardini et al., 2022). We offer this design and these findings as a potential avenue for further exploration, coupling some degree of experimental control with the complex and multifaceted motivations that form the substance of people's actual day-to-day interactions and decisions.

Methods

Experimental protocol

We conduct Dictator Games with adult residents in eight communities in five countries. Our key design choice is that players are paired with other residents in the same community, presented to them via photographs. We implement the games using a newly-developed Android app for behavioural economic and peer-report data, based on software (Ross and Redhead, 2022) designed to facilitate running the network-structured behavioural economic games (Gervais, 2017).

Participants could opt to give an amount of their choice, in 10% increments of the total endowment (0%, 10%, . . . , 100%. Other increments were used in some sites, see SI G). Each participant makes decisions in two conditions: in the "anonymous" condition, recipients will be informed of the amount allocated to them, but not who made the allocation; in the "revealed" (a) Anonymous (b) Revealed condition, recipients will be informed of the amount allocated to them and shown the photograph of the person who made the allocation (they will also be asked to rate the appropriateness of the amount given).

Donors know in which condition they are making each decision. That is, donors know whether their identity will be revealed to the recipient to whom they are (possibly) allocating money. By using social network information for each community to build a list of dyadic pairings, we are able to ensure that there is variation in the relative position and social proximity of recipients for each donor. In short, the different pairings of donor and recipient (across the two conditions) should entail variation in the extent to which there is a reputational stake for the donor, and so consequent variation in how they play. The full protocol entailed three visits to each participant, spread over a number of days (see SI H for more details). Each participant was shown 14 recipients in one condition, then 14 in the other (see Figure 3 for a demonstration of how this appears to participants in the app. Participants were shown 12 recipients per condition in WH and 15 in TZ). Condition order was randomised across participants. Recipients were drawn from across the community, with deliberate oversampling of high-and low-centrality recipients, to ensure that each participant makes allocations to a broad range of others. The allocations were economically motivated decisions: participants knew that some of their decisions would be selected to be paid out. The endowment for each allocation decision was determined with consideration of local daily wage labour rates and monetary denominations, and a general aim for comparability across sites. 1We ran the same general design, with some modifications, in eight communities: "TE" and "AZ" in Tamil Nadu, India; "WH" and "WL" in western Colombia; "TZ" in the High Atlas Mountains of Morocco; "TM" in Chiapas, Mexico; "NP" in eastern Nepal, and "UP" in Uttar Pradesh, India.

Demographic and social network data

In each community, we have comprehensive sociodemographic data that allows us to characterise participants in terms of their age, gender, material wealth, etc. Table S6 reports the demographics of donors across the communities. We further have extensive information on the social connections linking residents together. This includes self-reported social support relationships, covering a range of different types of support, both material and immaterial. SI I describes the network data in more detail. Here, we use an aggregate network constructed from the combination of the various relationship types to construct a single network representing the flows of support between residents. Plots of the networks are shown in Figure S24.

Table S7 reports the number of observations for the different elements of the experimental design in each community. Our coverage is quite high, with an overall participation rate of 77% of all adult residents across communities. Non-participation was primarily due to people being unreachable at the time of data collection. SI G presents basic details on each community and describes site-specific deviations from the general design. Two site-specific deviations warrant noting here. First, in WH and TZ, participants saw the same recipients across both conditions, as opposed to different recipients. Second, in TZ norms of propriety meant that we could not use photographs, but instead gave the names of the recipients along with their birth year and the names of their parents.

A central focus in our analyses is on the position and proximity of players. To characterise the position of players, we use PageRank centrality, which broadly identifies nodes in a network that are structurally important, in that other structurally important nodes connect to them. Details on the transformations we apply to make centrality measures commensurable across communities are offered in the next section.

For the social proximity of donor i and recipient j, we use the shortest path between themi.e., how many intermediaries it would take to connect i and j, when being maximally efficient in traversing the network. If two people are friends, they will have a distance of one, if they are friends-of-friends, they will have a distance of two, etc. Summaries of these measures are presented in Table 2.

Models

We use ordered beta regression (Kubinec, 2023) for model M1 (where the raw allocations are the outcome), using the ordbetareg package in R, which builds on brms (Bürkner, 2018). Ordered beta regression is designed specifically for zero-and one-inflated proportions, and is therefore well-suited to modelling the share of a total endowment given in a Dictator Game. We fit logistic regression models for the other two-derived-binary outcomes. We use the same set of predictors and the same random effect structure across models, with one exception: the "precision" parameter (ϕ), which governs dispersion in the ordered beta model and does not exist in logistic regression, is modelled as a site-wise random intercept.

The R code specifying the model form is available in SI J.

The predictors and random effect structure are described in Table S9. The hierarchical structure maps onto the nesting of our data: allocations are nested within site, donor (each participant makes multiple allocations), recipient (the same recipient appears as a partner for different donors), donor-recipient dyad (when dyads were repeated across conditions), donor and recipient household (this also accounts for the fact that our measure of wealth is at household level), and research assistants. We include random intercepts for all these levels. In selecting random slopes, we loosely follow the injunction to "keep it maximal" (Barr et al., 2013), ensuring in particular that we include donor-and site-level random slopes for the fixed effects against which we test hypotheses. We omit random slopes where we have insufficient data to identify them (for example, at household and dyad levels) and where their inclusion creates unnecessary computational burden (Matuschek et al., 2017). In particular, we do not include random slopes at the recipient level, as early attempts suggested little to no heterogeneity at this level.

We treat network centrality and social distance as ordered categorical rather than numeric variables (see Table S10). This allows us to model their effects as monotonic but non-linear (Bürkner and Charpentier, 2018). The rationale for doing this rests on the observation that incremental increases in centrality mean very different things at different parts of the centrality distribution. Generally, influence or prominence is not evenly distributed, but rather concentrated among a restricted number of individuals at the top of the centrality distribution. Similarly, incremental steps are qualitatively different at low and high distances.

We use weakly regularising priors form most parameters, and improper flat priors for populationlevel fixed effects. Model diagnostics are included in SI K and prior sensitivity checks in SI L.

Missing data

Incomplete coverage of the underlying network data would force us to drop almost a quarter of the observations. To prevent this, we imputed values by simulating new networks from the observed ones. We fit an exponential random graph model to the full network of adult residents and simulate outgoing edges for residents who did not provide responses for the social support survey (Krause et al., 2020). We then calculate measures of centrality and social proximity from these imputed networks. Imputing with an exponential random graph model (ERGM) is superior to standard multiple imputation done directly on the dataset, because such techniques would treat each allocation pairing as independent, while the ERGM can account for higher-order associations between dyads (e.g., the effect of having friends in common on the prospect of a tie). Further details are included in SI I.3. For a small number of observations where demographic correlates were missing, we additionally conducted multiple imputation using the R package mice.

We fit models to 25 imputed datasets, comfortably in excess of recommended figures for this amount of missing data (van Buuren, 2018). Because of the computational costs of fitting complex models in a Bayesian workflow, we only do this for two main model specifications per outcome. We then combine the posterior draws from all 25 models into a single object (Zhou and Reiter, 2010). Coefficients and credible intervals for the resulting models are extremely similar to those fit when dropping partial cases (see SI K), but using imputed models allows us to include participants we would otherwise drop in the calculation of predicted values and marginal effects.

Marginal effects

In the results section above, we report effect sizes on the outcome scale. These are obtained following principles outlined in Arel-Bundock (2025). All estimates are computed using "counterfactual grids": they represent the mean predicted effect of changing values for one variable, in our observed data, while keeping other covariates at their observed levels. We use weights to compensate for the unequal size of the different sites, and our deliberate over-sampling of central recipients.

C Sensitivity to partial pooling

To assess how partial pooling affects coefficient estimates in model M1, we fit eight additional models using the same specification but restricting the data to each community. The coefficient estimates from these models are therefore estimated without any pooling.

The results are shown in Figures S11. As it is designed to, partial pooling pulls site-level estimates towards the overall population-level parameter. This has a noticeable effect on estimates of the effect of revelation (and its interaction with other parameters), in particular for sites where the no-pooling estimates have wide posterior Credibility Intervals. Unlike their partialpooling counterparts, no-pooling estimates for revelation are compatible with a zero-or negative effect-sizes for several communities: WH, TM, TE, AZ.

In the main text of the article, we claim that the effect of revelation is cross-culturally consistent. No-pooling estimates are still compatible with this claim-the credibility interval for all no-pooling estimates encompasses the overall estimated fixed effect-but some caution may be warranted. Nevertheless, there is no reason to believe that no-pooling estimates are superior, and we note that where there is clear cross-cultural heterogeneity-as is the case for the Intercept-partial-pooling models clearly recovers it.

D Models without monotonicity constraint

H5a and H5b (see Table S1) suggest that peripheral, respectively central, donors will react more strongly to the effect of revelation. E Marginal effects calculation

The estimated effect sizes and model predictions reported in the main text and used to generate figures were obtained following principles laid out in Arel-Bundock (2025). Three aspects of our workflow are worth describing in detail, because they influence how the resulting effect sizes and associated credibility intervals should be interpreted.

Prediction grid. We use an "empirical grid" to generate model predictions, creating counterfactual values for the variables whose effect size we wish to estimate. For instance, when computing how the effect of revelation changes with distance, we start with a grid containing our actual observations. We replicate this entire grid multiple times, fixing the values of distance and condition to all their possible combinations but keeping other covariates at their observed values. We then generate predicted values for all the resulting combinations, using a large number of posterior draws, and use these to compute and summarise predictions and contrasts of interest.

A limitation of this procedure is that the counterfactual grids we use can contain unrealistic observations. For example, the procedure allows us to ask how fixing donors' centrality to the bottom vs top decile affects the outcome, on average, while keeping other donor characteristics constant. This counterfactual estimation of the effect of donor centrality is correct from a modelling standpoint and adequately translates model parameters into interpretable effect sizes on the outcome scale, but in reality an individual's network centrality is not something that can change easily, and it is correlated with other covariates (e.g., gender, age, etc.).

It is also possible to compute effect sizes summarised by observed levels of a variable of interest. The trade-off is that effect sizes computed in this way are no longer "conditional" on keeping other variables constant-but they do avoid implausible counterfactuals. For an illustation, see Fig S16, which shows the effect of revelation by donor centrality computed using the two different approaches. While summarising effects by observed values is informative, we do not use it in the main text because we believe it is further removed from how readers will typically interpret effect sizes.

Random effects. When computing predicted model values, we include all random effects estimated in the model (i.e. we include site-, donor-, recipient-, household-, and dyad-level effects). As a result, the estimated effect sizes and credibility intervals are specific to the sample which we observed, not necessarily valid for any theoretical superpopulation from which our observations are drawn-they are analogous, in this sense, to a "Sample Average Treatment Effect" (SATE, but see the remarks below on weighting). Importantly, when testing hypotheses in the main text, we refer to estimated fixed-effect parameters, not computed effect sizes. Conditional on our model being correct, the fixed effect paramaters and associated credibility intervals are valid for a theoeretical superpopulation of sites, participants, etc. from which our observed sites, participants, etc. would be randomly sampled.

Weighting. When computing average predictions and effect sizes for a given site, we give each donor and recipient equal weight. When computing average predictions and effect sizes across sites, we additionally give each site equal weight. This post-stratification strategy compensates both for our deliberate over-sampling of peripeheral and central recipients, and the the different sample sizes in each site. If we did not weight each site equally, our estimates would be severely over-influenced by South Asia, where the four communities with the highest number of observations as situated. The trade-off is that our strategy gives vastly more weight to individuals in small sites. At the extreme, observations from WH (Colombia) will carry, on average, 14.5 times more weight than those from UP (India). In practice, the problem is not as severe as it may seem, because the use of partial pooling in our model will move estimated coefficients for small sites, such as WH, more than for large sites such as UP. Consider the effect of revelation: using equal sites for each site, we report in the main text that donors give 1.5% [1.2%, 1.7%] more of the initial endowment on average, acrross sites. If we do not use equal weighting for each site, the figure becomes 1.6% [1.4%, 1.8%]. The difference is negligible.

G.1 TE and AZ

The TE and AZ communities are two neighbouring villages (separated by a few kilometres) located in Sivagangai District, Tamil Nadu, India. Residents engage in a mix of agriculture (mostly rice, sugar cane, cotton, banana, and coconut) and wage labour in nearby towns and cities. The nearest market towns are about ten minutes drive away, and the nearest city of Madurai (with a few million inhabitants) is roughly a one hour drive away. Residents are members of a mix of caste and religious groups (Hindus, Catholics, and Protestants), with these divisions structuring much of people's interactions with one another. In TE, Dalit (also often referred to as Scheduled Caste) groups make up the numerical majority in this village, holding many positions of leadership, and many households are relatively well off. In AZ, the balance of particular caste and religious groups is slightly different, with a smaller number of Dalit (or Scheduled Caste) residents who are consequently somewhat more relegated and disadvantaged compared to others. People are certainly concerned with maintaining a "good name" in their community and avoiding negative gossip and enviousness.

Eleanor Power has been conducting fieldwork in the community since 2011 (see, e.g., Power, 2017; Power and Ready, 2018; Power, 2018; Power and Ready, 2019).

G.2 WL and WH

The WL site is an ethnically diverse community of Afrocolombian, Emberá, and Mestizo residents located in the Western Lowlands of Colombia. G.3 TZ

The TZ site is located in the Ait Hani district in the High Atlas of Morocco, about an hour and a half drive from the town of Tinghir (pop ∼ 45, 000). H Experimental Design

The implementation of the games is done on Android tablets using a custom Android application (Ross and Redhead, 2022), designed to implement "RICH" (recipient identity-conditioned heuristics) games and dyadic peer-ratings (Gervais, 2017). Source files for the version of the application used in this study are available on our GitHub repository (https://github.com/rep2si/DieTryinSR). The Android application works in conjunction with an R package that builds the game settings and pairings. This allows us to build code templates in R, creating donor-recipient pairs on the basis of whatever covariate data we choose to supply. We can then conduct the games asynchronously, showing photographs of multiple recipients to donors sequentially, and paying out these allocations at a later stage.

Decisions are motivated: real money is at stake. However, we do not pay respondents for every decision they make, or for every decision made towards them. We randomly select four decisions to be paid out: two decisions are ones where the respondent was a donor to people in the community (they get paid what they chose to keep for themselves), and two decisions are ones where the respondent received money from others (they get paid the amount that the others gave them). The choice to pay two decision "halves" rather than one "full" decision was made to ensure equitable payment, as the oversampling of some players would otherwise lead to greater payout opportunities for some.

H.1 Data Collection Protocol

We now outline the general data collection procedure. Notable variations to this design at any site are noted briefly in the description of each site above.

The study requires three visits to each participant (see Figure S21 for a schematic). Table S7 shows the number of observations for each element of the design across all sites.

During the preliminary visit (Visit 1), we acquire consent for the study and take a photograph of the participant, explaining how this will be used. Everyone who gives consent is included in the games.

In Visit 2, participants again give consent, are introduced to the game rules, and complete a comprehension check. They then make allocations in Dictator Games under two conditionsone in which their identity is kept anonymous and the other in which it is revealed to the recipient. Participants are first told that they will make Dictator Game allocations in two conditions. In all communities except for NP (Nepal) and UP (India), they receive explanations for both conditions at the outset, then make allocations in both conditions. In NP and UP, they receive explanations for the first condition, complete corresponding allocations, then received explanations for the second condition and complete corresponding allocations. Participants are taught to distinguish the game condition based on a salient visual cue in the Android app (namely, the background colour that appears behind the photograph of the recipient: orange for revealed and blue for anonymous; see Figure 3). Participants are also informed that none of the allocations are compulsory-i.e., with each allocation decision, they can opt out of making an allocation (cf. Dana et al., 2006; Lazear et al., 2012), with the implications of such a decision explained to them (in such cases, there is no impact on the recipient for whom it effectively has not happened, but for the donor it is treated as an allocation to self of 0). Conditions are presented sequentially and the order in which they are presented is randomised. This is done in order to control for ordering effects. Participants are asked to allocate an endowment to 14 specific recipients (whose photographs are presented to the participant) per condition. In NP and UP, participants were asked to make two additional allocations, one per condition, to recipients whose identity they do not know, and whom they are informed will be selected randomly from the adult members of their community. This appears as the eighth allocation in each condition. After participants make allocations, RAs provide a second, overall assessment of comprehension following game play to act as a confirmatory checkpoint, or as an opportunity to revise the previous assessment of comprehension. Participants then make a first round of reputational evaluations for several key others in the community-e.g., How generous do you think this person is? How fair do you think this person is? (see Figure S22). Visit 2 concludes with the payout of a participation/show-up fee.

In Visit 3, we ask participants how much they expect to have received from various donors, inform participants how much they were allocated by donors (with or without donor identity, depending on the condition in which an allocation was made), and elicit a second round of reputational evaluations. Participants are initially asked how much they expect they were given by some of the people for whom they appeared as a recipient in Visit 1 (i.e., how much they expect some of their donors gave them). A small financial incentive is given for guesses that fall within a range of the actual allocation. Participants are then informed of all allocations that were made to them. When the allocation was made in the revealed condition, they are also shown the photograph of the donor, and are asked to judge whether the allocation is not appropriate, appropriate, or very appropriate. Finally, participants make reputational evaluations for several members of the community, as during Visit 2. Visit 3 concludes with a debrief stage during which participants are paid the total amount they earned from the games and a second show-up fee. In (a) Fair (b) Generous the days following the final debriefing visit, members of the research team met informally with community members to discuss their overall experience.

They asked about their perceptions of the experimental protocol and any discomfort it may have caused. These discussions did not reveal anything concerning. Since implementing the research protocol, we have returned to TE (India) and AZ (India) sites in January 2026 for a feedback visit, in which we presented early findings to participants and, once more, sought to elicit expressions of any discomfort or unpleasantness that might have emerged after we left the field. No such discomfort was reported.

H.2 Pairings

Donor-recipient pairings for the various elements were determined through custom R functions meant to ensure an full coverage as possible. Once the set of participants was determined (i.e., after Visit 1), pairings for all elements were made; adjustments to this (e.g., based on players not completing subsequent visits) were done at the relevant moments.

For the Dictator Game allocation, every participant makes decisions in both conditions and they largely see different recipients across both conditions (with a very low chance of seeing repeat recipients across condition). For TE, AZ, TM, UP, within each condition, donors are paired with 14 recipients comprising: • two central individuals (i.e., two individuals randomly selected from the top 15% of the (a) Expected (b) Revealed (c) Anonymous network centrality distribution) • two peripheral individuals (i.e., two individuals randomly selected from the bottom 15% of the network centrality distribution).

• 10 further individuals randomly selected from the entire set

For WL, within each condition, donors are paired with 14 recipients comprising: • two central individuals (i.e., two individuals randomly selected from the top 23% of the network centrality distribution) • two peripheral individuals (i.e., two individuals randomly selected from the bottom 23% of the network centrality distribution) • 10 further individuals randomly selected from the entire set For WH, within each condition, donors are paired with 14 recipients comprising: • one central individuals (i.e., one individual randomly selected from the top 25% of the network centrality distribution) • one peripheral individuals (i.e., one individual randomly selected from the bottom 25% of the network centrality distribution) • 10 further individuals randomly selected from the entire set For NP, within each condition, donors are paired with 14 recipients comprising: • two central individuals (i.e., two individuals randomly selected from the top 19% of the network centrality distribution) • two peripheral individuals (i.e., two individuals randomly selected from the bottom 15% of the network centrality distribution) • 10 further individuals randomly selected from the entire set For TZ, within each condition, donors are paired with 15 recipients comprising: • two central individuals (i.e., two individuals randomly selected from the top 15% of the network centrality distribution) • two peripheral individuals (i.e., two individuals randomly selected from the bottom 15% of the network centrality distribution) • 11 further individuals randomly selected from the entire set

The centrality cutoffs were varied across sites so that those identified as central or peripheral matched who the ethnographers knew to hold standing in each community. These pairings are not quite random-uniform: we use custom functions to try to arrive at the most balanced possible over-sampling of central and peripheral players. So, central and peripheral players are effectively distributed as evenly as possible across donors.

At the start of Visit 3, before we report allocation decisions to participants, we first elicit their expectations of what 5 of their revealed donors gave to them. Also, when allocation decisions are being reported, we record recipients' assessment of the "appropriateness" of what was given to them by each revealed donor.

As the contingent nature of these pairings should suggest, a first pass of all pairings is made prior to Visit 2. Following the completion of data collection for Visit 2, these pairings are revised to account for pairs becoming unviable (if, for example, a player does not complete Visit 2 or if they opt out of a decision). Replacement pairings are made accordingly.

H.3 Payment

Participant compensation consists of three key components: • Participation/show-up fees, paid at the ends of Visit 2 and Visit 3.

• Payment from the Dictator Game allocations -Participants make 28 Dictator Game decisions towards known others in the community and will have had a number of decisions made towards them. We do not pay them for every decision they make, or for every decision made towards them. We pay participants for a total of four decisions: two decisions are ones where they were a donor to people in the community (they get paid what they chose to keep for themselves), and two decisions are ones where they received money from others (they get paid the amount that other people gave them). Choosing to "opt out" of any allocation decision has implications for payout: -Payment process for skipped decisions from the donor's perspective -For the donor, if they choose to skip making an allocation towards a person whose photograph they are shown, the decision stops there and they will not choose how to split the money.

The recipient will not be told anything. However, if this allocation decision is selected for payout, the donor gets 0.

-Payment process of skipped decisions from the recipient's perspective -For the recipient, it is as if the game with the donor (which the donor chose to 'skip') did not happen. As a result, this will have no consequence for them, and will not impact their final payout (i.e., skipped decisions are never in the pool of decisions from which we draw payouts).

• Payment for accurate expectations -Participants are asked to guess how much five different donors gave them, with close guesses accruing a small additional award.

For our analyses, we use an aggregate network representing the multifaceted social support relationships between adult community residents. Figure S24 shows the observed aggregate network for each of the communities. Questions are broadly aligned, as all communities are part of the "ENDOW project," which has standardized data collection procedures.

I.1 Survey Respondents

In TE, AZ, WH, WL, and NP, we aimed to survey all adult residents. In TM and TZ, respondents were limited to male and female household heads. In Table S6, we show the proportion of game participants for whom we have their own self-reported social support network ties.

I.2 Network Construction

Our aim is to construct a comparable network across the different communities. This means that we work with a subset of network prompts that is meant to elicit comparable domains of support across the communities. This entails: • borrowing a week's wages ("monetary loan"), • borrowing food and other basic household items ("household items") • behavioural assistance to women ("female behavioral") and men ("male behavioural") in the sharing unit • socializing and information sharing to women ("female information") and men ("male information") in the sharing unit • assistance from government or NGO officials ("government") • other site-specific assistance outside the community ("external") [this question was not asked in WH and WL]

Note that this is not the full set of questions asked at each community (outlined in the section below). For example, we do not include questions asking about who people stated came to them for support, instead limiting our attention to just questions about who people stated they went to for support.

As our attention is on social standing and social proximity within the community, we construct networks of all adult residents from which to subsequently construct our centrality measures. Note that this attention on adult residents means that we exclude people who were named as providing support by survey respondents if they are not resident or not an adult. We also define residency at the time at which the games were conducted, rather than the time at which the network data were collected. It is important to note that centrality measures derived from differently constructed networks arrive at similar results. Alongside the network of adult residents, we considered networks that included: (1) all partners named (so including many partners external to the community), (2) all residents (so including non-adults), (3) all surveyed individuals, and (4) all donors. Across communities, the Pearson's correlation coefficient of the unweighted PageRank centrality from any combination of these networks was never below 0.71 and was on average 0.95. We are therefore confident that whichever decision rule is used to define the subset of nodes included in the network, the main results hold.

If we carry forward the decision to use the network of adult residents, then when we construct the distance between residents i and j we consider only the pathways through other adult residents; if they both named a common friend who resided elsewhere, this would not be considered. Again, making this change from considering only adult residents to the most expansive case of considering all partners named results in small changes to relatively few pairings. Across all sites, 13.2% of the allocation pairings differ in their distance with these changes, and the vast majority of these by only a single step. Those differences are thus generally small. Networks constructed in this way are shown in Figure S24.

I.3 Network Imputation

Different sampling frames were used in the different communities, resulting in differences in our coverage of network data for adult residents and participants (see Table S6). Most notably, in TM and TZ it was largely male-and female-household heads who were surveyed for the social network prompts. This means that for some donors and some pairs of donors-recipients we lack network information (see Table 2). To deal with this, we simulate network data based on what has been observed using an exponential random graph model (ERGM) (Krause et al., 2020). We note that for TM and TZ, data is clearly not missing at random, so some caution is warranted.

In brief, we fit an ERGM to the network of all adult residents (at the time of the running of the games), where we note which connections could not have been reported due to the relevant person having not been surveyed. The ERGM includes terms for: the age of i (Age (outgoing)); the age of j (Age (incoming)); the absolute difference in the ages of i and j (Age difference); whether i and j are the same gender (Same Gender); the gender of i (Male (outgoing)); the gender of j (Male (incoming)); whether j is a person of high status / a leader in the community (High status (incoming)); whether i and j are of the same social group, which could refer to caste, religion, or tribal group (Same Group); the coefficient of biological relatedness between i and j (with, e.g., a value of 0.5 representing a tie between a parent and child or between full siblings) (Blood Relatedness); the equivalent coefficient for relatedness by marriage (with, e.g., a value of 0.5 representing a tie between spouses) (Affinal Relatedness); the normalized square root of the distance between the houses of i and j (Distance); the effect of j naming i on the prospect of i naming j (Reciprocity); and two related terms for triadic closure (i.e., the effect of having friends in common, specifically, geometrically-weighted edge-wise shared partners (GWESP) and geometrically-weighted dyad-wise shared partners (GWDSP)). The results of that model are then used to simulate 25 networks, where observed dyads are kept fixed and only unobserved dyads are imputed. This is done using the ergm package in R and its functionality for dealing with missing data (Hunter et al., 2008; Krivitsky et al., 2023; Handcock et al., 2025). Table S8 includes the model coefficients for each site. The alpha decay parameter for the GWESP and GWDSP terms was determined by finding the combination that resulted in the lowest AIC/BIC values for the network. We evaluated the MCMC diagnostics and goodness of fit measures to ensure that the resulting ERGM appropriately captured the structure of the observed network. Figure S25 gives examples of what the resulting networks look like.

We can then fit our main regression models again using centrality and distance measures computed from the imputed data. We describe the rest of the procedure in SI K.

K Fit diagnostics

As explained above, we use an ERGM to impute missing network values and MICE to impute missing values for demographic variables. Using these techniques, we generate 25 complete datasets, fit a model to each one, and group posterior draws from all models into a single object (following Zhou and Reiter, 2010). A side-effect of this procedure is that usual fit diagnostics lose meaning: R-hat values for the combined model, in particular, no longer adequately indicate how well chains have mixed, as between-chain variation is driven by changes in underlying data (across the imputed datasets). In addition, for computational efficiency, we only use 500 warmup iterations for each of the 25 models, and only take 100 posterior draws per chain. This low number of posterior draws can lead to instability in the R-hat values and unreliable ESS figures for each of the 25 models (see Table S18). These diagnostic figures are misleading; they do not reliably indicate problems in the combined model.

To demonstrate that the model obtained from combining imputations is adequate, we follow a two-step strategy: first, in Figures S26, S27, S28 we show that estimated coefficients obtained using multiple imputations are very similar to those obtained with complete-case analysis. Thus, our conclusions do not rely on imputations; we would have reported the same findings dropping cases with missing values. The only difference worth mentioning explicitly is for M3 (giving exactly 0), where using imputation leads to a more precise identification of the effect of revelation, with 0, the no-effect value, outside the posterior 95% credibility interval. Because this is the experimental treatment, for which no value is imputed, we can be confident that the gain in precision is warranted rather than an artifact of imputation.

Second, we show that fit diagnostics for models based on complete-case analysis are adequate. These diagnostics are shown in Tables S11, S13, S15. M1, M2, M3 are fit using the main specification (see Tables 1). There were no post-warmup divergent transitions while fitting these models, and the R-hat and ESS values are mostly excellent. Only the values for within-Donor Revealed × Distance varying slopes suggest less-than-ideal fits-most likely because there is little heterogeneity at this level, as suggested by the 95% CI for the corresponding SD. Out of precaution, we did fit models without these random slopes, shown in tables S12, S14, S16. These latter models may seem preferable in terms of fit, but as outlined in SI P, removing within-donor slopes could lead to anti-conservative estimates for a parameter against which we test one of our hypotheses. O Unknown recipients

In NP (Nepal) and UP (India), we additionally invited participants to make allocations to unknown members of their community. The protocol was identical to the regular allocations, with the sole difference that the donor was shown a generic pictogram rather than a photo of the recipient, and told that the allocation would go to a randomly selected member of their community (see Fig S40). Each donor made one such allocation in the "anonymous" condition and one in the "revealed" condition. This was done in-app; the unknown alter was presented half-way through each block of regular allocations. We do not include allocations to unknown alters in the data used to fit the main models.

Table S19 shows the results of a simple model fit only to allocations to unknown alter. The results are consistent with our main findings: donors give more when their identity is revealed, even when the recipient is unknown. Model predictions suggest that the effect size is slightly larger, but of similar magnitude, to what we find in the regular allocations: participants in NP are predicted to give 2.9% [0.8%, 5.1%] more of the total endowment and participants in UP 4.0% [2.4%, 5.5%]. As with the regular allocations, we do not find a clear effect of donor centrality.

F Unexplained heterogeneity

We find large amounts of unexplained heterogeneity at the donor level, but not at the recipient level. This is true both for random intercepts and random slopes for the effect of revelation, see Figures S17 and S18. In other words, over and above centrality and distance effects, there are marked differences in how much individual donors give, and how acutely they respond to the effect of revelation. However, the same does not hold true for recipients: we do not find large amounts of unexplained heterogeneity at this level. Knowing who is making an allocation yields much better predictions than knowing to whom an allocation is being made. This is an important consideration for future research, which may do well to focus on donor characteristics when modelling amounts given in the Dictator Game.

G.5 NP

NP is a village in the Himalayan foothills of East Nepal. Residents engage in subsistence agriculture (staple crops: millet, corn, rice), but extreme levels of out-migration have left the community largely bereft of young people, without whom agricultural activity is receding. The community comprises a wide diversity of caste and ethnic groups, living in physically distinct parts of the village. Two Dalit communities are present, one of which is almost entirely landless and therefore particularly disadvantaged. Residents are mainly Hindu, though a young, Nepali form of syncretic Christianity is rapidly gaining ground. The district capital, a hilly town of approximately 50,000 inhabitants, is an hour's walk / 20-minute slow drive away on unpaved roads. Kathmandu is the closest city, some 4 hours' drive away. Ivan Deschenaux has been conducting fieldwork in the community since 2024, following earlier fieldwork elsewhere in East Nepal (Deschenaux, 2019).

The underlying demographic data were gathered between April and June 2024 and the network data in December 2024, with ethical approval from the London School of Economics and Political Science Research Ethics Committee (Ref. 326856 and 441059). Residency and other basic information were updated immediately prior to the experimental games data collection.

The experimental games data collection took place between 17 February 2025 and 7 March 2025. This was done under the direction of Ivan Deschenaux and Poorvi Iyer by a team of eleven research assistants.

G.6 UP

UP is a village in Kanpur district, Uttar Pradesh, India. Agriculture remains an important part of the local economy, with crops including wheat, maize and pulses. Residents also engage in agricultural and non-agricultural wage labour, private salaried employment and small-scale businesses. The village is well connected to a nearby town and the city of Kanpur, allowing residents to seek employment beyond the village, particularly in construction, factories, shops and other non-agricultural activities.

The village comprises a mix of caste and religious communities, with considerable differences in their economic and social positions. There is only one Dalit (Scheduled Caste) community in the village, which, alongside a religious minority community, is among the most economically disadvantaged. Both communities have limited access to agricultural land and rely more heavily on casual wage labour. Other caste groups are relatively better positioned in terms of landownership, business activities and employment opportunities, although economic differences also exist within these groups. In this village, caste remains central to the organisation of economic life and the social relations through which people interact with one another.

Komal Chauhan has been conducting fieldwork in this village since 2024, following earlier fieldwork elsewhere in Uttar Pradesh (Chauhan, 2022).

The underlying demographic data for UP were gathered between February and June 2024 and the network data in January and February 2025, with ethical approval from the London School of Economics and Political Science Research Ethics Committee (Ref. 326648 and Ref. 480486 respectively). Residency and other basic information were also updated immediately prior to the experimental games data collection.

The experimental games data collection took place between 26 April 2025 and 12 May 2025. This was done under the direction of Komal Chauhan and Poorvi Iyer by a team of 11 research assistants.

All sites In all sites, the comprehension checks covered: • Arithmetic: whether the participant could explain how much the donor and recipient would receive, given the initial endowment and a hypothetical allocation.

• Condition: whether the participant could distinguish the two game conditions, that is, explain the difference between the revealed and anonymous condition.

NP and UP only In addition to the above we also checked: • Condition, enhanced Rather than asking only whether participants could tell the two conditions apart, the participant had to demonstrate that they understood who would, and would not, come to know the identity of the donor in four hypothetical cases • Endowment: whether the participant understood that they had the full endowment available for every allocation, rather than a single endowment to be split across all decisions.

• Overall assessment: the research assistant's subjective judgement of the participant's overall comprehension.

Comprehension measures

For TE, AZ, TM, TZ, WH, and WL, participants were classified into two levels: • Fail.

The participant did not meet the lenient criterion on one or more dimensions: they gave incorrect answers even after repeated explanation, or the research assistant judged their overall comprehension to be very poor.

• Lenient. The participant passed every dimension, allowing for correct answers reached after additional explanation.

In NP and UP, we additionally recorded how much re-explaining and reprompting participants required to pass comprehension checks, adding the following categories: • Intermediate.

On every dimension, the participant answered correctly either immediately or after a single repetition, and the research assistant judged their overall comprehension to be at least partial ("understood everything well" or "understood some components").

• Strict. The participant answered every dimension correctly on the first attempt, with no repetition or additional explanation, and the research assistant judged their overall comprehension to be complete ("understood everything well").

Comprehension effects

Fig S32 and S33 show that including or dropping individuals who fall into the "fail" category, as described above, has no practical effect on estimated coefficients in the main models.

To assess whether the effect of revelation changes with the more granular levels of comprehension we have in NP and UP, we fit an ordered beta regression model with a three-way interaction between donor comprehension level, condition and site (NP and UP) in the predictors. Figure S34 shows the relative frequency of each comprehension level. Results are shown in Figure S35, which reveals a clear pattern for UP, where the effect is smaller and not clearly distinct from 0 for participants who fail comprehension tests or only pass the "lenient" level, and vastly stronger for participants who pass the "strict" level. The results for NP are less clear: the effect is larger and more clearly identified as non-0 for participants passing the "strict" and "intermediate" checks than those only passing the "lenenient" one. However, surprisingly, the effect is strongest for participants who fail comprehension checks outright. Despite this unexplained pattern in NP, we believe these results provide some justification for using granular comprehension tests rather than simple binary ones, when conducting experimental games in remote settings such as those where this study was conducted.

N Repeated measures within participant

Our design called on participants to make multiple allocations in rapid succession, across two conditions. We do not formally test whether participants developed fatigue, anchored to past decisions, or otherwise displayed changing patterns of behaviour over time. The plots included here are meant to offer only a general overview of the possible effects of time and repeated measurement on allocations. Figure S36 suggests that there was no overall increase or decrease in generosity over time, except in TZ, where participants appear to have given less, on average, during later decisions. In addition, S37 suggests that a similar pattern may have occured within each condition block in WL.

Figure S38 shows that in most sites, participants showed decreased variation in their allocations as time went by (e.g., the SD for a participant's first five allocations is higher than for allocations 2 to 6, 3 to 7, etc.). Finally, S39 shows the average autocorrelation, across participants, for different lags.

These patterns would be a cause for concern if the order in which participants saw recipients was correlated with the predictors we test hypotheses against, but this is not the case. Donors saw participants in a randomised order, such that the possible effects of time do not threaten the findings we report.

P Models with and without random slopes for Condition x Distance

The main models allow Condition × Distance to vary by participant. In reality, there seems to be very little heterogenity at this level: participants do not seem to differ markedly in how their sensitivity to condition varies with distance (see SD, Rhat and ESS values in Tables S11, S13, S15). Typically, this would be sufficient justification for removing the model parameter that allows Condition × Distance to vary by participant, but Figure S41 shows that doing so can lead to anti-conservative estimates for the corresponding population-level parameter. Because we test H3 precisely against this population-level parameter, we have opted to keep the Condition × Distance random slope in the model.

Q Robustness check: STRAND multiplex models

As a robustness check on the ordered beta regression (ordbetareg: Kubinec, 2023) pipeline in brms (Bürkner, 2018), we use a standard multiplex social relations model (Ross et al., 2025) to analyse the same raw data processed so as to be represented as binomial counts: where K = 10 is the maximum allocatable amount, and respondents' donations are expressed as units between 0 and K. In this case, we model-simultaneously-two networks of directed ties: anonymous flows in one layer, and revealed flows in another. The model structure is similar, but not identical, to the one used in the main text. The covariates we include are the same as in the main model. However, we include correlated random effects for donor, recipient, and dyad. These random effects are slightly different than those used in the main model. As in the main text, STRAND models estimate layer-specific random effects, but STRAND explicitly estimates the correlations in these random effects within and between layers. The downside of the STRAND models is that we must fit each site separately (so we have no partial pooling), and there is less flexibility in terms of the outcome distribution (though the binomial outcome distribution is not unreasonable).

Results are plotted in Figure S42. We recover the same general conclusions as in the main model. Most notably, there is a negative effect of distance on giving in most sites, and there is a positive effect of revelation in most sites. As in the main model, the STRAND models fail to recover appreciable interactions between revelation and distance or centrality.
