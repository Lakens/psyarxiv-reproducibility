How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Full text

Abstract

Personal optimism is widespread. This research provides cross-cultural evidence for collective pessimism. Across four pre-registered experiments in 40 countries (N = 52,508), people believed it is much more likely that a future dystopian society will materialize than a utopian society. Dystopian predictions were driven not by internal attribution, but by asymmetric external attribution: People believed political leaders in society can exert greater influence on dystopian than utopian world development, and high leader impact was correlationally and causally linked to higher scenario likelihood. Text-based analyses revealed that participants named a political leader nearly twice as often in dystopias than utopias, and such personalized dystopias were considered more likely. Dystopian predictions were stronger among left-leaning individuals and in rich democracies, yet generalized across ideologies and world regions.

Introduction

Humans are prospective creatures (1) (2) (3), and individuals across the world tend to be remarkably optimistic about their own future. In one 16-country survey, 89% of the participants expected their personal lives to improve over the next five years (4). Yet, when asked about society as a whole in a different survey, only 35% expected global living conditions to improve (5). This asymmetry matters because future-oriented thinking, or prospection, shapes well-being (6, 7), cooperation (8, 9), moral decision-making (10, 11), collective action (12, 13), and politics (14, 15), and because political movements increasingly mobilize voters around narratives of societal decline (16).

Research in psychology and behavioral science has focused almost exclusively on individual prospection. Here we study collective prospection (17, 18), focusing on how people judge the likelihood that a future utopian or dystopian society will one day come true, and what drives those predictions. We test whether people across 40 countries covering all world regions consider a dystopian future more likely than a utopian one, and whether this asymmetry reflects how people attribute societal outcomes to political leaders.

Research on individual prospection typically finds personal optimism. For instance, people commit the 'planning fallacy' by underestimating the required time and resources needed to complete future tasks (19, 20). They also overestimate the probability of positive life events and underestimate their own risk of negative events (21) (22) (23). Optimism persists even under explicit instructions to be realistic, because best-case scenarios come first to mind and crowd out worst-case alternatives (24). Personal optimism is driven by a combination of cognitive and motivational processes (for reviews, see (25, 26)), and critically, is often rooted in internal attribution: People are more optimistic about future events they believe to be largely under their own control (27, 28). There are exceptions from personal optimism (29), whereas the most relevant one for the current research is that people tend to shift towards pessimism for important events considered to be beyond their control (30).

Far less is known about the balance between optimism and pessimism when people consider the collective future of society as a whole. To our knowledge, no large-scale crosscultural experiments have examined the perceived likelihood of utopian versus dystopian societies. The few existing studies point toward society-level pessimism rather than optimism. People are roughly twice as likely to predict economic decline for their country as for themselves (31). Whereas positive events come to mind first and are judged more likely in individual prospection (24, 32, 33), one study found the reverse fluency pattern for collective prospection (34), in which participants generated negative future societal events more readily than positive ones. Importantly, that work assessed the fluency of event generation, not optimism versus pessimism in the form of likelihood judgments, and it was conducted in a narrow cultural context (the United States and Canada). Whether people globally believe a dystopian future is more likely than a utopian one, and why, currently remains unknown.

Our primary hypothesis (H1), predicting collective pessimism, is that people across the world will judge a dystopian society as more likely to come true than a utopian society. Second, we propose that this type of pessimism is rooted in how societal outcomes are attributed, as people might believe that political leaders are capable of exerting greater influence on dystopian than utopian world development (H2).

As our theoretical framework for these pre-registered hypotheses, we combine two mechanisms: The negativity bias in human psychology and asymmetric leader attribution. First, the negativity bias refers to a general principle in which "bad is stronger than good" ( (35); see also (36)), meaning that negative information, life events, and experiences have greater impact than the positive equivalent on a range of outcomes, including attention, emotion, first impressions, learning, memory, romantic relationships, and moral judgment. It is currently unclear, however, if and when the negativity bias applies to prospective thinking. Whereas research on individual prospection tends to find personal optimism, reflecting a positivity bias, we suggest that in collective prospection, the negative dimension will dominate the likelihood judgment.

Second, we propose that attributional inference, meaning how ordinary people explain the internal versus external causation of events (37), plays a key role in this type of future thinking (27, 28). Specifically, when the future in question is society's rather than one's own, the outcome should feel less tied to one's own intentions and actions, thereby removing the self-attributional basis for optimism. An external force we consider especially important in this context is the top-down impact of political leaders. The "side-effect effect" documented by experimental philosophers shows that people are more willing to attribute harmful than helpful outcomes to the intentional agency of leaders (38), suggesting an asymmetry in how outcomes are linked to powerful agents. In that paradigm, participants read about a situation where the outcome was known and had already occurred, and then judged whether the agent brought it about intentionally. We propose a prospective extension of this mechanism, operating forward in time on society-level beliefs, where the prediction of future worlds will follow a similar leader-driven asymmetry. We tested these hypotheses in four pre-registered experiments across 40 countries (total N = 52,508), where participants were randomly assigned to imagine a utopian or dystopian society before making identical likelihood judgments. In Experiments 1, 2, and 3, people evaluated the likelihood of future scenarios generated and written by themselves. In Experiment 4, people evaluated fixed and content-symmetric scenarios written by the research team based on common themes identified in the participant-generated scenarios in Experiments 1 and 2. The leader-attribution mechanism was tested using both observed mediation (Experiments 1 and 2) and experimental manipulation of the mediator in a causal-chain design (Experiments 3 and 4). Beyond the primary hypotheses, we examined whether self-generated dystopias are more often personalized around specific political leaders than utopias and whether such personalized dystopias are judged more likely; explored variation in dystopian predictions across individual-level political ideology and country-level wealth and democracy; and identified the most common themes in self-generated utopias and dystopias. The data collections were conducted in the following time periods: November 28th 2024-February 28th 2025 (Exp. 1); May 12th 2025-June 21st 2025 (Exp. 2); March 30th 2026 (Exp. 3); and March 31st to April 13th 2026 (Exp. 4).

We report the main findings from each experiment below. The full method description, and all secondary analyses and figures, are provided at the end of this document (Supplemental Materials).

Results

Experiment 1. Participants (N = 767) from four culturally diverse countries (India, Mexico, South Africa, and USA, see Table S1) were randomly assigned to imagine and write about either their utopian or dystopian future society, meaning the best possible or worst possible world or society they could think of. They were then asked to rate the likelihood of this scenario to materialize, and attribute its realization to (a) political leaders, (b) oneself, and (c) chance (good or bad luck) (all scale formats: 0-10). These four samples were fairly representative in terms of gender and ethnicity, except India. U.S. participants were also representative in terms of educational attainment and political ideology.

Consistent with the collective pessimism hypothesis (H1), a Welch's t-test revealed that participants thought their future dystopia was more likely to occur than their future utopia, M = 5.98, SD = 2.67 vs. M = 3.39, SD = 2.96, t(760.09) = 12.71, p < .001, d = .92, bootstrap 95% CI [.76, 1.09]. The effect was large and consistent both across and within each of the four countries (see Text S1, Figures S1 and S2, Table S2).

Providing initial evidence for our proposed mechanism (H2), participants believed that political leaders can exert greater influence on dystopian than utopian world development, M = 8.17, SD = 2.17 vs. M = 6.85, SD = 2.99, t(706.07) = 7.01, p < .001, d = .50, bootstrap 95% CI [. 36, .64]. Moreover, exploratory analyses showed that this asymmetric leader attribution correlationally mediated the main effect of condition on likelihood judgment, as higher leader attribution was indirectly associated with higher scenario likelihood, b = .27, 95% CI [.15, .41], SE = .07, z = 4.08, p < .001.

Regarding our other potential mechanisms, the utopia and dystopia conditions did not differ in attribution to luck, M = 3.87, SD = 2.98, vs. M = 3.61, SD = 2.79, t(763.43) = -1.24, p = .214, d = -.09, bootstrap 95% CI [-.23, .05], but participants attributed greater influence to their own actions in bringing about their utopia than their dystopia, M = 4.73, SD = 3.00, vs. M 4.28, SD = 3.14, t(765) = -2.05, p = .040, d = -.15, bootstrap 95% CI [-.29, -.01]. However, we observed no significant mediational effects of scenario likelihood via attribution to self or chance (ps > .09, Text S2, Figure S3), meaning that leader attribution was the only significant mediator. Exploring political ideology, a multilevel moderation analysis found that the dystopian dominance in likelihood judgment was significantly stronger among left-leaning than right-leaning individuals, b = -.39, 95% CI [-.57, -.22], robust SE = .09, p < .001, but the dystopian main effect was statistically significant throughout the left-right political spectrum except for the far right end, i.e., ≥ 9.32 (maximum possible score 10; Figure S4).

Experiment 2.

This study was a cross-cultural test of our primary hypotheses, enabling a broader test of robustness and generalizability across large participant samples (N per country > 1,000) from 40 countries (total N = 47,719), which were broadly representative with respect to age, gender, and political orientation, see Table S3. We also leveraged this experiment to conduct a text analysis of how often a political leader was mentioned in the dystopias and utopias people wrote about, and which specific leaders were mentioned most often.

Consistent with the collective pessimism hypothesis (H1), multi-level regressions with random intercepts and slopes revealed that participants thought their future dystopia was significantly more likely to occur than their utopia, M = 5.49, SD = 2.82 vs. M = 3.76, SD = 3.23, b = 1.83, 95% CI [1.48, 2.17], t(39.13) = 10.37, p < .001, see Figure 1, Panel A, Table S4. This effect was statistically significant in the predicted direction in 35/40 countries, nonsignificant in one, and reversed in four (see Figure 1, Panel B).

Consistent with our proposed attribution mechanism (H2), participants in this global sample also believed that political leaders can exert significantly greater influence on dystopian than utopian world development, M = 6.93, SD = 2.71 vs. M = 5.61, SD = 3.20, b = 1.37, 95% CI [1.12, 1.61], t(39.11) = 10.83, p < .001 ( also see Table S4), which again correlationally mediated the main effect of condition on perceived likelihood, b = .36, 95% CI [.29, .43], SE = .04, z = 10.15, p < .001). The dystopian dominance in likelihood judgment was significant across both sides of the political spectrum, but the magnitude was weaker for politically rightleaning individuals (multilevel moderation effect: b = -.31, 95% CI [-.34, -.27], p < .001; see Figure S5). In contrast to Experiment 1, participants in the dystopia and utopia conditions did not significantly differ in their own perceived ability to influence whether their scenario would come true, M = 4.53, SD = 2.99, vs. M = 4.44, SD = 3.11, b = .12, 95% CI [ -.06, .31], t(39) = 1.28, p = .199, also see Table S4. Luck attribution was not measured in Experiment 2, given its non-significant effect in Experiment 1. Exploring the role of country-level factors as potential moderators of the collective pessimism effect, the tendency to predict that a future dystopia is more likely than a future utopia was on average stronger in high-GDP than low-GDP countries, b = .57, bootstrap 95% CI [.28, .86], bootstrap SE = .14, pHolm = .017, and countries scoring high versus low on the Human Development Index (i.e., a composite measure of average achievement on health, education, and living standard), b = .87, bootstrap 95% CI [.66, 1.10], bootstrap SE = .12, pHolm = .016, see Figure S6, Table S5. These findings challenge the interpretation that dystopian predictions are merely a natural extension of difficult present realities.

Next, we conducted a text analysis of the leaders that participants mentioned in the different scenarios they wrote about. We provide general findings here; see Figure S7, Table S6 for a detailed overview of country differences, and these can be further explored using our https://dystopia-utopia.shinyapps.io/country/. A binomial general linear mixed model (random intercept and slope by country) showed that participants were far more likely to name at least one leader in the dystopia than the utopia condition, OR = 2.02, 95% CI [1.73, 2.35], z = 9.00, p < .001 (see Figure 2, Panel A). Moreover, a linear mixed model (random intercept by country, controlling for condition) showed that naming at least one leader was associated with a higher scenario likelihood judgment, b = 0.58, 95% CI [0.52, 0.65], t(47,700) = 18.76, p < .001 (see Figure 2, Panel B). Donald Trump dominated leader mentions in both conditions, and was included approximately four times as often in dystopian than utopian scenarios (see Figure 2, Panel C; Table S7 for statistical tests, Text S3 for additional details). Vladimir Putin ranked second in both conditions, and showed a similar excess of mentions in dystopian scenarios. Participants' political ideology significantly moderated the difference in Trump mentions between conditions, but not the difference for Putin (see Text S4, Table S8 and Figure S8): The more right-leaning participants were, the smaller the excess of Trump mentions in the dystopia relative to the utopia condition. However, the two prevalences converged only at the extreme right-wing end of the scale (participants scoring 7 on the 1-7 scale, ≈5% of the sample), where their 95% confidence intervals overlapped. In addition, we explored the most common ideological profiles of named leaders, see Text S5, Tables S9 and S10 for details. Finally, topic modeling provided insights into what people envisioned when describing their dystopia or utopia. After topic reduction, we identified 15 distinct topics in the dystopia and 14 in the utopia condition, see Figure 3, Table S13 for details. Interestingly, leaders including Trump and Putin emerged as their own topic cluster in dystopian but not utopian visions. For country variation in topics, see Table S14, Figures S16 and S17, for political orientation variation in topics, see Figures S18-S20. For associations between relative topic prevalence and likelihood judgments, see Table S15, Figure S21. Experiments 3 and 4. Our observational mediation results from Experiments 1 and 2 suggest that the likelihood judgment of a future societal scenario is partly a function of political leader attribution. To isolate the leader attribution mechanism, we moved beyond the correlational approach and conducted two final studies experimentally manipulating the mediator in a 2 × 2 design, in Experiments 3 and 4. This design permits testing our proposed explanation as a causal-chain model (Dystopia vs. Utopia → Leader attribution → Scenario Likelihood), and is considered a superior approach to mechanism evidence in psychology (e.g., (39)). Observed mediation infers the mediator-to-outcome path from association alone, under strong assumptions about causal direction and no confounding. Experiments 3 and 4 provide the missing experimental test of that path.

We predicted that random assignment to high (vs. low) perceived impact of political leaders would lead to higher subsequent likelihood judgments for their given scenario coming true. Whereas Experiment 3 relied on self-generated scenarios, a final extension is that Experiment 4 introduced fixed and topic-symmetric scenarios between conditions, to rule out the possibility that the main effect and mediation findings in Experiments 1 and 2 were due to participants thinking about utopias and dystopias in different domains. Both final experiments were conducted in general population online samples from the United States, which were representative with respect to age, gender, and ethnicity.

In Experiment 3 (N = 2,029, see Table S17 for details), participants generated their own utopian or dystopian scenarios as before, but were then asked to think about a specific political leader while doing so or given no such leader instruction, in a 2 (scenario: utopia vs. dystopia) × 2 (leader salience: present vs. absent) between-subjects design. Discussion

The nature of dystopian and utopian worlds has been richly portrayed in classic literature, film, and modern TV series, suggesting they play a prominent role in human imagination. How most people actually think about such alternative societies has received less attention in psychology and the behavioral sciences. In the current research, we provide global evidence of the content, drivers, and perceived likelihood of dystopian versus utopian societies.

Whereas research on individual prediction tends to find personal optimism, the current research reveals pervasive collective pessimism: Data from four pre-registered experiments in 40 countries (N = 52,508), found that people assessed a future dystopian society as significantly more likely than a utopian one. This tendency was substantial, and persisted across both self-generated and fixed scenarios, appearing in 35 of the 40 countries. Furthermore, self-generated dystopias were about twice as likely as utopias to be personalized around a specific political leader. In terms of the mechanism, we found both observed mediation and experimental causal-chain evidence supporting our proposed explanation of asymmetric leader attribution: People believe that political leaders in society can have a greater impact on dystopian than utopian world development, and this belief is one important driver of the dystopian dominance in collective prediction.

The theoretical implications of this research emerge along three distinct lines. First, they delineate a boundary condition for the extensively documented optimism in individual prospective thinking. Specifically, when the anticipated future pertains to society at large rather than personal circumstances, a negativity bias appears to supersede such optimism. This observation expands the psychological axiom that "bad is stronger than good" (35) into the domain of collective future cognition. Second, the research extends attribution theory (37). The asymmetry that links harmful "side-effect" outcomes more to powerful agents than helpful outcomes (38) has been studied for outcomes that have already occurred. We show that it also shapes predictions about future societies that do not yet exist. Third and finally, the results invite the possibility that personal optimism and collective pessimism are mirror images of an identical attributional logic: While individuals may perceive themselves as largely controlling their own futures, we find that they view the collective future as dependent on powerful external actors who are presumed to cause more harm than good.

We must consider alternative interpretations. The prevalence of dystopian narratives may stem from a structural asymmetry rather than inherent pessimism. Whereas a utopia may demand simultaneous perfection across all variables, a dystopia may for some people require only partial failure. Experiment 4 speaks against this hypothesis, as participants rated the dystopian scenario more than twice as probable even when content domains were controlled and only valence differed. Disproportionate exposure to negative news may well contribute to the baseline asymmetry in likelihood judgment, but it cannot explain the attributional pattern we also observed. In our view, a media-exposure account does not predict that randomly assigning people to perceive high leader influence would raise likelihood judgments. It also does not predict that this manipulation would work equally for utopian and dystopian scenarios, as it did in Experiments 3 and 4.

Several limitations persist. Although our samples covered all global regions, they relied on online panels rather than fully representative populations and underrepresented African countries; the causal tests of the leader-to-likelihood pathway (Experiments 3 and 4) were restricted to the United States; and our methodology assessed beliefs about extreme hypothetical futures rather than calibrated forecasts. Notably, the dystopian prediction effect was absent or reversed in a small, yet populous subset of nations in Experiment 2, including India and China. For India, this contrasts with Experiment 1, where the effect was significant in a smaller sample. Because that Indian sample was less representative in age, gender, and ethnicity than the sample in Experiment 2, we regard the larger and more representative Experiment 2 estimate as the better guide, and treat the Indian result as unsettled. Generally, the observed variation does not undermine the generalizability, but aligns with our moderation findings: Collective pessimism was found in most countries, but it peaked in wealthy and established democracies, and waned or even reversed in contexts where recent lived trajectories rose sharply, suggesting that dystopian predictions are not merely an extension of adverse present conditions.

The cross-cultural findings issue a cautionary note for liberal democracies. It was within affluent, democratic nations that collective pessimism proved most acute. Consequently, political campaigns leveraging stories of societal decay may encounter considerable support in these contexts (16), particularly amid a decade of documented global democratic decline (42, 43). When the public perceives dystopian outcomes as more probable than utopian ones and attributes asymmetric power to actualize them to political leaders, believable optimism regarding our collective future becomes a rare commodity. Thus, presenting plausible and positive societal visions may hold equal significance for sustaining democracy as highlighting the dangers of democratic decline.

At a broader level, this paper shifts the analytical focus of prospection research from the individual person in a single cultural context to collective cognition, at societal scale across the world. The results indicate that a global majority express collective pessimism by predicting that a dystopian future is more likely than a utopian future, and consider the asymmetric impact of political leaders to be one important part of the explanation.

Materials and Methods Experiment 1 Materials and Method

Participants and Sensitivity Analysis

After obtaining informed consent, a total of 803 participants (i.e., nIndia = 200, nMexico = 200, nSouth Africa = 202, nUSA = 201) took part in the experiment. Sample size was determined apriori based on financial constraints. Participants were representative in terms of sex for all countries and ethnicity for all except India. US participants were also populationrepresentative in terms of educational attainment and political ideology. After excluding those who had failed an attention check as pre-registered (n = 23), as well as those who did not follow the instructions (n = 12) or used AI models for answering (n = 1)foot_0 , we retained a final sample of 767 participants.

A sensitivity analysis in G*Power (Version 3.1, (44)) revealed that in a two-tailed independent samples t-test with an alpha level of .05, the achieved sample for the two groups provided 80% power to detect a Cohen's d effect size of ≥ .20. Based on the same parameters, the 2x4 ANOVA could detect a condition main effect (dfnumerator = 1) of approximately f = .10, corresponding to ηₚ² = .01. For the country main effect and the interaction effect (both dfnumerator = 3), the minimum detectable effect was approximately f = .12, corresponding to ηₚ² = .01. For exploratory moderation analysis, a sensitivity analysis, N = 767, α = .05, indicated our experiment had 80% power to detect interaction effects as small as f² = .01.

Procedure

The hypotheses, method and analytic procedures were pre-registered prior to data collection at: https://doi.org/10.17605/OSF.IO/Q7P3F. After ethics approval from the internal review board at the University of Oslo (Reference number 30444004), data were collected via the panelist provider Prolific between November 28th 2024 and February 28th 2025. To be eligible, participants had to be aged eighteen years or above, be fluent in English and reside in one of four countries: India, Mexico, South Africa, or the USA.

The experiment took place on Qualtrics. Each one half of the participants per country were randomly assigned to the utopia and the other half to the dystopia condition. Those assigned to the utopia condition were instructed to imagine their best imaginable future society or world. They were then cued to write a minimum of about 100 words about what their vision entailed and what made it utopian. Those in the dystopia condition received the equivalent instructions but focused on their worst imaginable future society or world (see Text S6 for instructions).

Measures

Manipulation Check. After having described their utopia or dystopia, participants' state utopian thinking (e.g., "At the moment, I have an idea of what the ideal society might look like."; r(765) = .59, p < .001) and state dystopian thinking (e.g., "At the moment, I have an idea of what the worst imaginable society might look like."; r(765) = .60, p < .001) were assessed with two items each that were measured on Likert scales ranging from 1 (strongly disagree) to 7 (strongly agree).

Probability Judgement. Participants filled out one item measuring the likelihood of their experimental condition (i.e., utopia/dystopia) to occur (i.e., "How likely do you think it is that such a [utopia/dystopia] will ever happen?" ; 0 extremely unlikely to 10 extremely likely).

Attribution Measures. Participants also completed three single-item attribution measures regarding the realization of their utopia/dystopia: 1) attributed internal control (i.e., "To what extent do you think your own actions can affect whether such a [utopia/dystopia] will happen or not?"), 2) attributed political leaders' control (i.e., "To what extent do you think that political leaders in society can affect whether such a [utopia/dystopia] will happen or not?"), and 3) attributed role of luck (i.e., "To what extent do you think it is a question of luck vs. unluck (random events) whether such a [utopia/dystopia] will happen or not?"). Responses were scored on Likert scales ranging from 0 (not at all) to 10 (very much).

Demographics. We assessed age, gender, marital status, citizenship, religious affiliation, migration background, education, and employment status. Furthermore, political orientation was measured in three distinct ways: 1) on an 11-point scale, progressing from 0 (far left) to 5 (center) to 10 (far right), 2) on a slider asking participants to indicate their political orientation regarding social issues, e.g., race relations, gender roles, from0 = liberal to100 = conservative, and 3) on a slider asking participants to indicate their political orientation regarding economic issues, e.g., taxes, public spending, again ranging from0 = liberal to100 = conservative.

Data Analysis

The analyses were conducted in two phases. In Step 1, we tested our pre-registered hypotheses via t-tests, Welch's tests where homogeneity assumptions were violated, and 2 (utopia vs. dystopia) x 4 (country) Analyses of Variance (ANOVA). In Step 2, we ran exploratory analyses to tease out additional, non-pre-registered patterns. To do so, we assessed moderation of the hypothesized effects by political orientation. Additionally, we conducted multi-group parallel-mediation analyses to examine whether the experimental effect on likelihood was mediated by our three attribution measures (i.e., internal control, political leaders' control, and luck).

Participants who did not follow the task were manually excluded via Excel. All other analyses were conducted in R (version 4.5.2, ( 45)) via the R Studio interface. Moderation analyses were performed with multi-level models (participants nested within countries) using lme4 (46) and lmerTest (47). Johnson-Neyman plots were generated via the interactions package (48). For multi-group parallel mediation analyses, lavaan (49) was used. Graphics were created via ggplot2 (50). To ensure accessibility, colorblind-friendly palettes were applied. For effect size calculations, effsize (51) and effectsize (52) were utilized. Finally, residual bootstrapping to account for issues of normality and to provide more robust confidence intervals was conducted using boot (53), whereas wild bootstrapping to account for cases of heteroscedasticity was executed using twowaytests (54) for the ANOVAs and lmeresampler (55) for the moderation analyses.

Main Analysis.

Leader Classification.

Before any machine learning, every free-text answer passed through a language-agnostic cleaning pipeline. Honorifics such as "Prime Minister" or "Pres." were stripped with a regular expression; excess white-space and punctuation were normalized; for Latin-script strings only, letters were transliterated to ASCII with unidecode, while Chinese, Cyrillic and other non-Latin scripts were left intact. A second expression split multi-name strings on commas, slashes or the word "and" in fifteen languages. The langdetect package v. 1.0.9 (61)) then attempted to identify the interface language, returning "unknown" for very short strings. Literal placeholders such as "none", "不知道" or "없음" were mapped to an id_status code of no_input, and a set of survey-instruction fragments in East-Asian languages was deleted.

After this stage the data comprised 18,189 candidate strings: 62.8 percent were ultimately identified as valid leader names, 33.3 percent remained unidentified, and 3.9 percent contained no processable input.

Canonicalization relied on the GPT-4o-mini model served through the OpenAI v1.68.2 API. For every unique cleaned string an asynchronous call requested a single JSON object containing an English name, a Wikidata Q-ID, and a confidence score from zero to one. The prompt included the respondent's ISO country code and detected interface language so that, for example, "总统习近平" from a Chinese respondent resolved to "Xi Jinping." We accepted returned names whose confidence was at least 0.80. Any lowerconfidence variant was fitted against the high-confidence list with RapidFuzz; a similarity of ninety or above replaced the variant with its already accepted counterpart.

To merge near-duplicates that nonetheless survived canonicalization, the accepted names were embedded with sentence-transformers (all-mpnet-base-v2) and clustered using DBSCAN with a cosine-distance threshold of 0.12. Each cluster received an integer ID, and singletons took an ID above one hundred thousand. The cluster lookup was merged back into the full long file.

We also explored whether our macro-level indicators moderated the effects of our experimental conditions on likelihood judgment and leader attribution. Taxonomic Political Leader Differences

Every unique leader name with a non-negative cluster ID was classified on three ideological dimensions by GPT-4o-mini, strictly following the rubric below: If a leader fits multiple categories, choose the most prominent. If info is insufficient, output "NA".

The model returned valid JSON containing a one-to-five social political score (from 1 very liberal to 5 very conservative), a one-to-five economic political orientation score (from 1 very liberal to 5 very conservative), and an eight-category taxonomic class (79), or "NA" if confidence fell below fifty percent.

The automatic political orientation scoring was validated by three human experts who rated sixty-five randomly sampled leaders on the same five-point social and economic scales. Their mutual reliability was α = 0.88 for social and 0.74 for economic. The correlation between the averaged human ratings and GPT scores reached .88 on the social dimension and .70 on the economic dimension, both statistically significant at p < .001. For the categorical taxonomy, two separate coders classified seventy leaders. Using Fleiss PABAK the within-human agreement ranged from .54 to .91 across the eight classes, and the machine-human agreement ranged from .77 to 1.00.

With the classified data, we conducted three tests comparing the political orientation of the leaders mentioned in the two conditions. We first tested for the taxonomy by Gunther and Diamond (79). As displayed in Figure S11, the rank of the first three categories was the same in both conditions, with nationalist mass-based leaders mentioned most often, followed by electoralist and socialist mass-based leaders. Direct comparisons were then conducted between the two conditions using the same statistical approach as for leader names. Extreme right, elite-based, and nationalist mass-based leaders were more likely to be mentioned in the dystopian condition, see Table S10. Electoralist, religious mass-based and leftlibertarian leaders were more likely to be mentioned in the utopia condition. No significant difference was observed for socialist mass-based leaders.

Exploratory tests showed that the effect of condition interacted with participants' political orientation (see Table S11, Figure S12). Specifically, the more conservative participants were, they less likely they were to mention electoralist and social mass-based leaders in the utopia condition and somewhat more likely to mention them in the dystopia condition. By contrast, the more conservative participants were, the more likely they were to mention extreme-right and nationalist mass-based leaders in the utopia condition and the less likely they were to mention nationalist mass-based leaders in the dystopia condition.

Again based on cross-national analyses presented in the Shiny App (https://dystopia-utopia.shinyapps.io/country/), under the utopia condition, nationalist massbased leaders were the clear front-runners, topping the list in 29 countries and placing second in nine. The secondary category in the utopia condition was electoralist / mediadriven leaders, which held the first spot in eight cells and came in second in 23. In the dystopia condition, nationalist mass-based again led overwhelmingly, ranking first in 37 cells and second in three (i.e., they were in the top two dystopia mentions for every country). The next most cited category was socialist mass-based, which was first in two countries and second in eight.

Details About the ANOVA Results for Experiment 1

To test whether the main effect differed across countries, as pre-registered, we conducted a 2 (Condition: Utopia/Dystopia) x 4 (Country: India/Mexico/South Africa/USA) ANOVA for likelihood judgment. The results indicated a significant main effect of Country (F(3, 759) = 15.10, p < .001, bootstrap p < .001, η²p = .06, bootstrap 95%CI [.03, .10]) and Condition (F(1, 759) = 172.46, p <. 001, bootstrap p < .001, η²p = .19, bootstrap 95%CI [.14, .24]). No significant interaction effect between Country and Condition was found, F(3, 759) = 1.53, p = .205, bootstrap p = .176, η²p = .01, bootstrap 95%CI [.00, .02]. Post hoc testing using Tukey's HSD showed that across all countries, participants in the dystopia condition scored 2.59 points higher on the likelihood judgment scale than participants in the utopia condition, 95%CI [2.20, 2.98], pTukey < .001. Furthermore, there was a significant difference in likelihood judgment between all countries (all ps < .01), except for South Africa and Mexico (p = .999). The biggest mean difference occurred between the USA and India with American participants scoring on average 1.89 points lower on the likelihood judgment scale than participants from India, 95%CI [-2.61, -1.17], pTukey < .001.

Details About the Mediation Analyses for Experiment 1

We ran an exploratory multi-group parallel mediation using structural equation modeling to determine whether the effect of condition on likelihood was mediated via our three attribution judgments. Participants were grouped by country (i.e., India, Mexico, South Africa, USA). We used the maximum likelihood estimator and applied bootstrapping with 5,000 re-samples.

We first ran an unconstrained model, allowing all parameters to be estimated freely across countries. Next, we constrained each path separately to test differences in model fit using Wald tests. When constraining path b3 (i.e., the path from luck to likelihood), a Wald test showed model fit was significantly worse compared to the baseline model (p = .049), indicating differences between countries for this path. Constraining any of the other paths did not significantly worsen model fit (all ps > .05), suggesting no significant difference between the countries for these paths. Therefore, in the final, partially constrained model, we allowed path b3 (i.e., luck to likelihood) to vary freely across countries, but constrained all other paths. This partially constrained model was not inferior to the fully unconstrained model (Δχ2(18)= 19.05, p = .389) and showed very good fit (χ2(18)=19.05, p = .389, RMSEA = .017, CFI = .998, TLI = .995, SRMR = .035). Neither self attribution nor luck mediated the relationship between condition and likelihood, see Figure S3. The total indirect effect of condition on likelihood was significant in the USA (β = .04, b = .20, 95% CI [.01, .39], SE = .10, z = 2.03, p = .042), but not in India, Mexico, or South Africa (all ps > .05). The total effect of the condition on likelihood judgment was positive and significant for all countries (all ps < .001, βs >. 46).
