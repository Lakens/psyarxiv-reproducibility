Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

Metacheck does not yet analyze automatically whether sentences which include non-significant p-values are correct, but we recommend manually checking the sentences below for possible misinterpreted non-significant p values.

p = 0.170 A repeated-measures correlation accounting for multiple awakenings within participants revealed no significant association between thought and perception ratings (r = -0.149, p = 0.170).

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

This module checks whether the data columns in a repository are documented in a codebook or README. How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Checking code requires downloading its file contents. For a paper whose repository is on Dryad, this never succeeds unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (listing the repository’s files does not need one). Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Full text

Abstract

Previous studies on the neural correlates of dreaming using high-density EEG (hdEEG) and the serial awakening paradigm have identified posterior brain regions related to dreaming, with maximal activity over occipital areas. Here, we first aimed to extend these findings by examining EEG activity associated with dreaming during N2 sleep in a larger sample and using improved analytical methods. Second, we investigated whether EEG activity was associated with continuous ratings of perceptual and thought-related experiences. We have applied hdEEG (256 electrodes) with source localization and the serial awakening paradigm in N2 sleep of 39 participants to study the neural activity during different time windows preceding each awakening. We found that having a conscious experience with recall (CE) compared to no experience (NE) is related to increased beta/gamma frequencies in a widely distributed part of the cortex, with peak T-values in posterior occipital-temporal regions in the longer time window (30 s), and in parietal regions in the shorter time window (20 s).

Exploratory regression analyses revealed significant associations between EEG activity and thought-related experience, but not perceptual experience. These findings highlight the need to distinguish between the neural correlates of different dimensions of dream experience and to investigate their temporal characteristics and variations across sleep stages.

INTRODUCTION

The question of how subjective experience arises from brain activity remains central to the cognitive and neuroscientific investigation of consciousness. Dreaming offers a unique opportunity to address this question, as it represents a spontaneously occurring form of conscious experience, largely decoupled from overt voluntary behaviour and unresponsive to external stimuli (Nir and Tononi 2010). Over the past decade, research using high-density electroencephalography (hdEEG) during sleep has shed new light on the neural correlates of dreaming, notably identifying specific cortical regions and frequency bands associated with the presence or absence of conscious experiences during sleep (Perogamvros, Baird, Seibold et al. 2017 , Siclari, Baird, Perogamvros et al. 2017 , Sterpenich, Perogamvros, Tononi and Schwartz 2020).

A seminal contribution to this field was a study (Siclari, Baird, Perogamvros et al. 2017) that used serial awakenings in 32 healthy participants combined with hdEEG source localization to compare periods preceding conscious experience reports (conscious experience, CE) and no-experience reports (no experience, NE) during the 20 seconds preceding the awakening. A 'posterior hot zone' -covering bilateral parietal and occipital cortices -was identified, characterized by decreased low-frequency power (1-4 Hz) and increased high-frequency power (20-50 Hz), and was reliably linked to the presence of both NREM and REM dreams.

More specifically, dream-related regions included the medial and lateral occipital lobe, but also the precuneus, the posterior cingulate gyrus and retrosplenial cortices. This, as well as previous (Solms 1997), and following papers (Tononi, Boly and Cirelli 2024 , Tononi, Albantakis, Barbosa et al. 2025 , Selte, Haworth, Vanasse et al. 2026), suggest that specifically posterior-central regions, including the inferior parietal lobule, precuneus, posterior cingulate, and midcingulate cortex, consistently emerge as neural correlates of consciousness based on lesion, stimulation, and recording studies. Absence of dreaming has also been attributed to lesions in the temporo-parieto-occipital (TPO) junction (Solms 1997 , Yu 2001) and subcortical regions, such as the striatum (Yu 2001, Perogamvros and Schwartz 2012).

While the distribution of significant sources was widely distributed in the occipital and parietal lobes in (Siclari, Baird, Perogamvros et al. 2017), a subsequent EEG microstate analysis of the same data showed mainly occipital activation related to dreaming (Brechet, Brunet, Perogamvros et al. 2020), potentially reflecting the predominating presence of sensory experiences in dreaming. Indeed, most of our dream experiences are perceptual (>80% of all dreams) (Hall and Van De Castle 1966 , Foulkes and Foulkes 1985 , Fosse, Stickgold and Hobson 2001 , van der Heijden, Thevis, Verhaegen and Talamini 2024). The most prevalent sensory modality is vision (>90% of dreams contain at least one visual element), followed by audition (~50%), movement and tactile sensations (~20%), and smell or taste (<1%) (Calkins 1893 , Strauch and Meier 1996 , Desseilles, Dang-Vu, Sterpenich and Schwartz 2011). On the other hand, non-perceptual dreams, in the form of thoughts are also possible, especially in NREM sleep (~20-40%) (Foulkes 1962 , Hall and Van De Castle 1966 , Foulkes and Foulkes 1985 , Fosse, Stickgold and Hobson 2001). These would be experiences, typically in the form of abstract, verbally structured or conceptual thoughts without vivid sensory imagery. Such experiences may involve inner speech, reasoning, planning, or ruminations. A study of the neural correlates of dreaming should also take these types of dreams into account and aim to distinguish between neural patterns associated with different contents of dreaming.

Although posterior cortical regions have been linked to dreaming, the spatial distribution of their activity across different pre-awakening time windows remains to be clarified. The choice of these windows can be informed by the reported duration of conscious experiences, typically on the order of tens of seconds. Depending on the duration of conscious experiences and when they occur relative to awakening, different pre-awakening time windows may reveal differences in the strength and spatial distribution of EEG activity. Moreover, the relationship of EEG activity with specific phenomenological dimensions of dreams remains incompletely understood. Based on previous evidence (Siclari, Baird, Perogamvros et al. 2017 , Brechet, Brunet, Perogamvros et al. 2020), we here expected posterior EEG activity during N2 dreaming to be associated with perceptual experiences. Given that thought-like experiences are common during N2 sleep, we explored the associations between EEG activity and continuous ratings of perception and thought.

The present study had thus two main objectives. First, we aimed to extend previous findings on the neural correlates of dreaming during N2 sleep by comparing EEG activity preceding awakenings followed by reports of conscious experience (CE) and no experience (NE), using a larger sample than before (Siclari, Baird, Perogamvros et al. 2017), and an updated analytical approach. N2 sleep was particularly suitable for this comparison because, unlike REM sleep, where most awakenings yield reports of conscious experience (Stickgold, Malia, Fosse et al. 2001), it provides a more balanced proportion of CE and NE reports, allowing for more robust comparisons between conditions. Second, we aimed to investigate, independently of the CE-NE contrast, whether continuous ratings of perceptual and thought content were associated with EEG spectral activity during conscious experiences. To address these objectives, we analyzed serial awakenings from 39 participants, incorporating several methodological improvements: (1) a robust statistical approach using threshold-free cluster enhancement (TFCE), (2) spectral analyses across a continuous frequency scale from 1 to 50 Hz, avoiding arbitrary frequency band segmentation, (3) examination of both absolute and relative EEG power, (4) a regression analysis of continuous perception and thought ratings, and (5) an analysis of different time windows (30 s, 20 s, 10 s and induced 60 s).

METHODS AND MATERIALS Population

Thirty-nine healthy participants (age 44 ± 13.5 years, 24-65 range, 15 males) were recruited as part of a larger research project at the Wisconsin Center for Sleep and Consciousness.

Thirty-two participants had been included in (Siclari, Baird, Perogamvros et al. 2017), while seven additional participants from the same cohort were included in the present analysis. All participants underwent the same recruitment and screening procedures. They were selected from a larger sample of 69 participants of the original experiment, based on their answers after awakenings. More specifically, participants were required to have at least one report of conscious experience (CE) and one report of no experience (NE) during N2 sleep within the same night. Awakenings affected by technical problems or unreliable responses due to excessive somnolence were excluded from analysis. Ethical approval was obtained from the Madison Institutional Review Board of the University of Wisconsin and a signed informed consent was obtained from each participant before the experiment.

Serial awakenings

Collection of behavioral and EEG data during sleep was accomplished following a "serial awakening" paradigm that each participant underwent during one night of high-density EEG recording. The detailed procedure of participant recording and awakenings is described in previous publications (Siclari, Larocque, Postle and Tononi 2013, Siclari, Baird, Perogamvros et al. 2017). Serial awakenings were performed in the sleep laboratory after at least 10 min of stable N2 sleep and, at pseudorandom intervals of at least 20 min. Awakenings were initiated by a 1.5 sec sound administered through speakers. While awakened, participants were asked to answer a structured interview about their most recent subjective experience prior to awakening ("What was the last thing going through your mind prior to the alarm sound").

They were asked to report whether they had been experiencing anything (conscious experience with recall of content, CE), experiencing something but could not remember the content (conscious experience without recall of content, CEWR), or not experiencing anything (no experience, NE). If participants reported CEWR or NE, no further questions were asked. If participants reported having a conscious experience with recall of content (CE), they were asked to describe its most recent content on several dimensions. Notably, participants were asked to rate their experience 1) on a "perceptual" scale (e.g., seeing or hearing) ranging from 0 (no perception) to 5 (maximal perception), and 2) on a "thought" scale ranging from 0 (no thinking) to 5 (maximal thinking). The complete questionnaire is provided in supplementary material S1. The offline EEG recorded 2 minutes prior awakenings were extracted and assigned to the CE, CEWR or NE categories.

Among the questions, participants were also asked to report the duration of their last experience, before the alarm sound. Six possible options were given: 1) 0-5 sec, 2) >5s-10s, 3) >10s-1 min, 4) >1min-10min, 5) >10min-1h, 6) >1 h.

Sleep recordings

While sleeping in the laboratory at the Wisconsin Center for Sleep and Consciousness, participants were recorded with polysomnography including a 256-channel high density EEG (hd-EEG) sampled at 500Hz (Electrical Geodesics, Inc., Eugene, OR). Four of the 256 electrodes placed at the outer canthi of the eyes were used to monitor eye movements while additional polysomnography channels were used to record electromyography. Sleep scoring was performed over 30-second epochs according to standard criteria (Berry, Brooks, Gamaldo et al. 2016). Sleep stages were initially identified online during the serial-awakening protocol to guide awakenings during consolidated sleep. Subsequently, offline sleep scoring was performed to confirm sleep-stage classification, and only awakenings classified as N2 were included in the present analyses.

EEG analysis

The signal corresponding to the 2 min preceding each awakening was extracted and considered for preprocessing. EEG data were filtered in two steps using Netstation (EGI).

First, a zero-phase IIR Butterworth high-pass filter at 0.1 Hz was applied, followed by a zerophase IIR Butterworth bandpass filter between 0.3 and 50 Hz. Data were then segmented into 2-minute epochs and an additional 1 Hz high-pass filter was applied in MATLAB using the eegfilt function (EEGLAB, (Delorme and Makeig 2004)), which implements a zero-phase FIR windowed sinc filter. All filters were applied in a zero-phase fashion to avoid phase distortion. The EEG data was high-pass filtered at 1Hz instead of lower frequencies, as there were strong sweating artifacts in some of the participants that caused intermittent highamplitude slow frequency oscillatory activity around 0.3 Hz. Epochs containing signal amplitudes exceeding ±150 µV were rejected. Channels showing flat signals or clear artifacts upon visual inspection were marked as bad and excluded from analysis. After bad electrode exclusion, the EEG was subjected to ICA decomposition in order to remove artifact components using EEGLAB toolbox. Bad electrode signals were then interpolated from nearby channels using spherical splines (NetStation, Electrical Geodesic Inc.) and EEG was average referenced.

A primary investigation focused on the last 30 sec of recording for further analysis (see Results, Dream duration). Additionally, we conducted a similar investigation on the last 20 and 10 second windows of the recording to detect potential differences when closer in time to the awakening. The x-second epochs were downsampled to 250Hz and the power spectral density (PSD) was calculated using multitaper from 1 to 50Hz with a 0.5Hz step in the source using the 'mne.minimum_norm.compute_source_psd_epochs' function from MNE package in Python (MNE v1.7.0, (Gramfort, Luessi, Larson et al. 2013)). The sources were defined on the Freesurfer derivative template 'fsaverage' BEM model included in MNE and including 2052 source points for the two hemispheres in total. The inverse operator was calculated on that same model with free dipole orientations. The chosen inverse solution method was sLORETA (Pascual-Marqui, Esslen, Kochi and Lehmann 2002). The power spectra were individually averaged across epochs of the same conditions and individually normalized (i.e. divided) by broadband average power for each condition independently to correct for inequal signal-tonoise ratio, due to possible different number of epochs between conditions, and to obtain relative power per frequency bin. As seen in the Results section, although the average number of trials could be close, their standard deviations are nearly as large as the means, implying high variability across subjects. Thus, averaging unequal numbers of trials can bias absolute power values (with less trials meaning fewer stable estimates and potentially higher background noise that could cause a drift in the frequency spectrum). Hence, normalization per condition helps equalize the contribution of each condition across subjects, reducing the confound introduced by varying trial numbers. As relative power could lack sensitivity in the low frequencies -low frequencies' power is largely contributing to the normalization -the results on absolute non-normalized data are also presented to gain a comprehensive overview of the neural processes at work and for comparison to existing literature.

To further explore the relationship between EEG activity and reported dream content, the frequency-domain data from CE trials were averaged across frequency bands (delta: 1 to 4 Hz, theta: 4 to 8 Hz, alpha: 8 to 12 Hz, sigma: 12 to 16 Hz, beta: 16 to 30 Hz, gamma: 30 to 50 Hz) and six bilateral cortical regions (i.e. frontal, limbic, occipital, parietal, temporal and medial wall). These PSD indices per trial were kept as absolute power or corrected by their own broadband power to approach the relative power values obtained across all trials.

Finally, the induced power locked on the time of awakening was computed for the last 60 sec, with 5 sec windows segmentation to get a better idea of the likely ongoing cerebral processing across time according to the different conditions. Computation of induced spectral power was performed using the 'mne.minimum_norm.source_induced_power' function from MNE package with the same inverse operator and inverse method as for the power spectra calculation but gathering the source points into 68 regions of interests (34 per hemisphere) from Freesurfer 'aparc' labels.

Statistics

Based on participants' questionnaire responses, each awakening was classified into one of three main categories (CE, CEWR, or NE). Consequently, the number of participants included varied across different contrasts (i.e. CE vs NE, CEWR vs NE, CE vs CEWR). In order to assess the differences between conditions for the given contrasts, a non-parametric clusterlevel paired t-test was applied for the spatio-temporal data, i.e. participants x frequency bins x source points or participants x regions x frequency bins x time points. This data driven approach takes no assumption for functionality of frequencies or regions. After pairwise subtraction of the two conditions of a given contrast, the test was performed using the mne.stats.spatio_temporal_cluster_1samp_test function from MNE package. An adequate model of adjacency was first computed. For PSD analysis that model was taking into account the immediate neighbors between source points and n+1/n-1 for frequency bins. For induced power the model was taking into account n+1/n-1 for frequency bins and for time points but no-adjacency between regions of interest considered as independent. Cluster level tests were controlled with threshold-free cluster enhancement (TFCE) method (Smith and Nichols 2009). While preserving statistical rigor, the TFCE avoids for arbitrary threshold selection of cluster-based methods and increases sensitivity by enhancing the spatially contiguous effects.

Thus, it is particularly well adapted for EEG analyses in the inverse space. The TFCE was applied with a height factor of 2 and an extend factor of 0.5 and were performed over 500 permutations. Clusters with p-values below 0.05 were considered as significant and then aggregated together to form the final images of the results. In order to have a better idea of the distribution of the differences according to the frequencies the results were displayed along all frequencies together, and frequency band by frequency band (delta: 1 to 4 Hz, theta: 4 to 8 Hz, alpha: 8 to 12 Hz, sigma: 12 to 16 Hz, beta: 16 to 30 Hz, gamma: 30 to 50 Hz).

Using the PSD indices per trial from CE awakenings for frequency bands and cortical lobes showing significant differences in the CE-NE comparison, we examined the associations of EEG activity with the perceptual and thought scales via a regression analysis using a mixed linear model. Using separate thought and perception scales in the regression models allowed us to examine their associations with EEG activity independently, as both dimensions may coexist within the same conscious experience. PSD indices were entered as the dependent variable, perception and thought ratings as fixed effects, and participant as a random effect.

As these analyses were exploratory and restricted to frequency bands and cortical regions showing significant CE-NE differences, p-values were reported without correction for multiple comparisons. Additionally, differences between the slopes of perception and thought were tested in separate regression analyses focusing on the interaction between the two factors (i.e. "perception versus thought" as a factor). While the first regressions tested the independent effects of perception and thought on PSD within the same model, the second regressions tested the interaction of the two factors to assess the differences between their slopes and how much their effects on EEG correlates differ.

RESULTS

Experience sampling during sleep

Among the 287 awakenings performed in the 39 subjects, 124 were CE (mean: 3.17 per subject, SD=1.46), 56 were CEWR (conscious experience without recall of content; mean: 2.24 per subject, SD=1.42) and 107 were NE (mean: 2.74 per subject, SD=1.51) (Table 1).

According to the contrast studied, the number of included participants could vary. The CE vs NE contrast involved 39 participants, while comparisons between CEWR-NE conditions and CE-CEWR conditions were performed in the subset of these participants (N=24) that had all three types (CE, CEWR, NE) of report during the same night. Among CE reports, mean thought and perception ratings were comparable (thought: 2.19 ± 1.52; perception: 2.10 ± 1.58; mean ± SD), with 15.3% and 20.2% of reports receiving a score of zero for thought and perception, respectively. A repeated-measures correlation accounting for multiple awakenings within participants revealed no significant association between thought and perception ratings (r = -0.149, p = 0.170).

Dream duration

Among reports of conscious experience with recall of content (CE), 43 were estimated to be covering the last 10 seconds, 39 within 10-60 seconds before awakening, and 36 within 1-10 minutes, representing together approximately 95% of all CE reports. In contrast, only 6 reports were estimated to last more than 10 minutes. Thus, a 30-second window provides a representative temporal sampling of the neural correlates underlying a big part of conscious experiences reported in this paradigm.

We consider the 30 s window as a pragmatic compromise: long enough to capture sustained pre-awakening activity in a substantial proportion of reports, yet short enough to limit contamination by earlier, potentially unrelated activity. Importantly, an exploratory analysis included multiple windows (10 s, 20 s, 30 s, and induced 60 s) to assess the robustness of our findings across different time frames.

CE vs NE comparison

DISCUSSION

We first show that dreaming in N2 sleep was associated with widespread increases in relative beta/gamma power and decreases in absolute low-frequency power, with maximal effects in posterior-central regions. The spatial distribution of EEG differences varied across the time windows examined, with maximal effects in parietal regions in the shorter window (20 s; Fig. 3) and in occipito-temporal regions in the longer window (30 s; Fig. 1). Contrary to our initial hypothesis, regression analyses revealed no significant associations of such EEG activity with perception, but with thought-related experience. These findings suggest that the electrophysiological correlates of conscious experience during N2 sleep are not exclusively related to perceptual aspects of dreaming and may also reflect other phenomenological dimensions, such as cognitive aspects.

Spatial distribution and temporal characteristics of EEG activity associated with N2 dreaming

Using TFCE, we observed a widespread increase in relative beta/gamma activity during dreaming (CE) relative to no reported experience (NE), with peaks in occipital-temporal regions at the 30-second time scale of analysis. On one hand, the widespread cortical activity suggests that dreaming involves a broad cortical activation pattern, rather than a focal 'dream' region (see also (Zhang and Wamsley 2019)). This widespread activity may reflect the diversity of dream content reported by our participants, including sensations, thoughts, emotions, faces, speech, and movement. On the other hand, the maximal EEG power differences included posterior regions implicated in perceptual as well as higher-order representational processes, such as the visual cortex, the inferior temporal cortex and the middle temporal gyrus.

When using the 20-second analysis window used in (Siclari, Baird, Perogamvros et al. 2017), we observed stronger high-frequency activity in more central and lateral regions, notably the sensorimotor cortex, premotor cortex, parietal-temporal-occipital (PTO) junction, retrosplenial cortices and the precuneus. The central structures of the 20-second window have been previously proposed as either one of the main neural correlates of dreaming (inferior parietal lobule and TPO junction) (Solms 1997), of dream movement (sensorimotor cortex) (Dresler, Koch, Wehrle et al. 2011 , Noreika, Windt, Kern et al. 2020), or part of the main substrate of consciousness in our brain (Tononi, Boly and Cirelli 2024).

Although the 10-second window was temporally closest to the awakening and the associated subjective ratings, it yielded no statistically significant results. The lack of significant results for this time window may be related to higher variability of the data in such a short period and less precise spectral estimation. By extension, in the longer windows more repetitions from the same specific brain activity can occur in time and reach significance.

The spectral power differences observed between CE and NE over the 60-second preawakening window further supported a major involvement of posterior cortical regions (occipital, parietal, and temporal) in dreaming, consistent with a recent study using the same time window in a larger sample (N = 140) (Selte, Haworth, Vanasse et al. 2026). Altogether, these findings provide further support for the involvement of the posterior hot zone in dreaming (Siclari, Baird, Perogamvros et al. 2017).

The different spatial maxima observed across pre-awakening windows may reflect regional differences in the temporal persistence of EEG activity associated with conscious experience.

Tentatively, the relative predominance of parietal regions in the 20-s window may suggest stronger CE-NE differences, with parietal regions being involved, e.g., in integrating internally generated information; by contrast, the relative predominance of more occipitotemporal regions in the 30-s window may reflect less sustained differences by extending further into the preceding period, with occipito-temporal regions being involved, e.g., in visual and/or object-related processing. From a functional perspective, these regions may have different functions and timings in the contributions to the generated conscious experiences.

Such interpretations remain speculative, nevertheless, as the 20-and 30-s windows examined are overlapping and as analyses were performed on averaged power. Shorter windows may more accurately represent the brain state just prior to awakening, whereas longer windows contain more data for spectral estimation, which could lower the noise level as well as allow for more detection of sporadic neural activity. Longer windows might also include neural activity that is less directly associated with the reported experience. Thus, more conclusive interpretations will require further analyses.

Associations between EEG activity and thought/perception ratings during N2 sleep

We initially hypothesized that posterior EEG activity associated with dreaming during N2 sleep would be related to the perceptual content of conscious experiences. Contrary to this hypothesis, we did not find significant associations between EEG spectral power and perception ratings, but with thought ratings. However, we cannot conclude that EEG activity is more strongly associated with thought than perception, as the regression slopes did not differ significantly.

Although both cognitive and perceptual aspects are present in NREM and REM dreaming, thought-like experiences are relatively more prominent during NREM sleep, whereas perceptual experiences predominate during REM sleep (Fosse, Stickgold and Hobson 2001, Carr and Nielsen 2015). Previous studies have documented thought-like experiences without perceptual imagery during NREM sleep (Foulkes 1962, Fosse, Stickgold and Hobson 2001), suggesting that perceptual content is not a universal feature of dreaming. Indeed, NREM dreams often combine thought-like and perceptual characteristics (Siclari, Larocque, Postle and Tononi 2013) and have been characterized as more conceptual than REM dreams (Martin, Andriano, Mota et al. 2020), which tend to be more perceptual, social, immersive, emotionally intense, and complex (Perogamvros, Baird, Seibold et al. 2017). In our N2 sample, thought and perceptual dimensions had similar mean ratings (2.19 and 2.10 respectively; Table 1), suggesting that the observed associations with thought cannot simply be attributed to higher average thought ratings.

These observations raise the possibility that the relationship between cortical activity and the phenomenological dimensions of dreaming varies across sleep stages. Previous studies showed associations of posterior brain regions with perceptual content and frontal regions with thought content in REM sleep (Siclari, Baird, Perogamvros et al. 2017). Our results extend these observations by showing that thought ratings are associated with activity across multiple cortical regions during N2 sleep. However, the previous study used a single bipolar thought-perception scale, whereas we used separate continuous ratings of these dimensions, limiting direct comparisons. Thus, cortical activity may be associated with different phenomenological characteristics across sleep stages. Direct comparisons between dreaming in N2 and REM sleep within the same participants are needed to determine whether these neural-phenomenological relationships are stage-dependent.

Our findings may also be interpreted in light of recent evidence linking dream phenomenology, EEG activity, and subjective sleep depth. A recent study (Michalak, Marzoli, Pietrogiacomi et al. 2026) reported that reflective thought was associated with lighter sleep depth at a subjective level during N2 sleep, whereas perceptual immersion was associated with deeper subjective sleep. At the same time, there was negative correlation between subjective sleep depth and gamma power. Therefore, these findings do not exclude that the associations between thought ratings and relative gamma power in our study may partly reflect variations in sleep depth or cortical arousal, rather than processes specifically related to thought content. Interestingly, REM sleep, which is typically characterized by more immersive and perceptual dreaming, has been reported as particularly deep at a subjective level (Stephan, Lecci, Cataldi and Siclari 2021). These observations suggest that the relationships between dream phenomenology, EEG activity, and perceived sleep depth may vary across sleep stages. The association between perceptual immersion and sleep depth resonates with Freud's proposal that dreams act as 'guardians of sleep' (Freud 1900), although a causal role of dreaming in sleep stability remains to be established.

Strengths and limitations

To our knowledge, this is the largest study to date combining 256-channel high density EEG, cortical source localization and the serial awakening paradigm to investigate the neural correlates of dreaming (N = 39). We see that such a large sample size allowed us to find a more extended network of brain regions related to dreaming compared to previous studies.

Such an increase in statistical power is the goal of recent large-scale, standardized datasets, such as Wong et al. (Wong, Herzog, Andrade et al. 2025), which compiled 20 EEG sleep datasets -including the present one -comprising 505 participants and 2,643 awakenings with dream reports. This collective resource reflects a growing consensus on the need for harmonized paradigms, rigorous statistical pipelines, and transparent data sharing.

A previous study (Siclari, Baird, Perogamvros et al. 2017) reported posterior activation (i.e., decreased low-frequency power without increased high-frequency power) when comparing conscious experiences without recall (CEWR) to no experience (NE). In our analysis, based on a larger sample size, we did not find significant differences for this comparison. One possible explanation is that CEWR may be difficult to reliably distinguish from NE, as participants may occasionally classify an absence of conscious experience as CEWR or a forgotten dream as NE. Such misclassifications could introduce noise and reduce the sensitivity of comparisons involving these categories. It may also be that these so-called 'white dreams' are low-information experiences, and our analysis is mostly sensitive to the neural correlates of recalled high-information contents -that is, experiences with cognitive access (Fazekas and Nemeth 2018). Consistent with this interpretation, both the previous study (Siclari, Baird, Perogamvros et al. 2017) and our current analysis show widespread increases in high-frequency activity for CE vs. NE, whereas the absence of such effects in CEWR vs. NE (in both analyses) may indicate that CEWR corresponds to a less stable, and more ambiguous subjective state than CE.

In line with this interpretation, the CE vs. CEWR comparison at the 20-second time window (Fig. 5) revealed increased low-gamma activity (30-34 Hz) for CE in the superior parietal and paracentral regions bilaterally, with a stronger effect in the left hemisphere -a result partially overlapping with the previous study (Siclari, Baird, Perogamvros et al. 2017) for the same contrast. These regions are implicated in working memory, attentional shifts, and the manipulation of information in working memory.

A limitation of this study concerns the serial awakening paradigm itself. Participants reported their mental content just prior to being awakened by an alarm, which may not represent the temporal extension and richness of dreams as described in spontaneous morning reports.

Accordingly, our results should be interpreted as pertaining to brain activity related to the last conscious content experienced prior to awakening in N2 sleep, and not as pertaining to more complex dreams with a richer narrative structure, which might be present during all stages of sleep. In this context, the fact that we investigated only the last conscious experience prior to awakening might also be considered a strength of our paradigm, since it allowed us to relate brain activity in circumscribed pre-awakening time windows to participants' reports in a temporally precise and unbiased manner. Nevertheless, future studies combining serial awakenings with more extended dream reports, complemented by large language model-based analyses of dream content (Perogamvros, Rochas, Beau et al. 2025), may help bridge the gap between momentary conscious content and more elaborated dream narratives.

Another limitation concerns the temporal variability observed across pre-awakening windows.

Effects were not stable across time, with no significant differences in the -10 s window and partially distinct spatial patterns at -20 s and -30 s. This variability does not support the existence of a temporally stable "generator" of experience underlying extended dream episodes. Rather, it suggests that neural activity associated with reported experiences fluctuates in the seconds preceding awakening. As a reminder, since awakenings occurred randomly, preceding brain activity was not directly related to the awakening itself. Besides, given the limited spatial resolution of sLORETA and lack of individual MRIs, anatomical labels should be interpreted as approximate regional localizations rather than precise identification of specific cortical areas.

Finally, CE vs NE contrasts showed widespread relative beta/gamma increases across large cortical regions, with posterior maxima. Although these findings may reflect the involvement of distributed cortical networks in conscious experience during N2 sleep, we cannot exclude that they partly reflect more general fluctuations in sleep depth or cortical arousal. Moreover, high-frequency activity and source reconstruction may contribute to spatially extended patterns. The widespread activation should therefore be interpreted cautiously.

CONCLUSIONS

Taken together, these findings reveal widespread increases in relative beta/gamma power associated with conscious experience during N2 sleep, with prominent involvement of posterior cortical regions. Exploratory analyses further suggest that these EEG changes may be associated with thought-related aspects of dreaming, and are not necessarily limited to perceptual content. Furthermore, differences across pre-awakening analysis windows suggest that the spatial distribution of the observed EEG associations may depend on the temporal window examined.
