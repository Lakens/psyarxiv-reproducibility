Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Checking code requires downloading its file contents. For a paper whose repository is on Dryad, this never succeeds unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (listing the repository’s files does not need one). Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Rapid judgments based on political candidates' facial features often predict electoral outcomes. Building on this, we explored how facial impressions of honesty and competence-formed under suboptimal processing conditions-predict voting intentions for actual political candidates. In this study, 484 participants (Colombians: 199; Peruvians: 285; male: 30.2%) were exposed to candidate faces from Colombia and Peru under time constraints (33 ms or 100 ms). Participants rated these faces on honesty and competence and subsequently indicated their likelihood of voting for each candidate. Our findings demonstrate that while rapid facial impressions predict voting preferences overall, this effect is strongly amplified when candidates are recognized from one's own country, whereas for foreign candidates, the relationship remains minimal or disappears. Crucially, because voting intentions were evaluated during subsequent unconstrained viewing, these rapid impressions interact with fullviewing processing rather than acting in complete isolation. By utilizing real candidate photographs, this study confirms that rapid facial impressions align with electoral preferences in naturalistic settings, operating through an integrated process where familiar faces instantly retrieve pre-existing political attitudes.

Keywords: Facial impressions, honesty, competence, voting intentions

The inherent complexity of voting frequently prompts voters to employ cognitive heuristics to facilitate their choices. Empirical research consistently demonstrates that voters frequently rely on candidate appearance during the electoral process (Ahler et al., 2017; Olivola & Todorov, 2010). This phenomenon has been interpreted by some as an indication of voter irrationality or a lack of information (Banducci et al., 2008; Lenz & Lawson, 2011).

The present research addresses the influence of facial impressions on voting intention by exploring how facial impressions of honesty and competence made under suboptimal processing conditions predict voting intention of real political candidates. We chose to situate the research within the electoral contexts of Colombia and Peru, given the situation that both countries held presidential elections in 2026. For this reason, it is a rare opportunity to study the automatic component of electoral preferences in real-world contexts.

The face as a source of social information

The human face constitutes a special stimulus category within the visual recognition system, processed distinctly from other types of stimuli (Farah et al., 1995; Tsao et al., 2008). This distinct processing is characterized by holistic recognition (Richler, et al., 2011) and a tendency to easily grab attention (Young & Bruce, 2023). Facial features shape evaluations in several domains. People rely on faces when making social judgments because the face is a readily accessible type of stimuli (Hahn et al., 2018; Jaeger et al., 2019a). This sensitivity may be rooted in innate predispositions, which are placed even during intrauterine life (Ronga et al., 2025). Further, facial features are often believed to be a reliable source of social information (Jaeger et al., 2019b), even when their diagnostic validity is controversial (Jaeger et al., 2024; Giacomin & Rule, 2019; Holtzman, 2011; Todorov et al., 2015).

There is a consistent positive bias regarding attractive faces (Langlois et al., 2000; Olivera-La Rosa et al., 2025), which has been explained as a "halo effect" (Kahneman, 2011), in which the salient features of the stimuli shape global inferences that are consistent with the evaluation of the face. In this way, the attribution of trustworthiness to an individual has been demonstrated to be tightly linked to their facial attractiveness (Ma et al., 2016). Conversely, a negative bias towards unattractiveness is also present: unattractive people are often judged poorly in several social dimensions (Griffin & Langlois, 2006; Olivera-La Rosa et al., 2023).

From an evolutionary perspective, making extremely quick judgments based on facial features may constitute a highly adaptive cognitive tool for reducing undesired social interactions, since the cost of acting quickly and making a mistake is lower than the cost of conducting a thorough analysis of the person before acting (Schaller & Park, 2011).

Appearance-based social perception in the political domain

Recent adversarial collaboration on social evaluation suggests that social perception is dealt using two main dimensions: Horizontal (i.e., to what extent the target is willing and able to create positive social relations with others) and Vertical (i.e., to what extent the target is willing and able to achieve their personal intentions whatever those may be). Further, each dimension is divided into two facets: Morality and Friendliness compose the Horizontal dimension and Ability and Assertiveness compose the Vertical one (Abele et al., 2021). Extensive research shows that these two dimensions (also referred as Warmth and Competence, Fiske et al., 2007) guide impression formation across social contexts and predict affective, cognitive, and behavioral responses to others (Luna-Cortes, 2025).

This theory has been widely applied to appearance-based judgments, showing that warmth and competence can be rapidly inferred from faces alone. Facial features automatically activate stereotypes associated with these dimensions, even in the absence of conscious deliberation (Imhoff et al., 2013). Such inferences are consequential: warmth-related impressions are closely linked to trust, moral evaluation, and humanization, whereas competence is associated with perceived status, leadership ability, and effectiveness (Luna-Cortes, 2025).

In the political domain, prior research based on social evaluation indicates that voters infer candidates' friendliness and competence from appearance and use these impressions to guide voting intentions, particularly when political knowledge or familiarity with the candidate is low (Fiske, 2019; Unkelbach et al., 2023). Specifically, there is a consistent positive bias towards perceived facial competence in voting behavior (Ballew & Todorov, 2007; Hall et al., 2009; Laustsen & Petersen, 2018; Todorov et al., 2005). This bias may be rather automatic; it occurs even when viewing faces for as little as 100 ms (Ballew and Todorov, 2007; Olivola & Todorov, 2010).

Effects of first impressions from faces may be sensitive to cultural differences and political orientation. Greater perceived power (dominance and facial maturity) in a candidates' face predicted US electoral success, whereas greater perceived warmth (likability and trustworthiness) predicted Japanese voters (Rule et al., 2010). Right-wing and conservative candidates are more likely to be voted when their faces look dominant, while liberals' candidates are more likely to lose votes when they are perceived as dominant (Laustsen & Petersen, 2015 , 2016), suggesting that political leanings may moderate the impact of inferences based on facial features.

Interestingly, negative evaluations based on appearance may have a stronger impact on voting than favorable ones, which can be interpreted as electoral judgment being driven by a negative bias towards risky (e.g., untrustworthy) candidates (Spezio et al., 2008). This negative bias is consistent with loss aversion, the empirical finding that the subjective disutility of a loss outweighs the utility of an equivalent gain (Kahneman & Tversky, 1990).

While competence has often been highlighted as a predictor of electoral success, the moral primacy hypothesis of social evaluation suggests that moralityrelated judgments (i.e., those linked to honesty and corruption) may emerge earlier in the perceptual process and exert a stronger influence under conditions of uncertainty. Individuals are motivated to first assess whether another person poses a potential threat or benefit, before evaluating their capacity to enact those intentions (Fiske et al., 2007 , Leach et al., 2007; Brambilla et al., 2012).

Time course of face processing

Research on the time course of face processing has shown that people extract information about a face very rapidly (Bar et al., 2006 , Dobs et al., 2019). Willis and Todorov (2006) showed that trustworthiness judgments from facial features are consistently made after 100ms exposure to novel faces, and that these judgments can even be made as little as 33 ms (Todorov et al., 2009). Because deciding whether an unfamiliar person is trustworthy is critical in social settings, the efficiency of these trustworthiness judgments is likely due to their adaptive value (Engell et al., 2007). Oosterhof and Todorov (2008) found that trustworthiness judgments from facial appearance best approximate the valence evaluation of novel faces.This finding is supported by the role of the amygdala (i.e., a brain structure related to fear conditioning and detection of threats, Amaral, 2002; LeDoux, 2000) in such judgments (Engell et al., 2007; Todorov & Engell, 2008).

Face detection (knowing what a face is) and face identification (knowing whose it is) are processed sequentially and are dissociated (Barragan et al., 2012; Dobs et al., 2019). Information extraction about a face may operate hierarchically, following a coarse-to-fine processing of its dimensions. Barragan-Jason and colleagues (2012) found that a superordinate task such as detecting a human face (i.a., human vs animal faces) takes a minimum of 285 ms which is a processing time similar to what they found for processing the gender of a face. Crucially, they found that people are significantly slower when they have to recognize faces, that is, once a face is detected, there is a gap around ∼190ms before participants responded whether the target faces were familiar or not. Dobs and colleagues (2019) found that facial gender and age are encoded before identity information. Their results showed that face familiarity enhances identity and gender representations at early stages of face processing, which was interpreted as familiar faces tuning of early feed-forward processing mechanisms.

Some research, however, has questioned the primacy of superordinate information processing over identity identification in early latencies of facial information processing (Anaki & Bentin, 2009; Nemrodov et al., 2016; Tanaka & Curran, 2001). Presenting a face for 100-200 ms was enough for the visual system to recognize it as familiar and identify it as a specific person (Wiese et al., 2019), with some evidence suggesting that these processes can take as short as 33 ms under specific conditions (Wiese et al., 2024). The discrepancy between results could be due, at least in part, to the use of different tasks, stimuli, and samples (Barragan-Jason et al., 2012).

Research overview (Hs and RQs)

Based on the reviewed literature, it remains an empirical question whether evaluative judgments, such as trustworthiness, occur before the processing of more detailed, specific facial information, such as identity information or other social evaluation processes such as competence evaluation. Furthermore, more research is needed to determine whether judgments of trustworthiness and competence derived from facial appearance can occur at early stages of facial processing in the electoral context. Building on previous research showing that perceived trustworthiness and perceived competence are crucial traits in person perception (Fiske et al., 2007), and that the perception of these traits shapes voters' preferences when choosing which candidate to elect (Laustsen & Petersen, 2018; Olivola & Todorov, 2010; Rule et al., 2010), we explored whether quick first impressions have predictive value for electoral preferences. Specifically, we assess whether Colombians and Peruvians judge political candidates' honesty and competence just by seeing their faces under suboptimal processing conditions, and how these impressions predict voting intentions. The following hypotheses are examined: -H1: When a candidate is unknown, facial impressions of honesty and competence made under suboptimal processing conditions predict voting intention. Whereas they will not predict voting intention when the candidate is previously known.

After data collection and data analysis authors concluded that pre-registered hypotheses H2 (Log-transformed response times for evaluative judgments will be regressed on evaluation type, exposure duration, and their interaction. A significant main effect with faster RTs for honesty would support H2) and H3 (Within honesty trials, RTs for the evaluative judgment and the recognition judgment will be compared using judgment type as the key predictor) were untestable with the collected dataset. Hence, we re-phrased them as Exploratory Research Questions: RQ1: Is the correlation between honesty impressions and voting intentions stronger than correlation between competence and voting intentions? RQ2a:Is the relation between competence impressions and voting intentions more strongly affected by exposure duration than the relation between honesty impressions and voting intentions? Based on the moral primacy account, we expected the honesty-vote relation to remain largely stable across exposure durations, because honesty-relevant information is extracted early in face processing, whereas the competence-vote relation was expected to strengthen with increasing processing time. RQ2b: Is the relation between candidate identity and voting intentions more strongly affected by exposure duration than the relation between honesty impressions and voting intentions? Whereas early extraction of moral information was expected to render the honesty-vote relation stable across exposure durations, the identity-vote relation was expected to depend on processing time, because face identification requires more extensive processing than evaluative judgments (Dobs et al., 2019; Wiese et al., 2024)

Method

We preregistered all hypotheses, variables, exclusion criteria, and data analysis: https://osf.io/auy3r/overview?view_only=3ae03d4f59544a2fb4ed93e55a8e4a5e

Participants

We recruited 484 participants (331 females) via internal email and social networking. Participants were from Colombia (41.1%) and Peru (58.9%). By using samples from both countries, each population serves as a preliminary familiarity control sample for the other country. We assumed that Colombian candidates would not be familiar to the Peruvian population, and vice versa. Before the experiment, all participants affirmed their consent to participate in the study and provided written consent in accordance with ethical procedures approved by the Bioethics Committee of [BLINDED FOR REVIEW]. They then indicated their age, gender, educational level and country of residence.

Materials and procedures

The experimental design consisted of two parts. First, participants were exposed to faces of political candidates under time constraints (speeded block), and asked to rate their feelings of honesty and competence. We tested our hypotheses by using a 2x2x2x2 mixed factorial design, with candidates (Colombia/Peru), exposure times (33/100 ms) and evaluative judgment (Honesty/Competence) as within subjects factors, and participants residence (Colombia/Peru) as between subject factor. Second, participants were asked to rate the likelihood of choosing each political candidate for a public position. Notably, because voting intentions were evaluated during this subsequent unconstrained viewing phase, the design assesses how initial speeded impressions inform and interact with post-exposure evaluative decisions, rather than measuring voting choices strictly under continuous suboptimal conditions.

40 faces of political candidates to the presidential election of Colombia (20) and Peru (20) were selected as target faces. We use real pictures of political candidates in both Colombian and Peruvian presidential elections to increase the ecological value of this research. Although using real public pictures implies an inherent variability in dimensions crucial to social perception such as attractiveness or age (among others), we believe that our approach is best suited to understand how snap judgments from facial information shape voting intentions in real electoral contexts.

To mitigate this methodological issue, we established two methodological controls. First, target faces were selected from the Internet following defined criteria: a) The 20 most popular candidates from each country were selected, b) Official photos or photos taken intentionally for electoral purposes (not candid photos), c) All photos depict faces clearly visible, d) Faces with neutral to positive emotional expressions were considered, photos with extreme emotional expressions (e.g., exaggerated smiles) were excluded. An oval shape was applied to all faces to prevent the background from providing additional information (see supplementary material). Second, a pilot study N = 62 (30 Colombia, 29 Perú, 3 indicated Other country) was run to obtain reference values in dimensions relevant to social perception, which would help us to interpret possible effects. Therefore, participants from both countries rated all target stimuli in likability, familiarity, competence and honesty. Following Willis y Todorov (2006) approach, the mean trait judgments across participants served as the criterion judgments for the experiments.

A semirandom selection of faces were applied, so each participant was exposed to a subset of 20 faces: 50% faces Colombia, 50% faces Peru; 50% 33ms, 50% 100ms. Half of those 20 trials were rated on honesty and the other half on competence. Therefore, the experimental task consists of 20 trials.

Participants were asked to respond quickly, using their first instinct. Each trial started with a 500ms fixation cross. Then, a target's face appeared on the screen (for 33ms or 100ms) followed by a 7-point likert scale of honesty or competence, which was available for 6s (1: dishonesty, 7: honesty; 1: incompetence; 7: competence, respectively) thus functioning as a backward mask. Exposure times were selected based on previous research on face evaluation (Todorov et al., 2009). Response times for evaluative judgments were measured. Once the scale disappeared, participants were asked if they recognized the target face through a yes/no recognition judgment. The interval between trials was1500ms.

Once they had completed the 20 speeded trials, participants saw the same 20 faces again, one at a time, in a newly randomized order and without time constraint. For each face, they rated the likelihood of choosing that candidate for a public position on a 7-point Likert scale (How likely are you to vote for this person for public position? 1: not at all likely; 7: very likely). Because the order of the voting block was reshuffled, the speeded rating and the vote of the same face were separated by a variable number of other faces. The instructions for the speeded block did not announce the voting block, which was introduced only after the last speeded trial. An awareness check was administered at the end of the session

Results

Analytic Approach

Analyses were conducted in R using lme4 and lmerTest for linear mixedeffects models (LMMs) and emmeans for simple slopes and contrasts; data and analysis code are available on OSF. All models included crossed random effects for participants and candidates, so that inferences generalize across both samples of people and of faces. The random-effects structure began with a by-participant random slope for the impression and was simplified only when a model failed to converge or produced a singular fit; unless noted otherwise, the maximal structure was retained. Categorical predictors were effect-coded (-0.5/+0.5): exposure time (33/100 ms), judgment type (competence/honesty), recognition (not recognized/recognized), candidate country, and participant country. Impression ratings were z-standardized within judgment type, so that slopes express the change in voting intention (1-7) per 1 SD of that trait's impression and are directly comparable across traits. Fixed effects are reported with Satterthwaite degrees of freedom; simple slopes and contrasts use the asymptotic approximation, which at this number of trials is equivalent to Satterthwaite and computationally far cheaper. Tests were two-tailed with α = .05.

Because judgment type varied between trials -each face was rated on one trait only -honesty and competence could not be entered as two predictors of the same vote. The honesty-versus-competence comparison (RQ1) was therefore modelled as the difference between the two impression-vote slopes within a single mixed model, which respects the repeated-measures structure better than comparing two independent correlations; within-subject correlations are reported alongside as a descriptive reference.

Data and Exclusions

Of 498 recruited participants, 14 were excluded following the preregistered criteria: nine provided fewer than 70% valid responses in the evaluative task, five showed zero variance in their evaluative responses, and none responded consistently faster than 200 ms. At the trial level, 23 individual ratings (0.24% of nontimeout responses) with response times below 200 ms were discarded. The final sample comprised N = 484 participants and 9,680 trials. Analyses of voting intention were based on the 9,210 trials with both a valid impression rating and a valid vote rating (2,842 recognized, 6,368 unrecognized); analyses restricted to honesty trials were based on 4,614 trials.

Participants resided in Colombia (n = 199, 41.1%) or Peru (n = 285, 58.9%); 331 identified as women (68.4%), 146 as men (30.2%) and 7 as non-binary (1.4%). Age was collected in bands, and 87.0% of the sample fell in the 18-25 band. The median session lasted 3.6 min (IQR = 2.9-4.3). At the end of the session participants reported how clearly they had seen the briefly presented faces: 7.9% reported seeing nothing at all, 37.8% a face they could not make out clearly, 39.9% several faces they could not make out clearly, and 14.5% several faces clearly. The manipulation of suboptimal processing conditions was therefore effective for 85.5% of the sample.

Recognition of Candidates

Participants reported recognizing the candidate on 30.8% of trials. Recognition depended jointly on exposure time and on whether the candidate was from the participant's own country (Table 1). A logistic GLMM with crossed random effects showed main effects of exposure, b = 0.58, SE = 0.06, z = 10.51, p < .001, OR = 1.79, and of own-country candidacy, b = 1.46, SE = 0.06, z = 24.96, p < .001, OR = 4.33, qualified by their interaction, b = 0.65, SE = 0.11, z = 5.94, p < .001, OR = 1.92. Additional exposure increased the estimated probability of recognition from .29 to .50 for own-country candidates but only from .11 to .14 for foreign candidates. Recognition rates varied widely across participants (Mdn = 25%, IQR = 15-40%; 26 participants never recognized a candidate and 81 recognized more than half) and across candidates (Colombian candidates 14-40%, Peruvian candidates 18-53%). Recognition judgments took a median of 907 ms.

Supporting the validity of this measure, candidate recognition rates correlated r = .84, 95% CI [.71, .91], p < .001, with normative familiarity obtained from the independent pilot sample. Recognition was unrelated to normative likeability, r = -.09, p = .591, and tended to be negatively related to the normative criteria for honesty, r = -.30, p = .063, and competence, r = -.24, p = .134: the better-known candidates were, if anything, judged less favourably.

Statistical test for hypotheses and research questions Confirmatory Hypothesis Tests

H1: Impressions and Voting Intentions for Unknown Versus Known Candidates

An LMM predicted voting intention from the facial impression, trial-level recognition and exposure time, with judgment type and candidate country as covariates. Facial impressions predicted voting intentions overall, b = 0.42, SE = 0.02, t(504.1) = 18.97, p < .001, and this relation was stronger at longer exposures, b = 0.10, SE = 0.03, t(8732.8) = 3.96, p < .001. The impression × recognition interaction was significant, b = 0.38, SE = 0.03, 95% CI [0.32, 0.44], t(7695.9) = 12.99, p < .001, but its direction was opposite to the preregistered prediction. Consistent with the first part of H1, impressions formed under suboptimal conditions predicted voting intentions for unrecognized candidates, both at 33 ms, b = 0.19, SE = 0.03, 95% CI [0.13, 0.25], and at 100 ms, b = 0.28, SE = 0.03, 95% CI [0.22, 0.34]. Contrary to the second part of H1, the slope for recognized candidates was not null but roughly three times larger (33 ms: b = 0.56, 95% CI [0.49, 0.63]; 100 ms: b = 0.67, 95% CI [0.61, 0.73]). The unrecognized-minus-recognized difference was significant at both exposures (33 ms: Δb = -0.37, SE = 0.04, z = -9.30; 100 ms: Δb = -0.39, SE = 0.04, z = -10.43; both p < .001), and the three-way interaction with exposure was not significant, b = 0.01, SE = 0.05, p = .771, indicating that the pattern held equally at both exposures. H1 was therefore only partially supported: rapid facial impressions did predict voting intentions for unknown candidates, but familiarity amplified rather than eliminated this relation (Figure 1).

RQ1: Honesty Versus Competence

A second LMM tested whether honesty impressions predicted voting intentions more strongly than competence impressions, with exposure time, candidate country and recognition (centered) as covariates. The maximal randomeffects structure was singular and was simplified by dropping the by-participant random slope for judgment type. The two slopes were nearly identical (competence: b = 0.44, 95% CI [0.39, 0.49]; honesty: b = 0.41, 95% CI [0.36, 0.46]), and the impression × judgment-type interaction was not significant, b = -0.03, SE = 0.02, 95% CI [-0.08, 0.02], t(8672.0) = -1.13, p = .257. Within-subject correlations pointed in the same direction (honesty: rrm = .29, 95% CI [.26, .32]; competence: rrm = .32, 95% CI [.30, .35]). RQ1 was not supported: both traits predicted voting intentions to an equivalent degree (Figure 2). RQ2a: Exposure Time and the Honesty Versus Competence Slopes

The focal impression × judgment-type × exposure interaction was not significant, b = -0.02, SE = 0.05, t(8749.4) = -0.32, p = .751. Instead, longer exposure strengthened the impression-vote slope for both traits alike (impression × exposure: b = 0.14, SE = 0.02, t(8711.7) = 5.50, p < .001): the competence slope increased from 0.36 at 33 ms to 0.50 at 100 ms, Δb = 0.14, SE = 0.04, z = 4.09, p < .001, and the honesty slope from 0.34 to 0.47, Δb = 0.13, SE = 0.04, z = 3.63, p < .001. RQ2a was not supported: the modulation by exposure was common to both traits rather than selective for competence (Figure 3).

RQ2b: Morality Versus Identity

On honesty trials, voting intention was regressed simultaneously on the morality impression (honesty rating, z-scored) and on candidate identity (binary recognition, z-scored), each interacting with exposure time, with candidate and participant country as covariates. Morality impressions were the dominant predictor, b = 0.39, SE = 0.03, t(474.5) = 13.29, p < .001, with identity contributing a smaller unique effect, b = 0.10, SE = 0.02, t(4492.5) = 4.72, p < .001. Contrary to RQ2b, it was the morality-vote relation that was moderated by exposure, b = 0.12, SE = 0.04, t(4208.8) = 3.23, p = .001, strengthening from 0.33 at 33 ms to 0.45 at 100 ms, whereas the identity-vote relation remained stable, b = 0.02, SE = 0.04, t(4225.1) = 0.68, p = .495 (0.09 vs. 0.11). Because both predictors were standardized, the two moderation coefficients are on the same metric; their difference was not significant, Δb = 0.09, SE = 0.05, z = 1.72, p = .085. RQ2b was not supported, and the descriptively inverted pattern should be interpreted with caution (Figure 4).

Hypotheses Conditional on Candidate Identification

Because the impression-vote relation was substantially larger for recognized candidates, we re-estimated each hypothesis within recognized and unrecognized trials, testing differences formally as interactions with recognition rather than comparing significance across subsets.

The impression-vote slope was significantly positive even when participants did not recognize the candidate (Table 2), indicating an appearance-based route that does not require identification. The equivalence of honesty and competence held within both levels: slopes were indistinguishable for unrecognized candidates (honesty 0.23 vs. competence 0.23, Δb = -0.003, z = -0.10, p = .918) and differed only marginally, and in the direction of competence, for recognized candidates (0.59 vs. 0.66, Δb = 0.07, z = 1.90, p = .057); the three-way test was not significant, b = -0.07, SE = 0.05, p = .135. The exposure modulation was also equivalent across recognition levels: the slope increased from 0.19 to 0.28 for unrecognized candidates, z = 2.81, p = .005, and from 0.56 to 0.67 for recognized candidates, z = 2.82, p = .005, with no difference between them, b = 0.02, p = .755, and no four-way interaction, b = 0.005, p = .959. On honesty trials the morality slope was larger for recognized candidates, b = 0.29, SE = 0.04, t = 6.94, p < .001, but its modulation by exposure did not differ by recognition, b = 0.04, p = .624.

Because recognition was not manipulated, we ran three robustness analyses (Table 2). Adjusting for candidate-level normative familiarity and likeability, together with their interactions with the impression, left the focal interaction essentially unchanged, b = 0.35, SE = 0.03, p < .001; the impression-vote slope was itself steeper for normatively familiar candidates, b = 0.08, SE = 0.01, p < .001. Restricting the analysis to the 443 participants who contributed both recognized and unrecognized trials -which removes any between-participant explanation such as political engagement or scale use -also left it unchanged, b = 0.38, SE = 0.03, p < .001. Critically, however, the interaction disappeared when analyses were restricted to foreign candidates, b = -0.03, SE = 0.04, p = .486, where the slopes for unrecognized (0.16) and recognized (0.13) trials were indistinguishable. The same pattern is evident in the raw within-participant correlations between impressions and votes, which were .12 and .74 for unrecognized and recognized own-country candidates but .10 and .14 for foreign candidates (Figure 5). Recognition amplified the impression-vote relation only for own-country candidates, that is, only where identification could plausibly activate a pre-existing political attitude; claimed recognition of a foreign candidate, which occurred on 19.8% of those trials, carried no such amplification.

Agreement With Free-Viewing Criterion Judgments

Following Todorov et al. (2009), we assessed how closely impressions formed under time constraints agreed with criterion judgments of the same faces obtained without time constraints from the independent pilot sample (Cronbach's αs across pilot raters: honesty = .86, competence = .84, likeability = .90, familiarity = .87). For each participant and cell we computed the correlation between their own ratings and the criterion means of the faces they saw, transformed it to Fisher's z, and tested the average against zero.

A temporal dissociation emerged between the two traits (Table 3). Honesty impressions agreed with the free-viewing criterion already after 33 ms, r = .11, t(427) = 2.96, p = .003, and did not improve with longer exposure, t(396) = 0.65, p = .518. Competence impressions did not reach significance at 33 ms, r = .08, t(428) = 1.94, p = .053, and emerged only at 100 ms, r = .22, t(445) = 5.03, p < .001, a significant increase, t(398) = 2.77, p = .006. A trial-level LMM regressing impressions on the criterion reproduced this pattern (criterion × exposure: b = 0.07, SE = 0.03, t(8823.2) = 2.34, p = .020; criterion slopes: competence 0.07, 95% CI [-0.00, 0.14], at 33 ms versus 0.17 [0.09, 0.24] at 100 ms; honesty 0.10 [0.02, 0.17] versus 0.13 [0.06, 0.20]). The temporal dissociation predicted for the impression-vote relation thus appeared instead at the level of information extraction: morality-relevant information was available after 33 ms, whereas competence-relevant information accrued with additional exposure.

Agreement was also higher on recognized than on unrecognized trials (Table 3), and the criterion × recognition interaction was significant in the trial-level model, b = 0.28, SE = 0.03, t(5326.6) = 8.55, p < .001. This is expected, because the normative criterion incorporates knowledge about the candidates and not appearance alone: 38.0% of pilot ratings were made on faces the pilot rater called familiar, those raters gave systematically higher ratings (honesty M = 3.69 vs. 2.97; competence M = 3.96 vs. 3.22), and the candidate profiles produced by familiar and unfamiliar pilot raters correlated only r = .49 and .43. The near-zero individual-level agreement on unrecognized trials should therefore not be read as an absence of appearance-based signal: aggregated at the candidate level, honesty impressions of unrecognized candidates at 33 ms recovered a substantial part of the normative consensus, r = .47, p = .003, whereas competence impressions did not, r = .01, p = .960.

Normative Predictors of Impressions and Voting Intentions

Candidate-level norms from the pilot explained a substantial share of the between-candidate variance in the experimental impressions. Normative likeability predicted impressions, b = 0.13, SE = 0.03, t(36.9) = 4.29, p < .001, whereas normative familiarity did not, b = 0.01, p = .768; together the norms accounted for 36.8% of the candidate-intercept variance, χ²(8) = 21.95, p = .005, rising to 44.0% when the trait-matched criterion was added, χ²(2) = 6.72, p = .035. Because normative likeability and the trait criteria were strongly collinear at the candidate level (r = .86 for honesty and .74 for competence), their unique contributions could not be separated (both ps < .09 in the combined model); they are best interpreted as a shared general evaluative factor.

Norms also predicted voting intentions over and above the participant's own momentary impression (b = 0.42): the trait criterion, b = 0.08, SE = 0.04, p = .031, and normative likeability, b = 0.12, SE = 0.04, p = .006. Crucially, which norm mattered depended on recognition (Table 4). For unrecognized candidates, voting intentions tracked normative likeability, b = 0.18, 95% CI [0.10, 0.27], but neither the trait criterion nor familiarity. For recognized candidates the pattern reversed: likeability was unrelated to the vote, b = -0.04, whereas the trait criterion, b = 0.21, and normative familiarity, b = 0.22, both predicted it. All three interactions with recognition were significant (ps < .001). Facial appeal thus guided voting intentions when candidates were not identified, whereas reputation and prominence guided them when they were.

Sensitivity Analyses

Because the awareness check indicated that 85.5% of participants reported no or degraded visibility of the faces, we re-estimated all focal tests excluding the 70 participants who reported seeing several faces clearly (n = 414) and again restricting the sample to those reporting no or minimal visibility (n = 221). All conclusions held (Table 5): the impression × recognition interaction remained large, the RQ1 and RQ2a nulls remained null, and the morality moderation remained significant. In the most restrictive subsample the difference between the morality and identity moderations reached significance, b = 0.17, z = 2.14, p = .032, suggesting that the inverted RQ2b pattern is clearest under the most degraded processing conditions, although this is a subgroup analysis and should be treated as exploratory. Selfreported awareness did not moderate the impression-vote slope, b = 0.04, SE = 0.06, p = .516 (clear reporters 0.45, others 0.41).

Given the null results for RQ1, RQ2a and RQ2b, we computed the smallest effect detectable with 80% power as approximately 2.8 times the observed standard error of each focal term. The design was sensitive to a difference of 0.07 between the honesty and competence slopes (RQ1; observed 0.03), to a selective exposure modulation of 0.14 (RQ2a; observed 0.02), and to a difference of 0.15 between the morality and identity moderations (RQ2b; observed 0.09). The nulls for RQ1 and RQ2a are therefore informative, whereas the test of RQ2b was less conclusive.

Brief Exposure Versus Free Viewing: Analyses of the Voting Measure

Voting intentions were rated under free viewing, after the speeded block. The impression-vote relation could therefore reflect information extracted during the brief exposure, impressions formed or revised while viewing the face freely, or a tendency to answer consistently with the earlier rating. The design cannot separate these sources, but three features of the existing data bear on them (Table 6). These analyses were not preregistered; all models followed the specification used for H1.

First, exposure time varied within participants, whereas the voting block was identical for all faces, so any difference between faces seen for 33 and 100 ms must originate in the speeded phase. The impression-vote relation was stronger after 100 than after 33 ms, b = 0.10, SE = 0.03, 95% CI [0.05, 0.15], p < .001 (slopes 0.37 vs. 0.47), and this held for unrecognized candidates (0.19 vs. 0.28, z = 2.80, p = .005). If voting intentions reflected only impressions formed during free viewing, the amount of information available during the brief exposure should not have mattered. This pattern therefore indicates that information extracted in the speeded phase carried over to the vote, although it cannot rule out that longer exposure also made the earlier response easier to remember.

Second, the relation did not depend on whether participants reported having seen the faces clearly, b = 0.04, SE = 0.06, 95% CI [-0.08, 0.16], p = .516, and awareness did not modulate the exposure effect, b = 0.07, SE = 0.07, p = .304. Across the four awareness levels, the slopes were 0.29, 0.38, 0.46 and 0.46, from no to clear visibility (omnibus χ²(3) = 5.86, p = .118; linear trend p = .058). Participants who reported seeing nothing at all (n = 38) still showed a reliable slope, b = 0.30, SE = 0.08, p < .001, but they also reported recognizing 24% of own-country candidates, which suggests that the retrospective report is a coarse index of visibility. In the most degraded cell (participants reporting no or minimal visibility, unrecognized candidates, 33 ms), the slope was small but positive, b = 0.11, SE = 0.05, 95% CI [0.01, 0.21], p = .038.

Third, because the voting block was reshuffled, the distance between the rating and the vote of the same face varied randomly (serial positions in the two blocks were uncorrelated, r = -.01). A tendency to answer consistently with a remembered earlier rating should weaken as this distance increases. Overall, the impression-vote slope declined with distance, b = -0.04 per 10 intervening faces, SE = 0.02, 95% CI [-0.07, -0.01], p = .019 (per minute: b = -0.05, p = .009), but the decline was confined to recognized candidates (impression × distance × recognition: b = -0.11, SE = 0.03, 95% CI [-0.17, -0.05], p < .001). For recognized candidates, the slope fell from 0.81 at the shortest to 0.46 at the longest distance, b = -0.09, SE = 0.02, p < .001. For unrecognized candidates, it did not change, b = 0.02, SE = 0.02, p = .436 (0.20 vs. 0.26), although the design could have detected a decline of 0.06 per 10 faces with 80% power.

Finally, because impressions were not centred within participants, the slopes above combine within-participant covariation with between-participant differences in scale use (e.g., participants who used the upper end of both scales). Re-estimating the models on person-mean-centred impressions left the exposure effect (b = 0.12, SE = 0.03, p < .001), the absence of awareness moderation (b = 0.05, p = .458) and the distance × recognition interaction (b = -0.10, SE = 0.04, p = .011) unchanged. It did, however, reduce the slope for unrecognized candidates at 33 ms to 0.07, 95% CI [0.00, 0.14], against 0.21 [0.14, 0.28] at 100 ms. In the most degraded cell, the within-participant slope was no longer reliable, b = 0.08, 95% CI [-0.03, 0.18], p = .172.

Taken together, these analyses suggest that the impression-vote relation is not simply a product of free viewing or of consistent responding: it depended on how long the face had been seen in the speeded phase, it did not depend on reported awareness, and for unrecognized candidates it did not weaken with the distance between rating and vote. At the same time, part of the strong relation for recognized candidates appears to reflect carry-over of the earlier response or of the identification that accompanied it. In addition, the evidence that impressions formed after only 33 ms predict voting intentions for unrecognized candidates is weak once between-participant differences in scale use are removed. The clearest evidence for a contribution of the brief exposure therefore comes from the 100-ms condition.

Summary

None of the three preregistered dissociations emerged as predicted. Instead, the results converge on two routes from facial appearance to voting intentions. Impressions formed with as little as 33 ms of exposure predicted voting intentions even for candidates participants did not recognize, and on those trials the vote tracked the shared facial appeal of the candidate rather than any consensus about their honesty or competence. When participants identified the candidate -and only when that candidate was from their own country -the impression-vote relation tripled and voting intentions tracked reputation and prominence instead of facial appeal. Across both routes, longer exposure strengthened the impression-vote relation equally for honesty and competence. Finally, agreement with free-viewing criterion judgments revealed the temporal dissociation that the vote-based tests did not: honesty impressions were aligned with the normative consensus after 33 ms, whereas competence impressions required 100 ms.

Discussion

This study evaluates whether facial impressions of honesty and competence, formed under suboptimal processing conditions, predict voting intentions for actual political candidates. By conducting this research within the electoral contexts of the 2026 presidential elections in Colombia and Peru, we capture a unique opportunity to examine the implicit components of electoral preference in authentic, high-stakes environments.

The findings demonstrate that facial impressions made under suboptimal conditions predict voting intentions, but this relationship is substantially moderated by candidate recognition and origin rather than holding uniformly. Specifically, candidate familiarity strongly amplifies the impression-vote relation for own-country candidates, whereas for foreign candidates, the effect disappears or remains minimal. Furthermore, because voting intentions were indicated during unconstrained free viewing following the speeded task, claims that impressions formed exclusively under suboptimal conditions drive voting decisions must be tempered; initial rapid cues interact with subsequent deliberate viewing during final choice. These results refine established literature on the automaticity of trustworthiness and competence evaluations (Ballew & Todorov, 2007; Todorov et al., 2009; Willis & Todorov, 2006), reinforcing the evidence that voting behavior remains susceptible to rapid facial cues, particularly when integrated with familiar candidate representations (Banducci et al., 2008; Lenz & Lawson, 2011; Olivola & Todorov, 2010).

These findings could be interpreted as new evidence on the automaticity of appearance-based trait inferences in voting intentions. Specifically, our results corroborate prior research demonstrating that voters implicitly derive perceptions of friendliness and competence from facial appearance to inform their voting intentions (Ballew & Todorov, 2007; Hall et al., 2009; Laustsen & Petersen, 2018; Rule et al., 2010; Todorov et al., 2005). Ballew and Todorov (2007) showed that impressions of competence could be formed as little as 100ms exposure to faces, without any deliberation, and that these impressions can influence voting decisions (see also, Olivola & Todorov, 2010). Our results confirm and extend these findings, by showing that both competence and honesty impressions could be formed with as little as 33ms exposure to faces and that these impressions are predictive of voting intentions. Unlike Ballew and Todorov (2007), who use software generated-faces, the use of faces of real political candidates in this research made it possible to show that rapid facial impressions are consistent with candidates preferences in more naturalistic settings.

Crucially, our findings demonstrate that facial impressions are most predictive of voting intentions when the candidate is familiar, revealing that recognition substantially moderates this relationship. Our finding that familiarity amplified, rather than attenuated, the relationship between facial impressions and electoral choices contrasts with previous literature, which posits that such effects are amplified under conditions of low political knowledge or candidate unfamiliarity (Fiske, 2019; Unkelbach et al., 2023). From a processing perspective, brief exposure durations (33-100 ms) followed by backward masking effectively interrupt ongoing visual input, limiting sensory processing to early feed-forward activity. However, ultra-fast familiarity and identity processing can occur within these latencies (Wiese et al., 2024). In this rapid window, a familiar face may act as an instantaneous retrieval key that reactivates pre-existing cognitive and emotional political attitudes. These entrenched attitudes are structured not only by deliberative knowledge but by peripheral associations accessible immediately upon identity retrieval (Lau & Redlawsk, 2001). Consequently, when participants subsequently rate voting intentions under free-viewing conditions, these reactivated attitudes may help shape and reinforce the initial impression-vote link for own-country candidates, whereas unrecognized foreign candidates lack this attitude-retrieval mechanism Regarding our second hypothesis, the results contradict the expectation that honesty impressions would demonstrate a stronger correlation with voting intentions than competence. Unlike previous research suggesting a clear moral primacywhere morality-related judgments dominate impression formation (Brambilla et al., 2012; Leach et al., 2007)-our findings reveal that both honesty and competence are equally predictive of electoral preferences.

This parity suggests that the moral primacy hypothesis may be less rigid within the political domain. While morality is undoubtedly a core pillar of social evaluation, competence remains a central predictor of voting behavior, likely reflecting an 'adaptive followership' mechanism where voters seek cues indicative of problem-solving efficacy (Laustsen & Petersen, 2018). Our findings align with more recent applications of the Stereotype Content Model (Fiske, 2019), which emphasizes the nuanced, parallel roles of these dimensions in shaping political perception.

Regarding our third hypotheses, our findings indicate that both honesty and competence impressions form rapidly-within 33 ms-suggesting that the underlying psychological mechanisms are highly efficient. Although we did not observe the predicted temporal dissociation in the impression-vote relationship, a clear dissociation emerged at the level of information extraction: honesty impressions aligned with criterion judgments at 33 ms, whereas competence impressions required additional processing time. This delay suggests that competence evaluations at 33 ms may initially rely on valence-based processing before stabilizing into distinct competence-related judgments at 100 ms.

Our results suggest that the identity-vote association is a more stable phenomenon than the honesty-vote association, which appears sensitive to the duration of exposure. This may reflect the cognitive architecture of these judgments: identity recognition functions as a retrieval process in which pre-existing attitudes are activated once a familiarity threshold is reached, rendering the association relatively invariant to short-term exposure fluctuations (Dobs et al., 2019). Conversely, honesty judgments-even under suboptimal conditions-may involve a more constructive, evaluative process that benefits from, and is therefore moderated by, the incremental processing time available between 33 ms and 100 ms.

Despite the contributions, the present study is not free of limitations. First, by utilizing real photographs of political candidates, we introduced a methodological trade-off: we prioritized the ecological validity of the research over the use of a standardized set of face stimuli. Although a pilot study was conducted to mitigate potential biases, we could not control all facial features that influence electoral perception. For instance, dimensions such as perceived age and face typicality were not systematically assessed. Regarding age, findings in the literature remain contradictory: Zebrowitz and Montepare (2005) suggested that the positive effect of perceived competence on election outcomes may be mediated by perceived age, noting that 'baby-faced' politicians are less likely to be elected than their more mature-faced counterparts. Conversely, Olivola and Todorov (2010) found that a baby-faced appearance was a positive predictor of both actual and hypothetical votes. In this vein, research also indicates that voters prefer candidates with high facial similarity, particularly when candidates are unfamiliar (Bailenson et al., 2005). This is consistent with evidence that self-resemblance significantly affects the perception of trustworthiness (Nakano & Yamamoto, 2022), as Olivola and Todorov (2010, p. 92) observe: 'voters preferred politicians who resembled them.' Future studies should address the role of perceived age and face typicality/resemblance in the obtained findings.

Second, a key methodological limit involves the measurement of voting intentions: because voting likelihood was rated during unconstrained free viewing immediately following the speeded evaluation task, our paradigm cannot claim that voting decisions are driven exclusively by suboptimal viewing conditions. Additional analyses of the voting measure indicate that while brief exposure effects carried over to voting decisions (particularly at 100 ms), post-exposure free viewing and response consistency-especially for recognized candidates-interact with these initial rapid cues. Future research should utilize paradigms that constrain both the trait rating and the voting decision under identical time limitations to further isolate pure implicit effects.

Practical Implications

The present findings demonstrate that electoral preferences are anchored in early, heuristic-driven information processing, often occurring before voters consciously identify candidates. When the candidate is unknown, these initial impressions may establish a foundational anchoring bias, which likely shapes subsequent information processing, risking a confirmation bias (Kahneman, 2011) as voters interpret later candidate messaging through the lens of their first impressions.

While these initial impressions are potent, they are not deterministic. Voting decisions are multi-faceted processes shaped by a confluence of variables, including political affiliation, ideology, and candidate proposals, that can mitigate or override initial facial evaluations (Ahler et al., 2017; Hayes et al., 2014; Jenke & Huettel, 2020). Consequently, campaign strategists must be cognizant of the temporal dynamics of these biases to develop more effective communication interventions.

Campaign assessors should first identify the specific social dimensions triggered by a candidate's appearance to optimize persuasion strategies. When candidates face negative impressions of competence, communication should leverage multimodal consistency. Because leadership and competence are frequently inferred from vocal characteristics, such as verbal fluency, moderate pacing, and prosodic confidence (Klofstad et al., 2012; 2016), campaigns can utilize these cues to update initial impressions. For example, evidence suggests that vocal cues are more influential in judgments of dominance, whereas facial appearance is the primary driver of perceived trustworthiness (Mileva et al., 2018; Rezlescu et al., 2015). Furthermore, formats such as structured debates and long-form interviews are essential to trigger a shift from automatic to deliberative processing. By employing both peripheral and central persuasive cues (Petty & Cacioppo, 1986), candidates can disrupt initial heuristics. Strategies should include presenting verifiable track records, professional attire, and clear policy messaging.

Conversely, negative impressions regarding honesty pose a greater hurdle. While vocal acoustics can modulate these perceptions, such effects are highly context-dependent, precluding a standardized 'ideal' speech pattern (Maltezou-Papastylianou et al., 2025). Furthermore, because trustworthiness evaluations are largely resistant to rapid, peripheral persuasion, mitigating these biases necessitates long-term strategies that emphasize transparency, behavioral consistency, and authentic discourse to foster an enduring perception of integrity (Grimmelikhuijsen & Meijer, 2014). In conclusion, this research demonstrates that facial impressions of honesty and competence, formed under suboptimal processing conditions predict voting intentions for actual political candidates through an integrated process heavily moderated by candidate recognition. Rather than operating uniformly across all targets, rapid facial cues trigger an amplified predictive pathway specifically when candidates are recognized from one's own country, as ultra-fast identity processing (Wiese et al., 2024) allows the familiar face to serve as an instantaneous retrieval key for pre-existing political attitudes. Conversely, for foreign candidates, this relation is minimal or absent. Moreover, because final voting choices were evaluated during unconstrained free viewing, these initial speeded impressions inform rather than fully replace subsequent deliberate processing. By utilizing real political candidates within Colombian and Peruvian electoral contexts, this study underscores that rapid face perception interacts dynamically with pre-existing cognitive structures in naturalistic political decision-making.
