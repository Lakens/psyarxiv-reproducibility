Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

The value of herding dogs depends on how effectively they perform their job. Improving the rate of success for herding dogs requires understanding which dogs succeed and why. The present study determines whether dog personality and behavioral traits can be used to predict herding performance. We began by replicating Wilson and colleagues (2022), who found that personality traits predict herding ability in Australian kelpies. We asked American owners of herding dogs to complete an online survey about their dog's (n = 335) personality, behavior, and herding ability. We grouped related personality variables together in a principal components analysis to create dog personality traits. Next, we determined whether any dog personality traits predicted herding ability. We partially replicate Wilson et al.'s (2022) findings, with similar personality traits predicting herding ability. We then expanded on the previous study by creating a new set of traits that also included behavioral variables. The personality and behavior model captured the observed data better than the personality-only model. Lastly, we compared the personalities in our American herding dog sample to Wilson et al's (2022) Australian kelpies. The two groups of herding dogs were different on some key personality variables. We propose that herding dog handlers and breeders should focus on key personality and behavioral traits when making decisions about herding dog career paths and training efforts.

Introduction

Dogs often take on many roles in our lives; they can be companions and teammates and even family members (Bouma et al., 2023; McConnell et al., 2019). They also can serve important working roles. Herding dogs help with gathering and moving livestock such as cows and sheep. In general, dogs excel at this job because it taps into desire to chase prey animals (Coppinger & Coppinger, 2001). Farmers have taken advantage of that prey drive to train dogs when, where, and how to chase. Dogs that become effective herders are well worth the time and monetary investment, with the value of a herding dog's labor estimated at USD $34,396 (Arnott et al., 2014). Over time, we have created specific herding breeds (e.g., border collie, kelpie) with the help of artificial selection. However, dogs do not need to be a herding breed to herd livestock, and herding breeds do not always work on farms. Many herding breeds are kept as pets with no "job" other than to keep their human company. These companion-only dogs may encounter their farm counterparts at herding competitions, called trials, which are a recreational activity that turns herding into a sport. Whether in a recreational or agricultural setting, owners want their dog to be able to effectively herd livestock. Unfortunately, roughly one in five working farm dogs do not go on to become successful at their job (Arnott et al., 2014). Farmers who rely on these dogs must decide when to continue investing resources and training in herding dogs for agricultural work. The present study aims to inform herding dog owners about which traits they should focus on for career decisions and training to provide the best chances of success.

Herding dog success is, to some degree, in the eyes of the beholder. An owner's perception of their dog's overall herding ability is a mental representation that is built up over time. Each time the dog herds, the owner receives new information to incorporate into their mental representation. That information could tell the owner something about their dog's personality. We view personality as a "suite of correlated behaviors expressed either within a given behavioral context or across different contexts" (Sih et al., 2004). While the term temperament overlaps with personality in the literature, we use personality here to maintain consistency with similar studies of herding dogs (Gartner, 2015; Jones & Gosling, 2005). Within the herding context, dogs display herding behaviors; the maneuvers and abilities that are specifically useful for herding livestock. The dog's personality and behavior then, in turn, influence their owner's mental representation of the dog's herding ability. In this study, we focus on the relationship between owner's perceptions of their dogs' personality, behavior, and herding ability.

Personality

In the world of working dogs, personality traits may be the key to success. Bolder dogs achieve greater success in working dog trials (Svartberg, 2002) and less fearful dogs successfully complete service dog training (Dollion et al., 2019). The impact of personality on working dog outcomes suggests that personality is a predictor worth exploring in herding dogs. Dog owners' perceptions also point to personality traits as a key to herding success. When asked to indicate which personality traits are valuable in herding dogs, owners tend to agree that motivation, confidence, friendliness, and trainability are desirable (Early et al., 2019). While each herding environment requires a slightly different skill set, herding dogs all share a similar set of core personality traits (Early et al., 2018). Across contexts, dog owners believe that dog personality traits influence herding ability.

Owners' ratings of their own dog's herding ability support their belief in the power of personality. Studies focused on a single herding breed, the kelpie, suggest that dog personality explains differences in both owner perceptions and dog behavior (McGreevy et al., 2015; Wilson et al., 2022). Personality traits in kelpies predict owner ratings of herding ability (Wilson et al., 2022). Owner perceptions of kelpie personalities also align with observed difference in how the dogs perform on behavioral tests (McGreevy et al., 2015). This validation suggests that owner reports of dog personality not only relate to owners' perceptions of herding ability but may reflect actual behavioral differences displayed by herding dogs.

Behavior

Herding dogs perform specific herding behaviors when moving livestock (Coppinger & Coppinger, 2001; Early et al., 2014). These behaviors enable the dogs to manipulate the direction of movement, pace, and dispersion of a group of livestock. Dog owners consider these herding behaviors to be an important factor in a dog's herding ability (Early et al., 2019). If one animal starts to separate from the group, the dog needs to recognize this and quickly bring them back to the group. A dog's ability to anticipate this issue and act to rectify it is correlated with their overall herding ability (McGreevy et al., 2015).

Behavioral measures are a common way to capture overall herding ability. Herding competitions use scores that are based on the dog's herding behaviors and speed. Success at herding competitions has been used to make breeding and purchasing decisions (Conessa & Mailhac, 2013). However, performance in competitions does not appear to be heritable (Storteig Horn et al., 2017). Taking a different approach, the Swedish Sheepdog Society used trainer ratings of young dogs' personality and behavioral variables to assess herding. Some of the traits measured by the Swedish Herding Trait Characterization are heritable (Arvelius & Klemetsdal, 2013). Building off of this idea, Lasserre et al. (2024) designed the French Idele Scoring System to determine whether a dog meets criteria for an "adequate phenotype". Taking a different approach, McGreevy et al. (2015) asked owners to rate their dogs' behavior on the Livestock Working (Herding) Dog Assessment Form. There is initial evidence of heritability of these behavioral ratings and they have fair to moderate agreement with expert ratings (McGreevy et al., 2015). Owner ratings of their dogs' behaviors may be linked to perceptions of their dogs' overall herding dog abilities.

Personality and herding behavior are both separately linked to overall herding ability. In this study, we examine how personality and behavior variables can be combined to predict overall herding ability. First, we investigate which dog personality traits best predict overall herding ability (Research Question 1) by replicating the methods of Wilson et al. (2022) in a population of American herding dogs. Then, we explore which combinations of dog personality and behavioral traits best predict overall herding ability (Research Question 2). Lastly, we investigate whether dog personality and owner-rated herding ability differ across breeds and countries (Research Question 3).

Methods

Ethics Statement

All procedures were conducted in an ethical and responsible manner, in full compliance with all relevant codes of experimentation and legislation and were approved by the University of Nebraska-Lincoln Internal Review Board (project ID UNL-00023563). All participants (dog owners) offered consent to participate, and they acknowledged that de-identified data could be published publicly.

Participants

Owners of herding dogs (n = 186) submitted online survey responses for a total of 390 individual dogs. After removing responses that were missing data for all of our study variables (personality, behavior, ability rating), we had 373 usable observations. Dog owners met eligibility criteria if they currently owned at least one working herding dog. We defined working herding dog as any dog that has experience herding livestock. Respondents had to be at least 19 years old, live in the United States, and understand English. We recruited dog owners through a combination of recruitment methods. We posted recruitment materials in Facebook groups dedicated to dog-or farm-related topics and asked individual owners to share recruitment materials with others. We invited owners signed up for the Canine Cognition and Human Interaction Lab registry to participate in the study. For a more targeted recruitment approach, we also attended the 2024 United States National Cattledog Finals in Iowa and invited owners at the event to participate in the study. Lastly, we sent email study invitations to owners who competed in either the 2024 United States National Cattledog Finals or the 2024 United States National Sheepdog Finals and had an email address publicly available online. The pre-registered (https://osf.io/mshq9) sample size was determined by time constraints. Data collection began on September 15, 2024 and terminated on December 31, 2024.

The sample of herding dogs had 188 females (50.4%), 158 males (42.4%), and 27 dogs with no reported sex (7.2%). Dog ages ranged from 0.4 to 18.6 years with a mean of 5.7 years. On average, each participating owner had 3.26 dogs. The sample (n = 373) consisted of purebred border collies (n = 239), Australian shepherds (n = 20), Australian cattle dogs (n = 14), other breeds recognized or unrecognized by the American Kennel Club (n = 89), and mixed breeds (n = 6). The majority of the dogs (n = 231) had some experience with working in both farm and competition settings, while others had farm experience but no competition experience (n = 102) or experience working only in competition settings (n = 12). Most dogs with farm experience work in a utility environment (both large and small spaces) (n = 248). Some dogs also worked in yard environments (small spaces) (n = 111), paddock environments (large spaces) (n = 99), droving environments (travel over long distances) (n = 50), and truck environments (trucks transporting livestock) (n = 19). Owners most commonly reported that dogs had one to three years of experience working on a farm. Dogs with trial experience had competed in an average of 16.0 trials and most commonly had one to three years of experience.

Instruments

We built and distributed online surveys through REDCap hosted at University of Nebraska-Lincoln (Harris et al., 2019 (Harris et al., , 2009)). In addition to the below instruments, we collected demographic and herding experience data on both dogs and owners. Owners indicated (yes/no) whether dogs had any experience herding in farm or trial settings. Within farm settings, owners selected all working environments that the dog had experienced. The survey instrument is included at the end of the Supplemental Materials.

Herding Dog Assessment Form-Personality. The present study directly reproduced the Herding Dog Assessment Form-Personality (HDAF-P) (Wilson et al., 2022) to capture personality traits of particular interest in herding dogs. This instrument combines and modifies items from the Monash Canine Personality Questionnaire-Revised (Ley et al., 2009), the Herding Trait Characterization (Arvelius et al., 2013), and the Dog Impulsivity Assessment Scale (Wright et al., 2012). The Herding Dog Assessment Form-Personality asks the respondent to indicate how well a specific personality variable (e.g. confidence) describes their dog. Each item is on a 5-point Likert-type scale (1 = very low,2 = low,3 = average,4 = high,5 = very high), plus a sixth option of "I don't know." The instrument includes 17 personality items. We transformed all personality variables into centered z-scores for the analyses.

Livestock Working (Herding) Dog Assessment Form (adapted).

We used an adapted version of the Livestock Working (Herding) Dog Assessment Form (LWHDAF) (McGreevy et al., 2015), a large-scale survey of working dogs on farms in Australia developed as part of the University of Sydney Farm Dog Project. The instrument includes one section on personality variables, one section on working maneuvers (behaviors) and herding variables, and one section on training. The section on working maneuvers and herding variables was selected for adaptation and use in the present study. We will refer to the herding maneuvers and variables as "behavioral variables" for the rest of the article. For each item, we included a brief narrative description of the behavioral variable drawn from the definitions provided by McGreevy et al. (2015). For example, force was described as "pressure applied by the dog in order to move livestock." Where no definition was available from McGreevy et al. (2015), the authors used their best judgment to write a definition. Item descriptions were revised based on feedback from herding dog owners. We used the original 5-point Likert-style answering scheme (1 = Extremely poor,2 = Poor,3 = Average,4 = Good,5 = Excellent). Additionally, we expanded the answer options to include a sixth "I don't know" option to better align with the answer options from the Herding Dog Assessment Form-Personality (see previous section). Notably, responses to the behavioral items on this scale indicate the respondent's perception of the dog's skill level. This differs from the personality variables measured by the HDAF-P. We transformed all behavioral variables into centered z-scores for the analyses.

Herding Ability.

Overall herding ability was measured using a single survey item. The item read "overall herding ability" and asked the owner to rate their dog on a five-point scale. Replicating Wilson et al. (2022), the response options were: "one of the worst dogs I have ever seen/trained," "below average." "about average," "above average," "one of the best dogs I have ever seen/trained." Responses were coded in the data such that low values indicated "worse" ratings and higher values indicated "better" ratings. We transformed the ratings into centered z-scores for the analyses.

Analyses

This study's methods and analyses were pre-registered at https://osf.io/mshq9/.

Research Question 1.

Our first research question asks which personality in dogs are associated with owner-reported overall herding ability. We evaluated the association between personality variables and overall herding ability by replicating Wilson et al.'s (2022) correlations between dog personality variables and owner ratings of overall herding ability. In a separate analysis, we used a principal components analysis (PCA) with all of the personality variable to identify which personality variables clustered together and how each component impacted the variance in the sample. Components that fell above the inflection point on a scree plot were selected for use. We additionally ran a parallel analysis (Horn, 1965) to support the selection of components as predictors. We applied the weightings from each component to dog's scores on each personality item to create new weighted scores. We then summed the weighted scores across the personality items for each dog, producing a single weighted score for each dog. We repeated the process for each selected component so that each dog had one score per component. We then used the weighted scores for each component as variables in our regression analyses. All of the components selected based on the scree plot were entered into the model for the selection process. We used model selection to determine which combination of PCA components and fixed effects variables would be included in the best-fit linear mixed regression for predicting owner-rated overall herding ability. Fixed effects included the identified components as well as dog sex, gonad removal, age, and work environment. Following Wilson et al., we first performed a series of univariate fixed effects regressions with owner included as a random effect. Each potential predictor variable (including the components) was run in its own linear regression with overall ability as the outcome variable (e.g., overall_ability ~dog_age + (1|owner_id) or overall_ability ~comp1 + (1|owner_id)). A reverse stepwise method based on Akaike Information Criterion (AIC) was used for model selection. We report Bayes factors for the correlations and regression model; however, we follow Wilson et al.'s (2022) approach by drawing on p-values and AIC for interpretations of the data.

Research Question 2.

Our second research question asks which combination of personality and behavioral variables in dogs are associated with owner-reported overall herding ability. We performed a second set of analyses that incorporated behavioral variables (in addition to personality variables) as predictors of overall herding ability. We used a principal components analysis of both the personality and behavioral variables to identify principal components for the new model. We conducted a linear mixed regression with the components of the principal components analysis as predictors of overall herding ability. We selected components to include in the model as predictors based on a scree plot and supported by a parallel analysis. We created weighted scores from each component to use as predictors in the model. Any other fixed effects (e.g., dog sex) that were included in the final selected model for the replication were automatically included in the new models. Dog (individual) and owner were considered as random effects and tested for inclusion in the best-fit model. We based the previous model selection on AIC to replicate Wilson et al.'s (2022) selection methods. For the model including both personality and behavioral variables as predictors, we chose to perform model selection based on Bayes factors calculated from Bayes Information Criteria (BIC). Bayes factors provide the amount of evidence for the alternative model relative to a reference model (Wagenmakers et al., 2010; Wagenmakers, 2007). First, we used an intercept-only model as the reference model for the random effects models. Models containing dog, owner, and dog nested in owner, were compared against the reference model. A Bayes factor of at least 3 was required for the reference model to be rejected in favor of the alternative model. If more than one model exceeds a Bayes factor of 3, then the model with the greatest Bayes factor was chosen. If no random effects model had a Bayes factor of at least 3 when tested against the intercept-only, then the intercept-only model was selected as the reference model for fixed effect model selection. To assess the fixed effects, we assigned a new reference model that included the random effect determined above and all fixed effects from the final personality-only model (overall_ability ~fixed_effects_fromPersonality + random_effects). The alternative models included the reference model plus every possible combination of the selected PCA components. For example, one fixed effects model was (overall_ability ~fixed_effects_fromPersonality + comp1 + random_effects) and another was (overall_ability ~fixed_effects_fromPersonality + comp1 + comp2 + random_effects). These fixed effects models were each compared against the reference model including only the chosen random effects (or intercept-only model) and the fixed effects from the personality-only model. We again used the Bayes factor criteria outlined above to select the final best fit model and based our interpretations on the Bayes factor of the model.

Research Question 3.

Our third research question asks whether dog personality and owner-rated herding ability differ across breeds and countries. We addressed this question by comparing our American sample to Wilson et al.'s (2022) sample of Australian kelpies. We ran a series of t-tests to compare each personality variable of the dogs in our sample to the dogs in Wilson et al.'s sample. Similarly, we compared owner-rated overall herding ability across samples using a t-test. Both frequentest and Bayesian statistics are reported, but we draw on the Bayes factors for interpretation.

Outliers and Exclusions.

Following Wilson et al.'s data analysis plan, both missing data and "I don't know" responses were treated as missing data. Per the pre-registered analysis plan, we excluded missing data at the individual item level. Any observations missing data for all of the the predictor variables and the outcome variable (ability rating) were excluded from analyses. Following these methods, 21 observations were excluded from the personality-only regression (n = 369) and 17 were excluded from the personality and behavior regression (n = 373). No outliers were defined for this study. Results

Personality Variables

The distribution of ratings across most personality variables was skewed toward higher values (Table S1). However, patience (skewness = 0.1), timidness (0.6), hyperactivity (0.4), nervousness (0.8), and impulsiveness (0.2) were all skewed toward lower values. Mean personality variable scores ranged from 2.0 (calmness) to 4.3 (trainability).

We examined the correlations between the personality variables using Kendall's rank correlation coefficient (τ ) (Figure 1). We observed associations between the personality variables of friendliness and sociability (τ = 0.84, p < 0.001), confidence and boldness (τ = 0.69, p < 0.001), and calmness and patience (τ = 0.63, p < 0.001). Overall herding ability was associated with both confidence (τ = 0.45, p < 0.001) and intelligence (τ = 0.44, p < 0.001).

A Kaiser-Meyer-Olkin Test for Sampling Adequacy (Kaiser, 1974) returned a measure of sampling adequacy of 0.82, surpassing the suggested minimum score of 0.5 required for factor analysis (Hoelzle & Meyer, 2013). We performed a principal components analysis on the personality variables to summarize the variance in the sample. The principal components analysis reduced the 17 personality variables into a series of components that described a portion of the variance in the sample. Based on the scree plot of the components and supported by evidence from Horn's parallel analysis, we selected the first four components which collectively describe 66.3% of the variance in the sample (Figure 2). The four personality components can be described by the variables weighted the heaviest (magnitude > 0.3) within each component (Table 1). For ease of interpretation, we have reversed the signs on all loadings for the components which contained primarily negative loadings. Personality component 1 captures 24% of the total variance and we refer to this personality trait as confident. The confident trait pairs high levels confidence, boldness, intelligence, initiative, and persistence with low levels of timidness and nervousness. The internal consistency for the most heavily weighted variables is high (ω = 0.85) for the absolute values of the loadings. Personality component 2 describes 22% of the variance and is characterized by positive representations of hyperactivity, excitability, and impulsiveness and negative representations of calmness and patience (active trait) (ω = 0.82). Personality component 3 (11%) contained positive loadings of sociability and friendliness (social trait) with high internal consistency (ω = 0.92). Lastly, personality component 4 (9%) contained positive weightings on trainability, obedience, nervousness, timidness, and hyperactivity (biddable trait), with low internal consistency (ω = 0.11).

Univariate regressions suggest that the confident personality trait (β = 0.32, SE = 0.02, t = 15.93) and biddable personality trait (β = 0.14, SE = 0.04, t = 3.27) were both associated with higher ratings on herding ability. For non-personality fixed effects, we see that intact dogs (vs. spayed/neutered) were rated more highly in herding ability (β = -0.52, SE = 0.11, t = -4.75). The yard environment was the only working environment not associated with overall herding ability. We combined the predictors of interest in a linear mixed regression model to predict overall herding ability. Replicating Wilson et al. (2022) we used a reverse stepwise method to find the best fit model based on Akaike Information Criterion (AIC). Starting from a model including all possible fixed effects and owner as a random effect, we progressively removed predictors to achieve the lowest possible AIC. The best fit model determined by this method included sex, age, gonad removal status, utility work environment, trial work environment, and confident and biddable personality traits as predictors of overall herding ability (Table S2).

Personality and Behavioral Variables

Building on the associations between personality variables and overall herding ability, we added behavioral variables as a new set of predictors (Table S3).

Mean behavioral variable scores ranged from 3.7 (force) to 4.3 (cover). All of the behavioral variables skewed toward higher values. Natural ability had the greatest skewness (-0.3) of all the variables. Notably, back, bark, and bite were excluded from analyses due to a large amount (n > 50) of missing data for each variable.

We conducted Kendall's rank correlations between all 28 personality and behavioral variables (Figure 3). Among the 11 behavioral variables, correlation coefficients (τ ) ranged from 0.13 to 1. Natural herding ability correlated with the majority of the personality and behavioral variables and overall herding ability (τ = 0.64, p < 0.001). Also, overall herding ability was correlated with the majority of the behavioral variables. Cast and gather were also strongly associated (τ = 0.54, p < 0.001). Correlations between personality variables and behavioral variables were weaker than among personality variables or behavioral variables. Nonetheless, we observed associations between force (behavior) and confidence (personality) (τ = 0.48, p < 0.001), force and boldness (personality) (τ = 0.47, p < 0.001), and anticipation (behavior) and intelligence (personality) (τ = 0.44, p < 0.001). Natural herding ability was also strongly correlated with the personality variables intelligence (τ = 0.46, p < 0.001) and confidence (τ = 0.43, p < 0.001).

A Kaiser-Meyer-Olkin Test for Sampling Adequacy on the combined personality and behavioral variables yielded a score of 0.9, so we proceeded with the Principal Components Analysis on the combined personality and behavioral variables. Based on the scree plot, the first five components had eigenvalues greater than one. However, Horn's parallel analysis showed that the fifth component did not offer additional explanatory power when compared to the simulated eigenvalues generated from a random matrix (Figure 4). We selected only the first four components which collectively describe 56.8% of the variance in the sample.

Personality and behavior component 1 described 28% of the variance and was characterized by moderate weighting (magnitude > 0.3) across multiple variables (Table 2). Behavioral variables gather, cover, break, anticipation, and natural ability were all positively represented (> 0.25) along with the personality variable confidence. The internal consistency for the most heavily weighted variables is high (ω = 0.83) for the absolute values of the loadings. A dog fitting this trait might be described as proactive, with a strong ability to read and respond to the livestock. Personality and behavior component 2 (14%) focused on stronger (magnitude > 0.3) positive representations of hyperactivity, excitability, and impulsiveness paired with negative representations of calmness and patience (ω = 0.85). This is the same active trait found in the previous personality analysis. Personality and behavior component 3 (8%) had strong (magnitude > 0.3) positive representations of timidness and nervousness and negative representations of friendliness and sociability (fearful trait) (ω = 0.59). Lastly, personality and behavior component 4 (6%) had strong (magnitude > 0.5) positive representations of sociability and friendliness (social trait) (ω = 0.92).

We replicated the previously described regression analysis with the four personality and behavior components as predictors. In the end, the best fit model with the highest Bayes factor when compared against the reference model included gonad removal status, utility work environment, trial work environment, and personality traits proactive and active (BF > 1000) (Table S4). The best-fit model did not include any random effects. The inclusion of the proactive and active traits indicates that both personality and behavioral variables are associated with overall herding ability. From the included traits we see that overall herding ability was greater in dogs with higher levels of natural ability and confidence, and more skill at anticipation and many of the more concrete herding behaviors (e.g., cover, break, gather, etc.). On the other hand, the inclusion of the active trait indicates some positive effects of more excitability, impulsiveness, and hyperactivity and potential negative effects of greater patience and calmness. Compared to the proactive trait (β = 0.72), the standardized regression coefficient for the active trait (β = 0.04) is very small. The active is contributing less to the model than the proactive trait.

Comparisons Across Countries and Breeds

Our third research question asked whether dog personality and owner-rated herding ability differ across breeds and countries. We employed the same personality instrument (HDAF-P) and overall ability survey item as Wilson and colleagues (2022) designed and used for their study (see Methods for details). For this analysis, we compared personality variables and overall herding ability ratings between Wilson et al.'s Australian kelpies (n = 228) and our American sample (n = 372, 64% border collies) (Table 3). The American dogs showed strong evidence (Bayes factor > 3) for lower scores on confidence (USA = 3.85 ± 0.97, AUS = 4.14 ± 0.86, BF10 = 65.4), calmness (USA = 3.36 ± 1.09, AUS = 3.63 ± 1.07, BF10 = 5.9), patience (USA = 3.18 ± 1.08, AUS = 3.49 ± 0.99, BF10 = 34.4), hyperactivity (USA = 2.45 ± 1.14, AUS = 2.78 ± 1.24, BF10 = 19.5), and friendliness (USA = 4.11 ± 1.05, AUS = 4.33 ± 0.84, BF10 = 3.3). There was not enough evidence to determine whether the average overall herding ability ratings differed between the samples (USA = 3.68 ± 0.86, AUS = 3.85 ± 0.84, BF10 = 1.3).

Exploratory Analyses

In addition to the pre-registered analyses, we performed a series of exploratory post hoc analyses.

Type of Herding Experience. We investigated the relationship between herding environment and herding ability by directly comparing dogs with different herding experiences. Dogs who had experience herding in both farm and trial settings (n = 231) received the highest ability ratings on average (M = 3.8). Dogs with only farm experience (n = 102) had the next highest mean rating (M = 3.5), followed by dogs with only trial experience (n = 12, M = 3.4). Mean ability rating differed between the dogs with only farm experience and with experience in both farm and trial settings (M = 0.4, 95% CI [0.2, 0.6], t(203.7) = 3.3, p = .001). We did not statistically compare the trial-only group to the other groups due to the limited sample size (n = 12).

Amount of Herding Experience. Next, we explored how the amount of herding experience a dog had related to ability rating. For dogs with trial experience, the number of trials a dog participated in was correlated with ability rating (ρ = .20, p < .001). A linear regression showed that number of trials competed in predicted herding ability (β = 0.01, SE = 0.00, t = 3.73, p < 0.001). However, this effect disappeared once we controlled for age (β = 0.02, SE = 0.01, t = 1.76, p = 0.080).

Age, Sex, and Gonad Status. Age was not significantly correlated with overall ability (ρ = -.02, p = 1.000) or a significant predictor in a univariate linear regression (b = 0.00, 95% CI [-0.03, 0.03]). The association between age and ability only existed when controlling for the other predictors in the best-fit multivariate regression. Like age, sex of the dog was a predictor in the multivariate model but not a significant correlate (ρ = .06, p = 1.000) or predictor on its own (b = 0.15, 95% CI [-0.06, 0.36]). However, gonad status was also included in the best-fit multivariate model and both correlated with (ρ = -.22, p = .024) and predicted overall ability on its own (b = -0.50, 95% CI [-0.71, -0.28]).

Comparison of Regression Models.

We have shown that herding behaviors contribute to herding performance in addition to personality. But we did not directly assess whether adding behaviors to the models is better than having personality alone. To test this, trimmed the data to only the participants who had data for both the personality and the behavioral variables (n = 365). We then re-ran the two models and compared them using Bayes factors calculated from Bayes Information Criterion (BIC). There was strong evidence (BF > 1000) that the personality and behavior model captured the observed data better than the personality-only model. Note that the traits (PCA components) in the personality and behavior model are composed of more variables (n = 28) than the personality-only model (n = 17) because there are behaviors as well as personality variables. However, both models have the same number of predictors, giving them equal model complexity for the Bayes Information Criterion. The better fit of the personality and behavior model is likely due to the traits better capturing herding ability.

Breed Differences. Lastly, we explored breed differences by comparing the border collies (n = 239) in our American sample to the kelpies in Wilson et al.'s (2022) Australian sample. Like the American sample as a whole, the border collies were less confident (border collie = 3.80 ± 1.00, kelpie = 4.14 ± 0.86, BF10 = 132.3) and less patient (border collie = 3.23 ± 1.06, kelpie = 3.49 ± 0.99, BF10 = 4.0) than the kelpies. However, the border collies were also more timid (border collie = 2.31 ± 1.07, kelpie = 2.01 ± 0.93, BF10 = 11.8) and impulsive (border collie = 2.87 ± 1.13, kelpie = 2.58 ± 1.13, BF10 = 4.0) than the kelpies.

Discussion

In this study, we replicated and built upon previous literature addressing the complex associations between dogs personality, behavior, and herding ability.

The first research question investigated which personality variables in dogs are associated with owner-reported overall herding ability by replicating Wilson et a. (2022). The personality traits in our sample are similar to those reported by Wilson et al. (2022), but their best-fit regression model included four PCA components while our model only included two. Our best-fit model for predicting herding ability rating included both the confident and biddable personality traits. The confident trait describes a dog that is intelligent and does their job without hesitation. Dogs with the biddable personality trait are high on variables related to ease of training, energy level, and fear. The variables most heavily weighted in the confident and biddable traits are also included in Wilson et al.'s personality components. The confident trait is in line with prior literature (e.g., Svartberg (2002)) supporting a positive association between confidence/boldness, intelligence, trainability, and working performance. While confident is low on fear, biddable is high. Fear is often found to be undesirable in working dogs (Dollion et al., 2019; Rooney et al., 2016; Scott & Fuller, 2020; Svartberg, 2002), but our evidence suggests the story might not be so simple in herding dogs. Overall, while some of our findings are in line with Wilson and colleagues (2022), others differ.

Expanding on the replication, our second research question asked whether a combination of personality and behavioral variables could predict herding ability. We found that a combination of both personality and behavioral variables significantly predict overall herding ability. This model was more complex than the best-fit personality model and accordingly explained more variance. Both the proactive and active traits appeared in the personality and behavior model. The herding behaviors in the proactive trait collectively paint a picture of a dog that is skilled at reading and anticipating the actions of livestock. The active trait, on the other hand, describes a hyperactive dog that is impulsive and excitable. Both traits predicted higher herding ability ratings, though the proactive trait offers more predictive power within the model. The weighting of individual behavioral variables within the traits suggests that some herding behaviors are more relevant than others. This supports owner's perceptions that some herding behaviors are more important to overall herding ability than others (Early et al., 2019). While the personality and behavior model is more likely to produce the observed data, we do not put too much weight in this comparison. The personality and behavior model is more complex than the personality-only model and would be expected to perform better in a test that does not account for the complexity captured by the PCA components. Future studies could address this limitation by designing analysis plans with the goal of comparing models.

Working environment played a role in the best-fit model for predicting herding ability. Dogs that work in utility settings (a combination of large and small spaces) and compete in herding trials were also more likely to be rated highly. Exploratory analyses expanded this finding to show that dogs with experience working in both farm and trial settings had significantly higher ability ratings than those with only farm experience. Our sample did not have a large enough group of dogs with trial-only experience to statistically compare with the other two groups. However, the mean ability rating of dogs that only had trial experience was the lowest of the three groups. Of the dogs with trial experience, those who competed in more trials were given higher ability ratings than those who competed in fewer trials. In a univariate linear regression, number of trials a dog competed in predicted herding ability. When taking age into account, however, the effect of number of trials was no longer significant. Future studies could systematically examine the effect of herding environment on herding ability by collecting longitudinal data to account for age and purposefully sampling across working environments.

Age was present in both of our best-fit multivariate regression models, with younger dogs receiving higher overall ability ratings than older dogs. However, the association between age and ability is not simple enough to be captured in a correlation or univariate regression. The relationship between age and ability only emerges once we have controlled for the effects of a number of other predictors. Similarly, sex of the dog was a predictor in the multivariate model but not a significant correlate or predictor on its own. After controlling for age, gonad status, work environment, personality, and behavior, male dogs received higher ability ratings than female dogs. Gonad status was also included in the best-fit multivariate model and both correlated with and predicted overall ability on its own. Owners rated intact dogs significantly higher on their herding ability than spayed/neutered dogs. Neutering dogs, particularly males, impacts their behavior (Arroube & Pereira, 2025; Fadel et al., 2016). Our findings could suggest that the post-neuter behavioral presentation is less useful for herding than the intact presentation. On the other hand, owners may be more likely to keep their most skilled herding dogs intact for breeding purposes. The effect of gonad removal on ability rating could be specifically studied -and potentially ruled out as an explanation -with a pre-post research design.

In our last research question we compared our American study sample to the kelpies in Wilson et al.'s Australian study sample. We found that the American dogs were rated as less confident, calm, patient, hyperactive, and friendly than the Australian dogs. Differences between these samples suggest that personality could differ between the American and Australian populations of herding dogs. As Wilson and colleagues (2022) point out, geographic regions can create different environmental pressures that favor dogs with particular behavioral traits. Beyond geography, humans play a large role in the selection and breeding of dogs. Americans and Australians could prefer dogs with different personality profiles. Breed is another possible driver of differences between the samples. We explored the effect of breed in this comparison by repeating the analyses with a subset of our sample that included only border collies. Compared to the Australian kelpies, our border collies were rated as less confident and patient, and more timid and impulsive. The personalities of the border collies may be driving the observed differences between our samples as a whole. Border collies and kelpies are used for the same general purpose, but they are two distinct breeds with unique herding styles. The present study cannot untangle the influence of breed from that of country. More research specifically designed to examine the differences between populations of herding dogs would allow for greater generalization of findings.

Limitations

Our findings are limited by the cross-sectional design of this study. Though our sample represented a wide geographical range within the United States, we cannot generalize to herding dogs living in other countries. Similarly, our sample predominantly consists of border collies, limiting our ability to generalize across herding breeds. As we note, the present study cannot separate the effects of breed and location on dog personality. Our personality and behavioral variables represent different types of ratings. The personality ratings capture the owner's perception of how strongly the dog presents the personality adjective (e.g. boldness). On the other hand, the behavioral ratings record the owner's perception of how skilled the dog is at the behavior listed. While this distinction may seem slight, it means that values on these two variables must be interpreted differently. Behavioral variables in this study cannot tell us the intensity or "how much" of a behavior is desirable. Skill level on behavioral variables and overall herding ability may be overlapping concepts. This could explain the relatively high correlations between most of the behavior variables and the herding ability rating. The present study focuses on dog owner perceptions of dog traits and abilities. There is evidence to support the validity of owner report for dog personality and behavioral variables. However, we do not claim that owner perceptions are accurate representations of some underlying "true" level of herding ability. The construct that we are operationalizing with owner ratings of herding ability is a human perception of herding. Importantly, these perceptions are what drive decision making about herding dog populations. Though we did not measure ability directly, measuring perceptions is useful since these perceptions inform decisions about which dogs are selected and bred for herding, as well as how they are trained.

Implications

Ultimately, our goal is to improve the success rates of herding dogs. This study can inform decision making and training for the success of adult herding dogs in the United States. Prior literature suggests that dog personality and behavior are influenced by a combination of genetics and environment (Fratkin et al., 2013; Salonen et al., 2023; Strandberg et al., 2025).

Heritability estimates vary for herding behaviors. Arvelius et al. (2013) found moderate to high estimates for the traits included on the Herding Trait Characterization, while Storteig Horn et al. (2017) found much lower rates for the behaviors scores in Norwegian herding trials. We used a modified version of the Livestock Working (Herding) Dog Assessment Form to capture behaviors which show initial evidence for heritability estimates of at least 0.15 (McGreevy et al., 2015). We provide evidence that these (potentially) heritable herding behaviors are linked to owner ratings of overall herding ability. In line with previous literature, we suggest that selective breeding based on specific herding behaviors is a viable method for increasing overall herding ability over generations.

Beyond breeding, interventions can focus on variables that are susceptible to environmental influence. For instance, desensitizing and counter-conditioning can be used decrease a dog's fear responses to specific stimuli (Mai et al., 2021; Rooney et al., 2016). Persistence, another personality variable which appears to be positively associated with herding success, may be increased through training (Cavalli et al., 2022). Dogs that receive more training also tend to be rated as more trainable (Kubinyi et al., 2009). While this relationship is not necessarily causal or unidirectional, Kubinyi and colleagues found that the dogs that were rated the lowest on trainability in their sample were dogs over the age of three who had received no professional training. This provides initial evidence that training itself may increase the personality variable of trainability in dogs. Training for herding dogs already focuses on herding behaviors, but could more intentionally target the behaviors identified in this study to make the most of training efforts. Additionally, training dogs to work in different environments could be beneficial. Dogs who frequently participate in herding trials may practice or learn new skills that benefit their overall herding ability. Taken together, this evidence suggests that training may be able to increase levels of personality and behavioral variables that are associated with herding ability in dogs.

Conclusions

Herding dogs play a critical role in the management of livestock worldwide. Yet we know little about the factors underlying their herding performance. In this study, we have replicated previous work in a new sample of herding dogs and expanded the narrow body of knowledge on herding dogs. The personality and behavioral traits identified in this study may be used to inform dog owner's decisions about dog career paths and training efforts for herding dog success.
