Reporting p values imprecisely (e.g., p < .05) reduces transparency, reproducibility, and re-use (e.g., in p value meta-analyses). Best practice is to report exact p-values with three decimal places (e.g., p = .032) unless p values are smaller than 0.001, in which case you can use p < .001.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (e.g., “decreased at the p < .05 significance threshold”).

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

Participants were not informed about the neurotype of their interaction partners.

After the online session, subjects completed final questionnaires (see section 1 in Supplement for details) and were debriefed and thanked for their participation.

Volunteers were recruited through participant databases of the Institute of Cognitive Neuroscience at the University College London (UK) and the Center for Brain and Cognition at the Universitat Pompeu Fabra (Barcelona, Spain).

Autistic participants were additionally recruited via X (Twitter), Prolific, UK-based autistic charity organizations (Autistica, Center for ADHD and Autism Support), internal communication within AIMS-2-TRIALS, informal peer networks within the autistic community, and the University of Sheffield’s autistic contact list.

Non-autistic participants were additionally recruited via study flyers at University College London campuses.

All participants provided electronic informed consent forms and received financial compensation for their participation: €10 per hour for Spain-based participants or £10 per hour for UK-based participants.

Recruited volunteers were autistic or non-autistic adults between 20 and 35 years of age, fluent in English or Spanish, and with no self-reported learning disability nor speech impairment.

Autistic participants were required to confirm having a clinical autism diagnosis (e.g., Autism Spectrum Disorder, Asperger’s Syndrome).

Non-autistic participants were excluded if they were under the care of a psychologist or psychiatrist (i.e., an NHS professional for UK-based participants or a clinical psychologist/psychiatrist for Spain-based participants).

^Note: Participants were asked whether they know anyone who is autistic; response options were: F = yes, a family member/partner, C = yes, a close person (e.g., a friend), NC = yes, not a close person (e.g., work colleague), N = no.

Participants were never informed of others’ neurotypes, and they never explicitly revealed their status in the study.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. Abstract

Social connection is often conceptualized as an individual competence, yet it fundamentally unfolds through dynamic coordination between people. To test what drives social connection across diverse interaction styles, we examined naturalistic conversations between autistic and non-autistic adults using a round-robin design. We combined multimodal behavioral tracking-spanning dozens of behaviors across facial expression, head movement, vocal prosody, and turn-taking-with dispositional profiling across same-and mixed-neurotype dyads. Non-autistic dyads reported higher rapport than mixed pairs. While individual dispositions (traits, states) shaped evaluations, non-verbal synchrony emerged as the sole behavioral predictor of rapport across all dyad types. In contrast, none of the individual behaviors were linked to connection. Autistic participants showed greater motivation to interact again with their partners. By demonstrating that rapport operates through interpersonal coordination even across contrasting communicative profiles of autistic and non-autistic adults, these findings establish that social connection is an emergent property of interacting minds.

1. Introduction

Social interaction is a dynamic, multidirectional process. An individual's disposition, behaviors, and perspectives interact with those of their interlocutor, and with situational context (Monnier et al., 2025). Individual cognitive and motivational traits and reciprocal interaction together create 'social feedback loops' (West et al., 2026) allowing rapport and other social qualities to emerge between people. While neuroscience and psychology have traditionally focused on social cognition from the perspective of an individual observer, there has been a surge of studies investigating real-time, person-to-person interactions (Jaegher et al., 2010; Schilbach et al., 2013). These aim to answer the longstanding question of how people connect with each other, and why this process is not equally easy for everyone. As difficulties in social interaction are a core characteristic of Autism Spectrum Disorder (hereafter: autism) (American Psychiatric Association, 2013), autism provides a valuable lens for understanding the complexity and variability of human interaction. In the present study, we report a multidimensional analysis of behavioral and dispositional factors in real-time interactions between same and mixedneurotype dyads, identifying predictors of rapport and motivation for future encounters, and contrasting the diverse interaction characteristics of autistic and nonautistic adults.

1.1. Social interaction difficulty in autism

Although the fact that autistic 1 people experience significant social interaction difficulties is widely agreed upon, it is debated if these difficulties are caused exclusively by the individual's deficits in social skills, as the traditional, clinical model suggests. In this traditional model, autism is a disorder with persistent social deficits in communication and interaction across contexts (American Psychiatric Association, 2013). As such, autistic people may have limited ability to 'read' other people's minds, interpret their behaviors, and they lack motivation to engage in social relations (e.g., Baron-Cohen et al., 1985; Chevallier et al., 2012). However, more recent perspectives and greater involvement of the autistic voices in research have challenged these assumptions (e.g., Gernsbacher & Yergeau, 2019; Jaswal & Akhtar, 2018). An alternative framework, the social model of autism aligned with the neurodiversity movement, views autism as a natural variation of human neurobiology. In this model, social difficulty or disability experienced by autistic individuals comes at least partially from the inaccessible society built mainly in line with the needs and norms of the typically developing people who form the majority of the society. Thus, the interactional difficulties emerge primarily from the mismatch between individuals of vastly different dispositions, like in the case of autistic and nonautistic neurotypes (Bolis et al., 2017; Milton, 2012).

These two models -clinical and social -can be viewed as complementary. For example, autistic individuals may produce (Brewer et al., 2016; Sheppard et al., 2026) and decode (Harms et al., 2010) facial expressions differently than typically developing people, making it harder to read and be read by both non-autistic and other autistic peers (Alkhaldi et al., 2019; Brewer et al., 2016; Sheppard et al., 2016). At the same time, same-neurotype dyads -both autistic or both typically developing -often report having smoother and more successful interactions than mixed-neurotype pairs (Crompton, Hallett, et al., 2020; Crompton, Sharp, et al., 2020; McNaughton et al., 2024; Morrison et al., 2020; Rifai et al., 2022), which emphasizes the relative construction of the social meaning and the importance of compatibility with another person in relationships (Finke & Dunn, 2026). Therefore, social challenges in autism may have both individual and relational origins.

In a recent review (Matyjek et al., 2025), we analyzed studies comparing autistic dyads with nonautistic or mixed-neurotype dyads (one of each neurotype), and found both behavioral similarities (e.g., general turn-taking) and differences (e.g., reduced mutual gaze and backchannelling -listener's signals like "yeah", "aha", or nodding) in autistic interactions. The clearest differences between autistic and neurotypical interactions related to interpersonal (e.g., mutual gaze, backchannelling, reciprocal smiling), as opposed to intrapersonal (e.g., individual facial expressiveness, prosody, tendency to smile) behaviors. Despite this relational nature of socially meaningful and observable behaviors, the strongest support for the social model of autism -with interactions being more successful in autistic than mixedneurotype pairs -came from studies measuring self-reported social interaction outcomes, like subjective ratings of rapport.

Because interlocutors cannot access each other's internal states directly, these subjective feelings of connection must be informed by the observable behaviors they witness in real time. However, because past work has focused mainly on singular behaviors in isolation, it remains unclear which specific features-or combinations of features-drive these evaluations. To determine what makes an interaction click, we need an approach that tracks multiple behaviors simultaneously, testing whether rapport is shaped by a partner's individual expressive style, the emergent coordination between them, or both.

1.2. Components of social interaction

Human social interaction is inherently complex, involving two or more agents who continuously generate and respond to information on multiple levels (Holler & Kuhlen, 2026; Holler & Levinson, 2019; Jaegher et al., 2010; see Figure 1A). Each participant brings their own disposition to the interaction, including stable traits such as personality, social anxiety, tendency to mask or camouflage some behaviors, and reasoning skills, as well as transient states such as stress, fatigue, or momentary anxiety (Hessels et al., 2018; Neff et al., 2021). Social interaction also depends on interactants' sociocognitive abilities, including theory of mind, emotion recognition, and empathy, and on their social motivation, that is, the willingness to engage and the reasons for doing so (Schilbach et al., 2013).

Social behavior can be considered at two levels (Matyjek et al., 2025). One level concerns intraindividual tendencies, such as a person's propensity to smile or to speak with a melodic prosody. The other level concerns interpersonal coordination processes (driven by one or more interactants) that emerge between interactants, such as turn-taking, backchannelling, or behavioral synchrony (e.g., one person's smiling triggering the smile of the partner). In real-time conversation, communicative cues systematically co-occur as composite multimodal signals that serve shared communicative functions (Enfield, 2009; Holler & Levinson, 2019; Trujillo & Holler, 2023). Because different behavioral cues are often aligned functionally -despite differences in timescales (Hamilton et al., 2026) -they naturally cluster into coherent behavioral families (Van Kleef, 2017). For example, one can nod and utter "oh, wow", both to provide listener feedback and contribute to interpersonal alignment. Similarly, intraindividual expressivity and prosodic dynamics combine facial expressions, laughter, and pitch variation to signal personal warmth and communicative intents (Ambady & Rosenthal, 1992; Scherer, 2003). Further, interpersonal dynamics unfold across distinct coordination systems: the discrete, structural rhythm of turn-taking that regulates conversational exchange (Levinson, 2016; Sacks et al., 1974), and the continuous non-verbal synchrony that binds interactants' movements and expressions into a shared temporal alignment (Tickle-Degnen & Rosenthal, 1990; Wheatley et al., 2012). All these individual and dyadic processes jointly shape the outcomes of social interaction, which may include subjective evaluations of rapport, liking, and willingness to interact again, as well as more objective outcomes, including information transfer or joint task performance (Tickle-Degnen & Rosenthal, 1990; Vacharkulksemsuk & Fredrickson, 2012).

1.3. Predictors of social success

Defining successful interaction is not straightforward. Sometimes, the goal of an interaction is to transmit information (e.g., giving someone directions to a train station). Oftentimes, a goal (primary or secondarily) is to build connection. In such settings, social success -and difficulty -have a subjective nature and different neurotypes may rely on different social behaviors in building their subjective judgements of interaction quality. In neurodiverse interactions it is important not to assume that norms of typically developing individuals are the ground truth for interaction quality judgements. For example, in neurotypical interactions, greater mutual gaze is often associated with more positive outcomes, such as increased satisfaction or liking (Senju & Johnson, 2009). Yet this pattern does not necessarily generalize to autistic-autistic interactions (Crompton, Sharp, et al., 2020; Heasman & Gillespie, 2019). Further, even though autistic people are rated more negatively (social warmth, awkwardness, attractiveness) by both typically developing and other autistic observers, some studies show that both groups prefer to share future interactions with people of the same neurotype as their own (Morrison et al., 2020). Thus, autistic individuals may be more 'forgiving' of unsuccessful exchanges and open to repeating an interaction regardless of the immediate first impressions. Alternatively, they may simply rely on different social cues in the formation of the interaction quality judgements. Deviations from typical development norms should therefore not be interpreted automatically as evidence of poorer interaction. Instead, the quality of an interaction should be assessed with reference to the subjective experiences of each participant (Crompton, Sharp, et al., 2020; Milton, 2012).

This raises our central question: what predicts rapport or motivation for continuing the relationship, and for whom? One likely source is a person's own disposition, which shapes how we interpret and experience the interaction. For example, higher social anxiety may bias attention towards threat, increase self-consciousness, and thus contribute to a more negative subjective experience of the interaction (Nordahl et al., 2017). A second source is the partner's behavior, from which impressions of warmth, confidence, and sociability are formed, and which in turn can influence liking and rapport (Ambady & Rosenthal, 1992; Gratch et al., 2007). A third source is the degree of interpersonal coordination that emerges between the two interactants. Real-time interactions involve constant prediction of the other's movements, which can help to attribute their affective, cognitive, and motivational states and adjust our actions accordingly to ensure a smooth and fluid interaction (Koban et al., 2019; Sebanz & Knoblich, 2009). In neurotypical interactions, greater non-verbal coordination is associated with more positive outcomes, including liking, rapport, and interaction satisfaction (Vacharkulksemsuk & Fredrickson, 2012). We therefore argue that, in dyadic interaction, an individual's subjective social outcomes are likely shaped by their own disposition (traits and states), their partner's behavioral tendencies (intonation and non-verbal expressivity), and the interpersonal dynamics that emerge between them, including both verbal and non-verbal domains (turn-taking, backchannelling, non-verbal synchrony; Figure 1B). Although identifying predictors of positive social interaction outcomes is clearly important, 'because of the gestalt nature of the experience of rapport, it is not easy to identify nonverbal behavioral correlates of the components' (Tickle-Degnen & Rosenthal, 1990). Even seemingly intuitive predictors of positive outcomes, such as a smile, can signal different things depending on the context (a positive expression of warmth or a negative expression of anxiety; Martin et al., 2017).

To identify predictors of social interaction outcomes, it is therefore necessary to observe multiple interactions in their natural behavioral flow and relate these patterns to individual subjective evaluation of the interaction. Only recently has this become feasible, owing to advances in recording technology, automated behavioral analysis, computational power, and statistical methods. However, most existing studies have focused on singular types of behaviors, such as smiling, gaze, or motion energy (McNaughton et al., 2024; Plank, Traiger, et al., 2023; Rifai et al., 2022). Studies that have adopted a broader, more data-driven approach to verbal and non-verbal behavior have tended to focus on predicting autism classification rather than interaction quality (Drimalla et al., 2019; Plank, Koehler, et al., 2023). What is currently lacking is an exploratory, data-driven approach that can identify which behavior streams and dispositional characteristics are associated with positive interaction outcomes across naturalistic social encounters with neurodiverse participants. 1.4. Current study

Here, we analyze dispositional and behavioral predictors of two subjective evaluations of interaction success -rapport and social motivation to meet again in the future -in naturalistic interactions of dyads composed of two autistic (AUT), two non-autistic (NAUT), or one autistic and one non-autistic adult (MIX). Participants joined an online session in which they interacted in a roundrobin design with peers of their own and of the other neurotype over a goal-free, 'get-to-know-you' conversation (see Figure 2). Round-robin designs provide a powerful methodological framework for dyadic research because they allow us to statistically disentangle individual-level tendencies (how a person generally behaves or evaluates others) from partner effects (how they are evaluated by others) and unique dyadic chemistry (the connection specific to a given pair; Kenny, 1988). While previous round-robin studies have successfully used this approach to unpack singular behaviors -such as nonverbal mimicry (Salazar Kämpf et al., 2018) or laughter (Wood et al., 2022) -we extend this logic across a multimodal set of social signals. A battery of standardized questionnaires was used to quantify participants' traits and states, and subjective ratings of rapport and social motivation were collected for each interaction and participant. To identify what drives connection without a priori assumptions, we combined dispositional components based on individual traits and states (Figure 1D) with dozens of intra-and interpersonal behaviours, organised into multimodal behavioural composites of signals spanning individual expressivity and intonation, and interpersonal non-verbal synchrony, turn-taking, and backchannelling cues (Figure 1C). 3. Discussion

We examined dispositional and behavioral predictors of self-reported rapport and social motivation in naturalistic online conversations between autistic, non-autistic, and mixed-neurotype dyads. Overall, the results suggest that subjective social connection is shaped by a combination of individual dispositions, relational dynamics, and the specific pairing of two people, rather than by a stable set of individual behaviors or by neurotype alone.

Non-autistic dyads reported higher rapport than mixed-neurotype ones, whereas autistic dyads did not differ reliably from other pairing compositions. At the same time, self-reported motivation to meet again did not differ between the dyad types. This result does not provide clear support for either a strictly clinical account, which would predict poorer outcomes in autistic dyads, or a strong social-mismatch account, which would predict superior outcomes in autistic compared with mixed dyads. It also cannot be explained by non-autistic individuals being better guessers of their partners' diagnosis status and showing an explicit same-neurotype preference: a secondary analysis suggested that both groups were similarly better in guessing partners matching their own neurotype. Instead, it is consistent with evidence for a social privilege of non-autistic individuals, whose interaction style is often more readily recognized and rewarded as socially successful, including in brief interactions and first impressions (Morrison et al., 2020; Sasson et al., 2017; Sheppard et al., 2016). Such social privilege may contribute to the higher rapport observed in non-autistic dyads without necessarily implying that autistic people are intrinsically less able to form social connection.

The predictor models of rapport and social motivation shed light on what drives these evaluations. Non-verbal synchrony was the only behavioral family emerging from dozens of considered behaviors that consistently predicted rapport. This non-verbal synchrony was a composite reflecting greater temporal coordination in smiling, laughter, facial expressivity, and head movement, and was associated with stronger perceived rapport across dyad types and neurotypes. This expands on a large body of work linking interpersonal coordination to affiliation, liking, interaction quality, and rapport (Fujiwara et al., 2026; Tickle-Degnen & Rosenthal, 1990; Tschacher et al., 2014; Vacharkulksemsuk & Fredrickson, 2012), a relationship shown to be causal through real-time manipulation of expressive alignment (Arias-Sarah et al., 2024). Our results extend this association to autistic and mixed-neurotype dyads and suggest that non-verbal synchrony may be a general relational process rather than a specifically nonautistic marker of successful interaction. Recent work similarly indicates that autistic people can show social motor synchrony comparable to non-autistic people, even where subjective interaction experiences vary between dyad compositions (McNaughton et al., 2024).

Remarkably, none of the intrapersonal behavioral families emerged as stable predictors of rapport or social motivation. In other words, participants' rapport and social motivation ratings were not systematically predicted by how much one partner smiled, laughed, nodded, moved, spoke, or by their intonation tendencies. This does not mean that these behaviors are irrelevant. However, the dyadic, relational, interpersonal behaviors are more impactful on the emerging social outcomes. For example, smiling frequently influences rapport when it elicits a reciprocal response from the partner. Therefore, our findings support approaches that treat socially meaningful behavior as interactional rather than as a property of a single person (Jaegher et al., 2010; Sebanz & Knoblich, 2009).

It is worth noting that beyond our specific behavioral findings, the overarching variance structure of the data provides statistical support for a relational account of social interaction. By using a roundrobin design where each participant interacted with multiple partners, we applied Social Relations Modelling to decompose subjective outcomes into three sources: how a person generally evaluates others (rater effect), how a person is generally evaluated by others (partner effect), and the unique chemistry of a specific pairing (dyad effect). For rapport, this unique dyadic effect accounted for the largest share of explained variance (43%), outweighing rater (32%) and partner effects (26%). A similar relational contribution shaped social motivation to meet again, with dyad-specific effects accounting for 34% of the explained variance. This relational complexity also explains why we found a large effect for non-autistic dyads reporting higher rapport than mixed-neurotype dyads even though the dyad type had limited rapport-predictive value (based on approximated Bayes Factors). Similarly, our selected dispositional and behavioral features captured only a portion of the structured variance (fixed effects marginal R² values of .15-.20) compared to the total variance explained when accounting for the specific pairing of two individuals (total model conditional R² values of .68-.74). Rapport and social motivation therefore reflect not only who people are, but also the particular combination of two people and numerous unmeasured features of the encounter, such as prior expectations, conversational content, shared interests, and momentary states (Ambady & Rosenthal, 1992; Hessels et al., 2018; Monnier et al., 2025). A key strength of our exploratory, data-driven approach is precisely that it isolates stable predictive features-such as non-verbal synchrony-without flattening this complexity based on a priori decisions.

Social interaction outcomes were also predicted by the rater's dispositions. Both rapport and social motivation were positively associated with cognitive engagement and negatively with autism-like traits. Importantly, these associations did not vary by rater neurotype or dyad composition. While the negative link with autism-related traits reflects the immediate burden of social anxiety and effortful selfmonitoring (Hull et al., 2017; Nordahl et al., 2017), the positive role of cognitive engagement highlights the executive demands of conversation. This component integrated both stable traits (higher loading of reasoning and conscientiousness) and transient states (lower momentary stress and tiredness). Real-time conversation is a fast-paced, predictive process: tracking cues, inferring intentions, and adapting responses in the moment requires attentional and executive bandwidth (Schilbach et al., 2013). Crucially, because this component spans both traits and states, it demonstrates that successful interaction depends not only on baseline cognitive resources, but on immediate access to them in the moment (Wilson & Hutcherson, 2026). Given that navigating social environments can be disproportionately fatiguing and taxing for autistic adults (Hull et al., 2017), future research should move beyond static trait measures to track time-point-to-time-point fluctuations in stress and exhaustion, examining how the real-time depletion of cognitive resources shapes social outcomes over the course of an encounter.

Attitudes towards autism also predicted greater social motivation in autistic and mixed dyads, but not in non-autistic dyads. Similarly, when looking at the neurotypes of each interactant instead of the dyadic composition, attitudes towards autism mattered when interacting with autistic, but not nonautistic partners. This context-specific association suggests that positive beliefs about autism matter when autism is socially relevant to the interaction. For example, attitudes may shape whether differences in conversational rhythm, expressivity, or other interactional features are interpreted as signs of incompatibility or as acceptable variation. This aligns with evidence that autistic and non-autistic people can differ in how they interpret one another's behavior and mental states, and that social difficulty often reflects reciprocal misunderstanding rather than an individual autistic deficit (Crompton, Sharp, et al., 2020; Heasman & Gillespie, 2019). Positive attitudes may thus be one route through which people become more accommodating of individual atypical interactional styles.

Interestingly, in the model with both interactants' neurotypes, autistic participants reported higher social motivation overall than non-autistic participants, regardless of their partner's neurotype. This finding challenges accounts that treat autism as involving a general reduction in desire for social contact (Chevallier et al., 2012). Instead, it suggests that autistic people are motivated to pursue new social relationships even when interactions are effortful or when they experience greater stress or tiredness. This pattern is consistent with accounts suggesting that reduced social participation in autism may reflect inaccessible social environments, repeated negative social experiences, anxiety, or limited opportunities rather than reduced interest of the individual (Jaswal & Akhtar, 2018; Milton, 2012).

Autistic adults often report loneliness and barriers to developing satisfying relationships, yet loneliness is associated with factors such as social anxiety, limited social support, and dissatisfaction with available relationships rather than autism alone (Mazurek, 2014). Future studies should examine whether higher willingness to socially re-engage reflects greater openness to new connection, fewer opportunities for social contact, greater tolerance of interactional awkwardness, or some combination of these explanations.

In the light of this broader pattern of results, the association between autism-related traits and lower rapport tells a nuanced story. On the one hand, this finding validates the lived experience of autistic people, for whom navigating social interaction is often cognitively and emotionally demanding, exhausting, and accompanied by the frustration of feeling misunderstood (Hull et al., 2017). On the other hand, because autism-like traits influenced rapport across all dyad types, this association should not be mistaken for a lack of social drive or inherent inability to connect in all autistic people. Crucially, social difficulty does not equal a lack of social motivation: autistic participants in our study reported higher social motivation to meet again with their interaction partner, regardless of their neurotype, compared to non-autistic raters. Furthermore, the "autism-related traits" component combined high loadings of autistic traits, social anxiety and camouflaging with low extraversion, and therefore likely captured a broader profile of social atypicalities rather than autism alone. For example, social anxiety can increase concern about negative evaluation and self-focused attention, and camouflaging can make social participation cognitively and emotionally demanding (Cage & Troxell-Whitman, 2019; Hull et al., 2017; Nordahl et al., 2017). Finally, autism-related traits -and other primary drivers of the outcomes: non-verbal synchrony, cognitive engagement -cut across diagnostic borders, with similar effects in autistic, non-autistic, and mixed-neurotype interactions. These findings show that clinical and social perspectives need not be mutually exclusive: while clinical frameworks capture the individual dispositions that make social navigation more effortful, the social model highlights how connection ultimately emerges through shared relational dynamics and mutual accommodation.

Several limitations should be considered. First, interactions in this study took place online, where visual information, mutual gaze, bodily coordination, conversational timing, and social presence differ from in-person encounters. Nevertheless, large-scale datasets of video-mediated conversations demonstrate that online interactions capture rich, ecologically valid interpersonal dynamics (e.g., the CANDOR corpus; Reece et al., 2023), and our replication of a synchrony-rapport association previously observed in face-to-face settings further suggests that online interaction reflects fundamental relational processes. Second, this study did not examine conversational content or mutual gaze. Topic selection, common ground, self-disclosure, humor, agreement, and repair of misunderstanding along dynamic negotiation of mutual gaze are likely to contribute substantially to rapport and to motivation for continued interaction. Future research should integrate automated behavioral analysis guided by our feature selection results with linguistic, semantic, and discourse-level measures, and extend it to eye contact information. Another valuable missing information would be quantification of participants' loneliness or social network. This could shed light on whether the increased social motivation in the autistic group here was motivated by reduced current social opportunities. Further, our sample size and demographic scope were modest. Future work should test larger cohorts across wider age ranges and varied socio-demographic backgrounds. Finally, the present study was exploratory and feasibility constrained. Its value lies in taking a broad, data-driven view of interaction rather than testing one presumed marker of autistic social difficulty. The selected effects should therefore be treated as targets for preregistered replication in larger and more diverse samples, rather than as exhaustive explanations of social connection. Although our secondary models suggested that gender (mis)match, age difference, and language (English, Spanish) did not influence the pattern of reported results, future studies should examine whether these results generalize across diverse cultures, languages, genders, ages, communication modalities, and in-person settings, as well as across relationships that develop beyond a first encounter.

To conclude, our findings suggest that social interaction is not an individual performance against a fixed set of normative social skills. On the contrary, social connection is created between people more than located within an individual. While individual cognitive engagement supports the resources needed to interact, interpersonal non-verbal synchrony acts as the primary behavioral drive of rapport across diverse dyad compositions, showing how personal dispositions and relational dynamics jointly shape connection. Autism makes this diversity especially visible because autistic people often navigate social environments built around non-autistic expectations. Thus, autism provides a useful lens for studying variation in social dispositions in general, but diagnostic categories alone cannot explain how people experience an interaction. Ultimately, all social interactions depend on fit, mutual interpretation, and shared adaptation. Supporting connection should involve reducing the pressure to conform to a single normative interactional style and sharing the responsibility for mutual understanding across all interaction partners.

Sample size was determined in advance by time and funding constrains. The maximum sample size was estimated at 60 participants balanced between autistic and non-autistic individuals. 4.2. Procedure

We employed a partial round-robin design to examine interaction dynamics across autistic-autistic (AUT), non-autistic-non-autistic (NAUT), and mixed-neurotype (MIX) dyads (see Figure 2A and B). Ten videoconference sessions were conducted via the Zoom application, five in English and five in Spanish. Each session comprised six participants (three individuals of each group). Participants were never informed of others' neurotypes, and they never explicitly revealed their status in the study. Each participant completed four dyadic interactions: two same-neurotype and two mixed-neurotype, yielding a total of 12 interactions per session. Where a participant was missing (no-show, N=3), an experimenter completed the interaction with the unpaired participant to preserve the session structure; these interactions were excluded from analysis. For a visualization of the study flow, see Figure 2C. Participants first completed an online preexperimental survey with demographics and trait questionnaires (see Table 1). Several days later, they attended a recorded Zoom session, accompanied by two experimenters. Participants were assigned in pairs to three simultaneous breakout rooms across four interaction rounds. Their self-view was disabled. An experimenter was present in each breakout room with their camera and microphone disabled, monitoring passively.

Each interaction lasted 10 minutes and comprised two five-minute tasks. First, dyads engaged in an unstructured 'get-to-know-you' conversation. Optional prompts were provided to facilitate discussion (weather, pets, hobbies, etc.), but participants could select their own topics. Second, dyads completed a word-description task inspired in the Taboo board game 2 . In this article, we analyze only data from the unstructured conversation (however, the behavioral measurements correlated between the tasks, see section 2.2.6. in the Supplement).

After each interaction, participants completed a brief questionnaire rating their current states (stress, tiredness, anxiety) and evaluating the most recent interaction with another participants in terms of rapport and social motivation (more ratings were assessed in the study which are beyond the scope of this paper). Both rapport and social motivation were rated on a 0-100 scale. Participants were then allocated a new partner for the subsequent round. Following the videoconference session, participants completed a post-experimental questionnaire with autism-related items (see Table 1). See section 1 in the Supplement for details on all collected states/traits data.

4.3. Data preprocessing

We derived individual and dyadic behavioral measures from the interaction recordings. See all extracted behaviors and their correlations in Figure 1C. Video was processed at 25 Hz with OpenFace v. 2.2.0 (Baltrušaitis et al., 2016) (facial Action Units -AU -head pose, and landmarks): individual measures comprised the proportion of time smiling (concurrent AU6 and AU12 activation) and laughing (manual coding; ICC ≈ .85), mean facial expressivity (summed intensity of 17 AUs), head movement magnitude (frame-to-frame Euclidean magnitude of three-dimensional head rotation), and nod frequency (calculated with head-pose features using a custom random-forest classifier). Dyadic synchrony for smiling, laughter, expressivity and head movement was indexed by the absolute mean cross-correlation across consecutive 30-s windows, evaluated over lags of 2s. For each synchrony measure, observed dyads were compared against 1,000 shuffled pseudo-dyads to confirm that the observed synchrony was consistently greater in real than pseudo-dyads.

Audio recordings were transcribed with Whisper (Radford et al., 2022), checked and corrected manually, and segmented in Praat 6.4.26 (Boersma et al., 2025) into speaker-labelled inter-pausal units (continuous speech by one speaker with <200 ms silences). These annotations yielded individual and dyadic measures of speech duration, turn duration, turn transitions, floor-transfer offsets (FTO), pure (floor stays with the primary speaker) and change backchannels (turn transition after the backchannel), and successful and failed turn-taking attempts. Backchannel rates were normalized by total turn length of the partner. Praat was also used to derive individual intonation measures (pitch variability, pitch range, wiggliness and spaciousness; Wehrle et al., 2018). Speech volume was extracted frame-by-frame from each participant's separate audio recording in Matlab and volume synchrony was quantified as the correlation between mean volume in consecutive cross-speaker primary turns. Detailed preprocessing, operational definitions, missing data handling, and quality checks are reported in section 2 of the Supplement.

4.4. Data analysis

In line with open-science practices, our research questions, round-robin design, multimodal measurement battery and the analysis approach were preregistered on the Open Science Framework: https://osf.io/dxngs/files/2gams. Our three-step analytical pipeline (dimension reduction, stabilitybased feature screening, and mixed-effects modeling, see below) is a refined implementation of this planned exploration.

All data were analyzed in R v.4.6.0 (R Core Team, 2026). First, we tested whether rapport/social motivation varied with dyad type (AUT/NAUT/MIX). Where appropriate, pairwise comparisons were corrected with Holm method. Social Relations Models (SRM) were additionally calculated to explore the effects of the rater, partner, and dyad pairing. Then, own dispositions, partner's behaviors and dyadic behavioral synchrony was analyzed to identify predictors of rapport/social motivation. For all analyses, one's own self-reported rapport and social motivation were predicted with the parter's intraindividual behaviors (e.g., partner's tendency to smile, partner's backchannel count normalized by own total turn length), dyadic behavioral metrics (e.g., number of floor transitions), and one's own dispositional traits (e.g., autism-related traits).

This was done in three steps: dimensionality reduction, predictor selection, and mixed model testing. We describe these steps below (see section 3 in the Supplement for more details). First, dimensionality of the data with multiple predictors was reduced separately for dispositional and behavioral variables to handle multicollinearity issues (see Figure 1C and Figure 1D). For disposition metrics, self-reported trait variables were reduced using Principal Component Analysis (PCA). The strongest three components were retained and interpreted as: autism-related traits (high loadings of autistic, social anxiety, and camouflaging traits, low extraversion), attitudes towards autism (high loadings of attitudes, stigma, and familiarity with autism, low openness), and cognitive engagement (high loadings of reasoning skills and conscientiousness, low stress and tiredness). See Figure 1D for the loadings of each disposition score on the three components.

Behavioral variables were first grouped into predefined theoretical families. See Figure 1C for a correlation plot between all behaviors and grouping into families. Two intrapersonal families: expressivity and intonation, and three interpersonal families: turn-taking, backchanneling, and non-verbal synchrony (see Table 2), were created. Raw behavioral variables were z-scored, and family-level composite scores were calculated by taking the mean of the variables within each family (see Supp. Figure 13 and 14 in the Supplement for correlation plots of behaviors and behavior families).

In the second step, predictor selection, because of the large number of potential predictors and interaction terms, we used Ridge regression as a feature screening procedure to identify stable predictors of rapport and social motivation before fitting final inferential models. We fit Ridge regression models using cv.glmnet function from glment v. 5.0 (Friedman et al., 2010) with a Gaussian outcome and alpha = 0 . The initial design matrix included all main predictors and their interactions with the participant's neurotype (autistic/non-autistic). Predictors were standardized, and model tuning was based on 10-fold cross-validation. To avoid data leakage, folds were assigned at the participant level so that all observations from a given subject were kept within the same fold. To evaluate coefficient stability, we performed a grouped nonparametric bootstrap with 500 resamples at the subject level. In each bootstrap iteration, participant IDs were sampled with replacement. To preserve the clustered structure of the data, duplicated bootstrap copies of the same participant were assigned unique bootstrap-specific IDs, and 10-fold cross-validation within each bootstrap sample was defined at this new ID level. A Ridge model was refitted within each bootstrap sample, and coefficients at lambda.min (the penalty yielding minimum cross-validated prediction error) were stored. Bootstrap inference focused on coefficient stability and effect size. Features were selected for the final analysis if they met two criteria across the 500 resamples: (1) a mean absolute coefficient magnitude of at least 1.5, and (2) a sign stability of at least 80% (i.e., the coefficient was positive or negative in at least 80% of resamples). To preserve structural hierarchy, main effects were automatically retained if their higher-order interaction terms were selected. See Figure 4 for the results of the stability selection procedure. Given the large number of potential predictors and interaction terms in our dataset, multicollinearity was a clear issue. Creating disposition components and behavioral families reduced this complexity, but testing all in mixed models still risked overfitting. In the final third step, mixed model testing, we fitted linear mixed-effects models (LMMs) to evaluate the impact of the selected predictors separately on rapport and social motivation using the lmerTest package v. 3.2.1. (Kuznetsova et al., 2017). Fixed effects included the selected in step two behavioral and disposition predictors, alongside their interactions with (1) dyad type to explore dyad composition general effects, and (2) partner's and rater's own neurotype, to explore further autistic and non-autistic differences within the MIX dyads. To account for the non-independence of dyadic data, models included crossed random intercepts for the actor, the partner, and the specific dyad. Model parameters were estimated using the bobyqa optimizer, statistical assumptions were checked before interpretation with diagnostic plots, treatment contrasts were used, and main effects (across the threelevel dyad composition) were interpreted with ANOVA on the model. Bayes factors (BF) were approximated using the Schwarz criterion (BIC; (Wagenmakers, 2007)). Finally, three control variables: absolute age difference between the partners in a dyad, gender matching (binary:1 = match,0 = nonmatching), and language (English/Spanish) were added as fixed effects to test for their potential confounding effects. Likelihood ratio tests and information criteria (AIC/BIC) indicated that these demographic controls did not improve model fit, so they were excluded from the final models, but are reported in section 4 of the Supplement.
