Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Checking code requires downloading its file contents. For a paper whose repository is on Dryad, this never succeeds unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (listing the repository’s files does not need one). Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Food learning in early life largely relies on social learning. Previous research has shown that infants learn something is edible when they directly observe someone else eating it.

However, the role of other forms of food-related social information remains largely unknown.

Food processing actions (e.g., chopping, mashing) are essential components of human food behaviors and a ubiquitous part of infants' everyday lives. Here we examined whether infants (i) differentially attend to eating and food processing actions compared to control actions and (ii) learn that novel foods are edible after observing eating and food processing actions performed with them. We tested 12-month-olds' responses to three different actions: eating, food processing, and a control action (touch). First, we showed infants side-by-side videos of an adult performing two different actions with novel foods across three between-subjects conditions and measured their gaze and pupil dilation with an eye-tracker. Then, we offered infants the novel foods shown in the videos and measured their choices and eating behaviors.

Our eye-tracking results indicate that infants differentially attend to eating and food processing actions relative to the control action, and show increased pupil dilation for the control action relative to the two actions that may indicate edibility (eating and cutting). When asked to choose which novel food they could eat, infants chose the novel food they saw an actor eat, but only when that eating action was paired with the control action. These findings help identify important mechanisms that increase acceptance of healthy foods early in life.

1. Introduction

Eating a balanced diet rich in healthy foods like fruits and vegetables is essential for good health (Wirt & Collins, 2009). Developing healthy eating habits is especially important in the first years of life because many food habits and preferences are acquired early in development and are associated with dietary patterns in later childhood and adulthood (Luque et al., 2018; Nicklaus et al., 2005). However, as any parent knows, this process can be quite challenging. Food neophobia-the avoidance of novel foods-is well known to occur during early childhood. Young children who are in the process of learning what to eat apart from milk (either breastmilk or formula) often do not readily accept novel foods, but instead first tend to show avoidance behaviors towards them (Cole et al., 2017; Dovey et al., 2008; Fletcher, et al., 2017; Lafraire et al., 2016; Moding & Stifter, 2016a , 2016b , 2018; Perry et al., 2015). Children are particularly likely to exhibit food neophobia towards fruits and vegetables (Rioux, 2019).

As a result, food neophobia is associated with a significant reduction of children's dietary variety, which is necessary for normal and healthy development (Falciglia et al., 2000; Woodside et al., 2013). Therefore, it is important to understand how children learn about novel foods in order to identify specific mechanisms that increase acceptance of healthy foods early in life. While individual learning plays an important role in the development of food preferences in infancy and childhood (e.g., via flavor-flavor learning [FFL] or flavor-nutrient learning [FNL], in which a new food is paired with a flavor or nutrient that is already liked; see Mura-Paroche et al., 2017 for a review), we focus here on social learning processes.

1.1. The effect of social information on food learning and avoidance behaviors

Food learning in childhood relies heavily on social learning (see e.g., DeJesus et al., 2018; Shutts et al., 2013 for reviews). The existing research has established that children learn what to eat by directly observing social cues that signal edibility (Addessi et al., 2005; Birch, 1980; Laureati et al., 2014). For instance, seeing an adult eating a novel food increases toddlers' willingness to taste this food (Addessi et al., 2005) and school-based interventions where 6-to 9-year-old children observe peers eating novel fruits and vegetables increases children's consumption of these foods and decreases their food neophobia (Laureati et al., 2014). From 6 months of age, infants also learn that a particular entity is edible by observing an adult eat it (e.g., Liberman et al., 2016; Wertz & Wynn, 2014 , 2019) and have expectations about the structure of eating actions (e.g., expecting spoons to be brought to the mouth; Gredebäck & Melinder, 2010; Kochukhova & Gredebäck, 2010). Importantly, infants and young children are selective in the way they use social information to infer edibility (Liberman et al., 2016; Wertz & Wynn, 2014 , 2019). For example, they learn that a particular entity is edible after observing an adult eating it but not when an adult handles it in other ways (e.g., putting it behind their ear; Wertz & Wynn, 2014 , 2019). Therefore, it seems that food learning in infancy and early childhood is based on a set of specific actions that can indicate edibility and, as a consequence, not all social information about food has the potential to decrease infants' and children's food avoidance behaviors.

1.2. Cues of food processing as relevant social information about food

The effects of watching someone else eat a food on infants' and young children's food learning and avoidance behaviors has been well studied (see e.g., DeJesus et al., 2018, Rioux, 2019 for reviews). However, the effects of other forms of food-related social information remain largely uninvestigated. One form of social information that deserves further investigation is food processing. Here we define food processing as actions that alter the naturally occurring state of foods (e.g., an apple growing on its tree), such as cutting, grinding, or cooking. These processing techniques have been an important part of human life for millennia (Wrangham, 2009) and are still the main techniques applied to the foods in human societies (e.g., Mombo et al., 2016). Food processing is a prior and often necessary step for human food consumption. For example, foods like breads, stews, cakes, etc. do not exist until naturally occurring foods are processed, sometimes in elaborate ways. Therefore, cues of processing are reliable social signals about what kinds of entities are consumed within the local environment.

Consistent with this view, adults and children from three years of age view processed foods (e.g., foods cooked and pureed) as human-made objects that bear markers of previous human intervention, while they view unprocessed foods as naturally occurring (Foroni et al., 2013; Girgis & Nguyen, 2020). In addition, adults view processed foods as being more ready to eat than unprocessed foods (Foroni et al., 2013). Similarly, children miscategorized non-food items (e.g., pieces of wood) that have been sliced into pieces as foods (Foinant et al., 2021a), suggesting that children are more likely to think something that has been cut is a food. These results indicate that adults and young children use cues of food processing to infer that another person has already interacted with a candidate food and has deemed it to be edible. However, it is not yet known whether infants make this same inference.

Another important aspect of food processing is that many processing techniques reduce the toxicity of raw food items. For example, cassava root is a staple food in many societies, but it cannot be eaten raw and requires complex processing techniques to be consumed without a risk of poisoning (Mombo et al., 2016). It is therefore possible that, in addition to serving as a potential social signal of edibility, cues of food processing also indicate that processed food items are safe to handle, which would decrease avoidance behaviors. Accordingly, children assign negative properties (e.g., "This food makes you throw up") less often to processed foods compared to unprocessed foods (Foinant et al., 2021b). In addition, infants from 7 months of age are less reluctant to touch novel processed plant foods (e.g., unfamiliar fruits and vegetables picked and cut into pieces) than novel unprocessed whole plants with fruits (Rioux & Wertz, 2021). Furthermore, infants put cut food items in their mouths twice as often as unfamiliar fruits and vegetables that have been removed from plants but are still whole (Rioux & Wertz, 2021).

Importantly, in previous studies of food processing, infants and young children did not witness the acts of food processing directly (Foinant et al., 2021a (Foinant et al., , 2021b;; Foroni et al., 2013; Girgis & Nguyen, 2020; Rioux & Wertz, 2021). Instead, they were presented with foods that had already been processed (e.g., foods cooked and pureed, or cut into pieces) and were able to infer the previous human intervention. Therefore, infants' responses to the food processing actions themselves remain unknown.

1.3. Attending to and learning from actions that may indicate edibility

The existing literature indicates that watching what others eat and seeing evidence of food processing are important aspects of human food learning. However, two broad questions remain unanswered. The first question is whether infants are particularly attentive to eating and food processing actions when learning about food. It is well established that infants differentially attend to certain types of important stimuli or actions (e.g., Golinkoff et al., 2013).

For example, 6-month-old infants prefer to look at someone speaking their native language versus someone speaking a different language (Kinzler et al., 2007). In addition, 10-to 12month-old infants prefer to take both food and toys from a native speaker over someone speaking a foreign language (Kinzler et al., 2007; Shutts et al., 2009). But what about eating and food processing actions?

There are a number of reasons why infants may pay particular attention to someone performing eating and food processing actions. Infants learn that a particular entity is edible after observing an adult putting it in the mouth, but not when the adult handled it in other ways (e.g., placing it behind the ear, holding it in front of the face and expressing negative affect; Wertz & Wynn, 2014 , 2019) and it is possible that they will also differentially attend to this eating action. Similarly, infants' attention may be drawn by food processing actions because they may also serve as indicators of edibility, or a signal that a food can be handled (e.g., Foinant et al., 2021b; Rioux & Wertz, 2021). Therefore, the current experiment tested whether infants differentially attend to eating and food processing actions relative to a control action.

The second question is whether infants perceive social cues of food processing as cues about the edibility of the foods per se. Previous results indicate that infants are more willing to approach and handle processed foods. For example, Rioux & Wertz (2021) presented 7-to 15month-old infants with unprocessed whole plants and processed plant foods (e.g., unfamiliar fruits and vegetables cut into pieces) and found a reduced reluctance to touch and eat processed plant foods compared to whole plants. However, the existing work was not designed to assess eating behaviors, that is, whether infants put the different items in their mouth, so it is not yet clear whether infants use food processing actions as a cue of edibility.

1.4. The current experiment

The aim of the current experiment is to investigate whether infants (i) differentially attend to eating and food processing actions compared to a control action and (ii) choose and attempt to eat (i.e., put in their mouth) novel foods after observing eating and food processing actions performed with them.

To answer these questions, we conducted an experiment with 12-month-old infants using a combination of a preferential looking time paradigm and a choice paradigm. Infants were first presented with a split-screen presentation of an adult performing different actions on novel foods (the Action Presentation Phase). During the Action Presentation Phase, infants were divided into three between-subjects conditions. In each condition, infants saw a different pairing of two actions. These pairings were created from combinations of three possible actions: eating, a food processing action (cutting), and a control action (touching). Two of these actions-eating and cutting-may indicate edibility, while the touching action served as a control for lowerlevel features of the other actions. The eating action was an adult lifting a novel food with a pair of tongs to her mouth and consuming a bite of it. The cutting action was an adult chopping a novel food into pieces with a knife. We used cutting as our food processing action because (i) cutting is a typical food processing action that is also a common component of many more complex food processing techniques and (ii) previous work has shown that infants and young children can distinguish between cut and whole foods (Foinant et al., 2021b; Rioux & Wertz, 2021), which makes cutting a suitable action to use with infants. The touch control action was an adult holding a novel food with a shoe horn and touching the food with her finger. In order to control for the necessary presence of a knife in the cutting action, we ensured that each action included an artifact: tongs in the eating action, a knife in the cutting action, and a shoe horn in the touch control action. Combining these actions into pairs led to three between-subjects conditions, each showing an alternating set of action videos: 1) eating vs. touching, 2) cutting vs. touching, and 3) eating vs. cutting. Infants' gaze was recorded with an eye-tracker to determine (i) which actions they look at longer and (ii) their pupillary changes in response to each display, as infants' interest in a stimulus can be indexed by increased pupil dilation (Ackermann et al., 2019; Hepach & Westermann, 2016).

After the Action Presentation Phase of the experiment, infants in all conditions were presented with the two novel foods shown in the videos and asked "Which one can you eat?" (Choice Phase). We recorded which novel food the infants subsequently chose (i.e., the first novel food they touched using a visually-guided reach) and attempted to eat (i.e., put in their mouth). All infants were presented with the same choice procedure, regardless of the action types presented in their between-subjects condition. Infants saw intact versions of the novel foods during the Choice Phase that did not show any traces of the actions performed in the Action Presentation Phase (e.g., pieces missing from cutting or eating). We did this because our interest in the present study was the identity of a novel food (i.e., that it was associated with a particular action type), not changes in its quantity or appearance (see e.g., Cheries et al., 2008).

1.4.1. Predictions

The current study assessed infants' responses to an eating action, a food processing action (cutting), and a touch-control action using looking time, pupil dilation, and choice measures. Previous research has established that infants tend to look longer at and reach for stimuli they prefer (Holvoet et al., 2016; Kinzler et al., 2007; Hamlin & Wynn, 2011). Infants also show increased pupil dilation when their attention is caught by a stimulus they are interested in (Ackermann et al., 2019). The existing literature suggests several possible interpretations of pupil dilation measures. Specifically, phasic pupil dilation, which occurs in immediate response to a stimulus, has been established as a measure of arousal and cognitive load (e.g., Hepach & Westermann, 2016; Steinhauer et al., 2022). Depending on the specific experimental manipulations used in a study, cognitive load can occur due to attention, learning, or surprise (Hepach & Westermann, 2016). For example, increased pupil dilation during the presentation of a stimulus can indicate increased interest, and increased pupil dilation when watching an association between a particular stimulus and additional attributes or events predicts enhanced learning of these associations (Ackermann et al., 2019; Cheng et al., 2019).

Moreover, infants' pupils dilate in response to novelty, indicating surprise at unfamiliar or unexpected events (Jackson & Sirois, 2022). We describe our pupil dilation findings in terms of cognitive load, but we acknowledge that at least one (if not more) of these underlying processes are likely to be involved.

We had two main predictions. First, if infants differentially attend to actions that could indicate edibility (eating and cutting), we predicted that infants would exhibit longer looking times and increased pupil dilation in response to the eating and cutting actions compared to the control action in the Action Presentation Phase (Prediction 1). Second, if infants learn that novel foods are edible by seeing eating and food processing actions performed on them, we predicted that infants would choose and eat the novel food item shown in the eating and cutting action videos in the Choice Phase (Prediction 2). Based on the existing research outlined above, we expected that infants would view our eating action as a cue of edibility. Our experimental design allowed us to assess whether infants treat a food processing "cutting" action similarly to the eating action or, alternatively, if they treat it similarly to the touch control action.

>Methods

2.1. Participants

Participants were 78 healthy, full-term, 12-month-old infants (40 girls; M age = 12 months, 14 days, SD = 8 days, range = 12 months, 0 days -12 months, 30 days). An additional 10 infants were run but excluded from the final sample due to (i) fussiness during the test session (N = 5), (ii) parental interference (e.g., pointing to the screen) during critical phases of the presentation (e.g., N = 2), or (iii) inattentiveness (i.e., infants failing to watch a critical phase of the presentation; N = 3). Datasets of 8 further infants were excluded from the final sample for failing to meet data inclusion criteria for both the eye-tracking and choice measures (see Supplementary Materials [SM] Section 1.1 and Fig. S1 for details).

Infants were randomly divided into three independent between-subjects conditions (Eat vs. Touch: N = 27, Eat vs. Cut: N = 23, Cut vs. Touch: N = 28; see Table 1 for demographic details broken down by condition). Randomization was achieved by repeating a predetermined order of experiment versions, in which condition as well as side of color, side of action, and side of first presentation were crossed, resulting in 24 versions of the experiment. Infants coming to the laboratory were tested in the order version 1 -24. Experiment versions assigned to infants who did not provide data during the testing phase were reassigned to the next incoming infant. It was our goal to approximately assess a multiple of four of the 24 experiment versions. However, since exclusion occurred mainly after data collection was finished, the final distribution of participants across conditions is not perfectly balanced in all parts of the study, although the number of infants in each part is roughly equivalent (see Fig. S1).

Some datasets of these 78 infants were excluded from only one dependent measure because the data failed to meet our inclusion criteria (see SM Section 1.1), resulting in datasets of N = 65 infants in the eye-tracking analysis and N = 50 infants in the choice analysis (see Fig. S1). These sample-sizes were based on previous studies using similar methodologies (e.g., Kinzler et al., 2007; Wertz & Wynn, 2019) and based on a power analysis assuming a power of 80% and a large effect size Cohen's f = 0.4, as this is common in infant research (run in G*Power version 3.1, repeated measures ANOVA).

We chose 12-month-olds to include infants with some solid food experience (i.e., already eating solid foods such as raw and cooked fruits and vegetables) and who often engage in social referencing (i.e., looking to an adult when confronted with novel objects or situations and adjusting behavior based on the adult's behavior; e.g., Bazhydai et al., 2020; Schimtow & Stenberg, 2013). In addition, by this age, infants are selective about the actions they use to infer edibility (Rioux & Wertz, 2026; Wertz & Wynn, 2014). Participants were recruited from a predominantly White population around Berlin, Germany. All infants heard German spoken more than 50% of the time and had no food allergies. The study was approved by the local Ethics Committee and parents gave written consent for their child's participation. 2.2. Stimuli

Two types of stimuli were presented to children: black carrots and white parsnips. We chose these stimuli because we assumed they are relatively unfamiliar to infants, and infants would not typically eat them in their raw form at this age. Our questionnaire measures confirmed our assumptions that these roots were unfamiliar and not typically eaten raw (see SM Section 2.7 for details). In addition, we chose these food stimuli because vegetables are often among the first foods introduced to infants' diets, but are also the primary targets of children's food avoidance behaviors (Cole et al., 2017; Lafraire et al., 2016). Moreover, we chose these stimuli for practical reasons: They were easy for the adult actor in our study to cut and eat.

2.3. Apparatus

Infants were tested in a testing room lit to match the medium luminance of the presentation screen. Infants sat in a baby seat with their parents directly behind them. Parents were instructed not to direct their infant's behaviors during the entire session.

For the first part of the session (Action Presentation Phase, see Section 2.4.1 below) infants were presented with a video-recorded presentation displayed on a TV screen at 140 cm distance (Samsung LED TV, 50′′ display, with 1,280 by 1,024 pixel resolution equivalent to 32° by 26° visual angle, and 400 Hz CMR refresh rate). The screen was positioned such that the actor in the videos appeared to be sitting within our presentation stage and presenting the events in person. Participants' gaze was measured with an EyeLink1000 eye-tracker (SR Research Ltd) in remote mode, which is suitable for unrestrained infants. The EyeLink 1000 with its high-speed remote camera provides monocular tracking at a 500 Hz sampling rate. The camera was positioned in front of the infant at a distance of approximately 60 cm (EyeLink 1000 User Manual, 2010). After positioning the infant and caregiver in front of the eye-tracker, an experimenter stepped behind a curtain from where the infant and caregiver could be monitored on a video screen and started the experiment.

2.4. Procedure

The testing session consisted of two parts: an Action Presentation Phase using a preferential looking time paradigm and a Choice Phase using a manual forced-choice paradigm.

Preferential looking time paradigms have been used successfully with infants for decades, including eye-tracking methods, as have manual forced-choice paradigms (e.g., Aslin, 2007; DeJesus et al., 2015; Hamlin et al., 2007; Hamlin & Wynn, 2011; Golinkoff et al., 2013; Stahl & Feigenson, 2015; Wertz & Wynn, 2014; Wertz & Wynn, 2019).

2.4.1. Action Presentation Phase

The study began with a five-part Action Presentation Phase (see Fig. 1, top panel): (i) Calibration: First, we conducted a five-point calibration of our eye-tracker with each infant using attention grabbers that have been shown to reliably draw infants' gaze to their center (Schlegelmilch & Wertz, 2019).

A calibration was accepted if the calibration error was below 1°. Directly after calibration, seven three-second trials showing neutral light and dark stimuli were presented to assess the individual infant's pupil responses to contrast changes (Schlegelmilch, 2024; see also SM Section 2.1). Calibrations were repeated, if necessary, before Action 2", for a similar alternating presentation see e.g., Kinzler et al., 2007). In the first video, an actor performed one type of action on a root she took from a pile in front of her (e.g., cutting a black carrot, see Fig. 1, Panel 2). In the second video, the same actor performed another type of action on a root taken from the other pile (e.g., eating a parsnip, see Fig. 1, Panel 3). Infants watched the two action type videos repeated three times each for a total of 6 trials. While one video was playing, the other side of the screen showed a blank grey surface. Central attention grabbers, each presented for 3 seconds, were shown between each action video. The duration of the action videos was 19 seconds each during their first appearance, including a 3 second phase with the actor looking at the infant before the actions started. During the repeated presentations, this looking phase was removed and the video duration was 16 seconds each.

The action pairs shown to infants differed across the three independent between-subjects conditions: Eat vs. Touch, Eat vs. Cut, Cut vs. Touch (see below, Section 2.4.3. Experimental Conditions). The following were counterbalanced across participants: the side of the screen on which the video appeared first (left vs. right); the action performed on the left vs. right of the screen; the root type used for each action (black carrot vs. white parsnip).

(iv) Action Still (1 trial): Next, we showed infants a side-by-side still image from each action video to examine whether any preferential looking during the dynamic action videos would carry over to still images. To do this, the infants were shown a central attention grabber followed by a still image from each of the two action types presented concurrently side-by-side, in the same orientation they appeared during the video presentation, for 30 seconds (see Fig. 1, Panel 4 "Action Still", and Fig. 2 for still images of all actions).

(v) Root Still 2 (1 trial): The presentation ended with a second presentation of the still image of the root stimuli (see Fig. 1, Panel 5 "Root Still 2"). This second presentation allowed us to test whether watching the different actions performed on the roots altered infants' attention toward the roots themselves. As before, the root stimuli were shown for 15 seconds in the same orientation they appeared throughout the presentation. After a sound indicated that the trial had ended, the Root Still image remained on the screen so that it was visible for the upcoming Choice Phase (see Section 2.4.2).

Throughout the Action Presentation Phase, we recorded infants' gaze to determine (i)

what they attend to and (ii) their pupillary dilation. Changes in pupil size can occur for different reasons, such as luminance differences of the stimuli or cognitive load reflecting attention and learning (Alnæs et al., 2014; Cheng et al., 2019; Steinhauer et al., 2022). Therefore, following Hepach & Westermann (2016), in order to keep the luminance conditions as constant as possible, (i) the videos were presented on a flat screen monitor using uniform ambient lighting conditions across participants, and (ii) we assessed pupil dilation directly after each action video while the central attention grabber was on the screen. Specifically, we assessed pupil dilation in a period from 400 ms to 2000 ms after the action presentation. In this period, gaze had arrived at the screen center where identical attention grabbers were shown for all actions, and when cognitive load elicited by visual and cognitive processing of the shown actions was expected to still affect pupil size (for a similar procedure see e.g., Hepach et al., 2012). 2.4.2. Choice Phase

The study ended with a Choice Phase (see Fig. 1, bottom panel). At the beginning of this phase, an experimenter, who was blind to the action performed with each root type, emerged from behind a curtain and then reached toward the screen that still showed the two piles of roots from Root Still 2. The experimenter gave the illusion of picking up one root from each of the piles, presenting two real roots to the infant (see Fig. 1, Panel 6; adapted from Kinzler et al., 2007; DeJesus et al., 2015). Importantly, during the Choice Phase, all infants were presented with whole roots that did not show traces of the actions performed on them during the Action Presentation Phase. We selected intact, whole roots for two reasons. First, this ensured that the roots were identical in size and did not provide visual cues about the previously observed actions (e.g., missing pieces resulting from eating or cutting). Second, it encouraged infants to track object identity rather than appearance. This distinction between identity and appearance is important because changes in appearance can affect infants' and young children's representations of objects (Cheries et al., 2008 , Keil, 1989 , Piaget et al., 1960).

For example, in the classic conservation-of-mass task, young children often report that changing an object's shape (e.g., flattening a ball of clay) changes its mass (i.e., the child will say the flatted ball has more clay than the round ball; Piaget et al., 1960). Using intact roots allowed us to investigate the identity of a root (i.e., that it was associated with a particular action) independent of changes to its quantity or appearance. This approach is consistent with evidence showing that, although infants fail to track object quantity when a food (a cracker) is split into two pieces, they maintain a representation of its identity (Cheries et al., 2008).

After appearing to remove the roots from the screen, the experimenter asked the infant which one they would like to eat (as in Wertz & Wynn, 2014 , 2019). To do this, the experimenter held the two roots out of infants' reach, and said, in German, "Hi, do you see these?" ("Hallo, Siehst du das hier?") while making sure infants looked at both roots.

Then the experimenter asked infants "Which one can you eat? Can you show me? Which one can you eat?" ("Welches kannst du essen? Zeig mir: Welches kannst du essen?") in infant directed speech (See Fig 1., Panel 7). At the end of their verbal prompt, the experimenter moved the two roots forward within the infants' reach. If infants were reluctant to choose, the experimenter repeated the questions.

Infants' choices were coded as the first root they touched while looking at it (i.e., their first visually-guided reach, as in Wertz & Wynn, 2014 , 2019). Infants' eating behaviors were coded as whether or not they brought the root in contact with their mouth. For safety reasons, we did not let infants bite the root and recorded only infants' attempts to put the root in their mouth. If infants did not touch either of the roots after 60 s, the session ended. Caregivers were asked to keep their eyes closed throughout the Choice Phase to prevent them from influencing infants' behavior.

2.4.3. Experimental Conditions

Infants were randomly assigned to one of three between-subjects conditions that differed in the pairings of actions presented during the Action Presentation Phase; the Choice Phase was the same across conditions.

(1) Condition1 = Eat vs. Touch Actions (N = 27). This condition investigated whether infants preferentially attend to eating actions compared to a control action. Infants were shown an actor eating one root stimulus in one video (see Fig. 2, Panel A) and touching the other root stimulus in the other video (see Fig. 2, Panel B). In the eating action video, an actor was seated at a table behind one root type. The actor first greeted the infant, then lifted the root in front of her using a pair of tongs, grabbed the root with her other hand and placed it in her mouth. The tongs were included to control for the presence of a knife in the cutting action video (described below). The actor took two bites, returned the root to the table with her hand, and placed her hand next to it. In the touch action video, the same actor was seated behind the other root type.

The actor greeted infants, then held the root using a shoehorn (to control for the presence of a tool) and touched the food with her finger. She then moved her hand up and tucked her hair behind her ear to match the low-level features of the eating action (i.e., a hand moving up towards the face, performing a natural-looking action, and moving down again). We used an eating action because infants use this action to learn about edibility (e.g., Liberman et al., 2016; Wertz & Wynn, 2014 , 2019). We used the touch action as a control action that, taken on its own, does not indicate the edibility of an object because infants routinely see their caregivers touching a wide variety of objects, including food and non-food, but is also a familiar action for infants. The advantage of using a familiar action as a control compared to an unfamiliar action closely matched for low-level features (e.g., putting the food behind the ear; Wertz & Wynn, 2014) is that it removes potential confounds from the preferential looking method (i.e., infants looking longer to unfamiliar actions; see e.g., Aslin, 2007) and from the pupil dilation measure (i.e., infants showing increased pupil dilation to surprising events; Hepach & Westermann, 2016).

(2) Condition2 = Cut vs. Touch Actions (N = 28). This condition tested whether infants preferentially attend to food processing actions and view them as a cue of edibility. Infants were shown a video of an actor slicing one root type in front of her with a knife (see Fig. 2, Panel C) paired with a video of the actor touching the other root type. In the video displaying a cutting action, after greeting the infant, the actor held the root with one hand while cutting slices two times with the knife using her other hand. At the end of the video, the actor tucked her hair behind her ear (to match the low-level features of the eating action). The touch action was the same one described above and, as in Condition 1, the touch action here serves as a low-level familiar control action that allows us to determine whether infants respond differently to foodprocessing actions (cutting) compared to any kind of contact (touching).

(3) Condition3 = Eat vs. Cut Actions (N = 23). In the third condition, we directly compared the two actions that could indicate edibility (described in detail above) to test whether infants preferentially attend to one action over the other, or if they treat the two actions similarly.

2.4.4. Parent Questionnaires

In order to assess whether infants' prior food experiences or eating behaviors may affect their responses, we asked parents to complete a battery of five questionnaires. All questionnaires were completed online, either before or after the lab session.

The first questionnaire assessed infant's familiarity with the different stimuli presented in the study (i.e., black carrot, parsnip and white parsley root, knife, tongs, shoehorn)foot_0 . In the experiment infants saw black carrot and parsnip but we also asked about white parsley root as it is very similar-looking to parsnip. Parents were asked: (i) whether their infant has ever seen these six objects (Yes/No) (ii) how often their infant interacts with these objects (from never to nearly every day) and (iii) how often their infant sees their parent interacting with these objects (from never to nearly every day). The stimuli were chosen to be a priori unfamiliar to infants and results from this questionnaire confirmed our assumption: Familiarity with black carrots M = 2.74, familiarity with parsley roots M = 3.58, familiarity with parsnip M = 5.85; Ratings could range from 0 (Infants never saw, interacted or saw their caregivers interacting with the object) to 15 (Infants saw, interact and see their caregivers interacting with the object every day).

The second questionnaire asked about food consumption at home and age of introduction to fruits and vegetables. Parents were asked how often their infant eats 10 typical German foods at home (i.e., milk, dairy products, bread, cereals, fresh fruits and vegetables, meat, fish, sweet products, savory snacks, ready-to-eat foods). Their responses were rated on a nine-point Likert scale (0 = never to9 = more than five times a day). Parents were also asked at what age they introduce in their infant's diet the following foods: Infant formula, pureed foods, fresh fruits and vegetables, cereal products, meat and family foods.

The third questionnaire was the Children's Feeding and Eating Difficulties Questionnaire (Rigal et al., 2012). This questionnaire is divided into three parts. The first part contains twelve questions and asks parents about their infant's attitude about food (e.g., "My child looks forward to mealtimes"). Their responses were rated on a 5-point Likert scale (1 = Very wrong to5 = Very true). The second part contains seventeen questions and asks parents about their feeding practices (e.g., "During mealtimes, when your child hesitates to taste a food, does it happen that you get angry?"). Their responses were rated on a 5-point Likert scale (0 = Never to5 = Always). The last part contains twenty-one questions and asks parents about what they do when they are confronted with different feeding situations (e.g., "Your child wants to eat pasta when you intended to cook vegetables. You stick to your idea of vegetables without trying to negotiate."). Their responses were rated on a 4-point Likert scale (1 = Very unlikely to4 = Very likely).

The fourth questionnaire was the Child Food Rejection Scale (Rioux et al., 2017), which directly assesses children's food neophobic and picky eating behaviors. Six questions are related to food neophobia (e.g., "My child always chooses familiar food"). Five questions are related to pickiness (e.g., "My child refuses to eat some foods because of their texture").

Parents' responses were rated on a 5-point Likert scale (1 = Strongly disagree to5 = Strongly agree).

The last questionnaire assessed socio-demographic characteristics of the two parents.

Specifically, parents were asked about their level of education, as a proxy for social-economic status. This approach is commonly used in studies examining correlates of food rejection (Cole et al., 2017). The questions were adapted from the standardized Mikrozensus survey (see e,g, Schneider, 2015). First, parents were asked if each parent has a general school-education qualification. If this was the case, they were asked about the level of school education they had received. Next, they were asked about professional education, and last about their highest qualification, with options ranging from vocational internship to PhD. Answers were then transformed into the ordered variable Years of Education, ranging from 10 years (intermediate level of maturity or "Mittlere Reife") to 21 years (PhD).

Correlational analyses revealed that none of the questionnaire measures were systematically related to our DVs of interest. See SM Section 2.7 for details of the questionnaires and analyses.

Our analyses were performed in the R environment using a linear mixed-effects approach (Bates, et al., 2015). Video examples, data and analysis scripts are available on the Open Science Framework (OSF): https://osf.io/2645w/?view_only=c8a76a6a8036436eafc7804da6d9071f

2.5.1. Analysis plan for infants' looking behavior during the Action Presentation Phase

In order to test whether infants differentially attended to actions that may indicate edibility (eating and cutting) than by the control action, we examined infants' looking behavior and pupil dilation during the Action Presentation Phase (see showed the goal of each action (e.g., root in the mouth, knife cutting the root, finger touching the root; still images are shown in Fig 2). The analysis of the Action Still looking times assessed whether infants' attention remained differentially captured by the eating and cutting actions after the dynamic action video sequences had concluded. For the Root Stills, infants saw the same still image of the roots twice during the presentation. The first time infants saw the Root Still was before any action was performed on the two roots (see Fig.1 Panel 1) and the second time they saw the Root Still was after infants saw the videos of different actions performed on the two types of roots (see Fig 1 Panel 5). We measured the change in infants' looking time for both roots across the two time points (i.e., the mean looking time during the second Root Still minus mean looking time during the first Root Still). The analysis of the Root Still looking times tested whether infants' visual attention to a novel root stimulus was influenced by having previously observed eating and cutting actions performed on it. For both the Action Still and Root Stills, we tested the significance of the following predictors: Action (Eat, Cut, Touch), Condition ("Eat vs. Touch", "Cut vs. Touch", "Eat vs. Cut"), Sex (Male, Female) and Age (continuous factor).

In the final models, infant participants served as a random factor. Action, Condition, Sex and Age were modeled as fixed effects. The model for Action stills will hereafter be referred to as Model 2, while the model for Root still will hereafter be referred to as Model 3.

Third, we ran another linear mixed-effect model with infants' pupil dilation as the dependent variable. Pupil dilation was assessed during the period from 400 ms to 2000 ms after each Action Video, when gaze rested on identical attention grabbers (see Fig 1., Panels 2 and 3). Pupil dilation data were obtained using the following preprocessing steps: (i) Sampling rate reduction: Our eye-tracking data was assessed at a 500 Hz sampling rate (see Section 2.3.

Apparatus above). Because in infant studies eye-trackers with a sampling rate of 60 Hz are more common (e.g., Tobii eye-tracking systems), we reduced our data to 60Hz in the pupil-dilation analysis to make it comparable to the results of other pupil dilation studies.

(ii) Baseline correction and standardization: Because participants naturally differ in their individual baseline pupil sizes, pupil data was baseline-corrected within each infant by subtracting the median of the individual's data from each of its values, respectively.

Additionally, pupil data was standardized (following procedures suggested by Mathôt et al., 2018) to obtain our dependent variable of pupil dilation. Note that the raw units of pupil size on which this procedure is based are arbitrary units, as is common in EyeLink systems (EyeLink 1000 User Manual, 2010). Following the same approach as with our looking time data, we tested the significance of the following predictors: Action (Eat, Cut, Touch), Condition ("Eat vs. Touch", "Cut vs. Touch", "Eat vs. Cut"), Trial (1 → 6), Sex (Male, Female), Age, Horizontal and Vertical gaze position and Head distance to the screen (continuous factors). Direction of gaze and eye distance can affect pupil size measurement and are therefore suggested to be included as control variables in pupil dilation analyses (Gagl et al., 2011). We included Trial to gain insight into whether infants show an increase or decrease in cognitive load as indexed by changes in pupil dilation, after repeated presentations of each action type. Note that each individual infant only saw three repetitions of an action video, therefore the trial variable includes both within-and between-subjects data. Condition also did not contribute to the model and was removed to avoid overfitting. In the final model, infant participants served as a random factor, as did video side (left vs. right) and Trial under the condition of participant. Action (Eat, Cut, Touch), Trial (1 → 6), Sex (Male, Female), Age, Horizontal and Vertical gaze position and Head distance to the screen (continuous factors) were modeled as fixed effects. This model will hereafter be referred to as Model 4.

Finally, we ran linear mixed-effects models with infants' pupil dilation as the dependent variable and adding the interaction term Action*Trial to the model. Because a significant interaction would indicate that differences between action types vary across trials, this additional exploratory analysis was conducted to better understand the timeline of cognitive load elicited by the repeated presentations of the different action types. In this model, infant participants served as a random factor, as did video side (left vs. right) and Trial under the condition of participant. Action (Eat, Cut, Touch), Trial (1 → 6), Action*Trial, Sex (Male, Female), Age, Horizontal and Vertical gaze position and Head distance to the screen (continuous factors) were modeled as fixed effects. This model will hereafter be referred to as Model 5.

4. Discussion

The aim of this study was to investigate whether 12-month-old infants (i) differentially attend to actions that may indicate edibility (eating and cutting) compared to a control action (touching), and (ii) choose and attempt to eat (i.e., put in their mouth) novel foods after observing eating and food processing actions performed with them. Our results show that 12-month-old infants did indeed look longer at eating and cutting actions than at the touch control action. Infants show this pattern of response to the action videos, but not when static images of the same actions were presented. Moreover, infants exhibited the greatest pupil dilation in response to the touch control action. After watching the action videos and being asked "Which one can you eat?" infants chose the novel food they had seen an adult eat, but only when that eating action was paired with the touch control action.

4.1. Infants' differential attention to actions that may indicate edibility (eating and cutting) compared to a control action (touching)

The current results demonstrate that, while infants were interested in all actions, they exhibit longer looking times when attending to actions that may indicate edibility (eating and cutting) compared to the control action (touching). This difference was constant across trials (i.e., for looking time data, the Action*Trial interaction did not improve model fit, unlike for the pupil data). This pattern supports our first prediction and adds to existing research showing that infants differentially attend to important stimuli or actions (e.g., Golinkoff et al., 2013).

Importantly, our findings add a novel dimension to our understanding of social learning about food in infancy: The set of specific actions infants attend to when interacting with food includes food processing actions like cutting. In fact, infants pay similar attention to someone cutting a food and someone eating a food, which is an established cue of edibility (e.g., Liberman et al., 2016; Wertz & Wynn, 2014 , 2019), despite the fact that our cutting action shares more lowlevel features with the touch control action. Future studies could investigate whether variation in infants' everyday exposure to food processing actions influences their attention to these actions. While some infants routinely observe their caregivers preparing food, others may have fewer opportunities to do so.

Our results also showed that infants exhibit the greatest overall pupil dilation in response to the touch control action. This finding may seem at odds with our claim that infants attend to actions that may indicate edibility more than the control action as infants' attention towards a stimulus has been found to be indexed by increased pupil dilation (Ackermann et al., 2019; Hepach & Westermann, 2016). An alternative interpretation is that infants attend more to eating and cutting actions in order to learn about potential food items, but were to some degree puzzled by our touch control action. In fact, previous studies have found that infants can show increased pupil dilation when they observe a surprising event (e.g., someone bringing a spoon to the hand instead of bringing it to the mouth, Gredebäck & Melinder, 2010) and that pupil dilation reflect both infants' interest and surprise (Hepach & Westermann, 2016; Jackson & Sirois, 2022). The touch action we used as a control does not indicate edibility per se and infants routinely see their caregivers touching both food and non-food objects. However, to match the three different actions we tested for low-level features (e.g., length of the action sequences, use of a metal tool in all actions), we used a touch action that involved stroking the novel food with one finger while holding it to the table with a metal shoehorn-which might have been particularly unexpected for infants. Future studies could use different control actions that are not likely to indicate edibility, and are also not surprising.

Our analysis of the pupil data across the consecutive trials revealed interesting differences that could reconcile our looking time and pupil dilation findings (see Fig. 5).

Specifically, pupil dilation evolved differently across trials depending on the action type: dilation for both the eating and cutting actions increased over the trials, while dilation for the touch control action did not significantly change across the trials. Mean pupil size for all actions was close to baseline during the first action video in our presentation, but changed when the second action was presented. Since the touch control action in the second trial was always preceded by an action that may indicate edibility (eating or cutting), and the eating and cutting actions may share more similarities (e.g., the conceptual content of indicating edibility, or being seen as more familiar or less unusual than the touch control action), seeing a touch action following an eating or cutting action might have violated infants' expectations more than seeing a cutting action following an eating action or vice versa. Pupil size reflects immediate responses to events, and is therefore seen as a more precise measure of cognitive processes than looking time (Jackson & Sirois, 2009). Compared to looking time which reflects general interest in a display, pupil dilation can reflect interest in particular objects and associations between objects and events (Ackermann et al., 2019). Thus, the differently evolving trajectories of pupil dilation for the action types over trials may indicate that, even if the touch control action was consistently surprising to infants, the combination of actions that may indicate edibility of a novel food were of increasing interest across trials (e.g., Chen & Westermann, 2018).

Additionally, the increase in pupil dilation for the eating and cutting actions as trials progressed might indicate that infants were actively learning about these actions (e.g., Ackermann et al., 2019; Cheng et al., 2019). This would be similar to findings by Cheng and colleagues (2019) in a study investigating the relationship between focused attention and working memory performance. In their study, increased pupil size in 13-month-olds after the presentation of a stimulus predicted greater learning success. Interestingly, looking time, which was assessed during stimulus presentation, neither predicted learning success nor correlated with pupil dilation (Cheng et al., 2019), suggesting discrepancies between looking time as a measure of more general interest and pupil dilation as an indication of the more differentiated processes of learning or surprise. Future work using stimuli like ours could include additional tasks to assess learning effort (see e.g. Kaldy & Blaser, 2020) to distinguish whether the changes in pupil dilation we found over consecutive trials reflect cognitive load due to attention, learning, or surprise. In any case, taken together, our pupil dilation and looking time results show that infants respond differently to the eating and cutting actions than to the touch control action.

The previous literature indicates that eating actions are particularly influential because they serve as cues of edibility (Liberman et al., 2014; Rioux & Wertz, 2026; Wertz & Wynn, 2014 , 2019), and the current results suggest that food processing actions may be viewed similarly. Food processing actions might capture infants' attention because these actions transform a novel (food) item into something that more closely resembles food items that are more familiar to them (since infants are typically first introduced to pureed or cut foods).

Learning about food involves distinguishing between what is edible and what is not (Mura-Paroche et al., 2017). In this sense, food processing actions might help infants identify food items by signaling that the whole, unfamiliar food object they observe being processed is the same as the pureed/cut foods they already know.

4.2. Infants' choices between the novel food item shown in the eating and cutting action videos

Although our eye-tracking data shows that infants react to the eating and cutting actions more similarly than the touch action, our choice data suggest that infants may make different inferences from eating and cutting actions depending on the context in which they occur. Infants chose the food they saw an actor eat when this occurred in the context of the touch control action, replicating previous findings that infants view eating actions as cues that a novel food is edible (e.g., Liberman et al., 2016; Wertz & Wynn, 2014 , 2019). In contrast, although infants differentially attended to the cutting action, our choice data suggest they did not preferentially choose the food they saw an actor cut when this occurred in the context of the touch control action. One possible explanation is that infants' attention is captured by food processing actions but cues of processing are weaker cues of edibility than eating actions. In this case, similar designs but with more repetitions of each action might reveal that infants use cues of food processing to guide their food choices as well.

However, when the eating and cutting actions were paired, infants also no longer reliably chose one novel food type over the other, suggesting that context may play a role in how infants make edibility inferences from eating and cutting actions. There are (at least) two possible interpretations of this pattern of choice results. First, it may be that the results in the "Eat vs. Cut" condition represent a failure to replicate the results of the "Eat vs. Touch" condition, which could cast doubt on the interpretation that infants view eating actions as an indicator of edibility. However, there is considerable converging evidence that infants and young children view eating actions as an indicator of edibility (e.g., DeJesus et al., 2018; Liberman et al., 2016; Wertz & Wynn, 2014 , 2019), so it is unclear why infants would fail to do so only in the "Eat vs. Cut" condition of this study. Therefore, there is a second possible interpretation. Specifically, infants may view both the eating and cutting actions as indicators of edibility, but only when the cutting action occurs within the context of other actions that may indicate edibility (like eating actions). In that case, infants in the "Eat vs. Cut" condition may not show a preference for one of the two roots when asked "Which one can you eat?" because they view them both as potentially edible.

Finally, to better understand the factors that may have influenced infants' choices during the Choice Phase, following the suggestion of an anonymous reviewer, we conducted a followup exploratory analysis to examine the relationship between each infant's choice of a particular root and their interest in the preceding action-videos. Due in large part to the number of "No

Choice" responses in the choice phase, only 37 infants could be included in this analysis across all three conditions and there were no significant relationships within this subset of participants.

Future studies with a larger sample size will be necessary to explore this question in detail.

4.3. Limitations

One potential limitation of our study is that our attempt to closely match our three action types may have made them seem unusual to infants. For example, we included a tool in all three actions such that the actor first lifted the root with tongs in the eating video, cut the root with a knife in the food processing video, and held the root still with a shoehorn in the touch control video. While the knife was necessary for the food processing video, it is possible that the presence of an extraneous artifact in the eating and touch action could have been surprising to infants. Our data suggest that it does not seem to be the case for the eating actions-infants' looking times and pupil dilation were similar across the eating and cutting videos, suggesting that they were not particularly puzzled by the sight of the tongs in the eating video. However, it may explain infants' longer looking times and greater pupil dilation during the touch control action videos. Even if this is the case, it suggests that infants were responding to a semantic interpretation of the videos that allowed them to evaluate the plausibility of each action type, rather than lower-level features.

Another limitation of the current study was that, during the Action Presentation Phase of the experiment, the same actor appeared twice on the screen (i.e., performing one action on the left and another action on the right side of the screen). We chose to have the same actor on all the videos to avoid a potential confound of preference for one person over the other. It might have been surprising for infants to see the same actor who was alternating in the action videos then duplicated in the action still image. However, although infants showed interest in the actor's face during the Action Stills, additional follow-up analyses of infants' gaze shifts did not indicate particular attention to the actors' duplicated faces. Specifically, although infants looked longer at the actor's face area overall, their gaze shifts were distributed similarly between the side-by-side face areas and between other AOIs within the Action Still. Instead, infants' gaze shifts were roughly equally distributed between all areas of interest.

Finally, a caveat to our choice results is that approximately 40% of infants did not choose any food. While this is similar to other studies using choice measures with participants in Northern Europe (e.g., Lucca et al., 2025), it reduced our effective sample size and therefore warrants replication. Further, we were unable to assess infants' eating behaviors because very few infants attempted to eat the novel food stimuli they had chosen (approximately 25% of infants who made a choice attempted to put the root in their mouths). Previous work successfully assessed infants' eating behavior in a choice phase using dried fruits (Wertz & Wynn, 2014 , 2019; although even in these studies, only a subset of infants [approximately 60%] also put the chosen food in their mouth), so it is plausible that infants' lack of eating in the current study was due to the particular novel food stimuli we chose. We used white parsnips and black carrots in order to have foods that were obviously unprocessed, unfamiliar to infants, and could be both eaten and cut. However, infants may have been reluctant to put these root vegetables in their mouths because they were large, hard and did not smell particularly appetizing (unlike fragrant dried fruit) and infants are often offered foods that are cut into pieces at this age. It is also possible that infants' reluctance to choose reflected a lack of hunger.

Previous studies have found a relationship between 12-month-old infants' hunger levels and their attention to food images, highlighting the need to take this variable into account in future studies (Rioux et al., 2025). We did not assess infants' hunger in our study, therefore we cannot rule out this possibility. Future studies attempting to measure infants' eating behavior could use different unfamiliar food stimuli, including items that are more palatable and account for infants' hunger level prior to testing.

4.4. Future directions

Future studies will be necessary to understand the precise role that food processing actions like cutting play in food learning in infancy. Specifically, future work could investigate whether a food processing action like cutting indicates edibility per se or something more like the possibility to become edible in the future (e.g., after additional processing steps take place).

Cutting a food is a clear signal of previous human intervention and is interpreted as such by children and adults (e.g., Foroni et al., 2013 , Girgis & Nguyen, 2020). It can also signal intended consumption and modulate edibility evaluations (i.e., whether an item is a food vs. non-food).

For example, Foinant et al. (2021a) found that when 4-to 6-year-old children performed a food vs. non-food categorization task, they were more likely to miscategorize cut non-food items (e.g., pieces of wood) as foods than to miscategorize whole non-food items as foods. However, a food that is cut into pieces might require further processing before being actually edible (e.g., cassava roots are staple foods in many African countries but have to be cooked to be safely consumed). It is possible that more advanced processing techniques like cooking, which actually change a food's chemical properties and decrease their potential toxicity (while cutting does not) might be needed to reliably signal edibility. In the current experiment, we chose cutting a novel food into pieces as a first step because previous work has shown that infants and children behave differently toward cut foods (Foinant et al., 2021a (Foinant et al., , 2021b;; Rioux & Wertz, 2021), but future studies can include more complex food processing techniques.

Future studies should also investigate how food processing actions may alter infants' representations of food. Infants expect artificial objects to remain cohesive and are surprised when they break apart (e.g., Shutts et al., 2009; Spelke et al., 1993). However, their expectations about food are likely to differ. Infants may not expect foods to remain cohesive because they routinely observe their caregivers transforming food through actions such as cutting, mashing, and cooking. Additionally, the functional properties of foods are likely more related to internal properties (e.g., nutrients, presence or absence of toxins) than to their shape. Consistent with this possibility, although infants fail to track object quantity when a food (a cracker) is split into two pieces, they nevertheless maintain a representation of its identity (Cheries et al., 2008), and older children readily accept transformations of food items (e.g., cutting, melting), whereas they are less likely to accept comparable transformations of non-food natural kinds and artifacts (Girgis et al., 2025).

Another important avenue for future research is to investigate whether the present results are specific to food. In the current experiment, the root stimuli we used were unfamiliar to infants, so it is likely that they had no prior knowledge of whether the roots were food before any action was shown. However, it remains an open question whether infants would selectively attend to eating and food processing actions when these actions are performed on any kind of object. Research on food learning has shown that observing an individual eat an object is a powerful cue of edibility. For example, Liberman and colleagues (2016) showed that infants interpreted the same artifact object-an opaque bowl-differently depending on the type of action performed on it. When an adult ate from the bowl with a spoon, infants construed its contents as food; however, they did not do so when the adult simply lifted the bowl. However, Wertz and colleagues (Rioux & Wertz, 2026; Wertz & Wynn, 2014) showed that infants perceive some objects (i.e., plants) as more likely to be food than others (i.e., artifacts) after observing the same eating actions performed on them. Future research could use a variety of food and non-food objects to further test the specificity of the effects found in the present study.

Another important question for future research is whether the communicative intent of the person performing the actions is necessary for infants to learn about them. In our study, the adult greeted and made eye-contact with the infants before performing the action, which are ostensive signals of communication. Ostensive communication serves the functions of social information exchange and transmission of cultural knowledge during development and infants expect information to be object-centered and generalizable in ostensive contexts (sometimes referred to as natural pedagogy, Csibra & Gergely, 2009; Egyed et al., 2013; Gergely & Kiraly, 2019). On the other hand, infants often passively observe adults and peers eating and processing foods in their daily routine, so it might be that even in non-ostensive contexts (e.g., Kline, 2015) infants use others' actions to learn about food.

Finally, it is an open question from which social partners infants learn best what to eat.

Infants make social inference based on what they see others eat (e.g., Liberman et al., 2014 Liberman et al., , 2021)), but the impact of social status on food learning in infancy is largely unknown. Studies on children's learning from testimony (i.e. others telling them facts about new objects) has shown that children do not treat all informants equally. Instead, they tend to trust more the information provided by familiar over unfamiliar people, reliable over unreliable, experts over non-experts or nice over mean (Wood et al., 2013; Zmyj et al., 2010). Yet, this line of research has mostly been conducted with non-food stimuli and with school-age children and the handful of studies investigating infants and toddlers's food selection based on others' testimonies or actions has revealed mixed findings. For instance, after watching either a stranger or a familiar adult eating an unfamiliar food, 18-to 30-month-old children accept to eat that food (Addessi et al., 2005; Wertz & Wynn, 2014 , 2019), while in another study, 12-month-old infants prefer to learn from an in-group vs. an out-group member (Shutts et al., 2009). Future studies could therefore investigate who has the most influence on infants and toddlers' food selection (e.g., familiar model over unfamiliar, in-group over out-group, etc.).

4.5. Conclusion

The present work investigated the actions infants rely on to learn what to eat. Previous research has shown the influential role of eating actions for guiding infants' food selection (Edelson et al., 2016; Harper & Sanders, 1975; Wertz & Wynn, 2014 , 2019) and our results demonstrate that infants pay similar attention to eating and food processing actions. However, our choice results suggest that infants' food choices are differentially influenced by eating and processing actions depending on the context in which these actions occur. The strength of the present work is in using converging measures to gain a fuller picture of the cognitive mechanisms underlying infants' food learning. Our findings can help identify important mechanisms that increase the acceptance of healthy foods early in life.

These same criteria for parental interference applied to parental interference during the Root Stills and Action Still.

Directly after calibration, alternating light and dark stimuli were presented to assess the individual infant's pupil dilation and constriction responses to contrast changes. All correlations between the questionnaire measures and our primary DVs of interest (i.e., looking times towards dynamic actions and image stills, pupil dilation and food choices) are reported in Tables S9-S14 below.

These correlational analyses revealed that none of the questionnaire measures were systematically related to our DVs of interest. For instance, with Questionnaires 1 and 2, we assessed whether infants' familiarity with the two roots, or the age of introduction of vegetables in their diet, influenced the average times they spent looking at each dynamic action type (i.e., mean looking time per child across all consecutive trials towards cutting, eating or touching dynamic actions in relation to their prior experiences with the study objects). Interestingly, almost none of the questions assessing infants' prior experiences with the study objects were related to infants' looking times, pupil dilation or probability to make a choice. This is in line with previous findings that infants' reaching behaviors and social looking behaviors towards leafy plants and plant foods are not influenced by their' general experience with plants nor their experience with the plant foods they are presented with (Rioux & Wertz, 2021; Wertz & Wynn, 2014; Włodarczyk et al., 2018 Włodarczyk et al., , 2020)).

The absence of a relationship with parental feeding strategies may be due to the content of the Children Feeding and Eating Difficulties questionnaire (Questionnaire 3). Although the questionnaire assesses caregivers' strategies for overcoming feeding difficulties, it primarily focuses on practices such as scolding and the use of rewards and does not assess social learning strategies, such as parental modeling, closer to what was presented to infants in the current study. The absence of a relationship with eating difficulties or neophobic behaviors (Questionnaire 4) may reflect a limitation of the present study. Specifically, we did not obtain a meaningful measure of food consumption because very few infants attempted to eat the roots.

As eating difficulties and food neophobia are primarily expressed during actual eating, their influence may not be reflected in our choice measure.

Finally, regarding parental education (Questionnaire 5), as reviewed by Cole et al., (2017), while some studies found that higher maternal education was associated with a lower risk of picky eating behavior in children (e.g., Migraine et al., 2013), other studies found no such relationship (e.g., Carruth et al., 2004), as was also observed in the present study.
