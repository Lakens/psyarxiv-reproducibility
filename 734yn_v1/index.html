Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Ethics Approval Check works

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

Human research committee names - Institutional Review Board / IRB (US standard) - Independent Ethics Committee / IEC (ICH-GCP international clinical trial term) - Ethical/Ethics Review Board (generic) - Ethics (Advisory/Review) Committee/Board/Panel/Sub-committee - Research Ethics Committee/Board/Panel (UK/Canada/Australia) - Medical Ethics Committee - Human Subjects/Research Committee / Human Research Ethics (Advisory) Panel - Committee for/on the Protection of Human Subjects - Committee on (Health) Research Ethics - Office of Research Ethics - Abbreviations: IEC, REC, REB, ERB, METC, DEC. REC/REB/ERB/DEC are short enough to collide with unrelated jargon (e.g. REC as a recognition-heuristic model abbreviation, DEC as a decision-task label, Reb as an author surname), so these four require an ethics/approval/committee/board/panel/institutional/ protocol word within ~30 characters in the same sentence. IRB and IEC are kept unconstrained as they are not observed to collide in practice. - Dutch: Medisch-ethische toetsingscommissie (METC) - French: Comité d'éthique / Comité d'Ethique

Animal research committee names - Institutional Animal Care and Use Committee / IACUC (US standard) - Any sentence containing animal(s) and committee (or board/panel) within ~5 words of each other — catches Experimental Animal Care and Use Committee, Animal Ethics Committee, Animal Welfare Board, Animal Welfare Ethical Review Body, etc. - UK: Animal Welfare Ethical Review Body / AWERB - Dutch: Dierexperimentencommissie / DEC (see DEC constraint above); Instantie voor Dierenwelzijn / IvD - German: Tierversuchskommission / TvK (advisory committee under §15 Tierschutzgesetz) - French: Comité d'éthique en expérimentation animale / CEEA; Comité d'éthique animale - Spanish: Comité de ética en experimentación animal / CEEA

Approval phrasing - Ethics/Ethical (approval|clearance) [was] (granted|obtained|received|given|secured) - Ethically approved - Approved by the (ethics|irb|institutional|independent|local|review|research) ... - This/The study/protocol/experiment/procedures/methods/research [was] (approved|reviewed) by - Study was ethically approved - (Followed|met|follow) the ethical (guidelines|standards|requirements) - In accordance with ... ethical (guidelines|standards) - Ethics protocol - Approved under (protocol|reference|number)

Waiver / exemption - Ethics/Ethical (waiver|exemption) - IRB (waiver|exemption|exempt) - Exempted from (ethics|irb|institutional review) - Waived by the (ethics|irb|institutional|review) (committee|board) - Deemed exempt

Declaration of Helsinki - Declaration of Helsinki / Helsinki Declaration

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Abstract

Background: Individual differences shape the acute subjective psychedelic experience, but menstrual cycle status remains an understudied source of potential variability.

Methods: In a longitudinal observational study, 169 participants reported psychedelic use during the two-month study period. Participants were classified by menstrual cycle status during their most intense psychedelic experience: menstruating during the experience (n=15), menstruating but not during the experience (n=60), not menstruating (n=25), and male participants (n=69).

Primary analyses examined associations between cycle status and ego dissolution (Ego Dissolution Inventory; EDI), mystical-type experience (Mystical Experience Questionnaire; MEQ), and challenging experience (Challenging Experience Questionnaire; CEQ), adjusting for dose and age. Exploratory analyses examined MEQ and CEQ subscales and post-acute risk of harm to self and others.

Results: Participants menstruating during their experience reported higher EDI scores than both those menstruating but not during the experience and male participants (β=-0.89 and -0.68, ps≤.011). Cycle status was not associated with MEQ or CEQ scores. Exploratory analyses found higher physical distress and death subscale scores among participants menstruating during their experience than among those menstruating but not during the experience (β=-0.77 and -0.80, ps≤.005). Risk of post-acute harm to self and others was higher among those menstruating during the experience than among those menstruating regularly but not during the experience (OR=6.41, p=.022).

Conclusions: Menstrual cycle timing may be associated with aspects of the acute psychedelic experience, specifically ego dissolution and potentially risk of post-acute harm to self and others.

These preliminary findings support further investigation of menstrual cycle status in psychedelic research.

Menstrual Cycle Status and the Acute Subjective Psychedelic Experience

In recent years, clinical research on psychedelics has increasingly examined individual differences that shape the acute subjective psychedelic experience. Studies have identified interindividual differences that impact the psychedelic experience including dose, personality traits, and demographic factors (Aday et al., 2021; Haijen et al., 2018; Hartogsohn, 2017). Sex is increasingly recognized as one such factor. For example, one recent study found that female participants reported greater subjective intensity following psychedelic use than male participants (Mason et al., 2026), suggesting that sex may moderate the acute psychedelic experience.

Despite this growing body of research, comparatively little attention has been paid to sexspecific physiology, including menstrual cycle timing and hormonal fluctuations across the menstrual cycle. Because many psychedelic compounds act through the serotonergic system (Nichols, 2016), and ovarian hormones are known to modulate serotonergic signaling (Bethea et al., 2002), hormonal fluctuations across the menstrual cycle may contribute to variability in the acute subjective psychedelic experiences. Therefore, understanding these factors is important for informing more personalized approaches to psychedelic research and treatment.

The acute psychedelic experience is multidimensional, encompassing both positive and negative valence. In a longitudinal observational study of people who used psychedelics in naturalistic settings, we investigated whether menstrual cycle status at the time of participants' most intense psychedelic experience during the two-month study period was associated with three dimensions of that experience: ego dissolution, mystical-type experience, and challenging experience. We also explored whether cycle status was associated with specific features of mystical-type and challenging experiences, and with overall risk of harm in the days or weeks following the experience.

Methods

Sample

Participants were recruited in June of 2024 through Prolific Academic, a participant recruitment platform that frequently produces high-quality participation (Douglas et al., 2023).

Informed consent to participate was obtained electronically from all participants prior to their completion of baseline surveys. The University of Wisconsin-Madison Institutional Review Board determined that the study procedures were exempt from review. This study was part of a larger study (Simonsson et al., 2025) in which participants received payment for completion of their surveys.

At baseline, participants reported sociodemographic characteristics, including age.

Participants were invited to complete a follow-up survey two months later and were then asked whether they had used psychedelics in the past two months. Of the participants who completed baseline and follow-up, 169 reported a psychedelic experience during the study period and formed the analytic sample. Those participants who reported female sex assignment at birth were also asked questions about reproductive status, including pregnancy status, breastfeeding status, regular menstruation status, as well as whether they were menstruating at the time of their most intense psychedelic experience during the two-month study period.

Measures

Ego dissolution was measured with the 8-item EDI (Nour et al., 2016; item range 0-100; α = .92). Mystical-type experience was measured with the 30-item MEQ (Barrett et al., 2015; item range 0-5; α = .97), which comprises four subscales: mystical, positive mood, transcendence of time and space, and ineffability. Challenging experience was measured with the 26-item CEQ (Barrett et al., 2016; item range 0-5; α = .98), which comprises seven subscales: fear, grief, physical distress, insanity, isolation, death, and paranoia. Total and subscale scores were the mean of their items, with higher scores indicating a more intense experience. At followup, participants also reported whether they had experienced thoughts or attempts to harm themselves or others in the days or weeks following their psychedelic experience.

Analysis

All analyses were conducted in R (R Core Team, 2025). Linear regression models were fitted with a four-level cycle status variable (menstruating during the experience, menstruating regularly but not during the experience, not menstruating, and males) as the predictor of interest, while EDI, MEQ, and CEQ total scores served as outcomes. Separate models were run for the three outcome variables. Menstruating during the experience was set as the reference category, and the covariates described below were included predictors.

To characterize potential differences across dimensions of the psychedelic experience, exploratory analyses were conducted using the MEQ and CEQ subscales. FDR correction (Benjamini and Hochberg, 1995) was applied to the exploratory subscale models only, across the 11 subscales and separately for each of the three group contrasts. To derive standardized coefficients, the outcome variables were standardized (i.e., z-scored); all predictors (cycle status and covariates) were categorical and were left in their original coding.

Overall risk of post-acute harm was examined with logistic regression using the same predictors and covariates, with results reported as odds ratios. Because harm was relatively uncommon, Firth's penalized likelihood logistic regression (Firth, 1993) was conducted as a sensitivity analysis.

Because the group of participants who reported menstruating during the psychedelic experience was relatively small, a sensitivity analysis was also conducted in which the four-level menstrual cycle variable was collapsed into a binary variable comparing participants who were menstruating during the psychedelic experience with all other participants. The same covariates and outcome measures were retained in these models.

Models were adjusted for dose (low, moderate, large, very large, extremely large) and age group (18-24, 25-34, 35-44, 45-50). These covariates were selected based on documented associations with the intensity of subjective psychedelic experiences and, for age, relevance to menstrual cycle status (Hirschfeld and Schmidt, 2021; Mason et al., 2026; Shadani et al., 2024).

In additional analyses, the same models were fitted with sex at birth (female vs. male) as the predictor in place of cycle status.

Results

Sample Characteristics

Of the 169 participants, 100 (59%) were female and 69 (41%) were male participants. Among female participants, 15 (15%) were menstruating during their most intense psychedelic experience, 60 (60%) were menstruating regularly but not during the experience, and 25 (25%) were not menstruating regularly. At follow-up, 3 female participants (3%) reported being pregnant and 2 (2%) reported breastfeeding (Table 1).

Associations Between Menstruation Status and Acute Psychedelic Experience

The regression model for EDI showed a significant association between menstruation status and EDI scores (Table 2). Participants who were menstruating during the psychedelic experience reported significantly higher ego dissolution scores than participants who were menstruating regularly but not during the experience (β = -0.89, p = .002) and male participants (β = -0.68, p = .011). The difference from participants who were not menstruating regularly was similar in size but did not reach significance (β = -0.62, p = .050). The standardized coefficients indicated moderate-to-large effects (Cohen, 1992). Menstruation status was not significantly associated with MEQ or CEQ scores (Table 2).

Compared with participants who were menstruating during the psychedelic experience, MEQ scores did not differ significantly for those menstruating regularly but not during the experience (β = -0.50, p = .075), those not menstruating regularly (β = -0.43, p = .176), or male participants (β = -0.47, p = .078). Likewise, CEQ scores did not differ significantly for any comparison (β = -0.31 to -0.47, ps ≥ .09).

Overall, 29 participants (17%) reported thoughts or attempts to harm themselves or others in the days or weeks following the experience. This post-acute risk of harm was reported by 7 of 15 participants (47%) menstruating during the experience, 4 of 60 (7%) menstruating regularly but not during the experience, 4 of 25 (16%) not menstruating, and 14 of 69 (20%) male participants. Participants menstruating during the experience had higher adjusted odds of risk of post-acute harm than those menstruating regularly but not during the experience (OR = 6.41, 95% CI [1.35, 33.90], p = .022). Differences relative to participants not menstruating (OR = 1.56, p = .60) and male participants (OR = 2.49, p = .17) were not significant. Results were similar using Firth's penalized likelihood (Supplementary Table S3).

Exploratory subscale analyses revealed two findings that survived FDR correction (Supplementary Table S1). Relative to participants who were menstruating during the psychedelic experience, those menstruating regularly but not during the experience reported lower scores on the CEQ physical distress subscale (β = -0.77, p raw = .005, p FDR = .028) and death subscale (β = -0.80, p raw = .002, p FDR = .023).

Sensitivity Analyses

Sensitivity analyses yielded results consistent with the primary analyses. When the fourlevel cycle status variable was collapsed into a binary variable, participants who were menstruating during the psychedelic experience reported significantly higher EDI scores than all other participants combined (β = -0.74, p = .004). Associations with MEQ (β = -0.48, p = .064) and CEQ (β = -0.37, p = .155) total scores remained nonsignificant.

Additional Analyses

Notably, in additional analyses comparing female and male participants, there were no statistically significant differences in any of the outcomes (Supplementary Table S4).

Discussion

This study examined whether menstrual cycle timing was associated with key aspects of the acute psychedelic experience, namely ego dissolution, mystical-type experience, and challenging experience, in a longitudinal sample of people who used psychedelics in naturalistic settings. Female participants menstruating during their psychedelic experience reported significantly higher ego dissolution than those menstruating regularly but not during the experience and male participants, with moderate-to-large effect sizes. No significant associations were observed for mystical-type experience or challenging experience at the total score level.

Exploratory subscale analyses revealed that female participants menstruating during the experience also reported greater scores on physical distress and death subscales. Female participants menstruating during the experience were also more likely to report thoughts or attempts to harm themselves or others in the days or weeks following the experience, although this difference was significant only relative to those menstruating regularly but not during the experience.

Previous research on sex differences in response to psychedelics remains limited, and available evidence has not allowed for strong conclusions regarding sex-dependent effects (Shadani et al., 2024). Moreover, studies have rarely been designed to examine hormonal state or menstrual cycle stage as sources of variability in response to psychedelics (Cohen and Blest-Hopley, 2025). In the present sample, no differences emerged when female and male participants were compared overall, whereas differences were observed across menstrual timing groups, suggesting that sex alone may not capture variability associated with menstrual cycle status. The observed increase in ego dissolution may reflect a broader amplification of psychedelic effects during menstruation rather than a change only specific to self-experience. The precise hormonal mechanism underlying this finding remains unclear, however, and future research incorporating direct measurements will be necessary to clarify it (Mason et al., 2026; Shoar et al., 2025).

Associations with mystical-type and challenging experience total scores were not statistically significant. This pattern could indicate that menstrual cycle status affects some aspects of the acute psychedelic experience, such as ego dissolution, but not others. However, a more likely explanation is limited statistical power, given the small number of participants menstruating during the experience. Larger samples will be needed to determine whether menstrual timing relates to the intensity of the acute experience broadly or to ego dissolution specifically.

Female participants menstruating during their experience reported risk of post-acute harm more often (47%) than those menstruating regularly but not during the experience (7%), those not menstruating regularly (16%), and male participants (20%). This difference was significant only for the comparison with those menstruating regularly but not during the experience, and it rests on a small number of events, so it should be treated as exploratory. Still, if replicated, it would suggest that menstrual timing is relevant to the safety of psychedelic use, not only to the subjective experience.

Exploratory subscale analyses showed that female participants menstruating during the experience had higher scores on the CEQ physical distress and death subscales than those menstruating regularly but not during the experience. Psychedelics serve as nonspecific amplifiers of ongoing mental and bodily states (Grof, 2008), and it is important to consider setting in this context. Participants who were menstruating may have entered the experience with physical discomfort and a specific mindset, which psychedelics could have amplified into greater distress or more challenging content. Another biological explanation is also possible. Menstruation falls in the early follicular phase, when estradiol and progesterone are relatively low. Such sex hormones modulate central 5-HT2A receptor binding in humans (Moses et al., 2000), and this phase may be associated with increased sensitivity to psychedelics (Kuypers et al., 2026). Neither explanation has been tested directly, and future studies should assess pre-experience mood and menstrual symptoms alongside hormonal measures.

An important limitation to note is the smaller sizes of the menstruating-during-experience group (n = 15) and the overall sample (n = 169). As this provided limited statistical power, findings should be considered preliminary and interpreted cautiously. Other limitations include the study's naturalistic, observational design, which relied on self-report for menstrual timing rather than direct confirmation via hormonal assays. Given the observational design, causal claims regarding the link between menstruation and acute experiences cannot be made.

These limitations notwithstanding, this study suggests that menstrual cycle state at the time of a psychedelic experience may be associated with some acute subjective phenomena.

Future research should examine these associations in larger prospective samples and incorporate direct hormonal measurement across the full menstrual cycle. Accounting for menstrual cycle status in future clinical trials may help clarify sources of variability in response and inform safer, more personalized psychedelic therapy.
