Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

About the personal-information flags. These are pattern matches, not confirmed disclosures, and they are tuned to over-report rather than miss something. Expect false positives:

  • Column names are matched against identifying words in English and other European languages (email, telefoonnummer, geboortedatum, …). A column called phone_number flags whether or not it holds one, and an empty or already-anonymised column flags on its name alone.
  • Values are matched against the shape of an identifier. An IP address pattern also matches a version string or a dotted numeric code; a card-number pattern requires both a real issuer prefix and a checksum, but a long numeric ID can still coincide.
  • Free text is flagged when a column holds long, mostly-distinct prose — the shape open-ended answers take. Most such columns contain no names at all.

A flag means look at this column. Where the data is already de-identified (an ip column reading Anonymized, a name column the authors emptied), no action is needed.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). How Code Check works

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. Full text

Abstract

Are simpler explanations better, all else equal? Many people seem to think so. And many capitalize on this preference by claiming that their explanations are simple -perhaps the simplest! But some scholars have argued that the case for simplicity's status as a theoretical virtue is quite thin. And some psychological studies raise questions about the reliability of simplicity's benefits. Alas, once acquired, status as a theoretical virtue is rarely lost. To advance the debate, we conducted three experiments that test another way so-called theoretical virtues may impact reasoning (N = 1312). Merely labeling diagnoses 'the simplest explanation' made them more alluring in ways that were not warranted by relevant base rates, symptoms, or other causal information (experiment 1)even when those diagnoses were not actually simplest! Neither the opposite label ('most complex') nor an alternative explanatory virtue label ('most unifying') had such consistent or reliable effects (experiment 2), suggesting simplicity itself is particularly seductive. The good news is that judgments and decisions were mostly unaffected by fallacious appeals to simplicity when we switched to other contexts and measures (experiment 3). That limited generalization suggests a variety of testable hypotheses about the boundaries and moderators of simplicity's allure. For example, perhaps people rely more on intuitions about simplicity when diagnostic decision-making would otherwise require effortful reflection on technical terminology and difficult-to-compute probabilities. Together, our findings replicate and extend prior research on simplicity preferences, complement recent arguments and evidence about the risk of considering simplicity, and increase suspicion about simplicity's virtuous status.

1. Introduction

Many people intuit that, all else being equal, simpler theories and explanations are rationally "preferable" to more complex ones -a.k.a., the "principle of parsimony" (Baker 2022). Indeed, scientists are often described as appealing to simplicity in theory selection: "Undoubtedly, … considerations of …simplicity … play important roles [such as] a criterion of choice between theories which are in other respects comparable" (Kuhn 1969 (Kuhn /1977, 342, 342; see also Morgan 2013). Simplicity can be defined in a variety of ways against a variety of objectives, but the basic idea -also known as Occam's Razor -prescribes the entities and causes explanations invoked not be multiplied beyond necessity (Sober 2015).

Recent findings in psychology paint seemingly competing pictures about how simplicity affects judgments of explanation quality. The first view reflects the razor's sheen: simpler is better. Important work on causal reasoning suggests this view. Lombrozo's (2007) seminal study first clearly detected and quantified the ubiquity and magnitude of simplicity preferences. Participants were tasked with identifying the most satisfying explanation for the symptoms of imaginary alien patients (sore "mintells" and purple spots). After learning the base rates of hypothetical diseases, participants chose between simple diagnoses invoking a common-cause and more complex diagnoses invoking two independent causes. Those base rates are crucial for calculating the probability of each explanation, but whether people use them can depend on how they interpret other available information (Tversky and Kahneman 1977; Sotos 1991; Turpin et al., 2020). Lombrozo's clever design could therefore reveal the psychological influences of both base rates and explanatory simplicity. Results revealed some sensitivity to base rates, but also a strong preference for simpler one-cause explanations over more probable complex ones. Strikingly, only when the complex explanations were 10 times more probable were they deemed more satisfying than simpler ones.

Some recent research reinforces and extends this finding. Vrantsidis and Lombrozo found simplicity preferences both in fictitious alien-disease scenarios resembling Lombrozo's original cases (2022) and in scenarios involving more familiar, everyday entities (2024). Even children systematically preferred simplicity in studies from Bonawitz and Lombrozo (2012). They modified Lombrozo's study for preschool-aged children by displaying a toy with different functions and similarly manipulated probabilistic data across conditions by varying frequencies of distinct types of evidence. When prompted to say why a toy's fan and light were on, children could answer with a simple one-cause or a two-cause explanation. For parsimony preferences, like progenitor like progeny: children strongly preferred simpler explanations, even when complex alternatives were more likely.

Explicit statistical measures of simplicity capture a similar disposition. Bayesian accounts of Occam's razor, for instance, penalize complex hypotheses that can accommodate wider ranges of possible data. Blanchard, Lombrozo, and Nichols (2018) first investigated explanatory inference with Bayesian metrics. When participants estimated the probability and "explanatoriness" of competing hypotheses, complex ones were penalized for their greater flexibility -accommodating data via more free parameters and/or parameters with more possible values -over simpler hypotheses.

In addition to causal explanation, the simpler-is-better picture is also on display in studies of causal learning. When learning about mathematical functions, for example, Little and Shiffrin (2009) found individuals exhibit a simplicity bias. Lu et al. (2008) also observed that perceptions of parsimony influenced perceptions of causal strength; explanations positing small numbers of strong causes were consistently preferred over those invoking more, but comparatively weaker, causes. Similarly, Walker et al. (2017) found that prompting explanation-seeking behavior amplified preferences for simple hypotheses. This may underlie an interesting pattern Pacer and Lombrozo (2017) identified. In that study, after selecting explanations for alien symptoms, participants reported the base rate frequencies they remembered. For simple-but-improbable explanations, perceived empirical support was consistently inflated. And the effect was larger when the explanation task preceded the memory task. Taken together, such studies document a widespread and systematic proclivity for simplicity in causal learning, inference, and memory.

Other studies paint a seemingly different picture in which people are unswayed by simplicity, or even favor complexity. Zemla et al. (2017) proposed familiar and, therefore, more ecologically valid stimuli than the highly controlled pseudo-scenarios explored in Lombrozo's and many others' materials. For non-fantastical, real-world cases they believed explanatory affinity would bend towards complexity, and thus employed real-world questions such as: "why isn't China's population decreasing if they've had a one-child policy for 35 years?" Participants similarly chose the most satisfying option among several explanations displaying varying degrees of complexity: simple explanations again had one cause, and complex explanations had multiple. Results revealed preferences for complex explanations comprising more causal details. These results corroborate other content effects of parsimony: Longer arguments with more premises, supplying quantitative data, citing sources, using complex language, or evaluating opposing views were usually judged better supported than analogous simpler alternatives (Heit and Rotello 2012; Kikas 2003; Lawson 2014; Weisberg et al. 2015; Cruz and Lombrozo 2025; cf. Oprea 2020). Complexity also appears attractive in curve-fitting contexts where higher-order lines better fit the data, or in evaluating explanations in stochastic causal scenarios (e.g., Johnson et al. 2019).

There are various proposals about why people sometimes prefer simplicity and sometimes prefer complexity, though there is still debate over the right way to conceptualize this. So-called "complexitymatching" might reconcile these conflicting pictures of simplicity's allure. By varying the complexity of explanans and explananda, Lim and Oppenheimer (2020) found participants judged explanations most satisfying when they matched the level of complexity of the explained events: people preferred simpler explanations for simpler events and complex explanations for more complex events. While suggestive, these studies sometimes did not detect these effects (on, for example, the readability of or the number of causes in participants' explanations). So complexity matching is not the whole story. Evaluating that hypothesis is not our objective, however.

Rather, we investigate a distinct, potentially significant, and relatively unexplored effect of common labels such as 'the simplest explanation'. Words are powerful. They shape how we understand and think about the world around us, and they are the sine qua non semantic vehicles of framing effects. Framing one and the same fact positively versus negatively -labeling the same information as 'gains' vs. 'losses', 'saving' vs. 'letting die', 'estate' vs. 'death' tax -can contaminate perceptions of outcomes and thereby alter decisions (Tversky and Kahneman 1981). The pervasiveness and potency of this phenomenon has been demonstrated across numerous domains of human decision-making (McDonald et al. 2021; Otterbring et al. 2021; Ropert Homar and Knežević Cvelbar 2021). Science, like any other human activity, may also be vulnerable to framing effects caused by labels. 'Simple' can be a cognitive term of endearment while 'complexity' can express reproach. Scientific theories, hypotheses, and explanations invoke 'simplicity' "more frequently than the other theoretical virtues" (Mizrahi 2022). Politicians also routinely champion their simple policies over the convoluted complexity of their opponents (Sharkansky 2002). Even professional education and training imbibes the norm. In judging criminality, for instance, the FBI Law Enforcement Bulletin counsels, "the least complicated explanation of an event is usually the correct one" (Rothwell 2006). Given its widespread invocation, the wide-ranging, well-established power of frames raises our primary research question: can simply labeling something 'simplest' generate a framing effect? After all, if simple labels can exacerbate the already striking departure from correct evidential reasoning found by some studies of simplicity preferences, parsimony could -in some important contexts -deserve demotion from its honorific status as a theoretical virtue.

Some evidence is already compatible with a framing effect of simplicity. Shimojo et al. (2020) drew attention to simplicity with both visual cues and verbal labels. Their combined intervention had no effect in disease diagnosis scenarios in one experiment, but had a small effect in a second experiment where participants were provided a general tutorial about explanatory virtues. It was not until Liefgreen and Lagnado (2021) that we had evidence that the visual cue can by itself produce the latter effect: in legal reasoning contexts, causal diagrams shifted preferences toward either a simpler or a more complex hypothesis, depending on the condition. It remains to be seen whether a verbal label can by itself produce similar framing effects. So our experiments tested the effects of adding only 'simplest', 'simpler', and 'simple' to diagnostic, scientific, and real-world explanations.

Experiments 1 and 2 replicated the preference for the fewer-root-causes notion of simplicity (Lombrozo 2007) and isolated an additional, fallacious allure of simplicity. Experiment 1 had three conditions. A control condition reproduces Lombrozo's vignette, unmodified. Another condition attached 'simplest' to a simple (one-cause) explanation. To further test the label's potency, a third condition attached 'simplest' to a more complex (two-cause) explanation. Experiment 2 had the same experimental design as experiment 1 but tested whether 'most complex' and 'most unifying' had the The Allure of Simplicity same effects as 'simplest'. Given the strength of the implied simplicity preference numerous studies have demonstrated, we predicted adding 'simplest' to explanations in experiment 1 would make them even more alluring, extending Lombrozo's results. For experiment 2, intuition may predict a similar preference for explanations labeled 'most unifying' (because unity is allegedly virtuous), and predict aversion to 'most complex' labels (because complexity is simplicity's conceptual contrast). Experiment 3 adapted stimuli from Bonawitz and Lombrozo (2012) and presented some new stimuli to assess the generalizability of simplicity labeling effects. Like experiments 1 and 2, participants selected their preferred diagnosis, but they also rated stand-alone explanations.

Experiment 1 reliably found that labeling an alien diagnosis the 'simplest' explanation made it more alluring, even when the diagnosis was not simpler and when base rates did not make the explanation more probable! Surprisingly, experiment 2 did not detect such a consistent or reliable effect of 'most complex' or 'most unifying'. So, the seemingly fallacious allure of simplicity was not attributable to a more general allure of superlatives or theoretical virtues. Also, simplicity and complexity labels did not seem to have opposing effects: the positive valence of the former did not invert to negativity for the latter. The scenarios and measures in experiment 3 found only a marginal effect of simplicity labels, but on only a minority of judgments (and in the opposite direction), generating hypotheses about the boundaries or moderators of simplicity's allure. Altogether, these results vindicate some concerns about the epistemic credentials of theoretical virtues like simplicity but also suggest these concerns may have limits. In short, even if the simplest theories or explanations should be preferred in certain cases, we found that explicit appeals to 'the simplest explanation' can lead to vicious reasoning.

These data clearly indicate that simpler explanations are preferred and labeling explanations as 'simplest' can further increase the appeal of explanations, even when the labeled explanations are not actually simplest! However, one may wonder whether any superlative (or superlative explanatory virtue) label increases explanatory appeal. Would a 'most unifying' label reliably make explanations more appealing? What about the opposite of the 'simplest' label, 'most complex'? To evaluate whether the labeling effect from experiment 1 was due to the concept of simplicity per se or a more general labeling effect, we conducted another experiment.

5. General Discussion

Parsimony is but one of a much broader set of so-called "theoretical virtues" (Barnes 1992 (Barnes , 1995;; Schindler 2018). Allusions to these virtues, and parsimony's prized place among them, permeate the history of science. And in more recent history, "both natural and social scientists tend to agree that a theory being simple raises their confidence [in a theory's correctness]" (Schindler 2022, 553). For some, simplicity even constitutes an intellectual precondition of scientific consideration: "[physicists] demand simplicity and rigidity in our principles before we are willing to take them seriously" (Weinberg 1993, 148-9). Despite forceful criticism from skeptics (McAllister 1996; Roche 2018), the overwhelmingly positive assessment of simplicity in the literature suggests philosophers' and scientists' widespread acceptance of its virtuous status (see Baker 2022). But recent psychological findings are upending this sanguine outlook, even for pragmatist accounts that rightly admit of failure cases (Douglas 2009 (Douglas , 2013;; Achinstein 2018, 68-121, 122-167). Building on Lombrozo's early work on the role of simplicity in explanatory evaluations (2007), we tested whether non-evidential simplicity cues can bias reasoning beyond what evidence warrants. Experiment 1 found that merely labeling a diagnosis 'the simplest explanation' made more people find it "most satisfying", even when that diagnosis was not actually simplest, and even after accounting for sensitivity to relevant base rates. Experiment 2 found that the effects of other superlative or virtue labels ('most complex' and 'most unifying') were not as reliable or consistent. These virtue labeling effects alone may call into question whether all theoretical "virtues" are appropriately named. And the less reliable effects of other simplicity labels in other contexts reveal a panoply of testable hypotheses.

5.1 Theoretical Virtues and Nearby Concepts

Many scholars see theoretical virtues as conferring epistemic advantages, not just psychological appeal: "Theoretical virtues are the traits of a theory that show it is probably true or worth accepting" (Keas 2018). One way simplicity is thought to fulfill this epistemically virtuous function is by providing a cue for approximating Bayesian inference (Vrantsidis and Lombrozo 2022). Indeed, simplicity cues may be among the most salient features of explanations because the relevant probabilities are not available, because we lack the capacity to compute the relevant probabilities, or because the probabilities are not estimated precisely enough to be informative. And real-world phenomena are often so complex that our explanations of them are too artificial and imprecise to objectively determine which one of them is both representative of all the probable causes and actually simplest (on all credible metrics of simplicity). And when our evidence is that difficult to parse, people will rely more on other cues, such as whether one explanation seems simpler (Lombrozo 2007, experiments 1 and 4), especially in the face of a pernicious appeal to 'the simplest explanation' -that is, a claim that an explanation is simplest when it is either not provably simplest or provably not simplest (as in our first experiment).

So even if a simpler-is-better heuristic can have epistemically beneficial consequences in some circumstances (Johnson et al. 2019; Vrantsidis and Lombrozo 2022), results like ours reveal how simplicity could nonetheless fall short of virtue status: some common simplicity cues not only fail to be a reason to regard an explanation as "probably true or worth accepting" (unlike theoretical virtue), they also undermine such epistemic functions (contrary to theoretical virtue). Upon reflection this may not be surprising. Unlike virtues, "useful" heuristics are not supposed to be good wherever they manifest (Tversky and Kahneman 1974). Rather, heuristic success or failure varies widely (Todd and Gigerenzer 2007), and deploying heuristics only when they work is far from straightforward (Byrd 2025b).

The exact nature of the fallacious allure of simplicity merits careful examination because a possible objection is lurking. Theoretical virtues are so named because they (putatively) help scientists discover what's true. As such, these virtues would provide evidential support beyond what data scientists analyze. The idea is that simplicity's influence on explanatory judgments (beyond the influence of base rates and other evidence) may not be erroneous; perhaps simplicity can provide additional epistemic guidance of the kind that theoretical virtues are supposed to afford (Vrantsidis 2026a).

Two threads to this objection should be distinguished. First, appeals to parsimony typically occur -and their prospects for credibility are greatest -when data are equivocal: they don't decide between competing hypotheses about existing data. That's the typical reason for Occam's "all else being equal" disclaimer. But the uncertainty of those circumstances is obviously irrelevant in Lombrozo's (2007) vignettes (and our adaptations in the first two experiments): these vignettes are definite and clearly sufficient to determine the relevant probabilities for candidate explanations. In these scenarios there is no empirical gap for theoretical virtues to exploit. But if there are real-world explanations that are evidentially tied, would deference to simpler explanations be justified?

This brings us to the second thread about predictive success where justifying simplicity's virtuosity is less straightforward. Perhaps the evidential support theoretical virtues supposedly possess can contravene in circumstances of complete certainty, when what the data probabilistically say about hypotheses is explicit and determinate. In fact, empirical evidence suggests social scientists, natural scientists, and philosophers agree that conflicts with known and incontrovertible data are acceptable when a theory is unifying, but only the social scientists tended to think this about simplicity (Schindler 2022). Of course, there are clear cases where such evidential support exists. The Akaike Information Criterion, Bayesian Information Criterion, Minimum Description Length, and other model-selection principles all supply theoretically grounded and statistically exact conditions under which simplicity has unequivocal evidentiary force (Burnham and Anderson 2002). But pinning simplicity's virtue status on model-selection statistics is hopeless. First, even within these frameworks, the circumstances favoring simplicity are very narrowly circumscribed (Justus 2011). Second, these selection criteria are statable, provable, and applicable only within specific, well-developed analytic frameworks that lack real-world complexity and are immune to the cognitive pitfalls of human reasoning (Simon 1955). So any empirical claim that simplicity has the same epistemic success beyond these specific frameworks is speculative extrapolation at best. So the prospects for a general defense of simplicity appear dim. 7 These empiricist scruples generalize. Arguments for treating simplicity or another explanatory characteristic as a theoretical virtue cannot rest solely on simplicity's intuitive appeal, aesthetic beauty, tradition, or historical precedent in science; they must establish whether relying on that characteristic actually promotes the epistemic outcomes theoretical virtues are supposed to provide (rather than occasionally, indirectly, or heuristically providing epistemic value). In short, simplicity's credentials can only emerge after running the gauntlet of empirical data. 8 So what we need are data-driven assessments of whether theoretical virtues actually achieve the epistemic objectives scientists (and philosophers) expect. Selection bias, for instance, can only be identified and corrected with data. As Sober emphasizes about a different virtue (unification), "We must avoid the mistake of selective attention [and] count the failures as well as the successes…. [W]e need to watch out for a selection bias; the apparent track record to date overestimates the success rate of unification and it is hard to say by how much" (Sober 2015, 46-47). Our results seem to reveal not-yet-counted failures of simplicity.

As a matter for direct empirical evaluation rather than intuition or speculation, the track record of theoretical virtues is largely underexplored, though a growing number of studies are beginning to address this gap for simplicity (Lombrozo 2007; Bonawitz and Lombrozo 2012; Pacer and Lombrozo 2017; Johnson et al. 2019; Shimojo et al. 2020; Sehl et al. 2024; Zemla 2023; Vrantsidis and Lombrozo 2022, 2024; Vrantsidis 2026a Vrantsidis , 2026b) ) as well as other virtues (Henderson 2014 , Douven and Schupbach 2015 , Douven and Wenmackers 2017 , Dellsén 2018). 9 Our experiments address this deficiency by investigating whether explicit appeals to parsimony improve or inhibit probabilistic reasoning. We found a substantial inhibitory effect in experiment 1. Results from that experiment demonstrated that explicitly labeling a diagnosis 'the simplest explanation' made more people choose that explanation, regardless of base rates and even though the allegedly 'simplest' explanation was not actually the simplest, but a conjunction of two simpler explanations. In short, 'the simplest explanation' can be more alluring than more relevant factors such as base rates (Tversky and Kahneman 1977) or the conjunction rules of probability (Tversky and Kahneman 1983). This is the fallacious allure of simplicity (as distinct from other preferences for simplicity, rational or otherwise).

5.2 Implications and Future Directions

Our 'simpler' and 'simple' labels in experiment 3 did not yield the kind of effects on explanation choice or ratings that you might expect based on experiment 1. What explains the different pattern of results is an open question, as there were many differences between the two experimental designs. Differences between other experiments are also worth discussing.

What can we infer from differences between our experiments? Perhaps the more relatable content in experiment 3 cued familiar experiences that made relevant base rates more salient relative to simplicity cues (Zemla et al. 2017). Indeed, Lombrozo found that "experienced" base rates seemed more memorable than stated base rates (2007, experiments 3 versus 2). And content familiarity has been found to mitigate fallacious inferences associated with other heuristics (Cox and Griggs 1982; Griggs and Cox 1982). Of course, content familiarity cannot be the whole story: familiar content does not always improve reasoning (Pollard and Evans, 1987) and simplicity preferences sometimes emerge in experiments involving real-world stimuli (Vrantsidis and Lombrozo 2024).

Colleagues and reviewers have also proposed other difference-making differences between our experiments. Consider a few. The evaluative goal may matter: choosing one from a few one-and twocause explanations is not the same as rating a stand-alone, one-cause explanation. Relatedly, differences in measurement instrument may matter: for example, the alien diagnosis task involved six response options but the everyday diagnosis involved just two; so the difference in simplicity between the onecause and two-cause diagnoses of the everyday case may have been so obvious that labeling one 'simpler' supplied scant additional information. There may also be domain differences, such as between the everyday diagnosis and scientific explanation evaluations: perhaps people (such as our undergraduate participants) expect good scientific explanations to be more complex than diagnoses in everyday troubleshooting (Johnson et al. 2019). There may also be differences in how simplicity is conveyed: perhaps 'simplest' (experiment 1) is more potent than 'simpler' or 'simple' (experiment 3).

Because evaluative goal, response format, domain expectations, simplicity cues, and other details varied between the alien diagnostic tasks (in experiments 1 and 2) and our more familiar cases (in experiment 3), cross-experiment comparisons cannot by themselves identify which factor or combination of factors caused different results. Researchers with the capacity to run a massive, manyarm experiment could estimate the differential effects of each candidate moderator. For now, the limited generalization of simplicity's fallacious allure offers hopeful hypotheses about the prospects of mitigating heuristic failures in some paradigms and populations (Peters et al. 2022).

What can we infer from differences with other experiments? The presence, amount, nature, or interpretation of information can result in various framing effects (Tversky and Kahneman 1981). Druckman (2001) suggests that even those effects can be substantially reduced by showing people both frames. And more information may help in experiments like ours: Lombrozo found that revealing base rates of each conjunction of diseases (from the two-cause diagnoses) made fewer participants select the one-cause explanations (2007, experiments 4 versus 2). So even if sensitivity to base rates was not sufficient in these diagnostic tasks, giving people more of the relevant base rates did seem to reduce the fallacious allure of simplicity. Indeed, one reviewer proposed that insofar as the explicit base rates in experiment 1 were perceived correctly (as credible and relevant), they may have reduced (rather than increased) the fallacious allure of 'the simplest explanation', suggesting our estimate of simplicity's seductive strength may be conservative. Of course, providing more information does not necessarily improve decision-making (Byrd 2022 (Byrd , 2025b) ) when gauged against standard accounts of rationality (Carnap 1947). Adding appeals to authority, mathematical formalism, extraneous causal details, or other content can create new frames, confounds, or communicative failures (Dorison and Rogers 2024).

What about the other superlative or theoretical virtue labels? Results from experiment 2 suggest the 'most complex' or 'most unifying' explanations lack the rhetorical allure of 'the simplest explanation'. Perhaps more puzzling was the apparent absence of a negative effect of the 'most complex' label in experiment 2. Conceptually, 'complexity' and 'simplicity' are typically understood as logical contraries. The virtue status of simplicity therefore naturally implies a correlated demerit for complexity. However, experiments 1 and 2 detected the conceptual but not the normative contrast. Perhaps whatever underlies the 'complexity matching' phenomenon found in other studies countervails the fault complexity should accrue as the contrast of (alluring) simplicity.

A reviewer proposed that causal structure may also impact the appeal of complexity: unlike the alien cases we adapted that involve deterministic diseases that produce separate symptoms (Lombrozo 2007), cases involving probabilistic causes that contribute to the same outcome may make more complex, multi-cause explanations seem more complete or informative (Zemla et al. 2023). Testing these hypotheses (and developing others) would begin to chart how virtue (or vice) labels might impact the psychology of explanation seeking and assessing (see, for example, Kleinberg and Marsh 2020 or Tešić and Hahn 2023).

5.3 Conclusion

Understanding when, how, how much, and most importantly why 'the simplest explanation' can be unduly alluring is no simple endeavor. These experiments take a first step in discerning the role that such simplicity labels might play in explanation evaluation. One formidable challenge is the great difficulty involved in discerning the explanatory value simplicity itself offers (sans any labeling phenomena). Similar to much of what's been uncovered since Lombrozo's original work, our findings -especially the seemingly fallacious allure of 'the simplest explanation' -add ample suspicion that simplicity can fail to function virtuously, and can even function viciously.
