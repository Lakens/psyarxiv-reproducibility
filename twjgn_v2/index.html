About the personal-information flags. These are pattern matches, not confirmed disclosures, and they are tuned to over-report rather than miss something. Expect false positives:

  • Column names are matched against identifying words in English and other European languages (email, telefoonnummer, geboortedatum, …). A column called phone_number flags whether or not it holds one, and an empty or already-anonymised column flags on its name alone.
  • Values are matched against the shape of an identifier. An IP address pattern also matches a version string or a dotted numeric code; a card-number pattern requires both a real issuer prefix and a checksum, but a long numeric ID can still coincide.
  • Free text is flagged when a column holds long, mostly-distinct prose — the shape open-ended answers take. Most such columns contain no names at all.

A flag means look at this column. Where the data is already de-identified (an ip column reading Anonymized, a name column the authors emptied), no action is needed.

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Full text

Abstract

In September 2026 the National Institute for Health and Care Excellence (NICE) opened consultation on the first batch of its update to the 2005 guideline for obsessive-compulsive disorder (OCD) and body dysmorphic disorder (BDD) (GID-NG10435). The draft replaces stepped care with matched care and reviews first-line treatment.

We appraised the draft and its supporting documents against six questions informed by selected AGREE II domains, analysing NICE's published effect estimates, sample sizes, sensitivity analyses and economic results descriptively; every value was checked against its source document. Comparison guidelines were identified by a documented search.

The adult OCD review included 82 randomised controlled trials and the BDD review 13 studies. The committee cited small samples and wide credible intervals when it did not recommend metacognitive therapy (52 participants) or eye movement desensitisation and reprocessing (EMDR; 59 participants). Self-administered cognitive behavioural therapy with therapist support, the second adult option, rests on 61 participants, with a wider credible interval than EMDR's, and was recommended on other documented grounds. The top-ranked adult option had a probability of 0.17 of being the most costeffective. The first-listed BDD option ranked fifth of nine in the network meta-analysis. The draft gives no drug-specific dose targets, no consolidated definition of an adequate trial and no primary severity measure for allocation or response. Treatment after non-response to an adequate trial is outside the scope of Batch 1; on the assumptions in NHS England's 2013 specification, a cascade beginning with 48 million adults in England and Wales yields approximately 48,000 people not responding to a serotonin reuptake inhibitor followed by local graduated exposure. All six selected multimodal OCD comparison guidelines address augmentation; none provides a treatment pathway for BDD.

The draft rests on a substantial evidence synthesis. The published rationale does not fully explain why small samples and imprecision precluded recommendations for some treatments but not others; several operational parameters are not specified; and further-line treatment is outside the first batch.

INTRODUCTION

The National Institute for Health and Care Excellence (NICE) published its guideline on obsessive-compulsive disorder (OCD) and body dysmorphic disorder (BDD), CG31, in November 2005 [1]. It was placed on NICE's static list in February 2014, and a surveillance review in 2019 concluded that it should be updated [2]. NICE is updating the guideline in batches. The draft scope, consulted on in May and June 2025, listed eight review questions, and the final scope, published in November 2025, retained four for the first batch [3, 4]. The draft guideline for Batch 1 was published for consultation on 17 September 2026; consultation closes on 21 October 2026, and publication is expected on 16 February 2027 [5].

Under CG31, treatment was organised as stepped care, with intensity increasing in steps defined largely by functional impairment. The draft replaces this with matched care, in which treatment is chosen at assessment according to the person's clinical needs, treatment history and preferences. Its treatment tables for adults with OCD, children and young people with OCD, and people with BDD list options in an order "based on clinical-and cost-effectiveness evidence and safety" [6, p. 31]. The evidence behind the tables comes from four evidence reviews, three network meta-analyses (NMAs) and three de novo economic models, all published with the draft [7] [8] [9] [10] [11] [12] [13].

This paper appraises the consultation draft and re-examines the quantitative results published with it. It describes (1) what the update was intended to address and what Batch 1 covers; (2) the evidence base for each population; (3) how the documented reasoning links the evidence to the recommendations, and whether the documented reasons account for the differences between treatments; (4) how the draft handles combination treatment, dosing, treatment adequacy and assessment; (5) how its positions compare with contemporary international guidance; and (6) how many people may need treatment that is outside the scope of Batch 1, on the assumptions NHS England has published.

Because the draft is open for consultation, its recommendations may change before publication.

METHODS

Documents appraised

We appraised the consultation draft [6], evidence reviews A to D [7] [8] [9] [10] and the technical appendices to evidence review B [14], economic analysis reports A to C [11] [12] [13], the draft and final scopes and NICE's responses to comments on the draft scope [3, 4, 15], health inequalities report A [16], the 2019 surveillance review [2] and CG31 [1]. All were obtained from NICE's website between 17 September and 7 October 2026. Population estimates were taken from NHS England's specification for the national service for severe OCD and BDD [17].

Appraisal framework

AGREE II assesses clinical practice guidelines across six domains: scope and purpose, stakeholder involvement, rigour of development, clarity of presentation, applicability and editorial independence [18]. This paper is not a formal AGREE II appraisal, which would require several independent raters and domain scores. Six questions were informed by the domains most relevant to the content of the draft (scope and purpose, rigour of development, clarity of presentation and applicability): the purpose and scope of the update; the evidence base; the link between evidence and recommendations; combination treatment, dosing, treatment adequacy and assessment; consistency with international guidance; and the population outside the scope. For each, we recorded what the draft and its supporting documents state, with page references, and compared the committee's documented reasons with the corresponding data.

Data extraction and secondary analyses

Posterior median standardised mean differences (SMDs) with 95% credible intervals (CrIs), participants randomised, trial arms and median ranks were taken from the NMA tables of evidence reviews A to C; log-odds ratios for discontinuation for any reason, the results of sensitivity analyses and risk-of-bias ratings from the same reviews; net health benefit (NHB), quality-adjusted life years (QALYs), costs and probabilistic rankings from economic reports B and C; and prescribing and referral proportions from health inequalities report A [16]. Every row of each NICE results table used was transcribed, not only the rows discussed. Values were extracted by one reviewer with AI assistance (see Acknowledgements) and were not double-extracted independently. Instead, every transcribed value was checked by script against the text of its source PDF (the numbers in each row, in order), every quotation from a NICE or NHS England document was matched verbatim against its source, and every DOI was checked against Crossref. The supplementary data give every value with its source table and page and the SHA-256 checksum of each source file [19].

No new meta-analysis or economic modelling was performed, and no published estimate was re-weighted, pooled or adjusted. The secondary analyses are descriptive: the width of each 95% CrI (upper minus lower limit); the change in each estimate between NICE's base case and its sensitivity analyses; NHB recalculated from the published QALYs and total costs as a check on extraction (all values agreed with the published figures to within 1 QALY per 1,000), and NHB differences expressed per person; mean participants per trial arm; the proportion of trials rated at high risk of bias by type of trial, compared with Fisher's exact test and a sensitivity analysis; and a recalculation, under alternative response rates, of NHS England's estimate of the number of adults who would not respond to a serotonin reuptake inhibitor (SRI) followed by local graduated exposure, with the specification's own rates as the reference case. NHB is total QALYs minus total costs divided by the cost-effectiveness threshold of £20,000 per QALY; the models report it per 1,000 people over 12 weeks of treatment and five years of follow-up [12, 13]. Following NICE's usage, a difference is described as credible when its 95% CrI excludes zero. Because an NMA estimate draws on direct and indirect evidence, its CrI, not the number of participants randomised to a treatment, is the measure of its precision; both are reported because the committee cited both. Where NICE's documents give different values for the same quantity, both are reported, with the value used. In the NMA tables and figures, participants are the number randomised to each treatment across its arms (NICE's N); elsewhere, N is the total number randomised in a trial or pairwise comparison. Calculations were made in the workbook's formulas and checked against an independent calculation in Python 3.14, with Fisher's exact test from SciPy 1.18.1; each analysis, and every computed value reported here, is listed with its inputs in the supplementary data.

RESULTS

Purpose and scope of the update

The 2019 surveillance review gave, among its reasons for updating the guideline, "Advances in transcranial magnetic stimulation and deep brain stimulation technology for treatment of obsessive-compulsive disorder" and the "Introduction of new pharmacological interventions and new augmentation therapies amongst treatment-resistant groups". Stakeholders expressed concern at "a lack of provision for those individuals who remain treatment resistant at the end of the existing stepped care pathway as there are currently no recommendations covering this area", and described barriers in Improving Access to Psychological Therapies (IAPT, now NHS Talking Therapies) services that included significant waiting times, delays in referral and inaccessibility for some people "due to the severity of their OCD" [2].

The draft scope listed eight review questions: three on brief assessment tools, three on first-line treatment (for children and young people with OCD, adults with OCD and people with BDD), one on further-line treatment and one on access to treatment [3]. The final scope retained the three treatment questions and the access question for Batch 1 (Figure 1). Further-line treatment after no or limited response, including switching, augmentation and non-invasive neuromodulation, was listed among areas that may be covered in future batches, as was relapse prevention, which had not been a draft-scope question; recognition and assessment were moved to a separate guideline covering common mental health conditions. NICE states that further updates will be decided once work on Batch 1 is complete [4]. In its responses to comments on the draft scope, NICE explained that all guidelines now have an 18-month maximum development timeline and that this, "combined with the volume and complexity of topics within the original scope", meant the guideline would be published in batches; it acknowledged that this was "a narrower scope than the consultation version" [15, pp. 1 and 3]. It answered 16 comments, including requests to define treatment-resistant OCD and to review augmentation, neuromodulation and ablative neurosurgery, by stating that further-line treatment or treatment-resistant OCD was no longer in the first batch (pp. 27-100). The draft sets out the limits of Batch 1 explicitly. It does not cover further-line treatment after no or limited response, including switching and augmentation strategies, or relapse prevention [6, p. 1]. Its section on treatment notes that the committee did not review evidence specifically for people whose current episode has not responded to "at least 1 adequate trial (in terms of length, quality, and intensity or dose)" of a treatment option in the section, and states that "we cannot say whether the recommendations in this section are applicable to that population" (p. 30). Where this population begins therefore depends on how an adequate trial is defined, which the draft does not consolidate (see 'Dosing and treatment adequacy'). Its update information states that it "is an update of NICE guideline CG31 (published November 2005) and will replace it" (p. 101), whereas NICE's project page states that the guidance "will partially update" CG31 [5]. The final scope provided for recommendations to be retained from CG31 and edited [4]. The draft marks no recommendation as retained, although the rationale for some new recommendations draws on CG31: the questions used to identify OCD "are based on the 2005 OCD and BDD guideline, the ICD-11 on OCD and the committee's experience" [6, p. 17]. CG31's recommendations on the management of poor response to initial treatment (1.5.4.1 to 1.5.4.8 and 1.5.4.10 for adults, and 1.5.5.1 to 1.5.5.4 for children and young people) and on intensive and inpatient treatment (CG31 section 1.6) have no counterpart in the draft [1].

Unless and until it is reviewed, guidance for this group depends on whether the final guideline retains any of CG31's recommendations on poor response (see 'Interpretation'); the international guidance compared in 'Comparison with international guidance' addresses it.

Evidence base

For adult OCD, the review identified 82 randomised controlled trials (RCTs). The base-case efficacy NMA included 63 RCTs (143 arms, 6,014 participants) after the exclusion of seven very small studies, each with at least one arm of fewer than 10 participants, because the network that included them showed high heterogeneity and evidence of inconsistency [8, pp. 63, 65, 94-96]. The review for children and young people included 28 RCTs and the BDD review 13 studies (Table 2). By participants, the BDD network is about one-tenth the size of the adult network.

Most pairwise comparisons in the adult OCD review were rated low or very low certainty, mainly because of risk of bias and imprecision, and many participants in trials of cognitive behavioural therapy (CBT) were also taking selective serotonin reuptake inhibitors (SSRIs; [8]). The NMAs assume transitivity. In the BDD network, NICE's estimates of the relative effects of active treatments were "based exclusively on indirect comparisons using waitlist as the common comparator" [9, p. 11]; a network of this shape has no closed loops, so the agreement between direct and indirect evidence cannot be checked. In BDD trials, psychological treatments show larger effects against waitlist or inactive controls than against placebo or active controls [33], as in psychotherapy trials for depression [34]. The BDD economic model had no BDD-specific utility data: according to its parameter table, it took the utility of remission from adults with OCD and derived the loss of utility without remission from data on social anxiety disorder (the report's text assigns the two values the other way round; [13, pp. 21 and 44]), and it used OCD mortality risks. The proportion of people with BDD receiving treatment came from a German study of 429 people with BDD, but other service use was estimated from data on adults with OCD [13, pp. 19-21 and 30]. The qualitative review identified secrecy and shame, the perception that treatment feels too manualised, and professional scepticism about low-intensity interventions as barriers to treatment, each rated high confidence [10].

The economic analyses report part of this uncertainty. In the adult model, the probability that the top-ranked option, individual CBT, is the most cost-effective at £20,000 per QALY was 0.17, and the 95% intervals for the mean cost-effectiveness ranks were 1 to 8 for individual CBT, 1 to 10 for cognit-ive therapy and 1 to 8 for self-administered CBT with therapist support [12, Table 19, p. 61]. A threshold analysis found the preference for individual CBT or cognitive therapy (CT) over group CBT robust, although systematic bias across the whole network could not be ruled out, whereas placing self-administered CBT with therapist support above group CBT, the second and third options in the adult table, "was sensitive to small and plausible study level changes in the evidence" [8, p. 100]. For BDD, NICE's Technical Support Unit did not undertake a threshold analysis, because "there was no clear decision rule linking the recommendations on treatments for BDD to the respective BDD NMA results" [9, p. 11].

Adults with OCD: evidence and decisions

The draft's adult table lists individual CBT or CT, self-administered CBT with therapist support, group CBT, SSRIs and clomipramine, in that order [6, p. 31]. Behavioural therapy (BT) is not listed as a separate option; the committee noted that "CBT, CT, and BT are similar in clinical practice" [8, p. 99]. Metacognitive therapy (MCT) and eye movement desensitisation and reprocessing (EMDR) receive no recommendation for or against: the draft lists options rather than recommending against the others, and the evidence review records the committee's reasons. Serotonin-noradrenaline reuptake inhibitors (SNRIs) are likewise not listed. Table 3 and Figures 2 and 3 give the NMA estimates, sample sizes and cost-effectiveness ranks. 4 and 6; NICE [12], Table 19; NICE [6], Table 1.

The committee's documented reasons were as follows.

MCT was not included because the sample size was "relatively small (n=52 participants across 2 trials) with wide credible intervals", and "therapists should receive further training in order to deliver MCT". EMDR had "only been tested on n=59 participants across 2 RCTs included in the NMA and reported wide credible intervals, which lowered the committee's confidence in the effect"; the committee discussed a possible benefit in trauma-related OCD, which the evidence did not allow it to analyse, and considered EMDR an area for future research [8, p. 101]. Self-administered CBT with therapist support was recommended because "there was a population who could benefit", including people who may not want group CBT and people with particular presentations of OCD such as scrupulosity, and after the committee considered the economic analysis (p. 99). The draft's table describes its content as mirroring therapist-administered CBT protocols, so it shares its content with the first-listed option [6, p. 32]; the evidence review does not give this as a reason. The committee also noted that the amount of support given in self-administered CBT could vary in practice and affect outcomes, and that lower levels of therapist support might be less effective [8, p. 99]. SNRIs showed no evidence of effect against pill placebo, and the committee "agreed that in practice these would also likely only be given as further line treatment". SSRIs were recommended above clomipramine because of their precise estimate and their general tolerability and acceptability (p. 102).

The comparisons between psychological therapies and medicines rest partly on indirect evidence, and trials of psychological therapy cannot blind participants to treatment. Cognitive therapy: definition and extrapolation

Evidence review B classed an intervention as CT when it did not include ERP or other behavioural components, and placed inference-based CBT in this category [8, p. 9]. The draft's shared description of CBT and CT includes ERP or behavioural experiments [6]. The evidence reviews found no direct evidence for CT in children and young people or in BDD; in these populations the committee extrapolated from CBT evidence "because of the shared theoretical basis and overlap in techniques" [6, pp. 47, 57]. The same stated reasoning was not applied to MCT or EMDR in adults, for which direct comparative trials exist.

Body dysmorphic disorder

The committee's ordering differed from the BDD NMA ranking (Table 5). Individual CBT, which ranked fifth of nine categories, was placed first on the basis of extrapolation from the OCD evidence and clinical experience; the committee noted that "there were only 47 participants contributing evidence towards this intervention" [9, p. 47]. Transdiagnostic CBT, ranked first, rested on a single trial that randomised 128 people, 64 of them to transdiagnostic CBT, in which everyone given it remitted, with no change in the control group and no dropouts; the committee judged that this "may not be a reproducible finding" (pp. 18, 47). Individual MCT (two RCTs, 68 participants randomised to MCT) ranked third in the NMA and third of five in the economic model; the committee did not include it, "as they had not recommended therapist-delivered individual MCT for OCD populations" (p. 47). In the BDD economic model, group CBT had the highest NHB, with a probability of 0.74 of being the most cost-effective option, followed by self-administered CBT with therapist support, individual MCT and individual CBT, whose NHB exceeded that of waitlist by 8 QALYs per 1,000 adults [13, Table 15, p. 53]. Combination treatment

CG31 recommended combined SSRI and CBT (including ERP) for adults with severe functional impairment [1]. The draft states: "If both psychological and pharmacological treatments are appropriate, consider these in combination" [6, p. 31]. The committee found no trial of therapist-delivered CBT combined with an SSRI as a first-line treatment and made a research recommendation for one. In the NMA, behavioural therapy combined with an SSRI rested on one arm of 14 participants, and the committee "did not feel confident in recommending it" [8, p. 103]. In the pairwise evidence statements, behavioural therapy with an SSRI compared with an SSRI alone gave an SMD of -2.09 (95% CI -3.04 to -1.15) on follow-up scores at six months and -1.34 (-2.18 to -0.51) on change from baseline, from a single RCT of 28 participants rated very low certainty.

Dosing and treatment adequacy

Recommendation 1.11.2 asks prescribers to explain that "the goal will be to achieve the maximum tolerable dose", that it can take "up to 12 weeks from reaching the maximum tolerable licensed dose" to see the full effect, and that medicine "is typically taken for at least 12 months, including after symptom remission or partial remission" [6]. The rationale adds that "higher doses are usually needed to achieve optimal responses" (p. 67). The recommendations do not give drug-specific doses; the final scope states that the guideline "will assume that prescribers will use a medicine's summary of product characteristics to inform decisions made with individual patients" [4]. The committee described 20 mg of fluoxetine, the British National Formulary starting dose, as suboptimal for OCD, and noted that most SSRI trials in the NMA used optimal doses, 60 mg or more of fluoxetine in most trials [8, p. 102]. A meta-analysis of nine fixed-dose trials (2,268 participants) found higher SSRI doses more effective than low or medium doses, with more dropouts from adverse effects [47]; a later dose-response meta-analysis of 11 studies (2,322 participants) found efficacy increasing up to about 40 mg fluoxetine-equivalent and then decreasing, with tolerability worsening at higher doses [48].

The draft uses the phrase "at least 1 adequate trial (in terms of length, quality, and intensity or dose)" to define the popu-lation it did not review (p. 30) but does not give a consolidated operational definition of an adequate trial. Its guidance on duration appears in two places. The SSRI row of the adult treatment table states that "Treatment should be continued for at least 12 weeks to evaluate response" and that "Benefits should be felt within 8 to 12 weeks" (pp. 33-34), while Recommendation 1.11.2 states that it can take "up to 12 weeks from reaching the maximum tolerable licensed dose" to see the full effects. The table gives no starting point for its 12 weeks, whereas the 12 weeks in 1.11.2 run from reaching the maximum tolerable dose; the two coincide only if that dose is reached at the start, and the draft does not say which applies when judging whether a trial has been adequate. The adult table also gives a usual course of 12 to 14 psychological treatment sessions, and the draft sets no threshold for response. An international expert consensus defines response as a reduction of at least 35% in Y-BOCS score with a Clinical Global Impression-Improvement (CGI-I) rating of "much" or "very much improved", and partial response as a reduction of at least 25% but less than 35% with a CGI-I rating of at least "minimally improved", each lasting at least one week [49]. The durations given by the comparison guidelines are in Table 6. In a retrospective chart review at a Dutch academic centre, most patients referred for specialist care had not received adequate pharmacological treatment beforehand [50].

Assessment

The draft mentions two validated instruments, the Obsessive Compulsive Inventory-Revised (OCI-R) and the Body Image Questionnaire (BIQ), and Recommendation 1.12.2 calls for "routine outcome monitoring with validated sessional outcome measures". It does not name a primary severity measure for treatment allocation or for judging response, and the Y-BOCS is not mentioned in the recommendations. Severity nonetheless informs treatment allocation: the draft defines the matched care approach as matching treatment to assessed clinical needs "such as symptom severity, degree of functional impairment" [6, p. 94], and its adult table describes self-administered CBT with therapist support as particularly suitable for OCD associated with less severe functional impairment, and both that format and group CBT as possibly unsuitable for OCD associated with severe functional impairment (pp. 32-33 and 36). The draft does not define these levels. The three draft-scope questions on brief assessment tools were moved to a separate guideline [4]. Severity benchmarks for the Y-BOCS-II, derived from 2,982 children and adults, have been published [51]. NHS England's national service includes a Y-BOCS score above 30 among its entry criteria [17].

To indicate the size of the population for whom further-line treatment is relevant, we used the illustrative cascade in NHS England's specification for the national service for severe OCD and BDD. NICE's own analysis of primary care records gives a more recent view of treatment. Among adults with a recorded diagnosis of OCD or BDD in the three years before 1 February 2025, 16% of men and 14% of women had been prescribed an antipsychotic in the preceding three months, against 52% and 53% prescribed an SSRI; 11% of each had been referred to NHS Talking Therapies [16, pp. 8 and 26-27].

DISCUSSION

Principal findings

The draft rests on a substantial synthesis: four evidence reviews, three NMAs and three economic models, with 82 RCTs for adult OCD. Its leading recommendations for adults broadly correspond to the NMA and economic rankings, although NICE's own probabilistic and threshold analyses show substantial uncertainty in the ordering. Five further findings emerge from the published data. First, the reasons documented for not recommending MCT and EMDR, small samples and wide credible intervals, also describe self-ad-ministered CBT with therapist support, which was recommended on other documented grounds. Second, the ordering of the BDD treatment table differs from both the BDD NMA ranking and the ranking in the BDD economic model. Third, the draft does not specify drug-specific dose targets, a consolidated definition of an adequate trial, a response threshold or a primary severity measure. Fourth, treatment after non-response to an adequate trial is outside the scope of Batch 1, and the draft marks none of CG31's recommendations as retained. On the assumptions of NHS England's 2013 specification, a cascade that begins with 48 million adults in England and Wales leaves approximately 48,000 people not responding to an SRI followed by local graduated exposure; if those two treatments are regarded as adequate trials, these people are one subgroup of the population outside the scope of Batch 1. Fifth, on augmentation, dose ranges, neuromodulation and neurosurgery, the positions of the draft and of NICE's HealthTech guidance differ from those of most comparison guidelines, and the NICE draft is the only guideline in this comparison set with a treatment pathway for BDD.

Interpretation

NICE committees weigh clinical effectiveness, cost-effectiveness, feasibility, equality and experience, and the reasons recorded in the evidence reviews may not capture every consideration. This appraisal compares only the documented reasons with the published data. Sample size and credible-interval width are not decision rules in NICE's methods; they are compared here because the committee gave them as reasons for not including MCT and EMDR, and the comparison shows only that these reasons do not by themselves separate the options that were included from those that were not. Where the same stated criterion applies to options that received different decisions, the difference may reflect other considerations, such as the training needed to deliver a therapy, the theoretical overlap between CBT and CT, the value of a low-intensity option, or the acceptability of a format, which the committee cited for group CBT in BDD; the documents do not set out how these were weighed. The draft notes that the higher placing of individual therapist-administered CBT and CT may increase the use of psychological therapies, which "could impact service capacity and workforce planning" [6, p. 39]; the training needed to deliver MCT was among the committee's reasons for not including it [8, p. 101].

The treatment tables are ordered lists. Where more than one option is appropriate, recommendation 1.9.4 asks clinicians to "offer the appropriate treatments in the order listed" [6, pp. 30-31]. The economic model gives the top-ranked adult option a probability of 0.17 of being the most cost-effective, and NICE's threshold analysis found the order of the second and third adult options sensitive to small changes in the evidence, although it found the preference for individual CBT or CT over group CBT robust, so the ordering carries more uncertainty than an ordered list conveys. For BDD, the committee departed from a small and poorly connected network, and NICE's Technical Support Unit judged a threshold analysis infeasible because no decision rule linked the recommendations to the NMA.

Phased development is common in guideline updates. The consequences of phasing here depend on the final guideline: the draft states that it will replace CG31, while the final scope allowed recommendations to be retained. If CG31's recommendations on poor response are not carried forward, NICE guidance will not address treatment after first-line non-response unless a later batch covers it; if they are carried forward, they will not have been reviewed since 2005.

The differences from international guidance partly reflect different remits and evidence thresholds; on augmentation, they reflect the scope of Batch 1, which excluded it. NICE assesses neuromodulation and neurosurgery through a separate HealthTech programme, and its guideline methods give weight to cost-effectiveness and to the certainty of evidence. Several comparison guidelines grade treatments on smaller or uncontrolled bodies of evidence, and some make recommendations for settings with different licensing, costs and resources.

Strengths and limitations

This appraisal uses only documents in the public domain, reports every extracted value with its source table and page, and provides the extracted data, calculations, an analysis register, checksums of the source files and the guideline screening decisions as supplementary data. It also has limitations. It is not a formal AGREE II appraisal: there was no independent rating or domain scoring. Values were extracted, and search records screened, by one reviewer with AI assistance, without independent double extraction or screening. Script-based checks against the source documents reduce, but do not remove, the risk of transcription error, and they cannot detect an error in a source document. The appraisal questions and analyses were not preregistered; to limit selective reporting, every row of each NICE results table used was transcribed, and the comparisons were chosen to test the reasons the committee documented. The secondary analyses use NICE's published summary estimates; they cannot account for correlations between estimates or re-run the NMA, and CrI width is a descriptive measure of precision rather than a test. We did not obtain the executable economic models, which NICE supplies on request, subject to a signed confid-entiality agreement. The NHB values, costs and probabilistic ranks are therefore NICE's published results: the appraisal could not test the models' assumptions, re-run their probabilistic analyses or examine other scenarios, and the recalculation of NHB checks only that the published figures are internally consistent. NHB differences expressed per person describe model output at £20,000 per QALY over the models' time horizon, not health gained by individual patients. Without the BDD model, we could not establish whether the report's text or its parameter table correctly describes the sources of the utility values (see 'Evidence base'). The economic model for children and young people (economic report A) was not analysed. The recalculation of NHS England's estimate uses illustrative response rates and, like the specification, assumes that the rates apply in sequence. The guideline search was restricted to Englishlanguage documents found through PubMed and web searches, which excluded two Dutch consensus statements and a French practical guide and may have missed other national guidance; the ISRS guideline on radiosurgical capsulotomy was not included because its full text was not available to us. One eligibility criterion, the restriction of single-intervention guidance to TMS, DBS and ablative neurosurgery, was clarified during screening rather than prespecified; it excluded one record, on transcranial direct current stimulation. HT has interests relevant to treatment after first-line non-response, which are declared below. The draft may change after consultation; this appraisal describes it as published for consultation.

CONCLUSION

NICE's consultation draft for OCD and BDD moves from stepped to matched care on the basis of a substantial evidence synthesis. The published rationale does not fully explain why small samples and imprecision precluded recommendations for some treatments but not others; NICE's own analyses show that the ranking of options is uncertain; and several operational parameters, including dose targets, a consolidated definition of an adequate trial and a primary severity measure, are not specified. Treatment after non-response to an adequate trial, which includes the neuromodulation and augmentation approaches cited in the 2019 surveillance review, is outside Batch 1, and with no CG31 recommendation marked as retained, guidance for this group in the interim is unresolved. On several questions, including augmentation, dose ranges, neuromodulation and neurosurgery, its positions differ from those of most contemporary international guidelines.
