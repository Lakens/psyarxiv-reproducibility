How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. Abstract

Phantom limb sensations persist in most amputees and offer a window into how the body is represented without sensory input from the missing limb. In this state, vision may help resolve conflicts between the perceived body and the physical world. In obstacle tolerance (OBT), the phantom remains present despite overlapping with physical matter; in obstacle shunning (OBS), it retracts or disappears. Whether these experiences extend beyond subjective perception to visual attention during action remains unclear.

We tested whether OBS and OBT are associated with distinct gaze and taskperformance patterns during obstacle avoidance. Fifteen individuals with transradial amputation (7 OBS, 8 OBT) and 29 able-bodied controls physically executed or imagined a limb repositioning movement while avoiding an obstacle. We recorded gaze using mobile eye-tracking and quantified obstacle-directed dwell time using automated obstacle segmentation and fixation detection. We analysed trial duration and attention shifts between the obstacle and the limb or environment.

Bayesian mixed-effects models showed that participants with OBT spent less time looking at the obstacle when using the affected rather than the intact limb during motor execution. They were also more likely to make three or fewer attention shifts with the affected-limb, suggesting reduced obstacle monitoring when phantom-object overlap is tolerated. Participants with OBS took longer than controls during both motor execution and motor imagery.

These findings suggest that OBS and OBT are associated with distinct action-related visuospatial strategies. Phantom-object relations appear to extend beyond subjective experience to the visual and temporal organisation of behaviour around physical objects.

• Phantom retraction near obstacles was linked to longer trial durations.

• Phantom-object tolerance was linked to reduced obstacle-directed gaze and fewer attention shifts during affected-limb movements.

• Gaze dynamics and task timing indexed phantom-object representation during action.

1.Introduction

While the body is the primary instrument with which we perceive the world around us, it also provides the reference frame through which external space is structured and action is controlled (Bermúdez, 1998; Blanke, 2012; Gallagher, 2003). Limb amputation disrupts this reference frame, yet the missing limb often remains present in phenomenological experience. Many persons with an amputation report phantom limb sensations (PLS), including postural, motor, tactile, thermal and/or painful qualities of the absent limb (Giummarra et al., 2007 (Giummarra et al., , 2010;; V. Ramachandran & Hirstein, 1998). These sensations vary markedly across individuals and over time, indicating that body representation remains plastic after the loss of the physical limb. Current accounts suggest that phantom limb experiences emerge from the interaction between persistent internal body models and the altered sensory signals available after amputation, making PLS a valuable model for studying the construction and maintenance of body representations (Makin et al., 2013; Makin & Bensmaia, 2017).

Prosthetic devices are a central component of rehabilitation after limb loss. They are primarily designed to restore or support lost motor functions and thereby improve autonomy in daily life (Horgan & MacLachlan, 2004; Murray & Fox, 2002). Beyond functional compensation, prostheses may also shape how persons with an amputation experience their changed body, including body image, perceived bodily completeness, and adaptation mechanisms to the functional and social consequences of limb loss (Gozaydinoglu et al., 2019; Horgan & MacLachlan, 2004; Murray & Fox, 2002). However, functional use of a prosthesis does not necessarily imply bodily integration, as the device may support action while still being represented as an external object rather than as part of the body.

In persons with an amputation and PLS, prosthesis embodiment may depend on how the prosthesis relates to the phantom limb. Qualitative studies indicate that phantom sensations can either facilitate or interfere with prosthesis use: some describe the phantom and prosthesis as merging, whereas others experience them as spatially or functionally incompatible (Bouffard et al., 2012; Giummarra et al., 2010). Consistent with this distinction, recent work suggests that the degree to which the phantom limb is consciously experienced as part of the bodily self (phantom self-consciousness) contributes to prosthesis embodiment only when the phantom and the prosthesis can be perceived as co-located, a phenomenon described as phantom-prosthesis tolerance (Bekrater-Bodmann, 2022). Thus, the interaction between the phantom and physical objects may be critical to understanding whether an artificial limb is incorporated into the bodily self or remains an external tool.

A particularly informative case is the interaction between the phantom limb and ordinary physical obstacles. In obstacle tolerance (OBT), the phantom remains present even when its perceived position overlaps with a solid object, for example, when the residual limb is placed against a wall, and the phantom is felt as extending into or through it (Jalavisto, 1950; Saetta et al., 2018). In obstacle shunning (OBS), by contrast, the phantom retracts, fades, or disappears when such overlap would occur. The phantom therefore appears to respect the physical constraint that two solid objects cannot occupy the same space, often referred to as the law of impenetrability (E. D. Chen, 2020; Saetta et al., 2018). These phenomena show that a limb with no physical mass can nevertheless be constrained by physical matter at the level of bodily experience. As such, OBS and OBT provide a useful model for investigating how bodily representations interact with external space when direct sensory input from the limb is no longer available.

OBT and OBS have mostly been studied through self-report and apparent-motion paradigms (Jalavisto, 1950a; Saetta et al., 2018). In these paradigms, perceived bodypart trajectories are shaped by prior knowledge about the body and the physical constraints imposed by objects, including the law of impenetrability (Shiffrar & Freyd, 1990; Stevens et al., 2000). OBS and OBT are associated with distinct perceptual biases when a limb appears to move through or around an obstacle, suggesting that phantomobject relations influence visuomotor representations. Whether these differences are also expressed during goal-directed interaction with real objects remains unclear. Addressing this question would help determine whether the previously reported perceptual differences extend to action and visual monitoring of obstacles. In doing so, it would clarify the relationship between phantom limb experience and body representations used during action after amputation.

Visual attention provides a direct behavioural window into this question. During natural action, gaze is directed toward information that supports movement planning, online control, and obstacle avoidance (Hayhoe & Ballard, 2005; Johansson et al., 2001; Ross et al., 2015). Gaze toward an obstacle can therefore indicate how behaviourally relevant that obstacle is for the acting body. This is especially relevant in persons with an amputation because visual information can strongly influence phantom limb perception.

Mirror visual feedback, a therapeutic approach that uses the reflection of the intact limb to create the visual illusion of the missing limb, and related visual manipulations can alter phantom posture, movement, and pain, showing that visual signals remain shaping body representation even in the absence of afferent input from the missing limb (Hunter, 2003; V. S. Ramachandran & Rogers-Ramachandran, 1996).

In the present study, we investigated whether the distinction between OBS and OBT is reflected in visual attention during obstacle avoidance. Participants completed a limb repositioning task in which they physically executed or imagined movements from one side of a real obstacle to the other. This allowed us to test whether phantom-object relations previously identified in perceptual paradigms are also expressed during goaldirected interaction with physical objects.

We focused on obstacle-directed gaze as an implicit marker of the obstacle's behavioural relevance for the perceived body. We further examined trial duration and visual attention shifts between the obstacle and the limb or surrounding environment, because these measures provide complementary information about task-related demands and the dynamic allocation of attention during obstacle avoidance. We hypothesised that, if OBS reflects a conflict between the perceived phantom limb and physical object boundaries, individuals with OBS should allocate more visual attention to the obstacle when the affected limb is involved. They should also show longer trial durations if dealing with this conflict increases cognitive or sensorimotor demands. In contrast, if OBT reflects tolerance of phantom-object overlap, obstacle-directed gaze should be reduced or less strongly modulated by the affected limb due to the absence of a conflict between the perceived phantom limb and physical object boundaries.

2.3 Gaze behavior analysis

To interpret when the gaze of the participants was over the obstacle when performing the repositioning task, two neural network models for object detection in images were used: one for the able-bodied participants and another for the participants with an amputation. This was done to increase the precision of the Region of Interest (ROI) segmentation, as data from able-bodied participants were collected in a laboratory environment, while data from participants with an amputation were collected in a clinical environment with differences in background, colour, and illumination. The segmentation was performed in both cases with a Faster R-CNN model (Ren et al., 2016), which was retrained in Python 3.8 (Python 3.8.0, 2019) and PyTorch (PyTorch, 2024) with 870 manually segmented video frames from all the able-bodied participants for their segmentation model, and 450 manually segmented frames from all the clinical population videos for the other model. Each model outputted the X and Y positions of the top-left and bottom-right corners of the square ROI segmenting the obstacle (four values in total). Since the sampling rate of the world camera (25 fps) was four times slower than the sampling rate for the eye camera (100 Hz), the position of the ROI was linearly interpolated between frames for a more accurate estimation of the position of the region of interest with respect to the participants' gaze. An example of the outcomes for both models is shown in Figure 1. For the analysis of gaze behaviour, gaze positions were analysed with a Python implementation of the IMC2 dispersion algorithm (Hessels et al., 2017). Since Dwell times have been related to increases in cognitive and affective processing load (Aleya et al., 2022; Paletta et al., 2014; Walter & Bex, 2021), the Dwell-time Ratio inside the ROI and Trial Duration metrics were extracted for each trial, as well as the number of Attentional Shifts crossing the ROI limits. Dwell-time Ratio and Trial Duration were chosen instead of raw Dwell time to disentangle whether the influence on gaze behaviour was due to the diversion of visual attention towards the obstacle or to the time taken to perform the task, rather than to their combination.

2.4 Statistical analysis

The dataset from MDSInfo and gaze behaviour from MDS4-Exercise 4 were analysed using R 4.4.2 (R: The R Project for Statistical Computing, 2024) with implementations from the BRMS (Bürkner, 2017 (Bürkner, , 2018 (Bürkner, , 2021) ) and EMMEANS (Lenth et al., 2024) packages. Differences among experimental Conditions were assessed using posterior contrasts of estimated marginal means from Bayesian mixed-effects models. Marginal means were computed at the population level by excluding random effects derived from predictions for the Dwell-time Ratio and Trial Duration models, yielding populationaverage estimates rather than subject-specific predictions. For nonlinear hurdle models for the Attention Shifts, marginal means were computed by integrating over participantlevel random effects to obtain population-averaged estimates. Pairwise contrasts were evaluated on the latent scale, and the strength of evidence was quantified using 95% highest-density intervals and the probability of direction. Estimated marginal means were back-transformed to the original scale for interpretation and graphical reporting.

For the analysis of Attention Shifts, the number of saccades crossing the ROI boundary was modelled using a Bayesian hurdle Gaussian mixed-effects model. Because the empirical distribution showed a substantial point mass at zero and a continuous positive tail, a two-part hurdle formulation was adopted, in which the probability of producing zero saccades or attentional shifts and the distribution of non-zero values are estimated separately (e.g., following the approach in (Moffat & Cross, 2024)). To stabilise model fitting and maximise the understanding of the distribution of both value clusters, saccade counts were pre-processed by applying a threshold of 3 saccades, as this value was where the number of Attention Shifts presented the lowest density between both clusters across all the values acquired in the combined data pool of Motor Execution and Motor Imagery tasks. According to this threshold, values ≤ 3 were recorded as zero, whereas values > 3 retained their observed magnitude.

The model decomposed the response into two components: a Bernoulli process estimating the probability of a zero outcome (hurdle probability, hu parameter), and a Gaussian distribution for strictly positive saccade counts. The linear predictor for both components included Condition as a fixed effect, where Condition reflects the combination of population group (Control, OBS, or OBT) and limb used (Intact or Affected). Participant identity (ID) was included as a random intercept term (1|ID) to account for repeated observations within individuals. Four Markov chains were run for 6,000 iterations each (1,500 warm-up), with adapt_delta = 0.99 and max_treedepth = 15 to ensure robust sampling. Convergence was assessed using R-hat statistics, bulk and tail effective sample sizes, and visual inspection of chain mixing. Posterior means and 95% highest-density intervals (HDIs) were used for inference. The same model structure and priors were applied to both Motor Execution and Motor Imagery conditions.

For the study of relationships between demographic data, PLS assessment metrics, and prosthetic use habits, a Bayesian Linear Mixed Model was used for each metric of interest: the proportion of Dwell time inside the ROI, Trial Duration, and Saccades across the ROI boundary. Similar formulas were used for the models stated above for each metric, with the substitution of the Condition factor by the formula Population * Metric of interest. Where the Population would be OBT or OBS, and the Metric of Interest would be the predictor of interest from the demographic, PLS assessment, or prosthetic use data. Additionally, these models were only fitted with data concerning the affected limb.

Regarding the number of Attention Shifts performed by the participants (given more than three), there was strong evidence for fewer Attention Shifts with increasing years since amputation (pd = 0.99, Estimate = -0.54, 95% HDI [-0.91, -0.14]). 4. Discussion

The present study examined the extent to which obstacle shunning (OBS) and obstacle tolerance (OBT), two distinct ways in which a phantom limb relates to physical matter, are reflected in visual attention and task performance near a real obstacle. The clearest pattern emerged during motor execution. Participants with OBT spent a smaller proportion of the trial looking at the obstacle with the affected than with the intact limb and were more likely to complete affected-limb trials with three or fewer attention shifts. Participants with OBS, in contrast, took longer than controls to complete the task, with this delay being also present during motor imagery. Thus, the gaze effect was expressed mainly as reduced obstacle monitoring in OBT rather than as a direct increase in OBS. Together, the findings indicate that phantom-object relations extend beyond subjective reports and illusory perception to the visual and temporal organisation of goal-directed behaviour. These findings contribute to the understanding of body representation after amputation, highlighting the relevance of both phantom limb experience and its relationship with physical objects during action, as reflected in visual attention and task performance.

The two gaze measures in OBT converge on a pattern of reduced obstacle monitoring during affected-limb movements. This distinction concerned both the proportion of time spent looking at the obstacle and the probability that a trial remained within the lowshift range, as when more than three attention shifts occurred, there was no clear evidence that their number differed across conditions. During natural action, gaze is closely coupled to the information needed for movement planning and online control (Hayhoe & Ballard, 2005; Johansson et al., 2001), and fixation location can influence the trajectory selected during obstacle avoidance (Ross et al., 2015). This coupling remains remarkably preserved after amputation. Gregori et al. (2019) found that persons with a transradial amputation directed their gaze to the target object more than 500 ms before the intended grasp, with a visuomotor pattern like that of able-bodied participants despite the absence of the physical hand. Against this background, the OBT findings suggest that the obstacle carries less information that needs to be repeatedly sampled when phantom-object overlap is tolerated. This does not imply a weaker phantom representation. Rather, the phantom-object relation may be sufficiently stable that the obstacle boundary creates less uncertainty about the phantom's position or continuity. A shorter residual limb may also reduce physical collision risk and contribute to this pattern.

The longer trial durations in OBS point to a complementary aspect of the same bodyobject relation. OBS participants were slower than controls with both the intact and affected limbs, while both groups with an amputation were slower with the affected than with the intact limb during motor execution. Longer movement times are generally associated with greater sensorimotor or attentional demands (Mahboobin et al., 2007). In OBS, however, a nearby object has an additional consequence, as overlap can cause the phantom to retract, fade, or disappear. Acting near an obstacle may therefore require the intended movement to be reconciled with a body representation whose spatial continuity can change in the presence of physical matter. The fact that slowing in OBS was also evident for the intact limb suggests that this may become a broader action strategy rather than a response confined to the phantom side. Trial duration cannot identify the underlying mechanism on its own, but together with the gaze findings, it points to different ways of managing body-object constraints in OBS and OBT.

The conceptual importance of these findings becomes clearer when they are considered alongside previous apparent-motion work. In apparent-motion paradigms, two images of a limb presented on opposite sides of an obstacle create the impression that the limb has moved between them. At short stimulus intervals, observers tend to perceive the shorter path of the limb moving through the obstacle; with more time, prior knowledge about the body and solid objects increasingly favours a physically plausible path around it (Shiffrar & Freyd, 1990; Stevens et al., 2000). Saetta et al. (2018) reproduced this general effect in participants with an amputation and controls but also found opposite biases within the group with an amputation. OBS was associated with more throughobject percepts, whereas OBT was associated with more around-object percepts. At first sight, the OBT result may seem paradoxical because these participants consciously tolerate phantom-object overlap. The proposed explanation was that, precisely because the phantom remains spatially present when an object occupies the same location, its represented volume continues to behave as body-related space and solidity constraints remain relevant. In OBS, by contrast, overlap can be resolved by retraction or disappearance of the phantom, reducing the perceptual conflict created by a throughobject trajectory. The present task preserved the same basic spatial configuration but moved from an ambiguous visual illusion to action around a real obstacle. The findings are therefore complementary rather than contradictory, since apparent motion concerns which path is perceived, whereas gaze reflects how much visual monitoring is required while an action is organised. A stable phantom representation, as in OBT, may strongly constrain perceived trajectories while requiring less repeated checking of an obstacle that does not disrupt phantom continuity.

One possible mechanism linking these findings is that OBS and OBT differ in how visual information is weighted relative to the persistent representation of the missing limb. Phantom awareness is not insulated from external sensory input. Hunter (2003) showed that normal vision could suppress the phantom component of touch-evoked dual percepts, whereas a mirror illusion transiently enhanced spontaneous phantom awareness in several participants with an amputation. Mirror visual feedback can also evoke sensations of phantom movement (V. S. Ramachandran & Rogers-Ramachandran, 1996). Neuroprosthetic studies extend the same principle, indicating that kinesthetic feedback can be integrated within minutes to improve prosthetic movement control and increase agency (Marasco et al., 2018), while temporally congruent visual and neural tactile feedback can increase prosthesis embodiment and reduce distorted phantom shortening (Rognini et al., 2019). Together, these findings show that post-amputation body representation remains responsive to congruent visual and multisensory information. In OBS, an object boundary may therefore require more processing because it can alter the experienced phantom, while in OBT the same boundary may require less repeated verification because overlap leaves the phantom intact. The present data do not show that gaze itself changes phantom perception, but they are consistent with differences in the behavioural relevance assigned to visual information about physical boundaries.

Motor imagery did not reproduce the motor-execution pattern.

There was no strong evidence of differences in obstacle dwell-time ratio during imagery, and the probability of making three or fewer attention shifts depended on both group and the limb being imagined. This divergence is consistent with previous evidence that phantom motor execution and motor imagery are distinct processes rather than interchangeable forms of the same representation. Raffin et al. (2012) showed that persons with an amputation could both execute and imagine phantom movements, with execution accompanied by stump muscle activity and slower phantom than intact-limb movements, whereas imagined movements showed comparable timing for the two sides. The two conditions also recruited partially overlapping but dissociable neural networks, with execution engaging sensorimotor regions more strongly and imagery relying relatively more on parietal and occipital regions. In the present task, executed movement required online control of an evolving body-object relation, whereas imagery required the trajectory to be internally simulated without an actual collision. Phantom-object relations may therefore influence visual attention differently depending on whether an action is being physically controlled or mentally simulated.

The exploratory analyses suggest that obstacle monitoring may also relate to the history and motor qualities of the phantom. Longer time since amputation was associated with a greater probability of trials with three or fewer attention shifts and, among trials above this threshold, with fewer shifts overall. Earlier observations suggested that obstacle shunning experiences become less frequent with increasing age and time since amputation, although (Jalavisto, 1950) examined much shorter and more coarsely defined post-amputation intervals (after amputation and six months after, instead of years as in our sample).

Additionally, more frequent sensations of being able to move the phantom intentionally were associated with a higher probability of making more attention shifts. Greater intensity of these sensations showed the same association in OBT participants. Voluntary phantom movements have been associated with a smaller discrepancy between the phantom and the prosthesis and greater prosthesis embodiment (Giummarra et al., 2010), potentially favouring behaviours associated with intact limbs. Stronger sensations of the phantom moving conjointly with the intact limb were associated with a greater probability of making fewer attention shifts in OBT participants. This pattern may relate to shared neural pathways involved in phantom and intact-limb motor execution, including the primary motor cortex (M1), primary somatosensory cortex (S1), and cerebellum (Anderson & Lenz, 2011; Raffin et al., 2012). These regions and sensorimotor internal models contribute to motor planning, particularly during complex coordinated movements (H. Chen et al., 2006; Crammond, 1997; Wolpert & Ghahramani, 2000). If conjoint phantom-intact limb movements depend on shared sensorimotor models, participants reporting stronger conjoint movements may represent the phantom more similarly to the intact limb. These findings are compatible with the broader view that phantom limbs retain dynamic postural and motor properties and can remain incorporated into ongoing sensorimotor representations (Giummarra et al., 2010; Raffin et al., 2012). They raise the possibility that visual monitoring changes with the stability or controllability of the phantom, but the present cross-sectional data cannot establish adaptation over time. This possibility could be tested by measuring phantom position and perceived movement control alongside gaze across repeated sessions. This would allow examination of whether changes in phantom controllability and stability are accompanied by changes in visual attention during obstacle monitoring.

Prosthesis use provides a further connection between the present findings and experience-dependent body representation. Greater daily use of body-powered and myoelectric prostheses was associated with shorter trial durations, while associations between prosthesis use and attention shifts differed across device types and did not form a single consistent pattern. The device-specific effects should therefore remain exploratory. The broader literature nevertheless shows that prosthetic experience can reshape both the represented body and the space surrounding it. Canzoneri et al. (2013) found that, without a prosthesis, perceived arm length and peripersonal-space boundaries shifted towards the stump; wearing the prosthesis increased perceived limb extent and expanded peripersonal space to include the prosthetic hand. Bekrater-Bodmann (2022) further showed that perceived phantom-prosthesis co-location mediated the relationship between phantom self-consciousness and prosthesis embodiment. These results converge on a common principle: embodiment depends not only on the vividness of a phantom, but also on whether the phantom can be spatially reconciled with physical objects and artificial limbs. OBS and OBT may capture one aspect of this spatial compatibility. The present gaze effects could therefore provide a behavioural index of how the perceived body is organised relative to nearby physical matter, although neither peripersonal space nor prosthesis embodiment was measured directly here.

Limitations

Several limitations should also be considered when interpreting these results. The sample included 15 participants with an amputation, divided into seven OBS and eight OBT participants, and the prosthesis subgroups were smaller still, with gender-related findings being particularly difficult to interpret because only two participants with amputation were women. Some attention-shift estimates had very wide credible intervals, and the threshold of three shifts was derived from the observed distribution. OBS and OBT were treated categorically, although phantom-object and phantomprosthesis relations may be better represented dimensionally (Bekrater-Bodmann, 2022). Gaze and trial duration are indirect measures and cannot determine whether a fixation reflects anticipatory planning, online control, conflict monitoring, or postmovement checking. The study also lacked an obstacle-free comparison, so longer trial durations cannot be attributed specifically to phantom-object conflict. Residual-limb geometry may contribute to collision risk, and control and participants with amputation recordings were obtained in different environments, requiring separate obstaclesegmentation models. Finally, motor execution and imagery were analysed separately rather than within a direct task comparison.

Future studies could combine mobile eye tracking with movement kinematics, electromyography, and trial-by-trial measures of phantom position to examine how obstacle monitoring relates to movement execution and the experienced spatial configuration of the phantom. Testing apparent-motion perception and real obstacle avoidance in the same participants would be particularly informative because it would determine whether illusion-based OBS/OBT biases predict the visual strategies used around real objects. Standardised recording conditions and dimensional measures of phantom-object compatibility would improve precision, while longitudinal studies incorporating validated measures of prosthesis embodiment could establish whether phantom-object relations, gaze behaviour, and prosthesis integration change together over time.

5. Conclusion

Taken together, the main findings extend OBS and OBT from phenomenology and visual illusion to action-related visuospatial processing. In OBT, affected-limb movements were accompanied by less obstacle-directed gaze and a greater probability of fewer attention shifts, consistent with reduced need to monitor a boundary that does not disrupt phantom continuity. In OBS, longer task durations are consistent with greater demands when action occurs near a boundary that can alter the experienced phantom. The distinction is not expressed as a simple opposition across every measure or task. Instead, phantom-object phenomenology appears to interact with the specific demands of visual monitoring, movement control, and motor simulation. This provides a more behaviourally-grounded account of how a physically absent limb can continue to structure interactions with the external world.
