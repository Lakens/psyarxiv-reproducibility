How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. This package was validated by the Metacheck team on articles in Psychological Science.

How Preregistration Check works

Retrieve information from preregistrations in a standardised way, and make them easier to check.

The Preregistration Check module identifies preregistrations on the OSF and AsPredicted based on links in the manuscript, retrieves the preregistration text, and organizes the information into a template. The module retrieves text from the OSF with its API, and from AsPredicted with ResearchBox’s API when a ResearchBox key is set (see rbox_token()), or else from the preregistration’s web page. The information in the preregistration is returned. An AsPredicted link that could not be read is named in the report, with the reason.

The module can’t extract information from non-structured preregistration templates (i.e., where the preregistration is uploaded in a single text field) and it can’t retrieve information in preregistrations that are stored as text documents on the OSF.

If you want to extend the package to be able to download information from other preregistration sites, reach out to the Metacheck development team.

How StatCheck works

Check consistency of p-values and test statistics

The Statcheck module runs Statcheck. Statcheck searches for regular expressions that match a predefined pattern, and identifies APA reported statistical tests. More information on the package can be found at https://github.com/cran/statcheck. The module only returns Statcheck results for t-tests and F-tests, as these are the only tests which have been validated, see https://osf.io/preprints/psyarxiv/tcxaj_v1/.

Statcheck was developed by Michèle Nuijten and Sascha Epskamp.

Statcheck considers p = 0.000 an error, as you should report p < 0.001. Furthermore, p < 0.03 is an error if the p-value was 0.031, and one should simply report exact p-values (p = 0.031). Statcheck might miss one-sided tests, and falsely assume the p-value is incorrect. For more information, see StatCheck.

This module only checks statistical results reported in the running text of the manuscript. It cannot (yet) process statistics reported only in tables.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Full text

Abstract

Background: Rates of mental health problems in adolescents have increased in the last decade, prompting urgent calls for effective, scalable preventative interventions. To determine whether a novel, group-based, transdiagnostic indicated prevention programme (Building Resilience through Socioemotional Training; ReSET), delivered through existing school mental health provision, improves mental health and wellbeing in at-risk adolescents. Methods: Two-arm cluster randomised controlled superiority trial (1:1) evaluating ReSET plus usual care versus usual care only, with outcomes assessed immediately post-intervention and at 12-month follow-up. Adolescents aged 12-14 identified through whole-school screening as scoring in the top 25th percentile for overall psychopathology symptoms, in schools selected to over-represent high-need communities (≥30% free school meals eligibility). ReSET is an 8session group -based intervention that targets two key mechanisms implicated in risk for psychopathology in adolescents -the quality and quantity of social relationships and emotional processing. Pre-registered co-primary outcomes were overall self-reported psychopathology (SDQ) and wellbeing (WEMWBS), assessed immediately post-intervention and at 12-month follow-up.

Results: Of 4,005 adolescents screened, 1465 met eligibility, 727 consented and 560 were enrolled. There was no evidence of intervention effects on either co-primary outcome immediately post-intervention. At 12-month follow-up, there was evidence of improvement in overall psychopathology (adjusted mean difference -1.36, 97.5% CI -2.23 to -0.50, p=0.0004; SMD=0.25, 95% CI 0.11 to 0.42). Secondary outcomes showed a consistent pattern: no effects immediately post-intervention, but significant benefits for anxiety, depression, general psychopathology, and internalising symptoms at 12-month follow-up. No effects on externalising symptoms were observed at either timepoint.

The delayed emergence of benefit is consistent with a skills-based prevention model in which adolescents acquire skills that support resilient functioning when facing subsequent emotional and interpersonal challenges. These findings suggest that transdiagnostic interventions targeting socioemotional processes have the potential to prevent common adolescent mental health problems, though replication and longer-term evaluation are needed.

Introduction

In light of the rising rates of mental ill-health among adolescents, there have been urgent calls to increase the availability of scalable interventions that prevent the onset or worsening of mental health problems in this age group (McGorry et al., 2024). However, evidence suggests that universal prevention programmes have limited impact and in some cases may even lead to harm (Andrews et al., 2023). Indicated prevention appears to be a more feasible approach (Andrews & Foulkes, 2025). Further, most existing indicated prevention programmes target specific conditions (most commonly depression), limiting their utility for addressing the broader mental health needs of adolescent populations. Longitudinal studies show that adolescents may experience multiple overlapping mental health difficulties and may transition between diagnoses over time, making disorder-specific targeting potentially challenging (Dalgleish et al., 2020).

A transdiagnostic approach provides a logical strategy to address this challenge by targeting common mechanisms that operate across disorders, or, alternatively, by providing flexible therapies that address multiple problem areas (Astle et al., 2024; Dalgleish et al., 2020; McGorry et al., 2018). In a recent systematic review, Du Toit et al. (2025) identified only one full-scale trial of a transdiagnostic indicated prevention programme for adolescents. Jeppesen et al. (2021) tested the efficacy of a modular CBT programme for help-seeking adolescents aged 6-16 years scoring over the 90 th percentile for mental health problems. The modular programme allowed therapists to select different treatment elements to match a young person's profile of presenting symptoms across different diagnostic domains. Delivered by trained psychologists over 9-13 one-to-one sessions, the trial showed robust benefits for overall symptomatology at 3 and 6-month follow-ups. This modular approach to transdiagnostic intervention, though promising, has some limitations, particularly the requirement that clear symptom profiles are already present, treatment sessions have to be one-to-one and skilled clinicians are required for delivery. Given the level of need in the population, evaluating alternative approaches remains a priority, particularly those that can be brought to scale.

Here we report results from the ReSET trial, the first large-scale, adequately powered RCT of an indicated prevention programme targeting transdiagnostic mechanisms in youth psychopathology. We adopted a whole-school screening approach to identify at-risk adolescents and bypass the help-seeking and referral barriers that typically prevent young people from accessing support, targeting those scoring in the top 25% of overall mental health symptoms. This novel, group-based, intervention, Building Resilience through Socioemotional Training (ReSET) teaches skills targeting two mechanisms of change: communication skills and emotion processing abilities (Mitic et al., 2021). The intervention exploits the dynamic relationship between young people's social interactions and their emotional functioning. By equipping young people with the skills to manage their emotions and relationships more effectively, ReSET aims to disrupt the negative reciprocal cycles of emotional dysregulation and social difficulties that can drive the transition from sub-threshold symptoms to clinical disorder. The intervention was designed to be delivered in schools using their existing mental health provision, to shorten the pathway from efficacy trial to implementation.

To address the targeted transdiagnostic mechanisms, ReSET integrated techniques from two distinct disciplinary backgrounds, clinical psychology/psychiatry and cognitive neuroscience (Lloyd, Law, et al., 2024; Viding et al., 2024). To strengthen skills related to adolescents' communication abilities, ReSET adapted techniques used in Interpersonal Psychotherapy-Adolescent Skills Training (IPT-AST; Young et al., 2012). These adapted techniques were designed to support young people's relationships by teaching them social and communication skills that foster positive interactions and practising these skills through roleplay exercises. When developing ReSET, specific content was also included to explain the important connection between relationships and emotions. This content was designed to link the relationship focused work with the emotion processing skills trained via established computerised cognitive-emotional training tasks (Penton-Voak et al., 2013; Zsigo et al., 2024).

The first of these encouraged young people to practice positive emotion regulation strategies (namely, distancing and reinterpretation) in response to fictional examples. The second, the Interpretation Bias Training Task, modified young people's perceptions to view neutral/ambiguous faces as friendly rather than hostile. ReSET thus focused on highlighting the reciprocal relation between social interactions and emotions (Lloyd, Law, et al., 2024) and their joint contribution to emotional health and wellbeing. To ensure the novel intervention was acceptable to young people, ReSET underwent an extensive, co-produced development process, including pilot and feasibility testing (Lloyd et al., 2025; Lloyd, Law, et al., 2024; Lloyd, Wu, et al., 2024).

The intervention was delivered to adolescents aged 12-14 years, as this age range immediately precedes the peak period of accelerating risk for common mental health problems among adolescents (Solmi et al., 2022). The trial also included an integrated process evaluation, exploring the experience of the young people who took part in the ReSET intervention (Lucas et al., 2026). Because ReSET is a skills-based prevention programme, benefits were expected to consolidate as adolescents encounter subsequent emotional and interpersonal challenges; primary outcomes were therefore also assessed at 12-month follow-up. The primary hypothesis was that among adolescents with increased risk of mental health, those who received the ReSET programme will have better mental health and well-being outcomes than those in the non-intervention arm. The trial was registered on the ISRCTN registry on 20/04/2024 (ISRCTN88585916; see https://www.isrctn.com/ISRCTN88585916).

Methods

Study Design and Participants

We conducted a parallel, cluster randomised controlled, multicentre superiority trial of the ReSET programme versus pupils' school provision as usual. Outcome assessors were masked to allocation. Owing to the nature of the intervention, participants and intervention providers could not be masked. The trial took place in mainstream secondary schools in the Southeast of England, with a total of 11 participating schools across 12 study sites. Pupil screening and informed consent were obtained via physical forms or the REDcap platform. Parents and carers were provided with opt-out forms for the screening questionnaire. Active consent was required from parents/carers and adolescents participating in the intervention and control arms of the trial. Outcome measures were collected via the PsyTools platform. The study received ethical approval from UCL's research ethics committee (ref: 21815/001). For the study protocol, see (Viding et al., 2024).

Participants were 12-14 year-old pupils (School years 7-9) from 11 state-maintained secondary schools in London and the South East of England. Participants were eligible if they had a Total Difficulties score of 15 or above on SDQ (Goodman et al., 1998). This threshold was selected as it represented the top 25% of scores for adolescents of this age group, based on a nationally representative sample in the UK (University of Essex, 2022). Pupils could be excluded from the trial if school staff identified them as having high rates of school absence or if they were not considered suitable for a group-based intervention, though this rarely occurred.

There were no other exclusion criteria and diagnoses of neurodivergence were recorded. To encourage socioeconomic diversity in the sample, at least 30% of pupils at participating schools had to qualify for free school meals.

Choice of primary endpoint

The primary endpoint for this trial was the assessment conducted immediately postintervention. This decision reflected a cautious and pragmatic design choice, balancing statistical power and feasibility against the uncertainty inherent in longer-term follow-up in school-based trials, including potential attrition and school transitions. Further, previous indicated prevention trials of closely related interventions, particularly IPT-AST, have reported detectable short-term improvements in mental health outcomes, making it reasonable to anticipate measurable post-intervention effects.

At the same time, the intervention was explicitly designed as a preventative, skillsbased programme, with the expectation that any benefits might consolidate over time as adolescents encountered new social and emotional challenges and enter a period of increased risk. For this reason, outcomes were also assessed at 12 months from baseline as a key followup timepoint for evaluating potential preventative effects.

Randomisation and masking

Randomisation was at the school year-group level with 1:1 randomisation. Within schools, one year group was allocated to the intervention arm and the other to the control arm.

Randomisation was balanced across schools using block randomisation, implemented by an independent statistician (see Viding et al., 2024). Only the independent statistician and project coordinator were aware of the randomisation schedule. Neither the trial statistician nor assessors were aware of the randomisation schedule.

Participants completed assessments independently on a tablet device to minimise the impact of the researcher presence on the outcome data collection. Where researchers were unblinded to the allocation, this was recorded along with the timepoint at which they were unblinded.

Procedures

Participants were screened for eligibility in the school term preceding their enrolment into the trial. Assessments of primary and secondary outcomes took place at the beginning of each school term (baseline), which were followed by the 8-week intervention for those in the intervention arm. The primary endpoint assessment typically occurred at the end of that same term. Follow-up data were collected for all primary and secondary outcomes 12 months after baseline. The trial ran across several school terms, with 10 participants allocated to the intervention arm and 10 allocated to the control arm in any one school term.

The ReSET intervention

ReSET is an 8-week group-based programme. Beginning with a 1:1 meeting, participants then completed eight, 90-minute group-based sessions comprised of up to 10 adolescents, which involved a combination of discussion activities, role-plays, and app-based cognitive-emotional training. Mid-way through the programme (weeks four or five), another 1:1 meeting is held to identify barriers to participation, monitor progress, and review key strategies. Parents and/or carers are also invited to attend this mid-group meeting. For further description of the intervention, see Supplementary Materials and Lloyd et al. (2025).

Facilitators delivering the intervention were pairs of trained mental health practitioners, including school staff trained in mental health support, Mental Health Support Teams from the charity sector or NHS, and members of the research team. All facilitators completed two days of training prior to delivering the intervention. The training was provided by a consultant clinical psychologist with extensive experience of IPT-AST and research team members with expertise of the cognitive-emotional training protocols. During delivery of the intervention, facilitators had weekly supervision meetings with the consultant clinical psychologist who was the project clinical lead. Fidelity checks were also completed by a member of the research team, who was not involved in delivering the intervention, in weeks one, two and five. If areas of the intervention were not being delivered as intended, feedback and support was provided through weekly supervision meetings

Outcomes

The co-primary outcomes for this trial were overall psychopathology, measured using the total difficulties score on the SDQ (Goodman et al., 2000), and overall wellbeing (WEMWBS; Tennant et al., 2007).

The secondary outcomes comprised a series of measures pre-specified in the trial protocol. Mental health secondary outcomes, closely aligned with the intervention's theoretical targets, assessed depression (Patient Health Questionnaire-8; PHQ-8; Kroenke et al., 2009)), and generalised anxiety (Generalised Anxiety Disorder Assessment-7; GAD-7; Spitzer et al., 2006). We also included secondary outcome measures of latent factor scores of general psychopathology, internalising problems, and externalising problems (latent factors created using a bifactor confirmatory factor analysis using items from the SDQ and the Me & My Feelings Questionnaire (MMFQ; Patalay et al., 2014).

Additional secondary outcomes included substance misuse, insomnia, and social network characteristics. Peer social networks were measured through peer nominations collected from the entire year group of participating cohorts and included indegree for likeability and best friend, as well as outdegree for advice-seeking (see supplementary material for more information on all outcomes).

Any adverse events reported in the intervention and control arms were recorded.

Adverse events were defined as incidents that required referral to a Child and Young Person Mental Health Support Team, Child and Adolescent Mental Health Service (CAMHS), GP, or emergency services.

Statistical Analysis

The statistical methods for all analyses reported here, including analyses of the primary endpoint and the 12-months follow-up data, were specified in a pre-registered statistical analysis plan (SAP, ISRCTN registry reference: ISRCTN88585916). The target sample size for this trial was 540 participants, based on a power analysis giving 92.8% power to detect a moderate effect of the intervention (δ = 0.4) in one outcome (Viding et al., 2024), setting the significance level at 2.5% to correct for multiple testing of two primary outcomes (Viding et al., 2024). The power calculation allowed for 20% estimated attrition.

The participants are clustered in schools and year groups. Participants in the intervention arm are additionally clustered in ReSET groups in the intervention arm, but there is no such additional clustering in the control arm. The prespecified primary outcome analysis was therefore a partially clustered linear mixed effects model with normally distributed heteroscedastic errors (Candlish et al., 2018). This model includes a random effect for intervention groups, to account for partial clustering. It also controls for clustering within schools via a random effect and for the school year (or cohort), the timing of the measurement (i.e. school term), and baseline outcome measure score via fixed effects. These complex models turned out to be difficult to fit and failed to converge for most outcomes. Where this was the case, we followed the procedure prespecified for this eventuality in the SAP, and fitted the most complex model possible. For the two primary outcomes, this was a mixed effects linear regression with a random intercept for school, but not for ReSET groups. The trial data structure and statistical handling are summarized in Supplementary Table S12.1.

The analysis for secondary outcomes used the same model as for primary outcomes where the outcome was a psychometric scale (GAD-7, PHQ-8) or a factor score (general psychopathology, internalizing difficulties, externalizing difficulties). Where the outcome was a count variable (network variables), an analogous mixed effects Poisson model was used to estimate the rate ratio of intervention vs control arm. Where the outcome was a binary variable, a Poisson model with robust standard errors was used to estimate the risk ratio of intervention vs control arm. Details of the precise model estimated for each outcome are given in the Supplementary Materials Section 4.

Primary endpoint: end of intervention

Primary endpoint data were analysed after those data were available, but before 1-year follow-up data had become available. The evidence for an intervention effect on primary outcomes was evaluated via a two-sided t-test on the adjusted mean difference in outcome scores between trial arms. We used a 2.5% level of significance, and accordingly effect estimates are presented with symmetric 97.5 % confidence intervals. Analyses were carried out in the R software and Stata version 18 (or later).

Effect estimates for the secondary outcomes are presented with 99% confidence intervals. P-values were not calculated. No formal adjustment for multiple testing was made for secondary outcomes.

Analysis of 1-year follow-up data

Analysis of follow-up data included data from both the end-of-intervention and followup timepoints. The analysis model described above was extended by including a random intercept for participant to account for within-subject dependency of observations, and a time×intervention interaction term. As for the primary analysis, models that accounted for partial clustering by treatment group failed to converge for most outcomes, and the most complex possible model was fitted for each outcome (see the Supplementary Materials Section 4). For the two primary outcomes, this was a mixed effects linear regression with random intercepts for participant and school, but no random effect for ReSET groups.

Participants were included in these analyses if they provided data for at least one time point. Estimates are valid in the presence of missing outcome data under the assumption that data are missing at random given the variables included in the model.

Analyses compared groups defined by intention to treat and included all those with available data. Several supportive analyses were conducted for the primary endpoint in line with the SAP. A per protocol analyses included all participants in the control arm and those participants in the intervention arm who adhered to the intervention (defined as attending at least five of the group sessions).

Three sensitivity analyses respectively adjusted for imbalances at baseline, imputed missing outcome data, and adjusted for predictors of missing outcome data. Standardized mean differences (SMD) for psychometric scales were calculated by dividing the estimated mean difference by the pooled baseline standard deviation. Confidence intervals for SMDs were estimated by non-parametric bootstrap with 1000 replications. Analyses were conducted in R and Stata. The trial design, Protocol and Statistical Analysis Plan were registered on the ISRCTN registry (reference: ISRCTN88585916). See Supplementary Materials Sections 5-8 for a full analysis report. A separate manuscript reporting a mediation analysis is currently in preparation (see https://osf.io/34jur/overview).

Results

Recruitment for the trial took place between April 2023 and April 2024, with the final assessment date for the primary endpoint occurring in July 2024. A total of 4005 pupils were screened for eligibility, of which 1,465 (36.58%) met the criteria to be enrolled in the trial. Of those eligible, parental consent was received for 727 (49.63% of eligible pupils) and 560 participants were enrolled into the trial. Randomisation of year groups within schools led to 278 pupils being randomised to the control arm and 282 to the intervention arm. We assessed 538 participants at the primary endpoint (270 control, 268 intervention, 96.1% retention; Figure 1) and 502 at 1-year follow-up (255 control, 247 intervention; 89.6% retention).

Trial outcomes post-intervention

Primary outcomes

At the primary endpoint immediately post-intervention, intent-to-treat analysis of the co-primary outcomes indicated no clear evidence of intervention effects on the SDQ Total Difficulties Score measuring overall psychopathology (adjusted mean difference = -0.36, 97.5% CI -1.12 to 0.40, p = .290, SMD = 0.07; Table 2), or on the WEMWBS scale measuring wellbeing (adjusted mean difference = 1.05, 97.5% CI -0.47 to 2.56, p = .121, SMD = 0.12).

Unplanned sensitivity analyses using bootstrap, to explore the effect of potential model misspecification, yielded very similar confidence intervals (Supplementary Table S9.2).

Secondary outcomes

The mental health secondary outcomes showed small differences between trial arms, mostly favouring the intervention: depression mean difference=-0.62 (99% CI -1.76 to 0.52, SMD = 0.11); anxiety mean difference=-0.41 (99% CI -1.39 to 0.57, SMD = 0.08), general psychopathology mean difference=-0.03 (99% CI -0.20 to 0.13, SMD = 0.03), internalising problems mean difference=-0.08 (99% CI -0.22 to 0.07, SMD = 0.07). The small mean difference for externalizing problems favoured the control arm, mean difference=0.11 (99% CI -0.07 to 0.29, SMD = -0.04).

The non-mental health secondary outcomes also showed no evidence of benefit, and most favoured the control arm: alcohol use risk ratio=1.32 (99% CI 0.66 to 2.63), drug use risk ratio=0.67 (99% CI 0.24 to 1.88), insomnia, risk ratio=1.02 (99% CI 0.81 to 1.30), indegree for best friend nomination rate ratio=0.85 (99% CI 0.69 to 1.06), outdegree for advice seeking rate ratio=0.99 (99% CI 0.85 to 1.14). The indegree for likeability rate ratio=0.73 (99% CI 0.61 to 0.87) indicates a statistically robust effect favouring the control condition, although no formal adjustment for multiple testing was made for secondary outcomes.

Trial outcomes at 1-year follow-up

1-year follow up of the primary outcomes

At 1-year follow-up (Table 3), we found evidence of lower overall psychopathology symptom levels in the intervention group relative to the control group (adjusted mean difference=-1.36, 97.5% CI -2.23 to -0.50, p = .0004, SMD = 0.25). Our model estimates that improvement from end-of-treatment to 1-year follow-up was on average 0.99 points better in the intervention group compared to the control group (97.5 % CI: 0.09 to 1.90; see Appendix Table S7.1). The intervention group also reported higher wellbeing (adjusted mean difference=1.50, 97.5% CI -0.05 to 3.05, p = .030, SMD = 0.17), although this did not reach statistical significance at .025%. Our model estimates that improvement from end-of-treatment to 1-year follow-up was on average 0.44 points better in the intervention group compared to the control group (97.5 % CI: 1.35 points worse to 2.22 points better; see Appendix Table S7.2). Unplanned sensitivity analyses using bootstrap, to explore the effect of potential model mis-specification, yielded very similar confidence intervals (Supplementary Table S9.2).

Adverse events

There were 14 adverse events, each occurring with unique individuals in the intervention arm. These events were deemed to be unrelated to the trial, as they involved safeguarding disclosures pertaining to events that had occurred prior to enrolment and were disclosed through contact with a ReSET facilitator.

Supportive analyses

For the per-protocol analysis, 243 (86 %) of intervention participants were classed as adherent and included. Effect estimates and confidence intervals from the per-protocol analysis were similar to those from the intent-to-treat analysis reported, and in no case would have led to substantively different conclusions. The same was true for all sensitivity analyses (see Supplementary Materials Sections 5-8). Further, we found no evidence of differences between the trial arms in an analysis of treatment received after the intervention (which due to resource constraints in the schools was collected in a single 'census' of current provision after all the intervention groups had ended across all schools; see Supplementary Materials).

Simulating population-level effects

We estimated that when applied at a population level the intervention would avert approximately 1,727 cases per 100,000 adolescents in this age group and timeframe, representing approximately 19% of the pre-intervention case burden, assuming a normal distribution with mean 9 and SD 6, targeting of the top 25% on SDQ total scores, an effect size of d = .25 (the 1-year follow-up effect on the mental health primary outcome), uptake of 50% (the rate achieved in this study), and a clinical threshold of 17 on the SDQ total score. This approach of course assumes that only adolescents scoring at or above the clinical threshold benefit from the intervention, which is unlikely to be true in practice. For further simulation information, see Supplementary Information.

Discussion

This cluster-randomised controlled trial is the first to evaluate an indicated prevention programme for adolescents targeting skills relevant for transdiagnostic mechanisms, designed to be scalable by being delivered in groups, and embedded in schools' existing mental health provision. At the primary endpoint, immediately post-intervention, we found no evidence of benefit on either overall psychopathology or wellbeing. In contrast, at 12-month follow-up, adolescents allocated to the intervention arm showed statistically robust reductions in overall psychopathology and internalising symptoms, relative to those receiving usual school provision. Effect sizes were consistent across multiple related outcomes. Sensitivity analyses suggested the results were robust to variations in adherence (though session attendance was generally high), and patterns of missing data (which was generally low, even at 12-month follow-up). There was little evidence of differences in patterns of referral or service use between the two arms of the trial during or after the intervention that might otherwise explain the long-term benefits we observed.

The findings suggest that the trial's primary evaluation endpoint happened too early to capture the gradual impact of this skills-focused indicated prevention programme. In hindsight, the apparent delayed impact may not be surprising, as ReSET was not designed to target symptoms directly; rather, the programme was designed to upskill young people to manage their emotions and social interactions more effectively. Benefits to mental health symptoms from this type of intervention are likely to accrue gradually, as young people apply their newly acquired skills to the emotional or social challenges they currently face and to new challenges they encounter over time. The pattern of findings is similar to that reported by Clarke et al (1995), which found no benefits of a CBT-based indicated prevention programme for depression in adolescents immediately post-intervention but consistent benefits 12 and 24 months later. We selected the primary endpoint to be immediately post-intervention primarily to mitigate the risks to statistical power posed by potential attrition over time; however, the concern about attrition turned out to be unwarranted, as follow-up rates after a year were very high (~90%). We recommend that future research includes evaluation immediately after, 3 months, 6 months and 12 months post-intervention, to track the evolution of its impact.

At 12-month follow-up, adolescents allocated to the intervention arm showed statistically robust reductions in overall psychopathology and internalising symptoms, relative to those receiving usual school provision. Although effect sizes were modest, they were consistent across multiple related outcomes and marginally larger than those reported in other school-based mental health prevention trials with at least medium-term (6-months+) follow-up (Werner-Seidler et al., 2017). One possible mechanism for this delayed benefit is that the intervening time between the intervention and 12-month follow-up is one in which adolescents face increasing emotional and interpersonal challenges. These exposures may provide greater opportunity to deploy the skills acquired during the programme and experience their benefit, positively impacting mental health, but requiring time to show effects. Indeed, this interpretation is consistent with literature on 'sleeper effects' of psychosocial interventions (Wade et al., 2022), which also show delayed benefit.

The bifactor model used to derive the latent factor scores yields orthogonal factors, meaning that the p-factor (general psychopathology) and the internalising and externalizing factors represent statistically independent dimensions of psychopathology. The significant effects on the p-factor and internalizing factor at 1 year follow up therefore represent evidence of separate, independent benefits of the intervention. The convergent findings for GAD-7 and PHQ-8 further corroborate this pattern across different measurement approaches. The results therefore suggest that the programme produced benefits to both general distress, or global mental health difficulties, and to symptoms of depression and anxiety specifically. Notably however, ReSET did not improve externalising symptoms at either follow-up, with effects favouring the control arm; mean differences between trial arms were small and confidence intervals wide and inclusive of zero at both timepoints. The lack of impact on externalizing problems may reflect real limitations in the scope of impact of this intervention or, alternatively, might reflect limitations in the scope for identifying improvements due the symptom profiles of young people entering the trial and/or overlap between externalizing symptoms and the global p-factor scores. It should also be noted that IPT-AST has typically been trialled for internalising symptoms (Young et al., 2012). As ReSET utilised features of IPT-AST in combination with cognitive-emotional training tasks, it may be that the intervention was not optimised to reduce externalising problems. Nevertheless, in light of some indications in past literature that group-based interventions can be unhelpful for youth with conduct problems (Dishion et al., 1999), the lack of negative impacts on externalizing problems in this trial is noteworthy.

In this trial, secondary social network outcomes showed small to moderate differences favouring the control group at both follow-up timepoints. These findings raise the possibility that participation in the intervention was associated with changes in peer networks, including fewer friendship nominations or a narrower set of peers identified as sources of advice.

However, it should be noted that the number of nominations does not indicate the quality of participants' relationships, which may be more important for mental health outcomes (Mitic et al., 2021) and differences tended to diminish at 1 year follow-up. In addition, evidence from a process evaluation conducted in parallel with the trial suggested that young people developed new peer connections through taking part in the intervention, which were found to be helpful for managing interpersonal difficulties (Lucas et al., 2026). The changes in social networks we observed post-intervention may therefore reflect some changes in young people's social relationships as they reevaluate their friendships and form connections to new peers.

Nevertheless, it is also important to consider that this may reflect unintended consequences of the trial. For example, being removed from their typical classes may have reduced participants' time spent with chosen friends, potentially reducing the number of nominations they received.

In the context of the increasing emphasis placed on the prevention of mental health problems in adolescence, including by policymakers (McGorry et al., 2024), and the rising demand for effective interventions for mental health in schools, the findings are potentially clinically important. This trial found evidence that ReSET is associated with medium-term benefits for mental health, with effect sizes in the range considered clinically meaningful as highlighted in Cuijpers et al. (2014) who identified a SMD of 0.24 as the minimally important difference for psychotherapeutic interventions. Observing clinically meaningful impacts on the SDQ is noteworthy in context of evidence that this measure strongly predicts future mental health diagnosis (Armitage et al., 2023; Bouter et al., 2024). The delivery of ReSET through existing school mental health support systems, the high acceptability as reported in a complementary process evaluation (Lucas et al., 2026). The high retention rates and promising outcomes at 1-year follow-up suggest that ReSET has potential to make a valuable contribution to prevention efforts in schools (Andrews & Foulkes, 2025). Given its compatibility with existing school mental health support structures, ReSET was designed to be scalable and is well-suited to large-scale replication and pragmatic evaluation. The trial also demonstrates the feasibility of a whole-school screening-to-intervention pathway: of 4,005 pupils screened, approximately 37% were identified as at-risk, 50% consented to take part and 560 were enrolled, with 90% retained at the 1-year follow-up. This approach -embedding universal screening within routine school mental health provision rather than relying on help-seeking or referral -has the potential to significantly broaden access, minimise selection bias, and move the field closer to making population-level impacts on mental health problems as demonstrated by our simulations. However, this simulation is illustrative and relies on a number of assumptions. Further optimisation of engagement processes would be valuable to increase participation above the 50% achieved in this study and the generalisability of the trial should be considered in context of the population that consented to the study.

A key limitation of this trial is the heterogeneity of facilitators delivering the intervention. Although all facilitators received standardised training and weekly supervision, professional backgrounds varied across sites, which may have influenced intervention fidelity.

However, we found no statistical evidence of clustering of outcomes by site (Supplementary Materials). This heterogeneity may also be viewed as a strength, as interventions that do not rely on highly specialised facilitators are more feasible to deliver at scale. Further limitations are that the study was conducted across 12 sites without an active control condition, meaning that effects could reflect nonspecific factors such as group support or expectancy rather than the intervention itself. In addition, the outcomes relied on self-report measures of psychopathology rather than clinical diagnoses. Further evaluation of the intervention at scale with an active control, multiple informants and diagnostic assessments of mental health outcomes would be valuable to assess the potential large-scale effectiveness of the ReSET intervention. Finally, although we recorded participants' additional service utilisation (e.g., CAMHS or school counselling), this information was provided by school staff at a single point in time, which meant the time since the intervention had ended varied. Not all schools provided this information, so for both these reasons these data do not reflect a comprehensive record of additional service utilisation by participants.

In conclusion, this cluster-randomised controlled trial evaluated a school-based, indicated preventative intervention targeting transdiagnostic socioemotional processes in adolescence. The ReSET programme did not produce detectable improvements in overall psychopathology or wellbeing immediately post-intervention but was associated with reductions in overall psychopathology, internalising symptoms, and related transdiagnostic outcomes at 12-month follow-up. These findings are consistent with a preventative, skillsbased intervention model in which benefits may emerge over time rather than as immediate symptom change. Taken together to whole-school screening combined with indicated, groupbased transdiagnostic intervention could have the potential to contribute to the prevention of adolescent mental health difficulties in the medium term.
