Reporting p values imprecisely (e.g., p < .05) reduces transparency, reproducibility, and re-use (e.g., in p value meta-analyses). Best practice is to report exact p-values with three decimal places (e.g., p = .032) unless p values are smaller than 0.001, in which case you can use p < .001.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (e.g., “decreased at the p < .05 significance threshold”).

What we found

We found 61 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Inequity in access to urban green spaces perpetuates marked disparities in psychological wellbeing in cities. The present study evaluates whether micro-scale biophilic interventions in virtual environments act as a socio-perceptual equalizer (Environmental Equigenesis Hypothesis) and modulate attention through oculomotor patterns of soft fascination (Attention Restoration Theory). Within this framework, 60 Hz eye-tracking integrated into Immersive Virtual Reality (IVR) was used to capture implicit attentional dynamics objectively. Framed within a mixed methods project registered on the Open Science Framework (OSF) after data collection and before any inferential analysis, and given the density of the data obtained, this manuscript reports exclusively the quantitative block focused on oculomotor and psychometric triangulation, reserving the qualitative analysis for a subsequent report. A sample of 75 participants exposed to 360° virtual tours evaluated low-, medium-, and high-socioeconomic-status (SES) neighborhoods under Original and Enhanced conditions. Eye-tracking revealed that the biophilic design did not alter the total volume of fixations but significantly reduced the average fixation duration, a pattern compatible with the attentional coupling of soft fascination. In parallel, subjective increases in positive affect, liking, esthetic evaluation, and relaxation were observed, while perceived stress did not change significantly overall. No significant differences in esthetic evaluation between neighborhoods remained after the intervention, and the areas-of-interest (AOIs) metrics showed a different allocation of gaze across neighborhoods, partly because the interventions applied were not the same in each one. Eye-tracking complemented the self-report data, although the main equigenesis findings rest on the psychometric measures.

Introduction

Accelerated global urbanization has redefined patterns of human settlement, progressively replacing natural infrastructure with dense, highly mineralized built environments. This transformation has not only intensified the physical and psychological disconnection between the population and natural ecosystems but has also positioned itself as a major determinant in the growing prevalence of cognitive fatigue, chronic stress, and affective disorders in cities (Beatley, 2016; Wolch et al., 2014). However, the impacts of environmental deprivation are not distributed uniformly across the urban matrix; on the contrary, socio-spatial segregation perpetuates profound environmental inequity. Neighborhoods with lower socioeconomic status (SES) systematically face lower vegetation coverage, lower-quality parks, and greater exposure to physical and social stressors, drastically reducing daily opportunities for psychological restoration (Galera et al., 2025; Mitchell and Popham, 2008; Rigolon et al., 2018; Xian et al., 2024). In this scenario, biophilic design, the intentional incorporation of nature, biological patterns, and organic forms into the built environment (Kellert, 2018; Ryan et al., 2014), emerges as a strategic urban intervention with high potential for promoting mental health and social equity.

The theoretical body of environmental psychology offers two complementary conceptual frameworks to explain the mechanisms underlying environmental restoration. On the one hand, Attention Restoration Theory (ART; Kaplan and Kaplan, 1989; Kaplan, 1995) posits that conventional urban environments demand constant effort of directed attention (top-down mechanism), which is susceptible to depletion and cognitive fatigue. Exposure to natural elements, in contrast, recruits involuntary attention or "soft fascination," a low-effort visual processing that allows for the recovery of attentional capacity. On the other hand, Stress Recovery Theory (SRT; Ulrich, 1983; Ulrich et al., 1991) holds that primary visual contact with organic patterns triggers an immediate positive and nonspecific affective response, modulating autonomic nervous system reactivity and attenuating sympathetic alertness without requiring complex prior cognitive elaboration.

Despite the solid empirical support for ART and SRT, the interaction between the restorative benefits of biophilic design and the socioeconomic inequity of the urban environment continues to raise crucial questions. The Equigenesis Hypothesis (Mitchell and Popham, 2008) suggests that restorative environmental resources can operate as a "socio-perceptual equalizer," exerting a disproportionately stronger buffering impact on vulnerable communities. In low-SES communities, characterized by prolonged green deprivation, the incorporation of biophilic interventions may generate a higher marginal gain compared with affluent neighborhoods, where daily environmental resources attenuate the margin of improvement (ceiling effect); we refer to this idea here as a basal restorative deficit. However, most research on equigenesis has analyzed macro-scale green infrastructure (such as peri-urban parks or protected areas), leaving a substantial gap regarding whether micro-scale biophilic interventions (such as the integration of vegetation on facades, vertical gardens, and organic-themed urban art) succeed in equalizing esthetic and affective evaluations on urban streets with different degrees of baseline degradation.

It should be noted that in the present design the participants are not residents of the neighborhoods they evaluate, so what varies is the baseline quality of the scene and not the observer's own environmental deprivation.

At the methodological level, the evaluation of landscape perception has historically faced the tension between the ecological validity of field studies, (with limited control of environmental confounding variables), and the rigidity of static photographs in the laboratory (Browning et al., 2020; Dupont et al., 2014; Higuera-Trujillo et al., 2017). The development of Immersive Virtual Reality (IVR) combined with eye-tracking technologies has overcome this dilemma, offering a platform of high perceptual fidelity and rigorous experimental control (Ferreira et al., 2025; Finkler et al., 2025; Frost et al., 2022; Jin et al., 2024; Mostajeran et al., 2025; Weng et al., 2025). Through immersive 360° videos, IVR allows participants to be placed in dynamic three-dimensional urban tours, while eye-tracking objectively records gaze behavior in real time. Metric by metric, the analysis of Total Fixation Count, Average Fixation Duration, Average Saccadic Velocity, and the count of selective fixations on areas of interest (AOI Fixation Count) offers a direct neurocognitive window to unravel the mechanism of the 'nature gaze' (Fleming et al., 2024). This allows discerning whether the psychological benefit responds to a quantitative exploratory overload or to the establishment of a pattern of 'soft fascination' characterized by distributed, agile, and selective attentional processing of organic components.

As a direct antecedent of this line of research, our group conducted an exploratory pilot study (N = 16; Ferreira et al., 2026) that demonstrated the methodological feasibility of integrating IVR and eye-tracking to capture socio-perceptual responses to biophilic transformations in neighborhoods with different socioeconomic levels. The preliminary results of the pilot provided initial empirical evidence in favor of equigenesis in the perceptual domain: whereas in the baseline scenario (Original) there was a marked esthetic gradient favoring high-SES environments, the biophilic intervention exerted a social equalization effect (ηp² = .41 for both liking and esthetic evaluation), raising the ratings of the most disadvantaged neighborhoods to equate them with those of affluent environments. However, the pilot study also revealed an oculomotor paradox: enriched low-SES scenes triggered the highest volume of fixations (M = 462.6) and visual coverage (M = 48.78%), and low-SES scenes showed higher saccadic velocity than the other scenes in both conditions (a main effect of SES, not of the intervention). This pattern was tentatively interpreted as novelty-motivated arousal, suggesting a dissociation between conscious affective improvement and physiological stress recovery that requires a longer exposure time.

Despite its valuable methodological contributions, the pilot study had a small sample size (N = 16), employed some single-item scales, and lacked a pre-specified differentiation between confirmatory and exploratory variables. To overcome these limitations and provide robust empirical verification, the present study scales the 3 × 2 factorial design of the pilot, which was fully within-subjects, to a mixed design with an independently calculated sample of N = 75 participants, with a distinction between confirmatory and exploratory hypotheses registered on the Open Science Framework (OSF) platform after data collection and before analysis. The AOI scheme was also changed with respect to the pilot, and the protocol differed in other respects (participants now viewed the tours standing with free body rotation rather than seated, and each tour comprised six instead of ten scenes). Absolute oculomotor values, including AOI counts and saccadic velocity, are therefore not directly comparable between the two studies, and the present analyses rely on within-study contrasts between conditions and neighborhoods. The study evaluates, confirmatory and exploratory, how micro-scale biophilic interventions modulate affect, esthetic evaluation, and oculomotor dynamics in Low, Medium, and High SES neighborhoods in the city of Almería (Spain).

Five main hypotheses, as specified in the OSF registration, are formulated: H1 (General effect of biophilia): Scenes enriched with biophilic design will significantly increase positive affect (PANAS Positive Affect), liking (Liking), esthetic evaluation (Esthetic Evaluation), subjective relaxation (Relaxation), and patterns of global visual engagement (Total Fixation Count) (assessed both globally and selectively) compared with unmodified original urban scenes.

H2 (Environmental equigenesis prediction):

The marginal psychological benefit (affective and evaluative) produced by the biophilic intervention will be significantly greater in the low-SES neighborhood context compared with the medium and high SES contexts, with biophilia acting as a socio-perceptual equalizer of public space.

H3 (Equigenic attentional attraction in intervened areas):

The volume of fixations directed at the specific intervention areas (AOI Fixation Count) will experience a significantly more pronounced increase in low-SES scenes after the incorporation of biophilic elements.

H4 (Affective-physiological dissociation SRT vs. ART):

Exposure to biophilic design will immediately increase positive affect and the subjective sensation of relaxation, but will not induce a simultaneous immediate reduction in perceived stress (Perceived Stress) or an alteration in oculomotor arousal dynamics (Average Saccadic Velocity).

H5 (Specific attentional coupling of soft fascination):

The exploration time focused specifically on natural and organic artistic elements (Fixations on Added Vegetation, Fixations on Biophilic Art), accompanied by shorter and more fluid fixation patterns (Average Fixation Duration, a marker of soft fascination according to ART), will correlate positively with the increase in positive affect and esthetic appreciation.

Method Participants and Experimental Design

The sample consisted of university students from the University of Almería (UAL), recruited through public calls disseminated via the university's institutional online portal. The final evaluated sample comprised N = 75 valid participants. Regarding gender distribution, 89.3% (n = 67) were women, 9.3% (n = 7) were men, and 1.3% (n = 1) preferred not to specify their gender. Regarding participant age, the median was 19 years, with an age range between 17 and 43 years. Participants were assigned to one of three neighborhood socioeconomic status levels (Low SES: n = 24; Medium SES: n = 26; High SES: n = 25).

The sample size was determined a priori through a power analysis in G*Power 3.1 for a mixed ANOVA 3 × 2 (one between-subjects factor: Neighborhood SES; one within-subject factor: Design Condition). Assuming a level α = .05, a power (1 -β) = .80, a correlation between repeated measures of .50, nonsphericity correction ε = 1, and a small-to-medium effect size of f = 0.20, the calculation indicated a minimum required sample of N = 66 participants (with df = 63 in the denominator for the Condition × SES interaction). To prevent loss of power derived from experimental mortality or oculomotor calibration failures, the sample was oversampled by 14%, reaching the target figure of 75 participants.

To guarantee methodological validity and participant safety during immersion in virtual reality and oculomotor recording, the following exclusion criteria were applied: presenting a self-reported history of severe motion sickness, color blindness or achromatopsia, neurological alterations, or any other medical condition that could interfere with the safe use of the VR headset or affect performance in the evaluation tasks. Regarding inclusion criteria, only normal or corrected-to-normal visual acuity was determined.

The study employed a mixed factorial design 3 × 2. The between-subjects factor referred to Neighborhood SES (3 levels: Low, Medium, and High), classified from the tertiles of average income by postal code and municipality published by the National Statistics Institute (INE). On the other hand, the within-subject factor consisted of the Design Condition (2 levels: Original vs. Enhanced). Each participant observed a single neighborhood in both conditions. One block per SES level was used, so Neighborhood SES is confounded with the specific streets of each block.

The order of presentation of the conditions was randomized through simple assignment, and the assignment of neighborhood SES was counterbalanced among participants.

The study was approved by the Human Research Bioethics Committee of the University of Almería (Ref. UALBIO2026_016; date: 7 May 2026). All participants signed the informed consent prior to the start of the sessions. Data were collected between 15 May and 30 June 2026.

The study was registered on the OSF (preregistration for studies with existing data) after data collection and before any descriptive or inferential analysis of the final dataset (https://doi.org/10.17605/OSF.IO/3TCWR ).

Stimuli and Technological Equipment

The stimuli consisted of immersive virtual tours based on 360° videos with a fixed viewpoint. The original recording was captured at 8K resolution using an Insta360 X4 camera under homogeneous morning lighting. Each condition was composed of a tour of six sequential 360° videos of approximately one minute each (total exposure time ≈ 6 minutes per tour).

The Enhanced versions maintained exactly the same geometry and perspective as the Original Scenes. In the enhanced versions, micro-scale interventions were applied that included: addition of vegetation (trees, shrubs, planters, and green facades), organic-themed artistic murals, digital facade cleaning, and elimination of visual degradation elements (such as graffiti and overhead wiring). The interventions were adapted to each neighborhood, and the type and number of intervened AOIs were not equivalent across neighborhoods. The six videos per neighborhood are a subset of the footage recorded for the pilot study (Ferreira et al., 2026), in which comparable enhancement proportions were targeted across neighborhoods (approximately +25% green pixel density and +15% esthetically treated surface area). Those proportions are reported for the full pilot set and are not reported separately for the six-video subset analyzed here; moreover, the type and number of discrete interventions, and therefore of intervened AOIs, differed between neighborhoods.

The immersive presentation and real-time oculomotor recording were carried out using Meta Quest Pro headsets through the SightLab VR platform (WorldViz) over the OpenXR protocol. The system recorded eye-tracking data at a sampling frequency of 60 Hz (one sample every ≈16.7 ms). To maximize ecological validity and reduce experimental fatigue, the headset's stored calibration profile was used together with automatic slippage correction algorithms.

Oculomotor data processing employed the velocity-threshold identification algorithm (I-VT): fixations were defined as periods with gaze velocity below 30°/s lasting a minimum of 100 ms, while saccades were identified as movements above said threshold.

Experimental Procedure

The experimental procedure was developed following a rigorously standardized and sequential protocol. Upon arrival at the laboratory, participants were received, compliance with inclusion criteria was verified, and they signed the corresponding informed consent. Next, each participant was assigned in a counterbalanced manner to one of the three neighborhood socioeconomic levels (Low, Medium, or High SES). Subsequently, the Meta Quest Pro virtual reality headset was adjusted and the eye-tracking profile was verified to guarantee optimal oculomotor recording.

The testing phase began with exposure to the first experimental condition (Original or Enhanced, randomized among participants), consisting of a tour through six immersive 360° videos. During visualization, participants remained standing at a fixed central anchor area; free 360° body rotation was allowed for free exploration of the environment, but translational displacement was restricted to preserve consistency of the viewpoint. Advancement through the scenes was controlled directly by the participant using the hand controller, so viewing time was self-paced. Throughout the immersive tour, the system continuously recorded gaze dynamics at a sampling frequency of 60 Hz.

At the end of the first condition, participants removed the headset and immediately completed the post-exposure questionnaire battery, which included the PANAS scale, ad hoc evaluative items, and open-response questions. A 5-minute washout interval was then applied using a neutral distractor task to prevent emotional or attentional carryover effects between conditions. Next, participants completed exposure to the second experimental condition under the same posture, body rotation, and oculomotor recording protocol, followed by a second administration of the questionnaire package. The session concluded with a debriefing phase and closure of the procedure.

Although the study's registration on the Open Science Framework (OSF) originally proposed a mixed-methods approach integrating this quantitative oculomotor evaluation with the qualitative analysis of post-exposure open responses, the high density and complexity of the data advised delimiting the scope of this first manuscript. In order to rigorously deepen the oculomotor and psychometric indicators, this submission focuses exclusively on the quantitative dimension supported by eye-tracking, while the qualitative corpus will be reported in a subsequent independent publication.

Statistical Analysis and Inference Plan

All statistical analyses were executed under a prefixed significance level of α = .05 using JASP v0.98.8 software.

Primary Model (Confirmatory)

A mixed ANOVA 3 × 2 was applied to each of the 7 main confirmatory variables (PANAS Positive Affect, Liking, Esthetic Evaluation, Relaxation, Perceived Stress, AOI Fixation Count, and Total Fixation Count), including Individual SES as a covariate. The model evaluated the main effects of Condition, Neighborhood SES, the critical Condition × SES interaction, and the covariate effects. The covariate was entered without centering, so the main effects of Condition in these models are conditional on a covariate value of 0 and may understate the raw mean differences shown in Tables 2 and 3; the interpretation therefore relies mainly on the Condition × SES interactions and on the Holm-corrected within-group comparisons.

Significant interactions or main effects were followed by pairwise comparisons corrected using the Holm method.

Exploratory Models

Exploratory ANOVAs: The same mixed ANOVA structure was applied to the global oculomotor variables in both conditions (Average Fixation Duration and Average Saccadic Velocity). In all analytical blocks, Holm correction was applied for multiple comparisons within each family of tests. Effect sizes are reported as partial eta-squared (ηp²) for ANOVAs and Spearman's ρ for correlations.

Deviations from the registration: Kruskal-Wallis and Wilcoxon tests were used for the intervention subcomponents and for the two skewed latency variables (Time to First Fixation, First Fixation Duration). The registration expected a positive association between fixation duration and affective gains in Block E, whereas the interpretation of shorter fixations as a marker of soft fascination in this manuscript is post hoc. The qualitative block, which includes registered integrated analyses linked to H1 and H2, is deferred to a separate report.

Results

Global and Focused Visual Attention (Oculomotor Metrics)

Total Fixation Count

The mixed ANOVA 3 × 2 with the Individual SES covariate on the Total Fixation Count did not show a significant main effect of the within-subject factor Condition, F(1, 71) = 1.576, p = .213, ηp² = .022. Nor was a significant interaction observed between Condition and Neighborhood SES, F(2, 71) = 0.301, p = .741, ηp² = .008, nor between Condition and the individual socioeconomic covariate, F(1, 71) = 0.008, p = .928, ηp² < .001. The between-subjects main effect of Neighborhood SES was also not significant, F(2, 71) = 0.557, p = .576, ηp² = .015.

The averages of the Total Fixation Count remained homogeneous across conditions and socioeconomic levels (see Table 2).

AOI Fixation Count

Regarding fixations directed at the urban modification areas (AOI Fixation Count), a significant main effect of Condition was found, F(1, 71) = 5.403, p = .023, ηp² = .071, reflecting an increase in the number of fixations during the Enhanced condition. Likewise, the betweensubjects factor Neighborhood SES showed a significant main effect, F(2, 71) = 9.475, p < .001, ηp² = .211. Post-hoc comparisons (Holm-corrected) for the SES effect revealed significant differences between the Low SES and Medium SES groups (t = 2.979, p Holm = .008), as well as between the Low SES and High SES groups (t = 4.256, p Holm < .001), while the difference between Medium and High SES did not reach significance (t = 1.328, p Holm = .188). The Condition × Neighborhood SES interaction was not statistically significant, F(2, 71) = 1.388, p = .256, ηp² = .038.

Average Fixation Duration

The exploratory analysis on Average Fixation Duration revealed a significant main effect of Condition, F(1, 71) = 9.686, p = .003, ηp² = .120. The average duration of each fixation decreased in the Enhanced condition (M = 0.224 s) compared with the Original condition (M = 0.241 s), a difference of about 17 ms (see Table 2). The Condition × Neighborhood SES interaction, F(2, 71) = 1.822, p = .169, ηp² = .049, and the main effect of Neighborhood SES, F(2, 71) = 0.849, p = .432, ηp² = .023, did not reach statistical significance.

Average Saccadic Velocity

The mixed ANOVA for Average Saccadic Velocity did not evidence significant main effects of Condition, F(1, 71) = 0.158, p = .692, ηp² = .002, nor of Neighborhood SES, F(2, 71) = 0.065, p = .937, ηp² = .002. The Condition × Neighborhood SES interaction was equally nonsignificant, F(2, 71) = 0.024, p = .977, ηp² < .001.

Initial Attentional Orientation (Time to First Fixation and First Fixation Duration)

For Time to First Fixation, the mixed ANOVA showed no main effect of Condition, F(1, 71) = 0.397, p = .531, ηp² = .006, and no Condition × SES interaction, F(2, 71) = 1.791, p = .174, ηp² = .048, with only a between-subjects main effect of Neighborhood SES being observed, F(2, 71) = 5.398, p = .007, ηp² = .132. Due to severe deviation from normality (Shapiro-Wilk W = 0.720, p < .001), the nonparametric Wilcoxon signed-rank test confirmed the absence of significant differences between the Original and Enhanced condition (W = 896.0, p = .445, r rb = -.111).

Regarding First Fixation Duration, the ANOVA did not identify significant effects of Condition, F(1, 71) = 0.515, p = .476, ηp² = .007, of Neighborhood SES, F(2, 71) = 0.272, p = .763, ηp² = .008, nor of the interaction, F(2, 71) = 1.535, p = .223, ηp² = .041. The nonparametric Wilcoxon test (given the observed skewness, Shapiro-Wilk W = 0.856, p < .001) corroborated this null result (W = 1286, p = .465, r rb = -.098).

The exploratory one-factor between-subjects analyses on the subcomponents of the Enhanced condition reflected a differentiation in the spatial distribution of scanning according to the neighborhood's socioeconomic level. These results should be read with caution, since the interventions applied were not equivalent across neighborhoods (for example, murals were present in all three neighborhoods, but were fewer in the Medium and High SES scenes, where they were coded together with other biophilic improvements), and the counts are raw and not normalized by the number or size of the AOIs.

Fixations on Added Vegetation:

A highly significant difference between groups was identified, F(2, 72) = 15.53, p < .001. The nonparametric Kruskal-Wallis test confirmed this result, H(2) = 21.90, p < .001. The Low SES group concentrated the highest average volume of fixations on pure vegetation (M = 302.1).

A main effect of SES was observed, F(2, 72) = 59.03, p < .001; Kruskal-Wallis H(2) = 60.02, p < .001. Fixations were focused almost exclusively in the Medium SES group (M = 34.88), being significantly higher than those recorded in Low SES (z = -7.420, p Holm < .001) and High SES (z = 5.549, p Holm < .001).

The analysis evidenced significant differences between SES levels, F(2, 72) = 23.87, p < .001; Kruskal-Wallis H(2) = 21.32, p < .001. PANAS Positive Affect

The mixed ANOVA on Positive Affect scores demonstrated a significant main effect of the within-subject factor Condition, F(1, 71) = 9.395, p = .003, ηp² = .117, as well as a significant interaction between Condition and Neighborhood SES, F(2, 71) = 4.544, p = .014, ηp² = .114.

The esthetic appreciation exhibited the most pronounced main effect of Condition among the confirmatory variables, F(1, 71) = 25.28, p < .001, ηp² = .263, accompanied by a highly significant Condition × Neighborhood SES interaction, F(2, 71) = 7.961, p < .001, ηp² = .183.

The main effect of Neighborhood SES was also significant, F(2, 71) = 5.558, p = .006, ηp² = .135.

Post-hoc tests revealed that in the Original condition there was a gap in esthetic perception between the Low SES group (M = 1.625, SD = 0.65) and the High SES group (M = 3.080, SD = 1.29; t = -4.703, p Holm < .001). After the biophilic intervention, esthetic evaluation increased significantly in all three groups: Low SES (Δ = +2.417, t = -10.09, p Holm < .001), Medium SES (Δ = +1.808, t = -7.920, p Holm < .001), and High SES (Δ = +1.080, t = -4.624, p Holm < .001). Discussion

The findings of this study suggest that the integration of micro-scale biophilic design elements in virtual urban environments is associated with improvements in participants' subjective evaluations, accompanied by differentiated visual scanning patterns. In line with Hypothesis 1 (H1) for the subjective measures, the presence of vegetation and organic art was linked to higher mean scores in positive affect (F(1, 71) = 9.395, p = .003, ηp² = .117), liking (F(1, 71) = 12.71, p < .001, ηp² = .152), esthetic appreciation (F(1, 71) = 25.28, p < .001, ηp² = .263), and subjective relaxation (F(1, 71) = 11.75, p = .001, ηp² = .142). However, the absence of significant differences in Total Fixation Count between conditions (p = .213, ηp² = .022) and the lack of correlation between global exploratory volume and affective deltas (ρ ≤ .042, p ≥ .720) indicate that these benefits would not appear to depend on a quantitative increase in spatial scanning (counts were not normalized by viewing time, which was self-paced). On the other hand, the decrease observed in average fixation duration, which decreased from 0.241 s in the Original condition to 0.224 s in the Enhanced one (F(1, 71) = 9.686, p = .003, ηp² = .120), constitutes an oculomotor pattern compatible with the phenomenon of soft fascination, a fundamental pillar of Attention Restoration Theory (ART; Kaplan and Kaplan, 1989; Kaplan, 1995). According to this conceptual framework and recent oculomotor evidence on attention toward nature elements (Fleming et al., 2024; Weng et al., 2025), exposure to organic elements would facilitate low-effort involuntary visual processing, characterized by shorter, more agile, and distributed eye movements. This interpretation should be taken with caution: the difference (about 17 ms) is close to the temporal resolution of the eye tracker (≈16.7 ms at 60 Hz), it refers to the whole scene and not to the intervened areas, and other explanations such as familiarity with the second exposure to the same footage cannot be ruled out, since the order of the conditions was randomized but not analyzed. The exploratory analyses of Block E are partly consistent with it: a higher count of fixations on pure vegetation presented a moderate inverse association with average fixation duration (ρ = -.391, p < .001) and positive correlations with the increase in positive affect (ρ = .305, p = .008), esthetic appreciation (ρ = .275, p = .017), and relaxation (ρ = .236, p = .042), and the time devoted to examining biophilic art was associated with the reported gains in esthetics (ρ = .349, p = .002), positive affect (ρ = .325, p = .004), and relaxation (ρ = .265, p = .022). However, these associations were not adjusted for SES (the Low SES group had the most fixations on these elements and the largest gains), only the correlation between fixations on biophilic art and esthetic appreciation survived Holm correction, and none of the correlations between the change in average fixation duration and the affective deltas was significant. The present data therefore do not show that shorter fixations underlie the affective benefits.

The data provide indications consistent with the Environmental Equigenesis Hypothesis (H2; Mitchell and Popham, 2008), suggesting that micro-scale biophilic interventions could act as a moderator of certain socio-perceptual inequalities in public space. This pattern is compatible with the notion of basal restorative deficit, according to which communities exposed to greater prior environmental deprivation, a common characteristic of socioeconomically disadvantaged urban environments (Galera et al., 2025; Rigolon et al., 2018; Xian et al., 2024), would present a proportionally higher margin of affective and evaluative improvement than affluent environments, where daily natural resources attenuate the marginal gain. This trend was observed in Positive Affect, whose significant interaction effect (F(2, 71) = 4.544, p = .014, ηp² = .114) responded to a statistically significant increase restricted to the low socioeconomic level group (Δ = +9.80 points, p Holm < .001), compared with elevations that did not reach post-hoc significance in the medium (p Holm = .344) and high (p Holm = .141) levels. Likewise, in esthetic appreciation, where the intervention showed its highest effect size among the confirmatory variables (ηp² = .263; interaction ηp² = .183), the marked gap between the low socioeconomic level (M = 1.625) and the high level (M = 3.080) observed in the original scenario was no longer significant after the biophilic intervention (M Low = 4.042 vs. M High = 4.160, p Holm = 1.000). These observations are supported by the correlations of Block B, where Neighborhood SES showed negative associations with the esthetics deltas (ρ = -.422, p < .001), positive affect (ρ = -.259, p = .025), and relaxation (ρ = -.230, p = .047), although only the esthetics correlation survived Holm correction. However, in the liking variable, the increase was cross-cutting among groups (ηp² = .152, interaction p = .394), which points to a broad hedonic preference toward urban vegetation. Support for H2 is therefore partial: the interaction was significant for positive affect and esthetic evaluation, but not for liking, relaxation or perceived stress; the interaction for positive affect would not survive a correction across the seven confirmatory models; and the similar esthetic ratings after the intervention (close to the top of the scale) reflect a nonsignificant difference and not a demonstration of equivalence. Moreover, since participants were not residents of these neighborhoods, the results describe how scenes of different baseline quality respond to the same kind of intervention, and not the effect on people living in deprived environments. Regarding Hypothesis 3 (H3), although the intervened areas attracted a significant number of fixations (F(1, 71) = 5.403, p = .023, ηp² = .071), the absence of a significant interaction (p = .256, ηp² = .038) suggests that attentional attraction was not disproportionately greater in the vulnerable group, reflecting instead a higher attentional level in this group that was already present in the Original condition (M = 282.4 vs. 217.5 and 212.8 fixations).

The analysis of the intervention subcomponents reflects that the allocation of gaze toward different typologies of urban renewal differed across neighborhoods. The higher volume of fixations on pure vegetation in the low socioeconomic level group (M = 302.1; H(2) = 21.90, p < .001) is compatible with the idea that vegetation acts as a high-salience restorative stimulus in landscapes with an initial green scarcity. Likewise, fixations on biophilic art were recorded only in the low SES group (M = 32.38) because, in the medium and high SES scenes, the fewer murals present were coded together with other biophilic improvements. This reflects the current AOI coding of mural elements rather than a difference in attention across neighborhoods and will be addressed in a revised version. In contrast, the greater focus toward pure physical urban regeneration elements in the medium socioeconomic level (M = 34.88; p < .001) or toward mixed regeneration with vegetation in the high level (M = 84.52; p < .001) may indicate an exploration oriented toward the quality of built finishes and their integration with the landscape (Ferreira et al., 2026). Because the type and number of interventions were not the same in the three neighborhoods, these patterns partly reflect the stimuli themselves, and they should be tested in a design that applies the same interventions everywhere and normalizes the counts by AOI number or size.

Regarding Hypothesis 4 (H4), the results only partly agree with a dissociation between the subjective affective response and stress recovery. Participants reported a greater sensation of subjective relaxation in the Enhanced condition (F (1, 71) = 11.75, p = .001, ηp² = .142), while the overall effect of condition on perceived stress (p = .209, ηp² = .022) and on average saccadic velocity as an oculomotor indicator of arousal (p = .692, ηp² = .002) was not significant, and these two changes were not correlated (ρ = -.056). However, mean stress ratings were lower in the Enhanced condition in the three groups, and the reduction was significant in the low SES group (p Holm = .003), with ratings close to the floor of the scale, so the absence of an overall effect should not be taken as evidence that stress did not change. This observation can be related to the theoretical distinction between the immediate affective responses postulated by Stress Recovery Theory (SRT; Ulrich, 1983; Ulrich et al., 1991) and the cognitive and physiological restoration processes contemplated in ART (Kaplan, 1995). It could be that brief exposures in virtual reality of the order of 6 minutes (Frost et al., 2022) are sufficient to activate conscious perceptions of serenity but not a deep deactivation of latent stress, although this remains a hypothesis. Similarly, the stability observed in the nonparametric metrics of initial orientation (Time to First Fixation: p = .445; First Fixation Duration: p = .465) indicates that the attentional benefits of biophilia would not respond to an automatic bottom-up capture bias in the first milliseconds, but rather to a distributed processing throughout the immersion.

Compared with the pilot study (Ferreira et al., 2026), which used a fully within-subjects design with 16 participants, the present results replicate some findings and not others. The convergence of esthetic evaluations across neighborhoods after the intervention was observed in both studies (interaction η²p = .41 in the pilot and .18 here), as were the main effect of the intervention on relaxation without a Condition × SES interaction and the absence of an overall effect on perceived stress. In contrast, the Condition × SES interaction for liking found in the pilot was not observed here, whereas an interaction for positive affect, absent in the pilot, emerged in the present sample. Among the oculomotor indices, the effect of the intervention on average fixation duration, which did not reach significance in the pilot, was significant here, while the association between changes in saccadic velocity and changes in relaxation reported in the pilot was not replicated. Given the differences in design, sample size, viewing posture and AOI scheme, the most consistent result across both studies is the esthetic convergence, whereas the affective and oculomotor patterns require confirmation in larger and more diverse samples.

From the perspective of urban planning and biophilic design (Beatley, 2016; Kellert, 2018; Ryan et al., 2014), these findings suggest that micro-scale interventions represent a promising strategy for improving the perceptual quality of public space in disadvantaged neighborhoods. However, when considering their translation into public health policies (Wolch et al., 2014), it must be borne in mind that the mitigation of perceived stress would potentially require continued daily exposures and integrated green itineraries. Among the limitations of this study is the composition of a university sample with a high percentage of women (89.3%) and a median age of 19 years, which advises caution before extrapolating the results to other age or clinical groups. Likewise, passive exposure via 360-degree video with a fixed viewpoint in virtual reality limits active translational exploration. Only one block per SES level was used and the interventions were not equivalent across neighborhoods, so SES is confounded with the specific streets and with the type of intervention. Fixations on Biophilic Art depend on an AOI coding scheme that was not applied uniformly across neighborhoods; results involving this variable are preliminary and will be revised in a subsequent version. The single-item scales are not validated and are strongly intercorrelated, perceived stress and negative affect show floor effects, and there was no pre-exposure measure of affect. The eye-tracking was recorded at 60 Hz without recalibration, and fixation counts were not normalized by the self-paced viewing time. In addition, individual SES was entered as an uncentered covariate, which may understate the main effects of condition, seven confirmatory models were tested at α = .05 without correction across models, and the exploratory correlations were not adjusted for SES. Future research using immersive virtual reality and eye-tracking (Finkler et al., 2025; Jin et al., 2024; Mostajeran et al., 2025) should evaluate the impact of these interventions in real scenarios or with free navigation, with several blocks per SES level and identical interventions, incorporating complementary neurophysiological recordings over longer exposure periods. Finally, in terms of methodological scope, it should be recalled that the design registered on OSF contemplated the collection of qualitative data through open questions after each virtual tour. Due to the extension and complexity of the quantitative findings presented in this work, it was deliberately decided to divide the research report into two phases; the subsequent publication of the qualitative corpus will allow complementing the oculomotor and evaluative pattern described here, deepening the experiences and meanings attributed by participants to the biophilic transformation of the environment.

Conclusions

The evidence observed in this sample indicates that the incorporation of micro-scale biophilic interventions in virtual environments was not accompanied by an increase in the global exploratory volume of the scene (Total Fixation Count: ηp² = .022) and was associated with a small reduction in average fixation duration (ηp² = .120), which is compatible with, but not specific to, the soft fascination mechanism characteristic of the attentional restoration processes postulated by the environmental psychology literature.

The results show trends congruent with the environmental equigenesis hypothesis for positive affect and esthetic evaluation, highlighting an increase in positive affect that reached statistical significance exclusively in the lowest socioeconomic level neighborhood (Δ = +9.80 points) and the disappearance of significant differences in esthetic evaluation between unequal urban contexts, reducing the initial gap until reaching similar post-intervention averages (M ≈ 4.04-4.16). The interaction was not significant for liking, relaxation or perceived stress. For its part, the elevation in liking manifested cross-sectionally among socioeconomic levels (ηp² = .152), suggesting a generalized interest toward the integration of nature in the city.

Biophilic immersion induced an increase in serenity and subjective relaxation (ηp² = .142), whereas the overall effect on perceived stress (ηp² = .022) and on saccadic arousal indicators (ηp² = .002) was not significant. Perceived stress did decrease significantly in the lowest socioeconomic level neighborhood, so the proposed dissociation between conscious affect and perceived stress is not clearly supported, and whether the recovery of latent stress requires longer or continued exposures remains an open question.

The allocation of gaze toward the renewed elements differed between neighborhoods: observers exposed to the disadvantaged scenes directed more fixations toward pure vegetation (M = 302.1 fixations), whereas in the affluent sectors the scanning was oriented mostly toward the integration of architectural and natural elements (M = 84.52 fixations). These patterns should be interpreted in light of the interventions applied in each neighborhood.
