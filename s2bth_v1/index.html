Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Ethics Approval Check works

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. This package was validated by the Metacheck team on articles in Psychological Science.

This module was developed by Lisa DeBruine, Daniel Lakens and Cristian Mesquida

How Preregistration Check works

Retrieve information from preregistrations in a standardised way, and make them easier to check.

The Preregistration Check module identifies preregistrations on the OSF and AsPredicted based on links in the manuscript, retrieves the preregistration text, and organizes the information into a template. The module retrieves text from the OSF with its API, and from AsPredicted with ResearchBox’s API when a ResearchBox key is set (see rbox_token()), or else from the preregistration’s web page. The information in the preregistration is returned. An AsPredicted link that could not be read is named in the report, with the reason.

The module can’t extract information from non-structured preregistration templates (i.e., where the preregistration is uploaded in a single text field) and it can’t retrieve information in preregistrations that are stored as text documents on the OSF.

If you want to extend the package to be able to download information from other preregistration sites, reach out to the Metacheck development team.

How Marginal Significance works

List all sentences that describe an effect as ‘marginally significant’.

The marginal module searches for regular expressions that match a predefined pattern. The list of terms is a subset of those listed in a blog post by Matthew Hankins. The module returns all sentences that match terms describing ‘marginally significant’ results.

Some of the terms identified might not be problematic in some contexts, and there are ways to describe ‘marginal significance’ that are not detected by the module.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Humans rely on social-cognitive processes, such as social working memory, to maintain and manipulate information about social relationships. While social and self-relevant information is often prioritised over non-social information, it remains unclear whether these processes are sensitive to social exclusion.

Therefore, this preregistered study investigated whether social exclusion influences working memory for social and non-social information. A total of 125 participants (age: M = 37.4 years, SD = 13.8; 49.6% female) first completed Cyberball, an online task inducing feelings of social inclusion or exclusion, followed by the Network Memory Task assessing memory for social (e.g., friendship) and non-social (e.g., flight paths) networks.

Consistent with previous findings, we found that social, relative to non-social information was processed faster in working memory. We also replicated a self-reference effect, whereby selfrelevant information was remembered more accurately and processed more quickly than nonself-relevant social and non-social information. Contrary to our hypotheses, social exclusion did not directly impact working memory performance.

However, exploratory analyses showed that higher rejection sensitivity was associated with slower reaction times across all conditions, following exclusion. Overall, our results suggest that the direct effects of social exclusion on working are limited and potentially dependent on individual difference in rejection sensitivity.

Introduction

Humans continuously navigate complex social environments in which they must represent and update information about relationships between individuals. The ability to maintain and manipulate social relational information in working memory, often termed social working memory, is therefore critical for effective social functioning 1, 2 . Indeed, prior research suggests that cognitive functions have evolved to preferentially process social information, with information about our social networks processed more efficiently than structurally matched non-social information 1.

Social networks refer to the interconnected relationships between individuals, such as friendships, family ties, and other stable social relationships 3 . Unlike a group, which simply denotes a collection of individuals, a social network explicitly captures the connections between them, with people conceptualised as nodes and relationships as edges. Efficiently representing and navigating social networks is important for social functioning, as it enables individuals to track who knows whom, understand interpersonal dynamics, and anticipate social outcomes 3 . Working memory therefore plays a central role in social cognition by allowing individuals to temporarily retain and flexibly update relational social information 2.

One paradigm used to examine social working memory is the Network Memory Task 1 (NMT), in which participants encode and recall relational structures that are either social (e.g., relationships between people) or non-social (e.g., flight paths between cities). Research using this paradigm finds an overall working memory advantage for social network information. In addition, both adults and adolescents show a self-reference effect, remembering social networks that include themselves better than networks involving others 1, 4 . Self-referential processing, defined as the capacity to differentiate and prioritise selfrelevant over non-self-relevant information, is considered a core mechanism underlying selfrepresentational systems and the neurocognitive basis of the self 5 . Together, these findings suggest that both sociality (the tendency to prioritise social vs non-social information) and self-relevance shape relational working memory performance. Social cognition is also highly sensitive to changes in social context. Social exclusion, defined as being ignored or rejected by others, represents a powerful social stressor that threatens the fundamental need to belong 6 . While much of the literature has focused on its emotional consequences, exclusion also appears to influence cognition 7 . For example, social exclusion has been associated with impaired verbal working memory and attentional filtering processes following brief virtual exclusion experiences 8, 9 . In contrast, other work suggests that exclusion enhances memory for specific types of social information, particularly those related to social cues and interactions, as demonstrated in a simulated chat room experiment with undergraduate students, where rejected participants exhibited improved recall for social interactions 10 . This pattern has been interpreted within the goal-driven resource redistribution theory 11 , which proposes that exclusion shifts cognitive attention toward socially relevant information that may support reintegration, such as social cues or relationships, while deprioritising non-social information. However, it remains unclear whether exclusion specifically affects working memory for social network information in the same way.

To understand why exclusion affects humans so deeply, it is important to consider the fundamental human need it threatens: the need to belong. Humans are highly social beings, and belonging is considered a fundamental psychological need with important implications for emotional and cognitive functioning 6 . Social connections are not only desirable, they are essential for survival and well-being, comparable in importance to basic physiological needs such as food and water 12 . Supporting this view, Tomova et al. 13 found that after a brief period of social isolation, participants showed midbrain activity in regions typically associated with food craving, suggesting that the brain may encode social deprivation in a similar way to primary drives like hunger.

When the need to belong is threatened through social exclusion, individuals often experience intense emotional distress, including feelings of loneliness, sadness, and anxiety 6 . Importantly, exclusion is not merely distressing, it also appears to trigger compensatory mechanisms aimed at restoring social connection. Following episodes of exclusion, individuals often show an increased motivation to reconnect with others 14 . This drive to reconnect with others may manifest cognitively, by enhancing attention to and memory for socially relevant cues that could facilitate reintegration into the group 10, 15 . From an evolutionary perspective, such responses may be adaptive, as maintaining social bonds increases access to protection, resources, and social support 16.

Sensitivity to social exclusion may also vary across development. Adolescents often show heightened sensitivity to peer evaluation and rejection compared to adults 17 , and prior work suggests that the cognitive and affective effects of exclusion may be particularly pronounced during adolescence 8 . However, it remains unclear whether age moderates the effects of exclusion on social working memory across the lifespan. Therefore, the present study aimed to address two primary research questions: (1) How does social exclusion affect working memory for social networks? And (2) Does this effect vary based on age, from older adolescence through adulthood? To examine this, the study included participants aged 18-65 years, allowing investigation of potential age-related differences in sensitivity to social exclusion across adulthood.

Participants first completed the Cyberball paradigm 18 , a widely used virtual ball-tossing task designed to experimentally induce feelings of social inclusion or exclusion. Participants were randomly assigned to either an inclusion or exclusion condition. Following this manipulation, participants completed the Network Memory Task 1 , in which they encoded and recalled different relational network structures. These networks differed in content (social vs. nonsocial) and in self-relevance. Social networks depicted relationships between people, whereas non-social networks consisted of abstract associations, such as flight paths between cities. Additionally, social networks were either self-social (i.e., self-relevant; including the participant) or other-social (i.e., self-irrelevant; excluding the participant). This paradigm allowed assessment of whether social exclusion influences working memory for social networks, particularly self-relevant relational information.

Based on prior literature, a social prioritisation effect (H1a) was hypothesised, such that participants would classify associations from social networks more accurately and more quickly than associations from non-social networks. A self-reference effect (H1b) was also hypothesised, whereby participants would classify associations from self-social networks (i.e., networks that include themselves) more accurately and more quickly than associations from other-social networks (i.e., networks that do not include themselves).

With regard to social exclusion, it was hypothesised that excluded participants would show enhanced performance for social relative to non-social networks (H2a). In addition, exclusion effects were expected to be strongest for self-social networks (H2b), such that excluded participants would classify associations from self-social networks more accurately and more quickly than in other conditions. Finally, age was examined as a potential moderator of exclusion effects (H2c), with younger participants hypothesised to show stronger exclusionrelated effects than older participants.

Together, these hypotheses aimed to clarify how sociality, self-relevance, and exclusion interact with age to shape social working memory, providing insight into the cognitive mechanisms underlying social development.

Results

Baseline working memory performance

Participants in the inclusion condition showed slightly higher baseline working memory performance on the Backward Digit Span Task than participants in the exclusion condition (ps < .05). Therefore, maximum digit span was included as a covariate in all subsequent analyses. Two participants were excluded due to the absence of correct responses on the task.

Manipulation Check

To confirm that the Cyberball manipulation successfully induced feelings of social exclusion or inclusion, the participants' subjective reports of being ignored, excluded, and their perceived ball reception was examined, as well as mood and belonging ratings immediately after the game. Participants in the exclusion condition reported feeling significantly more ignored and excluded, and reported receiving the ball less often than participants in the inclusion condition (all ps < .001). Excluded participants also reported lower belonging, higher sadness, and lower happiness immediately following the Cyberball task (all ps < .001), confirming the effectiveness of the manipulation.

Effects were attenuated in the reflective ratings collected at the end of the experiment. Excluded participants continued to report higher sadness (p = .006), whereas differences in belonging and happiness were no longer significant (ps > .05). Discussion

Human cognition is deeply embedded in social environments, where the ability to represent and remember relationships between individuals is important for effective social functioning.

As social exclusion threatens a fundamental need to belong, it may shape how such social information is processed and remembered. Therefore, the present study examined whether social and self-relevant information is prioritised in working memory and whether this prioritisation is influenced by social exclusion.

Participants completed a Cyberball task inducing social inclusion or exclusion, followed by a Network Memory Task comparing social networks (i.e., relationships between people) that either included the participant (self-social/self-relevant networks) or did not include the participant (other-social/self-irrelevant networks), alongside structurally matched non-social networks (e.g., flight paths between cities). Five main findings emerged. First, social information was processed more efficiently than non-social information, reflected in faster reaction times. Second, self-relevant networks showed a robust processing advantage, with faster and more accurate performance. Third, social exclusion did not influence working memory performance or the prioritisation of social, self-social, or other-social network information. Fourth, exploratory analyses suggested that rejection sensitivity moderated cognitive responses to exclusion, indicating that stable individual differences may influence exclusion-related effects. Finally, these effects were not moderated by age. However, exploratory analyses indicated that trait level rejection sensitivity might interact with exclusion experiences to impact domain general working memory performance.

Consistent with prior work using the Network Memory Task 1, 4 , participants responded faster to social compared with non-social networks. Although accuracy did not differ significantly across conditions, this likely reflected ceiling effects, as overall performance was high. These findings support the prior evidence suggesting that social information is prioritised in cognition and processed more efficiently than comparable non-social information. For example, similar social prioritisation effects have been observed across attention, memory, and perception paradigms [19] [20] [21].

One explanation for this advantage is that human cognition evolved to efficiently process social relationships and group dynamics 22 . Supporting this account, individual differences in social working memory have been found to be associated with real-world social network size 23 . Social information may also receive processing priority because it serves an important functional role in everyday life. Efficiently representing social relationships allows individuals to track interpersonal connections, anticipate social outcomes, and navigate complex social environments 24 Alternatively, the advantage may partly reflect greater familiarity with social relational structures compared to abstract non-social networks. Repeated exposure to social interactions throughout life may facilitate more efficient encoding of social information. However, because the task involved learning novel networks, familiarity alone is unlikely to fully explain the observed advantage. Therefore, social prioritisation likely reflects a combination of evolutionary pressure, functional relevance, and experiential familiarity.

Our study also demonstrated a self-reference effect in working memory. Participants responded faster and more accurately when processing self-social networks compared to other-social or non-social networks. This finding is consistent with extensive evidence showing that self-relevant information is encoded and remembered more efficiently than nonself-relevant information 25, 26 . Moreover, self-relevant stimuli capture attention even under minimal processing conditions, indicating a general prioritisation mechanism that facilitates encoding and retrieval 27 . Importantly, the present findings extend this effect to relational working memory, suggesting that self-relevance enhances the encoding and retrieval of associations between network structures.

A central explanation for this effect is that self-relevant information is integrated within a rich and well-organised self-schema. According to this account, the self provides a highly structured knowledge system that supports deeper encoding, richer associations, and more efficient retrieval 25, 28 . This increases the number of available retrieval pathways and facilitates memory performance. This interpretation is further supported by evidence that selfreferential processing emerges early in development, with infants as young as 18 months showing enhanced memory for self-associated objects in tasks requiring them to distinguish between objects belonging to themselves and those belonging to a puppet 29 . Complementing this, self-reference may also enhance cognitive 'binding' processes, facilitating integration across elements and processing stages 30 . Rather than reflecting a distinct mechanism, this account specifies how self-relevance enhances cognitive performance by promoting more efficient integration within working memory. In the present task, this likely supported the formation of more coherent relational representations, improving both encoding and retrieval. This effect is likely to be particularly adaptive in real-world settings, where tracking one's position within a social network is essential for maintaining relationships, anticipating others' behaviour, and navigating complex social environments.

Contrary to our hypotheses, social exclusion did not influence working memory performance or modulate prioritisation of social, self-social, or other-social network information. This contrasts with prior work suggesting that exclusion either impairs cognitive performance through resource depletion 7, 9, 31, 32 or enhances attention to social information to facilitate reconnection 10, 11, 33 . However, null effects are rarely reported in the literature, with only limited evidence suggesting an absence of exclusion effects, particularly in adult samples 8 . This suggests that while effects of social exclusion are often found, they may not be uniformly observed across all populations and paradigms.

One interpretation of our lack of effects, is that social and self-referential prioritisation reflects relatively stable properties of cognitive processing that are not easily altered by transient social experiences. From this perspective, prioritisation effects observed in working memory may reflect enduring domain-sensitive biases rather than flexible, state-dependent shifts in cognitive allocation 34, 35 . This interpretation is consistent with the overall pattern of results observed in the present study, in which social and self-relevant information was prioritised irrespective of exclusion condition. Crucially, this suggests that while exclusion may influence motivation or affective processes, it does not necessarily extend into higherlevel cognitive systems involved in relational integration. Alternatively, exclusion effects may depend on task demands. Prior studies often employed relatively simple paradigms 9 , whereas the present task required encoding and retrieval of complex relational structures, placing greater demands on working memory and cognitive control. Under these conditions, exclusion-related motivational shifts may have less influence on performance. This interpretation aligns with broader evidence suggesting that higher cognitive load can limit the extent to which motivational or affective factors influence cognitive processing 36, 37 . Together, the findings suggest that the cognitive effects of social exclusion may be constrained by task complexity and cognitive demands, highlighting important boundary conditions for exclusion effects in working memory. Thus, exclusion-related effects may primarily emerge in tasks that allow flexible attentional allocation but are reduced when performance is constrained by high cognitive demands.

Although no overall effects of social exclusion were observed, exploratory analyses suggested that stable individual differences may influence cognitive responses to exclusion. Specifically, individuals reporting higher rejection sensitivity showed slower reaction times following exclusion than inclusion. This suggests that the cognitive impact of exclusion varies across individuals. One explanation is that rejection-sensitive individuals continue to cognitively and emotionally process the exclusion experience during the subsequent task, reducing cognitive efficiency and slowing responses. This interpretation is consistent with cognitive resource and affective interference accounts 36, 37 and with evidence showing prolonged emotional responses to exclusion in socially sensitive individuals 38 . Importantly, rejection sensitivity reflects a broader trait disposition characterised by heightened expectations of rejection, emotional reactivity, and reduced cognitive efficiency under stress 36, 39 , rather than immediate responsiveness to experimentally induced exclusion alone. Individuals higher in rejection sensitivity may therefore experience exclusion as more salient and carry its effects into subsequent cognitive processing. Together, these findings suggest that stable individual differences, rather than transient social experiences alone, may partly determine the cognitive consequences of social exclusion.

In contrast, the present study found no evidence that age moderated the effects of social exclusion on working memory performance. Although adolescence is often characterised as a period of heightened sensitivity to social evaluation 17 , exclusion effects may be strongest in earlier developmental periods (approximately ages 10-14) 8 , which were not represented in the present sample. Age did, however, consistently predict slower reaction times, consistent with established age-related declines in processing speed 40, 41 . Importantly, this effect was independent of social content and exclusion condition, suggesting domain-general cognitive slowing rather than changes in social prioritisation.

Our results should be considered within the context of a number of limitations. First, the effects of the Cyberball manipulation may have attenuated over time. Although participants reported clear feelings of exclusion immediately following the task, these effects were reduced in later reflective ratings, suggesting that the emotional impact of exclusion may not have been sustained throughout the experiment. This attenuation may have been amplified by the online testing environment, where participant engagement and immersion are more difficult to control. Second, accuracy performance showed evidence of ceiling effects, likely due to the use of low-load stimuli in the Network Memory Task. Although low-load conditions were selected based on prior work demonstrating stronger social processing effects under reduced cognitive demand 1 , this may have limited sensitivity to detect subtle condition differences in accuracy. Whilst primary analyses were hypothesis-driven and preregistered, exploratory findings should be interpreted cautiously and need to be replicated in larger samples.

Future research should examine whether exclusion more strongly influences social working memory earlier in adolescence, when sensitivity to peer evaluation is heightened. Indeed, developmental research suggests that concerns about peer acceptance peak in midadolescence (around ages 15-16) and decline thereafter, alongside a peak in social anxiety and the onset of social anxiety during this period 42, 43 . Therefore, replication in a younger age sample may elucidate developmental responses to exclusion that the current study is unable to examine. It may also be valuable to investigate how real-world social factors, including loneliness, friendship quality, and social network size, relate to relational working memory under conditions of exclusion. For example, it is possible that individuals with close, supportive, friendships may buffer against the effects of short-term induced exclusion. Finally, future studies should examine whether exclusion differentially affects processing of emotionally valenced social information, such as affiliative or threatening social cues. This is because prior research suggests that negative social information may be preferentially processed within social networks 44 , raising the possibility that exclusion selectively alters attention to threat-related or affiliative social cues.

Overall, the present study replicates previous work demonstrating that social network information is prioritised in working memory, relative to non-social networks. This was reflected in faster processing of social networks and enhanced performance for self-relevant associations. Social exclusion did not influence working memory performance or modulate the prioritisation of social information. However, exploratory results offer important avenues for future work, suggesting that trait-levels of rejection sensitivity may interact with exclusion experiences to impact working memory performance. In summary, these findings suggest that social and self-referential prioritisation in working memory may reflect relatively stable features of cognitive processing rather than flexible responses to short-term social experiences, such as social exclusion.

Methods

This study was approved by the University of Oxford Central University Research Ethics Committee [CUREC Reference: MS IDREC 1830067] and was preregistered prior to participant recruitment (https://osf.io/3zp69). All procedures involving human participants were performed in accordance with the Declaration of Helsinki and all relevant institutional guidelines and regulations.

Participants

Sampling procedure

A total of 128 adult participants took part in the study. Participants were aged 18-65 years (M = 37.4, SD = 13.8). The sample included 64 females, 63 males, and 1 participant who identified as another gender or preferred not to say. The sample size was based on an a priori power analysis conducted in G*Power 3.1.9.7 45 , assuming a small effect size (f = 0.15), α = 0.05, and power = 0.95. This was informed by previous findings using the Network Memory Task with adolescents 4 , which reported a comparable effect size (f = 0.145). Additionally, we increased the total by 10% to account for potential attrition or poor data quality in this online study, bringing the final target to 128 participants.

Participants were randomly assigned to one of two between-subject conditions: social exclusion or social inclusion, with approximately equal numbers in each condition. Participants taking part in this study had to be 18-65 years old, fluent in English, and have no history of head injury that caused lasting problems with memory, thinking, or concentration, no diagnosed neurological or neurodevelopmental conditions or learning disabilities, and no diagnosed psychiatric condition (except for depression and/or generalised anxiety). Informed consent was obtained electronically from all participants prior to participation.

Participants were recruited via Prolific, an online platform for behavioural research. Age quotas were applied during recruitment to ensure a broad age distribution: approximately 35% of participants were recruited from the 18-24 age range, 35% from the 25-45 range, and the remaining 30% of participants from the 46-65 range. Participants received £6.75 for completing the approximately 50-minute-long study. Data was included in the analyses only if participants completed the study attentively, defined as correctly answering at least 3 out of 4 attention check items.

Three participants were excluded for failing pre-defined attention checks. In line with Prolific's participant management system, rejected submissions can be replaced by new participants while maintaining the original recruitment target. Consequently, the final sample size reflects the planned number of valid cases. Additionally, one participant was excluded due to consistently below-chance accuracy across all task conditions, indicating a failure to adequately understand the task. A further two participants were excluded because they did not provide any correct responses on the Backward Digit Span Task, resulting in missing baseline working memory scores required for the analyses. Following these exclusions, the final sample comprised 125 participants, with n = 62 in the Exclusion and n = 63 in the Inclusion condition. Materials and Procedure

Experimental design

This study investigates the effect of social exclusion on working memory for social networks in older adolescents and adults. Participants completed three behavioural tasks and selfreported measures designed to assess cognitive performance, social sensitivity, and emotional state. At the start of the session, participants completed a demographics questionnaire, which included age, gender, ethnicity, their highest level of education and their parent's highest level of education (see Appendix B for questionnaire). Participants also ranked their perceived social status on the MacArthur Scale of Subjective Social Status 46 , rating themselves on a ladder going from lowest social status 1 to highest social status 10 where they stand in comparison to the British society and their own community (this measure was not analysed in the present study).

To assess the depressive symptoms of the participants a self-report measure was included, the Depression, Anxiety and Stress Scale for adults (DASS; 47 ). Furthermore, we measured participants self-reported sensitivity to rejection using the Social Sensitivity Scale 48 . Next, participants completed the Backward Digit Span Task, a standard measure of general working memory capacity, included to enable comparisons between groups and to control for baseline cognitive ability.

Measures

Depressive symptoms. Depressive symptoms were assessed using the Depression, Anxiety and Stress Scale (DASS; 47 ). The DASS-21 is a self-report questionnaire consisting of three 7item subscales measuring depression, anxiety, and stress. Participants were instructed to indicate how much each statement applied to them over the past week using a 4-point Likert scale, ranging from 0 (did not apply to me at all / never) to 3 (applied to me very much or most of the time / always). Intermediate response options reflected increasing frequency or intensity (1 = sometimes;2 = often). Higher scores indicating greater symptom severity.

Internal consistency was good in the present sample (Depression α = 0.92, Anxiety α = 0.82, Stress α = 0.90). Only the depressive subscale was used in the present study.

Social rejection sensitivity.

Social rejection sensitivity was assessed using the Online and Offline Social Sensitivity Scale 48 . The 18-item measure assesses sensitivity to social evaluation and interpersonal experiences in both online and offline contexts. Participants rated their agreement with statements describing feelings in social situations on a 4-point Likert scale (0 = strongly disagree,3 = strongly agree), with higher scores indicating greater social sensitivity. Internal consistency was good (Cronbach's α = 0.91).

General working memory capacity.

General working memory capacity was measured using the Backward Digit Span Task, a standardised measure of working memory. In this task, participants were required to recall sequences of digits in reverse order. Following two practice trials, participants were presented with five test trials at each sequence length, beginning with two-digit sequences. Advancement to the next level required correct recall on at least three of the five trials. Sequence length increased by one digit at each level (e.g., from two to three digits), and the task continued until participants failed to meet the performance criterion at a given level.

Manipulation check.

Perceived social exclusion was assessed using the Reflexive Questionnaire (RXQ) and the Reflective Questionnaire (RCQ) 49 following the Cyberball task and after the NMT. Participants rated the extent to which their basic social need to belong and their mood were threatened during the game. Each questionnaire included three items assessing belonging, with two items reverse-coded. Responses were provided on Likert scales, with higher scores indicating greater perceived need threat and stronger feelings of exclusion. Although the full questionnaires are considerably longer, for the purposes of this study the focus was only on the first three items assessing belonging, the mood items (happy and sad), and the manipulation check items measuring perceived exclusion and the proportion of times participants believed they received the ball (see Appendix B for full item list).

Internal consistency was good in the present sample (RXQ Belonging α = 0.93; RCQ Belonging α = 0.87).

Experimental manipulation

After the questionnaires and Backward Digit Span Task, participants were randomly assigned to one of two conditions in the Cyberball task 18 , a validated social inclusion and exclusion paradigm. In this task participants are incorporated into a ball tossing game with two other avatars. In the inclusion condition, participants received the ball equally throughout the game (1/3 out of all the 30 throws); in the exclusion condition, they initially received the ball but then were subsequently left out of the game by the two other avatars (they receive the ball twice in the beginning and then not anymore). This manipulation is designed to induce feelings of social inclusion or exclusion. Participants completed self-report measures assessing subjective feelings of distress, belonging, and motivation to reconnect immediately after the Cyberball task and after the whole experiment (Reflexive and Reflective Questionnaire 49 ). Participants were randomly assigned to either the social exclusion or social inclusion condition at the participant level using block randomisation implemented in the Gorilla Experiment Builder . Gorilla's built-in randomiser ensured equal probability of assignment and approximately balanced group sizes across conditions.

Following the Cyberball manipulation, participants completed the Network Memory Task 1 , which assesses working memory for relational structures in social and non-social networks.

The task employed a within-subject design with three conditions: two social conditions (selfsocial and other-social) and one non-social condition.

For timing reasons, only the low-load condition from Andrews et al. 1 was used. This was chosen because in previous work the low-load (3 nodes per network), relative to the high-load (4 nodes per network), condition generated the most reliable effects. That is, in the low-load condition, networks consisted of three individuals (in the social conditions) or three cities (in the non-social condition), rather than four. In the social conditions, participants read short scenarios describing fictional social interactions, either involving themselves (self-social) or involving others only (other-social). In the non-social condition, participants read scenarios describing flight connections between cities. Following each scenario, participants were tested on their memory for network connections (i.e., social ties or flight paths), with accuracy and reaction time recorded as outcome measures.

After two practice trials, participants completed 6 trials per condition, resulting in a total of 18 trials across the task. A schematic overview of the task is shown in Figure 4. Data analysis

All statistical analyses were conducted in R using linear mixed-effects models. Separate models for accuracy (proportion of correct response) and reaction time (RT for correct trials only) were run. All models included Participant ID as a random intercept to account for repeated measures within subjects. Age (continuous) was included as a covariate in all models.

For Hypothesis 1a (the effect of social versus non-social condition on working memory performance), a model with Network Memory Task condition (social vs. non-social) as a fixed effect, age as a covariate, and participant ID as a random effect was fitted. Afterwards, a three-level model (non-social, social-other, social-self) was run to test specific condition differences regardless of the initial result. Hypothesis 1b (self-social networks that include the participant will be remembered more accurately than social networks that do not include the participant) was tested within this three-level model by directly comparing self-social and other-social conditions, with pairwise comparisons to assess whether memory performance is enhanced in self-social trials.

For Hypothesis 2a (social exclusion enhances working memory for social vs. non-social networks), the H1 model was extended by adding Cyberball condition (inclusion vs. exclusion; between-subjects) and the Cyberball × Network Type (social vs. non-social; within-subjects) interaction, with age as a covariate and participant ID as a random intercept. The follow-up used above was mirrored by replacing Network Type with the three-level condition (non-social, social-other, social-self) to probe which levels drive an interaction.

For Hypothesis 2b (social exclusion particularly enhances memory for self-social networks), the H2a model was extended by adding Cyberball condition (inclusion vs. exclusion; between-subjects) and the Cyberball × Self-relevance (self-social vs. other-social; withinsubjects) interaction, with age as a covariate and participant ID as a random intercept.

To test Hypothesis 2c (the effect of social exclusion on memory performance varies with age) the Cyberball x Age and the Cyberball × Network Type × Age interaction was examined.
