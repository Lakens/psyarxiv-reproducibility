How Ethics Approval Check works

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

Human research committee names - Institutional Review Board / IRB (US standard) - Independent Ethics Committee / IEC (ICH-GCP international clinical trial term) - Ethical/Ethics Review Board (generic) - Ethics (Advisory/Review) Committee/Board/Panel/Sub-committee - Research Ethics Committee/Board/Panel (UK/Canada/Australia) - Medical Ethics Committee - Human Subjects/Research Committee / Human Research Ethics (Advisory) Panel - Committee for/on the Protection of Human Subjects - Committee on (Health) Research Ethics - Office of Research Ethics - Abbreviations: IEC, REC, REB, ERB, METC, DEC. IRB and IEC are kept unconstrained as they are not observed to collide in practice. - Dutch: Medisch-ethische toetsingscommissie (METC) - French: Comité d'éthique / Comité d'Ethique

Animal research committee names - Institutional Animal Care and Use Committee / IACUC (US standard) - Any sentence containing animal(s) and committee (or board/panel) within ~5 words of each other — catches Experimental Animal Care and Use Committee, Animal Ethics Committee, Animal Welfare Board, Animal Welfare Ethical Review Body, etc. - UK: Animal Welfare Ethical Review Body / AWERB - Dutch: Dierexperimentencommissie / DEC (see DEC constraint above); Instantie voor Dierenwelzijn / IvD - German: Tierversuchskommission / TvK (advisory committee under §15 Tierschutzgesetz) - French: Comité d'éthique en expérimentation animale / CEEA; Comité d'éthique animale - Spanish: Comité de ética en experimentación animal / CEEA

Approval phrasing - Ethics/Ethical (approval|clearance) [was] (granted|obtained|received|given|secured) - Ethically approved - Approved by the (ethics|irb|institutional|independent|local|review|research) ... - This/The study/protocol/experiment/procedures/methods/research [was] (approved|reviewed) by - Study was ethically approved - (Followed|met|follow) the ethical (guidelines|standards|requirements) - In accordance with ... ethical (guidelines|standards) - Ethics protocol - Approved under (protocol|reference|number)

Waiver / exemption - Ethics/Ethical (waiver|exemption) - IRB (waiver|exemption|exempt) - Exempted from (ethics|irb|institutional review) - Waived by the (ethics|irb|institutional|review) (committee|board) - Deemed exempt

Declaration of Helsinki - Declaration of Helsinki / Helsinki Declaration

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Checking code requires downloading its file contents. For a paper whose repository is on Dryad, this never succeeds unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (listing the repository’s files does not need one). Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Data Check works

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. Translational Abstract

When planning a longitudinal panel study, one of the most important decisions is when to collect the data. Using simulations, we evaluated a continuous-time version of the random-intercept cross-lagged panel model-a statistical model that can handle unequally spaced measurement occasions. We varied sample size, number of measurement occasions, and the timing of assessments, and then examined how well the model recovered dynamic features (such as temporal stability and cross-effects between the two processes). Our results indicate that collecting more repeated measurements and using larger samples were the most influential factors for enhancing estimation performance. Cross-effects between the two processes were notably hard to recover. They showed low estimation efficiency and low statistical power across many conditions. Regarding sampling schedules, performance was similar across designs, and prior knowledge of the system dynamics did not lead to better performing schedules.

We introduce the random-within-window and short-and-long-lags designs. These are simple schedules that include irregular time intervals by design and require no prior knowledge about the bivariate dynamics. We pro-vide ready-to-use R code for generating them. We also provide R code to fit continuous-time random-intercept crosslagged panel models to data from any panel study, enabling researchers to take advantage of irregular time intervals rather than treating them as a nuisance. Finally, we illustrate the methods with data from a panel study on self-esteem and depression.

Together, these resources help researchers design more efficient longitudinal studies and draw more precise conclusions about change over time

How to Design a Panel Study for Investigating Bivariate Dynamics Using

Continuous-Time Modeling

Panel studies are common in behavioral sciences, particularly when the focus lies in the examination of the temporal unfolding of at least two processes over the course of time. Typically, panel data comprise a few measurement occasions or waves (e.g., three to five; Orth et al., 2021), following a sample of participants across a relatively large time span (e.g., 5 years). This differs from other types of studies, such as intensive longitudinal designs employing more repeated measurements, fewer participants (even N=1) and a smaller time span.

One of the main goals of panel studies is to examine the time-lagged reciprocal effects between the variables of interest. In the absence of an experimental design, this is the method by which evidence for reciprocal Granger-causal relationships is gathered (Granger, 1969). Dynamic longitudinal models are often used to analyze panel data for this purpose (Usami et al., 2019). These models are dynamic in the sense that they describe how the variables evolve over time as a function of their own and each other's previous states. By far, the most common approach is to specify these models within a structural equation modeling (SEM) framework. This entails that the data are structured in a wide format, and each column collects a measurement occasion at a specific time, which implies a discrete treatment of time. That is, discrete-time (DT) models represent change through transitions between successive measurement occasions, such that the modeled effects are tied to the time interval separating those occasions. Therefore, estimated values for the parameters capturing autoregressive effects (i.e., from previous states of the same process) and cross-lagged effects (i.e., from other processes past states) are dependent on the specific time interval between observations (Voelkle et al., 2012). This leads to a major problem: The magnitude of the time-lagged effects found for the same pair of variables can change greatly between studies with different times between observations (Dormann & Griffin, 2015; Voelkle et al., 2012; Voelkle & Oud, 2013). For instance, in a study where anomia and authoritarianism are measured annually, both processes would appear to be quite stable due to the presence of a high time-lag autoregressive effect. Meanwhile, if measurements were taken every 6 years, the stability (i.e., autoregressive) effect of both variables would be diminished, even close to zero (Voelkle et al., 2012). This phenomenon occurs because the first measurements have a greater capacity to explain subsequent measurements of the same variable when they are closer in time (e.g., after 1 year) compared with those that are more distant in time (e.g., after 5 years), resulting in different parameter values. The trend is different for cross-lagged effects, as the effect of one process on another typically becomes stronger after a certain amount of time and then diminishes in strength as the time between measurements increases (Dormann & Griffin, 2015; Driver, 2025; Ryan & Hamaker, 2022; Voelkle et al., 2012).

An increasingly frequent alternative to address the issue of interval-dependent parameters is the use of continuous-time (CT) models (de Haan-Rietdijk et al., 2017; Deboeck & Preacher, 2016; Oud & Jansen, 2000; Ryan et al., 2018; Voelkle et al., 2012; Voelkle & Oud, 2013). In this framework, the longitudinal trajectories of the variables are assumed to unfold continuously, and each measurement is considered a discrete realization of this continuous process (Deboeck & Preacher, 2016; Voelkle et al., 2012). Given that emotional and behavioral processes are likely to exist and fluctuate between observations, this framework is particularly useful to analyze them. Dynamical CT models involve working with differential equations, which allow estimating parameters that characterize change for an infinitesimally small time interval. This entails a very important advantage: The time-dependent parameters can then be rescaled and interpreted for a given time interval of interest. Another important advantage of CT models is their ability to naturally account for irregular time intervals between observations, both between and within individuals, providing greater flexibility in the measurement of variables (Ryan et al., 2018).

The problem of deciding when to measure

One critical aspect when designing a longitudinal study is deciding when to measure. Determining the optimal number and spacing of measurement occasions can be challenging, as researchers often lack enough knowledge about the causal process and the shape of the trajectories (Adolph et al., 2008; Collins & Graham, 2002). Cole and Maxwell (2009) pointed out that measuring with inadequate time intervals can lead to underestimated effect sizes and, therefore, misinterpretations of causal relations.

According to them, researchers must balance two issues: (a) allowing sufficient time for changes in one variable to influence the other variable while (b) ensuring the effect is measured before it disappears over time.

A few works have addressed this problem in the context of in-tensive longitudinal data (ILD) and ambulatory assessment. For example, Seizer et al. (2024) provided a comprehensive review and considerations for designing a longitudinal study and its data collection. However, they recognized the difficulties in the absence of strong theoretical guidelines for sampling rates and recommend avoiding undersampling and using pilot studies. The latter recommendation has been made by other authors too (e.g., Adolph et al., 2008; Hopwood et al., 2022).

The use of continuous-time models does not eliminate the need to make appropriate decisions about when to measure variables. Recently, Batra et al. (2023) examined the ability of different sampling rates to recover the parameters in univariate autoregressive (AR(1)) models applied to ILD. However, the impact of these sampling choices for bivariate trajectory in panel studies remains unclear, especially because it is unknown how the decisions about temporal sampling impact the recovery of the reciprocal relations between two variables. Adolf et al. (2021) proposed an approach for determining optimal time intervals in the context of CT modeling of ILD. They considered the optimal sampling rate (OSR) to be the one that minimizes the standard error of the model parameters (i.e., optimizes estimation efficiency). By specifying the CT parameters and the number of repeated measurements, it is possible to calculate the reliability of the estimates using the inverse Fisher information as a function of the sampling rate to obtain the interval that minimizes the standard errors.

Importantly, and in contrast to the existing literature on ILD, few studies have addressed this problem in the context of panel studies. One exception is the work by Dormann and Griffin (2015), who proposed a set of formulae-both for DT and CT approaches-to calculate the optimal time interval (OTL) given a set of generating parameters. They considered optimal interval the one in which the lagged effect of one variable on the other is maximum while controlling for previous values of the latter one.

More recently, Mulder et al. (2026) have examined the consequences of using different time aggregation methods (i.e., collecting information on how, e.g., a person feels at the moment, over the last week or over the last month) and undersampling (i.e., using time intervals that are too large in relation to the time scale on which the process fluctuates) in panel data and DT models. In their work, more aggregated and undersampled data led to misleading conclusions regarding the direction and size of the estimates.

Unresolved issues in the temporal sampling of panel data

Despite these previous works, the crucial problem of deciding when to measure is far from resolved, and several important problems remain. First, most of them focus on intensive longitudinal data, which involves studying processes that evolve rapidly through frequent measures taken in a relatively small number of participants (e.g., positive or negative affect, measured during several days or weeks). Much less attention has been paid to the adequate design of panel studies, which typically involve studying processes that evolve over longer periods, by taking less repeated measures, over longer time spans, and with larger samples.

Second, and importantly, the literature examining the consequences of the temporal design of measures has focused almost exclusively on discrete time modeling (e.g., Kuiper & Ryan, 2018). For example, Timmons & Preacher (2015) investigated how the recovery of a non-dynamical (linear and non-linear) univariate process is influenced by the number and spacing of measurements within a fixed study duration.

Non-linear processes were found to be especially sensitive to both the number of observations and their distribution over time, as well as the interaction between them.

For these non-linear trajectories, the main piece of advice derived from these results was to accumulate most of the measurements around the moment of greatest curvature of the trajectory. However, their study did not delve into trajectories with no specific curvature, such as processes that follow stable trajectories that fluctuate around a mean level.

Furthermore, these recommendations stem from studying deterministic processes and it is, therefore, unclear the extent to which they can be extended to stochastic systems. A stochastic system is one in which the variable of interest cannot be fully predicted based on its state at previous points in time. The source of this uncertainty is usually conceptualized as dynamic or innovative shocks to the trajectories. Generally, the variability of these innovations is modeled as a variance parameter, sometimes called dynamic error (Cáncer & Estrada, 2023; Schuurman et al., 2015). This dynamic error has a crucial role in longitudinal processes, because their stability over time depends on both these dynamics shocks and the value of the autoregressive and cross-lagged parameters (i.e., given a fixed value for a process' autoregression parameter, the observed autocorrelation between repeated measures will be lower with a higher variance of the stochastic innovations; see the next section for more details).

Designing a panel study (and longitudinal studies in general) requires decisions about the time interval between measures and the total number of measurements. These aspects have received considerable attention in the methodological literature. However, the overall duration of the study and the distribution of measurements throughout are equally critical design choices, yet they remain relatively underexplored.

For instance, in a hypothetical research project spanning a 5-year period, if new waves of measurement were taken, for example, every 6 months, the study would include up to 10 repeated measurements. However, if there were funding for, say, only six waves of data collection, the researchers would need to decide to either take them every 10 months and cover the whole time range, or take them every 6 months instead (i.e., for theoretical reasons) and cover only a fraction of the total available time range. Furthermore, measurement occasions do not need to be evenly spaced. For example, they can be randomly distributed throughout the study, resulting in varying time intervals both between and within participants, while maintaining a constant average interval overall (e.g., Hasl et al., 2024; Real-Brioso et al., 2024). Measurements can also be concentrated within a specific phase of the study (e.g., at the beginning or when greater curvature of the trajectories is expected). Considering this, the term sampling rate, often used in the literature, may be too narrow, and researchers should focus on the sampling schedule instead, as it encompasses all the aspects related to the timing of data collection.

Noteworthy, it is highly problematic to accommodate irregular measurement occasions with DT dynamical models, as they assume fixed and evenly spaced intervals. This constraint limits design flexibility and often forces researchers to impose regularity on data col-lection schedules. In contrast, CT models inherently account for variability in time intervals because the exact timing of each measurement is explicitly incorporated into the model (Ryan et al., 2018). This feature enables more flexible study designs, such as irregular or strategically concentrated measurement schedules. In other words, by adopting CT models, researchers can access a wider range of strategies for designing panel studies.

These extended design possibilities have received little attention to date. Hasl et al. (2024) delved in how the variability in measurement intervals affects parameter recovery in a single process. However, the performance of CT models that simultaneously incorporate two interrelated processes in panel data has not been evaluated. This is an important issue, as the interpretation of cross-effects, which is usually the central focus of bivariate longitudinal studies, is sensitive to many methodological decisions regarding data modeling (see Driver, 2025). Furthermore, no work has conducted a systematic evaluation of how the degree of stochasticity could change sampling needs in panel studies.

Therefore, this paper seeks to address these gaps by comprehensively examining the capacity of continuous-time models to identify and estimate parameters governing the causal relations between two interrelated processes in panel data. We focus on one of the most common statistical models in this context: the Random-Intercept Cross Lagged Panel Model (RI-CLPM), which we explain in the next section.

Random-Intercept Cross Lagged Panel Model

The Random Intercept Cross-Lagged Panel Model (RI-CLPM) was proposed as an extension of the Cross-Lagged Panel Model (CLPM), and developed to account for different sources of stability in psychological constructs (Berry & Willoughby, 2017; Hamaker et al., 2015; Zyphur et al., 2020). Unlike the CLPM, which only models stability through autoregressive relations, RI-CLPM separates within-person (statelevel) fluctuations from stable between-person (trait-level) differences. This distinction is very useful, as failing to account for stable inter-individual differences leads to misinterpretations of causality and inflated intra-individual parameter estimates (Hamaker et al., 2015; Lucas, 2023; Mulder & Hamaker, 2021). The RI-CLPM has been widely applied in contexts where psychological processes can be assumed to involve two distinct components: a stable, trait-like component that reflects consistent individual differences over time, and a more transient, state-like component that captures short-term variations influenced by prior states (Mulder & Hamaker, 2021; Orth et al., 2021 Orth et al., , 2024;; Usami et al., 2019). A common example is the trait-state distinction in depression (see Endler et al., 2000; Schrader, 1994): individuals differ in their general level of depressive symptoms (trait level), but also experience short-term variations (state level), with levels changing and carrying over from one week to the next.

Although we will use a continuous-time implementation of the RI-CLPM, we start by describing the discrete-time form, since it is much more common in the literature. In the usual discrete-time specification of the RI-CLPM (Equations 1 and 2), the observed variables xi and yi are explained (i.e., regressed on) three components: 1) the so-called "grand means" (μx,t and μy,t), which are time-varying group means, 2) the random-intercepts (RIx and RIy), which are the time-invariant stable trait factors that represent an individual's trait-like deviations from the grand means (i.e., stable between-individual differences) and 3) x * i,t and y * i,t , which are the temporal deviations from the expected scores of individual i at occasion t: 𝑥 𝑖,𝑡 = 𝜇 𝑥,𝑡 + 𝑅𝐼 𝑥,𝑖 + 𝑥 * 𝑖,𝑡 [2]

The temporal deviations in the latter term of each equation are, in turn, modeled as a function of three components: 𝑥 * 𝑖,𝑡 = 𝑎 11 • 𝑥 * 𝑖,𝑡-1 + 𝑐 12 • 𝑦 * 𝑖,𝑡-1 + 𝑑𝑥 𝑖,𝑡 [3] 𝑦 * 𝑖,𝑡 = 𝑎 22 • 𝑦 * 𝑖,𝑡-1 + 𝑐 21 • 𝑥 * 𝑖,𝑡-1 + 𝑑𝑦 𝑖,𝑡 [4]

The first term in Equations 3 and 4 captures the influence of the deviation at the previous time point (t-1) in the same variable, through the autoregressive effects (AR, a11 and a22). They represent the amount of 'within-person carry-over effect' (Hamaker, 2015). For instance, if a11 is positive, individuals with scores in x above their expected level at time t-1 will likely have scores above their expected level at the next time t.

The second term captures the influence of the deviation at t-1 on the other variable, or the cross-lagged effects (CL, c12 and c21). They capture the extent to which the level in one process can be predicted from earlier deviations from the expected level in the other variable, after accounting for both the process's own previous deviation and its overall structural change. For example, if c12 is negative, individuals that scored less than usual in one process (yt-1) will tend to have higher at the next occasion in the other process (xt).

Finally, the residual components (dxi,t and dyi,t) characterize the innovations or dynamic errors. These components can be interpreted as random alterations that affect, at a latent level, the fluctuations of the processes. Importantly, their effects are carried over subsequent times (Cáncer & Estrada, 2023; Schuurman et al., 2015). For instance, a random event such an unexpected stressful situation (e.g., a sudden dismissal) may affect the latent level of depressive symptoms, and may consequently affect the following days or weeks. Thes magnitude and number of these random impacts are captured by the innovation or dynamic error variance of each process, which is often assumed to be time-invariant σdx 2 and σdy 2 , and can be correlated (σdxy 2 ). This is a stationary structural equation model, meaning that all the parameters have constant value over time. Therefore, the dynamic parameters (including the two AR and the two CL) have the same value for any given pair of observations t-1 and t.

Furthermore, the intervals between observations are assumed to remain constant over time. Note that Equations 3 and 4 are often included in a single matrix equation. Here we present them separately for ease of understanding. The following section presents the corresponding continuous-time state-space matrix formulation.

Continuous-Time State-Space Implementation of the RI-CLPM

In this study, we illustrate how to estimate the RI-CLPM described above in continuous-time (CT). This has several benefits. In contrast with the better-known specification in discrete time, typically estimated within a structural equation modeling framework (e.g., Mulder & and Hamaker, 2021), CT modeling allows flexibly incorporating heterogeneous time intervals between measurement occasions, both across and within participants. This is advantageous in most longitudinal studies, and particularly in panel studies, for several reasons: a) Even when a research design schedules all participants to be measured at the same time points (i.e., waves), logistical constraints and unforeseen circumstances often make it impossible to collect data from everyone at the same time.

b) Some degree of data incompleteness is almost inevitable, which results in uneven time intervals between observations. c) Parameter estimates in CT models are independent of the time interval between measurements. Therefore, they can be rescaled to any time interval of interest, which allows for greater comparability across studies (Dormann & Griffin, 2015; Voelkle et al., 2012).

d) CT models make it possible to move beyond evenly spaced waves and implement more flexible sampling schedules. For example, oversampling during specific periods of interest or introducing variability in time intervals both between and within individuals. The present work leverages CT modeling to introduce and assess the performance of several such flexible sampling schedules for panel data.

Various modeling frameworks are available for estimating dynamic models with latent variables in CT. Here, we will specify a continuous-time RI-CLPM (CT-RI-CLPM) as a state-space model (SSM; Chow et al., 2010; Hunter, 2018). An SSM is composed of two equations: the state equation (Equation 5), which represents the dynamics of change in the latent variables, and the output equation (Equation 6), which links latent variables to observed measures:

In equation 5, f(t) is a vector including all the latent variables (in this framework, they are termed latent states) at time t, and A is the drift matrix of continuous-time autoregressive and cross effects, which determines how the latent states change over an infinitesimally small time interval. The term But represents the influence of observed exogenous covariates u(t), whose effect is captured by the loading matrix B. In addition, q(t) accounts for stochastic disturbances, often referred to as dynamic errors or process noise (i.e. innovations). These disturbances are typically drawn from a normal distribution, with mean zero and variance to be estimated. That is, the greater the variance of the dynamic errors, the less stable the process will be, because the state of the system at time (t) will be less predictive of its change.

Present study

This study aims to examine the influence of various design choices on the recovery of the temporal dynamics between two processes in panel studies with continuous-time (CT) modeling. In particular, we evaluated the performance of a CT implementation of the Random-Intercept Cross-Lagged Panel Model, with special interest in the recovery of the parameters that characterize auto-and cross-effects.

We tested various patterns of relationship, including strong, weak, and asymmetrical dynamic influences between the two processes. We also varied the ratio of within-vs. between-individual variance, thereby assessing the effects of different degrees of stochasticity (i.e., the magnitude of the random innovations). This is a novel and important contribution to literature, since stochasticity is key to understanding the stability of psychological processes. Simultaneously, we evaluated the impact of key aspects of the study design: sample size, number of repeated measures, sampling schedule, and total duration of the study.

Regarding the sampling schedule, we examined whether the sampling methods that have been proposed for longitudinal studies to determine the optimal measurement interval (i.e., Adolf et al., 2021; Dormann & Griffin, 2015) lead to adequate parameter estimation in panel studies under the different sets of population parameters. We will compare such methods with a novel approach introduced in this work: the short and long lags designs. Finally, we illustrated an empirical application of the CT-RI-CLPM, to demonstrate their practical implications in real-world data.

We expected to find an interaction between the number of repeated measurements, the sampling plan, and the intervals between assessments. Specifically, we expected that conditions with a greater number of measurements would show better parameter recovery, and this positive effect would be larger when observations are more closely spaced.

Method Simulation conditions and population generating parameters

Regarding the population generating parameters, we varied 1) the values of the drift A matrix to represent distinct dynamic patterns (i.e., both cross-effect strong, both weak, or one strong and one weak, i.e., unidirectional); and 2) the ratios of within-and between-individual variance, thereby modeling different levels of stochasticity by shifting variance toward the within-person level. Each of these conditions was examined under a set of distinct sampling schedules and sample sizes.

Sampling schedules

The sampling schedules compared in this study were selected based on a thorough review of prior methodological literature. Existing research has proposed several strategies for deciding the "optimal time lag" (Dormann & Griffin, 2015) or the "optimal sampling rate" (Adolf et al., 2021). We compared these approaches and evaluated their relative performance under continuous-time modeling. In addition, we introduce a novel sampling strategy: sampling schedules combining short and long lags (SHALL), which offer a key advantage over previous proposals. This strategy does not require prior knowledge of the true parameters governing the system's dynamics, which makes it particularly suitable for applied research contexts where such information is typically unavailable.

Consistent with common practice in panel studies (e.g., Janshen & Eisma, 2024), we focus primarily on sampling schedules including few repeated measurements per individual (i.e., 4, 5 and 6) and some more optimistic scenarios (i.e., 8, 10 and 12). The time unit in this simulation was a year, given that annual assessments are among the most common in panel studies (Orth et al., 2021 (Orth et al., , 2024)). Therefore, when transforming CT parameters into DT parameters for a given interval Δt, a value of Δt = 0.083 would correspond to a month, whereas Δt = 0.5 would correspond to one semester, and the resulting parameter estimates should be interpreted in accordance with their time intervals. Below we describe the schedules applied. Table 3 summarizes them, and schedule.

Random-within-window schedules (RWW)

First, we designed four schedules with sampling at random times and full coverage of the whole time span of interest. This total span was fixed at five years, as four to six annual assessments are most commonly used in panel studies. Observations were equally spaced on average (Δt = 1.25, 1, 0.83, 0.63 0.5 and 0.42 for 4, 5, 6, 8, 10 and 12 measures respectively), but each individual measurement occasion was scheduled within a predefined time window (specifically, one randomly week within each window), resulting in irregular intervals both between-and within-individuals.

Note that collecting more than 5 repeated measures per participant in a panel study spanning 5 years is relatively uncommon. Nevertheless, we included one condition with 20 measurements (average Δt = 0.25) as a benchmark scenario for all sampling schedules.

Schedules with Short and Long Lags (SHALL)

Previous works have recommended very short time intervals between observations (Dormann & Griffin, 2015; Hopwood et al., 2022; Ram et al., 2017; Seizer et al., 2024). Considering this and leveraging on the advantages of our continuous-time modeling framework, we introduced a set of "Short and Long Lags" sampling schedules (SHALL).

These schedules imply: a) concentrating repeated measurements at the beginning of the study, so that fluctuations between short-term processes can be captured, and b) including additional measurements further apart to achieve full coverage of the total time span of interest (i.e., five years in our study), to obtain information about the stable part of the processes.

In order to design these schedules, the smallest time interval considered was Δt = 1/12 ≈ 0.083, corresponding to one month. Note that, for the sake of applicability to other scenarios, researchers may re-scale their time unit considering their minimum interval and maximum time span. For instance, if Δt = 0.08 corresponded to 2 months, Δt = 1 would correspond to 2 years, and the target time span of five years would be reached at t = 2.5). In these schedules, we placed all the measurement occasions except the last one very close at the beginning of the study (constant Δt = 0.083, corresponding to monthly assessments). The final measurement was taken five years later for all cases.

For instance, with five time points per case, SHALL-5(4s-1l), the first four measurements are taken monthly, and the last measurement is taken at the end of the study, five years after the first measurement (see Figure 1). The results from this sampling schedule were used to evaluate whether the recommendation from previous work to measure "as frequently as possible" is appropriate in the context of panel studies.

Model specification

We fitted a continuous-time random-intercept cross-lagged panel model (CT-RI-CLPM). A total of 17 parameters were estimated in all conditions: initial values of the within-person processes (μx0, μy0, σ²x0, σ²y0, σx0y0), dynamic parameters from the drift and diffusion matrices (a11, c12, c21, a22, σ 2 dx, σ 2 dy, σdxy) and grand means and randomintercepts variances of the between-person process (μx, μy, σ 2 RIx, σ 2 RIy, σRIxy).

The CT-RI-CLPM was estimated using a state-space specification (SSM) in the OpenMx package (Boker et al., 2018; Hunter, 2018; Neale et al., 2016) in R (R Core Team, 2024). Model estimation was conducted using the functions mxExpectationStateSpaceContinuousTime and mxFitFunctionML, which rely on a hybrid Kalman Filter. This algorithm iteratively updates the state vector and state covariance matrix through a two-step process: a prediction step, which forecasts the next state based on previous estimates, followed by an update step, which refines predictions using observed data. Parameter estimation is further optimized using Maximum Likelihood prediction error decomposition, minimizing prediction error across time (Hunter, 2018; Kalman, 1960; Neale et al., 2016; You et al., 2020). The R code for estimating the CT-RI-CLPM models, along with tables containing all the generating parameter values for each condition and results, is available at: https://osf.io/vudta (Real-Brioso, 2026). The code used to simulate trajectories for each sampling schedule is available upon request.

Data analysis

We used several metrics to evaluate various aspects of the estimation accuracy and efficiency: percentage of improper solutions, total relative bias for the whole model, raw bias distribution for specific parameters (including mean and empirical standard error), and proportion of Type S errors (Gelman & Carlin, 2014) for the parameters of the drift matrix A. We focused on these dynamic parameters (i.e., the auto-effects a11 and a22, and the cross-effects c12 and c21), particularly the two cross-effects, because they are often the primary focus when applying a RI-CLPM.

Researchers commonly examine whether there is a lead-lag relation, whether the dynamic relation is reciprocal, and whether the influence of one variable on the other is positive or negative.

Improper solutions

Improper solutions are inadmissible model outputs, such as those including negative variances, or parameter estimates and/or standard errors that were not adequately estimated. These outcomes typically arise due to convergence issues during model estimation. In our study, we used the percentage of improper solutions for a given condition as an indicator of the difficulty to fit the model in such condition.

Improper solutions were excluded from subsequent analyses to preserve the validity of the recovery indicators. In this study, we used the status code provided by the OpenMx output to identify convergence success. A code of 0 indicated successful optimization with no estimation errors, while codes greater than 0 implied improper solutions. We then obtained the percentage of improper solutions for all the replications within every condition.

As mentioned before, we discarded the first values generated to allow the processes to reach a stable state. Consequently, the evaluation of overall parameter bias did not take into account the estimates of the initial values (μx0, μy0, σ²x0, σ²y0, σx0y0), and therefore P = 12. Previous research has suggested that relative bias should remain below an absolute value of 0.10 to be considered acceptable (Flora & Curran, 2004; Rhemtulla et al., 2012).

Accuracy and efficiency

In all replications, the raw bias was computed for each parameter θ (Bias = θestθ). We examined the accuracy and efficiency of the resulting sampling distributions by computing its mean and standard deviation, and by visually inspecting its shape. Next, a detailed analysis of the parameters in the drift matrix A was performed, given that the main interest in bivariate models is to study the cross-effects c12 and c21 and to interpret the predictive and potentially causal relations.

We computed the percentage of replications that correctly estimated the sign of the parameter (i.e., the percentage of replications that did not lead to the so-called Type S errors conditional on non-significance; Gelman & Carlin, 2014). We also computed the percentage of replications with the 95% confidence interval for the parameter including only values of the correct sign. Type S errors are especially important in cross-effects within bivariate dynamic models, because they provide information about how the processes relate to one another (e.g., a negative sign indicates that decreases in self-esteem are followed by later increases in depressive symptoms, whereas a positive sign would indicate the opposite).

Robustness to Type S estimation errors for the cross-effects

A high percentage of replications in which the parameter estimate has the wrong sign, i.e., a type S error, suggests that the estimate conveys little or no information about the true direction of the effect (Gelman & Carlin, 2014). In this section, we assess the robustness to type S errors, defined as the proportion of estimates with correct sign (i.e., negative), for the two cross-effect parameters (c12 and c21). We focus on these two parameters because they typically represent the primary focus when applying a bivariate dynamic model, as discussed earlier. As expected, in practically all replications, the estimates for the autoregressive parameters a11 and a22 correctly reflected their true sign (negative in CT metrics).

Empirical example

To illustrate the implementation of CT-RI-CLPM described in this paper, we replicated the discrete-time structural equation modeling (DT-SEM) analysis conducted by Orth et al. (2021), using the publicly available dataset My Work and I (MWI) from their Supplemental Materials. This dataset has been employed in prior research (Kuster et al., 2012 (Kuster et al., , 2013) ) and includes data from 663 participants (51% female; 96% residing in Switzerland). The study comprises five waves of measurements of self-esteem and depression, assessed using the German versions of 10-item Rosenberg Self-Esteem Scale (RSE; Rosenberg, 1965) and the 20-item Center for Epidemiologic Studies Depression Scale (CES-D; Radloff, 1977), respectively. Measurements were collected every two months, which translates to a time interval of Δt = 0.167 in annual time units.

The dataset was converted to long format including a time column, where the first measurement was set at t = 0 and the last measurement at t = 0.67. Both CT-SSM and DT-SEM approaches yielded fairly similar results, leading to the same substantive conclusions. By Δt = 1 (i.e., one year), both effects become negligible, suggesting that a yearly measurement schedule and a DT estimation approach would not detect these existing dynamic associations in this sample. Note that this scenario differs from those examined in our Monte Carlo study. Nevertheless, the estimates for this dataset suggest asymmetric dynamics both in terms of lead-lag effects and degree of stochasticity (i.e., drift matrix A, and diffusion matrix Q, respectively).

Discussion

Summary of Findings

The primary goal of this study was to evaluate how key design choices influence the recovery of temporal dynamics between two processes in panel studies, and to Our results indicate that the sample size and the number of repeated measurements had the strongest impact on parameter recovery, whereas differences attributable to sampling schedules were comparatively minor. In general, estimation was adequate in conditions with a large volume of information: 12 measurement occasions, and a sample of 2000 cases. When substantial cross-effects are expected, these requirements can be relaxed, with adequate recovery achievable using more conventional sample sizes (from 250 cases) and fewer measurement occasions (six per case).

The greatest estimation challenges were found with auto-and cross-effect parameters (a11, a22, c12 and c21) in the drift matrix. This was especially pronounced for cross-effects, which are often the primary focus in applications of cross-lagged modeling. Our findings indicate that cross-effect point estimates are generally unbiased, but estimation efficiency is low, resulting in wide sampling distributions. For strong cross-effects, statistical power was adequate with samples of 250 cases or more.

However, adequate inferential decisions about weak cross-effects required substantially larger samples (at least 2000 cases) combined with 12 or more measurement occasions.

Some systematic bias was observed under conditions with asymmetric drift and diffusion matrices: in these scenarios, one process exhibited higher stochasticity, which partially obscured the influence of the other process, pulling the corresponding crosseffect estimate toward zero. This bias was small in absolute terms but became apparent when computing relative bias due to the small magnitude of the true values, and was effectively mitigated by increasing the number of measurement occasions.

Parameters related to between-person components and dynamic error (i.e., stochastic innovations) were consistently well recovered across varying rations of within-and between-individual variance. This suggests that the degree of stochasticity in the process has limited impact on the estimation of the drift and diffusion matrices, whereas factors such as the number of repeated measurements and sample size have a greater influence on accurate recovery, especially of the cross-effects.

In addition, we illustrated the application of a continuous-time RI-CLPM using an empirical dataset. By estimating the parameters in continuous time and subsequently rescaling them to discrete time, we were able to replicate the findings of the original study, which applied a discrete-time structural equation model to the same data. The results indicated that depression exerted a greater influence on low self-esteem, consistent with the scar model (Lewinsohn et al., 1981; Orth & Robins, 2013). This finding stands in contrasts with recent works, also using continuous time modelling (Aebi & Orth, 2025), which appears to support the so-called vulnerability model, whereby low self-esteem predicts depressive symptomatology rather than reverse (Beck, 1967; Orth & Robins, 2013).

Theoretical and Methodological considerations

A central implication of our findings concerns how researchers conceptualize the temporal design of longitudinal studies. Previous literature has focused on identifying an optimal sampling rate, that is, a single ideal time interval between consecutive measurements (Adolf et al., 2021; Dormann & Griffin, 2015). Our results suggest that a more productive framework is to think in terms of a sampling schedule. This concept encompasses also the total duration of the study and the temporal distribution of measurement occasions, which can be irregular by design. This shift is enabled by Our findings also challenge the common recommendation to measure as frequently as possible (Dormann & Griffin, 2015; Hopwood et al., 2022; Ram et al., 2017; Seizer et al., 2024). The SHALL schedules tested this recommendation directly: they concentrated all but one measurement occasion at the beginning of the study, with only the final occasion placed at the end, effectively maximizing measurement density over a short window.

These schedules obtained the worst results. In contrast, the remaining sampling schedules distributed occasions across a broader range of time intervals and performed consistently better. This pattern suggests that in a continuoustime framework, capturing variability across diverse time lags is more informative than concentrating measurements within a too narrow temporal window.

Although satisfactory conditions for recovering the dynamics of a bivariate system were identified, the drift matrix consistently showed lower estimation efficiency than other model components (i.e., greater variability in the sampling distributions of its parameter estimates). This was especially pronounced for cross-effects, and is consistent with some findings from studies examining intensive longitudinal designs (de Haan-Rietdijk et al., 2017). Some empirically plausible conditions, particularly those involving weak cross-effects, led to markedly deficient parameter estimation when design conditions were insufficient. Furthermore, under conditions with asymmetric drift and diffusion matrices, a subtle but systematic pattern emerged: the cross-effect corresponding to the process with higher stochasticity (c12) was pulled toward zero, accompanied by a slight redistribution of residual variances between the two processes.

This suggests that when the two processes differ substantially in their within-person variability, the elevated noise in one process can partially obscure the influence of the other, leading the model to compensate through small systematic shifts in related parameters. Although this bias was small in absolute terms (and negligible once a sufficient number of measurement occasions was incorporated), it became apparent in relative bias indices due to division by small true values. This illustrates a broader point: global indices such as total relative bias can conceal important estimation challenges specific to individual parameters.

More generally, the common practice of evaluating estimation performance through overall bias indices such as RMSRB can be misleading in the context of bivariate dynamic models. In our study, such indices would suggest that estimation was generally satisfactory, obscuring the severe challenges associated with recovering crosseffects. Metrics such as robustness to type S error (the rate at which point estimates recover the correct sign) and statistical power (the rate at which the 95% confidence interval falls entirely within the correct sign) proved far more informative. Both are direct consequences of estimation inefficiency, are easier to interpret, and better capture conditions under which researchers risk drawing substantively incorrect conclusions about directional effects. We recommend that future simulation studies of bivariate dynamic models adopt these indicators alongside conventional bias metrics.

Finally, our findings should be interpreted in light of the population-generating values used to define simulation conditions. The classification of cross-effects as "weak" or "strong" depends on factors that warrant further systematic investigation.

Orth et al. (2024) proposed that a discrete-time cross-lagged effect of 0.07 represents a moderate value, but this guideline did not account for the nonlinear dependence of cross-lagged effects on the measurement interval. We derived our simulation values from studies employing annual measurements, where a "strong" discrete-time crosslagged effect (the third quartile in Orth et al.'s distribution) was approximately 0.08.

This choice, combined with the fact that many panel studies have not reported the time intervals used (Dormann & Griffin, 2015; Miller et al., 2025), may have restricted the range of continuous-time cross-effect values examined. We therefore recommend that researchers carefully consider whether the cross-effects of interest in their substantive domain are likely to be weak or strong, in order to select the appropriate design guidelines from those presented here.

Limitations and future directions

Several issues were unexplored in the present study and therefore remain to be addressed. First, we have assumed processes that do not present measurement error.

Although estimating a simpler model is a first step in exploring these sampling conditions, previous studies have argued that not including measurement error can affect the estimation of other parameters (Driver, 2024). A next step would be to use the stable trait autoregressive trait-state model (STARTS; Kenny & Zautra, 2001), which would be analogous to RI-CLPM including the estimation of measurement error.

However, convergence problems are commonly encountered in discrete-time empirical settings (Orth et al., 2021), so its performance in continuous time remains to be known.

Second, the correlations of the between components (rRIxy) and the within residuals (rdynxy) have been fixed in all populations. Recently, the role of the correlation of the latter in CT models and how it affects cross-effects estimation has been addressed (Kuiper & Hamaker, 2025). Therefore, the potential interplay between varying degrees of residual correlation and the estimation of cross-lagged parameters should be further examined to identify possible systematic biases resulting from asymmetric yet differently correlated systems.

Another limitation of the present study is that we have assumed that both processes maintain the same dynamics regardless of whether they are measured at intervals of, for example, two months or one year. This assumption may not be held in all scenarios. For example, measuring emotionality on a weekly basis would provide information about individuals' sensitivity and self-regulation in response to minor changes (e.g., everyday unforeseen events). Instead, if emotionality is measured annually, even with the same instrument, we might obtain information about different processes governing individuals' regulation, e.g., resilience in the face of drastic changes that can occur in life (e.g., relocations, layoffs or the dissolution of a romantic partnership). This would lead to differences in the dynamic parameters that are not due to mere differences in time interval. We emphasize the importance of the theoretical foundations in an empirical setting to ensure that, despite using largely unequal time intervals, the same processes are being measured. On this regard, Andresen et al. (2025) have recently developed an approach that integrates IDL and panel data, enabling different timescales at micro, meso, and macro levels from a discrete-time framework.

The scope of this study was intentionally restricted to bivariate systems. An important direction for future research is the extension to trivariate or higher-order systems, which likely face greater estimation challenges given the increased number of parameters in the drift matrix. Such an extension also raises interpretive complexities: in multivariate systems involving three or more processes, true discrete-time cross-lagged effects may change sign depending on the length of the time interval, a consequence of the matrix exponential that maps the continuous-time drift matrix to its discrete-time counterpart (Voelkle, 2012). This complicates the interpretability of the continuous-time sign and represents a substantive challenge that warrants dedicated investigation.

Finally, future work should investigate whether the low estimation efficiency for the dynamic parameters in the drift matrix A, and subsequent low statistical power for the cross-effects, can be alleviated through alternative estimation procedures and/or parameterizations (e.g., Bayesian estimation, penalized likelihood, or previous rescaling of the variables' metrics). It would be advantageous to conduct bootstrap studies based on single samples for estimating the sampling distributions for the drift matrix parameters and obtaining a clearer picture about the center and dispersion of such distributions (Kulesa et al., 2015).
