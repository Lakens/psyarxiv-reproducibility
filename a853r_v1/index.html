How Ethics Approval Check works

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

Human research committee names - Institutional Review Board / IRB (US standard) - Independent Ethics Committee / IEC (ICH-GCP international clinical trial term) - Ethical/Ethics Review Board (generic) - Ethics (Advisory/Review) Committee/Board/Panel/Sub-committee - Research Ethics Committee/Board/Panel (UK/Canada/Australia) - Medical Ethics Committee - Human Subjects/Research Committee / Human Research Ethics (Advisory) Panel - Committee for/on the Protection of Human Subjects - Committee on (Health) Research Ethics - Office of Research Ethics - Abbreviations: IEC, REC, REB, ERB, METC, DEC. REC/REB/ERB/DEC are short enough to collide with unrelated jargon (e.g. REC as a recognition-heuristic model abbreviation, DEC as a decision-task label, Reb as an author surname), so these four require an ethics/approval/committee/board/panel/institutional/ protocol word within ~30 characters in the same sentence. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Checking code requires downloading its file contents. For a paper whose repository is on Dryad, this never succeeds unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (listing the repository’s files does not need one). Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Objective: Motivational incongruence refers to insufficient satisfaction of individual motives in interaction with the environment and is assumed to contribute to psychological distress and psychopathology when prolonged. This study examined reduced motivational incongruence as a potential change mechanism in psychotherapy by testing whether within-person decreases in motivational incongruence predict subsequent decreases in general psychological distress.

Method: Analyses were based on three psychotherapy samples from two randomized controlled trials and one observational dataset collected in routine care, comprising 1,656 patients in total.

In each sample, motivational incongruence and distress were assessed at four to six occasions during treatment using short forms of the Incongruence Questionnaire and the Symptom Checklist-90-R, respectively. Random-intercept cross-lagged panel models (RI-CLPMs) tested prospective within-person effects between motivational incongruence and distress. Latent curve models with structured residuals (LCM-SRs) served as exploratory robustness analyses. Results: Across three samples, the RI-CLPMs yielded significant and large prospective effects of motivational incongruence on subsequent distress. Reverse cross-lagged effects, from distress to subsequent motivational incongruence, were significant in two of the three samples. The exploratory LCM-SR supported the primary motivational incongruence-to-distress effect in one sample but yielded no admissible solutions in the other two. Conclusions: Across three independent psychotherapy samples, within-person reductions in motivational incongruence preceded reductions in distress, consistent with motivational incongruence as a potential transtheoretical change mechanism in psychotherapy. Motivational incongruence may therefore represent a candidate treatment target. Future research should test the proposed causal MOTIVATIONAL INCONGRUENCE AS A CHANGE MECHANISM 3 relationship experimentally and examine which dimensions of motivational incongruence are most relevant for individual patients.

Introduction

Understanding how patients improve in psychotherapy requires identifying the mechanisms through which change occurs. Importantly, evidence for a potential mechanism needs more than showing that a proposed process is associated with the outcome or changes during treatment (Cuijpers et al., 2019; Kazdin, 2007). Specifically, a proposed mechanism should precede the outcome it is assumed to influence and not just be associated with unclear temporal direction (Kazdin, 2009). Thus, assessing the proposed mechanisms and outcomes repeatedly during treatment is necessary for distinguishing whether the proposed mechanism precedes, follows, or reciprocally relates to changes in outcome (Crits-Christoph & Gibbons, 2021; Falkenström, 2024; Kazdin, 2007). Doss (2004) distinguishes change processes from change mechanisms. Change processes are therapist activities and patient responses occurring within sessions, whereas change mechanisms are patient-level developments in characteristics or skills that are hypothesized to contribute to improvement but cannot be controlled directly by the therapist. Psychotherapies based on different theoretical models often show comparable average effects on outcomes despite substantial differences in their theoretical assumptions, therapeutic procedures, and the proposed processes of change (Barkham & Lambert, 2021). One possibility is that different procedures lead to shared or overlapping patient-level changes that contribute to therapeutic improvement (Lutz et al., 2026).

Reduced motivational incongruence might represent such a transtheoretical patient-level change mechanism. According to consistency theory, human mental functioning is oriented toward satisfying basic psychological needs, which individuals pursue through approach and avoidance motives and the behaviors that serve them (Grawe, 2007). Motives serve as reference values against which individuals compare their perceived reality (Grawe, 2007; Grosse Holtforth & Grawe, 2003). Approach motives represent desired interactions with the environment or oneself that may satisfy psychological needs, whereas avoidance motives represent experiences or outcomes that individuals seek to prevent because they may threaten these needs (Grosse Holtforth & Grawe, 2003).

Motivational incongruence refers to insufficient satisfaction of individual motives in interaction with the environment (Grosse Holtforth & Grawe, 2003). Consistency theory assumes that prolonged motivational incongruence contributes to the development and maintenance of psychological distress and psychopathological symptoms (Grawe, 2007; Grosse Holtforth et al., 2008). Accordingly, a decrease in motivational incongruence (i.e., better motive satisfaction) may represent a transtheoretical change mechanism through which psychological distress may decrease during psychotherapy. Conversely, psychological disorders may themselves impede motive satisfaction, suggesting a reciprocal relationship between motivational incongruence and distress (Grosse Holtforth & Grawe, 2003). Motivational incongruence is assessed in self-reports with reference to patients' everyday experiences rather than the immediate therapy session. The motives assessed by the Incongruence Questionnaire were derived bottom-up from schemaanalytic and plan-analytic individual case formulations rather than from techniques or theoretical concepts of one specific psychotherapy orientation and formulated in common-language terms (Caspar, 2022; Grosse Holtforth & Grawe, 2000 , 2003).

Several findings support the relevance of motivational incongruence for psychological distress: Cross-sectional findings indicate that psychotherapy patients report higher motivational incongruence than nonclinical participants (Grosse Holtforth & Grawe, 2003; Lutz et al., 2006), and that motivational incongruence is substantially associated with greater psychological distress and depressive symptom severity, as well as lower subjective well-being (Grosse Holtforth & Grawe, 2003). In addition, specific dimensions of motivational incongruence are associated with distinct interpersonal problems (Grosse Holtforth et al., 2007). Importantly, motivational incongruence decreases over the course of psychotherapy in different clinical contexts, including multimodal inpatient cognitive-behavioral treatment (Berking et al., 2003), outpatient psychotherapy (Caspar et al., 2023; Lutz et al., 2006), as well as interdisciplinary treatment for chronic primary pain, where reductions in motivational incongruence were associated with reductions in psychological distress (Scheidegger et al., 2023; Vincent et al., 2021). Finally, selfreported motivational incongruence has been associated with resting-state EEG activity in a healthy sample (Stein et al., 2013), suggesting that the construct relates to indicators beyond selfreport.

Together, these findings indicate that motivational incongruence is elevated in clinical samples, decreases during treatment, and covaries with psychological distress. None of these designs, however, can establish whether changes in motivational incongruence precede changes in distress, which is a necessary condition for a change mechanism (Crits-Christoph & Gibbons, 2021; Kazdin, 2007). Accordingly, a growing number of studies have used repeated assessments during treatment to test whether proposed change processes predict subsequent outcomes within patients (e.g., Gómez-Penedo et al., 2023; Rubel et al., 2017; Wester et al., 2024). For motivational incongruence, such tests are lacking in psychotherapy samples. Accordingly, previous studies have called for research clarifying the direction of the relationship between incongruence and psychological distress (Berking et al., 2003; Scheidegger et al., 2023; Vincent et al., 2021).

The only cross-lagged study to date, conducted in a nonclinical sample with intervals of two to three years, found that better mental health consistently predicted lower subsequent motivational incongruence, whereas the reverse association emerged at only one interval and was weak and opposite to expectation (Bachmann et al., 2014). However, this study did not distinguish stable between-person differences from within-person fluctuations.

Three methodological considerations are central to examining these associations. First, distinguishing between-person and within-person associations is essential to psychotherapy mechanism research (Falkenström et al., 2020), as illustrated by research on the therapeutic alliance (Zilcha-Mano, 2017). Unlike the traditional cross-lagged panel model (CLPM), which can conflate these levels, the random-intercept cross-lagged panel model (RI-CLPM) separates patients' stable, trait-like levels from occasion-specific deviations. Correlations between the random intercepts indicate whether patients who are generally more incongruent are also generally more distressed, whereas cross-lagged paths indicate whether deviations in motivational incongruence predict subsequent deviations in distress, and vice versa (Falkenström, 2024; Hamaker et al., 2015). This separation strengthens the validity of causal inference compared with analyses that conflate within-person and between-person associations (Falkenström, 2024; Falkenström et al., 2020). Second, systematic change during psychotherapy can introduce time trends. Unmodeled trends in either construct, including correlated individual differences in change, can bias autoregressive and cross-lagged estimates under certain conditions (Falkenström et al., 2026). Accounting for these trends therefore reduces the risk of biased findings. A third consideration is reverse causality, in which the presumed outcome causes the presumed predictor. The RI-CLPM examines both directions within a single model: the effect of motivational incongruence on subsequent distress and the effect of distress on subsequent motivational incongruence are estimated simultaneously. Both effects may operate simultaneously, as anticipated by consistency theory (Grosse Holtforth & Grawe, 2003; Scheidegger et al., 2023; Vincent et al., 2021).

The present study addressed the lack of prospective evidence on the relationship between motivational incongruence and general psychological distress during psychotherapy by examining reductions in motivational incongruence as a potential transtheoretical mechanism of change. To this end, we tested the cross-lagged effects between motivational incongruence and general psychological distress using data from two randomized controlled trials (RCTs) and one large routine-care sample, accounting for the three methodological considerations outlined above. Evidence that reduced motivational incongruence predicts lower subsequent distress would support motivational incongruence as a candidate treatment target. It would also provide a basis for future research on selecting which motive dimensions to address in treatment based on each patient's individual pattern of motivational incongruence.

We hypothesized that (a) within patients, lower motivational incongruence at one assessment predicts lower psychological distress at the next assessment, and (b) patients who generally report higher motivational incongruence than other patients also report higher psychological distress. Because consistency theory also assumes that psychological disorders may interfere with motive satisfaction, we hypothesized that (c) within patients, lower psychological distress at one assessment predicts lower motivational incongruence at the next assessment.

Method

Samples and Procedure

The present study included data from two randomized controlled trials and one large routine-care sample to examine the temporal dynamics between motivational incongruence and general psychological distress across controlled and routine-care settings. Each sample was analyzed separately. Within the two trials, the treatment conditions were pooled, because the parent trials had found no differential effects on outcome (Caspar et al., 2023; Grosse Holtforth et al., 2019). Sample sizes were determined by the availability of eligible existing data. For inclusion in the present analyses, patients from the source samples were required to have at least one observed motivational incongruence or general psychological distress score across the analyzed assessments. Additional recruitment, treatment, and measurement details are provided in the Supplemental Material.

Bern Randomized Trial

The Bern trial sample was drawn from a randomized controlled trial (Caspar et al., 2023) in which 104 patients recruited at a Swiss university outpatient clinic were randomized. Patients were eligible if they were at least 18 years old and met diagnostic criteria for a unipolar depressive disorder, anxiety disorder, or adjustment disorder according to the Diagnostic and

Statistical Manual of Mental Disorders (DSM-IV-TR; American Psychiatric Association, 2000).

After providing informed consent, patients were randomized to Psychological Therapy (PT) with emotion-focused or self-regulation-focused add-ons. Both treatment arms were planned to comprise approximately 25 (± 3) sessions to facilitate comparisons of therapeutic processes across treatments (Caspar et al., 2023). PT is an integrative cognitive-behavioral treatment approach guided by individualized case formulations based on Plan Analysis (Babl et al., 2016; Caspar, 2022; Caspar et al., 2023). Treatment was delivered by psychologists with at least 1.5 years of postgraduate psychotherapy training. Measures were assessed at pretreatment, after 8 and 16 sessions, and at posttreatment, approximately 24 weeks after the start of treatment. Measures

Motivational Incongruence

Motivational incongruence was assessed in the Bern and Zurich trials using the 23-item short form of the self-report Incongruence Questionnaire (S-INC; Grosse Holtforth & Grawe, 2003). Approach incongruence, referring to the insufficient satisfaction of approach-oriented motives, is assessed with 14 items, whereas avoidance incongruence, referring to the occurrence of undesired experiences or outcomes that a person seeks to avoid, is assessed with nine items.

Items assessing approach incongruence (e.g., "I have been independent.") are rated on a 5-point Likert scale ranging from 1 (much too little) to 5 (completely sufficient). Items assessing avoidance incongruence (e.g., "I have felt powerless") are rated on a 5-point Likert scale ranging from 1 (does not apply at all) to 5 (applies very strongly). Items assessing approach incongruence are reverse scored so that higher scores consistently indicate greater motivational incongruence. Approach and avoidance incongruence scores are calculated by averaging the corresponding items, and the total incongruence score is calculated as the mean of the two subscale scores. Internal consistency across the 23 items at pretreatment was Cronbach's α = .87 in the Bern and .83 in the Zurich trial.

In the Trier sample, motivational incongruence was assessed with the INC-10 (Lutz et al., 2006), a short form comprising six items assessing approach incongruence and four assessing avoidance incongruence. The wording, response format, and direction of scoring are unchanged from the original questionnaire. The total incongruence score was calculated as the mean of all 10 items. Internal consistency of the total incongruence score at pretreatment assessment was Cronbach's α = .82.

General Psychological Distress

General psychological distress was assessed with a brief self-report version derived from the Symptom Checklist-90-R (SCL-90-R; Derogatis, 1977; Franke, 2002) in each sample. The specific short form differed across the three samples, with higher scores indicating greater distress.

In the Bern trial, psychological distress was measured with the Brief Symptom Inventory (BSI; Derogatis & Melisaratos, 1983; Franke, 2000), a 53-item short form of the SCL-90-R covering its nine primary symptom dimensions. Items are rated on a 5-point Likert scale ranging from 0 (not at all) to 4 (extremely). The Global Severity Index (GSI) was computed as the mean across all 53 items. Internal consistency at pretreatment assessment was Cronbach's α = .93.

In the Zurich trial, psychological distress was measured with the Symptom-Checklist-K-9 (SCL-K-9; Klaghofer & Brähler, 2001), a nine-item short form of the SCL-90-R containing one item from each of the nine primary symptom dimensions. Items are rated on a 5-point Likert scale ranging from 0 (not at all) to 4 (extremely). The GSI (GSI-9-K) was computed as the mean across all nine items. Internal consistency at pretreatment assessment was Cronbach's α = .77.

In the Trier sample, psychological distress was measured with the 11-item Hopkins Symptom Checklist (HSCL-11; Lutz et al., 2006), a short form of the SCL-90-R assessing depression-and anxiety-related symptoms. The HSCL-11 total demonstrated a strong association with the GSI of the SCL-90-R (r = .89; Lutz et al., 2006). Items are rated on a 4-point Likert scale ranging from 1 (not at all) to 4 (extremely). The total score was computed as the mean across all 11 items. At pretreatment, the score was calculated from the 11 corresponding BSI items, which had been linearly transformed as part of the standard procedure in the source dataset to increase comparability with the HSCL-11 response format. Internal consistency at pretreatment assessment was Cronbach's α = .87. Across all measures and samples, scale scores were computed only when all underlying items were available at a given assessment.

Statistical Analyses

Analyses were conducted in R (version 4.4.3; R Core Team, 2025) using the lavaan package (version 0.6-21; Rosseel, 2012). Motivational incongruence and general psychological distress were analyzed as manifest variables with scores constructed as described above. To deal with missing data, full information maximum likelihood was used to fit the models to the raw data (Schafer & Graham, 2002).

Following the recommendations of Hu and Bentler (1999), model fit was evaluated using the comparative fit index (CFI) and the root mean square error of approximation (RMSEA); good fit was indicated by CFI ≥ .95 and RMSEA ≤ .06. Nested models (e.g., constrained vs. unconstrained) were compared using the RMSEAD index, which is the RMSEA associated with the chi-square difference test (Savalei et al., 2024). A low RMSEAD value suggests that the additional constraints included in the more parsimonious model lead only to a small difference in fit and that therefore the more parsimonious model should be favored. We used the more relaxed cutoff value of RMSEAD = .08 proposed by Savalei et al. (2024). All tests of statistical significance were conducted at an alpha level of .05.

The statistical analyses were conducted in three steps. First, in preliminary analyses, we tested for a trend in the data and determined the specific model used in the main analyses.

Second, in the main analyses, we used the resulting model (i.e., a detrended random-intercept cross-lagged panel model) to estimate prospective effects between motivational incongruence and general psychological distress. Third, in exploratory analyses, we used an alternative approach to modeling the trend, namely, the latent curve model with structured residuals.

Preliminary Analyses

Because participants were assessed repeatedly while undergoing psychotherapy, the sample-level means of both constructs were expected to decline across waves as treatment progressed. If left unmodeled, such temporal trends can bias autoregressive and cross-lagged estimates. Falkenström et al. (2026) showed that unmodeled time trends can bias these estimates under certain conditions. Because such trends are to be expected in data collected during a clinical intervention, we addressed this issue in three steps. First, we examined whether temporal mean trends were present in motivational incongruence and general psychological distress. For each sample, we inspected the wave means visually. We then compared a model in which the means of each construct were constrained to be equal across waves with a model in which they were estimated freely. An RMSEAD above the cutoff of .08 was taken to indicate that the equalmeans model should not be retained and that mean trends should be modeled in the longitudinal analyses (for additional information on the tests of temporal mean trends, see the Supplemental Material, Part 3). Second, following the procedure used by Falkenström et al. (2026), we examined whether temporal trends needed to be modeled within the RI-CLPMs. For each sample, we compared two versions of the RI-CLPM: a nondetrended model in which the intercepts of observed variables were constrained to be equal across waves and a detrended model in which the intercepts of observed variables were estimated freely at each wave. Model fit was compared using RMSEAD, with the more parsimonious model (i.e., the nondetrended model) retained only when RMSEAD was below the cutoff of .08. Third, we tested whether the autoregressive and cross-lagged effects between motivational incongruence and distress were stable over time. For each sample, we compared two versions of the RI-CLPM: one in which the autoregressive and cross-lagged effects were constrained to be equal across waves (Figure 1) and one in which these effects were estimated freely across waves. As in the previous comparisons, RMSEAD was used to determine whether the more parsimonious constrained model could be retained.

Main Analyses

To test for prospective effects between motivational incongruence and general psychological distress, we estimated detrended RI-CLPMs separately in the Bern and Zurich trial samples and in the Trier sample. The models for the Bern and Zurich trial samples included four waves; the model for the Trier sample included six waves. The RI-CLPM decomposed each observed score into a random intercept and a residualized wave-specific factor. The random intercepts are time-invariant latent factors that capture stable between-person differences in motivational incongruence and psychological distress. The random intercepts of the two constructs were allowed to correlate. The residualized wave-specific factors capture occasionspecific within-person deviations from a person's expected level at each wave. The autoregressive and cross-lagged effects were estimated among these residualized wave-specific factors. The error terms of the residualized wave-specific factors were allowed to correlate within each wave.

Exploratory Analyses

In exploratory analyses, we used an alternative approach to modeling the trend. Specifically, we estimated the same within-person dynamics using a latent curve model with structured residuals (LCM-SR; Curran et al., 2014). The LCM-SR builds on the RI-CLPM by adding a random linear slope factor for each construct; this slope factor captures between-person differences in the rate of change of motivational incongruence and distress over time. Because the slope, autoregressive, and cross-lagged parameters were all estimated jointly in a single step, the resulting autoregressive and cross-lagged effects reflect the within-person reciprocal effects between motivational incongruence and distress after accounting for between-person differences in each construct's rate of change. As in the main analyses, we compared a version of the LCM-SR in which the autoregressive and cross-lagged effects were constrained to be equal across waves with an unconstrained version. Again, model fit was compared using RMSEAD to determine whether the more parsimonious constrained model could be retained. We report the LCM-SR as an exploratory analysis because it is a demanding model that carries a relatively high risk that the estimation does not converge or does not converge properly.

Discussion

Summary of Findings

The present study aimed to examine prospective within-person effects and betweenperson associations between motivational incongruence and general psychological distress in two randomized trials and one routine-care sample.

Our findings for the primary RI-CLPMs showed that at the within-person level, lower motivational incongruence at one assessment predicted lower general psychological distress at the subsequent assessment across all three samples. Thus, the primary analyses supported the hypothesized (a) within-person association across controlled and routine-care psychotherapy contexts. In contrast, the primary findings on the reverse cross-lagged within-person association, specified in hypothesis (c), were less consistent. Lower psychological distress predicted lower subsequent motivational incongruence in the Zurich sample and Trier sample but not significantly in the Bern sample. Thus, hypothesis (c) was supported in two of the three samples, providing evidence for a reciprocal prospective relationship in these samples.

At the between-person level, the random intercepts were positively associated across all samples, but significantly only in the Zurich sample and Trier sample. This finding indicates that patients who reported generally higher motivational incongruence across treatment also reported MOTIVATIONAL INCONGRUENCE AS A CHANGE MECHANISM 22 higher distress across treatment. Thus, hypothesis (b) was supported in two of three samples. These between-person associations are consistent with previous cross-sectional findings showing substantial associations between motivational incongruence and general psychological distress (Grosse Holtforth & Grawe, 2003; Lutz et al., 2006; Scheidegger et al., 2023; Vincent et al., 2021).

Motivational Incongruence as a Potential Change Mechanism

Previous studies have shown that motivational incongruence is associated with psychological distress and decreases during psychotherapy (Berking et al., 2003; Grosse Holtforth & Grawe, 2003; Lutz et al., 2006; Scheidegger et al., 2023; Vincent et al., 2021). The present findings extend this evidence by demonstrating temporal precedence and prospective within-person associations while separating stable between-person differences. This strengthens the evidence for reduced motivational incongruence as a potential change mechanism. The standardized prospective effects from motivational incongruence to distress were large in all three samples according to the empirical benchmarks proposed by Orth et al. (2024) for crosslagged effects.

The findings also extend the previous cross-lagged investigation of motivational incongruence and mental health (Bachmann et al., 2014). In contrast to their findings, we found a consistent prospective motivational incongruence-to-distress association in psychotherapy samples, using substantially shorter assessment intervals and separating stable between-person differences from within-person fluctuations. This separation strengthens the case for potential causality, because observed or unobserved patient characteristics that remain stable over the study period cannot, by design, confound these within-person associations (Falkenström et al., 2020 (Falkenström et al., , 2026)). Thus, the prospective associations observed in the present study cannot be explained by stable differences between patients that may be associated with both motivational incongruence and psychological distress.

An additional consideration concerns systematic change over treatment, as unmodeled longer-term trends could bias estimated cross-lagged effects (Falkenström et al., 2026). To address this issue, the primary RI-CLPMs freely estimated occasion means to account for sample-level trends, while the exploratory LCM-SRs additionally accounted for between-person differences in linear rates of change. The LCM-SRs yielded no admissible solutions in the Bern and Zurich samples. Consequently, the robustness of the prospective associations after additionally accounting for individual treatment trajectories could not be examined in these samples. In the Trier sample, the motivational incongruence-to-distress effect remained significant, whereas the reverse effect was small and not significant. This provides additional support for the motivational incongruence-to-distress association, although the constrained model's near-boundary solution requires cautious interpretation and robustness could not be established across all three samples. Despite these methodological strengths, the present analyses still do not establish causality, as the proposed mechanism was not experimentally manipulated and time-varying confounding remains possible. Nevertheless, the findings are consistent with a mechanism interpretation and provide comparatively strong observational evidence for the proposed prospective relationship.

Reciprocal Associations

The prospective effects from psychological distress to motivational incongruence in the Zurich and Trier samples are consistent with consistency theory, which assumes that psychological disorders may themselves impair the satisfaction of an individual's motives (Grosse Holtforth & Grawe, 2003). Importantly, such reciprocal effects do not contradict an understanding of reduced motivational incongruence as a potential change mechanism: a mechanism may contribute to subsequent symptom change while also being influenced by prior states of that outcome (Falkenström et al., 2022). Notably, the prospective effects from motivational incongruence to distress (β = .13-.40) were numerically larger than the reverse effects (β = .02-.16) in each sample. Because the bidirectional effects have the same sign, the pattern observed in the Zurich sample and Trier sample is consistent with a reinforcing feedback process, in which lower motivational incongruence may be followed by lower distress, which in turn may contribute to reduced motivational incongruence (Falkenström et al., 2022).

Generalizability Across Psychotherapy Contexts

According to consistency theory, reduced motivational incongruence is assumed to be relevant across psychotherapeutic orientations. Previous studies have shown that motivational incongruence decreases across different treatment settings and patient groups (Berking et al., 2003; Caspar et al., 2023; Lutz et al., 2006; Scheidegger et al., 2023; Vincent et al., 2021). The present study extends this evidence by demonstrating consistent prospective within-person associations between motivational incongruence and subsequent psychological distress across two randomized trials and a routine-care sample that differed in treatment setting and patient population. At the same time, all treatments shared a cognitive-behavioral foundation, although they differed in their therapeutic foci and integrated techniques from different therapeutic orientations. Thus, the present study does not directly test generalizability across clearly distinct therapeutic orientations. Replication across such orientations would provide a stronger test of the proposed transtheoretical relevance of reduced motivational incongruence.

Clinical Implications

The present findings have potential implications for motivational incongruence as a treatment target. The motives assessed by the questionnaire refer to experiences and personenvironment transactions directly relevant to patients' everyday lives. Their bottom-up origin and relatively concrete formulation may make them accessible to patients and therapists across different therapeutic backgrounds and facilitate their incorporation into individualized case formulations and treatment planning.

Motivational incongruence can be considered a potential treatment target at different levels of abstraction or specificity. Depending on the questionnaire version and intended purpose, motivational incongruence may be assessed at the level of overall motivational incongruence, approach and avoidance incongruence, specific motivational dimensions, or individual motives. At each level, reduced motivational incongruence could represent a candidate change mechanism. In this study, we examined only total incongruence. A next step would be to examine which dimensions of motivational incongruence predict subsequent psychological distress, for which patients, and under which circumstances. Further research could then examine which therapeutic processes, including interventions, are associated with reductions in those dimensions.

Identifying such targets also requires considering that findings at the group level may not apply equally to individual patients (Huibers et al., 2021). Prior personalized process-outcome research has aimed to develop and test approaches for estimating the relevance of therapeutic processes for individual patients to inform treatment recommendations (Gómez Penedo et al., 2023; Lutz et al., 2022; Rubel et al., 2020). Applying such approaches to motivational incongruence could help move from a general candidate mechanism toward personalized treatment targets and contribute to data-informed treatment recommendations and clinical decision-support systems (Lutz et al., 2024).

Strengths, Limitations, and Future Directions

The present study has several strengths. The prospective associations between motivational incongruence and psychological distress were examined across three psychotherapy samples, covering both controlled and routine-care treatment contexts. Importantly, the statistical models separated stable between-person differences from within-person fluctuations and estimated the prospective associations in both directions. In addition, systematic change over treatment was accounted for in the main analyses and further addressed in the exploratory analyses.

Despite these strengths, several limitations should be considered. First, while the analytic strategy strengthens the mechanism argument, the analyses do not establish causality, as timevarying factors associated with both motivational incongruence and psychological distress may still confound the observed prospective associations (Falkenström et al., 2020). To more directly test causality, future research would need to identify interventions that reliably reduce motivational incongruence and examine their effects on motivational incongruence and subsequent outcomes in a controlled experimental setting (Kazdin, 2009). Second, the interpretation of cross-lagged associations depends on the time interval between assessments.

The actual lag through which motivational incongruence may influence psychological distress remains unknown, and the available assessment intervals differed across samples. The present findings therefore establish prospective associations at the examined intervals but do not show that the same associations would be observed at shorter or longer intervals (Crits-Christoph & Gibbons, 2021; Falkenström, 2024). The relevant lag may also vary between patients. More intensive longitudinal assessments could help clarify the timescale of these associations. Third, the analyses were based on manifest scale scores, meaning that measurement error was not modeled separately from the within-person fluctuations of interest. Moreover, the more complex LCM-SRs yielded no admissible solutions in the Bern and Zurich samples, limiting our ability to examine the robustness of the findings when additionally accounting for individual time trends. This limitation should be interpreted in light of recent methodological work cautioning that more extensive adjustment for stable or trend-like components in longitudinal panel models is not necessarily preferable in all settings. Such adjustments can reduce some sources of bias, but may also introduce new bias when they absorb variance from dynamic processes, mediators, or posttreatment variation (Bailey et al., 2026; Guo et al., 2025). Fourth, both constructs were assessed by self-report only, and instruments differed across samples. These measurement differences limit direct comparisons of effect sizes across samples.

Conclusion

Across three psychotherapy samples, prospective within-person associations between motivational incongruence and subsequent psychological distress support motivational incongruence as a potential change mechanism in psychotherapy. The prospective relationship may also be partly reciprocal. These findings suggest that motivational incongruence may represent a promising treatment target. Preliminary Analyses

Visual inspection of the wave means suggested systematic downward trends for both motivational incongruence and distress in all three samples (Figure S1). Constraining the means to be equal across waves led to a meaningful loss of fit in each sample (RMSEAD = .200-.386), indicating that trends were present in the data (for details, see the Supplemental Material, Part 3).

Consistent with this, the nondetrended RI-CLPM fit meaningfully worse than the detrended RI-CLPM in all three samples (RMSEAD = .210-.421; Table S2; for details, see the Supplemental Material, Part 4). We therefore used the detrended RI-CLPM in the main analyses. Constraining the autoregressive and cross-lagged effects to be equal over time did not lead to a meaningful loss of fit in any sample (RMSEAD = .000-.077). Both the constrained and the unconstrained model fit the data well (CFI = .98-1.00; RMSEA = .000-.064; Table 2), although RMSEA slightly exceeded .06 for the constrained model in the Bern sample. We therefore used the detrended, constrained RI-CLPM as the primary model for the main analyses reported below.
