Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Abstract

Cognitive bias modification for interpretation directly modifies maladaptive interpretation biases, central to the development and maintenance of obsessivecompulsive disorder. Although it has been examined across a range of disorders, its efficacy for Obsessive-Compulsive Disorder (OCD) has not been synthesized. Methods: A systematic search of Embase, PubMed, and PsycInfo (last search 5 May 2026) identified randomized controlled studies targeted OCD-relevant interpretation biases. The synthesis combines a narrative mapping of design and training parameters, followed by three random-effects meta-analyses for interpretation biases, OCD-relevant beliefs, and OCD symptom severity. Prespecified moderators were training dosage, targeted domain, control condition, and study sample. Risk of bias was assessed with RoB 2 and certainty of evidence with GRADE. The review was preregistered (https://osf.io/n3hbk). Results: Across 19 studies (N = 1,294), single-session designs predominated in analogue samples and multi-session protocols in the few clinical studies. Cognitive bias modification for interpretation showed a large effect on interpretation biases (g = -0.92 [-1.18, -0.65]), a moderate effect on OCD-relevant beliefs (g = -0.40 [-0.57, -0.22]), and a small effect on OCD symptom severity (g = -0.19 [-0.34, -0.04]). General or mixed training protocols outperformed domain-specific protocols, and symptom reductions were larger in clinical than in subclinical samples. All studies raised some concerns on RoB 2, and certainty of evidence ranged from low to moderate. Conclusions: We present empirical evidence that cognitive bias modification for interpretation reliably modifies post-intervention interpretation biases, with moderate transfer to OCDrelevant beliefs and small transfer effects on OCD symptom severity, supporting its potential as an adjunctive intervention. The larger effects observed for broader training protocols and in clinical samples highlight that future trials should prioritize while additionally using outcome measures that are independent of the trained paradigm. Given the few studies per subgroup these findings require replication.

Introduction

Obsessive-compulsive disorder (OCD) is a debilitating mental health condition with a lifetime prevalence of approximately 2-3% and substantial burden across the lifespan. It is characterized by recurrent intrusive thoughts (obsessions) and repetitive behaviors or mental acts (compulsions; American Psychiatric Association, 2013). According to the central cognitive understanding of OCD, the maladaptive interpretation of intrusions may play a central role in the development and maintenance of the disorder (Salkovskis, 1985). These interpretation biases (IBs) are well known in OCD and are considered important mechanisms underlying OCD psychopathology (Clerkin & Teachman, 2011; Hezel & McNally, 2016; Rachman, 1998).

Rather than the widespread and common occurrence of intrusions per se, it is their severe negative interpretation -for example as indicating personal dangerousness, responsibility for harm, or moral reprehensibility -that often fuels maladaptive OCD-relevant beliefs and the downward cycle of distress and compulsive rituals (Rachman, 1998; Radomsky, Alcolado, et al., 2014). The interplay between dysfunctional IBs, OCD-relevant beliefs, and OCD symptom severity is well-documented across the lifespan, with robust empirical support from studies in adults, adolescents, and children (Cervin et al., 2022; Reeves et al., 2010; Wheaton et al., 2010).

Cognitive behavioral therapy (CBT) with exposure and response prevention is considered the gold standard treatment for adults, adolescents, and children with OCD (Cervin et al., 2024; Melin et al., 2020). However, approximately 40-50% of treated individuals do not achieve clinically significant improvement following first-line treatment, with lower response rates among individuals with predominantly obsessive symptoms (Skarphedinsson et al., 2015; Torp et al., 2015), in whom compulsive rituals are mental rather than behavioral. This suggests a specific requirement for interventions targeting IBs and underscores the need for adjunctive interventions targeting the core cognitive mechanisms implicated in OCD.

Cognitive bias modification for interpretation (CBM-I) is an experimental paradigm designed to directly modify maladaptive interpretations (Mathews & Mackintosh, 2000). It involves repeated training in which participants resolve ambiguous scenarios (e.g., an intrusive thought or ambiguous situation) in a benign, non-threatening manner (IB-inconsistent), with the aim of strengthening benign interpretation patterns. CBM-I is a scalable, inherently costeffective digitally delivered intervention that represents a low-risk approach with minimal evidence of adverse effects while offering increasing potential for personalization (Vrijsen et al., 2024). Meta-analyses of CBM-I across various disorders, including depressive and anxiety disorders, have demonstrated consistently large effects on IBs themselves, and small, more variable transfer effects on symptom severity (Fodor et al., 2020; Zhang et al., 2019). Initial findings on CBM-I for OCD are promising, showing consistent reductions in maladaptive OCD-relevant IBs alongside improvements in OCD-relevant beliefs, thus supporting a specific cognitive training mechanism rather than simple habituation or demand effects (Beadel et al., 2014; Clerkin et al., 2014; Clerkin & Teachman, 2011; Williams & Grisham, 2013). Studies examining transfer effects on OCD symptom severity are scarce and their findings are mixed (Cristea et al., 2015; Fodor et al., 2020). While individual studies have suggested that specific design and training parameters, including domain, session dosage, control condition (CC), and study sample (clinical vs. analogue), may influence CBM-I efficacy, systematic investigations of these design moderators are rare (Blackwell et al., 2017; Fodor et al., 2020; Menne-Lothmann et al., 2014).

To the best of our knowledge, no published systematic review or meta-analysis has focused specifically on CBM-I for OCD. Existing meta-analyses have primarily synthesized CBM-I studies for anxiety and depressive disorders (Cristea et al., 2015; Fodor et al., 2020; Jones & Sharpe, 2017; Menne-Lothmann et al., 2014), with OCD addressed only incidentally within broader reviews covering multiple disorders (Zhang et al., 2019). Moreover, the methodological and design features that may moderate treatment effects have rarely been addressed. According to cognitive models of OCD, maladaptive OCD-relevant beliefs are highly relevant factors that contribute to the emergence and maintenance of biased interpretations. As such, examining whether CBM-I modifies these maladaptive belief structures should yield a more stringent and clinically informative test of the cognitive mechanisms underlying the intervention (OCCWG, 1997; Salkovskis, 1985). Measures of OCD-relevant maladaptive beliefs may thus provide an especially informative test of fartransfer effects. The present review therefore synthesizes evidence across all three levels of the cognitive model: IB, OCD-relevant beliefs, and OCD symptom severity.

The aim of this review was twofold. First, we systematically identified and characterized all randomized controlled studies implementing CBM-I in the context of OCD, summarizing key design and training parameters, including paradigm type, targeted cognitive domain, stimulus specificity, training dosage, delivery modality, and CC. Second, we quantitatively synthesized the efficacy of CBM-I across three outcomes-IB, OCD-relevant beliefs, and OCD symptom severity-and examined the extent to which training dosage, targeted domain, type of control condition, and study sample moderated these effects. In view of evidence that transfer effects from computerized cognitive training to real-world measures of OCD symptom severity differ between adolescents and adults (Cristea et al., 2015; Hallion & Ruscio, 2011), we conducted subgroup analyses separately for adult and adolescent clinical samples, as well as subclinical analogue samples. Based on the existing literature, we expected CBM-I to show (a) a robust medium effect on the directly trained IB, (b) a smaller effect on OCD-relevant beliefs, and (c) a small effect on OCD symptom severity. Additionally, we expected that type of control condition, targeted domain, study sample, and training dosage would provide insights into variation in efficacy. By integrating a descriptive methodological synthesis with a quantitative effect size analysis, this review aimed to clarify the boundary conditions under which CBM-I is most effective and identify optimal design parameters for future research and clinical implementation.

Methods

Study Registration and Reporting

The study protocol was preregistered on the Open Science Framework (OSF; https://osf.io/n3hbk/overview). Data and analysis code are available on OSF (https://osf.io/n3hbk/resources). This systematic review and meta-analysis was conducted and reported in accordance with the Preferred Reporting Items for Systematic Reviews and Meta-Analyses guidelines (PRISMA, Page et al., 2021).

Eligibility Criteria

Eligibility was defined using the PICO framework (Population, Intervention, Comparison, Outcome; Richardson et al., 1995). Studies were eligible if they met the following predefined criteria:: Population. Human participants across the lifespan, including children, adolescents, and adults with a clinical diagnosis of OCD, subclinical obsessive-compulsive symptoms, or analogue study samples selected based on elevated OCD-relevant symptomatology.

Intervention. Structured cognitive bias modification for interpretation (CBM-I) specifically designed to target OCD-relevant interpretation biases, including but not limited to domains such as responsibility, perfectionism, contamination, importance and control of thoughts, and thought-action fusion. Comparison. Any clearly defined control condition, including active controls (e.g., psychoeducation), sham or no-contingency training, waitlist controls, or biasinducing conditions. Outcome. Studies were required to provide quantitative pre-and postintervention assessments of at least one of the following: (a) IB, (b) OCD-relevant beliefs, (c) OCD symptom severity. Study design. Randomized controlled studies and experimental studies with random allocation and pre-and post-intervention assessment. Only original peer-reviewed articles published in English were considered.

Search Strategy

To identify eligible studies, we searched three electronic databases: Embase, PubMed, and PsycInfo. Searches were restricted to titles and abstracts of English-language publications, with no restriction on publication year. An initial search was conducted on June 26, 2024, and an updated search was performed on May 5, 2026, following the same procedure. The search strategy combined terms related to three conceptual blocks: (1) obsessive-compulsive disorder (e.g., "OCD," "obsessions," "compulsions"), (2) cognitive bias modification for interpretation (e.g., "CBM-I," "interpretation bias," "ambiguous scenarios," "WSAP"), and (3) OCD-relevant cognitive domains (e.g., "perfectionism," "importance of thoughts," "thought-action fusion").

Search terms were developed collaboratively by all authors in consultation with a university librarian, who conducted the database searches (for the full search string, see Supplementary Material). In addition, backward citation tracking of reference lists of all included articles and forward citation tracking using Google Scholar were conducted to identify further eligible studies (for details see Supplemental Material 1-3).

Study Selection

Duplicate records were identified and removed using Rayyan (Ouzzani et al., 2016) and TERA tools (Forbes et al., 2024) prior to screening. Exclusion of duplicates, title and abstract screening and full-text assessment were partly conducted by two independent reviewers (DT, IS) using the predefined eligibility criteria, with Rayyan used to facilitate the screening process. Interrater reliability was assessed with the random subset of 400 records that were independently double-coded by both raters, yielding excellent agreement (κ = .978). Discrepancies between reviewers were resolved through discussion; where consensus could not be reached, a third senior reviewer (KW, R.L.) was consulted.

Data Extraction

Data extraction was conducted by two independent reviewers (DT, FU); discrepancies were resolved through discussion. A standardized data extraction form was developed and used to extract the following information: study characteristics (first author, publication year, journal, country), study sample characteristics (sample size, age, gender), study design characteristics (type of control, randomization procedure), CBM-I intervention characteristics (type of CBM-I paradigm), specificity of materials (generic vs. OCD-specific), mode of delivery (computerized, app-based, lab-based), number and duration of sessions, outcome measures for pre-, post-, and, if applicable, follow-up assessments (type and format of IB measures, measures for OCD-relevant beliefs and OCD symptom severity), and statistical results (e.g., means, standard deviations, statistical parameters). Specific variables were extracted as important parameters to describe training and study design features for the first part of the results. These variables included: sample demographics (number of participants, mean age, and gender distribution), pre-treatment OCD symptom severity, training dosage (number of treatment sessions), IB/domain (broad or specific focus), type of material (broad/specific/personalized), CC (active or passive), and evaluation of material. For the moderator analysis, domain, dosage, sample, and CC were extracted.

Risk of Bias Assessment

The methodological quality of the included studies was independently evaluated by two reviewers (DT, MM) using the Revised Cochrane Risk of Bias tool (RoB 2; Sterne et al., 2019) for randomized controlled trials (RCTs). Five domains were assessed: (1) randomization process, (2) deviations from intended interventions, (3) missing outcome data, (4) measurement of the outcome, and (5) selection of the reported result. Studies were categorized as having a 'low risk of bias,' 'moderate risk of bias/some concerns,' or 'high risk of bias'. The first and second authors independently conducted the risk of bias assessment for all studies. All study data were double-coded and discrepancies (4.13 %) were resolved through discussion.

Certainty of Evidence.

The certainty of the evidence for each outcome (interpretation bias, OCD-relevant beliefs, and OCD symptom severity) was assessed using the GRADE framework (Guyatt et al., 2011). As all included studies were randomized controlled studies, each body of evidence started at high certainty and was rated down across five domains: risk of bias (based on the RoB 2 judgments), inconsistency (heterogeneity magnitude and overlap of confidence intervals), indirectness (applicability of samples, interventions, and outcome measures to the clinical question), imprecision (width of the confidence and prediction intervals relative to the effect), and publication bias (funnel plot asymmetry and Egger's test).

Statistical Analysis

All meta-analytic computations were performed using the meta package (Version 8.0.2; Balduzzi et al., 2019) in R (Version 4.4.2; R Core Team, 2024) using RStudio (Version 2024.12.0+467; Posit Team, 2024). Effect sizes were expressed as Hedges' g, a bias-corrected standardized mean difference that is preferred over Cohen's d in the case of small sample sizes (Hedges et al., 2009).

Effect sizes were calculated using one of three approaches, depending on the available data. (A) Where pre-and post-intervention means and standard deviations were reported for both the CBM-I and control conditions (CC), Hedges' g was calculated as the standardized prepost change within each group, with the between-condition difference in change standardized by the pooled pretest standard deviation (Borenstein et al., 2009; Morris, 2008); a pre-post correlation of r = 0.5 was assumed and its robustness evaluated (Hedges et al., 2009). (B) Where only post-intervention data were available, Hedges' g was calculated as the difference between the post-intervention mean scores of the CBM-I and CC, divided by the pooled post-test standard deviation (Lakens, 2013). (C) Where neither option was possible, Hedges' g was estimated from available test statistics (e.g., t-values, F-values, and p-values) using standard conversion formulas (Hedges et al., 2009). Both estimators standardize the treatment-control contrast using a single-time-point between-person standard deviation and target the same parameter under the assumption of variance homogeneity (Morris, 2008). Negative values of Hedges' g indicate a reduction in IB, OCD-relevant beliefs, or OCD symptom severity in favor of the CBM-I condition (see Table S1 for full details).

Follow-up effect sizes (pre-to-follow-up comparisons) were computed with the same three approaches as the post-intervention estimates, depending on the data available for each study (A: Standardized change within each group from pre-and follow-up means and standard deviations; B: difference between the follow-up mean scores; C: estimated from available test statistics; see above). For each study, a delta was then calculated as the difference between the follow-up and post-intervention effect size (Δ = g_FU -g_Post), with positive values indicating an attenuation of the effect over time (i.e., an increase in interpretation bias, OCD-relevant beliefs, or OCD symptom severity relative to post-intervention)

Given the expected heterogeneity in study samples, training paradigms, outcome measures, and control conditions across the included studies, random-effects models were employed for all primary analyses. Between-study variance (τ²) was estimated using the restricted maximum likelihood (REML) method (Viechtbauer, 2005), with 95% confidence intervals derived using the Q-profile method. The 95% confidence intervals for all effect sizes are reported in square brackets. To ensure robust and conservative inference (small number of included studies, underestimating the uncertainty around pooled effect size estimates), the Hartung-Knapp (HK) adjustment was applied to all pooled effect size estimates (Hartung & Knapp, 2001; Hedges et al., 2009).

Statistical heterogeneity was assessed using Cochran's Q statistic and the I² index.

Following established conventions, I² values of 25%, 50%, and 75% were interpreted as low, moderate, and high heterogeneity, respectively (Higgins et al., 2003). A prediction interval was additionally computed to reflect the expected range of true effects in a hypothetical future study drawn from the same population of studies, providing a more informative estimate of betweenstudy variability than I² alone (IntHout et al., 2016).

To examine potential sources of heterogeneity, univariate meta-regressions were conducted separately for each prespecified moderator, including targeted domain, sample type (clinical vs. subclinical/analogue), training dosage (number of sessions), and type of control condition. Univariate rather than multivariate models were employed because the limited number of primary studies precluded reliable estimation of multivariate models and risked overfitting (Borenstein et al., 2009). Categorical moderators were examined using mixedeffects subgroup analyses and continuous moderators using random-effects meta-regression. To assess the potential impact of publication bias on pooled estimates, funnel plot asymmetry was visually inspected. Egger's regression test was applied as a formal statistical test of asymmetry (Egger et al., 1997) if k ≥ 10 studies were available for the respective analysis.

Results

Study Selection

A total of 3,321 records were identified, of which 3,264 originated from the database searches (Embase: k = 984; PubMed: k = 1,238; PsycInfo: k = 1,042) and 57 from backwards citation searching. After the removal of 2,175 duplicates, the remaining 1,146 records underwent title and abstract screening, leading to the exclusion of 1,110 records. The most common reasons for exclusion were that studies were not CBM studies (k = 631) or were not related to OCD (k = 301). Further records were excluded as they were unsuitable publication types (abstract, book, letter, or preregistration; k = 74), were not published in English (k = 54), did not have accessible abstracts (k = 15), or failed to meet the following other PICO criteria (k = 35): no pre-and/or post-intervention data reported (k = 7), non-randomized design (k = 5), no measurement of any target outcomes (k = 14), and no CC (k = 9). The remaining 36 full-text articles were assessed for eligibility, leading to the exclusion of 17 studies: mixed interventions without pure CBM-I training (k = 4), crossover or single-case designs or validation studies (k = 6), a reanalysis of an already existing dataset (k = 5), and causality studies with IB-consistent training (k = 2). Ultimately, 19 studies were included in the descriptive review and quantitative analysis.

Characteristics of Included Studies

Studies were distributed across adult clinical (k = 2), adolescent clinical (k = 3), and subclinical/ analogue samples (k = 14). Sample sizes ranged from n = 16 to n = 137, with a pooled total of N = 1,294 participants. The proportion of female participants ranged from 54% to 82% and the mean age ranged from approximately 11.2 to 38.3 years (see Table 1 for full details).

CBM-I paradigms.

All studies employed a computerized CBM-I intervention. The Ambiguous Scenarios Task (AST; Mathews & Mackintosh, 2000) was the predominant paradigm (k = 16).

In the AST, participants read or listen to scenario vignettes with ambiguous endings. By completing a word fragment (i.e., a word with missing letters), they resolve each scenario in an IB-consistent or IB-inconsistent manner. Two studies employed thought-action fusion (TAF)incongruent training (Siwiec et al., 2023; Siwiec et al., 2017) and one study used the Word-Sentence Association Paradigm (WSAP; Conley & Wu, 2018), which primes words with sentences and requires participants to judge whether a threatening or benign word is related to a preceding ambiguous sentence.

Targeted domain.

The majority of studies targeted the general OCD domain without a specific domain focus (k = 8), followed by contamination (k = 3), responsibility and checking (k = 3), importance and control of thoughts (ICT; k = 2), TAF (k = 2), and perfectionism (k = 1).

Stimulus specificity.

Ten studies applied standardized domain-specific materials with symptomcongruent recruitment, seven used a standardized broad-domain approach covering heterogeneous OCD themes irrespective of individual symptom presentation, and two employed a tailored symptom-matched design in which scenario subsets were selected to match each participant's primary symptom dimension (Beadel et al., 2016; Wolters et al., 2021).

Material development and validation.

The development of training materials showed considerable methodological continuity across studies, with two scenario sets serving as dominant benchmarks (Clerkin & Teachman, 2011; Mathews & Mackintosh, 2000). Six studies directly or indirectly adapted the training materials developed by Clerkin & Teachman (2011; Beadel et al., 2014; Clerkin & Teachman, 2011; Falkenstein et al., 2022; Salemink et al., 2015; Stech & Grisham, 2017; Wolters et al., 2021), five studies drew directly or indirectly on the scenarios developed by Mathews & Mackintosh (2000; Beadel et al., 2016; Black & Grisham, 2018; Grisham et al., 2014; Wong et al., 2021 Wong et al., , 2022)), and two studies reported both as source materials (Black & Grisham, 2016; Derin & Yorulmaz, 2023). Three additional studies developed materials directly from domains identified by the Obsessive Compulsive Cognitions Working Group (OCCWG) or assessed by the Obsessive Beliefs Questionnaire (OBQ), without reference to either benchmark set (Clerkin et al., 2014; Nasiry et al., 2020; Williams & Grisham, 2013), and three drew on alternative established paradigms (WSAP and TAF; Conley & Wu, 2018; Siwiec et al., 2017 Siwiec et al., , 2023)). Three studies were classified indirectly via their source materials (Wolters et al., 2021 , based on Salemink et al., 2015; Wong et al., 2021 , based onBlack & Grisham, 2018; Wong et al., 2022 , based on Beadel et al., 2016).

Eight studies conducted their own pilot testing or empirical validation, four relied on validation reported in previous studies without conducting further empirical testing, and the remaining seven studies did not report explicit information on pilot testing or validation.

Number of sessions.

Training dosage varied substantially, with the number of sessions ranging from 1 to 12 and the number of trials per session ranging from approximately 34 to 100. Singlesession designs predominated in analogue samples (k = 11 out of 14 studies), while clinical studies employed multi-session protocols with at least four sessions (k = 2 used four sessions, k = 2 used eight sessions, and k = 1 used 12 sessions).

Control condition.

All studies included a clearly specified CC, predominantly an active CC (k = 17), with only k = 2 using a passive CC (both waitlist controls, WLC). Two studies compared the CBM-I with two control conditions (Siwiec et al., 2023: stress management training and congruent training; Beadel et al., 2016: height fear content and a sham control condition; the first-named condition was used for the present comparison). Furthermore, the most common active CC was a no-contingency (k = 7), exposing participants to the same scenarios without systematic training directions (50 % IB-inconsistent and 50 % IB-consistent). Six studies used a neutral-content (e.g. height fear content, stress management training, psychoeducation control), two used an inverse training condition, and two used a WLC.

Follow-up measurement. Follow-up assessments were included in a subset of studies and for a subset of variables, with k = 3 for IB, k = 5 for OCD-relevant beliefs, and k = 5 for OCD symptom severity (after excluding the study by Derin & Yorulmaz, 2023) for this outcome; see outlier identification section below). Follow-up intervals ranged from one to four weeks (see Table S3 for further details).

Outcome measures. The majority of studies assessed IB using the Recognition Task or similar paradigms, yielding the Target Bias Index as the primary outcome (positive minus negative interpretation similarity ratings; higher scores indicate less maladaptive bias; e.g., Beadel et al., 2014). One study used threat-endorsement rates (Conley & Wu, 2018). OCD-relevant beliefs were primarily assessed using the OBQ (OCCWG, 2005), its child version (OBQ-CV; Coles et al., 2010), or domain-specific subscale versions (e.g., ICT, perfectionism). TAF-focused studies used the Thought-Action Fusion Scale (TAFS; Shafran et al., 1996). Two studies used construct-specific measures aligned with their targeted domains: the Responsibility Attitudes Scale (RAS; Salkovskis et al., 2000) and the Contamination Sensitivity Scale (CSS; Radomsky, Rachman, et al., 2014). OCD symptom severity was most commonly assessed using the Obsessive-Compulsive Inventory-Revised (OCI-R; Foa et al., 2002), its child version (OCI-CV; Foa et al., 2010), or the Padua Inventory-Washington State University Revision (PI-WSUR; Burns et al., 1996), including its contamination and checking subscales. Clinical studies used clinician-or interview-based measures, namely the Yale-Brown Obsessive Compulsive Scale (Y-BOCS; Goodman et al., 1989) and its child version (CY-BOCS; Scahill et al., 1997).

Further measures included the Dimensional Obsessive-Compulsive Scale (DOCS; Abramowitz et al., 2010), the Contamination subscale from the Vancouver Obsessional Compulsive Inventory (VOCI-CTN; Thordarson et al., 2004), and the distress scale from the Revised Obsessional Intrusions Inventory (ROII-Distress; Purdon & Clark, 1993).

Risk of Bias

All 19 included studies were rated across the five RoB 2 domains (Sterne et al., 2019; see Table S2 for full RoB 2 results). The randomization process (D1) was the strongest domain, with all studies rated as low risk. Bias arising from deviations from intended interventions (D2) was rated as low risk in seven studies (Beadel et al., 2014; Derin & Yorulmaz, 2023; Falkenstein et al., 2022; Siwiec et al., 2023; Stech & Grisham, 2017; Wong et al., 2021 Wong et al., , 2022)), whereas the remaining twelve studies raised some concerns, most frequently because intention-to-treat principles were not applied. For missing outcome data (D3), 15 studies were judged as low risk and four raised some concerns (Conley & Wu, 2018; Nasiry et al., 2020; Salemink et al., 2015; S. Siwiec et al., 2023) due to exclusions, high attrition, or loss to follow-up. The principal source of bias was measurement of the outcome (D4), for which no study was rated as low risk because all relied on self-report measures of interpretation bias, OCD-relevant beliefs, or OCD symptom severity, and blinding of outcome assessment was frequently unclear. A similar pattern emerged for selection of the reported result (D5), for which only three studies were rated as low risk (Derin & Yorulmaz, 2023; Falkenstein et al., 2022; Salemink et al., 2015), typically because a preregistered protocol was available; the remaining studies raised some concerns due to the absence of preregistration. Consequently, all studies received an overall rating of some concerns and no study was rated as showing a high risk of bias. This uniformity precluded the use of risk-of-bias ratings as a moderator or as the basis for sensitivity analyses. The overall judgments were driven primarily by the outcomemeasurement and selective reporting domains, whereas randomization and, to a lesser extent, adherence to intended interventions were generally handled well (see Figure 2). It should be noted that the stringency of the RoB 2 criteria (Sterne et al., 2019) led to a categorization of 'some concerns' for most studies, primarily due to absent preregistration, and reliance on selfreport outcomes. The latter precludes outcome-assessor blinding, as participants completed the outcome assessments themselves.

Quantitative Analysis

Outlier Identification and Publication Bias

Publication bias was assessed for all three primary outcomes using Egger's regression test (Egger et al., 1997) and visual inspection of funnel plots (see Figure 3). Egger's test indicated no significant funnel plot asymmetry for IB (t(14) = -0.91, p = .376) or OCD-relevant beliefs (t(12) = -0.85, p = .413), but did indicate asymmetry for OCD symptom severity (t(13) = -2.31, p = .04), providing statistical evidence of a publication bias in one of the three outcome domains, most likely attributable to a single study that was excluded as an outlier (see Figure 3). Outliers were identified through inspection of the corresponding funnel plot and using the confidence-interval criterion proposed by Harrer et al. (2021), according to which a study is classified as an outlier if its 95% confidence interval does not overlap with that of the pooled effect. Applying this criterion, the study by Derin & Yorulmaz (2023) was identified as a statistical outlier for OCD symptom severity (g = -2.05 [-2.81, -1.28] vs. pooled g = -0.34 [-0.60, -0.08]) and was therefore excluded from all analyses of this outcome. No outliers were identified for IB or OCD-relevant beliefs. A subsequent analysis of OCD symptom severity conducted after exclusion of this study showed no further evidence of asymmetry (t(12) = -1.68, p = .118). Note. Efficacy of CBM-I for Interpretation Bias

A total of k = 16 studies providing effect size data were included in the primary meta-analysis of CBM-I efficacy for IB (see Table S1 for details). The pooled random-effects estimate indicated a large effect of CBM-I on IB, which differed significantly from zero (g = -0.92 [-1.18, -0.65], t(15) = -7.29, p < .001), with negative values indicating a greater reduction in maladaptive IB in the CBM-I relative to the CC (see Figure 4). The pooled random-effects estimate indicated a moderate effect of CBM-I on IB both for the adult clinical sample (g = -0.66 [-1.21, -0.11]) and for the adolescent clinical sample (g = -0.75 [-1.32, -0.17]). Across all studies, individual effect sizes ranged from g = 0.00 (Salemink et al., 2015) to g = -1.84 (Conley & Wu, 2018), with the large majority of effects in the hypothesized direction. Three studies yielded effect sizes that did not differ significantly from zero: Salemink et al. (2015; g = 0.00 [-0.99, 0.99]), Black & Grisham (2018; g = -0.34 [-1.06, 0.39]), and Black & Grisham (2016; g = -0.33 [-0.67, 0.01]). The prediction interval ranged from g = -1.83 to g = -0.01, suggesting that a reduction in maladaptive IB would be expected across virtually all similar future study contexts, although the width of the interval reflects the substantial between-study variability observed in this literature. Heterogeneity was high, I² = 71.0% [51.8%, 82.5%], Q(15) = 51.68, p < .001, τ² = 0.17.

Efficacy of CBM-I for OCD-Relevant Beliefs

A total of k = 14 studies providing effect size data were included in the meta-analysis of CBM-I efficacy for OCD-relevant beliefs (see Table S1 for details). The pooled random-effects estimate indicated a moderate effect of CBM-I on OCD-relevant beliefs (g = -0.40 [-0.57; -0.22], t(13) = -4.88, p < .001), with negative values indicating a greater reduction in maladaptive OCD-relevant beliefs in the CBM-I relative to the control condition. The pooled random-effects estimate indicated a small effect of CBM-I on OCD-relevant beliefs for the adult clinical sample (g = -0.14 [-0.54; 0.27] and a moderate effect for the adolescent clinical sample (g = -0.68 [-3.66; 2.30]). Individual study effect sizes ranged from g = -0.01 (Wong et al., 2022) to g = -1.03 (Siwiec et al., 2023), with all effects in the hypothesized direction, although the majority did not reach statistical significance at the individual study level. The prediction interval ranged from g = -0.73 to g = -0.06, indicating that a reduction in maladaptive OCD-relevant beliefs would be expected in virtually all similar future study contexts, although effects may be small in some settings. Heterogeneity was low and not statistically significant, I² = 23.3% [0.0%, 59.2%], Q(13) = 16.95, p = .202, τ² = 0.02, suggesting that the observed dispersion of effects was largely consistent with sampling error.

Efficacy of CBM-I for OCD Symptom Severity

A total of k = 14 studies providing effect size data were included in the meta-analysis of CBM-I efficacy for OCD symptom severity (see Table S1 for details). The pooled random-effects estimate indicated a small effect of CBM-I on OCD symptom severity (g = -0.19 [-0.34, -0.04], t(13) = -2.78, p = .016), with negative values indicating a greater reduction in OCD symptom severity in the CBM-I relative to the CC. Individual study effect sizes ranged from g = 0.20 (Grisham et al., 2014) to g = -1.03 (Siwiec et al., 2023). Two studies yielded positive effect sizes in the non-hypothesized direction - Grisham et al. (2014; g = 0.20 [-0.20, 0.61]) and Wong et al. (2021; g = 0.10 [-0.32, 0.52]) -though neither differed significantly from zero. Most remaining studies yielded effect sizes clustered around zero. The prediction interval ranged from g = -0.45 to g = 0.07, indicating that although the pooled effect was statistically significant, the true effect in virtually all similar future study contexts could range from a moderate reduction to a small increase in OCD symptom severity. Heterogeneity for OCD symptom severity was negligible and not statistically significant (I² = 3.0% [0.0%, 56.4%], Q(13) = 13.41, p = .417, τ² = 0.01).

Follow-Up Efficacy of CBM-I

Follow-up data were only available for a subset of studies (IB: k = 3; OCD-relevant beliefs: k = 5; OCD symptom severity: k = 5 after excluding the identified outlier; see Table S3 for further details). Given this small and heterogeneous evidence base, the results of the pooled follow-up meta-analyses should be interpreted with caution. For IB (k = 3), the pooled follow-up effect was small to moderate but non-significant (g = -0.58 [-1.81, 0.65], p = .180, I² = 57.0%, τ² = 0.131) and the mean post-to-follow-up change was positive (mean Δ IB = 0.52), consistent with a gradual attenuation of the training effect over time, For OCD-relevant beliefs (k = 5), the pooled effect remained moderate and statistically significant (g = -0.89 [-1.72, -0.06], p = .041, I² = 88.2%, τ² = 0.396), an a mean post-to-follow-up change was negligible (Δ B = 0.05), indicating that effects on OCD-relevant beliefs were essentially maintained from postintervention to follow-up. For OCD symptom severity (k = 5), the pooled effect was small and non-significant (g = -0.34 [-0.78, 0.09], p = .094), and mean post-to-follow-up change was small and negative (mean Δ S = -0.12), suggesting that symptom-level improvements were, on average, retained rather than lost at follow-up (see Table S4 for further details).

Subgroup and Meta Regression Analyses

Four univariate moderator analyses were conducted for each outcome, examining type of control condition, targeted domain, sample, and training dosage. All results reported below refer to Hartung-Knapp-adjusted random-effects models.

Targeted domain moderated all three outcomes (all Qs ≥ 18.51, p ≤ .001).

General/mixed training produced the largest and most consistent effects, whereas domainspecific training was weaker (e.g., responsibility-and contamination-focused training) transferred weakly to beliefs and symptoms. TAF training was an exception, with a moderateto-large effect on beliefs (g = -0.70) but only a small effect on symptoms (g = -0.31). Given several subgroups of only one or two studies, these comparisons remain exploratory (see Table S5 for full details). Sample type did not moderate effects on IB or OCD-relevant beliefs (all Q(1) ≤ 0.86, p ≥ .354). For OCD symptom severity, however, sample type emerged as a significant moderator (Q(1) = 6.18, p = .013), with larger reductions in clinical samples (g = -0.45 [-0.75, -0.15]) than in subclinical samples (g = -0.12 [-0.29, 0.05]; see Table S6 for further details).

Type of CC moderated effects on IB, with the largest effects observed relative to nocontingency conditions (g = -1.15 [-1.60, -0.69]) and smaller effects relative to neutral-content conditions (g = -0.63 [-1.00, -0.26]). Type of CC did not moderate effects on OCD-relevant beliefs or OCD symptom severity (all Q ≤ 2.75, p ≥ .431; see Table S7 for further details).

Training dosage (number of sessions) was not significantly related to IB or OCDrelevant beliefs (b ≤ -0.04, Fs ≤ 1.12, ps ≥ .311, R² = 26.3%). For OCD symptom severity, the association the association was just below the usual level of significance (b = -0.04, F(1, 12) = 3.69, p = .079, R² = 81.0%; see Table S8 for further details), suggesting that higher dosage may be associated with larger reductions in OCD symptom severity.

Sensitivity Analyses

The Robustness of the primary findings was examined through five sets of sensitivity analyses.

First, within a leave-one-out sensitivity analysis effects remained significant in every iteration and varied only marginally (all p < .05; see Table S9 for further details). Second, influence diagnostics (Viechtbauer & Cheung, 2010) identified no study as an influential study for any outcome (see Table S10 for further details). Third, replacing the REML estimator of τ² with the Paule-Mandel estimaor produced virtually identical results across all three outcomes (all p ≤ .018; see Table S10 for further details). Fourth, the influence of pre-/post-training correlation (assumed to be r = .50 in previous analyses) was examined with varying correlations (Borenstein et al., 2009). Pooled estimates remained stable and significant (see Table S11 for all details). Fifth, when checking for effect size calculation approach was sensitive, findings were most robust for IB and least robust for symptom severity (see Table S12 for detailed results). Across all sensitivity analyses, the direction, magnitude, and statistical significance of the primary findings were maintained.

Certainty of Evidence

Certainty was rated moderate for interpretation bias (downgraded for inconsistency and indirectness, as most studies measured the bias with a variant of the trained task), low for OCDrelevant beliefs (downgraded for risk of bias and indirectness), and low for OCD symptom severity (downgraded for risk of bias, imprecision, and possible publication bias). Domainlevel judgments are reported in Table S13.

Discussion

This systematic review and meta-analysis provide the first comprehensive synthesis of CBM-I efficacy specifically in the context of OCD, examining effects across three theoretically distinct outcomes: IB, OCD-relevant beliefs, and OCD symptom severity. Overall, the findings demonstrate that CBM-I reliably modifies its primary target, IB, with a large pooled effect and exerts significant, albeit smaller, transfer effects on OCD-relevant beliefs and OCD symptom severity. These results are consistent with the cognitive model of OCD (Salkovskis, 1985), which posits a hierarchical relationship between maladaptive OCD-relevant beliefs, IB, and OCD symptom severity, and extend previous meta-analytic findings from the related anxiety and depression literature (Jones & Sharpe, 2017; Menne-Lothmann et al., 2014) specifically to OCD. Follow-up data allowed for a preliminary assessment of durability: The effect on IB was smaller and no longer significant, although this was based on only three studies. Effects on OCD-relevant beliefs remained moderate and statistically significant, suggesting comparatively more stable maintenance at this level. For symptom severity, the point estimate remained comparable to post-intervention, but was no longer significant, again with a wider confidence interval reflecting the small number of studies rather than a clear loss of effect. Taken together, these findings are consistent with maintained effects across outcomes but cannot be used to establish durability given the very small number of follow-up studies.

The large and robust effect on IB replicates and extends findings from the broader CBM-I literature, confirming that the training paradigm successfully shifts OCD-relevant interpretations towards more benign appraisals. The effect was maintained across study samples and remained stable in sensitivity analyses, including leave-one-out analyses and influence diagnostics. Its prediction interval excluded zero (g = -1.83 to -0.01), indicating that a reduction in maladaptive IB would be expected in virtually all similar future study contexts, although the width of this interval reflects considerable variability in the magnitude of true effects. Heterogeneity was substantial and remained largely unexplained by the examined moderators, pointing to the likely importance of factors not captured in the current analysis.

The moderate effect on OCD-relevant beliefs and the small effect on OCD symptom severity indicate that the effects of CBM-I extend meaningfully beyond the trained paradigm, consistent with a genuine modification of the underlying cognitive mechanisms rather than mere task habituation. The prediction interval for OCD-relevant beliefs, also excluded zero, suggesting that meaningful reductions can be expected across contexts. For OCD symptom severity, the prediction interval marginally crossed zero, likely reflecting the limited number of available studies rather than genuine between-study variability. This pattern is consistent with the broader CBM-I literature, in which transfer to clinical outcomes is consistently smaller than effects on the directly trained bias (Cristea et al., 2015; Hallion & Ruscio, 2011). The degree of between-study heterogeneity available to be explained also differed markedly across outcomes, with substantial heterogeneity for IB, low heterogeneity for OCD-relevant beliefs, and negligible heterogeneity for OCD symptom severity. For the latter two outcomes, little between-study variance remained for moderators to explain, rendering these moderator findings largely exploratory.

The finding that almost all studies successfully modified IB, while transfers to OCD symptom severity or behavior were frequently small or even absent (e.g., Beadel et al., 2016; Black & Grisham, 2018; Conley & Wu, 2018), raises important questions about the causal pathway assumed by cognitive models of OCD. One possibility is that the modification of IB, as currently operationalized, does not reach the necessary threshold to produce a downstream change in OCD symptom severity. Alternatively, the predominantly single-session designs and analogue study samples that characterize much of this literature may be insufficient to produce clinically meaningful effects. Two findings support the latter interpretation. First, sample type moderated OCD symptom severity, with clinical samples showing substantially larger reductions than subclinical or analogue samples, which is precisely the pattern to be expected if OCD symptom severity change requires elevated baseline symptomatology. Second, a trendlevel association between training dosage and OCD symptom severity suggests that higherdosage protocols may yield more robust OCD symptom severity reductions, a pattern echoed by descriptive findings from multi-session clinical studies (Falkenstein et al., 2022; Salemink et al., 2015; Wolters et al., 2021).

The descriptive synthesis further revealed considerable methodological homogeneity across the field. Single-session designs predominated in analogue samples, whereas the few clinical studies consistently used multi-session protocols. Most studies relied on the AST and drew their materials from one of two benchmark scenario sets, and nearly half did not report independent pilot testing or validation of stimuli. This convergence has facilitated cumulative research, but it has also propagated shared limitations across the literature, such as unvalidated materials, reliance on self-report, a narrow range of control conditions, and the frequent use of an outcome measure that is structurally almost identical to the training task. These limitations underscore the value of validated stimulus sets, structurally independent outcome measures, and greater methodological diversity in future work.

Several methodological parameters emerged as relevant to CBM-I efficacy. Regarding control condition, for IB, effects were substantially larger relative to no-contingency controls than relative to neutral or placebo conditions. This suggests that neutral-content control tasks may themselves produce some benign shift in interpretations, thereby attenuating the apparent training effect. Future studies should therefore prioritize active no-contingency controls to isolate the specific contribution of the training contingency (Blackwell et al., 2017). Targeted cognitive domain moderated all three outcomes and revealed a theoretically meaningful pattern: General or mixed training protocols consistently outperformed domain-specific training, whereas contamination-focused training showed near-zero effects on OCD-relevant beliefs, and only general/mixed training was associated with significant symptom reductions. This suggests limited generalization from narrow stimulus sets to broader OCD-relevant belief structures and overall symptomatology. However, because several domain subgroups comprised only one to three studies, these comparisons remain exploratory. Personalized or idiographic materials may improve transfer effects (Beadel et al., 2016; Vrijsen et al., 2024; Wolters et al., 2021).

The present findings support CBM-I as a promising adjunctive or mechanistic tool in OCD treatment rather than as a well-established standalone intervention. The smaller but significant transfer effects on OCD-relevant beliefs and OCD symptom severity provide preliminary support for its clinical utility as an add-on to treatment as usual, particularly in multi-session formats targeting individuals with elevated OCD symptomatology or a clinical diagnosis (Falkenstein et al., 2022; Salemink et al., 2015). Its practical advantages-low cost, remote delivery, minimal side effects, and scalability-make it an attractive complement to first-line CBT-based treatments, particularly for patients who are on waiting lists, have limited access to specialist care, or show insufficient response to standard treatment.

However, all studies received an overall bias rating of 'some concerns', precluding the use of risk-of-bias ratings as a moderator or sensitivity criterion. Two domains drove this overall judgment: Outcome measurement raised concerns in all studies because all relied on self-reports and blinding was frequently unclear. As CBM-I is a transparent intervention, demand characteristics cannot be ruled out -a concern that is particularly pronounced for symptom outcomes, which are furthest removed from the trained process and closest to participants' beliefs about whether the training should have helped. Selection of the reported result raised concerns in all but three studies, reflecting the near absence of preregistration. The transfer effects reported here may therefore be somewhat inflated, and preregistration, together with blinded or behavioral outcome measures, should become standard practice in future trials.

GRADE certainty was highest for the direct effect on interpretation bias and lower for the transfer effects on OCD-relevant beliefs and symptom severity, reflecting the reliance on selfreport outcomes and the scarcity of clinical trials. The conclusion that CBM-I meaningfully reduces clinical symptoms should therefore be regarded as preliminary until confirmed by adequately powered, preregistered trials in clinical samples.

Important limitations should be mentioned. First, the number of clinical studies remains small (k ≤ 5 for clinical subgroups), limiting precision. Second, the large effect on IB may partly reflect task-specific learning, as most studies assessed IB using a variant of the trained paradigm (typically the Recognition Task). Structurally independent measures such as the Scrambled Sentences Task, or ecological momentary assessment, may yield smaller but more robust effects and would provide more stringent tests of far transfer. Third, the substantial unexplained heterogeneity in IB limits the interpretability of the pooled estimate and suggests unexamined moderators such as baseline bias severity or stimulus specificity. Conversely, the low heterogeneity for OCD-relevant beliefs and OCD symptom severity meant that little variance was available for the moderator analyses to explain. Additionally, because the twelve moderator tests were conducted without correction for multiple comparisons, the subgroup differences remain exploratory and require replication in future research with larger subgroups. Fourth, the small number of follow-up studies and the heterogeneous assessment intervals limits conclusions about durability, with non-significant post-to-follow-up differences more likely reflecting insufficient power rather than genuine stability. Future research should therefore employ standardized follow-up intervals and adequately powered designs to address this gap. Finally, publication bias cannot be fully excluded despite non-significant Egger's tests, which have limited power when the number of studies is small.

Despite these limitations, the present review and meta-analysis, taken together, offers important strengths. To our knowledge, this is the first meta-analysis to synthesize CBM-I effects in OCD across three hierarchically ordered outcome levels: IB, associated OCD-relevant belief structures, and clinical symptoms. Effect sizes were calculated from primary data using a uniform procedure. Analyses employed random-effects models with the Hartung-Knapp adjustment, which provides more accurate coverage when the number of studies is small, and included prediction intervals. Robustness was examined systematically rather than through post hoc exclusions: The primary findings remained unchanged across leave-one-out analyses, influence diagnostics, application of an a priori outlier criterion, use of an alternative τ² estimator, and variation of the assumed pre-post correlation. In line with open-science principles, the dataset and all analysis scripts are openly available on the Open Science Framework, allowing full reproduction of the reported analyses and reuse in future syntheses.
