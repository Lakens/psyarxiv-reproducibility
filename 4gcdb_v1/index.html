How Ethics Approval Check works

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

Human research committee names - Institutional Review Board / IRB (US standard) - Independent Ethics Committee / IEC (ICH-GCP international clinical trial term) - Ethical/Ethics Review Board (generic) - Ethics (Advisory/Review) Committee/Board/Panel/Sub-committee - Research Ethics Committee/Board/Panel (UK/Canada/Australia) - Medical Ethics Committee - Human Subjects/Research Committee / Human Research Ethics (Advisory) Panel - Committee for/on the Protection of Human Subjects - Committee on (Health) Research Ethics - Office of Research Ethics - Abbreviations: IEC, REC, REB, ERB, METC, DEC. REC/REB/ERB/DEC are short enough to collide with unrelated jargon (e.g. REC as a recognition-heuristic model abbreviation, DEC as a decision-task label, Reb as an author surname), so these four require an ethics/approval/committee/board/panel/institutional/ protocol word within ~30 characters in the same sentence. IRB and IEC are kept unconstrained as they are not observed to collide in practice. - Dutch: Medisch-ethische toetsingscommissie (METC) - French: Comité d'éthique / Comité d'Ethique

Animal research committee names - Institutional Animal Care and Use Committee / IACUC (US standard) - Any sentence containing animal(s) and committee (or board/panel) within ~5 words of each other — catches Experimental Animal Care and Use Committee, Animal Ethics Committee, Animal Welfare Board, Animal Welfare Ethical Review Body, etc. - UK: Animal Welfare Ethical Review Body / AWERB - Dutch: Dierexperimentencommissie / DEC (see DEC constraint above); Instantie voor Dierenwelzijn / IvD - German: Tierversuchskommission / TvK (advisory committee under §15 Tierschutzgesetz) - French: Comité d'éthique en expérimentation animale / CEEA; Comité d'éthique animale - Spanish: Comité de ética en experimentación animal / CEEA

Approval phrasing - Ethics/Ethical (approval|clearance) [was] (granted|obtained|received|given|secured) - Ethically approved - Approved by the (ethics|irb|institutional|independent|local|review|research) ... - This/The study/protocol/experiment/procedures/methods/research [was] (approved|reviewed) by - Study was ethically approved - (Followed|met|follow) the ethical (guidelines|standards|requirements) - In accordance with ... ethical (guidelines|standards) - Ethics protocol - Approved under (protocol|reference|number)

Waiver / exemption - Ethics/Ethical (waiver|exemption) - IRB (waiver|exemption|exempt) - Exempted from (ethics|irb|institutional review) - Waived by the (ethics|irb|institutional|review) (committee|board) - Deemed exempt

Declaration of Helsinki - Declaration of Helsinki / Helsinki Declaration

Patterns are NOT designed to capture: - General ethical considerations or ethical dilemmas in study content - Mentions of “ethics” in theoretical or philosophical contexts - Author approval of a manuscript (e.g. “all authors approved the final version”) - Ethical behaviour as a measured variable (e.g. “ethical decision-making”) - URLs containing “ethics” in path components

Papers without any live-data signal are not flagged as missing ethics approval. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

In hybrid search tasks, observers search for any of multiple targets held in memory (e.g., finding all of the ingredients for a recipe in the supermarket). Performance declines with the log of the number of memorized targets, a cost often attributed to a serial scan through memory. In standard models of recognition memory, however, holding more items in memory weakens the match strength between each memory representation and the corresponding visual itemindependent of any serial search process. Here we propose an account of hybrid search based on memory strength, testing how memory strength affects hybrid search separately from memory set size. We found that strengthening memories through repetition and deeper encoding improved hybrid search at matched set sizes (Exp. 1). Taking advantage of NFL and NHL fans' pre-existing memory strength for sports logos (Exps. 2-3), we next found search was better for a larger set of familiar items (16 logos) than for a smaller set of unfamiliar items (12 logos), a reversal of the usual memory set-size effect. A standard global matching model (REM), with encoding parameters fit only to memory performance, not search data, reproduced these results and the canonical, approximately log-linear set-size cost in discriminability. Memory strength is thus a potentially strong determinant of hybrid search efficiency, with set-size effects not necessarily reflecting any serial memory search. Instead, models of recognition memory may provide a productive framework for the memory component of hybrid search.

Introduction

We perform visual search tasks many times a day, from rifling through a bag to find our keys, to looking for a familiar face in a crowded room. Often we search not for a single object but with many potential targets in mind, a task known as hybrid search (Wolfe, 2012). For example, we might look for any member of our friend group in a crowd, or for all the ingredients of a recipe at the supermarket. For some people, hybrid search is a core aspect of their occupation, as when airport security officers screen luggage for many kinds of potential hazards.

People take for granted how easy such searches usually are. Within a few seconds we either find a friend in a crowd or conclude they are not there and move on to search elsewhere. In the current work, we test the role of memory strength in hybrid search. We ask whether how strongly the to-be-searched-for items are represented in memory shapes performance, above and beyond the pure number of items being searched for, which has so far been the factor that has dominated most theorizing about these tasks.

Previous work has shown that the time to complete a hybrid search increases linearly with the number of items in the visual display and logarithmically with the number of items in the memory set (Wolfe, 2012). These linear and logarithmic relationships hold across stimulus types, including alphanumeric characters, objects, words, and categories (Boettcher & Wolfe, 2015; Cunningham & Wolfe, 2014). They extend to temporal (RSVP) search (Drew & Wolfe, 2014) and persist when the number of memorized items far exceeds working memory limits (Wolfe, 2012), suggesting that the searched target sets are held in activated long-term memory rather than solely working memory (Drew et al., 2016). Researchers generally treat these regularities as reflecting the core processes at work in hybrid search (e.g., Wolfe, 2012).

Although memory search consistently behaves differently from visual search, in the hybrid search literature, both are generally conceived of as fundamentally search processes, that is, as some process of 'looking through' a collection of discrete items. Indeed, the initial prediction of Wolfe (2012) was that memory set size, like visual set size, would produce linear costs; the logarithmic result instead motivated the proposal that memory is searched with an efficient, logarithmic-search-like algorithm, producing "the pattern that would be seen if half the items could be eliminated on the first step, another half on the next step, and so on" (Wolfe, 2012), so that an N-item list requires only log₂(N) comparisons. Hybrid search performance, according to this view, is primarily driven by the number of items in both the visual and memory sets, an understanding that has largely remained dominant in subsequent work, sometimes explicitly and often implicitly (Boettcher et al., 2018; Drew et al., 2017).

The search-through-discrete-items metaphor is relatively well grounded in the case of visual search, although simple serial accounts have repeatedly given way to more graded ones that nonetheless treat display items as discrete, individually inspectable objects. For example, while models of visual search have often combined parallel "guidance" of attention by target features with capacity-limited identification stages (Wolfe, 2007 (Wolfe, , 2020;; Wolfe & Horowitz, 2017); other models in this literature do derive set-size costs, including logarithmic RT functions, from solely parallel evidence accumulation (Lleras et al., 2020), with efficiency governed by the similarity structure of the underlying representations (Chapman & Störmer, 2024). Formal model comparisons suggest that limited-capacity parallel processing may be sufficient for most search tasks (Thornton & Gilden, 2007), even as sophisticated serial models remain competitive on benchmark RT distributions (Moran et al., 2016). Thus, while some component of serial processing is common in considering visual search processes (particularly given eye movements are necessarily serial), and objects on the search display are indeed discrete, separate entities in nearly all search task, even in this domain the architecture question has remained difficult to resolve (Townsend, 1990). Our focus here is the other, less-commonlyexamined component of hybrid search: the memory decision made about each inspected item.

Hybrid search is necessarily a recognition memory task. Indeed, at a visual set size of one item, it is exactly equivalent to a standard old/new recognition task. Nevertheless, existing models of hybrid search have generally had little to say about the strength of the individual memory representations being searched, even though this is a core aspect of how recognition memory is modeled and conceived of. This is at least partly by design rather than oversight. In standard hybrid search paradigms, observers learn the memory set to a criterion precisely so that differences in memory quality can (hopefully) be set aside without major consequences (e.g., Wolfe, 2012; Cunningham & Wolfe, 2014). But this methodological choice has had a theoretical consequence, since the resulting models treat memory-set items as interchangeable units, present on the list -and in memory -or not. Treating items this way makes memory search more analogous to visual search, and likely contributed to proposals like the logarithmic search of Wolfe (2012).

Notably, this treatment contrasts strongly with how memory is conceived in the recognition memory literature, where models typically assume that performance is governed by graded match signals that vary with encoding quality, repetition, distinctiveness, and interference (Clark & Gronlund, 1996; Shiffrin & Steyvers, 1997; Wixted, 2007), rather than reflecting a search through a discrete set of items. Indeed, there are already hints in the hybrid search literature itself that item-level memory quality matters, even when participants study the list to a fixed accuracy criterion. Search is markedly less efficient for categorically defined targets than for specific memorized pictures (Cunningham & Wolfe, 2014), the targets' value modulates their priority within a memory set (Wolfe et al., 2018), and in a dataset of roughly nine million hybrid search trials, item-level memorability measures strongly predict which targets were found and which distractors were rejected (Simpson et al., 2025). Outside hybrid search, other work also suggests that the strength of memories modulates visual search. For example, naturally familiar brand logos are found faster than unfamiliar ones in standard visual search, an advantage that brief laboratory training does not reproduce (Qin et al., 2014); long-term familiarity with distractors likewise makes them faster to reject (Wang et al., 1994). What has been missing is a direct test of whether memory strength shapes hybrid search efficiency when the number of items in memory is held constant, or when the two are pitted against each other. Furthermore, once the role of memory strength is acknowledged, it is important to test to what extent memory strength might explain the generally large effects of memory set size, as larger lists generally will be expected to produce weaker and more variable match signals -potentially allowing standard recognition models to explain some or even all of the memory set size effect.

Memory search: from serial scanning to global matching

The idea that memory is searched serially -as in Wolfe's logarithmic search proposal (2012) --originates with Sternberg's (1966 Sternberg's ( , 1969) ) memory-scanning experiments, in which response times to classify a probe as belonging to a small memorized set increased linearly with set size (~38 ms/item), with equal slopes for positive and negative probes. Sternberg interpreted this as serial exhaustive scanning, in which every item is compared before any response, producing strictly linear set-size functions. By contrast, self-terminating variants, which stop at a match, produce a mixture of fast and slow positive responses. However, modern recognition memory models do not generally conceieve of recognition as a search process in this way. This is because subsequent work undermined the serial-scanning interpretation on several fronts. With larger, well-learned memory sets, RT grows with the logarithm of set size rather than linearly, which seems inconsistent with constant-time-per-comparison scanning (Burrows & Okada, 1975); this is the same functional form later observed in hybrid search (Wolfe, 2012). Proberecognition RTs show strong recency gradients consistent with direct, strength-based access rather than exhaustive comparison (Monsell, 1978). And when retrieval speed and retrieval success are separated with response-signal methods, set size appears to affect the amount of evidence available rather than the rate of access, as expected if all comparisons proceed in parallel (McElree & Dosher, 1989). Formal modeling points to the same conclusion: parallel evidence-accumulation models reproduce Sternberg's linear functions without any serial scan (Ratcliff, 1978), and modern comparisons of serial, parallel, and global-access architectures against full RT distributions favor strength-based global access under the conditions that best discriminate the architectures (Donkin & Nosofsky, 2012; Nosofsky et al., 2011), though, as in visual search, the architectures mimic one another closely elsewhere.

In the recognition memory literature, then, the dominant framework that emerged from this history is the family of global matching models: for example, to name a few well known examples, SAM (Gillund & Shiffrin, 1984), MINERVA 2 (Hintzman, 1988), TODAM (Murdock, 1982), the Matrix model (Humphreys et al., 1989), and REM (Shiffrin & Steyvers, 1997; for reviews, Clark & Gronlund, 1996; Osth & Dennis, 2024). These models share a simple premise: long-term memory stores a trace of every encoded item, and a recognition decision is made by comparing the probe in parallel against all stored traces, computing its summed similarity to them (or some close proxy). The result is a single graded familiarity signal: high global similarity produces a confident "old" response ("I'm sure I've seen it"), and very low similarity produces a confident "new" response ("I'm sure I haven't seen it"). Critically, these models produce list-length costs without any serial search. Each additional stored trace adds variance to the match signal, so discriminability declines as the variance of the strength distributions grows with list length (in the simplest summed-signal case, d′ ∝ 1/√N), a smooth decline that closely resembles a logarithmic function over typical ranges (Clark & Gronlund, 1996; Shiffrin et al., 1990).

Such models also explain -uniquely --why people can often rapidly and confidently reject novel items, because a low global match, or a diagnostic novel feature, supports an immediate "new" response without consulting each memory (Glucksberg & McCloskey, 1981; Osth et al., 2023), and highly familiar probes can be accepted on familiarity alone, without extended retrieval (Atkinson & Juola, 1974). A simple serial search account, by contrast, would seem to require the entire set to be checked before rejecting, and so predicts target-absent decisions slower than target-present ones. That prediction generally holds in the visual aspects of visual search, motivating the view of it as a search/accumulation process (Wolfe, 2020); in recognition memory, however, it often fails, suggesting that "search" analogies are a poor description of recognition memory, and motivating the global matching family of models instead. In particular, recognition reaction time data instead suggest that response speed tracks the strength of evidence for whichever response is made. The fastest responses of all are typically high-confidence "old" decisions to strong targets (Murdock & Dufty, 1972), but strong "new" responses are also fast, and strengthening memory of a study list speeds the rejection of unstudied items as well as the acceptance of studied items (Criss, 2010; Hockley, 1982; Ratcliff & Murdock, 1976), unlike in visual search.

Formal models of these global matching frameworks can also explain reaction time effects like those observed in hybrid search. For example, accumulation-based extensions of global matching models to response time, such as the exemplar-based random walk (EBRW; Nosofsky & Palmeri, 1997) and related accumulator models (Hockley & Murdock, 1987; Ratcliff, 1978), predict that longer lists produce slower as well as less accurate decisions, even at high accuracy. Indeed, Nosofsky et al. (2014) showed that the curvilinear, approximately logarithmic RT functions that Wolfe (2012) attributed to logarithmic search arise naturally in an exemplar-familiarity model as memory set size increases from 1 to 16 in a standard old/new task.

Recognition memory models thus provide an alternative account of why hybrid search slows with memory set size: one with no "search" process at all, in which the operative variable is the strength of the match signal, and diagnostic signals lead to fast responses regardless of the number of items in memory.

Recognition models as a framework for hybrid search

As noted, a hybrid search display is, in effect, a recognition memory test with multiple simultaneous probes: each display item must be assessed as old (a target) or new (a distractor), much as eyewitness identification has recently been recast as a visual search task probing recognition memory (Wixted & Mickes, 2014; Wixted et al., 2021). Indeed, hybrid search at a visual set size of one is a standard list-length manipulation of recognition memory, and is well captured by global matching models (Nosofsky et al., 2014). On this view of hybrid search as recognition memory, then, each item-decision in hybrid search is slower and less accurate with more items in memory not because more items must be serially examined, but because additional memories add noise that makes old and new items less discriminable. This framing makes a distinctive prediction that list-based accounts do not: even among items encoded well enough to support near-ceiling recognition performance, variation in memory strength should modulate search efficiency -that is, items are not simply "on the list" or "not on the list". This is because even for well-studied items, memory is not all-or-none. Curvilinear ROCs in recognition suggest graded match strength even for well-learned items (Brady et al., 2023; Wixted, 2007), and strengthening encoding typically both raises hits and lowers false alarms (Criss, 2006; Stretch & Wixted, 1998) -not just making people more sure that items are on the list, but also faster and more accurate in rejecting items that are not on the list. In global matching models, deeper encoding stores more, and more accurate, features per item, making each item more discriminable from new items. Such models therefore predict that improved memory strength should improve performance at a constant list length and, in reaction-time extended versions of global matching models, speed decisions as well.

For example, simulations using the global matching model REM at list lengths of 5, 10, 25, 50, 100, 250, 500, and 1000 yield recognition d′ of approximately 2.2, 2.1, 1.7, 1.5, 1.4, 1.2, 1.0, and 0.8, nearly log-linear in list length. Doubling the feature-storage probability raises d′ to 3.5 at length 5 and 3.3 at length 10, and d′ remains above 2.0 even at length 1000.foot_0 Thus, in models like this, "list length" (memory set size) effects arise simply because the other items in memory add variance to the match signal, which lowers discriminability -not because of any search process. Thus, in such models any list length effect can be compensated for by increasing the strength of the underlying memories.

The current study

In the current work, we therefore tested whether memory strength shapes hybrid search efficiency independently of memory set size. Throughout, we use memory strength to mean the discriminability of old from new items on a standard recognition test, e.g. how quickly and easily studied items can be told apart from new ones on the basis of their encoded features. Experiment 1 manipulated strength directly at a fixed set size, as participants searched for two 32-item memory sets, one encoded once (as in standard hybrid search studies) and one encoded deeply through repetition and semantic elaboration (Craik, 2002; Craik & Tulving, 1975). Experiments 2 and 3 pitted strength against set size, exploiting naturally occurring expertise: NFL and NHL fans memorized 16 logos from their familiar sport and 12 from the unfamiliar sport. People tend to form richer, more distinctive memories for objects of expertise (Curby et al., 2009; Ericsson & Lehmann, 1996), so if strength dominates, search should be better for the larger, familiar set, reversing the memory set-size effect in a way that is impossible to predict or explain for search processes that iterate over the "set" of items in memory (as though memory is itself just a list of the well-learned items).

A complication of any such design (including designs that manipulate set size alone) is that memory set size and memory strength cannot be fully unconfounded behaviorally: adding items to a memory list itself tends to weaken the items' representations through interference (the list-length effect; Ratcliff et al., 1990; Shiffrin et al., 1990). Thus, while qualitatively we can show a reversal, quantitatively estimating the contributions of memory strength and list length to the decision process requires a proposed model of how the two interact. For this reason we pair the experiments with simulations of the standard global matching model (REM; Shiffrin & Steyvers, 1997), in which strength and set size are separately specified parameters, alongside response-time extensions of global matching models (Diller et al., 2001; Nosofsky & Palmeri, 1997). By calibrating each condition's encoding parameters solely to its observed memory-test performance, the model lets us ask whether a single strength-based mechanism, with no serial search and no parameters fit to the search data, quantitatively accounts for the full pattern of results, and lets us estimate the relative contributions of strength and list length that the data alone cannot fully isolate.

To preview, memory strength reliably improved hybrid search at matched set sizes (Exp. 1) and reversed the set-size effect when pitted against it (Exps. 2-3). Drift-diffusion decompositions located the benefit in the quality of memory-match evidence rather than response caution, and the calibrated model reproduced these results along with the canonical set-size cost.

Thus, global matching models on their own, with no search process per se, appear to be sufficient to explain hybrid search's memory components. To be clear, serial and parallel processing systems are notoriously difficult to distinguish with response-time data (Townsend, 1972 (Townsend, , 1990)), and a serial-scanning model in which the evaluation of each memory item depends on a continuous strength variable could accommodate strength effects (cf. Donkin & Nosofsky, 2012; Moran et al., 2016; Townsend & Fifić, 2004). Our claim is therefore not that serial memory search is refuted, but that it is unnecessary, as the standard machinery of recognition memory, graded and strength-dependent global matching, well supported by decades of work, suffices to explain hybrid search's memory effects, including the set-size effects that motivated serial scanning accounts, while pure list-length accounts that ignore strength cannot explain the present data.

Experiment 1: Hybrid search is better for more deeply encoded target sets

Experiment 1 tested the basic hypothesis that better-remembered items are searched for more efficiently than weakly remembered items when the memory list is the same size and every item is successfully encoded into memory in both cases.

Participants performed 2 blocks of hybrid search tasks. In each block, they first remembered a list of 32 items, then searched for the items on that list in a set of visual search displays of varying set sizes. Memory encoding was systematically varied across two blocks, such that in one block participants saw each item once (shallow-encoding block), as is usually done in hybrid search studies. In another block, each item was shown 8 times and each time it was seen, participants had to give a short response related to the item to increase memory strength (deep-encoding block). In both cases, after this initial encoding phase, all objects were tested in a subsequent old/new memory test to ensure they were memorized accurately regardless of block; finally, participants were asked to search for these objects in the hybrid visual search task.

Previous research has shown that pairing encoding tasks with questions that encourage semantic encoding of the stimuli leads to more accurate responses in recognition tasks (Craik, 2002; Craik & Tulving, 1975). In models of recognition memory, this occurs because more features are encoded more accurately for items that are seen multiple times, making them more discriminable from lures, and deep encoding questions encourage more distinct features to be encoded (Shiffrin & Steyvers, 1997). In our case, we stacked multiple methods to increase memory strength, as the particular method by which memory strength is increased is not key to our question. Thus, in this study, the comparison is between a single-exposure condition and a repeated, semantically elaborated condition, so the manipulation is best characterized as a difference in overall memory strength, produced jointly by repetition and depth rather than by depth alone. We use the labels "deep" and "shallow" for brevity.

We hypothesized that if memory strength affects search independently of the number of items on the list, performance in the hybrid search task would be improved for the deep relative to the shallow encoding condition.

Participants

Our final sample consisted of 75 undergraduate students from University of California, San Diego participating for course credit. A further 16 participants were run and excluded based on the following criteria, chosen in advance: having an overall memory accuracy ≤ 50%, responding outside a 150-10,000 ms window on more than 10% of search trials, or having average search accuracy below 50%. The final sample had mean age = 19.9 years, range 18-23 (9 male, 64 female, 2 other/undisclosed). All procedures were approved by the UC San Diego Institutional Review Board, and participants provided informed consent. Experiments were run online and completed on participants' personal devices.

Sample sizes for all experiments were set in advance at approximately 75 participants after exclusions, providing >95% power to detect within-subject effects of dz ≥ 0.45 at α = .05, and exceeding typical samples in hybrid search studies (e.g., Wolfe, 2012).

Procedure

The experiment consisted of 2 blocks (1 deep-encoding block, 1 shallow-encoding block) with 3 stages each: encoding, memory test, and visual search (Figure 1). In the encoding stage, participants were shown a set of items that needed to be memorized and subsequently searched for in that block. The targets were displayed one-at-a-time at the center of the screen for 3 seconds. In the shallow-encoding condition, each target was shown only once. In the deepencoding condition, each target was repeated 8 times in a randomized order and followed by a randomly ordered question from a set of 8 related to the item. The questions were: "What was the object you just saw?", "What is a use for the object you just saw?", "What is another object that looks like the object you just saw?", "What is another object that is related to the object you just saw?", "Where would you normally find this object?", "Where would you normally purchase this object?", "What is an unconventional use for the object you just saw?", "Who would normally use the object you just saw (e.g., architect)?" Participants were given 1 question per trial and asked to type in a response to the question. In both conditions, the target set consisted of 32 images selected from the Brady et al. (2008) object set. The 32 objects in each block were randomly selected from this set for each participant. In the memory test stage, participants were tested on the items they had studied initially. Each of the targets and an equal number of random foils were shown one-at-a-time at the center of the screen. Participants responded with a keypress to indicate whether the item was old or new. Following each object, participants reported the confidence in their response on a 1 (least confident) to 6 (most confident) scale. Finally, in the visual search stage, participants searched for the items in the target set. Items were presented at 128px by 128px, displayed in a jittered manner on an invisible, full-screen 4x4 grid, with random jitter to prevent co-linearity between items. Each search display contained either 8 (50%) or 16 (50%) objects, with one of the target objects either present (50%) or all target objects absent (50%). Participants responded with a keypress to indicate whether a target was present or absent. No search display contained more than a single target.

The experiment consisted of 256 visual search trials (128 per target set). There were an equal number of target present trials and target absent trials, and an equal number of each visual set size intermixed in both the deep and shallow encoding blocks, and the order of the deep and shallow blocks was counterbalanced across participants. In the deep encoding condition, participants viewed 32 objects 8 times each in randomized order for 3000ms each, with a question presented after each object (the same question for every object within a pass; e.g., "What is a use for the object you just saw?"). In the shallow encoding condition, a different set of 32 objects were presented only once each for 3000ms without questions, each followed by a self-paced screen to continue. Objects were drawn from the full image set such that assignment of objects to the deep and shallow sets were random across participants. Test phase: Participants completed a recognition memory test where they judged whether each presented object was "old" (from the memorized set) or "new" (foil), followed by confidence ratings on a 1-6 scale. Visual Search phase: Participants searched for any of the memorized objects in displays containing 8 or 16 items, responding whether a target was present or absent. Each search display contained either one target (50% of trials) or no targets (50% of trials), with response times exceeding 5000ms triggering a faster response prompt.

Results

Memory strength for the encoded items.

People remembered the items in both sets well, with near-ceiling confidence, so we could not compute full ROC curves (Brady et al., 2023) and instead report d′ alongside hit and false-alarm rates. Memory was reliably stronger in the deepencoding block, d′ = 4.33 (SD = 0.59), than in the shallow-encoding block, d′ = 3.27 (SD = 1.05), t(74) = 8.27, p < .001, Cohen's d = 0.95 (hits: .97 vs. .85; false alarms: .02 vs. .05). Note that, consistent with global matching models, but not straightforwardly consistent with a search process, the stronger list led to fewer false alarms t(74) = 4.20, p < .001, dz = 0.49), a 'mirror effect' whereby strong memories make you better able to reject new items, not just better at recognizing old items (Criss, 2006; Stretch & Wixted, 1998). Confidence for old items was likewise higher for deeply encoded items (M = 5.97 vs. 5.82 on the 1-6 scale), t(74) = 5.12, p < .001, d = 0.59, as was confidence across all test responses, t(74) = 6.03, p < .001, d = 0.70. Thus, although both sets were "in memory" by conventional criteria, the deep-encoding set was represented more strongly.

Hybrid search.

On each search trial we measured response time and accuracy (Figure 2).

Because participants can trade speed for accuracy in visual search (Wolfe, 2018), our planned primary measure was the inverse efficiency score (IES; mean RT divided by proportion correct, per condition cell; Townsend & Ashby, 1983; Bruyer & Brysbaert, 2011), with RT and accuracy also analyzed separately as a secondary analysis. However, because accuracy in some conditions was lower than is ideal for IES, we also report drift-diffusion model fits, which are more robust. For IES on target-present trials, a 2 (encoding) × 2 (visual set size) repeated-measures ANOVA revealed a significant effect of visual set size, F(1,74) = 187.47, p < .001, ηp² = .717, a significant effect of encoding, F(1,74) = 11.01, p = .001, ηp² = .130, and no interaction, F(1,74) = 0.80, p = .373, ηp² = .011. Target-absent trials showed the same pattern: visual set size, F(1,74) = 410.70, p < .001, ηp² = .847; encoding, F(1,74) = 4.33, p = .041, ηp² = .055; interaction, F(1,74) = 0.59, p = .446, ηp² = .008. Search was thus more efficient for the more deeply encoded set at both visual set sizes, on both trial types.

In accuracy, the encoding benefit was robust. Target-present: visual set size, F(1,74) = 103.62, p < .001, ηp² = .583; encoding, F(1,74) = 31.39, p < .001, ηp² = .298; interaction, F(1,74) = 10.13, p = .002, ηp² = .120 (the encoding benefit was larger at the smaller visual set size).

Target-absent: visual set size, F(1,74) = 27.07, p < .001, ηp² = .268; encoding, F(1,74) = 35.56, p < .001, ηp² = .325; interaction, F(1,74) = 0.99, p = .323, ηp² = .013. In RT, there was no main effect of encoding (target-present: F(1,74) = 1.31, p = .257, ηp² = .017; target-absent: F(1,74) = 1.42, p = .238, ηp² = .019), with significant set-size effects (Fs > 300, ps < .001, ηp² > .80) and small encoding × set size interactions (present: F(1,74) = 6.80, p = .011, ηp² = .084; absent: F(1,74) = 11.83, p < .001, ηp² = .138).

Although memory was near ceiling, individual items were occasionally missed on the memory pre-test, and such weakly encoded items could in principle be responsible for the search effects. Restricting target-present trials to targets each participant had correctly endorsed as "old" in the memory test, the encoding effect remained clearly significant in accuracy, F(1,74) = 16.12, p < .001, ηp² = .179, was attenuated in IES, F(1,74) = 3.96, p = .050, ηp² = .051, and was absent in RT (F(1,74) < 0.01, p = .994), as in the full data. Some attenuation is expected under a strength account, because excluding memory-test misses removes the lowest-strength items, disproportionately from the shallow condition, restricting the very strength variation under study.

Strength effects nonetheless persist among items that were demonstrably encoded, and the targetabsent benefits, which involve no specific target item, are unaffected by this restriction.

Drift-diffusion decomposition.

To characterize the encoding effect within a unified speed-accuracy framework that is more robust than IES, we converted each condition cell's accuracy, mean correct RT, and correct-RT variance into the core parameters of a diffusion decision process using EZ-diffusion (Wagenmakers et al., 2007): drift rate (v), boundary separation (a), and non-decision time. If memory strength improves memory-match evidence, it should raise v, the mean rate of evidence accumulation, which in recognition corresponds to the degree of match between the probe and the stored traces (Ratcliff, 1978; Ratcliff & McKoon, 2008); if conditions instead differ in how participants trade speed for accuracy, effects should appear in a, the amount of evidence required before a response is initiated. Both halves of this mapping have been validated experimentally: manipulations of stimulus discriminability lower v while accuracy emphasis raises a (Voss et al., 2004), and in recognition memory specifically, studying items twice rather than once raises v with no reliable change in a, while speed-versusaccuracy instructions produce large changes in a (Arnold et al., 2015). Note that in this case, this is a measurement model rather than a process model, because display-level search RTs aggregate multiple item evaluations; parameters were therefore estimated separately within each visual set size and trial type, and v should be read as only an effective evidence-quality index per display.

Deep encoding raised drift rates on both target-present trials, F(1,74) = 58.45, p < .001, ηp² = .441, and target-absent trials, F(1,74) = 80.33, p < .001, ηp² = .521, with the size of the drift benefit varying across visual set sizes (encoding × set size interactions: present, F(1,74) = 31.31, p < .001, ηp² = .297; absent, F(1,74) = 10.34, p = .002, ηp² = .123), and with no significant effect on boundary separation (target-present: F(1,74) = 3.59, p = .062, ηp² = .046; target-absent: F(1,74) = 0.01, p = .939).

Thus, although mean RT showed no encoding effect, the diffusion model recovered a large evidence-quality benefit for the deeply encoded set. The benefit was expressed in accuracy and RT variability rather than mean speed in this particular experiment.

Discussion Experiment 1

We found improved hybrid search performance for memory sets encoded more strongly, despite identical list lengths and near-ceiling old/new memory in both conditions. The benefit appeared in IES on both target-present and target-absent trials, and in this case appeared primarily in accuracy rather than RT; participants searched relatively slowly and carefully overall (mean RT 2.31 s), and speed and accuracy trade off in such tasks (Wolfe, 2018). The drift-diffusion decomposition recovered a large evidence-quality benefit even though mean RTs did not differ.

Accounts on which hybrid search performance is determined solely by the number of (sufficiently encoded) items in memory do not predict any difference between these conditions; recognition models predict it directly, as a discriminability difference. Notably, there are many possible global matching models of recognition memory that make predictions about reaction time. An effect of memory strength that appears mainly in accuracy is an a priori property of one of these response-time extensions (ARC-REM), in which decision timing reflects an assessment of retrieval completion rather than evidence strength (Diller et al., 2001; Nobel & Shiffrin, 2001; see Simulation section). However, given the flexibility with which participants can trade reaction time for accuracy in search tasks, our overall claim rests solely on overall performance integrating the two, rather than any particular reaction time vs. accuracy trade-off.

Experiment 2: Inverting the memory set-size effect

Experiment 1 demonstrated that memory set size alone isn't sufficient to explain performance on hybrid search tasks and that instead, how well items are encoded in memory is an important factor in supporting hybrid search. However, the observed performance differences during visual search were driven primarily by differences in accuracy, not response times.

Although this is straightforwardly accounted for by the drift diffusion model that shows drift rates differed with no significant change in boundary separation (i.e., no speed accuracy trade off), it leaves open the possibility that memory strength has some unique effect on just accuracy but not response time. In addition, as memory set sizes were the same across the deep and shallow encoding conditions, it's unknown if it's possible to make a larger memory set faster to search than a smaller one -which is a key prediction of recognition models that is incompatible with any form of serial memory search through a "list of encoded items" (e.g., that treat all items as present or absent from memory, as in traditional hybrid search proposals).

Thus, in Experiment 2, we aimed to use a stronger memory manipulation. To accomplish this, we opted to capitalize on items where participants already differ in how quickly and accurately they can encode them, without any training or specific encoding manipulations required on our part: objects of expertise. People in general form much richer and more distinctive memories for objects of expertise compared to items they are less familiar with (Curby et al., 2009; Ericsson & Lehmann, 1996). In particular, experts extract new and more informative perceptual features than novices, rely on larger and more informative chunks to structure their encoded memories, and select more distinctive information to encode that is more differentiable from other items to avoid interference (Ericsson & Lehmann, 1996). Thus, even if all participants remember the full memory set, experts will in general have richer, stronger and more distinctive memories for objects of their expertise, which should lead to faster hybrid search for such objects.

We recruited self-reported NFL and NHL fans, taking advantage of participants' strong pre-existing knowledge about sports logos. This allowed us to use the natural variation in the memory representations of sport logos across the two groups at encoding. Alongside this manipulation of expertise, we also manipulated list length. We had participants memorize a larger set of logos in their familiar sport and a shorter list in their non-familiar sport-directly testing the hypothesis that memory strength will matter more than this variation in list length per se for hybrid search performance. In standard hybrid search tasks, larger memory sets will generally be associated with weaker memories because of more interference (e.g., the list length effect, Shiffrin & Steyvers, 1997), confounding these two possibilities. By contrast, in this experiment the two accounts make completely opposite predictions, with list length predicting better performance for the smaller memory set which is less familiar, and memory strength accounts predicting better performance for the larger memory set which is more familiar.

Method Participants

Our final sample comprised 79 participants (mean age = 36.1 years, range 20-74; 63 male, 16 female) recruited via Prolific, where we could pre-screen their sports knowledge to selectively recruit NFL and NHL experts. 26 additional participants were tested and excluded for: any condition cell with an infinite inverse efficiency score, overall search accuracy below 50%, more than 10% of search responses outside the 500-4,500 ms window, or reporting interest in their nominally unfamiliar sport one or more scale points above their nominally familiar sport.

Participants were limited to be U.S. or Canadian-based and compensated at an hourly rate consistent with institutional guidelines. All procedures were approved by the UC San Diego Institutional Review Board, and participants provided informed consent.

Stimuli

Participants memorized a subset of the possible 32 NFL and 32 NHL logos. A total of 272 distractor stimuli were used for the memory test foils and the visual search task, consisting of logos of teams from the American Ultimate Disc League (AUDL), logos of teams from various international soccer leagues, and generated logos of similar visual content and quality from VectorStock (http://www.vectorstock.com/). All stimuli were presented on white backgrounds and were cropped to the same size.

Procedure

Participants were assigned to their experimental group -familiar with the NFL or familiar with the NHL -based on their reported familiarity for each league prior to the beginning of the study, using a Prolific pre-screen that allows selecting participants based on their sports' preferences.

All participants then completed 2 blocks of study, test and visual search. In one block, they were shown and then tested on 12 unfamiliar logos from their non-preferred sport, followed by visual search for those logos. In the other block, they were shown and tested on 16 familiar logos from their preferred sport, followed by visual search for those logos. In total there were 32 NHL and 32 NFL logos but only 12 or 16 of them were used as stimuli during memorization for each participant, so they had to remember the particular set of logos they were shown for each sport.

The order of the preferred sport and non-preferred sport blocks were counterbalanced across participants.

In the study phase at the start of each block, participants were instructed to memorize the targets for that memory set. Targets were shown in random order, one at a time for 3 seconds each, and all targets were shown twice over the course of the presentation to ensure strong encoding even in the non-preferred sport. Participants then took a recognition test wherein they were presented with either a target or a foil, one at a time, and asked to identify if the logo was one that they just memorized or a new logo. The number of foils shown in this stage was equal to the number of targets for that block but different for each block as well as different from the distractor stimuli used for the visual search trials. After each response, participants were asked to rate their confidence in their answer on a scale from 1 to 6. Discussion Experiment 2

Overall, we found improved performance in the hybrid search task for memory sets that people were familiar with, and thus represented more strongly in memory, despite having to memorize more objects and thus having a larger memory set size. In particular, IES was improved for both target-present and target-absent trials for the longer, more familiar lists. These differences in IES scores reflected benefits in both response times and accuracy. This is consistent with strengthbased global matching models, in which strongly represented memories produce stronger match signals. Notably, all of the results clearly go in the direction of better performance for the longer list rather than the shorter list. A larger memory set did not come with a cost, but instead led to an advantage when that memory set consisted of stronger rather than weaker memories. No account in which hybrid search performance is a function of memory set size alone can produce this pattern; yet it follows directly from strength-based global matching.

Experiment 3: Are participants just performing a category search?

Experiment 2 showed that with a strong enough memory manipulation it is possible to flip the classic memory set size effect, such that a larger memory set is searched more efficiently than a smaller one. Along with Experiment 1, this suggests that memory set size alone can't explain performance in hybrid search. However, we considered that in Experiment 2, it is in theory possible for participants to do a category search to find the target rather than specifically look through their memory set (e.g., is there an NFL logo present at all?). That is because while the memory task focused on ensuring only the subset of NHL or NFL logos were remembered, the visual search trials never included any of the other, non-studied logos from that same sport.

While this did not occur during the memory test -participants in fact rejected new logos better in the longer list of their familiar sport --this introduces the possibility that participants could complete the search task by responding 'present' when any NFL/NHL logo was present instead of responding 'present' when one of the specific logos they encoded for this experiment was present. Previous literature has demonstrated that search performance can vary depending on whether participants are searching for any objects from a category or a specific target within a category (Cunningham & Wolfe, 2014).

Thus, in Experiment 3, we replicated Experiment 2 but also included lures from the respective sport that weren't in the memorization phase during the visual search, ensuring participants actually searched for the studied logos in particular rather than performing a category search (a strategy the lures render unreliable: responding 'present' to any same-sport logo produces an error on every lure-present target-absent display).

Discussion Experiment 3

Experiment 3 replicated the findings of Experiment 2, with better hybrid search performance for familiar than unfamiliar logos in terms of IES and accuracy on target-present trials and in RT on both trial types. They also show that the improved hybrid search performance was the result of strongly represented memories and not the product of a simple categorical search for their domain of expertise. The lure trials also show how the memory decision treats partial matches. An unstudied logo from the relevant sport is a partial match: it shares category and format features with the studied set while mismatching on item-specific features. Global matching models predict the observed pattern: partial matches elevate the memory signal, which slows and occasionally defeats rejection. Graded lure dynamics of this kind are also the data that most strongly constrain models of the underlying decision process (Osth et al., 2023).

Simulating the experiments with a global matching model

Our central hypothesis is that the results of all three experiments are consistent with what is expected by standard models of recognition memory, in which a probe is compared in parallel to all stored traces and decisions rest on graded match signals, with no item-by-item search through the memory set. To test this more directly, we simulated all three experiments with REM (Shiffrin & Steyvers, 1997), the canonical global matching model, and ARC-REM, the reactiontime extension (Diller et al., 2001. The simulations aim to establish that no memory "search" is needed to explain hybrid search data, that is, that a single memory strength-based mechanism, with encoding parameters fixed by each condition's memory-test performance and no parameters fit to any search data, reproduces the full pattern, including the set-size effects that motivated serial-scanning accounts and their reversal under our strength manipulations.

While our behavioral experiments 2 and 3 provide strong evidence about the relative contributions of memory strength and list length through the demonstrations that a larger set of familiar items (16 logos) outperformed a smaller set of unfamiliar ones (12 logos), the precise contributions list length alone makes to "weakening" the items still remains unclear, which we examine below in a model where each is an explicit parameter.

In REM, each studied item is stored as a vector of w = 20 arbitrary feature values; each feature is stored with probability S and stored correctly with probability c. At test, a probe is compared in parallel to every trace, and the average likelihood ratio (the odds, λ) is compared to a criterion, with λ > 1 yielding an "old" response. A single neutral criterion was used for all conditions, so condition differences come only from encoding. As in all global matching models, list-length costs arise because each additional trace adds variance to the match signal, not because more items must be examined (Clark & Gronlund, 1996; Shiffrin et al., 1990).

Rather than fitting search data, we calibrated each condition's two encoding parameters (S, c) to reproduce that condition's observed memory pre-test d′, constraining the high-strength condition of each experiment to store at least as many and at least as accurate features as its lowstrength counterpart. For Experiments 2 and 3, which share a design, the calibration targets were the means of the two experiments' memory-test d′ values (treating them as a single experiment for this purpose).

The calibration recovers a sensible mapping of the manipulations onto encoding. For Experiment 1, shallow encoding was matched at S = 0.50, c = 0.85 and deep encoding gives more features stored more accurately, at S = 0.65, c = 0.90 (giving d′ = 3.32 and 4.63 against observed 3.27 and 4.33). Thus, deep encoding with eight repetitions can be thought of as storing more, and more accurate, features per item. All model values reported below come from a single simulation of each condition at its calibrated parameters, run separately from the calibration search.

For Experiments 2-3, the unfamiliar condition led to a match at S = 0.50, c = 0.75 and the familiar condition at S = 0.60, c = 0.75 (giving d′ = 2.93 and 3.26 against targets 2.93 and 3.38).

Thus, expertise can be thought of as resulting in the storage of more features per logo. Note that the (S, c) solutions are not uniquely identified, one can think of the manipulations as affecting either how much we store or how accurately somewhat interchangeably. We also note that neighboring combinations fit comparably so parameter interpretations are illustrative rather than exact.

With parameters fixed in this way, REM reproduces every key accuracy-level feature of the data, not just the memory strength it is matched to. First, at a constant list length of 32 (Experiment 1), stronger encoding produced substantially better per-decision discrimination and a mirror effect (d′ = 4.63 vs. 3.32; hits .99 vs. .94, false alarms .009 vs. .038). Second, the model reproduces the reversal in Experiments 2-3: per-decision d′ was higher for the larger, stronger set (16 familiar items, d′ = 3.26) than the smaller, weaker one (12 unfamiliar items, d′ = 2.93).

Simulating the unobserved cells of the strength × length crossing shows where this pattern comes from in the model: at matched strength, lengthening the list from 12 to 16 items cost only 0.06-0.15 d′ (unfamiliar strength: 2.93 → 2.87; familiar strength: 3.41 → 3.26), several times smaller than the 0.4-0.5 d′ strength differences from extra memory strength that override it (and far smaller than the 1.3 d′ encoding effect the model produced for Experiment 1). The two conditions actually tested thus show the observed crossover, with the larger familiar set outperforming the smaller unfamiliar set, even though within either strength level the model's d′ falls slightly as the list lengthens.

Third, with encoding fixed at the weak level and list length varied alone (N = 4-64), the model produces the canonical memory set-size cost in discriminability, with d′ declining approximately log-linearly (3.28, 3.07, 2.83, 2.60, 2.39). Each doubling of the list length cost a nearly constant 0.21-0.24 d′, as expected if the decline is log-linear. This is the signature usually attributed to logarithmic serial search, and here it arises purely from match-variance growth.

REM itself is silent about response time, but provides a strength of evidence term that can be turned into reaction time. Consider the single old/new decision made about one fixated item.

The decision variable is the odds λ that REM computes (e.g., how likely is this to be an old item?), and our manipulations act on this per-decision evidence: stronger encoding raises λ for studied items and, because stronger traces match novel probes more poorly (differentiation; Criss, 2006), lowers it for novel ones, while longer lists add variance to λ for both, making each individual decision less reliable.

How a change in this evidence surfaces in reaction time behavior then depends on a second, separable assumption about what ends the decision. In evidence-accumulation extensions, such as the exemplar-based random walk (Nosofsky & Palmeri, 1997), match signals are sampled into an accumulator until a response threshold is reached. A single decision based on better evidence is then both faster and more accurate, and the threshold setting determines the split: cautious, high-threshold settings push accuracy toward ceiling, so strength and list-length effects appear mainly in decision time, whereas speeded, low-threshold settings compress decision times and push the same effects into error rates. Models of this class, fit to proberecognition data, produce the curvilinear, approximately logarithmic RT set-size functions seen in hybrid search at a visual set size of one (Nosofsky et al., 2014), and they predict that strength should speed decisions, as we observed in Experiments 2-3.

In retrieval-completion extensions (ARC-REM; Diller et al., 2001), the decision instead ends when a fixed proportion of probe features has been processed. A single decision's duration is then set by retrieval dynamics rather than by the evidence, so strength and list length leave decision time nearly untouched and their effects fall entirely on accuracy, whatever its level. This limiting case was motivated by data in which encoding manipulations moved accuracy but not latency (Nobel & Shiffrin, 2001), and it is the natural account of Experiment 1, where the encoding benefit appeared in accuracy with flat mean RTs even though accuracy was well below ceiling. To verify this prediction, which runs counter to the intuition that stronger evidence should affect both reaction time and accuracy, we implemented ARC-REM with encoding parameters calibrated the same way: it reproduced the same d′ patterns while producing nearly identical per-decision retrieval times across strength conditions (within 5% of each other; e.g., per-decision times of roughly 1.40 vs. 1.47 s for shallow vs. deep hits in Experiment 1, despite the 0.9 d′ accuracy difference between them).foot_2 Which of these extensions better describes a given task plausibly depends on its pacing. The drift-diffusion model fits reported with each experiment provide an empirical estimate of this per-decision evidence quality, and in all three experiments, strength raised target-present drift rates while response caution was unchanged.

Finally, to show how such a model can produce display-level hybrid search effects, we embedded it in a minimal hybrid search wrapper motivated by the eye-tracking finding that observers perform one memory check per fixated item (Drew et al., 2017). Although this is a naive model of search, it provides some guidance. In it, display items are processed in random order, each receiving one model decision (drawn from the ARC-REM extension, which supplies per-decision times), terminating at the first "old" response (with a stricter criterion than single-probe recognition as appropriate when false alarms compound over multiple display items; Chun & Wolfe, 1996). This simple model reproduces the display-level structure of the empirical results.

Response times rise steeply with visual set size for present and absent trials, and search accuracy and target-absent efficiency are better for the strong memory set at both visual set sizes in both experimental designs, including better performance for the 16-item familiar set than for the 12item unfamiliar set. For example, at the largest display sizes, the model's target-present accuracy was .96 for the deep vs. .91 for the shallow set (Experiment 1) and .91 for the familiar vs. .83 for the unfamiliar set (Experiments 2-3), and its target-absent inverse efficiency favored the strong sets by 7% and 10%, respectively. Target-absent inverse efficiency doubled from the smaller to the larger displays in every condition, mirroring the steep visual set-size slopes in the data. Thus, the memory set-size effects that motivated serial-scanning accounts of hybrid search are fully consistent with, and straightforwardly explained by, the same strength-based matching process that explains recognition memory at large.

General Discussion

Hybrid search performance has canonically been understood in terms of how many items must be processed, both in the visual search through the display and in the memory search through the target set, with the logarithmic memory set-size cost attributed to an efficient serial search through the memorized list (Wolfe, 2012). Here we asked a question this framework was These findings more strongly connect hybrid search to the recognition memory literature, where the transition from serial-scanning accounts (Sternberg, 1969) to strength-based global matching (Clark & Gronlund, 1996; Gillund & Shiffrin, 1984; Shiffrin & Steyvers, 1997) was driven by the same phenomena observed here, e.g. graded effects of encoding strength, fast rejection of novel items, and set-size costs explicable as signal-to-noise effects (Burrows & Okada, 1975; McElree & Dosher, 1989; Ratcliff, 1978). A hybrid search display is, on this view, a recognition test with multiple simultaneous probes, effectively list recognition with many "new" items per test (cf. Wixted et al., 2021).

The architecture of memory matching

We have deliberately framed our conclusion in terms of the sufficiency of standard global matching models, rather than suggesting no serial model could ever account for the data. Serial and parallel architectures can mimic one another closely in response-time data (Townsend, 1972 (Townsend, , 1990)), distinguishing them requires distributional or factorial methods purpose-built for the question (Donkin & Nosofsky, 2012; Moran et al., 2016; Townsend & Fifić, 2004; Townsend & Nozawa, 1995), and a serial-scanning model in which each item's evaluation depends on a continuous strength variable could likely accommodate strength effects on search.

The present data do rule out any account on which hybrid search performance is determined by the number of well-encoded items in memory, with items treated as interchangeable list entries. Such accounts cannot produce better performance for a longer list.

Our positive claim is based on parsimony, that is, the strength-based global matching machinery independently required to explain recognition memory, and well established over decades of recognition memory research, can explain hybrid search's memory effects as well. It even predicts the logarithmic set-size cost that motivated serial-scanning interpretations, so no additional serial search mechanism need be posited. Distinguishing serial from parallel architectures directly would require designs borrowed from systems-factorial tests, or analyses of how lure processing changes with memory set size (Moran et al., 2016). Experiment 3's lure trials already exhibit the basic phenomenon such analyses would exploit, where categorically related, unstudied items reliably slow rejection and elevate false alarms. Crossing such lures with memory set size and parametrically varied repetition (to map a quantitative strength dimension; cf. Hockley, 1982) is, in our view, the most promising route to architectural tests in hybrid search if positive evidence is to be found for a "memory search" account beyond global matching models.

Strength and set size as joint determinants of performance

Our results should not be read as showing that memory set size is irrelevant; in the model, and likely in behavior, both factors operate on the same match signal. Indeed, because adding items to memory weakens each item's representation through interference, set-size manipulations are usually also -at least in part -strength manipulations (Ratcliff et al., 1990; Shiffrin et al., 1990). This is why the two cannot be fully unconfounded behaviorally, and why modeling is required to separate them. Our calibrated REM model quantifies this for our designs: over the 12-to-16-item range, the pure list-length cost is small (0.06-0.15 d′) relative to the strength differences our manipulations produced (0.4-0.5 d′ in Experiments 2-3, and 1.3 d′ in Experiment 1, against an observed memory test difference of 1.06 d′), which is why the reversal occurs.

With much larger set-size ranges (e.g., 4 to 100; Wolfe, 2012), list-length costs will be substantial, driving memory strength way down, unless strength manipulations between list lengths are correspondingly large. Thus, we argue that hybrid search efficiency reflects the discriminability of memory-match signals, to which both the number and the strength of stored representations contribute. This view is consonant with the broader recognition literature, where even the existence of pure list-length effects is contested once strength-related confounds are controlled (Dennis et al., 2008; Kinnell & Dennis, 2011; Osth & Dennis, 2015). It is likely the case in hybrid search as well that list length effects independent of strength will be small or hard to provide direct evidence for, but this is currently a model-based conclusion rather than something we have directly tested.

Relation to memory-set structure effects

Work on memory-set partitioning has already begun to map the limits on how observers can engage the items held in memory. Observers generally cannot restrict search to an arbitrary relevant subset of memorized items (Boettcher et al., 2018), but can when subsets are categorically distinct (Gronau et al., 2024), and display properties can guide which memories are interrogated (Nordfang & Wolfe, 2018). The original authors interpreted these phenomena through a guided-search lens, as a serial memory search limited to context-relevant items. However, they are equally natural under global matching, since memory traces include context features, so context-congruent traces produce stronger match signals and dominate the decision (Clark & Gronlund, 1996), with graded rather than all-or-none selection. Our strength effects are complementary, in that partitioning work shows that which memories are most affecting search depends on structure and context match, and we show that how strongly each memory matches governs efficiency even within a fixed set. There are likely constraints on the generality of the findings we present here. For example, the present findings are based on adult participants tested in controlled laboratory and online settings using simplified visual displays and well-defined target sets. Although these tasks were designed to capture core properties of everyday hybrid search, real-world searches like those performed in airport security screening, medical image interpretation, or educational assessment often involve more complex stimuli, higher stakes, and extended training histories.

Accuracy, RT, and strength benefits

As a result, while our results suggest that strengthening memory representations may improve search performance in such applied domains, future work will be necessary to directly test whether the same mechanisms operate under those conditions. Our strength manipulations also covaried with stimulus class differences across experiments (everyday objects vs. logos) and, in Experiments 2-3, with participants' broader domain knowledge. The model's calibration absorbs such differences into its encoding parameters, but which aspects of expertise produce stronger logo memories (perceptual experience, semantic knowledge, affective engagement) is a question for future work. Finally, each of our experiments included only two visual set sizes, and thus we cannot directly measure whether visual set size affected performance linearly, as expected based on previous work; further work, especially with larger visual set-size ranges, is needed to clarify how the functional form of RT increases in hybrid search relate to combined models of visual search and recognition memory (Wixted et al., 2021).

Conclusion.

Memory strength matters to hybrid search, independently of memory set size, and strength manipulations can outweigh and even reverse set-size effects. A standard global matching model of recognition memory, calibrated only to memory-test performance, captures these results together with the canonical set-size costs that originally motivated serial-search accounts. Models of recognition memory thus provide a productive, mechanistic framework for the memory component of hybrid visual search; integrating them with models of visual attention is the natural next step toward a full account of hybrid search.

Across three experiments, memory strength had large effects on hybrid search efficiency -independently of list length. Strengthening memories through repetition and elaborative encoding improved search at a fixed memory set size (Exp. 1); and when strength was pitted against list length using sports-logo expertise, participants searched a 16-item familiar set faster and more accurately than a 12-item unfamiliar set, reversing the canonical memory setsize effect (Exps. 2-3). The reversal held even with within-category lures that precluded categorical search strategies (Exp. 3). A global matching recognition model calibrated only to each condition's memory-test performance reproduced the full pattern, including the approximately log-linear set-size cost in discriminability itself, with no search process going through memory, just evidence variability and match signals.

The expression of the strength benefit differed across experiments, being primarily accuracy in Experiment 1, and both accuracy and RT in Experiments 2-3. The drift-diffusion fits reported in each experiment suggest that this variability reflects a single underlying effect. In all three experiments, memory strength raised target-present drift rates (the quality of memorymatch evidence) while leaving response caution unchanged. How that improved evidence expresses itself then depends on what times the decision, and participants may have timed their decisions differently in the two kinds of task. In Experiment 1, where search responses were slower each memory check could run to retrieval completion, and under retrieval-completion timing (ARC-REM) strength effects fall on accuracy even when accuracy is well below ceiling, which is what we observed. Experiments 2-3, with their faster search responses, are closer to the setting where threshold-based accumulation (EBRW) is often applied, and strength there produced the predicted joint benefits to speed and accuracy. The cross-experiment differences may therefore not be only noise but may reflect the expected behavior of strength-based mechanisms under different decision-timing scenarios.
