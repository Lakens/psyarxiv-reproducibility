What we found

We found 26 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Ethics Approval Check works

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

IRB and IEC are kept unconstrained as they are not observed to collide in practice. - Dutch: Medisch-ethische toetsingscommissie (METC) - French: Comité d'éthique / Comité d'Ethique

Animal research committee names - Institutional Animal Care and Use Committee / IACUC (US standard) - Any sentence containing animal(s) and committee (or board/panel) within ~5 words of each other — catches Experimental Animal Care and Use Committee, Animal Ethics Committee, Animal Welfare Board, Animal Welfare Ethical Review Body, etc. - UK: Animal Welfare Ethical Review Body / AWERB - Dutch: Dierexperimentencommissie / DEC (see DEC constraint above); Instantie voor Dierenwelzijn / IvD - German: Tierversuchskommission / TvK (advisory committee under §15 Tierschutzgesetz) - French: Comité d'éthique en expérimentation animale / CEEA; Comité d'éthique animale - Spanish: Comité de ética en experimentación animal / CEEA

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. This package was validated by the Metacheck team on articles in Psychological Science.

How Preregistration Check works

Retrieve information from preregistrations in a standardised way, and make them easier to check.

The Preregistration Check module identifies preregistrations on the OSF and AsPredicted based on links in the manuscript, retrieves the preregistration text, and organizes the information into a template. The module retrieves text from the OSF with its API, and from AsPredicted with ResearchBox’s API when a ResearchBox key is set (see rbox_token()), or else from the preregistration’s web page. The information in the preregistration is returned. An AsPredicted link that could not be read is named in the report, with the reason.

The module can’t extract information from non-structured preregistration templates (i.e., where the preregistration is uploaded in a single text field) and it can’t retrieve information in preregistrations that are stored as text documents on the OSF.

If you want to extend the package to be able to download information from other preregistration sites, reach out to the Metacheck development team.

How Marginal Significance works

List all sentences that describe an effect as ‘marginally significant’.

The marginal module searches for regular expressions that match a predefined pattern. The list of terms is a subset of those listed in a blog post by Matthew Hankins. The module returns all sentences that match terms describing ‘marginally significant’ results.

Some of the terms identified might not be problematic in some contexts, and there are ways to describe ‘marginal significance’ that are not detected by the module.

This module was developed by Daniel Lakens

Read more in the metacheck manual.

Validation: In a sample of 51 papers with 87 statements, this module correctly identified 38 statements (true positives) and incorrectly flagged 22 statements (false positives). It failed to detect 27 statements. Thus, among all statements flagged by the module, 63% were genuine cases (positive predictive value). However, the module missed 42% of all true statements (false negative rate).

How StatCheck works

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Does Teacher Praise Make Children Feel Less Smart? Two Preregistered Virtual Reality Experiments

Teachers often praise students to make them feel smart (Brummelman, 2020; Henderlong & Lepper, 2002). They dole out praise up to more than once per minute (Scott & and Tsai, 2025), often giving more praise to children from disadvantaged backgrounds (Harber, 2023; Schoneveld & Brummelman, 2023). But praise may not always have the intended positive outcome. Imagine two children receiving the same grade, and the teacher lavishing praise on only one: "Wow, you did a great job!" Children know that teachers praise those who succeed through hard work rather than natural ability (Barker & Graham, 1987). Thus, ironically, the praised student may infer that they are less smart. Indeed, this is a concern that has been voiced in social, developmental, and educational psychology (Brummelman, 2020). We tested this idea through two preregistered Virtual Reality (VR) experiments with 7-to 13-year-old children. Using virtual reality tools, we immersed children in a virtual classroom with virtual classmates and a virtual teacher, allowing us to isolate the causal effect of teacher praise in a dynamic social context.

Unequal Treatment in the Classroom

Teachers treat students differentially to tailor their education to students' level of ability (Parsons et al., 2018). In some cases, however, teachers' views are influenced less by a student's individual characteristics and more by their background. This may lead teachers to offer more negative feedback to students from disadvantaged backgrounds-for example, asking simpler questions, providing less sophisticated feedback, or assigning lower grades and track recommendations-thereby perpetuating inequality (Bloem et al., 2026; Brummelman et al., 2026; Brummelman & Sedikides, 2023; Turetsky et al., 2021). Here, we shift attention from overtly negative practices to a potentially overlooked source of inequality: praise, which is often intended to support students from disadvantaged backgrounds. Indeed, teachers tend to praise students from disadvantaged backgrounds more often (Harber, 2023; Schoneveld & Brummelman, 2023).

We theorize that, in some cases, praise can backfire by communicating teachers' low expectations to children (Good et al., 2018; Graham & Chen, 2020). According to attribution theory (Graham, 2020), people often assume success and failure are caused by internal factors like effort or ability. Like most adults (Celniker et al., 2023), teachers value effort (Biddle & Goudas, 1997; Weiner & Kukla, 1970) and praise the students they believe worked hard (Schoneveld & Brummelman, 2023; Weiner & Kukla, 1970). For example, teachers give more praise to students who succeeded through effort than to those who succeeded effortlessly (Covington & Omelich, 1979b , 1979a). In fact, teachers give more rewards to students with low ability who succeeded through hard work than to students with high ability who succeeded effortlessly (Weiner & Kukla, 1970).

Children tend to understand that teachers praise those who succeed through effort. From around age four, children infer that when a teacher praises one out of two students, the praised student worked harder-even if the praise makes no mention of effort (Barker & Graham, 1987). Such unequal praise can communicate low ability. When two students achieve the same success, the one who worked harder is often seen as lower in ability (Muenks & Miele, 2017). Children know that teachers praise for effort, so when they see that two students achieved the same success but only one student is praised by the teacher, they infer that the praised student is less smart (Barker & Graham, 1987; Miller & Hom Jr., 1996; Schoneveld & Brummelman, 2023). Thus, children use unequal praise as a low-ability cue when evaluating others. Crucially, however, it is unknown whether children make these inferences about themselves. When children achieve the same result as a classmate, but the teacher praises only them, would they infer that they themselves are less smart? This is a critical question because praise that lowers children's self-perceived ability can contribute to achievement gaps (Brummelman & Sedikides, 2023; Hofer et al., 2024).

Developmental Changes

From what age may children infer from praise that they are less smart? To make such an inference, children need to understand that those who succeed through hard work tend to be less smart than those who succeed effortlessly (i.e., the understanding that effort and ability can be compensatory). Some research suggests that, while young children think that those who work harder are smarter, children from age 9-12 understand that those who have to work harder tend to be less smart (for overviews, see Barker & Graham, 1987; Muenks & Miele, 2017; Nicholls, 1978).

Accordingly, studies adopting a third-person perspective found that older children (from about age 11) inferred that a child who received more praise for the same achievement was more hardworking but less smart (Miller & Hom Jr., 1996). By contrast, younger children inferred that the child who received more praise was more hardworking and smarter (Barker & Graham, 1987). However, recent work suggests that even children from age four can perceive effort and ability as compensatory (Cimpian, 2017; Muradoglu & Cimpian, 2020). Thus, whether children use unequal praise as a cue for low ability likely depends on children's understanding that effort and ability can be compensatory. This understanding likely develops before the age of 11, but whether children apply this understanding spontaneously may differ between contexts (Cimpian, 2017).

For this reason, we included a broad age range-children ages 7-13 years-so that we could explore age differences. We evaluated these differences rigorously. If children understand only from age 11 that effort and ability are compensatory, the effect of praise on self-perceived ability should be more pronounced for older children. Moreover, it should be more pronounced for children with a fixed mindset (Dweck, 1999)-who believe that ability is fixed, which leads them to believe that working hard signals low ability-and those who explicitly endorse the belief that working hard signals low ability (Miller & Hom Jr., 1996; Muenks & Miele, 2017). We explored all three possibilities.

Virtual Reality

To date, the impact of teacher praise on children's self-perceived abilities has not been investigated directly, probably because researchers lacked the tools to create a dynamic classroom setting where the causal impact of teacher praise can be studied experimentally. Creating such a setting, where children complete tasks alongside a classmate while being observed by the teacher, is almost impossible in regular laboratory settings.

We therefore developed a novel Virtual Reality (VR) procedure to recreate this context in a virtual world. VR combines the ecological validity of real-life interactions with the experimental control typically found in laboratory experiments (Blascovich et al., 2002). Children are immersed, from a first-person perspective, in a standardized yet lifelike context, which elicits more intense social processing than vignette-based methods (Verhoef et al., 2022). Children feel even more immersed in VR than adults do (Sharar et al., 2007), making it a particularly compelling tool for developmental research.

In the present research, we used VR to create the two necessary conditions under which praise can make children feel smart. First, children completed tasks alongside a virtual classmate, achieved the same success, and then received praise or no praise from the teacher. Only such a social-comparative context-where one person receives more praise than another-can lead praise to convey a message of low ability. Second, while children completed the tasks, they were observed by the teacher, who appeared to be knowledgeable of their abilities: Teachers observed children solving practice tasks (Study 1) or said that they had received information from children's parents about children's abilities (Study 2). Only when teachers appear knowledgeable of children's abilities can their praise signal low ability.

Present Research

We conducted two preregistered experiments in this dynamic virtual classroom environment. Children completed tasks alongside a virtual classmate while being observed by a virtual teacher who appeared knowledgeable about the children's prior abilities. Children achieved the same score as their classmate. In Study 1, the teacher praised the child or the classmate. In Study 2, we added two control conditions, so that the teacher praised the child, the classmate, both, or neither. Across both studies, we used general praise (e.g., "You did such a great job"), rather than effort praise (e.g., "You must have worked really hard"), as a critical test of the hypothesis that praise-even if it does not mention effort explicitly-signals to children that they are hardworking rather than smart. We hypothesized that receiving praise, while an equally achieving classmate does not, would make children feel less smart.

In Study 2, we explored the effects of teacher praise on children's physiological arousal, capturing in-the-moment affective responses that children may be unable or unwilling to report. If praise induces stress, it should increase heart rate, decrease heart rate variability, and increase skin conductance-responses which reflect parasympathetic withdrawal, a mix of sympathetic activation and parasympathetic withdrawal, and sympathetic activation, respectively (Kreibig, 2010). If praise induces social-evaluative threat, it should lead to blushing, an involuntary reddening of the face that occurs in response to perceived social scrutiny or evaluation, when individuals are worried that others might form unfavorable impressions of them (Brummelman et al., 2018; Leary et al., 1992).

Study 1

We hypothesized that children who received praise from the teacher while an equally performing classmate did not (self-praise condition) would perceive themselves as less smart (H1) and more hardworking (H2) than children who did not receive praise while their classmate did (other-praise condition). We explored whether praise influenced how children believe the teacher viewed their effort and ability, how liked children felt by the teacher, and how many challenges children took on (as low self-perceived ability may reduce challenge seeking, Zhao & Hu, 2026). We also explored whether effects of praise were moderated by task achievement and perceived task difficulty.

Methods

Participants

Participants were 237 children from Dutch elementary schools. We excluded 25 children who met preregistered exclusion criteria: fully missing data on key dependent variables (n = 22), incorrect praise delivery (n = 2), or technical malfunctions (n = 1). The final sample contained 212 children (59% girls, 41% boys, < 1% another gender, age: 7-12, M = 9.72, SD = 1.14). Most participants (96%) were born in the Netherlands (see Supplemental Material for details on socioeconomic background).

We received active informed parental consent for children's participation, and children provided assent.

Procedure and Design

Experimenters first visited schools to administer baseline surveys. Children reported their mindset by responding to the six items from the Implicit Theories of Intelligence Scale for Children (Dweck, 1999). Example items include: "You have a certain amount of intelligence, and you can't really do much to change it" (0 = strongly disagree to5 = strongly agree). Fixed-mindset items were reverse-coded, so higher scores indicated a stronger growth mindset (α = .82, M = 2.74, SD = 1.05).

Experimenters then visited schools to conduct VR sessions with each child individually.

Children wore a head-mounted display creating a multisensory environment, making it feel as though they had stepped into a generated world (see Figure 1).

Before children entered the virtual classroom, the experimenter told them that a real teacher and child from other schools were participating simultaneously (in reality, they were controlled by the experimenter). In the virtual classroom, children and the virtual classmate completed five puzzles each (called "figure-test"), alternating turns, with the participants going first.

The teacher told the students that the puzzles in each round were equally difficult. The puzzles, displayed on the board, were Raven matrices consisting of nine-piece patterns with the last piece missing, alongside eight numbered options for the missing piece (Raven, 1989). Children picked an answer for each puzzle and said their answer out loud. To create the impression that the teacher had some knowledge of the students' abilities, children completed a practice round of three puzzles before solving the five main tasks.

After completing all puzzles, the teacher told the children that they had both received the same score (three out of five), regardless of how the participating child had actually performed.

Children were then randomly assigned to one of the two conditions. In the self-praise condition, the child was praised, but the virtual classmate was not. In the other-praise condition, the virtual classmate was praised, but the child was not. The teacher walked to the non-praised child first (ensuring participants noticed that the other child had not been praised) and said: "[Name], you got three out of five puzzles right." The teacher then walked to the praised child and said: "[Name], you got three out of five puzzles right. Wow, you did such a great job! Honestly, that's really impressive!"

Self-Perceived Ability and Effort

After exiting the virtual environment, we measured our preregistered outcomes (via a survey on a tablet): self-perceived ability and effort (in randomized order). Children were asked: "Who is smarter, do you think? You or the other student?" and then "How much smarter are you/is the other student, do you think?" (a bit, quite a bit, much smarter). An overall score was created, ranging from0 = the classmate is much smarter than I am; to5 = I am much smarter than the classmate (selfperceived ability, M = 2.65, SD = 0.82). Children were also asked: "Who worked harder on the task, do you think? You or the other student?" and "How much harder did you/the other student work, do you think?" An overall score was created, ranging from0 = the classmate worked much harder than I did; to5 = I worked much harder than the classmate (self-perceived effort, M = 2.75, SD = 0.78).

Perceived Teacher View of Own Ability, Effort, and Liking

To index exploratory outcomes, children returned to the virtual classroom. To measure challenge seeking, they chose four times whether they wanted to do an easy task (with low chances of making mistakes, from which they would not learn much; scored 0) or a difficult task (with higher chances of making mistakes, from which they could learn a lot; scored 1). We created a mean score reflecting challenge seeking (M = .55, SD = .26).

After children exited the virtual classroom, we measured perceived teacher view of own ability, perceived teacher view of own effort, and perceived teacher liking (in randomized order, 6point scale). Children were asked: "Who does the teacher think is smarter, do you think? You or the other student?" and "How much smarter does the teacher think you are/the other student is, do you think?" Manipulation Check

Children were prompted to think back to when the teacher told them what score they got and were asked whom the teacher gave a compliment then (only them or only the other student).

Immersion

Children were asked: "What did you think of the VR?" They responded to the items "It just felt real" and "I was totally immersed in it" (0 = not true at all to3 = completely true, Verhoef et al., 2022). We created a mean score (r = .39).

Perceived and Objective Task Performance and Perceived Task Difficulty

Children were asked how many puzzles (0-5) they thought they had gotten right before the teacher had told them their score (M = 3.26, SD = 1.00). We coded children's task performance based on screen and audio recordings (valid data was available for 192 out of 212 children as some screen-recordings were missing, M = 2.49, SD = 0.93). Children were also asked: "How difficult did you find the figure-test?" (0 = not difficult at all to3 = really difficult, M = 1.33, SD = 0.55).

Data Analyses

We ran six linear regression models (i.e., one for each dependent variable) to determine the effect of condition (dichotomous; self-praise, scored as -1 vs. other-praise, scored as 1) on preregistered outcomes self-perceived ability and effort, and on exploratory outcomes challenge seeking, perceived teacher view of own ability and effort, and perceived teacher liking. We conducted analyses in R version 4.3.2 (R Core Team, 2023) using the lm.beta package (Behrendt, 2023). We used the University of Amsterdam's developed artificial intelligence website to refine our data analysis code.

Discussion

Contrary to our hypotheses, we found no evidence that receiving unequal praise made children feel less smart or more hardworking than their classmate. We also found no evidence that it led children to think that the teacher found them less smart, more hardworking, or liked them more than their classmate. Moreover, we found no evidence that any potential praise effects differed depending on children's age or mindset.

Study 2

In Study 2, we sought to establish, with greater confidence, that receiving praise does not make children feel less smart. To do so, we improved our design. First, we added control conditions in which neither child or both children received praise, so as to rule out that effects can be explained by receiving any praise at all instead of receiving more praise than a fellow student. Second, we made the praise more salient by having children solve tasks and receiving praise twice (rather than just once). Third, we measured physiological arousal to capture immediate responses related to stress and social-evaluative threat that children may be unwilling to report.

We also improved our outcome measures. First, we measured absolute rather than comparative self-judgements (e.g., "I am good at this" rather than "I am better at this than the other student") because the added control conditions in which both the child and the classmate were praised made social comparisons less meaningful. Second, we measured task-specific rather than domain-general self-perceived ability and effort because task-specific beliefs may shift more easily.

Third, we measured task-elicited rather than self-initiated effort ("I had to work hard" rather than "I worked hard") because task-elicited effort is typically interpreted as compensating for low ability (Muenks & Miele, 2017). Fourth, we measured interest in activities for "smart" vs. "hardworking" children (Bian et al., 2017) instead of challenge seeking to provide additional evidence that praise does not affect motivational outcomes. Fifth, we measured state self-esteem to capture whether praise makes children feel less worthy. Sixth, we measured children's understanding of effort and ability as compensatory to investigate whether praise effects depend on this understanding.

We hypothesized that children who received praise while their classmate did not (self-praise condition) would report lower perceived teacher view of own ability (H1), self-perceived ability (H2), and state self-esteem (H3) than children who did not receive praise while their classmate did (otherpraise condition). We explored comparisons with conditions in which both children were praised (both-praise condition) or neither child was praised (neither-praise condition). We explored whether praise influenced self-perceived effort, perceived teacher liking, interest in activities for "smart" vs.

"hardworking" children, and physiological arousal. We tested whether effects of condition on outcomes were moderated by task achievement and perceived task difficulty.

Methods

Participants

Participants were 257 children. Participants visited Science Center NEMO, a Dutch science museum in Amsterdam. The research was part of Science Live, a program that enables scientists to use NEMO visitors as participants. We excluded 32 participants who met preregistered exclusion criteria: the parent/caregiver withdrew consent (n = 1), fully missing data on key dependent variables (n = 21), incorrect praise delivery (n = 3), technical malfunctions (n = 2), or pilot sessions (n = 6). The final sample contained 225 children (48% girls, 51% boys, 1% another gender), aged 8-13 (M = 10.12 years, SD = 1.58). Most participants (97%) were born in the Netherlands (see Supplemental Material for details on socioeconomic background). We received active informed parental consent for children's participation and children provided assent.

Procedure and Design

Participating children first filled in a baseline survey. We used the same measures as in Study 1 for mindset (α = .78, M = 3.12, SD = 0.93). Children reported their perceived relationship between effort and ability by responding to four items, such as: "If you have to work very hard to achieve something, you are probably not very smart" (0 = not true at all to3 = completely true). The four items ( = .76) were averaged to create a mean score, with higher values indicating a stronger belief in a compensatory relationship between effort and ability (M = 0.98, SD = 0.63).

Participanting children then took part in the VR sessions. Children solved tasks (called "Memory," remembering as many objects as possible out of a set of objects displayed for 20 seconds) along with a virtual classmate in a virtual classroom, were told their score, and that the virtual classmate had the same score by a virtual teacher, and received (or did not receive) praise.

Solving the tasks and receiving praise occurred twice (trial 1 and 2). To create the impression that the teacher had some knowledge of the students' abilities, in the beginning of the VR session, the teacher appeared to review information about the students' abilities supposedly provided by parents/caregivers.

Self-Perceived Ability and Self-Esteem

After exiting the virtual environment, we measured preregistered outcomes (in randomized order). Children were asked: "How good are you at memory, according to [name teacher]? [Name teacher] probably thinks…". They responded to the items "that I am good at Memory", "that I can do Memory well", and "that I have talent for Memory" (0 = not true at all to3 = completely true; α = .85). We created a mean score (M = 1.79, SD = 0.64). Children were also asked: "How good are you at Memory, do you think? In this moment, I think…". They responded to the same items as for the measure of teacher-perceived view of own ability. We created a mean score (α = .84; M = 1.69, SD = 0.65). Children also responded to a shortened version of the State Self-Esteem scale (Thomaes et al., 2010). The items were: "Now, in this moment, I feel satisfied about myself", "… bad about myself", "… unsatisfied with myself", "… good about myself" (0 = not true at all to3 = completely true). We reverse-coded negatively-phrased items and created a mean score (α = .73; M = 2.40, SD = 0.53).

Self-Perceived Effort, Perceived Teacher Liking, Game Interest, and Physiological Arousal

We then measured exploratory outcomes. For self-perceived effort, children responded to the items "To solve the memory-task well, I had to really do my best", "… work hard", "… persevere" (0 = not true at all to3 = completely true). We created a mean score (α = .82, M = 2.09, SD = 0.70).

For perceived teacher liking, children were asked two questions (order randomized): "How much does teacher Anouk like you, do you think?" (teacher liking of the self,0 = does not like me at all to3 = likes me a lot, M = 2.16, SD = 0.70) and "How much does teacher Anouk like the other student, do you think?" (teacher liking of the classmate,0 = does not like the classmate at all to3 = likes the classmate a lot, M = 2.15, SD = 0.69). For game interest, children were asked how much they would like to play a game "in which only very intelligent children can be good" and one "in which only very hardworking children can be good" (Bian et al., 2017;0 = would not at all like to play to3 = would very much like to play; interest in games for smart children: M = 1.83, SD = 0.81, interest in games for hardworking children: M = 1.92, SD = 0.71).

We measured children's heart rate, heart rate variability, blushing, and skin conductance level. Markers were set for a baseline period (60s), for recall (while children solved the tasks), and for praise (immediately after children learned who did or did not receive praise). We aggregated the physiological data by computing one mean score per physiological measure, per participant, per period (i.e., baseline, recall, praise), and per trial.

Children were prompted to think back to when the teacher told them what score they got and were asked whom the teacher gave a compliment then (only them, only the other student, both students, or no one).

Immersion

We used the same measures as in Study 1 for immersion (r = .46).

Task Performance and Perceived Task Difficulty

We recorded children's task performance in round 1 (M = 5.37, SD = 2.00) and 2 (M = 5.29, SD = 1.67). We created a mean score (r = .42, p < .001, M = 5.33, SD = 1.55). Data Analyses

We preregistered analyses involving the two critical conditions: the self-praise and otherpraise conditions. We ran ANOVAs for the preregistered outcomes perceived teacher view of own ability, self-perceived ability, and state self-esteem, and for exploratory outcomes self-perceived effort and perceived teacher liking to determine the effect of condition on the outcomes. As preregistered, our interest was in specific pairwise comparisons between the self-praise and otherpraise condition, rather than in the overall omnibus F-tests, so we focused on Tukey-corrected pairwise comparisons between these two conditions.

For exploratory outcome game interest, ratings were nested within participants. We thus ran a mixed-effects model predicting game interest from game type (dummy coded using smart game as reference category), experimental condition (dummy coded using self-praise condition as reference category), and their interaction, with a random intercept for participants. We re-ran the model using the other-praise condition as the reference condition.

For exploratory outcomes physiological arousal, we ran mixed-effects models predicting heart rate, blushing, and skin conductance from experimental condition (dummy coded using selfpraise as the reference condition), period (recall = 1, praise = 0), trial (trial1 = 0, trial2 = 1), and baseline physiology (grand-mean-centered), the interactions between period and the condition dummies, and between period and trial, with a random intercept for participants. We ran a mixedeffects model predicting heart rate variability from experimental condition, trial, baseline HRV (grand-mean-centered), and the interaction between the conditions and trial, with a random intercept for participants. We used the University of Amsterdam's developed artificial intelligence website to refine our data analysis code.

Discussion

Contrary to our preregistered hypotheses, we found no evidence that unequal praise made children feel less smart, experience lower state self-esteem, or think the teacher found them less smart. We also found no evidence that it led children to feel more hardworking, show a stronger preference for games for "hardworking" (rather than "smart") children, or have higher physiological arousal. Moreover, we found no evidence that any potential praise effects differed depending on children's age, mindset, or perceived relationship between effort and ability.

Children thought that teachers liked praised students. This finding likely emerged only in Study 2 because the praise was more salient, and our updated measure picked up on more nuanced changes in perceived liking.

General Discussion

We used a novel Virtual Reality paradigm to test a previously unexamined question: Does receiving praise from the teacher-while an equally performing classmate is not praised-make children feel less smart? Across two highly powered and preregistered VR experiments in which we recreated a naturalistic classroom context and effectively manipulated teacher praise, we found no evidence that praise made children feel less smart. We also found no evidence that it raised children's physiological arousal, suggesting that praise did not trigger feelings that children were unwilling or unable to report. These results cast doubt on the widely held belief that teacher praise can make children feel less smart.

Theoretical Implications

Our findings suggest a dissociation between how praise makes children think about others versus the self. Previous research has adopted a third-person perspective, showing that when children learn that two students achieved the same outcome but only one of them was praised, they infer that the praised student is more hardworking but less smart (Barker & Graham, 1987; Miller & Hom Jr., 1996; Schoneveld & Brummelman, 2023). Using VR, we adopted a first-person perspective, finding no evidence that when children achieve the same outcome as a classmate but only they themselves are praised, they feel more hardworking or less smart. Thus, teacher praise can make children seem less smart in the eyes of others, but not necessarily in their own eyes.

Why may teacher praise not make children feel less smart? Children may evaluate themselves and others through two basic dimensions-warmth and competence (Fiske et al., 2007).

We suggest that when children meet a new teacher, they care primarily about being liked, less about being seen as smart, as establishing a positive relationship may matter most in such situations (Madjar et al., 2018; Urdan & Maehr, 1995). Indeed, in interpersonal encounters, individuals tend to initially focus on warmth before evaluating competence (Fiske et al., 2007). This may be particularly true for children in elementary school who have to navigate new social environments (Eskelä-Haapanen et al., 2017; van Rens et al., 2019). Our findings concur: Study 2 suggests that children view praise as a sign of being liked by the teacher. In particular, children who were praised by the teacher inferred that the teacher liked them more and liked the classmate less.

Did teacher praise make only some children feel less smart? One possibility is that teacher praise made only children from low socioeconomic status backgrounds feel less smart, because they may be attuned to low-ability cues due to frequent stigmatization (e.g., Goudeau et al., 2025).

Challenging this possibility, exploratory analyses revealed that the effects of teacher praise were not moderated by students' objective or subjective socioeconomic status (see Supplemental Material).

Another possibility is that teacher praise made only those children feel less smart who believe that those who work hard are less smart. This should be most true for older children, children who see an inverse relation between effort and ability, and children with a fixed mindset-groups who tend to infer that those who work hard are less smart (Cimpian, 2017; Dweck, 1999; Muenks & Miele, 2017).

Challenging this possibility, exploratory analyses revealed that the effects of teacher praise were not moderated by students' age, perceived relationship between effort and ability, or mindset.

The effects of praise did not differ between younger and older children. There is an ongoing debate about when children consistently understand that high effort can compensate for low ability (Muenks & Miele, 2017; Muradoglu & Cimpian, 2020). It is possible that only the oldest childrenthose from age 11 , who are generally thought to have this understanding (Muenks & Miele, 2017)would interpret unequal praise, experienced from a first-person perspective, as a low-ability cue.

Instead, we found no evidence that older children interpreted this unequal praise differently than younger children. Regardless of their age, children thus may not interpret unequal praise they experience from a first-person perspective as a low-ability cue.

Strengths, Limitations, and Future Directions

Our research pioneered Virtual Reality for testing causal effects of teacher praise in a classroom setting, combined self-reports with physiological measures, and replicated findings across two well-powered experiments with control conditions and moderators.

Our study also has limitations, which offer new research directions. First, our VR experiment does not capture teacher-student interactions as they unfold over weeks, months, or even years (Asaba, Santos, et al., 2025; Asaba, Stegall, et al., 2025; Corriveau & Harris, 2009). Future research should capture exactly when and how teacher praise can become a low-ability cue in teacher-student dyads. Second, we investigated effects of general praise. Because different types of praise have distinct effects on self-views and motivation (Amemiya & Wang, 2018; Brummelman et al., 2016; Cimpian et al., 2007), future research should examine distinct effects of different forms of unequal praise, such as praise that explicitly emphasizes effort. Third, our research was conducted in the Netherlands, an individualistic country that emphasizes both ability and effort as sources of achievement (Luyten & Bosker, 2004). Future research should examine whether the effects of teacher praise are more pronounced in countries emphasizing ability over effort, such as the United States (Holloway, 1988).

Conclusion

Teachers often use praise in an attempt to make children feel more competent. Yet, praise may communicate which children are liked by the teacher. Participants and Setting

In study 1, participating children attended one of four primary schools governed by a Catholic school board and located in small towns and villages in a semi-urban region in the Netherlands. Virtual Reality Procedure

Virtual Teacher and Classmate Characteristics

The VR software was developed by CleVR BV (https://clevr.net). Study 2 Analyses and Results

For Study 2, we examined whether the effect of condition on teacher-perceived ability, selfperceived ability, state self-esteem, perceived teacher liking, and physiological arousal was moderated by individual or contextual factors. We conducted regression models in which we included a) theoretical moderators (i.e., subjective SES, objective SES, age, mindset, perceived relationship between effort and ability, objective task performance, perceived task difficulty) and b) a methodological moderator (immersion in the virtual environment). For each outcome, both preregistered and exploratory, we tested regression models including condition (dummy-coded with self-praise as the reference group), the moderator, and their interaction as predictors. Moderators were mean-centered; subjective SES was not additionally centered because it was z-standardized prior to analysis. While SSS, task performance and immersion showed significant interactions with some condition dummies (see Table S5.2), none of these interaction effects were consistent across all conditions.

We also examined whether the effect of condition on game interest (interest in a game for smart vs. hardworking children) was moderated by individual or contextual factors. We estimated linear mixed-effects models predicting game interest from game type (smart game as the reference category), experimental condition (self-praise as the reference category), the mean-centered moderator, and their three-way interaction, with a random intercept for participants to account for the repeated-measures structure of the data. We tested moderation using the omnibus Type III Ftest of the three-way interaction, which tests whether the interaction between game type, condition, and the moderator differs from zero across all condition contrasts jointly. None of these three-way interactions became significant.

Marker Definition

Physiological data were collected continuously throughout the VR experiment. Markers were added for the following events: (a) 60-sec baseline, shortly after children entered the virtual classroom and were instructed to sit still for one minute; (b) Recall 1 (starting when the time for memorizing objects had ended and children were prompted to recall the objects aloud, ending when the child had finished recalling and the teacher resumed the protocol) ; (c) Praise 1 (starting after the teacher provided feedback and, depending on the condition, praise, to the participant -marking the moment when the participant learned which student(s) had received praise, ending after the teacher had returned to the board, waited approximately 15 seconds, and resumed the protocol), and (d) Recall 2 and (e) Praise 2, corresponding to the same events as in round 1 but occurring during the second task round.

Data Processing

We processed the physiological data using the start marker of each period. HRV data was sampled in 30-second segments following the guideline for HRV studies (Quigley et al., 2024), and all other physiological measures were sampled every 2 seconds. Following baseline markers, we extracted an average over 60 second-period of data for all measures; following recall-and praisemarkers, we extracted 30 seconds of data for HRV (as this is a recommended minimum), and 20 seconds for the other measures (since the marker type with the shortest average duration was 20 seconds, and using this window ensured consistency across participants).

If a participant's period (calculated based on the time difference between the start and end markers placed during the experiment) lasted less than 10 seconds, we excluded all physiological data for that period. If a participant's period lasted between 10 and 20 seconds, we excluded HRV values (as HRV requires a minimum of 30 seconds to yield reliable estimates), and computed the mean for the remaining physiological measures using only the markers that fit within the actual duration. We examined conditions differences in physiological arousal during praise and in the reaction to praise relative to the period before the praise (i.e., recall) because absolute values of blushing and skin conductance are not directly comparable across individuals (Braithwaite et al., 2013; Crozier & de Jong, 2012) and children may differ in their arousal levels during active classroom engagement.

To account for individual differences in physiological reactivity, we included a random intercept for each child, but did not estimate random slopes to avoid convergence issues.

The main effect of period reflects the difference in physiological arousal between the recall and praise phases within the reference condition during trial 1; The main effects of the condition dummy variables represent differences in physiological arousal during the praise phase of trial 1 between each experimental condition and the reference group; the period with condition interactions indicate whether the change in arousal from recall to praise (i.e., physiological reactivity) differs between each condition and the self-praise condition; The period with trial interaction tests whether the magnitude or direction of physiological reactivity differs between the two trials. We ran an extended model including the condition with trial and period with condition with trial (three-way) interactions. For none of the physiological measures did these interaction terms become significant, indicating that the effects of condition and period were consistent across the two trials. To follow up significant period with condition interactions, we used estimated marginal means derived from a model in which condition was specified as a four-level factor.

We fit a simpler linear mixed-effects model for the exploratory outcome heart rate variability (to account for the high number of missing values on the recall-periods), in which we only compared arousal differences during praise between the different conditions while controlling for baseline. We included predictors experimental condition, trial, baseline HRV (grand-mean-centered, covariate), and the interaction between the conditions and trial. We also included a random intercept for participant. Our primary interest was in specific pairwise comparisons, rather than in the overall omnibus F-tests, so we focused on pairwise comparisons. Physiological Reactivity in Self-Praise Versus Both-and Neither-Praise Conditions

Children in the self-praise condition differed from those in the both-praise condition in terms of their heart rate: Their heart rate remained higher (relative to when they were solving the tasks) after receiving praise (from 97.47 [95.55, 99.40] to 89.05 [87.20, 90.89] bpm, Δ = 8.43, p < .001) compared to that of children in the both-praise condition (from 99.35 [97.25, 101.45] to 87.98 [85.88, 90.07] bpm, Δ = 11.37, p < .001; b = 2.95, 95% CI [0.03, 5.86], p = .048, β = 0.05). Children in the self-praise condition did not differ from those in the neither-praise condition in terms of their heart rate. This suggests that when children receive more praise than an equally achieving classmate, their heart rate shows a smaller decrease after solving the task than when they receive equal praise as a classmate.

Children in the self-praise condition differed from those in the neither-praise condition in terms of their blushing: They retained stronger blushing (relative to when they were solving the tasks) after receiving praise (from 7696.62[6120.41, 9272.82] to 6376.72 [4827.23, 7926.2], Δ = 1319.90, p < .001) compared to children in the neither-praise condition (6799. 43[4856.43, 8742.43] to 3178.5 [1250.04, 5106.61], Δ = 3620.93, p < .001; b = 2301.03, 95% CI [219.96, 4382.11], p = .031, β = 0.07). Rpeaks were automatically detected using VSRRP9's built-in absolute-value peak detection algorithm.

A dynamically adjusting window of valid inter-beat intervals (IBIs) was applied to identify physiologically plausible beats when calculating heart rate and HRV. From the ECG, heart rate (HR; beats per minute) and heart rate variability (HRV) were extracted. HRV was quantified as the root mean square of successive differences (RMSSD; ms) over 30-s epochs.
