How Ethics Approval Check works

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Full text

Abstract

Event segmentationthe division of continuous experience into meaningful unitsis essential for understanding narratives. Yet little is known about how listeners segment auditory stories, how prosodic cues such as pauses contribute, and how age-related changes in hearing and cognition affect this process. We conducted two experiments to address these questions. In Experiment 1, human and advanced AI voices for audiobooks and podcast monologues produced longer pauses at thematic event boundaries than within events, indicating that pause timing aligns with narrative structure. In Experiment 2, younger (19-35 years old) and older (56-79 years old) adults listened to stories in which pauses were selectively prolonged at event boundaries or event centers. Older adults identified event boundaries more frequently overall. Prolonging pauses at event boundaries did not enhance boundary identification, whereas prolonging pauses at event centers led to boundary identification despite the absence of a major thematic shift, particularly in listeners with poorer hearing. Hence, aging may change the sensitivity to event boundaries during continuous speech listening, and pause duration can bias event segmentation when thematic cues are absent.

Introduction

Speech comprehension is critical for communication and social participation. Much of what we know about it comes from tasks in which listeners repeat or make judgements about short, disconnected sentences (Buss et al., 2019; Fogerty et al., 2021; George et al., 2006; Gifford et al., 2007; Gustafsson & Arlinger, 1994; Herrmann, 2023; Vickery et al., 2022). Such approaches differ from everyday speech perception: speech often unfolds as coherent narratives over tens of seconds to minutes (Bohanek et al., 2009; Hamilton & Huth, 2020; Herrmann & Johnsrude, 2020a; Irsik et al., 2022). Comprehending this type of speech requires integrating meaning over time to be able to extract the gist, which is not captured well by disconnected sentences.

Event Segmentation Theory (Zacks et al., 2007) offers a framework for assessing how individuals perceive, encode, and recall continuous experiences. It posits that experience is organized into discrete, meaningful units, referred to as events (Kurby & Zacks, 2008; Wang et al., 2024; Zacks, 2020; Zacks et al., 2007; Zacks & Swallow, 2007; Zacks & Tversky, 2001). That is, the brain maintains an "event model"a representation of the current situation that helps to predict upcoming information. Changes in a situation (e.g., moving between rooms) or its features (e.g. time, space, protagonist) are thought to increase prediction errors and trigger model updates that, in turn, yield perceived event boundaries (Zacks, 2020; Zacks et al., 2007). Individuals tend to agree on the placement of boundaries, referred to as "normative boundaries" (Panela et al., 2026; Sasmita & Swallow, 2022; Zacks et al., 2006). Segmenting audiovisual or written stories into events aids comprehension and later recall (Boltz, 1992; Lassiter, 1988; Lassiter et al., 1988; Newtson & Engquist, 1976; Schwan & Garsoffky, 2003; Zacks et al., 2006 Zacks et al., , 2007)). Event segmentation thus offers a promising, mechanistically grounded, approach to understanding the comprehension of naturalistic auditory narratives.

Thematic cues, such as changes in time, location, characters, goals, or causal structure, can be potent drivers of event boundaries in narratives (Bamberg & Marchman, 1990; Pettijohn & Radvansky, 2016; Speer & Zacks, 2005; Zwaan et al., 1995; Zwaan & Radvansky, 1998). For auditory narratives, however, the auditory signal itself may also carry information that could scaffold segmentation. Prosody marks structure in narratives through coordinated patterns of pitch, duration, and timing (Brugos et al., 2018; Féry, 2016; Frazier et al., 2006). Among these cues, sentence-level silent pauses are especially relevant for higher-level grouping because they punctuate larger units and are salient to listeners (Blau, 1990; Jacobs, 1988). In news broadcasts, longer pauses mark topic shifts (Shriberg et al., 2000; Tür et al., 2001), but whether this extends to other narratives is unclear. Moreover, topics can span multiple events, leaving unanswered whether speakers use longer pauses to mark event boundaries in non-news speech. This question is also relevant for modern text-to-speech systems, which are increasingly used in research and daily life (Ammari et al., 2019; Bentley et al., 2018; Buteau & Lee, 2021; Herrmann, 2023 Herrmann, , 2025c)), and may already be using, or could benefit from, human-like pausing at event boundaries.

Even if people and modern text-to-speech systems produce lengthened pause durations to mark event boundaries in speech, it does not necessarily follow that individuals use such cues to identify meaningful units during listening. The interplay of acoustic and thematic cues in speech comprehension is also unclear. Most work on how people segment ongoing input into events has been conducted using visual (reading, silent films) (e.g., Bailey et al., 2017; Feller et al., 2019; Newberry et al., 2021; Swets & Kurby, 2016) or audiovisual (movie) materials (e.g., Boltz, 1992; Sasmita & Swallow, 2022; Schwan & Garsoffky, 2004; Zacks et al., 2009). A key difference between these two modalities is that text readers often rely purely on thematic shifts for event segmentation, whereas film viewers make use of perceptual data in multiple domains (Cutting et al., 2012; Zacks et al., 2009). These materials, however, are unfit for studying acoustic cues in event segmentation, since listeners cannot revisit the input or rely on visual cues and have to segment a transient signal structured largely by prosody.

Speech comprehension and cognitive abilities change with advancing age (Cohen, 1987; Schneider, 2011; Wingfield, 2000). Older adults frequently report listening difficulties, particularly in noisy environments (Cruickshanks et al., 1998; Feder et al., 2015; Goman & Lin, 2016; Herrmann & Johnsrude, 2020a; Pichora-Fuller et al., 2016). Impaired hearing may render acoustic cues less evident, impeding the ability of older adults to segment the auditory input into events (Gordon-Salant et al., 2011; Roque et al., 2019; Schneider & Pichora-Fuller, 2001). On the other hand, there is evidence that older listeners may learn to rely more on salient temporal acoustic cues to manage perceptual uncertainty (Anderson et al., 2013; Souza et al., 2015; Wang et al., 2011). Neural data also suggest heightened responsivity to sound onsets (Alain et al., 2012; Herrmann et al., 2013 Herrmann et al., , 2018;; Sörös et al., 2009), such as speech onset after a pause, potentially increasing salience of pause cues.

Age-related changes in prediction abilities may also alter event segmentation processes (e.g., event-model updating): older adults often generate weaker linguistic predictions from context (Broderick et al., 2021; Federmeier et al., 2002 Federmeier et al., , 2003 Federmeier et al., , 2010;; Payne & Federmeier, 2018; Wlotko et al., 2010), which could influence how they identify and time event boundaries. At the same time, it has been proposed that older adults can leverage effectivelyand sometimes more effectively than younger adults the semantic context, particularly under effortful listening conditions (McCoy et al., 2005; Pichora-Fuller et al., 2016; Rabbitt, 1968 Rabbitt, , 1991;; Schneider et al., 2002; Sheldon et al., 2008; Sun et al., 2022). In an older population with normal hearing, however, this benefit may not be significant (Dubno et al., 2000).

Event segmentation further depends on prediction, working memory, and cognitive control, which are processes known to decline with age (Braver & West, 2011; Manard et al., 2014; Rozas et al., 2008). Reduced working memory can make the maintenance of contextual representations more difficult (Light & Capps, 1986; Noh & Stine-Morrow, 2009), and reduced inhibitory control can make it harder to suppress irrelevant information (Hasher et al., 1991; Hasher & Zacks, 1988; Kim et al., 2007; Rowe et al., 2006). That older adults sometimes exhibit poorer event segmentationreflected in lower agreement and poorer recognition of event structure (Kurby & Zacks, 2011; Zacks et al., 2006) has been attributed to such age-related decreases in cognition (Kurby & Zacks, 2011; Noh & Stine-Morrow, 2009; Smith et al., 2020; Zacks et al., 2006; but see Davis & Campbell, 2023; Kurby & Zacks, 2018). Whether event segmentation in auditory speech and the use of acoustic cues, such as pauses, differ between older and younger adults is unclear.

The present study investigates how thematic and pause-duration cues affect the identification of event boundaries during naturalistic speech listening in younger and older adults. After obtaining normative thematic event boundaries via an LLM approach (Michelmann et al., 2025; Panela et al., 2025), we first examine whether human speakers lengthen pauses at these boundaries and whether modern text-tospeech systems mirror these timing cues (Experiment 1). We then investigate whether pause lengthening at thematic boundaries shapes listeners' perception and how this interacts with age, hearing, and cognitive abilities (Experiment 2). Together, the current study provides a comprehensive account of how thematic and pauseduration information shapes event segmentation during speech listening in younger and older adults.

Experiment 1: Acoustic analysis of pause length at event boundaries in speech

Experiment 1 investigated whether pause lengthening marks event boundaries in human and in AI-synthesized speech. We obtained human audio recordings and transcripts, generated AI-voice audio from the same transcripts, and used a LLM to identify event boundaries in those transcripts. We then analyzed the audio recordings for pause lengthening at those boundaries.

Methods and materials

Transparency and Openness

Data and code are available at the https://osf.io/c7mk8/overview (https://osf.io/c7mk8/overview). The study design and analytic plan were not preregistered. Data preprocessing and initial analyses were performed in Python (v. 3.11.7); statistical analyses were carried out in R (R Core Team, 2022). To ensure transparency and openness, we detail our approach to data exclusion criteria, experimental manipulations, and all relevant measurements in the following sections.

Speech materials spoken by humans

We analyzed 200 existing auditory stories in American English: 100 audiobooks (stories read aloud) and 100 monologues (podcast stories told to an audience). The two categories differ in spontaneity, which can influence the duration and number of pauses (Bel, 2015; Kenny et al., 1998): audiobooks are read from existing text, whereas monologues are more naturally produced.

All stories were approximately 11 minutes long (mean duration: 671.92 s, SD: 154.55 s) and had existing transcripts. Most audiobooks (92%) came from LibriVox (https://librivox.org/), a collection of public-domain audiobooks read by volunteers, and the remainder (8%) from Listen to Genius (https://listentogenius.com/), which features professional actors. Monologues came from The Moth podcast (https://themoth.org/), in which speakers tell an audience short stories from personal experience (Cui & Herrmann, 2023; Gallardo Niacato, 2021; Gregory, 2020; Herrmann & Johnsrude, 2020b; Irsik et al., 2022; Michelmann et al., 2025). Both story types covered a variety of topics. Prolonged pauses and sound effects (music, laughter) were manually removed from the beginning and end of audio files where needed. Transcript errors were manually corrected, and paragraph breaks were removed such that the texts contained no physical segmentation cues, which is important for event-boundary identification using LLMs described below (Herrmann, 2025c; Michelmann et al., 2025; Panela et al., 2025).

Generation of synthesized speech

To examine whether AI voices mirror human pausing at event boundaries, we synthesized the 100 audiobooks and 100 monologues from their transcripts using three AI voices with a General American accent: the gender-neutral "Alloy" voice from OpenAI TTS ("text-to-speech"; model: 'tts-1'; Radford et al., 2023), and the "en-US-Casual-K" and "en-US-Studio-Q" male voices from Google TTS (https://cloud.google.com/text-to-speech/docs/list-voices-and-types; Oord et al., 2016). These voices were chosen because their prosody subjectively sounded close to natural speech. Audio was generated between January and June of 2025 via the OpenAI and Google APIs (Application Processing Interface) using custom Python scripts, with default pitch, speed, and volume parameters. Newer voices have been released since then.

Event segmentation procedure

Story transcripts were input to OpenAI's GPT-4o model (v2024-05-13; OpenAI et al., 2024) via its API in Python 3.11.7 (VanRossum & Drake, 2010), using a zero-shot prompt (Chen et al., 2025) previously validated for event segmentation (Michelmann et al., 2025; Panela et al., 2025):

An event is an ongoing coherent situation. The following story needs to be copied and segmented into large events. Copy the following story word-for-word and start a new line whenever one event ends, and another begins. This is the story: This was followed by the full story text and concluded by reiterating the instructions: This is a word-for-word copy of the same story that is segmented into large event units:

Temperature parameter, which controls randomness or creativity, was set to 0 for maximally deterministic outputs (Panela et al., 2025). Each event boundary was recorded as the word number of an event's final word. GPT-4o identified on average 10.44 events per audiobook (SD = 4.64) and 8.87 per monologue (SD = 2.74).

Forced alignment and pause duration calculation

Calculation of pause durations required obtaining times for word onsets and offsets. These were obtained through forced alignment, which aligns a transcript with its audio to derive word boundaries (Rousso et al., 2024). Different forced alignment algorithms can differ somewhat in their time estimations (Fromont et al., 2023; Rousso et al., 2024). To avoid a potential bias by a specific method, we separately calculated word onset and offset times using three different pipelines: Webmaus (https://clarin.phonetik.uni-muenchen.de/BASWebServices/; Kisler et al., 2017), ForceAlign (https://github.com/lukerbs/forcealign; Hwang et al., 2023) and WhisperX (https://github.com/m-bain/whisperX; Bain et al., 2023). The Webmaus approach was conducted through the online service provided by the University of Munich (https://clarin.phonetik.uni-muenchen.de/BASWebServices/), whereas ForceAlign and WhisperX pipelines were implemented in Python. The output of each pipeline contained onset and offset times for each word of a story. Around 10% of the stories where background sound effects overlapped with the speech and impeded estimating pause durations were excluded from the sample. (audiobooks: 10 files; monologues: 9 files).

We calculated pause durations at event boundaries and at event centers, the latter reflecting the sentence transition approximately midway between two boundaries. Because event boundaries always fell between sentences, event centers were also placed between sentences to allow comparison. Pause duration was defined as the interval between the offset of a sentence's last word and the onset of the next sentence's first word. For each story, voice (the original human voice and the three AI voices), and each of the three different forced alignment approaches, we computed the median pause duration across boundaries and across centers.

Although we focused on pause duration because previous research identifies it as an important cue (Blau, 1990; Jacobs, 1988; Shriberg et al., 2000; Tür et al., 2001), we also analyzed pitch and intensity contours, but no clear effects were observed (see Supplement 1).

Statistical analysis

Statistical analyses were conducted in R 4.2.1 (R Core Team, 2022). Linear mixedeffects models were fit using lme4 (Bates et al., 2015), with categorical predictors specified using sum (effects) coding and assessed using Type III Wald χ² tests (to avoid approximation errors and ensure computational stability given complex interaction structure and a large sample size). This was implemented in the car package (Fox et al., 2019). Effect sizes were estimated using effectsize (Ben-Shachar et al., 2020) and post hoc comparisons were conducted with emmeans (Lenth et al., 2026), using Tukeyadjusted p-values. Exact p-values are reported where possible; otherwise, conventional thresholds are used (e.g., p < .001). Given the large sample size, post hoc significance was assessed using standard asymptotic z-tests. We followed a maximal randomeffects approach, including random slopes when supported by the experimental design (Barr et al., 2013). Models resulting in singular fits were simplified to improve model stability.

A linear-mixed effects model was fit using the pause duration as the dependent measure, Reference Point (event boundaries, event centers), Voice (Human, Alloy, Casual, and Studio) and their interaction, Story Type (audiobooks, monologues) and forced alignment Pipeline (Webmaus, ForceAlign, Whisper) as within-story fixed effects and a random intercept for story (models with complex random slopes did not converge).

Results

The analysis revealed a significant Reference Point × Voice interaction (χ²(3) = 1693.81, p < .001, ηₚ² = 0.04). We also observed significant main effects of Reference Point (χ²(1) = 1097.23, p < .001, ηₚ² = 0.03), Voice (χ²(3) = 10719.66, p < .001, ηₚ² = 0.23), and Pipeline (χ²(2) = 482.20, p < .001, ηₚ² = 0.01). The main effect of Story Type was not significant (χ²(1) = 0.02, p = .901).

When unpacking the Reference Point × Voice interaction at the core of our research question, a significant difference between event boundaries (EB) and event centers (EC) was observed for the human speech (z = 51.42, p < .001) and Alloy voices (z = 11.95, p < .001). Conversely, the pause durations between EBs and ECs did not statistically differ within the Casual (z = 1.26, p = .207) nor Studio voices (z = 1.62, p = .106) (Figure 1). Participants

Thirty-six younger adults (median age: 21 years, age range: 19-35 years; 3 male, 28 female, 3 non-binary, 1 agender, 1 non-gender conforming) and thirty-six older adults (median age: 69.5 years, age range: 56-79 years; 18 male, 18 female) participated in the study. We performed a post hoc sensitivity analysis to ensure the sample size had sufficient power (see Supplement 3). Participants were native English speakers or had learned English before the age of 5 (for participants' ethnicity and second language abilities see Supplement 4). They reported having normal hearing and no neurological diseases. One person reported autism, but this did not affect their participation. None of the participants wore or had been prescribed hearing aids.

Hearing and cognitive assessment

Pure-tone audiometry was conducted at 0.25, 0.5, 1, 2, 4, and 8 kHz using a Maico M28 audiometer. Thresholds were averaged across ears, and the pure-tone average (PTA) was computed across 0.5, 1, 2, and 4 kHz (Humes, 2019).

Since cognition is integral for event segmentation (Zacks et al., 2007; Zacks & Swallow, 2007), we also administered measures of fluid intelligence and working memory span. Fluid intelligence was measured with the 12-item Raven's Advanced Progressive Matrices test (ArthurJR. & Day, 1994; Carpenter et al., 1990; Kpolovie, 2016; Loesche, 2020; Murphy et al., 2023; Raven, J, 1998; Rovetti et al., 2026). On each trial, participants completed a 3 × 3 matrix of geometrical shapes by selecting the missing bottom-right element, which would follow the matrix pattern, from eight options (for a sample matrix, see Bianchi & Schonfeld, 2021; Mitchum & Kelley, 2010). Participants had a maximum of 20 minutes for 12 trials.

Working memory was measured with a visual digit-span task (Jacobs, 1887; Wechsler, 2012). We chose a visual version to avoid confounds from age-related hearing loss. Visual and auditory digit span yield comparable performance in young adults (Olsthoorn et al., 2014). Digits (1-9) were presented one at a time for 1 s with no inter-digit interval, after which participants typed the sequence in order. Sequence length started at 3 digits and increased progressively to a maximum of 12 (Olsthoorn et al., 2014; Powell & Hiatt, 1996), with two trials per length. The task ended when both trials at a given length were incorrect, and the score was the longest length with at least one correct trial.

Age-group differences in PTA, Raven's, and digit-span scores were assessed with independent-samples t-tests, and all three measures were included in the regression models described below.

Speech materials

Participants listened to three stories, generated using LLMs for both text and speech synthesis (Georgiou et al., 2024; Herrmann, 2025c Herrmann, , 2025b)). Texts were generated with GPT-4o (v2024-05-13; OpenAI et al., 2024), using the following prompt (see also Herrmann, 2025b Herrmann, , 2025c Herrmann, , 2025a)): Generate a 2000 word humorous engaging story about <the topic>. Pay attention to the word count. Use simple vocabulary. The story should have at least 12 events, separated into paragraphs (an event is an ongoing coherent situation).

The story should not start with "once upon a time" and should not contain quotations, dashes, colons, or semicolons.

The three stories covered the topics "A hilarious airplane journey", "A stressful college exam and different ways of cheating", and "A day at the farm", comprising 1891, 1876, and 1923 words, respectively. Although the prompt mentions humorous stories to promote engagement, sentiment analysis indicated that the resulting stories were emotionally neutral, with comparable emotional content at event boundaries and event centers (see Supplement 5). A short practice story was generated using a similar prompt ("A stay abroad", 476 words). GPT-4o also generated ten comprehension questions and four response options (one correct, three incorrect) for each story. Materials were manually checked and edited where needed, and each story text was converted to a single paragraph. Audio files were generated with OpenAI's Whisper using the 'Alloy' voice (model: 'tts-1'; Radford et al., 2023), which produced pause durations most similar to human speech in Experiment 1. Audio files were manually verified to ensure high quality. Each experimental story lasted about 10 mins, whereas the practice story was about 2 mins.

Each story had pre-identified event boundaries resulting from the single prompt above (13, 13, and 14, respectively), all falling between sentences. We used these boundaries since LLM-identified boundaries are known to agree with human segmentation, sometimes even more closely than humans agree with one another (Michelmann et al., 2025; Panela et al., 2025). Word onset and offset times were obtained through Clarin's forced alignment web service (https://clarin.phonetik.uni-muenchen.de/BASWebServices/; Kisler et al., 2017) and used to locate the pauses at event boundaries and event centers (defined as in Experiment 1).

For every story, three pause conditions were created using MATLAB (v.

R2024b; The MathWorks, 2024) to investigate the effects of pause duration on event segmentation: Original (unmodified), Event-Boundary Pause, and Event-Center Pause (Figure 2). In the latter two conditions, pauses at event boundaries or event centers, respectively, were lengthened by inserting 1 s of silence at the pause midpoint. This 1-s duration was chosen to maximize potential effects without creating Event-boundary pause condition: prolongation of the pauses at the event boundaries by 1 s. Experimental procedure

Each participant listened to each of the three stories once (in a separate block), but each under a different pause condition. The order of stories and pause-conditions was counter-balanced across participants and age groups. A headphone icon was shown on the screen while a story was playing, and participants were asked to press the keyboard space bar whenever they felt one meaningful event had ended and another event had begun.

The notion of an event was introduced to participants in a short practice session, where they completed the task while listening to a 2-minute story. There were two runs during practice. In the first run, participants were asked to identify small events, whereas in the second run, participants were asked to identify large events in the same story. This procedure aimed to discourage overly fine-grained segmentation in the main experiment (Kurby & Zacks, 2011; Panela et al., 2025; Sasmita & Swallow, 2022; Swallow et al., 2018; Zacks et al., 2001). Instructions before the practice run were as follows:

In this experiment, you are going to listen to a series of stories. While listening, you will need to identify events in the story. Events are coherent complete sequences of actions, happening in the same time and place.

Events can be of different length. In the practice task, you will first need to listen to a 2-minute story and identify smallest meaningful event units.

Please press space when you feel that one event has ended and the next has begun.

Instructions before the second practice run were as follows:

You will listen to the same story the second time. Please now identify the largest meaningful event units. Please press space when you feel that one event has ended and the next has begun.

In the main experiment, participants were asked to only identify large events.

To check participants' attention, each story was followed by ten comprehension questions, presented in random order with four response options (chance = 25%), and answered using the keyboard.

Data analysis

Data preprocessing, initial analyses and regression analyses were carried out in MATLAB (The MathWorks, 2024). Other statistical analyses were performed through LMMs in R 4.2.1 (R Core Team, 2022). Similar to Experiment 1, linear mixed-effects models were fit using lme4 with sum coding. Effect sizes and Tukey-adjusted post hoc comparisons used effectsize and emmeans packages, respectively. Degrees of freedom for post-hoc testing were estimated using Kenward-Roger approximation (Kenward & Roger, 1997). Maximal random-effects structures were used where supported by the design, with singular models simplified for stability.

To assess evidence for our null findings, we compared models with and without the null effects using BIC-approximated Bayes factors (Raftery, 1995; Wagenmakers, 2007) via bayestestR (Makowski et al., 2019). To rule out bias from the uneven sex/gender split across age cohorts, we also compared each core model to one including Gender as a covariate using Likelihood Ratio Tests. Adding Gender did not improve model fit for any of our models (all p > .24), and all primary experimental effects remained unchanged.

Story comprehension.

For each participant, the percentage of correct answers was calculated for each pause condition (Original, Event-Boundary Pause, and Event-Center Pause). A LMM was fit using the percentage correct as the dependent measure, Pause Condition (event boundaries, event centers), Age Group (younger, older) and their interaction as fixed effects, and random intercepts for participant and story.

Number of button presses.

We calculated the number of button presses (used to mark event boundaries) for each pause condition and participant, and divided this number by the respective story duration in minutes, resulting in an average number of button presses per minute. A LMM was fit using this average number as the dependent measure, Pause Condition, Age Group and their interaction as fixed effects, and random intercepts for participant and story.

Agreement index. Consistency of boundary placement across participants is commonly measured with the agreement index, or inter-subject correlation (Panela et al., 2025; Sasmita & Swallow, 2022; Newtson, 1973; Newtson et al., 1977; Newtson & Engquist, 1976; Zacks et al., 2006; Zacks & Tversky, 2001), which quantifies how closely an individual's segmentation aligns with that of the group (Sasmita & Swallow, 2022; Zacks et al., 2006). For each participant and story/pause-condition, button presses were coded as 1s in an otherwise zero time series sampled at 50 Hz (0.02 s time steps). Time series were convolved with a Gaussian kernel (SD = 2 s) (Huff et al., 2017 (Huff et al., , 2018;; Newberry et al., 2021) to account for variability in response timing across participants. Each participant's time series was then correlated (Pearson's r) with the average time series of all other participants who heard the same story in the same pause condition, with higher values indicating greater agreement. A LMM was fit using the agreement indices as the dependent measure, Pause Condition, Age Group and their interaction as fixed effects, and random intercepts for participant and story.

Time-resolved probability of event-boundary identification.

The agreement index summarizes segmentation patterns across an entire story (Sasmita & Swallow, 2022; Zacks et al., 2006), but does not show when participants responded relative to specific points in the story. We therefore computed time courses of button presses around event boundaries and event centers (hereafter, reference points).

Analogous to event-related potentials in EEG (Luck, 2014), event-related pupil responses (Mathôt et al., 2018), and, most closely, peri-stimulus histograms of neural spiking (Gerstein & Kiang, 1960), this approach averages responses time-locked to recurring reference points, here button presses. For each participant and pause condition, button presses were placed on a timeline, where t = 0 was the reference point, and the full timeline (epoch) spanned -10 to +10 s around this point, allowing us to characterize responses over a broad temporal interval. A 2-s window was moved across this epoch in 0.05-s steps. At each step, the number of button presses within the window was divided by the number of reference points (event boundaries or event centers) in the story, providing a proportion of button presses in this window (as compared to the whole story). Taken together at all steps, proportions of button presses (response rates) result in time courses, which provide a measure of how responding changed around boundaries and centers. The 2-s window smooths over small differences in response timing.

Because each reference point is a pause, t = 0 can be placed at either edge of it: the offset of the preceding sentence or the onset of the following sentence. We computed time courses for both. Offset-locked time courses test whether responses follow the end of the preceding event, whereas onset-locked time courses test whether they follow the beginning of the next event. This distinction is important for our manipulated conditions, where the added 1 s of silence separates the two edges of the pause further.

For statistical analysis, response rates were averaged within a pre-reference window (-3 to -1 s) and a post-reference window (+1 to +3 s), chosen based on the evolution of the time courses. First, to test whether responding increased more after event boundaries than after event centers in speech without pause manipulations, response rates in the Original condition were analyzed with an LMM, including the factors of Reference Point (event boundary, event center), Time Window (pre, post), Age Group and their interactions as fixed effects and a random intercept for participant. Second, to test the pause manipulation, we computed the change in response rate from the pre-to the post-reference window (post-minus-pre = response_rate(+1 to +3) -response_rate(-3 to -1)) for each participant, pause condition, and reference point. This "baseline corrected" (Luck, 2014) response rate accounts for individual and group differences and biases in overall responses. Baselinecorrected responses were analyzed with an LMM including Pause Condition, Reference Point, Age Group and their interactions as fixed effects and random intercepts for participant and story.

A more detailed description of the full analysis procedure with examples can be found in Supplement 6.

Regression analyses.

To test whether cognitive and hearing abilities affected event-boundary perception, we ran two linear regression models, each with Raven's scores, digit-span scores, PTA, and age group as predictors. The first model isolated the influence of thematic shifts, using the baseline-corrected response rate at event boundaries in the 'Original' pause condition as the dependent variable. The second model isolated the influence of prolonged pauses, using the baseline-corrected response rate at event centers in the 'Event-Center Pause' condition as the dependent variable.

Discussion

We examined how pause duration and thematic shifts shape event segmentation in spoken stories. Experiment 1 shows that humans and modern AI voices produce longer pauses at event boundaries compared to event centers. Experiment 2 focused on whether pause durations are used by younger and older listeners to identify event boundaries. Older adults were more likely to identify event boundaries. Critically, we show for both age groups that pause lengthening does not contribute to event segmentation when a thematic story shift is present (i.e., at event boundaries), but that pause lengthening can lead to event segmentation in the absence of a thematic story shift (i.e., at event centers), especially for individuals with lowered hearing abilities. Our findings highlight the interplay between thematic and acoustic cues in producing and perceiving event boundaries. center for the Event-Center Pause condition as a function of PTA. Event Boundaries Are Marked by Prolonged Pauses in Human and AI Speech

The results of Experiment 1 show that human speakers produce longer pauses at event boundaries compared to event centers. This aligns with work showing that prosodic cues are crucial in signaling sentence boundaries in speech (Brugos et al., 2018; Frazier et al., 2006; Wagner & Watson, 2010), and topic shifts in news speech (Pfeiffer, 2001; Shriberg et al., 2000; Tür et al., 2001). Pause lengthening by speakers could potentially reflect different functions: real-time event processing by the speaker, a tendency for the speaker to aid event segmentation for the listener, or both. Disentangling these potential functions requires further research.

Experiment 1 also demonstrated that modern AI-based text-to-speech synthesizers capture this trend as well. That is, we found that a recent-generation AI voice -OpenAI's "Alloy" -produced longer pauses at event boundaries than at event centers. Older generations of text-to-speech models (e.g. Google's "Casual" or "Studio" voices) tended to exhibit a more uniform distribution of pause durations.

Perhaps the results may be expected, given that the speech input for model training may likely be based on audiobooks and podcasts, leading advanced models to capture human speech-production patterns.

Event Endings Matter More Than Event Beginnings for Segmentation

The results of Experiment 2 show that listeners consistently identify event boundaries during continuous story listening, in agreement with previous work (Kumar et al., 2023; Michelmann et al., 2021; Zacks et al., 2009). For our experimental manipulation and main analysis, we used event boundaries derived from LLMs (Michelmann et al., 2025; Panela et al., 2025), and the results confirm that humans identify event boundaries that were also identified by the LLM (Figure 6; supplementary Figure S2).

Experiment 2 further suggests that participants identified event boundaries based on information at the end of an event rather than waiting for a new event to begin (Figure 5). That is, in time courses locked to event onsets, responses in the Original condition peaked about 1 second after event onset, but when pauses at event boundaries were lengthened, the response peak was located at event onset.

Little to no information about the new event was available at this time. Had the listeners waited for the new event to unfold, response latencies relative to event onset should not have differed between conditions. Consistent with this, offset-locked responses peaked at similar times in both conditions (Figure 5). Listeners thus appear to detect event boundaries from event endings rather than beginnings.

This finding may contradict the framework proposed by the Event Segmentation Theory, which posits that event boundary perception is driven by prediction error elicited through the attempted integration of novel information into the current event model (Kurby & Zacks, 2008; Zacks et al., 2007; Zacks & Swallow, 2007). Our current results suggest that participants anticipate the near completion of an event rather than responding to a prediction error. Recent research has indicated that event segmentation may also be driven by prediction uncertainty (Franklin et al., 2020; Nguyen et al., 2024) such that event boundaries are perceived when the strength of predictions derived through the current event model reduces. Our data could thus reflect participants anticipating the impeding end to an event through the decrease in prediction strength. Responses after event ends could also be triggered by silence; however, silence alone is unlikely to drive boundary identification: responses at prolonged pauses were still significantly larger at boundaries than at event centers, indicating a role for thematic shifts.

Age-Group Differences in Event Segmentation

Older adults indicated the presence of an event boundary more frequently than younger adults, although the agreement with the event boundary placement did not differ between age groups (Figure 4B). Critically, this age-group difference remained after correcting for responses unrelated to event boundaries, using a pre-reference baseline (Figure 7).

Findings about age-related changes in event segmentation are mixed.

Research using audiovisual depictions of everyday activities suggests lower segmentation agreement and poorer recognition of event structure in older adults (Kurby & Zacks, 2011; Zacks et al., 2006). These declines have been attributed to age-related decreases in attention, working memory capacity, or processing speed (Kurby & Zacks, 2011; Noh & Stine-Morrow, 2009; Smith et al., 2020; Zacks et al., 2006). Nevertheless, other studies align more with the current findings, suggesting that event perception in movies (Kurby & Zacks, 2018) and written texts (Davis & Campbell, 2023; Radvansky et al., 2003; Radvansky & Copeland, 2001) is preserved with age, especially when using well-structured stimuli.

Older adults have sometimes demonstrated segmenting written and picture stories into fine-grained events (Magliano et al., 2012), although this is not always the case (Kurby & Zacks, 2011). Finer segmentation could imply that older adults have a lower threshold or shifted criterion for what counts as a meaningful thematic shift, such that they identify an event boundary even for less salient thematic shifts. This would be consistent with older adults' somewhat higher, though still low, rate of responses at event centers. Finer segmentation has been attributed to memory decline in older people (Braver & West, 2011), but neither memory span nor fluid intelligence predicted event segmentation in our study.

Interplay of Thematic Shifts and Pause Duration for Event Segmentation

The current results suggest that thematic shifts and acoustic cues interact when shaping event segmentation. Our observations and many previous studies have shown that thematic changes correlate with perceived event boundaries (Magliano et al., 2012; Zacks, 2020; Zacks et al., 2007 Zacks et al., , 2009;; Zwaan et al., 1995; Zwaan & Radvansky, 1998), although this has been much less investigated for speech listening (Kumar et al., 2023; Michelmann et al., 2021; see also Supplementary Materials). Thematic cues indicating event transitions provide a strong contribution to narrative structure organization (Bamberg & Marchman, 1990; Feller et al., 2019; Tür et al., 2001) and have been shown to increase the probability of event boundary responses (Davis & Campbell, 2023; Ezzyat & Davachi, 2011). Our data suggest that pause lengthening at event boundaries, however, did not further increase the probability for listeners to identify boundaries. Therefore, longer pauses may not provide additional information when a clear thematic shift is present in the narrative.

In contrast to event boundaries, prolonging pauses at event centersthat is, time points in the middle between two major narrative shiftsincreased the probability of an event segmentation response for listeners. The data thus indicate that in the absence of a thematic shift, pause durations can bias listeners into perceiving a boundary. Interestingly, we observed that the bias of perceiving an event boundary due to pause lengthening in the absence of a thematic shift (i.e., at the event center) was greater in people with greater hearing loss as indicated by the pure-tone average threshold. Hearing loss can lead to perceptual and neural hypersensitivity to sound (Baguley, 2003; Herrmann & Butler, 2021; Irsik et al., 2021; Tyler et al., 2014) that may particularly be expressed for sounds after a longer pause. Possibly, cochlear and neural changes associated with hearing loss result in greater sensitivity to acoustic cues that are then interpreted as a sign of an event in a story ending and a new event starting in the absence of a thematic shift. The scope of the study, however, limits this result to non-clinical hearing loss, given the sample characteristics (self-reported normal hearing, no hearing aids, and mild audiometric thresholds). This connection, therefore, needs to be further investigated in detail in clinical settings.

We also need to remark that Experiment 2 used a single AI voice and only three stories, requiring further work to confirm generalizability to human speech (despite high naturalness of AI voices) and a broader range of narratives.

Conclusion

We examined how speakers mark event boundaries in spoken stories and how listeners use pauses and thematic shifts to perceive them. Both human and AI speakers lengthened pauses at event boundaries. Listeners, however, relied primarily on thematic content and used pauses mainly when thematic cues were absent, particularly listeners with poorer hearing. Older adults identified event boundaries more often than younger adults. Together, these findings extend event segmentation research to the auditory domain and show that the way listeners organize continuous speech depends on the interplay of narrative content, acoustic cues, age, and hearing.
