Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

Animal research committee names - Institutional Animal Care and Use Committee / IACUC (US standard) - Any sentence containing animal(s) and committee (or board/panel) within ~5 words of each other — catches Experimental Animal Care and Use Committee, Animal Ethics Committee, Animal Welfare Board, Animal Welfare Ethical Review Body, etc. - UK: Animal Welfare Ethical Review Body / AWERB - Dutch: Dierexperimentencommissie / DEC (see DEC constraint above); Instantie voor Dierenwelzijn / IvD - German: Tierversuchskommission / TvK (advisory committee under §15 Tierschutzgesetz) - French: Comité d'éthique en expérimentation animale / CEEA; Comité d'éthique animale - Spanish: Comité de ética en experimentación animal / CEEA

Patterns are NOT designed to capture: - General ethical considerations or ethical dilemmas in study content - Mentions of “ethics” in theoretical or philosophical contexts - Author approval of a manuscript (e.g. “all authors approved the final version”) - Ethical behaviour as a measured variable (e.g. “ethical decision-making”) - URLs containing “ethics” in path components

Live data collection is detected by the internal helper .detect_live_data(), which searches for sentences indicating that data were collected directly from human or animal participants. Papers without any live-data signal are not flagged as missing ethics approval. The helper uses conservative patterns to avoid flagging secondary data analyses, computational experiments, or economics papers that analyse existing survey data. See .detect_live_data() for the full list of patterns and intentional exclusions.

A paper that states that no human or animal subjects took part (“no human subjects were involved”, “did not involve human participants”, or people taking part “not as subjects”) is not expected to have an ethics statement, whatever participant phrase it also has (see .detect_no_participants()). A negation near a participant phrase alone (“No participants were excluded”) does not count: it reports a study with participants.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

This module checks whether the data columns in a repository are documented in a codebook or README. How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Checking code requires downloading its file contents. For a paper whose repository is on Dryad, this never succeeds unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (listing the repository’s files does not need one). Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Purpose: The aim of this study is to determine which of four tasks testing different discourse genres (descriptive, procedural, conversational, and narrative) is the most sensitive in detecting syntactic and morphological complexity deficits in Spanish aphasia. Additionally, we compare two approaches for measuring syntax in discourse to identify the most accurate set of metrics for discriminating group membership.

Method: In this comparative cross-sectional study, we analyzed the discourse of an aphasia group (N = 20) and a non-brain-damaged group (N = 14). Data was preprocessed using manual and automated procedures. We measured syntactic complexity through proxies (mean length of utterance, noun-verb ratio, and verbs per utterance), in addition to a competing 'syntactic structures' metric. The latter includes variables of subordination, left branching, relative clauses, and word integration, while morphological complexity was measured through an inflectional index.

Results: The descriptive and narrative tasks highlighted the most significant differences across syntactic complexity metrics between the groups. Additionally, nested binomial logistic regression models showed that the 'syntactic structures' metric predicted groups better than the proxies alone.

Conclusions: A comprehensive assessment of syntactic complexity can be obtained through the administration of both descriptive and narrative tasks. The measurement of 'syntactic structures' in discourse proved a fitter and finer-grained approach for group discrimination than the incorporation of syntactic proxies alone. These findings provide guidance for a precise discourse assessment in Spanish aphasia.

1. Introduction

Syntax and morphology -the rules governing sentence structure and word formation and inflection, respectively -are key language components that are often impaired in aphasia following damage to fronto-temporal regions of the left hemisphere and the white-matter fibers that connect them. Syntactic complexity involves the use of recursive structures through clausal subordination and embedding (Hunt, 1970), while morphological complexity concerns how morphemes combine within words as well as how words relate to one another through inflection and derivation (Stump & Finkel, 2015). Deficits in both dimensions typically manifest in language use above the sentence level, that is, in discourse production (Armstrong, 2000).

Discourse, or connected speech, emerges from the interaction of phonological, lexicosemantic, and morphosyntactic processes (Prins & Bastiaanse, 2004), and is further shaped by pragmatic, cognitive and social factors (Linnik et al., 2015; Stark & Fukuyama, 2020, see Frau et al. 2025 for a review on pragmatic impairments). 2 Given this complexity, discourse assessment is essential for both aphasia evaluation and research (Bryant et al., 2016). Crucially, discourse analysis can uncover deficits that more constrained language tasks tend to miss (Beeke et al., 2003; Kemper et al., 2006; Marini et al., 2011), owing to its reliance on naturalistic and ecologically valid linguistic samples (Davidson et al., 2003; Doedens & Meteyard, 2019; World Health Organization, 2018). As components of the micro-linguistic dimension of discourse analysis (Glosser and Deser, 1991; Kintsch, 1994), syntax and morphology are a fundamental aspect of the evaluation of connected speech.

Despite its potential to inform the assessment of post-stroke syntactic deficits, cross-study comparison of syntactic complexity measures is challenging due to varying metrics and elicitation methods (Linnik et al., 2015; Stark et al., 2021a). Moreover, research on Spanish morphological deficits in aphasia discourse is particularly limited (Martinez-Ferreiro et al., 2017). To fill these gaps and guide researchers and clinicians toward a more efficient assessment of morphosyntactic deficits in aphasic discourse, this study investigates the simplification of syntactic and morphological complexity associated with aphasia in Spanish speakers, employing two metric approaches across different discourse genres to identify the most sensitive tasks and metrics.

1.1 Measuring syntactic complexity in aphasic discourse

Simplification of syntactic complexity, mainly manifested in a reduction of clause length and lower frequency of embedded clauses (Ulatowska et al., 1990), is a hallmark of impaired speech in speakers with aphasia (Schnur & Wang, 2024), especially those presenting with agrammatism, a cluster of language symptoms characterized by dysfunction in the production and comprehension of grammatical morphology and sentence structure (Menn & Obler, 1990). While syntactic simplification has been a common discourse marker in aphasia research, comparing results proves challenging given that discourse metrics measuring syntactic complexity are highly variable as well (Armstrong, 2000; Linnik et al., 2015). Two main approaches for measuring syntactic complexity can be discerned in aphasia studies. The most traditional approach requires parsing each separate utterance, counting of embeddings, and considering the subordination characteristics. Examples akin to direct measures of syntactic complexity include Glosser and Deser's (1991) 'weighted index of subordination', Sherratt's examination (2007) of subordinate clause frequency, clauses length, and the percentages of left branching, right branching, and main clauses; Wright and Capilouto's (2012) 'complexity index', and the automated extraction of 'syntactic accuracy' and 'structural complexity' scores reported by Schnur and Wang (2024). Evaluating the frequency and type of subordination and embeddings provides a direct index of the integrity of speakers' syntactic representations and mechanisms, at the cost of complex and time-consuming discourse processing steps.

Another possible approach to measuring syntactic complexity is implementing syntactic proxies, which involves adopting indirect measures to represent the complexity of a speakers' syntax. For instance, Vermeulen and colleagues (1989) described syntactic simplification in aphasic speech through reduced use of function words and shorter Mean Length of Utterance (MLU). Stark (2019) reported reduced proportion of verbs per utterance, in addition to an augmented noun-verb ratio and open-closed word class ratio. The usage of syntactic proxies has the advantages of saving time and effort, since they allow for the automated extraction of such variables using discourse analysis programs. Yet, metric analysis (e.g., the proportion of verbs per utterance or MLU) can only indirectly inform on finer-grained syntactic aspects, such as the presence of subordination and embeddings.

Relevant for this research, Agmon and colleagues (2024) proposed the 'syntactic structures' multidimensional metric, which consisted of cognitively demanding grammatical variables that are sensitive to aging or dementia. Such metric considers subordination, a homologue to previously used embedding indexes (Bastiaanse et al., 1996a; Gordon, 2020; Schnur & Wang, 2024; Sherrat, 2007; Ulatowska et al., 1990; Wright & Capilouto, 2012); Relative clauses, i.e. a form of subordination where a dependent clause modifies a noun in the independent clause; Left-branching clauses, which refers to a special form of subordination where the embedded clause is placed before or within the main clause; and complex noun phrases and complex adjectival modifications, both representing intraclausal combinatorial syntactic phenomena (see Table 2 for illustrative examples). Agmon et al. (2024) evaluated various syntactic complexity metrics, including the 'syntactic structures' model, and found that it outperformed other measures-e.g. sentence length, the Yngve score (Yngve, 1960), and syntactic frequency (Rezaii et al., 2022)-in detecting discourse differences between young adults and healthy elderlies. They observed that, compared to the younger group, the older group produced fewer subordinate clauses, relative clauses, and center embeddings per utterance.

While the measures described above have proved to be sensitive to the presence of syntactic simplification and agrammatism in aphasic speakers, no study has yet contrasted the relative accuracy, sensitivity and specificity of syntactic proxies and hierarchical syntactic metrics with this population.

1.2 Measuring morphological complexity in aphasic speech

Morphological processes are contingent upon the inflectional and derivational systems inherent to a specific language (Stump & Finkel, 2015). Particularly, inflectional morphology has garnered significant attention in speech and language pathology research, due to the challenges individuals with aphasia face, and particularly those with agrammatism, in producing finite lexical verbs (Bastiaanse et al., 1996a; Bastiaanse et al., 1996b; Bastiaanse et al., 2002; Martínez-Ferreiro et al., 2017).

While the majority of discourse studies have been conducted in English-speaking countries, the English inflectional paradigm is often regarded as simplistic (Beniamine, 2021) due to its limited number of inflected verb forms. Probably because of such a reduced inflectional paradigm, morphological errors are rare even in aphasic discourse samples (on average <0.57 errors made per task, as reported in Stark & Fukuyama, 2020). Consequently, morphological complexity as a discourse measure has been largely overlooked (Bryant et al., 2016; Stark et al., 2021a). Notable exceptions in discourse research include using an inflectional index in Dutch (Bastiaanse et al., 1996b), inflection proportion for nouns and verbs in English (Gordon, 2020), morphosyntactic accuracy in French (Sahraoui & Nespoulous, 2012), and finiteness proportion in Spanish (Martínez-Ferreiro et al., 2017).

1.3 Discourse genre sensitivities to syntactic and morphological complexity

An early focus of aphasia discourse studies was on the differential effects that elicitation genres had on linguistic measures.

Since the 1972 introduction of the Cookie Theft picture description task in the Boston Diagnostic Aphasia Exam (BDAE; Goodglass & Kaplan, 1972), different discourse elicitation methods have proliferated in both research and clinical assessment.

This has spurred increasing interest in whether discourse and associated metrics vary by task, and whether tasks can be meaningfully grouped into broader categories, such as discourse genres, based on the patterns they elicit, with potential clinical implications for the selection of assessment tools. Ulatowska and colleagues (1990) were among the first to demonstrate that different discourse genres tax the cognitive system distinctively and consequently elicit content that differs in information and structure (see also Doyle et al., 1995; Olness, 2006; Van Leer & Turkstra, 1999 for similar results).

The literature has converged on four core elicitation genres (Ulatowska et al., 1990; for a review, Bryant et al., 2016): expositional/descriptive, procedural/script, narrative, and conversational. In the expositional genre, subjects describe a topic -usually prompted by a single image or picture sequence -whereas the procedural genre elicits explanations of how a particular activity is carried out. The narrative genre involves recounting a factual or fictional story with characters, a setting, and a sequence of events, while the conversational genre entails an interactive dialogue with another speaker. These four genres have been systematically operationalized in AphasiaBank (MacWhinney et al., 2011; MacWhinney, 2019), a computerized database of clinician-patient interviews built around a tightly specified elicitation protocol in which investigators follow a structured script for questioning and narrative elicitation. A key advantage of AphasiaBank is its integration with the CHAT and CLAN programs, which allow a wide range of syntax-related indices to be computed automatically and accurately, facilitating cross-genre comparisons.

Recently, leveraging large-scale data from AphasiaBank and its computational resources, Stark (2019) systematically showed that expositional, narrative and procedural discourse each elicits unique linguistic features in both PWA and non-brain-damaged individuals. Stark and Fukuyama (2020) further highlighted that linguistic production is influenced by task type, aphasia type, and severity, with tasks in the same genre differing significantly from each other, while maintaining comparable linguistic features when compared to other genres. Other researchers (Coelho, 2002; Fergadiotis & Wright, 2011; Stark & Fukuyuma, 2020; Wright & Capilouto, 2009) have explored how specific task properties shape linguistic output beyond discourse genre.

Genre effects on discourse have been explained by top-down adjustments in the frame generation phase (Sherratt, 2007) of a multi-layered discourse model (Frederiksen et al., 1990). In Sherrat's (2007) model, conceptual frames generated at the early stages of discourse production reflect specific genres and provide the organizing grammar that eventually constrains the selection of syntactic structure during the stage of linguistic formulation. Hence, each genre activates a culturally generic frame structure (Mandler, 1987), while tasks within the same genre activate similar structures, resulting in shared downstream linguistic selection (Stark et al., 2021a).

Comparative studies mostly contrast descriptive and narrative genres (Fergadiotis & Wright, 2011; Olness, 2006; Schnur & Wang, 2024; Ulatowska et al., 1990; Van Leer & Turkstra, 1999). These studies reveal that picture description tasks often simplify syntax, typically eliciting declarative present-tense statements, deictic references, and limited verb production (Garrard & Forsyth, 2010; March et al., 2006; Stark, 2019), which contrasts with the syntactically richer production (e.g., more subordinate clauses) of narrative tasks. Additionally, picture descriptions may not reflect all aspects of real-world discourse and require minimal cognitive organization (Cannizzaro & Coelho, 2013; Olness, 2006). For example, in their study, Schnur and Wang (2024) compared the AphasiaBank's Cinderella story retell task (Goodglass & Kaplan, 1972) against the Picnic Scene description task from the Western Aphasia Battery (Kertesz, 2007) in a group of acute post-stroke participants, in order to determine which elicitation method more effectively captured language capabilities. They concluded that the storytelling task was more sensitive for assessing structural complexity in the discourse of this population.

In contrast, narrative tasks demand greater syntactic complexity, requiring reference to settings, event sequences, and character motives (Stark, 2019). Narratives have been shown to elicit more syntactic errors and complex structures than procedural tasks (Ulatowska et al., 1990), with storytelling being particularly useful for evaluating post-intervention syntactic improvements in PWA (Stark, 2019; Schnur & Wang, 2024). Previous research has concluded that the narrative genre typically involves a blend of past and present tense usage, with a lower frequency of nouns compared to other discourse types (Olness, 2006; Stark & Fukuyama, 2020).

Procedural (Stark, 2019; Ulatowska et al., 1981) and conversational genres seem overall inadequate for assessing syntactic complexity. Although less researched, conversational tasks often result in short, simple utterances with few errors, less conventional grammar, and limited syntactic richness (Beeke et al., 2003; Armstrong et al., 2011). However, high variability in conversational outcomes may be influenced by factors such as aphasia severity and conversational context.

While many aphasia studies have compared outcome measures across two discourse genres (Armstrong et al., 2011; Fergadiotis and Wright, 2011; Leaman & Edmonds, 2023; Olness, 2006; Pritchard et al., 2015; Schnur & Wang, 2024; Ulatowska et al., 1981; Ulatowska et al., 1990; Van Leer & Turkstra, 1999) or all three monologic genres (Stark, 2019; Stark & Fukuyama, 2020), there has not been a single study to our knowledge that encompasses all four identified elicitation genres. Given the task-specific nature of discourse and the heterogeneity of aphasia, a comprehensive study comparing multiple genres within a unified protocol and a same sample is needed. Additionally, employing a direct measure of syntactic complexity in comparison with syntactic proxies, as proposed by Agmon et al. (2023), would provide further insights into the sensitivity of linguistic metrics. Finally, it is essential to study syntactic and morphological complexity in an inflectionally rich language like Spanish (Real Academia de la Lengua, 2009), where morphological errors due to inflection challenges (Martínez-Ferreiro et al., 2017) can be more prevalent than in a morphologically poor language like English. To our knowledge, only one study has focused on Spanish post-stroke aphasic discourse (Martinez-Ferreiro et al., 2017), thus a thorough investigation of how morphological and syntactic simplification manifest across discourse tasks bears significant clinical and research relevance.

1.4 The Spanish morpho-syntactic system

Spanish is an inflected and synthetic Indo-European language with a rich morphosyntactic system (Martínez-Ferreiro et al., 2017). In the nominal domain, nouns are inflected for number and gender, and all modifiers within the noun phrase -articles, demonstratives, quantifiers, and adjectives -must agree with the head noun in both features (Real Academia Española, 2009).

Grammatical gender is arbitrarily assigned to nouns regardless of real-world referents (mesaFEM/table, huertoMASC/garden), though in animate nouns it frequently coincides with the sex of the referent (hermano, brother; hermana, sister), where the -a or -o morpheme often, but not always, reflects information about the referent's sexfoot_1 . Both attributive and predicative adjectives canonically follow the head noun (la casa roja, 'the red house', la niña está callada, 'the girl is quiet').

In the verbal domain, Spanish presents moderate complexity, encompassing 16 complete paradigms: 10 tenses in the indicative mood and 6 in the subjunctive, plus the imperative (Martínez-Ferreiro et al., 2017). Simple finite verbs are built from the verbal root and thematic vowel (-a, -e, -i), to which markers of tense, aspect, mood, person, and number are suffixed (Hualde et al. 2012). Aspect is morphologically distinguished in the past tense, which contrasts the preterit and the imperfect, and periphrastically in the present and future tenses (Real Academia Española, 2009). This articulate inflection paradigm renders subject pronouns pragmatically optional, classifying Spanish as a pro-drop language.

Verb phrases are structured around a lexical verb that may be accompanied by auxiliaries and clitic pronouns (El líbro loclitic leí ayer, 'The book, (I) read it yesterday'). The auxiliary haber constructs compound tenses followed by the past participle (he comido, '(I) have eaten'), while transitive verbs allow passive constructions formed with ser plus the past participle. Spanish also offers several periphrastic constructions for temporal reference, most productively the present progressive (estar + gerund) and future-referring periphrases (ir a + infinitive). Temporal adverbs such as ayer ('yesterday') and mañana ('tomorrow') must be compatible with the verb form used; any mismatch results in ungrammaticality (*ayer vendremos, 'yesterday we will come').

As for subordination, in Spanish complement clauses and relative clauses are syntactically fixed in post-head position (Creo que Juan llegó tarde, 'I think that Juan arrived late'; el libro que compré ayer, 'the book that I bought yesterday') (Real Academia Española, 2009). Adverbial clauses, by contrast, are positionally flexible: while they most frequently appear post-verbally (Me quedé en casa porque llovía, 'I stayed home because it was raining'), they can be fronted for discourse-pragmatic reasons (Si llueve, me quedo en casa, 'If it rains, I'll stay home').

1.5 Morphological and syntactic complexity in Spanish aphasia

Investigations on the morphological complexity of aphasic discourse in Spanish are very scarce. Using semi-structured interviews, Martínez-Ferreiro and colleagues (2017) investigated the production of verbal inflection in Spanish and reported a reduced rate of finite verbs produced by non-fluent people with mixed aphasia (PWA) compared to fluent PWA and the control group.

Greater information on finite verb production can be gathered from studies focusing on agrammatic production with structured tasks (e.g., delayed repetition, sentence completion, morphological transformation), which have generally reported selective impairment for tense compared to subject-verb agreement markers (person and number) (Benedet et al. 1998; Díeguez-Vide et al. 2012; Gavarró & Martínez-Ferreiro, 2007; Martínez-Ferreiro, 2003 , 2010 , 2013; Moreno-Torres Sánchez et al. 2005; Stecher et al. 2024; for a review, see Martínez-Ferreiro et al. 2015). This dissociation has been linked to reduced processing resources in PWA compared to brain-undamaged participants (Burchert et al. 2005; for a review, see Druks, 2014; Garraffa & Fyndanis, 2020).

As for nominal inflection, findings from a completion task in Spanish have shown that gender markings are frequently affected in aphasic production, with opaque conditions 4 often resulting in more errors (Piazza et al., 2022) 5 . To our knowledge, no study has so far investigated the complexity of nominal inflection in Spanish using discourse tasks.

Available evidence on the syntactic complexity of speech in Spanish aphasia is also scarce.

Hernández-Sacristán and Rosell-Clarí (2009) investigated how a group of PWA utilized the Spanish and Catalan "que" (that) during natural, undirected conversation. The results revealed not only that PWA used a restricted and simpler range of syntactic configurations compared to healthy controls (e.g., fewer relative clauses), but also that their speech was remarkably free of strictly ungrammatical errors. Similarly, Martínez-Ferreiro et al. (2017) reported that the production of subordinate clauses by fluent and non-fluent PWA in semi-structured interviews was significantly lower compared to a group of unimpaired speakers, although the study does not indicate the type of subordinate clauses produced. This line of evidence converges with findings from sentence elicitation tasks showing that the production of relative clauses (along with wh-questions and object clitics) is significantly impaired in Spanish agrammatism (Martínez-Ferreiro, 2010).

2. The current study

The current study aims to investigate how discourse tasks of different elicitation genres capture syntactic simplification and morphological deficits associated with aphasia in Spanish speakers. Our goals and approach are motivated by the clinical and research relevance of ecologically valid methods for the evaluation of clinical populations (Davidson et al., 2003; WHO, 2018). As reviewed above, spoken language can be elicited through a variety of discourse methods, each placing different demands on speakers that, in turn, can give rise to task-specific degrees of morphological and syntactic complexity in the output. In a similar vein, a range of syntactic complexity measures can be extracted from spontaneous speech, with their relative frequency shaped by the type of task used, presumably due to top-down adjustments in the task-specific conceptual frames generated during the early stages of discourse production (Sherratt, 2007).

Comparing outcomes across discourse genres and identifying which metrics and tasks best capture syntactic complexity in Spanish can support the adoption of ecologically valid methods in both research and clinical settings. Critically, by examining discourse production in Spanish, our study also aims to enrich the field of aphasiology by contributing data from an underrepresented language.

Hence, we attempt to answer three main questions: (1) Which discourse task is more sensitive to the detection of syntactic complexity simplification in the discourse of Spanish PWA?

(2) Which discourse task is more sensitive to the detection of morphological complexity deficits?

(3) Is 'syntactic structures' metric (Agmon et al., 2024) a better fit for assessing aphasic features in connected speech than the syntactic proxies one? Identifying the most suitable metrics and elicitation tasks to detect syntactic and morphological impairment has the potential to inform therapeutic programs (Leaman & Edmonds, 2023) and supports the crosslinguistic goal of disentangling language-specific impairments in Spanish aphasia (Linnik et al., 2015).

When compared with the expositional and procedural discourse, the narrative genre is frequently identified as the most syntactically and morphologically complex, as reflected in the proportion of embeddings (Schnur & Wang, 2024; Ulatowska et al., 1981; Ulatowska et al., 1990), syntactic complexity proxies (Stark, 2019; Stark & Fukuyama, 2020), and the usage of both past and present tense (Stark & Fukuyama, 2020). Although comparison between narrative and conversational genres are uncommon, the dialogic nature of conversational discourse allows for less conventional grammar to emerge in produced utterances (Armstrong et al., 2011; Beeke et al., 2003; Sajjadi et al., 2012). Thus, we hypothesize that a narrative task will be the most sensitive in detecting syntactic complexity deficits. Considering the possibility of eliciting more verbs with person and tense inflections, (Olness, 2006; Stark & Fukuyama, 2020), we hypothesize that the narrative task will also be the most sensitive in detecting morphological complexity deficits.

Additionally, we hypothesize that 'syntactic structures' (Agmon et al., 2024) will be a better metric for measuring the syntactic simplification of aphasic discourse than syntactic proxies, given the former's broader and more comprehensive scope.

3.5 Statistical analyses

Statistical analyses were performed using Jamovi (v 2.3.21.0; 2023), and plots were obtained in R (version 4.2.3, R Core team, 2023) via the ggplot2 package (v 3.5.1; Wickham, 2016) from RStudio (R Core Team, 2023). For each group, measures of central tendency were first calculated for each task and dependent variable (see Tables 3 and 4). Afterwards, based on the parametricity of the data (obtained via Levene's Test for Homogeneity of Variances), either Kruskall-Wallis tests or Welch's One-Way ANOVAs were executed in order to compare syntactic and morphological variables between both groups in each task. P-values resulting from group comparisons for each variable within each task were corrected using the Benjamini-Hochberg method (Benjamini & Hochberg, 1995). Post hoc analyses were conducted after significant main effects of group were observed. A simulation-based post-hoc sensitivity power analysis was conducted in R using the PMCMRplus package (Pohlert, 2024) to estimate the minimum effect size our design had 80% power to detect at  = .05 (5000 simulations). We assessed the statistical power of each between-group comparison using the same parametric and non-parametric inferential tests as those used in the main analyses. Moreover, to characterize the empirical precision achieved by our study, we calculated effect-size estimates and their 95% confidence intervals (Appendix Table B) using the effect size package in R (Ben-Schachar et al. 2020).

In order to examine whether the syntactic proxies or the 'syntactic structures' metric better predicted group category, four binomial logistic regression models were implemented using all discourse samples combined. Differently from Agmon and colleagues (2024), we used a nested modelling approach, which allowed for an accurate statistical comparison of the amount of variance explained by each model. Predictive performance was assessed using several key measures: accuracy, which refers to the proportion of both correct positive and negative predictions out of total predictions; sensitivity (i.e. the proportion of actual positives correctly identified), specificity (i.e. the proportion of actual negatives correctly identified), and the Area Under the Curve (AUC), which provides an overall assessment of the model's ability to discriminate between groups.

For this matter, 3 nested models were designed progressively including: A.1) the syntactic proxies, A.2) the measures contained in the 'syntactic structures', and A.3) the error-centered variables. A fourth model (B) was implemented after trimming for the predictors that showed high collinearity (i.e., a Variance Inflation Factors [VIF] greater than 5), and was based on its significant contribution to model fitness, to enhance parsimony.

5. Discussion

The current study aimed to identify which elicitation methods, from a set of tasks pertaining to different discourse genres, were most sensitive to capturing simplification of syntactic and morphological complexity in Spanish aphasia, and to determine the best measurement approach for this purpose. PWA and control participants' speech was analyzed to quantify syntactic proxies, such as mean length of utterance, number of verbs per utterance, noun-verb ratio; syntactic structure variables, which included different types of subordinate clauses (relative, left-branching clauses), complex noun phrases and adjectival/adverbial modifications; and finally, error-centered variables (i.e., ungrammatical sentences and morphological errors). The performance of these different metrics was compared to assess their accuracy in classifying participants into either PWA or control participants. Based on previous studies (Olness, 2006; Schnur & Wang, 2024; Stark, 2019; Stark & Fukuyama, 2020; Ulatowska et al., 1981; Ulatowska et al., 1990), we hypothesized that the narrative task would elicit the most significant differences between the aphasia and control group in both syntactic and morphological complexity, and that syntactic structure variables would be more accurate than proxies in determining participants' group membership, in line with Agmon et al. (2024). The results only partially support our hypotheses. Both the descriptive and the narrative tasks were useful to identify patterns of syntactic simplification, although to differing degrees. Moreover, none of the four tasks elicited significant group differences in morphological complexity. Finally, fine-grained syntactic structure metrics proved to be fitter and more accurate than proxies in determining group membership. In the following, we discuss these results and their implications in greater detail.

5.1 Both the narrative and descriptive tasks are useful for comprehensively assessing syntactic complexity

Analyses of variance indicates both the Cookie Theft picture description and the Hare and the Tortoise story retell tasks were sensitive to detecting syntactic simplification in aphasic speech, although the scope of their sensitivity appears to differ. On one hand, the Cookie Theft picture description consistently and reliably elicited group differences in several dependent variables that included both syntactic proxies and syntactic structure, such as MLU, relative and subordinate clauses and complex noun phrases and adjectival modification, but not in error-related measures.

On the other hand, the Hare and Tortoise study retell showed reliable group differences in left branching and complex adjectival/adverbial modification. Moreover, our PWA group tended to produce a significantly higher number of ungrammatical sentences compared to the control group (although this effect sits slightly below the minimum detectable effect threshold indicated by our sensitivity analysis, see Appendix B).

Overall, these results are at odds with our research hypothesis, which stated that the narrative genre-Hare and Tortoise story retell-would be the most sensitive to detecting syntactic complexity deficits in PWA. Based on previous findings (Schnur & Wang, 2024), we expected that the narrative task would elicit more syntactically complex discourse than the descriptive task in aphasic populations, which would in turn be reflected in greater inter-group differences. In their study, Schnur and Wang (2024) concluded that storytelling elicits structurally more diverse discourse than picture-description tasks. However, notable methodological differences exist between their study design and the current research, which could account for the differing outcomes. Firstly, Schnur and Wang (2024) employed different variables from the 'syntactic structures' metric (Agmon et al., 2024) that the present study adopted, which makes the comparison difficult and can yield different results. Secondly, Schnur and Wang (2024) utilized different discourse tasks compared to our study, namely the Picnic Scene (Kertesz, 2007) and the Cinderella story retell tasks (Goodglass & Kaplan, 1972). This last point is potentially critical since significantly different outcomes in distinct tasks within the same genre have been reported (Coelho, 2002; Fergadiotis & Wright, 2011; Stark & Fukuyama, 2020; Wright & Capilouto, 2009).

Two key differences between the Cinderella and the Hare and Tortoise story retells are that the former provides significantly less visual support, considering participants are asked to narrate the story just after viewing the pictures. In contrast, in the Hare and Tortoise task speakers can inspect the four-picture material while narrating the story. Furthermore, it is possible that the Cinderella story retell elicits syntactically more complex content, as its narrative involves a longer plot, and a greater number of characters and constituent events compared to our task.

Overall, our data show that descriptive and narrative tasks may be sensitive to group differences at different syntactic levels. On the one hand, the Hare and Tortoise story retell task elicits reliable group differences in the number of subordinate clauses, left branching and adjectival/adverbial modifications, all of which relate to speakers' capacity to build hierarchically structured sentences through clause-level modifications. On the other hand, the Cookie Theft picture description task is able to detect group differences in syntactic complexity also at the NPlevel, as evidenced by the significant difference between the two groups in relative clauses and complex NPs. Plausibly, picture description tasks require speakers to introduce NPs associated with referents identified in a visually rich scene and to elaborate on them through devices such as relative clauses, while narrating a story demands the creation of a temporal and causal scaffolding that relies more on left branching and adjectival/adverbial modifications.

Visual inspection of the data (Figure 2) seems to corroborate this interpretation.

Specifically, describing a picture and narrating a story may lead the control group to preferentially produce NP-or clause-level syntactic complexity, respectively. Although our narrative task showed less consistency in demonstrating significant group differences across syntactic variables than the Cookie Theft picture description, when comparing both tasks within the control group (see exploratory analysis in the Supplementary Table S6) significant differences (before Benjamini-Hochberg correction) show that the Hare and the Tortoise story retell evoked longer left-branching clauses and more complex adjectival/adverbial modifications than the Cookie Theft description task. Specifically, left branching clauses were frequently used as adjectival/adverbial phrases, since they provided supplementary information pertaining to various aspects such as time specifications, cause-and-effect relationships, and conditional statements. In contrast, a greater number of relative clauses was produced in the Cookie Theft picture description compared to the Hare and Tortoise task. The increased frequency of relative clauses boosted the mean dependency distance in relative clauses and amplified the number of words in complex noun phrases (see for example participant 23 in Table 2). While these patterns should be confirmed by further studies with larger samples, they suggest that speakers within the control group tended to employ a different pattern of syntactic structures and discursive resources in order to respond to the particularities of each task demand, in line with Sherrat's (2007) model.

Plausibly, when participants are involved in a single-picture description task, they first retrieve a frame structure that pre-activates the employment of relative clauses, facilitating the specification of nouns leading to a more informative description of the stimuli. Likewise, when participants are required to retell a story, they retrieve a frame structure that eases the availability of left branching clauses, which function as adjectival or adverbial phrases. Adverbial clauses are desirable for a narrative task given they provide an explicit organizing scaffold to a sequence of events, while left branching clauses can operate as a stylistic device that builds up suspense.

However, additional research is necessary to corroborate this interpretation and clarify the specific task properties that influence the use of complex syntactic structures.

In line with Ulatowska et al. (1990), the Hare and the Tortoise story retell not only elicited significant differences between groups in MLU and most 'syntactic structure' variables, but also in the proportion of ungrammatical utterances, unlike the Cookie Theft picture description.

Narrating a story involves the embedding of its events in a temporal scaffold and thus it can trigger the formulation of tense sequences and richer syntactic structures, which in turn can increase the probability of producing ungrammatical structures. Eliciting ungrammatical utterances in aphasia assessment has great clinical value, since it can provide qualitative information about which specific language mechanisms are impaired.

The present results also align with prior literature identifying procedural (Stark, 2019; Stark & Fukuyama, 2020; Ulatowska et al., 1981) and conversational genres (Armstrong et al., 2011; Beeke et al., 2003; Sajjadi et al., 2012) as unfit elicitation methods for the assessment of syntax.

The Ham and Cheese Sandwich procedural task evoked a high noun-verb ratio given the frequent list-like utterances employed, and the fewest number of utterances (e.g., participant 22: "you need sliced bread, ham, cheese and butter" ["se necesitan pan de molde, jamón, queso y mantequilla"]).

In contrast, the Structured Interview conversational task elicited the largest number of utterances prompted by five consecutive questions, but the outcome of both groups was often syntactically poor and short in length. This conversational task did not demand extensive answers, as the syntactic information contained in the questions themselves allowed for pragmatically short responses. As an illustration, participant 33 of the control group briefly responded to the question "What are you going to do for Christmas?" ("¿qué va a hacer en Navidades?") with "spending time with the family" ("hacer vida en familia [% cn:3]"). Although in line with previous literature, our failure to detect syntactic complexity in these two tasks should be interpreted with caution, given their limited power (Appendix B). Beyond the constraints imposed by sample size, the reduced power observed in these two tasks may nevertheless reflect the nature of the speech they elicited: both the list-like formulaic utterances and the pragmatically short responses of the structured-interview task offered very few opportunities for most of the syntactic structure variables under investigation to occur. This restricted range not only limits the number of observable target structures per participant but may also mean that group differences in syntactic capacity are less likely to be elicited by these two tasks, in contrast to the greater variety of syntactic structures available in narrative and descriptive elicitation contexts.

Furthermore, we consider that both pragmatic and contextual factors influenced the performance of participants in the discourse tasks. An important consideration is that participants' informativeness and engagement, as evidenced by the length and number of utterances, may be significantly influenced not only by clinical variables but also by the assessment setting, session rapport, and their inherent personality traits. This is especially relevant for the Structured Interview, where questions delve into the speakers' personal lives and habits. Consequently, in addition to syntactic impairment, the high variability in the number of utterances observed in the Structured Interview (see Table 3) may also be explained by differences in expressive pragmatic skills and/or individual and situational differences (Armstrong et al., 2011). Conversational production is indeed regarded as a useful tool for assessing expressive pragmatic skills (see, for example, the Assessment of Pragmatic Abilities and Cognitive Substrates protocol by Frau et al., 2025). Therefore, it is relevant for future studies to address the relation between pragmatic metrics and the manner in which syntactic structures are employed.

5.2 No discourse task elicited significant group differences in morphological complexity

Morphological complexity was assessed using the inflectional index, which divided the number of correctly inflected words by the total number of inflected words. Overall, morphological errors were uncommon (a frequency similar to that reported by Stark and Fukuyama, 2020), with the aphasia group making three times as many (n = 30) as the control group (n = 9). The low frequency of errors led to the inflectional index being non-robust, as it neither showed significant group differences in any discourse task in the analysis of variance, nor did it predict group membership in the binomial logistic regression.

However, a trend was observed in the Structured Interview, consistent with findings from Sajjadi et al. (2012), where a task effect in the inflectional index reached significance before correcting for multiple comparisons (Table 5). This result, contrary to our research hypothesis, may be partly explained by the design of the questions, which are intended to elicit verbs in various tense-mood inflections, potentially increasing the opportunities for inflectional errors to surface.

However, participants often opted for non-finite verbal forms instead of the target tensed forms, which may have attenuated group differences and could account for why the effect did not survive correction for multiple comparisons. Additionally, this task is cognitively demanding, as it prompts extended discourse through novel questions that require participants to respond via retrieving coherent episodes from long-term memory (Bliss & McCabe, 2006). This trend should be interpreted with caution and considered as hypothesis-generating until replicated in a larger sample, and possibly, with a finer grained morphological metric.

Incorrect person-number agreement of verbs accounted for 50% of the total morphological errors in the aphasia group, while gender agreement errors represented 20% (see Supplementary Table S7 for the classification of morphological errors). In contrast, verb tense errors were rare, amounting to 13%. This may be due to discourse strategies used by individuals with aphasia (Bastiaanse et al., 2002) to reduce linguistic demands, such as avoiding tense and person/number inflection on verbs. For example, a participant with aphasia responded "en el fin de semana, comprar (infinitive) mucha ropa" ("on the weekend, buying lots of clothes") instead of "compré Finally, although only numerically, the patterns of morphological errors found are not consistent with the tense-agreement dissociation reported in the literature on Spanish aphasia (Benedet et al. 1998; Díeguez-Vide et al. 2012; Gavarró & Martínez-Ferreiro, 2007; Martínez-Ferreiro, 2003 , 2010 , 2013; Moreno-Torres Sánchez et al. 2005; Stecher et al. 2024; for a review, see Martínez-Ferreiro et al. 2015). This could be due to the different profiles of the PWA tested in this study, very few of whom presented with frank agrammatism, but also to methodological aspects, such as the type of tasks used to elicit inflection (constrained vs. discourse tasks). Past tense is usually the most impaired across tenses (Bastiaanse et al. 2011): It is possible that, with the exception of one specific semi-structured interview question, the four tasks provided limited prompts for the use of the past tense, thereby reducing the number of tense errors observed.

However, this interpretation should be confirmed by more robust results with larger group sizes.

Also, a combination of discourse analysis and constrained tasks (e.g., sentence completion) might provide a more thorough assessment of the integrity of PWA's inflectional system and highlight potential dissociations between tense and agreement.

5.3 'Syntactic structures' is more accurate in predicting groups than proxies

The model including 'syntactic structures' (Agmon et al., 2024) variables together with the syntactic proxies, performed significantly better than the model that exclusively used syntactic proxies. The multidimensional metric of 'syntactic structures' was originally designed and tested by Agmon and colleagues (2024) for predicting age groups, with successful results. The present results indicate that 'syntactic structures' provide a model with good fitness and discriminatory power when predicting aphasia versus control groups. Crucially, its fitness and predictive power is not affected when excluding syntactic proxies such as MLU and verbs per utterance, which were found to be collinear with syntactic structure variables. Notably, the model is significantly enhanced in discriminative ability and fitness when error-centered variables are included. This suggests that including predictors that measure morphological and grammatical errors is relevant, as these variables indicate difficulties in computing morphosyntactic relations. Word-and utterance-level errors, characteristic of the discourse of speakers with aphasia, are frequently assessed in current aphasiology research and clinical practices (Stark et al., 2021b). Thus, it is appropriate that these linguistic phenomena are noted when designing a model that is discriminative between aphasic and non-brain damage discourse.

5.4 Implications for accounts of agrammatism

Recent accounts of morphosyntactic impairments in post-stroke aphasia have advocated for the processing, rather than structural, nature of the deficit. From this perspective, difficulties in the production (and comprehension) of verb inflection and of different types of structures do not stem from the loss of underlying syntactic representations (Tree Pruning Hypothesis, Friedman & Grodzinsky, 1997; Trace Deletion Hypothesis, Grodzinsky, 1995; see Druks, 2016 for a review), but from the damage to specific processing mechanisms (Kolk & Heeschen, 1992; Kok et al. 2007; McNeil et al., 1994; Thompson, 2003, to name a few; see a review in Bastiaanse & Thompson, 2012). Our approach and findings are agnostic to both structural and processing accounts, in that we limit our investigation to metrics that best detect morphosyntactic simplification to predict group membership. However, the different degrees of syntactic simplification that we observe within our PWA group are more easily accounted for under a processing account, since variability in performance is not compatible with the assumption that syntactic representations are unavailable to aphasic speakers.

The lack of online dependent variables, structured stimuli and instructions, and specific experimental manipulations, combined with recruitment criteria that extend beyond agrammatic patients, prevent us from pinpointing the precise syntactic processing mechanisms that may be impaired. Our finding that regression models including hierarchical syntactic measures are more accurate at classifying speakers with and without aphasia could, however, provide some hints about the levels of linguistic analysis at which impaired mechanisms could operate. Specifically, it suggests that in our sample of PWA, the impairment goes beyond the lexical level, reaching processing stages involved in e.g., syntactic structure planning and building. In this respect, two specific patterns are worth highlighting. First, the reduced proportion of left-branching structures, which may require the speaker to hold complex material in memory before reaching the head of the sentence, could reflect impairment in sentence planning mechanisms (arguably mediated by short-term and working memory deficits). Such impairments can be probed with dedicated tasks (Lee et al. 2015; Van Boxtel et al. 2023) and through the analysis of speech dysfluencies, though this falls beyond the scope of the present study. Second, the significant contribution of ungrammatical sentence proportion opens a window onto the integrity of monitoring mechanisms (Botvinick et al. 2001), i.e., the speaker's ability to detect and repair errors. PWA who produce a greater number of ungrammatical sentences may present with impaired monitoring that hinders self-correction, which could be further investigated using tasks tapping attentional mechanisms (e.g., the Attention Network Task; Fan et al. 2005). While theoretically plausible, these implications remain tentative and should be corroborated by data from structured linguistic and cognitive tasks collected in larger samples.

5.5 Discourse, syntax and the brain-language relationship

Despite being limited to behavioral data, this study carries meaningful implications for the brain-language relationship, which future research could further investigate. Specifically, the present results suggest that the heterogeneous brain damage in our sample, which resulted in aphasia, may have affected resources needed to necessary to successfully deploy complex syntactic structures, such as left-branching clauses and relative clauses (see Den Ouden et al., 2008 , Kirchner et al. 2018 and Lorca-Puls, 2024 for evidence regarding neuroanatomical correlates of complex syntax production and expressive agrammatism). As noted earlier, these syntactic devices differ not only in their complexity, but also in their locality and function. Relative clauses attach postnominally to an already established head, supporting local, within-sentence referential elaboration. Left-branching clauses, by contrast, are preposed and require the speaker to build and hold open a hierarchical dependency before reaching the main clause. Moreover, they typically encode temporal, causal and conditional relations that make up a discourse model.

Although mapping behavioral impairment to (lesioned) brain regions is clearly beyond the scope of this study, this functional distinction parallels proposals of a graded cortical hierarchy in which local, sentence-level combinatorial processing is supported by brain regions that operate over intermediate temporal integration windows, such as the superior temporal gyrus (Lerner et al. 2011). In contrast, maintaining and updating a discourse model across sentences involves also regions with longer temporal receptive windows, such as temporo-parietal and prefrontal areas (Lerner et al. 2011; see also Catani and Bambini, 2014), with these two levels interfacing rather than operating as separate modules. This hierarchy is based on narrative comprehension, but evidence of shared and coupled neural systems for the production and comprehension of naturalistic narrative speech (Awad et al., 2007; Giglio et al. 2022; Silbert et al., 2014) suggests that an analogous hierarchy could support narrative production as well. The selective vulnerability of left-branching structures in the narrative task could therefore stem from a bottleneck at this syntax-discourse interface, rather than from a generalized impairment in syntactic production.

5.6 Clinical and research implications

The evaluation of populations with clinical conditions of language should follow ecologically valid approaches such as discourse assessment (Davidson et al., 2003; World Health Organization, 2018). However, most researchers (Stark et al., 2021b) and speech and language therapists (Bryant et al., 2017) use a single elicitation method for evaluating discourse production in aphasia, with the single-picture description most frequently administered in English-speaking countries (Stark et al., 2021b). Under these circumstances, it is possible that aphasiology researchers and speech and language therapists are selecting insensitive discourse elicitation methods (Stark & Fukuyama, 2020). Therefore, and following the rationale of Schnur and Wang (2023), it is relevant to compare discourse elicitation methods in order to inform both empirical research on connected speech production and clinical strategies for identifying the most suitable production task or combination of tasks for the assessment of a specific language impairment. The present research addressed this need in the clinical field of Spanish aphasia by aiming to identify the most sensitive discourse tasks and metrics for eliciting and detecting syntactic and morphological complexity simplification.

Based on our findings, two methodological suggestions can be put forward for researchers and clinicians aiming to comprehensively assess syntactic complexity in Spanish speakers with aphasia. Firstly, when evaluating syntactic complexity, it is pertinent to conjointly administer descriptive and narrative tasks, such as the Cookie Theft picture description (or an equivalent single-picture description task, e.g. the Picnic Scene from the Western Aphasia Battery; Kertesz, 2007) and a narrative task akin to our Hare and the Tortoise story retell. This recommendation is supported by the reliable group differences elicited across several syntactic metrics by the descriptive task, the group difference in ungrammatical utterances elicited by the narrative task (a critical clinical marker of aphasia), and the distinct patterns of syntactic resources observed across tasks, consistent with Stark and Fukuyama's (2020) argument for the use of varied discourse elicitation methods for aphasia evaluation.

Secondly, from the obtained discourse samples, it is beneficial for researchers to measure a set of fit and noncollinear indicators such as noun-verb ratio, a broad embedding index (e.g., the employed subordination metric), dependency distances between the modifying verb within the relative clause and the relativized noun in the main clause, depth of left branching clauses, length of the complex noun phrases and adjectival/adverbial modifications, and proportion of ungrammatical utterances. The obtained measures could then greatly inform research and clinical settings to guide rehabilitation procedures. 8

Together, these factors prevented us from investigating and discussing genre effects on the morphological and syntactic complexity across different aphasia subtypes, severity and cognitive profiles, thus restricting our comparisons to the PWA vs. control group contrast.

Previous aphasiology research has found evidence for the simplification of both syntactic (Bastiaanse et al., 1996a; Glosser & Deser, 1991) and morphological complexity (Bastiaanse et al., 1996b; Bastiaanse et al., 2002; Martínez-Ferreiro et al., 2017) in fluent and nonfluent aphasia.

A larger, more controlled, sample could allow for testing the sensitivity and accuracy of our metrics across aphasia profiles and exploring possible interactions with tasks, an avenue we intend to pursue in future extensions of this work. Nevertheless, this investigation represents an initial step toward validating the hierarchical syntactic structure metrics as tools for accurately detecting patterns of syntactic simplification in PWA and language-unimpaired speakers.

A second limitation of the present study is the failure to include covariates in the analyses due to heteroscedasticity in most variables, which required non-parametric tests. Increasing the sample size is unlikely to resolve this issue, as the 'syntactic structures' metric showed frequent floor effects and a strongly left-skewed distribution, as anticipated by Agmon et al. (2024).

Likewise, the error-centered metrics faced similar challenges. These limitations may be intrinsic to the 'syntactic structures' metric, as it does not account for elements essential to communication, allowing participants to complete tasks without using complex syntactic structures like relative or left-branching clauses.

A third limitation is the lack of reliability and stability estimates for the employed outcome variables. Therefore, as the employed outcome variables lack standardization, it is uncertain to what degree each reflects the linguistic integrity of the participants. Thus, future extensions of this study should investigate which syntactic and morphological discourse metrics are stable over time through test-retest studies with speakers with aphasia (Stark et al., 2021a).

A further limitation of the present study concerns the cross-linguistic generalizability of task-based findings. Our results suggest that the narrative task was not more sensitive than the descriptive task in detecting syntactic complexity deficits in Spanish-speaking PWA, which contrasts with findings reported in English (Schnur & Wang, 2024; Stark, 2019; Stark & Fukuyama, 2020; Ulatowska et al., 1981; Ulatowska et al., 1990). Moreover, the morphological properties of Spanish, such as the bound nature of verb stems, may constrain the type of errors and avoidance strategies available to PWA, which would in turn influence the sensitivity of the inflectional index. However, the present study was not designed to directly compare task-elicited syntactic or morphological complexity across languages and therefore cannot determine whether this discrepancy is attributable to language-specific morphosyntactic properties of Spanish or to other methodological factors discussed above. Future research should directly address these gaps by comparing task-elicited syntactic and morphological complexity across languages using equivalent tasks and metrics, in order to better understand how language-specific properties interact with discourse genre in shaping morphosyntactic production in both typical and aphasic populations.

Finally, the current study only employed an inflectional index (an accuracy indicator based on Bastiaanse et al., 1996b) as a measure of morphological complexity. The results suggest that the inflectional index evokes exceedingly modest differences between the aphasia and control groups. In order to have a better insight of task effects in verb production within aphasic discourse, future research should inspect the distribution of finite and non-finite forms (Martinez-Ferreiro et al., 2017), and implement a finer-grained analysis on the types of inflections, at the interface with other levels of language (Bastiaanse & Prins, 1994).

6. Conclusion

The current study showed that picture-based descriptive and narrative tasks are sensitive tools for the detection of syntactic simplification in the spontaneous speech of Spanish PWA, while the analysis of morphological integrity may require the combination of (dialogic) discourse with constrained tasks. Fine-grained aspects of syntactic production, such as subordination, relative clauses and left-branching depth, emerge as highly accurate predictors of speakers' group membership. In conclusion, this study highlights the combined utility of specific discourse tasks and structured metrics to reveal syntactic simplification in aphasia, underscoring the value of multi-dimensional assessments in comprehensively understanding language impairments.
